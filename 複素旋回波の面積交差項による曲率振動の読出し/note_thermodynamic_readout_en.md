After that discovery, while investigating the definitions of temperature and entropy for particle systems in standard theory, a question suddenly arose.

The system I am studying presupposes neither space nor time as fundamental. Instead, it contains only M = N(N-1)/2 complex number relationships. This system is self-consistent and satisfies two conditions: a zero closure Σxn² = 0 and a finite recurrence U^N = I with period N.

**But in such a system, how are temperature and entropy defined?**

## Scale Invariance and the Fixed Point at the Origin

The characteristic feature of this system is that it is scale invariant.

No matter how we multiply all complex quantities by a constant, the zero closure relation remains unchanged:

Σxn² = 0 ⟹ Σ(λxn)² = λ² Σxn² = 0

In other words, there is no absolute scale. However, zero—the origin O—remains fixed under any scale transformation.

Here, an important discovery emerged.

We can decompose the zero closure into multiple zero sums: 0 + 0 + 0 + ⋯ = 0

If we regard each local zero closure Σxn² = 0 as a central projection and express it as Σxn'² = R², it can be interpreted as a projection onto a sphere of radius R.

When multiple spheres exist, they **all share the same origin O**.

Like in ancient geocentrism, the origin O—a fixed point—exists at the center of all worlds.

If there exists a fixed point in the scale direction (the origin O), might there also be a similar fixed point in the definition of evolution U^N = I?

## State Counting and Entropy

Let me begin from a fundamental perspective.

Boltzmann showed the relationship between state count Ω and entropy S as a foundation of statistical mechanics:

S = ln Ω

This relationship was derived from studies of particle systems and atomic gases, but more fundamentally, it is a counting problem: "How many distinct microscopic states realize the same macroscopic state?"

But in my system, which presupposes neither spacetime nor particles, how do we "count states"?

## Central Projection and the Observer

Here lies a crucial point.

When we decompose zero closure into multiple local zero closures, **there is not a unique way to decompose it**.

The same zero closure can be decomposed in different ways. In other words, even in the same fundamental system, the number N' of complex quantities in the subsystem depends on which subsystem we choose as the "object of observation."

What happens then?

If N' differs, the number of self-consistent states that are permitted also differs.

If we denote the state count as Ω(N'), then the state count itself changes depending on "which subsystem the observer chooses."

## The Emergence of Energy-Like Quantities

From the finite recurrence condition U^N' = I, the fundamental phase step is given by 2π/N'.

From this granularity in phase space, we can naturally construct an additive energy-like quantity:

E_read = Σ(1/N'_k)

This is not physical energy itself, but rather a metric derived from the internal phase scale of the observed subsystem.

However, if we take the ratio of the change in state count ΔΩ to the change in this energy-like quantity ΔE, we can define a quantity resembling temperature:

1/T_read = ΔS/ΔE = Δln(Ω)/ΔE

## Absolute Zero as a Fixed Point

Here, an important symmetry emerges.

Fixed point in the scale direction: **the origin O (geometric zero)**
Fixed point in the evolution direction: **absolute zero T = 0 (thermal zero)**

Do both truly arise from the same mechanism?

Strictly speaking, the answer is no. However, both represent "natural reference points in a scale-invariant system."

The zero closure Σxn² = 0 is invariant under scale transformations, yet the origin O alone remains.

Similarly, from the relationship 1/T = ∂S/∂E between state count Ω and temperature T, in the limit where material states are lost (T → 0), the information structure of the system exhibits a singularity.

This is not merely a formal analogy, but **suggests an essential property of the relational structure that precedes spacetime**.
