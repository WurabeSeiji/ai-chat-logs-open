## 問題設定：順序の逆転

N 個の要素を先に置けば、全二体関係の数は M = N(N-1)/2 になります。この数え上げ自体は正しい。しかしその前に、次の仮定が暗黙に入っています。

- N 個の節が先に存在する
- 節どうしを区別できる
- 節の同一性が変化の途中でも保存される
- すべての二節間に関係がある
- 各関係は一組の端点を持つ

基礎にあるものが無名な複素波だけなら、波には最初から頂点番号も辺番号も付いていません。配列の添字は計算機の記憶位置であって、物理的な名前ではない。

そこで本論文では順序を逆転します。完全ネットワークから関係量を出すのではなく、

無名な複素波集合 → 一意な因数分解 → 幾何・局在・凝縮体・動力学の読出し

を問う。完全ネットワークは存在論的前提ではなく、無名な関係量がシンプレックスへ一意に再構成されたときに初めて判明する再構成証明書になります。

## 基礎状態

基礎状態は、置換で同一視した複素波の多重集合 𝒲 = {w1, ..., wM}/SM だけ。これに二つの拘束を課します。

- 二乗ゼロ閉塞: Σwm² = 0（エルミートノルムではない複素二乗和。並び順に依存せず、共通スケール変換に対して閉じる）
- 有限回帰: U^q 𝒲 ≃ 𝒲（各波が同じ場所へ戻る条件ではなく、集合として置換同値を含めて元へ戻る条件）

計算ステップ番号 s は計算順序であって物理時間ではない、と明示的に区別しました。時間として読める因子は、内部巡回から別に再構成されなければならない。

## 因数分解としての構造読出し

無名集合から構造を読む操作を因数分解写像として定義します。因子 F = (C, θ, R, ε) は、部分多重集合 C、潜在パラメータ θ、再構成規則 R、残差 ε の組。

一意性の判定は、許容対称性（波の置換、因子名の置換、全体位相、共通スケール、合同変換）で商を取った非同値因数分解数 Ωfact で行います。

- Ωfact = 0 → 再構成不能
- Ωfact = 1 → 物理的同値を除いて一意
- Ωfact > 1 → 複数の非同値な解釈が残る

植え込んだ正解が一つ見つかっただけでは存在の証明にすぎない。一意な創発を主張するには、非同値な別解がないことの確認が必要です。

## 各構造の定義

- シンプレックス：無名な複素二乗長集合 D から、複素 Gram 行列の rank・非退化性・閉塞条件を満たす辺割当てが一つだけ残ったとき、n 頂点シンプレックスとして読む。このとき Kn は入力ではなく結果
- 倍音：基底波を先に置かない。共通基本量と整数比 ωm ≃ km ω0 で因数分解できる部分集合が見つかったとき、結果として倍音系列だったと読む
- 局在：倍音因子の合成読出しが位相 φ0 付近に鋭いピークを持つこと。背景空間内の一点という意味ではない。位相分解能は最高倍音次数 K に対して Δφ 〜 1/K
- 凝縮体：多数の無名波を少数の潜在パラメータで再構成できる持続的な低ランク因子。構成波が入れ替わってもよい。保存対象は要素名ではなく因数分解型
- 動力学：名前付き波の軌跡ではなく、因子署名 Σ(F) を保存しながら共通位相中心だけが変化する過程。移動とは、同じ材料が位置を変えることではなく、同じ因数分解型が位相中心を変えながら持続すること

## 対称性の二層構造

必要なのは最大の対称性ではありません。

因数分解を成立させる強い対称性 ＋ 読出しを選択する小さな対称性の破れ

の二層構造を作業仮説としました。完全対称点では方向・中心が縮退し、大摂動では因子が失われる。その間に形状を保存しつつ位置が選択される有限領域が存在するか、が検証対象です。

## 仮説と検証計画

仮説は H1〜H7 に分割し、個別に否定できる形にしました。

- H1: 無名シンプレックス再構成の一意性
- H2: 完全ネットワークの事後的出現
- H3: 倍音因子による局在読出し
- H4: 低ランク因子としての凝縮体
- H5: 因子型の保存としての移動
- H6: 創発的な空間・時間・対象の相互整合
- H7: 強い対称性と小さな破れの両立領域

数値実験は生成器と復元器を完全分離し、生成後に頂点番号・辺端点・生成順序・倍音次数・座標をすべて削除してから復元器へ渡します。

- E0: 置換不変性試験
- E1: 正解埋込みシンプレックス
- E2: 正解埋込み倍音・局在
- E3: 複合因子の整合性
- E4: 持続・移動ロック
- E5: ブラインド対照（構造を植え込まない群との偽陽性比較）
- E6: 摂動と臨界性

成功条件8項目と反証条件10項目を事前登録形式で固定しました。ランダム対照群でも同程度に構造が検出されるなら復元条件が弱すぎる、探索拡張で一意性が消えるなら見かけだった、など、失敗の判定方法まで先に書いてあります。

## 位置づけ

本論文は証明論文でも数値結果報告でもありません。空間・時間・粒子が導出されたとは主張していない。無名性を破らずに創発構造を検証するための、反証可能な問題設定を固定した論文です。無ラベル距離幾何（Boutin–Kemper 2004, Gortler–Theran–Thurston 2019）と問題意識を共有しつつ、複素二乗量・二乗ゼロ閉塞・有限回帰・因子持続性を同一の読出し枠組みへ載せた点が追加部分です。
