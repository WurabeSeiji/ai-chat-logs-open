# 時空なき複素関係系から温度が生まれる

詳細はコメント参照

空間・時間・粒子を基礎に置かない系でも、自己無撞着な複素関係だけから、温度とエントロピーを構成できる。
ゼロ閉塞という基本条件と、有限周期性から、状態数・エントロピー・温度型量が自然に現れる。
観測者が選ぶ部分系によって、温度そのものが変わる——これが観測者依存性。
絶対零度T=0は、スケール変換の不動点である原点Oと対称的に、系の本質的な特異点。
興味深いことに、この理論は観測宇宙のバリオン対光子比10^-9と予想外の整合性を示す。
ただの複素関係から、物理量が湧き上がる。疑問が研究を導いた。
