## Zenodo Metadata

**Keywords:** anonymous complex waves, factorization, zero-square closure, finite recurrence, simplex, unlabeled distance geometry, localization, condensate, emergent dynamics, numerical experiments

**Description:** Working hypotheses defining emergent structures (simplices, harmonic series, localization, condensates, persistent objects) as unique factorizations of an anonymous complex wave multiset identified under permutations. The complete network is a reconstruction certificate, not an input. Dynamics is preservation of factorization type with a changing common phase center. A falsifiable numerical verification program with ground-truth embedding, blind controls, permutation-invariance, perturbation, and persistence tests is fixed.
