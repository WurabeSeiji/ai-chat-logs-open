# 重力曲率がある測地線の上で、複素数の波が何をしているのか

## きっかけ

曲率のある空間で、測地線に沿って飛ぶ複素数の波のことを考えていました。

すると、あることに気づきました。

**曲率半径 R の方向って、測地線上から直接は観測できない方向だ。**

時間が観測できない方向だから虚数 $i$ で表現するのと同じように、曲率半径 R の方向も虚数でいいんじゃないか？

## 空間方程式の書き換え

通常、平坦な4次元時空は：

$$x^2 + y^2 + z^2 - t^2 = R^2$$

で表します。でも曲率がある場合、曲率半径 R の項も同じように左辺に持ってきて、虚数扱いにしてみると：

$$x^2 + y^2 + z^2 + (it)^2 + (iR)^2 = 0$$

**ああ、これって二乗閉塞の形だ。**

私のシリーズの公理：

$$\sum_{n} x_n^2 = 0$$

の形式になっている。

つまり、測地線から見ると、**曲率半径 R 方向は虚数方向に見える** ということです。

## 複素数の波の二乗

ここからが重要です。

複素数 $a + ib$ で表す波を二乗すると：

$$(a + ib)^2 = a^2 - b^2 + 2iab$$

展開すれば当たり前の計算です。

でも、**あ、ちょっと待って。**

交差項 $2iab$ に虚数がついてる。

## 虚数方向の値

実数部分 $a^2 - b^2$ は、実数領域（測地線方向）の二乗振幅として理解できます。

では $2iab$ は？

これって、**測地線に対して直交する虚数方向の値** なんじゃないかな。

つまり、曲率半径 R 方向に「何か」が伝わるとしたら、その「何か」ってこの交差項なのかもしれない。

## ひらめき

では、曲率半径 R 方向に伝わる値 $2iab$ って、いったい何なのか？

考えてみました。

もしかして、**これって重力波じゃないか？**

## 調べてみた

調べてみることにしました。

重力波の特徴：
- 周波数が計算から出てくる
- 振幅が観測と同じオーダーで出てくる
- 二倍角の偏極構造を持つ

複素波の交差項から出てくるもの：
- 虚数方向の面積振動
- 二倍角構造が自動的に現れる
- 曲率スケールを与えると周波数が決まる

以外なほど似てる。

## 簡潔さの力

一般相対性理論も使わない。標準理論も使わない。

単に：
1. 空間が曲率半径 R を持つ
2. 複素数の波がそこを飛ぶ
3. その二乗の交差項を見る
4. 虚数方向をキャッチする

これだけ。

シンプルすぎるくらいシンプルな方法なのに、重力波的な波が表現できてしまった。

## なぜこんなことが起こるのか

測地線という「観測できる方向」と、曲率という「観測できない方向」。

この二つの間に、複素数という数学的構造が橋渡しをしている。

複素数の二乗によって自動的に現れる交差項が、ちょうど「観測できない方向から伝わってくる波」を表現するのに適している。

形式的な計算遊びが、現象の本質に触れてしまったのかもしれません。
