# 絶対零度の幾何学 ――時空なき系での温度と熱力学の読出し

## はじめに

前回のノート「複素波の面積交差項が見せる重力波」では、複素数で表現した波が時空曲率のある測地線の上で振動すると、重力波的な波が時空曲率方向に伝達する可能性があることを見つけました。

その後、標準理論における粒子系の温度とエントロピーの定義を調べていて、ふと疑問が生まれました。

私が研究している系は、空間も時間も基礎には置かない、ただし M = N(N-1)/2 個の複素数の関係だけが存在する系です。この系は自己無撞着で、二乗ゼロ閉塞 Σxn² = 0 と、N回数での有限回帰 U^N = I という二つの条件を満たします。

**では、このような系では、温度とエントロピーはどのような定義になるのだろうか？**

## スケール不変性と原点の不動点

この系の特徴は、スケール不変であることです。

すべての複素量を定数倍しても、ゼロ閉塞関係は変わりません：

Σxn² = 0 ⟹ Σ(λxn)² = λ² Σxn² = 0

つまり、絶対的なスケールがない。ただし、ゼロ（原点 O）だけは、どんなスケール変換でも動かない。

ここで重要な発見が起きました。

ゼロ閉塞を複数のゼロ和へと分解できるのです：0 + 0 + 0 + ⋯ = 0

それぞれの局所ゼロ閉塞 Σxn² = 0 を中心投影と考えて、Σxn'² = R² と表すと、半径 R の球面への投影として解釈できます。

複数の球面が存在するとき、それらは**すべて同じ原点 O を共有**している。

まるで古代の天動説のように、原点 O という不動点が、すべての世界の中心に存在する。

## 温度の不動点を求めて

スケール方向での不動点（原点 O）が存在するなら、発展方向 U^N = I の定義にも、同じような不動点があるのではないか？

そう考えていて、ふと気づきました。

**温度にも、絶対零度 T = 0 という不動点がある。**

これは偶然ですか？

原点 O に相当する幾何学的な不動点が存在するなら、温度的な定義にも不動点があるのではないか。

そう考えて調べてみました。

## 状態数とエントロピー

基礎的な観点から始めます。

Boltzmann は統計力学の基礎として、状態数 Ω とエントロピー S の関係を示しました：

S = ln Ω

これは粒子系や原子気体の研究から導出された関係ですが、より基礎的には、「何種類の異なる微視的状態が、同じ巨視的状態を実現するか」という数え上げの問題です。

では、時空も粒子も仮定しない私の系では、どのように「状態」を数えるのか？

## 中心投影と観測者

ここが重要なポイントです。

ゼロ閉塞を複数の局所ゼロ閉塞へ分解するとき、**分解の仕方は一通りではありません**。

同一のゼロ閉塞が、異なる方法で分解できる。言い換えれば、同じ基礎系でも、どの部分系を「観測対象」として選ぶかによって、その部分系の複素量の数 N' が異なる。

するとどうなるか？

N' が異なれば、許容される自己無撞着な状態の数も異なります。

これを Ω(N') と表すなら、状態数そのものが「観測者がどの部分系を選ぶか」によって変わるのです。

## エネルギー型量の出現

有限回帰条件 U^N' = I から、基本位相刻みは 2π/N' で与えられます。

この位相空間の粗さから、自然に加法的なエネルギー型量を構成できます：

E_read = Σ(1/N'_k)

これは物理的エネルギーそのものではなく、観測する部分系の内部位相尺度から導出される計量です。

しかし、状態数の変化 ΔΩ とこのエネルギー型量の変化 ΔE の比を取ると、温度のような量が定義できます：

1/T_read = ΔS/ΔE = Δln(Ω)/ΔE

## 不動点としての絶対零度

ここで重要な対称性が見えてきます。

スケール方向での不動点：**原点 O（幾何学的ゼロ）**
発展方向での不動点：**絶対零度 T = 0（温度的ゼロ）**

両者は本当に同じメカニズムから生じているのか？

結論から言うと、厳密には異なります。しかし、両方とも「スケール不変な系における自然な基準点」です。

ゼロ閉塞 Σxn² = 0 は、スケール変換に対して不変ですが、原点 O だけは残る。

同様に、状態数 Ω と温度 T の関係 1/T = ∂S/∂E から、物質的状態が失われる極限（T → 0）では、系の情報構造が特異点を持つ。

これは単なる形式的な類似ではなく、**時空以前の関係構造の本質的な性質**を示唆しています。

## バリオン対光子比との奇妙な一致

興味深いことに、この理論的枠組みは、観測宇宙のある特性と予想外の整合性を示します。

N ~ 10^60 の要素から M ~ 10^120 の二体関係を作るとき、全許容状態の中で「バリオン的」と読める局所構造は極めて稀です。

その希薄性が、観測宇宙のバリオン対光子比 10^-9 と矛盾しないのです。

これが数値的な偶然か、それとも本モデルが宇宙論的な何かを捉えているのか。

現段階では、それは数値計算で検証すべき課題です。

## 疑問から研究へ

この探究を通じて感じるのは、最初の疑問がどれほど大切かということです。

「なぜ原点が特別なのか？」
「なぜ温度にも不動点があるのか？」
「これらは本当に関係しているのか？」

こうした問いが、数学的な構造を照らしていく。

時空も粒子も持たない、ただの複素関係から、スケール、温度、状態数、エントロピーという物理的な概念が自然に現れる。

それは、物理学の基礎が想像以上に深いところにあることを示唆しています。
