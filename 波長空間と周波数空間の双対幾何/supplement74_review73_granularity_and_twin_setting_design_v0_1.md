## 1. 補遺73 レビュー

### 1.1 承認

1. 相互再検証の完結(s=9 アンカー4点・s=11 の W・Δ・TV、全点一致)— 「0.0007=二結果圧縮」は二者独立確定。
2. 結合多重集合衝突 0 件への訂正(初版バグの明示)— 検証規律として正しい。
3. graded 規約幅の計測(s=9 でも graded Δ=0.0163=二値の24倍、ただし全規約で O(0.1) 乖離は不変)— 圧縮判定の追加傍証+構造結論の頑健性の両立。
4. 台の一致の3シェル双方向成立(零チャネル=(1,1,s−2) 型のみ)。

### 1.2 訂正・精密化(4点)

**R1(主要):結合振幅のキーイングは「逐次読み」に対応する。** 貴実装の結合配置キー frozenset([fs1,fs2]) は双子への**分割を区別可能**として扱う。しかしホログラムは占有集合のみの関数なので、**一回イベント読みでは同一の結合6セル集合の異なる分割は記録で区別不能**であり、合併集合キーで分割横断のコヒーレント和を取らねばならない({333,333} は合併あたり最大 C(6,3)/2=10 分割 — 効果は実質的)。分割キーが正当なのは、第一イベントの追記が分割を記録する**逐次読み**である。よって:完全相殺5対・配置依存の劇的効果は現状「分割キー(=逐次的コヒーレンス)変種の事実」と限定し、**合併キー版(一回読み)の再計算**を経てから構造結論を出すべき(相殺が埋まるか残るかは判定情報)。

**R2:「D3=インコヒーレント代理」の精密化。** 貴 incoherent は $|\eta|=1$ ゆえ**排他つき経路対計数**であり、D3(チャネル一貫×双子積×二値整合)とは別の対象。数値近接(0.98019 vs 0.98195)は配置あたり経路多重度が小さいことの帰結で、同一性ではない。維持すべき確定判定は「**D3 は結合コヒーレント振幅ではない**」。

**R3:単調性の言い換え。** 総称型系列((2,1,0,0)→(2,1,1,0)→(2,1,1,1))は 0.00068 → 0.241 → 0.174 と**非単調**。「乖離は s とともに成長」ではなく「**恒常的に O(0.1〜0.9)、型・セクター依存が大、最大値は成長**」が正確。

**R4(小、各一行検査):** (a) (2,2,0,0) 3セクターの Δ=0.90418 同値(5桁)— 導出分布自体が3セクターで一致するのか、Δ のみの一致か。(b) (3,0,0,0)B の Δ=0.50000 ちょうど — W の縮退(単一チャネル集中?)の確認。

## 2. 監査発見:干渉粒度と 0.96644 の同定(claude.ai 計算)

正準 W はチャネル一貫 — **記録で区別可能な終配置を跨いで**コヒーレント和を取っている。配置粒度 $W'_F=\sum_K |z_K|^2$($K$=終配置、衝突除外)を計算すると:

| チャネル | 経路 | 終配置数 | W(チャネル一貫) | W′(配置粒度) |
|---|---|---|---|---|
| (1,3,5) | 160 | **8** | 1088 | **576** |
| (3,3,3) | 36(うち16はセル衝突) | **2** | 40 | **40**(2配置が直交) |

双子式:チャネル一貫 0.98195 / **配置粒度 0.96644**。

> **同定**: 補遺73 の掃引コヒーレント最小値 0.96644 は、配置粒度の非結合積値 $2W'_{531}W'_{333}/(2W'_{531}W'_{333}+W_{333}'^2)$ に**厳密一致**。つまり貴掃引の「床」は配置粒度測度であり、上方偏差(0.972/0.994/1.0/完全相殺)が親対配置の排他・干渉効果である。掃引の値構造は {配置粒度の床} + {関係クラス依存の補正} と読める。

副産物2件:(i) 333 の36経路中**16本は kept∈{vc,vd} のセル衝突**(配置読みでは二重占有)だが、除外しても |z| 不変 — **衝突部分和の厳密相殺候補(第五の相殺候補)**。部分和=0 か位相回転かの一行検査を。(ii) 終配置数の少なさ(8/2)自体が輸送拘束の強さの表現 — 配置あたり経路多重度 20/10 がチャネル一貫と配置粒度の差(1088 vs 576)=配置間干渉の量を決める。

## 3. (iii) の概念設計:干渉粒度=記録区別能

**原理(一本)**: コヒーレント和は記録が区別しない代替の間でのみ取られる。根拠は在庫:測定=追記(補遺36)、記録=占有集合の関数(ホログラム)、存在する記録は現在読める(補遺36 §2.2)。これは外部から輸入するデコヒーレンス規則ではなく、**記録定理の干渉版**である。

この原理で「物理設定」は二つの指定に分解される:

**(α) 親対配置 — 固定であり可読。** 崩壊前ホログラムには親対の交差線が載る(補遺36 V2:前=2本の線)。よって配置は確定したモデル内データであり、導出双子測度は本来**関係クラス条件付き** $P(\cdot\,|\,\text{class})$ である。平均は認識論的操作としてのみ許され、配置盲目の数え上げ測度(D1/D2)と比較する場合は一様配置平均を**併記**する(配置盲目≠配置平均であることに注意)。
**予言(検証可能)**: $P(X|\text{pair})$ は親対の B₄×swap 関係軌道(補遺34 の21クラス)上で**一定**。掃引値 {0.966, 0.972, 0.994, 1.000, 完全相殺} はこの軌道分類で整理されるはず — 開問題 (i)(相殺5対の構造)の具体的取っ手。

**(β) イベント構造 — 唯一の自由ビット。** 一回か逐次か(補遺34 §3.2/36 §6.1 の留保)は、記録原理を介して**干渉粒度に翻訳**される:
- **一回イベント**:中間追記なし → 結果=合併占有集合 → 分割は区別不能 → **分割横断コヒーレント**(合併キー)。
- **逐次**:第一イベントの追記が双子1の終配置を確定 → 分割は記録済み → **分割インコヒーレント**、第二段は排他条件付きコヒーレント。

歴史的な一括/逐次(数え上げ、補遺36 V1)は、この同じ二分の**位相なし影**である。全体は次の表に整理される:

| | 一回イベント | 逐次 |
|---|---|---|
| 数え上げ | D2(一括 60/61) | D1(逐次 396/403) |
| 振幅 | **A_one**(合併キー結合振幅 — 未計算) | **A_seq**(段ごと配置粒度・排他条件付き — 未計算) |

(全セル条件付きで関係クラス指定、粒度はチャネルの情報クラスに従う — 下記。)

**粒度のチャネル依存(精密化)**: 記録区別能はチャネルの情報クラス(補遺17/38)に依存する。(5,3,1)=ホログラフィック(配置完全可読)→ 配置粒度。(3,3,3)=干渉計型(関係のみ可読)→ 可読な**関係クラス粒度**(配置より粗い → より多くの代替がコヒーレント)。チャネル一貫(0.98195)と配置粒度(0.96644)はこの「情報クラス別粒度」の両側の近似であり、記録原理の完全な実装は**チャネルごとに可読クラスで束ねる**こと — これが本設計の主提案。

**判定の内在性**: 一回/逐次は計算可能な別予言を与える(一回=配置依存の劇的効果(相殺対)、逐次=数え上げ近傍が見込み)。どちらをモデルが実現するかは、同時追記の存否(補遺48 の導出時計:二つの追記が同一ティックに乗れるか)との整合で攻められる — 登録のみ、主張しない。

## 4. Claude Code への引き継ぎ仕様

1. **合併キー版掃引(s=9、一回読み)**:R1 の再計算。完全相殺5対は残るか埋まるか。
2. **関係クラス分類**:親対を不変量(vp₁·vp₂、s(vp₁±vp₂)、軸台の重なり)で分類し、P(X|pair) のクラス一定性を検証(§3α の予言)。相殺対の位置を同定(開問題(i))。
3. **A_seq の実装**:第一段=双子1の配置粒度コヒーレント測度で配置を選択・追記、第二段=排他条件付き同測度。D1=396/403 との比較 — 近ければ「0.0007 ギャップはイベント構造でなく振幅/計数の差」と局在が確定し、遠ければイベント構造成分が分離できる。
4. **粒度系列**:衝突部分和=0 の確認(§2 副産物 (i))、情報クラス別粒度版の双子式値、s=11/13 の W′ 系列(配置粒度版 Δ′(s))。

## 5. 正直な限界

2. (α) の「クラス一定性」は予言であり未検証(引き継ぎ2)。
