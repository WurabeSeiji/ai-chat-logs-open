## 1. 辞書:単位円幾何との明示的対応

軸ごとに次の対応が成立する(すべて厳密)。

| 本モデル | 複素極座標モデル(振幅1固定) |
|---|---|
| (cos, sin) 二重項 | 複素数 $z$ の $(\mathrm{Re}, \mathrm{Im})$ |
| 振幅なし規律(論文9 §2.3) | $\lvert z\rvert=1$ の固定 |
| 枝の離散群($T_{1/4}$: cos→sin→−cos→−sin) | 位相の **Z₄ 離散化** $\{1,i,-1,-i\}$(ガウス整数の単数群) |
| 零点 $\delta_{\min}^2=\tfrac12$ | 単位円の厚み=直交位相成分の真空揺らぎ $\hbar/2$($\hbar=1$) |
| $SO(1,1)$ ブースト(論文6 §7.1) | スクイーズ変換 |
| 位置=位相(論文9 §2.4) | $z=e^{2\pi i k x}$ の偏角 |

設計者はこの同型を当初から自覚して組み立てており、本補遺はその自覚の正式な記録である。

## 2. 二つの独立な入力:ω と J

精密化を一つ。「共役」と「直交」は同じものの二つの顔ではなく、**二つの独立な入力**である。

- **ν–λ の共役性**($\nu\lambda=1$、対数平面の双曲構造、最小面積 $\tfrac12$)→ **シンプレクティック形式 $\omega$** の担い手。
- **cos/sin の 90° 位相差**(実定在波辞書の二重化)→ **複素構造 $J$** の担い手。

幾何学的量子化の運動学が要求する二構造($\omega$, $J$、両立して Kähler)を**両方とも公理として入力した**からこそ、体系の幾何は振幅1の複素極座標と一致する。どちらか一方だけでは一致しない。

## 3. 循環の境界線

主張の強度の管理のため、結果を二類に区分する。

**(A) 入力幾何の反響(「導出」と呼ぶべきでないもの)**:不確定性の床、スクイーズ自由度、波動性、干渉の存在自体、最小面積の不変性。これらは §1–§2 の入力を入れた時点で幾何的に約束されていた。

**(B) 単位円幾何からは決して出ない発見(シリーズの実質的成果)**:$N_0(3)=137$、奇数則と $R^2$ 分類定理、mod 4 / mod 8 選択則、安定種 $\{1,3,5\}$ と敷居 $s=7$、分岐比 192:56、例外なし分裂定理、d=4 の三重選択(検閲天井・mod 8・自己双対種子)、ホロノミー $\pi/2$ と SO(4) 強制、頂点の二つの独立な1単位不足(R/Q)。これらは離散格子の**算術**の産物であり、設計図に入っていなかった。

論文群の「主張しないこと」欄はこの境界を概ね守っているが、本補遺により設計レベルで明文化する。

## 4. 凍結=未決の閉合

凍結した自由度は二つであった:

1. **振幅**($\lvert z\rvert=1$ 固定)
2. **連続位相**(Z₄ への離散化)

シリーズ完結時点の二大未決も二つである:

1. **重ね合わせの所在**(=振幅の線形構造、論文12 §4.2)
2. **位置・並進の不在**(=連続位相、位置プログラム)

> **閉合**: 未決リストは凍結リストの像と正確に一致する。30年来の直観で凍結した二自由度の影が、構成の最後に同じ形で戻ってきた。これは (i) モデルが内的に整合している証拠であり、(ii) 「何を界面で復活させるべきか」の指定そのものである。

## 5. Fock 的読みと運動の所在

Fock 状態の言葉では:$\lvert z\rvert$ 確定・位相不定(離散/ゲージ)の状態は**数状態**であり、本モデルの粒子(エネルギーラベル確定)は Fock 的である。運動は**コヒーレント状態** — 数状態の振幅重ね合わせ — に住む。位置の不在と重ね合わせの不在が同じ扉に収束する理由は、この一行に要約される。

## 6. 関連プログラムへの接続

- **位置プログラム**(前回討議):本モデルの格子=運動量空間。位置空間は保存電荷格子 $\mathbb{Z}^4$ の **Pontryagin 双対** $T^4$=辞書のトーラス=λ側記録面そのものであり、必要な追加状態データは断片ごとの集合的梯子位相 $x_a$(**位相読み**=第二の読み原理、公理在庫への追加)。並進の Noether 電荷は $\Sigma k$ であり、論文12 §7.1 のベクトル保存則 $v_5\pm v_3=\pm v_9$ として**モデルが先回りして生成済み**。大域並進はゲージ、相対位置(縞の位相)が新観測量。位相の設定・更新は頂点 — 頂点写像・位相接続則・振幅問題と同一の扉。
- **清水リライト・プロジェクト**:本補遺の辞書は「$[x,p]=i\hbar$ を矩形波ソリトンの存在条件から」「Robertson=位相空間の面積」という命題の構成的実証である。
- **W8 シリーズ**:全軸位相軸前提と文字通り一致する($T^4$=位相円の直積)。数え上げ系列が独立に同じ前提に着地した。

## 7. 正直な限界

1. §1 の辞書は「ほぼ同一」の精密化であり、完全な同型ではない:複素モデルは連続位相を持つが本モデルは Z₄ である(その差分こそが §4 の未決=位置プログラムの対象)。
2. §3 の二分は粗い一次区分である。境界事例(例:検閲の厳密限界 ½ — 入力 δ と容器算術の両方に依存)は個別に判定を要する。
3. §5 の Fock 的読みは構造対応であり、生成消滅演算子の構成を伴わない。
4. §6 の位相読みは公理追加である(頂点構造からの導出が成るまで)。本補遺は設計図であって構成ではない。
