## 1. 問い:微細分裂は娘交換 $Z_2$ か

補遺56 §3.2 は、縮退軸の親で対称チャネル(等シェル娘を含む)が追加分裂することを報告し、それが補遺38 残余 $Z_2\times Z_2$ の娘交換成分か否かを残課題とした。本稿はこれを二段階で否定する。

### 1.1 娘交換は既に商に取られている(構成上)

現行 `run_parent` は等シェル娘対 $(v_c,v_d)$ を `if c==d and vc>=vd: continue` で**無順序和**として計算する。代表親 (2,1,1,1)、チャネル (3,3,7) で:

| 和の取り方 | $\lvert z_{(3,3,7)}\rvert^2$ |
|---|---|
| 無順序和(現行) | 60552 |
| 順序和(娘を区別) | 72224 |

無順序和は順序和の**娘交換対称部分そのもの**。したがって対称チャネルの重みは**娘交換に対して構成上すでに不変**であり、微細分裂は娘交換ではあり得ない。

### 1.2 微細分裂はそもそも幾何でなく規約の人工物(§2)

§2 の決定検査により、微細分裂は娘交換どころか**いかなる幾何学的 $Z_2$ でもなく**、経路列挙の字句順序規約の人工物であることが判明する。

## 2. 決定検査:字句順序規約 vs 置換不変規約

### 2.1 規約の所在

経路 $((a,b),x,(c,d),d_1)$ で $a=b$(第一段の二娘が同シェル)のとき、`two_step_paths` は $x=a$ の経路のみを生成し、`run_parent` は `vx=va`(字句順序で小さい娘)を崩壊側に選ぶ。「字句順序で小さい娘が崩壊する」は**軸置換で不変でない**(タプルの辞書順は置換で保存されない)。よって $a=b$ の経路を含むチャネルの重みは、軸の置換(同一 $B_4$ 軌道内の別セル)で**変わりうる**。

### 2.2 検査結果

置換不変(対称)規約＝「等シェル娘のどちらが崩壊するかを字句順序で固定せず両分岐を和」で再計算:

| 検査 | 字句順序(現行) | 置換不変(対称) |
|---|---|---|
| (2,1,1,1) 軸位置依存:2@axis0 vs 2@axis1 の $\lvert z_{(3,3,7)}\rvert^2$ | 60552 / 59600(**不一致＝軸依存**) | 70272 / 70272(**一致＝軸非依存**) |
| (2,1,1,1) 全64セルのセクター数 | **5**(24/12/12/8/8) | **2**(32/32) |

> **判定**: (2,1,1,1) の5セクターは**字句順序規約の人工物**。置換不変規約では2セクター(32/32)に崩壊し、軸位置依存も消滅する。劣勢軸の符号数 $\#\text{neg}$ も判別子でない(2@axis0 では全 $\#\text{neg}$ が同一 signature)。$\varepsilon=(-1)^{\Sigma\lvert k\rvert}$ は型上一定($\Sigma\lvert k\rvert=5$ で $\varepsilon=-1$)ゆえ判別子たりえない。

## 3. 補遺56 §3.2 の訂正:1ビットは支配軸一意なら一般

全型のセクター数を両規約で:

| $s$, 型 | 字句順序 | 置換不変 | 判定 |
|---|---|---|---|
| 9, (2,1,0,0) | 2 | 2(24/24) | 1ビット ✓ |
| 9, (1,1,1,1) | — | 1(16) | 自明 |
| 11, (2,1,1,0) | 2 | 2(48/48) | 1ビット ✓ |
| 13, (3,0,0,0) | 2 | 2(4/4) | 1ビット ✓ |
| 13, **(2,1,1,1)** | **5** | **2(32/32)** | **5は人工物・真は1ビット ✓** |
| 13, **(2,2,0,0)** | **3** | **3(12/6/6)** | **真の破れ(規約不変)** |

> **訂正登録**: 補遺56 §3.2 の「縮退軸で 3〜5 セクター＝1ビットが破れる」は、(2,1,1,1) の5を規約人工物と取り違えていた。正:**支配軸が一意な型では反転 $Z_2$＝1ビットが完全に一般**((2,1,1,1) も含む)。真の破れは**支配軸が縮退(タイ)する (2,2,0,0) のみ**で、そこでは両規約で3セクター(規約不変)。補遺53 §5-2 の弱点は「縮退一般」でなく「**支配軸タイのとき**」に絞られる。補遺52「ちょうど1ビット」・補遺54「単一 $Z_2$ 鎖ホロノミー」は、**支配軸が一意なら一般に正しい**。

反転 $I:v\to-v$ の作用も確認:$(支配符号, \#\text{neg})\to(-支配符号, 3-\#\text{neg})$ で全ケース signature 変化 — 反転は支配軸符号の主分裂(家系の入替)を担う、という補遺54 の同定と整合。

## 4. より重い発見:測度値 0.98195 は規約依存

対称チャネル(等シェル娘を含む)の重みが規約で変わる以上、その重みから作る測度値も規約依存である。s=9 代表親 (2,1,0,0):

| 規約 | $W_{531}$ | $W_{333}$ | $P(X)=2W_{531}/(2W_{531}+W_{333})$ |
|---|---|---|---|
| 字句順序(補遺51採用) | 1088 | 40 | **0.98195** |
| 置換不変(対称) | 1088 | **160** | **0.93151** |
| 数え上げ測度(参考) | — | — | 逐次 0.98263 / 一括 0.98361 |

$W_{531}$(全異シェル＝等シェル娘なし)は規約不変、$W_{333}$(三娘すべて同シェル)は**4倍変化**(40→160)。

> **判定**: 補遺51/52/54 が「導出測度が数え上げ測度 0.98263 に近接(差 0.0007)」と強調した **0.98195 は字句順序規約の産物**である。置換不変規約では $P(X)=0.93151$ となり数え上げから大きく外れる。**近接は意味のある一致でなく規約の偶然**である可能性が高い。チャネル重みの計算には未固定の規約自由度(等シェル娘のどちらが崩壊するか/対角項 $v_c=v_d$ を含むか)があり、値を約5%振る。測度値問題は補遺55 が言うより**さらに開いている**:セクター選択の力学が無いだけでなく、チャネル重み自体に未固定の規約自由度がある。

## 5. 規約に依存せず生き残るもの

| 結論 | 規約依存性 |
|---|---|
| Z₄量子化(補遺51 #6・補遺56 TEST A) | **非依存**(単段 tphase の全数検査で経路列挙を経由しない) |
| 反転＝支配軸符号の主分裂 $Z_2$(補遺54) | **非依存**(両規約で家系一致) |
| (1+i) 蝶番恒等式 $2s=N(v_1)+N(v_2)$(補遺49) | 無関係(代数的) |
| マーキング定理 $384=16\times24$(補遺50) | 無関係(代数的) |
| (2,2,0,0) の真の3セクター | 検査した2規約で不変 |

50年テーゼ(3公理＋正準構造、追加ゼロ)は本検査で公理が増減せず無傷。揺らいだのは「測度＝ちょうど1ビット」の縮退境界(支配軸タイで破れる)と、**測度値 0.98195 の頑健性**である。

## 6. 正直な限界

1. **正準規約は未特定**:どちらの規約(字句順序/置換不変、対角項の有無)が意図された崩壊振幅の定義に対応するかは、等粒子の数え方の物理的指定次第で、本稿はその完全な定義を持たない。本稿が確立するのは「結果が規約に敏感で、その敏感性が補遺で明示されていなかった」ことであり、これはどちらが正しいかに依らず成立する。**正準規約の特定(記録原理と整合する等粒子数え方)が測度値を一意化する鍵**であり、最優先の残課題。
2. **検査した規約は2つ**:字句順序と「全順序対(対角込み)」。(2,2,0,0) の3セクターは両者で不変だが、全規約での不変性は未証明。対角項を除く第三の対称規約は未検査。
3. **(2,2,0,0) の真の3セクターの正体は未同定**:支配軸タイの相対符号構造((++)/(+−)型)か否かは別途要計算(サイズ 12/6/6 の起源)。
4. **置換不変規約は対角 $v_c=v_d$ を含む**:二同種娘が同一セル状態に入る配置(ボソン的)を含めた。除く規約での再検査は §6-2 と同枠。
5. 物理的同一視は行わない。

## §A. 検算スクリプト(要点)

# 補遺57: 縮退セクターの規約依存性。補遺56 の機械に「対称(置換不変)規約」を追加して比較。
# (基盤関数 expcoeffs/cross_at/self_at/tphase/two_step_paths/all_finals/shell_cells は補遺56 と同一)

# 現行(字句順序)規約: 等シェル娘対を無順序和 (vc>=vd を skip, vx=va)
def run_parent(vp, parent, finals, o1=+1, o2=+1):
    z = {f: 0+0j for f in finals}
    for f in finals:
        for ((a,b),x,(c,d),d1) in two_step_paths(parent, f):
            for va in SH[a]:
                for vb in SH[b]:
                    if a==b and va>=vb: continue          # ← 字句順序で固定
                    e1 = tphase(vp, va, vb, o1)
                    if e1 is None: continue
                    vx = va if x==a else vb                # ← 小さい娘が崩壊
                    for vc in SH[c]:
                        for vd in SH[d]:
                            if c==d and vc>=vd: continue   # ← 字句順序で固定
                            e2 = tphase(vx, vc, vd, o2)
                            if e2 is None: continue
                            z[f] += e1*e2
    return z

# 対称(置換不変)規約: skip を外し全順序対を回す(両娘が崩壊側になる場合を網羅)
def run_parent_sym(vp, parent, finals, o1=+1, o2=+1):
    z = {f: 0+0j for f in finals}
    for f in finals:
        for ((a,b),x,(c,d),d1) in two_step_paths(parent, f):
            for va in SH[a]:
                for vb in SH[b]:
                    e1 = tphase(vp, va, vb, o1)            # ← skip なし
                    if e1 is None: continue
                    vx = va if x==a else vb
                    for vc in SH[c]:
                        for vd in SH[d]:
                            e2 = tphase(vx, vc, vd, o2)    # ← skip なし
                            if e2 is None: continue
                            z[f] += e1*e2
    return z

def sectors(s, run):
    from collections import defaultdict
    fins = all_finals(s); out = {}
    types = defaultdict(list)
    for v in SH[s]: types[tuple(sorted(map(abs, v)))].append(v)
    for t in sorted(types):
        sg = defaultdict(int)
        for v in types[t]:
            z = run(v, s, fins)
            sg[tuple(round(abs(z[f])**2, 1) for f in fins)] += 1
        out[t] = sorted(sg.values(), reverse=True)
    return out
