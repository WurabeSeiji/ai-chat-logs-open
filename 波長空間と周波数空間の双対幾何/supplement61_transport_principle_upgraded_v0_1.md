# 補遺61:移送原理の昇格 — 写像完備化後の適用範囲(標準量子論の動力学は再導出不要)

**作成**: 2026年6月12日
**版**: v0.1
**対象**: 2026-06-12 の設計者の問い —「xyzt への写像・逆写像が解決した今、標準量子論の枠組みで解けている動力学問題は、わざわざ再導出しなくても、私の仮説の体系でも解けると言えるのではないか」— の正式登録。論文12 §8.1・補遺41(移送原理・対応辞書)の延長であり、補遺42〜60 による前提の地位変化を反映した**昇格版**。新規計算を含まない在庫整理。claude.ai による独立レビュー予定。
**性格**: 一つの昇格と一つの適用条件表と一つの再分類。(1) **前提の地位変化**:補遺41 時点で「差分」(検閲領域の近似)に分類されていた三前提のうち、**連続時空は「欠けた前提」から「構成された極限」へ**(連続 x・連続 t・連続位相は同一の¼桁階層完備化の三つの顔 — 補遺43/48/49)。振幅は舞台(C段)・アルファベット(Z₄、導出)・重み(同種粒子対称化で一意 — 補遺58/60)まで在庫供給済みで、残るは連続係数の完備化(Z[i]→C)の登録事項のみ。ユニタリ発展は波動セクターの三条件補間(論文12 §4.2)+位相輸送の導出(補遺51)。(2) **昇格された移送原理**:標準量子論が連続時空+波動方程式の枠で解いた1粒子動力学(自由伝播・干渉・定常状態・経路和の骨格・トンネル等)は、**本体系の簿記の完備化極限での読みとして成立し、再導出は翻訳証明書にすぎない**。加えて本体系は標準理論が持たない付録 — 検閲以下の離散補正の存在と、その不可観測性の理由 — を併せて主張できる。(3) **0.0007 の再分類**:導出測度 0.98195(頑健性確定、補遺60)と逐次数え上げ 0.98263 の差は、移送の失敗ではなく**体系固有の反証可能予言の候補**(モデル内で全数照合可能)である。物理的同一視は行わない。

## 2. 昇格された移送原理

> **移送原理(昇格版)**: 標準量子論の定理は、その前提のすべてが本体系の公理・検証済み構造・**構成された完備化極限**に対応物を持つとき、本体系でも成立する。連続時空を前提する1粒子動力学はこの条件を満たし、**再導出を要しない**。再導出が与えるのは翻訳証明書であって新しい内容ではない(設計者の原則:再導出しないことは欠陥ではない — 補遺41)。本体系固有の追加内容は (i) 検閲以下の離散補正の存在、(ii) その不可観測性が定理であること、(iii) 補間が破れる予言領域(少数状態系・階層跨ぎ・禁止帯近傍 — 論文12 §4.2)。

## 3. 適用条件表

| 領域 | 移送 | 理由 |
|---|---|---|
| 1粒子波動力学(シュレーディンガー発展・干渉・定常状態・経路和の骨格) | **可** | 三条件補間+完備化で前提供給済み |
| Born 型重み・分岐測度 | **可(条件付き)** | 対称化で一意。ただし 0.98195 vs 0.98263 は未裁定 — §4 |
| 配置をまたぐ一般重ね合わせを本質的に使う定理(Tsirelson 値・Gleason 型等) | **条件付き** | C 完備化が登録段階のため「完備化が成るならば」の限定つき |
| ゲージ場の動力学(作用・伝播・散乱振幅の値) | **不可(現状)** | 論文10 の名乗り規律どおり(骨格のみ・作用未構成) |
| 頂点の遷移率・寿命の絶対値、物理単位への接続 | **不可** | 換算の門(第三観測量)が未通過 — 従来からの保留 |

## 4. 0.0007 の再分類

導出測度(位相つき管理連鎖+対称化)0.98195 と逐次数え上げ測度 396/403=0.98263 の差は、両方がモデル内で厳密に定義された量である以上、**どちらかが正しいかをモデルが決めるべき内部問題=体系固有の予言候補**である。判定には P(X) 型観測量の一般 $s$ への再定義(補遺56 §4)が必要。これは移送原理の弱点ではなく、標準理論が持たない解像度(測度の微細構造)を本体系が持つことの現れと位置づける。

## 6. 正直な限界

1. C 完備化(連続係数の重ね合わせ)は「位置と同型の階層完備化」として強く支持された登録事項であり、定理ではない — これに本質的に依存する定理の移送は §3 の通り条件付き。
2. 本補遺は在庫整理であり、新しい計算・新しい予言を含まない(0.0007 の再分類は位置づけの変更)。
3. 「解ける」の主張範囲は §3 の表が全てであり、表外への拡大解釈(場の量子論の動力学・重力)は行わない。
4. 物理的同一視は行わない。
