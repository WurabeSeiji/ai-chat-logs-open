## 1. 配置パリティ代数(訂正版・確定)

配置 K ごとに σ₀ 偶/奇の部分和 z⁺_K, z⁻_K(η_A の和)を定義する。L80 より:

$$z_K^A = z^+_K + z^-_K,\qquad z_K^B = -i\,(z^+_K - z^-_K)$$

**完全な辞書**:

| 配置の型 | 条件 | 帰結 |
|---|---|---|
| χ=−i | z⁻_K = 0 | \|z_B\|=\|z_A\|、共通配置 |
| χ=+i | z⁺_K = 0 | 同上 |
| A 専属(z_B=0) | z⁻_K = +z⁺_K | \|z_A\|=\|2z⁺\| |
| B 専属(z_A=0) | z⁻_K = −z⁺_K | \|z_B\|=\|2z⁺\| |

1. **四値ロック(m=3 の経験命題、証明対象)**:全36配置で z⁻_K/z⁺_K ∈ {0, ∞, +1, −1}(24+6+6)。一般には χ は単位円上の任意の値・|z_B|≠|z_A| があり得る(m=2 の唯一配置がその実例=両側非零・非ロック)。よって **m 依存性の正確な住所は「四値ロックの成否」**である。
2. |z_B|=|z_A| ⟺ |z⁺−z⁻|=|z⁺+z⁻| ⟺ **z⁺ ⊥ z⁻(複素平面で直交)**。片側零はその自明な特殊例。観測では共通配置が全て ±i(=片側零)なので、m=3 に「両側非零だが直交」型は存在しない — ロックの強さの傍証。
3. **チャネル相殺の分解**:z_B = −i[Σ_{片側} (±z_K) + Σ_{ratio=−1} (−2z⁻... )] — 四値ロックの下で S₊−S₋ はロック類ごとの小さい和に縮約される。証明戦略は二段:**(α) 四値ロックの証明(§2 の ι 構成)→ (β) ロック類上の残和の消滅(m 奇)**。
4. **排他族の重み対(新規の証明対象)**:W′_A=W′_B ⟺ Σ_{ratio=+1}|2z⁺_K|² = Σ_{ratio=−1}|2z⁺_K|²。6+6 配置の間に重さを保つ対応(配置水準の対合)があるはず — ι とは別の、配置集合上の対合の存在予想として登録する。

## 2. σ-対合配置版の具体的構成案(貴提案の実装)

**構成 ι**:経路 p の隠れた中間子 vx(第一段で崩壊した側 — 配置 K={kept, vc, vd} に**含まれない**)について、**vx の軸0枝を反転**(v_{x,0} → −v_{x,0}、v_{x,0}≠0 のとき)。

**性質(導出可能)**:
1. K を保つ(vx は K の外)— 配置内対合 ✓。
2. σ₀ = [kept₀<0]+[v_{x,0}<0] のうち kept は固定なので、v_{x,0}≠0 なら **σ-パリティを反転** ✓。
3. **η 乗数は2因子に分解**し、L80 と同じ3行算術で計算できる:
   - **e1 因子**(vx は第一段の娘):単軸親標的では軸0の分解符号 (n_{a,0}, n_{b,0}) が一意に強制される(|v_{a,0}|±|v_{b,0}|=m の同時成立は片方零を要するため)。強制された n 符号での係数比は cos↔sin 入替で **±i**(n=+\|v\| なら −i、n=−\|v\| なら +i)。
   - **e2 因子**(vx は第二段の親):標的の軸0符号反転の全単射により **(−1)^{[v_{c,0}<0]+[v_{d,0}<0]} ×(Cp 正規化比 ±i)**。
4. v_{x,0}=0 の経路は ι の定義域外 — その σ-パリティは **kept(=配置データ)だけで決まる**。すなわち「配置がパリティを固定する経路」と「ι が対にする経路」の二部構造が自然に出る — 四値ロックはこの二部構造+乗数の値から従うはず、が予想。

**機械検証仕様**:(i) m=2,3 の全経路で ι の η 乗数を実測し、上記2因子の積と全数照合(L80 と同型の一行検査)。(ii) ι の軌道構造(固定点なし/2-軌道)と乗数の値ごとに、四値ロックの 24/6/6 分類が再構成されるか。(iii) m=2 の唯一配置で何が壊れるか(ι の定義域・乗数のどちらか)— **「なぜ m 奇か」の最初の実データ**。(iv) 成功すれば (β) 残和消滅の m 奇性が次の(最後の)証明対象。
