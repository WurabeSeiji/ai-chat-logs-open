## 0. 本稿の位置づけと免責

本稿は、論文1以降の数え上げが**平坦ノルムで定式化されていた**こと(拘束 Σν²=𝒩² が定義する曲面 S^d(R) の内在曲率を、4自由度の数え上げに取り込んでいなかったこと)を補うための、**純粋な微分幾何の基礎計算**である。物理的同一視は行わない。ここでは確率も測度も振幅も登場しない。問うのはただ一つ:

> **正準化(離散単位=1、バラツキ ±½、曲率半径 R∈正整数、Rのバラツキ ±½)の下で、平坦な単位セルを曲率半径 R の正曲率定曲率空間に「測地線長を保って」置いたとき、一辺の長さ・頂点角・単位面積・単位体積はどう変わるか。**

採用する設定(前段の確定事項):

- **測地多角形 (P)**:セルの辺は測地線(大円弧)、頂点は測地線の交点。角度が一次的に定義される図形。
- **辺長固定**:測地的な一辺の長さを a=1 に固定する(測地線長保存)。このとき正曲率では頂点角が直角を超え、面積・体積は平坦より**増加**する。これが測りたい「歪み超過」である。
- 正規化:離散単位 1、セル半幅 ½(バラツキ ±½)、R∈{0.5, 1.0, …}(Rのバラツキ ±½ は §7 で扱う)。

次元は **1+1 から 5+1**(空間次元 d=1,2,3,4,5 に時間的1方向を添えた表記)で扱う。歪みを受けるのは空間的 d 次元測地胞体であり、以下 d を主パラメータとする。

---

## 1. 基本関数

半径 R の d 次元単位球面 S^d(R)(定曲率 K=1/R²)を、(d+1) 次元ユークリッド空間に標準埋め込みする。極からの測地距離 χ における「緯度 (d−1) 球面」の半径は

  σ_R(χ) = R sin(χ/R).      (1)

これが唯一の基本関数である。χ→0 で σ_R→χ(平坦極限)、χ/R が大きいほど σ_R < χ(緯線が極へ閉じる)。曲率効果はすべて (1) の sin から生じる。

無次元の**角変数**を

  u = χ / R   (ラジアン)      (2)

と定義する。正準化により測地距離は単位 1 で測るので、測地距離 ℓ のセルは u = ℓ/R を張る。

---

## 2. 1+1 次元(空間 d=1)

**定式化**:d=1 では「正方形」も「角」も存在しない。空間は閉曲線 S¹(R)(周長 2πR)。測地的単位セルは、円周上の長さ a=1 の弧。

- **一辺の長さ**:a=1(定義、不変)。
- **角**:定義されない(1次元に内角なし)。
- **単位面積・体積**:定義されない。
- **唯一の歪み量**:弧 a=1 が張る中心角 = a/R = 1/R。曲率の効果は「閉じていること」(全周 2πR に 2πR/1 個のセルが乗る)のみで、セル内部の計量歪みはゼロ(1次元多様体は常に内在的平坦、曲率テンソル恒等的に0)。

**結論(d=1)**:1+1 では歪みによる一辺・面積・体積の変化は**ない**。曲率は大域(閉性)にのみ現れ、局所セルは歪まない。これは「漏れ」の基準点(ヌル)であり、歪みは d≥2 で初めて発生する。

---

## 3. 2+1 次元(空間 d=2)— 歪みが現れる最小次元

**定式化**:S²(R) 上の測地正方形(4辺すべて測地線・4回回転対称・辺長 a=1)。基本は球面幾何のガウス・ボネ:

  (内角和) − 2π = Area / R².      (3)

辺長 a を固定した正方形の頂点角 θ を、球面三角法で厳密に求める。中心(正方形の重心)から各頂点への測地距離(対角半径)を ρ、各辺の中点への測地距離(辺心距離)を r とする。4回対称な測地正方形では、中心で各扇は頂角 π/2 の球面直角二等辺三角形に分解できる。

球面直角三角形(中心角 π/4 を半分に持つ)に球面三角法を適用する。辺の半分(中点から頂点)が張る角を a/(2R)、辺心距離が張る角を r/R とすると、辺が測地線で隣接辺と直交する条件から、頂点半角 θ/2 について

  **cos(θ/2) = cos(a/2R) · sin(π/4) / √(1 − sin²(a/2R)·... )**

——以下、初等的に閉じた形へ整理する。半角記法 s ≡ sin(a/2R)、c ≡ cos(a/2R) を用いると、4回対称測地正方形の頂点角は

  **θ = 2 · arccos( c / √(1 + s²) )      … (4-角)**

頂点角の直角超過を Δθ = θ − π/2。面積はガウス・ボネ (3) から

  **Area = R² · (4θ − 2π)      … (4-面積)**

一辺は定義により 1(不変)。

**平坦極限の検算**:a/2R → 0 で s→0, c→1, θ→2·arccos(1/√1)=2·0... ではなく、s→0 のとき c/√(1+s²)→1、arccos→0 となり θ→0。これは不正。

> **【要・機械検算】** 式(4-角)の球面直角四辺形の導出は、平坦極限 θ→π/2 を満たす形へ再導出が必要(本 v0.1 の (4-角) は中心分解の角の取り方に誤りがある疑い)。正しい関係は Lambert 四辺形(3直角1可変角)または Saccheri 四辺形の公式:辺長 a の球面正方形では、頂点角 θ が
>   cos(a/R) = cos²(side) ... の形で閉じる。
> Claude Code に、S²(R) 上で辺長 a=1 の測地正方形を数値構成(頂点を測地線交点として求解)し、θ(R) と Area(R) を R=0.5..10 で出力する独立計算を依頼する。以下の数表はそのプレースホルダであり、解析式確定後に確定値で置換する。

**歪み量(d=2、辺長 a=1 固定)の定義**:

- 一辺の長さ: 1(不変)
- 頂点角: θ(R) = π/2 + Δθ(R)、Δθ(R) > 0
- 単位面積: A(R) = R²(4θ(R) − 2π) = R²·4Δθ(R)
- 平坦比: A(R) / 1 = A(R)(平坦単位正方形面積=1 との比)

小角展開(a/R ≪ 1、検算用の漸近)では、球面正方形の面積超過は

  **A(R) ≈ 1 + (1/6)(1/R²) + O(1/R⁴)**,  Δθ(R) ≈ (1/4)(1/R²) + …      (5)

すなわち R が大きいと歪みは 1/R² で減衰し、平坦(面積1・直角)に戻る。R=3 では 1/R²=1/9 で約11%増、という前段のオーダー見積もりはこの (5) に対応する。**(5) は漸近形であり、R=0.5〜3 の小Rでは厳密式 (4) が必要(小Rで級数は破綻する)。**

## 4. 3+1 次元(空間 d=3)

**定式化**:S³(R) 上の測地立方体(6面・12辺・8頂点、各面が §3 の測地正方形、各辺長 a=1)。3次元定曲率での測地多面体の体積は、Schläfli の微分公式

  dV = (R²/?) Σ (二面角の微分) × (辺長) …(一般には Schläfli)

で与えられるが、正準的には**立体角超過**を使う。測地立方体の体積超過は、各頂点の立体角過剰と二面角の直角超過から、定曲率3次元の体積公式

  **V(R) = a³ · [ 1 + (c_3 / R²) + O(1/R⁴) ]**,  c_3 = 1/2(立方体の場合の係数、要確定)

の形になる。

> **【要・機械検算】** d=3 の測地立方体の体積 V(R) には初等閉形式が一般には無い(球面四面体体積=Schläfli 関数で、Lobachevsky/Clausen 関数を含む)。Claude Code に、S³(R) 上で辺長 a=1 の測地立方体を数値構成し V(R) を数値積分で出力する独立計算を依頼。係数 c_3 は数値フィットで確定する。

**歪み量(d=3)**:
- 一辺: 1(不変)
- 面の頂点角・二面角: §3 の θ(R) に対応(各面が測地正方形)
- 単位体積: V(R) > 1、漸近 V(R) ≈ 1 + c_3/R²

---

## 5. 4+1 次元(空間 d=4)— シリーズ本体の数え上げが住む次元

**定式化**:S⁴(R) 上の測地超立方体(8胞・24面・32辺・16頂点、各胞が §4 の測地立方体、辺長 a=1)。これが論文1〜2 の N₀(R) 数え上げが**本来**住むべき空間である(論文1の漏れ①の補正対象)。

4次元定曲率の測地超立方体の超体積は

  **V₄(R) = a⁴ · [ 1 + (c_4 / R²) + O(1/R⁴) ]**

> **【要・機械検算】** d=4 でも初等閉形式は無い(高次元球面多面体体積)。Claude Code に S⁴(R) 上で辺長 a=1 の測地超立方体の超体積 V₄(R) を数値積分で出力依頼。c_4 を数値確定。

**論文1・2 との接続(本稿の主目的)**:論文2 の平坦数え上げは各セルに超体積 1 を割り当て、N₀(R)·1 を総体積とした。本稿の補正により、曲率半径 R の S⁴(R) では各測地セルの超体積は V₄(R) = 1 + c_4/R² > 1。よって**曲率補正された実効セル数**または**実効体積**は

  Ṽ(R) = N₀(R) · V₄(R) = N₀(R) · (1 + c_4/R² + …)

であり、平坦 N₀(R) との差

  **ΔN(R) = N₀(R) · (V₄(R) − 1) = N₀(R) · c_4 / R² + …      (6)**

が、論文1の漏れがもたらす歪み超過の主項である。R が小さい(R=1,2,3)ほど 1/R² で大きく効き、R→∞ で消える。

## 6. 5+1 次元(空間 d=5、念のため)

**定式化**:S⁵(R) 上の測地5次元超立方体。超体積 V₅(R) = 1 + c_5/R² + …。初等閉形式なし、機械検算で c_5 を確定。本シリーズの主対象は d=4 だが、次元の必然性(論文11)との整合確認のため d=5 まで表に含める。

## 7. R のバラツキ ±½ の扱い

R∈正整数に対しバラツキ ±½ を与えるとは、各量を区間 [R−½, R+½] で評価することを意味する。各量 Q(R)(=θ, A, V₃, V₄, V₅)について、

  Q⁻(R) = Q(R−½),  Q⁺(R) = Q(R+½),  中心値 Q(R)

を表に併記する。これは論文1 §6 の「不確定性幅 δ=±½」を曲率量へ伝播させたものであり、論文1がスコープ外とした δ依存性(限界・第四)に、**幾何学的な第一候補(曲率半径のバラツキ)**を与える。

## 9. 本稿の主張範囲

主張する:
1. 歪みは d=1 では発生せず(局所平坦)、d≥2 で 1/R² を主係数として発生する。
2. 一辺の測地長は全次元・全 R で不変(1)。歪みは角・面積・体積にのみ現れる。
3. 角・面積・体積の超過は正(正曲率)で、R→∞ で平坦回帰、小 R で最大。
4. この超過 (6) が、論文1〜2 の平坦数え上げ N₀(R) に対する曲率補正の主項を与える。

主張しない:
- 物理的同一視(曲率を物理的時空曲率と同一視しない)。
- 測度・確率・振幅(本稿に存在しない)。
- §3〜6 の解析式の最終形(機械検算で確定するまでプレースホルダ)。

## 付録A:要・機械検算項目(Claude Code 依頼事項)

1. **d=2**:S²(R) 上で辺長 a=1 の測地正方形を頂点求解で構成、θ(R)・A(R) を厳密出力(R=0.5..10, 100, 1000, 10000)。§3 の式(4)の平坦極限不整合を解消する正しい閉形式の確定。
2. **d=3,4,5**:S^d(R) 上で辺長 a=1 の測地超立方体の超体積 V_d(R) を数値積分で出力。係数 c_d を数値フィット。
3. **極限検算**:R=10000 で全量が平坦値に 10⁻⁸ オーダーで一致することを確認。
4. **±½ バラツキ**:各量を R±½ でも評価し併記(§7)。
