## 1. (i) 測度ギャップは構造的 — 干渉は s で消えない(決着)

補遺56 §4 は「双子 P(X)=2W₅₃₁/(2W₅₃₁+W₃₃₃) は二チャネル構造に依存した s=9 固有観測量で、0.0007 の有限サイズ判定は延長不能」とした。本稿は **P(X) とは別の、全 s で定義可能な観測量**で判定する。

### 1.1 一般 s 観測量 D(s)

各シェル s の**全親を集計**し、最終チャネル f ごとに二つの分布を作る:
- コヒーレント(干渉あり): $p_f = W_f / \sum_g W_g$、$W_f = \sum_{\text{parents}} |z_f|^2$(振幅二乗、Z₄ 位相込み)
- インコヒーレント(干渉なし): $q_f = n_f / \sum_g n_g$、$n_f = \sum_{\text{parents}} (\text{非零経路数})$(位相を捨てた計数)

総変動距離 $D(s) = \tfrac12 \sum_f |p_f - q_f|$ は「干渉が測度を位相無視カウントからどれだけ動かすか」を測る。

### 1.2 結果(正準規約 unord_nodiag、全親集計)

| s | 親数 | D(s) | 支配チャネルの p / q |
|---|---|---|---|
| 9 | 64 | **0.13502** | (1,3,5): 0.951 / 0.816 |
| 11 | 96 | **0.14020** | (3,3,5): 0.687 / 0.547 |
| 13 | 96 | **0.18476** | (3,5,5): 0.528 / 0.360 |

> **判定**: 有限サイズ効果なら D(s)→0 のはずだが、**縮まらず微増**(0.135 → 0.140 → 0.185)。干渉の効きは恒常的で、s を上げても Born 測度は位相無視カウントに**古典化しない**。したがって 0.0007 型のギャップは有限サイズ補正ではなく、**Born 測度の構造的特徴**である。補遺61 §4 の「体系固有の反証可能予言候補」は、この計算で支持される(失敗でも偶然でもなく、振幅測度が位相無視測度と恒常的に異なることの現れ)。

### 1.3 数え上げ測度との関係(傍証)

s=9 のチャネル比で:振幅 1088/40 = **27.2**、逐次カウント比(396/403 ⇒ M₅₃₁/M₃₃₃)= **28.3**、一括カウント比(60/61 ⇒ 30)、対してセル項数比 = **4.44**。振幅は逐次/一括カウント比に近く、セル項数比からは遠い。つまり補遺の数え上げ測度(逐次/一括)は**位相無視の重み付きカウント**で、振幅とは別物。0.98195 が 0.98263 に近いのは、両者が「支配チャネル集中」測度として近い比を持つためで、漸近的同一の証拠ではない(§1.2 が示す通り Born 測度は古典化しない)。

**正直な限界**: D(s) の比較対象はセル項数(インコヒーレント)であり、補遺の逐次測度 396/403 そのものの一般 s 定義は再構成していない。定性結論(Born 測度は古典化しない)は確定だが、0.0007 という**特定の数値**の s 追跡には逐次測度の一般定義が要る(§A-2 と別枠の残課題)。

## 2. (iii) 3軸タイは accessible 範囲で縮退(障害=結果)

数え上げ則の系列:

| 支配軸 | 型 | セクター数 | 構造 |
|---|---|---|---|
| 1軸ユニーク | (2,1,0,0) | 2 | 反転 Z₂(支配符号) |
| 2軸タイ | (2,2,0,0) | 3 | (相対符号 same/opp 1ビット) × (同符号上のゲージビット)(補遺59) |
| **3軸タイ** | (1,1,1,0) | **1(全零)** | 退化 |
| 4軸タイ | (1,1,1,1) | 1(全零) | 退化(既知・補遺47) |

shell7 (1,1,1,0) は正準規約で全チャネル($(1,1,5),(1,3,3)$)が零、shell9 (1,1,1,1) も全零。いずれも $(m,m,m,*)$ の最大対称型で、3軸以上の支配対称が完全相殺を起こす。**非退化な3軸タイの最小例は (2,2,2,0)**(補遺6 の軌道表より 32セル、shell19 全144セル)。これは claude.ai 環境の実行制限時間を超え**計算不能**(タイムアウト)。

> **暫定結論**: 3軸タイの正則な数え上げ値は accessible 範囲では取れない($(m,m,m,*)$ は退化)。非退化な (2,2,2,0) の判定は shell19 計算を要し、**Claude Code に引き継ぐ**(§A-1、ローカルで完走見込み)。

## §A. Claude Code 引き継ぎ仕様

### §A-1 (iii) 3軸タイ (2,2,2,0)@shell19

`canon.py`(補遺57)の `run_mode` をそのまま使い、奇数シェルを K=5 で shell21 まで構築して実行:

```python
# canon.py の基盤関数 + run_mode を読み込み済みとする
from collections import defaultdict
for m in (15,17,19,21):
    if m not in SH: SH[m]=shell_cells(float(m),5)
S=19; fins=all_finals(S)
cells=[v for v in SH[S] if tuple(sorted(map(abs,v)))==(0,2,2,2)]  # 32セル
def tie3_class(v):
    nz=[v[j] for j in range(4) if v[j]!=0]      # 三つの|2|成分
    npos=sum(1 for s in nz if s>0)
    return f"|#+-#-|={abs(npos-(3-npos))}"        # 3=全同符号, 1=2-1混合
sigs=defaultdict(int); cls=defaultdict(lambda: defaultdict(int))
for v in cells:
    z=run_mode(v,S,fins,'unord_nodiag')
    sg=tuple(round(abs(z[f])**2,1) for f in fins)
    sigs[sg]+=1; cls[sg][tie3_class(v)]+=1
# 確認事項: (1) 全channel零でないか(退化チェック), (2) セクター数とサイズ,
#           (3) 各セクターの相対符号内訳(補遺59 と同じ分解)
```

判定基準:(a) 全零なら $(m,m,m,*)$ 退化が m に依らないことの確認、(b) 非零なら 2/3/それ以上のセクター数と相対符号(|#+−#-|∈{3,1})との対応で数え上げ則を確定。期待される構造は「相対符号(全同符号 vs 2-1混合)× ゲージ」だが、3軸では相対符号クラスが2つ(2軸タイと同じ)なので、2軸タイと同じ3セクターか、ゲージの作用が変わって別の数になるかが争点。

### §A-2 (ii) η² 80/80 等分布の代数証明

スペクトル水準の経路で η=η₁·η₂ を列挙(`eta_paths`、下記 §B)し:

1. **検証**: η² の ±1 分布が 531終で 80/80、333終で 18/18(=Ση²=0)を確認。
2. **対合構成**: 経路集合上の対合 σ で **η→iη(η² 反転)**を起こすものを探す。候補:
   - セルの¼周期シフト(縞シフト = cos↔sin 回転で交差線係数に i を掛ける — 補遺47/30)
   - 娘交換(vc↔vd)、軸符号反転(あるセルの1軸を反転)
   σ²=id・固定点なし・η→±iη を満たせば η² 等分布の代数証明が成る。

**位置水準の A1/B2 は別物**:補遺38/47 の管理連鎖(ベクトル一致 68本=531終48+333終20)の経路集合上で、i^δ₁ の和がゼロ(δ₁=±1 が等数)・sin枝数 mod4 が Z₄ 等分布、を「借入先行↔貸出先行」対合で構成する。スペクトル経路(160/36)では成立しないので注意。

## §B. claude.ai 実行済みコード要点(canon.py 拡張)

```python
# (i) 全親集計の W_f(コヒーレント)と n_f(インコヒーレント)、D(s)
def shell_distribution(s):
    fins=all_finals(s); SW={f:0.0 for f in fins}; SN={f:0 for f in fins}
    for vp in SH[s]:
        Z={f:0+0j for f in fins}; N={f:0 for f in fins}
        for f in fins:
            for ((a,b),x,(c,d),d1) in two_step_paths(s,f):
                for ia,va in enumerate(SH[a]):
                    for ib,vb in enumerate(SH[b]):
                        if a==b and not ia<ib: continue
                        e1=tphase(vp,va,vb)
                        if e1 is None: continue
                        vxs=[va,vb] if a==b else [va if x==a else vb]
                        for vx in vxs:
                            for ic,vc in enumerate(SH[c]):
                                for idd,vd in enumerate(SH[d]):
                                    if c==d and not ic<idd: continue
                                    e2=tphase(vx,vc,vd)
                                    if e2 is None: continue
                                    Z[f]+=e1*e2; N[f]+=1
        for f in fins: SW[f]+=abs(Z[f])**2; SN[f]+=N[f]
    tW=sum(SW.values()); tN=sum(SN.values())
    D=sum(abs(SW[f]/tW - SN[f]/tN) for f in fins)/2
    return D   # D(9)=0.13502, D(11)=0.14020, D(13)=0.18476

# (ii) スペクトル経路の η=η1·η2
def eta_paths(vp,parent,final):
    out=[]
    for ((a,b),x,(c,d),d1) in two_step_paths(parent,final):
        for ia,va in enumerate(SH[a]):
            for ib,vb in enumerate(SH[b]):
                if a==b and not ia<ib: continue
                e1=tphase(vp,va,vb)
                if e1 is None: continue
                vxs=[va,vb] if a==b else [va if x==a else vb]
                for vx in vxs:
                    for ic,vc in enumerate(SH[c]):
                        for idd,vd in enumerate(SH[d]):
                            if c==d and not ic<idd: continue
                            e2=tphase(vx,vc,vd)
                            if e2 is None: continue
                            out.append((e1*e2,(va,vb,vx,vc,vd)))
    return out
def z4(e):
    for p,u in enumerate([1,1j,-1,-1j]):
        if abs(e-u)<1e-9: return p
    return None
```
