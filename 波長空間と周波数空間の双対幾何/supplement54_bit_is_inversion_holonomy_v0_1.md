# 補遺54:同定テストの判定 — ビットは矢ではなく、反転の鎖ホロノミーである(補遺53 §3 の訂正)

**作成**: 2026年6月12日
**版**: v0.1
**対象**: 補遺53 §4-1(同定①=⑤の共変換テスト)と §4-2(矢による測度クラスの決定)の実施。前提:補遺38(残余 $Z_2\times Z_2$=反転×娘交換)、補遺43 §1.2(反転対称性=指標の複素共役)、補遺45(三列台帳:並進/計数/自己同型)、補遺51–53。スクリプト:`supplement54_bit_identification_tests.py`
**性格**: 三つの判定と一つの訂正。(1) **T1(矢の反転)**:管理連鎖の比較方向を時間反転(全段共役)しても $\lvert z\rvert^2$ は**不変** — **強制ビットは矢ではない**。補遺53 §3 の既定読み(同定①=⑤)は**否定**され、本稿で訂正する。(2) **T2(部分向き反転)**:第1段のみ・第2段のみの向き反転はクラスを A↔B に**切り替え**、両段反転は**戻す**。鏡像親($-2$ 支配枝)の固有計算はクラスB。よって**ビットの正体は、親の支配枝を境界値とする、管理連鎖のリンク向きの相対パリティ=反転($g\to-g$、複素共役)の $Z_2$ 鎖ホロノミー**である — 補遺45 の三列台帳の**自己同型列**に属し、補遺38 の残余 $Z_2\times Z_2$(反転×娘交換)と同じセクターの量である。(3) **セクター解釈**:測度クラスは曖昧さではなく**ホロノミーのセクター構造** — A=自明(ねじれなし)セクター $P(X)=0.98195$、B=ねじれセクター $0.95238$、親等重・非干渉平均は $(704,36)\to P(X)=0.97507$。(4) **終端宣言の維持と終端先の訂正**:導出の連鎖は依然として既存在庫の内で終端する(公理追加ゼロ)が、終端先は仮定3(矢)ではなく**正準反転自己同型の鎖ホロノミー**である。反転は任意のアーベル群が持つ正準構造(補遺43 §1.2)であり、公理ではないが導出対象でもない — 在庫の「自動的に付いてくる」部分。物理的同一視は行わない。

## 2. ビットの正体:反転の鎖ホロノミー

向き反転は比較周波数 $+v_p\to-v_p$、すなわち**正準反転 $g\to-g$(双対側では複素共役、補遺43 §1.2)を当該リンクに適用すること**である。T2 より:

> **同定(訂正版)**: 強制ビット=管理連鎖に沿った**反転自己同型の $Z_2$ ホロノミー**(リンク向きの相対パリティ、親の支配枝を境界値に含む)。クラスA=ホロノミー自明(平行・ねじれなし)、クラスB=ねじれ。台帳上の所属は補遺45 の**自己同型列**であり、補遺38 が頂点解の残余として発見した $Z_2\times Z_2$(反転×娘交換)の反転側と同じセクターである。

補遺53 §3 の「五つの衣装」は次のように訂正される:①矢・②$\Sigma\lambda^2$ 単調・③記録はλ側は従来通り**仮定3の1ビット**の衣装。④動径向き・⑤測度の向きは**別の $Z_2$** — 正準反転の鎖ホロノミー — の衣装である。体系の大域 $Z_2$ は一つではなく**二つ**(矢のビットと反転ホロノミーのビット)であり、両者は T1 により独立であることが機械的に確定した。

## 3. セクター解釈と測度の現況

ホロノミーは選択(規約)ではなく**配置・履歴の量**である(境界値=親の枝は状態データ、リンクの相対向きは鎖の幾何)。したがって測度クラスの「2値」は曖昧さではなく**セクター構造**と読める:

| セクター | $(W_{531},W_{333})$ | 分岐比 | 双子 $P(X)$ |
|---|---|---|---|
| A(自明ホロノミー) | (1088, 40) | 0.9645 | **0.98195** |
| B(ねじれ) | (320, 32) | 0.9091 | 0.95238 |
| 親等重・非干渉平均 | (704, 36) | 0.95135 | 0.97507 |

数え上げ測度(一括 0.98361/逐次 0.98263)との厳密一致は依然なし。最近接は自明セクターの 0.98195。

## 4. 編集・検証キュー(更新)

1. **補遺53 §3 の訂正の反映**(本稿が訂正登録。補遺53 v0.2 は不要 — 本稿参照で足りる)。
2. ホロノミーと補遺38 残余 $Z_2\times Z_2$ の形式的同一視(頂点4解の反転側=本稿のリンク反転、娘交換側=T2 の段内対称性)— 自己同型列の完全な台帳化。
3. 自明セクター=正準(平行輸送)の地位:ナチュラルネス論証を超える根拠(エネルギー論・数え上げ優位など)の有無。
4. $s=11,13$ 拡張(セクター構造が崩壊系列を跨いで持続するか・0.98195 と 0.98263 の差の挙動)。

## 5. 正直な限界

1. 「鎖ホロノミー」の定式化は2段鎖での全数事実に基づく(一般の多段鎖でパリティのみが効くことの証明は未了 — $s=11,13$ と同枠)。
2. §3 のセクター解釈において、どのセクターが実現するか(または両方が分布するか)の力学はない — 測度問題の最終決着はこの一点に残る。
3. T1 の「矢の反転=全段共役」は比較方向の反転としての操作化であり、矢のより強い操作化(帳簿の向きの反転)での再検査は自己同型列の台帳化(キュー2)に含める。
4. 物理的同一視は行わない。
