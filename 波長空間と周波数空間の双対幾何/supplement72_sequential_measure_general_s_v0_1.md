# 補遺72:逐次測度の一般 s 定義 — 0.0007 の正体は二結果圧縮(s=11 で Δ=0.24 へ跳躍)

**作成**: 2026年6月12日
**版**: v0.1(原番号71 — 補遺71=B2代数証明が先行登録済みのため72へ改番。内容は claude.ai 原文のまま)(番号衝突時は Claude Code 側で改番可)
**対象**: 補遺68 §1 の残課題「逐次測度 396/403 の一般 s 定義」(宿題③、claude.ai 担当の定義設計)の実施。原定義=補遺36 V1(双子宇宙 (9,9) の逐次条件付き数え上げ)。スクリプト要点は §B。s=9 アンカー4点の厳密再現と、s=11 での初の新データ点まで claude.ai 環境で実行済み。
**性格**: 一つの定義(D1〜D4)と一つの再現と一つの決着的発見。(1) **一般定義**:逐次測度=双子 (s,s) のイベントごと条件付き配置数え上げ(D1)、一括=結合終配置等重(D2)、導出双子=P∝mult·W_{F1}·W_{F2}·[結合容量整合](D3、s=9 の 2W/(2W+W′) 公式の忠実な一般化)、追跡観測量 Δ(s)=TV(D3, D1)(D4)。**良定義性の鍵**:条件付き数え上げは殻ごとの占有数のみに依存し配置に依らない(補題、容量二項係数の積)ため、双子設定で一意に閉じる。(2) **s=9 アンカー厳密再現**:逐次 396/403、一括 60/61、導出双子 0.98195、Δ(9)=0.00068、単一崩壊配置 24/31=0.7742 — 全一致。(3) **決着的発見(s=11)**:Δ(11)=**0.24136**(セクターA)/ 0.43971(セクターB)— Δ(9)=0.00068 から**3桁跳躍**。一方、逐次と一括(数え上げ側内部)の差は 0.069 に留まる。**0.0007 の「近接」は意味のある一致ではなく、s=9 双子観測量の圧縮の産物**:s=9 は (i) 排他が双子結果空間を2結果に強制(原点独占で {531,531} 禁止)、(ii) 両測度とも支配結果 X に ~0.98 集中、の二重圧縮で TV が潰れていた(単一崩壊水準では s=9 でも 0.774 vs 0.965 と大差、セクターB は s=9 でも Δ_B(9)=0.030)。s=11 の3結果空間で圧縮が解け、D(s)(補遺68 §1)と同水準の構造的乖離が露出した。**補遺68 の「測度ギャップは構造的」が、歴史的に正しい数え上げ測度(逐次)そのものに対しても確定**。物理的同一視は行わない。

## 1. 定義(D1〜D4)

容量 $c(m)=|SH[m]|$:c(1)=1, c(3)=8, c(5)=24, c(7)=40, c(9)=64, c(11)=96, c(13)=96(補遺6 軌道表と一致)。チャネル集合 = `all_finals(s)`。

**補題(良定義性)**: チャネル $F$ の残格子上の配置数は $M_F(\text{used}) = \prod_m \binom{c(m)-\text{used}_m}{\text{mult}_F(m)}$ — **殻ごとの占有数のみに依存し、どのセルが占有されたかに依らない**。よって逐次の条件付き数え上げは先手の配置を平均する必要がなく、チャネル水準で閉じる。

**D1(逐次・一般 s)**: 双子 (s,s)。先手チャネル $F_1$ の確率 $\propto M_{F_1}(\emptyset)$、後手は $\propto M_{F_2}(\text{used}=F_1\text{ の殻占有})$。$P_{\text{seq}}(\{F_1,F_2\})$ = 両順序の和(双子同種ゆえ対称)。s=9 で 396/403 を厳密再現。

**D2(一括・一般 s)**: 結合終配置の等重:$P_{\text{batch}}(\{F_1,F_2\}) \propto \prod_m \binom{c(m)}{\text{mult}_{F_1+F_2}(m)}$。s=9 で 60/61 を厳密再現。

**D3(導出双子・一般 s)**: $P_{\text{der}}(\{F_1,F_2\}) \propto \text{mult}\cdot W_{F_1}W_{F_2}\cdot[\text{結合容量整合(二値)}]$(mult=2 if $F_1\neq F_2$ else 1)。$W_F$ = 正準規約(補遺58/60)・指定親型・指定セクターの $|z_F|^2$。s=9・セクターA で $2W_{531}/(2W_{531}+W_{333})=0.98195$ を厳密再現(歴史的公式そのもの)。

**D4(観測量)**: $\Delta(s) = \mathrm{TV}(P_{\text{der}}, P_{\text{seq}})$ — 0.0007 の正統な一般 s 追跡量(s=9 で Δ=|0.98263−0.98195|=0.00068)。補助:TV(逐次, 一括)=数え上げ側の内部幅、単一崩壊 δ(s)=TV(W/ΣW, M/ΣM)。

> **判定**: Δ は s=9→11 で3桁跳躍。一方、数え上げ側内部(逐次↔一括)は 0.069 に留まる。**0.98195 と 0.98263 の近接(0.0007)は、意味のある一致ではなかった**。s=9 の双子観測量は (i) 原点独占による2結果強制と (ii) 両測度の支配結果集中(~0.98)の二重圧縮で TV が潰れる構造であり、s=11 の3結果空間で圧縮が解けると、導出測度と数え上げ測度は単一崩壊水準(s=9 でも 0.774 vs 0.965)・D(s)(補遺68:0.135→0.185)と同水準の **O(0.1〜0.4) の構造的乖離**を示す。傍証:セクターB は s=9 でも Δ_B(9)=|0.98263−0.95238|=0.030 — 「近接」はセクターA かつ s=9 限定の偶然だった。

**台帳への含意**: 補遺51 §2.2「これまでのどの規則よりも測度候補に近接」・補遺52 §3「近傍」は、**観測量の圧縮による見かけ**と再分類する(値の正しさは不変、近接の意義づけのみ訂正)。補遺61 §4 の「0.0007=体系固有の予言候補」は**より強い形で確定**:予言候補は特定の差 0.0007 でなく「導出測度は数え上げ測度と恒常的に O(0.1) 乖離する」という構造そのもの。

## 4. Claude Code への引き継ぎ仕様

1. **s=13 の Δ**:親型3種((2,1,1,1)/(2,2,0,0)/(3,0,0,0))× セクター(タイ型は n+1 セクター、補遺70)で Δ(13) を計算。D1/D2 は §B のまま(容量のみ)、D3 の W は正準 run(チャネル和キャッシュで高速化済みの機械)。結合結果空間で「異なるチャネル対が同一結合多重集合になる衝突」の有無を要確認(s≤11 では無し)。
2. **頑健性変種2件**:(a) D3 の容量整合を二値でなく**比率**(整合配置数/無制約配置数)にした graded 版 — 二値との差は D3 の規約自由度の幅。(b) **完全結合振幅版**(双子の経路を結合格子上でコヒーレントに和、排他を振幅水準で実装)— D3 の因子化が正しい双子化かの判定。重いが s=9 なら可能なはず。
3. **零チャネル一致の一般検査**(§5)。

## 5. 観察(登録):零チャネルの両側一致

容量不能チャネル(原点2個など)と振幅相殺チャネルが s=9((1,1,7):M=0 は不成立だが z=0)… 訂正:s=9 の (1,1,7) は M=C(1,2)·…=0(容量不能)**かつ** z=0(相殺)、s=11 の (1,1,9) も両方ゼロ。**数え上げ測度と導出測度は、ゼロの位置では一致する**(ゼロでない所の重みで乖離する)。一般 s での成立は未検査 — 成立すれば「両測度は台(support)を共有し重みのみ異なる」という綺麗な定式化になる(キュー)。

## 6. 正直な限界

1. D3 は s=9 の歴史的公式(因子化+二値整合)の忠実な一般化であり、**結合振幅の第一原理計算ではない**(§4-2b が判定者)。Δ(11) の大きさの一部が因子化近似に由来する可能性は排除していない — ただし s=9 で同じ因子化が 0.98195 を与えた以上、歴史的系列の追跡としては正統。
2. D3 は親型・セクターの指定を要する(数え上げ側は親非依存)。本稿はセクターA を正統(補遺54 の自明ホロノミー)とし、B を併記した。
3. 双子の先手順序は同種双子ゆえ対称で消えるが、異種双子(s≠s′)への拡張では順序平均の規約が要る(未定義)。
4. 結合多重集合の衝突(§4-1)は s≤11 で未発生、一般には要検査。
5. 物理的同一視は行わない。

## §B. 実装(検証済みコード要点)

```python
from fractions import Fraction as F
from math import comb
from collections import Counter, defaultdict

CAP={1:1,3:8,5:24,7:40,9:64,11:96,13:96}   # c(m)=|SH[m]|

def M_channel(f, used):
    tot=1
    for m,k in Counter(f).items():
        free=CAP[m]-used.get(m,0)
        if free<k: return 0
        tot*=comb(free,k)
    return tot

def seq_twin(s):                          # D1
    fins=all_finals(s)
    M1={f:M_channel(f,{}) for f in fins}; T1=sum(M1.values())
    P=defaultdict(lambda: F(0))
    for f1 in fins:
        if M1[f1]==0: continue
        used=Counter(f1)
        M2={f:M_channel(f,used) for f in fins}; T2=sum(M2.values())
        for f2 in fins:
            if M2[f2]==0: continue
            P[tuple(sorted([f1,f2]))]+=F(M1[f1],T1)*F(M2[f2],T2)
    return P

def batch_twin(s):                        # D2
    fins=all_finals(s); W=defaultdict(int)
    for i,f1 in enumerate(fins):
        for f2 in fins[i:]:
            joint=Counter(f1)+Counter(f2); tot=1
            for m,k in joint.items():
                if CAP[m]<k: tot=0; break
                tot*=comb(CAP[m],k)
            if tot>0: W[tuple(sorted([f1,f2]))]+=tot
    T=sum(W.values()); return {k:F(v,T) for k,v in W.items()}

def derived_twin(s, Wd):                  # D3 (Wd: 正準規約・指定親・指定セクターの |z_F|²)
    fins=all_finals(s); P={}; tot=0.0
    for i,f1 in enumerate(fins):
        for f2 in fins[i:]:
            joint=Counter(f1)+Counter(f2)
            if any(CAP[m]<k for m,k in joint.items()): continue
            w=(2 if f1!=f2 else 1)*Wd.get(f1,0)*Wd.get(f2,0)
            if w>0: P[tuple(sorted([f1,f2]))]=w; tot+=w
    return {k:v/tot for k,v in P.items()}

def TV(P,Q):
    keys=set(P)|set(Q)
    return sum(abs(float(P.get(k,0))-float(Q.get(k,0))) for k in keys)/2
# Δ(s) = TV(derived_twin(s,Wd), seq_twin(s))
# 検証済み: s=9 → 396/403, 60/61, 0.98195, Δ=0.00068, 24/31
# s=11 → Δ_A=0.24136, Δ_B=0.43971, TV(seq,batch)=0.06929
```

物理的同一視は行わない。本稿は宿題③(定義設計)の完了報告であり、s=13 以降の数値追跡と頑健性変種は §4 の通り Claude Code に引き継ぐ。
