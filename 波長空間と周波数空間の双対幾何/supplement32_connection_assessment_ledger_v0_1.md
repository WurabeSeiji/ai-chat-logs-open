# 補遺32:標準ゲージ理論との接続評価と残課題台帳 — 接続済みの骨格・未接続の四層・頂点という一枚の扉

**作成**: 2026年6月11日
**版**: v0.1
**対象**: 2026-06-11 の問い「一連の課題でまだやることはあるか。現段階でほぼ標準ゲージ理論とは接続できたのでは」への査読回答の記録。前提:補遺6–31(特にゲージセクター 19–23、ゲート処理 28–31)
**性格**: 接続評価は**半分は強い形で然り、半分は明確に否**である。(1) **接続済み**:格子ゲージ理論の運動学的骨格はほぼ完全に接続された — しかも接近の向きが逆(ゲージ原理を一度も仮定せず、安定性・観測可能性の問いの副産物として出現)であり、標準の構成より強い主張になっている。重要な同定:出現したのは **Yang–Mills 型ではなく重力型のゲージ構造**(離散フィアバイン+スピン接続+局所フレーム群 SO(4))であり、中心投影シリーズとの合流としてはむしろ望ましい。(2) **未接続**:標準ゲージ理論を「理論」たらしめる四層 — 物質・動力学・量子層・内部ゲージ群 — が残る。(3) **残課題台帳**:主戦場は頂点写像ただ一つに収束済み。昇格課題5件、遺産未決1件(ローレンツ集約写像)、機械検算・編集キュー。現在地の正確な表現:「**格子ゲージ理論の骨格と離散重力のフレーム構造には接続完了。Yang–Mills・物質・量子はすべて頂点という一枚の扉の向こう**」。物理的同一視は行わない。

## 1. 接続済みの在庫(運動学的骨格)

| 標準ゲージ理論の部品 | 本体系での実現 | 出所 | 地位 |
|---|---|---|---|
| ゲージ不変性の原理 | 記録定理から**導出**(記録不能な差異=ゲージ) | 補遺8, 22 §1–2 | 定理 |
| リンク変数(接続) | 位置適応+捻れなしで**運動学的に一意** | 補遺19, 21 §1 | 定理 |
| プラケットの曲率 | 兄弟三角形に集中(系譜・捻れはゲージ) | 補遺21 §2, 22 §1 | 定理 |
| 非可換 Stokes | 星型平坦=正準ゲージの下で成立 | 補遺21 §2.1, 22 §1 | 定理 |
| Wilson 作用 | 型は構成済み($s=1-\tfrac14\mathrm{Tr}H$)、β=0 が運動学的デフォルト | 補遺20, 23 §3, 31 | 構成+定理 |
| 連続構造群 | SO(4) が**強制される**(結晶学的制限) | 補遺20 §4, 21 §2.4 | 定理 |
| スピン構造・二重被覆 | 持ち上げ無矛盾、ピッチ½一意、励起次数 $Z_2$ | 補遺21 §3, 30 | 定理+構成 |
| 格子⇄連続の関係 | B₄=連続群の格子 remnant(標準の格子ゲージ理論と同型の構図) | 補遺20 §4.2 | 定理 |

**接近の向き**(補遺12 §0 の確認):上記はすべて、ゲージ原理を公理に置かずに安定性・観測可能性・整合性の問いから出現した。「ゲージ対称性は仮定ではなく記録構造の帰結」は、標準の構成にはない主張である。

### 1.1 重要な同定:出現したのは重力型ゲージ構造である

- 位置適応フレーム(補遺21 §1)=**離散的なフィアバイン(四脚場)**:各点(断片)に正規直交枠。
- 接続(補遺19)=**スピン接続**:フレームの平行輸送則。
- 構造群 SO(4) = 内部対称性ではなく**局所フレーム群**(接空間の回転)。

> 接続できた相手は Yang–Mills ではなく、**一階形式(フィアバイン+スピン接続)の重力のゲージ構造**に近い。これは欠陥ではない:中心投影シリーズ(重力側、Appendix C)との合流(補遺26 §4)としてはむしろ望ましい帰結であり、数え上げ側が重力のゲージ構造を独立に再構成したことを意味する。

## 2. 未接続の四層

| 層 | 標準理論での内容 | 本体系の現状 |
|---|---|---|
| (1) 物質 | 接続に結合する場、共変微分、流れ、電荷 | **不在**。枝二重項は整角と判定(補遺23 §1)。ねじ持ち上げ=唯一の内部候補(補遺30)、必然性未決 |
| (2) 動力学 | 運動方程式、伝播するゲージ自由度(ゲージボソン) | **不在**。β=0 デフォルト(補遺23, 31)。有限結合・伝播は頂点写像待ち |
| (3) 量子層 | 振幅・重ね合わせ・干渉する経路和 | **所在未決**(設計上の振幅なし規律)。現状は離散・古典・運動学的構造 |
| (4) 内部ゲージ群 | SU(3)×SU(2)×U(1) 型の内部対称性 | **居場所の特定まで**:横断 Stab セクター(補遺21 §1.3)+頂点局在(補遺22 §2.2)。U(1)⁴(ねじ)が最初の内部電荷候補(補遺30 §2.2) |

四層は独立ではない:(1)–(4) のすべてが頂点写像(イベントの内部状態決定則)に収束済みである(補遺31 §2.2)。

## 3. 残課題台帳(優先順)

### 3.1 主戦場(1件)

**頂点写像の構成** — 分裂・合体イベントにおける内部状態(フレーム初期化・内部配分)の決定則。β の有限値・κ・内部ゲージ場の物理化・振幅の所在の四者が全てここに収束済み(補遺22 §2.2、23 §4、31 §2.2)。**イベント=量子性が入る扉の最有力候補。**

### 3.2 昇格課題(5件)

1. ξ の内部導出(節集合の測地偏差 — 補遺28 §4。完了でゲート1全閉)
2. 自己双対種子原理の昇格(補遺29 §3.2 — 完了で d=4 の第二導出が定理化)
3. 集合的継承の厳密化(補遺29 §5.2 — 単位の実在化次元→共有格子次元)
4. 交換路の格子面分解(補遺30 §2.3 — 完了で統計の橋の判定)
5. 三つの $Z_2$ の関係表(パリティ/ループ/励起次数 — 補遺30 §4.2)

### 3.3 遺産未決(1件)

ローレンツ符号の集約写像(補遺8 v0.2 §3.4:対ごとの (1,1) → (1,3) の組み立て)。Appendix C との接続点であり、§1.1 の重力型同定により優先度が上がった。

### 3.4 機械検算キュー

## 4. 現在地の表現

> **格子ゲージ理論の骨格と離散重力のフレーム構造には接続完了。Yang–Mills・物質・量子はすべて、頂点という一枚の扉の向こうにある。**

「ほぼ接続できた」は骨格(§1)については正しく、理論の四層(§2)については時期尚早である。ただし未決の収束(全てが一つの対象に集約された状態)は、計画上は最良の形である — 攻めるべき場所が一つに定まっている。
