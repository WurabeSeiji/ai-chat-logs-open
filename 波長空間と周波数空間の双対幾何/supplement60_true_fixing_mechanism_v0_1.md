# 補遺60:測度値 0.98195 の真の固定機構 — 駆動因は対角でなく同種粒子の対称化(補遺57 §4・58 §1 の機構訂正)

**作成**: 2026年6月12日
**版**: v0.1
**対象**: 補遺58(Claude Code)と補遺57(claude.ai)の機構説明の相違の決着。claude.ai の分離検算(2026-06-12)を Claude Code がローカルで独立再現し、両者一致。
**性格**: 一つの決着と二つの訂正と一つの新観察。(1) **決着(2×2分離表、独立に二者で確認)**:s=9 で $(W_{531},W_{333})$ は無順序なら対角込/除に依らず (1088, **40**)、順序なら対角込/除に依らず (1088, **160**)。**値の駆動因は順序(同種粒子の対称化)ただ一つ**であり、対角項は値に無関係。(2) **補遺58 §1 の訂正**:「0.93151=対角項(排他違反)の混入」は**誤り**。三本柱のうち効くのは (i) 無順序=**同種粒子対称化(配置読み:状態は集合、論文7 §2.1)** のみ。(ii) 対角除外は値に無関係(出典も不正確 — 二重占有を禁じるのは直交定理でなく集合構造)、(iii) 両分岐和は比に無関係(既登録)。結論(在庫から一意に 0.98195)は**維持** — 機構記述のみ訂正。(3) **補遺57 §4 の訂正(claude.ai 自身による)**:0.93151 は「正当な代替規約」ではなく**同種娘を区別して数えた(distinguishable)誤った統計**の値。機構:順序計数は等シェル第2段の振幅 $z_{333}$ を**2倍**(重み4倍、40→160)にする一方、531 の等シェル段は第1段にあり事象多重度(両分岐)で既に飽和しているため不変。「測度値は規約依存」の警報は過剰だった — **同種粒子なら 0.98195 に一意**。(4) **新観察**:対角項の輸送位相は 16/512 件で非零((2,0,0,0) 型=偶セル線への輸送)だが、**集計では厳密に相殺**する(第四の厳密相殺現象の候補)。「自己スペクトル全偶による自動消滅」(本日の Claude Code の説明)も部分的に不正確で、正しくは「経路水準では寄与しうるが総和で消える」。物理的同一視は行わない。

## 1. 分離検算(両者で独立確認)

| 計数 | $W_{531}$ | $W_{333}$ | $P(X)$ |
|---|---|---|---|
| 無順序・対角除(補遺58 正準/字句順序) | 1088 | 40 | **0.98195** |
| 無順序・対角込 | 1088 | **40** | **0.98195** |
| 順序・対角除 | 1088 | **160** | 0.93151 |

対角を固定して順序を切替→ 40↔160。順序を固定して対角を切替→不変。**QED:駆動因は対称化のみ。**

## 2. 統一された固定機構

> **固定機構(一本)**: シェル等しい娘は同種であり、配置読み(状態=占有セルの**集合**、論文7 §2.1)が**無順序計数=対称化**を強制する。順序計数(distinguishable)は同一物理配置の二重計数で、等シェル第2段の振幅を2倍(重み4倍)に水増しする。**0.98195 は対角の扱い・分岐の扱いに依らず、同種粒子対称化だけで一意に固定される** — 補遺58 の結論より頑健な形で成立。

これは新公準ではない:同種性と集合性は論文7 で定理水準。**量子統計の「同種粒子は数え分けない」が、測度値の固定機構として既存在庫から働いた。**

## 3. 新観察:対角寄与の集計相殺

対角対 $(v_c,v_c)$ の輸送位相は恒等的にゼロではない:$\Phi_c^2$ は偶数周波数のみを持つため奇数線には寄与しないが、**偶セル線((2,0,0,0) 型、shell 7 の8セル)へは16件が非零**。それにも関わらず総和への寄与は厳密にゼロ(§1 の表)。対角寄与の集計相殺は A1 対合・B2 等分布・η² 80/80 に続く**第四の厳密相殺候補**として登録する(代数証明は同じキュー)。
