# 補遺58:正準規約の特定 — 排他定理が振幅の数え方を一意化する(補遺57 §6.1 の解決)

**作成**: 2026年6月12日
**版**: v0.1
**対象**: 補遺57 §6.1 の最優先残課題「正準規約の特定(記録原理と整合する等粒子数え方)が測度値を一意化する鍵」の解決。スクリプト:`supplement58_canonical_convention.py`(補遺57 の機械を再利用)。
**性格**: 一つの特定と三つの帰結。(1) **正準規約は既存在庫から一意に決まる**:等シェル娘の数え方は、(i) 娘対は配置読み(論文7:状態=占有セルの**集合**)により**無順序**、(ii) 同一セルの二重占有(対角項 $v_c=v_d$)は**非重複=直交定理(論文5)が禁止** — 対角除外、(iii) 「どちらの娘が崩壊するか」は粒子の同一性でなく**事象の多重度** — 両分岐を和。選択の自由は残らない。(2) **人工5セクターの解消と真の破れの保持**:正準規約で s=13 型 (2,1,1,1) は **2セクター [32/32]**(補遺57 の対称規約と同じ修復)、型 (2,2,0,0) は **3セクター [12/6/6]**(真の破れ、保持)、s=9/11 の2セクターも不変。(3) **測度値 0.98195 の復権**:正準規約は s=9 で $(W_{531},W_{333})=(1088,40)$、$P(X)=$ **0.98195** を与える。補遺57 が対称規約で得た 0.93151 は**対角項(ボソン的二重占有)を含む計算**であり、モデル自身の排他定理が禁止する配置を数えていた — 非許容規約である。0.98195 は規約の偶然ではなく、**排他と整合する唯一の数え方の値**。(4) **構造的意義**:規約問題の正体は同種粒子の数え方の問題であり、本モデルではそれが公準でなく**定理(排他=配置読み+直交、論文7)から固定される** — 振幅水準の統計(フェルミ的数え方)まで既存在庫が一意化した。物理的同一視は行わない。

## 1. 正準規約の導出(選択の自由が残らないこと)

補遺57 が同定した規約自由度は三つあった。各々が既存原理で閉じる:

| 自由度 | 決定原理 | 帰結 |
|---|---|---|
| 等シェル娘対の順序 | **配置読み**(論文7 §2:状態=占有セルの集合) | 無順序 |
| 対角項 $v_c=v_d$(二重占有) | **非重複=直交定理**(論文5 §5)・排他(論文7 §2.1) | 除外 |
| 等シェル娘のどちらが崩壊するか | 粒子の同一性ではなく**事象の構造**(経路多重度、補遺39) | 両分岐を和 |

> **特定**: 正準規約=「無順序・対角除外・両分岐和」。これは選択ではなく、論文5/7 の定理の帰結である。補遺57 §6.1 の「物理的指定次第」は、指定が既に在庫にあったことで閉じる。

## 3. 台帳への反映(補遺55/56/57 整合更新)

1. 補遺57 §4「0.98195 は規約依存」→ **精密化**:許容規約(排他整合)の中では一意に 0.98195。規約感度の指摘自体は正しく、その解決が本稿。
2. 補遺56 §3.2/補遺57 §3:「1ビットは支配軸一意なら一般」は正準規約でも成立((2,1,1,1) 含む)。真の破れは支配軸タイ (2,2,0,0) の3セクターのみ(正体は未同定 — 補遺57 §6.3 のまま)。

## 4. 正直な限界

1. (iii)「両分岐和」は事象多重度の読みに基づく。代替読み(分岐をゲージとして商に取る=平均)では全体規格化のみ変わり、比 $P(X)$ は不変(和と平均は定数倍差)— よって測度値はこの読みの別に依存しない。
2. (2,2,0,0) の真の3セクター [12/6/6] の正体(タイ軸の相対符号構造か)は未同定のまま。
3. $s=9,13$ の代表検査(s=11 の正準再計算は2セクター構造が両規約一致のため省略、全型網羅は機械キュー)。
4. 物理的同一視は行わない。
