# 補遺14:無時間予言と分岐比 — 自発的崩壊の正しい問い・時計の循環・断片統計問題

**作成**: 2026年6月11日
**版**: v0.1
**対象**: 補遺13(検閲検証)の直接の続編。前提:補遺4 v0.3、補遺5、補遺6、補遺8 v0.2、補遺10 v0.2、補遺11
**性格**: 本稿は二つの問い「なぜ安定が自発的に崩れるのかを説明できるか」「時間発展がない系のままで予言は可能か」に答える。結論:(1) 「いつ・何が引き金で」という形の問いは背景時間を前提した悪設定であり、体系では時間=イベント列そのものなので、引き金の不在(自発性)は説明の欠落ではなく時間の構成原理である。(2) 予言は可能である — 分岐比は静的数え上げから出る。ただし三つの静的測度が異なる支配チャネルを与え、**断片統計(区別可能性)の決定**という新しい静的問題が立つ。(3) ν の直接観測不可能性(補遺8)とは同一の事実の二面である。物理的同一視は行わない。

---

## 1. 問いの再設定:自発性は時間の構成原理である

### 1.1 悪設定と良設定

「なぜ安定が自発的に崩れるのか」を「いつ・何が引き金で」と読むなら、崩壊の前に流れる背景時間が要る。本体系では時間=イベント列(τ=λ′ はイベント間隔の計数、補遺10 §3.5)であり、イベントの前に時間はない。**引き金の不在=自発性は、時間がイベントから構成されることの表現**である。

良設定の問いは三つに分解される:
1. どのチャネルが開いているか — 運動学。補遺13 §5 で完了(離散7本、連続は検閲済み)。
2. チャネル間の相対重み(分岐比)は何か — **静的数え上げで予言可能**(§2)。
3. 「いつ」 — 問いとして解消される。観測される「時間の中での崩壊」は、イベント連鎖を内部観測者(その時計はイベント連鎖そのもの)が読んだものである。

### 1.2 ν 観測不可能性との接続

ν はイベントを生成する側であり、時間はそのイベントの読みである。**ν を時間に対して測ることは、時計が自分自身を読む循環**になる。記録定理(補遺8 §1)・読み出しの持続時間コスト(同 §2.2)と同一の事実:**ν は時計の機構、λ は時計の文字盤であり、機構は文字盤に映らない**。「固有振動数が時間発展と観測される」の正確な形である。

### 1.3 量子力学との認識構造の一致(構造対応、同一視なし)

QM は放射性崩壊の「なぜ今か」に答えない。答えるのはチャネル構造と分岐比のみ。Fermi の黄金律 $\Gamma\propto|M|^2\rho(E_f)$ のうち、終状態密度 $\rho$ は**純粋に静的な数え上げ**である。本体系は $\rho$ に当たる部分を持ち、**動力学が将来付け加えるのは $|M|$=全体スケール一個のみ**。「時間発展は後付け」の定量的意味がこれである。

## 2. 無時間予言の実演:S=9 の分岐比(三つの静的測度)

| チャネル | ΠN₀(区別可能) | 対称化(同一断片で割る) | 容量損失 |
|---|---:|---:|---:|
| (7, 1, 1) | 73 (6.0%) | 36.5 (7.9%) | **62(最安)** |
| (5, 3, 1) | 297 (24.3%) | **297.0 (64.1%)** | 94 |
| (5, 1, 1, 1, 1) | 33 (2.7%) | 1.4 (0.3%) | 100 |
| (3, 3, 3) | **729 (59.6%)** | 121.5 (26.2%) | 110 |
| (3, 3, 1, 1, 1) | 81 (6.6%) | 6.8 (1.5%) | 116 |
| (3, 1⁶) | 9 (0.7%) | ~0 | 122 |
| (1⁹) | 1 (0.1%) | ~0 | 128 |

三測度は異なる支配チャネルを指す:多重度 → (3,3,3)、対称化 → (5,3,1)、容量会計 → (7,1,1)。

> **断片統計問題**: この不一致は欠陥ではなく、体系が初めて直面する鋭い静的問題である — **断片は区別可能か**。粒子統計の問いが、動力学なしの数え上げから強制的に立ち上がった。判定材料は既にある($B_4$ ゲージ:個々のセルは観測量ですらない、$Z_2$ 次数、0/1 占有=論理波仮説)。これも静的な問いであり、解けば分岐比は一意になる。

## 3. 構造対応(警報つき)

大域的に凍結した状態(凍結定理、補遺6 §1.2)+内部の関係的時間(イベント計数)という構図は、Wheeler–DeWitt の frozen formalism と Page–Wootters の関係時間に正確に対応する。1ビット(帳簿非対称)が内部読み順を供給する点が本体系の固有部分である。同一視はしないが、3仮定の体系が量子重力の中心難題と同型の構造に到達している点を記録する。

## 4. 正直な限界

1. §2 の三測度はいずれも候補であり、統計問題の解決(次の一手)までは分岐比は一意でない。
2. ΠN₀ 測度は階層の二重計上の危険を持つ(親レベルの状態数と内部状態数の混在 — 補遺10 §8.3 のアルファベット/符号語の区別)。統計問題の解決時に勘定の層を固定すること。
3. $|M|$(全体スケール=寿命の絶対値)は本体系の射程外であり、予言は比に限る。
4. §3 の対応は構造的指摘に留まる。

## 5. 次の一手(指定)

断片統計の決定:$B_4$ ゲージ・$Z_2$ 次数・0/1 占有から、断片の区別可能性を導出し、S=9 の分岐比を一意化する。成功すれば本モデル初の一意な無時間予言となる。
