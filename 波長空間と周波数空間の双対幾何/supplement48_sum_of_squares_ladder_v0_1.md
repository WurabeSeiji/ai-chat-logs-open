## 1. 「同じ扉」仮説の照合 — 反証

### 1.1 時間スペクトルの到達集合(零点込み)

$\nu_t^2 = \sum_i(|k_i|+\tfrac12)^2$ を格子から列挙する。展開すると
$$\nu_t^2 = \sum_i k_i^2 + \sum_i|k_i| + 1 = 1 + \sum_i |k_i|(|k_i|+1) = 1 + \sum_i(\text{oblong}).$$
各 oblong $|k|(|k|+1)$ は偶数なので **$\nu_t^2$ は常に奇数**(奇数則の再導出)。さらに $(\nu_t^2-1)/2 = \sum_i T_{|k_i|}$(三角数の和)であり、ガウスの Eureka 定理(全非負整数は3つの三角数の和)により4つの三角数の和は全非負整数を網羅する → **$\nu_t^2$ は全ての奇数に到達する**。

機械確認: 4軸ヌル条件で $1, 3, 5, \dots, 399$ の全奇数を網羅、隣接間隔は厳密に 2(例外なし)。3軸版(空間)では $4\nu_t^2 \equiv 3 \pmod 8$ の等差。**標的は等差数列 — 最も規則的な集合。**

### 1.2 振幅 Born 重みの到達集合

$|z|^2 = a^2 + b^2$($z\in\mathbb{Z}[i]$)は二平方和。Fermat の二平方和定理により、$n$ が二平方和 $\iff$ $n$ の素因数分解で $\equiv 3 \pmod 4$ の素数がすべて偶数べき。密度は Landau–Ramanujan により $\sim CN/\sqrt{\ln N}$ で **密度 → 0**。機械確認: $1$–$2000$ で 30.9%(対して3平方和 83.4%、4平方和 100%)。

### 1.3 照合

| | 到達集合 | 密度($N\to\infty$) | 規則性 |
|---|---|---|---|
| 時間 $\nu_t^2$(4軸,零点込み) | 全奇数 | — | 等差(間隔2) |
| 振幅 $|z|^2$ | 二平方和 | $\to 0$ | 疎・不規則 |

時間の到達値(奇数)のうち振幅集合(二平方和)に入るのは $<200$ で 36/100 のみ。$3, 7, 11, 15, 19, 21, \dots$ は時間に到達するが振幅には乗らない(逆に振幅は偶数の二平方和を含むが時間は奇数のみ)。

> **判定**: 「時間逆写像と振幅正準性は同じ平方和表現問題の二つの顔」という前回仮説は **反証**された。$T \neq A$、$T \not\subseteq A$、$A \not\subseteq T$。両者は同じ ladder(平方和の表現可能性)に住むが **異なる段** であり、支配する算術が異なる(Lagrange=全到達 vs Fermat=制限)。

## 2. 難易度判定の訂正

前回(2026-06-12 対話)、「t が難しいのは丸めの標的集合 $\{\sqrt s\}$ が素数のように不規則だから」と述べた。**これは誤りである。**

1. **標的は規則的**: §1.1 の通り $\nu_t^2$ は全奇数(間隔2)。$\sqrt{}$ で見ても間隔は $\sqrt{m+2}-\sqrt{m}\approx 1/\sqrt m$ と単調に縮む — 高エネルギーで分解能上昇、位置の階層分解能(補遺43 §3)と同型。
2. **t は独立な丸めを持たない**: 空間配置を $\tfrac14\mathbb{Z}$ に丸めた時点で $\nu_t = \sqrt{\sum_i \nu_i^2}$ が確定する **導出量**。t は「丸める座標」ですらなく「計算される量」である。

> **訂正登録**: ハードル1(写像・逆写像)は四軸すべてで通る。xyz は規則格子 $\tfrac14\mathbb{Z}$ へ丸め(損失=分解能以下=検閲)、t は丸めずに $\sqrt{\text{odd}}$ スペクトル上で導出。前回の「t が逆写像で躓く」は **撤回** — **t は xyz より易しい**。
>
> 維持される積極的論点: 「t が導出量である=t が基本自由度でない署名」(50年のテーゼ「真の自由度はより少ない」の証拠)はそのまま正しい。困難の所在ではなく、主張の証拠である。残る時間側の未構成は (1,3) 集約と矢(半群性)のみで、これらは丸めの問題ではない(§5-4)。

## 3. ladder の正体 — Hurwitz 塔対応

平方和の個数が次元に対応する:

| 段 | 平方和の個数 | 代数 | 到達集合(古典定理) |
|---|---|---|---|
| 振幅(位相平面 $J$) | 2 | 複素 $\mathbb{C}$ | 二平方和のみ(Fermat) |
| 空間3軸 | 3 | — | 全整数除く $4^a(8b+7)$(Legendre) |
| 時間(4軸ノルム時計) | 4 | 四元数 $\mathbb{H}$ | 全整数(Lagrange) |

Hurwitz の定理: 平方和が乗法的(ノルムが積を保つ)になる次元は $1,2,4,8$ のみ。これは本シリーズが既に「4次元時空を強制する基礎制約」として採用してきた $\mathbb{R},\mathbb{C},\mathbb{H},\mathbb{O}$ 塔そのものである。

> **対応**: 時間と振幅は「同じ扉」ではないが「同じ建物」— Hurwitz 塔の異なる窓。時間 = $\mathbb{H}$ 段(4平方、格子全体)、振幅 = $\mathbb{C}$ 段(2平方、位相平面)。振幅の二平方和制限は、モデルに既にある複素構造(cos/sin 直交性 = $J$、補遺42)そのものであり、新しい入力ではない。

## 4. 振幅要請への含意(ハードル2)

§3 より、**振幅集合が二平方和に制限されること自体は新しい入力ではない**(既存の $J$ 構造の算術)。したがって「振幅が制限される」ことと「振幅が要請される」ことは別の命題である。振幅要請の問いは依然として補遺47の一点に圧縮されたまま:

> 経路数を Born 重みに変える $\mathbb{Z}_4$ 位相割当が正準か。正準なら振幅は創発(追加不要 — 設計者のテーゼが正しい)、非正準なら追加入力(補遺46 §5.2 の棄却条件)。

二平方和という制限は、この正準性問題が住む舞台($\mathbb{C}$ 段の算術)であって、要請の根拠ではない。**本丸は正準性ただ一つ。** 設計者の疑い(現在の理論物理学が振幅を本質的に要請しているのは本当か)は、正準性が成り立つ方に賭けることと厳密に同値であり、機械検算はこれを反証も立証もしていない。

## 5. 正直な限界

1. **単位の非対称**: $\nu_t^2$(零点込み周波数²)と $|z|^2$(整数)は単位が異なる。本稿が照合したのは「到達可能性の算術構造」であり値の一致ではない。ただし「全奇数 vs 二平方和」という構造の差は単位に依らない。
2. **正準性は未決**: 振幅の正準性(§4)は反証も立証もされていない — 補遺47の判定(どの規則も測度三候補を再現せず、B1のみ干渉項つき新値)のまま。
3. **塔対応は構造的並行**: 2平方=$\mathbb{C}$、4平方=$\mathbb{H}$ は標準だが、本モデルの $\nu_t^2$ と振幅が厳密にその段に「乗る」ことの形式証明は別途要する。§3 は対応の主張であって同型の証明ではない(補遺41 の名乗りの規律に従う)。
4. **(1,3) 集約は未構成のまま**: 時間の写像(丸め)が通ることと、4つの局所時計を1つの大域時計に畳む集約写像が構成されることは別の課題。後者は依然 論文6 §7.3 以来の未構成項(有力候補: ヌル条件 $\nu_t^2=\sum_i\nu_i^2$ そのものを貼り合わせ規則とする)。本稿は丸めの規則性を示したのみで、集約と矢は範囲外。

## §A. 計算コード(付録)

```python
# 補遺48 §1: 時間逆写像の標的集合 vs 振幅Born重みの集合 を直接照合。
# nu_t^2 = Sum(|k_i|+1/2)^2 (零点込み). 振幅: |z|^2 = a^2+b^2 = 二平方和.
from sympy import factorint

def is_sum_of_k_squares_classical(n, k):
    if n < 0: return False
    if k == 2:  # Fermat
        for p, e in factorint(n).items():
            if p % 4 == 3 and e % 2 == 1: return False
        return True
    if k == 3:  # Legendre: n != 4^a(8b+7)
        m = n
        while m % 4 == 0 and m > 0: m //= 4
        return m % 8 != 7
    if k == 4: return True  # Lagrange
    raise ValueError

K = 25
oblong = sorted({a*(a+1) for a in range(0, K+1)})
def sumset(vals, r, cap):
    s = {0}
    for _ in range(r):
        ns = set()
        for a in s:
            for v in vals:
                if a + v <= cap: ns.add(a + v)
        s = ns
    return s

CAP = 400
s4 = {x + 1 for x in sumset(oblong, 4, CAP)}          # nu_t^2 (4軸,零点込み)
odd_sq = sorted({(2*a+1)**2 for a in range(0, K+1)})
s3_times4 = sumset(odd_sq, 3, CAP*4)                   # 4*nu_t^2 (3軸)

print(sorted(x for x in s4 if x <= 60))               # -> 全奇数 1..59
print(set(range(1, CAP, 2)).issubset(s4))             # -> True (全奇数網羅)
s4l = sorted(s4)
print(max(s4l[i+1]-s4l[i] for i in range(len(s4l)-1) if s4l[i+1] <= CAP))  # -> 2
print(sorted({x % 8 for x in s3_times4}))             # -> [3]

odds = list(range(1, 200, 2))
inA = [n for n in odds if is_sum_of_k_squares_classical(n, 2)]
print(len(inA), "/", len(odds))                       # -> 36 / 100
```

**出力(2026-06-12 実行)**: 時間 $\nu_t^2$(4軸,零点込み)= 全奇数(間隔2)。3軸 $4\nu_t^2 \equiv 3 \pmod 8$。$1$–$2000$ で二平方和 619個(30.9%)・三平方和 1668個(83.4%)・四平方和 2000個(100%)。奇数 $<200$ のうち二平方和は 36/100。$137 = 11^2+4^2$ は二平方和かつ奇数(両集合に乗る一例だが集合の一致を意味しない)。
