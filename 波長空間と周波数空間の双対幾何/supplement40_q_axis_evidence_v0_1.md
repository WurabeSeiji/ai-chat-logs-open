# 補遺40:Q 軸の証拠 — ε 簿記の全数検査・二重不足の独立性・背景 xyztRQ 六軸

**作成**: 2026年6月11日
**版**: v0.1
**対象**: 2026-06-11 の問い —「この結果(R 認可アーキテクチャ)は Q 軸を追加しても成立するか。クーロン力・強い力・弱い力を持ち込むと Q 軸が必要になるはず」— の検証。判定基準は補遺39 §5.2 で予告した通り:**Q の証拠は「可視+R 認可でも閉じない第二の還元不能な不足」として現れるはずである**。前提: 補遺15(チャネル)、補遺18 §4.3(到達可能集合)、補遺30 §4(励起次数 ε)、補遺35(裸線時計 ω²=s−ドレッシング)、補遺38(R 不足)、補遺39(認可原理・3次頂点)
**性格**: 既存の断片ラベルのうち励起次数 **ε(k)=(−1)^{Σ|k_i|}**(補遺30 §4.2、B₄ 不変)の頂点簿記を、s=7,9,11,13 の全親軌道×全許容チャネル×全娘軌道割当で全数検査した。主結果:(1) **第二の還元不能な1ビット不足の発見**:s=7 (1,1,1,0)型と s=9 (1,1,1,1)型は、いかなる許容チャネル・いかなる娘割当でも端点 ε を保存できない。R 取引の単位(origin 型、ε=+1)は中立なので **R 帳簿はこの不足を吸収できない** — 補遺38 と同一の論法による第二の隠れ方向 Q の存在証明。(2) **二つの不足は独立**:線閉鎖(R 系)と ε 保存(Q 系)の可否は4通りの組合せがすべて実現する(s=13 で YES/NO と NO/YES の実例)。R は Q を代用できず、Q は R を代用できない。(3) **ε 保存則の同値形 = 裸ノルム²パリティ保存** Σ\|k_d\|²≡\|k_p\|² (mod 2):Q 電荷の正体は可視線の運動部分(裸線時計の ω²)のパリティであり、ねじセクター(補遺30)に接続する。(4) 背景は **4可視+2隠れ=6軸 xyztRQ**。物理的同一視は行わない。

## 0. 判定基準と検査対象

補遺38 は R 軸を「可視帳簿で閉じないちょうど1単位の不足」として発見した。同じ論法を第二の隠れ軸に適用する:既存の保存ラベル候補について頂点簿記を検査し、**可視+R 認可でも閉じない系統的不足**が出れば、それが Q の証拠である。

検査対象: 励起次数 ε(k)=(−1)^{Σ|k_i|}(補遺30 §4.2 でねじ持ち上げから同定された B₄ 不変 Z₂ ラベル)。加法形 q(k)=Σ|k_i| mod 2、全系 Q-パリティ = Σq mod 2。R 取引の単位(±1 の s、origin 型 k=0)は q=0 — **ε 中立**。

## 2. 主結果:第二の還元不能な不足(E2、全数)

s=7,9,11,13 の全親軌道×全チャネル(補遺15/18 の許容チャネル、容量則込み)×全娘軌道割当で、端点 ε 保存の可否と線閉鎖(補遺38 基準)を判定:

> **全チャネルで ε 保存不能な軌道はちょうど二つ**:
> - **s=7 (1,1,1,0)型**(32セル): ε=−1、唯一のチャネル (3,3,1) の ε 終集合は {+1} のみ。
> - **s=9 (1,1,1,1)型**(16セル): ε=+1、両チャネル (5,3,1)・(3,3,3) の ε 終集合は {−1} のみ。
>
> R 取引は ε 中立なので、この1ビットの端点不足は **R 帳簿では原理的に吸収できない**。補遺38 と同一の論法により、これは**第二の隠れ方向 Q の存在証明**である(在庫追加ではなく不足の発見)。

s=11 は全チャネルで保存可。s=13 は各軌道とも保存可能なチャネルを持つ(完全 stuck は 7, 9 の上記2軌道のみ — 小さい s に限局した「初期宇宙の病」である点は記録に値する)。

## 3. 独立性:R 不足と Q 不足は別の帳簿(E2 続)

線閉鎖(R 系)× ε 保存(Q 系)の可否は、s=13 までの表で**4通りの組合せがすべて実現**する:

| 例 | ε 保存 | 線閉鎖 |
|---|---|---|
| s=13 (2,2,0,0) × (9,3,1) | YES | YES |
| s=9 (2,1,0,0) × (3,3,3) | YES | NO |
| s=13 (2,2,0,0) × (5,5,3) | **NO** | **YES** |
| s=9 (1,1,1,1) × 両チャネル | NO | NO |

> R では Q を代用できず、Q では R を代用できない — **独立な隠れ帳簿が2本**。背景は 4可視+2隠れ = **6軸 xyztRQ**。なお s=9 (1,1,1,1)型(補遺33 の角セル)は両帳簿で同時に stuck な唯一の s=9 軌道であり、その崩壊は R と Q の双方を経由するしかない、最も深く隠れセクターに依存する対象である。

## 4. 副次的結果

1. **ε が保存できる場合、娘の軌道選択則として働く。** 例: s=11 → (7,3,1) では ε 保存が 7-娘の軌道を (1,1,1,0)型に強制する。電荷保存が崩壊生成物の微細構造を選ぶ — 電荷的振る舞いの最初の実例。
2. **Q とねじセクターの接続。** 検査ラベル ε は補遺30 がねじ持ち上げから同定した励起次数そのものであり、「並進=内部 U(1)⁴ 電荷」(補遺30 §2.2)と整合する。隠れ平面 (R,Q) の回転 SO(2)=U(1)(可視セクターに触れない内部対称性 — 隠れ軸2本の最初の構造的帰結)に、担う電荷の候補が付いた。
3. **mod 8 定理(補遺39 §1)は隠れ軸の本数に無関心**であり、6軸背景でも可視4軸の算術は無傷。認可原理も方向ごとの言明なのでそのまま一般化する(Q 取引=端点で Q 保存・中間で ±1 ビット違反可 — 電荷変更型仮想頂点の骨格)。

## 6. 正直な限界

1. **ε は一つのラベル選択である**: 他の候補(補遺38 の残余 Z₂×Z₂ 符号、ねじの U(1)⁴ 位相そのもの)の簿記検査は未実施。Q が Z₂ で尽きるか U(1) 級かは未決。
2. **Q 取引の力学(仮想 ε 変位の明示的構成)は未着手** — R と同様、認可原理が許す枠の特定まで。
3. チャネル表は補遺15/18 の許容集合(容量則込み)に依拠。s=13 の5体チャネルの線閉鎖判定は対ごとの交差線のみで行った。
4. 「電荷」「ゲージ力風味」は構造対応の語であり同一視ではない。隠れ平面 U(1) と標準模型の U(1) の関係は未構成。
5. ε-stuck が小さい s(7, 9)に限局する理由(大きい s では多軌道チャネルが ε の両値を供給する)の一般証明は未了 — stuck 集合の有限性は予想に留まる。
