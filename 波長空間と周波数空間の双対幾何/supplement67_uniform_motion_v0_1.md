# 補遺67:等速運動の写像 — 桁オドメータ・スペクトル不変・位相回転としての速度

**作成**: 2026年6月12日
**版**: v0.1
**対象**: 設計者の問い(2026-06-12)—「x 座標が等速移動する写像を作れるか。その x–t 図と周波数・波長空間の図が見たい。等速運動していても周波数と波長は時間発展しないのですよね?」— の構成と機械検証。スクリプト:`supplement67_uniform_motion.py`、図:`supplement67_fig_uniform_motion.png`
**性格**: 一つの構成と三つの検証結果。(1) **構成(等速運動の写像)**:等速運動=**位置桁の混合基数オドメータ**。毎ティック(Δt=1/√s)に最深¼量子(深さ2で 1/36)を1進める — 桁列 (d,c₁,c₂) は base [4;3,3] のカウンタとして進む。階層ピーリング復号(補遺63)が**36ティック全てで桁=カウンタ値を返し、x̂ₙ=n/36 厳密**(O1: 36/36)。世界線は格子点を通る厳密な直線、速度は v=Δa/Δt=(1/36)·√s。(2) **設計者の予想は正しい — スペクトルは時間発展しない**:単一コムの等速移動36ティックで、全奇数線の**振幅 |Z(f)| の最大偏差 1.9e-15**(厳密不変)。スペクトル支持(線の位置=波長構成)も不変であり、したがって **R=√s_read と Q=ε_read も不変**(O2-i, iii)。(3) **時間発展するのは位相のみ — そして位相回転率が速度そのもの**:各線の位相は厳密に線形回転し(残差 ~1e-15)、回転率は **f·v に厳密一致**(f=1,3,5,7,9 全て、比 3.000000)。(4) **速度の所在**:単一スナップショットのどこにも速度は現れない(振幅も支持も静止状態と同一)。**速度は記録の列にのみ存在する** — 運動は状態の属性ではなく記録系列の属性(記録原理の運動学版)。物理的同一視は行わないが、台帳上:|スペクトル|=自由運動の保存量(運動量様)、位相=位置、位相回転率=速度、という割当てが機械的に確定した。

## 1. 検証結果

| 検証 | 結果 |
|---|---|
| O1 オドメータ復号(36ティック) | **36/36** 桁=カウンタ・x̂=n/36 厳密 |
| O2-i 振幅スペクトル不変性 | 最大偏差 **1.9e-15**(36ティック・全奇数線 f≤27) |
| O2-ii 位相回転の線形性 | 残差 ~1e-15、回転率= **f·v 厳密**(比 f=3/f=1 = 3.000000) |
| O2-iii R・Q の不変性 | スペクトル支持不変 → s_read・ε_read 不変 |

## 3. 速度の有理格子(注記)

読み出し可能な等速運動の速度は v = m·(最深¼量子)·√s(m 整数)の有理格子に乗る。中間の速度は複数ティックに1回の桁繰り上げ(より緩い階段)として表現され、平均速度は有理数の稠密集合を走る — 連続速度はその完備化(位置の¼桁完備化と同型の建付け)。

## 4. 正直な限界

1. 本補遺の運動は**運動学**(等速スケジュールの写像と読み出し)であり、なぜそのスケジュールが実現するか(動力学=力なし→等速の導出)は別問題。本系列では波動セクターの三条件補間(論文12 §4.2)の管轄。
2. 加速運動(桁スケジュールの非一様化)・複数断片の相対運動・衝突は未構成(キュー)。
3. ドップラー的読み(時空記録を t 方向に読んだときの時間周波数 f·v のサイドバンド)は §1 の位相回転と同じ事実の別表現だが、t 軸読み(マーキング)との整合は補遺50 の枠で別途。
4. 物理的同一視は行わない。
