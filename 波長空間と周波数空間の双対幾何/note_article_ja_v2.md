# 双対幾何シリーズ完結 ── 三つの仮定から、量子的・時空的に見える構造はどこまで定理として従うか（論文1〜12）

波長成分と周波数成分の間に最も単純な逆数双対 νλ = 1 を置く——そこから始めた観察シリーズが、全12論文で完結しました。新たに論文5〜12の8本（各 日英バイリンガル、CC BY 4.0）を Zenodo で一斉公開しています。

本シリーズは一貫して観察モデルです。時空・質量・エネルギー・運動量などの物理的実体を導出するものではなく、モデル内の量を物理量と同一視しません。標準理論との関係はすべて構造対応（structural correspondence）として記述し、各論文に「主張すること／主張しないこと」の欄を置いています。評価・解釈は読者に委ねます。

---

## 全体像 ── 在庫は三つだけ

シリーズ全体で使う仮定は、次の三つがすべてです。

- 仮定1：逆数双対　νλ = 1
- 仮定2：零点　½（最小の共役幅）
- 仮定3：非対称1ビット（保存則 Σν² は双対の一方の帳簿にのみ乗る）

連続時空・振幅・波動関数・収縮は、どれも仮定しません。問いはひとつです。

　この在庫だけから、量子的・時空的に見える構造は、どこまで「定理として」従うか。

主張はすべて、計算機による全数検証・厳密恒等式・機械精度の数値で支持されています。検証スクリプトと研究ノート（補遺1〜41）も全て公開しています。

## 基礎（論文1〜4、公開済み）

- 論文1：逆数双対と対数表現。双曲線 νλ = 1 は対数変数で直線 p = −q（符号反転対称）になる
- 論文2：4次元整数格子の数え上げ N₀(R) の厳密数表。N₀(1) = 1、N₀(2) = 9、N₀(3) = 137、……
- 論文3：追補（radial projection との接続）
- 論文4：高い半径の状態が有限個の状態群に分裂する表現、体積ギャップ、双対性の破れ、自己相似階層

このシリーズの数列の核は、単位セル（各方向の半幅 ½）が半径 R の4次元超球体に完全内接する条件

　Σ (|kᵢ| + ½)² ≤ R²

から得られる N₀(R) = 1, 9, 137, 473, 1545, … です。137 という値は物理定数との対応を仮定して導入したものではなく、純粋な数え上げの結果です（この立場はシリーズを通じて変わりません）。

## 展開（論文5〜12、今回公開）── 定理の連鎖

論文5：セル＝定在波辞書と半径の量子化
　格子の数え上げは、零点 ½ つきの実定在波の計数と厳密に一致します（辞書定理）。この同定から連鎖的に、最小共役幅の正体（零点量子）、体積ギャップの正体（有効境界の Weyl 不足量 16π/3）、例外なし分裂定理、そして R² が奇数整数に量子化される分類定理が従います。長く残っていた 137 か 105 かという境界の問題も、規格化の恣意性ではなく連続/離散の見方の違いとして内在的に解消されます。

論文6：保存則・記録・時間様構造
　もし双対の両側が同時に保存するなら、分裂は一切起こらず系は凍結します（凍結定理）。つまり仮定3の非対称1ビットこそが、時間様構造が存在できる条件そのものです。測定記録が常に波長側の配置として残ること（記録定理）、不確定性が対数共役平面のブースト不変な最小面積として内蔵されることも、ここで定理になります。

論文7：配置統計と関係的読み出し
　分裂後の断片を共有格子の占有セルと読むと、区別不能性と排他原理が仮定ではなく定理として従います。その帰結として、安定して存在できる種は {1, 3, 5} のみ、崩壊の敷居は s = 7、s = 9 の崩壊分岐比は 77.4% : 22.6% に一意に決まります。複数の断片の間の角度（関係的幾何）が、干渉縞の強度だけから完全に読み出せることも示します。

論文8：二つの会計 ── 凝縮・内部膨張・面積法則
　容器（曲率）が断片それぞれのものか、全体で共有されるか——会計の取り方ひとつで、分散と凝縮が反転します。閉じた系の内部分割を内部観測者の比で読むと、見かけのスケール因子は a ∝ √t（輻射期型）に従います。真空的な隙間は無構造な空白ではなく、進化を可能にする面積の貯水池です。

論文9：論理波と半波長検閲
　格子は零点 ½ を基底とする奇数倍音の梯子であり、これは2値の論理波の指紋です。曲率による梯子の歪みは最大でちょうど ½——分解能の半分以下に収まるため、連続的な崩壊チャネルは運動学的に閉じます（複合体の安定性＝変形空間の量子化）。さらに干渉閉合テストにより、大きな塊は単一実体としては存在できないことが示されます。階層化は選択ではなく強制です。

論文10：創発ゲージ構造
　ゲージ原理を一度も仮定せずに、接続が運動学だけで一意に決まり、最初のホロノミー（π/2 回転）が測地三角形の面積と厳密に一致し、連続群 SO(4) が結晶学的制限によって強制されます。スピン構造の素材と、結合定数のデフォルト値 β = 0 までが副産物として現れます。

論文11：次元の必然性
　複合体を守る検閲が成立する次元は d ∈ [0, 4] に限られ、飽和はちょうど両端のみ（両端点定理）。整数の記録帳簿が立つのは mod 8 の算術から d = 4 だけ。さらに最小セルが双対の固定点に座る次元も d = 4 のみ——上から・無条件・下から、三つの独立な機構が同じ値を挟み撃ちにします。

論文12：双子最小空間モデル（最終篇）
　偶数の初期値はパリティにより単一状態として存在できず、対として生まれることが強制されます。双子の取りうる分離は離散カタログに量子化され、mod 4 の禁止帯を持ちます。測定とは記録の追記（無 → 有）であり、収縮は記録の出現、その不可逆性は時間の矢と同じ1ビットに還元されます。もつれの瞬時の相関は速度ではなくレイヤの言明であり、無信号性は記録構造から従います。そして頂点の帳簿にちょうど1単位ずつ足りない二つの不足が、二つの不可視方向（R と Q）の存在を指し示します。

## ハイライト

- 二階建ての一致：安定種 {1, 3, 5} と敷居 s = 7 は、数え上げの階（論文7）と波の階（論文9）という独立な計算で同じ値に到達します
- 公準の削減：排他原理・測定の収縮・時間の矢・整数格子が、仮定から定理（または分解能構造）に降りてきます
- 次元の挟み撃ち：d = 4 が三つの独立な機構に選ばれます
- 反証可能性：このモデルでは振幅が曲率と結合できないため、重力媒介もつれ（BMV 型）実験が生きた判定者になります
- 再導出しないことは欠陥ではない：標準理論の定理は、前提の対応物が検証済みなら移送されます（移送原理）。差分は、標準理論が公準で済ませた問い（収縮・切断の位置・時間・次元）への解答候補の側にあります
