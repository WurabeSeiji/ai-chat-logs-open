置き方:
   T(0, 0, 0) = d
   T(0, 0, 1) = c
   T(0, 1, 0) = b
   T(0, 1, 1) = a
   T(1, 0, 0) = a
   T(1, 0, 1) = b
   T(1, 1, 0) = c
   T(1, 1, 1) = d

[三項の積] Prod(T,T,T)
   d の升目 (2 個): a*b*c + d**3
   a の升目 (2 個): a*(a*d + b*c)
   b の升目 (2 個): b*(a*c + b*d)
   c の升目 (2 個): c*(a*b + c*d)

[二項の積] T*T
   d の升目 (2 個): 2*a*b + c**2 + d**2 , a**2 + b**2 + 2*c*d   <- 二つの升目で値が違う
   a の升目 (2 個): (a + b)*(c + d)
   b の升目 (2 個): (a + b)*(c + d)
   c の升目 (2 個): 2*a*b + c**2 + d**2 , a**2 + b**2 + 2*c*d   <- 二つの升目で値が違う

[三項の積] 具体的な値で繰り返す (厳密)
  d=0, (a,b,c)=(1,ω,ω²)
     1 回目: d=1  a=1  b=1  c=1
     2 回目: d=2  a=2  b=2  c=2
     3 回目: d=16  a=16  b=16  c=16
     4 回目: d=8192  a=8192  b=8192  c=8192
  d=1, (a,b,c)=(1,ω,ω²)
     1 回目: d=2  a=2  b=1/2 - sqrt(3)*I/2  c=1/2 + sqrt(3)*I/2
     2 回目: d=10  a=10  b=1 - sqrt(3)*I  c=1 + sqrt(3)*I
     3 回目: d=1040  a=1040  b=20 - 20*sqrt(3)*I  c=20 + 20*sqrt(3)*I
     4 回目: d=1126528000  a=1126528000  b=832000 - 832000*sqrt(3)*I  c=832000 + 832000*sqrt(3)*I
  d=1, (a,b,c)=(i,-1,-i)
     1 回目: d=0  a=-2  b=0  c=-2
     2 回目: d=0  a=0  b=0  c=0
     3 回目: d=0  a=0  b=0  c=0
     4 回目: d=0  a=0  b=0  c=0
  d=0, (a,b,c)=(i,-1,-i)
     1 回目: d=-1  a=-1  b=-1  c=-1
     2 回目: d=-2  a=-2  b=-2  c=-2
     3 回目: d=-16  a=-16  b=-16  c=-16
