[二つを掛ける積] T*T の一回分 (記号のまま)
   複素数 1 (升目 (1,1,·)):  実部 = a1**2 + a2*a3 + b1**2 + b2*b3   虚部 = 2*a1*b1 + a2*b3 + a3*b2
   複素数 2 (升目 (1,2,·)):  実部 = a1*a2 + a2*a4 + b1*b2 + b2*b4   虚部 = a1*b2 + a2*b1 + a2*b4 + a4*b2
   複素数 3 (升目 (2,1,·)):  実部 = a1*a3 + a3*a4 + b1*b3 + b3*b4   虚部 = a1*b3 + a3*b1 + a3*b4 + a4*b3
   複素数 4 (升目 (2,2,·)):  実部 = a2*a3 + a4**2 + b2*b3 + b4**2   虚部 = a2*b3 + a3*b2 + 2*a4*b4
