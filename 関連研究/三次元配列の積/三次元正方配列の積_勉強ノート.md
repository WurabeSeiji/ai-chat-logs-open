## 1. なぜ行列の積のままでは立方体が閉じないか

行列の積は、添字を一本共有して足す。

(AB)_ij = Σ_t A_it B_tj

添字は 2 本 + 2 本 = 4 本、共有の 1 組(2 本)が消えて 2 本残る。だから行列×行列は行列である。

立方体は添字が 3 本。二つを一本の添字で縫うと 3 + 3 − 2 = 4 本残り、立方体にならない。KM §3.1 も、従来の「縮約による積」は階数を保たないと述べ、これが新しい積を定義する動機になっている。

閉じる道は二つある。

- **二つ掛ける(二項の積)**：三本目の軸に別の規則(巡回の足し算)を入れる。→ §2
- **三つ掛ける(三項の積)**：3 + 3 + 3 = 9 本。足す添字が三つの因子に 1 本ずつ入り(3 本消える)、残りの 6 本は 2 本ずつ同じ値を共有して 3 本になる。規則を足さずに閉じる。→ §3

## 2. 二項の積(t 積)

### 2.1 定義(KM 定義 3.1)

立方体 A を、三本目の軸に沿った n 枚の正方行列 A_0, …, A_{n−1} の束と見る(KM は 1 から数えるが、ここでは 0 から数える)。A∗B の s 枚目は

(A∗B)_s = Σ_{a+b ≡ s (mod n)} A_a B_b

右辺の A_a B_b はふつうの行列の積である。成分で書くと

(A∗B)_{ij,s} = Σ_{a+b≡s} Σ_t A_{it,a} B_{tj,b}

KM の書き方では A∗B = fold(circ(A)·MatVec(B))。circ(A) は A の束を巡回させて並べたブロック巡回行列である。

言葉で言うと、**縦と横は行列の積、高さは番号の足し算(一周 n)**。

### 2.2 性質(KM)

- **結合的**(補題 3.3)：A∗(B∗C) = (A∗B)∗C。
- **単位元がある**(定義 3.4)：0 枚目が単位行列、ほかの枚は 0 の立方体 I。A∗I = I∗A = A。
- **可逆なものは群をなす**(補題 3.6)。
- **転置**(定義 3.14、補題 3.16)：各枚を転置し、1 枚目以降の順を逆にする。(A∗B)ᵀ = Bᵀ∗Aᵀ。
- **フーリエ変換で対角化**：三本目の軸に沿って離散フーリエ変換をかけると、t 積は「枚ごとのふつうの行列の積」になる(KM Fact 1〜3)。

### 2.3 十字 N=4 で計算する

**(a) 対角だけに置く：O_kkk = z_k**

0 でない成分は 4 個：(0,0,0)=1、(1,1,1)=i、(2,2,2)=−1、(3,3,3)=−i。

O の a 枚目は、(a, a) の位置に z_a があるだけの行列である。a 枚目と b 枚目の行列の積は a = b のときだけ残り、(a, a) に z_a² が入る。行き先は 2a 枚目。同じことを繰り返すと

**O^p の 0 でない成分は、位置 (a, a, p·a mod 4)、値 z_a^p**

| | (0,0,·) | (1,1,·) | (2,2,·) | (3,3,·) |
|---|---|---|---|---|
| O | 0 枚目に 1 | 1 枚目に i | 2 枚目に −1 | 3 枚目に −i |
| O² | 0 枚目に 1 | 2 枚目に −1 | 0 枚目に 1 | 2 枚目に −1 |
| O³ | 0 枚目に 1 | 3 枚目に −i | 2 枚目に −1 | 1 枚目に i |
| O⁴ | 0 枚目に 1 | 0 枚目に 1 | 0 枚目に 1 | 0 枚目に 1 |

**O⁴ は単位の立方体 I に厳密に等しい。O⁵ = O。**(検算済み。O⁸ も I)

読めること：

- 値は z^p と冪で回り、同時に、置かれている枚(高さ)も p·a と回る。位相と位置が一緒に巡回する。
- 縦と横については対角のまま(a, a)。混ざるのは高さだけである。
- 4 個は互いに掛かり合っていない。成分ごとに別々に回っているだけである。

**(b) 三つの積を全部並べる：X_ijk = z_i z_j z_k**

64 個の成分は 1, i, −1, −i が 16 個ずつ。ΣX = 0、ΣX² = 0。

X の a 枚目は z_a·(z zᵀ)(z は縦ベクトル)。行列の積 (z zᵀ)(z zᵀ) = z (zᵀz) zᵀ で、zᵀz = Σz² = 0。したがって

**X∗X = 0**(検算済み)

十字の第二の性質 Σz² = 0(モーメントの釣り合い)が、そのまま「この配列は二乗で消える」になる。

**(c) 真ん中の添字だけ共役：Y_ijk = z_i z̄_j z_k**

a 枚目は z_a·(z z†)。(z z†)(z z†) = z (z†z) z† = 4 z z†。高さの和は Σ_{a+b≡s} z_a z_b = 4 z_s。したがって

**Y∗Y = 16 Y**(検算済み。16 = N²)

二乗しても形が変わらず、大きさだけが N² 倍になる。割り算を入れていないので、繰り返すと 16 倍ずつ大きくなる(そのまま報告する)。

(b) と (c) の違いは、縦と横の縫い目に Σz²(= 0)が出るか Σ|z|²(= N)が出るかである。共役を入れるかどうかで、消えるか残るかが分かれる。

## 3. 三項の積(Bhattacharya–Mesner 積、BM 積)

### 3.1 定義(G 定義 1、三階の場合)

三つの立方体 A, B, C から

Prod(A, B, C)_ijk = Σ_t A_itk · B_ijt · C_tjk

G の一般形は「A⁽¹⁾ は 2 番目の添字、A⁽ᵗ⁾ は t+1 番目の添字、最後の A⁽ᵐ⁾ は 1 番目の添字を、足す添字 j に置き換える」である。m = 2 にすると Σ_t A_it B_tj、つまり行列の積に戻る。

(注：G の PDF では、三階の場合を書き下した行の添字が一般形と合っていない。誤植と思われる。ここでは一般形から導いた上の式を採った。)

BB と BP は同じ積を別の並べ方で書く(条件 A2)：Σ_w A_wjk B_iwk C_ijw。A が 1 番目、B が 2 番目、C が 3 番目の軸に足す添字を持つ。どの因子がどの軸を受け持つかの番号の付け替えで、中身は同じである。

言葉で言うと、**結果の升目 (i, j, k) を、三つの因子がそれぞれ別の一本の軸の方向から覗き、その軸に沿って一緒に足し上げる**。縦×横×高さである。

### 3.2 性質

- **一般に結合的でない**(BB と検索で得た後続論文の記述。下で具体例を検算)。
- **単位元は行列のように一つには決まらない**。BB の序論によれば、Mesner と Bhattacharya(1994)は「単位の対」「逆の対」を、単位元と逆元の代わりとして導入した。中身は未読。
- 行列の代数で成り立つ半単純性・双対性の三項版が成り立つかは、まだ分かっていない(BB 序論)。
- G によれば、外積・縮約積・多重線形の行列積など、文献にある配列の積の多くは、一般化した BM 積かその双対の特別な場合である。

### 3.3 十字 N=4 で計算する

**(a) 対角だけに置く：O_kkk = z_k**

Σ_t O_itk O_ijt O_tjk が 0 でないのは i = t = k、i = j = t、t = j = k がすべて成り立つとき、つまり i = j = k = t のときだけ。

**Prod(O, O, O) は対角だけで、成分は z_k³**

十字では z³ = z̄ なので、一回で共役、二回で元に戻る(検算済み)。周期 2。K₄ 論文の m = 3 の倍音 U^(3k) と同じ形である。対角の外へは広がらない。

**(b) 三つの積を全部並べる：X_ijk = z_i z_j z_k**

Σ_t (z_i z_t z_k)(z_i z_j z_t)(z_t z_j z_k) = z_i² z_j² z_k² · Σ_t z_t³。十字では Σz³ = 0。

**Prod(X, X, X) = 0**(検算済み)

二項の積では Σz² = 0 で消え、三項の積では Σz³ = 0 で消える。足す添字に乗る冪が、積の項数と同じになる。

**(c) 真ん中だけ共役：Y_ijk = z_i z̄_j z_k**

足す添字 t に乗るのは z̄_t · z_t · z_t = |z_t|² z_t = z_t。Σz = 0 なので、これも 0(検算済み)。

つまり十字については、足す添字に z の何乗が乗るかで決まる。Σz = Σz² = Σz³ = 0、Σz⁴ = 4 なので、**足す添字に z⁴(または |z|² や |z|⁴ のように位相の消える組)が乗る置き方だけが残る**。

### 3.4 対称性(決め打ちの整数の配列で検算。乱数ではない)

- **軸を一つ回す**(T′_jki = T_ijk)と、Prod(A, B, C)′ = Prod(B′, C′, A′)。因子も一つ回る。
- **二本の軸を入れ替える**(1 番目と 3 番目)と、Prod(A, B, C)~ = Prod(A~, C~, B~)。因子が二つ入れ替わる。符号は付かない。
- **結合的でない**：Prod(Prod(A,A,A), A, A)、Prod(A, Prod(A,A,A), A)、Prod(A, A, Prod(A,A,A)) は互いに等しくない。
- 参考：同じ配列で、二項の積は (A∗A)∗A = A∗(A∗A)。

読めること：

- 行列では転置で積の順序が逆になる((AB)ᵀ = BᵀAᵀ、二つの入れ替え)。立方体では、三本の軸の並べ替え(6 通り)に因子の並べ替えが対応する。巡回(Z₃)だけでなく、入れ替えも含む。
- 四元数の i, j, k と同じなのは「三つの巡回で形が変わらない」こと。違うのは、二つを入れ替えたとき、虚数単位は符号が反転する(ij = −ji)のに対し、BM 積は因子が入れ替わるだけで符号は付かないこと。符号は、積の規則ではなく、配列の成分の側(反対称な配列を置くかどうか)で決まる。

## 4. 二つの積の比較

| | 二項の積(t 積) | 三項の積(BM 積) |
|---|---|---|
| 一回で掛かる数 | 二つ | 三つ |
| 三本の軸の扱い | 縦・横は行列の積、高さは巡回の足し算。軸は対等でない | 三本とも対等 |
| 結合的か | はい | いいえ |
| 単位元 | ある(0 枚目が単位行列) | 一つには決まらない(「単位の対」) |
| Oⁿ = I | そのまま意味を持つ | 「元に戻る」で判定するしかない |
| 十字を対角に置く | O⁴ = I。位相と高さが一緒に回る | 一回で共役、二回で元。周期 2 |
| 十字の三つの積を全部並べる | X∗X = 0(Σz² = 0 のため) | Prod(X,X,X) = 0(Σz³ = 0 のため) |
| 対角だけから始めて混ざるか | 混ざらない(高さだけ動く) | 混ざらない |

## 5. 気づいたこと(Claude の読み。文献の主張ではない)

1. **「1 + 3」が定義の中にある。** 三つ組の上のアソシエーション・スキームでは、どの場合にも必ず置かれる「自明な関係」が四つある(BB 定義 1、BP 定義 1.1)。
   - R₀ = {(x, x, x)}：三つとも同じ。対角。
   - R₁ = {(x, y, y)}、R₂ = {(x, y, x)}、R₃ = {(x, x, y)}：二つが同じで一つが違う。どの軸が違うかで三種類。

   対角が 1、二つそろいが 3 で、合わせて 1 + 3。三つとも違う組が、そのあとに来る「自明でない関係」である。木原さんの「最初は対角だけ」「(1+3)(1+3)」と同じ切り分けになっている。

2. **十字の閉じ方が、積の消え方を決める。** Σz = 0(重心)、Σz² = 0(モーメント)、Σz³ = 0 が、それぞれ別の置き方・別の積を 0 にする。残るのは位相が打ち消される組(4 乗、または共役との組)だけ。基点の論文の Q_loop の整除条件と同じ仕組みである。

3. **対角だけからは、どちらの積でも混ざらない。** 交差項が生まれるには、最初に対角の外(少なくとも「二つそろい」の R₁〜R₃ の位置)に何かが要る。

4. **割り算を入れないと、残る置き方は N の冪で大きくなる。**(§2.3 (c) で 16 倍)
