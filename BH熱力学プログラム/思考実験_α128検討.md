## ご立場の核心仮説（木原氏）

> **137 は xyQ 写像構造、128 は xy 写像構造。両者とも写像軸は t 軸。高エネルギーでは Q 軸も写像軸に加わって次元が削減されている。**

つまり：

| 観測者の状態 | 写像軸（観測者の内部参照系） | 観測される構造 |
|---|---|---|
| **低エネルギー（Thomson 限界）** | **t のみ** | 137 構造（xyQ 関与） |
| **高エネルギー（M_Z）** | **t + Q（fusion）** | 128 構造（xy のみ関与） |

→ 高エネルギーで Q 軸が観測者の写像軸に「吸収」され、観測される次元が 1 つ減る。

## 電磁相互作用と t 軸の本質的 coupling

### 負電荷の存在条件

電荷の正負を定義するには **時間方向の orientation** が必要：

- 正電荷：通常の粒子（t 軸正方向に進化）
- 負電荷：反粒子（Feynman-Stückelberg：t 軸逆方向の正電荷）
- CPT 定理：C（電荷共役）と T（時間反転）の同時操作で不変

→ **t 軸の orientation がなければ「+Q」と「−Q」の区別ができない**

t は座標としては中立だが、**観測者が t を「進化方向」として選んだ瞬間、Q 軸の符号が物理的意味を獲得する**。

### Maxwell 方程式における t-Q coupling

- $\nabla \times E = -\partial B/\partial t$
- $\nabla \times B = \mu_0 J + \mu_0 \epsilon_0 \partial E/\partial t$
- 電流 $J = \rho v$ は電荷 $\rho$ と時間変化の組み合わせ
- ゲージ変換 $A_\mu \to A_\mu + \partial_\mu \chi$ も t 方向を含む

→ **電磁相互作用 = (t 軸の orientation) × (Q 軸の符号構造) の coupling**

t と Q は独立な軸ではなく、**electromagnetism を定義する組**として一体化。

## CPT 対称性との整合

- C：Q → −Q（電荷共役）
- P：xyz → −xyz（パリティ）
- T：t → −t（時間反転）

ご立場では：
- **t と Q は coupling** していて、C と T は独立ではない
- 高エネルギーで t + Q が写像軸に吸収 → **CT が同時に内部参照に「入る」**

これは CPT 定理の **幾何学的具現化** と読める。

### 負電荷の幾何学的存在条件

$$\text{電磁気的に「負電荷」が定義可能} \iff \text{観測者が t を写像軸として選んでいる}$$
