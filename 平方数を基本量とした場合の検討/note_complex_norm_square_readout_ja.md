# 共役な複素数は、じつはただの平方和 ── 理論物理の基本表現をシンプルに読み直す

理論物理や工学で、波や振動を書くときに必ず出てくる表現があります。複素数です。とくに、複素数とその「共役」をかけ合わせる操作は、量子力学から信号処理まで、いたるところに現れます。

この記事では、その共役な複素数の操作が、じつはとてもシンプルな平方和（二乗の足し算）に等しい、という一点だけを、できるだけ易しく紹介します。新しい物理法則の話ではありません。すでに知られている数学を、見通しよく並べ直すだけの、短い観察ノートです。

## 複素数と、その共役

複素数は、実部と虚部という二つの数をひとまとめにしたものです。

　Z = x + iy

ここで i は虚数単位で、i² = −1 という性質を持ちます。x が実部、y が虚部です。

この Z の「共役」とは、虚部の符号だけをひっくり返したものです。

　共役 = x − iy

そして、複素数とその共役をかけ算すると、次のようになります。

　(x + iy)(x − iy) = x² + y²

虚部どうしの項がきれいに打ち消し合って、残るのは x² + y²、つまり二つの実数の二乗の足し算だけです。虚数 i は消えてしまいます。

これは、平面上の点 (x, y) の原点からの距離の二乗、すなわちピタゴラスの定理そのものです。半径を ρ とすれば

　x² + y² = ρ²

です。複素数を「大きさ ρ と向き（位相）θ」で書けば Z = ρ(cosθ + i sinθ) ですが、共役とかけ算すると向き θ は消えて、大きさ ρ の二乗だけが残ります。

言いかえると、共役な複素数のかけ算は、向きの情報を落として、二乗の大きさだけを取り出す操作です。

## たくさんの軸へ、対等に広げる

面白いのは、これがそのまま多次元へ広がることです。

実数の座標をたくさん用意して、二本ずつペアにして複素数に束ねます。

　Z₁ = x₁ + i x₂ 、 Z₂ = x₃ + i x₄ 、…

それぞれを共役とかけて足し合わせると、

　x₁² + x₂² + x₃² + x₄² + … = R²

となります。つまり、共役な複素数をいくつ束ねても、結局は全部の座標の二乗の足し算＝一つの半径の二乗になります。

ここで大事なのは、どの軸も対等だということです。特別あつかいされる軸はありません。いま見ている複素平面に出てこない軸（この記事では見えない軸と呼びます）も、同じプラスの符号で、同じ資格で足されるだけです。半径 R はいつでも「全部の二乗の足し算の平方根」ただ一つで、意味が二重になることはありません。

これがこの記事の主題です。共役な複素数という、理論物理でおなじみの表現は、じつは対等な平方和の別の書き方にすぎない、という読み替えです。

## もう一歩だけ（ただし、ここは物理ではありません）

最後に、もう一歩だけ踏み込みます。ここは代数の遊びであって、物理の主張ではないことを、先に強くお断りしておきます。

さきほどは実数の座標を束ねました。では、座標の一つをあえて虚数の値にとってみます。たとえば、ある座標を i z と置きます。すると、その二乗は

　(i z)² = i² z² = − z²

となり、マイナスがついた二乗が現れます。マイナスは、こちらが符号を手で決めたのではなく、i² = −1 という虚数の性質から自然に出てきたものです。

すると、全部の二乗の足し算をゼロと置いたとき、

　x² + y² + … = z²

のような、片側だけがマイナス側にまわった形が出てきます。ここでのポイントは、この形が、共役なかけ算（大きさを取り出す操作、いつでもプラス）とは別の操作から出ている、という一点です。実数の座標では両者は同じですが、虚数の座標のときだけ、この二つは食い違います。マイナスはそこからだけ生まれます。

繰り返しますが、これは代数の書き換えの観察です。ここに出てくる z を時間だと言ったり、この式から相対論や光円錐を導いた、などと言うつもりはありません。座標の記号は、あくまで幾何学的なラベルであって、物理の空間や時間の次元と同じものだとは主張しません。そこへ進むには、まったく別の物理的な仮定が必要になります。この記事は、その手前で止めます。

## まとめ

・共役な複素数のかけ算は、向き（位相）を落として、二乗の大きさだけを残す。結果は x² + y²、ただのピタゴラスの平方和。
・これは多次元へ、すべての軸を対等にしたまま広がる。共役複素の束ね＝一つの半径の二乗。
・座標の一つを虚数にとると、i² = −1 のせいでマイナスの二乗が出る。ただしこれは代数の帰結であって、物理（時間・相対論・計量）の主張ではない。

理論物理でおなじみの共役複素数を、いちばんシンプルな平方和の言葉に置き直してみると、意外と見通しがよくなる、というだけの小さなノートでした。
