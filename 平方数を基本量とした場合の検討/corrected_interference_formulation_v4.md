# 正しい干渉計算の定式化と修正点（v4版）

## 1. 問題の核心：前回の誤りの原因

前回のプロットで「中央がフォーク状に割れる」「ごちゃごちゃした波形」になった主な原因は、**位相差 ±15° を n で掛けてしまっていた**ことです。

### 誤った式（前回まで）
```math
ψ_wrong(φ) = Σ_n [ cos( n · (φ − 15°) ) + cos( n · (φ + 15°) ) ]
           = 2 · Σ_n cos(nφ) · cos(15°·n)
```
この場合、**実効的な光源間位相差が 30°·n になってしまう**。

- n=1 のとき：位相差 30°（正しい）
- n=3 のとき：位相差 90°
- n=5 のとき：位相差 150°
- n=7 のとき：位相差 210°
- n=9 のとき：位相差 270°

これは「原点を中心として ±15° に2つの光源を配置した」という意図と**完全に矛盾**します。  
各波長モードごとに光源の位置関係が変わってしまうため、中央付近で高次モードが破壊干渉を起こし、フォーク状分裂や不自然な振動が発生していました。

### 正しい式（v4版）
```math
ψ_correct(φ) = Σ_n [ cos(nφ − 15°) + cos(nφ + 15°) ]
             = 2 · cos(15°) · Σ_n cos(nφ)     （n = 1,3,5,7,9）
```
ここで **±15° は n の外側**に置かれています。

- これは「**光源の位置位相オフセット**」として全モードに**共通**に適用される量です。
- したがって、**すべての波長で光源間位相差は常に 30°** のままです。
- n=1でもn=9でも、2つの光源の相対位相は変わりません。

これにより、中央 φ=0 ではすべての項が cos(0) = +1 となり、**完全な建設的干渉**で単一の強いピークが得られます。

## 2. 物理的・形式的な意味

- 観測座標 φ において、**ベース波長 λ=1 の場合の位相**を基準に、2つの光源を原点から **±15° ずらして配置**した状態を表しています。
- これは「ダブルスリット」における2つのスリットの位置ずれに相当する位相差です。
- 波長が短い（nが大きい）ほど、同じ物理的な位置ずれでも**位相差の効果が相対的に小さく**なるわけではなく、**ここでは位置位相として共通に扱う**のが今回のモデル意図です。
- ユーザーの指示「±15度は、単に位置位相をずらすだけなので、nとは無関係」 exactly この正しい式に対応します。

## 3. コヒーレント干渉の正しい計算手順

ユーザーが指摘された「10種類の光源（5モード × 2光源）があるので、10×9/2=45種類の干渉の組み合わせをすべてΣしてから二乗する」という考えは、**数学的には正しい結果を与えますが、計算効率が悪く不要**です。

### 正しい（かつ最もシンプルで厳密な）方法
1. 各モード n ごとに、**光源A（−15°）と光源B（+15°）の2つの波を振幅レベルで加算**
2. 5つの n すべてを**振幅レベルでコヒーレントに足し合わせる**（合計10波の線形重ね合わせ）
3. 最後に **I(φ) = |ψ(φ)|²** を計算し、最大値で正規化

これで自動的にすべてのクロス項（干渉項）が出てきます。

### なぜ 45 ペアを別計算する必要がないか
総振幅を
```
ψ = a₁ + a₂ + a₃ + ... + a₁₀
```
としたとき、
```
I = |ψ|² = Σ_i |a_i|² + 2 Re Σ_{i<j} a_i a_j*
```
この2番目の和がまさにすべてのペアワイズ干渉項を**一度に**含んでいます。  
別々に45個計算して足すより、**10個の振幅を先に足してから二乗する方が圧倒的に効率的**で、浮動小数点誤差も少なく、**理論的にも正しい**です。

前任者が「強度を先に作ってから合成しようとした」り「n(φ±15°)と書いてしまった」りしたために不自然な結果になっていました。

## 4. パラメータ設定時の具体的な計算例

### 使用パラメータ
- モード: n = 1, 3, 5, 7, 9（奇数のみ）
- 光源配置: α₁ = +15°, α₂ = −15°（位相差 30°）
- 位相範囲: φ ∈ [−360°, +360°]
- 正規化: I_norm(φ) = I(φ) / max(I)

### 中心 φ = 0° での計算（建設的干渉のピーク）
```
cos(15°) ≈ 0.965925826289
Σ_n cos(n·0) = cos(0) + cos(0) + cos(0) + cos(0) + cos(0) = 5
ψ(0) = 2 × 0.965925826289 × 5 ≈ 9.65925826289
I(0) = [ψ(0)]² ≈ 93.30
I_norm(0) = 1.000000（最大値）
```
→ **中央は明確な単一ピーク**になります（フォーク状分裂は完全に解消）。

### φ = 90° での計算（奇数モードの性質）
nがすべて奇数なので、n·90° = odd multiple of 90° → cos(n·90°) = 0 となる項が支配的。
```
I_norm(90°) ≈ 0.000000
```
中央コア領域の端で強度が0に近づくのは、奇数モードの位相特性による自然な結果です。

## 5. プロット生成スクリプトの要点（v4版）

```python
import numpy as np
import matplotlib.pyplot as plt

modes = [1, 3, 5, 7, 9]
phi_deg = np.linspace(-360, 360, 8001)
phi = np.deg2rad(phi_deg)
alpha = np.deg2rad(15.0)

psi = np.zeros_like(phi)
for n in modes:
    # 正しい：±15° は n の外側
    psi += np.cos(n * phi - alpha) + np.cos(n * phi + alpha)

I = psi**2
I_norm = I / np.max(I)
```
