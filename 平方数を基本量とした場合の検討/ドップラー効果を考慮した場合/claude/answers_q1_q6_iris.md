## Q1 詳細:複素拡張が厳密に通る(証明)

### 主張
シフト核 S_N(φ−φ₀) は、半波長区間 [−π/2, π/2] 上の**完全な奇数調波基底** {e^{inφ} : n odd, n∈ℤ}(同値に {cos((2m+1)φ), sin((2m+1)φ)})の切り詰め再生核である。ゆえに任意の複素・帯域制限 ψ_base を厳密再生する。

### 完全性
{e^{inφ} : n odd} = e^{iφ}·{e^{i2mφ} : m∈ℤ}。後者は長さ π の区間で完全、e^{iφ} は unimodular ゆえ完全性を保つ。よって奇数調波基底は [−π/2, π/2] で完全(偶関数=square-wave 展開、奇関数=sin 展開、いずれも表現可能)。

### モードごとの再生(核心)
S_N(ψ) = (1/2) Σ_{n odd, |n|≤N} e^{inψ}。複素モード ψ(φ)=e^{ikφ}(k odd, |k|≤N)に対し:

```
(S_N * e^{ik·})(φ₀) = ∫_{−π/2}^{π/2} S_N(φ−φ₀) e^{ikφ} dφ
                    = (1/2) Σ_n e^{−inφ₀} ∫_{−π/2}^{π/2} e^{i(n+k)φ} dφ
```

ここで n+k は偶数(n,k とも奇)ゆえ sin((n+k)π/2)=0、積分は n+k=0 のときのみ π:

```
∫_{−π/2}^{π/2} e^{i(n+k)φ} dφ = π δ_{n+k,0}
⇒ (S_N * e^{ik·})(φ₀) = (1/2) e^{ikφ₀} π = (π/2) e^{ikφ₀}
```

線形性より、帯域制限複素波 ψ_base = Σ_{|n|≤N} c_n e^{inφ}(c_n∈ℂ)に対し:

```
(S_N * ψ_base)(φ₀) = (π/2) ψ_base(φ₀)            ← 複素、厳密
⇒ |(S_N * ψ_base)(φ₀)|² = (π²/4) |ψ_base(φ₀)|²    = (π²/4)(Re² + Im²)
```

### 帰結
ψ_base が複素なら conv も複素となり、|conv|² は実部²+虚部²の**真のクロス構造**を含む。2乗は **|Z|²=ZZ̄ ≠ Z²** の真のモジュラスとなり、Part 3(実・偶のみ、ZZ̄=Z²)で欠けていたボルン則の本質(複素干渉・Re/Im クロス項)をテストする。よって射程を「偶・実」に狭める必要はない。

### スコープの正直な記述(本文用)
- ψ_base は半波長区間 [−π/2, π/2](一基本領域)上の L² 関数。境界条件は奇数調波(両端で適切に振る舞う)。これは出発点論文の設定と整合する明示的スコープ。
- 帯域制限(|n|≤N)なら厳密、一般 ψ_base は N→∞ で再生(打ち切り収束)。
- 「任意の ψ_base」という曖昧表現は使わず、「半波長区間上の(複素)L² ベース波、奇数調波展開」と明記する。

## Q3:観測=畳み込みの根拠

局在参照波との重なりを読む操作(マッチトフィルタ/ヘテロダイン検波)として動機づける。原子時計のラムゼー計量が「周波数=参照発振器との相対位相(ビート)の読み出し」である事実を、観測=位相差・参照照合の operational な接地として引く(標準計量学の事実)。

ただし**正直に**:測定をこの局在核で表すこと自体は**モデル選択(仮定)**である。POVM/測定基底を局在波族にとる、という前提を明示し、導出と偽らない。これは Q2 の「2乗則は公準」と並ぶ、本稿が置く前提の一つ。

## Q4:sin 成分相殺/再生の機構を明示

- **偶・実 ψ_base**(Part 3):sin 調波は ψ_base(偶)に対し奇×偶=奇となり対称区間で積分ゼロ。cos 調波のみが再生に寄与。これが「相殺」の正体。
- **一般・複素 ψ_base**:sin 調波は**消えず、奇部/虚部を再生**する。上のモードごと再生 (S_N * e^{ikφ})(φ₀)=(π/2)e^{ikφ₀} が、cos/sin 両成分の役割を透明に示す。
- 本文では両者を明示し、「相殺は偶・実の特殊事情、一般には sin が虚部を担う」と書く。Part 3 の実・偶結果を「ZZ̄=Z² の退化ケース」、複素拡張を「一般ケース」と位置づける。

## Q5:Gleason・Zurek を引くか → 引く

- Gleason の定理:測定の非文脈性から確率測度が密度行列のトレース則(=2乗則)に限られる。
- Zurek の envariance:環境誘起不変性からボルン則(2乗)を導出。
- **位置づけ**:これらは2乗則を深い仮定(非文脈性/envariance)から**導出**する試み。本稿はそれをせず、**2乗則を公準として残し、その下で形が |ψ_base|² に一致することのみを示す**。引用により「本稿が何を試みていないか(2乗則の導出)」を明確化し、過剰主張を防ぐ。de Broglie–Bohm/Valentini(初期分布 |ψ|² を仮定)とも対比。

## Q6:規格化

- 再生は conv=(π/2)ψ_base、ゆえに |conv|²=(π/2)²|ψ_base|²。
- 確率密度にするには区間で規格化:P(φ₀) = |conv(φ₀)|² / ∫|conv|² dφ₀ = |ψ_base(φ₀)|² / ∫|ψ_base|² dφ₀。
- (π/2)² 定数は規格化で相殺。本文で規格化規約を明示し、|ψ_base|² が(規格化後)確率密度に一致、と書く。
