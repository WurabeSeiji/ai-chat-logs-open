## 1. 何を主張する論文か(主張の射程 ― 厳守)

**主張する**:
> 半波長区間の一定振幅奇数倍音和(孤立ピーク波)を観測の局在核とみなし、「観測は位相差にのみアクセスする(ゆえに二乗)」という一前提を置くと、任意のベース波 ψ_base に対し、観測分布が **|ψ_base|²(ボルン則の二乗形)に厳密に一致**する。これにより、ボルン則の二乗構造は自由な公準ではなく「位相差観測」という一点に還元され、分布の形は再生核性から完全に導出される。

**主張しない(過剰主張の回避 ― 絶対厳守)**:
- 「ボルン則を導出した/測定問題を解いた」とは**書かない**。
- ランダム性の起源(なぜ単発が一点に出て試行ごとに散るか)は**未解決**と明記する。本論文はそこに触れない。
- 「強度=確率」の確率解釈、および「観測=位相差(自己照合)」は**前提(公理)**として明示し、導出したと偽らない。
- 三層宇宙論(R0/R1/R2)、ミニブラックホール、中心射影、νλ=k、ヌル条件などの木原の他の枠組みは**一切持ち込まない**。本論文は単一のフラクタル(孤立ピーク波)のみで完結させる。

**正確な一文(要旨に使う)**:
> 「ばらつくこと」を公理として残せば、標準理論がボルン則 |ψ|² を一括で仮定するのに対し、本稿は二乗の形を局在核の再生核性から導き、残す公理を「ランダム性の存在」一点に減らす。

## 2. 数学的核(論文の本体。すべて検証済み)

### 2.1 出発点(論文の対象)
半波長区間 φ ∈ [−π/2, π/2] 上の一定振幅奇数倍音和:

```
S_N(φ) = Σ_{m=0}^{(N−1)/2} cos((2m+1)φ) = sin((N+1)φ) / (2 sin φ)
```

中央主ピーク S_N(0) = (N+1)/2、局在幅 ~ 1/(N+1)。

### 2.2 基底の直交性(鍵)
区間 [−π/2, π/2] 上で {cos((2m+1)φ)} は直交基底:

```
∫_{−π/2}^{π/2} cos((2m+1)φ) cos((2m'+1)φ) dφ = (π/2) δ_{mm'}
```

ゆえに S_N は、この基底を**係数1で切り詰めた再生核(truncated reproducing kernel)**。等振幅であることが再生核となる条件。← 論文の「振幅すべて1」がここで必然になる、を明確に書く。

### 2.3 核の恒等式(sympy で厳密に確認済み)
```
∫_{−π/2}^{π/2} cos((2m+1)(φ₀−φ)) cos(φ) dφ = (π/2) cos(φ₀) δ_{m,0}
```
m≥1 はすべてゼロ、m=0 だけが生き残る。

### 2.4 主結果(全 N で厳密、数値偏差 ~10⁻¹⁶)
```
(S_N * cos)(φ₀) = (π/2) cos(φ₀)
⇒ |(S_N * cos)(φ₀)|² = (π²/4) cos²(φ₀)
```
ベース波 cos φ(最低奇数倍音)を局在核で位相差畳み込みし二乗すると、規格化後ちょうど cos²(φ₀)=ベース波の二乗=ボルン分布。

### 2.5 一般のベース波
ψ_base = Σ c_m cos((2m+1)φ) に対し、N がその最高次数を覆えば:
```
|(S_N * ψ_base)(φ₀)|² = (π²/4) |ψ_base(φ₀)|²
```
(数値確認:ψ_base = cos φ + 0.5 cos3φ − 0.3 cos5φ で N≥5 のとき偏差 ~10⁻¹⁵。N<5 は第5モード取りこぼし。)

### 2.6 否定対照(論文に必ず入れる)
「速い振動 sin²((N+1)φ) を平均(→1/2)して包絡を観測分布とする」読みは、重み ∝ 1/((N+1)sinφ)² となり、φ=0 で発散し**規格化すらできない**(確率分布になりえない)。cos² とは別物。これにより「位相差畳み込み＋二乗」が唯一正しい操作化であることが確定する。

### 2.7 二条件と数式の対応(考察で明示)
- 「位相差しか観測できない」=核が差 φ₀−φ にのみ依存(畳み込み)＋ 共役 Z\bar Z(二乗)。← 二乗の起源。
- 「観測できない位相差は無視」=有限 N 打ち切り(帯域より細かい差を捨てる)。N が帯域を覆えば厳密。

## 3. 論文の構成(この順で書く)

1. **要旨** ― §1 の正確な一文を中心に。物理的実在の主張をしないことを明記。
2. **はじめに** ― ボルン則 |ψ|² が標準理論では公準であること。本稿は二乗の「形」を局在核から導き、残す公理をランダム性一点に減らす、という射程を述べる。先行研究(de Broglie–Bohm/Valentini の量子平衡)に簡潔に触れ、それらが初期分布 |ψ|² を仮定する点との対比で、本稿は形を導く点が異なると述べる(ただし本稿もランダム性は公理、と正直に)。
3. **設定** ― §2.1–2.2(孤立ピーク波と基底の直交性)。出発点論文を引用。
4. **観測モデル** ― 二条件(位相差のみ→畳み込み＋二乗、不可観測は無視→打ち切り)を定義。原子時計のラムゼー/ヘテロダイン計量が「周波数=参照との相対位相(ビート)」であることを、観測=位相差の operational な接地として簡潔に引く(標準計量学の事実として)。
5. **主結果** ― §2.3–2.5。核の恒等式 → 主結果 → 一般ベース波。証明は初等的(直交性のみ)。
6. **否定対照** ― §2.6。包絡読みの失敗。
7. **数値検証** ― 機械精度一致の表(N=1,9,31,99 で偏差 ~10⁻¹⁶)。`born_from_localization.py` で再現可能と明記。
8. **考察** ― §2.7(二条件と数式の対応)。等振幅が再生核の必然条件であること。**何が導かれ何が前提か**の切り分け(§1 の「主張しない」を正直に展開):形は導出、二乗の確率解釈と位相差観測は公理、ランダム性の起源は未解決。
9. **結論** ― 控えめに。「ボルン則の二乗構造を、ランダム性の公理一点を残して、局在核の再生核性から導出した」。標準理論より公理が一つ軽い、と述べる。
10. **付録** ― 検証コードの説明、図の再現方法、核の恒等式の sympy 出力。
