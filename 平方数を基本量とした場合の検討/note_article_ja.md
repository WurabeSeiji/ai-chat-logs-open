# 平方数で読むと、曲がった平方和が直線になる ── 曲率歪みと平方量読出しの整理

## 本記事の目的

新しい観察・整理論文を公開しました。

今回の論文は、物理法則を証明する論文ではありません。標準物理を置き換える論文でもありません。

出発点はとても初等的です。

ある正の量 x をそのまま読むのではなく、平方量 X = x² を基本量として読む。

すると、曲がった制約に見えていた平方和

　　Σ xᵢ² = E

が、平方量側では

　　Σ Xᵢ = E

という直線的な単体制約になります。

この読み替え自体は、確率単体と球面の平方根表示などに近い、既知構造を持つものです。したがって、そこを新発見とは言いません。

今回のポイントは、その平方量読出しを、先に公開した論文0の曲率歪みの結果と並べたとき、

- どの式では曲率補正を入れないのか
- どの式から曲率補正候補を検討すべきなのか

が、かなり単純な幾何学の言葉で分けられる、という点です。

論文本体はこちらです。

## まず、論文0で何を証明していたか

今回の話は、自己参照している論文0を土台にしています。

論文0は、正曲率の定曲率空間に、一辺 1 の測地的な単位セルを置いたとき、一辺・角・面積・体積がどう歪むかを厳密に計算したものです。

重要な結論は、次の四つです。

- 一辺の測地長は、構成により厳密に 1 のまま。
- 角度は曲率半径 R に依存して 90° からずれる。
- 面積は曲率半径 R に依存して歪む。
- 体積の歪みは次元 d に依存し、その最初の係数は d(d−1)/12。

つまり、曲率歪みは、長さそのものには最初から出ません。

最初に出るのは、二方向が張る面積です。

この点が、今回の平方量読出しとつながります。

【論文0 図B：測地帯の展開】

画像ファイル：波長空間と周波数空間の双対幾何/paper0_figB_band_unfold.png

論文0の計算では、辺は測地線長として保たれます。一方で、面を張ると曲率の影響が出ます。

角度については、曲率半径 R に対して次の形が得られます。

　　θ(R) = arccos(−tan²(1/(2R)))

この角度を使うと、一辺 1 の測地正方形の面積は

　　A(R) = R² { 4θ(R) − 2π }

となります。

平坦な単位正方形の面積は 1 なので、面積補正係数を

　　k_s(R) = R² [ 4 arccos(−tan²(1/(2R))) − 2π ]

と定義できます。

平坦極限では

　　k_s(R) → 1

であり、展開の先頭は

　　k_s(R) = 1 + 1/(6R²) + O(R⁻⁴)

です。

【論文0 図C：角度超過】

画像ファイル：波長空間と周波数空間の双対幾何/paper0_figC_angle_excess.png

さらに、d 次元体積については、小曲率極限で

　　V_d(R) = 1 + c_d/R² + O(R⁻⁴)

　　c_d = d(d−1)/12 = C(d,2)/6

となります。

この形が非常に重要です。

d(d−1)/12 は、独立な二方向の組の数 C(d,2) に比例しています。つまり、d 次元の体積歪みは、各二次元面の面積歪みの足し合わせとして読めます。

ここから、今回の論文で使う判定規則が出ます。

**曲率補正の最初の入口は長さではなく面積である。**

## 平方量読出しとは何か

今回の論文では、正の領域で

　　Xᵢ = xᵢ²

と置きます。

すると、たとえば二次元の正の円弧

　　x² + y² = 1

は、平方量側では

　　X + Y = 1

という線分になります。

【図1：2次元の平方写像】

画像ファイル：figures/fig01_2d_square_map.png

三次元では、正の球面八分体

　　x² + y² + z² = 1

が、平方量側では

　　X + Y + Z = 1

という三角形単体になります。

【図2：3次元の平方写像】

画像ファイル：figures/fig02_3d_square_map.png

ここで大事なのは、これは等長な平坦化ではない、ということです。

平方写像は距離を保存しません。

微分すると

　　dXᵢ = 2xᵢ dxᵢ

ですから、長さの測り方は変わります。

したがって、球面の内在計量がそのまま平面計量になるわけではありません。

本稿で使っているのは、もっと限定された事実です。

平方和制約が、平方量側で一次式になる。

この一点だけです。

---

## 平方量側に簡単な式を置く

平方量側で

　　X = A T

を置きます。

ここで

　　X = x²

　　T = t²

と読み戻すと、

　　x² = A t²

なので、正の平方根を取って

　　x = √A t

になります。

これは、見た目としては等速運動

　　x = vt

と同じ形です。

次に、平方量側で

　　X = 1/2 B T²

を置くと、

　　x² = 1/2 B t⁴

なので、

　　x = √(B/2) t²

になります。

これは、見た目としては等加速度運動

　　x = 1/2 a t²

と同じ形です。

【図3：平方量側の式と運動形の読出し】

画像ファイル：figures/fig03_motion_readouts.png

ただし、ここでも注意が必要です。

これは速度や加速度を物理的に導出した、という意味ではありません。

平方量側に置いた単純な式を、正の平方根側で読むと、古典力学で見慣れた形と同型になる。

それだけを述べています。

## なぜ一次元の式では曲率補正が出ないのか

ここで論文0の結果が効きます。

論文0では、曲率歪みの最初の入口は面積でした。

長さだけで閉じる関係には、二方向が張る面積セルがありません。

したがって、平方根側で

　　x = √A t

や

　　x = √(B/2) t²

が出ても、そこにいきなり k_s(R) を掛ける理由はありません。

この判断は、加速度があるかどうかで決まるのではありません。

式が一次元量だけで閉じているか、それとも二方向が張る面積量を含むかで決まります。

この点は、二体衝突の式を見ると分かりやすくなります。

一次元完全弾性衝突では、質量 m₁, m₂ と速度 u₁, u₂ を外から置くと、運動量保存とエネルギー保存から通常の衝突式が出ます。

エネルギー式には u² が出てきます。

しかし、この u² は、同じ一次元速度成分の二乗です。独立な二方向が張る面積ではありません。

したがって、ここにも k_s(R) を入れる場所はありません。

この整理はかなり重要です。

補正の入口は、質量でも、加速度でも、二体問題でもありません。

補正の入口は、面積量の出現です。

---

## 遠心型モデルだけが最初の自然な入口になる

では、どこで面積が出るのか。

最小の自然な例として、遠心型の式を考えます。

古典的には

　　a_c = v²/r

と書かれます。

ここでは、接線方向の速さ v と、半径方向の長さ r が同時に現れます。

円運動を幾何的に見れば、接線方向と半径方向という二つの独立な方向があります。

ここで初めて、一次元の長さだけではなく、二次元面積セルを検討する入口が出ます。

そこで、論文0の測地正方形の面積係数

　　k_s(R) = R² [ 4 arccos(−tan²(1/(2R))) − 2π ]

を、最小の試験モデルとして遠心型の式に置いてみると、

　　a_c^(R) = k_s(R) v²/r

と書けます。

【図5：面積補正係数 k_s(R)】

画像ファイル：figures/fig05_area_coefficient_ks.png

ここで k_s(R) は、自由に調整する係数ではありません。

R が決まれば、論文0の幾何式から一意に決まります。

しかし、ここも慎重に分けます。

k_s(R) が一意に決まることと、それを遠心型の式にこの向きで掛けるべきことは別問題です。

測度として読むのか、密度として読むのか、面積として読むのか、逆面積として読むのかで、k_s(R)、1/k_s(R)、あるいは別の関数が現れる可能性もあります。

したがって、本稿の主張はここまでです。

遠心力を証明したのではありません。

遠心型の式は二方向を含むので、一次元式とは違って、面積補正を検討する自然な入口を持つ。

そういう観察です。

---

## 今回の論文で一番大事な線引き

今回の論文は、誤読されると、すぐに次のように読まれてしまいます。

平方写像で曲率が消えた。

平方写像の非等長性から k_s(R) が出た。

平方量読出しから古典力学を導いた。

しかし、これはすべて本稿の主張ではありません。

本稿が言っているのは、もっと控えめで、もっと幾何的なことです。

- 平方和制約は、平方量側で線形単体制約として読める。
- その読出しの下で、一次式・二次式は、等速運動形・等加速度運動形と同型に見える。
- しかし、一次元量だけで閉じる式には、論文0の面積補正を入れる場所はない。
- 二方向が現れ、面積セルが関与するところで、初めて k_s(R) を候補として検討できる。

ここに今回の整理原理があります。

平方写像そのものは既知構造に近い。

論文0の曲率歪みの式も、幾何学として別に確定している。

今回の論文の面白さは、その二つを混ぜて一方から一方を導くことではありません。

むしろ、混同しないことです。

長さだけの式と、面積を含む式を分ける。

この分離が、曲率補正候補をどこで考えるべきかを決める、という整理です。

---

## 何を主張しないか

最後に、本稿が主張しないことを明確にしておきます。

- 物理法則を証明したとは主張しません。
- 古典力学、相対論、量子論を置き換えるとは主張しません。
- Xᵢ を確率、エネルギー、質量、時間などの特定の物理量と同一視しません。
- 平方写像が等長写像であるとは主張しません。
- 曲率空間そのものが平坦空間へ消えるとは主張しません。
- k_s(R) の遠心型モデルへの掛け方が、力学法則として一意に導かれたとは主張しません。
- 平方写像の非等長性が k_s(R) の原因であるとは主張しません。
- 平方写像の計量歪みと、論文0の測地正方形面積超過を同一視しません。

この論文は、発見を大きく見せるための論文ではなく、誤読が入りやすい場所に線を引くための論文です。

それでも、私はこの整理には意味があると思っています。

なぜなら、平方量読出しで式が思った以上に単純化する一方で、曲率補正はどこにでも入るわけではないからです。

補正が入らない場所を明確にすることは、補正が入りうる場所を見つけることと同じくらい大事です。
