# 論文化および機械計算実験・図化評価のための指示書

**作成日**: 2026年7月1日  
**目的**: 古典波動モデル（源位置揺らぎ＋局在波パケット二重スリット干渉）において、加速電圧から定まる運動量 p と干渉整列条件から定まる波長 λ の間に de Broglie 的関係（pλ ≈ 定数）がモデル内部から現れることを、数値的に示すための論文を作成する。

**本研究の位置づけ（重要・必ず明記）**
- 新しい実験手法の提案ではない。
- 実在実験の再現・検証を主目的としない。
- 「この古典波動モデルの中で、幾何的整列条件と線形写像により、運動量と波長の間にプランク定数と解釈可能な定数関係が構造的に現れる」ことを示す**概念的・数値的思考実験**である。

---

## 1. モデルの定義（正確に実装すること）

### 基本パラメータ（代表値から開始）
- 源-スリット距離 L = 5 cm（または 0.05 m）
- スリット間隔 W = 5 μm（または 5×10^{-6} m）
- 源位置揺らぎ分布: P(y) = cos²(π y / Δ)（Δ は波長程度またはコヒーレンス長程度の代表値を使用）
- 加速電圧 V の範囲: 50 V 〜 500 V 程度（電子波長 0.05〜0.17 nm 程度に対応）

### 使用する波動モデル
- N=1（単一波長）の場合と、奇数倍音和 S_N を用いた局在波パケットの場合の両方を実装。
- 干渉強度 I(s; y) の厳密計算:
  - 各高調波 n に対する位相 Φ_k^{(n)}(s; y)
  - 総複素振幅 ψ = Σ_n (e^{iΦ_1^n} + e^{iΦ_2^n})
  - I = |ψ|²

### 整列条件の扱い
- N=1 の場合は整列条件不要（常に干渉）。
- N > 1 の場合は、r_k = √(L² + (W/2)²) が m λ₀ / 2 に近い場合に shape preservation が良好になる。

---

## 2. 計算戦略（段階的実施を強く推奨）

### Phase 1: N=1（ベースライン確認）
- まず N=1 で全計算を実施。
- 各加速電圧 V に対して:
  - 古典運動量 p を計算。
  - 源位置 y を P(y) からランダムサンプリング。
  - 各 y に対する干渉パターンの中央ピーク位置を記録。
  - ヒストグラムを作成し、分布形が保存されていることを確認。
- p（横軸）と 1/λ（縦軸）のプロットを作成し、線形関係が現れるかを確認。
- この段階で「それらしい λ と h に近い値が出る」ことを確認する。

### Phase 2: N を段階的に増加
- N = 3, 5, 9, 17, 31 など奇数で増加。
- 各 N について:
  - 「中央コヒーレンスが高く、off-axis での散乱損失が小さい」良好な V の範囲を調べる。
  - その範囲が N の増加とともに狭くなる様子を定量的に示す（1/(2N) との比較も）。
- 計算コストを抑えるため、最初は全範囲均等サンプリングではなく、**前段階で良好だった V の周辺を重点サンプリング**することを推奨。

### Phase 3: 最終評価プロット
- 横軸: 加速電圧 V から計算した運動量 p
- 縦軸: 良好な shape preservation が得られる条件での 1/λ
- N ごとに異なる色やマーカーでプロットし、線形性（1/λ ∝ p）の頑健性を比較。
- N が大きいほど良好な領域が狭くなる（脆くなる）ことを可視化。

## 3. 生成すべき図（最低限）

1. **波形図（代表値）**
   - N=1 と N=17（または適切な N）で、y=0 中心における I(s) の比較。
   - 整列が良好な場合と不良な場合の比較。

2. **確率分布図（ヒストグラム）**
   - N=1 と高 N で、源位置をランダムサンプリングしたときの検出位置分布。
   - 分布形の保存と、N 増加による変化を示す。

3. **最終重要図: p vs 1/λ**
   - 横軸: p（運動量）
   - 縦軸: 1/λ
   - N=1 と複数の高 N を重ねてプロット。
   - 線形回帰線を入れ、傾きが 1/h に近いことを確認（または定数関係の存在を示す）。

4. **許容範囲の変化図（任意だが推奨）**
   - N に対する「良好な V の範囲の幅」のプロット。
   - 理論曲線 1/(2N) との比較。

## 4. 論文化時の注意点

### 主張の範囲を厳密に守る
- 「このモデル内では…関係が現れる」と書く。
- 「実験的に pλ = h を検証した」「新しい測定法を提案する」などの表現は避ける。
- 実在実験の難しさ（振動・熱・真空安定性）は、モデルの「脆さ」との構造的対応として軽く触れる程度に留める。

### 計算の限界の明記
- N を大きくすると計算コストが増大すること。
- m（干渉次数）を現実的にどの程度まで取れるか。
- 代表値を使用しているため、定量的な精度は限定的であること。

### 構造の推奨
1. 導入：モデル概要と本研究の位置づけ
2. モデル定義と計算方法
3. N=1 の結果（ベースライン）
4. N を上げた場合の変化（許容範囲の狭まりと脆さ）
5. p vs 1/λ プロットと線形関係の議論
6. 結論と今後の展望（実在システムとのアナロジーなど）
