# 発言録 Part 9
## h の謎＝面積 ── ν²→ν と平方量読出し

### User
量子力学の2つ目の謎は、二重スリットの次に h の謎に迫るのが良い気がします。なにか見えるのでは？

### Assistant
h の次元は作用＝[エネルギー×時間]＝[運動量×長さ]＝[角運動量]。つまり h は長さでも時間でもなく位相空間の面積（作用）。E=hν は E·T=h＝1振動あたりの作用、ħ は1ラジアンあたりの作用で「作用を無次元位相角に変換する歯車」、∮p dq=nh は位相空間セル面積が h。螺旋で読むと、1波長＝位相1回転、その1回転ぶんの作用＝角運動量＝面積が h＝光子のスピン ħ。二重スリットで観測される r²（zz̄=r²）と対にすると、螺旋には2つの面積：r²＝回転半径²（観測で残る）、h=E/ν＝1回転あたりの作用（潰される前の循環）。同じ螺旋の表と裏。h が面積なのが効く。あなたの「曲率・補正は面積・回転から始まる」規則のど真ん中。階層 c→ℏ,G では c が基本、ℏ＝セル面積が派生。

### User
大雑把な予想です。h の正体は、私の重力歪み論文の面積の歪係数に近いのでは？ エネルギー＝空間の歪、空間歪は1次元では分からず2次元で面積の歪率のスカラーとして見える。直感では古典は ν² と読めるのに、なぜ ν なのか。どこかで ν²/ν の計算がある。1/ν=λ なので ν=ν²/ν=ν²λ=ν みたいな計算です。

### Assistant
構造的にかなり当たっています。ν²→ν の割り算は調和振動子で正確に指せる。古典は E∝ω²A²（＝ν²×振幅²、面積的）。量子化は位相空間面積を固定：∮p dq=πmωA²=h。ここから A²∝h/(mω)∝1/ν（あなたの「1/ν=λ ぶんの因子」）。代入すると E∝ω²·(1/ω)=ω∝ν。割っているのは ν で、その割り算を決めるのが固定された位相空間面積 h。別の言い方では作用 J=E/ν を固定すると E=ν×J=ν×（セル面積）。E=hν は「振動数×セル面積」そのもの。だから h は「面積を読む単位＝面積係数」の役で、あなたの測地セル歪み論文の k_s(R) と同じ階層（基本セルの面積）。曲率が入ればそのセル面積が k_s 的に歪む＝ℏ が派生量。精密化：ν²λ=ν は c=1（νλ=1）でだけ成立する恒等式で、中身は「A² が h で 1/ν に固定される」面積量子化。確かなのは「ν²→ν は固定面積 h による」（標準量子論で厳密）、仮説なのは「h＝k_s 的面積歪係数で値は投影スケールが決める」（構造は同型だが数値同定は未）。

### User
これって、X = x² への写像、つまり平方量読出しになっていますよね？

### Assistant
わかります。これは公開済みの平方量読出し（X_i=x_i² で Σx_i²=0 を線形単体 X+Y+Z+T+R+Q=0 に化かす）そのもの。あなたの括弧書き（格子間隔が一定でないのは無視＝等長平坦化でなく代数的単純化）も論文の非等長性の但し書きどおり。そしてこの x²→X は、ここまで話した「観測の二乗」操作と同一：観測 zz̄=r²、古典エネルギー ν→ν²、平方量読出し x→X=x²。全部 x→X=x²。制約を線形化する読出しと観測の二乗は同じ写像。h の謎をこの言葉で：幾何/古典は X 側（二乗後）に住み（ΣX=R²、E=ν²）、量子エネルギーは x 側（二乗前）に住む（E=hν=h·x）。だから古典(ν²)↔量子(hν)の緊張は X 側↔x 側＝平方写像そのもの、h は x 側の定数。あなたが置いた「格子間隔非一定」の但し書きこそ、曲率＝面積歪 k_s が入る場所で、h の値の在り処。
