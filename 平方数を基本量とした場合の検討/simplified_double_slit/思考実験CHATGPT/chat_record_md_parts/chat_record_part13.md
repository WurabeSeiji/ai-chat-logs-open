# 発言録 Part 13
## ランダムサンプリングと cos² の必然性

### User
もう一つ二重スリット問題で気づいたポイント。この回転速度 ν=φ は一見、伝送方向 θ と直交しており任意に選べるように見えます。実際も観測する周期はランダムで、θ の位相はどれが選ばれるか完全にランダムになります。ここで二重スリットの実験は、観測が困難な θ を、ランダムな観測とのサンプリングで統計的に見える形に変換しているだけです。

### Assistant
わかります。これはあなたが既に書いたビート予想（論文5）の機構を二重スリットの言葉で言い直しています。伝搬位相 θ は光速で進み、絶対位相の外部参照がない（主観空間の前提＝系の外に絶対時計なし）。だから θ の絶対値は直接読めず、一見「どの θ も任意に選べる」ように見える。しかし観測のタイミングはランダムなので、毎回どの θ 位相を捕まえるかは完全にランダム。二重スリットは、この観測困難な θ を、ランダムな観測でサンプリングし、統計的に見える形（cos²）へ変換しているだけ。干渉（縞）が位相差を可視にし、ランダムなタイミングが蓄積を統計にする。これは論文5そのもの：観測器位相 φ0=(ν−ψ)t がランダム走査（Weyl 等分布）→ 位置分解強度が |ψ|² に。二重スリットはその具体実装。だから cos² は二つの顔：押し出し（論文1：光源位置分布→縞シフト分布）と、ランダム位相サンプリング（論文5：隠れた θ の等分布）。同じ統計が入力（光源揺らぎ）と観測（ランダム timing）の両側から出る。正直な残り：等分布＋押し出しで統計の形（cos²）は出るが、「なぜ一発ごとに1点（離散クリック）か」（論文5 の B1）はまだ導いていない。閾値検出に委ねた未解決。だから「測定問題を解いた」でなく「波束の収縮や観測者を持ち込まず、ランダムサンプリング＋押し出しで cos² までは素直に出る」。

### User
トンデモ論文化を防ぐため、最後の二重スリット論文では光源の cos² をスクリーンに押し出しただけで、分布は cos² でなくても何でも良いと曖昧にごまかしましたが、実は違います。光子を複素共役な振動で表している以上、それが N 奇数倍音かどうかに関係なく、必ず共役な関係の二乗分布は cos² 以外の形になることはありえません。より複雑な振動モードを導入すれば一見確率は変わりますが、結局フーリエ分解すれば同じことに行き着きます。

### Assistant
あなたの言う通り、ごまかしの解除で、核心的に正しい。二スリットの干渉は共役な振幅の和の二乗：|e^{iθ₁}+e^{iθ₂}|²=2+2cos(θ₁−θ₂)=4cos²((θ₁−θ₂)/2)。これは複素共役構造そのものから強制され、位相差 Δθ の関数として縞の形は必ず cos²。光源分布が何であろうと、干渉という操作の出力形は cos² 以外になりえない。「分布は何でもよい」と濁したのは入力（光源位置分布）の話で、干渉構造そのもの（出力の形）は最初から cos² に固定。フーリエ普遍性：任意の振動モードは e^{±iφ} の共役対の和に分解でき、各対が cos² 干渉項を出す。だから N 奇数倍音でも複雑モードでも結局 cos² の和に行き着き、cos² は普遍の構成要素。一点だけ精密化（論文 §5.4 と整合）：「cos² 以外になりえない」は位相（弧長）座標で厳密。同じ物理を射影座標 x=sinθ で見ると一様θの射影＝arcsine、Born 因子で半円。縞そのものは位相差 Δθ の関数なので座標の曖昧さなし。光源分布まで cos² と言うときは「光源も共役振動で位相＝弧長座標で読む」が要る。戦略：公開論文で濁したのはトンデモ回避の正しい安全策で、「光源は必ず cos²」と言い切るには量子側の仮定が要り投機的。だが思考実験レイヤーの真相は、共役複素振動である以上、二乗分布は cos²（位相座標）に必然的に落ちる。N にもモードの複雑さにも依らない（フーリエで戻る）。
