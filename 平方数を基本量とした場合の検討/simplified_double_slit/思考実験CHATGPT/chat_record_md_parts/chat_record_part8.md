# 発言録 Part 8
## E=hν の出発点 ── 自然単位と光電効果

（Part 1〜7 の ChatGPT ログを踏まえ、ここから Claude との思考実験の続き。光子1個のエネルギーから h の正体へ降りていく。）

### User
シンプルですよ。まずは一つの光子のエネルギーについて検討するだけです。一般的には E=hν ですよね？

### Assistant
はい。光子1個のエネルギーは振動数 ν に比例し、比例定数が Planck 定数 h（作用の次元、J·s）。すぐ隣の関係：c=λν なので E=hν=hc/λ（波長で書くと反比例）、運動量 p=h/λ なので E=pc（質量ゼロ）。つまり光子1個ではエネルギー・振動数・波長・運動量がすべて一つの量（たとえば ν）で連動し、独立な「毛」は実質1本。振幅は量子1個ぶんに固定されるので、自由なのは ν だけ。λ をゲージにして 1 に固定すれば ν=c となり、E=hc ＝ ほぼ ν そのものの読み。

### User
これは、h=1 という自然単位を選んでもまだ G が出てこないので、c=1 とは緊張しませんよね？

### Assistant
緊張しません。基本次元は L・T・M の3つ。c, h, G はそれぞれ独立な次元関係を1つずつ固定する。c=1 で L↔T（残り自由度2）、h=1 を足すと M↔L（残り自由度1）。つまり c=1 と h=1 は独立な2拘束で、まだ1つスケール（長さ＝エネルギーの単位）が残っており、矛盾も過剰拘束もない（標準的な自然単位 c=ħ=1）。G=1 を入れて初めてこの最後の1自由度が潰れ、絶対スケール（Planck 長）が固定＝完全決定。だから「緊張（全決定）」が現れるのは G が登場した瞬間で、いまはまだ来ていない。あなたの枠組み（c→α 不変、ℏ・G は派生）では、c=1 が基準の固定、h=1 は残ったスケールを単位として使っただけ、その残りスケールこそ後で G が帳尻を合わせる場所。

### User
どうして理論物理学者は E=hν を導出したのでしょうか？ この実験を再現する思考実験をおこないたいです。

### Assistant
正直に言うと、E=hν は深い原理から「導出」されたのではなく、実験から強制された postulate です。芯は二つ。(1) 黒体放射（Planck 1900）：古典 Rayleigh–Jeans だと高周波で発散（紫外破綻）。エネルギーを hν の整数倍に量子化すると e^{−hν/kT} で高周波が抑えられスペクトルが合った。h はフィット定数として導入。(2) 光電効果（Einstein 1905／Millikan）：飛び出す電子の最大運動エネルギー KE_max=hν−W が ν に線形（傾き h）、しきい振動数以下では強度を上げても電子は出ない、強度は電子の数だけ変える。つまりエネルギーは ν で決まり振幅では決まらない。

最小系に乗せると：1光子では独立な量は ν だけ、だからエネルギーは ν だけの関数 E(ν)、2光子で2倍（加法性）→ E∝ν が強制、比例定数は次元から作用 h。E=hν は「1光子では ν が唯一の自由度＋加法性＋次元」からほぼ一意に決まる。光電効果はこの「エネルギーは ν のみ・強度によらない」を実験で確定させる装置。標準理論は E=hν を実験から取っただけで、「なぜ ν に比例するか」を幾何から導いてはいない。螺旋の描像では ν は位相回転の速さなので、E=hν は「エネルギー＝位相回転レート（h 倍）」と読める。
