今回の note と前回の二重スリット二論文をつなぐと、意図はかなり明確に見えます。

理解では、言いたい核心は、標準理論やゲージ理論の局所的な硬さを否定するのではなく、むしろそれを前提にして、曲率歪みが“どこから初めて観測式に入るのか”を、長さ・面積・回転・位相読出しの階層で切り分けたい、ということです。

今回 note は、平方写像そのものを新発見として主張する記事ではありません。独自性は、曲率補正をどこに入れてよく、どこに入れてはいけないかの線引きにあります。

これは「強い重力歪みがある場合でも、面積や回転の効果がある場合を除く一次元の現象の記述はそのまま正しく、角度の関係する場合にも局所的、ベース波長の 1/2 以下ではスケールが曲率で変わるだけで厳密に成立する」という発言と対応しています。

つまり今回 note は「曲率があるから何でも補正される」のではなく、「長さだけで閉じる現象は補正しない。二方向・角度・面積・回転が出たところから補正候補が始まる」という規則を、慎重に書いたものです。

前回の二重スリット二論文は、今回 note の物理的・波動的な具体例になっています。第一の二重スリット論文は、点光源の位置揺らぎ y があるとき、各試行の干渉縞は形を保ったまま幾何学的経路差でシフトし、そのシフト量分布が入力位置分布の pushforward になる、という内容でした。

第二の局在奇数倍音論文では、局在波を奇数倍音和で作り、それを二重スリットに通した場合、整列条件を満たせば形は保存されるが、光源—スリット距離が基本波長の整数または半整数倍に揃う必要があり、最高奇数倍音次数 N が大きいほど許容帯が狭くなる、と述べています。

したがって、二重スリット二論文は「波動・位相の具体例」、今回 note は「曲率・平方量・面積補正の一般整理」です。

木原さんの意図は、標準理論・ゲージ理論は非常に強い局所理論であり、それを否定したいわけではない。むしろ、なぜそんなに強く、強い重力歪みの中でも局所的には壊れにくいのかを、初等幾何と読出し変数の側から理解したい、というものに見えます。

ただし論文では「強重力でも厳密に成立する」と前面に出すより、「本稿のモデル範囲では、一次元量だけで閉じる関係には曲率面積補正を入れる根拠が現れない」と書く方が安全です。
