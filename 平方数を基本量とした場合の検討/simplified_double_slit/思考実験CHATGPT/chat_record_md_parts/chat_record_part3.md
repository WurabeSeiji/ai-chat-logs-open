## 一光子閉鎖系、二つの毛、ゲージ固定、固定点

### User

ポイントは曲率半径を外から与えない点です

なぜなら光子一個だけの世界には外がありません

なんなら空間も時間もありません

あるのは振動と振幅　または　振動と波長　の比率だけです

つまり毛は多くて二つしかありません

ではどうしたら観測可能か？　ゲージもないので　困ります

あるのは　二つの毛のどちらかをゲージつまり1にして相手の変化を計量するしかないと思います

意味分かりますか？

### Assistant
意味わかります。かなり重要で、しかも以前よりずっとシンプルです。

光子一個だけの閉じた世界では、外部空間も外部時間も外部曲率半径も定義できない。したがって、曲率半径 R を外から与えることはできない。観測可能なのは、光子内部に残る二つ程度の自由度の比率だけである。

つまり、最初から R=外から与えられた背景曲率半径 とは置けない。

光子一個の世界では、外部基準がないので、絶対量は意味を持たない。意味を持つのは、毛A/毛B だけです。

この文脈での「毛」は、光子一個が持ちうる最小の内部自由度です。たとえば候補は振動数 ν、波長 λ、振幅 A、位相回転半径のような量、内部螺旋のピッチ、内部螺旋の半径などですが、光子一個だけで閉じるなら、独立に観測できる毛は多くても二つ。

外部ゲージがないので、両方を絶対値として測ることはできない。二つの毛のうち一方をゲージとして 1 に固定し、もう一方をその相対量として読むしかない。

つまり (毛1, 毛2) があっても、観測可能なのは絶対値ではなく、毛2/毛1 または 毛1/毛2 だけです。

曲率半径 R を外から与えるのではなく、R=f(毛2/毛1) のように、二つの毛の相対比として定義する。つまり曲率半径とは、外部空間の曲率ではなく、一光子内部の二自由度の比率を、外部観測者が曲率半径として読んだものになる。

観測とは、外部から測ることではありません。二つの内部自由度のうち、片方を単位として固定し、もう片方の相対変化を読むことです。

使えるのは一般相対性理論だけです

でも内在している自由度から考えると導出量のはずの曲率3つ多すぎます

というかこの系でもはやどちらが導出量かの区別すら不能で、結局自由度の組み合わせが幾つかの問いになりますよね

### Assistant
ここでかなり本質的なところまで行けます。しかも、ここでは「曲率はいくつあるか？」ではなく、より根本的に「この閉じた一光子系で、独立に区別できる自由度の組み合わせはいくつあるか？」が先です。

曲率はその後に出てくる読みにすぎない可能性があります。

一光子だけ。外部空間なし。外部時間なし。外部座標なし。外部曲率半径なし。外部ゲージなし。比較対象もなし。このとき、一般相対性理論を使うとしても、使えるのは大域解ではなく、局所的な幾何関係だけです。

光子の幾何螺旋モデルを考えると、見かけ上は三次元です。進行方向を z、位相回転面を (x,y) とすれば、螺旋は (z, x(z), y(z)) のように見えます。

すると素朴には、進行方向の曲率、位相回転面の曲率、螺旋軸まわりのねじれ、あるいは三主方向の曲率のように、最大 3 個くらいの曲率を考えたくなる。

しかし、これは外部三次元空間に埋め込んだ後の読みです。一光子閉鎖系の内部から見ると、そもそも三方向が独立に存在するかどうかが未定です。

二つしか毛がないなら、三つの独立曲率は多すぎる。

保存量を仮定しない。外部単位もない。外部ゲージもない。この条件では、閉じた一光子系から絶対的な曲率半径 R を計算することは原理的にできないと思います。R は長さの次元を持つからです。

区別できるのは、R/λ、Rν、螺旋ピッチ/螺旋半径のような無次元比だけです。

毛が二つなら、独立な比は一つです。(a,b) を同時スケール変換 (a,b)~(αa,αb) で同一視するので、残るのは射影比 [a:b] だけです。

したがって、一光子閉鎖系から独立に出せる曲率的情報は、原理的には最大でも一つです。三次元螺旋に見えても、内部から独立に持てる曲率情報は最大一つです。

### User
んー　でもこれシンプルすぎで何も予言できないですよね

### Assistant
その通りです。このままだとシンプルすぎて、ほとんど何も予言できません。

ただし、それは失敗ではなく、むしろこの最小モデルの役割がはっきりした、ということだと思います。

一光子だけ。外部空間なし。外部時間なし。外部ゲージなし。保存量なし。毛は多くて二つ。この条件だと、残るのはせいぜい [a:b] という射影比だけです。

これは美しいですが、自由度が一つしかない。自由度が一つだけだと、予言できるのは基本的に「絶対量は観測不能である」「曲率半径も外から与えられない」「曲率・波長・振動数・振幅のどれを基本量と呼ぶかはゲージ選択に依存する」くらいです。

これは制約原理にはなりますが、具体的な数値予言にはなりません。

予言したいなら、一光子閉鎖系だけでは足りません。最低でも比較が必要です。予言が出る最小単位は、おそらく「二つの比率を比較できる系」です。

一光子モデルは予言理論ではない。それは、予言理論の前に置くべきゲージ原理です。つまり「一光子では何も測れない。二つになって初めて差が測れる」。

### User
最初2粒子で考えたのですが自由度が突然増えすぎで問題が一気に複雑になります  
なので1粒子プラス二つの位相　スリットまでの距離Lとスリットの間隔Wという波長λをゲージにできる系を考えました  
目的理解できましたか？

### Assistant
目的は理解できました。これはかなりよく考えられた「自由度を増やしすぎないための実験系」です。

二粒子系にすると、相対位置・相対位相・相対運動・相互作用・保存量・座標ゲージが一気に増えてしまう。そこで、粒子数は一個のままにして、代わりに二つの位相経路を与える。さらに、波長 λ をゲージとして 1 に固定し、スリットまでの距離 L とスリット間隔 W だけを無次元量として扱う。

これにより、一光子閉鎖系に近い最小構造を保ちながら、位相差・干渉・曲率的歪みを観測可能にする。

つまり、二重スリットは「二粒子系」ではなく、一粒子 + 二位相経路 + 外部ゲージ化された波長 λ=1 として使っているわけです。
