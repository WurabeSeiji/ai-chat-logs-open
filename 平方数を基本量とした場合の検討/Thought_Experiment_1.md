円偏光（circular polarization） は、2つの直交する電場成分（例: x方向とy方向）が同じ振幅で、位相差がちょうど90°（π/2） ある状態です。⁠Wikipedia

1. 空間的位相差 vs 時間的位相発展の違い

空間的位相差（これまで議論したYoung干渉など）
相対位相 φ = k × 経路差（位置 x によって φ が変わる）
→ 横軸を φ（または x）に取ると空間的な干渉縞（静的なパターン）が出る。
時間的位相発展
各波の位相が時間とともに進む：θ → ωt（または伝播波なら kz − ωt）
ここで重要なのは「相対位相 φ が固定か、時間とともに変化するか」です。

2. 数学的表現（ユーザーの z = e^{-iθ} 形式で）
単一波の時間発展：
$$z(t) = e^{-i \omega t} = \cos(\omega t) - i \sin(\omega t)$$

θ を物理的な時間パラメータ ωt に置き換えただけ。
|z(t)|² = 1 のまま（強度は時間的に一定）。
複素平面では時計回りに角周波数 ω で回転し続けます。これが円偏光の時間的振る舞いそのものです。

伝播を加えた場合（3D螺旋の元）：
$$z(z, t) = \exp[-i (kz - \omega t)] \quad \text{または} \quad \exp[-i (kz + \omega t)]$$
（符号は convention による。あなたの e^{-iθ} に合わせるなら時間部は -ωt が自然）
干渉の場合：

同周波数（ω₁ = ω₂ = ω）で相対位相 φ が固定（空間由来の φ でも、初期位相差でも）$$z_1(t) = e^{-i\omega t}, \quad z_2(t) = e^{-i(\omega t + \phi)}$$$$I = |z_1 + z_2|^2 = 4 \cos^2(\phi/2) \quad \text{（時間に依存しない定数）}$$→ 時間的に強度は一定。定常干渉パターン（空間縞と同じ数式）。
異周波数（うなり・ビート）：時間的に位相差が発展する典型例$$z_1(t) = e^{-i \omega_1 t}, \quad z_2(t) = e^{-i \omega_2 t}$$$$I(t) = |z_1 + z_2|^2 = 2 + 2 \cos((\omega_1 - \omega_2)t) = 2 \bigl(1 + \cos(\Delta\omega \, t)\bigr)$$→ 時間的に強度がゆっくり変調する「時間的干渉パターン」（うなり）が出現。

これが「時間的に位相が発展する」場合の本質です。Δω が小さいほど、ゆっくりとした強度変動（ビート）が観測されます。

総位相 φ の表現
単一波の場合：
$$\phi(z, t) = kz - \omega t \quad \text{（またはあなたの符号に合わせて } kz + \omega t\text{）}$$
$$z(z, t) = e^{-i \phi(z, t)} = e^{-i(kz - \omega t)}$$

k：波数（空間的位相変化の速さ、$  k = 2\pi / \lambda  $）
ω：角周波数（時間的位相変化の速さ、$  \omega = 2\pi f  $）

これで：

固定時刻 t → 空間 z 方向に位相が進み、螺旋や干渉縞の空間パターン。
固定位置 z → 時間 t とともに位相が進み、時計回り回転や時間振動。
両方同時 → 波が進行しながら回転する3D螺旋（helix） が自然に現れます（円偏光の電場軌跡）。

干渉の場合も同じ
2波の総位相差 Δφ = φ₁(z,t) − φ₂(z,t)
（例：経路差による kz 項 + 初期位相 + 時間項）

同周波数 → Δφ が空間的に変わる部分で空間干渉縞、時間項は共通なので I は定常。
周波数差あり → Δφ に Δω t 項が入り、時間的に動く干渉パターン（縞が移動したり、うなりが生じたり）。

つまり、位置と時間を別々に位相（kz と -ωt）に変換して足し合わせるだけで、全て統一的に扱えます。これが複素指数関数 e^{-iφ} の美しさです。

1. 基本形（単位振幅の場合）
N 個の波がコヒーレントに重なる場合：
$$Z = \sum_{n=1}^{N} e^{-i \phi_n}$$
総強度（正規化強度）：
$$I = |Z|^2 = Z \overline{Z} = \left| \sum_{n=1}^{N} e^{-i \phi_n} \right|^2$$
これを展開すると：
$$I = N + 2 \sum_{1 \leq j < k \leq N} \cos(\phi_j - \phi_k)$$

第1項 N：各波自身の強度寄与（対角成分）
第2項：すべてのペア間の干渉項（クロス項）。位相差 Δφ_{jk} = φ_j − φ_k によって強め合い（cos ≈ +1）または打ち消し合い（cos ≈ −1）が決まる。

N=2 のとき → I = 2 + 2 cos(φ₁ − φ₂) = 4 cos²((φ₁ − φ₂)/2) と、これまでの結果と完全に一致します。
2. 一般形（各波に振幅 A_n がある場合）
$$z_n = A_n \, e^{-i \phi_n}$$
$$Z = \sum_{n=1}^{N} A_n \, e^{-i \phi_n}$$
