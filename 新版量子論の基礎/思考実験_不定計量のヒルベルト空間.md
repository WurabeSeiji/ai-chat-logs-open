### ヒルベルト空間の定義 — 正定値性は必須

数学的に厳密に言うと、**ヒルベルト空間 (Hilbert space)** の定義には以下が含まれます：

| 公理                             | 内容                                                                                |
| -------------------------------- | ----------------------------------------------------------------------------------- |
| 内積 $\langle v, w\rangle$       | 双線形・共役対称                                                                    |
| **正定値性 (positive-definite)** | $\langle v, v\rangle \geq 0$、等号成立は $v = 0$ のみ                               |
| ノルム                           | $\lVert v \rVert \equiv \sqrt{\langle v, v\rangle}$ ← 正定値性によって well-defined |
| 完備性                           | Cauchy 列が収束する                                                                 |

**正定値性はヒルベルト空間の中核公理**であって、これがなければ「ヒルベルト空間」とは呼べません。$\mathbb{C}^N$ も $\ell^2$ も $L^2$ も、すべてこの正定値性を満たしている空間として導入されています。

### クライン空間の定義（清水本が省略した内容）

**クライン空間 $\mathcal{K}$**：複素ベクトル空間で、次のような構造を持つ。

1. **不定内積** $[v, w]$：双線形・共役対称だが、**正定値性を要求しない**
   $$[v, v] \in \mathbb{R}, \quad \text{正・負・ゼロ いずれの値も取りうる}$$
2. **直交直和分解**が存在する：
   $$\mathcal{K} = \mathcal{K}_+ \oplus \mathcal{K}_-$$
   - $\mathcal{K}_+$ 上では $[v, v] > 0$（**通常のヒルベルト空間**）
   - $\mathcal{K}_-$ 上では $[v, v] < 0$（**負計量のベクトルだけからなる部分空間**）
   - 両者は $[\cdot, \cdot]$ について直交：$v \in \mathcal{K}_+, w \in \mathcal{K}_- \Rightarrow [v, w] = 0$

**負計量ベクトルの定義**：

$$
[v, v] < 0 \text{ となるベクトル } v
$$

これはノルム（長さ）として解釈できない（負の平方根は実数で取れない）。だから「**負計量**」を持つベクトルは、**通常の意味での「長さ」を持たない**。

#### $\mathbb{C}^2$ で具体例

通常の $\mathbb{C}^2$ では内積は $\langle u, v\rangle = u_1^*v_1 + u_2^*v_2$。これは正定値で、ヒルベルト空間。

クライン空間版の $\mathbb{C}^2$ では、たとえば

$$
[u, v] = u_1^*v_1 - u_2^*v_2
$$

と定義する。すると：
- $e_1 = (1, 0)$ について $[e_1, e_1] = 1 > 0$（正計量）
- $e_2 = (0, 1)$ について $[e_2, e_2] = -1 < 0$（**負計量**）
- $v = (1, 1)$ について $[v, v] = 1 - 1 = 0$（**null ベクトル**）

この空間ではノルム $\lVert v \rVert = \sqrt{[v,v]}$ が定義できない（虚数や 0 になる）。だから確率を $\lVert \hat{P}(a)|\psi\rangle \rVert^2$ では定義できない。


### $\mathbb{C}^2$ で書き下せば

通常の**複素ヒルベルト空間 $\mathbb{C}^2$**：

$$
|\psi\rangle = \begin{pmatrix}\psi_1 \\ \psi_2\end{pmatrix},\quad
\langle\psi|\phi\rangle = \psi_1^{*}\phi_1 + \psi_2^{*}\phi_2 \quad (\text{両方プラス})

→ $\langle\psi|\psi\rangle = |\psi_1|^2 + |\psi_2|^2 \geq 0$（常に非負＝**正定値**）

**クライン空間版の $\mathbb{C}^2$**：

$$
|\psi\rangle = \begin{pmatrix}\psi_1 \\ \psi_2\end{pmatrix},\quad
[\psi, \phi] = \psi_1^{*}\phi_1 \;\boxed{-}\; \psi_2^{*}\phi_2 \quad (\text{一方マイナス})
$$

→ $[\psi, \psi] = |\psi_1|^2 - |\psi_2|^2$ は **正にも、負にも、ゼロにもなる**

### 行列で表すと

通常のヒルベルト空間の内積は **単位行列**を挟んだ形：

$$
\langle\psi|\phi\rangle = \begin{pmatrix}\psi_1^{*} & \psi_2^{*}\end{pmatrix}\begin{pmatrix}1 & 0 \\ 0 & 1\end{pmatrix}\begin{pmatrix}\phi_1 \\ \phi_2\end{pmatrix}

クライン空間の内積は **対角成分が ±1 の計量行列 $\eta$** を挟んだ形：

$$
[\psi, \phi] = \begin{pmatrix}\psi_1^{*} & \psi_2^{*}\end{pmatrix}\boxed{\begin{pmatrix}1 & 0 \\ 0 & -1\end{pmatrix}}\begin{pmatrix}\phi_1 \\ \phi_2\end{pmatrix}
$$

→ **計量行列 $\eta = \mathrm{diag}(+1, -1)$ が「符号付け」の正体**

### ミンコフスキー時空との類似

| **不確定性関係**                   | 交換子 $[\hat{A}, \hat{B}]$ の正・負・ゼロが物理的意味を決める         |
| **エネルギー条件 (GR)**            | $T_{\mu\nu}v^\mu v^\nu \geq 0$（弱エネルギー条件）が因果律を保証       |

### 共通構造：「正定値性」と「Lorentz 不変性」の衝突

すべての場面に共通する構造は：

```
       ［正定値性が必要］              ［Lorentz 不変性が必要］
        ・確率（Born 規則）              ・時空対称性
        ・ノルム（Hilbert）              ・場の量子化
        ・エネルギー（安定性）            ・経路積分の定義
                  ↓
          両方を同時に満たせない
                  ↓
      ［符号付き構造を導入してごまかす］
        ・Krein 空間
        ・Wick 回転
        ・反粒子（負エネルギー解）
        ・ゴースト（BRST）
        ・符号付き測度
```

つまり、**理論物理学の発展史は「正定値性 vs Lorentz 不変性」という根本的なトレードオフを、新しい数学装置で次々と隠蔽してきた歴史**——とまとめられます。

### 各装置は「同じ問題の別の現れ」

| 装置                         | 何をごまかしているか                                       |
| ---------------------------- | ---------------------------------------------------------- |
| **Minkowski 計量**           | 時間と空間の符号差を最初から内蔵                           |
| **複素ヒルベルト空間**       | 位相を持つ複素数を導入して、相対位相を符号として実現       |
| **Wick 回転**                | 振動積分の発散を、虚時間で減衰積分に変換                   |

→ **どれも「符号をどう処理するか」という同一の問題を、別の装置で扱っている**だけ。

### なぜこの問題が「呪縛」なのか

(1) **根源的に解けない**：「正定値性」と「Lorentz 不変性」は両立しないことが定理として知られています（Källén-Lehmann 表示など）。「両立させる」のではなく「不両立を別の場所に押し付ける」しかない。

(2) **装置を増やしすぎた**：100 年かけて、各装置（Wick 回転、ゴースト、超対称性、…）が独立に発展してしまい、**それらが本当は同じ問題の現れ方であることを忘れている**。各分野の物理学者は、自分の領域の符号問題が「特有の難問」だと思っている。

(3) **根本に近い場面で破綻が大きい**：真空エネルギー問題（$10^{120}$ 桁差）、量子重力の繰り込み不可能性、初期宇宙の特異点——これらはすべて「符号問題が最も先鋭化した場所」で発生しています。
