# 補足資料：運動量と位置の検討

> 量子論における運動量と位置の本質的な扱い方の整理。
> 古典力学の「$p = mv$」直感がもたらす混乱を解消し、運動量を**質量フリーな基本量**として位置づける。

---

## 1. 問題提起：質量は基本量か派生量か

古典力学では「**運動量 ＝ 質量 × 速度**」（$p = mv$）と定義されるため、運動量は質量を含む派生量に見える。しかし：

- **質量は標準モデルでは派生量**：Higgs 場の VEV と Yukawa 結合から生成
- ハドロン質量の 99% は **QCD 結合エネルギー**（Higgs 由来は約 1%）
- 光子・グルーオンは質量ゼロ

→ **質量こそが派生量。「$p = mv$」を運動量の定義とすると、より基本的な量から派生的な量を介して定義することになり、論理が逆転している**。

---

## 2. 運動量の本質：質量フリーで定義可能

### 2.1 de Broglie 関係

$$
p = \frac{h}{\lambda} = \hbar k
$$

- **必要なもの**：波長 $\lambda$（または波数 $k$）、プランク定数 $h$
- **質量は不要**

→ 光子だろうが電子だろうが、**運動量は波長だけで決まる**。

### 2.2 並進対称性の生成子（Noether の定理）

運動量演算子は **空間並進の生成子**：

$$
\hat T(a) = e^{-i\hat p a/\hbar}\quad \text{（並進 } a \text{ の生成子）}
$$

→ Noether の定理：空間並進対称性 $\to$ 運動量保存則。**対称性から直接定義され、質量は介在しない**。

### 2.3 量子論での演算子定義

$$
\hat p = -i\hbar\,\frac{\partial}{\partial x}
$$

- 微分演算子として直接定義
- 質量は式中に現れない
- 任意の波動関数 $\psi(x)$ に作用可能

### 2.4 位相勾配としての運動量

波動関数を極形式で書くと：

$$
\psi(x) = |\psi(x)|\,e^{i\phi(x)}
$$

運動量の期待値は：

$$
\langle\hat p\rangle = \hbar\,\langle\partial\phi/\partial x\rangle
$$

→ **運動量は位相の空間勾配**。位相が一次実在なら、運動量はその直接的な観測量。

---

## 3. 位置の本質：運動量の正準共役

### 3.1 正準共役関係

$$
[\hat x, \hat p] = i\hbar
$$

→ 位置と運動量は**互いに正準共役**。一方が他方の生成子であり、対称的な関係。

### 3.2 位置演算子

座標表示では：

$$
\hat x = x\quad\text{（乗算演算子）}
$$

- 直接的な定義
- 質量は不要

### 3.3 位置の固有状態の特異性

位置の固有状態 $|x\rangle$ は：

$$
\hat x|x_0\rangle = x_0|x_0\rangle,\quad \langle x|x_0\rangle = \delta(x - x_0)
$$

- 規格化不能（$\delta(0) = \infty$）
- ヒルベルト空間の正当な住人ではない（リッグド・ヒルベルト空間に住む超関数）
- §3.15 補講で詳述

→ **位置固有状態は数学的便宜の理想化**。実在の粒子は常に有限の波束。

### 3.4 観測と位置

実際の観測は**位置の確率密度** $|\psi(x)|^2$ として現れる：

- 検出器が「ここでクリック」という離散イベント
- 多数のイベントの統計分布が連続的に見える
- 位置自体が「測定値」として観測可能

## 4. 位置・運動量の不確定性

### 4.1 Heisenberg–Robertson 不等式

$$
\Delta x \cdot \Delta p \geq \frac{\hbar}{2}
$$

→ 位置と運動量の同時確定は不可能。**位相空間における 1 量子状態の最小占有面積 ＝ $\hbar/2$**。

### 4.2 位相空間描像

「面積 = $\hbar/2$」は不変、形（縦横比）は自由：

- $\Delta x$ 小・$\Delta p$ 大（位置を絞った状態）
- $\Delta x$ 大・$\Delta p$ 小（運動量を絞った状態）
- $\Delta x = \Delta p = \sqrt{\hbar/2}$（最小不確定ガウス波束）

→ §3.19 末尾の補講で詳述。

### 4.3 質量との関係

- 不確定性関係そのものには質量は出てこない（$\hbar/2$ は普遍定数）
- 速度の不確定性 $\Delta v = \Delta p / m$ は質量に依存（派生量）

→ **不確定性関係も質量フリー**。質量は派生量 $v$ の段階で初めて入る。

## 5. キネマティクス vs ダイナミクス

質量の役割を整理すると：

| 物理量 | 質量フリーか | 必要なもの |
|---|---|---|
| 運動量 $p$ | **質量フリー** | 波長、$h$ |
| 位置 $x$ | **質量フリー** | 直接観測 |
| 波数 $k = p/\hbar$ | **質量フリー** | 位相勾配 |
| 振動数 $\nu = E/h$ | **質量フリー** | 位相の時間変化率 |
| 不確定性 $\Delta x \Delta p$ | **質量フリー** | $\hbar/2$ |
| エネルギー‐運動量関係 $E(p)$ | **質量必要** | $E^2 = (pc)^2 + (mc^2)^2$ |
| 速度 $v = p/m$ | **質量必要** | $m$ |
| 時間発展 $\partial_t \psi$ | **質量必要** | $E$ 経由 |
| 群速度 $v_g = dE/dp = p/m$ | **質量必要** | $m$ |

→ **キネマティクス（運動学）は質量フリー、ダイナミクス（動力学）に質量が必要**。

## 6. 相対論的構造

### 6.1 4 元運動量

$$
p^\mu = (E/c,\,\vec p)
$$

→ エネルギーと運動量は 4 次元時空での 1 つのベクトルの成分。

### 6.2 Lorentz 不変量としての質量

$$
p^\mu p_\mu = \frac{E^2}{c^2} - |\vec p|^2 = (mc)^2
$$

→ **質量の 2 乗は 4 元運動量の長さの 2 乗**。Lorentz 変換で不変な量。

特殊な場合：

- **光子（$m = 0$）**：$E = pc$、4 元運動量はヌルベクトル
- **静止した massive 粒子**：$E = mc^2$、$\vec p = 0$
- **相対論的 massive 粒子**：$E = \gamma mc^2$、$\vec p = \gamma m\vec v$

→ **質量は 4 元運動量の Lorentz 不変な長さとして派生**。運動量が一次、質量は二次。

## 8. 質量の物理的意味——「ディレイ係数」

質量の役割を情報理論的に言い直すと：

- **運動量を持っていても、時間発展がどれだけ遅いか**
- **同じエネルギーで、どれだけ遠くまで進めるか**（群速度 $v = p/m$）
- **位相変化が空間にどれだけ早く伝わるか**

→ 質量 ＝ **位相の時間発展に対する応答の遅さ**（ディレイ）

仮定 I-3「演算には有限のディレイが不可欠」と整合：質量は具体的なディレイの度合いを表す量。

例 3.20 の状態を **質量に依存しない形**で書き直すと：

- **光子でも電子でも同じ形** $e^{i\vec k\cdot\vec r}$

質量が現れるのは：

- エネルギー：$E = p^2/(2m)$（非相対論） or $E = \sqrt{(pc)^2 + (mc^2)^2}$（相対論）

→ 状態 $|p_x, p_y, p_z\rangle$ は質量フリーで定義され、質量は**時間発展のレートを決める係数**として後段で入る。

## 11. 加速度の表現——3 つの視点

運動量・位置が質量フリーで定義できるなら、加速度はどう扱うか。これは**運動量議論の自然な延長**で、3 つの同値な視点で整理できる。

### 11.1 標準 QM では加速度に質量が入る

Ehrenfest の定理：

$$
\frac{d^2\langle\hat x\rangle}{dt^2} = \frac{1}{m}\frac{d\langle\hat p\rangle}{dt} = \frac{\langle\hat F\rangle}{m}
$$

→ Newton の $F = ma$ が量子力学にも持ち越される。**質量が分母に出てくる**。

中身を分解すると：

| 量 | 式 | 質量フリー？ |
|---|---|---|
| 位置変化率 $d\langle\hat x\rangle/dt$ | $\langle\hat p\rangle/m$ | ✗（質量で割る） |
| **運動量変化率** $d\langle\hat p\rangle/dt$ | $-\langle\nabla V\rangle = \langle\hat F\rangle$ | **○** |
| 加速度 $d^2\langle\hat x\rangle/dt^2$ | $\langle\hat F\rangle/m$ | ✗（質量で割る） |

→ **力 $F$ は質量フリー、加速度 $a = F/m$ は質量を必要とする**。

### 11.2 力こそが一次量

$F = dp/dt$ は **運動量保存則の修正量**で、質量を含まない。

```
基本：F = dp/dt（運動量変化率） ← 質量フリー
派生：a = F/m（質量で割って加速度） ← 質量必要
```

→ Newton の第二法則は実は **$F = dp/dt$ が基本関係**で、$a = F/m$ は質量による単位変換。

### 11.3 相対論的視点——測地線からのずれ（質量フリー）

一般相対論では加速度を**幾何学的に**定義：

$$
a^\mu = \frac{Du^\mu}{D\tau}
$$

ここで $u^\mu$ は 4 元速度、$D/D\tau$ は共変微分。

- **自由落下している粒子**：測地線に沿って運動、$a^\mu = 0$
- **加速度計が指す加速度**：測地線からのずれ
- **テスト粒子の質量は不要**（等価原理）

→ **加速度は幾何学的概念で、テスト粒子の質量によらない**。質量はソース側（曲率を作る $T_{\mu\nu}$）で初めて必要。

### 11.4 W10 / 思考実験フレームでの加速度

仮定 III-2：

$$
R = \frac{1}{a} = \text{曲率半径} = \text{空間広がり} = \frac{\lambda}{2}
$$

→ **加速度は $1/R$ で定義される**。$R$ は粒子固有のスケール。

| 量 | 関係 |
|---|---|
| 加速度 $a$ | $1/R$ |
| 曲率半径 $R$ | $\lambda/2$（半波長） |
| 波長 $\lambda$ | de Broglie $\lambda = h/p$ |

組み合わせると：

$$
a = \frac{1}{R} = \frac{2}{\lambda} = \frac{2p}{h}
$$

→ **加速度は運動量と $h$ だけで表現される。質量は不要**。

### 11.5 質量はどこで効くか

加速度自体の定義に質量は不要だが、**加速度の物理的応答**（外力に対する反応）に質量が効く：

```
基本：粒子の R = λ/2 = 1/a（幾何的、質量フリー）
   ↓
粒子の質量 m（Higgs + QCD で生成、派生）
   ↓
外力 F に対する応答：
   - 同じ F でも、m が大きいと加速しにくい
   - これが Newton の F = ma の意味
```

→ **質量は「外力に対する加速の応答の遅さ」**。質量＝ディレイ係数の解釈と整合。

### 11.6 3 つの定義の整理

| 視点 | 加速度の定義 | 質量フリー？ |
|---|---|---|
| **Newton** | $a = F/m$ | ✗（質量で割る） |
| **力ベース（部分的）** | $F = dp/dt$（$a$ そのものではないが基本量） | **○** |
| **GR 幾何ベース** | $a^\mu = Du^\mu/D\tau$（測地線からのずれ） | **○** |
| **W10 ベース** | $a = 1/R = 2/\lambda$（粒子の固有スケールの逆数） | **○** |

→ **加速度は質量フリーに定義できる**（GR、W10）。Newton の $a = F/m$ は質量による単位変換にすぎない。

### 11.7 「加速度 ＝ R の逆数」の物理的意味

仮定 III-2 が言っているのは：

> **粒子の固有の「広がり」（波長／曲率半径／$R$）が、その粒子が経験する加速度の逆数**

直感的には：

- **広がりが大きい（$R$ 大）**：穏やかな加速度（$a$ 小）
- **広がりが小さい（$R$ 小）**：強い加速度（$a$ 大）

例：

- 静止電子の Compton 波長 $\lambda_C = h/(m_e c) \sim 10^{-12}$ m → $a \sim 1/\lambda_C \sim 10^{12}$ m$^{-1}$（適切な単位で）
- 光子の波長は自由：エネルギーに応じて加速度が変わる
- 重力場中の粒子：曲率半径が変わる → 加速度が変わる

→ **加速度は「粒子のサイズの逆数」**として幾何学的に定義される。

### 11.8 統一的描像

```
位相 φ（一次実在）
   │
   ├─ 空間勾配 → 波数 k → 運動量 p = ℏk
   │
   ├─ 時間勾配 → 角振動数 ω → エネルギー E = ℏω
   │
   └─ 波長 λ
         ↓
     粒子の特徴スケール R = λ/2
         ↓
     加速度 a = 1/R = 2p/h ← 質量フリー！

──────────────────────
質量 m（派生、Higgs + QCD）
   │
   ├─ E と p の関係を変える：E² = (pc)² + (mc²)²
   │
   ├─ 外力応答の遅さ：F = m·a（Newton の派生関係）
   │
   └─ ディレイ係数（仮定 I-3）
```

→ **位相 → 波長 → R → 加速度** という流れで質量フリーに加速度を定義できる。質量は「外力応答の遅さ」として後段で入る。

### 11.9 一行まとめ

> **加速度は「力 $F = dp/dt$」（質量フリー）と「質量による応答の遅さ」（質量必要）の積として理解される。標準 Newton の $a = F/m$ は派生関係。GR では測地線からのずれ、W10 では $a = 1/R = 2/\lambda$ として質量フリーに定義できる。質量は加速度自体ではなく、「同じ力に対する加速の遅さ」を決めるディレイ係数として後段で登場する。**

## 12. 質量の方向問題と t-R 分解

### 12.1 質量はスカラーか、隠れた方向の運動量か

「質量には方向がない」というのは、観測 3 次元の視点からは正しい（スカラー）。しかし、より深く見ると：

> **質量は「観測者に対して直交する隠れた軸の運動量」**

として、方向を持つ量と等価に扱える。隠れた軸の候補は 2 つ：

| 視点 | 「隠れた方向」 | 質量の正体 |
|---|---|---|
| **特殊相対論** | 時間軸 $t$（4D 内、3D 空間に直交） | 時間方向の運動量（静止系で $P^t = mc$） |
| **W10 / KK** | R 軸（4D の外、観測時空に直交） | R 方向の運動量 $P^R$ |

→ どちらも「**質量は隠れた方向の運動量**」という共通構造。

### 12.2 5D 質量殻条件——構造の精密化

5D 時空 $(x, y, z, t, R)$ で**質量ゼロ**の粒子を考えると：

$$
(P^t)^2 \;-\; |\vec p|^2 \;-\; (P^R)^2 \;=\; 0
$$

→ 標準の相対論的エネルギー関係

$$
E^2 = (pc)^2 + (mc^2)^2
$$

と完全に同じ形。対応：

| 5D 表現 | 4D 表現 | 物理的意味 |
|---|---|---|
| $P^t$ | $E/c$ | **時間軸方向の運動量 = 総エネルギー / $c$** |
| $\vec p$ | $\vec p$ | **空間方向の運動量** |
| $P^R$ | $mc$ | **R 軸方向の運動量 = 静止エネルギー / $c$ = 質量 × $c$** |

→ **$t$ 軸と $R$ 軸は別のエネルギー成分を担う**。

### 12.3 役割分担の精密化

| 軸 | 運動量成分 | 物理的意味 | Lorentz 性質 |
|---|---|---|---|
| **R 軸** | $P^R = mc$ | **静止エネルギー** / $c$（質量そのもの） | **4D Lorentz 不変** |
| **t 軸** | $P^t = E/c$ | **総エネルギー** / $c$（静止 ＋ 運動） | 4D Lorentz 変換で変わる |
| $x, y, z$ | $\vec p$ | **3 次元空間運動量** | 4D Lorentz 変換で変わる |

そして運動エネルギーは：

$$
\boxed{\;E_{\text{kinetic}} \;=\; c\,(P^t - P^R) \;=\; c\,P^t - mc^2\;}
$$

→ **「$t$ 成分と $R$ 成分の差」が運動エネルギー**。非相対論極限 $|\vec v| \ll c$ で $E_{\text{kinetic}} \approx |\vec p|^2/(2m)$。

### 12.4 幾何学的描像

5D 運動量空間を $t$-$R$ 平面に射影すると：

```
   P^t（時間軸：総エネルギー / c）
    │
    │       ● (P^t, P^R)
    │      ╱
    │     ╱  ← ベクトル長 |p|（空間運動量）
    │    ╱     角度は速度に応じて変化
    │   ╱
    │  ╱
    │ ╱
    │╱
    ●───────────────  P^R（R 軸：静止エネルギー / c = mc）
   (0,0)
```

| 状況 | $P^t$ | $P^R$ | $\|\vec p\|$ | 角度 |
|---|---|---|---|---|
| **静止粒子** | $mc$ | $mc$ | $0$ | $0$（$t$ と $R$ 重なる） |

## 13. 加速度の中心投影起源——「見えない軸の速度」と 4D 加速度

### 13.1 ご指摘の核心仮説

> **見えない軸（$t, R, Q$）方向の速度が、4D 観測者には加速度として見える。**

これは「**等速 5D/6D 運動 → 中心投影の非線形性 → 4D 加速度**」という構造で実現される。

### 13.2 直交射影との違い——なぜ中心投影が重要か

| 射影の種類 | 5D 等速運動 → 4D 観測 |
|---|---|
| **直交射影**（線形） | 4D でも等速度（加速度ゼロ） |
| **中心投影**（非線形、$1/y$ 等） | **4D で加速度が現れる**（投影の非線形性から） |

→ **W10 が中心投影を採用するのは、加速度を「投影の幾何学的副産物」として説明するため**。

### 13.3 2D → 1D 中心投影の例

簡単な例で確認：2D 平面 $(x, y)$ を、原点中心で 1D の直線 $y = 1$ に**中心投影**：

$$
X(t) = \frac{x(t)}{y(t)}
$$

2D で等速直線運動：$x(t) = x_0 + v_x t,\;y(t) = y_0 + v_y t$。

1D 投影の速度・加速度：

$$
\frac{dX}{dt} = \frac{v_x y - x v_y}{y^2},\qquad \frac{d^2 X}{dt^2} = \frac{-2(v_x y - x v_y)v_y}{y^3}
$$

→ **2D では加速度ゼロ、1D では一般に加速度あり**。中心投影の非線形性（$1/y$）が等速度を加速度に変換する。

### 13.4 5D → 4D での加速度

5D 等速運動を中心投影で 4D に落とすと、同じ構造で加速度が現れる：

```
5D 背景空間 (xyzt + R)
   │
   │  粒子は 5D で等速直線運動（測地線、加速度ゼロ）
   │
   ↓ 中心投影 π : 5D → 4D（非線形写像、R 軸を消去）
   │
4D 観測時空 (xyzt)
   │
   │  投影された軌道に「見かけの加速度」が発生
```

| 5D 等速運動成分 | 中心投影後の 4D 観測 |
|---|---|
| R 軸単独の等速 | 質量（鏡静止エネルギー、4D 加速度なし） |
| t 軸単独の等速 | エネルギー（時間発展） |
| xyz 単独の等速 | 慣性運動 |
| **xyz と R の結合** | **4D 加速度**（投影非線形性） |
| **xyz と Q の結合** | **電磁加速度**（KK 機構） |

→ **「単独の軸方向速度」は静的観測量、「結合した速度」が加速度を生む**。

### 13.5 重力加速度の例

一様重力場中の自由落下：

- **5D 視点**：粒子は 5D で測地線（加速度ゼロ）
- **4D 視点**：地表に対して落下、加速度 $g$
- **中心投影**：5D 等速運動の R 成分が「地球方向の加速度」に変換される

→ GR の等価原理（自由落下＝測地線運動）が、中心投影で具体化される。

### 13.6 数学的構造の概要

5D 速度 $u^A = (u^t, u^x, u^y, u^z, u^R)$ について、4D 投影後の加速度は：

$$
\text{4D 加速度} \;\propto\; \text{Jacobian の非線形項} \;\sim\; \frac{u^R u^x}{R^2},\;\frac{u^R u^t}{R^2},\;\ldots
$$

→ **R 軸速度 × xyz 速度（または R × t）が加速度を生む**。単独成分ではなく**結合項**が本質。

### 13.7 統一視点

| 物理量 | 6D での正体 | 観測 4D での見え方 |
|---|---|---|
| 質量 $m$ | $P^R = mc$（R 軸運動量、単独） | 静止エネルギー（スカラー） |
| 電荷 $q$ | $P^Q$（Q 軸運動量、単独） | 電荷スカラー |
| エネルギー $E$ | $P^t = E/c$（t 軸運動量、単独） | 時間成分 |
| 運動量 $\vec p$ | $P^x, P^y, P^z$（観測軸成分） | 空間ベクトル |
| **加速度** $\vec a$ | **6D 等速運動 × 中心投影の非線形項** | xyz ベクトル |
| 加速度大きさ $\|a\|$ | $1/R$（粒子固有スケール）または投影 Jacobian | スカラー |

→ **すべての観測 4D 量が「6D の構造の異なる側面」として統一**。

### 13.8 一行まとめ

> **見えない軸の単独速度は静的観測量（質量・電荷・エネルギー）として現れるが、観測軸との結合が中心投影の非線形性を通じて 4D 加速度を生む。GR の等価原理（自由落下＝測地線）は中心投影による具体化。「速度がそのまま加速度」ではなく、「速度の結合が中心投影で加速度に化ける」が正確な構造。**

## 14. 6D 直交構造と自己ループ問題

### 14.1 ご指摘の仮説

> **エネルギー（t）・質量（R）・電荷（Q）は直交軸にあるので、事実上自己ループしないのでは？**

直感的には正当だが、「そんなに甘くないか？」のご懸念も的を射ている。整理すると：

> **自由理論では確かに自己ループなし。相互作用項が直交を破ってループを生む。ただし思考実験フレームの他の前提（離散位相・ディレイ・有限 R）が UV 発散を防ぎ、ループは有限値で収まる。**

### 14.2 自由理論：直交で自己ループなし

自由ラグランジアンは各軸ごとに分離：

$$
\mathcal{L}_{\text{free}} = \mathcal{L}_t + \mathcal{L}_x + \mathcal{L}_y + \mathcal{L}_z + \mathcal{L}_R + \mathcal{L}_Q
$$

- $\mathcal{L}_t$：時間並進 → エネルギー保存
- $\mathcal{L}_R$：R 並進 → 質量保存
- $\mathcal{L}_Q$：Q 並進 → 電荷保存

→ **どの軸の運動量も他の軸に流れない、自己ループは発生しない**。自由場の伝播子は対角的、各粒子は独立。

### 14.3 相互作用が直交を破る

相互作用項が異なる軸を結合：

| 相互作用 | 結合する軸 | 物理的効果 |
|---|---|---|
| **Yukawa** $y\bar\psi\psi\phi$ | フェルミオン（R, Q）↔ Higgs（R 軸 VEV） | 質量生成 |
| **電磁** $g\bar\psi\gamma^\mu A_\mu\psi$ | フェルミオン（Q）↔ 光子（Q 場） | EM 相互作用 |
| **強い** $g_s\bar q\gamma^\mu G_\mu^a T^a q$ | クォーク（色 Q）↔ グルーオン | 強い相互作用 |
| **重力** $h_{\mu\nu}T^{\mu\nu}$ | エネルギー運動量 ↔ 計量 | 質量エネルギーが時空を曲げる |

→ **相互作用 vertex で軸が結合 → 自己ループが発生**。

例：電子の自己エネルギー

```
e⁻ ──┬─── γ（仮想光子）──┬─── e⁻
     │                    │
     └─── 同じ e⁻ ────────┘  ← 自己ループ
```

→ Q 軸内でループ、t 軸成分（仮想光子のエネルギー）が全範囲を走る → 標準 QFT で UV 発散。

### 14.4 ご指摘の直感が半分正しい理由

| 観察 | 評価 |
|---|---|
| 自由部分は直交分離 | **正しい**（自由理論の正確な特徴） |
| 相互作用が直交を破る | 相互作用は「追加」されたもの |
| 相互作用が全 UV 発散の源 | **正しい**（標準 QFT でもそう） |
| 直交だから自己ループしない | **半分正しい**（自由部分はそう、相互作用部分は違う） |

→ ご指摘は **「自由理論の正確な観察」** で、相互作用が直交を破る部分が見落とされている。

### 14.5 UV 有限性は他の前提から

「そんなに甘くないか？」のご懸念は的確。直交性だけでは UV 有限にならない。しかし、思考実験フレームには**他の UV 有限化メカニズム**：

| 仮定 | UV 有限化の役割 |
|---|---|
| **I-3 ディレイ**（有限処理時間） | 短時間スケールの cutoff（高周波カット） |
| **I-5 位相は離散値** | 無限大波数を許さない |
| **III-2 R = 粒子固有スケール = λ/2** | 短波長を粒子サイズで cutoff |
| **III-5 重力以外は曲率非依存** | 多次元発散を 1D 計算に還元 |
| **IV-2 相互作用は波長重なりで発生** | 距離が離れた粒子は相互作用しない |
| **VI 6 軸直交** | 自由部分を整理、相互作用を vertex に局所化 |

→ **これらが組み合わさって自己ループは有限値で評価される**。直交性は構造的整理、他の前提が UV 有限化、両者組合せで繰り込み不要な有限理論になる。

### 14.7 電子自己エネルギーの例

### 14.9 ご指摘の射程
