### 540° の数学

球面三角形（半径 $R$）の内角の和：

$$
\Sigma = \pi + \frac{A}{R^2}
$$

$$
\Sigma_{\max} = \pi + \frac{2\pi R^2}{R^2} = 3\pi = 540°
$$

## 【アイリス】

**CPT 不変性** と **Lorentz 不変性** は、標準物理が「自然の根本対称性」と主張する 2 つの性質です。

### Lorentz 不変性

特殊相対性理論の核心：

> **物理法則は、すべての慣性系（一定速度で動く観測者）で同じ形になる。**

具体的には、座標変換

$$
t' = \gamma(t - vx/c^2),\qquad x' = \gamma(x - vt)
$$

（Lorentz 変換）を行っても、Maxwell 方程式・Dirac 方程式・標準モデルのラグランジアンなど、すべて形が変わらない。

→ 「**動いている観測者と止まっている観測者で、同じ物理法則が成り立つ**」という主張。

### CPT 不変性

3 つの離散変換の組合せ：

| 記号  | 名前                          | 内容                                  |
| ----- | ----------------------------- | ------------------------------------- |
| **C** | 荷電共役 (Charge conjugation) | 粒子 ↔ 反粒子（電荷を反転）           |
| **P** | パリティ (Parity)             | 空間反転 $\vec x \to -\vec x$（鏡映） |
| **T** | 時間反転 (Time reversal)      | 時間方向反転 $t \to -t$               |

主張（**CPT 定理**）：

> **任意の相対論的局所場の理論は、C・P・T の 3 つを同時に行う変換の下で不変。**

実験的に極めて高精度で確認されている（例：粒子と反粒子の質量差 $< 10^{-18}$）。

### 個別では破れる

| 変換         | 破れる例                                   |
| ------------ | ------------------------------------------ |
| **C 単独**   | 弱い相互作用で破れる                       |
| **P 単独**   | 弱い相互作用で破れる（1956 Wu 実験）       |
| **CP 同時**  | $K^0$ 中間子・$B^0$ 中間子で破れる（1964） |
| **T 単独**   | CP 破れと連動して破れる                    |
