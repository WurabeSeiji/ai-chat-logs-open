## 第 1 部：標準量子論の構造的曖昧さ

本部では，これまでの議論で見えた標準量子論の **15 の暗黙の前提・曖昧さ** を整理する．

### 1.1 二重スリット記述の単純化（§0.3.1）

**標準教科書の記述**：光源 → 2 つのスリット → 検出スクリーン，という単純化された幾何．

**暗黙の前提**：
- スリットは数学的な点（幅ゼロ）
- 光源は点源
- 検出スクリーンは平坦
- 全てが古典的時空配置

**実際の現実**：
- スリットは有限の幅 → 単スリット回折のエンベロープ
- 光源は有限の広がり → コヒーレンス
- 検出は離散事象 → 量子的測定

**本試案での扱い**：これらの「単純化」は本試案の枠組みでは **適切な近似** として再導出される．本試案では，すべてを **位相空間上の波動** として扱い，必要に応じて単純化を導入する．

### 1.2 経路差モデルの不完全性（§0.8）

**標準教科書の記述**：$P(x) \propto \cos^2(k\Delta r/2)$

**暗黙の前提**：すべての明線が等高．干渉縞の存在範囲が無限大．

**実際の現実**：干渉縞は中央最大の単スリット回折エンベロープ内にのみ存在．

**本試案での扱い**：単スリット回折を含む完全な記述は，**位相空間上のフーリエ解析** で自然に出る．本試案の枠組みでは「波束の有限性 + フーリエ展開」で統一的に扱う．

### 1.3 距離減衰の取り扱い（§0.6）

**標準教科書の記述**：通常は無視．

**実際の現実**：3D 球面波は $1/r$ 振幅減衰．

**暗黙の前提**：実験スケールで $r$ がほぼ一定 → 無視できる．

**本試案での扱い**：閉じた位相空間では，「広がり」と「減衰」が **位相のトポロジー** に組み込まれる．通常の $1/r$ は局所平坦近似での記述．

### 1.4 単一開口の自己干渉（§0.3.1）

**標準教科書の記述**：二重スリットを主要モデルとする．

**暗黙の前提**：二重スリットが量子干渉の本質．

**実際の現実**：単一の有限開口でも自己回折で干渉縞（同心円のエアリーパターン）が出る．量子干渉は **空間的に広がった対象の普遍的性質** ．

**本試案での扱い**：量子干渉は **位相空間上の波動の重ね合わせ** から普遍的に出る．二重スリットは「離散経路 2 つ」という特殊例．単一開口は「連続経路無限個」．本質的に同一現象．

### 1.5 ソリトン的波形と干渉（§0.7 補足）

**標準教科書の記述**：単色平面波で計算．

**暗黙の前提**：波は連続波 / 単色．

**実際の現実**：鋭く局在したソリトン的波束でも，フーリエ展開で各成分が独立に干渉．長波長成分が干渉を担う．

**本試案での扱い**：波の「連続/局在」は **位相空間上の異なる断面** で，本質的に同じ実体の異なる側面．フーリエ展開は両者の橋渡し．

### 1.6 Born 規則の公理的位置（§0.11, §0.14）

**標準教科書の記述**：$P = \vert\psi\vert^2$ は **要請 (3)** として導入．

**本試案での扱い**：Born 規則は **位相空間上の波動の閉ループ性** から自然に導出される（順方向波 × 逆方向波の積として）．取引解釈と整合．

### 2.1 中心概念：時空は位相空間 + 巻数

- $\theta^\mu$：位相（有限）
- $n^\mu$：巻数（整数）
- $x^\mu$：合計（事実上の連続実数）

**帰結**：
- 局所的には連続実数の振る舞い
- 大域的にはコンパクト

### 2.2 波動方程式は閉ループとして閉じる

**前提**：波動関数 $\psi$ は位相空間上で周期境界条件を満たす：

$$\psi(\theta^\mu + 2\pi, \ldots) = \psi(\theta^\mu, \ldots) \quad \forall \mu$$

**帰結**：
- 平面波解 $\psi = e^{ik_\mu x^\mu}$ は $k_\mu \in \mathbb{Z}$ に制限
- **波数・周波数が離散**
- 量子化が **必然**

**形式**：

時間方向の周期 $T$，空間方向の周期 $L$ について：

$$k_x = \frac{2\pi n_x}{L_x},\ k_y = \frac{2\pi n_y}{L_y},\ k_z = \frac{2\pi n_z}{L_z},\ \omega = \frac{2\pi n_t}{T}$$

$n_\mu \in \mathbb{Z}$ が量子数．

**エネルギー**：

$$E = \hbar\omega = \frac{2\pi\hbar n_t}{T} = n_t \hbar \omega_0$$

エネルギーは基底周波数 $\omega_0 = 2\pi/T$ の **整数倍** ．量子化が **構造的に強制** される．

### 2.4 時間対称性と取引解釈

**前提**：波動方程式は時間反転対称．遅延波と先進波が等しく存在．

**取引の構造**：

- 系 A（送信側）：遅延波 $\psi_A^{\text{ret}}$ を未来方向に放出

- 確率：$P = \psi_A^{\text{ret}} \cdot \psi_B^{\text{adv}*}$

**Born 規則の自然な導出**：

$$P = \vert\psi_A^{\text{ret}}\vert^2 \quad \text{(系 B のすべての結果を足し上げた場合)}$$

これは標準量子論の Born 規則と **一致** ．取引の和として導出される．

本試案は，標準量子論の **暗黙の前提を明示化** し，**より整合的な拡張枠組み** を提案する研究プログラムの概念設計である．清水本を含む標準教科書を **破壊せず**，かつ **深い問題への入り口** を確保する戦略を取る．

本試案の **真の意義** は，新しい予言を出すことではなく：

> **「**自然の本来の構造はもっと深い**」という認識を，**標準教科書を読む読者が出会う具体的な引っかかり** において，**整合的な代替像** として提示する** ことにある．

本書（清水）の各章節を読みながら，「ここで何かが曖昧だ」と感じた読者に，**「そう感じるのは正しい．その曖昧さの正体はこれだ．こう拡張すると整合する」** と示すこと——これが本試案の運用上の役割．
