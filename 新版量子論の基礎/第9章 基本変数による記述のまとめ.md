# 第9章 基本変数による記述のまとめ

2.3節で、「基本変数を用いて理論を構成することがしばしば行われる」と書いた 。実際、第4、5、7章で述べた理論は、全て基本変数を使って記述されていた 。基本変数を用いて記述すると、古典論と量子論の論理構造の共通点と相違点が、とても見やすい形で理解できる 。

## 9.1 基本変数

ラグランジュ形式の古典力学では、系の全ての物理量は一般化座標と一般化速度 $\{q_j, \dot{q}_j\}$ の関数であった 。また、ハミルトン形式では正準変数 $\{q_j, p_j\}$ の関数であった 。このように、系の全ての物理量を構成できる基本的な変数（基本変数）を用いて理論を構成することが、物理ではよく行われる 。

基本変数の間で適当な変換をすれば、別の基本変数に移れる 。例えば調和振動子では、正準変数の代わりに生成・消滅演算子を基本変数として選ぶことができる 。古典論において、生成・消滅演算子に対応する $a$ は：


$$a \equiv \sqrt{\frac{m\omega}{2\hbar}}q + \frac{i}{\sqrt{2m\hbar\omega}}p \tag{9.1}$$

であるが、量子論では $q$ と $p$ が交換しないため、これらを同時に誤差なく測ることはできず、その意味で $\hat{a}$ は可観測量ではない 。量子論の場合、基本変数は可観測量とは限らないのである 。

### 自由度と階層性

有限個の基本変数で記述できる系を**有限自由度系**、無限個必要な系を**無限自由度系**と呼ぶ 。いくつの基本変数を用いるかは、分析したい物理現象の内容（マクロかミクロか）に応じて決める 。

* 
**剛体モデル**: ボールの全体的な運動だけに興味があるなら、重心座標と回転角を基本変数に選ぶ 。


* 
**微小部分モデル**: ボールの変形や破裂まで扱うなら、各微小部分の座標を基本変数に選ぶ 。



ミクロな基本変数を採るほど理論の適用範囲は広くなるが、解を求めることが困難になり、結局はマクロな基本変数と等価な近似を行うことも多い 。分析したい内容に応じて適切な階層を選択することが重要である 。

## 9.2 基本変数を用いた古典論の基本的仮定と枠組み

古典論では、対象に応じて以下のような基本変数を採る：

* 
**粒子**: 座標 $q_j(t)$ と、速度 $\dot{q}_j(t)$ または運動量 $p_j(t)$ 。


* 
**場**: 場の振幅 $\phi(r, t)$ と、時間変化率 $\dot{\phi}(r, t)$ または共役運動量 $\pi(r, t)$ 。


* 
**計算機**: 各ビットデータの値、ヘッドの位置、内部状態など 。



### 古典論の基本的仮定の再定義

1. 
**(i)** 全ての基本変数は、どの瞬間にも定まった値（数値）を持っている 。


2. 
**(ii)** 全ての物理量は基本変数の関数 $A = A(\{q_j, p_j\})$ である 。


3. 
**(iii)** 測定とは、その時刻における物理量の値を知ることである 。


4. 
**(iv)** 物理状態とは、その時刻における基本変数の値の一覧表のことである 。


5. 
**(v)** 時間発展とは、基本変数の値が時々刻々変化することである 。

### 量子論の基本的仮定（続き）

(a) 粒子や剛体の古典力学と同じように選び、足りないもの（スピンなど）を適宜補う。これがいわゆる**量子力学**（quantum mechanics）である 。
(b) 「場」とその時間微分、または共役運動量に選ぶ。これが**場の量子論**（quantum field theory）である 。
(c) さらにミクロなもの（重力をも量子論で記述することを目指す理論など）を選ぶ 。

これらは階層構造になっており、ミクロな基本変数を選ぶほど理論の適用範囲は広くなるが、解析が困難になるため、目的に応じて最適な階層を選択するのが実用的である 。

#### 基本的仮定の詳細

* 
**(i)** 基本変数のすべてが各瞬間に確定した数値を持っているとは限らない 。演算子形式では、これらを演算子 $\hat{\xi}_i, \hat{\eta}_i$ で表す 。


* **(ii)** 任意の物理量（可観測量）$A$ は基本変数の関数である：


$$A = A(\{\xi_i, \eta_i\}) \tag{9.5} [cite: 1511]$$


ただし、基本変数の任意の関数が必ずしも可観測量になるとは限らない 。


* 
**(iii)** 物理量の測定値は一般に測定のたびにばらつくが、その確率分布 $\{P(a)\}$ は、関数形 $A(\{\xi_i, \eta_i\})$ と「物理状態」から一意的に定まる 。


* 
**(iv)** **物理状態**とは、あらゆる可観測量 $A$ に対して測定値の確率分布 $\{P(a)\}$ を与える「写像」である ：



$$\psi : A(\{\xi_i, \eta_i\}) \mapsto \{P(a)\} \tag{9.6} [cite: 1515]$$


演算子形式ではこれを「状態ベクトル」で表し、ボルンの確率規則を用いて分布を導く 。


* 
**(v)** **時間発展**とは、測定時刻によって得られる確率分布 $\{P(a)\}$ が変化することである 。これは基本変数が変化すると考えても（ハイゼンベルク描像）、状態が変化すると考えても（シュレディンガー描像）等価である 。



量子論の予言の具体的な内容は確率分布 $\{P(a)\}$ であり、見かけ上異なる理論（演算子形式、経路積分など）や異なる表示（座標表示、行列表示など）であっても、同じ $\{P(a)\}$ を与えるのであれば、それらはすべて等価な理論である 。
