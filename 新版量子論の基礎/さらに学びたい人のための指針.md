# 付録 A 複素数と複素ベクトル空間

### A.1 複素数

$i^2 = -1$ となる虚数単位 $i$ を考え、$x, y$ が実数のとき $z = x + iy$ を**複素数** (complex number) と言う 。$x$ を実部 ($Re(z)$)、$y$ を虚部 ($Im(z)$) と呼ぶ 。
$z^* \equiv x - iy$ を**共役複素数**と呼ぶ 。
 $|z| \equiv \sqrt{x^2 + y^2}$ を絶対値と呼び、以下の関係が成り立つ：


$$|z|^2 = z^*z = zz^* \tag{A.1}$$

 **オイラーの公式：**


$$e^{i\theta} = \cos\theta + i\sin\theta \quad (\theta \text{は実数}) \tag{A.2}$$

任意の複素数は $z = |z|e^{i\theta}$ と書け、$\theta$ を偏角（または位相）と呼ぶ 。

### A.2 複素ベクトル空間

集合 $V$ が加法とスカラー倍の公理を満たすとき、**複素ベクトル空間**と呼ぶ 。
**例：** $N$ 個の複素数を並べた列ベクトル全体の集合 $C^N$ は複素ベクトル空間を成す 。
ベクトル $x_1, \dots, x_m$ が $c_1x_1 + \dots + c_mx_m = 0$ となるのが係数がすべて $0$ の時だけであれば、これらは**線形独立**であると言う 。
線形独立なベクトルの数の最大値をその空間の**次元** (dimension) と呼ぶ 。

$V$ の次元が $n$ であるとき、適当な $n$ 個の線形独立なベクトル $b_1, b_2, \dots, b_n$ が見つかれば、これを $V$ の**基底**と呼びます 。$V$ の任意のベクトルは、これらの線形結合として一意に表せます 。
特に、各ベクトルのノルムが $1$ で、かつ互いに直交する基底を**正規直交基底**（orthonormal basis）あるいは正規直交完全系と呼びます 。

# 付録 B 行列

数字を並べて括弧でくくったものを**行列**（matrix）と呼びます 。$i$ 行 $j$ 列目の成分を $M_{ij}$ と書きます 。行の数と列の数が等しいものを**正方行列**と呼びます 。

* 
**和とスカラー倍**: 各要素に対する演算として定義されます 。


* 
**行列の積**: $n$ 行 $m$ 列の行列 $A$ と $m$ 行 $l$ 列の行列 $B$ の積 $AB$ の $ij$ 要素は $\sum_{k=1}^m A_{ik}B_{kj}$ で定義されます 。


* 
**非可換性**: 行列の積は、かける順番を変えると一般に結果が変わります（$AB \neq BA$） 。このとき、これらは**交換しない**（非可換）と言います 。


* 
**単位行列 ($\hat{1}$)**: 対角要素がすべて $1$ で、他が $0$ の正方行列です 。


* 
**逆行列 ($\hat{M}^{-1}$)**: $\hat{M}\hat{M}^{-1} = \hat{M}^{-1}\hat{M} = \hat{1}$ を満たす行列です 。


* 
**エルミート共役 ($\hat{A}^\dagger$)**: 複素共役をとって転置（行と列を入れ換え）した行列です 。


* 
**エルミート行列**: $\hat{A}^\dagger = \hat{A}$ となる行列です 。


* 
**ユニタリー行列**: $\hat{U}^\dagger = \hat{U}^{-1}$ となる行列です 。

**問題 3.1**
もしも $\sum_{j}c_{j}|\psi_{j}\rangle=0$ であれば、$|\psi_{k}\rangle$ との内積をとると $c_{k}\langle\psi_{k}|\psi_{k}\rangle=0$ となる 。仮定より $\langle\psi_{k}|\psi_{k}\rangle \neq 0$ なので $c_{k}=0$ となり、これらは線形独立である 。

**問題 3.3**


$\hat{\sigma}_{y}^{\dagger}=(\hat{\sigma}_{y}^{*})^{t}=\begin{pmatrix}0 & i \\ -i & 0\end{pmatrix}^{t}=\begin{pmatrix}0 & -i \\ i & 0\end{pmatrix}=\hat{\sigma}_{y}$ となる 。

**問題 3.4**
異なる固有値に属する固有ベクトルが直交すること、および完全性関係 $\sum |a,l\rangle\langle a,l| = \hat{1}$ を用いる 。
$|a,j\rangle' = \hat{1}|a,j\rangle' = \sum_{a',l} |a',l\rangle\langle a',l|a,j\rangle' = \sum_{l} |a,l\rangle\langle a,l|a,j\rangle'$ 
これより、$\sum_{j} |a,j\rangle'\langle a,j|' = \sum_{j,l,l'} |a,l\rangle\langle a,l|a,j\rangle'\langle a,j|'a,l'\rangle\langle a,l'| = \sum_{l,l'} |a,l\rangle \delta_{l,l'} \langle a,l'| = \sum_{l} |a,l\rangle\langle a,l|$ が導かれる 。
