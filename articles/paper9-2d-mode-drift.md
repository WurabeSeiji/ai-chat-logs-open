## 残された問題：$\pi^2/2$ はなぜ α の係数として現れるか

論文 7 の式

$$\alpha^{-1} = 137 + \frac{\pi^2}{2}\alpha$$

において、係数 $\pi^2/2$ は数値的には 4 次元単位球の体積 $V_4(1)$ と一致します。しかし

- なぜ「4 次元単位球の体積」が α の係数として現れるのか？
- $\pi^2/2$ と α の積はどんな物理的量なのか？
- 0.036 という具体的数値の起源は何か？

論文 7 は自己整合方程式として閉じた構造を提示しましたが、これらの**物理的意味**は open problem として残されていました。

本稿はこの空白に**ひとつの物理的解釈**を与えます。

## 核心観察：α は面積次元の量である

### α の dimensional analysis

α 自身は dimensionless（無次元）ですが、物理的に α が関与する量は $\alpha^2$ として現れます：

- Thomson 散乱断面積：$\sigma_T = \frac{8\pi}{3}r_e^2 \propto \alpha^2 \cdot [\text{length}]^2$
- Rutherford 散乱：$\frac{d\sigma}{d\Omega} \propto \alpha^2 \cdot [\text{length}]^2$
- 古典電子半径：$r_e = \alpha \cdot \frac{\hbar}{mc} \propto \alpha \cdot [\text{length}]$

つまり $\alpha^2$ は面積次元、α は「**面積の幾何学的な平方根**」のような量です。

### 帰結：α は 2 次元構造に結合する

α への寄与を 4 次元空間内の振動モードから考えると、α の面積次元性により：

> **寄与しうるのは「2 次元的な面積を持つ振動モード」に限定される。**

これは Wilson 格子ゲージ理論において、ゲージ結合定数がプラケット（2D 面、2-form）の作用係数として現れることと整合する事実でもあります。

## 振動モードの次元別選別

論文 7 の系（137 個の 4D 超立方体＋外接 4-球面）の振動モードを次元別に分類し、等方平均下での生存条件を整理します。

| モード次元 | 数学的性質 | 等方平均の結果 |
|---|---|---|
| 0D（点） | 位置の揺らぎ | **ゼロ**（並進対称性） |
| 1D（辺） | 方向を持つ | **ゼロ**（向き反転で相殺） |
| **2D（面）** | **面積はスカラー量** | **生き残る** |
| 3D（立体） | 体積要素は擬スカラー | **ゼロ**（向きで符号反転） |
| 4D（4-胞） | 4-体積要素は擬スカラー | **ゼロ** |

**鍵となる事実**：**面積はスカラー量**であり、面の向きを反転しても面積は不変。一方、長さ・体積（有向な体積要素）は向きを反転すると符号が変わる。

したがって：

> **4 次元空間の振動モードのうち、等方平均下で α に寄与しうるのは 2D 面モードのみ。**

これは α の面積次元性（前節）と完全に整合します。これは Wilson 形式の「α は 2-form セクター（プラケット）に結合する」という標準的事実とも一致します。

## $\pi^2/2$ の物理的解釈：2D 面の位置位相空間

137 個の超立方体の 2D 面振動モードを完全に指定するには、以下が必要です：

- **位置**：4 次元球内のどこに 2D 面があるか
- **方向**：6 個の 2-平面方向（$\binom{4}{2} = 6$）のうちどれか
- **振幅**：振動の励起度

固定された方向と振幅に対して、2D 面の位置自由度を 4 次元単位球内で積分すると：

$$\int_{B_4(1)} dV = \frac{\pi^2}{2}$$

これは数値的に $V_4(1)$ と一致しますが、本稿の解釈では：

| 解釈 | $\pi^2/2$ の物理的意味 |
|---|---|
| 旧解釈（W7 論文） | 4 次元単位球の体積 $V_4(1)$ |
| **本稿の解釈** | **2D 面モードを 4D 単位球内に配置できる位置自由度の測度** |

両者は数値的に同一ですが、物理的意味は異なります。この解釈の下では、$\pi^2/2$ が α の係数として現れる**必然性**が明確になります：α が 2D 面モードに結合する以上、その位置位相空間体積が結合定数の幾何学的係数として現れる。

## W7 自己整合方程式の物理的解釈

$$\alpha^{-1} = 137 + \frac{\pi^2}{2}\alpha$$

の各項は、本稿の解釈下で次のように読めます：

| 項 | 数学的内容 | 物理的解釈（本稿） |
|---|---|---|
| **137** | 4D 球 $B_4(3)$ に内接する単位立方体充填数 | **全振動モードが基底状態の寄与**：4D $\mathbb{Z}^4$ 格子の整数論的事実 |
| **$\pi^2/2$** | $V_4(1)$、または 2D 面モード位置位相空間 | **2D 面モードを 4D 単位球内に配置できる位置自由度** |
| **α**（係数項の） | 結合定数 | **各 2D 面モードの励起振幅** |
| **$(\pi^2/2)\alpha$** | 0.036（数値的に） | **2D 面モードのゼロ点振動の集団的寄与** |

各 2D 面モードは調和振動子近似下でゼロ点エネルギー $\frac{1}{2}\hbar\omega$ を持ち、その集団的寄与が 0.036 ドリフトを生む、という構造です。

α が 2D 面モードの振幅であり、かつ 2D 面モードのゼロ点寄与が $\alpha^{-1}$ に補正を与えるという**自己整合性**から、

$$\frac{\pi^2}{2}\alpha^2 + 137\alpha - 1 = 0$$

が自然に導かれます。

## Wilson 格子ゲージ理論との同型性の物理的内容

| Wilson 格子ゲージ理論 | W7 自己整合（本稿の解釈） |

| 結合定数 $\beta = 1/g^2$ | $\alpha^{-1}$ |
| プラケット（2-form 構造） | 2D 面振動モード |

> **W7 自己整合方程式は、Wilson 格子ゲージ理論のプラケット作用構造の、4D 球幾何上での具体化である。**

として**物理的に位置付け**られます。

## Scope：本稿の射程と限界

本稿が扱うのは **$\alpha^{-1}(Q^2 \to 0) = 137.036$（Thomson 極限）のみ**です。

本稿は以下を扱いません：

- α の高エネルギー running（$\alpha^{-1}(M_Z) \approx 127.95$ への流れ）
- 標準モデルの lepton/quark ループによる真空偏極の幾何学的再導出
- 結合定数の統一（α と $\alpha_s$、$\alpha_w$ 等の関係）
- 重力との接続

α は標準モデルでエネルギースケール $Q^2$ に依存して走り、$\alpha^{-1}(0) = 137.036$ から $\alpha^{-1}(M_Z) \approx 127.95$ へ約 9.08 単位減少します。この running は標準 QED の精密測定で十分よく記述されており、本稿は競合しません。

本稿の幾何学的解釈は、α の**境界条件（$Q^2 = 0$ での値）**に物理的起源を与える立場をとります。階層的に：

| 階層 | 内容 | 担当 |
|---|---|---|
| 1 | 137（整数、幾何不変） | 論文 6 [BH6] |
| 2 | $(\pi^2/2)\alpha \approx 0.036$ | **本論文** |
| 3 | $\Delta\alpha_{SM}(Q^2)$ | 標準 QED 真空偏極 |

高エネルギー側（階層 3）の幾何学的再定式化、特に $\alpha^{-1}(M_Z) \approx 128$ の幾何学的導出は**将来課題**です。本稿の主張（Thomson 極限の幾何学的起源）は、running の機構が何であれ独立に成立します。

## 観測される α の不確定性

本稿の解釈には、興味深い帰結があります：

各 2D 面モードのゼロ点振動は標準量子論の不確定性原理から有限の分布幅を持ちます。したがって α の観測値には**理論的下限の幅**が存在することになります。

CODATA 値：$\alpha^{-1}(0) = 137.035999084(21)$

不確定性 $(21) \approx 2.1 \times 10^{-8}$ は実験精度ですが、本稿の理論的下限がこれよりさらに小さいかどうかは、モード固有振動数の今後の検討課題です。

本稿の解釈下では：

- α は「鋭い点」ではなく「分布の中心値」
- 観測される 8.7 ppb のずれ（W7）は、モード寄与の高次補正の余地
- 将来の精密測定で本稿の理論的下限が観測可能になる可能性
