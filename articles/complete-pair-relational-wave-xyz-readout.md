AB二体の一つの位相関係を、ABC三体とABCD四体の完全二体関係へ拡張し、関係の増加がXY・XYZ方向の読出しにどう現れるかを数値実験で調べました。

## AB二体問題からの拡張

これまでのAB二体閉鎖位相系では、位相差の関係は $AB$ の一つだけでした。位置読出しや加速度様読出しは、この一次元的な関係から構成されていました。

今回は、$N$体から得られる全二体関係

```math
\mathcal E_N
=
\bigl\{\{i,j\}\mid 1\le i<j\le N\bigr\}
```

のそれぞれに、一つの複素関係波 $X_e$ を対応させます。関係波数は、

```math
M
=
\lvert\mathcal E_N\rvert
=
\binom{N}{2}
```

です。したがって、ABは1波、ABCは3波、ABCDは6波を持ちます。CやDを観測器として使わず、すべての関係波を同格な物理状態の成分としました。

## 閉鎖を保つ更新

状態は、

```math
\sum_{e\in\mathcal E_N}X_e^2
=
R^2
```

を満たすように構成します。

端点を共有する二関係だけを、位相差の正弦から作る実反対称生成子 $K$ で結びます。更新にはCayley変換

```math
U
=
\left(I-\frac{K}{2}\right)^{-1}
\left(I+\frac{K}{2}\right)
```

を使いました。$K$ は実反対称なので $U$ は実直交行列となります。状態の逐次正規化、観測減衰、絶対背景軸は使っていません。

位相差の正弦結合則は、第0・第1公理だけから導出したものではなく、本数値実験の保存的な作業仮説です。

## 実験結果

AB、ABC、ABCDの各構成を32試行、各720ステップ更新しました。構成ごとの主要結果は次の通りです。

| 構成 | 関係波数 | 活動波数 | 生成子ランク | 零空間次元 | 回転平面数 |
|---|---:|---:|---:|---:|---:|
| AB | 1 | 0 | 0 | 1 | 0 |
| ABC | 3 | 3 | 2 | 1 | 1 |
| ABCD | 6 | 6 | 6 | 0 | 3 |

表の値は、各構成の32試行すべてで一致しました。

## ABCではXY平面とZ法線が生じる

ABCには $AB,BC,CA$ の三関係波があり、全試行で三波すべてが活動しました。

一方、生成子は、

```math
\operatorname{rank}K=2,
\qquad
\dim\ker K=1
```

でした。したがってABC関係空間は、

```math
\boxed{
\text{one rotation plane}
\oplus
\text{one invariant direction}
}
```

に分かれます。

三つの内部関係方向はXYZ三軸方向と読めますが、位相関係として実際に読み出されるのはランク2に対応するXY二軸です。残る一方向は、XY平面から定まる不変法線Zであり、独立した位相関係としては読み出されません。

## ABCDではXYZ三方向まで読み出せる

ABCDは六関係波を持ちます。全試行で、

```math
\operatorname{rank}K=6,
\qquad
\dim\ker K=0
```

となり、六方向は三つの回転平面へ分解されました。

六つの内部関係方向すべてを、独立した空間軸として読むことはできません。空間方向として一意に読めるのはXYZ三方向であり、残る三方向は一意に方向を定められません。

```math
\boxed{
\text{内部の関係方向は増加するが、}
\quad
\text{一意に読み出せる空間方向はXYZ三方向で止まる}
}
```

## 保存と名称置換共変性

全構成を通じた最大誤差は、

- 二乗閉鎖誤差: $1.92\times10^{-13}$
- 絶対値二乗和の変動: $2.42\times10^{-13}$
- 名称置換共変性誤差: $1.47\times10^{-13}$

でした。すべて判定許容差 $10^{-10}$ より小さい値です。

## この論文が主張する範囲

本論文が数値実験で直接確認したのは、AB、ABC、ABCDの三構成です。

その結果を基に、五体以上で関係数を増やしても、増えるのは一意に方向を定められない内部関係であり、空間方向として読める関係はXYZ三方向を超えないと解釈します。

残余方向が時間、曲率半径、その他の物理軸のどれに対応するかは、本稿では同定しません。
