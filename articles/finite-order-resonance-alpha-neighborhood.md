微細構造定数を説明できるのではないか。

それが、この数値実験を始めた明確な動機でした。

2026年7月15日の全域掃引では、`α⁻¹ ≈ 137` と `α⁻¹ ≈ 128` に対応する領域の近傍に、極めて鋭いピークが現れました。しかし、その位置にピークができる原因は分かっていませんでした。

今回、その原因を特定した続報を公開しました。

## 結論から言うと

我々が直接発見したのは、微細構造定数そのものではありませんでした。

ピークの正体は、二チャネル交換散乱作用素の**有限位数共鳴**でした。

一回の散乱を

```math
\begin{pmatrix}
A_{j+1}\\
B_{j+1}
\end{pmatrix}
=
U_R
\begin{pmatrix}
A_j\\
B_j
\end{pmatrix},
\qquad
U_R=
\begin{pmatrix}
r&t\\
t&r
\end{pmatrix}
```

とします。

この作用素の対称固有値と反対称固有値は、

```math
\lambda_s=1,
\qquad
\lambda_a=-e^{2i\arcsin\sqrt R}
```

です。

反対称固有値が有限回で1へ戻る条件から、ピーク位置は厳密に

```math
R_{n,m}
=
\cos^2\left(\frac{\pi m}{n}\right)
```

と求まります。

このとき、

```math
U_{R_{n,m}}^n=I
```

となり、どの初期状態から始めても作用素自体が有限回で元へ戻ります。

## 全域掃引で見つけていた二つの根

低エネルギー側の主ピークは、

```math
R_{124,23}
=
\cos^2\left(\frac{23\pi}{124}\right)
=
0.697177927556659290\ldots
```

でした。

これを当初の対応仮説

```math
N(R)=\frac{4\pi}{(1-R)^2}
```

で読むと、

```math
N(R_{124,23})
=
137.036042914598545\ldots
```

となります。

一方、全域掃引の第二主ピークは、

```math
R_{122,23}
=
0.688363946817592550\ldots
```

という別の有限位数根でした。

## 高エネルギー観測値の近傍にも偶数根がある

高エネルギー側の観測値

```math
\alpha^{-1}(M_Z^2)=128.946\pm0.015
```

の近傍を調べると、

```math
R_{620,117}
=
\cos^2\left(\frac{117\pi}{620}\right)
```

があり、

```math
N(R_{620,117})
=
128.947864735670559\ldots
```

を与えました。

観測値との差は `0.0018647`、引用した不確かさに対して `0.1243σ` です。

前回の計算窓は最大1024ステップでした。しかし、この620周期根を二完全周期で読むには1240サンプルが必要です。そのため、この根は以前の時間窓では完全なピークとして見えていませんでした。

## なぜピークが無限に鋭くなるのか

現在の評価量は、時間列の平均、振幅、前半後半のドリフトを合わせた `gray error` です。

偶数基本位数根で二完全周期を読むと、理想演算では

```math
\overline S=0,
\qquad
A=0.02,
\qquad
D=0
```

となります。

したがって、

```math
\varepsilon=0,
\qquad
d=-\log_{10}\varepsilon\to+\infty
```

です。

ここで発散するのはエネルギーではありません。評価残差が0になるため、ピークの深度が無限大になるという意味です。計算精度を上げるほど、ピークは高く、狭くなります。

実際に、50桁演算では深度約52、80桁演算では深度82から83が得られました。

## コードに137や128を隠していないか

この点は、もっとも重要な監査項目です。

散乱振幅を作る中核コードの入力は `R` だけです。

```python
delta_f = 2.0 * math.asin(math.sqrt(reflection_rate))
half_delta = 0.5 * delta_f
phase = complex(math.cos(half_delta), math.sin(half_delta))

t = phase * math.cos(half_delta)
r = -1j * phase * math.sin(half_delta)
```

時間発展は、

```python
a, b = normalize_pair(
    r * a + t * b,
    t * a + r * b,
)
```

を反復しているだけです。

全域掃引では、最小値・最大値・刻みから等間隔の `R` を生成し、全点へ同じ評価関数を適用しました。その評価式には、`α`、137、128、有限位数根のいずれも含まれていません。

解析根を直接計算するコードは、全域掃引でピークを発見した後、その正体を確認するために追加したものです。

## 倍音が必要なのに、倍音条件へ鈍感だった理由

波束内部の倍音自由度を `H` とすると、同じ交換則が各内部成分へ作用する範囲では、全作用素は

```math
U_R^{\mathrm{total}}=U_R\otimes I_H
```

と書けます。

倍音の種類、振幅、位相、波長は内部状態を変えます。しかし、二チャネル交換部分の固有値は変えません。

したがって、倍音は根を作っていたのではありません。反対称固有位相を局在性や配分差の読出しへ結合し、共鳴を見えるようにしていました。

これにより、倍音が一つ以上必要なのに、倍音の具体的構成や初期値が大きく変わってもピーク位置が動かなかった理由を説明できます。

## 発見後に先行研究との接点へ気づいた

有限位数根を同定した後に文献を調べ、円分固有値による初期状態非依存のFloquet厳密再帰、Farey列による共鳴配置、E8の31個の8次元直交分解との接点に気づきました。

順序は重要です。

これらの理論を先にコードへ入れてピークを作ったのではありません。波束の局在性移乗と灰色準安定界面を調べる数値モデルが先にあり、全域掃引でピークを発見し、その後に作用素根と先行研究へ接続しました。

特に低エネルギー側では、

```math
31\times4=124,
\qquad
124\times2=248
```

という時間構造が現れます。

ただし、これをE8の31個の8次元部分空間へ送る具体的写像はまだ構成していません。現時点では構造仮説です。

## 何が未解決なのか

我々は、閉鎖交換系によって微細構造定数を説明できると期待して探索を始めました。

しかし、今回直接特定したのは、微細構造定数そのものではなく、一般的な厳密再帰理論へ接続する別の有限位数共鳴現象でした。

それでも、その極めて鋭いピークは、低エネルギーと高エネルギーの二つの物理的 `α⁻¹` の近傍に実際に存在します。

なぜでしょうか。

有限位数根が数論的に稠密であるために起きた偶然なのか。

それとも、4次元離散幾何、E8型対称性、交換散乱の選択則、あるいはまだ特定していない別の構造が要求する必然なのか。
