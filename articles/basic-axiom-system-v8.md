v8 の変更は0層（第一原理層）の再編です。公理の本文はどれも変えていません。変えたのは構成と、一本の公理の追加です。

## 公理0の統合

v7 まで別立てだった公理0（成分無名性）と公理0+（定式化無名性）を、単一の公理0（無名性）の条項1・条項2として統合しました。成分に名前を与えない、定式化にも名前を与えない——もともと一つの思想の二つの側面だったものを、形式の上でも一つにしました。

## 公理0.5: スケール無名性（新規取り込み）

第5論文（自発的分裂）で導入したスケール無名性を、0層へ正式に取り込みました。

系の関係・更新則・読出しは、いかなる絶対スケールも参照してはならない。すべての構成は Z → λZ（λ は非零複素数）のもとで共変でなければならない。関係は同次、生成子は零次同次、読出しは比率量のみ。系の内部から絶対スケールを測る手段は存在しない。

これは公理0と同格の証明不能な形成規則です。名前も無い、スケールも無い——読めるのは関係と比率だけ、という単一の思想の条項です。共変性群の |λ|=1 部分は共通位相の不可読性（公理5）に対応し、位相とスケールの読出し不能性は同じ一つの群の偏角部分と絶対値部分になります。

そして公理1の右辺の零は、族 Σx² = c の中でこの公理と両立する唯一の選択です。「なぜ = 0 なのか」に、スケール無名性が選択の余地なしという形で答えます。

なお、v7 までの公理0.5（次元別中心投影読出し）は公理0.6 へ改番しました（本文の変更なし）。公理番号でこれを引用している外部論文はなく、公開済みの第5・第6論文は「公理0.5＝スケール無名性」で書かれているため、この改番で全文書の番号が一貫します。

## 公理1に理論背景を追記

公理1（全正符号ゼロ閉鎖）に、幾何学的な理論背景への参照を追加しました。

閉鎖 Σx² = 0 の解集合は複素等方錐であり、非自明解には虚部が必須。公理0.5による射影化のもとで状態空間は射影クアドリック（コンパクトなケーラー多様体）になり、コンパクト性により離散スペクトルと有限次元状態空間が幾何から従う——量子性は追加の仮説ではなく、二つの公理から自動的に従う構造です。

この同定は、既知数学の引用だけで書いた独立の解説ノートにまとめてあります。

https://zenn.dev/noriaki_kihara/articles/zero-square-sum-geometric-identity

さらに x = q + ip と分解すると、公理1の虚部は「スケール変換の生成子（ディラテーション）が零」という条件そのものであり、スケール自由度の消去が閉鎖に内蔵されていることも同ノートに整理しています。公理0.5と公理1の関係は、見かけより深いかもしれません。

## まとめ

v8 の0層は、公理0（無名性：成分・定式化）→ 公理0.5（スケール無名性）→ 公理0.6（次元別中心投影読出し）→ 公理1（全正符号ゼロ閉鎖）という並びになりました。「読めるのは関係と比率だけ」という形成規則群が先にあり、その中で唯一許される二次閉鎖として Σx² = 0 が立つ、という論理順です。
