
## 何を置き換えたか

前回のシミュレーションでは、有限解像度相互作用セルに入ったとき、進行方向読出し量 `q_A,q_B` を反転する規則を置いていました。

今回の実験では、直接の `q` 反転命令を使いません。

かわりに、二つの経路を明示的に作ります。

```math
P_A(1)P_B(2)
```

という直接経路と、

```math
P_A(2)P_B(1)
```

という交換経路です。

この交換経路へ、内部逆相核の位相差 `Δ_F` を転写します。

```math
\Psi_{\Delta}(1,2)
=
\frac{1}{\sqrt2}
\left[
P_A(1)P_B(2)
+
e^{i\Delta_F}P_A(2)P_B(1)
\right]
```

`Δ_F=π` のとき、完全重なり点では

```math
1+e^{i\pi}=0
```

となり、直接経路と交換経路が完全に干渉消去されます。

## 今回の一番大事な確認

今回は、最初から奇関数波を置いたわけではありません。

左側だけに単一局在波束を置きました。初期右側確率は

```text
2.4303500961591473e-89
```

です。つまり、反射波や鏡像成分は初期状態に埋め込まれていません。

その波束を自由伝播させ、相互作用窓に入ったところで、偶・奇チャンネルに分解し、奇チャンネルへ内部核位相 `Δ_F` を転写して再合成しました。

結果は次です。

| `Δ_F` | 反射率 `R` | 通過率 `T` |
|---:|---:|---:|
| `0` | `1.8261693781071190e-19` | `1.0000000000000002` |
| `π/2` | `0.5` | `0.5` |
| `π` | `1.0000000000000002` | `1.7939211291143336e-19` |

位相掃引全体で、

```math
R(\Delta_F)=\sin^2\frac{\Delta_F}{2}
```

```math
T(\Delta_F)=\cos^2\frac{\Delta_F}{2}
```

が最大誤差 `5.55e-16` で成立しました。

## 保存性も確認した

局所交換干渉写像は、単に反射らしい見た目を作っただけではありません。

次も確認しています。

- 外部 `q=-q` 命令なし
- 鏡像初期条件なし
- 反射境界条件なし
- `U(π)^2≈I`
- `U(Δ_F)U(-Δ_F)≈I`
- ノルム保存
- 補償付き二乗閉鎖保存
- 識別振動 `m_A=1`, `m_B=2` の保存

特に、前回の AB/C 完全弾性衝突シミュレーションのセル内 `q` 反転を、

```text
q_out = q_in * (T - R)
```

へ差し替える統合テストも行いました。

`Δ_F=π` では `R≃1, T≃0` なので、

```text
q_A:  1 -> -1
q_B: -1 ->  1
```

が、直接代入ではなく、交換干渉写像の読出しとして生成されました。

## 今回の到達点

前回は、完全弾性反射を含む実行フレームワークを作りました。

今回は、その反射演算そのものを、

```text
内部逆相核
→ 交換経路への位相転写
→ 偶奇チャンネル干渉
→ R=1, T=0
→ 方向反転
```

という形に置き換えました。

つまり、方向反転はもう外部命令ではなく、内部位相により選択された干渉結果として読めます。

## 主張しないこと

この論文は、標準的なフェルミ粒子散乱やS行列散乱理論を導出するものではありません。

また、今回は連続ハミルトニアンを細かい時間刻みで積分したものではなく、相互作用窓内で一度作用する局所写像方式です。

確認したのは、前回の人工的な方向反転規則を、保存的・可逆的・位相選択的な局所交換干渉写像へ置換できることです。
