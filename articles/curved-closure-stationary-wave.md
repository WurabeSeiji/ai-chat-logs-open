今回の追加論文では、全正符号ゼロ閉鎖

```math
\sum_n x_n^2=0
```

を満たす奇数倍音の複素波が、曲率付き局所セルに置かれたとき、曲率由来の相対位相漏れをどう扱うかを数値構成しました。

## 何を調べたか

前稿では、フェルミオン的内部逆相核から局所交換干渉写像を構成し、外部の

```text
q -> -q
```

命令を使わずに完全反射読出しを得ました。

今回の問いは、その完全反射写像を曲率付き局所セルに置いたとき、曲率相対位相漏れで反射が破れるのか、また閉鎖定常波への再選別で回復するのかです。

## 曲率は最初から無視しない

本稿では、曲率の影響を「無視できる」とは置きません。

曲率由来の相対位相漏れを

```math
\delta_{K,m}
```

として入れます。

閉鎖ペア

```math
x_m,\quad ix_m
```

にこの漏れが入ると、

```math
x_m^2+\left(e^{i\delta_{K,m}}ix_m\right)^2
=
x_m^2\left(1-e^{i2\delta_{K,m}}\right)
```

となり、一般に閉鎖残差が出ます。

つまり、曲率の影響は存在しないのではなく、過渡状態では検出されます。

## 閉鎖定常波への再選別

内部位相再選別

```math
\beta_{K,m}
```

が

```math
\delta_{K,m}+\beta_{K,m}=0
```

を満たすと、閉鎖条件は回復します。

このとき、曲率相対位相漏れは消えたのではありません。安定に存在できる閉鎖定常波の内部位相構成へ吸収されています。

## 数値結果

最小実験では、曲率相対位相漏れを受けた過渡状態で、

| 状態 | 閉鎖ペア RMS | 通過漏れ |
|---|---:|---:|
| transient | `1.2319416790092972e-02` | `1.1503183254481797e-01` |
| stationary | `9.4283259783636047e-19` | `0.0` |

となりました。

さらに8種類の曲率相対位相モデルと7種類の補正自由度を掃引しました。

最大曲率相対位相 `1.2` に対し、無補正では最大通過漏れ

```text
1.6202719613622976e-01
```

が残りました。

一方、full 補正では、

```text
閉鎖ペア RMS: 7.8949412793793227e-19
通過漏れ: 0.0
```

まで回復しました。

## 完全反射との接続

片側入射の局所交換干渉写像へ、残留曲率位相を戻す統合検証も行いました。

無補正では最大動的通過漏れ

```text
1.6202719613622971e-01
```

が出ました。

full 補正では、

```text
1.6608667989341789e-19
```

まで低下しました。

動的散乱は二チャンネル期待式と最大誤差 `5.55e-17` で一致し、ノルム最大誤差は `4.44e-16` でした。

## 今回の到達点

今回の結論は、曲率がない、ということではありません。

曲率は過渡状態では閉鎖残差と通過漏れとして現れます。

ただし、系が

```math
\sum_n x_n^2=0
```

を満たす閉鎖定常波へ再選別されると、曲率相対位相漏れは内部位相へ繰り込まれ、完全反射読出しが回復します。

したがって、この公理は単なる保存条件ではなく、曲率相対位相漏れの検出条件、閉鎖定常波への再選別条件、完全反射読出しの安定条件として働きます。
