ABC閉鎖位相系における、独立計量Cと関係性補償分解による距離指数読出し予備実験総括を公開しました。

## AB二体で残った問い

AB二体実験では、関係性 `f_AB` だけで加速度様の調和読出しが可能であることを確認しました。

しかし、AB二体だけでは測定機自身が系の中に乗っているため、その加速度様読出しが距離に対して比例なのか、逆比例なのか、逆二乗なのかを独立に判定できませんでした。

そこで本実験では、第三波 `C` を導入し、AB距離指数を読む独立計量ゲージになれるかを検査しました。

## Cは外部観測器ではない

ここで重要なのは、`C` は外部から置いた絶対ゲージではないことです。

`C` も同じ閉鎖位相系の一部なので、Cを置くと同時に

```text
f_AC
f_BC
f_ABC
```

も発生します。

したがって、単にCを足せば解ける、という問題ではありません。

## 結果

Cゲージには有効窓がありました。

`R_C` が小さすぎると、Cの波長が長くなり、位置変化量を読むセル分解能が足りません。

一方で `R_C` が大きすぎる、またはC配置が偏ると、`f_AC` や `f_BC` の汚染が増えます。

その有効窓の中で読めた距離指数は主に

```text
alpha ≈ -1
```

でした。

本実験では

```text
I_AB(L) ∝ L^{-alpha}
```

として分類しているので、これは

```text
I_AB(L) ∝ L
```

すなわち比例型を意味します。

逆比例型、逆二乗型は native には検出されませんでした。

## 関係性分解

ABC三体系では、少なくとも次の関係性を分けて考える必要があります。

```text
f_AB
f_AC
f_BC
f_ABC
```

本実験では、`f_ABC` を代表時間 `tau_ABC` として使い、AB円周方向には直接足さない方が読出し分類が濁らないことも確認しました。

## 何が分かったか

今回否定されたのは、

```text
現在の一次元的AB調和モデルにCゲージを足せば、
nativeに逆比例または逆二乗が出る。
```

という狭い主張です。

逆二乗一般を否定したわけではありません。

むしろ、現在のモデルは局在した二波による一次元的な相対位相調和モデルとして振る舞っており、その単純延長では逆二乗は出ない、という境界が明確になりました。

次に問うべきは、広がった波を直接仮定することではなく、局在波の多数回観測、初期揺らぎ、そしてその揺らぎの観測側への押し出しが、統計的な面積広がりとして見えるかどうかです。
