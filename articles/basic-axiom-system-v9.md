## v9で追加したもの

v9では、公理0.6と公理1の間に、次の公理を追加しました。

```text
公理0.7: 無名部分投射存在
```

既存の公理0、0.5、0.6、1–17および作業公理の番号と本文は変更していません。

この配置には理由があります。今回必要になったのは、$E_8$という対称群を公理として導入することではなく、基礎公理が許す候補空間と、実際に物理的に実現される状態空間を区別する一般原理だからです。

## 候補空間

公理0.5のスケール無名性により、絶対スケールだけが異なる状態は同じ候補とします。

```math
X\sim_{\mathrm{sc}}\lambda X,
\qquad
\lambda\in\mathbb C^\ast
```

公理0.7以外の採用された必須公理を満たす非自明候補系を、このスケール同値関係で同一視した集合を、

```math
\mathscr S_{\mathrm{ax}}
```

と書きます。

作業公理や追加条件を採用する分枝では、それらを満たす部分集合が、その分枝の候補空間になります。

## 部分投射

候補空間の部分集合

```math
\mathscr D_{\mathcal P}
\subseteq
\mathscr S_{\mathrm{ax}}
```

と写像

```math
p_{\mathcal P}:
\mathscr D_{\mathcal P}
\longrightarrow
\mathscr Y_{\mathcal P}
```

の組

```math
\mathcal P
=
\left(
\mathscr D_{\mathcal P},
p_{\mathcal P}
\right)
```

を部分投射と呼びます。

ここでいう部分投射は、線形代数の直交射影だけではありません。次の三つを含み得ます。

- 候補の一部だけを定義域として残す選択
- 読出し不能な差異を同一視する商
- 読出し可能な関係量を表示空間へ送る写像

部分投射は、候補空間の真部分集合だけを残すか、異なる二状態を同じ像へ送るとき非自明です。

## 許容条件

非自明な部分投射が次の条件をすべて満たすとき、許容部分投射と呼びます。

- 成分または定式化の個別名に依存しない
- 絶対スケールに依存しない
- 基礎閉鎖および投射像の合成則に整合する
- 同一視された二状態は、採用された読出し量だけからは区別できない
- 投射後にのみ得られる物理名や対称群名を投射条件に用いない

許容部分投射全体を

```math
\mathfrak P(\mathscr S_{\mathrm{ax}})
```

と書きます。

## 公理0.7

公理の中心式は、

```math
\boxed{
\exists\mathcal P_*
\in
\mathfrak P(\mathscr S_{\mathrm{ax}})
\quad\text{such that}\quad
\mathscr S_{\mathrm{phys}}
=
\operatorname{Im}\mathcal P_*
}
```

です。

物理的に実現される状態空間は、基礎公理が許すすべての候補そのものではなく、少なくとも一つの非自明な許容部分投射の像である、と置きます。

ただし、この公理は次を主張しません。

```text
許容部分投射が一意である
実際の部分投射を選ぶ汎関数または力学が得られている
基礎公理だけから特定の対称群が一意に強制される
```

したがって、これは選択結果を先に指定する公理ではなく、候補空間と物理的実現空間の間に、無名な選択層が存在することを規定するメタ選択公理です。

## 対称性は投射後に同定する

選択像における読出し可能な遷移差集合を

```math
\Delta_{\mathcal P_*}
```

とすると、物理的対称性は、選択像の読出し関係、遷移差集合および合成則を保存する自己同型群として定義されます。

```math
G_{\mathrm{phys}}
:=
\operatorname{Aut}
\left(
\operatorname{Im}\mathcal P_*,
\Delta_{\mathcal P_*}
\right)
```

論理順序は次のようになります。

```text
基礎公理
→ 候補空間
→ 無名な許容部分投射
→ 物理的部分像
→ 像の対称性の事後同定
```

## $E_8$との関係

$E_8$、八成分性、二クァルテット構造、240根、248次元、位数30は、公理0.7には含めていません。

独立論文では、公理0.7の一般枠組みに加えて、

```text
正定値八成分読出し
二クァルテット分解
局所 D4 遷移格子
共通中心中性射影
```

を分枝条件としたとき、対角接着類

```math
(0,0),\qquad(v,v),\qquad(s,s),\qquad(c,c)
```

だけが残り、得られる遷移格子が$E_8$格子と同型になることを条件付きで示しています。

- 独立論文 Concept DOI: https://doi.org/10.5281/zenodo.21521899
- 紹介記事: https://zenn.dev/noriaki_kihara/articles/anonymous-partial-projection-e8

ここで固定したのは、

```text
E8を選ぶ公理
```

ではなく、

```text
無名な部分投射が選んだ像を、投射後に分類する
```

という順序です。

未解決なのは、実際の物理系がどの許容部分投射を選ぶかを決める汎関数または力学です。$E_8$分枝については、八成分性、局所$D_4$構造、二つのクァルテットへの共通中心作用を、同じ無名な選択則から導くことが次の接続課題になります。
