二チャネルの交換を有限回反復すると、どの交換重みで初期状態へ完全に戻るのか。

この問いを解析した結果、交換対称なユニタリ作用素の有限位数閉包から

```math
R_{n,m}=\cos^2\left(\frac{\pi m}{n}\right)
```

という離散的なBorn型重み系列が得られました。論文を公開しました。

- Concept DOI: https://doi.org/10.5281/zenodo.21422470
- Version DOI: https://doi.org/10.5281/zenodo.21422471
- GitHub: https://github.com/WurabeSeiji/ai-chat-logs-open

## 発見の順序

この研究は、Born則や `cos²` 則を再現する目的で始めたものではありません。

出発点は二つの数値モデルでした。

1. 波束の局在性と倍音構造が二チャネル間を移乗し、収縮に見える局在化が起きるかを調べるモデル
2. 白猫・黒猫というA/B二状態、その中間の灰色準安定状態、弱読出し、強観測選択を調べるモデル

異なる目的で作った両モデルが、正規化や観測反作用を加える前には、同じ線形交換核

```math
U=
\begin{pmatrix}
r&t\\
t&r
\end{pmatrix}
```

を共有していました。

パラメータ全域を掃引したときに非常に鋭いピークが見つかり、その原因を後から調べると、作用素の有限位数回帰でした。つまり、Born型重みを評価関数に入れて探したのではありません。

## 三角関数を仮定せずに導く

A/B交換作用素を

```math
X=
\begin{pmatrix}
0&1\\
1&0
\end{pmatrix}
```

とします。交換対称性は

```math
[U,X]=0
```

です。

対称・反対称射影を

```math
P_s=\frac{I+X}{2},
\qquad
P_a=\frac{I-X}{2}
```

とすると、交換対称な二チャネルユニタリ作用素は、全体位相を固定した後に

```math
U=P_s+\zeta P_a,
\qquad |\zeta|=1
```

と書けます。

A/B基底へ戻せば

```math
U=
\frac12
\begin{pmatrix}
1+\zeta&1-\zeta\\
1-\zeta&1+\zeta
\end{pmatrix},
```

したがって

```math
r=\frac{1+\zeta}{2},
\qquad
t=\frac{1-\zeta}{2}
```

です。

ここまで、`sin` や `cos` を散乱振幅の独立仮定として置いていません。

## 有限位数条件が離散位相を選ぶ

完全再帰条件を

```math
U^n=I
```

とします。射影作用素は互いに直交するため、これは

```math
\zeta^n=1
```

と同値です。

非自明な基本位数を `n`、`n` と互いに素な整数を `m` とすると、

```math
\zeta=e^{-2\pi i m/n}.
```

これをチャネル振幅へ戻すと、A基底入力からA/Bへ出る遷移重みは

```math
\left|\frac{1+\zeta}{2}\right|^2
=
\cos^2\left(\frac{\pi m}{n}\right),
```

```math
\left|\frac{1-\zeta}{2}\right|^2
=
\sin^2\left(\frac{\pi m}{n}\right)
```

となります。

つまり論理の順序は、

```text
交換対称性
→ 対称・反対称固有位相
→ 有限位数閉包
→ 円分位相 m/n
→ 離散Born型チャネル重み
```

です。

## 標準Born則と何が同じで、何が違うか

A基底入力に一回作用させると、

```math
U_{n,m}|A\rangle
=
r_{n,m}|A\rangle+t_{n,m}|B\rangle.
```

同じA/B基底へ射影して絶対値を二乗する操作は、標準二状態Born則と同じ数学的操作です。

しかし、本論文はBorn則全体を導出したとは主張しません。

導出したのは、**完全再帰を許す位相と、その位相をA/B基底へ戻した離散的な二乗重み**です。

まだ導出していないものは明確です。

- 単一試行で確率的結果が発生する機構
- 多数回試行の頻度が二乗重みへ収束する法則
- 一般次元の射影測度
- 現実の観測不可逆性

したがって、正確な結論は「Born則を導出した」ではなく、**有限位数回帰から離散Born型重みが出現した**です。

## 数値ピークとの一致

前報で見つかった二つの主ピークは、

```math
R_{124,23}=0.697177927556659\ldots,
```

```math
R_{122,23}=0.688363946817593\ldots
```

という有限位数根でした。

どちらも基本位数が偶数で `m=23` が奇数です。二完全周期を標本化すると、現在のgray metricでは平均0、目標振幅一致、前半後半ドリフト0が厳密に成立します。そのため理想演算では誤差が0となり、

```math
d=-\log_{10}\varepsilon\to+\infty
```

という無限深ピークになります。発散するのはエネルギーではなく、ゼロ残差の逆対数です。

## 共通線形核と後段写像を分ける

有限位数根を作るのは共通線形核 `U` です。

一方、観測された現象には別の後段写像が加わります。

- System A: 線形交換後に各チャネルを別々に正規化する
- System Bの弱読出し: 軌道をなるべく保持して配分差を読む
- System Bの強観測: 非線形反作用でA/Bどちらかへ押し出す

したがって、再帰根、収縮に見える局在性表示、弱読出し、強観測選択を一つの作用の効果として混同していません。同じ核へ異なる後段写像を接続した構造です。

## 次の検証

本論文が示した成立条件は、

```text
交換対称ユニタリ核
+ 円分有限位数閉包
+ A/Bチャネル射影
→ 離散Born型二乗重み
```

です。

次に必要なのは、交換対称性を破る一般 `U(2)` 制御実験、ノイズ下での根の頑健性、測定頻度則、そしてチャネル別正規化を含む全非線形写像の監査です。
