## この論文が解こうとした問題

基礎公理が複数の閉鎖系を許すなら、観測される物理的対称性を、公理の全解空間の対称性と同一視する必要はありません。

そこで本論文では、物理的状態空間を、候補空間全体ではなく、そこから選択された部分投射像として定義しました。

```math
\boxed{
\exists\mathcal P_*\in\mathfrak P(\mathscr S)
\quad\text{such that}\quad
\mathscr S_{\mathrm{phys}}
=
\operatorname{Im}\mathcal P_*
}
```

$\mathscr S$ は基礎公理が許す候補空間、$\mathfrak P(\mathscr S)$ は次を満たす非自明な部分投射の集合です。

- 成分の個別名に依存しない
- 絶対スケールに依存しない
- 基礎閉鎖と投射後の合成則に整合する
- 同一視された状態は採用した読出しだけでは区別できない
- 投射後に得られる物理名や対称群名を選択条件へ先回りして入れない

この公理は、どの対称群を選ぶかを指定しません。物理的対称性は、選択像に残った関係を保存する自己同型群として、投射後に同定します。

## $E_8$ が現れる分枝

一般公理の後に、次の分枝条件を置きます。

1. 遷移差の読出し空間が正定値八次元である
2. 八成分が二つの四成分系へ直交分解される
3. 各四成分系の局所遷移格子が $D_4$ 型である
4. 二つの $D_4$ 判別群に同一の中心が作用する
5. 共通中心に対する中性成分だけが読出し像に残る

$D_4$ の判別群は、

```math
\mathcal A
=
D_4^*/D_4
\cong
(\mathbb Z/2\mathbb Z)^2
=
\{0,v,s,c\}
```

です。二つの四成分系の判別類を $(a,b)$ とし、共通中心中性射影を

```math
\Pi_{\mathrm{com}}(a,b)
:=
\frac{1}{|\mathcal A|}
\sum_{z\in\mathcal A}
\chi_a(z)\chi_b(z)
```

とすると、指標の直交関係から、

```math
\Pi_{\mathrm{com}}(a,b)
=
\delta_{a+b,0}
```

を得ます。

$\mathcal A$ の各元は $-a=a$ を満たすため、中性条件を通過するのは、

```math
\boxed{
(0,0),\quad
(v,v),\quad
(s,s),\quad
(c,c)
}
```

だけです。これが二つのクァルテットを結ぶ対角接着になります。

## 偶・自己双対八次元格子

接着前の格子は、

```math
L_0=D_4\oplus D_4
```

で、行列式は $16$ です。対角接着群の位数は4なので、接着後の格子 $\Lambda$ は、

```math
\det\Lambda
=
\frac{\det L_0}{[\Lambda:L_0]^2}
=
\frac{16}{4^2}
=1
```

となります。

また、$D_4$ の非零判別類は、

```math
q(v)=q(s)=q(c)=1
\pmod{2\mathbb Z}
```

を満たします。対角類では、

```math
(q\oplus q)(a,a)
=
1+1
=0
\pmod{2\mathbb Z}
```

となるため、接着後の格子は偶格子です。

したがって $\Lambda$ は、正定値・八次元・偶・ユニモジュラー格子です。八次元ではこの格子は同型を除いて一意なので、

```math
\boxed{
\Lambda\cong\Lambda_{E_8}
}
```

と同定されます。

## 240、248、30

$D_4\oplus D_4$ 内部のノルム2ベクトルは $24+24=48$ 本です。三つの非零対角接着類は、それぞれ $8\times8=64$ 本を与えます。

```math
\boxed{
48+3\times64=240
}
```

よって根の本数は240本です。Cartan 部分のランク8を加えると、

```math
\boxed{
\dim\mathfrak e_8
=
8+240
=248
}
```

となります。

さらに $E_8$ の Coxeter 元 $C$ は、

```math
\boxed{
C^{30}=I
}
```

を満たし、240根は長さ30の八軌道に分かれます。

## 何を証明していないか

本論文は、

```math
\sum_jx_j^2=0
\quad\Longrightarrow\quad
E_8
```

という無条件導出を主張していません。

正確な主張は、

```text
無名部分投射存在公理
＋ 正定値八成分
＋ 二クァルテット
＋ 局所 D4
＋ 共通中心中性射影
→ E8 格子
```

です。

未解決なのは、実際の物理系がなぜこの分枝を選ぶかです。特に、八成分性、局所 $D_4$ 構造、二つのクァルテットへの共通中心作用を、同じ無名な選択則から導く必要があります。

また、$E_8$ 内に位数30の Coxeter 元が存在することと、物理的発展作用素 $U$ をその元と同一視することは別です。$U$ と Coxeter 軌道を結ぶ作用素レベルの対応写像は、今後の接続課題です。

## 基本公理系へ何を加えるか

基本公理系の次版へ加える候補は、$E_8$ という対称群名ではありません。

加えるのは、

```math
\mathscr S_{\mathrm{phys}}
=
\operatorname{Im}\mathcal P_*,
\qquad
\mathcal P_*
\in
\mathfrak P(\mathscr S)
```

という一般的な無名部分投射存在公理です。

$E_8$、240、248、30は、公理へ埋め込む値ではなく、追加分枝条件を満たす像を分類した結果として独立論文側に残します。

今回固定した順序は、

```text
基礎公理
→ 複数の許容閉鎖系
→ 無名な許容部分投射
→ 物理的部分像
→ 像の対称性の同定
```

です。

つまり、$E_8$ を都合よく選んだのではなく、無名な部分投射が選んだ像を分類した結果が $E_8$ だった、という構成です。
