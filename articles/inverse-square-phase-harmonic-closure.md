## 前回までに分かっていたこと

既公開のAB二体実験では、標準的なばね式、重力式、クーロン式、背景座標を置かず、ラベルなし二体関係 $f_{AB}$ だけから、相対位置位相に非零の二階差分が現れました。

公開データを再計算すると、4種類の初期偏差と2種類のプロトコルの全8条件で、

```math
\Delta^2\chi_s
=-\omega_d^2\chi_s
```

が成立します。

周期96ステップに対する離散係数は、

```math
\omega_d^2
=4\sin^2\left(\frac{\pi}{96}\right)
=0.0042821535227929855
```

です。回帰傾きは理論値と一致し、閉鎖残差 $Q_{\mathrm{closed}}$ は全条件でゼロでした。

つまり、加速度様の二階構造そのものは、すでに数値実験に存在していました。

## なぜ前回は逆二乗にならなかったのか

前回変えていたのは、初期位置位相偏差 $\delta$、すなわち振幅でした。一方、調和周期と角速度は固定していました。

そのため、nativeな加速度様読出しは、

```math
f_{AB}^{\mathrm{native}}
=\omega_d^2\max|\chi|
\propto\delta
```

となり、比例型になります。

面積の逆数を後処理すれば $1/\delta^2$ は作れます。しかし、それはnativeな読出しではありません。

前回の結果が誤っていたのではなく、振幅を変えながら角速度を固定した実験だったため、比例型が得られていました。

## 今回見直した量

今回、距離に対応する量を振幅ではなく、閉じた位相円の一セル幅として読みます。

非零整数倍音 $n$ に対して、

```math
\Delta\theta_n
=\frac{2\pi}{|n|}
```

です。

同じ倍音は、角速度も同時に

```math
\omega_n=n\omega_1
```

と定めます。

したがって、位相セル幅と角速度は独立なパラメータではありません。

```math
|\omega_n|\Delta\theta_n
=2\pi\omega_1
\equiv\Omega
```

より、

```math
|\omega_n|
=\frac{\Omega}{\Delta\theta_n}
```

となります。

これは外部から置いた逆数則ではありません。同じ閉鎖整数 $n$ が、セル数と倍音角速度の両方を定めるために生じます。

## 未来位相位置を中心とする加速度写像

円周上の現在位置から見た未来位相位置を、関係的な回転中心として読みます。

関係的な曲率半径を $R$、角速度を $\omega$ とすると、円周進行方向に読まれる加速度の大きさは、

```math
\alpha=R\omega^2
```

です。

ここで新しい力を追加しているのではありません。既公開AB実験で中心方向の閉鎖補償として表示されていた同じ $f_{AB}$ を、未来位相位置を基準とする進行方向へ写しています。

## 逆二乗則

加速度写像

```math
\alpha_n=R|\omega_n|^2
```

へ、調和閉鎖

```math
|\omega_n|
=\frac{\Omega}{\Delta\theta_n}
```

を接続すると、

```math
\boxed{
\alpha_n
=\frac{R\Omega^2}{\Delta\theta_n^2}
}
```

を得ます。

対数微分は、

```math
\frac{d\log\alpha_n}
{d\log\Delta\theta_n}
=-2
```

です。

したがって、特定条件で実行した本実験では、逆二乗則が成立しました。

この逆二乗は、球殻面積への流束希釈を仮定して得たものではありません。

```text
加速度は角速度の二乗
角速度は閉じた位相セル幅の逆数
```

という二つの関係を接続した結果です。

## 導入していないもの

今回の導出では、次を導入していません。

- 外部入力としての $1/L^2$
- 面積の逆数による後処理
- 球殻上の強度希釈
- 三次元背景空間
- 質量源
- 重力定数
- 重力場

この論文は重力を導出する論文ではありません。

示したのは、背景座標を先に置かない閉鎖位相系で、既存の加速度様二階構造と調和閉鎖を接続すると、位相セル幅に対する逆二乗則が現れる機構です。

## 成立範囲

本実験の特定条件では、逆二乗則が成立しています。

一方、次は未検証です。

- 任意の閉鎖系への一般化
- 任意の倍音配置への一般化
- 非整数・非調和更新への一般化
- 任意の位相―距離変換への一般化
- 標準重力加速度との一致
- Newton定数や質量源の導出

未検証なのは一般化範囲であり、本実験条件における逆二乗則ではありません。
