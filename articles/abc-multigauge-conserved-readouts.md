2026-07-13に、フェルミオン的反射写像の計算式更新に合わせて再計算した v2 を公開しました。多ゲージ干渉から `p,E,R` を読む本稿の主要結果は維持されています。

## 問い

これまでの波の情報読出しシリーズでは、空間や時間に相当する量を、外部にある背景座標ではなく、閉じた位相系からの読出しとして扱ってきました。

今回の問いは、その同じ方針で、

```text
質量
運動量
エネルギー
```

に見える保存量も読めるのか、です。

ただし、本稿の `p,E,R` は標準物理の運動量、エネルギー、質量そのものではありません。ABC 閉鎖位相系の内部で、多ゲージ干渉から再構成される保存読出し量です。

## 単一ゲージでは測定成立としない

今回の重要な条件は、単一ゲージ値を測定値とみなさないことです。

局所波 `A,B` と観測機 `C` からなる ABC 系に対して、複数の読出しゲージを使い、干渉相関の安定成分を読みます。

空間位相方向の相関勾配を

```text
p_read
```

時間位相方向の相関勾配を

```text
E_read
```

複数ゲージで安定して残る振幅二乗残差を

```text
R_read
```

として扱います。

## 対称衝突での基礎結果

単回 ABC 衝突では、`p,E,R` が複数ゲージから再構成されました。

| 量 | 最大誤差 |
|---|---:|
| `p_read` | `2.5202062658991053e-14` |
| `E_read` | `2.2315482794965646e-14` |
| `R_read` | `4.440892098500626e-16` |

また、8回の反復衝突でも、`p` 反転、`E,R` 保存、識別振動保存、補償付き閉鎖が維持されました。

## 非対称 R で単純反転が破れる

等振幅条件では、単純な

```text
q -> -q
```

が反射読出しとして成立します。

しかし、`R_A` と `R_B` が異なる場合、同じ単純反転は

```math
R_Ap_A+R_Bp_B
```

を保存しません。

これは破綻ではなく、`R` が質量的に読まれるなら、保存写像も `R` 重み付きへ一般化される必要がある、という診断です。

## 一般化保存写像

そこで、

```math
P_R=R_Ap_A+R_Bp_B
```

および

```math
K_R=R_Ap_A^2+R_Bp_B^2
```

を保存する写像を構成しました。

8種類の非対称振幅ケースでは、

| 保存量 | 最大保存誤差 |
|---|---:|
| `R*p` | `2.3803181647963356e-13` |
| `R*p^2` | `1.4086509736443986e-12` |

で保存が確認されました。

## 追加検証

さらに、次の検証を行いました。

- 非単位・非対称初期位相勾配
- 同方向追いつき衝突
- 一般化写像の複数回衝突
- 読出しノイズ頑健性
- `R_B/R_A=0.015625` から `64.0` までの極端 `R` 比スイープ

統合サマリーでは、9本の実験すべてが `valid` となり、単一ゲージのみの判定は一つも使いませんでした。

## 今回の到達点

本稿の結果は、標準質量、標準運動量、標準エネルギーを直接導出したという主張ではありません。

しかし、

```text
空間位相勾配 -> 運動量的読出し
時間位相勾配 -> エネルギー的読出し
安定振幅二乗残差 -> 質量的読出し
R*p 保存 -> 運動量的保存に見える関係
R*p^2 保存 -> 二乗量保存に見える関係
```

を、ABC 閉鎖位相系の内部で、多ゲージ干渉から一貫して構成できることを確認しました。

質量・運動量・エネルギーを、先験的な実体量ではなく、閉鎖位相系からの保存読出しとして扱うための数値構成です。
