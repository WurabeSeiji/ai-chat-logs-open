先に、交換対称な二チャネル作用素の有限位数回帰から、離散Born型重み

```math
\cos^2\left(\frac{\pi m}{n}\right),
\qquad
\sin^2\left(\frac{\pi m}{n}\right)
```

が得られることを独立論文として公開しました。

- 先行論文 Concept DOI: https://doi.org/10.5281/zenodo.21422470

今回、その定理を変更せず、さらに前段にある「なぜ非実方向が必要になるのか」を別論文として公開しました。

- 本論文 Concept DOI: https://doi.org/10.5281/zenodo.21422505
- 本論文 Version DOI: https://doi.org/10.5281/zenodo.21422506
- GitHub: https://github.com/WurabeSeiji/ai-chat-logs-open

二本を分けた理由は重要です。第1論文の有限位数交換定理は標準的な複素線形代数だけで成立します。第2論文は、数体系と「閉鎖」の意味に関する、さらに根源的な解釈を扱います。両者を一つにすると、独立に成立する定理と追加の基礎仮説が混同されます。

## 出発点は共役を含まない

今回の出発点は

```math
Q_0(x):=\sum_{k=1}^{N}x_k^2=0,
\qquad
(x_1,\ldots,x_N)\neq(0,\ldots,0)
```

です。

ここで `Q₀` は複素共役を含みません。

すべての成分が実数なら、

```math
x_k^2\ge 0
```

なので、和が0になるには全成分が0でなければなりません。

したがって非自明解を要求すると、解ベクトルは

```math
\mathbf{x}\in K^N\setminus\mathbb R^N
```

にあります。固定した閉鎖座標では、少なくとも一つの成分が非実数です。

## 最小二成分系

最小系

```math
x^2+y^2=0,
\qquad x\neq0
```

では、

```math
\left(\frac{y}{x}\right)^2=-1.
```

平方が `-1` になる要素を `i` と書けば、

```math
y=\pm ix.
```

この段階では共役を使っていません。

論理は、

```text
複素数を仮定
→ x²+y²=0
```

ではなく、

```text
x²+y²=0 に非自明解を要求
→ 平方根 -1 の方向が必要
```

です。

`K` が実数体を含む可換体なら、この `i` が生成する最小部分体は

```math
\mathbb R(i)\cong\mathbb C
```

です。

## `Q₀` と `Q₊` を分ける

ここで、二種類の二乗を混同できません。

閉鎖を定義する二乗は、

```math
Q_0(x)=\sum_kx_k^2.
```

大きさを読む正定値二乗は、

```math
Q_+(x)=\sum_kx_k^*x_k
=
\sum_k|x_k|^2.
```

例えば、

```math
(x,y)=(a,ia)
```

なら、

```math
Q_0=a^2+(ia)^2=0
```

ですが、

```math
Q_+=|a|^2+|ia|^2=2|a|^2>0.
```

したがって `Q₀=0` は、状態や物理量がすべて消滅したという意味ではありません。向きを含む代数的閉鎖登録が0であり、正定値読出しは非零であり得ます。

## 共役は後段の読出しに属する

非実方向は `x²+y²=0` の非自明性から必要になります。

共役は後から、

```math
i\mapsto-i
```

と非実方向を反転し、

```math
z^*z
```

を正定値量として読む操作に位置づけます。

つまり、

- 虚数方向の必要性
- 共役の役割
- Born型二乗読出し
- Born頻度則

は同じ問題ではありません。

## どこから追加構成になるか

厳密に導出したのは、非自明二乗閉鎖が非実方向を要求するところまでです。

そこから一般の連続位相へ進むには、追加条件を置きます。

1. 連続性
2. 合成の結合性
3. 可逆性
4. 正定値読出しの保存

この追加構成により、非実方向を

```math
e^{i\phi}
```

という `U(1)` 位相回転へ拡張します。

さらに交換対称性を独立に置き、反対称セクターへ位相 `ζ` を配置すると、

```math
U=P_s+\zeta P_a
```

です。

有限位数条件

```math
\zeta^n=1
```

は

```math
\zeta=e^{-2\pi im/n}
```

を選びます。A/B基底へ戻した振幅は

```math
r=\frac{1+\zeta}{2},
\qquad
t=\frac{1-\zeta}{2},
```

正定値二乗読出しは

```math
|r|^2=\cos^2\left(\frac{\pi m}{n}\right),
\qquad
|t|^2=\sin^2\left(\frac{\pi m}{n}\right)
```

となります。

## 最重要の未解決点C2

非自明二乗閉鎖と交換力学を一直線の無条件導出として書くことはできません。

```math
Q_0(x)=x^Tx
```

に対し、既報の交換核

```math
U=P_s+\zeta P_a
```

は

```math
U^TU=P_s+\zeta^2P_a
```

を満たします。

閉鎖面上の点

```math
x_0=(1,i)^T,
\qquad Q_0(x_0)=0
```

に作用させると、

```math
Q_0(Ux_0)=i(1-\zeta^2).
```

一般の有限位数根では `ζ²≠1` なので、交換後の状態は `Q₀=0` の閉鎖面から外れます。

したがって、既報の交換核は一般には `Q₀=0` を保存する自己写像ではありません。

この接続を作るには、

- 閉鎖面を保存する別の交換写像
- 閉鎖面へ戻す射影規則
- 閉鎖条件を保つ拡大状態空間

のいずれかが必要です。本論文では、これを接続課題C2として明示的に未解決としました。

## 正確な論理構造

本論文の結論は次の四層です。

```text
非自明二乗閉鎖
→ 非実方向
［導出］

非実方向
+ 連続性・可逆性・Q₊保存
→ 位相回転
［追加構成］

位相回転
+ 交換対称性・有限位数・二乗読出し
→ 離散Born型重み
［条件付き導出］

Q₀=0 と交換核の動的接続
［未解決C2］
```

Born則全体、単一試行の確率的選択、多数回頻度則を導出したとは主張しません。

この論文が厳密に加えたのは、複素位相を最初から量子論固有の道具として置かず、非自明二乗閉鎖が要求する最小の非実方向として位置づけたことです。
