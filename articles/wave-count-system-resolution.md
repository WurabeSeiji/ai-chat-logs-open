このシリーズでは「波の数」という言葉を当たり前のように使ってきました。本論文はその足元を調べたものです。主張は二つだけです。

## 主張1：波の数は、系の中では決まらない

閉鎖 Σx² = 0 の項数——Σx² = R² と書いたときのベース振動に対する最大倍音番号——は、外から分解能を置くことで初めて決まる数であり、系が内部で決める量ではありません。

これは仮定ではなく導出です。零閉鎖（右辺の零は特権的な基底も基本振動も分解深度も指定しない）、成分の無名性（成分は固有の個体ではなく分解の座標）、位相の不可読性、そして閉鎖塔の平坦化（倍音の倍音は倍音なので、一塊で読む表示と多数に分解して読む表示は同じ閉鎖に戻る）——この四つを合わせると、結果が「波の数」であるような内部読出しは存在しないことが従います。波の数は、絶対位相や絶対スケールと同じ「原理的に読めない量」の族に属します。

一本の弦の音を、一つの音と数えるか、基音と倍音の十個の成分に数えるかは、弦ではなく聞き手の分解能が決める——それと同じ構造です。

数値実証もシンプルです。同一の走行データに計数規約の格子（周波数分解能×振幅床、352セル）を適用する再解析だけで、読出される波の数は1個から7個まで変わりました。走行は一度きり。変えたのは読み方だけです。

## 主張2：数え方を決めた瞬間に上限が生まれ、しかも定常はその下で止まる

計数規約 C =（周波数分解能 ω₀、相対振幅床 ε）を固定すると、読出せる波の数には上限

n_max = min(⌊Ω/ω₀⌋, 1/ε²)

が生じます。二本柱はどちらも閉鎖から出ます。振幅床側の 1/ε² は、配分比の総和が1に固定されている（＝閉鎖）ことによる鳩の巣原理で、開いた系では消えます。周波数側の ⌊Ω/ω₀⌋ は離散更新の帯域上端（Nyquist型）です。

重要なのは二層の区別です。上限が「ある」ことは閉鎖の帰結で、規約に依りません。上限が「いくつか」は規約の比で、床を下げ続ければ際限なく上がります——波の数が無限に拡大して見えるのは、存在が増えているのではなく、観測の床が下がっているからです。

実験（8体・12体・16体、時系列＋規約格子の全数検査）では、上限の違反はゼロ。過渡的には上限への接触も観測しました（8体で天井ちょうどの8個）。ところが定常状態は上限に届かず、天井の1〜4割で安定します。原因も特定しました。振幅は熱化して等分配へ向かうのに、振動数が帯域の端へ凝集していくため、区別できる周波数クラスが減るのです。振幅の熱化と振動数の凝集の共存——これがこの力学の特徴的構造です。

## 一行でまとめると

数は読み方が決め、上限は閉鎖が決め、充填は力学が決める。「波はいくつあるか」という問いは、この三層に解体するのが正しい、というのが本論文の結論です。

存在は無限に開き、読出しだけが飽和する。前論文（第5論文）の自発的分裂、第3論文の三方向飽和、第4論文のレジスタ凍結と合わせて、シリーズの有限性はすべて読出しの層の飽和として統一されます。

なお、粒子数が観測に依存すること自体は標準理論も知っています（パートン数の分解能依存、Unruh効果の観測者依存）。本論文はそれらを置き換えるものではなく、閉鎖とスケール無名性という別の出発点から同じ構造を出す別写像であり、そのうえで「数え方を固定したときの上限」の定理を加えるものです。
