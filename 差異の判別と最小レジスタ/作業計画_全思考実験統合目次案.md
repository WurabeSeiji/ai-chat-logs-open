# 全思考実験シリーズ反映状況と統合目次案

**目的**：現在の本文（第0章〜第4章）が、複数の思考実験シリーズのどこまでを反映しているかを整理し、未反映部分を含めた最終的な章構成案を作る。

**方針**：本書は標準理論の置換ではなく、標準理論の手前にある「なぜ」を、少ない部品から再構成する思考実験として書く。したがって、全章で次の区別を保つ。

| 区分 | 本文での扱い |
|---|---|
| 定理・恒等式 | 本体章に置く |
| 構成 | 明示した仮定の下で作る |
| 対応 | 標準理論の既知構造と同じ形を持つことの確認として書く |
| 仮説 | 仮説章に隔離し、観測予言と未計算部分を明示する |
| 撤回済み主張 | 付録の訂正記録に置く |

ここにもう一つ、全巻を貫く規律を明示しておく。

**スケール共変性の規律**：局所的な系で成立する文法は、宇宙スケールの系でも、スケールファクタ $R$ の違いだけで同じ形で成立しなければならない。したがって、$a^2+b^2=r^2$ の $r$ を、ある章では単なる保存量、別の章では曲率半径、さらに別の章では動的自由度、というように都合よく読み替えてはならない。読み分ける場合は、必ず「同じ台帳のどの射影を読んでいるか」として説明する。

この規律の下では、物理的に読めるのは絶対スケールではなく、系どうしのスケール比・位相差・増分率である。孤立系の一様な拡大縮小は、外部基準なしには物理的変化として読めない。収縮や膨張を語るには、親系・外部系・別スケールとの比較、または $R$ 方向の位相増分率を明示する必要がある。

さらに、台帳の各軸は基本的に共役複素対として読む。したがって、ある軸の実数読出し値がゼロであることは、その軸の複素レジスタがゼロであることを意味しない。たとえば $Z_R=\rho_R e^{i\theta_R}$ に対して $\mathrm{Re}\,Z_R=0$ でも、$\rho_R$ や $\theta_R$ は存在しうる。これは単振動で変位がゼロでも位相と速度が消えないのと同じである。

このため、後続章では「ゼロ」を少なくとも次の四種類に分ける。

| ゼロの種類 | 意味 | 注意 |
|---|---|---|
| 実数読出し値のゼロ | $\mathrm{Re}\,Z_A=0$ や、ある射影値がゼロ | 位相・振幅は消えない |
| 複素レジスタ自体のゼロ | $Z_A=0$、すなわち両成分がゼロ | このときだけ、その軸の位相は退化する |
| 位相増分率のゼロ | $p_A=d\theta_A/ds=0$ 型の読み | 保存量としての毛がゼロでも、軸や位相座標は消えない |
| 総和としてのゼロ | 複数成分の相殺で外部読出しがゼロ | 内部成分や交差項は残りうる |

光子の「静止質量ゼロ」は、この表では $R$ 方向の位相増分率 $p_R$ が質量毛として読まれない、または $p_R=0$ と読むべきであり、$R$ 軸や $Z_R$ 自体が存在しないという意味ではない。

## 0. 巻構成の再整理

全思考実験を一冊にすべて入れることは可能だが、読者負荷と主張の硬さを考えると、**三巻構成**に分ける方が自然である。

### 第1巻：基礎テキスト

第1巻は、比較的硬い基礎テキストとしてまとめる。現在の第0章〜第4章に、あと二章を追加すれば閉じられる。

| 章 | 役割 |
|---|---|
| 第0章 | 観測の最小構成 |
| 第1章 | 読出しの代数とファイバー |
| 第2章 | 読出しが存在できる宇宙と複素化の入口 |
| 第3章 | 離散位相の整数実装 |
| 第4章 | 台帳と保存量の文法 |
| 第5章 | 閉包・目盛り・マスターカウンター・スケール私有 |
| 第6章 | レジスタ・因果・不確定性の二層・Born型読出しの境界 |

第1巻の最終目標は、「観測の最小構成」「複素構造の必要性」「離散位相の実装」「保存量の文法」「目盛りと不確定性の発生条件」までを、標準理論の導出ではなく、硬い代数・構成・対応として整理することである。

第1巻では、運動方程式や相互作用の具体法則には入らない。そこに入ると、仮説の濃度が上がるためである。

### 第2巻：応用テキスト

第2巻は応用テキストとし、二部構成にする。

第2巻から読み始める読者のために、本文の前に **「第2巻 はじめに」** を置く。ここでは、第1巻の最小復習（台帳・位相増分率・閉包・レジスタ）、標準理論との翻訳規則、本巻で描きすぎないこと、そして本巻で主張しないことを明示する。思考実験ノートは本文の前提にせず、補足として「著者が AI と行った思考実験・検証ノート」と位置づける。特に第2巻は標準理論を置換する巻ではなく、標準理論の同じ不変量・変換構造・保存量を、本書の台帳語で読み替える応用巻であることを先に宣言する。

| 部 | 内容 | 注意点 |
|---|---|---|
| 動力学編 | 台帳を動かす。光錐、Lorentz型変換、同時性、エネルギー運動量、点粒子近似、運動方程式の導入 | ここから「運動方程式を置く」仮説が入る。系の外からの測定をどう定義するかが中心問題 |
| 相互作用編 | 複数の系がどう接続し、階層を作るか。重力型・電磁型の読出し候補、ゲージ的接続、粒子種、崩壊、もつれ、ブラックホール | 構成的に最も難しい。系の階層構成、共有台帳、接続、境界、遮蔽を明示的に定義する必要がある |

この切り分けにより、第1巻は「比較的硬い基礎」、第2巻は「標準理論と矛盾なく接続できるかを試す応用」として読める。特に第2巻では、標準理論を導出したとは書かず、**どこまで矛盾なく同じ形へ接続できるか**を検査する。

### 第3巻：検証・訂正・作業記録

第3巻は、本文の流れに入りきらない思考実験、数値検証、撤回済み主張、予言在庫をまとめる。ここは「理論をさらに進める巻」ではなく、**どこまで確かめたか、どこで言い過ぎたか、何が未計算かを読者に公開する巻**である。

## 第V部 応用テキスト：相互作用編

ここから先は、第IV部までより仮説濃度が上がる。第V部では、標準理論の通常の定式化には含まれない追加仮定を明示して導入する。ただし、その目的は標準理論と異なる物理法則を主張することではない。台帳・共有境界・接続という少数の制約条件を読出し仮定として加え、特定の条件下で、標準理論にすでにある構造をより見通しよく解釈するための補助線として使う。

第7章〜第9章では、標準理論にすでにある不変量・読出し・発展方程式の形を、台帳語でどこまで読み直せるかを中心に扱った。これに対して相互作用編では、複数の系がどの台帳を共有するか、どの境界で記録を交換するか、どの接続で異なる位相原点やスケールを比較するか、という追加の構成が必要になる。

したがって第V部では、次を最初に明記する。

| 線引き | 内容 |
|---|---|
| 標準理論を置換しない | Maxwell 方程式、Einstein 方程式、Yang-Mills 理論、標準模型を導出したとは言わない |
| 読出し候補として置く | $R$ 軸・$Q$ 軸・共有台帳・接続を、標準理論の有効表示に接続しうる候補として読む |
| 追加仮説を隠さない | 相互作用の具体法則、頂点写像、結合定数、内部ゲージ群との同一視には新しい仮説が入る可能性がある |
| 比喩で終わらせない | どこが恒等式・構成・対応で、どこからが仮説かを章末で分ける |

特に、相互作用は「背景時間の上で力が働く」とは始めない。まず、二つ以上の系が一部の台帳・モード・境界・記録面を共有し、その共有を外部から読んだ有効表示として相互作用が現れる、と読む。ここでは、**頂点写像**、すなわち分裂・合流・記録追記の具体規則が未確定の中心課題になる。

- □ **第10章 重力型読出しと電磁型読出し**
  - **問い**：なぜ重力と電磁気は違う顔をするのか。
  - $R$ 軸は、曲率・質量型・重力型の有効表示に接続しうる読出し候補として扱う。
  - $Q$ 軸は、符号付き内部位相・電荷型・電磁型の有効表示に接続しうる読出し候補として扱う。
  - $R,Q$ の座標欄、$\Delta R,\Delta Q$、位相増分率 $p_R,p_Q$、外部読出し $m,q$ を混同しない。
  - 重力型読出しは、全成分にかかるノルム・スケール・曲率側の有効表示候補として整理する。
  - 電磁型読出しは、符号付き内部円の位相差・位相増分率の有効表示候補として整理する。
  - 逆二乗型場、ポテンシャル、光子型伝播との接続は、Maxwell 型表示に必要な部品の候補として扱う。
  - Maxwell 方程式や Einstein 方程式を導出したとは書かず、有効表示への接続点として扱う。
  - この章ではまだ「相互作用の具体法則」を完成させない。まず $R/Q$ 読出しの分業だけを置く。

- □ **第11章 系の階層構成——共有台帳・接続・境界**
  - **問い**：複数の系はどう階層を作り、どこで相互作用するのか。
  - 親系・子系・孫系。
  - 共有台帳、継承、分割、合流。
  - 相互作用＝二つ以上の系の台帳が、一部のモード・境界・記録面・読出し条件を共有すること。
  - 接続＝異なるスケール・異なる位相原点・異なる局所フレームの換算簿記。
  - 頂点写像＝分裂・合流・記録追記の局所規則として定義する。ただし具体法則は仮説として扱う。
  - 相互作用を、背景時間上の力学ではなく、記録列・共有境界・台帳の継承関係として読む。
  - 共有台帳がない場合、読めるのは相関ではなく外部測定面に落ちた別々の記録だけである。
  - ここを定義しないと、重力・電磁・ゲージ・崩壊・もつれが全部曖昧になる。

- □ **第12章 ゲージ的接続の射程——フレーム輸送と内部対称性候補**
  - **問い**：なぜゲージ場か。
  - ゲージ＝読めない原点・位相規約・局所フレーム選択の貼り替え不変性。
  - 局所ゲージ＝共在不能な領域間の参照・位相・フレームを比較する輸送簿記。
  - まず、フレーム輸送・接続・ホロノミーを扱う。これは Yang-Mills 型というより、離散的なフレーム接続・重力型ゲージ構造に近い対応として読む。
  - U(1) 型：$Q$ 軸の閉位相読出し、または円上の位相原点の任意性として扱う。
  - SU(2) 型：2成分の有効レジスタが同一ノルムを保つ内部読出し候補として扱う。
  - SU(3) 型：3成分のノルム保存構造として扱う。ただし空間三軸の SU(3) 型と、標準模型の色 SU(3) はただちに同一視しない。
  - 標準模型の粒子表現、結合定数、対称性破れ、世代構造、強い相互作用の閉じ込めは導出しない。
  - ここは「標準模型を導出」ではなく「どこまで同じ文法で読めるか」に限定する。
