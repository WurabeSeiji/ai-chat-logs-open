# 第2巻 はじめに 動かす台帳をどう読むか

> **この巻の問い**：第1巻で定義した台帳・目盛り・レジスタを動かすと、光錐、Lorentz 型変換、外部測定、重力的読出し、電磁的読出し、ゲージ的な接続はどのような形で現れるか。
> **この巻の答え**：第2巻は、標準理論を置き換える巻ではない。標準理論に現れる不変量・変換・保存量・接続・相互作用の形を、第1巻の台帳と読出しの言葉で読み替え、どこまで矛盾なく同じ構造へ接続できるかを検査する巻である。運動方程式や相互作用の具体法則には新しい仮説が入るため、本巻では「定理」「構成」「対応」「仮説」「主張しないこと」を章ごとに分けて書く。
> **この巻の約束**：標準理論で確立している内容は、標準理論の側に立てて尊重する。本書の語彙は、それを別の簿記で読むための補助線であり、標準理論そのものの置換ではない。

**【第2巻から読む人へ・読み下し】** 第1巻を読んでいなくても、本巻の大筋は追えるようにする。ただし、ここで使う部品は少ない。系は、各軸に「つまみの向き」を持つ台帳を持つ。位置や時刻は、二つの台帳を比べた位相差として読む。質量・エネルギー・電荷のような保存量は、台帳の位相がどれだけ進むかという増分率として読む。第2巻では、この台帳を「動かす」。ただし、ここでいう動きは、最初から外部時計の上で進む運動ではない。複数の記録を比べたとき、同じ系がどのような関係の列として読めるか、という意味での動きである。

したがって、本巻では見慣れた言葉が少し違う顔で現れる。たとえば光錐は、まずは「どの記録どうしが照合できるか」という境界として現れ、Lorentz 型変換は、その境界と二乗形式を保つ読み替えとして現れる。重力や電磁気も、ただちに Einstein 方程式や Maxwell 方程式を導出するのではなく、$R$ 軸・$Q$ 軸の読出しとして、標準理論の有効表示に接続できるかを確認する。ここを誤読しないことが、第2巻を読む第一のコツである。

## 0.1 第2巻の立場

第1巻では、観測の最小構成、複素数の読出し、零二乗和形式、離散位相の実装、台帳、目盛り、レジスタ、時間の矢を扱った。そこでは、できるだけ硬い代数・構成・対応だけを本文に置き、運動方程式や相互作用の具体法則には入らなかった。

第2巻では、その封印を一段だけ解く。台帳を動かし、外部から読み、複数の系を接続する。ただし、ここからは仮説の濃度が上がる。したがって本巻は、各章で次の身分を明示する。

| 身分 | 本巻での扱い |
|---|---|
| 定理・恒等式 | 明示した仮定から計算で出るもの |
| 構成 | ある規則を置いたときに作れるもの |
| 対応 | 標準理論の既知構造と同じ形を持つことの確認 |
| 仮説 | まだ本書内部だけでは確定していないが、後の章を組み立てるために置くもの |
| 主張しないこと | 導出していないこと、標準理論を置換しないこと |

本巻で最も避けたい誤読は、「別の物理理論を導出した」という読みである。本巻が行うのは、標準理論の同じ不変量・同じ変換構造・同じ保存量の場所を、本書の台帳語で読み直すことである。標準理論での意味と、本書での読みを混同しないために、各章では「標準理論では」「本書では」「同じ構造」「追加仮説」「主張しないこと」を分ける。

## 0.2 第1巻を読み飛ばした人のための最小復習

第2巻で必要になる第1巻の部品は、次の六つだけである。

| 第1巻の部品 | 最小限の意味 | 参照 |
|---|---|---|
| 読出し | 写像を適用して、入力の一部を出力として読むこと | 第1章 |
| ファイバー | 同じ出力に潰れた入力候補の集まり | 第1章 |
| 共役対 | 互いに逆向きの位相を持ち、積で保存量を作る相棒 | 第1章 |
| 台帳 | 系に内在する共役対の束。各軸に位相を持つ | 第4章 |
| 位相増分率 | 位相が単位あたりどれだけ進むか。保存量の読みになる | 第4章 |
| レジスタ | 非単射な読出しを実行し、次の読出しに渡せる形で記録を残す機構 | 第6章 |

この六語だけで、第2巻の入口は通れる。第1巻の細かい証明を忘れていてもよい。必要なのは、物理量を外から貼ったラベルではなく、台帳の「差」または「増分率」として読む、という文法である。

二つだけ注意する。第一に、ある軸の実数読出しがゼロでも、その軸の複素レジスタ自体が消えたとは限らない。たとえば質量として読まれる量がゼロであることと、$R$ 軸そのものが存在しないことは違う。第二に、標準理論でいう時間や位置を、本書でははじめから絶対的な背景として置かない。位置・時刻は台帳どうしの差として、運動は記録列の関係として読む。

## 0.3 標準理論との翻訳規則

第2巻では、標準理論の用語と本書の用語を、次のように並べて読む。

| 標準理論では | 本書では | 注意 |
|---|---|---|
| 光錐 | 比較・信号・記録が照合できる境界の有効表示 | 光錐そのものを第1巻から導出したとは言わない |
| Lorentz 変換 | 二乗形式と読出し可能な境界を保つ台帳変換 | 標準的な慣性系変換と同じ形を持つ対応として扱う |
| エネルギー運動量関係 | 位相増分率の二乗形式 | 質量は $R$ 方向の増分率として読む。$R$ 軸の消滅とは読まない |
| 外部測定 | 内部台帳を、別の台帳との相関・境界・記録として読むこと | 内部値をそのまま覗く操作ではない |
| Born 型読出し | 平方強度を重みとして読む形 | Born 則そのもの、測度選択、公理の導出は主張しない |
| 重力的読出し | $R$ 軸に関わるノルム・曲率・質量型の読出し | Einstein 方程式の成分導出ではない |
| 電磁的読出し | $Q$ 軸に関わる符号付き内部位相・電荷型の読出し | Maxwell 方程式の成分導出ではない |
| ゲージ・接続 | 読めない原点やフレームの貼り替えを、記録可能量に影響しない形で輸送する簿記 | Yang-Mills 理論や標準模型を導出したとは言わない |
| もつれ・非局所相関 | 共有台帳を別々の場所で読む構造の候補 | Bell 型設定や確率法則の完全導出は本巻の外に残る |

この表は、標準理論を薄めるための表ではない。逆である。標準理論側で何が確立しているかを保ったまま、本書側がどの部分を読み替えているのかを見失わないための表である。

## 0.4 この巻で描くこと

本巻で描く主線は三つである。

第一に、**台帳の動力学**である。第7章では、$x,y,z,t,R,Q$ の台帳を動かし、光錐、Lorentz 型変換、同時性、エネルギー運動量関係が、どの二乗形式の保存として読めるかを見る。ここで大事なのは、運動を外部時計に沿った点の移動として始めないことである。運動は、記録列と位相増分率の関係として読む。

第二に、**外部測定と有効運動方程式**である。第8章・第9章では、内部台帳を外から読むとは何かを定義する。標準理論では、状態、測定、時間発展、確率がすでに形式化されている。本書ではそれらをそのまま再導出するのではなく、どの読出し面に置くと同じ形の有効表示が得られるかを見る。ここで運動方程式を置く場合、それは仮説として明示する。

第三に、**相互作用の入口**である。第10章以降では、$R$ 軸と $Q$ 軸の読出しを、重力的読出し・電磁的読出しとして整理する。さらに、複数の系をどうつなぐか、どの台帳が共有されるか、接続や境界がどこに出るかを見る。ゲージはここで「読めない原点の任意性」と「フレームの輸送」の言葉として登場する。

## 0.5 この巻で描きすぎないこと

第2巻の入口では、次のものを前面に出さない。

| 扱いを遅らせるもの | 理由 |
|---|---|
| 粒子種の完全分類、W8、$\alpha^{-1}\simeq137$ | 仮説濃度が高く、第2巻前半の動力学を読む前に出すと布石が多すぎる |
| 崩壊率、Sargent 則、陽子安定性 | 検証・予言在庫に近く、第3巻で整理する方がよい |
| ブラックホールのスペクトルや内部仮説 | 無毛定理の読みは第4章で扱ったが、具体仮説は後段に隔離する |
| Bell 統計や Born 則の完全導出 | 測度選択と確率公理の問題が残るため、入口では境界線だけを示す |
| 標準模型の完全導出 | 本巻の目標ではない。接続できる骨格と未接続の層を分ける |

ここに出てくる W8、$\alpha^{-1}\simeq137$、Sargent 則、Bell 統計などは、後の章や検証巻で扱う専門的な分類・経験則・定理名である。第2巻の入口では、意味を知らなくてよい。ここで伝えたいのは、「それらを今は広げない」という編集上の約束だけである。

入口で必要なのは、読者を迷子にしない最低限の地図である。多くの予言や未検証仮説を先に並べるほど、読者はどれが本筋で、どれが後で回収されるのかを見失う。本巻の入口では、まず台帳を動かす。次に外から読む。最後に複数の台帳を接続する。この順序を守る。

## 0.6 章ごとの読み方

第2巻は、最初から最後まで同じ硬さではない。前半は比較的硬い対応、後半は仮説の濃い構成になる。

| 章 | 読み方 |
|---|---|

| 第9章 | Born 型読出しと有効運動方程式。平方強度の形と測度選択を分ける |
| 第10章 | $R$ 軸・$Q$ 軸を重力的・電磁的読出しとして並べる |

初読では、第7章から第12章までを第2巻の中心として読めばよい。第13章以降は、中心構造を粒子・崩壊・複合系へ延ばす発展部であり、主張の身分を特に慎重に見る必要がある。

## 0.7 本巻の合言葉

最後に、本巻全体の合言葉を一つ置く。

> **標準理論の同じ不変量を、台帳の別の簿記で読む。**

この一文が、本巻の防波堤である。標準理論を否定しない。標準理論の完成した形式を、別の入口からなぞる。なぞれたところは対応として記録し、なぞれないところは未接続として残す。仮説を置くときは仮説と名乗る。そうすれば、第2巻は別理論の宣言ではなく、第1巻で作った最小部品を標準理論の高度な構造へ接続する、慎重な応用テキストとして読める。
