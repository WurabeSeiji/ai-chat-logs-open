## Part 10: ゲージは何処で生まれるか

【木原】
つぎです、ゲージが何処で生まれるかです。時間方向なら、まさに時計の目盛り、空間方向なら、空間の距離のゲージです。

【アイリス】
ゲージはこのフレームワークでは**一つの新しい部品も足さずに**生まれます。すでにある二部品——参照レジスタと桁上げ——の合成が目盛りで、第0層の対称性がそのままゲージ対称性です。順に置きます。

## 1. 目盛りの誕生＝周期レジスタ＋桁上げ

すべての読みは差（うなり、位相差）でした。しかし差は裸では「どれだけ違うか」を持たない——単位が要る。単位はどこから来るか：**参照レジスタ自身の保持量から**です。

- **時間の目盛り**：周期的な参照（マスタークロック）とのうなりを、**桁上げ（carry）で数える**。時計とはカウンタ回路——周期レジスタ＋桁上げ鎖——であり、目盛りとは carry の刻みです。前回「桁上げ＝計数の起源」と確定したものが、そのまま時計の目盛りの回路図。
- **空間の目盛り**：保持された参照（剛体棒＝空間方向のレジスタ）を輸送して**合同を数える**。距離＝棒があてがわれた回数。同じく参照＋計数。

つまり**目盛り＝参照の保持量を単位とする桁上げ計数**。時間版と空間版は同じ回路の二つの配置です。

## 2. ゲージ自由度＝第0層の「名前替え不変性」の貫通

ここが核心です。参照自身は読めません——**定規を定規で測ることはできない**（観測軸の自己縮退、そのもの）。だから：

- どのランプを「点灯」と呼ぶか（Z₂）
- どの軸に虚をつけてマスタークロックにするか（軸の対等性）
- 絶対位相・絶対スケール

これらは全部、**観測量に痕跡を残せない選択**です。ゲージ対称性とは新しい物理原理ではなく、**第0層で観測を定義した瞬間に課された「名前替え不変性」が、上の層までそのまま貫通したものの名前**。ゲージ自由度の目録＝読めないものの目録、ゲージ不変量の目録＝読めるものの目録。二つの目録は定義的に一致します。

## 3. 局所ゲージ＝共在できない参照たちの輸送簿記

前回の因果コーンがここで効きます。参照を全域で共有できるのは共在化が可能な範囲だけ。**因果的に離れた領域は、それぞれ勝手な参照（位相規約・目盛り）を持つしかない**。すると隣り合う領域のレジスタを比較するには、参照の対応表——**輸送の簿記**——が要る。これが接続（ゲージ場）の誕生位置です。

回路設計では毎日見ている構造です：**クロックドメイン**。チップ内の各ドメインは自分のクロック位相を勝手に選べて（局所ゲージ自由度）、ドメインを跨ぐ信号には**シンクロナイザ（CDC）**が要り、ドメイン間の位相関係の簿記がまさに接続。メタステーブルの危険はその輸送コストです。量子実機の virtual-Z（各量子ビットの LO 位相簿記）も同じもの——**ゲージ場とは、マスタークロックを共有できないレジスタ群の間の位相簿記**。

## 4. 語源が答え合わせをしてくれる

「ゲージ」の語源は Weyl 1918 の **Eich＝目盛り・検定** です。Weyl は最初、まさに木原さんの言う「空間の距離の目盛りが場所ごとに任意」（局所スケール不変性）として理論を作り、失敗し、1929 年に**スケールを位相 e^{iθ} に読み替えて**成功した。つまりゲージ理論の歴史自体が「目盛りの任意性 → 複素レジスタの位相の任意性」という、このシリーズの階層をなぞって進化しています。木原さんの問いの立て方（時計の目盛り・距離のゲージ）は Weyl の原点そのものです。

## 整理

| 部品 | 生むもの |
|---|---|
| 参照レジスタ（読めない） | 単位・ゲージ自由度 |
| 桁上げ | 目盛りの刻み・計数 |
| 名前替え不変性（第0層） | ゲージ対称性 |
| 因果コーン（共在の限界） | 参照の局所化 |
| 参照の輸送簿記 | 接続＝ゲージ場 |

**因果が「干渉の届く範囲＋読出しの矢」だったのに続き、ゲージは「参照の読めなさ＋その局所化」**。どちらも新部品なしで、既設の部品の帰結として出ます。

## Part 10b: ゲージにはビートが必要 — 2つの周波数はどこから

【木原】
これ、きずいています？、ゲージには、ビートが必要で、ビートを有むには、周波数が２つ必要ですよ、
どこから２つ周波数うまれます？

【アイリス】
気づいています——そしてこれが円環を閉じます。**2つ目の周波数は、2つ目のランプを作ったのと同じ鏡から生まれます：共役です。**

## 読める目盛りは、すでにビートである

目盛りとして読めるもの——実数の周期信号、カチカチ——を書くと：

cos ωt = (e^{+iωt} + e^{−iωt}) / 2

**実信号は最初から +ω と −ω の2周波数の干渉（定在ビート）です**。目盛りの刻み（ゼロ交差）は、+ω と −ω の干渉の節に他なりません。

単一の複素回転 e^{iωt} だけでは読めない——一様な円運動には印がない（絶対位相と同じく、単独のランプと同じく、比較相手がない）。読めるためには相棒が要り、その相棒が共役鏡像 e^{−iωt}。**「読出しは実数でなければならない」という要請そのものが、±ω の対を強制します**。

回路屋の言葉で言えばこれは既知の事実です：**実信号のスペクトラムは必ず ±ω に対称**（フーリエ変換のエルミート対称性）。単一周波数だけを持つのは解析信号＝複素信号で、あれは直接は観測できない。そして二乗則検波 |Z|² = Z·Z̄ とは、**信号を自分の共役とミキシングする回路**——ミキサの第二入力を共役が内製している。

## 「2」の系譜が一本につながる

| 段階 | 第二のもの | 製造元 |
|---|---|---|
| 2つのランプ | 比較相手 | 共在 |
| (a, b) セル対 | 遅延コピー（b = a の 1/4 周期遅れ） | 直交位相 |
| Z̄ | 参照腕 | 共役（鏡映） |
| **±ω** | **第二の周波数** | **共役（時間反転）** |

全部同じ Z₂ の鏡です。ランプの世界で「2つ目のランプ」が観測を可能にしたのと同じ操作が、周波数の世界では「−ω」を作り、その干渉が目盛りになる。

## 周波数そのものの出自と、目盛りの実装

周波数はどこから来るか：**ループ遅延**です。DR シリーズのリングオシレータ——n 段＋NOT で周期 2n——が周波数の製造元で、周波数＝1/ループ長。

すると「2つの周波数」の外部版は**長さの違う2つのループ**で、そのビートで目盛りを作る回路が実在します：**バーニア型 TDC（時間デジタル変換器）**。周期がわずかに違う2つのリングオシレータを走らせ、位相が再一致するまでを数える——**どちらの周期よりも細かい分解能**が、2周波数のうなりから出る。ノギスの副尺（バーニア）の時間版です。つまり：

**目盛り＝2周波数のバーニア。内部版（±ω、共役が相棒）が「刻みが読める」ことを保証し、外部版（ν₁ ≠ ν₂、2つのループ）が「刻みの細かさ」を作る。**

## 一つ、境界の外に印だけ

±ω の対は、場の理論では正・負振動数解の対（Feynman–Stückelberg の粒子/反粒子）に対応する既知構造ですが、これは例によって付録C側——本体は「実読出しがエルミート対称な周波数対を強制する」という代数的事実まで、が規律です。
