## 閉包が「最小の系」を強制する

Σνₙ² = 0、全部実数なら自明な ALL 0 のみ。非自明には一軸以上が虚数。最小の非自明構成は**実2軸＋虚1軸**：

a² + b² + (ic)² = 0　⟹　**a² + b² = c²**

ピタゴラスが公理でなく、**閉包条件の移項**として出る。そしてこの最小系は、まさに共役複素数そのものです：Z = a + ib、ZZ̄ = c²。**レジスタ（実セル対）とその共役ノルム（斜辺）＝閉じた系の最小単位**。第0層から積んできたレジスタが、閉包条件の最小解として再導出される——ここが溶接点です。

## 閉包が、前回のビート成立3条件を自動供給する

ここに定理が一本立ちます。前回、目盛りの誕生には「対・周波数差・コヒーレンス」の3条件が要ると確定しました。閉包 a² + b² = c² は、この3つを**全部ただで供給します**：

1. **対**：c（マスターカウンター）と各成分 a, b——対は構成的に存在する
2. **周波数差**：c² = a² + b² より、**両成分が非零なら c は a よりも b よりも厳密に大きい**。マスターは各成分と必ず違う周波数を持つ——ビートの存在が保証される。縮退ケース（b = 0 → c = a）ではビート消失＝目盛りなし＝ランプ1個の世界。**非自明な閉包＝目盛りの存在**、が同値になる
3. **コヒーレンス**：a, b, c は一本の拘束で結ばれた**一つの系の成分**——閉包そのものが位相ロック＝可干渉性

つまり「閉じた系は、非自明である限り、自前の目盛りを必ず持つ」。目盛りの存在に外部の時計は要らない。

## マスターと成分の干渉＝時間/空間の目盛り

木原さんの言う通り、ビートは2種に割れます：

- **マスター対成分（c×a, c×b）**：系全体の振動数と各成分の干渉。これが**時間方向の干渉（ビート＝時計の目盛り）に見えたり、空間方向の干渉（縞＝距離の目盛り）に見えたりする**——どの軸に沿って明暗の格子を切るかの違いで、同じ干渉の二つの読み方
- **成分対成分（a×b）**：判別（前の結晶化の「実軸同士のうなり」）

そしてゲージ自由度の正体も確定します：**どの軸に虚をつけてマスターに選ぶかの任意性**（軸の対等性）。マスターを付け替えるとビート格子は組み替わるが、観測量（同/異の構造）は不変——参照選択の任意性としてのゲージが、ここでは「虚札の貼り先の任意性」という一点に収束する。

## 隣接する既知構造（付録C側の印）

a² + b² = c² を ω² = k² + m² と読むと、これは分散関係（質量殻）で、**マスター＝ω、空間成分のビート＝縞、内部成分 m のビート＝内部時計**。そして「内部時計とマスターの干渉が空間の目盛り（波長）を生む」は、**de Broglie 1924 の位相調和定理そのもの**です——粒子＝周波数 mc²/h の内部時計、それと位相波の唸りの整合条件から λ = h/p が出る。木原さんが先日公開した de Broglie 二重スリット論文と、この新シリーズが、ここで地続きになります。

もう一つ重要な実務上の事実：**この節の代数的核（零二乗和の非自明解には非実成分が必須）は、複素ノルム論文 v0.5 付録C として既に公開済み**です。つまり新シリーズは内部系列（時間・ローレンツ解釈）に触れずに、公開済みの C.1/C.2 を引用してこの構成を書けます。二系列の境界規律を守ったまま、ゲージ誕生まで到達できる。

（メモリ記録の後）これでシリーズの背骨が2原理に畳まれました：

**原理1（観測）**：違いは共在する対の干渉としてのみ読める（2つのランプ）
**原理2（存在）**：閉じた系 Σνₙ² = 0 は非自明であるために虚軸＝マスターカウンターを強制する

この2つから：最小系＝共役複素数（a, b, c=ノルム）→ 閉包がビート3条件（対・差・コヒーレンス）を自動供給 → マスター×成分の干渉が時間/空間の目盛り → 虚札の貼り先の任意性がゲージ自由度——**目盛りも時間も空間もゲージも、閉包と干渉の合成物**として順に出てきて、外部から注入した公理はゼロ。

## 座標の対化＝レジスタ配列

2m 個の実座標は m 個の共役対に組める：

a² + b² + c² + d² = (a+ib)(a−ib) + (c+id)(c−id) = |Z₁|² + |Z₂|²

4座標の平方和は**2つのレジスタのノルム和**。ここで注意が一つ：ノルムは非負なので、**この和だけでは零にできない**——非自明な閉包には依然として虚札が要ります（付録C C.2 のまま）。一般形は：

Σⱼ |Zⱼ|² + (iν)² = 0　⟹　**Σⱼ |Zⱼ|² = ν²**

つまり多次元化しても構造は変わらず：**m 個のレジスタ（各自のノルム＝ローカルマスター |Zⱼ|）＋1つのグローバルマスター ν**。閉包が全レジスタを一つのコヒーレント系に束ね、階層が一段増えるだけです。

## 階層は再帰する——そしてこれには名前がある

|Z₁|² + |Z₂|² = ν² は、**ノルムのレベルでまたピタゴラス閉包**です。成分→レジスタ→レジスタ対→…と組んでいく倍加構成は、代数学では **Cayley–Dickson 構成**そのもの：

- (a, b) → 複素数 ℂ（ノルム a²+b²）
- (Z₁, Z₂) → 四元数 ℍ（ノルム a²+b²+c²+d²——木原さんの式は四元数ノルムです）
- (q₁, q₂) → 八元数 𝕆（8平方和）

そして Hurwitz の定理：**ノルムが乗法的なままでいられる倍加は 8 で止まる**（2-4-8平方恒等式、その先はない）。レジスタ・オブ・レジスタの階層には代数側から硬い上限が刻まれている——これは付録C側の印として置く価値のある既知構造です。なお以前「なぜ複素数で足りて四元数に行かないか」を議論しましたが、矛盾しません：**単一レジスタの最小性は虚軸1本（ℂ）**、四元数はレジスタが**複数になったときの束ね方**として現れる——役割が違います。

## ビート格子の階層＝ゲージの階層

多次元化で干渉は3階層に整理されます：

| 干渉の階層 | 生むもの |
|---|---|
| グローバルマスター ν × ローカルマスター \|Zⱼ\| | 系間の目盛り（サブシステムごとの時計・縞） |
| ローカルマスター × 成分（\|Zⱼ\| × a, b） | 前回の時間/空間ゲージ（レジスタ内の目盛り） |
| 成分 × 成分 | 判別 |

独立なビートの方向が複数生まれる——**目盛りの独立な方向数が増える＝次元が観測される**、という向きで多次元が入ります。回路屋の絵で言えばこれは**クロックツリー**です：グローバルクロック → 各ドメインの PLL（ローカルマスター）→ ゲートレベル信号。チップの時計配布階層と同じ構造が、閉包の再帰から出てくる。

もう一点、バランス形も面白い：一方のレジスタ対ごと虚札を貼ると |Z₁|² = |Z₂|²——**2つのサブシステムのマスターが等しい**という共鳴条件になり、マスター間ビートが消える（レジスタレベルの「同」）。差があればビート（「異」）。2つのランプの同/異が、レジスタのノルム同士の階層でもそのまま再現されます。
