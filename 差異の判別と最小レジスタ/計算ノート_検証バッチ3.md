## 検証[3] Born cos² への収束 —— 厳密な可視度定理として成立

### 定理（数値で完全確認）

|W_N(θ)|² のフーリエ係数は正確に三角窓（Fejér 型）：

**|W_N(θ)|² = Σ_{j=−(N−1)}^{N−1} (N − |j|) e^{i2jθ}**

（数値確認：N=9 で j=0→9.0000, j=1→8.0000, …, j=9→0.0000、機械精度）

したがって、有限 N 核 F_N = |W_N|²/(πN) による読出し（畳み込み）は、周波数 2m の cos² 縞の可視度を**ちょうど**

**V(m, N) = 1 − m/N**（m ≥ N で 0 ＝分解能カットオフ）

に落とす。数値畳み込みでも全テスト点（N=5,9,17 × 各 m）で理論値と4桁一致。

### 意味

- **Born cos² への収束レートは 1/N に厳密に線形**。「再生核性の成立は N が支える」（会話録_5）が、可視度の閉形式として定量化された
- 1/N 族の統一：縞の鋭さ 1/(N+1)（論文検証済み）＝隣接 N 識別可能性（バッチ0）＝**可視度損失 m/N（本結果）**——すべて同じレバーの別の顔
- m ≥ N のカットオフは Nyquist の離散版：核は自分のモード内容より細かい縞を原理的に読めない
- 線引き：三角窓は標準的な信号処理（Fejér 核）と共有の数学。枠組み固有の主張は「自然の状態が有限 N である」の側にあり、この定理はその帰結の正確な形を与える

## 検証[S] Sargent 則 Q⁵ の格子セル計数 —— 再現＋小 Q 偏差の定量化

### 設定と結果

β崩壊型3体終状態（核は運動量吸収のみ）。電子・ニュートリノの運動量を整数格子（間隔1）に置き、超相対論近似 E=|p| でエネルギー殻 E_e + E_ν = Q のセル数を計数。

- **大 Q 側（Q=15〜40）の log-log 傾き = 4.972**——Sargent 則（理論値5）を格子計数が再現。**寿命＝ビート機構の「行き先セル計数」成分の検証ステップが成立**
- **小 Q 偏差の定量化**（連続体則 C·Q⁵ を Q=40 で規格化）：

| Q（格子単位） | 相対偏差 |
|---|---|
| 2 | **+91%** |
| 3 | +74% |
| 4 | +36% |
| 5 | +19% |
| 10 | +6.7% |
| 20 | +1.4% |
| 40 | 0（規格化点） |

**行き先セル数が少ない（Q が格子間隔の数倍）崩壊は、連続体位相空間則より速い**——低 Q 予言の最初の定量形。偏差は正（セル過剰）で、~10 格子単位以内で数%〜数十%。

### 線引き

- 偏差の符号・大きさはビンの取り方（幅1、E=|p| 近似）に依存し得る——頑健なのは「Q ≲ 10 格子単位で O(10%) の偏差、〜1/Q 的に収束」という形
- 物理の予言に格上げするには**格子間隔の物理値**（未知）が要る。観測可能な領域は「しきい値から格子間隔数個分」＝ endpoint 近傍、という照準は変わらず

## 検証[5] W8 スピン照合 —— 部分的整合＋判定不能の核心を特定（橋渡し予想として定式化）

### W8 の定義（原典確認）

定義 2.1：xyzt の非零本数 k でフェルミオン型（k=2）／ボソン型（k≠2）を判定し、**n＝{t, R, Q遷移} の非零本数**（フェルミオンは {R, Q遷移}）から s = n（ボソン）または s = n + 1/2（フェルミオン）。スピン2は tR/tQ/RQ の3型、スピン3は tRQ の1型。

### 整合している部分（✓）

1. **毛の資格**：W8 のスピンは配向の組合せ不変量（チャート非依存の離散ラベル）——「種類＝毛、値＝読み出し」の要求と一致
2. **ボソンの単調対応**：n = 0,1,2,3 ↔ s = 0,1,2,3——「活性な非空間軸の本数」がそのままスピン量子数
3. **1/2 の Z₂ 機構の対応候補が存在**：バッチ2で検証した対蹠 Z₂ より、**奇数セクターの波はチャート（ℝP¹）を一周すると符号反転する**——スピノルの定義的性質（2π回転で−1）が、対蹠ビットを運ぶ波として枠組み内に既に存在する。W8 のフェルミオン 1/2（k=2＝空間2軸の選択が消費する自由度）と、この奇数セクターの 1/2 が同一物か——が照合の核心

### 判定不能の核心（正直な結論）

**W8 には連続回転の作用が定義されていない**。巻き数比の描像（チャート回転 φ あたり内部位相が nφ 巻く）を検定するには、配向状態への回転作用の定義が先に要る——現状では「同じ答えか」の判定が**構成不能**であり、成否ではなく未定義。

### 橋渡し予想（照合を判定可能にする形）

**予想：非空間軸（t, R, Q遷移）の活性軸1本は、チャート回転1周あたり内部位相の巻き1単位を寄与する。フェルミオンの +1/2 は、k=2（空間2軸＝双ベクトル）状態が奇数セクター（対蹠ビットを運ぶ波）に載ることから来る。**

これが証明されれば：W8 の組合せ的スピン＝巻き数比のスピンが導出として接合し、スピン3（tRQ、SM に対応粒子なし）の実在性にも巻き数側から独立の判定が入る。反証されれば、W8 か巻き数描像のどちらかに修正が要る——どちらに転んでも情報になる、判定可能な形に到達した。
