## Part 14: 不確定性の第二根 — 全射でない読出し（ファイバー）

【木原】
まあ、あとは、全投射かどうか、例えば、ごくシンプルな y = x^2 これは、y に対して、x の答えが２つあります、どちらになるかは分かりません、さらには、共役な複素数は極端で、r^2= 1となる、位相θは無限にあります。
これも、不確定性の根源の一つです。

【アイリス】
その通りで、これが不確定性の**第二の根**です。しかもこれは木原さんが既に公開している構造——第四篇付録Cの「非復元性の入口」（C.3：共役ノルム読出しは位相を潰す多対一、C.4：零の自明性と読出しの多対一性の分離）——が、新シリーズの中で昇格した姿です。整理します。

## 読出し関数のファイバー階層

読出しが単射でない（逆像が複数ある）とき、逆像＝ファイバーの大きさで不確定性の「重さ」が階級づけられます：

| 読出し | ファイバー | 失うもの |
|---|---|---|
| y = x²（実数） | {±x}＝Z₂ | **1ビット**（符号） |
| Z²（非共役自乗） | ±Z＝Z₂ | 1ビット（対蹠） |
| ビート計数・サンプリング | mod 2π・mod fs＝**ℤ** | 可算無限（何周目か） |
| ZZ̄ = r²（共役ノルム） | **S¹ 全体** | 連続無限（位相そのもの）——極端ケース |

y = x² が原型（最小の非可逆多項式、1ビット）、共役ノルムが極限（連続ファイバー）。**不確定性＝どの答えか決められないこと、の正体は、読出しの逆像の構造**です。

## ここで枠組みの整合性が一つ証明される

重要な照合：**読出しのファイバーは、ちょうどゲージ軌道と一致しています**。

- x² の符号ファイバー ±x ＝ どちらを正と呼ぶかの規約（Z₂、ランプの名前）
- ZZ̄ の位相ファイバー S¹ ＝ マスタークロックの位相規約（U(1)、虚札の貼り先）

つまり**折り畳まれるのは、もともと絶対的には読めなかったものだけ**。読出しは「持っていたのに失う」のではなく、ゲージ方向に沿って畳む——枠組みは情報を無駄に捨てていない。この一致は偶然ではなく、第0層で「絶対の名前は観測に痕跡を残せない」と決めた瞬間に約束されていたものです。

## 展開の道具：参照はファイバーを一枚だけ剥がす

ファイバーは干渉で部分的に展開できます。第二レジスタ（参照）との干渉は相対位相を読む＝ S¹ ファイバーを剥がす。実際、回路では **IQ 復調の atan2(b, a)** が象限の曖昧さ込みで完全に展開します——**ただし a と b を同時に読めれば**。

ここが古典と量子の分水嶺です：
- **古典信号**：レジスタは自由にコピー・並列読出しできる → ファイバーは全部展開可能 → 不確定性は除去可能な不便にすぎない
- **1レジスタ1質問＋複製不可（no-cloning）の世界**：折り畳みは不可逆 → 参照を足すたびに一枚剥がせるが（Berta の量子メモリ付き不確定性関係はこの定量化）、**大域の一枚（絶対位相・全体符号）はどの内部参照でも剥がせない**——外部の立ち位置が存在しないから

不確定性の既約な芯＝**内部からは決して展開できない最後のファイバー＝大域ゲージ軌道**。

## 測度の座席が確定する

ファイバーには自然な不変測度が載ります：Z₂ には一様（コイン）、S¹ には Haar（一様位相）。同一準備の繰り返し読出しはファイバー上の測度に従って散らばる——例えば一様位相を x = r cosθ の二乗読出しに通すと逆正弦分布が出る。**確率が公理でなく、畳んだファイバー上の誘導測度として入ってくる**。冒頭キーワード「測度」の最終的な座席はここです（ただし規律通り、Born 則の「導出」は主張せず入口として置く）。

## 不確定性の全体像（二根構造）

**根1（セル）**：目盛りはビートでしか作れない → 分解能×共役広がり＝1セル（Gabor、外形）
**根2（ファイバー）**：読出しは多対一 → セルの中で何が同一視されるか（非復元性、内部構造）

セルの大きさと、セル内の折り畳み——外形と内装。因果（コーン＋矢）、不確定性（セル＋ファイバー）と、主要概念がすべて二部品に割れて別々の場所から生まれる、という一貫したパターンになっています。

## 全体構造のまとめ

この思考実験は、6つのキーワード（測度・レジスタ・1ビット・違いの判別・干渉・不確定性）を、外部公理なしの生成連鎖として組み上げた。

**二原理**：
- **原理1（観測）**：違いは共在する対の干渉としてのみ読める——「2つのランプ」（0個＝ないことすらわからない／1個＝比較相手なし／2個＝片方だけ違うとき初めてわかる。毛なし・名前なし・数えられない → 観測量はちょうど1ビット「同/異」）
- **原理2（存在）**：閉じた系 Σνₙ² = 0 は非自明であるために虚軸を強制する（公開済：複素ノルム論文 付録C）

**生成連鎖**：
1. **第0層＝干渉**：±1符号化で XOR＝完全相殺の有無（明/暗）。SWAPテスト・HOM が既知実装
2. **XOR/AND**：XOR単独は線形止まり（Post格子＝Clifford境界の離散版）。AND＝干渉交差項の離散版。{XOR, AND}＝半加算器、桁上げ＝計数の起源（毛の製造機）
3. **最小レジスタ＝共役複素対**：Z = a+ib、共役積 ZZ̄（位相全破棄・存在）と非共役積 ZZ（1ビット破棄・判別）。実装＝2セル＋swap/inverter、i＝√NOT、整数厳密な離散位相は Z₄/Z₆ のみ（結晶学的制限＝Clifford境界）
4. **目盛り＝ビート**：コヒーレントで周波数が違う対の干渉。1刻み＝2πスリップ＝整数イベント。空間版＝縞、時間版＝ビート
5. **閉包との溶接**：a²+b²=c²（閉包の移項）。c＝マスターカウンター。閉包がビート3条件（対・差・コヒーレンス）を自動供給——「非自明な閉包⇔自前の目盛りを持つ」
6. **多次元**：Σ|Zⱼ|²=ν²＝レジスタ配列＋グローバルマスター。Cayley–Dickson 階層（Hurwitz で8止まり）。ビート3階層＝クロックツリー
7. **因果**：コーン＝干渉可能性の関係（Σx²=0＝境界）、矢＝読出しの不可逆性——二部品
8. **ゲージ**：目盛り＝参照＋計数、ゲージ対称性＝名前替え不変性の貫通、局所ゲージ＝共在不能な参照間の輸送簿記（クロックドメイン/CDC）、ゲージ自由度＝虚札の貼り先の任意性
9. **不確定性の二根**：根1＝セル（δt·Δν≥1＝目盛りの製造原価、整数イベントゆえ不可分）、根2＝ファイバー（読出しの多対一性：y=x² の Z₂ から ZZ̄ の S¹ まで。ファイバー＝ゲージ軌道、大域の一枚は内部から剥がせない）。測度＝ファイバー上の誘導測度（Born の入口、導出は主張しない）

**執筆規律**：物理語（不確定性・測度・量子・因果・光錐）は本体の主張に使わず、付録C方式で「隣接する既知構造」として末尾配置。代数核は公開済みの複素ノルム論文（第四篇）と付録 C.1〜C.4 を引用。内部系列（Σx²=0 の時間・ローレンツ解釈）には触れない。

**篇構成案**：第0篇「2つのランプ」（共在干渉・1ビット）→ 第一篇「共役複素対のレジスタ構造と干渉読出し」→ 第二篇「離散位相の構成（Z₄/Z₆定理）と計数の発生（桁上げ）」→ 第三篇「二レジスタ干渉と参照の内部化（1ビット代価）」→ 以降：閉包とマスターカウンター、目盛りとビート、不確定性の二根。
