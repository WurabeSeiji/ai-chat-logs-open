# 第3巻 はじめに——検証・予言・訂正のサンドボックス

> **この巻の問い**：第1巻・第2巻で整理した台帳文法は、どこまで検証でき、どこからが未検証の仮説なのか。どの主張は予言在庫として残り、どの主張は訂正・撤回されるべきなのか。
> **この巻の答え**：第3巻は、第1巻・第2巻とは性格が異なる。本巻の主目的は、初級の理論物理学のテキストとして体系を学ぶことではなく、著者の仮説を検証し、予言候補を整理し、誤った仮説を訂正することである。そのため、標準理論物理学で検証済みではない仮説や解釈を多数含む。本巻は、確定理論ではなく、仮説検証のためのサンドボックス、すなわち実験場である。
> **この巻の約束**：計算済みの結果、標準理論との対応、未検証の仮説、予言在庫、撤回済み主張を混ぜない。強い主張ほど、根拠・未決定点・主張しないことを明示する。

**【読み下し】** 第1巻と第2巻では、なるべく読者が順に学べるように、台帳・読出し・目盛り・測定・相互作用の文法を整理してきた。第3巻は、そこから少し場所を移す。ここは教科書の本文というより、作業台である。計算できたもの、まだ仮説にすぎないもの、将来観測と照合したいもの、そして言い過ぎだったので撤回するものを、同じ台帳に並べて点検する。したがって、本巻には大胆な候補も出てくる。しかし、それらは標準理論で確認済みの事実としてではなく、検査のために置かれた候補として読む。

---

## 0.1 第3巻の位置づけ

第1巻は、観測の最小構成、二つの積、射影、零二乗和形式、離散位相、台帳、目盛り、レジスタを整理した基礎テキストである。第2巻は、その文法を、動力学、外部測定、相互作用、粒子種、崩壊、複合系、ブラックホール型読出しへ接続する応用テキストである。

第3巻は、その続きとして新しい標準理論を宣言する巻ではない。むしろ、第1巻・第2巻で出てきた主張を、次の観点から棚卸しする巻である。

| 観点 | 内容 |
|---|---|
| 検証済み | 代数的に確定しているもの、直接計数したもの、数値検証したもの |
| 対応候補 | 標準理論の既知構造と同じ形を持つが、物理的同一視まではしないもの |
| 仮説 | 本書の文法を進めるために置いたが、標準理論側では未確認のもの |
| 予言在庫 | 将来、観測可能量や数値計算と照合したい候補 |
| 訂正・撤回 | 言い過ぎ、誤実装、根拠不足により弱める、または取り下げる主張 |

この意味で、第3巻は「完成した理論の最終章」ではない。むしろ、理論を壊さずに検査するための場所である。

## 0.2 標準理論との関係

本巻には、標準理論物理学では検証されていない仮説や解釈が多数含まれる。これは欠陥を隠すためではなく、逆である。どこからが未検証なのかを本文の外へ追いやらず、読者が見える場所に置くためである。

したがって、本巻では次を徹底する。

| 区分 | 本巻での扱い |
|---|---|
| 標準理論で確立しているもの | 標準理論側の結果として尊重する |
| 本書で計算したもの | 計算条件、定義、数値結果を明示する |
| 形が似ているもの | 対応候補として扱い、同一視しない |
| 未検証の仮説 | 仮説として名乗る |
| 予言候補 | どの観測量と照合するかを残す |
| 誤った主張 | 訂正・撤回として記録する |

本巻で扱う仮説は、標準理論の確定事実ではない。また、標準理論を置き換える主張でもない。第3巻の役割は、標準理論と本書の台帳文法の間にある候補を、検証可能な形へ分解することである。

## 0.3 サンドボックスとしての第3巻

ここでいうサンドボックスとは、安全に仮説を試す実験場である。そこでは、完成した結果だけでなく、途中の計算、失敗、撤回、未定義点も価値を持つ。

第3巻では、次のような素材を扱う。

| 素材 | 扱い |
|---|---|
| 数値検証 | スクリプト、計算条件、出力結果、近似の範囲を整理する |
| 先行論文の結果 | 本文で使った自己引用や定量対応を、どこまで言えるかに分ける |
| 思考実験メモ | 本文に入れるには仮説濃度が高い候補を、予言在庫として保管する |
| 撤回済み主張 | 誤りの履歴として残し、本文の信頼性を上げる |
| 未計算候補 | 何を計算すれば前へ進むかを明示する |

本巻では、失敗した仮説を消さない。消すと、どこで線を引き直したのかが分からなくなるからである。むしろ、訂正の記録を残すことで、第1巻・第2巻の本文がどこまで安全になったのかを示す。

## 0.4 この巻で扱うもの

本巻で扱う主な候補は、次の通りである。

| 対象 | 本巻での扱い |
|---|---|
| 除外率・可視度・結晶学的制限 | 検証済みまたは計算済みの関係として整理する |
| 容量計数と $N(1)=137$ | 定義済みの直接計数と、電磁型読出しへの対応仮説を分ける |
| Sargent 則 $Q^5$ | 行き先セル計数との対応候補として整理する |
| 低 $Q$ 偏差 | 予言在庫として残す |
| 陽子安定性 | 反証可能仮説として扱う |
| W8 | 組合せ不変量候補として、到達点と未定義点を整理する |
| ブラックホール型スペクトル候補 | QNM、エントロピー係数、Hawking 放射準位候補として隔離する |
| 大域 $R$ 共有・干渉読出し | 第3巻候補の思考実験として保管する |
| 高次元ブラックホール型構造 | 図示候補・次元簿記候補として保管する |

ここに並べたものは、同じ確定度ではない。あるものは定義と計算がある。あるものは対応候補である。あるものはまだ思考実験にすぎない。第3巻の仕事は、それらを同じ強さで語らないことである。したがって、この一覧は成果一覧ではなく、検査対象の一覧である。項目に挙げたこと自体は、その正しさを意味しない。

## 0.5 この巻で主張しないこと

第3巻では、次を主張しない。

| 主張しないこと | 理由 |
|---|---|
| 標準理論物理学を置き換えた | 本巻は検証・予言・訂正の台帳であり、標準理論の代替体系ではない |
| 未検証仮説が正しい | 仮説は検査対象であって、結論ではない |
| 数値一致が物理的同一視を意味する | 一致・近似・漸近比は、対応候補であり、同一視には追加条件が要る |
| 予言在庫が観測予言として完成している | 観測量、スケール、抽出法、誤差評価が未決定のものが多い |
| 撤回済み主張をなかったことにする | 訂正記録として残し、どこで安全側へ戻したかを明示する |

この巻の読者は、「面白い仮説が出てきた」と読むだけでなく、「その仮説はどの欄に入っているのか」を常に見る必要がある。

## 0.6 読み方

第3巻を読むときは、各項目について次の六つを確認してほしい。

| 確認する欄 | 問い |
|---|---|
| 定義 | 何を数え、何を比較しているのか |
| 根拠 | 代数、直接計数、数値実験、先行論文、思考実験のどれか |
| 身分 | 定理、構成、対応、仮説、予言在庫、撤回済みのどれか |
| 未決定 | まだ何が決まっていないのか |
| 観測接続 | どの観測量・実験・数値計算と照合できるのか |
| 主張しないこと | どこまで言ってはいけないのか |

この六つを見れば、仮説の強さを取り違えにくくなる。第3巻は、本文の主張を強く見せるための巻ではなく、主張の強さを正しく弱めるための巻でもある。

## 0.7 本巻の合言葉

第3巻の合言葉は、次の一文である。

> **検証できるものは検証し、まだ検証できないものは仮説として名札を付け、誤ったものは訂正する。**

これが本巻の基準である。第1巻・第2巻で作った台帳文法を大切にするためにも、未検証のものを確定済みのように扱わない。逆に、仮説だからといって捨てもしない。検査できる場所に置く。第3巻は、そのためのサンドボックスである。
