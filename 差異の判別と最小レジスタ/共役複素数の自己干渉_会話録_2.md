【木原】
素晴らしい３Dですね、私のテーマは、奇数倍音がある場合ですが、Z1,Z3,Z5の３つを合成したイメージになりますかね？

【アイリス】
はい、まさにそのイメージです。等振幅の Z₁, Z₃, Z₅（巻き数 1, 3, 5 の三本の螺旋）の合成として作りました。

（成果物: odd_harmonics_synthesis_3d.html — three.js によるインタラクティブ3D可視化）

作る前に代数を整理すると、きれいな構造が出ます：

**W(θ) = e^{iθ} + e^{i3θ} + e^{i5θ} = e^{i3θ}(e^{-i2θ} + 1 + e^{i2θ}) = (1 + 2cos 2θ)·e^{i3θ}**

つまり奇数倍音三本の合成は、**中央倍音（n=3）の巻き数を持ち、半径が 1+2cos 2θ で脈動する螺旋**に厳密に一分解されます。3D で見ると、単一モードの一定半径螺旋と違い、W（ピンク）は膨らんだり潰れたり、節（半径ゼロ）を通過して符号反転しながら進みます。

そして射影の階梯が前回と同じ形で、しかし一段豊かになって現れます：

- **W + W̄ = 2(cos θ + cos 3θ + cos 5θ) = sin 6θ / sin θ**（黄）：θ = 0, π に鋭く局在した波。御論文の奇数倍音局在波そのものです
- **Σ ZₙZ̄ₙ = 3**（緑）：Parseval 直線。モード毎の零射影の総和で、依然 θ 完全消去
- ただし **|W|² = (1 + 2cos 2θ)²** は定数では**ない**——交差項 ZₘZ̄ₙ (m≠n) が θ を運ぶ

この最後の点が単一モードとの決定的な差です。単一モードでは ZZ̄ が θ を完全消去しましたが、多モードでは「対角項（保存・零射影）」と「交差項（干渉・部分射影）」が分離し、Born 分布の形は交差項側に棲む。再生核の議論がここに接続するはずです。

断面ベクトルは周転円方式（Z₁ → +Z₃ → +Z₅ の連結）にしたので、三本の腕がどう畳まれて合成 W になるか、θ を回すと視覚的に追えます。
