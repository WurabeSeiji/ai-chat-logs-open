# 第14章 寿命と崩壊——行き先セル・Sargent則・陽子安定性

> **この章の問い**：なぜ寿命や崩壊率があるのか。粒子は「壊れやすい」から崩壊するのか、それとも別の読出し束へ移る記録の頻度として読むべきなのか。
> **この章の答え**：本章では、寿命を、内部モードの読出し束が別の読出し束へ移る有効頻度として扱う。崩壊には、行き先セル、保存量整合、共有境界、接続、頂点写像、記録追記が必要である。Sargent 則の $Q^5$ 型は、三体終状態の行き先セル計数として接続しうる候補であり、格子計数では大きな $Q$ 側でその指数に近い振る舞いが確認できる。ただし、これは崩壊率全体や弱い相互作用を導出したという意味ではない。低 $Q$ 偏差と陽子安定性は、反証可能な仮説候補として扱う。

**【高校向・読み下し】** 粒子の寿命というと、物が古くなって壊れるようなイメージを持ちやすい。しかし、この本では少し違う。粒子が崩壊するとは、ある読出し束が、境界と接続と頂点写像を通じて、別の読出し束として記録されることである。壊れやすさだけではなく、「どの行き先に行けるか」「保存量が合うか」「その行き先が何通りあるか」「記録に落ちるテンポがあるか」が効く。だから寿命は、硬さではなく、崩壊として読める記録がどれくらいの頻度で立つかの有効表示である。

先に用語をほどいておく。**寿命**とは、同じ粒子種として再識別される読出し束が、別の読出し束へ移る記録の平均間隔として読む量である。**崩壊率**とは、その移り変わりが単位読出し時間あたりに記録される有効頻度である。**行き先セル**とは、保存量・境界条件・内部モード条件を満たして、崩壊後の読出し束として記録されうる候補のことである。**Sargent 則**とは、ベータ崩壊型の寿命や崩壊率に現れる $Q^5$ 型の経験的・位相空間的な振る舞いを指す。**低 $Q$ 偏差**とは、行き先セルが少ない領域で、連続体近似からずれる候補である。**陽子安定性仮説**とは、陽子型の読出し束には許された行き先セルがない、または巻き数保護があるため崩壊ビートが立たない、という反証可能仮説である。（いずれも→用語集）

## 14.1 第VI部の中での位置

第13章では、粒子種を、外部測定で安定に再識別できる内部モードの読出し束として扱った。そこでは、電子型、光子型、中性質量型、閉じ込め型などを、標準模型の粒子表ではなく、台帳上の読出し候補として整理した。

本章では、その読出し束が変わる場合を見る。つまり、ある粒子種として読めていた束が、別の粒子種の組として記録される場合である。

ただし、本章でも、標準理論の崩壊計算を置き換えない。崩壊率を実際に計算するには、相互作用の種類、結合定数、行列要素、位相空間、スピン和、選択則、くりこみなどが必要である。本章が扱うのは、その手前にある読出し文法である。

| 層 | 本章で扱うこと | まだ扱わないこと |
|---|---|---|
| 寿命 | 崩壊記録が立つ平均間隔として読む | 個々の粒子の実測寿命の導出 |
| 崩壊率 | 行き先セルと頂点写像を通じた有効頻度として読む | 標準理論の行列要素計算 |
| Sargent 則 | $Q^5$ 型を行き先セル計数の候補として読む | 弱い相互作用や核行列要素の導出 |
| 低 $Q$ 偏差 | セル数が少ない領域での格子計数偏差候補 | 実験値への直接換算 |
| 陽子安定性 | 行き先不在または巻き数保護の反証可能仮説 | 陽子崩壊禁止の完全証明 |

この章は、粒子種の安定性を語る章である。同時に、次の検証編へつながる予言在庫の入口でもある。

## 14.2 寿命は壊れやすさではなく崩壊ビートの読出しである

日常語では、寿命は「どれくらい壊れにくいか」と読まれやすい。しかし、本書では、寿命を内部構造の硬さだけでは定義しない。

本章では、寿命を次のように読む。

> **寿命 ＝ ある読出し束が、別の読出し束へ移る記録が立つ平均間隔。**

したがって、崩壊率は次のように読む。

> **崩壊率 ＝ 崩壊記録が単位読出し時間あたりに立つ有効頻度。**

この見方では、粒子が崩壊するには、少なくとも二つのものが必要である。

| 必要なもの | 読み |
|---|---|
| 行き先 | 崩壊後として記録されうる読出し束 |
| ビート | 崩壊前後を照合し、記録へ落とす有効頻度 |

行き先がなければ、崩壊は記録として立たない。ビートがなければ、崩壊が起きる時計が立たない。したがって、寿命の長さは、単に粒子が硬いかどうかではなく、行き先セルの数、共有境界、頂点写像、保存量整合、接続整合の組み合わせとして読む。

ここでいうビートは、背景時間に外から置かれた絶対時計ではない。第7章以降の言葉で言えば、記録列に沿って比較可能な位相増分率の関係として出る有効なテンポである。

## 14.3 崩壊の最小構図

第11章では、相互作用の最小構図を

$$
\text{系Aの台帳}
\quad+\quad
\text{系Bの台帳}
\quad+\quad
\text{共有境界}
\quad+\quad
\text{接続}
\quad\longrightarrow\quad
\text{外部記録}
$$

として置いた。崩壊は、この構図のうち、始状態と終状態の読出し束が異なる場合である。

本章では、崩壊の最小構図を次のように書く。

$$
\text{始状態の読出し束}
\quad+\quad
\text{行き先セル}
\quad+\quad
\text{共有境界}
\quad+\quad
\text{接続}
\quad+\quad
\text{頂点写像}
\quad\longrightarrow\quad
\text{終状態の外部記録}
$$

ここで「行き先セル」とは、崩壊後の粒子種・運動量・内部モード・境界条件の候補である。セルという言葉は、連続空間の点ではなく、外部測定で区別可能な記録単位を表している。

崩壊が成立するには、少なくとも次が必要になる。

| 条件 | 内容 |
|---|---|
| 保存量整合 | 質量型、電荷型、角運動量型などの読出しが前後で矛盾しない |
| 境界整合 | 始状態と終状態を照合する共有境界がある |
| 接続整合 | 位相原点・局所フレーム・スケールの換算ができる |
| 頂点写像 | 始状態の束を終状態の束へ移す局所規則がある |
| 記録可能性 | 終状態が外部記録として区別できる |

この表は、標準模型の崩壊頂点を導出したものではない。標準理論側の相互作用頂点を読む前に、台帳の側で何をそろえなければならないかを分けたものである。

## 14.4 行き先セルと保存量

崩壊では、行き先が多いほど、一般に崩壊記録が立ちやすくなる。これは、同じ始状態から到達できる終状態の候補が多いほど、記録へ落ちる経路が増えるからである。

本章では、行き先セルを次のように読む。

> **行き先セル ＝ 保存量・境界条件・内部モード条件を満たし、外部記録として区別可能な終状態候補。**

行き先セルを数えるとき、次を混同してはいけない。

| 混同してはいけないもの | 理由 |
|---|---|
| エネルギー差 $Q$ と崩壊率そのもの | $Q$ は行き先セル数に効くが、結合や頂点写像を含まない |
| 行き先セル数と行列要素 | セル数は数え上げであり、各セルへの重みは別に必要 |
| 保存量整合と崩壊の必然性 | 保存量が合っても、頂点写像がなければ崩壊は立たない |
| 行き先不在と存在不可能性 | 本書の外部読出しでは崩壊記録が立たない、という主張に限る |

模式的には、崩壊率は

$$
\Gamma
\sim
\text{試行テンポ}
\times
\text{行き先セル数}
\times
\text{モード共有窓}
\times
\text{頂点写像重み}
$$

のような成分に分けて考えられる。ただし、この式は標準的な崩壊率公式ではない。どの成分をどう掛けるか、どの測度で積分するか、どの行列要素を使うかは、具体理論側の問題として残る。

本章で使うのは、このうち「行き先セル数」という一成分である。

## 14.5 Sargent 則 $Q^5$ をどこまで読むか

ベータ崩壊型の過程では、崩壊エネルギー $Q$ と崩壊率の間に、$Q^5$ 型の振る舞いが現れることが知られている。これはしばしば Sargent 則として参照される。

本書では、この $Q^5$ 型を、まず行き先セル計数の候補として読む。

三体終状態に近い崩壊では、電子とニュートリノ型の自由度が終状態の位相空間を作る。連続体近似では、利用できるエネルギー幅が大きくなるほど、終状態のセル数が急に増える。その代表的な形が

$$
N(Q)\propto Q^5
$$

である。

直感的には、$Q$ が少し大きくなるだけで、終状態の粒子たちへ運動量やエネルギーを割り振るマス目の組み合わせが急増する。$Q^5$ 型は、この行き先セルの組み合わせの増え方を連続体で粗く読んだ顔である。

本書の検証ノートでは、電子型・ニュートリノ型の運動量を整数格子に置いた単純なセル計数で、大きな $Q$ 側において log-log 傾き $4.972$ が得られている。これは、Sargent 則の指数 5 に近い。したがって、少なくとも「行き先セル数が $Q^5$ 型を作る」という成分は、この台帳読みと相性がよい。

ただし、ここから弱い相互作用の崩壊率は出ていない。実際のベータ崩壊には、弱い相互作用の結合、核行列要素、フェルミ関数、スピン和、選択則、放射補正などが関わる。本章が確認しているのは、崩壊率の一部としての行き先セル計数が、標準的な $Q^5$ 型表示へ接続しうる、ということだけである。

| 言えること | 言えないこと |
|---|---|
| 行き先セル計数は $Q^5$ 型と接続しうる | Sargent 則を台帳だけから完全導出した |
| 格子計数で大きな $Q$ 側の指数に近い振る舞いが出る | 個々の核種の半減期を計算した |
| $Q$ は行き先セルの増加に効く | 崩壊率は $Q$ だけで決まる |

## 14.6 低 $Q$ 偏差は何を意味するか

連続体近似では、行き先セルはなめらかに増える。しかし、台帳側でセルが離散的であるなら、$Q$ が小さい領域では、セル数の粗さが見える可能性がある。

本章では、これを低 $Q$ 偏差候補として扱う。

> **低 $Q$ 偏差 ＝ 行き先セル数が少ない領域で、連続体の $Q^5$ 型からずれる候補。**

検証ノートの単純な格子計数では、$Q$ が格子間隔の数倍程度の領域で、連続体則からの偏差が現れた。たとえば、規格化の取り方に依存するが、$Q=10$ で数パーセント程度、より小さい $Q$ でより大きな偏差が出る。

ここで重要なのは、偏差の数値そのものを実験予言として直ちに使わないことである。物理的な予言にするには、格子間隔に相当する物理スケール、終状態の質量、測定分解能、行列要素、実験で見る endpoint 近傍の扱いが必要になる。

したがって、本章で言えることは次に限る。

| 区分 | 内容 |
|---|---|
| 計算で確認したこと | 単純な格子セル計数では、大きな $Q$ 側で $Q^5$ 型に近づき、小さい $Q$ 側で偏差が出る |
| 仮説 | 実際の低 $Q$ 崩壊にも、行き先セルの離散性が endpoint 近傍で痕跡を残す可能性 |
| 未決定 | 格子間隔の物理値、偏差の符号、実験での抽出法 |
| 主張しないこと | 既存の半減期データをこの章だけで説明した |

この低 $Q$ 偏差は、予言在庫としては面白い。しかし、本章では予言の完成ではなく、観測可能量へ接続する候補として残す。

## 14.7 陽子安定性：硬さではなく行き先の不在

陽子は、標準模型の範囲では非常に安定な粒子として扱われる。一方、多くの大統一理論では、陽子崩壊が非常に長い寿命で起こりうると予想される。

本書では、陽子安定性を次の形の反証可能仮説として置く。

> **陽子安定性仮説 ＝ 陽子型の読出し束には、許された行き先セルがない、または巻き数保護があるため、崩壊ビートが立たない。**

この仮説の要点は、陽子が硬いから壊れない、ということではない。崩壊後として記録されうる読出し束が、保存量・境界・頂点写像・巻き数条件を同時に満たさないなら、崩壊記録が立たない、という読みである。

| 保護候補 | 読み |
|---|---|
| 行き先不在 | 保存量を満たす終状態セルが台帳上で立たない |
| 巻き数保護 | 内部モードの巻き数が、頂点写像でほどけない |
| 境界不整合 | 始状態と終状態を照合する共有境界が作れない |
| 接続不整合 | 位相原点や内部フレームの換算が閉じない |

ただし、これは陽子安定性の証明ではない。陽子型の質量、内部モード、可能な終状態、頂点写像、巻き数保存則を具体的に構成しなければ、完全な判定にはならない。

この仮説は強い。もし陽子崩壊が一事象でも確実に観測されれば、「陽子型には崩壊ビートが立たない」という強い形の仮説は退けられる。したがって、本章では陽子安定性を、標準理論の確定事実ではなく、反証可能な予言候補として扱う。

## 14.8 崩壊率を導出したと言わない理由

本章では、寿命、崩壊、行き先セル、Sargent 則、低 $Q$ 偏差、陽子安定性を同じ台帳文法に置いた。しかし、崩壊率を導出したとは言わない。

理由は明確である。崩壊率には、少なくとも次の層が必要である。

| 必要な層 | 内容 |
|---|---|
| 相互作用の種類 | どの頂点写像が許されるか |
| 結合定数 | 頂点写像がどの強さで働くか |
| 行列要素 | 始状態と終状態の重なりや選択則 |
| 位相空間 | 終状態セルの測度と積分 |
| 内部表現 | スピン、ヘリシティ、内部ゲージ表現 |
| 補正 | 放射補正、くりこみ、環境依存 |

本章で扱った行き先セル数は、このうちの一部である。行き先が多いほど崩壊しやすい、という方向は自然である。しかし、各行き先への重みがゼロなら崩壊しないし、頂点写像がなければセル数だけでは何も起きない。

したがって、本章の主張は、崩壊率の完全計算ではなく、崩壊率を読むために必要な台帳項目の整理である。

## 14.9 本章の境界

本章で確定したことと、まだ置いていないことを分ける。

| 区分 | 内容 |
|---|---|
| 定義 | 寿命、崩壊率、行き先セル、低 $Q$ 偏差、陽子安定性仮説 |
| 構成 | 崩壊を、読出し束が共有境界と頂点写像を通じて別の読出し束へ記録されることとして置いた |
| 計算との対応 | 行き先セル計数が大きな $Q$ 側で Sargent 則 $Q^5$ 型に接続しうること |
| 仮説 | 低 $Q$ 偏差、陽子型の行き先不在、巻き数保護 |
| 主張しないこと | 弱い相互作用、核行列要素、個別半減期、陽子安定性、陽子崩壊禁止の導出 |

本章の役割は、寿命と崩壊を、壊れやすさではなく、行き先セルと崩壊ビートの読出しとして整理することである。次章では、粒子単体からさらに進み、複合系・もつれ・記録の共有がどのように読まれるかを見る。
