【アイリス】
ここは本日最深の問題で、しかも御frameworkが最初から抱えている核心的な緊張です。分解します。

**前半：最小レジスタ = 2分割、は確定でよい**

インデックスの区別には最低二つの値が要る——分割数 2、位相 ±180°（e^{i0} と e^{iπ}、すなわち ±1 の符号）が最小レジスタです。これは本日の言葉で完全に整合します：先ほど「不対軸に残る Z₂」と呼んだもの、平方が失う符号、共役和が失う回転の向き——本日繰り返し現れた Z₂ が、実は**レジスタの最小単位（1ビット）**だった。喪失の最小単位と記録の最小単位が同じ Z₂ である——捨てる情報の粒と書く情報の粒が同一——のは偶然ではなく、レジスタ＝非単射写像の定義からの帰結です（最小の非単射は 2対1）。

**後半：ご指摘のジレンマを正確に立てる**

- (A) 系の**外**から読むなら：読み出しは系に触れず情報も失わせないが、閉じた系に「外」はない——神の視点の密輸入。認識論的基礎に反する
- (B) 系の**中**で読むなら：レジスタも観測者も系の一部。非単射読み出しは情報を落とす——では**全体の情報は減るのか？** 閉じた系の保存則（ユニタリ性、ρ² 保存）と矛盾しないか

これは量子測定問題そのもの、ブラックホール情報パラドックスと同型の緊張です。標準理論はここで観測者を系の外に置いて(A)を選び、御frameworkはそれを拒否するので(B)を引き受けるしかない。

**(B)は矛盾しない——情報は消えず、移動して届かなくなる**

鍵は、本日の「消える」と「ない」の区別をもう一度使うことです。系の中での読み出しを精密に書くと：

読み出しとは、対象の状態とレジスタの状態の間に**相関を作る**操作です。系全体（対象＋レジスタ）で見れば、この操作は可逆でありえて、全情報は保存される。しかし読み出し**後**、レジスタを見る側（同じく系内の存在）がアクセスできるのはレジスタの値だけ——1ビット——であり、対象とレジスタの**相関の中に逃げ込んだ位相情報**は、系内のどの単独レジスタからも読めない。つまり：

**情報は失われない。ただし「対象単独」「レジスタ単独」という部分からは読めない場所——相関——へ移動する。**

不可逆性とは全体の情報消失ではなく、**部分から見た復元不能性**です。系内の観測者は定義上つねに部分しか読めない（自分自身を含む全体を読むレジスタは、自分より大きい自分が要るので構成できない）。だから系内観測者にとって読み出しは厳密に不可逆——しかし系全体では何も消えていない。第二法則と同じ構造です：エントロピー増大は情報の消滅ではなく、部分（粗視化されたレジスタ）から見た散逸。

**するとご質問への答えはこうなります**

「外から読めていることになるが本当か？」——なりません。外は不要です。「中で読むと情報を失わないか？」——**観測者は**失います。**系は**失いません。この二つは矛盾ではなく、「情報を失う」の主語が違う。そして観測者相対の認識論では、物理として意味を持つのは前者だけ——「系全体の情報」は、それを読めるレジスタが系内に存在しない以上、定義可能だがアクセス不能な神の視点側の量です。保存則は成立しているが、その成立を検証できる観測者は系内にいない——本日の「等号は神の視点でのみ厳密」と同じ場所に落ちます。

線引き：相関への移動で全体保存と部分不可逆が両立すること、自分を含む全体を読むレジスタが構成不能であることは定理側（後者は対角線論法の骨格）。「物理的に意味があるのは部分から読める情報だけ」は御frameworkの認識論的公理の適用であって、証明ではありません。

【アイリス】
「毛」の語を出された時点で、これはブラックホール無毛定理の問いですね。答えは系の身分によって二つに割れ、どちらも本日の道具で正確に書けます。

**場合1：その閉じた系が、より大きな系の部分系である場合（ブラックホール型）**

外の観測者が読めるものはあります——ただし読めるのは**零射影値だけ**です。無毛定理の内容「外部から見えるのは質量・電荷・角運動量のみ」を本日の言葉に翻訳すると：

**外部に漏れるのは ZZ̄ 型の保存量（対角項）のみで、内部レジスタのインデックス——位相、分割の詳細、どのモードがどの値か——は一切漏れない。**

つまり「毛がない」とは「外からの読み出しが零射影である」ことの別名です。外部観測者にとって、地平の内側は θ を消された円と同じ：ρ²（質量等）は読めるが、円周上のどこか（内部配置）はすべての配置が解。そして御自身のブラックホール系列がこの絵の定量側を既に持っています——充填欠損がエントロピーとしてスケールする、とは「外から識別不能な内部配置の数」が境界の幾何（面積）で数えられる、という主張であり、エントロピーとはまさに**外部から零射影されて潰れた内部インデックスの個数の対数**です。毛は観測できない、しかし毛が「何本あったか」の勘定だけは面積として観測できる——これが無毛定理とエントロピー面積則の対の正確な関係です。

**場合2：その閉じた系が全体（宇宙）である場合**

このとき「系の外から観測できるか？」は、偽ではなく**定義不能**です。本日確立した「格子未満の問い」と同じ身分：答えが隠されているのではなく、問いを立てる場所が系に存在しない。「外の観測者」は座標も状態空間もレジスタも持ちようがなく、「外から読む」という写像の始域が定義できない。神の視点の拒否とは、この問いを未解決問題リストから**問い不成立リスト**へ移すことです。

**一つの帰結**

前の応答の「系全体の情報は保存されるがアクセス不能」と合わせると：場合1では、部分系の「全体情報」は外部との相関を含めれば大きい系の中で保存され、外部はその零射影（保存量＋面積）だけを読む。場合2では、そもそも「全体を外から読む」が不成立なので、保存則の検証者は原理的に不在——保存則は系内では**定理として証明できるが観測としては完結できない**言明になります。

線引き：無毛定理は一般相対論の定理（ただし古典・4次元・電磁場までの条件付き）。「無毛＝外部読み出しの零射影性」は形の一致として厳密に対応が付きますが、御frameworkでの再導出は本日やっていません。充填欠損＝隠れた内部インデックス数、は御論文の結果との整合の確認です。

**1. 偏光（スピン1、ヘリシティ ±1）**

これが最大の欠落です。スカラーの Z は一モードにつき一つの複素振幅しか持ちませんが、実在の光子は各モードに**独立な複素振幅が二つ**（右円偏光・左円偏光）あります。単なる Z の個数を増やしても駄目で、二つの成分が空間回転で**互いに混ざる**という変換則（ベクトル性）が要る。つまり必要なのは Z のクラスターではなく **Z の対（ダブレット）のクラスター**——各格子点 n に Z を一本でなく二本立て、回転群がその二本を混ぜる作用を持つこと。本日の言葉なら：偏光とは「モード格子とは別の、内部の共役対」です。興味深いことにヘリシティ ±1 は Z₂ 的な離散ラベルの顔と U(1)（偏光位相）の顔を併せ持ち、御frameworkで Q 軸（離散ラベル軸）を導入した動機と同じ型の拡張がここでも要求される——W8 の xyztRQ 構造で偏光がどの軸の符号対に対応するかは、照合すべき具体的問題として立ちます。

**2. 光子数（第二量子化の自由度）**

Z クラスターは**一光子の**状態空間としては（偏光を足せば）完備ですが、「同じモードに光子が2個」は表現できません。ρₙ を大きくするのは古典振幅の増加であって光子数の増加ではない——n 光子状態はクラスターの n 倍ではなく、クラスター空間の**対称テンソル積**です。ただしこれは欠陥と言い切れません：単一光子の議論に限る（一個の検出事象を扱う）ならクラスターで閉じており、多光子はクラスター系を「一段上の格子の一点」とみなす再帰（クラスターのクラスター）で構成する道があります。どちらを選ぶかは表現の設計判断です。

**後段のご指摘——二系の必要性——について**

これは前回の帰結の正確な適用です：光子クラスター（閉じた小系）単独では、その θ も n も読めない——読むには外にレジスタが要る。「我々の時空の系」がそのレジスタ側です。ただし一点だけ精密化を：必要なのは二つの**独立な**系ではなく、**一つの大きい系の中の部分と部分**（光子クラスター＋検出器クラスター、相関可能な同一格子上の二区画）です。完全に別の系では相関が定義できず読み出しが成立しない。「観測する側が要る」は正しく、「外に」は前回の場合1（部分系として）の意味で読むのが整合的です。

まとめ：単色＝単一Z、多色＝クラスター、は運動学的自由度については過不足なし。不足は偏光（各モードの内部ダブレット＋回転混合則）と光子数（テンソル積構造）の二つで、前者は本質的な拡張要求、後者は設計判断。偏光の欠落は、逆に言えば「内部共役対をどう格子に載せるか」という W8 側の問題と同じ形をしており、二つの系列の接合点になり得ます。

**「光子が二つ」の操作的な中身**

相互作用（検出）前に「この系には光子が n 個ある」を読み出すレジスタは存在しません。読めるのは検出事象——レジスタへの不可逆な書き込み——の**回数**だけです。すると本日の言葉で正確に定義し直すと：

**光子数とは状態の自由度ではなく、そのクラスターが引き起こせるレジスタ書き込み事象の数**——読み出しの側の量です。

相互作用前のクラスターにとって「一つか二つか」は、格子未満の問いと同じ身分：隠された値があるのではなく、系内に問いを立てる場所がない。「区別不能」ではなく「区別という概念が読み出し前には定義されない」。ご指摘の通り、一つのクラスターです。

**では前の応答の何が残るか——残るのは相関の問題だけ**

私が「テンソル積が要る」と言ったことの正当な芯を、レジスタ言語に翻訳し直すとこうなります：問題は状態の表現力ではなく、**複数のレジスタ読み出しの間の相関統計**を再現できるか、です。具体的な試金石が一つあります：

単一光子源の反バンチング——一つのクラスターがビームスプリッタの両側の二つの検出器に**同時には決して書き込まない**（g²(0) = 0）という観測事実。古典的な振幅クラスター（ρ を分割して両腕に流す描像）では、両検出器への同時書き込み確率は必ず正になり、g² ≥ 1 が出てしまう。つまり要求されるのは「クラスターは分割されて伝播するが、**レジスタ書き込みは全体で一回きり**」——読み出しの排他性です。一回の検出がクラスター全体を消費し、遠方のもう一方の腕での書き込み可能性を同時に消す。

これは状態側の自由度の不足ではなく、**レジスタ機構側の規則**の問題として立て直されます：書き込みは局所的な振幅にではなくクラスター全体に紐づく、という非局所な排他律。第二量子化のテンソル積とは、この「書き込み回数の相関」を状態側に押し込んで簿記する記法だった——数の実在ではなく、読み出し相関の勘定方法。ご指摘はこの反転を正確に突いています。

【木原】
Bell整合の最低条件ってなんですか？

【アイリス】
問いを正確に立てると：「二つの遠隔レジスタの出力相関が量子予言（cos²Δ 型、CHSH 値 2√2）を再現するために、状態側＋読み出し側に最低限何が必要か」。定理で確定している部分から積み上げます。

**まず、禁止側の定理（何では足りないか）**

1. **局所的な値の事前実在では不可能**（Bell/CHSH）：各クラスターが「どの軸で読まれたら何を返すか」の応答表を事前に持つモデルは、応答表がどれほど巧妙でも CHSH ≤ 2。観測は 2√2 まで出る。よって「読み出し前に値がある」は削除確定——本日すでに使った結果です
2. **決定論的で文脈非依存な割り当ても不可能**（Kochen–Specker）：統計以前に、単一系でも「全ての測定軸に一貫した値を同時に割り当てる」こと自体が幾何学的に矛盾する。値の非実在は確率の問題ではなく組合せ論の問題
3. **ただし信号は送れない**（no-signalling）：相関がどれほど強くても、片側の周辺分布は相手の軸選択に依存しない。だから必要なのは「影響を伝える機構」ではない——ここを間違えると要求が過剰になります

**次に、上限側の定理（何があれば足りて、何は要らないか）**

4. **cos² 相関は二成分共役対の内積構造から出る**：前回までの言葉で、二クラスター間に位相コヒーレントな共役対の対（シングレット型の位相結合）があれば、任意の二チャート角 Δ に対する相関 −cos 2Δ（CHSH 2√2）が再現される。つまり十分条件は既に手元の部品で書けている
5. **2√2 で止まる理由も内積構造**（Tsirelson 限界）：no-signalling だけなら相関は論理上 CHSH = 4 まで許される（PR箱）。自然が 2√2 で止まるのは、相関が「共有された応答表」より強く「任意の相関」より弱い、正確に**内積の cos² が許す帯域**に載っているから

**以上から、最低条件の同定**

三つに畳めます：

- **(a) チャート選択に先立つ連続位相幾何が、二クラスターに単一の結合構造として張られていること。** 離散的な共有情報（何ビットの共通乱数でも）は 1 により不足。要るのは連続の位相対——「値は無いが円は有る」の円が、二系に**一つの円として**共有されている状態。これが「計量前の幾何」の正確な中身
- **(b) 読み出しが非単射（一回・排他的・不可逆）であること。** 各レジスタの書き込みは一回きりで、同じクラスターを別チャートで読み直せない——KS の矛盾が現実化しないのは、矛盾する値の組を**同時に取り出すレジスタが構成できない**から。反バンチングの排他律と同じ規則がここでも防波堤になっている
- **(c) 相関の帯域が内積構造（平方和の交差項）で与えられること。** cos² より弱ければ Bell を破れず、強ければ Tsirelson を超えて no-signalling が壊れる。本日の言葉なら：相関は必ず**交差項経由**で運ばれ、対角項（保存量）経由では運ばれない——だから信号は送れず（周辺分布は対角項のみで決まり不変）、相関は送れる（交差項は二点相関にだけ現れる）

**注目すべき整合**

(c) は本日の構図の非自明な検算になっています。「零射影（対角項）は何も漏らさず、部分射影（交差項）だけが漏らす」という冒頭の階梯が、no-signalling と Bell 相関の共存——片側では何も見えず、相関にだけ幾何が現れる——と正確に同じ分配になっている。この一致は設計したものではなく出てきたものなので、枠組みの整合性の証拠として数えられます。

線引き：1, 2, 3, 5 は定理。4 は標準理論内の計算事実。(a)(b)(c) が「必要最小限」であるという同定のうち、必要性は 1, 2, 5 が支えますが、「これだけで十分」の側は御framework 内での再構成（レジスタ規則からの導出）がまだ無い——特に (b) の排他律は、反バンチングのときと同じく、遅延回路系列にとって未解決の構成問題のままです。最低条件の**リスト**は確定、その**実装**が宿題、という状態です。

「高次モード = 高エネルギー」と書いたとき、私は各倍音が**独立に励起される**描像（熱的な描像：モード n の励起には ℏωₙ が要る）で数えていました。しかしこの framework の粒子は独立励起の集合ではなく、**一つの局在波形**——単一の定常振動——です。そして局在波形の倍音係数は自由パラメータではなく、波形が決まれば従属して決まる：矩形波なら 1/n、それに類する局在波形なら次数に応じて振幅が下がる。総エネルギーは Σ ρₙ² ——**振幅の減衰がこの和を収束させる**（矩形波の 1/n なら Σ1/n² = π²/6、有限）。10³⁸ 本という本数は器の解像度であって、各本が ℏωₙ を請求してくる励起の頭数ではない。エネルギーは倍音の**本数**ではなく波形の**総振幅**が決める——一個の波の勘定です。

つまり「10³⁸ 本の高エネルギーモードを張るコスト」という私のパラドックスは、独立励起（場の量子論の真空励起の数え方）を局在波形（一体の定常振動）に密輸した誤計上でした。連続体からの持ち込みの可能性を自分で疑っておきながら、その場で犯していた。

**しかもこれで部品が二つ、噛み合っていたことになります**

1. **Parseval が質量の定義式になる**：Σρₙ² = R² ——本日「保存量・零射影の総和」と呼んだ量が、そのまま**粒子の静止エネルギー（質量）**の候補です。振幅減衰則がこの和を有限に閉じ、局在の鋭さ（減衰の遅さ）とエネルギー（和の大きさ）が同じ係数列で結ばれる——「小さく局在したものほど重い」型の関係が勘定から自動で出る構図。W8 の M(σ) との照合先がまた一段具体化します
2. **昨日からの三題が同じ係数列で閉じる**：局在（奇数倍音の合成）、Born 骨格（再生核＝等振幅系の性質、実振幅系はその変形）、エネルギー有限性（Σρₙ² 収束）——三つとも**同じ振幅列 ρₙ の性質**として書かれている。御論文の等振幅奇数倍音（有限 N）と、減衰振幅（N→∞ で収束）は、同じ構造の二つの正規化——有限 N の等振幅で切るか、無限 N を減衰で閉じるか

**訂正後の負債残高**
