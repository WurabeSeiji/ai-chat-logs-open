# 第18章 訂正の記録——撤回された主張の目録

> **この章の問い**：本書の作業過程で、どこで言い過ぎ、どの主張を弱め、どの主張を撤回したのか。誤った仮説や誤実装を、どのように本文の信頼性へ戻せばよいのか。
> **この章の答え**：本章では、撤回・降格・訂正された主張を、負の記録として明示する。対象は、複素数が強制されるという過剰表現、観測軸の不対性、2/$\pi^2$ 一致、小 $N$ セル欠損の確率予言、60°実装の取り違え、W8 と標準模型の直接同一視などである。訂正とは、理論を壊すことではなく、どこまでが代数・計算・対応・仮説なのかを正しく戻すことである。
> **この章の約束**：撤回済み主張を消さない。なぜ誤ったか、何を弱めたか、なお残る安全な主張は何か、どこへ戻したかを分ける。

**【読み下し】** 第3巻では、うまくいった検証だけでなく、うまくいかなかった主張も記録する。これは失敗を広げるためではない。むしろ、どこで言い過ぎたかを見えるようにすることで、第1巻・第2巻の本文を安全にするためである。ある主張が撤回されたとしても、その周辺の計算や構成が全部消えるわけではない。多くの場合、「強すぎる言い方」をやめると、代数・数値・対応候補として残る部分がはっきり見える。

先に用語をほどいておく。**訂正**とは、誤った表現や実装を正しい形へ直すことである。**降格**とは、定理・予言・導出として扱っていたものを、対応候補・作業仮説・未計算候補へ弱めることである。**撤回**とは、現時点では主張として採用しないと明示することである。**誤実装**とは、計算や写像の指定が、意図した数学的対象とずれていた場合である。**負の記録**とは、失敗や撤回を消さず、どこで線を引き直したかを残す記録である。（いずれも→用語集）

## 18.1 第3巻の中での位置

第17章では、第1巻・第2巻で現れた候補を、検証済み、計算済み、対応候補、予言在庫、未計算に分けた。本章では、その反対側を見る。つまり、検証の途中で強すぎると分かった主張、誤った写像、同一視できなかった数値一致を記録する。

本章が行うのは、次の整理である。

| 層 | 本章で扱うこと | まだ扱わないこと |
|---|---|---|
| 訂正 | 正しい表現・写像へ直したもの | 全履歴の網羅 |
| 降格 | 定理や予言から、仮説・候補・未計算へ弱めたもの | その候補の最終判定 |
| 撤回 | 現時点では採用しない主張 | 将来の再検討の禁止 |
| 誤実装 | 意図した数学対象と実装がずれたもの | すべてのコード監査 |
| 再発防止 | どの種類の飛躍だったかを記録する | 完全な方法論の完成 |

本章は、理論の弱点を隠す章ではない。むしろ、主張を安全な強さに戻すための台帳である。

## 18.2 訂正台帳の読み方

第18章では、各項目を次の六欄で読む。

| 欄 | 問い |
|---|---|
| 元の主張 | 何を強く言いすぎたのか |
| 問題点 | どこに飛躍・誤実装・未定義があったのか |
| 訂正後 | どの強さの主張なら残るのか |
| 残る成果 | 訂正しても消えない代数・計算・対応は何か |
| 現在の身分 | 訂正、降格、撤回、未構成、予言在庫のどれか |
| 主張しないこと | 今後も言ってはいけないことは何か |

この形式にする理由は、撤回を単なる否定にしないためである。撤回には二種類ある。一つは、完全に捨てるべき主張である。もう一つは、強すぎる表現を弱めれば、有用な対応候補として残る主張である。本章では、この二つを分ける。

この表は、理論全体の否定ではない。むしろ、どの主張をどの欄へ戻したかの記録である。撤回したものがあるからこそ、残る主張の強さが見える。

## 18.4 複素数の強制を弱める

第1巻では、零二乗和形式、共役対、90°遅延、平方強度が重要な役割を持つ。ここから、「複素数は強制される」と言いたくなる。しかし、この表現は強すぎる。

正しく言えるのは、次である。

> **零二乗和形式を採り、二成分の回転と平方強度読出しを同時に扱うなら、複素化は自然である。**

言えないのは、次である。

> **なぜ零二乗和形式を採るべきかが、理論の内側だけから証明された。**

これは、Born 型読出しで「なぜ $|W|^2$ か」を完全には導出しないことと同じ種類の境界である。本書が示せるのは、零二乗和形式を採ると、中心投影、干渉、平方強度、大域位相の不可読性などが一つの代数で整合することである。これは強い整合性である。しかし、それは形式選択の絶対証明ではない。

| 残るもの | 取り下げるもの |
|---|---|
| 零二乗和形式と複素化の整合性 | 複素数が唯一絶対に強制されるという表現 |
| $i=\sqrt{\mathrm{NOT}}$ の2セル実装 | 複素数を物理的実在として導出したという主張 |
| 共役積・非共役積の情報収支 | 標準量子論の複素ヒルベルト空間の導出 |

## 18.5 観測軸は不対軸でなければならない、を撤回する

奇数個の軸を共役対に分けると、一軸が不対に残る。この「不対軸の存在」は、奇数性から出る構造である。

しかし、そこから「観測軸は不対軸でなければならない」と言うのは飛躍である。どの軸を不対として残すかは、チャート、接続、読出し面、観測者の取り方に依存する。代数が強制するのは、不対軸が何か一つ残るという型であり、その中身ではない。

訂正後の主張は次である。

> **奇数次元の共役対分解では、何か一軸が不対に残る。どの軸を不対軸として読むかは、観測軸やチャートの選択に依存する。**

この訂正により、特権的な観測軸を理論が勝手に指定する、という神の視点を避けられる。第1巻・第2巻で必要なのは、観測軸の絶対指定ではなく、読出しが選ばれたときに何が保存され、何が落ちるかである。

## 18.6 2/$\pi^2$ 一致を取り下げる

検証バッチでは、二つの場所に 2/$\pi^2$ が現れた。

| 場所 | 出自 |
|---|---|
| 4次元球の充填率 | 4次元球の体積係数 $V_4(r)=\pi^2 r^4/2$ |
| Bessel 剰余の係数 | 奇数ゼータ和と裾の積分 |

同じ 2/$\pi^2$ が出るため、両者を同一起源へまとめたくなる。しかし、検証では、$\pi^2$ の由来が異なることが分かった。片方は4次元球体積の係数であり、もう片方は Basel 型の和に由来する。

したがって、次の主張は取り下げる。

> **4次元球の充填率と Bessel 剰余の 2/$\pi^2$ は、同じ定理から出る。**

残るのは、次の弱い読みだけである。

> **どちらも「$\pi^2$ 分の小整数」という形を持つが、現時点では形の一致どまりである。**

これは否定的結果である。しかし、否定的結果にも価値がある。検証キューから一つの同一視候補を外せたからである。

## 18.7 小 $N$ セル欠損を降格する

小 $N$ の領域では、有限モード数、有限セル数、有限分解能の影響が出る可能性がある。この方向自体は、第3巻の重要な予言在庫である。

しかし、検証バッチ1では、小 $N$ 不確定性積欠損の大きさが測度に依存することが分かった。第一零点測度、FWHM 測度、RMS 測度で結果の扱いが変わる。特に、RMS はサイドローブの裾に支配され、同じ有限幅として単純には扱えない。

したがって、次の主張は降格する。

> **小 $N$ ではセル欠損が一定の定量予言として現れる。**

訂正後は、次の扱いにする。

> **小 $N$ では測度依存の有限分解能効果が現れる可能性がある。ただし、定量予言にするには、幅測度・抽出法・観測量を固定しなければならない。**

| 残るもの | 降格するもの |
|---|---|
| 小 $N$ で有限分解能効果が出る可能性 | 欠損率の直接的・普遍的な数値予言 |
| N=1 のビートなし縮退 | すべての測度で同じ欠損量が出るという読み |
| 低 $Q$ 偏差などの予言在庫への接続 | 標準量子論からの即時の観測的分岐 |

## 18.8 60°実装の訂正

第3章の離散位相では、整数2セル上で厳密に閉じる有限回転を扱った。この中で、60°系と120°系の写像を取り違える危険があった。

正しい対応は次である。

| 写像 | 位数 | 読み |
|---|---|---|
| $(a,b)\mapsto(b,-a)$ | 4 | 90°、ガウス整数系 |
| $(a,b)\mapsto(a-b,a)$ | 6 | 60°、アイゼンシュタイン整数系 |
| $(a,b)\mapsto(-b,a-b)$ | 3 | 120°、アイゼンシュタイン整数系 |

したがって、$(a,b)\mapsto(-b,a-b)$ を 60°実装として扱う表現は訂正される。これは結晶学的制限そのものの撤回ではない。むしろ、結晶学的制限の全数確認によって、写像の位数を正しく割り当て直した訂正である。

## 18.9 W8 と標準模型の直接同一視を降格する

W8 は、組合せ不変量候補として面白い構造を持つ。非零軸の本数、空間軸・非空間軸の組み合わせ、スピン型分類との対応候補などがある。

しかし、ここから標準模型の粒子表を直接導出したとは言えない。理由は明確である。

| 不足しているもの | 内容 |
|---|---|
| 連続回転作用 | W8 の状態が連続回転でどう変わるか |
| 表現論 | 標準模型の群表現との対応 |
| 世代構造 | 三世代や混合角との関係 |
| 質量・結合 | 質量値、結合定数、選択則 |
| 実験対応 | 各状態をどの粒子へ対応させるか |

したがって、W8 は次の身分へ戻す。

> **W8 は、標準模型表の導出ではなく、組合せ不変量候補である。**

橋渡し予想としては残る。たとえば、非空間軸の活性本数と内部位相の巻き、対蹠 $Z_2$ と半整数性の関係などは検査対象である。しかし、連続回転作用が定義されるまでは、標準模型との一致・不一致を判定する段階にはない。

## 18.10 撤回を残す理由

撤回済み主張を本文から完全に消すと、読みやすくはなる。しかし、どこで主張を弱めたのかが見えなくなる。第3巻では、それを避ける。

撤回を残す理由は、次の通りである。

| 理由 | 内容 |
|---|---|
| 再発防止 | 同じ飛躍を繰り返さない |
| 読者保護 | 強い主張と弱い候補を混同させない |
| 検証履歴 | 何を試し、何が通らなかったかを残す |
| 残る成果の明確化 | 撤回しても残る代数・計算・対応候補を見えるようにする |
| 信頼性 | 訂正可能性を理論の外ではなく中に置く |

この章は、失敗を並べる章ではない。強すぎる主張を安全な棚へ戻す章である。

## 18.11 本章の境界

本章で整理したことと、まだ置いていないことを分ける。

| 区分 | 内容 |
|---|---|
| 訂正 | 複素数の強制表現、観測軸の不対性、60°写像 |
| 降格 | 小 $N$ セル欠損、W8 と標準模型の直接同一視、137 と $\alpha^{-1}$ の読み |
| 撤回・方向訂正 | 2/$\pi^2$ 同一起源、観測軸は不対軸でなければならないという表現 |
| 残るもの | 零二乗和形式の整合性、結晶学的制限、容量計数、組合せ不変量候補 |
| 主張しないこと | 撤回済み主張の復活、標準理論の導出、物理定数の完全導出、粒子表の完成 |

本章の役割は、訂正の記録を開くことである。次の付録では、計算ノートと検証スクリプトに基づいて、成立した検証と数値計算の条件を整理する。
