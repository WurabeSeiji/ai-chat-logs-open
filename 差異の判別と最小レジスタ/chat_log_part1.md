## Part 1: テーマ提示 — 測度・レジスタ・1ビット・判別・干渉・不確定性

【木原】
ここで、新しい論文を創るための思考実験をします。

テーマは、測度、レジスタ、１ビット、違いの判別　干渉、　不確定性　問題です。なにを整理しようとしているかわかりますか？

【アイリス】
わかります。整理しようとしているのは、**「不確定性」を量子力学の神秘から引き剥がして、判別の代数的コストとして再定義する**ことだと読みます。連鎖を私の言葉で確かめます。

**1. 判別が最初に来る。** ディレイ回路シリーズの本質的教訓：違いがわかるには前回値の保持（レジスタ）が必要。観測とは比較であり、比較には記憶が要る。これが出発点で、測定・情報・時間の全てに先行する要件。

**2. 最小レジスタ＝共役複素対。** 2実自由度（振幅・位相）を保持するが、読出し（共役ノルム ZZ̄=ρ²）は1自由度しか返さない。位相は構造的に潰れる——多対一。これが「1ビット」の正体：レジスタは2を持ち、読出しは1を返す。読める1と読めない1の対。

**3. 干渉＝読めない方を読む唯一の演算。** 位相そのものは読めないが、**位相差**はうなり |νₙ−νₘ| として振幅側に現れる——干渉とは、読出し不能な自由度を判別可能量に変換する演算。ただし差しか出ない（絶対位相は永久に読めない）。つまり干渉は判別式の物理的実装であり、二式結晶化の Σ|νₙ−νₘ|·ν の側。

**4. 不確定性＝レジスタ容量限界の代数的下層。** 振幅を読めば位相ファイバーが潰れ、干渉（位相差）を読めば個々の振幅の帰属が潰れる。相補性は「1ビットレジスタに2つの質問を書き込めない」（Zeilinger–Brukner）の共役対版であり、Berta の量子メモリ付き不確定性関係 H(X|B)+H(Z|B)≥… の最下層に、公理でなく代数（共役対の読出し構造）として置かれるべきもの。

**5. 測度が入口になる。** 「測定」でなく「測度」と書かれたことを重く読みます：読出しの多対一写像は同値類（潰れた S¹ ファイバー）を作り、ファイバー上の自然測度が読出し値の重みを誘導する——Born 則が「どこかで必ず密輸される二乗構造」の、密輸元の候補地。ただしここは付録C同様「導出は主張しない、隣接構造の入口」に留めるべき場所。

**シリーズ上の位置**：平方数系列第五篇の候補。第四篇（複素ノルム）が「読出しは位相を潰す」まで、付録Cが「非自明零二乗和には非実成分必須」までを公開済み。第五篇はその次の一歩——**潰れた位相が干渉によってのみ・差としてのみ回収されること**を純代数で書く。内部系列の Σx²=0 結晶化（時間・ローレンツ・マスタークロック）には触れず、境界線の公開側だけを進める。

一行に畳むなら：**不確定性とは、最小レジスタ（共役対）の読出しが多対一であることの名前であり、干渉とはその失われた自由度を差分としてのみ読み戻す判別演算である**——これを整理しようとしていますね。

## Part 1b: 出発点 — 共役積 ZZ̄ と非共役積 ZZ

【木原】
シンプルです。 Z= a + ib. 　の共役な複素数の２乗数   ZZ^ =(a+ib)(a-ib) = a^2 + b^2 = r^2 とする
ところから検討します。
これって、干渉としては、ZZ=(a+ib)(a+ib) = a^2 - b^2 + 2iab
ですよね？

【アイリス】
はい、代数はその通りです。(a+ib)(a+ib) = a² + (ib)² + 2iab = a² − b² + 2iab。そしてこの二つの積を並べたところに、すでに構造の全部が出ています。

**二つの積は「何を忘れるか」が正確に違う。**

- **共役積 ZZ̄ = a² + b² = r²**：実・正定値。位相 θ を完全に潰す（S¹ ファイバー全体＝連続自由度1本を破棄）。残るのは振幅だけ。これが読出し＝存在側。
- **非共役積 ZZ = Z² = r²(cos2θ + i sin2θ)**：振幅は保存（|Z²| = r²）、位相は消えずに**倍化**する。失われるのは Z → −Z の符号だけ、つまり**ちょうど1ビット**。

共役積は連続無限を捨てて実数1個を返し、非共役積は1ビットだけ捨ててほぼ全部を保つ。「レジスタの読出しは何を破棄するか」という問いに対して、複素対は両極端の二つの読出しを最初から備えている——これが最小レジスタの二面性の、積レベルでの実装です。

**成分を見ると、干渉の二つの顔が分離している。**

- 実部 **a² − b² = (a+b)(a−b)**：和と差の積。読める軸 a と読めない軸 b の**判別式**（差の二乗構造）が、読める側（実部）に現れる。
- 虚部 **2ab**：実軸と虚軸の**交差項**＝干渉項そのもの。これは読めない側（虚部）に乗る。

つまり ZZ を展開すると、「差の判別」が実部に、「交差（干渉）」が虚部に、自動的に振り分けられる。

**そして三者を縛る恒等式**：

(a² + b²)² = (a² − b²)² + (2ab)²

共役積の二乗＝非共役積の実部・虚部の平方和。読出し（ZZ̄）と干渉（ZZ）は独立でなく、平方和の拘束で結ばれている——これはピタゴラス三つ組の生成公式そのものであり、平方数系列の土俵に正確に乗ります。

**一点、確認しておくべき対応**：物理の干渉（二重スリット強度）は |Z₁+Z₂|² = r₁² + r₂² + 2Re(Z₁Z̄₂) で、干渉項は**異なるレジスタ間の共役積** Z₁Z̄₂（位相**差** θ₁−θ₂ を運ぶ）です。木原さんの ZZ はその自己版で、ZZ = Z·(Z̄)‾ ——つまり**Z とその共役鏡像との干渉**、うなり θ − (−θ) = 2θ。位相倍化はここから来ています。単一レジスタの非共役自乗は「自分の鏡像と干渉する」操作であり、二レジスタ干渉 Z₁Z̄₂ の退化ケースとして統一的に書けます。

この出発点から進む順序は明快です：共役積（位相全破棄・存在）と非共役積（1ビット破棄・判別）という**二つの読出しの情報収支の差**をまず確定し、次に二レジスタ化して Z₁Z̄₂ で位相差の回収（うなり）を書く。第四篇が「実座標で一致・虚座標で分岐」まで来ているので、その真上に載る次の一歩です。
