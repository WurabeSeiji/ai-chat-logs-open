# 第17章 検証済みの関係と予言在庫——何を検査できるか

> **この章の問い**：本書で整理した構造のうち、どこまでが検証済みで、どこからが予言在庫なのか。数式の一致、直接計数、数値検証、標準理論との対応、未検証仮説を、どう分ければよいのか。
> **この章の答え**：本章では、第1巻・第2巻で現れた主張を、検証済み、計算済み、対応候補、作業仮説、予言在庫、未計算、訂正候補に分けて整理する。ここでいう検証済みとは、定義・計算条件・出力が明示されている範囲での確認であり、ただちに物理的同一視を意味しない。予言在庫とは、観測可能量や追加計算へ接続しうる候補であり、完成した観測予言ではない。
> **この章の約束**：本章は成果一覧ではなく検査対象の一覧である。項目に挙げたこと自体は正しさを意味しない。各項目について、定義、根拠、身分、未決定、観測接続、主張しないことを分ける。

**【読み下し】** 第1巻と第2巻では、たくさんの構造が出てきた。二つの積、可視度、結晶学的制限、137、Sargent 則、低 $Q$ 偏差、陽子安定性、ブラックホール型読出しなどである。しかし、それらは同じ強さの主張ではない。あるものは計算で確かめた。あるものは標準理論と形が似ているだけである。あるものはまだ思考実験である。この章では、それらを一つの棚に並べる。ただし、「並べたから正しい」のではない。どの棚に置くべきかを見えるようにするのが、この章の仕事である。

先に用語をほどいておく。**検証済み**とは、少なくとも本書内または先行論文で、定義と計算条件が明示され、代数計算・直接計数・数値検証として確認されたものを指す。**計算済み**とは、具体的な計算やプログラム出力があるが、物理的同一視までは済んでいないものを指す。**対応候補**とは、標準理論の既知構造と同じ形を持つが、標準理論そのものの導出とは扱わないものを指す。**予言在庫**とは、将来の観測量・数値計算・実験設計と照合したい候補である。**未計算**とは、必要な定義・スケール・測度・行列要素などがまだ不足している状態である。（いずれも→用語集）

## 17.1 第3巻の中での位置

第3巻は、仮説検証のためのサンドボックスである。第3巻はじめにで述べたように、本巻は初級理論物理学の教科書本文ではない。ここでは、第1巻・第2巻で出てきた候補を、強さの違いごとに分ける。

第17章は、その最初の棚卸しである。

本章が行うのは、次の整理である。

| 層 | 本章で扱うこと | まだ扱わないこと |
|---|---|---|
| 検証済み | 定義・計算条件・出力が明示された関係を整理する | すべての物理的意味づけ |
| 計算済み | 数値検証や直接計数の結果を一覧化する | 観測値への直接換算 |
| 対応候補 | 標準理論の既知構造と同じ形を持つものを分ける | 標準理論そのものの導出 |
| 予言在庫 | 将来照合したい候補を隔離する | 完成した観測予言 |
| 未計算 | 何が足りないかを明示する | その場での完全解決 |

この章は、第18章の訂正記録と対になる。第17章では、何が検査対象として残るかを見る。第18章では、どの主張を撤回・降格・訂正すべきかを見る。

## 17.2 六欄テンプレート

第3巻では、各候補を次の六欄で見る。

| 欄 | 問い |
|---|---|
| 定義 | 何を数え、何を比較しているのか |
| 根拠 | 代数、直接計数、数値実験、先行論文、思考実験のどれか |
| 身分 | 定理、構成、対応、仮説、予言在庫、撤回済みのどれか |
| 未決定 | まだ何が決まっていないのか |
| 観測接続 | どの観測量・実験・数値計算と照合できるのか |
| 主張しないこと | どこまで言ってはいけないのか |

この六欄を使う理由は、主張の強さを混ぜないためである。

たとえば、$N(1)=137$ は、定義済みの容量計数としては直接計数された整数である。しかし、それを電磁型読出しの容量として読むことは仮説であり、微細構造定数 $\alpha$ の導出ではない。同じ数字を扱っていても、身分が違う。

同様に、Sargent 則の $Q^5$ 型に近い格子計数が出ることと、個々の崩壊率や半減期を計算したことは違う。前者は行き先セル数の対応候補であり、後者には弱い相互作用、核行列要素、選択則、フェルミ関数、補正などが必要である。

## 17.4 検証済み・計算済みに近いもの

本書で比較的強く扱えるものは、定義と計算条件が明示できるものである。

代表は次の四群である。

| 群 | 内容 | 注意 |
|---|---|---|
| 代数群 | 共役積、非共役積、交差項、平方強度 | 物理確率までは出ない |
| 離散構成群 | 整数セル対、$i=\sqrt{\mathrm{NOT}}$、結晶学的制限 | 実装媒体や量子計算万能性とは別 |
| 数値検証群 | 除外率の閉形式、可視度定理、結晶学的制限の全数確認 | 実験一般化や観測値同一視とは別 |
| 容量計数群 | $N(1)=137$、格子体積不足 $\Delta(R)$ | 物理定数との同一視は別問題 |

ここでの強さは、「その定義の中では計算できる」という強さである。たとえば $N(1)=137$ は、定義された容量計数規則の中では直接計数された整数である。しかし、これを電磁型読出し容量として読むには、別の対応仮説が必要である。

同じように、格子体積不足 $\Delta(R)$ と 4+1 次元 Schwarzschild-Tangherlini 型エントロピーの定量対応は、定義された比較の中では $R^3$ スケーリングと漸近比を持つ。しかし、それは標準的なブラックホール熱力学そのものの導出ではない。

## 17.5 対応候補として扱うもの

対応候補とは、標準理論にある構造と同じ形を持つが、標準理論そのものを導出したとは言わないものを指す。

| 対応候補 | 同じ顔 | 残る距離 |
|---|---|---|
| Lorentz 型変換 | 光錐型境界と二乗形式の保存 | 慣性系原理・光速値・時空幾何全体 |
| Born 型読出し | 平方強度の重み | 測度選択・確率公理・Gleason 条件 |
| 重力型読出し | $R$ 側のノルム・曲率・質量型表示 | Einstein 方程式・計量場の完全構成 |
| 電磁型読出し | $Q$ 側の符号付き内部位相・電荷型表示 | Maxwell 方程式・電流・量子化 |
| ゲージ的接続 | 原点・フレームの貼り替え不変性 | Yang-Mills 作用・標準模型表現 |
| 共有台帳としてのもつれ | 空間的分離と台帳共有の分離 | Bell 型相関関数・Born 確率 |

対応候補は、本書の読みを標準理論へ接続する入口である。しかし、入口と導出は違う。第3巻では、この違いを毎回確認する。

## 17.6 予言在庫として扱うもの

予言在庫とは、今後の検証に回す候補である。ここで重要なのは、予言在庫を観測予言と混同しないことである。

| 予言在庫 | 予想される形 | 必要な追加作業 |
|---|---|---|
| 低 $Q$ 偏差 | endpoint 近傍でセル離散性の痕跡が出る可能性 | 物理スケール、実験抽出法、行列要素の扱い |
| 陽子安定性 | 行き先セル不在または巻き数保護により崩壊ビートが立たない可能性 | 陽子型の内部モード、終状態、頂点写像の具体化 |
| BH スペクトル候補 | 境界容量や面積準位が QNM・放射準位に痕跡を残す可能性 | QNM 計算、放射モデル、標準理論との比較 |
| 大域 $R$ 共有 | 離れた部分系に共通制約が残る可能性 | 数学的定義、Bell 型設定との距離の整理 |
| 高次元 BH 図示 | 4次元球側の境界型 $R^3$ と 3+1 次元 BH の $R^2$ 面積を次元簿記として比較 | 物理的投影仮説の有無を明示 |

これらは、正しいと主張するための一覧ではない。どの方向に検査を進めるかの在庫である。

予言在庫に置く条件は、次の三つである。

| 条件 | 内容 |
|---|---|
| 形がある | 何らかの関係式、偏差、制約、分類が示せる |
| 照合先がある | 観測量、数値計算、標準理論の既知結果と比べられる |
| 未決定点が明示できる | 何が足りないかを表にできる |

この三条件を満たさないものは、予言在庫ではなく、単なる思いつきとして保留する。

## 17.7 未計算として残るもの

未計算とは、失敗ではない。何を計算すればよいかが見えている状態である。

本書で大きく残る未計算部分は、次である。

| 未計算部分 | 必要なもの |
|---|---|
| 粒子表全体 | 内部モード、表現、世代、質量、結合の具体構成 |
| 崩壊率 | 頂点写像、行列要素、選択則、結合定数、位相空間測度 |
| Bell 型相関 | 測定基底、確率法則、相関関数、局所性条件の明示 |
| ブラックホール放射 | 場の量子論、真空選択、温度、スペクトル、補正 |
| 情報問題 | 全過程の時間発展、外部放射、相関回収、ユニタリ性の扱い |
| 大域 $R$ 共有 | 数学的定義、局所読出し条件、観測可能量 |

未計算を未計算として書くことは、第3巻の重要な仕事である。未計算を隠すと、仮説が確定結果のように見える。未計算を明示すると、次に何をすればよいかが見える。

## 17.8 第18章へ送るもの

本章は、検証済みの関係と予言在庫を整理した。しかし、すべての候補がこの章に残るわけではない。中には、訂正・撤回・降格として第18章へ送るべきものがある。

第18章へ送る代表例は、次である。

| 対象 | 第18章での扱い |
|---|---|
| 複素数が強制される、という強すぎる表現 | 零二乗和形式から複素化が自然、に弱める |
| 観測軸は不対軸でなければならない、という主張 | 条件付きまたは撤回として整理する |
| 2/$\pi^2$ 一致 | 撤回済み主張として記録する |
| 小 $N$ セル欠損の確率予言 | 降格し、直接予言とは扱わない |
| 60度実装 | 誤実装・訂正として整理する |
| W8 と標準模型の直接同一視 | 未構成として扱い、組合せ不変量候補に留める |

撤回は、理論の失敗を隠すものではない。むしろ、どこで主張を弱めたかを見えるようにするための記録である。

## 17.9 本章の境界

本章で整理したことと、まだ置いていないことを分ける。

| 区分 | 内容 |
|---|---|
| 定義 | 検証済み、計算済み、対応候補、仮説、予言在庫、未計算、訂正候補 |
| 構成 | 各候補を六欄で棚卸しする検証台帳を置いた |
| 整理したこと | 第1巻・第2巻の主張を、同じ強さで語らないための分類表を作った |
| 予言在庫 | 低 $Q$ 偏差、陽子安定性、BH スペクトル、大域 $R$ 共有、高次元 BH 図示 |
| 主張しないこと | 予言在庫の正しさ、標準理論の置換、物理定数の完全導出、崩壊率や BH 熱力学の導出 |

本章の役割は、第3巻の検査台帳を開くことである。次章では、ここからさらに進み、撤回済み・降格済み・誤実装の主張を明示的に記録する。
