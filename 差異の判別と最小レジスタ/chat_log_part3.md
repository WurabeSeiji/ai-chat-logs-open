## 90°ディレイの実装：セル2個＋インバータ1個

レジスタを実セル2個の対 (a, b) とし、これを Z = a + ib と**みなす**（ハードに複素数は要らない、セル対が複素数です）。

90°遅延＝ ×(−i) は、展開すると −i(a+ib) = b − ia。つまり：

```
D: (a, b) → (b, −a)     … 配線交差 ＋ インバータ1個。乗算器ゼロ。
```

クロックごとに D を適用すると：

```
(a, b) → (b, −a) → (−a, −b) → (−b, a) → (a, b)
  0°      90°       180°       270°      360°=0°
```

周期4で一巡。ここで決定的なのは **D² = (a,b)→(−a,−b) = 両線NOT**。つまり **i とは「NOTの平方根」**です。

## これが木原さんのDRシリーズへの直接の答えになっている

DR1のリング（FD列＋NOT一個、周期2n）は {+1, −1} の交替、つまり **Z₂ レジスタ**です。1本のブール線上では NOT の平方根は存在しません（真理値表を書けば1線√NOTが不可能なのは自明）。ところが**線を2本にした瞬間、√NOT＝swap+inverter が実装できる**。これが「なぜ複素数か」の回路的な答えです：

**複素構造とは、NOT（180°遅延）を2つの90°遅延に分解できる最小のレジスタ拡張である。**

虚部セル b の中身も実装的に明確です。回転信号 a(t) = r cos ωt に対し b(t) = r sin ωt = **a(t − T/4)**、つまり **b は a の1/4周期遅延コピーそのもの**。「運動量＝世界に内蔵されたディレイレジスタ」の実装形が、直交位相（quadrature）セルです。共役 Z̄ = (a, −b) はインバータ1個で作れる**逆走コピー**。

なお、クロックごとに ×(−i) するこの構成は、DSPでは **fs/4 直交発振器／fs/4ダウンコンバータ**として実在します。乗数が {1, i, −1, −i} だけなので乗算器不要——実際の受信機で使われる理由が「Z₄ が最安のディレイ実装だから」です。

## どの離散角が正確に作れるか：ここに定理が一本立つ

整数セル演算（加減・交差・符号反転のみ、丸めなし）で**厳密に**実装できる位相ステップは：

| 角度 | 格子 | 実装 |
|---|---|---|
| 180° (Z₂) | ℤ | NOT（インバータ） |
| 90° (Z₄) | ガウス整数 ℤ[i] | (a,b)→(b,−a) |
| 60° (Z₆) / 120° (Z₃) | アイゼンシュタイン整数 ℤ[ω] | (a,b)→(−b, a−b)（加算器1個追加） |

そして**これで全部**です。結晶学的制限定理（格子を保つ回転は位数 1,2,3,4,6 のみ）により、45° も 72° も、どんな整数セル構成でも厳密には作れない——cos45° = 1/√2 が無理数だから近似（CORDIC）になる。

つまり「離散値でよいから位相を遅らせる系」の設計空間は、整数厳密の範囲では **Z₄（ガウス）と Z₆（アイゼンシュタイン）の2種しか存在しない**。これは木原さんの「基礎は離散整数、連続は創発（近似）」のテーゼの、回路で検証可能な形です。任意角の回転（連続位相）だけが乗算器＝無理数近似を要求する。

## 読出しと干渉も全部既製の回路がある

- **器の読出し** ZZ̄ = a² + b²：乗算2＋加算1。位相に盲目、回転しても不変——**包絡線検波器**。
- **二レジスタ間の判別** Z₁Z̄₂：実部 a₁a₂ + b₁b₂（内積＝相関器）、虚部 b₁a₂ − a₁b₂（位相検出器）。合わせて **IQ復調／ロックインアンプ**そのもの。位相は**差としてしか**出力に現れない（命令セットに絶対位相を読む演算が存在しない）。
- **自己干渉** ZZ = (a²−b², 2ab)：アナログの**周波数2逓倍回路**の実装式そのまま。

整理すると、論文の骨格は幾何でなくこう書けます：

1. **定義**：レジスタ＝整数セル対 (a,b)、演算＝{交差, 反転, 加算}
2. **構成**：D = (a,b)→(b,−a) が90°遅延を実装、D²=NOT、D⁴=1 —— i＝√NOT
3. **定理**：整数厳密な離散位相遅延は位数 1,2,3,4,6 に限る（結晶学的制限）
4. **読出し**：不変量 a²+b²（保持の検証）、対間の内積/交差（判別、差のみ）
5. **帰結**：DR シリーズの Z₂ リングは、この構造の1セル退化ケース

先ほどの私の幾何的説明は、この実装の言い換えにすぎませんでした。順序は木原さんの言う通りで、**まず作れることを示し、幾何はその注釈**です。次に確認すべきは、この2セルD段を DR1 のようにリング化したとき（n段＋NOT閉路）に何が出るかで、そこで Barkhausen 位相条件（一周の位相和＝2πk）が離散形で出てくるはずです。
