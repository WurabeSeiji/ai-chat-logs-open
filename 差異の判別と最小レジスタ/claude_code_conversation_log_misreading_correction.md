## 3. Claude Codeへの要点メモ

以下は、Claude Codeが論文本文を修正する際に必ず反映すべき要点。

### 3.1 第0篇の役割

第0篇の二つのランプ問題は単なる導入比喩ではない。

ここでは、シリーズ全体を拘束する定義が導入されている。

- 観測とは「差異が区別できること」
- 区別できない対象・軸・方向・符号は無名である
- 無名なものを勝手に特権化してはいけない
- 区別できると主張するなら、その区別を可能にする読出し構造・対称性の破れ・境界条件などを明示する必要がある

### 3.2 全軸対称性の位置づけ

全軸対称性は、外部から任意に追加された仮定ではない。

本論文集の観測定義・無名性の原理では、区別の根拠がない段階で特定軸を選ぶことはできない。

したがって、全軸対称性は、区別以前の表現に課される最小条件である。

### 3.3 第二篇の誤読防止

第二篇では、零二乗和形式が突然導入されているように読まれやすい。

しかし本来は、中心投影シリーズで既に与えられている

\[
\sum_i x_i^2 = R^2
\]

という二乗和形式が前提にある。

ここで \(R\) は曲率半径である。

無名性を適用すると、\(R\) だけを特別な外部軸として固定する根拠はない。

どの軸も投影軸、すなわち曲率半径方向として選ばれうる。

このため、右辺を左辺に移すと

\[
\sum_i x_i^2 - R^2 = 0
\]

という零二乗和形式が現れる。

これは孤立した仮定ではなく、中心投影形式と無名性を合わせた表示である。

### 3.4 負符号の意味

\(-R^2\) の負符号は、内在空間に本質的な負計量を入れるという意味ではない。

これは、どの軸を投影軸として外へ出したかという表示選択による符号である。

中心投影シリーズの言葉では、左辺の系は主観空間である。

量子力学的な読み方では、左辺の系は内在空間である。

この内在空間からは、曲率半径の大きさは角度歪みから計算できるが、曲率半径方向そのものは直接観測できない。

観測できない軸を内在表現に戻すとき、その軸は実数軸ではなく、虚数単位を伴う軸として表現される。

この意味で、本来の内在空間における左辺の項は全て正の二乗項として扱われる。

### 3.5 複素数導入の必然性

左辺の全項を正の二乗項として読み、全てを実数とすると、

\[
\sum_i x_i^2 = 0
\]

の非自明解は存在しない。

オールゼロしかない。

したがって、非自明な構造を持つには、少なくとも一つの左辺項が複素数である必要がある。

さらに無名性を徹底すると、「この軸だけ実数で、別の軸だけ虚数である」と最初から決める根拠がない。

したがって、後に「左辺項は全て共役な複素数ではないか」という仮定を導入するのは自然である。

これは特定軸だけを実数・虚数に固定しないための仮定である。

### 3.6 \(\lambda\), \(\nu\), 離散化、不確定性

この系に波長 \(\lambda\) と振動数 \(\nu\) を導入して位相空間として読むと、系は有界で閉じた系になる。

有界閉系では、連続値を無限精度で識別できない。

信号理論的には、波長側では \(\lambda/2\) 以下、振動数側では \(\nu/2\) 以下の差異は観測できない。

ここでいう観測できないとは、本論文集の定義に従い、「差異として区別できない」という意味である。

区別できない差異は、理論物理学的には存在すると主張する根拠を持たない。

したがって、これら二つの読出し不能性が、根源的な不確定性の原因として現れる。

### 3.7 第二篇冒頭に追加すべき文案

以下の趣旨を第二篇の冒頭に追加すること。

```text
本篇で扱う零二乗和形式は、孤立した代数的仮定ではない。本シリーズの前提には、中心投影シリーズで扱った二乗和形式がある。そこでは、左辺の二乗和が右辺の曲率半径 R の二乗として表される。本篇では、第0篇で導入した無名性、すなわち「区別の根拠がないものを特権化しない」という規則を、この中心投影形式に適用する。したがって、曲率半径 R もまた、外部から固定された特別な軸ではなく、任意の軸が担いうる投影軸として扱われる。零二乗和形式は、この中心投影形式と無名性を合わせた表示であり、任意に導入されるものではない。
```

## 4. 最終まとめ

今回の誤読の原因は、第二篇を単独で読み、中心投影シリーズで既に導入されていた

\[
\sum_i x_i^2 = R^2
\]

という曲率半径形式を前提に入れなかったことにある。

本来の構成は、

1. 第0篇で「観測＝差異を区別できること」と定義する。
2. 区別できないものは無名である。
3. 無名な対象・軸・符号を勝手に特権化してはいけない。
4. 中心投影シリーズでは、二乗和の右辺として曲率半径 \(R\) が現れている。
5. 無名性により、\(R\) だけを特別な軸として固定できない。
6. どの軸も投影軸、すなわち曲率半径方向として選べる。
7. 右辺を左辺に移すと、零二乗和形式が現れる。
8. 負符号は内在空間の負計量ではなく、投影軸選択に由来する表示上の符号である。
9. 内在空間では曲率半径方向は直接観測できず、大きさだけが角度歪みから計算される。
10. 観測不能な軸は虚数単位を伴う表現として戻される。
11. 全項を実数正二乗とすると非自明解が消えるため、複素構造が必要になる。
12. 無名性を徹底すると、特定軸だけ実数・虚数とする根拠がなく、全項を共役複素対として扱う仮定へ進む。
13. \(\lambda\) と \(\nu\) を導入した有界閉位相系では、読出し不能な最小差異が生じ、これが根源的不確定性として現れる。

この構成を明示すれば、第二篇は「全軸対称性を仮定した」「零二乗和形式を置いた」「複素数を勝手に導入した」という読みから解放される。
