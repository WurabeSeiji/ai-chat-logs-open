## 主モデル：等振幅局在波 W_N(θ) = Σₖ e^{i(2k−1)θ}

|W_N|² = sin²(Nθ)/sin²θ。ピーク N²、第一零点 θ₀ = π/N、Parseval は厳密（(1/2π)∫|W_N|² = N）。

**重要な帰結（v1 の主張の撤回を含む）**：等振幅・有限 N の局在波では、**規格化は厳密に成立し（剰余ゼロ）、実効次元 d_eff = N（厳密な整数）**。v1 の「規格化剰余 19%」「非整数次元」は、この物理モデルには適用されない。剰余は消えたのではなく、**別の場所に住む**：

### 剰余の三つの新しい住所

**(a) 漏れ率 L(N) → 約 9.7%（N 非依存の定数に収束）**
主ローブの外（サイドローブ）に漏れる強度割合。N→∞ でも消えない**構造定数**（sinc² の主ローブ占有率 90.3% の離散版）。局在は完全にならない——「理想の局在」との差が定数として残る。

**(b) 隣接モード数の識別可能性 = 1/(N+1) ＝ 論文の「鋭さ」と同一**
規格化した状態間の忠実度 |⟨Ŵ_N|Ŵ_{N+1}⟩|² = N/(N+1)。つまり N 本と N+1 本の局在波の区別可能性はちょうど **1/(N+1)**——de Broglie 論文で数値検証された鋭さ ~1/(N+1) と同じ量である。**縞の鋭さとは、モード数の識別可能性そのものだった**（定理レベルの同一視）。帰結：大 N ではモード数の絶対値 N は相対精度 1/N でしか読めない——「項数の曖昧化」の定量形。

**(c) 小 N での不確定性積の欠損**
σ_n·θ₀ は N→∞ で π/√3 に収束するが、N=2 では 13% 小さく、N=1 では積が定義されない（σ_n = 0：モード広がりゼロ＝相方なし＝ビートなし＝目盛りなしの縮退ケースが、表の中に自動で現れている）。

## 正直な再評価：予言候補①への影響

**この訂正は予言候補①（規格化剰余 δ(N) の観測）を弱めます。** 等振幅・器が N を決める描像では規格化は厳密であり、「確率の欠損」という判別実験は成立しない。さらに (a)(b)(c) の数値はいずれも標準的なフーリエ解析でも同じ値が出る——**与えられた N に対する数学は標準理論と共有**であり、そこに分岐はない。

分岐が残る場所は一段上です：**自然が有限 N（器が決める分割数）を使っているか、無限（連続体）を使っているか。** 標準理論が連続・無限基底を仮定する状況で、有限 N の痕跡——
- モード数識別のスケーリング 1/(N+1) が観測にどう現れるか
- de Broglie 論文の**除外率 1.5〜4.0%**（整列判定 NG）——有限 N 性の操作的な影として既に測られている数
- endpoint 近傍（行き先セル数が少ない崩壊）での連続体位相空間則からの離散偏差

——を探すことが、予言プログラムの正確な照準になる。「与えられた N の数学」ではなく「**N の有限性そのものの証拠**」が標的です。
