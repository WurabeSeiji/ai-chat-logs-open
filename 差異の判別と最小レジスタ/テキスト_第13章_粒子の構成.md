# 第13章 粒子の構成——内部モード・スピン・W8・137

> **この章の問い**：粒子の種類とは何か。電子型、光子型、スピン、内部モード、W8、$\alpha^{-1}\simeq137$ は、本書の台帳ではどこまで読めるのか。
> **この章の答え**：本章では、粒子種を、外部測定で安定に再識別できる内部モードの読出し束として扱う。質量型・電荷型の毛は位相増分率として読めるが、粒子の種類そのものは単なる $p_R,p_Q$ だけでは決まらない。種類を担う候補は、各軸の器の中に立つ内部モード、符号構造、対蹠同一視、安定な係数列である。ただし、本章は標準模型の粒子表、質量スペクトル、結合定数、スピン表現、QED を導出しない。W8 は組合せ不変量候補、$\alpha^{-1}\simeq137$ は容量計数候補として扱う。

**【高校向・読み下し】** 粒子の名前は、名札のように最初から宇宙に貼られているわけではない。何度測っても同じ質量型・電荷型・スピン型の顔で出てくるなら、私たちはそれを「同じ種類の粒子」と呼ぶ。電子なら、質量型の読みと負の電荷型の読みとスピン型の読みが安定して出る。光子なら、質量型の読みはゼロで、光のような境界を進み、偏光やヘリシティのような内部ラベルが出る。けれど、ここで電子の質量の値や、光子の量子電磁力学を作ったわけではない。この章では、粒子名の手前にある「どの台帳モードが安定して同じ顔で読めるか」を整理する。

先に用語をほどいておく。**粒子種**とは、外部読出しで安定に再識別できる内部モードの同値類である。**内部モード**とは、台帳の各軸や内部器に立つ位相成分・係数列・符号構造のことである。**毛**とは、外部から保存量として読める位相増分率である。**スピン型読出し**とは、内部符号構造や対蹠同一視が、外部表示で角運動量型・ヘリシティ型のラベルとして現れる候補である。**W8** とは、本章では内部符号構造を分類する組合せ不変量候補であり、標準模型の粒子表そのものではない。**容量計数**とは、読出し可能な内部状態数や配置数を数える候補であり、結合定数の導出ではない。（いずれも→用語集）

## 13.1 第VI部の中での位置

第10章では、$R$ 側と $Q$ 側を、重力型読出し・電磁型読出しの候補として分けた。第11章では、相互作用を、共有台帳・境界・接続・頂点写像を通じて外部記録へ残ることとして定義した。第12章では、読めない原点や局所フレームを貼り替えても記録が変わらない構造を、ゲージ的接続として読んだ。

第13章からは、個別の「種類」に近づく。ただし、ここで注意が必要である。粒子名を並べると、すぐに標準模型の粒子表を導出する章のように見えてしまう。本章はそこまでは行かない。

本章で行うのは、次の整理である。

| 層 | 本章で扱うこと | まだ扱わないこと |
|---|---|---|
| 保存量 | $p_R,p_Q$ などを質量型・電荷型の毛として読む | 具体的な質量値や結合定数 |
| 種類 | 安定な内部モードの読出し束として粒子種を見る | 標準模型の粒子表の導出 |
| スピン | 内部符号構造・対蹠同一視の読出し候補として扱う | Dirac 方程式やスピン統計定理の導出 |
| W8 | 組合せ不変量候補として扱う | 標準模型表現との完全同一視 |
| 137 | 容量計数候補として扱う | 微細構造定数 $\alpha$ の導出 |

この章は、第14章の寿命・崩壊へ進む前に、「何が同じ粒子種として保たれるのか」を定義する準備章である。

## 13.2 粒子種は名札ではなく再識別可能な読出し束である

無名性の立場では、粒子名は最初から貼られた固有名ではない。外部測定を何度行っても、同じ読出し束として再識別できるとき、その安定な同値類に名前を付ける。

本章では、粒子種を次のように読む。

> **粒子種 ＝ 外部測定面で安定に再識別できる内部モードの読出し束。**

ここで「同じ」とは、内部の全情報が同一という意味ではない。読めない位相原点、局所フレーム、内部規約を貼り替えても、外部記録に残る保存量・符号・モード型・境界応答が同じ同値類に入る、という意味である。

たとえば、電子型の読出しでは、質量型の毛、負の電荷型の毛、スピン型ラベル、安定な内部モードが同じ束として出る。光子型の読出しでは、質量型の毛がゼロとして読まれ、光錐型境界、電磁型接続、偏光・ヘリシティ型のラベルが同じ束として出る。

ただし、これは電子や光子の標準理論的な全構造を導出したという意味ではない。ここでしているのは、粒子名の手前にある再識別条件を、台帳の言葉で定義することである。

**【高校向】** 人の名前を知らなくても、同じ顔、同じ声、同じ指紋が何度も出てくれば「同じ人だ」と分かる。粒子名も似ている。名前が先にあるのではなく、何度読んでも同じ顔で出てくる読出し束に、あとから名前を付ける。

## 13.3 毛と種類を分ける

第4章では、質量、エネルギー、角運動量、電荷を、位相増分率として読んだ。第10章では、$p_R$ を質量型、$p_Q$ を電荷型の読出しとして整理した。

しかし、毛だけでは粒子種は決まらない。

| 区分 | 読み | 例 |
|---|---|---|
| 毛 | 外部から保存量として読める位相増分率 | $p_R\to m$、$p_Q\to q$、角運動量型ラベル |
| 種類 | 内部モードの安定な構造 | 電子型、光子型、ニュートリノ型などの候補 |
| 状態 | 同じ種類の中で変わる外部読出し | 運動量、読出し周波数、測定面での偏光基底 |
| 位置 | 読み手との関係で出る外部記録 | 親台帳上の位相差・記録列 |

粒子種を担う候補は、各軸の器の中に立つ内部モードである。模式的に書けば、ある軸 $a$ の内部モードは

$$
C_a=(c_{a,1},c_{a,3},c_{a,5},\ldots)
$$

のような係数列として表せる。ここで添字 $1,3,5,\ldots$ は、閉包条件や対称性条件の下で有効に残る倍音候補を表す記号である。重要なのは、単に倍音がたくさんあることではない。高い倍音は、局在や解像度を支える供給者として働く。一方で、粒子種を分けるのは、その係数列がどの安定な形を持つかである。

したがって、本章では次を分ける。

| 混同してはいけないもの | 理由 |
|---|---|
| $p_R$ と粒子種 | $p_R$ は質量型の毛であり、種類の全情報ではない |
| $p_Q$ と粒子種 | $p_Q$ は電荷型の毛であり、内部モード全体ではない |
| 倍音の多さと情報量 | 倍音は解像度を供給しうるが、種類は安定な係数構造で読む |
| 外部位置と内部モード | 位置は読み手との関係量であり、粒子の種類そのものではない |

## 13.4 位置と運動は親台帳上の集団位相として読む

粒子の種類を内部モードとして読むなら、位置や運動はどこに置かれるのか。

本書では、位置を粒子の中に貼られた絶対名として扱わない。外部から読める位置は、読み手台帳と対象台帳の間の位相差、記録列、境界条件として出る。第8章の外部測定の言葉で言えば、位置は内部値そのものではなく、読出し面に落ちた関係記録である。

粒子の運動も同じである。第7章で見たように、運動は背景時間上の点の移動としてではなく、記録列と位相増分率の関係として読む。

この章では、粒子の位置・運動を次のように整理する。

| 読み | 内容 |
|---|---|
| 種類 | 内部モードの安定な読出し束 |
| 位置 | 親台帳上で読み手と対象の間に出る集団位相差 |
| 運動 | 記録列に沿った位相増分率の関係 |
| 局在 | 内部モードの係数列が外部読出しで作る有効な幅 |

ここで「集団位相」とは、内部モード全体が外部読出し面に作る代表的な位相差である。粒子を点として扱える場合、その点は内部構造そのものではなく、外部測定で使える代表位置である。

**【高校向】** 会社そのものは社員、部署、書類、建物などのまとまりでできている。しかし地図では、本社所在地の一点で代表させる。粒子の位置もこれに近い。内部モード全体を外から読むとき、代表点のように見える読出しが立つ。

## 13.5 電子型と光子型の最小読出し

ここで、電子型と光子型を、あくまで読出し候補として並べる。

| 型 | 台帳側の候補 | 外部に出る顔 | 主張しないこと |
|---|---|---|---|
| 電子型 | 安定な内部モード、$p_R\neq0$ 型の質量読出し、符号付き $p_Q$ 型の電荷読出し、スピン型ラベル | 質量を持つ荷電粒子型の有効表示 | 電子質量、電荷の値、$g$ 因子、Dirac 方程式、QED の導出 |
| 光子型 | $p_R=0$ 型の質量ゼロ読出し、光錐型境界、電磁型接続、偏光・ヘリシティ型ラベル | 質量ゼロの電磁型伝播モード | Maxwell 方程式の量子化、Fock 空間、光子数統計の導出 |
| 中性質量型 | $p_Q=0$ だが $p_R\neq0$ と読める内部モード | 電荷を持たない質量型粒子候補 | ニュートリノや中性粒子の標準模型表現の導出 |
| 閉じ込め型 | 内部符号・色型候補が外部へ単独で出ないモード | 複合状態としてだけ読める候補 | QCD、色閉じ込め、漸近的自由性の導出 |

光子型については、特にゼロの読み分けが重要である。光子型を

$$
p_R=0
$$

と読むことは、$R$ 軸が消えるという意味ではない。質量型の外部読出しがゼロである、という意味である。同じように、電気的に中性と読むときの

$$
p_Q=0
$$

も、$Q$ 軸の不在を意味しない。

また、光子の振動数は、光子だけの内在名ではなく、読み手の時計との交換レートとして読まれる。光子型の側に残る候補は、ヌル境界に沿った位相の巻き数構造、偏光・ヘリシティ型のラベル、電磁型接続との対応である。

この表は、標準模型の粒子表ではない。あくまで、粒子種を読むための最小の台帳項目を並べたものである。

## 13.6 スピン型読出し

スピンは、粒子が小さな球として自転している、という意味ではない。標準理論でも、スピンは内部自由度と回転対称性に関わる量である。

本書では、スピン型読出しを次のように読む。

> **スピン型読出し ＝ 内部符号構造・対蹠同一視・位相の巻き方が、外部表示で角運動量型またはヘリシティ型ラベルとして出ること。**

第3章では、90度遅延、quadrature、巻きの発生条件を見た。第12章では、二成分・三成分のノルム保存内部変換を見た。スピン型読出しは、これらの内部位相構造が、外部の回転操作に対してどのような符号変化や同一視を持つかに関わる。

ただし、本章ではスピン表現を導出しない。特に、次は主張しない。

| 主張しないこと | 理由 |
|---|---|
| スピン $1/2$ の完全導出 | SU(2) 表現、回転群との関係、量子状態空間の構成が必要 |
| Dirac 方程式の導出 | ローレンツ共変性、スピノル、質量項、場の方程式が必要 |
| スピン統計定理の導出 | 相対論的量子場理論の構造が必要 |
| 電子の $g$ 因子の導出 | 量子電磁力学の補正が必要 |

本章で言えるのは、内部符号構造と対蹠同一視が、スピン型ラベルの置き場所として自然である、というところまでである。

## 13.7 W8 は粒子表ではなく組合せ不変量候補である

W8 という名前は、粒子種を分類する内部符号構造の候補として使う。ただし、ここでの W8 は、標準模型の粒子表そのものではない。

本章では、W8 を次のように扱う。

| 扱い | 内容 |
|---|---|
| 組合せ不変量候補 | 内部モードの符号、向き、有無、対蹠同一視を分類する粗い目録 |
| 粗視化 | 係数列の詳細ではなく、外部読出しで安定に残る符号構造を見る |
| 対応候補 | 標準模型の粒子種分類と照合しうる候補 |
| 未構成部分 | 連続回転作用、標準模型表現、世代構造、結合定数との完全対応 |

W8 を使う理由は、粒子種を連続量の値だけで分類しないためである。質量や電荷の値は毛として読める。しかし、粒子種の違いには、内部モードの符号構造や安定な組合せが関わる可能性がある。

したがって、本章での主張は次に限る。

> W8 は、内部モードの粗い符号構造を整理する組合せ不変量候補である。

ここから、標準模型の全粒子表、世代数、混合角、結合定数が出たとは言わない。

## 13.8 137 は結合定数の導出ではなく容量計数候補である

$\alpha^{-1}\simeq137$ という数は、物理学では微細構造定数の逆数として知られている。本書でも 137 型の数え上げ候補に触れる。ただし、この扱いには強い注意が必要である。

本章では、137 を次の身分でだけ扱う。

> **137 型の数え上げ ＝ 内部モードや読出し可能状態の容量計数候補。**

容量計数とは、どれだけの内部配置、符号、境界条件、読出し状態が区別可能かを数える候補である。これは、結合定数そのものを導出することとは違う。

| 言えること | 言えないこと |
|---|---|
| 内部モードの容量に 137 型の数え上げが現れる可能性を検討する | 微細構造定数 $\alpha$ を導出した |
| 電磁型読出しの強さと容量計数の対応候補を置く | QED のくりこみ群や結合定数の走りを導出した |
| どの数え上げが安定かを検証課題にする | 実験値 $137.035999\ldots$ を計算した |

この線引きは重要である。137 という数は魅力的だが、魅力的な数ほど過剰主張を呼びやすい。本書では、容量計数候補として残し、結合定数の導出とは書かない。

## 13.9 安定条件と崩壊への橋

粒子種を安定な内部モードとして読むなら、次に問うべきことは、なぜある粒子は長く残り、ある粒子は崩壊するのかである。

本章では、安定条件を次のように置く。

| 条件 | 読み |
|---|---|
| 内部閉包 | 内部モードが自前の目盛りと閉包条件を持つ |
| 保存量整合 | $p_R,p_Q$ などの毛が境界で矛盾しない |
| 接続整合 | 位相原点・局所フレームの換算が閉路で破綻しない |
| 行き先制限 | 崩壊後の読出し束が許される境界・保存量・記録面を持つ |
| 記録安定性 | 外部測定で同じ粒子種として再識別できる |

崩壊とは、内部モードの束が別の読出し束へ分解され、共有境界と頂点写像を通じて外部記録に落ちることである。これは第14章で扱う。

ここでも、具体的な崩壊率はまだ出ない。崩壊率には、行き先セルの数、位相空間、結合、頂点写像、保存量の再配分が必要である。本章では、崩壊を語るために、まず粒子種と安定条件を定義しただけである。

## 13.10 本章の境界

本章で確定したことと、まだ置いていないことを分ける。

| 区分 | 内容 |
|---|---|
| 定義 | 粒子種、内部モード、スピン型読出し、W8、容量計数 |
| 構成 | 粒子種を安定に再識別できる内部モードの読出し束として置く |
| 対応 | 電子型、光子型、中性質量型、閉じ込め型を読出し候補として整理する |
| 仮説 | 内部モードの係数列、符号構造、W8、137 型容量計数 |
| 主張しないこと | 標準模型の粒子表、質量スペクトル、結合定数、世代構造、QED、QCD、Dirac 方程式の導出 |

本章の役割は、粒子名を台帳の読出し束として扱うための文法を置くことである。次章では、この文法を使って、寿命・崩壊・行き先セル・保存量の再配分を見る。
