# 共役複素数の自己干渉 — 極座標表現と射影の幾何（会話録 その4）

【木原】
「観測軸は不対軸でなければならない」
これは成立しないでしょう　観測軸は選択問題です　完全に対称でどの軸でも観測軸になれます

【アイリス】
訂正を受け入れます。私の主張は二つの別問題を混同していました。

**混同の構造**

- **代数的事実**：奇数項の平方和では、共役対に組んだ後に一軸が不対で残る
- **私の飛躍**：その不対軸が観測軸である／観測軸は不対軸でなければならない

しかし「どの軸を不対のまま残すか」は代数が決めません。5軸 (x, y, z, t, R) から二対＋一軸への分解は、どの軸を余らせるかについて完全に対称です。(xy)(zt) 対で R が余る分解も、(xR)(yz) 対で t が余る分解も、代数上等価。中心投影モデルで北極（接点）をどこに取ってもよい——観測者の位置が任意である——こととパラレルで、不対軸の指定は**チャートの選択**であって構造の性質ではない。観測者が軸を選ぶのであり、軸が観測者を選ぶのではない。

**定理として残るもの**

正しく縮めると：「奇数次元では、**どの**共役対分解を選んでも**何か**一軸が不対で残る」——存在は強制されるが、**どれか**は自由。つまり：

- 強制されるのは「不対軸の存在」（分解の型：n対＋1）
- 選択されるのは「どの軸がそれか」（チャート＝観測者の視点）

これは御frameworkの認識論的基礎——神の視点ではなく観測者相対——と正確に整合します。むしろ私の元の主張のほうが「特権的な観測軸が構造的に指定される」という神の視点側の言明になっていた。偶数次元では全軸を対に組み切れて不対軸が存在し得ないのに対し、奇数次元は「観測視点を一つ選ばざるを得ない」構造を持つ——選択の**必然性**が定理で、選択の**内容**が自由、という整理が正しい形です。

ご指摘の通り、「〜でなければならない」は成立せず、「観測軸を選ぶと、その選択が不対軸を指定する」が正確な向きです。

【木原】
ここでレジスタ問題に戻ります
レジスタとは何か？の定義がポイントです　私は　因果を生む存在で　ある状態を　不可逆に　別の状態で読み出す機構だと考えます　この不可逆性が因果の方向を産むのでは？

【アイリス】
その定義は今日の代数で正確に解剖できます。そして一箇所、循環の危険があるので先に処理します。

**循環の危険と、その回避**

「不可逆」を素朴に「後から元に戻せない」と定義すると、「後から」が時間順序を前提し、その時間の向きを因果から導こうとしているので循環します。しかし今日の言葉なら不可逆性を**無時間的に**定義できます：

**不可逆性 = 写像の非単射性（多対一）**

Z ↦ 2ρcos θ は円周上の θ と −θ を同一の値に写す。Z ↦ ρ² は円周全体を一点に写す。逆写像が存在しないのは時間の性質ではなく、**写像それ自体の論理的性質**です。「戻せない」のではなく「戻り先が一意でない」。これなら時間を一切前提せずに不可逆性が立ちます。

**するとレジスタの定義はこうなる**

レジスタとは：状態空間から記録空間への**非単射な写像を実行する機構**。今日の階梯で言えば、恒等射影（Z→Z）はレジスタではない——何も失わない写しは記録ではなくコピーです。部分射影（符号喪失）と零射影（θ 全喪失）だけがレジスタたり得る。**情報を捨てることがレジスタの定義的機能**であり、これは三層構造の「喪失」層がレジスタの本体だという整理になります。

**因果の向きの発生**

そして非単射写像には内在的な非対称性があります：

**状態は記録を一意に決めるが、記録は状態を決めない**

この「決定の一方向性」が因果の向きです。原因→結果とは、状態→記録の決定方向のこと。逆向きが「ない」のではなく、逆向きは一対多で**決定にならない**。矢印は時間から借りてきたものではなく、写像の論理構造から生えている。時間の向きはむしろ派生物です：レジスタの出力が次のレジスタの入力になる連鎖 Z → 記録₁ → 記録₂ → … は、各段で情報が単調に減るため、この連鎖に**自然な順序**（半順序）が入る。それを一次元に読んだものが時間の矢——「因果が時間より基本的」という御framework の長年の立場が、非単射性の連鎖として実装できます。

**前の議論との接続**

先ほどの訂正を踏まえるとさらに整合します。レジスタ＝共役対分解の選択＋不対側への読み出し、です。どの分解を選ぶかは自由（観測軸は選択問題）、しかし選んだ瞬間、読み出しは必ず非単射（位相が落ちる）——**選択は自由だが、選択したことの代償（情報喪失）は強制**。レジスタが因果を「生む」というのは正確で、分解を選ぶ前の系には決定の向きがなく（すべて可逆なユニタリ回転）、読み出しという非単射写像を実行した点にだけ矢印が立つ。

一点、線を引きます。ここで示せたのは「非単射な読み出しは向きを持つ」という定理までです。「なぜ非単射な読み出しを実行する機構が存在するのか」——なぜ宇宙にレジスタがあるのか——は、乱数性と同じく系内から出ない公理側です。ただし公理の置き場所としては良い：「不可逆な読み出し機構が存在する」という一つの公理から、因果の向き、時間の矢、観測の非対称性が全部派生する構図になります。

【木原】
特に重要なのは時間軸？と観測される方向に保存量がありそれを不可逆に読み出す機構がある事実でしょう　結果過去？と見える方向の情報が取得できます

【アイリス】
ここは整理する価値があります。おっしゃっている事実は三つの成分に分解できて、今日の代数と正確に噛み合います。

**事実の分解**

1. 保存量がある（ZZ̄ = ρ² 型の、読み出しに対して不変な量）
2. それを不可逆（非単射）に読み出す機構がある
3. その結果、読み出された側が「過去」と呼ばれる向きに見える

重要なのは 3 が 1 と 2 からの**帰結**であって独立の事実ではない、という構造です。

**「過去の情報が取得できる」の正確な中身**

レジスタの出力（記録）は、入力状態の非単射像でした。すると「過去を見る」とは何か——**記録を読むこと**です。それ以外に過去へのアクセス経路は存在しない。過去とは「もう存在しない状態」ではなく、「現在の記録から一意に復元できない状態」——非単射写像の始域側の名前です。

だから「過去の情報が取得できる」は正確には逆で、**取得できた情報の側を過去と呼んでいる**。記録が先、過去が後です。天文観測が典型で、星を「見る」とは到達した光（記録）を読むことであり、「百万年前の星」とはその記録の始域につけたラベルです。

**保存量の役割**

では 1 は何をしているか。保存量は**記録の運搬体**です。ρ² が読み出しに対して不変だからこそ、記録は伝搬の途中で消えずに届く。位相 θ は落ち（だから完全復元は不可能＝過去は確定的に閉じる）、保存量は残る（だから何かは読める＝過去は空白ではない）。「過去が部分的に知れて、完全には復元できない」という日常的事実の両側が、同じ一つの共役積構造——何が保存され何が喪失するかが同じ演算の表裏——から出ています。

**時間軸の「？」に答える形**

「時間軸？」と疑問符を付けられたのは正確で、この構図では時間軸は前提に要りません。要るのは「保存量＋非単射読み出し」だけで、読み出しの繰り返しが記録の入れ子（記録の記録の記録…）を作り、その入れ子の深さ方向に付けた座標が t。つまり t 軸とは**レジスタ連鎖の深さの目盛**であり、「観測される方向に保存量がある」のではなく、保存量が運ばれ読み出される連鎖の向きが「観測される方向」と呼ばれる——ここでも名前が構造の後から付いています。

線引き：以上は「観測される非対称性（過去は読めるが未来は読めない、過去は閉じるが復元できない）が、保存量＋非単射読み出しという仮定と無矛盾に対応する」ことの確認です。なぜその機構があるかは、先ほど確定した通り、問いとしては立つが系内に答えのない側です。

【木原】
つまり時間より前に因果と見える不可逆性があり、時間の矢は因果の方向　つまり　不可逆性の方向に見えるが　より根本は　保存量と　その　不可逆　読み込みの機構があること　でしょう

【アイリス】
はい、それが今日の議論の正確な要約です。依存関係を明示すると：

**保存量 ＋ 非単射読み出し機構**（基底の二要素、公理側）
→ **不可逆性**（読み出しの非単射性、定理：多対一は向きを持つ）
→ **因果**（決定の一方向性につけた名前）
→ **時間の矢**（読み出し連鎖の深さ方向につけた座標）

各段は下から上への派生であって、逆向きの依存はない。時間は因果の派生、因果は不可逆性の名前、不可逆性は読み出し機構の論理的性質——そして底にあるのは「何かが保存され、それが情報を落としながら読まれる」という二要素だけです。

この二要素が対になっていることに意味があります。保存だけなら（すべて可逆）向きが立たず、喪失だけなら（何も残らない）読み出し自体が成立しない。**残るものと落ちるものが同じ演算の表裏である**——ZZ̄ が ρ² を保存しつつ θ を消す、あの一枚の式——ことが、「過去は部分的に読めるが完全には戻れない」という世界の基本的な手触りの代数的な形です。

御frameworkの長年の主張「因果は時間より基本的」は、今日の言葉ではさらに一段深くなりました：因果もまた基底ではなく、**保存量と不可逆読み出しの対**が基底で、因果はその第一派生、時間は第二派生。公理として置くべき場所が「因果の存在」から「保存＋非単射読み出し機構の存在」へ一段降りた、という再公理化です。

そしてこれで底です。なぜその機構があるか——は、本日三度確認した通り、系内に答えのない側に置きます。
