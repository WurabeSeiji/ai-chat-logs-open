## 概要

第一篇 [1] の共役複素対を、実数（整数）のセル対で**実装**する。(i) セル対 $(a, b)$ を $Z = a + ib$ とみなすと、90°の位相遅延は $D: (a, b) \mapsto (b, -a)$——配線交差とインバータ1個、乗算器ゼロ——で実装され、$D^2 = \mathrm{NOT}$（両線符号反転）、$D^4 = 1$ を満たす。すなわち **$i$ とは NOT の平方根**であり、1本のブール線上には存在しない $\sqrt{\mathrm{NOT}}$ が、線を2本にした瞬間に実装可能になる——複素構造とは、180°遅延を二つの90°遅延に分解できる最小のレジスタ拡張である。(ii) 整数セル演算（加減・交差・符号反転、丸めなし）で**厳密に**実装できる離散位相遅延の位数は $\{1, 2, 3, 4, 6\}$ に限られる（結晶学的制限）。証明は Euler のトーシェント関数による（整数係数2次の特性多項式が原始 $m$ 乗根を持つ条件 $\varphi(m) \leq 2$）。60°の正しい実装は $(a, b) \mapsto (a - b,\ a)$、120°は $(a, b) \mapsto (-b,\ a - b)$ である。したがって整数厳密な位相格子は**ガウス整数（$\mathbb{Z}_4$）とアイゼンシュタイン整数（$\mathbb{Z}_6$）の二種しか存在せず**、45°（$\cos 45° = 1/\sqrt{2}$）は最初に格子から外れる角である。(iii) 第一篇の読出しの階梯は既製の回路と一対一に対応する：零射影 $Z\bar{Z}$＝包絡線検波、対間干渉 $Z_1\bar{Z}_2$＝IQ 復調（相関器＋位相検出器）、自己干渉 $Z^2$＝周波数2逓倍。(iv) 回転応答（巻き数）の発生条件を数値計算で確定する：実符号対（位相 $\{0, \pi\}$、$\mathbb{Z}_2$）は円周上で巻き 0 だが、**対蹠同一視した射影直線上ではちょうど巻き $1/2$**（一周で符号反転）を持ち、整数巻き $\pm 1, \pm 2$ には **quadrature（$\pm\pi/2$ の相対位相＝$\mathbb{Z}_4$ 細分）が必須**である。静的な実符号の集合は巻きを担えず、回っている（quadrature の）内容だけが巻きを担う。本稿は観察的技術ノートであり、量子計算の Clifford 境界（90°系＝古典的にシミュレート可能、45°＝T ゲート＝普遍性の入口）等への言及は接続点に留める。

## 1. はじめに

### 1.1 位置づけ

第一篇 [1] は複素振幅の読出しの代数を、第二篇 [2] は複素構造が強制される条件を扱った。本稿は方向を変えて**実装**を問う：複素数を持たないハードウェア——整数のセルと配線——の上に、第一篇の構造（位相・共役・読出しの階梯）はどこまで厳密に構成できるか。回路設計の語彙（セル・インバータ・遅延）を使うが、内容はすべて初等的な代数と組合せ論の定理である。

### 1.2 本稿の立場

第一篇 §1.2 の立場（観察的技術ノート）を引き継ぐ。「実装」とは、指定された演算（整数の加減・成分交差・符号反転）の合成で写像を厳密に（近似なしで）実現することを指す。

## 2. セル対と $i = \sqrt{\mathrm{NOT}}$

**定義 2.1（セル対）**. 整数のセル2個の対 $(a, b) \in \mathbb{Z}^2$ を、複素数 $Z = a + ib$ と**みなす**。ハードウェアに複素数は要らない——セル対が複素数である。

**命題 2.2（90°遅延の実装）**. 90°の位相遅延 $Z \mapsto -iZ$ は

$$D: (a, b) \mapsto (b, -a)$$

——配線交差＋インバータ1個、乗算器ゼロ——で厳密に実装される。$D$ の反復は

$$(a,b) \xrightarrow{D} (b,-a) \xrightarrow{D} (-a,-b) \xrightarrow{D} (-b,a) \xrightarrow{D} (a,b)$$

であり、$D^2 = \mathrm{NOT}$（両線の符号反転＝180°）、$D^4 = \mathrm{id}$。

*証明*. $-i(a + ib) = b - ia$。∎

**命題 2.3（1線では $\sqrt{\mathrm{NOT}}$ が存在しない）**. 一本のブール線上の写像 $f: \{0,1\} \to \{0,1\}$ で $f \circ f = \mathrm{NOT}$ を満たすものは存在しない。

*証明*. $\{0,1\}$ 上の写像は4つしかなく、恒等・定数2つ・NOT のいずれの自乗も NOT にならない。∎

**注意 2.4（複素構造の実装的定義）**. 命題 2.2 と 2.3 の対比が本稿の第一の要点である：**複素構造とは、NOT（180°遅延）を二つの90°遅延に分解できる最小のレジスタ拡張**である。虚部セルの中身も実装的に明確で、回転信号 $a(t) = \cos\omega t$ に対し $b(t) = \sin\omega t = a(t - T/4)$——**$b$ は $a$ の 1/4 周期遅延コピー**（quadrature 成分）である。共役 $\bar{Z} = (a, -b)$ はインバータ1個で作られる逆走コピーであり、クロックごとに $D$ を作用させる構成は、ディジタル信号処理の $f_s/4$ 直交発振器として実在する（乗数が $\{1, i, -1, -i\}$ に限られ乗算器が不要——実用受信機で使われる理由そのもの）。

## 3. 結晶学的制限：厳密な離散位相は $\{1, 2, 3, 4, 6\}$ に限る

**定理 3.1**. 整数成分の $2 \times 2$ 行列 $M \in GL(2, \mathbb{Z})$ が有限位数 $m$（$M^m = I$、$m$ 最小）を持つならば、$m \in \{1, 2, 3, 4, 6\}$。逆に各位数は実現される。

*証明*. $M$ の固有値は特性多項式 $x^2 - (\mathrm{tr}M)x + \det M$（整数係数・2次）の根であり、$M^m = I$ より1の冪根である。固有値が原始 $m$ 乗根なら、その最小多項式（円分多項式 $\Phi_m$、次数 $\varphi(m)$）は特性多項式を割るから $\varphi(m) \leq 2$。Euler のトーシェント関数について $\varphi(m) \leq 2 \iff m \in \{1, 2, 3, 4, 6\}$。実現例：$m = 2$ は $-I$、$m = 4$ は命題 2.2 の $D$、$m = 3, 6$ は命題 3.2。∎

**命題 3.2（60°・120°の厳密実装）**. アイゼンシュタイン格子上で

$$(a, b) \mapsto (a - b,\ a) \quad \text{は位数 } 6\ (60°), \qquad (a, b) \mapsto (-b,\ a - b) \quad \text{は位数 } 3\ (120°)$$

——いずれも加算器1個＋交差＋反転で実装される。

*証明*. 対応する行列 $\begin{pmatrix} 1 & -1 \\ 1 & 0\end{pmatrix}$, $\begin{pmatrix} 0 & -1 \\ 1 & -1 \end{pmatrix}$ の冪を直接計算（トレース 1, $-1$、行列式 1——定理 3.1 の $\varphi(m) \leq 2$ の実例）。全数検証（成分 $\in [-3, 3]$、$\det = \pm 1$ の全行列 232 個で発見された位数の集合が $\{1,2,3,4,6\}$ に一致）は同梱プログラムによる。∎

**注意 3.3（設計空間の完全な分類）**. したがって「整数セルで厳密に作れる離散位相遅延」の設計空間は、**ガウス整数 $\mathbb{Z}[i]$（90°系、$\mathbb{Z}_4$）とアイゼンシュタイン整数 $\mathbb{Z}[\omega]$（60°系、$\mathbb{Z}_6$）の二種で尽きる**。45°は $\cos 45° = 1/\sqrt{2}$ が無理数のため、いかなる整数セル構成でも厳密には作れず、近似（CORDIC 等）を要する——**格子から外れる最初の角**である。

## 4. 読出しの階梯の回路対応

第一篇の読出しは、それぞれ既製の回路と一対一に対応する：

| 第一篇の読出し | 演算 | 回路 |
|---|---|---|
| 零射影 $Z\bar{Z} = a^2 + b^2$ | 乗算2＋加算1 | 包絡線検波器（位相に盲目・回転不変） |
| 対間干渉 $Z_1\bar{Z}_2$ | 実部 $a_1a_2 + b_1b_2$／虚部 $b_1a_2 - a_1b_2$ | IQ 復調・ロックインアンプ（相関器＋位相検出器） |
| 自己干渉 $Z^2 = (a^2 - b^2) + 2iab$ | — | 周波数2逓倍回路 |

位相が**差としてしか**出力に現れないこと（絶対位相を読む演算が命令セットに存在しないこと）は、この対応表の水準で既に実装されている。

## 5. 巻きの発生条件：実符号対と quadrature

回転応答（巻き数）を数値計算で確定する。状態を方位角 $\chi$ 上の関数で表し、回転 $R_\varphi$（$\chi$ のシフト）前後の干渉位相 $\psi(\varphi) = \arg\langle \Psi | R_\varphi \Psi\rangle$ の傾きを巻き数とする（同梱プログラム）。

**結果 5.1**. (i) 実符号対（成分の位相が $\{0, \pi\}$ に限る——本稿の整数セルの静的構成）は、円周 $S^1$ のループで**巻き 0**（干渉位相が立たず振幅が $\cos\varphi$ で落ちるのみ）。(ii) 同じ実符号対を**対蹠同一視**した射影直線 $\mathbb{R}P^1$ のループで読むと、一周あたり位相 $\pi$ が蓄積し、**巻き $+1/2$**。(iii) quadrature 対（相対位相 $\pm\pi/2$、すなわち $\mathbb{Z}_4$ への細分）は巻き $\pm 1$、$m = 2$ の quadrature は巻き $\pm 2$。(iv) 方位角に依存しない因子の寄与（ギア比）は 0 であり、ノルムは回転で不変（閉包は回転応答を伝達しない）。

**注意 5.2（要点）**. **整数巻き $\pm 1, \pm 2$ には quadrature——$\pm\pi/2$ の相対位相、位相 $\{0, \pi\}$ の格子のちょうど中間点——が必須**である。静的な実符号の集合は巻きを担えない。担えるのは「回っている」内容だけである。一方、半整数の巻き $1/2$ は quadrature なしで、実符号対＋対蹠同一視（射影構造）だけから生じる——これは本シリーズの対蹠定理（反周期性 ⟺ 奇数調和のみ）の回転版であり、追加の構造を要さない。

**注意 5.3（$\mathbb{Z}_2 \subset \mathbb{Z}_4$ の階梯）**. 本稿の構成を通しで読むと：1線（$\mathbb{Z}_2$、NOT のみ、巻きなし）→ 2セル（$\mathbb{Z}_4$、$\sqrt{\mathrm{NOT}}$、quadrature、整数巻き）→ 対蹠同一視（半整数巻き）——**巻きの資格が、格子の細分の階梯と正確に同期する**。

## 6. 隣接する既知構造との接続点（導出は主張しない）

1. **Clifford 境界**（量子計算）：90°系のゲート群（H, S, CNOT）のみの回路は古典計算機で効率的にシミュレートできる（Gottesman–Knill [4]）。45°（T ゲート、$e^{i\pi/4} = (1+i)/\sqrt{2}$）を加えた瞬間に普遍量子計算となる。**本稿の整数厳密境界（$\mathbb{Z}_4$ 格子）と、古典シミュレート可能性の境界が同じ場所にある**——格子に乗る位相＝古典で実装可能な範囲、格子から外れる最初の角＝量子優位性の入口、という対応。$\sqrt{\mathrm{NOT}}$（$\sqrt{X}$ ゲート）が量子標準ゲートであり古典1線に存在しないことも命題 2.3 と同じ事実の両面である。
2. **パラメトロン**（後藤英一）：発振の位相 $0/\pi$ を1ビットとする論理素子——「位相がレジスタとして動く」の実用化の先例。
3. **格子ガスの等方性**（HPP/FHP [5]）：正方格子（$\mathbb{Z}_4$ 対称）は連続極限で等方性を回復できず、六角格子（$\mathbb{Z}_6$）が初めて Navier–Stokes を再現した——本稿の二種の格子の選択が連続極限の成否を決めた歴史的実例。
4. **LFSR**：XOR とディレイのみの機械（CRC・擬似乱数）は強力だが線形に留まる——第0篇 §5 の境界の実装版。
