# 共役複素数の自己干渉 — 極座標表現と射影の幾何（会話録）

日付: 2026-07-05

---

【木原】
共役な複素数の自己干渉を極座標表現すると

【アイリス】
Z = ρe^{iθ}、Z̄ = ρe^{-iθ} として重ね合わせると：

**和（干渉）**

Z + Z̄ = ρe^{iθ} + ρe^{-iθ} = 2ρcos θ

虚部が正確に打ち消し合い、結果は実数。極座標で見ると、干渉とは「θ と −θ の対称な二本のベクトルの合成」であり、合成ベクトルは必ず実軸上に落ちます。

**強度**

|Z + Z̄|² = 4ρ²cos²θ

ここで Born 分布の cos² 形が直接現れます。

**構造の読み**

- **保存**：ρ²（ZZ̄ = ρ² は θ に依存しない不変量）
- **喪失**：θ の符号。cos θ は偶関数なので θ と −θ、θ と 2π−θ は識別不能。回転の向き（巻き数の符号）が消える
- **射影**：連続量 θ が cos θ という実軸への射影値としてのみ観測に現れる

つまり共役対の自己干渉とは、極座標で言えば「位相角を実軸へ正射影する操作」そのものです。観測が得るのは cos θ（射影長）であって θ 自体ではない——θ の構造的不確定性は干渉後も解消されず、符号情報の喪失としてむしろ強化される。

DR系列の遅延回路との対応で言えば、Z と Z̄ は往路と復路であり、和を取る時点で「どちら向きに回ったか」の記録が回路から消える、という読みになります。

---

【木原】
θ の構造的不確定性　ってどういうことですか？

【アイリス】
観測可能量が ZZ̄ = ρ² という積の形でしか現れないとき、θ が原理的に決まらない、という意味です。

**代数的な事情**

ZZ̄ = ρe^{iθ} · ρe^{-iθ} = ρ² e^{i(θ−θ)} = ρ²

θ は計算の途中で e^{i(θ−θ)} = e^0 として**完全に相殺**されます。つまり ρ² という結果は、θ = 0 でも π/3 でも任意の値でも同一。逆に言えば、ρ² からは θ についていかなる情報も復元できません。

**「測定精度の問題ではない」という点**

「不確定」と言うと、値は存在するが測れない、という描像を想像しがちですが、ここでの主張はより強い。ZZ̄ という量の代数構造そのものが θ を消去している。方程式 ZZ̄ = ρ² を θ について解こうとすると 0·θ = 0 の形になり、解が「存在しない」のではなく「すべての θ が解」になる。これは装置の限界でも情報の隠蔽でもなく、**その量が θ を担っていない**という構造的事実です。

**前の話との接続**

先ほどの Z + Z̄ = 2ρcos θ では θ は cos θ として部分的に現れました。つまり：

- 積 ZZ̄ → θ 完全消去（構造的不確定）
- 和 Z + Z̄ → θ の偶関数成分のみ通過（符号喪失）

どちらの観測チャネルを通しても θ の完全な値は外に出ない。この「出口がない」ことが構造的不確定性であり、御framework で乱数性の公理を置く場所——θ がどの値を取るかを決める機構は代数の外にある——と対応しているはずです。

【木原】
つまり　全投射どころか何も投射しない極端な例ですね

【アイリス】
その通りです。射影の系列として並べると：

- **ZZ̄ = ρ²**：θ の射影核が零。何も通さない（零射影）
- **Z + Z̄ = 2ρcos θ**：実軸への正射影。偶成分のみ通過、符号は落ちる（部分射影）
- **Z 単独**：θ 全体を保持（恒等射影）——ただしこれは観測としては実現しない

面白いのは、保存量 ρ² を取り出す操作こそが θ に対する零射影だという点です。「何が保存されるか」と「何が完全に失われるか」が同一の演算 ZZ̄ の表と裏になっている。保存と喪失が別々の過程ではなく、一つの積演算の二側面である。

三層構造（保存／喪失／射影)で言えば、ZZ̄ は喪失が極大化して射影がゼロになる端点であり、Born 則の cos² はその手前——部分射影の強度——に位置する、という整理になります。

【木原】
んーこれわかりやすいですね
これをわかりやすく幾何的に図化できますかZ単独は3dでは螺旋構造ですよね

【アイリス】
はい、Z 単独はまさに螺旋です。3D（θ軸 × Re × Im）でインタラクティブに図化しました。

（成果物: conjugate_projection_3d.html — three.js によるインタラクティブ3D可視化）

構成は四層の重ね描きです：

- **Z（水色）**：右巻き螺旋。θ の全情報を保持
- **Z̄（橙）**：左巻きの鏡像螺旋。巻き数の符号だけが逆
- **Z+Z̄（黄）**：二本の螺旋が実平面（Im=0、うっすら表示した面）へ潰れた余弦波。螺旋の「影」です
- **ZZ̄（緑）**：ただの水平直線。うねりが完全に消え、θ の痕跡ゼロ

スライダーで断面を動かすと、各 θ での Z と Z̄ のベクトルが表示され、虚部が等大逆符号で相殺する様子（点線）と、和ベクトルが常に実軸上に立つことが見えます。「▶ θ を回す」で連続アニメーションになります。

視覚的なポイントは、**螺旋 → 余弦波 → 直線**という系列が、そのまま恒等射影 → 部分射影 → 零射影の階梯になっていることです。緑の直線を見ると「保存量とは、うねり（位相）を完全に捨てた残余である」ことが一目でわかります。ドラッグで視点を回して、真上（Im軸方向）から見ると和が螺旋の正射影そのものであることも確認できます。
