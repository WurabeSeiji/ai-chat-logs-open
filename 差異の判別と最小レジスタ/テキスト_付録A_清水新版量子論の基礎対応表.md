# 付録A 清水『新版 量子論の基礎』対応表——標準テキスト・注釈・本書の接続

> **この付録の問い**：清水先生の『新版 量子論の基礎』本文と、その周辺に付けた木原注釈・思考実験ノートは、本書のどの章と接続するのか。どこまでが標準量子論の枠組みで、どこからが本書側の解釈・仮説・予言在庫なのか。
> **この付録の答え**：本付録は、一般的な量子論対応表ではない。ローカルの `新版量子論の基礎/` フォルダにある清水先生テキスト本文、補講、木原注釈、思考実験メモを親資料として、本書各章との対応を整理する。清水本文は標準量子論の正典として尊重し、木原注釈は、標準本文の背後にある暗黙の前提、読出しの境界、観測可能性、個体化、複素構造、位相空間描像を検査するための問題提起として扱う。
> **この付録の約束**：注釈中の強い表現を、そのまま本書の確定主張にしない。標準理論で確立している内容、本書の安全な対応、未検証仮説、強すぎて第18章へ送るべき表現を分ける。

**【読み下し】** 清水先生のテキストは、量子論を学ぶための標準的な道筋を与える。一方、木原注釈は、その道筋の途中で「この仮定はどこから来たのか」「観測できないものをどのように同一視しているのか」「波動関数や複素数をどの層で読むべきか」を繰り返し問い直している。本付録では、その問い直しを、本書の台帳・読出し・非単射性・個体化・予言在庫の言葉へ接続する。ただし、接続できることと、標準量子論を導出したことは違う。この付録は、その違いを守るための対応表である。

先に用語をほどいておく。**清水本文**とは、標準量子論としての本文・補講・定理・要請の記述を指す。**木原注釈**とは、その本文に対して付けられた疑問、補足、思考実験、再解釈メモを指す。**標準接続**とは、本書の用語が清水本文の既知構造と対応する場合である。**注釈接続**とは、木原注釈で提起された問題意識と本書の章が対応する場合である。**安全な対応**とは、形の類似や読み替えを述べるが、標準理論の導出や置換とは言わない扱いである。（いずれも→用語集）

## A.4 第2章が本書に与える最重要接点

清水先生の第2章で最も重要なのは、状態を次のように扱う点である。

> **状態は、物理量 $A$ を入力すると、その測定値の確率分布 $\{P(a)\}$ を返すものとして扱える。**

これは、本書の「読出し」の言葉と形式上よく接続する。状態そのものを直接見るのではなく、物理量を選び、測定面を通して、出力分布を読む、という点で対応している。したがって、本書の差異判別は、清水第2章の標準枠組みと次のように接続する。

| 清水第2章 | 本書 |
|---|---|
| 物理量 $A$ | 読出し面・目盛り |
| 測定値 $a$ | レジスタに出る値 |
| 確率分布 $\{P(a)\}$ | 外部記録に残る分布 |
| すべての物理量で分布が一致 | 外部読出しから区別不能 |
| 分布が異なる物理量がある | 差異が読出し面に出る |

ただし、ここで本書は一歩だけ慎重に読む。清水本文では、すべての物理量について分布が一致するなら同じ状態と定義する。本書では、この定義を尊重しつつ、「外部読出しから同じであること」と「内部台帳に差がないこと」を常に分ける。これが、ブラックホール型読出し、もつれ、外部測定、予言在庫へ続く本書側の分岐である。

## A.5 木原注釈から拾うべき核

木原注釈は多いが、本書に直接関係する核は次の五つである。

| 核 | 注釈側の内容 | 本書での安全な扱い |
|---|---|---|
| 個体化閾値 $\Delta$ | $L<\Delta$ では誤差以前に「二点間距離」という問題が立たない | 第6章・第17章で、測定限界ではなく読出し対象の成立条件として扱う |
| 検出器層・統計層・情報層 | 検出器に出る実数値、統計分布、複素位相構造を分ける | 第9章・第18章で、実数読出しと複素構造を混同しないために使う |
| 波動関数の非直接観測性 | 単発測定では点状イベントが出て、滑らかな $|\psi(x)|^2$ は統計で現れる | 第8章・第9章で、外部記録と内部表示を分ける |
| 位相・時間・空間の表示注意 | 位相を時間軸や空間軸へ描くのは理解用の図であって物理的強制ではない | 第7章・第13章で、図示と実在主張を分ける |
| 不確定性の面積読み | Robertson 型の下限だけでなく、位相空間面積・対称/反対称成分を見る | 第6章・第17章で、対応候補として保管する |

特に思考実験(6)の $\Delta$ は、本書にとって重要である。そこでは、$\Delta$ は単なる測定誤差ではない。$\Delta$ より下では、二つの点を二つとして立てる読出しそのものが成立しない。この構造は、本書の「差異が読めるとは何か」という問いに直結する。

注釈の中には、非常に強い表現がある。本付録では、それらをそのまま採用せず、第3巻の身分管理へ戻す。

| 強い注釈表現 | 付録Aでの安全な扱い | 送る先 |

| 標準量子論の不整合が解消される | 標準記法の背後にある図示・解釈上の曖昧さを検査する、と書く | 第18章 |

| 離散時空が観測可能性原理から必然的に出る | 個体化閾値・離散読出しの思考実験候補として扱う | 第17章 |
