# 思考実験メモ：大域 $R$ 共有と干渉読出し条件

**位置づけ**：第3巻候補。第15章「複合系ともつれ」の本文には入れすぎない背景思想を、検証・予言・訂正巻の思考実験在庫として保存する。

**作成日**：2026-07-08

---

## 1. メモの核

第15章では、共有台帳を「複数の部分系が保存量、位相関係、内部符号構造、読出し条件を共有しているため、別々の測定面で読んでも相関が残る構造」として扱った。

この背景には、より強い見方がある。

> 同じ閉じた系に属する要素は、少なくとも一つの保存量または読出し条件を共有している。典型例として、$xyztRQ$ 台帳の $R$ 欄を共有している場合がある。

分かりやすい例では、部分系 A と部分系 B が、同じ $R$ 側の保存量、共通半径、ノルム制約、またはそれに付随する位相関係を共有する。このとき、A と B が外部空間では離れて読まれても、後で局所記録を照合すると相関が残りうる。

---

## 2. 大域閉宇宙への拡張候補

さらに強い候補として、我々の四次元時空全体が、閉じた有限な曲率半径 $R_0$ を共有していると読む場合がある。

この読みでは、宇宙の端に近い領域と反対側の領域であっても、同じ大域 $R_0$ 台帳に属するという意味では、完全に無関係な二冊の台帳ではない。したがって、非常に広い意味では、同じ閉じた系の共有条件の下にある、と読む余地がある。

ただし、この表現は非常に危険である。第15章本文では、次のような誤読を避けるため、あえて抽象的な共有台帳の説明に留める。

| 誤読 | 避ける理由 |
|---|---|
| 宇宙全体がただちにもつれている | 観測可能な Bell 型相関や干渉条件を別途示していない |
| 宇宙の端から反対端へ信号が飛ぶ | 共有台帳は超光速通信を意味しない |
| 非局所相関を宇宙曲率で説明した | 定量的相関関数や測定基底依存性を構成していない |
| 共有 $R_0$ が局所隠れ変数表である | 全測定結果の事前リストではなく、保存量・位相・読出し条件の制約である |

したがって、第2巻本文では「共有台帳を別々の測定面で読むと相関記録が残る」と書くに留め、第3巻で大域 $R_0$ 共有の射程を検証課題として扱う。

## 3. 干渉可能性と位相台帳の読出し

もう一つの核は、干渉の位置づけである。

干渉は、単なる波の重なりではなく、内部位相台帳を外部記録へ写すための読出し条件として扱える。

| 読出し状態 | 読めるもの | 読みにくくなるもの |
|---|---|---|
| 非干渉的読出し | 到達位置、粒子数、強度、保存量のような粗い記録 | 位相差、相対位相、共有台帳の細部 |
| 干渉的読出し | 位相差、経路差、コヒーレンス、共有台帳由来の相関 | 内部台帳そのものの全情報 |
| 共有台帳読出し | 相関、保存量制約、同時整列条件 | 全測定基底の事前結果 |

したがって、「干渉がなければ存在しない」とは言わない。より正確には、干渉がなければ、位相差を含む台帳構造は外部記録として読みにくくなる。しかし、強度、到達位置、粒子数、保存量のような粗視化された記録は残りうる。

---

## 4. 高次奇数倍音との接続

高次奇数倍音は、鋭い局在や高い解像度を支える一方で、読出し条件に対して敏感である。

候補となる流れは次である。

1. 高次奇数倍音が局在を支える。
2. 高次側ほど、位相・経路差・共有台帳の整列条件が厳しくなる。
3. 読出し条件が外れると、高次倍音が干渉に参加できなくなる。
4. 有効 $N$ が下がり、局在や位相構造の読出しが粗くなる。
5. 外部記録は、細部の位相台帳ではなく、到達位置・強度・保存量のような粗い記録へ落ちる。

この整理は、第8章の外部測定論、第13章の内部モード、第15章の共有台帳、第3巻の検証編をつなぐ候補である。

## 5. 第3巻での扱い候補

第3巻では、次の問いとして整理できる。

| 問い | 扱い |
|---|---|
| 同じ閉じた系に属する部分系は、最低一つの保存量を共有すると言えるか | 概念検証 |
| 大域 $R_0$ 共有は、観測可能な相関とどう区別されるか | 誤読防止と反証可能性 |
| 干渉可能性は、位相台帳を読める条件として定式化できるか | 測定論との接続 |
| 高次奇数倍音の脱落は、局在幅や可視度の低下として検査できるか | 数値検証候補 |
| 共有台帳は、局所隠れ変数表とどう違うか | Bell 型議論への防御線 |

第15章本文へ入れる場合は、次の弱い形に留める。

> より広い見方をすれば、同じ閉じた系に属する部分系は、何らかの共通の保存量や読出し条件を共有していると読むこともできる。ただし、本章ではこの大域的共有を、直ちに観測可能な干渉や Bell 型相関と同一視しない。ここで扱うのは、外部測定面で相関記録として読める範囲の共有台帳に限る。

ただし現時点では、第15章本文には入れず、第3巻候補として保存する。
