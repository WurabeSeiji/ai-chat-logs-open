## 序章 確定度の表記法

# 第I部 確定している代数核（誤謬・余りなし）

## 1. 共役複素数の二つの積 ◎

Z = a + ib に対し、積は二つしかなく、**何を忘れるかが正確に違う**。

| 積 | 結果 | 失うもの |
|---|---|---|
| 共役積 ZZ̄ | a² + b² = r²（実・正定値） | 位相 θ 全体（S¹ 連続ファイバー） |
| 非共役積 ZZ | (a² − b²) + 2iab = r²e^{i2θ} | 符号 ±Z のみ（ちょうど1ビット） |

- 共役積とは**平方和を取り出す代数装置**である。虚数単位の符号反転がクロス項 ±iab を相殺し、平方和だけを残す
- ZZ の実部 a²−b² = (a+b)(a−b) は判別式（差の構造）、虚部 2ab は交差項（干渉の構造）——判別と干渉が実部/虚部に自動で振り分けられる
- 三者を縛る恒等式：**(a² + b²)² = (a² − b²)² + (2ab)²**（ピタゴラス三つ組の生成公式）
- **射影の階梯**：ZZ̄＝零射影（θ を何も通さない）／Z+Z̄ = 2ρcosθ＝部分射影（偶成分のみ、符号喪失）／Z 単独＝恒等射影（観測としては実現しない）。**保存量 r² を取り出す操作こそが θ への零射影**——保存と喪失は一つの積演算の表裏
- θ の構造的不確定性：ZZ̄ = ρ² を θ について解くと「すべての θ が解」になる。測定精度の問題ではなく、**その量が θ を担っていない**という代数構造の事実

幾何像：螺旋（Z）→ 余弦波（Z+Z̄）→ 直線（ZZ̄）が恒等→部分→零射影の階梯（可視化: [conjugate_projection_3d.html](conjugate_projection_3d.html)）。

## 2. 単独の Z：a² + b² = r² ◎

- a = ρcosθ, b = ρsinθ より **a² + b² = ρ² = r² は ZZ̄ = ρ² と同一の式**。ピタゴラスの定理と共役ノルムは一枚の式である
- 円の方程式は円周上の点を指定しない——「すべての θ が解」の幾何的な姿。零射影とは点を円全体に脱色する操作
- ピタゴラスの円とは、螺旋から θ の履歴を捨てた**端面図**（[conjugate_projection_3d.html](conjugate_projection_3d.html) を θ 軸正面から見た図）

## 3. 複数の Z・偶数項：a² + b² + c² + d² = e² + f² = R² ◎

- **複素構造 J² = −I は偶数次元の実空間にしか存在しない**（J の固有値 ±i は必ず対で現れる）。ゆえに共役積から作る平方和は必然的に偶数項——2m 個の実座標は m 個の共役対に組める
- 4平方和＝2レジスタのノルム和＝四元数ノルム：a²+b²+c²+d² = |Z₁|² + |Z₂|²。階層は再帰し **Cayley–Dickson 構成**（ℂ→ℍ→𝕆）をなす。ノルム乗法的な倍加は **Hurwitz の定理により 8 で止まる**（2-4-8 平方恒等式）
- 多モードの平方和は二階建て：モード毎の円 aₙ²+bₙ² = ρₙ²（局所）＋ **Parseval 球 Σρₙ² = R²**（大域、2n−1 次元球面）。各 ρₙ 固定なら状態はトーラス Tⁿ 上
- |W|²（W = ΣZₙ）＝**対角項 Σρₙ²（保存・θ 非依存）＋交差項 2Σρₘρₙcos(θₘ−θₙ)**。観測に漏れるのは位相差という相対量だけ——大域位相 U(1) は多モードでも消えたまま（一斉回転で |W|² 不変）
- 偶数項ゼロ形式は「二つの共役積の等式」に必ず落ちる：a²+b²−c²−d² = 0 ⟺ **Z₁Z̄₁ = Z₂Z̄₂**（二つの円の半径の一致、保存量の受け渡し・共鳴の形）
- 奇数倍音の厳密分解：Z₁+Z₃+Z₅ = (1 + 2cos2θ)·e^{i3θ}（中央倍音の巻き数×脈動半径。可視化: [odd_harmonics_synthesis_3d.html](odd_harmonics_synthesis_3d.html)）

## 4. 零二乗和：最低一つの虚項が必須 ◎（公開済：複素ノルム論文 v0.5 付録C）

- Σνₙ² = 0 は、全項が実数なら自明解（ALL 0）しか持たない。**非自明解には一軸以上の虚数項が論理的に強制される**（付録C C.1/C.2 として公開済）
- 最小の非自明構成＝実2軸＋虚1軸：a² + b² + (ic)² = 0 ⟹ **a² + b² = c²**。ピタゴラスは公理でなく**閉包条件の移項**である。最小の閉じた系＝共役複素数そのもの（Z = a+ib, ZZ̄ = c²）
- c＝系全体の振動数＝**マスターカウンター**。閉包はビート成立の3条件を自動供給する：対（c 対 a, b）・周波数差（両成分非零なら c > a, c > b 厳密）・コヒーレンス（拘束＝位相ロック）。ゆえに**「非自明な閉包 ⇔ 自前の目盛りを持つ」**
- 多次元一般形：Σⱼ|Zⱼ|² + (iν)² = 0 ⟹ Σ|Zⱼ|² = ν²（レジスタ配列＋グローバルマスター、ノルムは非負なので虚項は依然必須）
- r を座標に昇格すると a²+b²−r² = 0 は (a,b,r) 空間の**光錐**：生成線＝中心投影の投影光線、北極超接平面＝アフィン切片 r=R、グノモンチャート＝光線束の断面。θ は生成線に直交するコンパクトファイバーに棲む
- 注意：「平方和ゼロの非自明解には計量の符号混合か複素化が必要（両者は等価）」が定理の正確な形。**なぜ自然がこの形式かは系内から出ない**

**構造上の要点**：本項目の零二乗和形式「2n 対＋虚1軸」は**奇数項**である。つまり確定項目4と保留項目6（奇数項の解釈）は同じ式の表裏——「虚項の存在」が確定側、「その虚項＝不対軸の解釈」が保留側。

## 5. 有界＋一価 ⇒ ν空間の等間隔離散格子 ◎【量子化の実体】

- θ の定義域が円（有界・閉）で、状態が円上の一価関数であるならば、許容モードは **ν 空間の等間隔離散格子** νₙ = n·ν₀ に限られる（円上の一価性：一周で位相が 2π の整数倍進む以外にない）
- **「n が整数」は規約**（歩幅 ν₀ = 1/λ₀ を単位に選んだラベル）。定理であるのは：離散性（許容波長は {円周/n}、稠密でない）・通約性（任意の二モードの比は有理数）・最長波長の存在（器の上限）——一句に畳めば**等間隔格子の存在**
- 巻き数描像（外への無限）は**分割描像**（有界な器 λ₀ を整数分の1に割る、内への無限）に反転される：λₙ = λ₀/n, νₙ = n·ν₀。有界性は一度も破られず、λ₀ という有界性こそが n を定義する基準
- 等距離性が本質である証拠：(i) 加法で閉じる（νₘ + νₙ = νₘ₊ₙ、モード合成が系内で閉じる）、(ii) 一様な加算器が実装できる（有限ステップ整数演算の実体）
- 離散か連続かは ν の性質ではなく **θ の定義域が閉じているか開いているかの帰結**（θ ∈ ℝ なら任意の実 ν が正当——連続スペクトル）。一価性の意味＝**レジスタ読み出しの再現性**（多価を許す物理系は実在する：Aharonov–Bohm、エニオン）

# 第II部 解釈が確定していない三項目

## 6. 奇数項の場合の解釈

**◎ 定理として確定している部分**
- 奇数項の平方和では、どの共役対分解を選んでも**一軸が必ず不対で残る**（複素構造の偶数次元性の帰結）
- 奇数項ゼロ形式 Z₁Z̄₁ + ⋯ + ZₙZ̄ₙ + (ir)² = 0 では、不対軸が**強制的に虚化側**（光錐の軸・曲率半径・投影の動径方向）に置かれる
- 不対軸の不確定性は U(1)（連続位相、非可算無限の解）ではなく **Z₂（符号 ±c のみ、二つの解）に退化**する。回るべき相方がいないので回転自由度そのものが構成できない

**○ 定理だが選択を含む部分**
- **どの軸が不対か**は代数が決めない——チャート（観測者の視点）の選択。「不対軸の存在」は強制、「どれか」は自由。xyztR の5軸は奇数なので、**R 軸が対を持てないこと自体は代数の強制**だが、R をその軸に選ぶのは framework の構成

**△ 示唆に留まる部分**
- 不対軸は（符号を除き）**確定値を持てる唯一の方向**であり、それは観測・記録が要求する性質——「観測の基準となる軸は位相を持てない軸でなければならない」という一本の線
- 位相を担う軸（連続・不確定）とラベルを担う軸（離散・ほぼ確定）の二種類しか平方和の代数は許さない——**xyztRQ の軸の質的二分が「共役対に組めるか否か」の一判定基準に還元**される可能性

**✕ 撤回済み**
- 「観測軸は不対軸で**なければならない**」——観測軸は選択問題（完全に対称でどの軸でも観測軸になれる）。正確な向きは「観測軸を選ぶと、その選択が不対軸を指定する」

## 7. 平方和＝平方和（等号）の解釈

**◎ 定理として確定している部分**
- 等号は文脈により三つの顔を持つ：**恒等式**（ρ² が |Z|² の定義なら厳密——ただし循環であり内容空）／**主張**（r² を独立に与えた瞬間、検証対象になる）／**理想化**（N → ∞・積分時間無限大の極限でのみ成立）
- 有限の観測者に対して厳密に成立するのは等号でなく **Bessel の不等式 Σₙ≤N ρₙ² ≤ R²**。差分＝剰余 δ は「まだ読み出していないモード」の取り分であり消去不能
- 整数格子上では a² + b² = r² を厳密に満たす点は**ピタゴラス数という例外点だけ**。一般には剰余 δ ≠ 0 が構造的に残る

**△ 解釈・予言に属する部分**
- 等号の正しい読み：状態の等式ではなく、**「異なる二つの読み出し経路が同じ記録に落ちる」という記録面上の整合条件**（両辺がそれぞれ非単射写像を通った記録同士の等置——y = x² の構造がある以上、全投射ではあり得ない）
- **等号は神の視点（連続体・完全基底・無限積分）でのみ成立し、観測者相対の系では常に Σ ≤ R²、剰余は消去不能**
- 剰余＝エントロピーの居場所（α⁻¹ = 137 + (π²/2)α の補正項、BH 充填欠損のスケーリングとの形の一致）
- **強い予言**：分割数 N が小さい系では、平方和の等号だけでなく**左辺の項数・次元定義自身が曖昧化**する（モードの識別可能性が格子から供給されなくなる）。次元＝大 N 極限でのみ鋭く定義される派生量、という再公理化。この N 依存の退化は**奇数倍音の干渉限界として既に計算・検証済み**（N=1 で干渉という概念自体が定義不能）。外挿（規格化・項数・次元への一般化）は未計算

## 8. 系とスケールファクターの私有【隠れた大テーマ】

現在の量子力学には「系」の考え方が希薄である。共役複素数自身が保存量 r² を持つ以上、すでに最小レベルで閉じた系になっている——そして**系ごとにスケールファクターが異なる**という前提が、一連の思考実験の全体に隠れて流れている。

**◎ 定理として確定している部分（第I部項目4の直接の帰結）**
- 共役対 ZZ̄ = r² は、保存量を持つ**最小の閉じた系**である
- 非自明な閉包はマスターカウンター c を持ち（項目4）、c がその系**固有の単位**——器 λ₀・格子間隔 ν₀・目盛り——を定義する。**閉包はスケールを私有する**
- 系間で観測可能なのはマスター同士の**比**のみ（「周波数は比しか測れない」の系間版）。系間の相互作用＝モード共有にはスケール換算が必須で、その換算簿記こそが接続（ゲージ場）の実体（第III部10節の深化）

**○ 規約の指摘——QM の系概念が希薄な理由**

- 本 framework では逆に、Born の |W|²/R² の分母 R² は「1 に規格化すべき雑務」ではなく**その系の器の容量＝系の同一性そのもの**

**△ この見落としが生んでいる誤解の目録（読み替え候補）**

# 第III部 代数核の上に立つ解釈体系

第I・II部の代数を、観測・レジスタ・物理へ読み替える階。各節に確定度を付す。

## 8. 観測の最小構成——2つのランプ

- **0個**＝ないことすらわからない／**1個**＝比較相手なしで観測量ゼロ／**2個**＝片方だけ違うとき初めて「違い」がわかる——「2」の起源
- 制約3つ（毛がない＝S_N 置換対称、点灯の絶対名なし＝Z₂ 全反転対称、数えられない＝濃度非アクセス）の下で、生き残る観測量は**ちょうど1ビット「一様か非一様か」**（N=2 で a⊕b＝XOR が唯一の非定数不変量）◎
- 時間・空間・順序・可算性すべて不要。必要なのは共在する対の比較のみ ◎
- ±1 符号化で XOR＝完全相殺の有無（明/暗）として干渉で読める——**干渉が第0層、最小観測＝平方和の加法性が破れたか否かの1ビット** ◎（既知実装：SWAP テスト、Hong–Ou–Mandel）
- **XOR 単独は線形止まり**（Post の格子・アフィン類）。万能は {XOR, AND, 1}（Zhegalkin）。**AND＝積＝干渉交差項の離散版**（強度和はピタゴラス側の無情報部分）、内積＝セル毎 AND の XOR 集約 ◎
- **{XOR, AND}＝半加算器**。ランプが数えられなかったのは桁上げ線がないから——数の発生＝carry の配線 ◎
- 物理対応：XOR＝g⁽¹⁾（場の加算）、AND＝g⁽²⁾（強度相関・コインシデンス）。非線形性は力学でなく読出し（二乗則検波）に宿る △

## 9. レジスタと因果・時間

- **不可逆性の無時間的定義＝写像の非単射性（多対一）**。「戻せない」でなく「戻り先が一意でない」——時間を前提せず不可逆性が立つ ◎
- **レジスタ＝非単射写像を実行する機構**。情報を捨てることが定義的機能（恒等射影＝コピーはレジスタでない）。最小レジスタ＝2分割（±180°、Z₂）——喪失の最小単位と記録の最小単位が同一 ◎

## 総括の一行

**確定しているのは五つの代数（二つの積・単独の円・偶数項の Parseval・零二乗和の虚項強制・等間隔格子）。保留は三つの解釈（不対軸の意味・等号の身分・系のスケール私有の射程）。その上のすべて——観測・レジスタ・因果・時間・目盛り・ゲージ・不確定性・Born・Bell・粒子・α137——は、この五つの代数の読み替えとして「説明可能・無矛盾・それが限界」の文型で書ける。そして閉包がスケールを私有するという隠れた前提が、レジスタ系列を最古の中心投影シリーズ（三層構造 R–R₁–R₀）に接合する。**

**検証後の追記（2026-07-05）**：この骨格は最初の実弾検査を通過した。除外率の閉形式 (2/π)√(1−A_th)/σ_n が公開済み論文の測定値（1.5〜4.0%）と完全整合し——枠組みが初めて「公開済み測定値を予言する側」に回った——、対蹠 Z₂＝奇数倍音が同値定理として成立して三系列（グノモン幾何・レジスタ原理・平方数系列の前提）が接合し、同時に弱い主張3件（2/π² の一致・小 N セル欠損・確率欠損予言）が篩にかけられて死んだ。予言の正しい型は「観測可能量同士の関係の形」（レバーは 1/N）であり、在庫は除外率の2軸スケーリング（一部検証済み）・陽子の絶対安定（GUT と対立する反証可能予言）・低 Q 崩壊の格子計数偏差（未計算）の三本である。
