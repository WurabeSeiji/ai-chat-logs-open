## 戦略的結論（接触・seeding の観点）

**高木レクチャーは seeding の場としては機能しない。**

- 講演そのものは最高水準の予習価値があり、Behrend CY3 のような最注目テーマを直接聴ける点で**インプット（学習・予習）の場としては極めて有効**。
- しかし**アウトプット（接触・名刺交換・関係構築）の場としては機能しない**：ティータイムですら名刺交換ゼロ、ほぼ顔見知りのクローズドサークルで、外部からの参入余地がない。
- **必要条件＝「話ができる対話の場」**。シグマサロン型（少人数・OB ネットワーク・話題提供と質疑のある場）でなければ、関係構築は成立しない。
- → 接触戦略上、**大規模学術カンファレンス（高木レクチャー型）は「聴きに行く場」と割り切り**、関係構築は別チャネル（シグマサロン 8/1 話題提供、池内氏ルート、真貝先生ら個別接続）に寄せる。3 要件（阪大客員・JPS・推薦者）の獲得経路として、高木レクチャー型イベントは数えない。
