## 1. 複素数は実体ではなく便利な記法

複素数 $z = a + ib$ の数学的実体は、**2×2 実行列**

$$z \leftrightarrow \begin{pmatrix} a & -b \\ b & a \end{pmatrix}$$

これだけです。この対応で：

| 複素数の操作 | 実行列の操作 |
|---|---|
| 加法 $z_1 + z_2$ | 行列の和 |
| 乗法 $z_1 z_2$ | 行列の積 |
| 虚数単位 $i$ | $\begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$ ＝ **90° 回転** |
| 共役 $\bar{z}$ | 転置（X 軸鏡映） |
| 絶対値 $|z|$ | $\sqrt{\det}$ |
| ユニタリ $|z|=1$ | $SO(2)$ 行列（回転） |

**「複素数」という名前は、SO(2)×ℝ₊（回転＋正のスケーリング）を可換に書く 1 記号への省略**です。$i$ も $\bar{z}$ も実体ではなく、$\mathbb{R}^2$ の自己同型群を扱う**書き方の便利さ**にすぎない。

物理学が「複素ヒルベルト空間」「エルミート共役」と仰々しく書くのは、**2 次元実ベクトル空間とその回転群**を、複素数 1 文字で省略しているだけ。3D CG プログラマが quaternion を $w + xi + yj + zk$ と書くのと同じ記法トリック（実体は $\mathbb{R}^4$ 上の群作用）。

## 2. $\theta(t) = kt + \theta_0$ は最強の追加仮定

これがさらに本質的です。「ψ(t) = re^{-iEt/ℏ}」は、暗黙に：

$$\theta(t) = -\frac{E}{\hbar} t + \theta_0, \quad \dot{\theta} = -\frac{E}{\hbar} = \text{const.}$$

つまり**位相が時刻 $t$ に対して線形**＝**角速度一定**を仮定しています。これは：

| 仮定 | 内容 |
|---|---|
| ハミルトニアン $\hat{H}$ が**時間不依存** | $H = H(t)$ ではなく $H = \text{const.}$ |
| 状態が**エネルギー固有状態** | $\hat{H}|\psi\rangle = E|\psi\rangle$、単一固有値 |
| 系が**自由**（外的相互作用なし） | 摂動・ポテンシャルなし |
| 力学が**最も単純** | 等角速度の円運動、SHM |

**この 4 条件が全て成立するから線形 $\theta(t) = kt + \theta_0$**。一つでも崩れると：

- $H(t)$ 時間依存 → $\theta(t) = -\frac{1}{\hbar}\int_0^t E(t')dt'$（非線形）
- 重ね合わせ状態 → 各固有成分は線形だが**全体は単純円運動でない**
- 摂動あり → 角速度が変動

つまり螺旋（helix）の絵が描けるのは、**「最も退屈な物理状況」＝定常状態のエネルギー固有状態だけ**。

## 3. これらを統合した究極の還元

ご指摘 2 つを合わせると、ψ(t) = re^{-iEt/ℏ} の本当の中身は：

```
入力: 進行度パラメータ s ∈ ℝ
出力: S¹ 上の点（または S¹ × ℝ₊ 上の点）
規則: s に対して S¹ 上を等角速度で進む
```

これは**「単位円上の点が等速で動く」だけ**。CG プログラマなら：

```javascript
function psi(s, omega, r) {
    const theta = omega * s;  // 線形仮定
    return [r * cos(theta), r * sin(theta)];
}
```

たった 3 行。これに「波動関数」「量子力学」「エルミート」「ユニタリ」「複素ヒルベルト空間」と仰々しい名前を貼っているのが標準物理学の記法です。

## 4. 本当に「量子的」な要素はどこ？

ここまで還元すると、**「量子力学」を量子力学たらしめる要素は螺旋の中にゼロ**であることが分かります。「単位円上の等速円運動」は古典物理学の調和振動子と何も変わらない。

「量子的」と呼ぶべき独立要素は claude.ai が指摘した 4 つ：

| 量子的要素 | 螺旋には含まれない |
|---|---|
| 状態空間が複素ヒルベルト空間（無限次元、ベクトル）| 螺旋は 1 つの点の運動 |
| Born 則 $|ψ|^2$ = 確率 | 螺旋はノルム保存だが「確率」概念は別 |
| 測定の射影公理（収縮） | 螺旋は剛体回転、収縮しない |
| 重ね合わせ・もつれ（テンソル積） | 螺旋は 1 自由度 |

螺旋は**運動学の絵**であって、**量子論の絵ではない**。標準物理学はこれらを密輸入してきた。

標準物理学の記法 $\psi(t) = re^{-iEt/\hbar}$ は、**ステルスで 6 つの仮定を導入**：

1. 引数 $t \in \mathbb{R}$ を「時間」と命名（パラメータ化の選択）
