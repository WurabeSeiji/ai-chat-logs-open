# 中心投影による次元削減 ── 「順次中心投影」を正しく代数化する

## はじめに

中心投影（central projection、グノモン正写像、gnomonic projection）は、ユークリッド空間の点を球面に放射状に投影する古典的な幾何学的操作です。

物理学・数学の各種フレームワークで、高次元から低次元への次元削減を「複数の軸で順次中心投影する」と記述することがあります。たとえば「軸 x₁, x₂, ..., x_k で順次中心投影し、n 次元から n−k 次元へ削減する」のような記述です。

しかしこの記述には**重大な曖昧さ**があります。1 回目の操作と 2 回目以降の操作が、本質的に異なる種類の写像であるという事実が、見過ごされやすいのです。

本記事は、この曖昧さを解消する代数的定式化を解説します。完全版の論文は Zenodo にプレプリントとして公開済みです（CC BY 4.0、日英対訳の md/tex/pdf 計 6 ファイル）。

## 第1章：1 回目と 2 回目以降の決定的な差

中心投影による次元削減を厳密に観察すると、以下の**二段階構造**が見えてきます。

### 第一段階：真の中心投影

n 次元ユークリッド空間 ℝⁿ の点 P を、原点を中心とする半径 r₁ の (n−1) 次元球面 Sⁿ⁻¹(r₁) に放射状に写す写像：

　　π(P) = (r₁ / ‖P‖) × P

これは ℝⁿ から Sⁿ⁻¹(r₁) への正真正銘の次元削減写像です。**この操作は 1 回限り**です。

### 第二段階：球面上の軸切断

一度球面上に乗った点に対して、「軸方向の操作」を適用するとき、それはもはや中心投影ではありません。

正しい操作は、球面 Sⁿ⁻¹(r) の点 X の軸 x_i 成分を c に固定する**同時刻面切断** σ_i です：

　　σ_i : Sⁿ⁻¹(r) → Sⁿ⁻²(r')、　 r' = √(r² − c²)

これは球面の内部だけで完結する操作で、ユークリッド背景座標を直接参照しません。

### 二段階の本質的差異

- 中心投影 π：ユークリッド背景 ℝⁿ → 球面 Sⁿ⁻¹(r₁)
- 軸切断 σ_i：球面 Sⁿ⁻¹(r) → 球面 Sⁿ⁻²(r')

両方とも「次元削減」と呼ばれることはありますが、**入力空間の種類が違います**。1 回目はユークリッド点を球面に乗せる写像、2 回目以降は球面上で完結する代数的操作です。

## 第2章：軸切断は完全に可換である

### 主定理：可換性

本論文の第一の主結果は、**異なる軸での切断は順序を問わず同じ結果を与える**ことです。

数学的には、球面 Sⁿ⁻¹(r) 上の異なる二軸 x_i, x_j に対する切断 σ_i, σ_j について：

　　σ_j ∘ σ_i = σ_i ∘ σ_j

が常に成立します。

### なぜ可換か

直観的には：軸 x_i での切断は「x_i 成分を消す」操作ですが、他軸の値には触れません。なので軸 x_j 成分の値は、切断 σ_i の前後で変化しません。

順序 A：x_i → x_j で切断
- 半径：r → √(r² − c_i²) → √(r² − c_i² − c_j²)

順序 B：x_j → x_i で切断
- 半径：r → √(r² − c_j²) → √(r² − c_j² − c_i²) = √(r² − c_i² − c_j²)

両者の最終半径は同じ。残る座標成分も同じ（x_i, x_j 両方が消えた残り）。よって写像として一致します。

### k 軸の合成

k 個の軸で切断する場合も、任意の順列に対して同じ写像になります（隣接互換から系として導かれる）。

これにより、軸の集合 S = {i₁, ..., i_k} に対する**合成切断** σ_S が、順序によらない一意な操作として定義できます。

## 第3章：合成曲率半径のピタゴラス的閉形式

### 主定理：閉形式

軸の集合 S で合成切断を施した後の最終球面半径は、次の閉形式で表されます：

　　r_final² = r₁² − Σ_{i ∈ S} (x_i*)²

ここで x_i* は **1 回目の中心投影直後の球面上での軸 x_i 成分の値**です。

### ピタゴラスとの関係

球面 Sⁿ⁻¹(r₁) 上の点 P = (x₁, ..., xₙ) は、定義から：

　　r₁² = x₁² + x₂² + ... + xₙ²

を満たします。これは n 次元のピタゴラスの定理そのもの。

軸の集合 S で切断すると、S に含まれる軸成分が「差し引かれて」最終半径を構成します：

　　r_final² = Σ_{i ∉ S} x_i² = r₁² − Σ_{i ∈ S} (x_i*)²

つまり、**球面上の点の座標成分は、軸の集合による直交分解として独立に寄与する**のです。

### 残存座標は不変

切断軸ではない軸の座標成分は、合成切断 σ_S を適用しても**変化しません**。これは「軸 x_i の切断が他軸の値に触れない」という事実の系として直ちに導かれます。

### 可逆性

合成切断 σ_S は**可逆**です。切断軸の値の集合 {x_i*}（i ∈ S）と切断後の像点 σ_S(P) があれば、元の球面上の点 P を一意に復元できます。

## 第4章：アーベル半群としての代数構造

軸切断操作の集合 {σ_S | S ⊆ {1, ..., n}} は、合成 ∘ を演算として：

- **可換**：σ_S ∘ σ_T = σ_T ∘ σ_S（S と T が互いに素のとき）
- **結合則**：(σ_S ∘ σ_T) ∘ σ_U = σ_S ∘ (σ_T ∘ σ_U)
- **単位元**：σ_∅ = id（恒等写像）

を満たします。これは部分集合の合併演算（互いに素な場合）に同型な**アーベル半群**の構造です。

逆元は存在しません（次元を増やす逆操作は定義されていない）ので、群ではなく半群です。

## 第5章：数値検証（7 次元 → 5 次元の例）

7 次元ユークリッド点 P = (1, 2, 3, 4, 10, 5, 3) を、r₁ = 10 で中心投影し、軸 x₅ と x₆ で切断してみます。

中心投影後の点は：
　　P' = (10/√164) × P ≈ (0.781, 1.562, 2.343, 3.123, 7.809, 3.904, 2.343)

軸 x₅ 成分：x₅* ≈ 3.904
軸 x₆ 成分：x₆* ≈ 2.343

**順序 A**（x₅ → x₆）の場合：
- x₅ 切断後：√(100 − 15.244) ≈ 9.206
- x₆ 切断後：√(84.756 − 5.488) ≈ √79.268 ≈ 8.903

**順序 B**（x₆ → x₅）の場合：
- x₆ 切断後：√(100 − 5.488) ≈ 9.722
- x₅ 切断後：√(94.512 − 15.244) ≈ √79.268 ≈ 8.903

**閉形式による検算**：
　　r_final² = 100 − 15.244 − 5.488 = 79.268
　　r_final = √79.268 ≈ 8.903

順序 A、順序 B、閉形式すべて一致します。

## 第6章：なぜこの結果が強力なのか

本論文の核心結果は、専門家から見れば**球面のピタゴラス分解と切断の可換性**であり、新しいことを証明しているわけではありません。

しかし、それでも本論文は極めて強力です。理由は次の通りです。

### 暗黙だったものを明示化する力

「複数軸での順次中心投影」という曖昧な記述が、これまでさまざまな文脈で行われてきました。本論文は、この記述を **1 回の中心投影 + k 回の球面切断** という代数演算として明示的に整理しました。数学的内容は同じでも、記述の正書法が確立されると、それを使って構築されるすべての論理が透明になります。

### 可換性が順序の呪いを解く

順次操作の最大の弱点は順序依存性です。「軸 x_i を先に切るか x_j を先に切るか」という議論が、本論文によって完全に消滅します。物理的記述が**軸の集合**だけに依存することが保証され、隠れた path dependence がないことが代数的に確認されます。

### 閉形式 r² = r₁² − Σ(x_i*)² の単一計算則

k 回の操作を 1 つの式で書ける、ということは、任意の n → d 次元削減が**一行で計算可能**になることを意味します。24 → 4、16 → 4、9 → 4、6 → 4 など、すべての具体的削減が同じ式の異なる入力として処理されます。

### アーベル半群構造による代数的レバレッジ

アーベル半群が成立する、ということは、表現論・テンソル積構造・ホモロジー代数・圏論的言語などの**代数的道具**が使えることを意味します。Wilson 格子ゲージ理論など、関連分野の代数構造との整合も自然に取れるようになります。

### 反論不可能な基礎の力

これは球面のピタゴラス分解と切断の可換性だけに依拠しているので、**証明できないほど自明**です。だからこそ、これに依拠する応用論文も基礎部分は崩れません。

## 第7章：歴史的並行

「自明だが強力」な結果は、数学・物理の節目で繰り返し現れてきました。

- ヒルベルト空間の内積：量子力学の全体構造を支える
- 微分形式の交代性 dx ∧ dy = −dy ∧ dx：de Rham コホモロジーへの入口
- マクスウェル方程式の Lagrangian 形式：ゲージ理論の起点
- Yoneda の補題：圏論の全体を貫通

いずれも証明はほぼ自明ですが、定式化が現代的構造を解き放つ、という共通点があります。本論文の軸切断半群もこの系列に位置づけられます。

## 第8章：本論文が扱わないこと

本論文は純粋に幾何学的な代数構造の論文です。次の事項は明示的に範囲外としています。

- 軸 x_i の物理的解釈（時空、観測者、ゲージ、相対論などにおける具体的な意味）
- 軸選択 S の物理的意味
- 特定の次元 (n, d) の物理的必然性
- ユークリッド以外の背景（擬リーマン計量、曲がった多様体）への一般化

これらは別論文で扱われる問題で、本論文の代数的結果はそれらの応用文脈とは独立に成立します。

## おわりに

本論文の結果は、見かけ上は球面ピタゴラスと切断の可換性に過ぎません。しかし、これを「正しい代数的言語」として整理することで：

- 高次元から低次元への削減が、軸の集合という組合せ的な対象に対する閉じた演算として一意に記述できる
- 順序依存性の混乱が完全に解消される
- 任意の応用分野（物理学・統計学・機械学習・制御理論など）で共通の基礎言語として使える

正しい記号体系を確立することは、新しい定理を証明するより重要な瞬間がある、というのが本論文の立場です。
