# Brézin–Itzykson–Parisi–Zuber (1978) 「Planar Diagrams」日本語解説

**原典**：E. Brézin, C. Itzykson, G. Parisi, J.-B. Zuber, "Planar Diagrams", *Communications in Mathematical Physics* **59**, 35–51 (1978)
著者所属：Service de Physique Théorique, CEA Saclay
G. Parisi は 2021 年ノーベル物理学賞受賞者

**本論文の位置づけ**：'t Hooft 1974（C1）の「大 N 平面極限」アイデアを **行列積分の鞍点法**で具体計算する手法に発展させた金字塔的論文。**行列模型＝ファットグラフの生成関数**という現代の定式化の起源。Eynard–Orantin の位相的漸化式（B1, B2）が解こうとする問題群の **歴史的出発点**。

**本書の位置づけ**：原典は著作権で保護されているため、本文書は **逐語訳ではなく、構造に沿った包括的な日本語解説**として作成。各章の中心概念・主要数式を保存しつつ、説明文は独自に再構成。

---

## 要旨

場の理論の **平面近似**を、大きな内部対称性群の極限を通して研究する。これは平面ダイアグラム（種数 0 のファインマン図）の **強力な計数法**を与える。3次・4次頂点について結果を提示。1次元の量子力学を平面近似で扱うと **自由フェルミ気体に等価**であることが示される。

---

## 1. 序論

**動機**：4次元非可換ゲージ理論の **強結合相**で信頼できる計算を可能にする手段。位相的展開と双対弦模型 [1] との関係の可能性。具体的成功例：

- 線形・非線形 σ-模型の大 N 極限では破れた相と破れていない相を区別できる
- 't Hooft の 2次元 QCD の解 [2]

**本論文の貢献**：
- 「ゼロ次元」場の理論（全プロパゲータを 1 に置く）の組合せ論を **非組合せ論的手法**で解く
- ファインマン図を直接数えず、**行列積分の鞍点解析**で実行
- 1次元 φ⁴ 非調和振動子の基底エネルギーを平面近似で全和できることを示す
- これが **自由フェルミ気体** の問題に書き換わるという驚くべき事実

**注意**：平面和は結合定数 g = 0 の近傍で解析的（理論全体ではそうでない）。これは経路積分の大場領域が大幅に切り捨てられたことを意味する。

## 2. 平面ダイアグラムと大 N 極限

### 'tHooft 平面性原理

SU(N) ゲージ場の大 N 極限で生き残るのは **平面図**のみ。平面トポロジーが頂点数固定で **閉じたインデックスループ数を最大化**するため。

Yang–Mills だけでなく、φ³ や φ⁴ の場の理論にも同じ思想が適用できる。場を **N × N 行列** M(x) に置き換え、対称性パラメータ α で 3 つのクラス：

- (i) α = 1：実対称行列 → SO(N)
- (ii) α = 2：エルミート行列 → SU(N)
- (iii) α = 4：複素行列 → SU(N) × SU(N)

### Lagrangian（原典 (1)）

$$\mathcal{L} = \frac{1}{2} \text{tr}(\partial M)^2 + \frac{1}{2} \text{tr}(M M^\dagger) + \frac{g}{N} \text{tr}(M M^\dagger M M^\dagger) \quad (1)$$

注目すべき極限：**N → ∞ かつ g 固定**。これで平面図のみが選ばれる。

### Feynman 則 — **二重線**

M-場のプロパゲータは **2本の線**（dual lines）で表せる。各線は別々のインデックスの伝播に対応：
- α = 4：両線が同じ向き
- α = 2：両線が逆向き（エルミート）
- α = 1：向き不要

これがファットグラフ（リボングラフ）の出発点。

### Euler の式と種数展開

連結真空図で P 個のプロパゲータ、V 個の頂点、I 個の閉インデックスループ：

$$2P = 3 V_3 + 4 V_4 + \cdots$$

ループ＝多面体の面と見て Euler 関係：

$$V - P + I = 2 - 2H$$

H は曲面の穴の数（球面なら 0、トーラスなら 1）。図の寄与は

$$\propto N^{V - P + I} g^V = N^{2 - 2H} \cdot (g\text{ 関連因子})$$

結合定数 gp ∝ N^(1-p/2) と取れば、真空エネルギー/N² は **平面図（H = 0）で有限極限**を持つ。1/N² 補正はトーラス図、以下高種数。

### 3つの行列模型の関係

α = 1, 2, 4 の真空和を E_α^(0)(g) とすると、対応する係数の単純比例関係（原典 (2)）が成立し、結局すべては **α = 2 のエルミート行列模型**から導出できる。

## 3. 4次頂点の組合せ論

### 1) 真空図 — 鞍点解析

ゼロ次元理論（時空を点にする）：

$$\exp\left(-N^2 E^{(0)}(g)\right) = \lim_{N \to \infty} \int dM \exp\left[-\frac{N}{2} \text{tr}\, M^2 + \frac{g}{N} \text{tr}\, M^4\right] N^{-1}$$  (3)

エルミート行列の測度：

$$d^{N^2} M = \prod_i dM_{ii} \prod_{i<j} d(\text{Re } M_{ij}) d(\text{Im } M_{ij}) \quad (4)$$

これを **固有値分解** M = U Λ U† で書き換えると、固有値 λᵢ と Vandermonde 行列式の二乗で：

$$dM = \prod_i d\lambda_i \prod_{i<j} (\lambda_i - \lambda_j)^2 \, dU \quad (5)$$

U 積分を実行（被積分関数は固有値のみに依存）し、$N^2$ で因子化：

$$\exp(-N^2 E^{(0)}(g)) = \lim_{N \to \infty} \int \prod_i d\lambda_i \prod_{i<j}(\lambda_i - \lambda_j)^2 \exp\left[-\frac{N}{2}\sum \lambda_i^2 + \frac{g}{N}\sum \lambda_i^4\right] \quad (6)$$

**鞍点解析**：Vandermonde 因子 ∏(λᵢ − λⱼ)² が固有値を反発させ、零の周りに均等分布させる。指数の中身を 1/N² で展開：

$$E^{(0)}(g) = \lim_{N \to \infty} \frac{1}{N^2}\left[\sum_i \left(\frac{1}{2}\lambda_i^2 + g \lambda_i^4\right) - \sum_{i<j}' \ln|\lambda_i - \lambda_j|\right] \quad (7)$$

停留条件：

$$\frac{\lambda_i}{N} + \frac{2 g \lambda_i^3}{N} = \frac{2}{N}\sum_{j \neq i} \frac{1}{\lambda_i - \lambda_j} \quad (8)$$

### 連続極限と固有値密度 u(λ)

λᵢ = √N λ(i/N) と再スケールし、x = i/N を連続化。固有値密度 u(λ) = dx/dλ で書き直す：

正規化条件（原典 (13)）：

$$\int_{-2a}^{+2a} d\lambda \, u(\lambda) = 1$$

停留条件（原典 (14)）— **奇異積分方程式**：

$$P \int_{-2a}^{+2a} d\mu \frac{u(\mu)}{\lambda - \mu} = \frac{\lambda}{2} + 2 g \lambda^3, \quad |\lambda| \leq 2a$$

ここで P は主値積分。

### 解析的解 — F(λ) 法

複素解析関数 F(λ) を導入：

$$F(\lambda) = \int_{-2a}^{+2a} d\mu \frac{u(\mu)}{\lambda - \mu} \quad (15)$$

性質：
- 区間 (−2a, 2a) で切られた λ 平面で解析的
- |λ| → ∞ で 1/λ
- 区間外の実 λ で実数値
- 区間に近づくと（原典 (16)）

$$F(\lambda \pm i\epsilon) = \frac{\lambda}{2} + 2 g \lambda^3 \mp i\pi u(\lambda)$$

これらを満たす唯一の解（原典 (17a)）：

$$F(\lambda) = \frac{\lambda}{2} + 2 g \lambda^3 - (1 + 4 g a^2 + 2 g \lambda^2) \sqrt{\lambda^2 - 4 a^2} \cdot \frac{1}{2}$$

ここで a は **臨界方程式**（原典 (17b)）：

$$12 g a^4 + a^2 - 1 = 0$$

### 固有値密度（原典 (18)）

$$u(\lambda) = \frac{1}{2\pi}(1 + 8 g a^2 + 4 g \lambda^2) \sqrt{4 a^2 - \lambda^2}$$

g = 0 のとき：$u(\lambda) = \frac{1}{2\pi}\sqrt{4 - \lambda^2}$、これは **Wigner 半円則**（中心極限定理のランダム行列版）。

### 真空エネルギー（原典 (20)）

$$E^{(0)}(g) - E^{(0)}(0) = \int_0^{2a} d\lambda \, u(\lambda)\left[\frac{1}{2}\lambda^2 + g \lambda^4 - 2 \ln \lambda\right] - (g = 0)$$

これを a の式（原典 (21)）と組み合わせると：

$$E^{(0)}(g) - E^{(0)}(0) = -\frac{1}{24}(a^2 - 1)(9 - a^2) + \frac{1}{2}\ln a^2$$

### 摂動展開と臨界点

最初の数項：$E^{(0)}(g) - E^{(0)}(0) = 2g - 18g^2 + O(g^3)$ — Table 1 と一致。

**臨界結合**（原典 (22)）：

$$g_c = -\frac{1}{48}$$

実負 g 側で a² が 1 から √2 に増加し、ここで u(λ) が端点で (λ + 2√2)^{3/2} のように消える（通常の √ ではなく 3/2 乗）。これは **行列模型の臨界現象**で、後に **2D 量子重力**との対応で再発見される（KPZ など）。

**大次数挙動**：

$$E^{(0)}(g) = \sum_k A_k g^k, \quad A_k \sim k^{-7/2} (-48)^k \cdot (\text{係数}) \quad (23)$$

これは大次数摂動論の Lipatov 型評価と一致。

### 2) Green 関数

平面 Green 関数は u(λ) の **モーメント**：

$$G_{2p}(g) = \langle \text{tr}\, M^{2p} \rangle = \int_{-2a}^{2a} d\lambda \, u(\lambda) \lambda^{2p} \quad (24)$$

生成関数 Φ(λ) を導入し、F(λ) との関係から閉じた形で計算できる。これにより **平面 4次プロパゲータが整理可能**。

### 結果（Table 2, 3, 4）

原典は具体的なファットグラフの数を低次まで列挙：
- 真空図：1, 2, 18, 297, 6,210, ... （Catalan 数の一般化）
- 4点 Green 関数の係数：8, 144, 3,168, ...

これらは **planar map counting** の組合せ論的結果と一致し、Tutte の手法（直接組合せ）と独立に再現する。

## 4. 3次相互作用の組合せ論

φ³（M³）相互作用も同様の手法で扱える（α = 2 のみ可、不安定だが摂動級数は意味を持つ）。

### 鞍点方程式（原典 (42)–(45)）

奇関数 φ³ で対称性 λ ↔ −λ が破れ、固有値支持区間は **対称でない** [2a, 2b]。

解析関数 F(λ) 法は同じく適用：

$$F(\lambda) = \int_{2a}^{2b} d\mu \frac{v(\mu)}{\lambda - \mu} = \lambda + \frac{3}{2}g \lambda^2 - \left[\frac{1}{2} + g \lambda + \frac{3 g (a + b)}{2}\right] \sqrt{(\lambda - 2a)(\lambda - 2b)} \quad (44)$$

支持区間の端点 a, b は無限遠での asymptotic 条件から決定（原典 (46)）。

### 単一パラメータ σ

$$\sigma = 3 g (a + b) \quad (48)$$

これは原典 (49) で

$$18 g^2 + \sigma (1 + \sigma)(1 + 2 \sigma) = 0$$

— 3次方程式で σ が決まる。g が小さい場合の摂動展開も得られる。

### 重要性

- 4次模型は **正方形分割（quadrangulation）**を生成
- 3次模型は **三角形分割（triangulation）**を生成
- 双方とも **行列積分→鞍点→代数関数 F(λ)** という同じ枠組み

両者を組み合わせると一般の k 角形分割が扱える。これが後の Kontsevich モデル（C3）や Eynard–Orantin の出発点。

## 5. 1次元平面理論 — 非調和振動子と自由フェルミ気体

最も衝撃的な節。1次元時空（量子力学）で行列模型を扱うと、**φ⁴ 非調和振動子の基底エネルギー** が **自由フェルミ気体**の問題に書き換わる。

### Hamiltonian（原典 (71)–(72)）

$$H = \frac{1}{2}\text{tr}\, \Pi^2 + \frac{1}{2}\text{tr}\, M^2 + \frac{g}{N}\text{tr}\, M^4 \quad (\Pi = \partial/\partial M)$$

大 N 極限：$H \psi = N^2 E^{(1)}(g) \psi$

### U(N) 対称性で固有値表示

ψ は固有値 λᵢ の対称関数。**反対称関数**

$$\phi(\lambda_1, \ldots, \lambda_N) = \prod_{i < j}(\lambda_i - \lambda_j) \, \psi(\lambda_1, \ldots, \lambda_N) \quad (75\text{b})$$

を導入すると、これは Vandermonde で乗算した波動関数。

### Schrödinger 方程式（原典 (76)）

驚くべきことに φ は **非相互作用フェルミ気体**の方程式に従う：

$$\left[\sum_i \left(-\frac{1}{2}\partial_{\lambda_i}^2 + V_i\right)\right]\phi = N^2 E \phi$$

ここで各 "粒子" は **同じ1粒子ポテンシャル** に従う：

$$h = -\frac{1}{2}\frac{d^2}{d\lambda^2} + \frac{\lambda^2}{2} + \frac{g}{N}\lambda^4$$

### Fermi 準位

1粒子エネルギー e₁ ≤ e₂ ≤ … と並べ、N 番目までを埋めて Fermi 準位 eF を決める。基底エネルギーは

$$N^2 E^{(1)}(g) = \sum_{n=1}^N e_n$$

大 N で連続スペクトラル密度に置き換え、**WKB 近似**で具体計算可能。

### 物理的意義

- **多体相互作用が因子化** — Vandermonde 因子のおかげ
- 平面極限では「行列の自由度 N² が、固有値の自由度 N に縮約され、しかも各固有値は独立」
- これは **量子力学の整合性条件** から来る非自明な結果
- 後の Hermitian 1-matrix integral の理論的基盤

### 解の振る舞い

WKB 近似で各 eₙ を計算し、Fermi 準位条件 N = ∫^{eF} ρ(e) de から eF(g) を決め、和 ∑ eₙ から E^(1)(g) を得る。具体的な摂動展開：

$$E^{(1)}(g) = \frac{1}{2} + \frac{3g}{4} - \cdots$$

これは **非調和振動子の基底エネルギーの平面寄与**を全和した結果。

### 非平面補正

論文末尾で「最初の非平面補正」（1/N² 補正）の計算法も論じる。これは **トーラス上のファインマン図**に対応し、行列模型の高種数展開の最初のステップ。

## 全体総括

### 本論文が確立した枠組み

1. **行列積分 = ファットグラフの生成関数**：これが現代行列模型の出発点
2. **鞍点解析 → 代数関数 F(λ)**：これが後のスペクトラル曲線の原型
3. **固有値密度 u(λ)**：平衡測度、サポートが「カット」を持つ代数関数として現れる
4. **大 N 展開 = 種数展開**：1/N² が種数 g に対応
5. **臨界現象 gc**：行列模型の連続極限が 2D 量子重力に対応する伏線
6. **量子力学への一般化**：自由フェルミ気体との対応 → 後の集団場理論・行列量子力学へ

### 現代視点での位置づけ

本論文の **F(λ)、u(λ)、鞍点条件** は、現代の **スペクトラル曲線** の概念の歴史的起源。Eynard–Orantin 漸化式（B1）が一般化する出発点は、まさにこの **代数関数を持つランダム行列の平衡分布**。

- **3次模型 ↔ 三角形分割 ↔ Kontsevich 模型（C3）**：Witten 予想の証明へ
- **4次模型 ↔ 正方形分割 ↔ Tutte 数え上げ**：Eynard 「Counting Surfaces」第2章
- **1次元理論 ↔ 自由フェルミ気体 ↔ 行列量子力学（MQM）**：Polchinski の double scaling limit

## W8（中心射影幾何）との接続点メモ

### 1. 「鞍点 → 代数関数」の方法論的近接性

W8 の自己整合方程式（例：α 恒等式 W7 の $(\pi^2/2)\alpha^2 + 137\alpha - 1 = 0$）は、BIPZ の (17b)「$12 g a^4 + a^2 - 1 = 0$」と **構造的に同じ**：

- どちらも **小さい有限次数の代数方程式**で物理量が決まる
- どちらも **臨界点**（W8 では恒等式が破綻する境界）を持つ
- 「鞍点条件としての代数関係」という共通の解釈

### 2. 固有値密度 u(λ) ↔ 中心射影での測度

BIPZ の u(λ) は「N → ∞ で固有値が連続化される密度」。これは **多くの離散自由度が連続極限を取る**点で、W8 の **離散組合せ構成から連続多胞体構造への移行**と方法論的に近い。

### 3. 二重線（ファットグラフ）↔ Schläfli 双対

't Hooft の二重線は「色つきの2本の線」だが、これは多胞体での **頂点 → 面の双対性**と同じ思想で、辺を「両側に面を持つ」と見る Schläfli 双対構造に翻訳できる可能性。

### 4. 当日の問い（候補）

1. 「BIPZ の固有値方程式 $12 g a^4 + a^2 - 1 = 0$ のように、**閉じた多項式**で物理パラメータが決まる例は、CEO 漸化式でも一般的に現れますか？特に α 恒等式のような **無次元自己整合方程式**との関連は？」

2. 「鞍点条件＝代数関数 F(λ) という思想は、Schläfli 双対のような **次元横断的構造**を持つ多胞体にも一般化されますか？」
