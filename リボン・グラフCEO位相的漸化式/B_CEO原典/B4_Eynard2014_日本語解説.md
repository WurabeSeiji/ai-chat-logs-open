## 概要（Abstract 要旨）

「位相的漸化式（topological recursion）」とは、多くの可積分系の漸近展開や数え上げ問題に現れる **再帰関係式** である。出発点はランダム行列の大サイズ漸近展開だが、そこから普遍的・幾何学的な不変量が見出されてきた。本概観では、その方法の **特殊化**として、Gromov–Witten 不変量や結び目多項式（Jones, HOMFLY, ...）など、多くの古典的不変量がこの枠組みで回復されることを例示する。定義・性質・応用の入門的レビュー。

## 1. 序論

位相的漸化式は **公理的に定義された再帰関係**（[1, 65]）であり、**スペクトラル曲線** S（平面解析曲線＋付加構造）に対して、2つの非負整数 g, n でラベル付けされた **微分形式族** ωg,n を対応させる：

$$\text{Topological Recursion}:\quad \text{spectral curve } S \longrightarrow \text{invariants } \omega_{g,n}(S)$$

- 初期項 ω₀,₁、ω₀,₂ は S 上の正準的な1形式・2形式
- 他の ωg,n は **2g + n − 2** に関する普遍的漸化で定義される
- ωg,n(S) は Sⁿ 上の対称 n-形式
- n=0 の場合は数値 Fg(S) = ωg,0(S) ∈ ℂ（「自由エネルギー」と呼ばれる）

### この不変量の性質

ωg,n は驚くべき性質を持つ：

- **シンプレクティック不変量**：スペクトラル曲線のシンプレクティック変換のもとで不変
- **準モジュラー形式**：曲線が種数 g のとき、モジュラー Sp_{2g}(ℤ) 群のもとで（ほぼ）モジュラー
- **広田型方程式**を満たす
- **形式–閉路双対性**変形関係（Seiberg–Witten 関係の一般化）を満たす
- 多くの特異極限のもとで **安定**

### 何を含むか

特殊化により以下が回復される：
- モジュライ空間の体積（Weil–Petersson 体積、Mirzakhani）
- Hurwitz 数
- 交点数（Witten–Kontsevich 予想の生成関数）
- Gromov–Witten 不変量
- マップの数え上げ（Tutte の枚挙）
- ランダム行列の期待値の漸近
- **結び目多項式**（Jones、HOMFLY、super polynomial …）— 体積予想の拡張、近年予想

これらが **一つの再帰関係式から導かれる**という事実が、現代数理物理における位相的漸化式の中心的位置を支えている。

## 2. 位相的漸化式の例

幾何的に互いに無関係に見える諸問題が、**類似の再帰構造**を共有することを示す。厳密な定義は §4 に譲り、まず具体例から入る。

### 2.1 Mirzakhani 漸化式 — 双曲体積

**設定**：g, n を 2g − 2 + n > 0 を満たす非負整数（(0,0), (0,1), (0,2), (1,0) を除く）。Vg,n(L₁, …, Ln) を、種数 g・境界長さ L₁, …, Ln の境界付きリーマン面のモジュライ空間 Mg,n の **Weil–Petersson 体積**とする：

$$V_{g,n}(L_1, \ldots, L_n) = \int_{\overline{M}_{g,n}, \, \ell(\partial_i)=L_i} \omega_{WP}$$

ここで ωWP は Weil–Petersson 形式。

**幾何的構成**：双曲面 Σ ∈ Mg,n は Poincaré 計量（定負曲率 −1）を持ち、境界がそれぞれ長さ Li の測地線。これを **2g − 2 + n 個のパンツ（pair of pants）**に分割できる。逆に、パンツを測地境界に沿って貼り合わせることで Mg,n 内のリーマン面が得られる。3g − 3 + n 個の長さと 3g − 3 + n 個の貼合せ角が **Fenchel–Nielsen 座標**で、ω = Σ dℓᵢ ∧ dθᵢ が WP 形式。

**Laplace 変換**：

$$W_{g,n}(z_1, \ldots, z_n) = \int_0^\infty \cdots \int_0^\infty V_{g,n}(L_1, \ldots, L_n) \prod_i e^{-z_i L_i} L_i \, dL_i$$

直接計算では低い g, n のみが知られていた：

$$V_{0,3}(L_1, L_2, L_3) = 1, \quad W_{0,3}(z_1, z_2, z_3) = \frac{1}{z_1^2 z_2^2 z_3^2}$$

$$V_{1,1}(L) = \frac{1}{48}(L^2 + 4\pi^2), \quad W_{1,1}(z) = \frac{1}{8 z^4} + \frac{\pi^2}{12 z^2}$$

**Mirzakhani の発見（2004）**：Vg,n を 2g + n に関する漸化で全て計算できる。Laplace 変換版は次の定理：

#### 定理 2.1（Weil–Petersson 体積の位相的漸化式）

任意の 2g − 2 + n > 0 に対して、(2.1) 式：

$$W_{g,n}(z_1, z_2, \ldots, z_n) = \mathop{\rm Res}_{z \to 0} \frac{1}{(z_1^2 - z^2) \sin(2\pi z)} \pi \Big[ W_{g-1,n+1}(z, -z, J) + \sum_{I \uplus I' = J;\, h+h'=g}^{\prime} W_{h, 1+\#I}(z, I) \, W_{h', 1+\#I'}(-z, I') \Big] dz$$

ここで J = (z₂, …, zn)、Σ′ は (I = J, h = g) と (I′ = J, h′ = g) の場合を除外。

$$W_{0,2}(z_1, z_2) = \frac{1}{(z_1 - z_2)^2}$$

**「位相的」漸化と呼ばれる理由**：Euler 標数 χ = 2 − 2g − n について、左辺の |χ| は右辺の各項の |χ| の和より1だけ大きい：

$$|2 - 2(g-1) - (n+1)| = |2 - 2h - (1+m)| + |2 - 2(g-h) - (1+n-1-m)| = |2 - 2g - n| - 1$$

つまり、**Euler 標数の絶対値が大きい不変量を、小さいもの達で再帰的に表現する**ので「位相的」。

**例（g=1, n=1）**：原典 (2.3) で

$$W_{1,1}(z_1) = \mathop{\rm Res}_{z \to 0} \frac{1}{(z_1^2 - z^2)} \frac{\pi}{\sin(2\pi z)} W_{0,2}(z, -z) \, dz = \frac{1}{8 z_1^2} \left( \frac{1}{z_1^2} + \frac{4\pi^2}{6} \right)$$

直接の双曲幾何計算と一致。

### 2.2 Hurwitz 数

**Hurwitz 数とは**：Hg,n(μ) を「種数 g・1点のみ分岐プロファイル μ（長さ n の分割）を持ち、他は単純分岐」のリーマン球面の連結分岐被覆の数。Riemann–Hurwitz 公式より単純分岐点は b = 2g − 2 + n + |μ| 個。

**組合せ的解釈**：|μ| 枚のシート（リーマン球面のコピー）を、分岐点で開かれた切れ目に沿って貼り合わせ、種数 g の連結曲面を作る方法の数。

#### 簡単な例

ℓ(μ) = 1 で g = 0 のとき、H₀,₁(μ₁) は μ₁ 枚のシートを完全分岐点 1つと単純分岐点 μ₁ − 1 個で貼り合わせて種数 0 を作る方法。これは **Cayley の公式**で：

$$H_{0,1}(\mu_1) = \mu_1^{\mu_1 - 2} \quad (2.4)$$

つまり完全グラフ Kμ₁ 上の **全域木の個数**！

長さ 2 の分割：

$$H_{0,2}(\mu_1, \mu_2) = (\mu_1 + \mu_2 - 1)! \frac{\mu_1^{\mu_1 + 1} \mu_2^{\mu_2 + 1}}{\mu_1! \mu_2!} \quad (2.5)$$

**生成関数**（離散 Laplace 変換）：

$$W_{g,n}(x_1, \ldots, x_n) = \sum_{\mu, \ell(\mu)=n} \frac{H_{g,n}(\mu)}{(2g - 2 + n + |\mu|)!} \sum_{\sigma \in S_n} \prod_i e^{\mu_i x_{\sigma(i)}} \quad (2.6)$$

ここから著しい等式：

$$W_{0,1}(x) = \sum_{k=1}^\infty \frac{k^{k-2}}{(k-1)!} e^{kx} = L(e^x) \quad (2.7)$$

L は **Lambert 関数**（eˣ = L · e⁻ᴸ の解）。

**座標変換** zᵢ = L(eˣⁱ) を行い、微分形式 ωg,n を導入：

$$\omega_{0,1}(z) = (1 - z) \, dz, \quad \omega_{0,2}(z_1, z_2) = \frac{dz_1 dz_2}{(z_1 - z_2)^2} \quad (2.10)$$

Goulden–Jackson–Vainshtein の **cut-and-join 方程式** を Laplace 変換すると、Bouchard–Mariño が予想した位相的漸化式が得られる：

#### 定理 2.2（Hurwitz 数の位相的漸化式 = Bouchard–Mariño 予想、初証明 [5]）

$$\omega_{g,n}(z_1, z_2, \ldots, z_n) = \mathop{\rm Res}_{z \to 1} K(z_1, z) \Big[ \omega_{g-1,n+1}(z, s(z), z_2, \ldots, z_n) + \sum_{I \uplus I' = \{z_2, \ldots, z_n\};\, h+h'=g}^{\prime} \omega_{h, 1+\#I}(z, I) \, \omega_{h', 1+\#I'}(s(z), I') \Big] \quad (2.11)$$

ここで再帰核 K は

$$K(z_1, z) = \frac{dz_1 \left( \frac{1}{z_1 - z} - \frac{1}{z_1 - s(z)} \right)}{2 (z - s(z)) (1 - z) \, dz} \quad (2.12)$$

写像 s: z ↦ s(z) は z = 1 近傍の対合（involution）で、s ≠ Id かつ：

$$s(z) e^{-s(z)} = z e^{-z}, \quad s(1) = 1 \quad (2.13)$$

z = 1 近傍の Taylor 展開：

$$s(z) = 1 - (z-1) + \frac{2}{3}(z-1)^2 - \frac{4}{9}(z-1)^3 + \frac{44}{135}(z-1)^4 - \cdots \quad (2.14)$$

具体例：

$$\omega_{0,3}(z_1, z_2, z_3) = \frac{dz_1 dz_2 dz_3}{(1-z_1)^2 (1-z_2)^2 (1-z_3)^2}$$

$$\omega_{1,1}(z) = \frac{1}{24} \left( \frac{1+2z}{(1-z)^4} - \frac{1}{(1-z)^2} \right) dz$$

### 2.3 マップ（離散曲面）の数え上げ

**マップ**：種数 g の連結向き付け可能曲面 Σ に「セル的に」埋め込まれた連結グラフ G（つまり Σ ∖ G が円板の不交合併）。Tutte が 1960 年代に平面三角形分割・平面四角形分割を数え上げた古典的問題。

**定義 2.1**（マップの数え上げ生成関数）：

$$W_{g,n}(x_1, \ldots, x_n; t_3, t_4, \ldots; t) = \frac{t}{x_1} \delta_{g,0} \delta_{n,1} + \sum_{v \geq 1} t^v \sum_{m \in M_{g,n}(v)} \frac{1}{\#\text{Aut}(m)} \frac{\prod_{j \geq 3} t_j^{n_j(m)}}{\prod_{i=1}^n x_i^{1 + l_i(m)}} \quad (2.18)$$

ここで Mg,n(v) は **v 個の頂点・n 個のマーク付き面・任意個の未マーク面（サイズ ≥3）** を持つ種数 g マップの集合（有限集合）。tₖ は k 角形に付けた重み。

**Tutte の漸化式**：マーク辺を再帰的に除去することでマップを数える。Tutte は M0,1（平面・根付き）のみを扱ったが、漸化は任意の (g, n) に拡張可能。

**例（四角形分割、t₄ ≠ 0、他は0）**：

$$W_{0,1}(x) = \frac{1}{2}\left[ x - t_4 x^3 + t_4 \left(x^2 + 2\gamma^2 - \frac{1}{t_4}\right) \sqrt{x^2 - 4\gamma^2} \right], \quad \gamma^2 = \frac{1}{6t_4}\left(1 - \sqrt{1 - 12 t \, t_4}\right) \quad (2.20)$$

**根付き平面四角形分割（m = n + 1 面、マーク含む）の数**：

$$\#\{\text{genus 0, } m \text{ faces}\} = 2 \cdot 3^m \frac{(2m)!}{(m+2)! \, m!} \quad (2.22)$$

**パラメータ表示の有用性**：x = α + γ(z + 1/z), W₀,₁ = y(z) と置換すると、ωg,n が綺麗な微分形式になる：

$$\omega_{g,n}(z_1, \ldots, z_n) = W_{g,n}(x_1, \ldots, x_n) \, dx_1 \cdots dx_n + \delta_{g,0}\delta_{n,2} \frac{dx_1 dx_2}{(x_1 - x_2)^2}$$

#### 定理 2.3（マップ数え上げの位相的漸化式、原典 (2.27)）

$$\omega_{g,n}(z_1, \ldots, z_n) = \mathop{\rm Res}_{z \to \pm 1} K(z_1, z) \Big[ \omega_{g-1,n+1}(z, 1/z, z_2, \ldots, z_n) + \sum^\prime \omega_{h,1+\#I}(z, I) \omega_{h', 1+\#I'}(1/z, I') \Big]$$

再帰核：

$$K(z_1, z) = \frac{dz_1 \left( \frac{1}{z_1 - z} - \frac{1}{z_1 - 1/z} \right)}{2\gamma (y(z) - y(1/z)) (1 - z^{-2}) \, dz} \quad (2.28)$$

**種数 g 別の四角形分割数の具体例**：

種数 1: $\#\{\text{genus 1, } n \text{ faces}\} = \frac{3^n}{6}\left[\frac{(2n)!}{n! n!} - 2^n\right]$ (2.31)

種数 2: $(12)^n \left[ 14 \binom{n+5/2}{n} - 13 \binom{n+2}{n} - \binom{n+3/2}{n} \right] / 2$ (2.32)

これらすべてが **同じ漸化式から系統的に導かれる**。

## 3. どうやって発見されたか

### 3.1 幾何における不変量

幾何学者は**不変量**（幾何対象に付随する数の集まり、しばしば整数や有理数）を求めてきた。生成関数 W(t) ∈ ℚ[[t]] の形にまとめられる。

枚挙幾何の典型例：**Gromov–Witten 不変量** は「Calabi–Yau 多様体への種数 g リーマン面の正則埋め込みを数える」量。

主要な問題系：
- これらの不変量は幾何の変形のもとでどう変化するか？
- 微分方程式（例えば ∂/∂tᵢ）を満たすか？
- 特異点近傍ではどうなるか？
- モジュラー性質を持つか？
- 異なる幾何が同じ不変量を持ち得るか（不変量の判別力）？
- **そして何より、これらをどう計算するか？普遍的手法はあるか？**

### 3.2 ランダム行列 — 意外な答え

確率論の別問題から答えが来た：**大サイズランダム行列のスペクトル統計**。

エルミート行列の固有値密度は、大 N 極限で **平衡測度**（しばしばコンパクト台を持つ代数関数）に収束する。これが「**スペクトラル曲線**」を与える。

**Wigner 半円則**（Gauss ランダム行列）：

$$\rho(x) \, dx = \frac{1}{2\pi}\sqrt{4 - x^2} \mathbf{1}_{[-2,2]} dx, \quad y^2 = x^2 - 4$$

**Marchenko–Pastur 則**（特異値）：これも代数曲線。

#### 3.2.1 大サイズ展開

2004 年頃の発見（[10, 13, 12, 57]）：**平衡測度（スペクトラル曲線 S）だけから、全ての期待値の漸近展開が、全ての位数で復元できる**。

分配関数の大 N 漸近：

$$\ln Z \sim \sum_{g=0}^\infty N^{2-2g} F_g$$

驚異的結果（[12, 11, 1]）：**普遍的汎関数** Fg : S ↦ Fg(S) が存在し、多くの行列模型のクラスで

$$F_g = F_g(S)$$

が成り立つ。Fg は S の Riemann 幾何のみから定義される。例えば F₁(S) は S 上の標準 Laplacian の行列式の対数（細部省略）。

同様に **普遍的汎関数 ωg,n** が、n 固有値の同時分布の g 次大 N 展開（より精密には n 個のレゾルベントの相関の cumulant）を与える：

$$\mathbb{E}\left( \prod_{i=1}^n \text{Tr}(x_i - M)^{-1} \right)_{\text{cumulant}} \underset{N \to \infty}{\sim} \sum_g N^{2-2g-n} \omega_{g,n}$$

ωg,n は 2g + n − 2 に関する再帰で定義される — **これが位相的漸化式**。

  **スペクトラル曲線 S → ωg,n(S) → 確率測度 dμ(M)** という流れで、S からランダム行列の全情報が復元できる。

#### 3.2.2 ランダム行列を幾何に使う

ωg,n は S だけから定義されるので、**S がランダム行列由来でなくても**、任意の代数曲線 S に適用できる（[1] の提案）。位相的漸化式は任意の平面曲線 S に「**疑似ランダム行列法則**」を対応させる：

$$\text{平面曲線 } S \xrightarrow{\text{位相的漸化}} \omega_{g,n}(S) = \text{S の不変量}$$

これらを **「S のシンプレクティック不変量」または「TR 不変量」**と呼ぶ。

**注意**：全ての代数曲線がランダム行列由来とは限らない（確率法則は正値性を要求）が、汎関数関係は解析的なので、正値性のない曲線にも適用可能。例：Weil–Petersson 体積のスペクトラル曲線 y = sin(2π√x)/(4π) はランダム行列の固有値密度になり得ない。

### 3.3 ミラー対称性との関連

- **A-model**（枚挙幾何）：モジュライ空間 M の「体積」（離散数え上げ）。生成級数

$$W(t) = \sum_d \text{Volume}(M(d)) \prod_i t_i^{d_i}$$

パラメータ tᵢ は fugacity, Kähler パラメータ, Boltzmann 重み, coupling 定数など文脈で呼び名が変わる。

- **B-model**（位相的漸化）：疑似ランダム行列の平衡スペクトラル曲線 y = f(x)（Riemann 面上の解析関数）。パラメータ t̂ の変形がスペクトラル曲線の複素構造変形を誘導：

$$\text{Spectral curve } S(\hat{t}) \xrightarrow{\text{TR}} \text{amplitudes } \hat{W}(\hat{t}) = \omega_{g,n}(S)$$

**ミラー対称性**：A-model と B-model が双対で、**ミラー写像** t ↔ t̂ により $\hat{W}(\hat{t}) = W(t)$。

ミラー対称性の難問の一つは：**与えられた A-model に対し、対応するスペクトラル曲線をどう見つけるか**。一般則は無いが、多くの場合、スペクトラル曲線は **A-model で数え上げられる対象の「最も確率の高い形状」**（大サイズ極限の形状）になる。

#### 典型例の対応表

| A-model | B-model（スペクトラル曲線） |
|---------|---------------------------|
| Kontsevich–Witten 交点数 | $y^2 = x$ |
| Weil–Petersson 体積 | $y = \sin(2\pi\sqrt{x})/(4\pi)$ |
| Hurwitz 数 | $y \, e^{-y} = e^x$ |
| ランダム行列の相関関数 | $y = 2i\pi \rho_{\rm eq}(x)$ |
| トーリック Calabi–Yau の Gromov–Witten | ミラー曲線 $H(e^x, e^y) = 0$ |
| 結び目の Jones 多項式 | A-多項式 $A(e^x, e^y) = 0$（指標多様体） |

### 3.4 シンプレクティック不変量の応用

**例 1：トーリック Calabi–Yau 3-fold（BKMP 予想）**

X を局所トーリック CY 3-fold、Wg,n(X) を境界数 n の開 GW 不変量とする。X のミラーは別の CY 3-fold で形式：

$$\{(x, y, u, v) \in \mathbb{C}^4 \mid H(e^x, e^y) = uv\}$$

H は X のモーメント写像から決まる多項式。**ミラー曲線** $\hat{X}: H(e^x, e^y) = 0$。

#### 定理 3.1（トーリック CY 3-fold の位相的漸化式 = BKMP 予想 [15, 14]、最初の証明 [16, 17]）

$$W_{g,n}(X) = \omega_{g,n}(\hat{X})$$

X の GW 不変量はミラー曲線の TR 不変量に等しい。証明のアイデアは、位相的漸化式の再帰構造を **グラフでエンコードできる**こと（後述 def.4.5）、そして GW 不変量の局所化グラフ [70, 71] との対応を組合せ論的に示すこと。

**例 2：結び目の指標多様体（未証明、予想）**

K ⊂ S³ を結び目、K の **A-多項式** A(X, Y) = 0 は補空間 S³ ∖ K 上の平坦 SL(2) 接続のホロノミー固有値の軌跡（指標多様体）。

色付き Jones 多項式 J_N(q) は S³ ∖ K 上の平坦 SL(2) 接続の Wilson loop（スピン N−1 表現）。ℏ = ln q, x = N ln q とおく。

**予想**（[19, 22, 21, 23]）：ℏ → 0, x = O(1) の極限で

$$\ln J_N(q) \sim \sum_{k=-1}^\infty \hbar^k S_k(x), \quad S_k(x) = \sum_{2g-2+n=k} \frac{1}{n!} \int^x \cdots \int^x \omega_{g,n}(S)$$

ここで S は K の指標多様体（A-多項式の方程式）。

**主張**：結び目の Jones 多項式は、その A-多項式の主シンプレクティック不変量を係数とする ℏ 級数である。

これは有名な **体積予想** [41, 42, 43] の拡張であり、Jones 多項式が **可積分系の τ-関数**であることを意味する。

## 4. 位相的漸化式とシンプレクティック不変量の定義

### 4.1 スペクトラル曲線

#### 定義 4.1（スペクトラル曲線、原典 [1] に近い）

スペクトラル曲線 S = (𝒞, x, y, B) は次のデータ：

- **𝒞**：Riemann 面（コンパクトでも連結でもなくてよい）
- **x: 𝒞 → ℂ**：有理形関数。dx の零点を **分岐点**（branchpoints）と呼ぶ。有限個と仮定。
- **y**：各分岐点での有理形関数の芽。分岐点 a が ra 次のとき、原典 (4.1) で

$$y(p) \underset{p \to a}{\sim} \sum_{k=0}^\infty \tilde{t}_{a,k} (x(p) - x(a))^{k/r_a}$$

- **B**：𝒞 × 𝒞 上の対称 (1,1)-形式。対角線上に二重極を持ち、他では解析的。局所座標 z で、原典 (4.2) で

$$B(p, q) \underset{p \to q}{\sim} \frac{dz(p) \otimes dz(q)}{(z(p) - z(q))^2} + (\text{解析的})$$

実は再帰計算には **分岐点近傍の解析関数の芽**だけで十分（残余を取るため）。ただし B が大域的に有理形だったり、Riemann 面に追加構造があると、不変量が更に多くの性質を享受する。

### 4.2 B-model 側の再帰的定義

簡単のため全ての分岐点が単純（ra = 2）と仮定。各分岐点 a の小近傍 Ua で **局所 Galois 対合** σa: Ua → Ua を、x の二葉を入れ替える対合として定義（x ∘ σa = x）。

#### 定義 4.3（位相的漸化、原典 (4.5)–(4.8)）

χ = 2g + n − 2 に関する再帰で：

$$\omega_{0,1}(p) = y(p) \, dx(p)$$

$$\omega_{0,2}(p, q) = B(p, q)$$

そして 2g + n − 2 ≥ 0 のとき：

$$\omega_{g,n+1}(p_1, \ldots, p_{n+1}) = \sum_{a \in \text{branchpoints}} \mathop{\rm Res}_{q \to a} K_a(p_1, q) \Big[ \omega_{g-1,n+2}(q, \sigma_a(q), p_2, \ldots, p_{n+1}) + \sum_{h+h'=g,\, I \uplus I' = \{p_2, \ldots, p_{n+1}\}}^{\prime} \omega_{h, 1+\#I}(q, I) \, \omega_{h', 1+\#I'}(\sigma_a(q), I') \Big] \quad (4.7)$$

**再帰核**：

$$K_a(p_1, q) = \frac{-\frac{1}{2} \int_{\sigma_a(q)}^q \omega_{0,2}(p_1, \cdot)}{\omega_{0,1}(q) - \omega_{0,1}(\sigma_a(q))} \quad (4.8)$$

**重要性質**（自明でないが [1] で再帰により証明）：ωg,n は 𝒞ⁿ 上の **対称** n-形式。定義は p₁ を特別扱いするが、結果は全 pᵢ に関し対称。

**自由エネルギー Fg = ωg,0**（n = 0 の場合、定義 4.4、原典 (4.11)）：g ≥ 2 で

$$F_g = \omega_{g,0} = \frac{1}{2 - 2g} \sum_a \mathop{\rm Res}_{q \to a} \omega_{g,1}(q) \, \Phi(q)$$

ここで dΦ = ω0,1。F₀, F₁ の定義は [1] 参照。

**具体例**：

$$\omega_{0,3}(p_1, p_2, p_3) = \sum_a \mathop{\rm Res}_{q \to a} K_a(p_1, q) \Big[ B(q, p_2) B(\sigma_a(q), p_3) + B(q, p_3) B(\sigma_a(q), p_2) \Big]$$

$$\omega_{1,1}(p_1) = \sum_a \mathop{\rm Res}_{q \to a} K_a(p_1, q) B(q, \sigma_a(q))$$

### 4.3 グラフによる定義

再帰式はグラフ表記で書ける：

- 各 B(p, q) 因子 → 向きなし辺
- 各 Ka(p, q) 因子 → 終点 q に「色」a を持つ向き付け辺
- 各 Resq→a → 色 a の3価平面頂点（入る辺 1、出る辺 2）
- グラフの値 = 各頂点での残余を辺の積（B と K）に取る

#### 定義 4.5（位相的漸化式のグラフ集合）

Gg,n(p, p₁, …, pk) は連結 3価グラフの集合で：

1. 2g + k − 1 個の3価頂点
2. p でラベルされた1価頂点 1個（**根**）
3. p₁, …, pk でラベルされた1価頂点 k個（**葉**）
4. 3g + 2k − 1 個の辺
5. 辺は向き付け/向きなし。向きなし辺 k + g 個、向き付け辺 2g + k − 1 個
6. 根 p から出る辺は向き付け
7. 葉に終わる k 個の辺は向きなし
8. 向き付け辺は **「広がる平面二進骨格木」** を成し、根から葉へ向き付け
9. 向きなし辺：頂点 → 葉 が k 個、内頂点同士を結ぶものが g 個（祖先関係内のみ）
10. 向き付け辺と向きなし辺が頂点から出る場合、向き付け辺が左の子

**グラフの重み**：

$$w(G) = \prod_v \mathop{\rm Res}_{q_v \to a_v} \prod_{e = (p,q) \in \text{向きなし辺}} B(p, q) \prod_{e = (p \mapsto q) \in \text{向き付け辺}} K_{a_p}(p, q) \quad (4.12)$$

残余は葉から根へ（深い頂点を先に積分）。

そして：

$$\omega_{g,n}(p_1, \ldots, p_n) = \sum_{G \in G_{g,n}(p_1, \ldots, p_n)} w(G) \quad (4.13)$$

このグラフ表記は **直観の支持・定理証明・実装** の全てに便利。

### 4.4 A-model 側の定義

スペクトラル曲線データを **モジュライ空間のコホモロジー環の tautological 類**に翻訳して A-model ポテンシャルを定義する別の同値定義。

#### Laplace 変換（定義 4.6–4.7）

$$e^{-f_{(a,j)}(u)} = \frac{u^{3/2} e^{u x(a)}}{2\sqrt{\pi}} \int_{\gamma_{(a,j)}} y \, dx \, e^{-ux}$$

ここで γ(a,j) は **最急降下路**（local x⁻¹(x(a) + ℝ₊) の弧）。large u 展開で「時刻」を定義：

$$f_{(a,j)}(u) \sim \sum_{k=0}^\infty t_{(a,j),k} u^{-k}$$

B も Laplace 変換（原典 (4.16)–(4.19) 参照）。

これにより **スペクトラル曲線は「時刻」の集合**として再定義できる（定義 4.8）。

#### 色付きモジュライ空間（定義 4.9）

単純分岐点の場合：

$$M_{g,n}(\mathbf{a}) = \{(\Sigma, p_1, \ldots, p_n, s)\}$$

Σ は種数 g の節点付き曲面、s: Σ → a は各成分上で定数の写像（分岐点で色付け）。原典 (4.21) で

$$M_{g,n}(\mathbf{a}) = \bigcup_{G = \text{双対グラフ}, N\text{色}} \prod_{v \in V(G)} M_{g_v, n_v}^{(a_v)}$$

複数分岐点の場合（ra > 2）は局所 Galois 群 Ga（多くは ℤ_{ra}）の分類空間 BGa を含めた Chen–Ruan コホモロジーで定義（4.10）。

#### Tautological 類（定義 4.11）

$$\Lambda(S) = \exp\Big( \sum_k t_{s_*, k} \kappa_k + \frac{1}{2} \sum_{k,l} \hat{B}_{s_*, k; s_*, l} \sum_{\delta \in \partial M_{g,n}(\mathbf{a})} l_{\delta*}(\tau_k \tau_l) \Big) \quad (4.24)$$

ここで τk = c₁(T_p*)^k = ψ(p)^k（マーク点 p のコタンジェント束の第1チャーン類の k 乗）、κk は **Mumford 類**。

#### 定理 4.1（A-model 不変量、[28, 29] で証明）

$$\omega_{g,n}(z_1, \ldots, z_n) = \int_{M_{g,n}(\mathbf{a})} \Lambda(S) \prod_{i=1}^n \check{B}_{s(p_i)}(1/\psi(p_i), z_i) \quad (4.25)$$

これは **A-model 側（モジュライ空間上の積分）と B-model 側（残余計算）が一致する**ことを示す、ミラー対称性の具体例。

## 5–6. シンプレクティック不変量の性質／可積分系・量子曲線への接続

（原典 §5 は紙数の都合で簡潔。§6 は積分可能性と量子曲線。）

**主要な性質**：

1. **シンプレクティック不変性**：曲線 S のシンプレクティック変換のもとで ωg,n と Fg が不変
2. **モジュラー性**：g 種数の曲線上で（ほぼ）モジュラー形式
3. **広田型方程式**：Fg(S) が可積分階層の τ-関数を与える
4. **量子曲線**：スペクトラル曲線 y(x) を「量子化」した微分作用素 Ψ̂(x) = exp(ℏ⁻¹∫y dx + …) の議論

**量子曲線**：古典スペクトラル曲線 P(x, y) = 0 に対し、量子化 P̂(x̂, ŷ) Ψ̂ = 0（x̂ = x, ŷ = ℏ ∂/∂x）が成立し、Ψ̂ は ωg,n の積分から構成される。これは結び目論での A-多項式 → AJ 予想（Jones 多項式が A-多項式の量子化を満たす）と直接対応する。

## 7. 結び目論への新応用

§3.4 で述べた **「Jones 多項式は A-多項式のシンプレクティック不変量」**予想の詳細。

K を結び目、A(X, Y) = 0 を A-多項式（指標多様体）。色付き Jones 多項式 J_N(q) の ℏ → 0, N → ∞, q = e^ℏ, x = ℏ N の漸近：

$$\ln J_N(q) \sim \sum_k \hbar^k S_k(x)$$

ここで Sk(x) は A-多項式の TR 不変量 ωg,n の積分で書ける。

**S₀(x)**：体積予想 — 双曲結び目補空間の体積に対応
**S₁(x)**：reidemeister torsion（捩り）に対応
**Sk≥2(x)**：高次の量子補正

これは **位相不変量と量子場の関係を統一的に与える**枠組み。HOMFLY 多項式、super polynomial 等への一般化も活発な研究領域（→ A6, A7 の藤–Gukov–Sułkowski 論文へ）。

## 8. 結論

位相的漸化式は：

1. **ランダム行列の大 N 漸近**から発見された幾何的構造
2. **任意のスペクトラル曲線**に普遍的に適用可能
3. **古典的不変量**（GW, 体積, Hurwitz, 結び目多項式）を統一的に生成
4. **A-model（モジュライ空間）と B-model（スペクトラル曲線）の双方から定義**できる
5. **可積分性・量子化・モジュラー性**を内包

未解決問題・進行中の研究領域：
- A-model から自然なスペクトラル曲線をどう構成するか（ミラー対称性の建設的問い）
- 結び目 Jones 多項式予想の証明
- 非半単純 Frobenius 多様体への一般化（高次分岐点）
- データサイエンス・統計力学・量子情報への新応用
