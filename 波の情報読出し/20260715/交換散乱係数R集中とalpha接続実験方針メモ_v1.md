## 目的

20260713 の交換干渉散乱行列実験で、片側高次倍音条件において `R=0.70` 付近が局在性交換の有効点として現れた。

本実験群では、この `R` が単なる調整値なのか、条件を変えても狭い範囲へ集まる有効係数なのかを調べる。

特に、過去の alpha 系列で現れた結合定数読み

```text
g = sqrt(4 pi alpha)
R_candidate = 1 - g
```

との接続可能性を検査する。

## 実験順序

### Stage 1: 20260713 条件の再現

既存の片側高次倍音・再帰散乱条件を再現する。

確認値:

```text
R=0.70 付近で局在性差 L_gap が小さくなること。
R=0.50 は単純な一回平均化であり、R=0.70 型の遅延局在性交換とは区別すること。
```

### Stage 2: R の精密スイープ

`R=0.68` から `R=0.71` 付近を細かく掃引する。

特に次を含める。

```text
R_137 = 1 - sqrt(4 pi / 137.035999...)
R_128 = 1 - sqrt(4 pi / 128)
```

評価量:

```text
R_star_L      : L_gap が最小となる R
R_star_N      : N_eff gap が最小となる R
R_star_joint  : L_gap と N_eff gap の合成スコアが最小となる R
collision_at_min
```

### Stage 3: N 依存性

片側高次倍音条件を変える。

候補:

```text
(N_A, N_B) = (1, 7), (1, 15), (1, 31), (1, 63)
(N_A, N_B) = (3, 31), (3, 63), (7, 63)
```

対照:

```text
(N_A, N_B) = (1, 1), (7, 7), (31, 31)
```

見ること:

```text
R_star が 0.697 付近へ集まるか。
N を上げると R_star の許容幅が狭くなるか。
R_star が条件依存で大きく動くか。
```

### Stage 4: alpha 読み

得られた `R_star` から、形式的に

```text
g_eff = 1 - R_star
alpha_eff = g_eff^2 / (4 pi)
alpha_eff_inverse = 1 / alpha_eff
```

を読む。

ここでは alpha を導出したとは主張しない。

主張できるのは、次のどちらかである。

```text
R_star が狭い範囲へ集まるなら、
閉鎖位相系の局在性交換に固有の有効結合点がある。

R_star が条件で大きく動くなら、
0.70 は特定条件下の有効反応点であり、
alpha 接続には追加の選択機構が必要である。
```

20260711 は加速度・時間読出しとの整合確認に使う。
