## 1. 目的

本計画の目的は、交換散乱行列に現れる反射率 `R` が、どの実験系で有効係数として鋭く読まれ、どの実験系では鈍感に扱われるかを分類することである。

特に、20260713 の局在性交換実験で観察された `R=0.70` 近傍が、単なる調整値なのか、複数の閉鎖位相系実験で共通して現れる有効反応点なのかを調べる。

本計画では、`R` が一つの普遍値であるとは仮定しない。

見るべきものは次である。

```text
R に敏感な系。
R に鈍感な系。
R=0.70 近傍でのみ特徴が出る系。
R が条件により動く系。
```

この分類により、なぜ `R` がその値の範囲に現れるのかを、実験系の幾何的特徴から検討する。

---

## 2. 実験系

本計画では、三つの実験系を分ける。

| 系統 | 実験系 | 主判定 |
|---|---|---|
| A | 局在性交換 R スイープ | `L`, `N_eff`, 倍音分布移乗 |
| B | 灰色猫準安定界面 R スイープ | `gray_metastable`, `gray_eigen`, selection |
| C | AB加速度様調和読出し R 感度スイープ | 調和読出し、`c=1` 面積、読出し破綻の有無 |

系統Aは、20260713 の片側高次倍音・再帰散乱実験を精密化する。

系統Bは、20260714 の白猫黒猫・灰色猫準安定界面を、`R` 依存性の観点から読む。

系統Cは、20260711 のAB二体加速度様調和読出しに部分反射 `R` を導入し、加速度様読出しが `R` に敏感か鈍感かを確認する。

## 4. 共通R掃引

主掃引範囲は次である。

```text
0.680 <= R <= 0.710
```

第一掃引では、

```text
Delta R = 0.001
```

を用いる。

必要に応じて、有効点の近傍で、

```text
Delta R = 0.0005
Delta R = 0.00025
```

へ細分化する。

対照として次を必ず置く。

```text
R = 0.0
R = 0.5
R = 1.0
```

`R=0.0` は完全透過端点、`R=0.5` は対称混合点、`R=1.0` は完全反射端点である。

さらに、alpha 接続の診断点として次を必ず含める。

```text
R_137 = 1 - sqrt(4 pi / 137.035999084)
R_128 = 1 - sqrt(4 pi / 128)
```

数値は次である。

```text
R_137 ≈ 0.6971778791
R_128 ≈ 0.6866714657
```

これらは判定値ではなく、全系統で同じ位置を読むための共通プローブ点である。

## 5. N条件

系統Aでは、片側高次倍音条件を主条件とする。

```text
(N_A, N_B) = (1, 15)
(N_A, N_B) = (1, 31)
(N_A, N_B) = (1, 63)
```

対照として、同次数条件も置く。

```text
(N_A, N_B) = (1, 1)
(N_A, N_B) = (31, 31)
(N_A, N_B) = (63, 63)
```

系統Bと系統Cでは、各実験系の既存条件を基本とし、必要な場合のみ `N` 条件を追加する。

## 6. 共通評価量

各系統で、次を記録する。

```text
R
T
Delta_F
case_id
condition_id
score
R_star
R_band
R_band_width
classification
distance_to_R_137
distance_to_R_128
```

`R_star` は各系統の主スコアが最良となる `R` である。

`R_band` は、最良スコアから許容範囲内に入る `R` の集合である。

第一判定では、許容範囲を次の二段階で記録する。

```text
within_5_percent
within_10_percent
```

`R_band_width` は、その範囲の幅である。

この幅を `N` 条件と比較し、`N` が高くなるほど許容範囲が狭くなるかを確認する。

また、各系統の `R_star` について、`R_137`, `R_128` からの距離を記録する。

```text
distance_to_R_137 = abs(R_star - R_137)
distance_to_R_128 = abs(R_star - R_128)
```

## 7. 系統別R感度分類

各系統の結果を、次に分類する。

```text
sharp:
  R_star が明確で、R_band_width が狭い。

broad:
  R_star はあるが、R_band_width が広い。

flat:
  掃引範囲内でスコア差が小さい。

multi_peak:
  複数の R に有効点が分かれる。

outside:
  有効点が 0.680 から 0.710 の外にある。
```

本計画では、`flat` や `outside` を失敗としない。

それらは、対象の読出し量が `R` に鈍感である、または `R=0.70` 近傍とは別の幾何条件で決まることを示す。

## 8. alpha接続の診断量

本計画では、alpha を導出したとは主張しない。

ただし、得られた `R_star` に対して、診断量として次を読む。

```text
g_eff = 1 - R_star
alpha_eff = g_eff^2 / (4 pi)
alpha_eff_inverse = 1 / alpha_eff
```

これは、交換散乱係数が既知の結合定数読みと近いかを確認するための形式的な読みである。

## 9. 実行順序

実行順序は次とする。

```text
Stage 0:
  系統Aの既存条件を再現し、20260713 の R=0.70 近傍観察を確認する。

Stage 1:
  系統A 局在性交換 R スイープを実行する。

Stage 2:
  系統B 灰色猫準安定界面 R スイープを実行する。

Stage 3:
  系統C AB加速度様調和読出し R 感度スイープを実行する。

Stage 4:
  三系統の R_star, R_band_width, R感度分類を比較する。
```

この順序にする理由は、系統Aが現在の `R=0.70` 近傍観察の直接母体であり、系統Bがその応用相図、系統Cが読出し頑健性対照だからである。

## 10. 総括論文で分析する点

総括論文では、次を中心に分析する。

```text
1. R_star は三系統で一致するか。
2. R_band_width は N により狭くなるか。
3. R に敏感な読出し量と鈍感な読出し量は何か。
4. R=0.70 近傍が現れる場合、その実験系に共通する幾何構造は何か。
5. R_star が分かれる場合、何がその差を作るか。
```

特に、局在性、倍音分布、状態選択、加速度様調和読出しのうち、どれが `R` に鋭く反応するかを比較する。

これにより、なぜ反射係数がその値の範囲に現れるのかを、単なる数値一致ではなく、閉鎖位相系の幾何的特徴として検討する。
