# 標準理論での α

## 1. 通常（低エネルギー状態）の α の厳密値

原子物理や日常生活のスケール（エネルギーがほぼゼロの極限）における微細構造定数 \(\alpha\) は、物理学史上最も精密に測定されている数値の一つである。

分かりやすいよう、逆数である \(1/\alpha\) の値で示す。

```text
1/alpha = 137.035999177 ± 0.000000021
```

※ 2022年 CODATA 推奨値。

実数としての \(\alpha\) 自体の値は、およそ次である。

```text
alpha ≈ 0.00729735256
```

電磁気学の計算では、よく「約 137 分の 1」として扱われる。

## 2. 高エネルギー状態での α の厳密測定値

素粒子物理学において、\(\alpha\) は固定された「定数」ではなく、衝突エネルギーが高くなるほど真空偏極の影響で値が大きくなる（結合が強くなる）という性質を持つ。

これを「走る結合定数」と呼ぶ。

高エネルギー状態の基準として最も厳密に測定されているのは、CERN の大型加速器などで測定される「Z ボソン質量エネルギー領域（約 91.19 GeV）」における値である。

高エネルギー状態（\(M_Z\) 領域）での逆数 \(1/\alpha(M_Z)\) の厳密測定値は次である。

```text
1/alpha(M_Z) = 127.944 ± 0.014
```

※ Particle Data Group (PDG) 発表値。

## 3. 数値の比較と物理的な意味

```text
低エネルギー:
  1/alpha ≈ 137

高エネルギー（M_Z）:
  1/alpha(M_Z) ≈ 128
  alpha(M_Z) ≈ 0.00781
```

エネルギーが 91 GeV クラスの超高エネルギー状態に達すると、電磁相互作用の強さが約 7% も強くなっていることが、実験によって厳密に実証されている。

## 4. 本シリーズで用いる alpha と R の参照値

本シリーズでは、次の換算を用いる。

```text
alpha = 1 / (1/alpha)
R = 1 - sqrt(4 pi alpha)
```

低エネルギー側:

```text
1/alpha = 137.035999177
alpha   = 0.007297352564331424
R       = 0.69717787923100305
```

高エネルギー側（M_Z 領域）:

```text
1/alpha(M_Z) = 127.944
alpha(M_Z)   = 0.007815919464765834
R(M_Z)       = 0.68660290255614798
```
