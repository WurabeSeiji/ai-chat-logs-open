# 標準理論での alpha

本メモは、20260715 系列で参照する標準理論側の微細構造定数 alpha の値を固定するための作業メモである。

ここでは、本シリーズの換算で直接使う値として、次の二つを採用する。

```text
低エネルギー極限:
  alpha(0)

Z ボソン質量領域:
  alpha(M_Z^2)
```

## 1. 低エネルギー極限の alpha

低エネルギー極限、すなわち通常の微細構造定数としては、CODATA 2022 推奨値を採用する。

```text
1/alpha(0) = 137.035999177 ± 0.000000021
alpha(0)   = 0.007297352564331424
```

有効桁の目安:

```text
相対不確かさ ≈ 1.53e-10
有効桁数     ≈ 10 桁級
```

この値は、低エネルギー原子物理・精密測定で用いられる標準的な参照値である。

出典:

```text
CODATA Recommended Values of the Fundamental Physical Constants: 2022
Peter J. Mohr, David B. Newell, Barry N. Taylor, Eite Tiesinga
https://arxiv.org/abs/2409.03787

NIST Fundamental Physical Constants
https://physics.nist.gov/constants
```

## 2. Z ボソン質量領域の alpha

高エネルギー側の参照値としては、ハドロン真空偏極を含む走る QED 結合として評価された次の値を採用する。

```text
1/alpha(M_Z^2) = 128.946 ± 0.015
alpha(M_Z^2)   = 0.0077551843407318
```

有効桁の目安:

```text
相対不確かさ ≈ 1.16e-4
有効桁数     ≈ 4 から 5 桁級
```

この値は、低エネルギーの alpha そのものではなく、真空偏極によって有効結合が変化した Z ボソン質量領域での値である。

出典:

```text
The muon g-2 and alpha(M_Z^2): a new data-based analysis
Alexander Keshavarzi, Daisuke Nomura, Thomas Teubner
https://arxiv.org/abs/1802.02995

同論文での記載:
Delta alpha_had^(5)(M_Z^2) = (276.11 ± 1.11) x 10^-4
alpha^-1(M_Z^2) = 128.946 ± 0.015
```

参考値:

```text
(g-2)_mu and alpha(M_Z^2) re-evaluated using new precise data
K. Hagiwara, R. Liao, A. D. Martin, D. Nomura, T. Teubner
https://arxiv.org/abs/1105.3149

alpha^-1(M_Z^2) = 128.944 ± 0.019
```

## 3. 本シリーズで用いる R への換算

本シリーズでは、alpha から R への換算を次で定義する。

```text
alpha = 1 / (1/alpha)
R = 1 - sqrt(4 pi alpha)
```

この換算では、実装上の散乱行列振幅 `t` そのものではなく、状態交換の成立度を `R` 軸上で読むための代表交換重み

```text
G_R = 1 - R
```

を採用し、これを標準理論側の無次元電磁結合振幅

```text
e = sqrt(4 pi alpha)
```

と比較する。

したがって、

```text
G_R = e
1 - R = sqrt(4 pi alpha)
```

として上の換算を用いる。

なお、実装上の散乱行列では `R=|r|^2`, `1-R=|t|^2` として扱う。したがって、標準散乱振幅 `|t|` を直接 `e` と同一視しているわけではない。

同じ式を用いると、標準理論側の参照値は次になる。

### 3.1 低エネルギー極限

```text
1/alpha(0) = 137.035999177 ± 0.000000021
alpha(0)   = 0.007297352564331424
R_low      = 0.697177879231003
delta_R   ≈ 2.32e-11

相対不確かさ ≈ 1.53e-10
有効桁数     ≈ 10 桁級
```

### 3.2 Z ボソン質量領域

```text
1/alpha(M_Z^2) = 128.946 ± 0.015
alpha(M_Z^2)   = 0.0077551843407318
R_MZ           = 0.687822933884774
delta_R        ≈ 1.82e-5

相対不確かさ ≈ 1.16e-4
有効桁数     ≈ 4 から 5 桁級
```

## 4. 注意

以前の作業メモでは、Z ボソン質量領域の値として次を仮置きしていた。

```text
1/alpha(M_Z) = 127.944 ± 0.014
```

しかし、今回確認した範囲では、本シリーズの換算式にそのまま入れる標準的な `alpha(M_Z^2)` の参照値としては、`128.946 ± 0.015` を採用する方が適切である。

したがって、以後この 20260715 系列では、特別な理由を明記しない限り、次を高エネルギー側の標準理論参照値として用いる。

```text
1/alpha(M_Z^2) = 128.946 ± 0.015
R_MZ = 0.687822933884774
```

## 5. v5 数値実験での有効桁数の目安

20260715 系列の `v5` 実験では、各 `R` についておおむね 250 回前後の反復写像を評価している。

浮動小数点演算そのものは double 精度であるため、丸め誤差だけを見れば 250 回程度の反復で 10 桁以上が直ちに失われるわけではない。

しかし、この実験で支配的なのは丸め誤差そのものではなく、次の要素である。

```text
best_step が整数であること
250 回前後の反復写像を使うこと
early stop 判定を使うこと
候補帯が有限幅を持つこと
スイープ刻みが delta_R = 1e-7 であること
候補帯内で偽ピークまたは近接ピークが生じること
```

したがって、`R` を 15 桁表示することはできるが、v5 実験系として意味を持つ有効桁数は、合理的には次の程度と見積もる。

```text
R の実験有効桁数: おおむね 7 桁程度
```

標準理論値と数値実験値を比較する場合は、標準理論側の有効桁数と実験系側の有効桁数のうち、低い方を比較可能な有効桁数として扱う。

```text
比較可能な有効桁数 = min(標準理論側の有効桁数, v5 実験系の有効桁数)
```

## 6. v5 ピークと標準理論値の比較

### 6.1 低エネルギー側 alpha(0)

低エネルギー側の標準値は 10 桁級である。一方、v5 実験系は 7 桁程度である。

したがって、この比較では v5 実験系の 7 桁を比較可能な有効桁数とする。

```text
R_low standard = 0.697177879231003
v5 peak 1      = 0.697177902556148
差             ≈ 2.33e-8
```

この差は、v5 実験系の有効桁数 7 桁精度内にある。

したがって、ピーク1は次のように評価する。

```text
ピーク1は、低エネルギー側の標準値 alpha(0) と、
v5 実験系の有効桁数 7 桁精度内で一致する。
```

### 6.2 Z ボソン質量領域 alpha(M_Z^2)

Z ボソン質量領域の標準値は 4 から 5 桁級である。一方、v5 実験系は 7 桁程度である。

したがって、この比較では標準理論側の 5 桁程度を比較可能な有効桁数とする。

```text
R_MZ standard = 0.687822933884774
v5 peak 2     = 0.688363902556148
差            ≈ 5.41e-4
```

`1/alpha` に換算すると次である。

```text
1/alpha(M_Z^2) standard = 128.946
1/alpha peak 2          = 129.394062925467
差                       ≈ 0.448062925467
```

相対差は次である。

```text
R での相対差       ≈ 0.08%
1/alpha での相対差 ≈ 0.35%
```

したがって、ピーク2は次のように評価する。

```text
ピーク2は、基準としている alpha(M_Z^2) の有効桁数 5 桁の範囲では一致する。
ただし、v5 実験系の有効桁数 7 桁では一致しない。

数値的には、1/alpha で約 0.35%、R で約 0.08% の近傍にある。
```

このため、ピーク2は `alpha(M_Z^2)` と完全同一の値とは扱わない。
ただし、高結合側の接続候補として保持する。
