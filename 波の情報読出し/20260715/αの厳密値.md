# αの厳密値

## 1. 低エネルギー極限

CODATA 2022 推奨値:

```text
1/alpha = 137.035999177 +/- 0.000000021
alpha   = 0.00729735256...
```

実験で用いる換算:

```text
R = 1 - sqrt(4 pi / (1/alpha))
```

```text
R_low = 0.69717787923100305
R_low uncertainty ~= +/- 0.000000000023203
R_low range ~= [0.69717787920780017, 0.69717787925420605]
```

## 2. 高エネルギー領域

Zボソン質量領域、約 91.19 GeV:

```text
1/alpha(M_Z) = 127.944 +/- 0.014
```

実験で用いる換算:

```text
R = 1 - sqrt(4 pi / (1/alpha(M_Z)))
```

```text
R_MZ = 0.68660290255614798
R_MZ uncertainty ~= +/- 0.000017148
R_MZ range ~= [0.68658575474354422, 0.68662004755443840]
```

## 3. 注意

高エネルギー領域の値は、低エネルギー極限のような単一固定値ではなく、エネルギースケールに依存する走る結合定数として読む。
