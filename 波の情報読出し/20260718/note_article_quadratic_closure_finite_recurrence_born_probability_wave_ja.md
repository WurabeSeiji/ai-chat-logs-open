# 時間方向に振動するcos²波をランダムに観測すると、確率波に見えるのでは？

前回の記事では、微細構造定数の逆数 α⁻¹≈137と128の近くに現れた、二本の鋭い谷について紹介しました。

波束が収縮したように見える実験と、白猫・黒猫・灰色猫の実験。

目的も観測方法も異なる二つの数値実験で、なぜか同じ交換係数の領域が現れました。初期波形や倍音条件を変えても、鋭い応答の位置はほとんど動きませんでした。

詳しく調べた結果、その原因は衝突断面としてのαそのものではなく、散乱作用素が有限回で完全に元へ戻る「有限位数回帰」だと分かりました。

一回の交換散乱をUとすると、根の位置では

Uⁿ = I

となります。

つまり、n回進むと作用素全体が一周して、完全に出発点へ戻ります。

これによって、なぜ異なる初期条件や実験でも同じ位置に谷が現れたのかは説明できました。

しかし、もう一つの謎は残りました。

なぜ、その有限位数根が、物理学で有名な α⁻¹≈137と128の近くに存在するのでしょうか。

この問題は、現在も解けていません。

ところが、その原因を調べる過程で、別の重要な構造に気づきました。

## 二つの整数だけからcos²が現れた

有限回で完全に元へ戻る交換重みを整理すると、すべての根は二つの整数nとmによって表せました。

その形は、

Rₙ,ₘ = cos²(πm/n)

です。

実験へ、自由な位相角を探索条件として入力していたわけではありません。

入力したのは交換係数Rです。そのRを広く掃引した結果、有限回で閉じる点が鋭い谷として現れました。後から解析すると、根の位置が整数比m/nと円周率πだけで表され、その形がcos²になっていたのです。

つまり、位相角を先に与えてcos²を作ったのではありません。

有限回帰するという条件が、結果として位相を

πm/n

という離散値へ選び、その読出し重みがcos²になりました。

## なぜcos²が気になったのか

量子力学では、二状態の観測確率がcos²とsin²の形で表されます。

これはBorn則の最も基本的な形の一つです。

私は以前から、なぜ確率がcos²になるのかを不思議に思っていました。

しかし標準量子力学は、最初から複素数の波動関数、複素共役、絶対値二乗を使います。

複素振幅を共役と掛け合わせ、位相方向を二乗の大きさとして読むなら、二状態の重みがcos²とsin²になるのは、ある意味では幾何学的に決まっています。

そのため、なぜcos²なのかをさらに前へ遡るのは難しく、Born則は公理として置くしかないのではないかと考えていました。

ところが今回の実験では、Born則を再現しようとしていない段階で、自由な位相角を入力していないにもかかわらず、有限回帰根からcos²が現れました。

そこで、このcos²がどこから来たのかを、さらに遡って調べました。

## 出発点はΣxₙ²=0だった

私の論文シリーズでは、最も基本的な閉塞条件として

Σxₙ² = 0

を置いています。

これは、系を構成する成分の二乗登録が、系の内部だけで非自明にゼロへ閉じるという条件です。

すべてのxₙが実数なら、各二乗は0以上です。その和を0にするには、すべての成分を0にするしかありません。

しかし、この閉塞条件では、全成分が0ではない非自明な解を要求します。

すると、実数だけでは閉じることができません。

最小の二成分で書けば、

x² + y² = 0

です。

xが0でなければ、この条件は

y = ±ix

を要求します。

つまり、虚数方向は最初から仮定した便利な道具ではありません。

非自明な二乗和をゼロへ閉じるために必要な方向として現れます。

ここから、四分の一回転としての虚数方向、連続する位相回転、有限回で閉じる位相へ進むと、先ほどの整数比m/nとcos²の系列へつながります。

導出の流れは、

非自明な二乗閉鎖

→ 虚数方向

→ 位相回転

→ 有限回帰

→ cos²とsin²の読出し重み

です。

共役な複素数を最初の出発点として置かなくても、第一公理であるΣxₙ²=0から、Born型のcos²/sin²構造まで到達できました。

## cos²は時間方向に現れていた

さらに重要なのは、このcos²が単なるパラメータ一覧ではないことです。

有限位数根で交換散乱を時間方向へ繰り返すと、A側とB側の読出し重みは、時間ステップに沿ってcos²とsin²の形で変化します。

A側が強くなるとB側が弱くなり、B側が強くなるとA側が弱くなる。そして有限回進むと、再び完全に元へ戻ります。

つまりcos²/sin²は、空間的な角度を外から与えて作った曲線ではありません。

有限回帰する作用素が、時間発展方向に描く波です。

## 時間波と確率波は区別できるのか

ここで、Born則との接点が現れます。

観測者が、有限回帰の内部位相そのものを見ることができず、時間軸上でAかBかだけを繰り返し観測するとします。

そのとき観測されるA/Bの重みは、cos²とsin²の形になります。

これは、標準量子力学でBorn則から得られる二状態の確率波と同じ観測分布です。

一方は、有限回帰する決定論的な時間波です。

もう一方は、本質的な確率波として解釈されます。

しかし、観測者がA/Bの結果だけを見ている限り、この二つを区別することはできません。

区別するには、背後にある有限回帰位相、整数で指定される周期nとm、または再帰そのものを直接観測する必要があります。

それらが観測できないなら、有限回帰する時間波は、そのままcos²/sin²の確率波として現れます。

したがって本研究は、Born型確率波を

有限回帰する時間構造の観測像

として解釈します。

この見方では、cos²/sin²の形を作っているのは確率ではなく、有限回帰する時間発展です。

観測者が内部位相を直接読まず、A/Bという結果だけを読み出すことで、その時間波が確率波として現れます。

つまりBorn則と観測問題は別々の問題ではなく、同じ構造の二つの側面です。時間発展がcos²/sin²の重みを作り、観測がその重みを確率として読みます。

この意味でBorn則は、有限回帰する内部位相を観測断面から読んだときに現れる、観測問題の統計的側面だと解釈できます。

## Born則を導出したのか

標準量子力学のBorn則全体を証明した、と主張するものではありません。

任意次元の量子状態、あらゆる観測演算子、測定後の状態変化、環境との相互作用までを一つの定理として導いたわけではないからです。

しかし、Born則の中心的な特徴である

なぜ二状態の確率重みがcos²とsin²の形になるのか

という問いについては、構造的な説明を得ました。

このモデルでは、cos²/sin²は確率公理として外から与えられたものではありません。

Σxₙ²=0という非自明二乗閉鎖から虚数方向が生じ、その位相が時間方向へ進み、有限回で閉じることによってcos²/sin²の読出し重みが現れます。

そして、その時間波を内部位相の見えない観測者が読むと、Born型の確率波と区別できません。

したがって、今回得られた中心結果は、

Born確率波と観測的に区別できないcos²/sin²時間発展を、非自明二乗閉鎖から構成した

というものです。

## 二つの論文に分けた理由

今回、この結果を二つの論文に分けて公開しました。

第一論文では、交換対称な二チャネル作用素が有限回で完全に閉じる条件を解析し、離散的なcos²/sin²重みを導出しました。

この定理は、標準的な作用素論の範囲だけで独立に成立します。

第二論文では、そのさらに前段へ戻り、なぜ実数だけでは足りず、虚数方向と複素位相が必要になるのかを、第一公理Σxₙ²=0から導出しました。

最初から二つを一つの論文へ混ぜると、有限位数定理そのものと、閉塞条件の根源的意味が混同されます。

そこで、まず有限位数交換からcos²が出ることを独立に示し、その後で、複素位相の起点をΣxₙ²=0まで遡る論文を公開しました。

二論文を順番に読むことで、

Σxₙ²=0

→ 複素位相

→ 有限位数回帰

→ 時間方向のcos²/sin²

→ Born型確率波としての観測

という全体の流れが見えるようになります。

## 何が残っているのか

大きな問題は二つ残っています。

一つは、有限位数根が、なぜ現実の α⁻¹≈137と128の近傍に存在するのかです。

これは現在も分かっていません。単なる数値的一致なのか、それとも共通する幾何学的・代数的・物理的構造があるのかは、今後の課題です。

もう一つは、有限回帰の整数周期や内部位相を、現実の実験で直接識別できるかです。

A/Bの確率分布だけなら標準Born則と区別できません。区別可能な物理理論へ進むには、有限回帰構造に固有の追加観測量を探す必要があります。

ただし、観測的に区別できないから無意味なのではありません。

確率波を最初から確率として置くのではなく、その背後にある時間構造から同じ観測像を構成できたことが、今回の発見です。
