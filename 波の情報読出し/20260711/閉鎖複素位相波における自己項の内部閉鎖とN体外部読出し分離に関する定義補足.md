# 閉鎖複素位相波における自己項の内部閉鎖とN体外部読出し分離に関する定義補足

**副題:** 単一波内部の `Σx_n^2=0` 閉鎖と、N体外部並進・加速度読出しにおける自己項分離の表示規律

**著者:** 木原 範昭  
**位置づけ:** 波の情報読出しシリーズ・定義補足論文

## 要旨

本稿では、「全正符号ゼロ閉鎖の読出し多重性に関する定義補足」で整理した公理1

```math
\sum_n x_n^2 = 0
```

の読出し規律を、N体外部読出しへ拡張する。

中心命題は次である。

> 一つの閉鎖複素位相波 `P_i` は、それ自体が `Σx_n^2=0` の内部閉鎖系である。したがって、`P_i` の自己項は無視されるのではなく、`P_i` 内部の閉鎖読出しに属する。定常閉鎖状態において、`P_i` の外部並進・加速度読出しは、`P_i` 自身ではなく、`P_j (j≠i)` との相対読出しから構成される。

この原理により、ABC 三体系では、

```text
A <- (B+C)
B <- (A+C)
C <- (A+B)
```

と読み、一般の N 体系では、

```text
P_i <- { P_j | j ≠ i }
```

と読む。

これは自己エネルギー、内部圧力、剪断、内部回転を否定するものではない。それらは、単一波 `P_i` の内部閉鎖読出しに含まれる。ただし、定常閉鎖後には、それらを `P_i` 自身の外部並進・加速度読出しの源として再入力しない。

重要な限定として、本稿の原理は定常閉鎖状態に対する表示規律である。相互作用直後、閉鎖再選別前、外部流入・流出中、または準安定遷移中には、自己項と外部項の分離は未確定であり、一時的な自己項漏れが観測され得る。

**キーワード:** 自己項内部閉鎖、N体外部読出し、全正符号ゼロ閉鎖、複素位相波、自己エネルギー、準安定遷移、閉鎖帰還位相遅延、外部並進読出し

---

## 1. 目的

本稿の目的は、N体読出しにおいて次の混同を避けることである。

| 混同 | 本稿での整理 |
|---|---|
| 自己エネルギーを無視している | 無視しない。内部閉鎖読出しに含める |
| 自己項を外部並進源にする | 定常閉鎖後は行わない |
| 自己曲率を捨てる | 捨てない。自己波内部の `Σx_n^2=0` 表示として読む |
| N体問題を単純化しすぎている | 外部読出しだけを `P_i <- {P_j | j≠i}` に分離する |
| 圧力・剪断を排除している | 排除しない。過渡・内部読出しとして扱う |

本稿は、標準相対論のエネルギー運動量テンソルを否定しない。

本稿で行うのは、閉鎖複素位相波モデルにおいて、自己項がどの読出し層に属するかを定義することである。

---

## 2. 既存定義補足からの接続

前稿「全正符号ゼロ閉鎖の読出し多重性に関する定義補足」では、公理1

```math
\sum_n x_n^2=0
```

が、位相二乗表示、補償対表示、合成二乗表示、半径読出し表示、安定残差読出し表示として読めることを整理した。

本稿は、その拡張である。

前稿の最小補償対は、

```math
A,\qquad iA
```

であり、

```math
A^2 + (iA)^2 = 0
```

を満たす。

したがって、一つの複素位相波は、単なる外部点ではない。

それ自体が、内部補償を持つ閉鎖系である。

また、局所読出しで二成分を

```math
a,\qquad b
```

として読む場合、合成二乗表示では、

```math
(a+b)^2
=
a^2+b^2+2ab
```

となる。

この交差項 `2ab` は、自己波内部の読出し交差項として現れる場合がある。

したがって、自己項は「存在しない」のではない。

自己項は、内部閉鎖の表示としてすでに読まれている。

---

## 3. 中心命題: 自己項内部閉鎖原理

本稿の中心命題を、次のように置く。

```text
自己項内部閉鎖原理:
閉鎖複素位相波 P_i が定常閉鎖状態にあるとき、
P_i の自己エネルギー、内部回転、内部交差項、内部半径読出しは、
P_i 内部の Σx_n^2=0 閉鎖表示に属する。
それらは無視されない。
ただし、P_i 自身の外部並進・加速度読出しの源としては再入力しない。
```

この命題は、次を意味する。

```text
自己項 = 内部閉鎖読出し
他者項 = 外部相対読出し
```

ここで「他者」とは、同じ読出し系内にあるが、`P_i` とは別の局所波 `P_j (j≠i)` を指す。

---

## 4. 適用条件

自己項内部閉鎖原理は、常に無条件で適用されるものではない。

適用条件は次である。

| 条件 | 内容 |
|---|---|
| 定常閉鎖 | `Q_closed ≈ 0` が成立している |
| 外部流入・流出なし | `P_i` へ外部からエネルギーが流入・流出していない |
| 内部補償成立 | 内部回転、補償対、安定残差読出しが定常化している |
| 識別保持 | `P_i` の識別位相または読出しラベルが保たれている |
| 外部読出し分離 | `P_i` と `P_j` の相対読出しが定義できる |

これらが満たされるとき、`P_i` の自己項は内部閉鎖に属すると扱える。

---

## 5. 適用してはいけない状態

次の状態では、自己項内部閉鎖原理をそのまま適用しない。

| 状態 | 理由 |
|---|---|
| 相互作用直後 | 自己項と外部項がまだ分離されていない |
| `Q_raw` が大きい | 閉鎖再選別前である |
| 準安定遷移中 | 閉鎖への帰還位相が確定していない |
| 外部流入・流出中 | 内部閉鎖系として孤立していない |
| 識別位相が崩れている | 同じ `P_i` を追跡できない |
| 観測戻入中 | 読出し操作が状態へ再入力されている |

この段階では、自己項が一時的に外部読出しへ漏れる可能性がある。

本稿ではこれを、過渡的自己項漏れと呼ぶ。

```text
transient self-leakage:
閉鎖再選別前または定常化前にだけ現れる自己項の外部読出し漏れ
```

過渡的自己項漏れは、失敗ではない。

むしろ、準安定遷移や閉鎖帰還位相遅延を調べる重要な観測対象である。

## 6. N体外部読出し分離

N個の局所波を、

```text
P_1, P_2, ..., P_N
```

とする。

各 `P_i` は、それ自体が内部閉鎖系である。

外部並進・加速度読出しでは、`P_i` が受ける外部効果を、

```text
P_i <- { P_j | j ≠ i }
```

として読む。

これは、`P_i` の自己項を捨てるという意味ではない。

`P_i` の自己項は、`P_i` 内部の閉鎖読出しへ属する。

外部読出しに現れるのは、`P_i` と `P_j` の相対位相差、相対時間位相勾配、相対安定残差、相対曲率半径読出しである。

---

## 7. ABC三体系での表示

ABC 三体系では、N体外部読出し分離は次のように書ける。

```text
A <- (B+C)
B <- (A+C)
C <- (A+B)
```

これは、A, B, C の自己項を無視する近似ではない。

A の自己項は A 内部の閉鎖へ属する。

B の自己項は B 内部の閉鎖へ属する。

C の自己項は C 内部の閉鎖へ属する。

外部並進・加速度読出しで A に効くのは、B と C との相対読出しである。

同様に、B に効くのは A と C、C に効くのは A と B との相対読出しである。

---

## 8. 圧力・剪断・自己エネルギーへの応答

標準的な反論として、次が考えられる。

> 圧力や剪断もエネルギーである。自己エネルギーを外部源から除くのは誤りではないか。

本稿の応答は次である。

```text
圧力、剪断、自己エネルギーを無視していない。
それらは、閉鎖複素位相波 P_i の内部閉鎖読出しに含まれる。
ただし、定常閉鎖後には、それらを P_i 自身の外部並進・加速度読出しの源として再入力しない。
```

過渡状態では、圧力・剪断・自己エネルギーに相当する読出しが外部へ漏れる可能性がある。

そのため、実験では `Q_raw`, `Q_metastable`, `Q_closed` を分けて記録する必要がある。

---

## 9. 準安定遷移と閉鎖帰還位相遅延

相互作用後、系はただちに安定閉鎖へ戻るとは限らない。

実際には、

```text
相互作用
  -> Q_raw
  -> 準安定状態 Q_metastable
  -> 定常閉鎖 Q_closed
```

という遷移を持つ可能性がある。

この準安定遷移時間は、自己項内部閉鎖の成立にとって重要である。

準安定状態は、電子回路や発振回路における帰還位相遅延に似た役割を持つ。

すなわち、自己項が即時に同相で戻る場合、発散的なフィードバックが起こり得る。

しかし、準安定遷移を経て位相遅延を持って閉鎖へ戻る場合、帰還位相が発散条件から外れ、ゲイン発散が抑制される可能性がある。

このため、次の量を記録する。

| 量 | 意味 |
|---|---|
| `τ_meta` | 準安定滞在時間 |
| `φ_delay` | 閉鎖帰還位相遅延 |
| `G_loop` | 閉鎖再帰ゲイン |
| `Q_decay_rate` | `Q_raw` から `Q_closed` への減衰率 |
| `self_leakage_window` | 自己項漏れが観測される過渡期間 |

この段階では、粒子安定性の導出までは行わない。

ただし、陽子、電子、光子のような長寿命状態や、重い粒子の崩壊可能性を扱う後続論文に向けて、準安定遷移時間を重要な読出し量として保持する。

## 10. 自己エネルギー発散問題への応答

自己項内部閉鎖原理は、自己エネルギー発散への一つの応答を与える。

反論は次の形を取る。

```text
自己エネルギーが自分自身へ戻るなら、フィードバックで発散するのではないか。
```

本稿の応答は次である。

```text
定常閉鎖状態では、自己エネルギーは外部フィードバックではなく内部閉鎖読出しに属する。
外部流入・流出がなく、閉鎖条件が保たれ、準安定遷移を経て帰還位相が安定条件を満たすなら、
自己項だけでは外部並進読出しの発散フィードバックを作らない。
```

これは、自己エネルギーが存在しないという主張ではない。

自己エネルギーは存在する。

ただし、それは内部閉鎖の安定性、`R_read`, `E_read`, 内部回転、半径読出し、安定残差読出しへ属する。

外部並進・加速度読出しに現れるのは、他者との相対位相差から生じる読出し勾配である。

## 11. 検証条件

本稿の定義を数値実験で使う場合、次を確認する。

| 確認事項 | 判定 |
|---|---|
| `P_i` 単独で `Q_closed≈0` が成立する | 単一波内部閉鎖 |
| `P_i` 単独で外部並進ドリフトがない | 自己項が外部源化していない |
| 相互作用直後に自己項漏れが出るか | 過渡現象として記録 |
| 準安定後に自己項漏れが消えるか | 内部閉鎖への再吸収 |
| `P_i <- {P_j | j≠i}` で外部効果が読めるか | N体外部読出し分離 |
| 観測戻入で自己項漏れが増幅されないか | 読出し器擾乱の検査 |

## 12. 後続論文での使い方

本稿の定義により、後続論文では次を自己引用して用いる。

### 12.1 加速度読出し

ABC 加速度読出しでは、

```text
A <- (B+C)
B <- (A+C)
C <- (A+B)
```

を外部読出し分離として使う。

ただし、これは定常閉鎖後の検算に限る。

`Q_raw` または準安定状態では、自己項漏れを別途記録する。

### 12.2 N体読出し

一般の N 体では、

```text
P_i <- {P_j | j ≠ i}
```

を用いる。

これにより、N体外部並進読出しを、各 `P_i` の内部閉鎖と、他者との相対読出しへ分離できる。

### 12.3 粒子安定性

粒子安定性を扱う後続論文では、自己項内部閉鎖と準安定遷移時間を、長寿命状態の候補条件として扱う。

```text
長い τ_meta
安定した φ_delay
低い self_leakage
Q_closed への確実な帰還
```

が、自己崩壊しにくい閉鎖波の条件候補になる。

## 13. 本稿で主張しないこと

本稿は、次を主張しない。

| 主張しないこと | 理由 |
|---|---|
| 標準相対論の自己力問題を完全に解いた | 本稿は閉鎖複素位相波の読出し規律である |
| 圧力や剪断を不要とする | それらは内部読出しまたは過渡読出しとして扱う |
| 自己エネルギーが存在しない | 存在するが内部閉鎖に属すると読む |
| 過渡状態でも自己項分離が常に成立する | 過渡状態では破れ得る |
| 粒子寿命を定量予言する | 準安定遷移時間を後続課題として残す |

---

## 14. 結論

本稿では、閉鎖複素位相波における自己項の扱いを、N体外部読出しへ拡張する定義補足として整理した。

一つの複素位相波は、それ自体が `Σx_n^2=0` の内部閉鎖系である。

したがって、自己エネルギー、内部回転、内部交差項、内部半径読出しは、無視されるのではなく、内部閉鎖読出しとして扱われる。

定常閉鎖後の外部並進・加速度読出しでは、自己項を外部源として再入力しない。

ABC 三体系では、

```text
A <- (B+C)
B <- (A+C)
C <- (A+B)
```

と読み、一般の N 体系では、

```text
P_i <- {P_j | j ≠ i}
```

と読む。

ただし、この分離は定常閉鎖状態に対する表示規律であり、相互作用直後、閉鎖再選別前、準安定遷移中、外部流入・流出中には破れ得る。

その破れは失敗ではなく、準安定遷移時間、閉鎖帰還位相遅延、自己項漏れを読むための重要な観測対象である。
