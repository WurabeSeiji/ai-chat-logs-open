## 1. 目的

本仕様書の目的は、AB 二体閉鎖位相系だけでは判別できなかった

```text
一定型
逆比例型
逆二乗型
```

の距離指数を、ABC 閉鎖位相系に戻して、独立計量波 `C` により読むことである。

前段の AB 二体実験では、`c=1` 内部較正と `chi-tau` 面積スイープにより、

```text
A_chi_tau ∝ L_AB^2
```

に相当する面積量は読めた。

しかし、AB 二体だけでは、`A` と `B` が観測対象であり、同時にゲージでもある。

したがって、相対距離が変化していることは読めても、その距離変化が

```text
L_AB^0
1/L_AB
1/L_AB^2
```

のどれに従うかを、独立に計量するゲージがない。

本仕様書では、この限界を受けて、第三波 `C` を導入する。

ただし `C` は重い基準点ではない。

`C` は、AB の位置変化量と時間位相変化量を読むための、閉鎖系内の独立計量ゲージである。

| 主張しないこと | 理由 |

## 4. AB 二体系の限界

AB 二体閉鎖位相系では、非自明な関係性補償は

```text
f_AB
```

のみである。

この場合、AB の相対距離変化は読める。

しかし、AB 自身が観測対象であり、かつ読出しゲージでもあるため、距離変化の尺度そのものが内部で同時に変化する。

したがって、AB 二体系だけでは、

```text
距離が縮んでいる
```

ことは読めても、

```text
距離の縮み方が L_AB^0 か
1/L_AB か
1/L_AB^2 か
```

を独立に判定しにくい。

これは AB 実験の失敗ではない。

むしろ、

```text
距離指数を読むには、独立な時空ゲージが必要である
```

という否定対照である。

## 5. 関係性補償の定義

ABC 閉鎖位相系では、補償読出しを個体に属させない。

補償は、閉鎖集合または部分集合に属する関係性として扱う。

ABC 三体系で扱う非自明な関係性補償は次である。

```text
f_AB
f_AC
f_BC
f_ABC
```

それぞれの意味は次である。

| 補償 | 属する閉鎖集合 | 役割 |
|---|---|---|
| `f_AB` | `{A,B}` | AB 関係の主対象 |
| `f_AC` | `{A,C}` | A-C 関係、C 由来の観測混入候補 |
| `f_BC` | `{B,C}` | B-C 関係、C 由来の観測混入候補 |
| `f_ABC` | `{A,B,C}` | 三体全体閉鎖の共通モード、中心方向補償候補 |

本仕様書の主対象は `f_AB` である。

ただし、`C` を入れた時点で `f_AC`, `f_BC`, `f_ABC` が生成されるため、これらを無視しない。

## 6. 円周方向読出しと中心方向読出しの分離

### 6.1 `f_ABC` は直接円周方向へ足さない

`f_ABC` は ABC 全体閉鎖の補償である。

これは三体合成中心方向、または共通閉鎖方向に属する。

したがって、AB の円周方向・相対位相方向の加速度読出しへ、最初から直接足し込まない。

`f_ABC` は、まず共通モードまたは背景補償として記録する。

AB 相対読出しに混入する場合は、射影漏れまたは閉鎖汚染として監視する。

### 6.2 円周方向の二体関係性

円周方向に直接投影される候補は、二体関係補償

```text
f_AB
f_AC
f_BC
```

である。

各局所波の円周方向加速度候補は、次の射影和として扱う。

```text
a_A^circ = Pi_A(f_AB) + Pi_A(f_AC)
a_B^circ = Pi_B(f_AB) + Pi_B(f_BC)
a_C^circ = Pi_C(f_AC) + Pi_C(f_BC)
```

ここで `Pi_P` は、局所波 `P` の観測可能な円周方向への射影である。

この式は、普通の外部力の足し算ではない。

関係性補償を、各局所読出し軸へ射影した後に足す、という作業規則である。

### 6.3 対称配置での符号例

AB が互いに近づく方向を、それぞれの局所正方向に取る。

さらに `C` を AB に対して対称位置に置き、`f_AC`, `f_BC` が AB の接近方向と反対向きへ射影される配置を考える。

この場合の作業表示は、

```text
a_A^circ = f_AB - f_AC
a_B^circ = f_AB - f_BC
a_C^circ = f_AC + f_BC
```

である。

ただし、これは絶対符号ではない。

一般には、射影係数 `sigma` を用いて、

```text
a_A^circ = + f_AB + sigma_AC f_AC
a_B^circ = + f_AB + sigma_BC f_BC
a_C^circ = sigma_CA f_AC + sigma_CB f_BC
```

と記録する。

`f_AB`, `f_AC`, `f_BC` 自体は、正の関係性強度として扱う。

符号は射影係数が与える。

## 7. C の役割

本仕様書での `C` は、重い観測者ではない。

`C` は、AB 関係補償 `f_AB` の距離指数を読むための独立計量ゲージである。

`C` が与えるべきものは、次の二つである。

```text
空間位相ゲージ chi_C
時間位相ゲージ tau_C
```

これにより、AB 二体系だけでは読めなかった

```text
L_AB
dL_AB/dtau_C
d^2L_AB/dtau_C^2
```

を読む。

ただし `C` は閉鎖系内の第三波であるため、完全に無影響ではない。

`C` を導入した時点で、

```text
f_AC
f_BC
f_ABC
```

が生じる。

したがって、本仕様書では `C` を次のように扱う。

| 役割 | 内容 |
|---|---|
| 主役ではない | 主対象は `f_AB` |
| 外部観測者ではない | `C` も閉鎖系内の一員 |
| 重い固定点ではない | `f_AC`, `f_BC` を支配的にしない |
| 独立計量ゲージである | `L_AB`, `tau_C` を読む |
| 汚染源でもある | `f_AC`, `f_BC`, `f_ABC` を必ず監視する |

## 8. C の適格性条件

距離指数の判定に入る前に、まず `C` が計量ゲージとして適格かを判定する。

### 8.1 分解能条件

`C` の波長を `lambda_C`、セル幅を `cell_C` とする。

`C` が AB の位置変化量を読むには、

```text
cell_C < observable_delta_L_AB
```

が必要である。

より実験的には、AB の変位範囲が、`C` の複数セルにまたがって読めなければならない。

したがって、`R_C` が小さすぎる場合、

```text
R_C が小さい
振動数が低い
波長が長い
セル間隔が広い
巻数・位置変化量が読めない
```

という理由で不適格になる。

これは単なる信号強度不足ではない。

計量セルが粗すぎることによる、位置変化量の読出し不能である。

### 8.2 擾乱条件

`R_C` が大きすぎる場合、`C` は細かいゲージになる。

しかし同時に、

```text
f_AC
f_BC
f_ABC
```

が大きくなり、AB の運動を支配する可能性がある。

したがって、次を監視する。

```text
|f_AC| / |f_AB|
|f_BC| / |f_AB|
|f_ABC| / |f_AB|
```

これらが大きく、かつ AB 相対読出しへ混入する場合、そのケースは `f_AB` の距離指数判定に使わない。

### 8.3 時間ゲージ条件

`C` の時間位相読出し

```text
tau_C(s)
```

が安定でなければならない。

実験ステップ `s` を時間と同一視しない。

距離指数を読むときの微分は、

```text
d/dtau_C
```

で行う。

### 8.4 対称配置条件

基本配置では、`C` を AB に対して対称な位置に置く。

これは `f_AC` と `f_BC` を消すためではない。

`f_AC` と `f_BC` をできるだけ対称にし、AB 相対読出しにおける C 由来の偏りを評価しやすくするためである。

## 9. 実験ステージ

### 9.1 Stage 0: AB 二体基準の再確認

まず、C を置かずに AB 二体基準を再確認する。

記録する量は次である。

```text
L_AB
V_AB
f_AB
A_chi_tau
Q_raw
Q_closed
```

目的は、AB 二体系では距離指数を独立判定できないことを再確認することである。

### 9.2 Stage I: C ゲージ適格性スイープ

次に、`C` のパラメータを掃引する。

最低限、次を変える。

```text
R_C / R_A
lambda_C
cell_C
epsilon_AC
epsilon_BC
C_position
C_phase
readout_window_C
```

各ケースで、次を判定する。

| 判定 | 内容 |
|---|---|
| `resolution_valid` | `C` が AB の位置変化量を複数セルで読める |
| `clock_valid` | `tau_C` が安定している |
| `disturbance_valid` | C 由来関係性が AB 主読出しを支配していない |
| `symmetry_valid` | `f_AC` と `f_BC` の非対称が制御可能である |
| `closure_valid` | `Q_closed` が許容範囲内に戻る |

このステージでは、逆二乗判定を行わない。

目的は、距離指数を読む資格のある C ゲージ範囲を探すことである。

### 9.3 Stage II: C ゲージによる AB 距離指数読出し

Stage I を通過したケースのみを用いて、AB の距離指数を読む。

読む量は次である。

```text
L_AB^C(s)
v_AB^C(s) = dL_AB^C/dtau_C
a_AB^C(s) = d^2L_AB^C/dtau_C^2
```

ここで `L_AB^C` は、C の空間位相ゲージで読んだ AB 距離である。

判定対象は、`a_AB^C` または距離変化率候補が `L_AB^C` に対してどの指数で変化するかである。

```text
I_AB(L) ∝ L^{-alpha}
```

として、候補指数を読む。

| `alpha` | 読出し |
|---|---|
| `alpha ≈ 0` | 一定型 |
| `alpha ≈ 1` | 逆比例型 |
| `alpha ≈ 2` | 逆二乗型 |
| 不安定 | 現行 C ゲージでは未判定 |

### 9.4 Stage III: 関係性混入の分解

Stage II の候補結果について、次を分解する。

```text
f_AB
f_AC
f_BC
f_ABC
```

特に、AB 相対読出しを

```text
relative_AB = read_A - read_B
```

として読む場合、共通モード `f_ABC` は消える可能性がある。

この消失は、`f_ABC` が存在しないことを意味しない。

AB 相対読出しでは共通モードが見えにくい、という読出し制約である。

同時に、

```text
f_AC - f_BC
```

が C 由来の非対称汚染として残る可能性を監視する。

### 9.5 Stage IV: C 配置対照

最後に、C の位置を変えた対照実験を行う。

最低限、次を比較する。

```text
C が AB 対称位置
C が A 側に偏った位置
C が B 側に偏った位置
C 位相を pi 反転した位置
```

もし距離指数候補が C 配置に強く依存する場合、それは `f_AB` のネイティブ指数ではなく、C 観測混入である可能性が高い。

もし C 配置を変えても、適格性条件を満たす範囲で同じ指数が残るなら、`f_AB` の距離指数候補として扱う。

## 10. 禁止事項

本仕様書では、次を禁止する。

```text
F = G m_A m_B / L_AB^2
a = F / m
1/L_AB を実装で足す
1/L_AB^2 を実装で足す
1/A_chi_tau を主成功判定に使う
tau_C = s と先験的に置く
C を固定された外部観測者として扱う
f_AC, f_BC, f_ABC を無視する
```

特に重要なのは、逆数や逆二乗を観測側で作り込まないことである。

本仕様書で検査するのは、

```text
C ゲージから見た AB 関係補償が、距離に対してどう変化するか
```

である。

## 11. 成功条件

本実験の成功条件は、逆二乗が出ることではない。

成功条件は、次のいずれかを、作り込みなしに分類できることである。

| 結果 | 意味 |
|---|---|
| `alpha ≈ 0` | 現行 ABC C ゲージでは一定型として読める |
| `alpha ≈ 1` | 逆比例型候補 |
| `alpha ≈ 2` | 逆二乗型候補 |
| `alpha` が C 配置で変わる | C 観測混入候補 |
| `resolution_valid` が成立しない | C セルが粗すぎて未判定 |
| `disturbance_valid` が成立しない | C が強すぎて未判定 |
| `clock_valid` が成立しない | 時間ゲージ不成立 |

この分類ができれば、実験は有効である。

## 14. まとめ

本仕様書では、AB 二体閉鎖位相系だけでは読めなかった距離指数を、ABC 閉鎖位相系に戻して、独立計量 `C` により読むための実験規律を定義した。

重要な点は、`C` を重い固定観測者として扱わないことである。

`C` は閉鎖系内の第三波であり、`f_AC`, `f_BC`, `f_ABC` を生成する。

したがって、`C` は同時に計量ゲージであり、汚染源でもある。

本実験では、まず `C` のゲージ適格性を検査し、そのうえで、AB 関係補償 `f_AB` の距離指数を読む。

逆二乗が出ることを成功条件にしない。

一定型、逆比例型、逆二乗型、未判定、C 汚染型を分離できれば、本実験は有効である。
