# 位置位相自由度の拡張における球殻スイープと逆冪読出しに関する定義補足

**副題:** 一角度円周位相から二角度球殻位相、三角度超球殻位相への拡張と、面積・超面体積分配による逆冪スケーリング検査
**日付:** 2026-07-12
**著者:** 木原 範昭
**位置づけ:** 波の情報読出しシリーズ・定義補足論文
**Version DOI:** pending
**Concept DOI:** pending

## 要旨

本稿では、AB 二体閉鎖位相系の位置位相読出しを、一つの円周位相自由度から、二つまたは三つの独立な位置位相自由度へ拡張するための表示規律を定める。

重要なのは、三次元空間や四次元空間を外部背景として先に仮定することではない。

本稿で行うのは、位置位相を読む自由度を

```text
1 個
2 個
3 個
```

へ増やしたとき、閉鎖位相系の読出しが、

```text
S^1 的円周読出し
S^2 的球殻読出し
S^3 的超球殻読出し
```

として表示されるかを整理することである。

一角度の `S^1` 読出しでは、広がりは弧長であり、逆二乗型を要求しない。

二角度の `S^2` 読出しでは、広がりは面積であり、保存読出しが面積に分配されるなら逆二乗型が検査対象になる。

三角度の `S^3` 読出しでは、広がりは超面体積であり、保存読出しが超面体積に分配されるなら逆三乗型が検査対象になる。

ただし、`S^3` 的読出しであっても、有効相互作用が二次元面へ制限される場合には、逆二乗型が残る可能性がある。

本稿の中心命題は次である。

> 逆二乗型は、一角度円周位相から直接要求されるものではない。二つ以上の独立な位置位相自由度が面積、閉路、または輸送不一致を形成する場合に初めて検査対象になる。

**キーワード:** 位置位相自由度、球殻スイープ、逆二乗読出し、逆三乗読出し、面積分配、超面体積分配、次元別中心投影読出し、全正符号ゼロ閉鎖

## 1. 目的

本稿の目的は、AB 二体閉鎖位相系における引力的読出しの距離依存性を、外部空間次元の仮定ではなく、位置位相自由度数の違いとして整理することである。

一角度円周位相だけを持つ AB 二体系では、調和振動的読出しや弧長に対する読出しは自然に定義できる。

しかし、そこから標準的な逆二乗型を直接要求するのは早い。

逆二乗型が現れるためには、保存読出しが何らかの面積へ分配される必要がある。

したがって、本稿では次を分ける。

| 位置位相自由度 | 表示 | 広がり | 逆冪候補 |
|---:|---|---|---|
| 1 | `S^1` 的円周読出し | 弧長 | `rho^{-1}` 型候補 |
| 2 | `S^2` 的球殻読出し | 面積 | `rho^{-2}` 型候補 |
| 3 | `S^3` 的超球殻読出し | 超面体積 | `rho^{-3}` 型候補 |

ただし、三角度読出しであっても、相互作用の有効分配が二次元面に制限されるなら、逆二乗型が現れる可能性も残す。

## 3. 本稿で主張しないこと

本稿は、次を主張しない。

| 主張しないこと | 理由 |
|---|---|
| 外部三次元空間の仮定 | 本稿で増やすのは位置位相自由度である |
| 外部四次元空間の仮定 | 同上 |
| 標準重力の導出 | 本稿は逆冪読出しの表示規律である |
| ニュートン重力定数 `G` の導入 | 標準単位系の力を置かない |
| 逆二乗則の仮定 | 逆二乗型は検査対象である |
| 逆三乗則の仮定 | 三角度読出しでの検査対象である |
| `S^3` なら必ず逆三乗になること | 有効分配が面に制限される場合を残す |

本稿の主張は、位置位相自由度数とスイープ測度の関係を定義し、後続実験で逆冪指数を検査できる形にすることである。

## 4. 位置位相自由度

AB 二体閉鎖対象を

```text
P_AB = A + B
```

とする。

閉鎖条件は同一である。

```math
Q(P_AB)=\sum_n p_n^2=0
```

この同じ閉鎖対象に対し、位置位相読出し自由度数 `d` を導入する。

```text
d = 1
d = 2
d = 3
```

ここで `d` は外部空間次元ではない。

`P_AB` から独立に読まれる位置位相の個数である。

| `d` | 位置位相読出し | 表示名 |
|---:|---|---|
| 1 | `theta_AB` | 円周位相読出し |
| 2 | `(theta_AB, phi_AB)` | 球殻位相読出し |
| 3 | `(theta_AB, phi_AB, psi_AB)` | 超球殻位相読出し |

これらは、標準幾何空間を先に置いた座標ではない。

同一閉鎖条件からの読出し表示である。

## 5. 半径的読出しとスイープ測度

AB 二体閉鎖対象から、半径的読出し

```text
rho_AB
```

を読む。

これは標準空間の距離そのものではない。

AB 二体系の合成閉鎖から読まれる半径的量である。

位置位相自由度数 `d` に対し、対応するスイープ測度を

```text
S_d(rho_AB)
```

と書く。

最小の表示として、比例関係を次のように置く。

| `d` | 表示 | スイープ測度 |
|---:|---|---|
| 1 | 円周 | `S_1(rho_AB) proportional rho_AB` |
| 2 | 球殻面 | `S_2(rho_AB) proportional rho_AB^2` |
| 3 | 超球殻面 | `S_3(rho_AB) proportional rho_AB^3` |

比例係数は、ゲージ規格化、位相枝、読出し窓に依存し得る。

本稿では、比例係数を第一原理値として置かない。

後続実験では、主に冪指数を検査する。

---

## 6. 保存読出し密度

AB 二体系に、ある保存読出し量

```text
I_AB
```

があるとする。

これは標準力学の力やエネルギーではない。

AB 閉鎖対象に安定に残るスカラー的読出しである。

この保存読出しが、位置位相自由度 `d` に対応するスイープ測度へ分配されるなら、密度読出しを

```text
D_d,AB(rho_AB)
=
I_AB / S_d(rho_AB)
```

と書ける。

このとき、比例係数を無視すれば、

```text
D_1,AB proportional rho_AB^{-1}
D_2,AB proportional rho_AB^{-2}
D_3,AB proportional rho_AB^{-3}
```

となる。

ただし、これは仮定ではなく検査対象である。

後続実験では、実際に読まれる密度または加速度的読出しが、どの冪指数に近いかを調べる。

## 7. 面積スイープ型と超面体積スイープ型

三角度読出し `d=3` では、二つの可能性を分ける必要がある。

### 7.1 超面体積スイープ型

保存読出しが `S^3` 的な超球殻面全体へ分配される場合、

```text
D_3,AB proportional rho_AB^{-3}
```

が候補になる。

この場合、三角度位置位相読出しでは、逆三乗型が現れる。

### 7.2 有効面積スイープ型

一方、三角度位置位相読出しであっても、実際の相互作用が二次元面上の有効スイープとして読まれる場合、

```text
D_eff,AB proportional rho_AB^{-2}
```

が候補になる。

この場合、`d=2` でも `d=3` でも逆二乗型が残る。

したがって、後続実験で重要なのは次である。

```text
d=3 で逆三乗へ移るか。
d=3 でも逆二乗に留まるか。
```

この差により、引力的読出しが超面体積へ分配されるのか、有効面積へ分配されるのかを検査できる。

---

## 8. 公理0.5との関係

公理0.5は次を要求する。

```text
単一軸上の読出しでは曲率補正を導入しない。
曲率補正候補は、独立な二方向以上が面積、体積、閉路、
または輸送不一致を形成する場合に限り導入する。
```

本稿の整理では、次のようになる。

| 位置位相自由度 | 曲率補正の扱い |
|---:|---|
| `d=1` | 単一円周位相なので、逆二乗型を要求しない |
| `d=2` | 面積スイープが定義できるため、逆二乗型を検査する |
| `d=3` | 超面体積スイープまたは有効面積スイープを検査する |

したがって、逆二乗型は公理として置かれない。

二つ以上の独立位置位相から面積読出しが構成される場合に、初めて候補として現れる。

## 9. AB 二体系で先に検査する理由

ABC 三体系へ進む前に、AB 二体系で位置位相自由度拡張を検査する。

理由は次である。

| 理由 | 内容 |
|---|---|
| 観測機 C の残渣を避ける | C を置くと観測影響と相互作用が混ざる |
| 三体合成曲率を避ける | `rho_ABC` が入る前に、AB の基本読出しを確認する |
| 逆冪指数を分離する | `d=1,2,3` の差を先に見る |
| 無名性を保つ | A/B のどちらが観測者かを決めない |

AB 二体系で、位置位相自由度数に応じたスケーリングが読めなければ、ABC 三体系での解釈はさらに曖昧になる。

したがって、後続実験の順序は次が望ましい。

```text
AB d=1
AB d=2
AB d=3
ABC 三体拡張
```

## 10. 後続実験への要請

後続実験では、AB 二体系に対して、位置位相自由度数 `d` を変えたスイープを行う。

最低限、次を記録する。

| 量 | 目的 |
|---|---|
| `d` | 位置位相自由度数 |
| `rho_AB` | AB 半径的読出し |
| `Theta_d,AB` | `d` 個の位置位相読出し |
| `S_d(rho_AB)` | スイープ測度 |
| `I_AB` | 保存読出し量 |
| `D_d,AB` | スイープ測度あたりの密度読出し |
| `alpha_fit` | `D_d,AB proportional rho_AB^{-alpha}` の推定指数 |
| `Q_raw`, `Q_closed` | 準定常/定常閉鎖の判定 |
| `protocol` | 反跳表示または透過表示の指定 |
| `readout_mode` | 読出し波なし、極弱、通常、強読出し |
| `decay_rate` | 読出し波による包絡減衰の制御量 |

検査したい判定は次である。

| ケース | 判定 |
|---|---|
| `d=1` で `alpha_fit approx 1` | 弧長分配型 |
| `d=2` で `alpha_fit approx 2` | 面積分配型 |
| `d=3` で `alpha_fit approx 3` | 超面体積分配型 |
| `d=3` でも `alpha_fit approx 2` | 有効面積分配型 |

ここで `alpha_fit` は、標準重力の指数を仮定するものではない。

読出し結果から後で推定する指数である。

また、`alpha_fit` の推定は、読出し波による包絡減衰と混同しない。

そのため、各 `d` について、少なくとも次の条件を分ける。

```text
Protocol F / readout_off
Protocol F / readout_on
Protocol B / readout_off
Protocol B / readout_on
```

ここで `readout_on` は、必要に応じて極弱、通常、強読出しへ分ける。

もし読出し波強度により `alpha_fit` や振幅包絡が大きく変わるなら、逆冪指数の判定とは別に、読出し波依存性として記録する。

## 11. ABC 三体系への接続

本稿では ABC 三体系を扱わない。

ただし、後続の ABC 三体実験へ進む場合、AB 二体系で得た読出し規律を次のように使う。

```text
(A-B) の d=1,2,3 読出し
(A-C) の d=1,2,3 読出し
(B-C) の d=1,2,3 読出し
```

そのうえで、三体全体

```text
(A+B+C)
```

の合成曲率読出しを、制御量として記録する。

三体合成曲率は捨てない。

ただし、AB 二体の単一読出しへ、三体全体の曲率を恣意的に直接混入しない。

混入が必要かどうかは、面積、閉路、輸送不一致の検算で後から判定する。

---

## 12. 結論

本稿では、AB 二体閉鎖位相系において、位置位相自由度を一つから二つ、三つへ拡張したときのスイープ測度と逆冪読出しを定義した。

重要なのは、三次元空間や四次元空間を外部背景として先に仮定しないことである。

増やすのは、位置位相を読む独立自由度である。

一角度読出しでは、広がりは弧長であり、逆二乗型を要求しない。

二角度読出しでは、面積スイープが定義でき、逆二乗型が検査対象になる。

三角度読出しでは、超面体積スイープなら逆三乗型、有効面積スイープなら逆二乗型が検査対象になる。

したがって、後続実験では、`d=1,2,3` の AB 二体系を先に検査し、引力的読出しが弧長、面積、超面体積のどれへ分配されるかを調べる。

ABC 三体系は、その後に拡張する。
