## 0. 目的

本仕様書は、ABC 閉鎖位相系において、ベースライン定常波 `C` を用いる実験群の共通基盤を定義する。

ここで定義する対象は、加速度そのものではない。

本仕様書が定義するのは、次の共通構造である。

| 対象 | 内容 |
|---|---|
| ベースライン定常波 `C` | 局在観測機ではなく、系内の共通参照媒体として扱う |
| 相互干渉経路 | `C->A`, `C->B`, `A->C`, `B->C`, `A->B`, `B->A` を分離記録する |
| 閉鎖再選別 | `Q_raw` から `Q_closed` への回復を測る |
| 準安定遷移 | 相互作用直後から定常閉鎖へ戻る過程を観測対象にする |
| 同時多読出し | 同一状態から複数読出しを分岐させ、観測残渣の混入を避ける |
| 候補効果分類 | 引力的・反力的・遅延的・ビート的効果を最初から分けて測る |

加速度編では、この基盤から得られる `δχ_read(P,s)` の時系列を用いて、速度的読出し、加速度的読出し、`R*a` 収支、幾何検算を行う。

中心閉鎖条件は次である。

```math
\sum_n x_n^2=0
```

これは共役ノルムではない。

また、特定成分を最初から負符号軸にする外部計量条件でもない。

負に見える寄与は、内部位相の二乗、補償対、または読出し表示から現れるものとして扱う。

## 2. 本基礎編で主張しないこと

本基礎編は、次を主張しない。

| 主張しないこと | 理由 |
|---|---|
| 加速度的読出しの成立 | 加速度判定は加速度編で行う |
| 標準重力の導出 | 本仕様は共通実験基盤であり、対応写像は後続課題である |
| 外部力や運動方程式の導入 | 位置変化は相互干渉と閉鎖再選別後の読出しとして扱う |
| 単一観測での成立判定 | 多ゲージかつ複数観測系列で分類する |
| 定常閉鎖前の自己項分離確定 | 準安定遷移中は自己項漏れと外部項混在を記録する |

本基礎編の目的は、後続の加速度実験、遅延残渣実験、準安定遷移実験、自己崩壊モデル実験で再利用できる共通実験面を作ることである。

## 3. 系の構成

### 3.1 局所波 A, B

局所波 `A,B` は、空間位相 `χ`、時間位相 `τ`、内部識別位相 `η`、代表振幅、内部識別モードを持つ。

基礎編では、`A,B` に明示的な並進速度を与えない。

```text
χ_A(0) = χ_A0
χ_B(0) = χ_B0
Δχ_A_external = 0
Δχ_B_external = 0
```

ここで `external` は、実装側で直接足し込む並進更新を意味する。

### 3.2 ベースライン定常波 C

前稿までの `C` は、局在した読出し器として使われた。

本基礎編では、`C` を閉鎖位相系内のベースライン定常波として扱う。

最小候補は次である。

```math
C_0(\chi,\tau)
=
\sum_{k \in K}
w_k
\exp i(k\chi-\Omega_k\tau+\phi_k)
+
w_k
\exp i(-k\chi-\Omega_k\tau-\phi_k)
```

これは左右対称の定常波対であり、初期状態では空間方向の一方的な流れを持たない。

`K` は倍音集合である。

```text
K = {1, 3, 5, ... , k_max}
```

奇数倍音を基本候補とするのは、既存の局在読出し器との連続性を保つためである。

### 3.3 相互干渉経路

本基礎編では、相互作用を一方向に限定しない。

最低限、次の経路を区別して記録する。

```text
C -> A
C -> B
A -> C
B -> C
A -> B
B -> A
```

この区別が重要である。

`C -> A` と `C -> B` だけでは、観測波が局所波を動かしただけなのか、閉鎖位相系内の相互干渉として位置位相が再選別されたのかを区別できない。

## 4. 禁止事項

本実験群では、運動を実装で作り込まないため、次を禁止する。

```text
χ_P(s+1) = χ_P(s) + v_P(s) Δs
v_P(s+1) = v_P(s) + a_P(s) Δs
F = m a
F = G m_A m_B / r^2
```

許される更新は、相互干渉、閉鎖再選別、多ゲージ読出し、読出し値の次ステップへの再埋め込みだけである。

---

## 5. 1ステップ更新の共通仕様

各ステップ `s` で、次を順に実行する。

### 5.1 相互干渉の計算

各ペア `P,Y` について、干渉項を計算する。

```text
I_{P<-Y}(s)
```

ここで、

```text
P,Y ∈ {A,B,C}
P ≠ Y
```

である。

干渉強度は、少なくとも次に依存させる。

| 項目 | 意味 |
|---|---|
| `ε_{P<-Y}` | 結合強度 |
| `R_Y_read` | 影響源側の安定残差読出し |
| `Δχ_{PY}` | 位置位相差読出し |
| `Δτ_{PY}` | 時間位相差読出し |
| `K_C` | `C` の倍音集合 |
| `window_g` | 読出しゲージ窓 |

距離らしい量が必要な場合も、標準距離ではなく位相差読出しから構成する。

### 5.2 仮更新状態と閉鎖残差

相互干渉後の仮状態を作る。

```text
A_raw(s+1)
B_raw(s+1)
C_raw(s+1)
```

この仮状態は、一般に閉鎖条件を完全には満たさない可能性がある。

したがって、仮閉鎖残差を記録する。

```text
Q_raw(s+1) = Σ x_raw,n(s+1)^2
```

### 5.3 閉鎖再選別

仮状態に対して、全正符号ゼロ閉鎖を回復する最小再選別を行う。

```text
(A,B,C)_closed(s+1)
=
Π_Q((A,B,C)_raw(s+1))
```

ここで `Π_Q` は、特定軸を負符号軸として特権化しない閉鎖再選別演算である。

再選別後の残差を記録する。

```text
Q_closed(s+1) = Σ x_closed,n(s+1)^2
```

合格条件は、

```text
|Q_closed| << |Q_raw|
```

かつ、

```text
|Q_closed| < ε_Q
```

である。

### 5.4 読出しと再埋め込み

閉鎖再選別後の状態から、複数ゲージで読出しを行う。

```text
χ_read(P,g,s+1)
τ_read(P,g,s+1)
R_read(P,g,s+1)
η_read(P,g,s+1)
```

ゲージ平均および安定成分として、

```text
χ_read(P,s+1)
τ_read(P,s+1)
R_read(P,s+1)
η_read(P,s+1)
```

を得る。

次ステップの初期状態は、外部運動方程式ではなく、閉鎖再選別後の読出し状態から構成する。

```text
state(s+1) = readout_reembedded((A,B,C)_closed(s+1))
```

## 6. 準安定遷移の記録

相互作用直後は、自己項と他者項が混在している可能性がある。

したがって、閉鎖回復を単なる数値処理として隠さず、次の遷移として記録する。

```text
Q_raw -> Q_metastable -> Q_closed
```

記録すべき量は次である。

| 量 | 意味 |
|---|---|
| `Q_raw` | 相互干渉直後の閉鎖破れ |
| `Q_metastable` | 閉鎖回復途中の残差 |
| `Q_closed` | 再選別後の閉鎖残差 |
| `τ_meta` | 準安定遷移時間 |
| `φ_delay` | フィードバック位相遅れ |
| `G_loop` | 閉鎖回復ループ利得 |
| `self_leakage_window` | 自己項と外部項の分離が未確定な時間窓 |

この準安定遷移は、失敗ではない。

むしろ、相互干渉が閉鎖系へ戻る際の遅延、位相差、ゲイン抑制を読むための重要な観測対象である。

定常閉鎖後に限り、N体外部読出し分離

```text
P_i <- { P_j | j ≠ i }
```

を外部並進・加速度読出しの作業規則として用いる。

## 7. 基礎編の適用チェックリスト

加速度編または後続実験で、本基礎編の外部源分離を使う前に、少なくとも次を確認する。

| チェック | 判定 |
|---|---|
| `Q_closed ≈ 0` | 定常閉鎖に戻っている |
| 外部流入・流出なし | 相互干渉と閉鎖再選別以外の注入がない |
| `R_read` が安定 | 質量的重みを読むための安定残差がある |
| `η` 識別保持 | A, B, C の識別モードが混線していない |
| 多ゲージ分散が小さい | 単一ゲージ依存ではない |
| `P_i <- {P_j | j ≠ i}` が適用可能 | 定常閉鎖後の外部源分離として読める |

このチェックを通過しない状態では、加速度候補が見えても、外部源分離に基づく重力的対応写像としては扱わない。

## 8. 候補効果分類

本実験群では、最初から単一の「成功」を期待しない。

特に、反力的効果と引力的効果を同じ観測で混同しない。

候補は少なくとも次に分ける。

| 記号 | 候補効果 | 予想される読出し |
|---|---|---|
| `R1` | C読出し器反力 | `C` 参照に依存した `δχ` |
| `R2` | C定常波圧による反力 | `C` 圧の向きに応じた離反傾向 |
| `R3` | A-B直接干渉反力 | `A-B` 距離位相の増大 |
| `G1` | `τ`方向 `E_read` 勾配による `χ`方向補償 | `R*aχ ≈ -∂χE_read` |
| `G2` | 閉鎖定常波ポテンシャルの谷への復元 | 山を越えない摂動が谷へ戻る |
| `G3` | サブ巻数ビート/alias による見かけの接近 | detuning 符号で見かけ速度が反転 |
| `G4` | C残渣を介した遅延接近 | persistent C でのみ残る遅延応答 |

この分類は、候補を弱めるためではない。

どの相互作用がどの読出し経路で現れているかを、後から検算可能にするためである。

## 9. 三段階実験設計

本基礎編では、実験全体を次の三段階に分ける。

| 段階 | 目的 | 主な判定 |
|---|---|---|
| Stage I | 候補効果の粗計量 | 引力的・反力的候補の符号、桁、スケーリングを個別に測る |
| Stage II | 同時多読出し | 微小ドリフトまたは複数効果が混在する場合に、同一状態から観測ベクトルを読む |
| Stage III | 別観測法照合 | 観測方法依存ではないかを、独立した読出し経路で検査する |

Stage I では、多少強めの結合を許す。

目的は精密対応ではなく、候補効果の指紋を取ることである。

Stage II では、同じ状態スナップショットから、次の観測ベクトルを同時に読む。

```text
Y(s)
=
[
  d_AB,
  d_AC,
  d_BC,
  δχ,
  δτ,
  E_read,
  ∂χE_read,
  beat_phase,
  unwrap_phase,
  principal_branch_phase,
  Q_raw,
  Q_closed,
  R_read,
  η_identification
]
```

複数の観測を別々の時刻で行うと、前の観測の残渣を次の観測が読んでしまう可能性がある。

したがって、Stage II では、状態を固定したうえで読出しだけを分岐させる。

```text
state(s) を固定
  -> readout set 1
  -> readout set 2
  -> readout set 3
```

この frozen fanout 読出しでは、読出し結果を次ステップへ戻さない。

戻入を含む実験は、別途 persistent/reset 条件として分ける。

Stage III では、同じ候補効果を別観測法で照合する。

最低限、次の三系列を分ける。

| 観測系列 | 内容 | 期待される一致 |
|---|---|---|
| 相対位相系列 | `d_AB = arg(O_B/O_A)` の縮小・拡大 | 引力的なら `|d_AB|` が縮む |
| 時間位相系列 | `δτ_read`, `E_read`, `∂χE_read` | `R*aχ ≈ -∂χE_read` と符号が合う |
| ビート系列 | `φ_P-φ_C` の detuning 読出し | detuning 反転で見かけ符号が反転する |

## 10. 基礎フェーズ

### 10.1 Phase 0: ベースライン無結合

相互干渉をすべて切る。

```text
ε_{P<-Y}=0
```

期待結果は次である。

| 量 | 期待 |
|---|---|
| `δχ_read` | ドリフトなし |
| `Q_closed` | ゼロ |
| 多ゲージ分散 | 数値誤差範囲 |

このフェーズは、数値実装そのものがドリフトを作っていないかを確認する。

### 10.2 Phase 1: 読出し器影響のみ

`C` を読出しに使うが、`A,B` の状態へフィードバックしない。

目的は、観測波の読出し操作そのものが `δχ` を作るかを測ることである。

### 10.3 Phase 2: Cのみ変形

`A,B` が `C` を歪ませるが、`C` から `A,B` へは戻さない。

```text
A -> C
B -> C
C -> A = off
C -> B = off
A <-> B = off
```

目的は、ベースライン定常波 `C` が局所波によりどの程度歪むかを測ることである。

### 10.4 Phase 3: Cを介した片側戻入

`A,B` が `C` を歪ませ、その歪んだ `C` が `A,B` に戻る。

```text
A -> C
B -> C
C -> A
C -> B
A <-> B = off
```

目的は、媒介波 `C` だけで位置位相偏位が生じるかを確認することである。

### 10.5 Phase 4: A-B直接相互作用追加

`A-B`, `B-A` の直接干渉も入れる。

```text
A -> C
B -> C
C -> A
C -> B
A -> B
B -> A
```

目的は、完全な相互干渉系で読出し構造が維持されるかを見ることである。

## 11. 加速度編へ渡す共通出力

加速度編へ渡す最小出力は次である。

| 出力 | 意味 |
|---|---|
| `χ_read(P,s)` | 位置位相読出し |
| `δχ_read(P,s)` | 初期値からのサブセル偏位 |
| `τ_read(P,s)` | 時間位相読出し |
| `E_read(P,s)` | 時間位相勾配読出し |
| `R_read(P,s)` | 安定残差読出し |
| `η_read(P,s)` | 識別位相読出し |
| `Q_raw(s)` | 相互干渉直後の閉鎖残差 |
| `Q_closed(s)` | 再選別後の閉鎖残差 |
| `candidate_effect_label` | `R1-R3`, `G1-G4` の候補分類 |
| `readout_method_id` | 相対位相系列、時間位相系列、ビート系列などの読出し系列 |

加速度編では、これらから `vχ_read`, `aχ_read`, `R*a` 収支、幾何検算を構成する。

## 12. 現時点の注意

本基礎編で最も重要なのは、観測手順が結果を作り込まないことである。

したがって、最初に見るべきものは「引力が出たか」ではない。

最初に見るべきものは次である。

```text
その候補効果は、どの対照条件では消えるか。
```

Phase 0 と Phase 1 で消え、Phase 3 以降で現れ、閉鎖再選別後にも読出しとして残る場合に限り、後続の加速度編で本格判定する。

また、すべての候補効果が同時にうまく成立することを成功とはみなさない。

引力的読出し候補、反力的読出し候補、読出し器擾乱、C残渣、ビート alias は、互いに混在し得る。

この基礎編の役割は、それらを一つの説明へ急いで畳み込むことではなく、観測可能な指紋として分離することである。
