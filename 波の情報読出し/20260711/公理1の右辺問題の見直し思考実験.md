# 公理1の右辺問題の見直し思考実験

**日付:** 2026-07-12  
**位置づけ:** 波の情報読出しシリーズ・思考実験メモ  
**目的:** `a^2+b^2=\rho^2` 型の読出しが、公理1そのものではなく、全正符号ゼロ閉鎖の表示変換にすぎない可能性を整理する。

---

## 1. 出発点

本シリーズの公理1は、

```math
\sum_n x_n^2=0
```

である。

これは共役ノルム

```math
\sum_n |x_n|^2
```

ではない。

また、最初から右辺に正の実在量を置く条件でもない。

しかし、局所読出しではしばしば、

```math
a^2+b^2=\rho^2
```

のように見える。

この表示だけを見ると、右辺の `rho^2` が正の実在量として先に存在しているように見える。

本メモの問いは次である。

> 本当に基本形は `a^2+b^2=\rho^2` なのか。  
> それとも、基本形は `a^2+b^2+c^2=0` であり、`a^2+b^2=\rho^2` は読出し表示にすぎないのか。

---

## 2. 右辺に正量があるように見える理由

基本形を、

```math
a^2+b^2+c^2=0
```

とする。

ここで、ある読出し窓において

```math
c=i\rho
```

と読まれるなら、

```math
c^2=(i\rho)^2=-\rho^2
```

である。

したがって、

```math
a^2+b^2+(i\rho)^2=0
```

は、

```math
a^2+b^2-\rho^2=0
```

として読める。

さらに移項すれば、

```math
a^2+b^2=\rho^2
```

となる。

しかし、この右辺の `rho^2` は第一原理層で独立に置かれた正量ではない。

`c` 成分が内部位相 `i` を含むため、二乗後に負符号として読まれたものである。

したがって、

```math
a^2+b^2=\rho^2
```

は公理1そのものではなく、

```math
a^2+b^2+c^2=0
```

の読出し表示である。

---

## 3. 右辺問題

`a^2+b^2=\rho^2` を基本形として扱うと、次の誤解が起きる。

| 誤解 | 問題 |
|---|---|
| `rho^2` が最初から右辺の正量として存在する | 公理1の全項ゼロ閉鎖が隠れる |
| 左辺が空間成分、右辺が半径または質量成分に見える | 成分名が先験化される |
| 負符号が外部計量として置かれたように見える | 内部位相の二乗による符号発生が見えなくなる |
| 中心投影で半径だけを読む | 双極的な位相向きが消える |

したがって、右辺に現れる正量は、基本実体ではなく、閉鎖和の一項を別表示で読んだ結果として扱う必要がある。

---

## 4. 双極構造の見落とし

中心投影型の表示では、半径や距離だけが強調される。

しかし、全正符号ゼロ閉鎖では、各項は単なる距離成分ではなく、内部位相を持つ閉鎖項である。

そのため重要なのは、

```text
中心からの半径
```

だけではなく、

```text
どの成分がどの内部位相で補償しているか
```

である。

この補償関係は、双極構造として読まれる可能性がある。

中心投影だけを行うと、

```text
双極の向き
符号を持つ成分
符号を失った安定残差
時間方向補償
```

が同じ半径的読出しへ潰れてしまう。

このため、重力的読出し、クーロン的読出し、圧力的読出しの分岐を説明しにくくなる。

---

## 5. R型・Q型・E型源への示唆

公理1を本当に

```math
\sum_n x_n^2=0
```

として読むなら、源の違いは、外部から別々の力を入れることではなく、閉鎖双極のどの情報が読出しに残るかで分かれる可能性がある。

| 型 | 読出しの性質 | 力に見える候補 |
|---|---|---|
| `R` 型 | 双極の向きが内部閉鎖で消え、安定残差だけが残る | 符号を失った質量的源、重力的候補 |
| `Q` 型 | 双極の向きが外部読出しに残る | 正負を持つ電荷的源、クーロン的候補 |
| `E` 型 | 時間位相方向の補償が空間側へ写る | 正圧・負圧、エネルギー的候補 |

この見方では、重力とクーロン力の違いは、力の種類を外部から別に置くことではなく、

```text
双極の符号情報が読出しに残るか
内部閉鎖で符号を失うか
時間方向補償として圧力へ写るか
```

の違いとして扱える可能性がある。

---

## 6. 加速度予備実験との関係

ベースライン定常波 `C` を用いた加速度予備実験では、弱い引力的候補と、より強い反力候補が分離して見えた。

しかし、反力候補が `10^3` オーダで大きい場合、単に弱い引力候補を追うだけでは、重力的読出しの説明には届かない。

この問題は、数値精度だけの問題ではない。

むしろ、

```text
R型源
Q型源
E型源
読出し器反作用
```

が同じ閉鎖和の中でどのように分岐して読まれるか、という定義問題である。

したがって、加速度実験を進める前に、公理1の右辺問題を見直す必要がある。

---

## 7. 最小結論

本思考実験の最小結論は次である。

```math
a^2+b^2=\rho^2
```

を第一原理とみなすべきではない。

第一原理として保持すべき形は、

```math
a^2+b^2+c^2=0
```

である。

そして、

```math
a^2+b^2=\rho^2
```

は、`c=i\rho` と読める場合の読出し表示である。

この順序を逆にすると、右辺の正量、半径、質量、距離、時間、エネルギーが、先験的に存在する名前付き成分に見えてしまう。

本シリーズの方針では、それらは閉鎖位相系からの読出し名であり、第一原理層では無名の閉鎖項である。

---

## 8. 次の課題

次に必要なのは、次の定義補足である。

```text
全正符号ゼロ閉鎖における双極読出しとR/Q/E源分離に関する定義補足
```

そこで扱うべき項目は次である。

1. 閉鎖項の双極的読出し
2. 符号を失う `R` 型残差
3. 符号を保持する `Q` 型読出し
4. 時間方向補償としての `E` 型読出し
5. 重力的候補、クーロン的候補、圧力的候補の分岐
6. 中心投影で失われる情報

この補足ができるまで、加速度実験は一旦保留する。

## 9. 追記: 双極方向写像としての符号問題

上記の整理では、`R` 型を「曲率が大きければ `R` と読む」という比較的シンプルな安定残差読出しとして扱った。

しかし、これはまだ粗い可能性がある。

無名性と矛盾しないように読むなら、最初から「これは `R` 軸である」「これは `Q` 軸である」と名付けてはいけない。

むしろ、問題は次のどちらかかもしれない。

```text
1. 右辺に来たときの符号問題である
2. 右辺は常に負として読まれるが、双極型の読み方で符号が分かれる
```

第一原理層では右辺は存在しない。

存在するのは、

```math
a^2+b^2+c^2=0
```

という閉鎖和である。

しかし、読出し表示では、

```math
a^2+b^2=-c^2
```

のように、一部の項が右辺へ移されたように見える。

このとき、右辺に来た項の符号をどう読むかが、力の向きに見えるものを決めている可能性がある。

## 10. xy平面での双極方向の思考実験

双極型を `x,y` 平面で考える。

このとき、少なくとも次の四つの写像がありうる。

```text
+Y 方向へ広がる双極
-Y 方向へ広がる双極
+X 方向へ広がる双極
-X 方向へ広がる双極
```

ここで、仮に `Y` 方向が右辺的補償軸として読まれるなら、次のような差が出る可能性がある。

| 双極の向き | 読出し符号の候補 | 力に見える向きの候補 |
|---|---|---|
| `+Y` 方向 | 常に正として読まれる | 一方向的な源 |
| `-Y` 方向 | 常に負として読まれる | 反対向きの一方向的な源 |
| `+X` 方向 | 正負の分岐を持ちうる | 符号付き相互作用 |
| `-X` 方向 | 正負の分岐を持ちうる | 符号付き相互作用 |

この読みが正しければ、加速度の方向差は、

```text
力の種類の違い
```

ではなく、

```text
閉鎖双極がどの方向の補償軸として読まれているか
```

の違いで出る可能性がある。

ただし、ここにはまだ大きな問題が残る。

この構造だけでは、重力だけが極めて弱い理由を説明しにくい。

## 11. t軸との関係に関する未解決メモ

さらに、`Q` がない時点でも `t` 軸、または `τ` 方向の読出しが存在する。

したがって、右辺問題は単に空間的な `x,y` 双極だけでは閉じない可能性がある。

次の疑問が残る。

```text
右辺に見える項は、実は t 軸と相殺するように読まれているのか。
R 型の符号消失は、t/τ 方向補償を経由しているのか。
Q 型の正負は、t/τ 方向ではなく x/y 双極方向に残るために出るのか。
E 型の圧力/負圧は、t/τ 方向の補償が空間方向へ写るために出るのか。
```

この時点では、まだ答えは分からない。

ただし、加速度実験で見えていた違和感、すなわち

```text
弱い引力的候補
強い反力候補
重力の弱さ
クーロン型では引力/反力が同オーダに見えること
エネルギーが正圧/負圧の両方へ写ること
```

は、すべてこの「双極方向と t/τ 補償の読み分け」に関係している可能性がある。

## 12. Codex の暫定意見

現時点での Codex 側の暫定意見は次である。

まず、`a^2+b^2=\rho^2` を基本形にすると、おそらく答えが遠のく。

この表示は便利だが、双極方向、内部位相、補償軸、符号保持の情報を落としやすい。

したがって、第一原理層では必ず

```math
\sum_n x_n^2=0
```

を保持し、右辺表示は読出し後の便宜表示として扱うべきである。

次に、`R`, `Q`, `E` の違いは、別々の実体量ではなく、閉鎖双極の情報がどのように残るかの違いとして整理する方がよい。

暫定的には、

```text
R型:
  双極の符号情報が内部閉鎖または t/τ 補償で失われ、
  安定残差として読まれる。

Q型:
  双極の向きが外部読出しに残り、
  片側反転で相互作用符号が反転する。

E型:
  t/τ 方向の補償が空間側へ写り、
  正圧・負圧の両方を取りうる。
```

と読むのが自然に見える。

ただし、これだけでは重力が弱い理由はまだ出ない。

重力の弱さを説明するには、おそらく追加で、

```text
R型は符号情報を失った後の高次残差である
Q型は双極符号が一次的に残る
E型は t/τ 補償が直接圧力へ写る
```

という階層差、または読出し次数の違いが必要になる。

つまり、重力が弱いのは、単に `R` が小さいからではなく、

```text
符号を失い、内部閉鎖を経由し、残差としてしか外部読出しに現れないため
```

かもしれない。

この方向であれば、無名性とも矛盾しにくい。

なぜなら、`R`, `Q`, `E` を先に名付けるのではなく、

```text
閉鎖双極のどの情報が読出しに残ったか
```

によって、後から `R`, `Q`, `E` と読むからである。

## 13. 追記: 全軸複素自由度として読む可能性

### 13.1 ユーザー側の気づき

良い気づきとして、これは「全軸複素数」と読むべきではないか。

`r,θ` と読んでも、`a,b` と読んでも、各軸に二自由度がある。

つまり、単純な実軸成分ではなく、各軸が複素自由度を持っている。

どれを読むか、またはどの演算で読むかによって、多くの組み合わせがありうる。

この読出しの選択問題である可能性が高い。

### 13.2 Codex 応答メモ

これはかなり核心に近い。

`r,θ` と読んでも、`a,b` と読んでも、各軸が実は複素自由度を持つなら、単純な座標軸ではなく、

```text
各軸 = 2自由度を持つ複素読出し候補
```

である。

本当は、

```math
x_n \in \mathbb{C}
```

で、

```math
\sum_n x_n^2=0
```

を見ている。

このとき、同じ閉鎖項からでも、次のような読出し選択がある。

```text
実部を読む
虚部を読む
位相を読む
振幅を読む
二乗後の符号を読む
共役積で読む
非共役二乗で読む
双極の向きを読む
平均で符号を潰して読む
差分で符号を残して読む
```

つまり `R/Q/E` の違いは、実体の違いというより、

> 全軸複素自由度のうち、どの組み合わせを読出しとして固定したか。

の違いかもしれない。

これは無名性と非常に相性がよい。

最初から「これは質量軸」「これは電荷軸」「これは時間軸」と名付けない。

同じ閉鎖複素位相系から、読出し演算の違いで後から分かれる。

暫定的には、次のように読む。

```text
R型:
  振幅二乗・安定残差・ゲージ平均を読む
  -> 符号が消える
  -> 質量的/重力的

Q型:
  双極差分・位相向き・片側反転を読む
  -> 符号が残る
  -> 電荷的/クーロン的

E型:
  τ方向位相勾配・時間補償を読む
  -> 圧力/負圧へ写る
  -> エネルギー的
```

この見方では、中心投影だけでは足りない理由も明確になる。

中心投影は、おそらく、

```text
複素自由度 -> 半径的スカラー
```

へ潰す読出しである。

それは `R` には向いているが、`Q` の符号や `E` の圧力符号を落とす。

したがって、加速度や重力を中心投影型だけで追うと、説明が苦しくなる。

次に必要なのは、

```text
全軸複素自由度における読出し演算の選択表
```

である。

行は読出し演算である。

```text
Re
Im
arg
|x|^2
x^2
x*y
x*conj(y)
difference
sum
gauge average
phase inversion
```

列は残る性質である。

```text
符号を保持するか
双極方向を保持するか
位相枝を保持するか
安定残差になるか
τ補償へ写るか
R/Q/E のどれに見えるか
```

ここを作ると、かなり霧が晴れる可能性がある。

## 14. 追記: 複素投影法という概念への接近

### 14.1 Codex 側の先走った提案

この流れから、Codex は一度「複素投影法」という概念が必要ではないかと提案した。

ここで想定した意味は、標準的な射影幾何の単なる複素版ではなく、

> 全軸複素自由度を持つ閉鎖位相系から、どの読出し演算で何を実在的・符号的・保存的な量として読むかを決める方法。

であった。

対象は、

```text
x_n ∈ C
Σ x_n^2 = 0
```

である。

問題は、同じ閉鎖系から、

```text
R
Q
E
χ
τ
p
```

など複数の読出しが出ることである。

そのため、どの複素成分を、

```text
Re
Im
|x|^2
arg
x^2
x*y
x*conj(y)
差分
平均
```

のどれで読むかを明示する必要がある。

読出し演算ごとに、残る情報が違う。

```text
|x|^2:
  位相符号を潰す
  安定残差を読む
  R型に向く

arg(x):
  位相向きを読む
  χ, τ, p, E に向く

x^2:
  内部位相の二乗符号を読む
  公理1の閉鎖に直結する

x - y:
  双極差分を読む
  Q型の符号に向く

x + y:
  共通モードを読む
  R型やC基準波に向く

x*conj(y):
  標準的相関・干渉強度に向く

x*y:
  非共役二乗型の閉鎖干渉に向く
```

この概念を置くと、以下のように整理できる可能性がある。

```text
R は実体ではなく、複素投影で符号を潰した安定残差
Q は実体ではなく、複素投影で双極符号を保持した読出し
E は実体ではなく、τ方向位相を圧力的に読んだ投影
χ も τ も背景座標ではなく、位相投影の読出し
a^2+b^2=ρ^2 は公理ではなく、特定の複素投影表示
```

この段階で、Codex は次の文書名を仮提案した。

```text
閉鎖複素位相系における複素投影法と読出し演算の分類に関する定義補足.md
```

## 15. 追記: 複素投影法へ急ぎすぎないという修正

### 15.1 ユーザー側の指摘

しかし、これは進みすぎである。

中心投影法の研究だけで、すでに十本以上の論文を書いている。

複素投影法を置くなら、基本から整理し直す必要がある。

最低でも五本程度の研究が必要である。

さらに、中心投影よりもベースとなる論文が少ない。

したがって、いきなり `R/Q/E` 分離や重力・クーロン・圧力写像へ進むのは危険である。

### 15.2 Codex 側の修正意見

この指摘は正しい。

「複素投影法」と呼べるものを置くなら、いきなり定義補足一本で済む話ではない。

中心投影法だけで十本以上積み上げたなら、複素投影法はむしろその下層、または横にある基礎理論である。

そのため、最低でも段階を分ける必要がある。

いきなり `R/Q/E源分離` へ行く前に、次の順番が自然である。

### 15.3 複素投影法研究の最小段階案

#### 1. 複素投影法 序論

何を「投影」と呼ぶのか。

中心投影法との違い。

```math
x_n \in \mathbb{C}
```

と

```math
\sum_n x_n^2=0
```

の関係。

#### 2. 非共役二乗投影

```text
x^2
Σx_n^2=0
```

を扱う投影。

共役ノルムではないこと。

右辺問題。

内部位相の二乗符号。

#### 3. 実部・虚部・位相・振幅の読出し分離

```text
Re
Im
arg
|x|
|x|^2
```

が何を失い、何を保持するか。

#### 4. 双極投影

符号を保持する読出し。

```text
+Y / -Y / +X / -X
```

的な枝。

`Q` 型へ行く前の基礎。

ユーザー:

Codex:

## 17. 追記: 遠心力・等価原理・角度スイープへの回帰

### 17.1 ユーザー側の気づき

よりシンプルに考えるなら、物理 II の遠心力の方程式へ戻るべきかもしれない。

アインシュタインも考えた等価原理へ戻る。

遠心力とは、曲率波形の円周方向、すなわち円周測地線に沿って等速移動しているものが、中心と逆方向への加速度を持つように見える現象である。

つまり、角度のスイープこそが加速度である、という原理原則へ戻る方がシンプルではないか。

今回のように円周方向への加速度を読むためには、円周と直交する方向への回転運動の写像が必要なだけではないか。

### 17.2 Codex 応答メモ

これは、C の相互作用による微小ドリフトを無理に引力候補として追うより、ずっと第一原理に近い。

複素平面で、

```math
z = R e^{i\theta}
```

と置く。

角度 `theta` を等速にスイープすると、

```math
\frac{dz}{ds}
=
iR\dot{\theta}e^{i\theta}
```

である。

さらにもう一度微分すると、

```math
\frac{d^2z}{ds^2}
=
-R\dot{\theta}^2e^{i\theta}
```

となる。

ここで負符号は、外部から置かれた力ではなく、

```math
i^2=-1
```

から出る。

これは公理1の構造、

```math
\sum_n x_n^2=0
```

で負符号が外部計量ではなく内部位相の二乗から現れることとよく似ている。

したがって、加速度を、

```text
外部力があるから出るもの
```

として探すのではなく、

```text
角度位相のスイープ
複素平面内の直交回転
i^2=-1 による法線方向写像
曲率読出しとしての加速度
```

として読む方がよい可能性がある。

### 17.3 進行波方向と直交方向の面

ここで気になるのは、複素数が直交する二軸を持っている点である。

複素平面は、単なる計算上の平面ではなく、

```text
進行波方向
進行波方向と直交する内部回転方向
```

を同時に持つように読める。

進行波は、ある方向へ進む。

しかし、その位相は、進行方向と直交する複素平面内で回転しているようにも読める。

この構造は、

```text
円周測地線に沿った等速移動
それに直交する法線方向への加速度
```

と非常によく似ている。

つまり、複素数の二軸性と、曲率運動における接線方向・法線方向の分離は、同じ読出し構造の別表示かもしれない。

### 17.4 離散位相と加速度発生点

さらに、位相が連続ではなく離散化していると考える。

この場合、全位相で滑らかに加速度が生じるのではなく、特定の位相点だけで加速度が読まれる可能性がある。

候補は、

```text
0
pi/2
pi
3pi/2
```

である。

この四点は、複素平面上で実軸・虚軸の向きが最大に分離される点である。

もし位相読出しがこの四点に強く同期するなら、加速度は連続的な力ではなく、

```text
離散位相点でだけ発生する曲率写像
```

として読まれる可能性がある。

この場合、見かけの加速度は、

```text
全位相で均等に働く力
```

ではなく、

```text
位相セル境界または直交軸通過点で発生する読出し更新
```

になる。

これは、以前のサブセル読出し、巻数以下の位相差、タイヤのホイールが逆転して見えるような位相エイリアス問題とも接続する。

### 17.5 この方向の意味

この見方では、加速度の源は、まず次のように整理される。

```text
1. 角度スイープがある
2. 複素平面内で直交回転がある
3. 二階読出しで i^2=-1 が現れる
4. 接線方向の等速位相運動が、法線方向の加速度として読まれる
5. 離散位相なら、加速度読出しは特定位相点に集中する可能性がある
```

これは、現在保留しているベースライン定常波 `C` の相互作用実験とは別の、より基礎的な道である。

つまり、次に問うべきことは、

```text
C が A/B を動かすか
```

ではなく、

```text
閉鎖複素位相波に角度スイープを与えると、
その二階読出しが曲率加速度として現れるか
```

である。

この方が、遠心力、等価原理、内部位相の二乗、全正符号ゼロ閉鎖を一つの線で結びやすい。

### 17.6 現時点の注意

ただし、この段階ではまだ次を主張しない。

```text
重力が導出された
遠心力と重力が同一になった
離散位相点だけで現実の力が発生する
```

ここでの主張はもっと限定的である。

```text
加速度候補を相互作用ドリフトから探す前に、
角度スイープと複素直交回転による二階読出しを調べる必要がある。
```

この読出しが成立するなら、加速度は外部から入れた力ではなく、

```text
曲率を持つ閉鎖複素位相波の角度スイープから出る読出し
```

として扱える可能性がある。

## 18. 追記: 内部回転軸の配向によるクーロン型と重力型の分岐

### 18.1 ユーザー側の気づき

この説明は都合がよい。

クーロン力は、曲率の影響を受けにくいように読める。

なぜなら、クーロン型の内部回転は、曲率方向と直交して回転しているからである。

一方、重力型は、曲率方向または進行波方向とほぼ同じ面で回転している。

そのため、重力型は曲率の影響を受ける。

ただし、重力型でも中心向き成分と反中心向き成分は、もともとほぼ同じ大きさで発生している。

この二つはほぼ相殺する。

しかし、回転軸が曲率の影響でわずかに内側を向くなら、中心方向の成分がわずかに勝つ。

その残差だけが、弱い一方向的な引力として読まれるのではないか。

この写像なら、

```text
なぜ重力が弱いか
なぜ重力には曲率が強く効くか
なぜクーロン力は引力/斥力が同程度に出るか
```

を同じ構造で説明しやすい。

### 18.2 Codex 応答メモ

この写像は、力の種類を外部から別々に仮定するより自然である。

問題の中心は、

```text
内部回転軸が曲率フレームに対してどう配向しているか
```

である。

暫定的には、次のように整理できる。

| 型 | 内部回転軸の配向 | 曲率の影響 | 外部に残る読出し |
|---|---|---|---|
| クーロン型 `Q` | 曲率方向と直交 | 一次的には受けにくい | 符号付き枝が残り、引力/斥力が同程度 |
| 重力型 `R` | 曲率方向または進行波方向とほぼ同じ面 | 受けやすい | 対向成分がほぼ相殺し、曲率ズレ残差だけが残る |
| エネルギー型 `E` | 時間方向へ投影された回転軸 | 圧力的に読まれる可能性 | 正圧/負圧、または反力/引力的写像 |

ここで重要なのは、重力型では反中心向き成分が存在しないのではない、という点である。

むしろ、

```text
中心向き成分
反中心向き成分
```

は両方ある。

しかし、その二つがほぼ相殺し、曲率による軸ズレの微小差だけが残る。

したがって、重力が弱い理由は、

```text
重力源が弱いから
```

ではなく、

```text
大きな対向加速度成分がほぼ打ち消され、
残差としてしか読めないから
```

かもしれない。

この場合、重力は曲率と強く結びつく。

なぜなら、残差を作るものが、曲率による内部回転軸の微小な傾きだからである。

### 18.3 スピン的内部回転軸としての読み

この構造は、理論物理学でいうスピン構造に近い。

ただし、標準理論のスピンそのものをここで導出したとは言わない。

より慎重には、

```text
閉鎖複素位相波の内部回転軸
曲率フレームに対する軸配向
0/pi, pi/2/3pi/2 の位相枝
二階読出しで現れる法線方向成分
```

が、スピン的自由度として振る舞っている、と読む。

標準理論では、

```text
粒子にスピンがある
スピンが場と結合する
```

と置く。

本シリーズの読出し順序では、

```text
閉鎖複素位相波がある
内部位相回転がある
その回転軸の外部読出しがある
それがスピン的自由度に見える
```

となる。

したがって、現時点では「スピン」と断定せず、

```text
内部回転軸読出し
スピン的読出し
閉鎖複素位相波の軸配向自由度
```

として扱うのがよい。

### 18.4 クーロン力と重力を加速度読出しで見る

このモデルでは、クーロン力と重力はどちらも加速度読出しとして扱える可能性がある。

ただし、同じ加速度読出しでも、軸配向と符号枝の残り方が違う。

#### クーロン型

クーロン型では、内部回転軸が曲率方向と直交している。

そのため、曲率による軸ズレ補正を受けにくい。

また、`0` と `pi` の位相枝、または双極符号が外部読出しに残る。

したがって、

```text
同符号なら反発
異符号なら引力
```

のように、引力と反力が同程度の強さで現れる。

これは、クーロン力が符号付き相互作用として見えることと相性がよい。

#### 重力型

重力型では、内部回転軸が進行波方向または曲率方向とほぼ同じ面にある。

そのため、曲率の影響を受ける。

しかし、中心向き成分と反中心向き成分は、基本的にはほぼ同じ大きさで発生する。

この二つがほぼ打ち消し合う。

残るのは、曲率による回転軸の微小なズレで中心向きがわずかに勝った成分である。

したがって、重力型は、

```text
強い相互作用が弱くなったもの
```

ではなく、

```text
大きな対向加速度の相殺後に残る弱い曲率残差
```

として読める。

この読みなら、重力が弱いことと、重力が曲率に深く結びつくことが同時に説明しやすい。

### 18.5 強い力と弱い力は同じ棚に置かない

この段階で、四つの力を無理に同じ加速度読出しへ押し込まない方がよい。

クーロン力と重力は、内部回転軸の配向と二階読出しによる加速度として、比較的近い枠で扱える可能性がある。

しかし、強い力はかなり特殊である。

強い力は、単純な外部加速度読出しというより、

```text
内部閉鎖
閉じ込め
局所位相拘束
複数閉鎖波の短距離結合
```

に近い可能性がある。

したがって、強い力は、クーロン型や重力型とは別に考える必要がある。

また、弱い力は、そもそも「力」と呼ぶべきものではない可能性がある。

弱い力は、持続的な加速度読出しというより、

```text
閉鎖状態の遷移
内部位相構成の組み替え
準安定状態の崩壊
読出し名の変更
```

に近いかもしれない。

この意味で、現時点の分類は次のようにする。

| 対象 | 本メモでの暫定分類 |
|---|---|
| クーロン力 | 符号枝を保持する内部回転軸の加速度読出し |
| 重力 | 対向加速度の相殺後に残る曲率ズレ残差 |
| 強い力 | 内部閉鎖・閉じ込め・短距離結合として別扱い |
| 弱い力 | 力というより閉鎖状態遷移・準安定崩壊として別扱い |

### 18.6 現時点の結論

現時点での暫定結論は次である。

```text
クーロン力と重力は、加速度読出しとして同じ幾何枠で近づける可能性がある。
ただし、クーロン力は符号枝が残る。
重力は対向枝がほぼ相殺し、曲率による軸ズレ残差だけが残る。
強い力と弱い力は、この枠に無理に入れない。
```

この整理は、加速度予備実験で見えた弱い引力候補と強い反力候補の問題を、より基礎的な幾何読出しへ戻す。

つまり、次に必要なのは、

```text
外部相互作用を増やす実験
```

ではなく、

```text
内部回転軸の配向
曲率フレームとの角度
0/pi 位相枝の符号保持
pi/2/3pi/2 位相枝の直交成分
曲率による軸ズレ残差
```

を分類する基礎メモである。
