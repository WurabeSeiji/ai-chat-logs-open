# 現在チャットメモ: 多ゲージ干渉読出し仕様方針

**日付:** 2026-07-11  
**位置づけ:** Codex との継続議論メモ  

---

## 0. 更新注記

本メモは、「全正符号ゼロ閉鎖の読出し多重性に関する定義補足」作成前の議論を含む。

したがって、本メモ内で

```text
a^2 + b^2 + rho^2 = 0
```

と略記していた箇所は、厳密には、`rho` を外部負符号軸として置くのではなく、内部位相を含む補償成分として

```text
a^2 + b^2 + (i rho)^2 = 0
```

と読む。

この読みは、公理1への追加条件ではない。同じ全正符号ゼロ閉鎖

```text
Sigma x_n^2 = 0
```

の読出し表示である。

以後、公理1の読出し多重性については、次を参照する。

```text
木原範昭「全正符号ゼロ閉鎖の読出し多重性に関する定義補足」2026-07-11.
```

## 1. 公理1の解釈に関する整理

本議論では、公理1

```text
Sigma x_n^2 = 0
```

の解釈について、次を確認した。

この確認は、後続の定義補足論文で、公理1の読出し多重性として整理された。

まず、

```text
a^2 + b^2 = r^2
```

を

```text
a^2 + b^2 + (i rho)^2 = 0
```

として読むなら、これは公理1の三成分局所読出しであり、公理1とは別の追加公理ではない。

この表示において、`a,b,rho` は第一原理的な固有名ではない。局所読出し表示における便宜的ラベルである。

したがって、半径閉鎖を

```text
a^2 + b^2 - r^2 = 0
```

として外部負符号つきで置く読みは、本シリーズの全正符号ゼロ閉鎖および無名性の方針に反する。

負符号は外部計量に置かず、成分の内部位相、補償対、または読出し表示から現れるものとして扱う。

---

## 2. 循環の確認

次の読みは循環する。

```text
Sigma x_n^2 = 0
```

を説明するために、

```text
a^2 + b^2 + (i rho)^2 = 0
```

を追加条件として置くこと。

これは同型の局所表示を再導入しているだけであり、公理1の外部根拠にはならない。

したがって、必要なのは公理1の追加ではなく、公理1の読出し表示の整理である。

この整理は、「全正符号ゼロ閉鎖の読出し多重性に関する定義補足」で行った。

同論文の方針は次である。

```text
公理1は変更しない。
追加公理も置かない。
複数の表示は、同じ Sigma x_n^2 = 0 の読出し表示として扱う。
外部負符号、特権軸、特権成分を第一原理に置かない。
```

---

## 3. 読出し問題としての物理量

本シリーズでは、すでに `x,y,z,t` を背景座標ではなく、閉じた位相系からの読出し量として扱ってきた。

同じ方針で、質量、エネルギー、運動量も、実体量として先に置かず、閉鎖位相系の干渉読出しとして扱う。

暫定対応は次である。

| 読出し対象 | 読出し候補 | 注意 |
|---|---|---|
| 運動量的量 | 位相勾配の投影読出し | 単一ゲージでは測定不可 |
| エネルギー的量 | 時間位相方向の進行率読出し | 複数時間窓で読む |
| 質量的量 | R軸側に残る安定残差 | 直接読まず、多ゲージ差分で読む |
| 電荷的量 | 内部識別巻数 | 既存の `eta` 識別読出しと接続 |

## 4. ABC完全弾性衝突モデルへ戻す理由

最小二成分の抽象実験より、既存の ABC 完全弾性衝突モデルへ戻す方がよい。

理由は、既存モデルですでに次が実装済みだからである。

```text
背景座標なし
内部観測あり
識別振動保存
閉鎖残差保存
完全弾性反射
複数回衝突
観測機 C
```

したがって次の問いは、既存の完全弾性衝突モデルに対し、

```text
質量的量・運動量的量・エネルギー的量に見える保存読出しを、
多ゲージ干渉読出しとして再構成できるか
```

である。

## 5. 測定条件

単一ゲージの内部計算値は測定値としない。

測定成立には、複数の参照波、複数の読出し窓、複数のゲージで再構成されることを要求する。

運動量的読出しは、空間位相方向の干渉相関勾配として読む。

```text
p_read ~ arg(O(chi + h) / O(chi - h)) / (2h)
```

エネルギー的読出しは、時間位相方向の干渉相関勾配として読む。

```text
E_read ~ arg(O(tau + h) / O(tau - h)) / (2h)
```

質量的読出しは、直接読まず、投影読出しを変えても残る安定な R 軸残差として読む。

```text
R_read = multi-gauge stable residual
```

ここでいう `R` は、第一原理的な半径軸ではない。

`R` は、複数ゲージを変えても消えずに残る安定残差を分類するための読出し名である。

---

## 6. t/R軸分離の見方

`t` と `R` は先験的な名前付き軸ではない。

変動が大きく連続的に読まれる軸を `t` と読み、変動が小さく安定して残る軸を `R` と読む。

したがって、R軸変動が小さいほど質量的量は測りにくい。

また、R軸の安定性が弱くなると、`t` と `R` の区別は困難になり、無名性の破れを安定に読めなくなる。

検証候補は次である。

```text
separation_ratio = Var(R_read) / Var(t_read)
```

```text
separation_ratio << 1 なら t/R 分離可能
separation_ratio ~ 1 なら t/R 分離困難
```

## 7. 次の作業方針

今回は数値検証メモからではなく、仕様書から作る。

理由は、計算以前に、何を測定成立と判定するかを固定する必要があるためである。

仕様書案:

```text
ABC完全弾性衝突における多ゲージ干渉読出し仕様書 v1
```

仕様書に含める項目:

```text
読出し対象
観測機 C のゲージ群
運動量的読出しの定義
エネルギー的読出しの定義
R軸残差の定義
t/R 分離条件
成功条件
破綻条件
本稿で主張しないこと
```

## 8. 成功条件の暫定案

```text
p_read:
  衝突で符号反転する。

E_read:
  衝突前後で保存される。

R_read:
  複数ゲージで不変な安定残差として読める。

m_A, m_B:
  識別振動が保存される。

Sigma x_n^2:
  補償付き閉鎖残差が保存される。
```

---

## 9. 破綻条件の暫定案

```text
R_read がゲージ依存になる。
R_read が衝突で変化する。
p_read が反射符号と一致しない。
E_read が保存しない。
観測機 C の容量不足で t/R 分離が崩れる。
単一ゲージ値を測定値として扱ってしまう。
```
