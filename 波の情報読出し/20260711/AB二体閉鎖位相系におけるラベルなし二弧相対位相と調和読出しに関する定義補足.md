**副題:** 観測機 C を置かない AB 二体系における無名相対位相、二弧読出し、`pi` 近傍調和読出しの表示規律

## 要旨

本稿では、観測機 `C` を置かない AB 二体閉鎖位相系において、相対位置位相をどのように読むかを整理する。

AB 二体系では、`A` が観測者で `B` が対象である、または `B` が観測者で `A` が対象である、とは第一原理層では言わない。

無名性により、`A` と `B` のどちらが観測機であるか、どちらが読まれる対象であるかは、閉鎖系内部から固有名として区別しない。

その代わり、AB 二体系に安定して残る読出し対象を、

```text
ラベルなし二弧相対位相
```

として定義する。

円周位相上で二点 `A,B` があるとき、両者の間には二つの弧がある。

一方の弧の位相差を `delta` と書けば、もう一方は

```text
2pi - delta
```

である。

しかし、どちらが近い方か、どちらが遠い方か、どちらを `A` から見たのか、どちらを `B` から見たのかは、無名性により第一原理名を持たない。

したがって、本稿では観測可能な二弧読出しを、順序なし集合

```text
D_AB = { delta, 2pi - delta }
```

として扱う。

特に `pi` 近傍では、

```text
D_AB = { pi - epsilon, pi + epsilon }
```

と書ける。

ここで符号付きの `epsilon` は、AB 二体系単独では固有名として読まない。

一方、

```text
epsilon^2
```

または `pi` 平衡からの対称偏差は、ラベルなし読出しとして扱える。

本稿の中心命題は次である。

> AB 二体閉鎖位相系では、観測機 C を置かなくても、ラベルなし二弧相対位相 `D_AB` と、`pi` 近傍からの対称偏差 `V_AB` は読出し候補になる。ただし、その変化が向心補償表示によるものか、`pi` 平衡点への閉鎖回復表示によるものか、円周位相の調和表示によるものかを、AB 二体系内部から一意に分離しない。

さらに、中心近傍での振る舞いについて、反跳表示と透過表示を区別して検査する。

ただし、ラベルなし二弧相対位相だけを見る場合、反跳したのか、透過してラベルが交換されたのかは縮退する可能性がある。

本稿では、AB 二体系の合成閉鎖から読まれる補償を

```text
f_AB
```

と書き、中心方向の向心補償表示と、円周方向の調和読出し表示を、同じ `f_AB` の二つの表示として扱う。

すなわち、本稿の AB 二体作業仮説は、

```text
f_AB = f_AB
```

である。

`f_A`, `f_B` を独立の力として導入しない。

また、長期観測では、読出し波の有無および強度により `V_AB(s)` の振幅包絡が変化するかを反証テストとして検査する。

この分離不能性は失敗ではない。

無名性および読出し多重性の現れである。

**キーワード:** AB二体閉鎖位相系、観測機なし読出し、ラベルなし二弧相対位相、調和読出し、AB合成補償、`f_AB=f_AB`、反跳表示、透過表示、読出し波停止、減衰反証テスト、`pi` 平衡、無名性、読出し多重性、全正符号ゼロ閉鎖

## 1. 目的

本稿の目的は、AB 二体系で相対位置位相を読む際に、観測機 `C` を暗黙に持ち込まないための表示規律を定めることである。

前段階の ABC 系では、`C` を観測機、参照波、またはベースライン定常波として扱った。

しかし、AB 二体系の最小検査では、`C` を置かない。

このとき、次の問いが生じる。

```text
C がないのに、誰が誰を観測するのか。
```

本稿の答えは次である。

```text
誰が誰を観測する、とは言わない。
AB 二体系にラベルなしで残る相対位相読出しだけを読む。
```

したがって、本稿は次を定義する。

| 対象 | 本稿での扱い |
|---|---|
| `A` が `B` を読む | 第一原理層では採用しない |
| `B` が `A` を読む | 第一原理層では採用しない |
| `A/B` のどちらが観測機か | 固有名として決めない |
| 近い弧、遠い弧 | 名前を持つ実体ではなく、順序なし二弧読出しとして扱う |
| `pi` からの符号付き偏差 | AB 二体系単独では固有符号を読まない |
| `pi` からの対称偏差 | 読出し候補として扱う |

### 2.1 公理0: 無名性

基本成分に、個別名、特権軸、特権符号、特権型を与えない。

AB 二体系では、`A` と `B` は作業ラベルである。

閉鎖系内部から、どちらが観測者でどちらが対象かを固有名として決めない。

### 2.2 公理0+: 定式化無名性

物理名、対象名、相互作用名、または既存理論上の分類名を理由として、第一原理層の方程式、射影、読出し規則を変更しない。

したがって、次の順序は採用しない。

```text
引力を見たい
したがって A が B を観測することにする
したがって近い方の弧だけを読む
```

採用する順序は次である。

```text
AB 二体閉鎖対象を置く
ラベルなし二弧相対位相を定義する
対称偏差を読む
その変化が調和的に見えるかを後から判定する
```

### 2.3 公理0.5: 次元別中心投影読出し

単一軸上の読出しでは曲率補正を導入しない。

本稿の AB 二体系は、まず一つの円周位相自由度を持つ `S^1` 型読出しとして扱う。

したがって、本稿では逆二乗型や面積スイープを仮定しない。

逆二乗型は、独立な位置位相自由度を二つ以上持つ後続の定義補足で検査対象にする。

### 2.4 公理3: 投影軸縮退と虚数方向読出し

投影法により内在座標系が構成されるとき、投影軸方向は、その内在座標系の住民から方向として判別されない。

ただし、投影軸方向の値が閉鎖条件内に残る場合、その値を消去せず、内在座標系では虚数符号を伴う補償成分として扱う。

本稿では、AB 合成中心 `O_AB` 方向の補償 `f_AB` が円周住民から方向として読めない場合、

```text
i f_AB
```

として閉鎖式内に保持する。

これが二乗読出しに現れると、

```text
(i f_AB)^2 = - f_AB^2
```

となり、観測可能な円周方向または調和読出しの補償量として現れる。

## 3. 本稿で主張しないこと

本稿は、次を主張しない。

| 主張しないこと | 理由 |
|---|---|
| 標準重力の導出 | 本稿は AB 二体系の相対位相読出し規律である |
| 標準クーロン力の導出 | 電荷的符号読出しは本稿の対象外である |
| 観測機 C の存在 | 本稿では C を置かない |
| `A` が観測者であること | 無名性により固有名として決めない |
| `B` が観測者であること | 同上 |
| 向心補償と `pi` 閉鎖回復の実在的分離 | AB 二体系内部では一意に分離しない |
| `f_A`, `f_B` を独立力として置くこと | AB 合成補償 `f_AB` の局所射影として扱う |
| 反跳表示と透過表示の実在的分離 | ラベルなし二弧読出しでは縮退する可能性がある |
| 読出し減衰を熱力学的散逸と同一視すること | 本稿では読出し波の有無による反証テストに限る |
| 逆二乗則 | 一角度円周位相では面積スイープを置かない |

本稿の主張は、AB 二体系で読める最小の相対位相量を、無名性に反しない形で定義することである。

## 4. AB 二体閉鎖対象

AB 二体閉鎖対象を

```text
P_AB = A + B
```

とする。

閉鎖条件は、他の系と同じく

```math
Q(P_AB)=\sum_n p_n^2=0
```

である。

ここで `P_AB` は閉鎖対象集合であり、外部空間に置かれた二粒子の集合ではない。

`A` と `B` は作業ラベルである。

ラベルの交換

```text
A <-> B
```

で読出し結果が本質的に変わる量は、AB 二体系の無名読出しとしては採用しない。

## 5. ラベルなし二弧相対位相

円周位相上の二点には、二つの弧がある。

片方の弧の位相差を `delta` とすれば、もう片方は

```text
2pi - delta
```

である。

しかし、AB 二体系では、次を固有名として決めない。

```text
A から B へ向かう弧
B から A へ向かう弧
近い方の弧
遠い方の弧
正方向の弧
負方向の弧
```

したがって、読出し対象を順序なし集合

```text
D_AB = { delta, 2pi - delta }
```

として定義する。

これは、AB 二体系から読まれるラベルなし二弧相対位相である。

## 6. `pi` 近傍の対称偏差

二弧相対位相が `pi` 近傍にある場合、

```text
D_AB = { pi - epsilon, pi + epsilon }
```

と書ける。

ここで、`epsilon` の符号はラベルなし二弧読出しでは固有名を持たない。

つまり、

```text
epsilon
```

そのものではなく、

```text
epsilon^2
```

または `pi` からの対称偏差を読む。

作業量として、

```text
V_AB
=
1/2 * [ (delta_1 - pi)^2 + (delta_2 - pi)^2 ]
```

を定義する。

ここで

```text
{delta_1, delta_2} = D_AB
```

である。

`D_AB = {pi - epsilon, pi + epsilon}` なら、

```text
V_AB = epsilon^2
```

となる。

`V_AB` は、符号なしの相対位相偏差である。

## 7. 調和読出し

ステップ列 `s` に沿って `V_AB(s)` を読む。

次の三つを区別して記録する。

| 振る舞い | 読出し |
|---|---|
| `V_AB(s) -> 0` | `pi` 平衡へ閉鎖回復する読出し |
| `V_AB(s)` が周期的に変化する | 調和振動的読出し |
| `V_AB(s)` が非ゼロで安定する | 準安定な相対位相偏差 |

ここでいう調和振動的読出しは、標準力学のばねやポテンシャルを仮定するものではない。

AB 二体閉鎖位相系のラベルなし二弧相対位相が、`pi` 近傍で対称偏差として脈動することを指す。

## 8. 原因の分離不能性

AB 二体系で `V_AB(s)` の減衰、脈動、または安定偏差が観測されたとしても、その原因を次のどれか一つへ一意に分離しない。

```text
向心補償表示
pi 平衡点への閉鎖回復表示
円周位相の調和表示
```

これらは、同じ読出しを与える複数の表示である可能性がある。

AB 二体系内部では、観測機 `C` も外部基準も置かないため、どの表示が実在の原因であるかを決定しない。

この分離不能性は、測定の失敗ではない。

無名性および読出し多重性の現れである。

したがって、後続実験で AB 二体系から確認できる主張は次に限る。

```text
AB 二体系に、ラベルなし相対位相の中心復元的または調和的読出しがある。
```

次は主張しない。

```text
その原因は向心補償である。
その原因は pi 閉鎖回復である。
その原因は古典的な力である。
```

## 9. AB 合成補償読出しの同一性仮定

AB 二体閉鎖対象

```text
P_AB = A + B
```

から、合成中心

```text
O_AB
```

および合成半径的読出し

```text
R_AB
```

が読まれるとする。

このとき、AB 合成閉鎖の補償読出しを

```text
f_AB
```

と書く。

本稿では、これを次のように仮定する。

```text
中心方向の向心補償読出し = f_AB
円周方向の調和読出し     = f_AB
```

すなわち、

```text
f_AB = f_AB
```

である。

これは曖昧な比喩ではない。

本稿の AB 二体問題における明示的な作業仮説である。

ただし、この等式は、標準ベクトル空間における中心方向成分と円周方向成分が同じ向きである、という意味ではない。

意味は次である。

```text
AB 合成閉鎖から読まれる補償は一つである。
中心方向表示も、円周方向表示も、その同じ補償 f_AB の読出しである。
方向は表示により異なるが、別の力 f_A, f_B を導入しない。
```

したがって、図化では次の規律を採用する。

| 図化対象 | 表記 | 扱い |
|---|---|---|
| AB 合成中心方向の補償 | `f_AB` | `O_AB` 方向の表示 |
| AB 円周方向の調和読出し | `f_AB` | 円周位相方向の表示 |
| A 側端点への局所射影 | `f_AB|A` | `f_A` ではなく `f_AB` の A 側射影 |
| B 側端点への局所射影 | `f_AB|B` | `f_B` ではなく `f_AB` の B 側射影 |

次の表現は採用しない。

```text
A が B による力 f_B を受ける
B が A による力 f_A を受ける
```

この表現は、原因側に `A`, `B` の固有名を与え、無名性を破りやすい。

採用する表現は次である。

```text
A 側には AB 合成補償 f_AB の局所射影が読まれる。
B 側には AB 合成補償 f_AB の局所射影が読まれる。
```

この仮定が誤りである可能性は残す。

後続実験で、中心方向の補償読出しと円周方向の調和読出しが同じ `f_AB` として扱えないことが示されるなら、本稿の AB 合成補償同一性仮説は反証される。

## 10. 反跳表示と透過表示

`pi` 近傍の調和読出しを数値実験で扱う場合、中心近傍で二つの表示を分ける必要がある。

一つは反跳表示である。

```text
Protocol F
```

と呼ぶ。

これは、中心近傍で二つの局所波が同一位置位相を占有せず、完全弾性衝突的に反転する表示である。

もう一つは透過表示である。

```text
Protocol B
```

と呼ぶ。

これは、中心近傍で二つの局所波が通過し、位相枝の `unwrap` により連続的に進む表示である。

| 表示 | 中心近傍の扱い | 読出し上の注意 |
|---|---|---|
| `Protocol F` | 反跳する | `p_read` 反転表示と接続しやすい |
| `Protocol B` | 透過する | ラベル交換と区別できない可能性がある |

ここで重要なのは、どちらが実在であるかを先に決めないことである。

ラベルなし二弧相対位相

```text
D_AB(s)
```

および対称偏差

```text
V_AB(s)
```

だけを見る場合、反跳した表示と、透過してラベルが交換された表示が、同じ読出しを与える可能性がある。

その場合、両者は表示多重性として扱う。

一方、`Q_raw`, `Q_closed`, `p_read`, 位相枝 `unwrap`、または識別振動読出しに差が出る場合は、その差を記録する。

後続実験では、`Protocol F` と `Protocol B` の両方を実行し、少なくとも次を比較する。

| 比較量 | 目的 |
|---|---|
| `D_AB(s)` | ラベルなし二弧読出しが一致するか |
| `V_AB(s)` | 対称偏差の包絡が一致するか |
| `Q_raw(s)` | 中心近傍で閉鎖残差が異なるか |
| `Q_closed(s)` | 定常化後に差が残るか |
| `p_read(s)` | 反転表示と透過表示の違いが読めるか |

## 11. 読出し波停止による減衰反証テスト

AB 二体系を長期に読む場合、`V_AB(s)` の振幅包絡が減衰する可能性がある。

この減衰を、物理的散逸、情報エントロピー、または標準熱力学的効果と同一視しない。

本稿では、より限定された反証テストとして扱う。

検査する問いは次である。

```text
読出しのための波を出すか、止めるかにより、
AB 二体系の調和読出し振幅包絡が変化するか。
```

後続実験では、次の条件を置く。

| 条件 | 内容 |
|---|---|
| `readout_off` | 読出し波を出さない |
| `readout_weak` | 極弱読出し波で読む |
| `readout_normal` | 通常読出し波で読む |
| `readout_strong` | 強読出し波で読む |

記録する量は次である。

| 量 | 目的 |
|---|---|
| `V_AB(s)` | 調和読出しの対称偏差 |
| `envelope_V_AB(s)` | 振幅包絡 |
| `decay_rate_V_AB` | 包絡減衰率 |
| `Q_raw(s)` | 読出し直後または再埋め込み前の閉鎖残差 |
| `Q_closed(s)` | 定常化後の閉鎖残差 |
| `R_read(s)` | 安定残差読出しの変化 |

判定は次のように行う。

| 観測結果 | 作業的解釈 |
|---|---|
| `readout_off` で減衰しない | AB 閉鎖対象単独では保存的に見える |
| 読出し波ありで減衰する | 読出し波が AB 部分系の読出しを変化させている可能性 |
| 読出し波強度と減衰率が相関する | 読出しによる外部相関または補償成分の移動候補 |
| 読出し波なしでも同様に減衰する | 閉鎖再選別、準安定化、数値更新則の候補 |

ここでいう外部とは、標準空間の外側ではない。

閉鎖対象を `AB` に限って読んだとき、読出し波を含む拡張対象

```text
AB + readout
```

へ移った相関または補償成分が、`AB` 部分系から消えたように見える可能性を指す。

したがって、全体閉鎖が破れていなくても、`AB` 部分系だけを読むと保存量が減ったように見える場合がある。

本稿では、この可能性を解釈として主張するのではなく、読出し波停止による反証テストとして扱う。

---

## 12. 一角度円周位相で逆二乗を要求しない

本稿の AB 二体系は、一つの位置位相自由度を持つ円周読出しである。

この場合、読出しの自然な広がりは、面積ではなく弧長である。

したがって、一角度円周位相から逆二乗型を要求しない。

一角度読出しで現れる可能性が高いのは、次のような構造である。

```text
pi 近傍の線形復元
調和振動的読出し
弧長または位相差に対する逆比例的読出し
```

もし後続実験で逆二乗型が出ないとしても、それは本稿の失敗ではない。

逆二乗型は、二つ以上の独立な位置位相自由度が作る面積スイープの検査対象である。

---

## 13. 後続実験への要請

後続実験では、まず AB 二体系のみを用いる。

観測機 `C` は置かない。

具体的な実験条件は、次の仕様書で分けて定める。

[AB二体閉鎖位相系における一角度円周位相調和読出し実験仕様書 v1.md](AB二体閉鎖位相系における一角度円周位相調和読出し実験仕様書%20v1.md)

一角度読出しの予備実験後、二角度・三角度拡張へ進む前に、次の仕様書で、実験ステップ `s` と時間位相読出し `tau_read` を分離し、内部 `c=1` 較正による `chi-tau` 面積スイープの有無を検査する。

[AB二体閉鎖位相系におけるc=1内部較正と空間位相・時間位相面積スイープ読出し実験仕様書 v1.md](AB二体閉鎖位相系におけるc=1内部較正と空間位相・時間位相面積スイープ読出し実験仕様書%20v1.md)

最低限、次を記録する。

| 量 | 目的 |
|---|---|
| `D_AB(s)` | ラベルなし二弧相対位相 |
| `V_AB(s)` | `pi` からの対称偏差 |
| `Q_raw(s)` | 相互作用直後または再埋め込み前の閉鎖残差 |
| `Q_closed(s)` | 定常化後の閉鎖残差 |
| `rho_AB(s)` | AB 二体合成半径的読出し |
| `theta_AB(s)` | AB 二体円周位相読出し |
| `f_AB(s)` | AB 合成補償読出し |
| `f_AB|A`, `f_AB|B` | `f_AB` の端点局所射影 |
| `protocol` | `Protocol F` または `Protocol B` |
| `readout_mode` | `readout_off`, `readout_weak`, `readout_normal`, `readout_strong` |
| `envelope_V_AB(s)` | 調和読出し振幅包絡 |
| `decay_rate_V_AB` | 包絡減衰率 |

初期条件として、例えば次を検査する。

```text
D_AB(0) = {175deg, 185deg}
D_AB(0) = {178deg, 182deg}
D_AB(0) = {170deg, 190deg}
```

これらが、

```text
V_AB(s) -> 0
V_AB(s) が脈動
V_AB(s) が非ゼロ安定
```

のどれに向かうかを読む。

この実験で読むのは、相対位相偏差の振る舞いである。

原因名の決定ではない。

## 14. 次段階との関係

本稿は、AB 二体系の一角度円周位相読出しを扱う。

次段階では、位置位相自由度を増やす。

```text
位置位相 1 個 -> S^1 的円周読出し
位置位相 2 個 -> S^2 的球殻読出し
位置位相 3 個 -> S^3 的超球殻読出し
```

これにより、弧長、面積、超面体積のどれに保存読出しが分配されるかを検査する。

逆二乗型は、本稿ではなく、二角度以上の位置位相読出しで検査する。

## 15. 結論

本稿では、観測機 `C` を置かない AB 二体閉鎖位相系において、ラベルなし二弧相対位相と調和読出しを定義した。

AB 二体系では、`A` が `B` を読む、または `B` が `A` を読む、とは第一原理層で言わない。

代わりに、二つの弧からなる順序なし集合

```text
D_AB = { delta, 2pi - delta }
```

を読む。

`pi` 近傍では、符号付き偏差ではなく、対称偏差

```text
V_AB = epsilon^2
```

を読む。

`V_AB(s)` が減衰する、脈動する、または非ゼロ安定することは観測可能である。

ただし、その原因を、向心補償、`pi` 平衡閉鎖回復、円周位相の調和表示のいずれか一つへ一意に分離しない。

この分離不能性は、無名性および読出し多重性の現れである。

本稿ではさらに、AB 合成補償読出しについて、中心方向表示と円周方向表示を同じ `f_AB` の読出しとして扱う。

すなわち、本稿の AB 二体作業仮説は、

```text
f_AB = f_AB
```

である。

`f_A`, `f_B` を独立力として導入せず、必要な場合は `f_AB|A`, `f_AB|B` という局所射影として図化する。

また、中心近傍の扱いとして、反跳表示 `Protocol F` と透過表示 `Protocol B` を分けて検査する。

両者が同じ `D_AB(s)` と `V_AB(s)` を与える場合、それらは AB 二体系のラベルなし読出しでは表示多重性として扱う。

さらに、長期観測では、読出し波を止めた場合と出した場合を比較し、振幅包絡の減衰が読出し波の有無または強度に依存するかを反証テストとして扱う。

また、一角度円周位相では逆二乗型を要求しない。

逆二乗型は、二つ以上の独立な位置位相自由度による面積スイープ読出しで検査する。
