# ABC完全弾性衝突における多ゲージ干渉読出し仕様書 v1

**副題:** 質量的量・運動量的量・エネルギー的量を単一内部値ではなく複数ゲージ干渉相関から再構成するための実験仕様  
**日付:** 2026-07-11  
**著者:** 木原 範昭  
**位置づけ:** 波の情報読出しシリーズ・数値実験仕様書  

---

## 0. 目的

本仕様書の目的は、既存の ABC 完全弾性衝突モデルに対して、質量的量、運動量的量、エネルギー的量に見える保存読出しを、多ゲージ干渉読出しとして構成できるかを検査するための仕様を固定することである。

本仕様書では、単一ゲージの内部計算値を測定値とは呼ばない。

測定成立には、複数の参照波、複数の読出し窓、複数のゲージで再構成された量が、同じ保存関係を満たすことを要求する。

## 1. 前提

### 1.1 基本公理

本仕様書は、次を前提とする。

| 項目 | 内容 |
|---|---|
| 公理0 | 無名性 |
| 公理1 | 全正符号ゼロ閉鎖 |
| 公理0.5 | 曲率を単一軸へ帰属させない読出し規律 |
| 既存実装 | ABC 完全弾性衝突モデル |
| 既存実装 | フェルミオン的逆相核による交換干渉反射 |
| 既存実装 | 曲率付き閉鎖定常波による曲率相対位相漏れの再選別 |

公理1は次である。

```text
Sigma x_n^2 = 0
```

ここで、負符号を外部計量へ置かない。

負に見える項は、成分の内部位相、補償対、または読出し表示から現れるものとして扱う。

### 1.2 既存 ABC モデル

既存の ABC 完全弾性衝突モデルでは、次がすでに実装済みである。

```text
背景座標なし
内部観測あり
識別振動保存
代表振幅保存
閉鎖残差保存
完全弾性反射
複数回衝突
重い観測機 C
```

本仕様書では、この既存モデルに読出し器を追加し、物理量に見える保存形式を測る。

## 2. 本仕様書で主張しないこと

本仕様書は、次を主張しない。

| 主張しないこと | 理由 |
|---|---|
| 標準物理の質量、運動量、エネルギーを完全導出したこと | 対応写像は別途必要である |
| 単一内部値 `A^2`, `qv`, `omega` を測定値と呼ぶこと | 干渉読出しではなく内部計算値にすぎない |
| R軸が先験的な実体軸であること | R は安定残差として読まれる名前である |
| t軸が先験的な実体軸であること | t は連続変動の大きい読出し軸として読まれる名前である |
| `E^2-p^2=m^2` 型の標準関係を仮定すること | 本仕様では内部読出し残差として扱う |

本仕様書の主張は、閉じた位相系の内部干渉読出しから、質量的、運動量的、エネルギー的に分類可能な保存読出し量を再構成できるかを検査することである。

## 3. 読出し対象

### 3.1 運動量的量

運動量的量は、空間位相方向の干渉相関勾配として読む。

単に既存の方向読出し量 `q` に代表振幅を掛けた値は、測定値とはしない。

測定候補は、観測機 `C` の読出し中心を空間位相方向にずらした二点相関から得る。

```text
p_chi_read(P, g, s)
  = arg(O_P,g(chi + h_chi, tau, s) / O_P,g(chi - h_chi, tau, s))
    / (2 h_chi)
```

ここで、

| 記号 | 意味 |
|---|---|
| `P` | 局所波 `A` または `B` |
| `g` | 読出しゲージ |
| `s` | 計算順序パラメータ |
| `O_P,g` | ゲージ `g` における干渉相関読出し |
| `h_chi` | 空間位相方向の読出し差分幅 |

### 3.2 エネルギー的量

エネルギー的量は、時間位相方向の干渉相関勾配として読む。

単に既存の `omega` を記録した値は、測定値とはしない。

測定候補は、観測機 `C` の読出し中心を時間位相方向にずらした二点相関から得る。

```text
E_tau_read(P, g, s)
  = arg(O_P,g(chi, tau + h_tau, s) / O_P,g(chi, tau - h_tau, s))
    / (2 h_tau)
```

### 3.3 質量的量

質量的量は、R軸を直接読むのではなく、多ゲージで投影読出しを変えても消えずに残る安定残差として読む。

この量を `R_read` と呼ぶ。

`R_read` は先験的な名前付き軸ではない。

複数ゲージで運動量的読出しとエネルギー的読出しを再構成した後、読出し軸を変えても保存される安定成分として定義する。

```text
R_read(P, s)
  = stable_residual over gauges g
```

実装では、各ゲージにおける可視投影成分と全読出し強度の差分を測り、ゲージ間分散が小さい成分を R 軸残差候補とする。

この差分は、公理に外部負符号を加えるものではない。読出し解析上の比較量である。

### 3.4 電荷的量

電荷的量は、既存の内部識別位相 `eta` の巻数読出しと接続する。

本仕様書では、電荷的量の定量導出を主目的としない。

ただし、`m_A,m_B` の識別振動が保存されることは、読出しの妥当性条件として保持する。

## 4. 読出しゲージ

### 4.1 ゲージの定義

読出しゲージ `g` は、観測機 `C` の参照波設定をまとめたものである。

```text
g = (delta_chi, delta_tau, delta_phi, h_chi, h_tau, C_width, C_gain)
```

| 成分 | 意味 |
|---|---|
| `delta_chi` | 空間位相読出し中心のずれ |
| `delta_tau` | 時間位相読出し中心のずれ |
| `delta_phi` | 参照波の内部位相オフセット |
| `h_chi` | 空間差分幅 |
| `h_tau` | 時間差分幅 |
| `C_width` | 観測機 C の読出し幅 |
| `C_gain` | 観測機 C の読出しゲイン |

### 4.2 最小ゲージ群

最小実験では、次のゲージ群を用いる。

| ゲージ | 目的 |
|---|---|
| `g0` | 基準読出し |
| `g_chi_plus` | 空間位相方向の正側読出し |
| `g_chi_minus` | 空間位相方向の負側読出し |
| `g_tau_plus` | 時間位相方向の正側読出し |
| `g_tau_minus` | 時間位相方向の負側読出し |
| `g_phi_shift` | 参照位相オフセットに対する不変性検査 |
| `g_width_shift` | 読出し幅に対する不変性検査 |
| `g_gain_shift` | 観測機ゲインに対する不変性検査 |

単一ゲージ `g0` の値だけでは測定成立としない。

## 5. t/R 軸分離条件

### 5.1 基本解釈

`t` と `R` は、先験的な名前付き軸ではない。

変動が大きく、連続的に読まれる成分を `t` と読む。

変動が小さく、ゲージを変えても安定して残る成分を `R` と読む。

したがって、質量的量は直接大きく読める量ではなく、R軸側の微小安定残差として読まれる。

### 5.2 分離比

t/R 軸の分離可能性を、次で評価する。

```text
separation_ratio
  = Var_g(R_read(P, g, s)) / Var_g(t_read(P, g, s))
```

または、時系列を含めて、

```text
separation_ratio_time
  = Var_{g,s}(R_read(P, g, s)) / Var_{g,s}(t_read(P, g, s))
```

判定は次である。

| 条件 | 判定 |
|---|---|
| `separation_ratio << 1` | t/R 分離可能 |
| `separation_ratio ~ 1` | t/R 分離困難 |
| `separation_ratio > 1` | R が時間的変動として読まれ、軸分類が不安定 |

## 6. R軸微小残差の増幅検査

R軸残差は微小であるため、初回実装では読出し検証用の人工ゲインを用いる。

```text
R_gain in {1, 10, 100}
```

成功条件は次である。

1. `R_gain` を増やすと、R軸残差候補の読出し振幅が対応して増える。
2. `R_gain` を変えても、ゲージ不変性判定は保たれる。
3. `R_gain = 1` に戻したとき、同じ符号と保存傾向が残る。

このゲインは読出し検証用であり、物理的質量の増大とは主張しない。

## 7. 衝突ステージ

既存の ABC 完全弾性衝突モデルに対し、次のステージで読出しを行う。

| ステージ | 読出し目的 |
|---|---|
| `initial` | 初期保存量の基準 |
| `approach` | 衝突前の運動量的読出し |
| `collision_cell` | 相互作用セル内での読出し |
| `collision_map` | 反射写像直後の読出し |
| `post_collision` | 衝突後の保存確認 |
| `final` | 最終保存確認 |

複数回衝突実験では、各 `ab_collision` で同じ読出しを行う。

## 8. 保存判定

### 8.1 運動量的読出し

運動量的読出しは、完全弾性反射で符号反転することを要求する。

```text
p_chi_read_A_after ~= -p_chi_read_A_before
p_chi_read_B_after ~= -p_chi_read_B_before
```

また、等振幅・等速度の対称条件では、全運動量的読出しが保存されることを要求する。

```text
p_total_before ~= p_total_after
```

### 8.2 エネルギー的読出し

エネルギー的読出しは、衝突前後で保存されることを要求する。

```text
E_tau_read_A_after ~= E_tau_read_A_before
E_tau_read_B_after ~= E_tau_read_B_before
```

また、全エネルギー的読出しも保存されることを要求する。

```text
E_total_after ~= E_total_before
```

### 8.3 質量的読出し

質量的読出しは、次の条件を満たすときに測定成立とする。

```text
R_read_A_after ~= R_read_A_before
R_read_B_after ~= R_read_B_before
```

かつ、

```text
Var_g(R_read_A) <= tolerance_R_gauge
Var_g(R_read_B) <= tolerance_R_gauge
```

すなわち、R軸残差は衝突で保存され、かつ複数ゲージで安定でなければならない。

## 9. 識別保存と閉鎖保存

### 9.1 識別保存

既存実験と同じく、内部識別振動を保存する。

```text
m_A_initial = m_A_final
m_B_initial = m_B_final
```

読出し量が保存されても、識別振動が入れ替わる場合は失敗とする。

### 9.2 閉鎖保存

補償付き二乗閉鎖を保存する。

```text
Sigma x_n^2 + Sigma (i x_n)^2 ~= 0
```

閉鎖残差が閾値を超える場合、読出し量の保存が見えても測定成立としない。

## 10. 成功条件

本実験の成功条件は次である。

1. 複数ゲージから `p_chi_read` が再構成される。
2. `p_chi_read` が衝突で符号反転する。
3. 複数ゲージから `E_tau_read` が再構成される。
4. `E_tau_read` が衝突前後で保存される。
5. R軸残差 `R_read` が複数ゲージで安定に再構成される。
6. `R_read` が衝突前後で保存される。
7. `separation_ratio << 1` により t/R 分離が確認される。
8. `m_A,m_B` の識別振動が保存される。
9. 補償付き二乗閉鎖残差が閾値内に保たれる。
10. 単一ゲージ値だけでは測定成立と判定しない。

---

## 11. 破綻条件

| 破綻条件 | 意味 |
|---|---|
| `R_read` がゲージ依存になる | 質量的量として読めない |
| `R_read` が衝突で変化する | 質量的保存読出しが成立しない |
| `p_chi_read` が反射符号と一致しない | 運動量的読出しが成立しない |
| `E_tau_read` が保存しない | エネルギー的読出しが成立しない |
| `separation_ratio ~ 1` | t/R 軸分離が不十分 |
| 観測機 C のゲインや幅で結果が変わる | 観測機依存の疑い |
| 識別振動が入れ替わる | 量の保存と個体保存を区別できない |
| 閉鎖残差が閾値を超える | 閉じた系として読めていない |
| 単一ゲージ値だけで判定する | 測定ではなく内部計算値の命名に留まる |

## 13. 最小実験条件

初回は、既存の対称 ABC 完全弾性衝突条件を用いる。

| 量 | 値 |
|---|---:|
| `A_A,A_B` | `1,1` |
| `A_C` | `1000` |
| `q_A,q_B` | `+1,-1` |
| `m_A,m_B` | `1,2` |
| `v_chi` | `1` |
| `omega_A,omega_B` | `1,1` |
| 衝突回数 | `1` および `8` |

非対称振幅条件は初回主判定には含めない。

非対称条件では、単純な方向反転写像が質量的読出しを含む弾性保存形式と一致するかが別問題になるためである。

## 14. 判定の順序

判定は次の順序で行う。

1. 既存 ABC 衝突写像が成立する。
2. 識別振動が保存される。
3. 補償付き二乗閉鎖が保存される。
4. 多ゲージ干渉相関から `p_chi_read` が再構成される。
5. 多ゲージ干渉相関から `E_tau_read` が再構成される。
6. 投影を変えても残る `R_read` が再構成される。
7. `R_read` のゲージ分散が閾値内に収まる。
8. 衝突前後および複数回衝突後に保存形式が保たれる。

この順序を満たさない場合、上位の質量的・運動量的・エネルギー的読出しは成立としない。
