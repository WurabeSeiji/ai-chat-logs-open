## 1. 目的

本仕様書の目的は、AB 二体閉鎖位相系において、観測機 `C` を置かずに一角度円周位相の調和読出しが構成できるかを検査することである。

ここで扱う対象は、標準重力、標準クーロン力、標準ばね振動ではない。

検査するのは、AB 二体閉鎖対象から読まれる

```text
D_AB(s)
V_AB(s)
rho_AB(s)
theta_AB(s)
f_AB(s)
```

が、`pi` 近傍で調和的に脈動するかである。

本仕様書では、AB 合成閉鎖から読まれる補償を `f_AB` と呼ぶ。

中心方向の補償表示と、円周方向の局所射影表示を、別の力 `f_A`, `f_B` へ分けない。

## 3. 本仕様書で主張しないこと

本仕様書は、次を主張しない。

| 主張しないこと | 理由 |
|---|---|
| 標準重力の導出 | 本仕様書は一角度円周位相の調和読出し検査である |
| 標準クーロン力の導出 | 電荷軸や符号付き力を置かない |
| 標準ばね定数の導入 | `pi` 近傍の対称偏差読出しを検査するのみである |
| 逆二乗則の要求 | 一角度円周位相では逆二乗型を要求しない |
| `f_A`, `f_B` の独立導入 | AB 合成補償 `f_AB` の局所射影として扱う |
| 向心補償と `pi` 閉鎖回復の実在的分離 | AB 二体系内部では分離不能な表示多重性として扱う |
| A が観測者で B が対象であること | 観測機 C を置かず、AB のラベルなし読出しを扱う |
| 絶対背景座標の仮定 | 図中の軸と角度は読出し補助表示である |

## 4. 実験対象

AB 二体閉鎖対象を

```text
P_AB = A + B
```

とする。

この対象は、定常化後に

```math
Q(P_{AB}) = \sum_n x_n^2 \approx 0
```

を満たすものとして扱う。

ただし、公理系 v4 に従い、外部影響直後から定常化までの準定常・準安定状態の存在は否定しない。

そのため、各ステップで次を分けて記録する。

| 量 | 意味 |
|---|---|
| `Q_raw(s)` | 相互作用直後、再定常化前の閉鎖残差 |
| `Q_closed(s)` | 再定常化後の閉鎖残差 |
| `closure_relaxation(s)` | `Q_raw -> Q_closed` の回復量 |

## 5. 読出し量

### 5.1 ラベルなし二弧相対位相

AB 二体系では、どちらが観測者でどちらが対象かを固定しない。

したがって、相対位相は符号付きの単一量ではなく、

```text
D_AB(s) = { delta_AB(s), 2pi - delta_AB(s) }
```

として読む。

ここで `delta_AB(s)` は、AB 間の短弧または長弧のどちらかを先験的に指定しない相対位相差である。

### 5.2 pi 近傍対称偏差

`pi` 近傍の偏差は、符号付き `epsilon` ではなく、対称偏差

```text
V_AB(s)
```

として読む。

実装上は、例えば

```math
V_{AB}(s) = (\delta_{\min}(s) - \pi)^2
```

または、同値なラベルなし二弧偏差として読む。

重要なのは、`pi` の左側か右側かを固有名として読まないことである。

### 5.3 合成半径と円周位相

AB 合成閉鎖から、

```text
rho_AB(s)
theta_AB(s)
```

を読む。

`rho_AB(s)` は半径的読出しであり、外部の実在半径を先に置くものではない。

`theta_AB(s)` は円周位相読出しであり、外部角度座標を先に置くものではない。

### 5.4 f_AB

AB 合成閉鎖から読まれる補償を

```text
f_AB(s)
```

とする。

本実験では、中心方向の補償表示と円周方向の局所射影表示を、同じ `f_AB` の二つの読出しとして扱う。

端点側で必要な場合は、

```text
f_AB|A
f_AB|B
```

と書く。

`f_A`, `f_B` は導入しない。

## 7. 二つの中心通過表示

中心近傍の表示として、次の二つを比較する。

### 7.1 Protocol F

```text
Protocol F
```

は、反跳表示である。

中心近傍で二つの局所波が同一位置位相を占有せず、完全弾性衝突的に反転する表示として扱う。

これはフェルミオンそのものを導入する意味ではない。

AB 二体読出しで、端点同一性を保った表示を検査するための作業表示である。

### 7.2 Protocol B

```text
Protocol B
```

は、透過表示である。

中心近傍で二つの局所波が互いを通り抜ける表示として扱う。

これはボゾンそのものを導入する意味ではない。

AB 二体読出しで、端点同一性を入れ替えた表示を検査するための作業表示である。

### 7.3 比較規律

`Protocol F` と `Protocol B` が同じ

```text
D_AB(s)
V_AB(s)
rho_AB(s)
f_AB(s)
```

を与える場合、それらは AB 二体系のラベルなし読出しでは表示多重性として扱う。

差が出る場合、その差を中心近傍表示依存性として記録する。

## 8. 読出し波停止反証テスト

AB 二体系を読むために、読出し波を出す場合、系から外へ情報が読まれる。

本仕様書では、それを直ちにエネルギー流出やエントロピー増大と同一視しない。

ただし、読出し波の有無が調和読出しの振幅包絡へ影響するかは、反証テストとして検査する。

次の四条件を置く。

| readout_mode | 意味 |
|---|---|
| `readout_off` | 時系列中の能動読出し波を停止し、最小限の終端読出しのみ行う |
| `readout_weak` | 弱い読出し波で毎ステップ読む |
| `readout_normal` | 標準読出し波で毎ステップ読む |
| `readout_strong` | 強い読出し波で毎ステップ読む |

評価対象は、

```text
envelope_V_AB(s)
decay_rate_V_AB
```

である。

もし `readout_off` で減衰が消える、または有意に小さくなるなら、読出し波による外部流出候補として記録する。

もし全条件で減衰が同等なら、減衰は読出し波依存ではない候補として記録する。

## 9. 実験手順

各ケースで、次を実行する。

1. AB 二体閉鎖初期状態を生成する。
2. `D_AB(0)` を `pi` 近傍の対称二弧位相へ設定する。
3. `Protocol F` と `Protocol B` をそれぞれ選ぶ。
4. `readout_mode` を選ぶ。
5. ステップ `s=0...N` について、AB 相互閉鎖の更新を行う。
6. 相互作用直後の `Q_raw(s)` を記録する。
7. 再定常化後の `Q_closed(s)` を記録する。
8. `D_AB(s)`, `V_AB(s)`, `rho_AB(s)`, `theta_AB(s)`, `f_AB(s)` を読む。
9. `envelope_V_AB(s)` と `decay_rate_V_AB` を推定する。
10. `Protocol F/B` と `readout_mode` 間の差を比較する。

明示的に禁止する更新は次である。

```text
F = G m_A m_B / r^2
F = k x
x(s+1) = x(s) + v(s) ds
v(s+1) = v(s) + a(s) ds
```

本実験では、これらの標準力学式を実装しない。

## 11. 成功条件

本予備実験は、次を満たすとき `valid` とする。

| 条件 | 判定 |
|---|---|
| `Q_closed(s)` が全ステップで十分小さい | 閉鎖が維持される |
| `D_AB(s)` と `V_AB(s)` がラベルなしで読める | 観測者 C を置かない |
| `V_AB(s)` の脈動または安定回復が検出される | 調和読出し候補 |
| `Protocol F/B` の差が記録される | 中心近傍表示依存を隠さない |
| `readout_mode` による減衰差が記録される | 読出し波停止反証テストを行う |
| `f_A`, `f_B` を使わない | `f_AB` 作業仮説を守る |
| 絶対背景座標を使わない | 公理0.5と無名性を守る |

---

## 12. 保留条件

次の場合、本予備実験は `hold` とする。

| 条件 | 理由 |
|---|---|
| `Q_closed(s)` が大きく崩れる | 閉鎖系として読めない |
| 符号付き `epsilon` を固有名として使う | AB 二体系の無名性を破る |
| `f_A`, `f_B` を独立力として使う | `f_AB` 作業仮説を破る |
| `readout_off` が実装されない | 読出し波停止反証テストにならない |
| `Protocol F` だけ、または `Protocol B` だけを実行する | 表示多重性を検査できない |
| 逆二乗型が出ないことを失敗扱いする | 本仕様書の対象外である |

## 15. 結論

本仕様書では、観測機 `C` を置かない AB 二体閉鎖位相系において、一角度円周位相の調和読出しを検査するための実験条件を定めた。

主な検査対象は、ラベルなし二弧相対位相 `D_AB(s)`、`pi` 近傍対称偏差 `V_AB(s)`、AB 合成半径 `rho_AB(s)`、円周位相 `theta_AB(s)`、および AB 合成補償 `f_AB(s)` である。

本実験では、`f_A`, `f_B` を独立力として導入しない。

中心方向の補償表示と円周方向の局所射影表示を、同じ `f_AB` の読出しとして扱う。

また、反跳表示 `Protocol F` と透過表示 `Protocol B` を比較し、読出し波停止反証テストにより、調和読出し振幅の減衰が読出し波に依存するかを検査する。

この実験は、標準重力の導出ではない。

一角度 AB 二体系における、もっとも小さい調和読出し候補の予備実験である。
