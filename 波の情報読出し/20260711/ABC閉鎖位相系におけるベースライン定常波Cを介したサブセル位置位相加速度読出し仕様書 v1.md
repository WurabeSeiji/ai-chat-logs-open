**副題:** 外部力・背景座標・明示的並進を置かず、相互干渉と閉鎖再選別から加速度的読出しが出現するかを検査するための実験仕様  
**日付:** 2026-07-11  
**著者:** 木原 範昭  
**位置づけ:** 波の情報読出しシリーズ・数値実験仕様書

## 0. 目的

本仕様書の目的は、ABC 閉鎖位相系において、外部力、背景座標、明示的な並進更新を導入せず、局所波 `A,B` とベースライン定常波 `C` の相互干渉だけから、位置位相の二階差分に相当する加速度的読出しが構成できるかを検査することである。

前稿では、局所波 `A,B` と観測機 `C` から、多ゲージ干渉により `p_read`, `E_read`, `R_read` および `R*p`, `R*p^2` に見える保存読出しを構成した。

本仕様書では、`C` の役割を局在した読出し器から、閉鎖位相系内のベースライン定常波へ拡張する。

中心となる問いは次である。

> `A,B` の明示的な並進を止めたまま、`A-C`, `B-C`, `A-B` の相互干渉と `Σx_n^2=0` の閉鎖再選別を反復したとき、サブセル位置位相の蓄積偏位 `δχ_read(s)` が残り、その二階差分 `a_read(s)` が力を受けた運動のように読めるか。

本稿では、この加速度的読出しを標準重力そのものとは呼ばない。

ただし、相互干渉により位置位相が曲がり、その曲がりが `R_read` により重み付けされるなら、重力的相互作用との対応写像を構成する候補になる。

## 1. 前提

### 1.1 基本公理

本仕様書は、基本公理系 v2 と、公理1の読出し多重性に関する定義補足を前提とする。

中心となる閉鎖条件は次である。

```math
\sum_n x_n^2=0
```

これは共役ノルムではない。

```math
\sum_n |x_n|^2
```

ではない。

また、第一原理層で特定成分だけを負符号軸にする条件を置かない。

負に見える寄与は、外部計量の符号ではなく、内部位相の二乗、補償対、または読出し表示から現れるものとして扱う。

### 1.2 既存成果

本仕様書は、次の既存結果を利用する。

| 既存結果 | 本仕様での使い方 |
|---|---|
| `χ,τ` は背景座標ではなく位相読出しである | 位置位相 `χ_read` を外部座標と同一視しない |
| `p_read,E_read,R_read` は多ゲージ干渉から読める | 加速度読出しも単一ゲージ値にしない |
| 非対称 `R` 条件で `R*p`, `R*p^2` 保存写像が成立する | 加速度候補を `R*a` 関係で検査する |
| `R` は安定残差として読まれる | 重力的効果の重みを先験的質量ではなく `R_read` とする |
| 公理1は単一で、読出し表示が多重である | 加速度も追加公理ではなく読出し表示として扱う |

## 2. 本仕様書で主張しないこと

本仕様書は、次を主張しない。

| 主張しないこと | 理由 |
|---|---|
| 標準重力の導出 | 本仕様は加速度的読出しの構成検査である |
| ニュートン重力定数 `G` の導入 | 相互作用強度は内部結合係数として掃引する |
| 背景空間における距離の仮定 | 距離は位相差読出しとして扱う |
| 外部力 `F` の仮定 | 位置位相偏位が干渉から出るかを検査する |
| 明示的な運動方程式 `χ(t+dt)=χ(t)+vdt` の導入 | 加速度を作り込まないため禁止する |
| 単一ゲージでの加速度測定 | 測定成立は多ゲージ再構成に限る |
| `C` を外部観測者とすること | `C` は同じ閉鎖位相系内の定常波である |
| セルをまたぐ大きな移動を要求すること | 目的はサブセル位置位相偏位の蓄積検出である |

本仕様の主張候補は、閉鎖位相系内部の相互干渉から、加速度的に振る舞うサブセル位置位相読出しを構成できるかである。

## 3. 中心仮説

### 3.1 作業仮説

本仕様書の作業仮説は次である。

```text
外部力なし
背景座標なし
明示的並進なし
相互干渉あり
閉鎖再選別あり
```

この条件で、

```text
Q_after ≈ 0
δχ_after ≠ 0
```

が成立するなら、閉鎖条件は回復しているが、位置位相の読出し偏位は残存している。

この残存偏位の時系列

```text
δχ_read(P, s)
```

から、

```text
a_read(P, s) = Δ^2 δχ_read(P, s) / Δs^2
```

を読む。

### 3.2 期待される物理的読み

この読出しが成立する場合、次の対応が候補になる。

| 読出し | 物理的に見える量 |
|---|---|
| `δχ_read` | 位置位相偏位 |
| `Δδχ_read` | 速度的読出し |
| `Δ^2δχ_read` | 加速度的読出し |
| `R_read` | 質量的重み |
| `R_read * a_read` | 力的または相互作用収支的読出し |

ただし、この段階では標準物理量との同一視は行わない。

## 4. 重要な禁止事項

本実験では、加速度を実装で作り込まないため、次を禁止する。

```text
χ_A(s+1) = χ_A(s) + v_A(s) Δs
χ_B(s+1) = χ_B(s) + v_B(s) Δs
v_A(s+1) = v_A(s) + a_A(s) Δs
v_B(s+1) = v_B(s) + a_B(s) Δs
F = m a
F = G m_A m_B / r^2
```

位置、速度、加速度、力を外部から更新式として入れない。

許される更新は、相互干渉、閉鎖再選別、多ゲージ読出し、読出し値の次ステップへの反映だけである。

## 5. 系の構成

### 5.1 局所波 A, B

局所波 `A,B` は、既存の ABC 系と同様に、空間位相 `χ`、時間位相 `τ`、内部識別位相 `η`、代表振幅、内部識別モードを持つ。

初期条件では、並進速度を明示的に与えない。

```text
χ_A(0) = χ_A0
χ_B(0) = χ_B0
Δχ_A_external = 0
Δχ_B_external = 0
```

ここで `external` は、実装側で直接足し込む並進更新を意味する。

### 5.2 ベースライン定常波 C

前稿までの `C` は、局在した読出し器として使われた。

本仕様では、`C` を閉鎖位相系内のベースライン定常波として扱う。

最小候補は次である。

```math
C_0(\chi,\tau)
=
\sum_{k \in K}
w_k
\exp i(k\chi-\Omega_k\tau+\phi_k)
+
w_k
\exp i(-k\chi-\Omega_k\tau-\phi_k)
```

これは左右対称の定常波対であり、初期状態では空間方向の一方的な流れを持たない。

`K` は倍音集合である。

```text
K = {1, 3, 5, ... , k_max}
```

奇数倍音を基本候補とするのは、既存の局在読出し器との連続性を保つためである。

### 5.3 相互干渉の向き

本仕様では、相互作用を一方向に限定しない。

最低限、次の経路を区別して記録する。

```text
C -> A
C -> B
A -> C
B -> C
A -> B
B -> A
```

この区別が重要である。

`C -> A` と `C -> B` だけでは、観測波が局所波を動かしただけなのか、閉鎖位相系内の相互干渉として位置位相が再選別されたのかを区別できない。

## 6. 1ステップ更新の仕様

各ステップ `s` で、次を順に実行する。

### 6.1 相互干渉の計算

各ペア `P,Y` について、干渉項を計算する。

```text
I_{P<-Y}(s)
```

ここで、

```text
P,Y ∈ {A,B,C}
P ≠ Y
```

である。

干渉強度は、少なくとも次に依存させる。

| 項目 | 意味 |
|---|---|
| `ε_{P<-Y}` | 結合強度 |
| `R_Y_read` | 影響源側の安定残差読出し |
| `Δχ_{PY}` | 位置位相差読出し |
| `Δτ_{PY}` | 時間位相差読出し |
| `K_C` | C の倍音集合 |
| `window_g` | 読出しゲージ窓 |

この段階では、標準距離や標準ポテンシャルを仮定しない。

距離らしい量が必要な場合も、位相差読出しから構成する。

### 6.2 仮更新状態の生成

相互干渉後の仮状態を作る。

```text
A_raw(s+1)
B_raw(s+1)
C_raw(s+1)
```

この仮状態は、一般に閉鎖条件を完全には満たさない可能性がある。

したがって、仮閉鎖残差を記録する。

```text
Q_raw(s+1) = Σ x_raw,n(s+1)^2
```

### 6.3 閉鎖再選別

仮状態に対して、全正符号ゼロ閉鎖を回復する最小再選別を行う。

```text
(A,B,C)_closed(s+1)
=
Π_Q((A,B,C)_raw(s+1))
```

ここで `Π_Q` は、特定軸を負符号軸として特権化しない閉鎖再選別演算である。

再選別後の残差を記録する。

```text
Q_closed(s+1) = Σ x_closed,n(s+1)^2
```

合格条件は、

```text
|Q_closed| << |Q_raw|
```

かつ、

```text
|Q_closed| < ε_Q
```

である。

### 6.4 多ゲージ読出し

閉鎖再選別後の状態から、複数ゲージで `χ_read` を読む。

```text
χ_read(P,g,s+1)
```

ゲージ平均および安定成分として、

```text
χ_read(P,s+1)
δχ_read(P,s+1)
R_read(P,s+1)
```

を得る。

### 6.5 次ステップへの反映

次ステップの初期状態は、外部運動方程式ではなく、閉鎖再選別後の読出し状態から構成する。

許される更新は次である。

```text
state(s+1) = readout_reembedded((A,B,C)_closed(s+1))
```

禁止される更新は次である。

```text
χ_P(s+1) = χ_P(s) + v_P Δs
```

## 7. 読出し量

### 7.1 サブセル位置位相偏位

セル番号または巻数レベルの大きな移動を要求しない。

局所波 `P` の位置位相偏位は、初期読出し位置からのサブセル偏位として定義する。

```text
δχ_read(P,s)
=
wrap_subcell(χ_read(P,s)-χ_read(P,0))
```

ここで `wrap_subcell` は、セルをまたがない範囲の位相偏位を読む処理である。

想定される効果は極めて微小であり、巻数レベルでは見えない可能性が高い。

### 7.2 速度的読出し

速度的読出しは、位置位相偏位の一階差分である。

```text
vχ_read(P,s)
=
[δχ_read(P,s+1)-δχ_read(P,s-1)] / (2Δs)
```

これは標準速度ではない。

位置位相偏位の差分読出しである。

### 7.3 加速度的読出し

加速度的読出しは、位置位相偏位の二階差分である。

```text
aχ_read(P,s)
=
[δχ_read(P,s+1)-2δχ_read(P,s)+δχ_read(P,s-1)] / Δs^2
```

数値ノイズが大きい場合は、局所二次フィットを併用する。

```text
δχ_read(P,s+j)
≈
c_0 + c_1 j + c_2 j^2
```

このとき、

```text
aχ_read ≈ 2c_2 / Δs^2
```

と読む。

### 7.4 R重み付き加速度収支

重力的相互作用候補として、次を測る。

```math
S_a(s)
=
R_A(s)a_{\chi,A}(s)
+
R_B(s)a_{\chi,B}(s)
```

合格候補は、

```text
S_a(s) ≈ 0
```

である。

また、非対称 `R` 条件では、

```math
\frac{a_{\chi,A}}{a_{\chi,B}}
≈
-
\frac{R_B}{R_A}
```

が成立するかを確認する。

これは標準重力の証明ではない。

`R_read` が質量的重みとして働くかを調べる読出し判定である。

### 7.5 実験全体の三段階構成

本実験は、最初から単一の統合実験として成功させることを目指さない。

むしろ、すべての候補効果が同時に綺麗に成立する場合は、読出し器依存、実装上の作り込み、または共通ドリフトを疑う必要がある。

したがって、本仕様では次の三段階で進める。

| 段階 | 目的 | 主な判定 |
|---|---|---|
| Stage I | 候補効果の粗計量 | 引力的・反力的候補の符号、桁、スケーリングを個別に測る |
| Stage II | 同時多読出し | 微小ドリフトまたは複数効果が混在する場合に、同一状態から観測ベクトルを読む |
| Stage III | 別観測法照合 | 観測方法依存ではないかを、独立した読出し経路で検査する |

Stage I では、多少強めの結合を許す。

目的は標準重力的な精密性ではなく、候補効果の指紋を取ることである。

候補は少なくとも次に分ける。

| 記号 | 候補効果 | 予想される読出し |
|---|---|---|
| `R1` | C読出し器反力 | `C` 参照に依存した `δχ` |
| `R2` | C定常波圧による反力 | `C` 圧の向きに応じた離反傾向 |
| `R3` | A-B直接干渉反力 | `A-B` 距離位相の増大 |
| `G1` | `τ`方向 `E_read` 勾配による `χ`方向補償 | `R*aχ ≈ -∂χE_read` |
| `G2` | 閉鎖定常波ポテンシャルの谷への復元 | 山を越えない摂動が谷へ戻る |
| `G3` | サブ巻数ビート/alias による見かけの接近 | detuning 符号で見かけ速度が反転 |
| `G4` | C残渣を介した遅延接近 | persistent C でのみ残る遅延応答 |

Stage I で、どれか一つの引力的候補が桁違いに大きく、対照条件でも安定に同じ符号を示すなら、その候補を本命として Stage III の別観測法照合へ進む。

どの候補も同程度であり、ドリフトが微小である場合は、Stage II の同時多読出しへ進む。

Stage II では、同じ状態スナップショットから、次の観測ベクトルを同時に読む。

```text
Y(s)
=
[
d_AB,
d_AC,
d_BC,
δχ,
δτ,
E_read,
∂χE_read,
beat_phase,
unwrap_phase,
principal_branch_phase,
Q_raw,
Q_closed,
R_read,
η_identification
]
```

複数の観測を別々の時刻で行うと、前の観測の残渣を次の観測が読んでしまう可能性がある。

したがって、Stage II では、状態を固定したうえで読出しだけを分岐させる。

```text
state(s) を固定
  -> readout set 1
  -> readout set 2
  -> readout set 3
```

この frozen fanout 読出しでは、読出し結果を次ステップへ戻さない。

戻入を含む実験は、別途 persistent/reset 条件として分ける。

Stage III では、同じ候補効果を別観測法で照合する。

最低限、次の三系列を分ける。

| 観測系列 | 内容 | 期待される一致 |
|---|---|---|
| 相対位相系列 | `d_AB = arg(O_B/O_A)` の縮小・拡大 | 引力的なら `|d_AB|` が縮む |
| 時間位相系列 | `δτ_read`, `E_read`, `∂χE_read` | `R*aχ ≈ -∂χE_read` と符号が合う |
| ビート系列 | `φ_P-φ_C` の detuning 読出し | detuning 反転で見かけ符号が反転する |

同じ符号、同じ桁、同じ `R` 依存が複数観測系列で再現される場合に限り、観測方法依存ではない候補として扱う。

一つの観測系列でだけ成立する場合は、重力的読出し候補ではなく、観測方法依存の読出し効果として保留する。

## 8. 実験フェーズ

### 8.1 Phase 0: ベースライン無結合

相互干渉をすべて切る。

```text
ε_{P<-Y}=0
```

期待結果は次である。

| 量 | 期待 |
|---|---|
| `δχ_read` | ドリフトなし |
| `aχ_read` | ゼロ |
| `Q_closed` | ゼロ |
| 多ゲージ分散 | 数値誤差範囲 |

このフェーズは、数値実装そのものがドリフトを作っていないかを確認する。

### 8.2 Phase 1: 読出し器影響のみ

`C` を読出しに使うが、`A,B` の状態へフィードバックしない。

目的は、観測波の読出し操作そのものが `δχ` を作るかを測ることである。

期待結果は次である。

```text
δχ_read ≈ 0
aχ_read ≈ 0
```

もしここで大きな偏位が出る場合、それは重力的相互作用ではなく読出し器擾乱である。

### 8.3 Phase 2: Cのみ変形

`A,B` が `C` を歪ませるが、`C` から `A,B` へは戻さない。

```text
A -> C
B -> C
C -> A = off
C -> B = off
A <-> B = off
```

目的は、ベースライン定常波 `C` が局所波によりどの程度歪むかを測ることである。

ここでは `A,B` の位置位相偏位は原則として残らない。

### 8.4 Phase 3: Cを介した片側戻入

`A,B` が `C` を歪ませ、その歪んだ `C` が `A,B` に戻る。

```text
A -> C
B -> C
C -> A
C -> B
A <-> B = off
```

目的は、媒介波 `C` だけで位置位相偏位が生じるかを確認することである。

この段階で `δχ_A, δχ_B` が互いに向かう向きに蓄積するなら、重力的読出し候補になる。

### 8.5 Phase 4: A-B直接相互作用追加

`A-B`, `B-A` の直接干渉も入れる。

```text
A -> C
B -> C
C -> A
C -> B
A -> B
B -> A
```

目的は、完全な相互干渉系で加速度的読出しが維持されるかを見ることである。

### 8.6 Phase 5: 閉鎖再選別検査

各ステップで次を比較する。

```text
Q_raw
Q_closed
δχ_raw
δχ_closed
```

重要判定は次である。

```text
Q_closed ≈ 0
δχ_closed remains nonzero
```

もし `Q_closed` と同時に `δχ_closed` も消えるなら、閉鎖再選別が重力的候補を完全に打ち消している。

もし `Q_closed` は消えるが `δχ_closed` が残るなら、閉鎖条件は回復しても、位置位相偏位は読出しとして残存している。

本仕様の最重要検査はここである。

### 8.7 Phase 6: 別観測法照合

Stage I または Stage II で有望な候補が見えた場合、同じ候補を別観測法で照合する。

このフェーズの目的は、観測方法依存のドリフトを、重力的読出し候補から分離することである。

最低限、次を比較する。

```text
direct_relative_phase:
  d_AB = arg(O_B/O_A)

time_phase_gradient:
  ∂χE_read

beat_alias_readout:
  unwrap arg(exp(i(φ_P-φ_C)))

closure_residual_readout:
  Q_raw -> Q_closed 後に残る δχ_closed
```

同じ候補が、複数観測法で同じ符号、同程度の桁、同じ `R` 依存を示す場合、観測方法依存ではない候補として保持する。

逆に、特定の観測法でだけ現れる場合は、次のように分類する。

| 条件 | 分類 |
|---|---|
| 相対位相系列だけで見える | A-B読出し枝依存の可能性 |
| 時間位相系列だけで見える | `τ`方向変調候補だが `χ`力学との接続は保留 |
| ビート系列だけで見える | タイヤ逆転型 alias 候補 |
| closure residual だけで見える | 閉鎖再選別依存の残差候補 |

Phase 6 での目的は、候補を否定することではない。

目的は、どの読出し経路で成立し、どの読出し経路では成立しないかを分類することである。

## 9. 幾何空間整合の検算

### 9.1 検算の目的

本実験は、第一には位相空間内の読出し実験である。

しかし、加速度的読出しが得られた場合、次の疑問が生じる。

> 位相空間で読まれた加速度候補は、幾何空間側の曲率半径読出しと整合するのか。

この検算では、標準重力方程式を導入しない。

目的は、位相空間で得た `aχ_read` の符号、相対比、`R` 依存が、局所的な合成曲率半径読出しから見ても矛盾しないかを確認することである。

### 9.2 自己項内部閉鎖に基づく外部源分離

`A,B,C` はそれぞれ `R_read` を持つ。

加速度的読出しが出るなら、各局所波は局所的な曲率半径読出しも持つ可能性がある。

本節では、定義補足論文「閉鎖複素位相波における自己項の内部閉鎖とN体外部読出し分離に関する定義補足」の N 体外部読出し分離を用いる。

同補足に従い、定常閉鎖後の外部並進・加速度読出しでは、

```text
P_i <- { P_j | j ≠ i }
```

として読む。

したがって、本仕様書の ABC 系では次のように扱う。

```text
A が受ける幾何効果: (B+C) の合成曲率半径
B が受ける幾何効果: (A+C) の合成曲率半径
C が受ける幾何効果: (A+B) の合成曲率半径
```

これは自己項を捨てる操作ではない。自己項は、各局所波の内部閉鎖読出しとして保持される。

外部源から分離されるのは、定常閉鎖後の巨視的な並進・加速度読出しにおける自己項の再入力である。

なお、この分離は定常閉鎖状態に限る。

相互作用直後、`Q_raw` が大きい状態、準安定遷移中、外部流入・流出中には、自己項と外部項の分離は未確定であり、過渡的自己項漏れとして別途記録する。

### 9.3 合成曲率源の定義

前節の N 体外部読出し分離

```text
P_i <- { P_j | j ≠ i }
```

に従い、対象 `P` に対する外部源集合を次で定義する。

```text
S_A = {B, C}
S_B = {A, C}
S_C = {A, B}
```

ここで `S_P` は、`P` 自身を含まない外部読出し源集合である。

この定義は、定義補足論文「閉鎖複素位相波における自己項の内部閉鎖とN体外部読出し分離に関する定義補足」に基づく。

なお、この処理は定常閉鎖状態に限る。

相互作用直後、`Q_raw` が大きい状態、準安定遷移中、外部流入・流出中には、`S_P` による外部源分離を確定したものとして使わず、自己項漏れと外部項の混在を別途記録する。

各源 `Y` の曲率源強度を `K_Y` とする。

`K_Y` は、この段階では標準質量でも標準曲率でもない。

`R_read(Y)` から構成される幾何検算用の読出し重みである。

最小実装では、まず次を試す。

```text
K_Y = R_read(Y)
```

必要に応じて、曲率半径型の読出しとして、

```text
K_Y = 1 / ρ_read(Y)
```

も比較する。

対象 `P` が見る合成曲率源強度は、

```text
K_eff(P)
=
Σ_{Y∈S_P} K_Y
```

とする。

対応する有効曲率半径を読む場合は、

```text
ρ_eff(P)
=
1 / K_eff(P)
```

とする。

これは検算用の表示であり、公理1に外部負符号や固有名付き曲率軸を追加するものではない。

### 9.4 合成曲率中心

幾何空間側の方向検算には、合成曲率源の中心を読む必要がある。

絶対位相原点を置かないため、通常の線形平均ではなく、円周位相上の重み付き平均を使う。

対象 `P` に対する合成源中心を、

```math
\chi_{\mathrm{eff},P}
=
\arg
\left(
\sum_{Y\in S_P}
K_Y e^{i\chi_Y}
\right)
```

と読む。

対象 `P` から合成源中心への相対位相を、

```math
d_{P|\mathrm{eff}}
=
\arg
\left(
e^{i(\chi_{\mathrm{eff},P}-\chi_P)}
\right)
```

とする。

引力的候補なら、`aχ_read(P)` は `d_{P|eff}` を縮める向きと整合する必要がある。

斥力的候補なら、`d_{P|eff}` を広げる向きと整合する。

### 9.5 幾何検算用の予測符号

合成曲率中心に向かう向きを、

```text
sign_geom(P) = sign(d_{P|eff})
```

とする。

位相空間で読んだ加速度の符号を、

```text
sign_phase(P) = sign(aχ_read(P))
```

とする。

引力的候補では、

```text
sign_phase(P) ≈ sign_geom(P)
```

を期待する。

斥力的候補では、

```text
sign_phase(P) ≈ -sign_geom(P)
```

を期待する。

ただし、ビート alias 型では見かけ符号が反転し得る。

そのため、幾何検算では次を併記する。

```text
sign_phase_unwrapped
sign_phase_principal_branch
sign_phase_beat
```

この三つの符号が一致しない場合は、幾何不整合ではなく、読出し枝またはビート反転候補として分類する。

### 9.6 三体問題を解かない検算

本検算は、ABC 三体問題を厳密に解くものではない。

むしろ、三体問題を次の三つの `2+1` 検算へ分解する。

```text
A <- (B+C)
B <- (A+C)
C <- (A+B)
```

各検算で、位相空間で得た加速度候補が、自分自身を除いた合成曲率源の向き、強度、`R` 依存と矛盾しないかを見る。

これにより、次を確認する。

| 検算 | 確認内容 |
|---|---|
| 自己項内部閉鎖 | 自分自身の `R_read` が内部閉鎖読出しに属し、定常閉鎖後の外部並進源として再入力されていない |
| 合成源方向 | `aχ_read(P)` が `S_P` の合成中心方向と整合する |
| 合成源強度 | `K_eff(P)` が大きいほど効果が大きいか |
| R比整合 | `R_A a_A + R_B a_B + R_C a_C` の全体系収支が小さいか |
| 読出し枝整合 | unwrap, principal branch, beat の符号差を分類できるか |

### 9.7 幾何検算の失敗条件

次の場合、位相空間で加速度候補が出ても、幾何空間整合は保留する。

| 条件 | 解釈 |
|---|---|
| 自己項を外部源として再入力しないと符号が合わない | 自己項内部閉鎖ではなく自己力混入で成立している可能性 |
| `χ_eff,P` の向きと `aχ_read(P)` が全く相関しない | 幾何空間側の相互作用候補ではない |
| `K_eff(P)` と効果の桁が無相関 | R/曲率重みとの接続が弱い |
| `C` が極端に大きい条件でのみ成立 | 既存の重い観測機近似に依存している可能性 |
| unwrap と beat で符号が逆になる | 幾何不整合ではなく読出し枝反転として再分類する |

この検算に通らない場合でも、位相空間内の読出し効果そのものは否定しない。

ただし、幾何空間の加速度または重力的対応写像としては保留する。

## 10. 掃引実験

### 10.1 結合強度掃引

内部結合強度を掃引する。

```text
ε_C ∈ {0, 1e-8, 1e-7, 1e-6, 1e-5, 1e-4}
```

期待する判定は、`δχ_read` および `aχ_read` が `ε_C` に対して単調または冪的に増えることである。

ただし、大きすぎる `ε_C` では読出し器擾乱が支配的になる可能性がある。

### 10.2 R比掃引

前稿と同様、`R_B/R_A` を掃引する。

```text
R_B/R_A ∈ {1/64, 1/16, 1/4, 1, 4, 16, 64}
```

検査対象は次である。

```text
R_A a_A + R_B a_B ≈ 0
```

および、

```text
a_A/a_B ≈ -R_B/R_A
```

である。

### 10.3 位相距離掃引

初期位置位相差を掃引する。

```text
Δχ_AB(0)
```

距離らしい依存性が見えるかを確認する。

ただし、この段階では `1/r^2` を仮定しない。

まずは、近いほど偏位が大きいか、遠いほど偏位が小さいかという単調性を検査する。

### 10.4 倍音上限掃引

`C` の倍音上限を掃引する。

```text
k_max ∈ {1, 3, 5, 9, 17, 33, 65, 129}
```

目的は、倍音を上げるほどサブセル偏位の読出し分解能が上がるかを調べることである。

予想は次である。

| 条件 | 予想 |
|---|---|
| 低倍音 | 偏位が滑らかだが分解能が低い |
| 中倍音 | サブセル偏位が読みやすい |
| 過大倍音 | 巻数レベルの平均では相殺され、加速度的蓄積が見えにくくなる可能性 |

倍音を上げることは、物理的な移動を大きくする操作ではない。

微小な位置位相偏位を読む位相顕微鏡として扱う。

### 10.5 ゲージ反転検査

読出しゲージを左右反転する。

```text
g -> mirror(g)
```

真のサブセル偏位読出しなら、反転規則に従って符号が反転し、保存収支は保たれるはずである。

ゲージ反転で偏位が消える、または任意に変わる場合、それは読出し器依存の擾乱である。

## 11. 判定基準

### 11.1 最小成立条件

最小成立条件は次である。

| 条件 | 判定 |
|---|---|
| Phase 0 で `aχ_read ≈ 0` | 数値ドリフトなし |
| Phase 1 で `aχ_read ≈ 0` | 読出し器単独擾乱ではない |
| Phase 3 以降で `δχ_read` が蓄積 | C媒介相互作用候補 |
| `Q_closed ≈ 0` | 閉鎖条件維持 |
| `δχ_closed ≠ 0` | 閉鎖再選別後も位置位相偏位が残る |
| `R_A a_A + R_B a_B ≈ 0` | R重み付き加速度収支候補 |
| Stage I で候補効果の符号と桁が分離される | 粗計量成立 |
| Stage III で複数観測法の符号が一致する | 観測方法依存でない候補 |
| `A <- (B+C)`, `B <- (A+C)`, `C <- (A+B)` の幾何検算が符号整合する | 位相空間と幾何空間の対応候補 |
| 単一ゲージ判定なし | 多ゲージ読出し成立 |

### 11.2 失敗条件

次の場合、加速度的読出しの構成は失敗または保留とする。

| 失敗条件 | 解釈 |
|---|---|
| Phase 0 で有意なドリフト | 実装ドリフト |
| Phase 1 で有意な加速度 | 観測波擾乱 |
| `Q_closed` がゼロに戻らない | 閉鎖系として不成立 |
| `δχ_closed` が完全に消える | 閉鎖再選別が効果を打ち消す |
| `R_A a_A + R_B a_B` が系統的に破れる | R重み付き相互作用ではない |
| ゲージごとに符号や大きさが任意に変わる | 多ゲージ読出し不成立 |
| 全候補効果が同時に同符号で成立する | 共通ドリフトまたは実装作り込みを疑う |
| 一つの観測法でだけ成立する | 観測方法依存として保留 |
| 自己項を外部源として再入力しないと幾何符号が合わない | 自己力混入として保留 |

## 14. 次の実装順序

実装は、次の順で進める。

1. ベースライン定常波 `C_0` の生成器を作る。
2. Phase 0 の無結合ドリフト検査を行う。
3. Phase 1 の読出し器影響検査を行う。
4. `A,B -> C` のみの C 歪み検査を行う。
5. Stage I として `R1-R3`, `G1-G4` の候補効果を個別に粗計量する。
6. 桁違いに大きい候補があるかを判定する。
7. 候補が混在する場合、Stage II として frozen fanout による同時多読出しを行う。
8. `C` の persistent/reset 条件を分け、残渣効果を検査する。
9. 閉鎖再選別前後の `Q` と `δχ` を同時記録する。
10. `aχ_read` を二階差分および局所二次フィットで読む。
11. `R_A a_A + R_B a_B` を検査する。
12. Stage III として相対位相系列、時間位相系列、ビート系列、閉鎖残差系列で別観測法照合を行う。
13. 自己項内部閉鎖に基づき、`A <- (B+C)`, `B <- (A+C)`, `C <- (A+B)` の幾何検算を行う。
14. `ε_C`, `R_B/R_A`, `Δχ_AB`, `k_max` の掃引を行う。
15. 統合サマリーを作成する。

## 15. 現時点の重要な注意

本実験で最も危険なのは、加速度を実装者が作ってしまうことである。

したがって、最初に見るべきものは「加速度が出たか」ではない。

最初に見るべきものは次である。

```text
その加速度候補は、どの対照条件では消えるか。
```

Phase 0 と Phase 1 で消え、Phase 3 以降で現れ、閉鎖再選別後にもサブセル偏位として残り、R重み付き収支を満たす場合に限り、加速度的読出し候補として扱う。

また、本実験では、すべての候補効果が同時にうまく成立することを成功とはみなさない。

引力的読出し候補、反力的読出し候補、読出し器擾乱、C残渣、ビート alias は、互いに混在し得る。

したがって、最初に必要なのは、統一的な成功判定ではなく、候補効果ごとの符号、桁、遅延、観測方法依存の分離である。

特に、観測方法依存の疑いがある場合は、同一状態からの frozen fanout 読出し、および Stage III の別観測法照合を必須とする。

この順序を守れば、本実験は「重力を仮定した実装」ではなく、「相互干渉から重力的に見える読出しが出るかを調べる実装」になる。
