## 1. 深追いしない前提

Part 02 では、無名性をより深く追った。

しかし、これを根源まで追うと、何が何を区別しているのかという問いが無限降下し、物理的な実験計画ではなく哲学論に近づく。

したがって、本稿ではそれ以上は深追いしない。

ここでは、これまでの実験系列で実際に役立ってきた構造だけを整理する。

---

## 2. ABC 系の中心投影読み

閉鎖条件を、

```text
sum x_n^2 = 0
```

として置く。

ABC 三体系では、これをまず有効読出しとして、

```text
A^2 + B^2 + C^2 = R^2
```

と読むことができる。

これは、ABC 関係を中心投影半径 `R` へ読むことに対応する。

ここでの `R` は、外部空間に置かれた絶対半径ではない。

`R` は、閉じた ABC 関係全体から読まれる代表関係量である。

---

## 3. R のベース振動

ABC 全体が閉じた関係系であるなら、代表関係 `R` にはベース振動がある。

閉じた系では、一周位相は閉じなければならない。

したがって、安定に読める内部成分 `A, B, C` は、`R` のベース振動に対して任意の振動数を持つのではなく、整数倍の関係として読まれる。

すなわち、

```text
theta_A = n_A theta_R + phi_A
theta_B = n_B theta_R + phi_B
theta_C = n_C theta_R + phi_C
```

または振動数で書けば、

```text
omega_A = n_A omega_R
omega_B = n_B omega_R
omega_C = n_C omega_R
```

である。

波長で書けば、

```text
lambda_R = n_A lambda_A
lambda_R = n_B lambda_B
lambda_R = n_C lambda_C
```

と読める。

つまり、`A, B, C` は `R` の倍音である。

---

## 4. A, B, C は原始名ではない

この整理では、`A, B, C` は原始的な名前ではない。

それらは、閉じた代表関係 `R` の中で安定に読める倍音成分である。

したがって、これまでの ABC 実験で `A, B, C` を用いて処理したことは、厳密な意味で第 0 原理から全て導出されたわけではない。

しかし、それらは任意に外から貼ったラベルでもない。

閉鎖条件と中心投影読みの下では、`A, B, C` は `R` の倍音として閉じる。

このため、無名性を完全に解決していなくても、ABC 系の読出しは有効な階層で成立していたと整理できる。

---

## 5. 閉鎖倍音フラクタル

さらに、`A, B, C` もそれぞれ閉じた系として読める。

すなわち、

```text
R
  -> A, B, C
       -> A_1, A_2, ...
       -> B_1, B_2, ...
       -> C_1, C_2, ...
```

という再帰構造を持つ。

親系の代表振動に対して、子系の読出し成分は倍音として現れる。

さらに、その子系もまた閉じた代表関係を持ち、その内部成分を倍音として読むことができる。

この意味で、閉鎖関係系は倍音階層としてフラクタルに展開する。

---

## 6. 既存論文の位置づけ

これまでの論文では、`A, B, C` を実装上の成分として扱ってきた。

これは、最深部の無名性から見れば未導出の有効記法である。

しかし、`sum x_n^2 = 0` の閉鎖条件と中心投影読みを採用すると、`A, B, C` は `R` の倍音階層として自然に閉じる。

したがって、既存論文の主張を変更する必要はない。

むしろ、既存論文でうまく閉じていた理由は、背後にこの閉鎖倍音階層があったためだと読める。

---

## 7. 公理候補

以上から、次の公理候補を置くことができる。

```text
任意の閉鎖関係系 S には、代表関係 R_S が読まれる。
S の内部で安定に読める成分 X_i は、R_S の整数倍音として現れる。
さらに X_i 自身も閉鎖関係系として読める場合、
X_i は新たな代表関係 R_Xi を持ち、
その内部成分もまた R_Xi の整数倍音として読まれる。
```

式で書けば、

```text
theta_Xi = n_i theta_Rs + phi_i
n_i in Z
```

である。

この公理候補は、無名性の問題を完全に消すものではない。

しかし、無限降下へ進む前に、閉鎖系の実験計算で使える有効階層を与える。

---

## 8. 含意

この整理では、`A, B, C` は外から貼った名前ではなく、閉鎖関係 `R` の倍音として読まれる有効成分である。

そのため、ABC 系での処理は、最深部の無名性をまだ完全には解いていないとしても、閉鎖倍音階層の中では物理的意味を持つ。

今後、奇数倍音、局在性、フェルミオン型・ボゾン型の区別を整理する場合も、それらはまずこの倍音階層の中で読まれるべきである。

この意味で、本メモは、以後の公理系に接続しうる強い候補である。

---

## 9. 二段階相互作用と断面読出し

閉鎖倍音階層の上で、相互作用は一段の加算ではなく、二段の写像として読む。

基本形は、

```text
(A, B) -> (A', B')
```

である。

ただし、これは単に固定行列を外から与える写像ではない。

まず、`A, B` の関係性から散乱行列を読む。

```text
S_AB = F(A, B)
```

次に、その散乱行列を入射チャネルに作用させる。

```text
(A', B')^T = S_AB (A, B)^T
```

したがって、全体写像は、

```text
(A', B')^T = F(A, B)(A, B)^T
```

である。

`S_AB` が固定行列なら、この写像は線形である。

しかし、`S_AB` 自身が `A, B` の関係性から読まれるなら、全体写像は一般に非線形である。

このとき干渉は二つに分かれる。

```text
行列生成干渉:
  A, B の関係性から S_AB = F(A, B) を読む干渉。

行列作用干渉:
  得られた S_AB を (A, B) に作用させ、
  出射チャネル (A', B') を作る干渉。
```

## 10. 衝突断面の内部読出し

この整理では、衝突断面を第一原理的な外部面積として置かない。

衝突断面は、

```text
F(A, B) の内部結合が、
外部入出力統計として読まれた量
```

である。

`F(A, B)` の内部に、有効結合を、

```text
g_AB
```

として読む。

例えば、

```text
S_AB = S(g_AB, Delta_AB, spectrum_AB)
```

であり、

```text
g_AB = G(overlap_AB, harmonic_alignment_AB, phase_relation_AB, localization_AB)
```

と読む。

このとき、反射率や透過率は、

```text
R_AB = |S_AB,reflection|^2
T_AB = |S_AB,transmission|^2
```

として読まれる。

また、衝突断面に相当する外部量は、

```text
sigma_AB ~ < |S_AB,reflection|^2 >
```

または、

```text
sigma_AB
~ measure{(A, B) | g_AB >= g_c}
  / measure{all admissible (A, B)}
```

として読める。

ここで `g_c` は、交換散乱チャネルが有効に立つ閾値である。

したがって、断面とは、

```text
どれくらいの外部面積で当たるか
```

ではなく、

```text
F(A, B) がどれくらい強い散乱行列を生成するか
```

の外部読出しである。

---

## 11. フェルミオン型とボゾン型の差

ボゾン型は、同じ状態を共有できる波として読む。

この場合、干渉は線形重ね合わせとして扱える。

```text
(A, B) -> A + B -> (A, B)
```

すなわち、重なった後に再分離できる。

一方、フェルミオン型は、同じ状態を共有できない波として読む。

この場合、`A, B` の関係性から交換散乱行列が生成され、

```text
(A', B')^T = F_F(A, B)(A, B)^T
```

となる。

ここでは、出射波 `A', B'` は、単なる `A, B` の再分離ではない。

反射、反跳、局在性移乗、波形更新が残る。

したがって、

```text
ボゾン型:
  線形干渉。
  共有可能。
  再分離可能。

フェルミオン型:
  状態依存散乱。
  共有不可。
  非線形更新。
```

として分類できる。

この差は、波の名前の差ではない。

`F(A, B)` がどの内部結合 `g_AB` を生成し、どの散乱行列 `S_AB` を返すかの差である。

---

## 12. 公理候補

以上から、次の公理候補を置く。

```text
閉鎖関係系における二体相互作用は、
入射波 A, B を直接足す操作ではなく、
A, B の関係性から散乱行列 S_AB = F(A, B) を読み、
その S_AB を A, B に作用させる二段階写像である。
```

さらに、

```text
衝突断面は独立した外部幾何量ではなく、
F(A, B) の内部結合 g_AB が、
入出力統計として読まれた有効量である。
```

この整理では、モデル内部の無次元結合率を、

```text
alpha_model
~ measure{(A, B) | g_AB >= g_c}
  / measure{all admissible (A, B)}
```

として読むことができる。

これは、標準理論の微細構造定数そのものを導出したという主張ではない。

ここで得られるのは、閉鎖倍音階層と交換散乱写像から読まれる、モデル内部の有効結合率である。
