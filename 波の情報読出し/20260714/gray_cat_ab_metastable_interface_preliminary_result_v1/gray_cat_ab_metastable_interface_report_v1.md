## 3. 判定

AB二体だけで、灰色猫固有相、灰色猫準安定相、大振幅振動領域、自然選択相が分離して観測された。

灰色猫準安定相は、C/Dを入れる後続実験の候補領域として使用できる。

自然選択相は、CなしDなしでA/Bへ落ちるため、観測による選択実験には使用しない。
