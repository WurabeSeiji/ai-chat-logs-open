# 白猫・黒猫・灰色猫を、閉じた波の系で読んでみた

新しい論文を公開しました。

今回のテーマは、白猫・黒猫・灰色猫です。

といっても、本物の猫を扱っているわけではありません。

ここでいう白猫と黒猫は、閉じた波の系の中にある二つの状態を、分かりやすく呼んだものです。

白猫状態を A。

黒猫状態を B。

その中間に見える状態を、灰色猫と呼びます。

今回調べたのは、かなり有名な問題に近い問いです。

箱の中の猫は、白なのか。

黒なのか。

それとも、観測するまでは白でも黒でもないような状態なのか。

ただし、今回の実験では、標準的なシュレディンガーの猫そのものを再現した、とは言いません。

もっと限定した問いを調べています。

背景の時空すら先に置かない閉じた複素位相系の中で、白と黒の配分が半々に近い状態を作り、その状態を弱く読むとどう見えるのか、強く観測するとどう変わるのかを数値実験しました。

## 何を調べたのか

今回のモデルには、A と B という二つの状態があります。

A が強ければ白猫。

B が強ければ黒猫。

A と B が同じくらいなら灰色猫。

このように読みます。

重要なのは、A と B が外から見える札のように置かれているわけではないことです。

このシリーズでは、背景空間や時間を先に置かず、複素数の波、位相、干渉、読出し波の関係だけで、位置のように見える量、時間のように見える量、加速度のように見える量を構成してきました。

今回も同じです。

白猫、黒猫、灰色猫も、外からラベルを貼るのではなく、閉じた系の中の波の配分として読みます。

実験は三段階です。

まず、A と B だけの系を作ります。

次に、C という弱い読出し波を置きます。

最後に、D という強い観測波を置きます。

ここで C も D も、人間の観測者ではありません。

どちらも、系の中に置いた波です。

C は弱く読む波。

D は強く観測する波。

この違いを使って、灰色猫が壊れずに読めるのか、それとも白猫か黒猫へ落ちるのかを調べました。

## 三つの代表的なパターン

今回の実験で見えた代表的なパターンは、次の三つです。

![白猫・黒猫・灰色猫 AB-ABC-ABCD 状態遷移図](gray_cat_state_transition_figures_v1/gray_cat_ab_abc_abcd_three_scenarios_v1.png)

一つ目は、準安定な灰色猫です。

AB の段階では、白と黒が混じったような状態を作ります。

C で弱く読むと、その状態は壊れず、白と黒が混じった状態として読めます。

しかし D で強く観測すると、白猫または黒猫へ落ちます。

二つ目は、灰色猫固有相です。

これは、白と黒の中間に見えるだけではなく、強く観測しても灰色のまま残る状態です。

強く見たら必ず白か黒へ落ちる、というわけではありませんでした。

三つ目は、C が強すぎる場合です。

C は本来、弱く読むための波です。

しかし C の結合が強すぎると、D を置く前に、ABC の段階ですでに白猫または黒猫へ落ちます。

つまり、C と D は本質的に別種類の特別な装置ではありません。

弱く読むか、強く作用するか。

その強さによって、読出しにもなり、選択にもなります。

## 灰色猫は一種類ではなかった

今回いちばん面白かったのは、灰色猫が一種類ではなかったことです。

見かけ上、白と黒が半々に見える状態でも、二つに分かれました。

一つは、灰色猫準安定相です。

弱く読むと灰色のまま読めます。

しかし強く観測すると、白または黒へ落ちます。

もう一つは、灰色猫固有相です。

弱く読んでも灰色。

強く観測しても灰色。

この場合は、白と黒のどちらかへ落ちるというより、灰色そのものが一つの状態として成立しているように見えます。

この区別は、単なる言葉遊びではありません。

実際に計算された値でも、三つのパターンは分かれました。

![白猫・黒猫・灰色猫 実測値 AB-ABC-ABCD 遷移](gray_cat_observed_value_transition_figures_v1/gray_cat_ab_abc_abcd_observed_values_three_scenarios_v1.png)

上段では、C で弱く読んでいる間は中間状態が保たれ、D が入ったところで片側へ落ちます。

中段では、D が入っても中間状態が保たれます。

下段では、C が強すぎるため、D の前に片側へ落ちています。

この三つが同じグラフ上で分かれたことが、今回の実験の一番大きな収穫です。

## 読むことと、選ぶことは同じではない

普通の言い方では、「観測すると状態が決まる」と言われます。

しかし今回の結果を見ると、少し丁寧に言い直した方がよさそうです。

弱く読むだけなら、灰色猫準安定相を壊さずに読める場合がありました。

強く観測すると、同じ準安定相が白または黒へ落ちる場合がありました。

つまり、読めることと、選択を起こすことは同じではありません。

ただし、観測と相互作用が完全に別物だと言いたいわけでもありません。

このモデルでは、観測も相互作用の一種です。

C も D も、外から覗く人間ではなく、系の中に置いた波です。

弱く相互作用すれば、状態を壊さずに読めることがある。

強く相互作用すれば、状態を白または黒へ押し出すことがある。

今回の結果は、そのように読むのが自然です。

## 白猫になったら、黒猫はいなくなるのか

ここも大事な点です。

今回の実験で白猫へ落ちた場合、それは白猫と黒猫の二匹に分裂した、という意味ではありません。

白側の配分がほぼ一杯になり、黒側の配分がほとんど消えた、という意味です。

黒猫へ落ちた場合は、その逆です。

ただし、閉じた系なので、全体量は保存されます。

外から何かが突然消えたり増えたりするのではありません。

A と B の配分が、片側へ強く寄る。

その寄った状態を、白猫または黒猫として読んでいます。

## 何を主張していないか

誤解を避けるために、ここははっきり書いておきます。

今回の論文は、標準的な量子力学の測定問題を一般に解いたものではありません。

本物の猫が白と黒の重ね合わせになる、と主張しているわけでもありません。

シュレディンガーの猫の完全な物理モデルを作った、という意味でもありません。

今回確認したのは、もっと限定されたことです。

閉じた複素位相系の中で、A/B 配分が灰色に見える状態を作り、その状態が弱い読出しでは保たれ、強い観測では白または黒へ落ちる条件がある。

さらに、灰色に見える状態の中には、強く観測しても灰色のまま残るものがある。

この範囲の主張です。

## まとめ

今回の数値実験では、白猫・黒猫・灰色猫という比喩を使って、閉じた波の系における準安定状態と観測応答を調べました。

結果は、かなり面白いものでした。

灰色猫に見える状態は一種類ではありませんでした。

弱く読むと灰色のまま読めるが、強く観測すると白または黒へ落ちる準安定相がありました。

一方で、強く観測しても灰色のまま保たれる固有相もありました。

さらに、読出し波 C が強すぎると、D を置く前に白または黒へ落ちました。

つまり、このモデルで見えているのは、「観測者が特別だから状態が決まる」という話ではありません。

系の中の波どうしの相互作用が弱ければ読むだけになり、強ければ選択を起こす。

その境界を、白猫・黒猫・灰色猫という形で読んだ実験です。

もちろん、まだ予備実験です。

でも、波束収縮や観測問題のような難しい問いを、背景時空を先に置かない閉じた系の中で、実験可能な相図として読み直す入口としては、かなり面白い結果になったと思っています。
