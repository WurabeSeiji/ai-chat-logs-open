# 木原による衝突定義と計算例

**日付：** 2026-07-10

**重要な発見：直接自乗 vs 共役自乗の根本的な違い**

---

## 【観測前の A0 状態定義】

### A1 の定義（極座標表現）

```
A1 = A(r,θ) = A(1, 0°)
   = cos(0°) + i·sin(0°)
   = 1 + 0i
   = 1
```

### A2 の定義（極座標表現）

```
A2 = A(r,θ) = A(1, 60°)
   = cos(60°) + i·sin(60°)
   = 0.5 + i·0.8660
```

---

## 【A0 の計算方法の比較】

### 方法1：直接自乗（本ビジョン）

```
A0 = Σ Ak²  
   = A1² + A2²
   = 1² + (0.5 + i0.8660)²
```

**詳細計算：**
```
(0.5 + i0.8660)² = 0.5² + 2(0.5)(i0.8660) + (i0.8660)²
                 = 0.25 + i0.866 - 0.75
                 = -0.5 + i0.866
```

**結果：**
```
A0 = 1 + (-0.5 + i0.866)
   = 0.5 + i0.866

特徴：複素数、虚部（干渉項）を保持
```

---

### 方法2：共役を使った二乗（標準理論）

```
a0 = Σ |Ak|²  = Σ Ak·Āk
   = A1·Ā1 + A2·Ā2
   = 1·1 + (0.5 + i0.8660)(0.5 - i0.8660)
```

**詳細計算：**
```
(0.5 + i0.8660)(0.5 - i0.8660) = 0.5² + 0.8660²
                                = 0.25 + 0.75
                                = 1.0
```

**結果：**
```
a0 = 1 + 1
   = 2.0

特徴：実数のみ、干渉項が消失
```

---

## 【根本的な違いの本質】

| 項目 | 直接自乗（A0 = ΣAk²） | 共役自乗（a0 = Σ\|Ak\|²） |
|------|----------------------|--------------------------|
| **結果** | 0.5 + i0.866 | 2.0 |
| **形式** | 複素数 | 実数 |
| **干渉項** | 2iab（保存） | なし（消失） |
| **物理的意味** | 隠れた状態 | 観測可能な強度 |

## 【B1（マスタークロック）の定義】

```
B1 = B(r,θ) = B(0.1, 10°)
   = 0.1·cos(10°) + 0.1i·sin(10°)
   = 0.09848 + i0.01736
```

B1 は B0 系のマスタークロック。小さな振幅（r=0.1）で基準位相を提供。

---

## 【衝突前の相互作用】

### A1 と B1 の干渉

```
A1' = A1 + B1
    = 1 + (0.09848 + i0.01736)
    = 1.09848 + i0.01736
```

### A2 と B1 の干渉

```
A2' = A2 + B1
    = (0.5 + i0.8660) + (0.09848 + i0.01736)
    = 0.59848 + i0.88336
```
