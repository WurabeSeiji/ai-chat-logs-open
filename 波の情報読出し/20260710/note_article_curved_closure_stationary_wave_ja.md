# 曲率は消えたのではなく、閉じた波の中へ織り込まれていたのかもしれない

新しい論文を公開しました。

今回のテーマは、少し不思議です。

ふつう、曲がった空間の中に波を置けば、波はその曲率の影響を受けるはずです。位相もずれる。干渉も変わる。完全にそろっていた反射条件にも、少し漏れが出るはずです。

では、なぜ多くの物理モデルでは、局所的には平坦だとみなして、非常に高い精度で計算できるのでしょうか。

曲率の影響は、本当に小さいから無視できるだけなのでしょうか。

それとも、安定に存在している波そのものが、すでに曲率の影響を内部に吸収した状態として読まれているのでしょうか。

今回の論文は、この問いを、私の波の情報読出しシリーズの基本公理から数値的に調べたものです。

中心にある条件は、全正符号ゼロ閉鎖です。

Σ x_n^2 = 0

これは、共役ノルムの和ではありません。

|x_n|^2 を足すのではなく、各成分 x_n をそのまま二乗して、全正符号で足し合わせたものがゼロになる、という条件です。

## 今回調べたこと

前回の論文では、完全弾性反射の方向反転を、外部から

q → -q

と命令するのではなく、フェルミオン的な内部逆相核と交換経路の干渉から生成しました。

つまり、反射は外部命令ではなく、内部逆相核、直接経路と交換経路、偶奇チャンネル干渉、相対位相 π から生じる読出しになりました。

今回の問いは、その次です。

この交換干渉反射を、曲率をもつ局所セルに置いたらどうなるのか。

曲率によって相対位相が少し漏れたら、完全反射は壊れるのか。

それとも、閉じた定常波として安定に残る条件が、曲率の漏れを内部へ織り込んで、反射を回復するのか。

## 曲率は最初から消していない

今回、曲率を「無視できる」とは置いていません。

むしろ、曲率由来の相対位相漏れを、明示的に入れました。

閉鎖ペアを x_m と i x_m とします。

ここに、曲率による相対位相漏れ δ_K,m が入ると、二乗和は一般にゼロではなくなります。

文章で書くと、x_m の二乗と、位相漏れを受けた i x_m の二乗を足すと、1 - exp(i 2δ_K,m) に比例する残差が出ます。

つまり、曲率の影響はちゃんと出ます。

閉鎖条件が破れ、反射にも通過漏れが出ます。

ここが大事です。

今回の結果は、「曲率の影響はない」という話ではありません。

曲率の影響はあります。過渡状態では見えます。

## 驚きは、その後にある

ところが、内部位相を再選別して、曲率による漏れ δ_K,m と内部補正 β_K,m が打ち消し合う状態に戻すと、閉鎖条件が回復しました。

つまり、δ_K,m + β_K,m = 0 となる閉鎖定常波へ戻すと、残差が消えます。

このとき、曲率が消えたわけではありません。

曲率による相対位相漏れが、安定に存在できる波の内部位相へ吸収された、と読むべきです。

言い換えると、曲率の影響は外から見えなくなったのではなく、閉じた波として存在するための内部条件に織り込まれた可能性があります。

これは、かなり面白い結果でした。

なぜなら、局所的に平坦に見えるということを、単に「小さい領域だから曲率を無視できる」と読むのではなく、

「曲率込みで閉じる定常波だけが、安定な読出しとして残っている」

と読む道が出てくるからです。

## 数値実験で何が起きたか

最小実験では、曲率相対位相漏れを入れた過渡状態で、閉鎖ペア RMS は 1.2319416790092972e-02、通過漏れは 1.1503183254481797e-01 になりました。

つまり、反射は完全ではなくなります。

しかし、閉鎖定常波へ再選別した後は、閉鎖ペア RMS は 9.4283259783636047e-19、通過漏れは 0.0 まで回復しました。

さらに、8種類の曲率相対位相モデルと、7種類の補正自由度を掃引しました。

最大曲率相対位相 1.2 に対して、無補正では最大通過漏れ 1.6202719613622976e-01 が残りました。

一方で、各倍音に対応できる full 補正では、閉鎖ペア RMS は 7.8949412793793227e-19、通過漏れは 0.0 まで戻りました。

片側入射の局所交換干渉写像に戻しても、同じ構造が確認できました。

無補正では通過漏れが出る。

閉鎖定常波として再選別されると、完全反射読出しが回復する。

## 何がそんなに重要なのか

今回の中心は、Σ x_n^2 = 0 という条件です。

これは、共役ノルム Σ |x_n|^2 ではありません。

各成分をそのまま二乗して、全正符号で足し合わせたものがゼロになる、という条件です。

最小ペアでは、A^2 + (iA)^2 = 0 となります。

外から負符号を入れなくても、複素位相 i によって、二乗和の中で符号反転が内部生成されます。

この公理は、単なる保存条件ではありませんでした。

今回の実験では、少なくとも次の役割を同時に持っていました。

・非自明な複素波が存在する条件

・曲率相対位相漏れを検出する条件

・閉鎖定常波へ再選別する条件

・完全反射読出しを安定化する条件

一つの条件が、これだけの役割を持ってしまう。

ここに、今回の一番大きな驚きがあります。

## これは何を主張していないか

誤解を避けるために、はっきり書いておきます。

今回の論文は、実在時空の曲率効果を定量予言するものではありません。

一般相対論を導出したものでも、標準量子論を置き換えるものでもありません。

また、「曲率は常に観測不能である」と主張しているわけでもありません。

むしろ逆です。

曲率相対位相漏れを入れると、過渡状態では閉鎖残差と通過漏れが出ます。

そのうえで、閉鎖定常波として安定に存在できる状態では、その漏れが内部位相へ繰り込まれ、外部読出しでは完全反射が回復する、という構成を確認しました。

## まとめ

今回のシミュレーションでは、曲率付き局所セルに置いた奇数倍音の複素波が、曲率相対位相漏れを受けると、いったん閉鎖条件を破り、完全反射にも漏れを出すことを確認しました。

しかし、系が Σ x_n^2 = 0 を満たす閉鎖定常波へ再選別されると、曲率相対位相漏れは内部位相へ吸収され、完全反射読出しが回復しました。

曲率はなかったことにされたのではない。

曲率は、閉じた波として存在するための内部位相構成へ織り込まれていたのかもしれない。

まだこれは、標準理論との対応写像を作る前の、内部公理系上の数値構成実験です。

それでも、局所平坦性を「近似」としてだけでなく、「安定な閉鎖定常波の読出し」として考える道が、少し見えてきた気がしています。
