# ここまでの複合波公理系

## 公理1：無名等振幅複合波公理

複合波は、初期合成振幅 \(A_0\) を持つ一つの系が、\(N\) 個の同振幅成分へ分解された波群である。

\[
\boxed{
\Psi_N
=
\frac{A_0}{N}
\sum_{k=1}^{N}e^{i\theta_k}
}
\]

各成分の振幅は

\[
\boxed{
|\psi_k|=\frac{A_0}{N}
}
\]

で等しい。

個別成分には固有名を与えない。  
振幅差による識別も許さない。

---

## 公理2：合成振幅保存公理

\(N\) 個の成分がすべて同相に整列したとき、複合波の合成振幅は初期振幅 \(A_0\) に等しい。

\[
\boxed{
\max_{\{\theta_k\}}
\left|
\sum_{k=1}^{N}\psi_k
\right|
=
A_0
}
\]

したがって、成分振幅は

\[
\boxed{
\frac{A_0}{N}
}
\]

でなければならない。

この公理により、成分数 \(N\) を増やしても、合成振幅が発散しない。

---

## 公理3：個別位相不可読公理

個別位相

\[
\theta_k
\]

そのものは、単独では読めない。

全体位相変換

\[
\theta_k\rightarrow \theta_k+\alpha
\]

は、内部構造を変えない。

したがって、絶対位相は内在的観測量ではない。

---

## 公理4：位相差読出し公理

観測可能な内部構造は、個別位相ではなく、成分間の位相差である。

\[
\boxed{
\Delta_{ij}
=
\theta_i-\theta_j
}
\]

読出し可能な位相差関係数は最大で

\[
\boxed{
\binom{N}{2}
=
\frac{N(N-1)}{2}
}
\]

である。

ただし、これは独立自由度数ではなく、区別可能な位相差関係数である。

---

## 公理5：系同一視公理

同じ初期合成振幅 \(A_0\) と同じ読出し可能な位相差構造を持つ二つの系は、区別不能であり、一つの系として同一視される。

\[
\boxed{
(A_0,\{\Delta_{ij}\})
\text{ が同じなら、同一系として扱う}
}
\]

ここで \(A_0\) は個別波の名前ではなく、系全体の保存量である。

---

## 公理6：反転対称性破れ許容公理

複合波は、一般には反転対称性を要求されない。

反転対称性は、正逆の位相進行成分が等重みで対応する特殊配置においてのみ現れる。

\[
\boxed{
\Psi(-x)=\Psi(x)
}
\]

は一般公理ではなく、特殊解である。

したがって、一般の複合波では

\[
\boxed{
\Psi(-x)\neq \Psi(x)
}
\]

を許す。

この公理により、位相進行の向き、因果方向、読出し方向を基本構造から消さない。

---

## 公理7：外部軸応答公理

スピン的情報は、複合波単体の内在値ではない。

スピンに相当する情報は、外部測定軸または外部基準波との相関読出しによって初めて定義される。

外部軸を

\[
\alpha
\]

とすれば、スピン的読出しは

\[
\boxed{
S(\alpha)
=
\mathcal{R}(\Psi,M_\alpha)
}
\]

のような応答関数である。

つまり、

\[
\boxed{
スピン = 複合波と外部軸の相関読出し
}
\]

であり、複合波単体に隠れた上向き／下向き値があるわけではない。

---

## 公理8：外部読出し位相公理

位置・時間・スピンに相当する値は、複合波単体に内在する絶対情報ではない。

それらは、外部読出し波または測定基準との相互作用によって、相対位相として初めて定義される。

位置位相については、

\[
\boxed{
\phi_x,\phi_y,\phi_z
}
\]

時間位相については、

\[
\boxed{
\phi_t
}
\]

を考える。

ただし、これらは内在座標ではなく、外部読出し波との相対位相である。

\[
\boxed{
\Delta\phi_\mu
=
\phi_\mu^{(\Psi)}
-
\phi_\mu^{(M)}
}
\]

\[
\mu=x,y,z,t
\]

したがって、

\[
\boxed{
x,y,z,t
}
\]

は複合波が最初から持つ絶対ラベルではなく、読出し位相差から再構成された値である。

---

## 公理9：時間位相仮説

時間に相当する情報は、時間座標そのものではなく、時間方向の読出し位相

\[
\boxed{
\phi_t}
\]

として現れる可能性がある。

単純には、

\[
\boxed{
\phi_t=\omega t \pmod{2\pi}
}
\]

である。

ただし、読出し構造によっては、

\[
2\pi
\]

周期だけでなく、

\[
4\pi
\]

周期、あるいは巻き数を含む被覆位相として読まれる可能性がある。

つまり、

\[
0^\circ,\ 180^\circ,\ 360^\circ,\ 720^\circ
\]

の区別は、読出し系が巻き数または被覆構造を保存する場合に意味を持つ可能性がある。

# 補助定義：分類統計

これは公理というより、複合波の分類量です。

## 規格化合成振幅

\[
\boxed{
\rho_N
=
\frac{1}{N}
\left|
\sum_{k=1}^{N}e^{i\theta_k}
\right|
}
\]

\[
0\le \rho_N\le 1
\]

---

## フェルミオン度、または逆相度

\frac{2}{N(N-1)}
\sum_{i<j}
\sin^2
\frac{\Delta_{ij}}{2}
}
\]

\[
F_N=0
\]

なら純粋ボソン的。

\[
N=2,\quad F_2=1
\]

なら純粋フェルミオン的。

\[
0<F_N<1
\]

ならエルミオン的。

---

## ボソン度

# しかし、まだ説明できないこと

おっしゃる通り、ここまでの公理だけでは、

\[
\boxed{
なぜ観測できる位相が離散値になるのか}
\]

は説明できません。

現状では、

\[
\theta_k,\quad
\Delta_{ij},\quad
\phi_x,\phi_y,\phi_z,\phi_t
\]

はいずれも連続値を取り得ます。

したがって、

\[
\boxed{
観測可能な位相は離散量である
}
\]

を導くには、追加の公理または保存量が必要です。

---

# 不足していると思われるもの

ここで不足しているのは、おそらく単なる位相差ではなく、

\[
\boxed{
位相を閉じる保存量
}
\]

です。

たとえば候補は次のようなものです。

## 候補1：閉路位相保存量

位相差ネットワークの任意の閉路について、

\[
\boxed{
\sum_{\text{cycle}}\Delta\phi
=
2\pi m
}
\]

\[
m\in\mathbb{Z}
\]

のような閉路条件がある。

これは、観測位相が連続値ではなく、整数巻き数に拘束される可能性を与えます。

---

## 候補2：読出し位相セル保存量

観測可能な位相は、読出し系との相互作用で、最小位相セル

\[
\epsilon_\phi
\]

の整数倍としてしか固定されない。

\[
\boxed{
\phi_{\mathrm{obs}}
=
m\epsilon_\phi
}
\]

\[
m\in\mathbb{Z}
\]

この場合、離散性は複合波単体ではなく、読出し相互作用の分解能または保存セルから来る。

---

## 候補3：総位相巻数保存量

複合波全体に、位相巻数

\[
\boxed{
W=\frac{1}{2\pi}\oint d\phi}
\]

が保存される。

\[
W\in\mathbb{Z}
\]

この保存量があると、位相そのものは連続でも、観測可能な状態遷移は巻数の整数変化に制約されます。

---

## 候補4：面積位相保存量

これまでのあなたの系列から見ると、単純な線位相ではなく、

\[
\boxed{
位相差の面積
}
\]

または

\[
\boxed{
二乗和
}
\]

に保存量がある可能性もあります。

たとえば、

\[
\boxed{
Q_\phi
=
\sum_{i<j}
\sin^2\frac{\Delta_{ij}}{2}
}
\]

あるいは、

\[
\boxed{
\sum_{\mu}
\phi_\mu^2
=
\text{const.}
}
\]

のような量です。

これは、観測位相が単なる連続角ではなく、閉じた保存量の断面として離散化する可能性を持ちます。

---

# 現時点の結論

ここまでの公理系だけでは、位相はまだ連続量です。

したがって、次に必要なのは、おそらく次のどれかです。

\[
\boxed{
閉路条件
}
\]

\[
\boxed{
巻数保存
}
\]

\[
\boxed{
最小読出しセル
}
\]

\[
\boxed{
位相面積保存
}
\]

\[
\boxed{
読出し相互作用における整数化条件
}
\]

です。

公理候補としては、まずこう置くのが一番自然に見えます。

\[
\boxed{
\textbf{観測位相離散性公理：}
観測可能な位相は連続値として直接読まれず、読出し相互作用において保存される閉路位相または巻数により、離散値としてのみ固定される。
}
\]

ただし、この公理の背後にはさらに、

\[
\boxed{
何が保存されるから離散化するのか
}
\]

を与える必要があります。
