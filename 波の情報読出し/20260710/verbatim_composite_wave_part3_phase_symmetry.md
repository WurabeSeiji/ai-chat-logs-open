# 複合波 公理化会話ログ Part 3
## 合成位相・並進対称性・反転対称性・反転対称性破れ許容公理

---

## User
ここです、複合波には独立？した自由度として振幅 = A0/N があります。
では合成した位相θは定義できるのでしょうか？

## Assistant
はい。ここは非常に重要です。

結論から言うと、**複合波全体の合成位相 \(\Theta\) は定義できます。**  
ただし、それは各成分に最初から与えられた独立の位相ではなく、

\[
\boxed{
N個の位相ベクトルを合成した結果として生じる有効位相
}
\]

です。

複合波を

\[
\Psi_N
=
\frac{A_0}{N}
\sum_{k=1}^{N}e^{i\theta_k}
\]

と定義しました。

このとき、合成された複素数

\[
S_N=\sum_{k=1}^{N}e^{i\theta_k}
\]

を置けば、

\[
\Psi_N=\frac{A_0}{N}S_N
\]

です。

ここで \(S_N\neq 0\) なら、複合波全体は極形式で

\[
\Psi_N
=
R_N e^{i\Theta_N}
\]

と書けます。

したがって、

\[
\boxed{
R_N=
\frac{A_0}{N}
\left|
\sum_{k=1}^{N}e^{i\theta_k}
\right|
}
\]

\[
\boxed{
\Theta_N=
\arg
\left(
\sum_{k=1}^{N}e^{i\theta_k}
\right)
}
\]

です。

つまり、合成位相 \(\Theta_N\) は定義できます。

---

ただし、ここで注意が必要です。

\[
\Theta_N
\]

は、個別成分の位相

\[
\theta_k
\]

と同じ種類の自由度ではありません。

個別成分の位相は、無名ルールのもとでは直接読めない。  
読めるのは位相差

\[
\Delta_{ij}=\theta_i-\theta_j
\]

です。

一方、合成位相 \(\Theta_N\) は、全成分を合成したあとに外部へ現れる、複合波全体の代表位相です。

したがって、

\[
\boxed{
個別位相は内部変数
}
\]

\[
\boxed{
位相差は内部関係
}
\]

\[
\boxed{
合成位相は外部読出し位相
}
\]

です。

この三つを分ける必要があります。

---

例で見ると分かりやすいです。

### 1. 全部同位相の場合

\[
\theta_1=\theta_2=\cdots=\theta_N=\theta
\]

なら、

\[
S_N=Ne^{i\theta}
\]

なので、

\[
\Psi_N=A_0e^{i\theta}
\]

です。

この場合、

\[
R_N=A_0
\]

\[
\Theta_N=\theta
\]

です。

つまり、全成分がそろっているとき、複合波は元の単一波と同じように読めます。

---

### 2. 位相がばらけている場合

例えば N=2 で、

\[
\theta_1=\theta+\frac{\delta}{2}
\]

\[
\theta_2=\theta-\frac{\delta}{2}
\]

なら、

\[
\Psi_2
=
\frac{A_0}{2}
\left(
e^{i(\theta+\delta/2)}
+
e^{i(\theta-\delta/2)}
\right)
\]

\[
=
A_0\cos\frac{\delta}{2}e^{i\theta}
\]

です。

このとき、

\[
R_2=A_0\left|\cos\frac{\delta}{2}\right|
\]

です。

合成位相は基本的に

\[
\Theta_2=\theta
\]

ですが、\(\cos(\delta/2)\) が負になる領域まで含めるなら、\(\pi\) ずれをどう扱うかが出ます。

特に、

\[
\delta=\pi
\]

なら、

\[
R_2=0
\]

なので、

\[
\Psi_2=0
\]

です。

この場合、

\[
\boxed{
合成位相は定義不能
}
\]

です。

なぜなら、振幅ゼロの複素数には偏角がないからです。

---

ここが非常に重要です。

\[
\boxed{
複合波の合成位相は、合成振幅がゼロでない場合にだけ定義できる。
}
\]

つまり、

\[
\sum_{k=1}^{N}e^{i\theta_k}\neq 0
\]

なら定義可能。

\[
\sum_{k=1}^{N}e^{i\theta_k}=0
\]

なら定義不能です。

---

これは、複合波モデルではかなり意味があります。

合成位相が定義できる状態は、外部から一つの波として読める状態です。

\[
\boxed{
外部読出し可能な複合波
}
\]

です。

一方、合成振幅がゼロになる状態は、内部には位相差ネットワークがあるが、外部へは単一波として出てこない。

\[
\boxed{
内部関係はあるが、外部合成位相を持たない複合波
}
\]

です。

これは非常に面白いです。

---

したがって、複合波には二種類の位相があります。

### 外部位相

\[
\Theta_N=
\arg
\left(
\sum_{k=1}^{N}e^{i\theta_k}
\right)
\]

これは、複合波全体として外へ読める位相。

ただし、合成振幅がゼロなら定義不能。

---

### 内部位相差

\[
\Delta_{ij}=\theta_i-\theta_j
\]

これは、複合波内部にある関係構造。

合成振幅がゼロでも、内部位相差は存在し得る。

---

この区別はかなり重要です。

つまり、

\[
\boxed{
合成位相 \Theta_N は、内部位相差ネットワークの射影結果である。
}
\]

です。

合成位相は独立自由度ではありません。  
内部位相差の配置から決まる有効量です。

---

さらに重要な点があります。

全体位相を一斉にずらすと、

\[
\theta_k\rightarrow\theta_k+\alpha
\]

なら、

\[
S_N\rightarrow e^{i\alpha}S_N
\]

したがって、

\[
\Theta_N\rightarrow \Theta_N+\alpha
\]

です。

一方で、内部位相差は変わりません。

\[
\Delta_{ij}\rightarrow\Delta_{ij}
\]

つまり、

\[
\boxed{
内部構造は位相差で不変
}
\]

\[
\boxed{
外部読出し位相は全体回転で変わる
}
\]

です。

このため、複合波を閉じた内部系として見るなら、\(\Theta_N\) は絶対的意味を持ちません。  
しかし、外部の参照波に対して読むなら、\(\Theta_N\) は意味を持ちます。

---

したがって、答えはこう整理するのがよいです。

\[
\boxed{
複合波には、成分ごとの共通振幅 A_0/N がある。
}
\]

\[
\boxed{
内部構造としては、位相差 \Delta_{ij} がある。
}
\]

\[
\boxed{
全体として合成した結果、合成振幅 R_N と合成位相 \Theta_N が定義される。
}
\]

ただし、

\[
\boxed{
\Theta_N は \(\Psi_N\neq0\) のときのみ定義される。
}
\]

そして、

\[
\boxed{
\Theta_N は独立自由度ではなく、内部位相配置の合成結果である。
}
\]

---

ここで「複合波」の定義を少し拡張するなら、こう書けます。

\[
\boxed{
\Psi_N
=
\frac{A_0}{N}
\sum_{k=1}^{N}e^{i\theta_k}
=
R_Ne^{i\Theta_N}
}
\]

ただし、

\[
\boxed{
R_N
=
\frac{A_0}{N}
\left|
\sum_{k=1}^{N}e^{i\theta_k}
\right|
}
\]

\[
\boxed{
\Theta_N
=
\arg
\left(
\sum_{k=1}^{N}e^{i\theta_k}
\right)
\quad
\left(
\sum_{k=1}^{N}e^{i\theta_k}\neq0
\right)
}
\]

です。

この \(R_N\) は、初期振幅 \(A_0\) 以下です。

\[
0\le R_N\le A_0
\]

全同相なら、

\[
R_N=A_0
\]

完全打ち消しなら、

\[
R_N=0
\]

です。

---

したがって、複合波の状態は本質的には、

\[
\boxed{
(A_0,\ N,\ \{\Delta_{ij}\})
}
\]

で決まります。

外部へ読める射影として、

\[
\boxed{
(R_N,\Theta_N)}
\]

が現れます。

この整理が一番よいと思います。

つまり、合成位相は定義できる。  
しかしそれは内部の根本自由度ではなく、

\[
\boxed{
位相差ネットワークを外部へ一つの波として射影したときの読出し位相
}
\]

です。

---

## User
つまり複合波は、並進対称性を維持していますよね？　反転対称性も維持できていますか？

## Assistant
はい。かなり重要です。

まず、いま定義した複合波を

\[
\Psi_N
=
\frac{A_0}{N}
\sum_{k=1}^{N}e^{i\theta_k}
\]

とします。

より空間波として書くなら、

\[
\Psi_N(x)
=
\frac{A_0}{N}
\sum_{k=1}^{N}e^{i(k_0 x+\theta_k)}
\]

または、同じ波数 \(k_0\) を共有する同振幅位相成分の束として読むなら、

\[
\Psi_N(x)
=
e^{ik_0x}
\frac{A_0}{N}
\sum_{k=1}^{N}e^{i\theta_k}
\]

です。

この形なら、**並進対称性は維持されています。**

なぜなら、空間を

\[
x\rightarrow x+a
\]

だけ並進すると、

\[
e^{ik_0x}\rightarrow e^{ik_0(x+a)}
=
e^{ik_0a}e^{ik_0x}
\]

となり、複合波全体に共通位相

\[
e^{ik_0a}
\]

が掛かるだけだからです。

つまり、

\[
\Psi_N(x+a)
=
e^{ik_0a}\Psi_N(x)
\]

です。

これは内部位相差

\[
\Delta_{ij}=\theta_i-\theta_j
\]

を変えません。

したがって、

\[
\boxed{
並進は複合波全体の外部位相を変えるだけで、内部位相差ネットワークを壊さない。
}
\]

この意味で、複合波は並進対称性を維持しています。

---

では、反転対称性はどうか。

ここは少し慎重に分ける必要があります。

空間反転を

\[
x\rightarrow -x
\]

とします。

すると、

\[
e^{ik_0x}
\rightarrow
e^{-ik_0x}
\]

です。

つまり、進行方向が反転します。

複合波は

\[
\Psi_N(x)
=
e^{ik_0x}
C_N
\]

と書けます。

ここで

\[
C_N=
\frac{A_0}{N}
\sum_{k=1}^{N}e^{i\theta_k}
=
R_Ne^{i\Theta_N}
\]

です。

反転すると、

\[
\Psi_N(-x)
=
e^{-ik_0x}C_N
\]

になります。

これだけを見ると、右向き波が左向き波に変わっただけです。

したがって、**単一の進行方向だけを持つ複合波は、一般には反転対称ではありません。**

つまり、

\[
\boxed{
一方向進行複合波は、並進対称性は持つが、単独では空間反転対称性を持たない。
}
\]

です。

---

ただし、ここで重要なのは、**反転対称性を維持する複合波を作ることは可能**だという点です。

そのためには、波数 \(+k_0\) と \(-k_0\) のペアを同じ重みで持たせればよい。

たとえば、

\[
\Psi_N^{(\pm)}(x)
=
\frac{A_0}{2N}
\sum_{j=1}^{N}
\left(
e^{i(k_0x+\theta_j)}
+
e^{i(-k_0x+\theta_j')}
\right)
\]

です。

反転対称にしたいなら、位相集合が反転で対応する必要があります。

もっとも単純には、

\[
\theta_j'=\theta_j
\]

と置く。

すると、

\[
e^{i(k_0x+\theta_j)}
+
e^{i(-k_0x+\theta_j)}
=
2e^{i\theta_j}\cos(k_0x)
\]

なので、

\[
\Psi_N^{(+)}(x)
=
\frac{A_0}{N}
\sum_{j=1}^{N}
e^{i\theta_j}\cos(k_0x)
\]

になります。

この場合、

\[
\cos(k_0(-x))=\cos(k_0x)
\]

なので、

\[
\Psi_N^{(+)}(-x)=\Psi_N^{(+)}(x)
\]

です。

これは偶対称、つまり反転対称です。

---

逆に、反転で符号が反転する奇対称も作れます。

\[
e^{i(k_0x+\theta_j)}
-
e^{i(-k_0x+\theta_j)}
=
2i e^{i\theta_j}\sin(k_0x)
\]

なので、

\[
\Psi_N^{(-)}(x)
=
\frac{A_0}{N}
\sum_{j=1}^{N}
e^{i\theta_j}\sin(k_0x)
\]

なら、

\[
\sin(k_0(-x))=-\sin(k_0x)
\]

より、

\[
\Psi_N^{(-)}(-x)=-\Psi_N^{(-)}(x)
\]

です。

これは反転で符号反転する奇対称です。

したがって、反転対称性には二種類あります。

\[
\boxed{
\Psi(-x)=+\Psi(x)
}
\]

という偶反転対称。

\[
\boxed{
\Psi(-x)=-\Psi(x)
}
\]

という奇反転対称。

どちらも、\(+k\) と \(-k\) の対を含めれば作れます。

---

ここで複合波の公理に戻ると、重要なのは次です。

**同振幅性は、反転対称性と相性が良い。**

なぜなら、反転対称性を保つには、反転ペア

\[
+k_0
\]

\[
-k_0
\]

の振幅が等しい必要があるからです。

つまり、

\[
\boxed{
反転対称性を維持するには、反転で対応する波成分が同振幅でなければならない。
}
\]

これは、無名等振幅複合波の考え方と自然に合います。

---

ただし、内部位相差ネットワークまで含めると、条件はもう少し厳密になります。

反転が内部成分を写像する操作だとすると、

\[
\theta_j
\rightarrow
\theta_{\pi(j)}
\]

のように、位相集合が入れ替わる可能性があります。

このとき反転対称性があるためには、位相差集合が保存される必要があります。

つまり、

\[
\boxed{
\{\theta_i-\theta_j\}
=
\{\theta_{\pi(i)}-\theta_{\pi(j)}\}
}
\]

です。

ここでも、個別位相に名前は不要です。

必要なのは、

\[
\boxed{
反転後も位相差の多重集合が同じであること
}
\]

です。

これは無名ルールに合っています。

---

したがって、答えはこう整理できます。

### 並進対称性

同じ波数 \(k_0\) を共有する複合波では、並進は全体位相を変えるだけです。

\[
\Psi_N(x+a)=e^{ik_0a}\Psi_N(x)
\]

内部位相差は変わらない。

したがって、

\[
\boxed{
複合波は並進対称性を自然に維持する。
}
\]

---

### 反転対称性

一方向進行波としての複合波は、単独では反転対称ではありません。

\[
e^{ikx}\rightarrow e^{-ikx}
\]

となり、別の進行方向へ移るからです。

しかし、\(+k\) と \(-k\) の反転ペアを同振幅で含めれば、反転対称性を維持できます。

偶対称：

\[
\Psi(-x)=+\Psi(x)
\]

奇対称：

\[
\Psi(-x)=-\Psi(x)
\]

の両方が可能です。

したがって、

\[
\boxed{
複合波は、反転ペアを同振幅で含むように構成すれば、反転対称性も維持できる。
}
\]

---

もっと木原モデル的に言えば、

\[
\boxed{
並進対称性は、複合波の全体位相自由度として自然に残る。
}
\]

\[
\boxed{
反転対称性は、複合波内部に反対向きの同振幅ペアを含めることで保存される。
}
\]

\[
\boxed{
無名ルールでは、反転対称性は個別波の名前ではなく、位相差集合が反転後も不変であることとして定義される。
}
\]

です。

ここはかなり大事です。  
なぜなら、複合波は「位相差ネットワーク」を内部情報として持ちながら、外部空間に対しては並進・反転の対称性を保つ形式に拡張できるからです。

---

## User
ん、どうなんですかね、反転対称性があるのは、通常 cos 波ですが？

## Assistant
はい。そこはあなたの感覚の方が正しいです。

**反転対称性を素直に持つのは、通常は cos 波です。**

\[
\cos(-x)=\cos x
\]

なので、cos 波は偶関数です。

一方、

\[
\sin(-x)=-\sin x
\]

なので、sin 波は反転で符号が反転する奇関数です。

つまり、

\[
\boxed{
\text{偶反転対称：}\cos kx
}
\]

\[
\boxed{
\text{奇反転対称：}\sin kx
}
\]

です。

---

複素進行波で見ると、

\[
e^{ikx}=\cos kx+i\sin kx
\]

です。

空間反転すると、

\[
e^{ik(-x)}=e^{-ikx}
\]

なので、右向き波が左向き波に変わります。

したがって、

\[
e^{ikx}
\]

単独は反転対称ではありません。

反転対称にするには、

\[
e^{ikx}
\]

と

\[
e^{-ikx}
\]

を同振幅で組みにする必要があります。

同相で足すと、

\[
e^{ikx}+e^{-ikx}=2\cos kx
\]

これは反転対称です。

逆相で引くと、

\[
e^{ikx}-e^{-ikx}=2i\sin kx
\]

これは反転で符号反転します。

---

したがって、複合波の反転対称性を考えるなら、前回の私の言い方は少し広すぎました。

より正確には、

\[
\boxed{
反転対称性を持つ複合波の基本形は、進行波ではなく、+k と -k の同振幅ペアから作られる cos 型定在波である。
}
\]

です。

つまり、複合波の最小反転対称成分は、

\[
\psi_j(x)=\frac{A_0}{N}\cos(kx+\theta_j)
\]

のように置く方が自然です。

この場合、

\[
\cos(k(-x)+\theta_j)=\cos(-kx+\theta_j)
\]

なので、\(\theta_j=0\) または \(\pi\) のように原点に対して整列していれば明確な偶対称になります。

一般の位相付き cos 波

\[
\cos(kx+\theta)
\]

は、原点 \(x=0\) に対しては必ずしも偶対称ではありません。  
ただし、中心を

\[
x_0=-\frac{\theta}{k}
\]

に取り直せば、

\[
\cos(k(x-x_0))
\]

となり、その中心に対して反転対称です。

つまり、

\[
\boxed{
cos 波は、自分の中心に対して反転対称である。
}
\]

---

ここから複合波に戻すと、かなり重要な修正が入ります。

複合波を進行波の束として定義すると、

\[
\Psi_N(x)=\frac{A_0}{N}\sum_j e^{i(kx+\theta_j)}
\]

これは並進対称性とは相性が良いですが、単独では反転対称ではありません。

一方、反転対称性を基本に置くなら、複合波は

\[
\boxed{
\Psi_N(x)=\frac{A_0}{N}\sum_{j=1}^{N}\cos(kx+\theta_j)
}
\]

または、複素表示では

\[
\boxed{
\Psi_N(x)=\frac{A_0}{2N}\sum_{j=1}^{N}
\left(
e^{i(kx+\theta_j)}
+
e^{-i(kx+\theta_j)}
\right)
}
\]

と書くべきです。

この形なら、各成分は \(\pm k\) の同振幅ペアです。

したがって、

\[
\boxed{
反転対称性を維持する複合波は、cos 型の等振幅複合波として定義するのが自然。
}
\]

です。

---

なので、ここで整理し直すなら：

\[
\boxed{
進行波型複合波：並進対称性を自然に持つ
}
\]

\[
\boxed{
cos 型複合波：反転対称性を自然に持つ
}
\]

です。
