## 現在のモデルではどう表すか

これまで自由光子を、

\[
\gamma(\chi,\tau)
=
A_\gamma S_\chi S_\tau e^{i\phi_\gamma}
\]

のような局在波として考えていました。

しかし局在しない光子なら、空間局在因子を外して、

\[
\gamma_k(\chi,\tau)
=
A_\gamma e^{i(k\chi-\omega\tau+\phi_\gamma)}
\]

または、複数モードの合成として、

\[
\gamma(\chi,\tau)
=
\sum_k a_k e^{i(k\chi-\omega_k\tau)}
\]

と置けます。

この場合、光子はどこか一点にあるのではなく、広い領域に位相構造として存在します。

フェルミオン側は局在波、

\[
F_P(\chi,\tau,\eta)
=
A_P
S_P(\chi-\chi_P)
S_P(\tau-\tau_P)
e^{im_P\eta}
e^{i\phi_P}
\]

です。

両者の相互作用強度は、局所的には、

\[
\Omega_{\gamma F}(s)
=
\iiint
F_P^*(\chi,\tau,\eta;s)
\,\gamma(\chi,\tau;s)
\,D_{\rm match}(\eta)
\,d\chi\,d\tau\,d\eta
\]

のような相関で決められます。

つまり、光子全体が局在する必要はありません。

\[
\boxed{
\text{広がった光子モードのうち、
フェルミオン局在波と位相整合する成分だけが相互作用する}
}
\]

という機構にできます。

## 吸収されるのは光子全体か

ここが重要です。

広がった光子モードに対して、一つのフェルミオンが相互作用した場合、

\[
\gamma_{\rm extended}
\longrightarrow
F_1
\]

と単純に全空間の波が一瞬で消える、と考える必要はありません。

まず光子モードを、

\[
\gamma
=
\gamma_{\parallel}
+
\gamma_{\perp}
\]

と分けます。

ここで、

\[
\gamma_{\parallel}
\]

はフェルミオンの吸収チャンネルと相関する成分、

\[
\gamma_{\perp}
\]

は直交して相互作用しない成分です。

吸収写像は、

\[
|F_0,\gamma_{\parallel}\rangle
\leftrightarrow
|F_1,0_{\parallel}\rangle
\]

にだけ作用します。

一方、

\[
\gamma_{\perp}
\]

はそのまま残ります。

つまり、

\[
\boxed{
\text{光子波全体を吸収するのではなく、
フェルミオンと整合する射影成分を内部状態へ転写する}
}
\]

と考えられます。

## 格子全体との相互作用

もし「自由格子」が、原子格子や多数のフェルミオンが並ぶ格子を意味している場合も可能です。

広がった光子モードは一つのフェルミオンだけでなく、

\[
F_1,F_2,\ldots,F_N
\]

すべてと同時に重なります。

相互作用チャンネルは、

\[
|G,\gamma\rangle
\leftrightarrow
\sum_{j=1}^{N}
c_j|F_j^{*}\rangle
\]

となります。

係数は光子位相によって、

\[
c_j
\propto
e^{ik\chi_j}
\]

のように決まります。

したがって吸収後は、どれか一つの粒子だけが外部命名によって選ばれるのではなく、

\[
\boxed{
\text{格子全体に広がった集団励起状態}
}
\]

が形成され得ます。

## 現在の無名性公理とも相性がよい

これは木原モデルの無名性と非常に相性がよいです。

外部から、

```text
この光子は粒子3に吸収される
```

とは指定しません。

代わりに、各局所波との相関、

\[
O_j
=
\int F_j^*\gamma\,d\chi d\tau
\]

が自動的に決まり、

\[
\sum_j O_j|F_j^*\rangle
\]

という集団出力になります。

どの局所波がどれだけ励起されるかは、

- 空間位相
- 時間位相
- 内部状態差
- 光子の波数
- 格子配置
- 相関の干渉

だけで決まります。

隠れた命名は不要です。

## 観測できるもの

局在していない光子の場合でも、観測可能なのは次です。

相互作用前には、

\[
\gamma_{\rm in}
\]

のモード、振動数、位相分布が読めます。

相互作用後には、

- 光子モードの減少・位相変化
- フェルミオンまたは格子の励起
- 集団励起モード
- 再放出された光子
- 入出力間の保存関係

を読めます。

したがって、

\[
\boxed{
\text{光子が局在していなくても、
光子モードと物質側状態の相互変換は観測可能}
}
\]

です。

## このモデルでの重要な拡張

自由光子を二種類に分けると整理しやすいです。

### 局在光子波束

\[
\gamma_{\rm packet}(\chi,\tau)
\]

有限領域に局在し、フェルミオンへ接近して相互作用する。

### 非局在・拡張光子モード

\[
\gamma_k(\chi,\tau)
=
A e^{i(k\chi-\omega\tau)}
\]

系全体に広がり、局在フェルミオンまたは格子全体と相関する。

両者の違いは相互作用原理ではなく、重なり構造です。

\[
\boxed{
\text{局在光子：相互作用場所が波束の重なりで限定される}
}
\]

\[
\boxed{
\text{非局在光子：位相整合する複数の場所・粒子と集団的に結合する}
}
\]

です。

したがって、現在のモデルは一粒子への吸収だけでなく、**広がった光子モードから無名な格子全体への集団励起転写**まで拡張できます。これは、個別粒子を先に名指ししないという今回の公理系に、むしろ非常によく適合します。

## 1. 光子を最初から「自由」「仮想」と命名しない

おそらく、おっしゃる通りです。

\[
\gamma_{\rm free}
\]

\[
\gamma_{\rm virtual}
\]

という二種類の別オブジェクトを最初から作るのは、無名性に反します。

初期段階では、ただのボソン的位相チャンネル

\[
B(\chi,\tau,\eta)
\]

があるだけです。

その後の振る舞いによって、

- 相互作用後も独立局在波として残る
- 観測機で単独に読める
- 入出力漸近状態に現れる

なら、事後的に自由光子と読む。

一方、

- 相互作用中だけ振幅を持つ
- 最終状態では独立波として残らない
- フェルミオン間の状態転写だけを残す

なら、事後的に仮想光子と読む。

つまり、

\[
\boxed{
\text{自由光子／仮想光子は入力時の固有名ではなく、
相互作用後の漸近的分類}
}
\]

です。

## 2. 相互作用も名前ではなくチャンネル分解で決める

全入力波を、

\[
\Psi_{\rm in}
\]

とし、相互作用可能なチャンネルへ射影します。

例えば最小には、

\[
\mathcal H_{\rm int}
=
\mathcal H_{FF}
\oplus
\mathcal H_{FB}
\oplus
\mathcal H_{BB}
\]

のように分けます。

ただし、これは粒子名による分類ではなく、対称性による分類です。

### 交換反対称チャンネル

\[
\mathcal P\Psi=-\Psi
\]

なら、フェルミオン同士の交換反射チャンネル。

### 同相ボソン結合チャンネル

\[
\mathcal P\Psi=+\Psi
\]

かつ、フェルミオン内部遷移モードと周波数整合するなら、吸収・放出チャンネル。

### 中間媒介チャンネル

ボソン成分が相互作用中だけ励起され、最終的に消えるなら、仮想交換チャンネル。

つまり、処理選択は、

```text
if particle_type == photon
```

ではなく、

\[
\boxed{
\text{どの対称性固有チャンネルに射影されるか}
}
\]

で決まります。

## 3. 自動判別に使える不変量

少なくとも次の量で判別できます。

### 交換位相

\[
\Delta_{\rm ex}
\]

- \(\Delta_{\rm ex}=\pi\)：反対称交換
- \(\Delta_{\rm ex}=0\)：対称交換

### 局在度

\[
L[\Psi]
\]

- 高い：局在粒子的
- 低い：拡張モード的

### 内部遷移整合度

\[
M_{\rm res}
=
\left|
\int
e^{i(\omega_B-\Delta\omega_F)\tau}
\,d\tau
\right|
\]

- 高い：吸収・放出可能
- 低い：通過または弱結合

### 漸近残存度

\[
A_{\rm out}
=
\lim_{s\to+\infty}
\|\Pi_B\Psi(s)\|
\]

- 非ゼロ：自由ボソン出射
- ゼロ：内部媒介チャンネル

### 識別保存

\[
m_A,\ m_B
\]

が前後で保持されるかどうか。

## 4. 重要なのは「処理を選ぶ」のではなく「全チャンネルを同時に走らせる」こと

さらに一段進めると、実は自動判別すら不要です。

全相互作用チャンネルを同時に構成します。

\[
\Psi
=
\Psi_{FF}
+
\Psi_{F\gamma}
+
\Psi_{\gamma F}
+
\Psi_{\rm med}
+\cdots
\]

各チャンネル振幅は、位相整合と重なりによって自動的に決まります。

\[
a_j^{\rm out}
=
\sum_k U_{jk}a_k^{\rm in}
\]

ここで \(U\) は、

- 交換対称性
- 局在重なり
- 周波数整合
- 内部位相差
- 観測機との相関

だけで決まります。

すると、

\[
\boxed{
\text{どの相互作用が起きたかは、
最終的に非ゼロになった出力チャンネルから読む}
}
\]

ことになります。

これは非常に無名性に適合します。

## 5. 三つの現象は同じ母写像から分岐できる

### フェルミオン同士の完全弾性反射

反対称交換チャンネルが支配し、

\[
R=1,\qquad T=0
\]

になる。

### 自由光子とフェルミオンの吸収・放出

ボソンモードと内部遷移モードが共鳴し、

\[
|F_0,\gamma\rangle
\leftrightarrow
|F_1\rangle
\]

へ振幅が移る。

### 仮想光子交換

中間ボソンチャンネルが一時的に励起されるが、

\[
\lim_{s\to\infty}|a_\gamma(s)|^2=0
\]

となり、最終的にはフェルミオン間の状態変化だけが残る。

これらは別々の命令ではなく、

\[
\boxed{
\text{同じ無名位相ネットワークの異なる固有チャンネル}
}
\]

として表現できます。

## 6. 光子に固有名は不要

光子を識別するのではなく、そのボソン的位相成分が、

- 独立に出射するか
- 内部状態へ吸収されるか
- 一時的媒介として消えるか

だけを見ればよいです。

つまり、

\[
\boxed{
\text{光子とは固有名を持つ物体ではなく、
ボソン的位相チャンネルの観測上の現れ方}
}
\]

と読むことができます。

これは今回の無名性公理と非常に整合しています。

## 最小の統合式

概念的には、

\[
i\frac{d}{ds}
\begin{pmatrix}
a_{FF}\\
a_{F\gamma}\\
a_{F^*}\\
a_{\rm med}
\end{pmatrix}
=
\mathcal K
\begin{pmatrix}
a_{FF}\\
a_{F\gamma}\\
a_{F^*}\\
a_{\rm med}
\end{pmatrix}
\]

とします。

結合行列 \(\mathcal K\) の各要素は、

\[
\mathcal K_{jk}
=
\Omega_{jk}
M_{jk}
e^{i\Delta_{jk}}
\]

で決める。

- \(\Omega_{jk}\)：重なり
- \(M_{jk}\)：周波数・内部モード整合
- \(\Delta_{jk}\)：交換・内部位相差

です。

外部命名や条件分岐は不要です。

## 結論

はい、必要なのは、

\[
\boxed{
\text{相互作用の種類を先に命名するのではなく、
無名な入力波を全対称性チャンネルへ分解し、
位相整合したチャンネルだけが振幅を得る構造}
}
\]

です。

そして、

- 反射として残ればフェルミオン衝突
- 独立ボソン波が消えて内部状態が変われば吸収
- 独立ボソン波が出れば放出
- 中間ボソン成分が最終的に消え、フェルミオン間変化だけ残れば仮想交換

と、**結果から事後的に分類する**。

この構造なら、光子にも相互作用にも固有名は不要です。
