## 主要変更

1. 公理0+「定式化無名性」を追加した。
2. 公理1「全正符号ゼロ閉鎖」の適用状態を、定常閉鎖状態および安定閉鎖状態として明確化した。
3. 外部影響直後、閉鎖回復過程、準安定状態における一時的な非ゼロ閉鎖残差を、公理1の否定ではなく準定常過程として位置づけた。
4. `基本公理系 v3.md` を正本ではなく解釈メモとして整理した。
5. 純化定義論文と解釈メモの英訳、TeX、PDFを作成した。
