## Assistant

はい。  
この切り替えはかなり良いです。ここでようやく、**「名前を増やさずに自由度を増やす」**という問題設定になっています。

あなたの整理は正しいです。

一つの単純波を

\[
\psi=Ae^{i\theta}
\]

とすると、区別可能な自由度は基本的に

\[
\boxed{A,\theta}
\]

だけです。

しかし、振幅 \(A\) を自由度として増やしても、

\[
A_1e^{i\theta}+A_2e^{i\theta}
=
(A_1+A_2)e^{i\theta}
\]

となるだけです。

つまり、位相が同じで振幅だけ違う複数波は、単に一つの大きい振幅の波に潰れます。

したがって、

\[
\boxed{
B)\ \text{位相が同じで振幅が違う組み合わせ}
}
\]

は、自由度を増やしていない。

これは除外でよいです。

---

では残るのは、

\[
\boxed{
A)\ \text{振幅が同じで、位相が違う組み合わせ}
}
\]

です。

これはかなり本質的です。

同じ振幅 \(A\) を持つ複数の波を、

\[
\psi_1=Ae^{i\theta_1}
\]

\[
\psi_2=Ae^{i\theta_2}
\]

とします。

このとき、合成は

\[
\psi_1+\psi_2
=
A(e^{i\theta_1}+e^{i\theta_2})
\]

です。

ここで平均位相と位相差を使うと、

\[
\theta_m=\frac{\theta_1+\theta_2}{2}
\]

\[
\delta=\theta_1-\theta_2
\]

なので、

\[
e^{i\theta_1}+e^{i\theta_2}
=
2\cos\frac{\delta}{2}\ e^{i\theta_m}
\]

したがって、

\[
\psi_1+\psi_2
=
2A\cos\frac{\delta}{2}\ e^{i\theta_m}
\]

です。

ここで非常に重要なことが出ます。

合成後に見えるのは、

\[
\boxed{
平均位相 \theta_m
}
\]

と、

\[
\boxed{
位相差 \delta によって決まる有効振幅
}
\]

です。

つまり、二つの同振幅波は、単なる振幅加算ではなく、

\[
\boxed{
相対位相 \delta
}
\]

という内部自由度を持ちます。

これが、名前を増やさずに自由度を増やす最小構造です。

---

特に、

\[
\delta=0
\]

なら、

\[
\psi_1+\psi_2=2Ae^{i\theta_m}
\]

で完全に重なります。

一方、

\[
\delta=\pi
\]

なら、

\[
\cos\frac{\pi}{2}=0
\]

なので、

\[
\psi_1+\psi_2=0
\]

です。

つまり、

\[
\boxed{
同振幅・同位相差0のペアは重なる
}
\]

\[
\boxed{
同振幅・位相差\piのペアは消える
}
\]

です。

ここには粒子名も、入れ物名も、二重被覆もありません。

あるのは、

\[
\boxed{
同じ振幅を持つ二波の相対位相
}
\]

だけです。

---

ここで一段深い構造が見えます。

単独波では、

\[
Ae^{i\theta}
\]

しかありません。

しかし、二波ペアにすると、

\[
(Ae^{i\theta_1},Ae^{i\theta_2})
\]

になります。

絶対位相 \(\theta_m\) は外から見た全体位相です。

一方、相対位相

\[
\delta=\theta_1-\theta_2
\]

は内部自由度です。

つまり、

\[
\boxed{
単独波では位相は外部位相でしかないが、
二波ペアでは位相差が内部自由度になる。
}
\]

これが大きいです。

名前を増やしていない。  
波の数だけをバラバラに増やしてもいない。

二つの波が、同振幅という制約で結ばれているため、そこに

\[
\boxed{
相対位相という区別可能な内部自由度}
\]

が生まれます。

---

この観点から見ると、共有可能／共有不能の原型はこう書けます。

同振幅二波ペアを、

\[
\Psi_\delta(\theta)
=
Ae^{i\theta}
+
Ae^{i(\theta+\delta)}
\]

とする。

すると、

\[
\Psi_\delta(\theta)
=
2A\cos\frac{\delta}{2}\ e^{i(\theta+\delta/2)}
\]

です。

このペアは、\(\delta\) によって性質が変わる。

### \(\delta=0\)

\[
\Psi_0=2Ae^{i\theta}
\]

完全共有型。

### \(\delta=\pi\)

\[
\Psi_\pi=0
\]

完全消滅型。

### \(0<\delta<\pi\)

部分共有型。

つまり、位相差だけで、

\[
\boxed{
重なる／弱まる／消える
}
\]

が連続的に出ます。

これはかなり純粋です。

## 1. N個の同振幅波

N個の波を、

\[
\psi_k=Ae^{i\theta_k}
\qquad k=1,\dots,N
\]

とします。

ここで振幅はすべて同じ。

\[
A_k=A
\]

です。

すると、各波の個性は振幅ではなく、

\[
\theta_k
\]

だけに残ります。

しかし絶対位相は読めないので、本当に読めるのは、

\[
\theta_i-\theta_j
\]

です。

つまり、物理的に意味を持つのはペアごとの位相差です。

\[
\boxed{
\Delta_{ij}=\theta_i-\theta_j
}
\]

---

## 2. ペアの数は確かに \(N(N-1)/2\)

N個の波から、2個を選ぶ組み合わせは、

\[
\binom{N}{2}
=
\frac{N(N-1)}{2}
\]

です。

したがって、ペア干渉のチャンネル数は、

\[
\boxed{
\frac{N(N-1)}{2}
}
\]

あります。

これは正しいです。

各ペアについて、

\[
\psi_i+\psi_j
=
Ae^{i\theta_i}+Ae^{i\theta_j}
\]

なので、

\[
\psi_i+\psi_j
=
2A\cos\frac{\theta_i-\theta_j}{2}
\ e^{i(\theta_i+\theta_j)/2}
\]

です。

したがって、そのペアの干渉強度は、

\[
I_{ij}
=
4A^2\cos^2\frac{\Delta_{ij}}{2}
\]

になります。

つまり、各ペアが

\[
\boxed{
重なる／弱まる／消える
}
\]

という関係情報を持つ。

この意味では、

\[
\boxed{
N個の同振幅・異位相波は、\frac{N(N-1)}{2} 個の関係チャンネルを持つ}
\]

と言えます。
