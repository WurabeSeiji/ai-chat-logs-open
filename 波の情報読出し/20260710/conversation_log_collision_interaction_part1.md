## 1. 波が広がっているなら、干渉は離れていても存在する

局所波が有限幅を持ち、さらに裾が厳密にゼロでないなら、

\[
P_A(\chi,\tau)P_B(\chi,\tau)\neq0
\]

は、中心が離れていても成立します。

したがって、

\[
|\chi_A-\chi_B|<\epsilon_\chi
\]

になった瞬間に初めて干渉が発生する、という記述は物理機構としては不自然です。

正確には、

\[
\boxed{
\text{干渉・結合は常時存在するが、離れていると極端に小さい}
}
\]

です。

これは標準的な波束散乱でも同じで、相互作用の寄与は入射・出射波束の重なりと相互作用ハミルトニアンによって決まります。時間依存波束法では、波束を時間発展させ、その重なりや相関からS行列と断面積を抽出します。断面積が相互作用開始を直接判定するわけではありません。

## 2. 「波の重なり」と「相互作用」は同じではない

ただし、一点区別が必要です。

二つの波が数学的に重なっているだけでは、必ずしも互いの波形を変化させません。線形な自由波動なら、

\[
\Psi=P_A+P_B
\]

として干渉縞はできますが、それぞれの波はそのまま伝播できます。

相互作用を起こすには、

\[
\boxed{
\text{波の重なりを別のチャンネルへ転写する結合則}
}
\]

が必要です。

標準理論では、これが

\[
H=H_0+H_{\mathrm{int}}
\]

の

\[
H_{\mathrm{int}}
\]

に相当します。

木原モデルでは今回構成した、

\[
\text{直接経路}
\leftrightarrow
\text{交換経路}
\]

の局所交換干渉写像が、その役割です。

したがって、次のように三層を分ける必要があります。

\[
\boxed{\text{波の重なり}}
\]

\[
\boxed{\text{相互作用チャンネルへの結合}}
\]

\[
\boxed{\text{観測可能な反射・通過への累積}}
\]

## 3. 標準理論の断面積は衝突判定ではない

標準的な断面積は、

\[
d\sigma
=
\frac{\text{特定の終状態へ移る率}}
{\text{入射フラックス}}
\]

として定義されます。

したがって断面積は、

\[
\boxed{
\text{一つの粒子対が今まさに衝突したか}
}
\]

を判定する量ではなく、

\[
\boxed{
\text{与えられた入射条件から、ある散乱出力が生じる確率的な有効面積}
}
\]

です。

つまり標準理論では、

1. 相互作用がどこで起きるかは \(H_{\rm int}\) やポテンシャルが決める  
2. 入射状態から出射状態への遷移振幅を計算する  
3. その出力を断面積としてまとめる  

という順です。

断面積そのものが「衝突開始条件」ではありません。

## 4. 実際には何を「衝突」と呼んでいるのか

標準散乱理論では、通常、

\[
t\to-\infty
\]

で十分離れた入射状態を置き、

\[
t\to+\infty
\]

で十分離れた出射状態を読みます。

その中間の具体的な「衝突瞬間」は、S行列では直接記述されない場合が多いです。

したがって、標準理論が実際に判定しているのは、

\[
\boxed{
\text{入力状態と出力状態の間に非自明な遷移があったか}
}
\]

です。

「どの瞬間、どの距離で衝突したか」は、断面積から直接は出ません。

木原モデルの観点では、これはかなり重要です。

\[
\boxed{
\text{衝突は一点事象ではなく、
累積干渉によって入出力チャネルが変わったこと}
}
\]

と読めます。

## 5. 有限セルの正しい位置づけ

したがって、前論文で使った有限セルは、

\[
\boxed{
\text{相互作用が始まる領域}
}
\]

ではなく、

\[
\boxed{
\text{反射・通過を観測上区別できるだけの干渉が蓄積した領域}
}
\]

と読み替える方が自然です。

つまり、

\[
|\rho|<\epsilon
\]

は物理的スイッチではなく、

\[
\boxed{
\text{観測解像度上、二局所波を独立な二つとして識別できなくなる領域}
}
\]

です。

実際の相互作用はその前から少しずつ進んでいます。

## 6. ハードセルから連続結合へ

次のモデルでは、二値条件、

\[
\begin{cases}
\text{相互作用なし},&|\rho|>\epsilon\\
\text{相互作用あり},&|\rho|<\epsilon
\end{cases}
\]

をやめます。

代わりに、連続的な相互作用重みを置きます。

\[
w_{AB}(s)
=
\iiint
P_A(\chi,\tau,\eta;s)
P_B^{\rm ref}(\chi,\tau,\eta;s)
\,d\chi\,d\tau\,d\eta
\]

または振幅の絶対値を使って、

\[
\Omega_{AB}(s)
=
\frac{
\iiint |P_A||P_B|\,d\chi d\tau d\eta
}{
\sqrt{
\iiint |P_A|^2
\iiint |P_B|^2
}
}
\]

とします。

すると、

\[
0\le\Omega_{AB}(s)\le1
\]

です。

- 遠方：\(\Omega_{AB}\ll1\)
- 接近中：\(\Omega_{AB}\) が増加
- 最大重なり：\(\Omega_{AB}\simeq1\)
- 離反：再び減少

となります。

## 7. 干渉写像も連続的にする

現在は相互作用窓内で一度、

1&0\\

H
\begin{pmatrix}
1&0\\

全相互作用後には、

\[
U_{\rm total}
=
\prod_s dU(s)
\]

です。

同じ生成子なので可換なら、

\[

1&0\\

## 8. 「衝突条件」ではなく「写像完成条件」

\boxed{
\text{交換干渉位相がどこまで蓄積したか}

\boxed{

\]

になります。

## 9. 断面積の木原モデル的な読み替え

この視点では、標準的な断面積は、

\[
\boxed{
\text{どの初期条件なら、累積干渉が特定の出力チャネルを形成するか}
}
\]

の測度と読めます。

たとえば衝突パラメータ \(b\) を変えたとき、

\[
\Theta_{AB}(b)
=
\int
\kappa\,
\Omega_{AB}(s;b)
\,ds
\]

とします。

すると反射確率は、

\[
R(b)
=
\sin^2
\frac{\Theta_{AB}(b)}{2}
\]

です。

全反射断面積に相当するものは、

\[
\sigma_R
=
\int R(b)\,d^2b
\]

となります。

つまり断面積は「衝突した面積」ではなく、

\[
\boxed{
\text{各衝突パラメータにおける干渉写像の完成度を積分したもの}
}
\]

と読めます。

## 10. 短距離相互作用と長距離相互作用

この整理は、相互作用の種類によって違いも説明できます。

### 短距離型

\[
\kappa(\rho)
\]

が狭い領域でだけ大きい。

この場合、有限セル近似はかなりよく機能します。

### 長距離型

クーロン型のように、

\[
\kappa(\rho)\neq0
\]

が遠方まで続く。

この場合、「衝突セルに入ってから作用する」という説明は成立しません。位相偏移は遠方から累積します。

木原モデルでも、ベースライン波の裾が長いなら、後者に近い可能性があります。

## 11. 観測機Cの役割

観測機Cが実際に判定するのは、

\[
\boxed{
\text{相互作用開始}
}
\]

ではなく、

\[
\boxed{
\text{A,Bを独立に識別できる入射状態から、
反射または通過として再び独立に識別できる出射状態へ変化したこと}
}
\]

です。

相互作用中は、

- AとBの局在が重なる
- 直接経路と交換経路が混ざる
- 個別粒子としての読出しが曖昧になる
- 出射後に識別振動 \(m_A,m_B\) を再読出しする

となります。

したがって観測機は「衝突瞬間」を見るのではなく、

\[
\boxed{
\text{入出力写像を読む}
}
\]

と考えるべきです。

## 結論

ご指摘は正しいです。

\[
\boxed{
\text{波が有限幅を持つ以上、相互作用はセル境界で突然始まるのではない}
}
\]

有限セルは、

\[
\boxed{
\text{相互作用開始条件ではなく、
観測上の識別不能域または写像完成域}
}
\]

と位置づけるべきです。

また標準理論の断面積も、

\[
\boxed{
\text{個々の衝突発生を判定するものではなく、
相互作用によって特定の出力が得られる確率的有効面積}
}
\]

です。

したがって、次の論文・実装では、

\[
\boxed{
\text{ハードな衝突セル判定}
\rightarrow
\text{連続的な重なり・相関による位相累積}
}
\]

へ進むのが自然です。

最終的な衝突の定義は、

\[
\boxed{
\text{交換干渉位相が累積し、
入射チャネルが反射・通過チャネルへ再編成されたこと}
}
\]

になります。
