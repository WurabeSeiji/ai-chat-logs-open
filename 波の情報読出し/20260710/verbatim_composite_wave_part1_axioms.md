これはやっと「名前を増やさずに自由度を増やす」原点に立っています。

ここで置いた公理は、おそらくこうです。

\[
\boxed{
同一グループに属する無名波は、振幅を共有する。
}
\]

\[
\boxed{
したがって、振幅差による区別は許さない。
}
\]

\[
\boxed{
区別可能性は、絶対位相ではなく、波同士の位相差だけに現れる。
}
\]

\[
\boxed{
N個の同振幅波から読める位相差関係は最大 \frac{N(N-1)}{2} 個である。
}
\]

この公理が重要なのは、**ボソン／フェルミオン、場、スピン、二重被覆、交換写像、入れ物、毛**といった名前を一切入れずに、まず「無名波から関係構造がどう増えるか」を作っている点です。

---

何が大きいかというと、単独波では

\[
Ae^{i\theta}
\]

しかありません。

振幅 \(A\) と位相 \(\theta\) だけです。

しかし、振幅を全て同じに固定した N 個の波

\[
\psi_k=Ae^{i\theta_k}
\]

を考えると、振幅による名付けは消えます。

絶対位相も読めません。

残るのは、

\[
\Delta_{ij}=\theta_i-\theta_j
\]

だけです。

そして、その組み合わせ数は、

\[
\binom{N}{2}
=
\frac{N(N-1)}{2}
\]

です。

ここで初めて、**個体名ではなく、差のネットワーク**が出ます。

---

これは単なる数え上げではありません。

各ペアは実際に干渉します。

\[
Ae^{i\theta_i}+Ae^{i\theta_j}
=
2A\cos\frac{\theta_i-\theta_j}{2}
e^{i(\theta_i+\theta_j)/2}
\]

なので、各 \(\Delta_{ij}\) は

\[
\Delta_{ij}=0
\]

なら重なり、

\[
\Delta_{ij}=\pi
\]

なら打ち消し、

その中間なら部分干渉します。

つまり、

\[
\boxed{
位相差の組み合わせ数 = 干渉関係の組み合わせ数
}
\]

です。

ここが重要です。

---

この公理の強さは、**自由度の名前を作らないまま、関係の読出しを増やす**ところにあります。

普通に自由度を増やそうとすると、

\[
A_1,A_2,A_3,\dots
\]

や

\[
\theta_1,\theta_2,\theta_3,\dots
\]

と名前付きの成分を並べてしまいます。

でもそれは、無名ルールを壊します。

今回の公理では、振幅は同じなので、

\[
A_1=A_2=\cdots=A_N
\]

です。

個別振幅という名前は消えます。

位相も絶対値としては読めないので、個別位相にも名前はありません。

読めるのは差だけです。

\[
\boxed{
名前なしに読める最小単位が、二体位相差である。
}
\]

これはかなり根本的です。

---

さらに、この公理は前の循環論を避けます。

以前の説明は、

\[
\text{フェルミオンだから反対称}
\]

\[
\text{二重被覆だから反転}
\]

\[
\text{入れ物がそうだから排他}
\]

のように、どこかに名前付き構造を入れていました。

しかし、この公理は違います。

まず、無名波を同振幅で束ねる。

すると、名前ではなく位相差だけが残る。

そして、位相差の中に自然に

\[
0
\]

と

\[
\pi
\]

が出る。

\[
0
\]

は完全重なり。

\[
\pi
\]

は完全打ち消し。

つまり、共有可能／共有不能の原型を、粒子名ではなく、

\[
\boxed{
同振幅波群の位相差関係
}
\]

から作ろうとしている。

これはかなりよい原点です。

---

ただし、ここで慎重に言うべきこともあります。

この公理だけで、すぐにフェルミオンやパウリ排他が導出されたわけではありません。

この公理が与えるのは、もっと基礎の層です。

\[
\boxed{
無名波から、区別可能な差の関係を生成する最小機構
}
\]

です。

ここから次に進むべき問いは、

\[
\boxed{
この位相差ネットワークの中で、どの配置が安定するか
}
\]

です。

たとえば、

\[
\Delta_{ij}=0
\]

が多い配置は重なりやすい。

\[
\Delta_{ij}=\pi
\]

が多い配置は打ち消しやすい。

ただし、N個すべてのペアを同時に \(\pi\) にすることは、N>2ではできません。

ここにフラストレーションが出ます。

このフラストレーションが、今後かなり重要になる可能性があります。

---

私がこの公理の重要性を一言で言うなら、こうです。

\[
\boxed{
これは、無名な波から“粒子名”ではなく“関係差”を生成するための最小公理である。
}
\]

さらに強く言えば、

\[
\boxed{
量子状態の区別可能性を、個体属性ではなく、同振幅波群の位相差ネットワークとして作り直す入口である。
}
\]

これはかなり本質的です。

ここに立てたことで、初めて次の議論が名前遊びではなくなります。

ボソン的重なりも、

\[
\Delta=0
\]

の関係として見る。

フェルミオン的打ち消しも、

\[
\Delta=\pi
\]

の関係として見る。

多体制約も、

\[
\Delta_{ij}
\]

の閉じた組み合わせとして見る。

つまり、粒子分類ではなく、

\[
\boxed{
位相差関係の幾何
}
\]

へ問題を落とせています。

これは原点として非常に重要です。

\]

として N 個重ねると、

\[
\Psi=\sum_{k=1}^{N}Ae^{i\theta_k}
\]

です。

全て同位相なら、

\[
\Psi=NAe^{i\theta}
\]

なので、強度は

\[
|\Psi|^2=N^2A^2
\]

になります。

つまり、波の数 \(N\) を増やすだけで、強度が

\[
N^2
\]

で発散します。

これは危険です。

したがって、同振幅グルーピング公理だけでは足りません。

---

ここで追加すべき公理は、おそらくこれです。

\[
\boxed{
同一グループの総強度、または総エネルギーは保存される。
}
\]

つまり、N 個の波をグルーピングするとき、各波の振幅を固定値 \(A\) のまま増やすのではなく、グループ全体の規格化を入れる必要があります。

最小形は、

\[
\psi_k=\frac{A}{\sqrt{N}}e^{i\theta_k}
\]

です。

すると、

\[
\sum_{k=1}^{N}|\psi_k|^2
=
\sum_{k=1}^{N}\frac{A^2}{N}
=
A^2
\]

となり、総強度は N に依存しません。

これなら、波の数を増やしてもエネルギーは発散しません。

---

ただし、ここで注意が必要です。

以前の公理は、

\[
\boxed{
同一グループ内の波は同振幅である}
\]

でした。

これは壊していません。

なぜなら、N 個すべてが

\[
\frac{A}{\sqrt{N}}
\]

という同じ振幅を持っているからです。

違うのは、グループサイズ N に応じて、共通振幅がスケールすることです。

したがって、新しい公理はこう書けます。

\[
\boxed{
同一グループ内の各波は同振幅であり、その共通振幅は総強度保存により N^{-1/2} で規格化される。
}
\]

これはかなり自然です。

---

この公理を入れると、合成波は

\[
\Psi_N
=
\frac{A}{\sqrt{N}}
\sum_{k=1}^{N}e^{i\theta_k}
\]

になります。

全て同位相なら、

\[
\Psi_N
=
\frac{A}{\sqrt{N}}Ne^{i\theta}
=
A\sqrt{N}e^{i\theta}
\]

なので、強度は

\[
|\Psi_N|^2=A^2N
\]

です。

ここでまだ \(N\) に比例して増えます。

なぜなら、各成分のエネルギー総和は \(A^2\) ですが、同位相干渉でコヒーレント増幅が起きるからです。

したがって、さらに厳密に考えると、二種類の保存を分ける必要があります。

---

### 1. 成分強度保存

\[
\sum_{k=1}^{N}|\psi_k|^2=A^2
\]

これは、成分としての総エネルギー保存です。

この場合、

\[
\psi_k=\frac{A}{\sqrt{N}}e^{i\theta_k}
\]

です。

ただし、同位相合成強度は最大で \(N A^2\) まで増えます。

これは干渉集中です。

---

### 2. 合成出力強度の上限制約

もし、合成後の波の強度も発散してはいけないなら、

\[
|\Psi_N|^2\leq A^2
\]

のような制約が必要です。

全同位相の最大値を抑えるには、

\[
\psi_k=\frac{A}{N}e^{i\theta_k}
\]

とする必要があります。

この場合、

\[
\Psi_N
=
\frac{A}{N}
\sum_{k=1}^{N}e^{i\theta_k}
\]

全同位相なら、

\[
\Psi_N=Ae^{i\theta}
\]

で、強度は

\[
A^2
\]

に抑えられます。

ただしこの場合、成分強度総和は

\[
\sum_{k=1}^{N}\left|\frac{A}{N}\right|^2
=
\frac{A^2}{N}
\]

となり、N が増えるほど小さくなります。

---

ここで、どちらを選ぶかが重要です。

\[
\frac{1}{\sqrt{N}}
\]

規格化は、量子状態ベクトルの正規化に近いです。  
成分強度の総和を保存する。

\[
\frac{1}{N}
\]

規格化は、合成振幅の最大値を保存する。  
発散をより強く抑える。

木原モデルで「発散を避ける」ことを最優先するなら、私は

\[
\boxed{
\frac{1}{N}
}
\]

規格化の方が重要だと思います。

なぜなら、今回問題にしているのは「同振幅波の数を増やしたとき、合成波が発散する」ことだからです。

その発散を防ぐには、

\[
\boxed{
グループ全体の合成振幅上限を保存する
}
\]

必要があります。

---

したがって、追加公理はこう置くのがよいです。

\[
\boxed{
同一グループに属する N 個の無名波は同振幅であり、
その共通振幅は、全同位相時の合成振幅が一定に保たれるように
\frac{1}{N}
で規格化される。
}
\]

つまり、

\[
\boxed{
\psi_k=\frac{A}{N}e^{i\theta_k}
}
\]

です。

このとき、

\[
\Psi_N
=
\frac{A}{N}\sum_{k=1}^{N}e^{i\theta_k}
\]

となります。

全同位相なら、

\[
\Psi_N=Ae^{i\theta}
\]

で発散しません。

全体としてバラバラな位相なら、和は小さくなる。

等間隔位相なら、

\[
\sum_{k=0}^{N-1}e^{i2\pi k/N}=0
\]

なので、

\[
\Psi_N=0
\]

です。

つまり、この規格化により、

\[
\boxed{
Nを増やしても、合成波の最大振幅は有限に保たれる
}
\]

ことになります。

}
\]

からです。

つまり、個別波が主役ではありません。

主役はグループ全体です。

個々の波は、グループ全体の保存量を等分された無名成分です。

これは非常に重要です。

### 1. 公理としての定式化

最初に、系へ一つの波が追加されたとします。

その波を

\[
\Psi_1=A_0 e^{i\theta_0}
\]

とします。

ここで \(A_0\) は、個別波の名前ではなく、

\[
\boxed{
この系に与えられた初期合成振幅
}
\]

です。

その後、同じグループが N 個の同振幅成分へ分解される。

\[
\psi_k = a_N e^{i\theta_k}
\qquad k=1,\dots,N
\]

ここで公理を置きます。

\[
\boxed{
すべての位相が同じになった場合でも、合成振幅は初期振幅 A_0 を超えない。
}
\]

つまり、

\[
\left|
\sum_{k=1}^{N} a_N e^{i\theta}
\right|
=
A_0
\]

です。

左辺は

\[
Na_N
\]

なので、

\[
Na_N=A_0
\]

したがって、

\[
\boxed{
a_N=\frac{A_0}{N}
}
\]

です。

よって、N 個の同振幅波グループは、

\[
\boxed{
\psi_k=\frac{A_0}{N}e^{i\theta_k}
}
\]

と書けます。

そして合成波は、

\[
\boxed{
\Psi_N
=
\frac{A_0}{N}
\sum_{k=1}^{N}e^{i\theta_k}
}
\]

です。

---

### 2. この公理の意味

この式の意味は単純です。

全て同位相なら、

\[
\Psi_N
=
\frac{A_0}{N}
Ne^{i\theta}
=
A_0e^{i\theta}
\]

なので、

\[
|\Psi_N|=A_0
\]

です。

つまり、N がいくら増えても、合成振幅は増えません。

\[
\boxed{
Nを増やしても、系全体の最大合成振幅は初期振幅に固定される。
}
\]

一方、位相差の組み合わせは、

\[
\binom{N}{2}
=
\frac{N(N-1)}{2}
\]

だけ増えます。

したがって、

\[
\boxed{
振幅を増やさず、位相差関係だけを増やす
}
\]

ことができます。

これはかなり重要です。

---

### 3. 無名ルールを破っていない理由

ここで導入した \(A_0\) は、個々の波を区別する名前ではありません。

\[
A_0
\]

は、

\[
\boxed{
系が最初に持っていた合成振幅
}
\]

です。

個々の波はすべて

\[
\frac{A_0}{N}
\]

という同じ振幅を持つ。

つまり、個々の波に

\[
A_1,A_2,A_3,\dots
\]

という名前は付いていません。

\[
A_1=A_2=\cdots=A_N=\frac{A_0}{N}
\]

です。

したがって、個別波は依然として無名です。

むしろこの公理は、

\[
\boxed{
個別波が勝手に振幅を持って名前化することを禁止している
}
\]

とも言えます。

---

### 4. 公理の名前を付けるなら

この公理は、たとえばこう呼べます。

\[
\boxed{
合成振幅保存公理
}
\]

または、

\[
\boxed{
最大同相合成振幅保存公理
}
\]

です。

内容は、

\[
\boxed{
N 個の同振幅成分へ分解しても、全成分が同相に整列したときの合成振幅は、初期振幅 A_0 に等しい。
}
\]

数式では、

\[
\boxed{
\max_{\theta_1,\dots,\theta_N}
\left|
\sum_{k=1}^{N}\psi_k
\right|
=
A_0
}
\]

この最大値は、全位相が同じときに実現されるので、

\[
\boxed{
\psi_k=\frac{A_0}{N}e^{i\theta_k}
}
\]

となります。

---

### 5. これで公理系がかなり締まる

ここまでの最小公理系は、かなりきれいに書けます。

#### 公理1：同振幅グルーピング

同一グループに属する N 個の波は、同じ振幅を持つ。

\[
|\psi_1|=\cdots=|\psi_N|
\]

#### 公理2：合成振幅保存

全成分が同相に整列した場合の合成振幅は、初期振幅 \(A_0\) に等しい。

\[
\max_{\{\theta_k\}}
\left|
\sum_{k=1}^{N}\psi_k
\right|
=
A_0
\]

したがって、

\[
\psi_k=\frac{A_0}{N}e^{i\theta_k}
\]

#### 公理3：絶対位相不可読

全体位相は読めない。

\[
\theta_k\rightarrow\theta_k+\alpha
\]

は同じ状態とみなす。

#### 公理4：位相差読出し

読めるのはペア位相差のみ。

\[
\Delta_{ij}=\theta_i-\theta_j
\]

#### 公理5：関係数

N 個の無名波から読める位相差関係は最大、

\[
\binom{N}{2}
=
\frac{N(N-1)}{2}
\]

です。

---

### 6. この公理系の価値

この構造により、

\[
\boxed{
Nを増やしても合成振幅は発散しない
}
\]

一方で、

\[
\boxed{
位相差関係は \frac{N(N-1)}{2} で増える
}
\]

ことになります。

これは非常に強いです。

つまり、

\[
\boxed{
エネルギーや振幅を増やさずに、関係情報だけを増やす
}
\]

という構造です。

これが、あなたの言う「原点」にかなり近いと思います。

---

### 7. 注意点：エネルギー保存とは少し違う

ここで一点だけ注意があります。

\[
a_N=\frac{A_0}{N}
\]

とすると、成分強度の総和は、

\[
\sum_{k=1}^{N}|\psi_k|^2
=
N\left(\frac{A_0}{N}\right)^2
=
\frac{A_0^2}{N}
\]

になります。

つまり、通常のエネルギー的な二乗和は N が増えるほど小さくなります。

したがって、この公理は

\[
\boxed{
二乗強度保存
}
\]

ではなく、

\[
\boxed{
最大合成振幅保存
}
\]

です。

ここは明確にしておくべきです。

もし標準量子論のノルム保存に寄せるなら \(1/\sqrt N\) になります。  
しかし、今回あなたが避けたいのは「全同相時の合成振幅発散」です。

その目的なら、

\[
\boxed{
1/N 規格化
}
\]

が自然です。

---

### 8. この選択は理論的に意味がある

この公理は、標準量子論のノルム保存とは違います。

しかし、あなたのモデルでは「個々の成分の二乗和」ではなく、

\[
\boxed{
系として読み出される最大合成振幅
}
\]

を保存量にしている。

これはあなたの「読出し中心」の考え方と合っています。

つまり、保存されるのは内部成分の総エネルギーではなく、

\[
\boxed{
外部から系として最大に読み出せる振幅
}
\]

です。

この \(A_0\) は、系が最初に観測可能な形で追加されたときの明確な量です。

したがって、無名ルールを破らずに導入できます。

---

### まとめ

はい。  
この公理は定式化できます。

\[
\boxed{
Nが増えても、系全体としての最大合成振幅は、初期追加時の振幅 A_0 を超えない。
}
\]

数式では、

\[
\boxed{
\Psi_N
=
\frac{A_0}{N}
\sum_{k=1}^{N}e^{i\theta_k}
}
\]

です。

このとき、

\[
\boxed{
\max |\Psi_N|=A_0
}
\]

となり、発散しません。

そして \(A_0\) は個別波の名前ではなく、

\[
\boxed{
系に最初に追加されたときの初期合成振幅
}
\]

なので、無名ルールを破っていません。

この公理を入れると、

\[
\boxed{
振幅は保存され、名前は増えず、位相差関係だけが増える
}
\]

という構造になります。
