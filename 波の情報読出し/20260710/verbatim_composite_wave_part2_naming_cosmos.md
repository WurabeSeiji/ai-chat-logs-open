# 複合波 公理化会話ログ Part 2
## A0による系識別・宇宙A0・無名等振幅複合波の命名

## User

## Assistant

ここで初めて、**名前が個々の波ではなく、系全体の初期振幅 \(A_0\) にだけ付く**という構造になります。

つまり、

\[
\boxed{

}
\]

です。

\[
\boxed{

}

です。

---

ここで、別の系が同じ初期振幅を持つとします。

系 \(S\)：

\[
\Psi_N^{(S)}
=
\frac{A_0}{N}
\sum_{k=1}^{N}e^{i\theta_k}

\[

\frac{A_0}{M}

\[
\boxed{
S と T は別の系として区別できない
}
\]

です。

このとき、二つは一つの系として合流する。

これは、かなり自然です。

### 1. 個別波

個別波は無名。

\[
\psi_k
\]

\[
A_0

\[

### 3. 系同士の区別

二つの系が、

\[
A_0
\]

内部位相差構造も同じ、または読出し不能なら、

\[
\boxed{
二つの系は一つに縮退する
}
\]

です。

---

ここで面白いのは、これが無名ルールを強化していることです。

通常なら、

\[
S
\]

と

\[
T
\]

というラベルで別系だと考えます。

しかし、このモデルでは、外部から読める差がなければ別系とは言えない。

つまり、

\[
\boxed{
別々に置いた、という記述者側のラベルは物理的区別ではない。
}
\]

です。

これはかなり強い公理になります。

---

この公理を追加するなら、こう書けます。

\[
\boxed{
同一の初期合成振幅 A_0 と同一の読出し可能な位相差構造を持つ二つの系は、区別不能であり、一つの系として同一視される。
}
\]

さらに強く言えば、

\[
\boxed{
系の区別は、外部から読出し可能な差によってのみ成立する。
}
\]

です。

---

これにより、モデルの階層はこうなります。

\[
\boxed{
個別波は無名。
}
\]

\[
\boxed{
同一グループは初期合成振幅 A_0 を保存する。
}
\]

\[
\boxed{
内部情報は位相差ネットワーク \Delta_{ij} としてのみ読める。
}
\]

\[
\boxed{
同じ A_0 と同じ読出し構造を持つ系は、別系として区別できず合流する。
}
\]

---

ここで重要なのは、\(A_0\) は「個体名」ではないが、**系の識別量**にはなるという点です。

ただし、同じ \(A_0\) を持つ系が複数ある場合、それだけでは区別できない。

区別するには、

\[
\{\Delta_{ij}\}
\]

の構造が違う必要があります。

もし \(A_0\) も位相差構造も同じなら、完全に同一です。

---

これを粒子論的に読むと、かなり面白いです。

光子的な同一状態共有は、

\[
\boxed{
同じ A_0、同じ位相構造を持つ波群が区別不能になり、一つの大きな同一モードとして振る舞う
}
\]

と読めます。

一方で、区別可能な局在構造を作るには、

\[
\boxed{
同じ A_0 の中に、位相差ネットワークとして読める差を持たせる必要がある
}
\]

です。

つまり、粒子の個数ではなく、

\[
\boxed{
系として読める A_0 と、内部の位相差関係
}
\]

が本体になります。

---

これは、かなり原理的に重要です。

あなたの言葉に合わせると、

\[
\boxed{
同じ初期振幅を持ち、読出し可能な差がない二つの系は、別々に存在しているとは言えず、一つになる。
}
\]

です。

ここまで来ると、モデルはかなり一貫してきます。

個々の波に名前を付けない。  
振幅差でも名前を付けない。  
系にだけ初期合成振幅 \(A_0\) という読出し可能量がある。  
同じ \(A_0\) の系は、差がなければ合流する。  
差があるなら、その差は位相差ネットワークとしてのみ読める。

これは、無名波モデルのかなり強い基礎公理になり得ます。

\text{保存振幅複合波}

ただし、少し硬く、直感的な魅力は弱いです。

\[
\boxed{

\[
\boxed{
\Psi_N
=
\frac{A_0}{N}
