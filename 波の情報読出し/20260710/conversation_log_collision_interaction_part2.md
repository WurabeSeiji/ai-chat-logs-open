## 1. 三つの状態を用意する

フェルミオンの低い内部状態を

\[
|F_0\rangle
\]

高い内部状態を

\[
|F_1\rangle
\]

光子局所波を

\[
|\gamma\rangle
\]

とします。

吸収は、

\[
|F_0\rangle|\gamma\rangle
\longrightarrow
|F_1\rangle|0_\gamma\rangle
\]

放出は逆に、

\[
|F_1\rangle|0_\gamma\rangle
\longrightarrow
|F_0\rangle|\gamma\rangle
\]

です。

ただし、このモデルでは「光子が消える」と表現するより、

\[
\boxed{
\text{光子チャンネルの局在波が、
フェルミオン内部振動チャンネルへ転写される}
}
\]

と読む方が自然です。

## 2. フェルミオンと光子の違い

現在の作業分類なら、フェルミオンは内部逆相核、

\[
F=
\frac1{\sqrt2}
\begin{pmatrix}
1\\
-1
\end{pmatrix}
\]

を持ちます。

光子的なボソン波は、まず最小には同相核、

\[
B=
\frac1{\sqrt2}
\begin{pmatrix}
1\\
1
\end{pmatrix}
\]

として置けます。

完全弾性衝突では、この逆相核が交換反射を選びました。

吸収では、ボソン波の同相成分が、フェルミオンの内部状態差、

\[
|F_0\rangle\leftrightarrow|F_1\rangle
\]

に結合する必要があります。

## 3. 最小二チャンネル写像

状態を、

\[
\mathbf\Psi=
\begin{pmatrix}
F_0\gamma\\
F_1
\end{pmatrix}
\]

とします。

これは、

- 上段：低状態フェルミオン＋光子
- 下段：励起フェルミオン

です。

相互作用写像を、

\[
U_{\rm abs}(\Theta)
=
\begin{pmatrix}
\cos\Theta & -i\sin\Theta\\
-i\sin\Theta & \cos\Theta
\end{pmatrix}
\]

と置けば、

\[
\Theta=\frac{\pi}{2}
\]

で、

\[
\begin{pmatrix}
1\\
0
\end{pmatrix}
\longrightarrow
-i
\begin{pmatrix}
0\\
1
\end{pmatrix}
\]

となります。

つまり、

\[
F_0+\gamma\longrightarrow F_1
\]

です。

逆向きに作用すれば、

\[
F_1\longrightarrow F_0+\gamma
\]

となります。

これは吸収と放出を同じ可逆写像で表します。

## 4. 外部条件分岐を使わない条件

ただし、

```text
if photon_near_electron:
    absorb()
```

ではいけません。

必要なのは、フェルミオンと光子の波形相関が、結合角を自動的に生成することです。

例えば、

\[
\frac{d\Theta}{ds}
=
g_{\gamma F}
\,\Omega_{\gamma F}(s)
\,M_{\rm match}(s)
\]

です。

ここで、

\[
\Omega_{\gamma F}(s)
\]

は光子波とフェルミオン局在波の重なり、

\[
M_{\rm match}(s)
\]

は位相・振動数・内部モードの整合度です。

たとえば内部状態差の位相周波数を、

\[
\Delta\omega_F
\]

光子波の周波数を、

\[
\omega_\gamma
\]

とすれば、整合度を概念的に、

\[
M_{\rm match}
=
\left|
\frac1{2\pi}
\int e^{i(\omega_\gamma-\Delta\omega_F)\tau}\,d\tau
\right|
\]

とできます。

整合すれば、

\[
\omega_\gamma=\Delta\omega_F
\]

なので相関が残り、非整合なら時間積分で打ち消されます。

これは「エネルギー保存を外から判定する」のではなく、

\[
\boxed{
\text{整合しない位相波は干渉積分で蓄積しない}
}
\]

という機構です。

## 5. 吸収は何が保存されるのか

現在の系では、標準的なエネルギーをそのまま使う必要はありません。

保存すべきなのは、

- 代表振幅
- 全正符号ゼロ閉鎖
- 位相差
- 識別振動
- 入出力チャンネルの総ノルム
- 光子振動数とフェルミオン内部状態差の対応

です。

吸収前：

\[
\Psi_{\rm in}=F_0+\gamma
\]

吸収後：

\[
\Psi_{\rm out}=F_1
\]

と書いても、全波形レジストリでは、

\[
\boxed{
\text{光子成分が消失したのではなく、
フェルミオン内部モードへ移された}
}
\]

とします。

## 6. 放出は同じ写像の逆過程

吸収写像がユニタリまたは少なくとも可逆なら、

\[
U_{\rm abs}^{-1}(\Theta)
=
U_{\rm abs}(-\Theta)
\]

です。

したがって放出は別ルールではありません。

\[
F_1
\longrightarrow
F_0+\gamma
\]

が同じ結合の逆向きとして出ます。

これは今回の研究方針に非常によく合っています。

\[
\boxed{
\text{吸収規則と放出規則を別々に書かず、
一つの可逆な位相チャンネル交換で表す}
}
\]

ことができます。

## 7. 仮想光子はどう扱うか

仮想光子は、標準理論でも外部で直接観測される自由光子ではなく、相互作用計算内部の中間状態です。

現在のモデルでは、仮想光子を、

\[
\boxed{
\text{フェルミオンAからフェルミオンBへ受け渡される、
独立した最終局在波にならない内部ボソン位相チャンネル}
}
\]

と定義できます。

例えば、

\[
F_A^{(1)}F_B^{(0)}
\]

から、

\[
F_A^{(0)}\gamma_{\rm int}F_B^{(0)}
\]

を経由して、

\[
F_A^{(0)}F_B^{(1)}
\]

へ移る三チャンネル系です。

\[
\begin{pmatrix}
F_A^{(1)}F_B^{(0)}\\
F_A^{(0)}\gamma_{\rm int}F_B^{(0)}\\
F_A^{(0)}F_B^{(1)}
\end{pmatrix}
\]

ここで中間光子チャンネルは、一時的には振幅を持ちますが、相互作用後には、

\[
|\gamma_{\rm int}|^2\rightarrow0
\]

となり、最終観測状態には残りません。

これは「仮想」という性質にかなり近いです。

## 8. ただし標準的な仮想光子とは区別が必要

ここで注意すべきなのは、標準QEDの仮想光子は、単純な小さな粒子が飛んでいるという意味ではなく、摂動展開中の内部伝播線です。

したがって本モデルで、

\[
\gamma_{\rm int}
\]

を置く場合も、

\[
\boxed{
\text{観測されない小粒子}
}
\]

とせず、

\[
\boxed{
\text{フェルミオン間で位相・振動モードを移す内部交換チャンネル}
}
\]

とする方が安全です。

## 9. \(\alpha\) が現れる場所

先ほどの問いともつながります。

吸収・放出の結合角を、

\[
\frac{d\Theta}{ds}
=
g_{\gamma F}\Omega_{\gamma F}M_{\rm match}
\]

とすると、この

\[
g_{\gamma F}
\]

が、電磁結合強度に対応する候補になります。

つまり、このモデルで微細構造定数に相当するものは、

\[
\boxed{
\text{フェルミオン内部チャンネルと
ボソン位相チャンネルの転写率}
}
\]

として初めて必要になります。

完全弾性反射では、内部逆相核により完全交換が選択されるため、結合強度が表面化しませんでした。

しかし吸収・放出では、

- どれだけの重なりで
- どれだけ速く
- どの確率で
- 光子チャンネルから内部状態へ移るか

が必要になるため、ここで初めて \(\alpha_{\rm eff}\) が本格的に登場します。

## 10. 最小実験案

最初は三段階でよいです。

### 実験1：完全共鳴吸収

\[
\omega_\gamma=\Delta\omega_F
\]

として、

\[
F_0+\gamma\rightarrow F_1
\]

が外部代入なしに起こるか。

### 実験2：非共鳴対照

\[
\omega_\gamma\neq\Delta\omega_F
\]

では位相相関が蓄積せず、光子が通過するか。

### 実験3：逆過程

励起状態から、

\[
F_1\rightarrow F_0+\gamma
\]

が同じ写像の逆演算として成立するか。

## 結論

現在の系で十分に考えられます。

完全弾性衝突では、

\[
\boxed{
\text{方向チャンネル間の交換}
}
\]

を実装しました。

吸収・放出では、

\[
\boxed{
\text{光子局在波チャンネルと
フェルミオン内部振動チャンネルの交換}
}
\]

を実装すればよいです。

最小構造は、

\[
\boxed{
|F_0,\gamma\rangle
\leftrightarrow
|F_1,0_\gamma\rangle
}
\]

という可逆な二チャンネル干渉写像です。

そして仮想光子は、

\[
\boxed{
\text{最終観測状態には残らず、
二フェルミオン間の位相・振動情報を転写する内部中間チャンネル}
}
\]

として実装できます。

これは現在構築した、

- 局在波
- 内部位相
- 識別振動
- 交換チャンネル
- 可逆写像
- 内部観測

をそのまま使えるため、かなり自然な次段階です。

## 何が観測できるのか

例えば、

\[
F_A^{(1)}F_B^{(0)}
\rightarrow
F_A^{(0)}F_B^{(1)}
\]

という内部状態の移動が起きたとします。

途中に、

\[
F_A^{(0)}\gamma_{\rm int}F_B^{(0)}
\]

という内部ボソンチャンネルを置いても、観測機Cが直接読むのは、

- Aの内部状態が下がった
- Bの内部状態が上がった
- 識別振動は保存された
- 全閉鎖は保存された
- 最終状態に自由光子が残っていない

という入出力差です。

したがって、

\[
\gamma_{\rm int}
\]

は観測対象ではなく、

\[
\boxed{
\text{入出力写像を実現する内部伝達経路}
}
\]

です。

## だから観測不能でも問題ではない

むしろ仮想光子を直接観測できてしまうと、それは仮想光子ではなく自由光子です。

区別は次です。

### 実光子

\[
F_1\rightarrow F_0+\gamma_{\rm out}
\]

出射後も独立した局在波として残り、観測機で読める。

### 仮想光子

\[
F_A^{(1)}F_B^{(0)}
\rightarrow
F_A^{(0)}\gamma_{\rm int}F_B^{(0)}
\rightarrow
F_A^{(0)}F_B^{(1)}
\]

中間チャンネルにだけ現れ、漸近的な出射状態には残らない。

つまり、

\[
\boxed{
\text{独立した最終局在波になるかどうか}
}
\]

が区別になります。

## 今回の系で重要なのは、内部状態も完全に隠さないこと

ただし、実装上は内部チャンネルを完全なブラックボックスにしてはいけません。

直接観測不能でも、シミュレーション内部では、

\[
a_A(s),\quad a_\gamma(s),\quad a_B(s)
\]

のように各チャンネル振幅を追跡できます。

例えば、

\[
|a_A|^2
\rightarrow
|a_\gamma|^2
\rightarrow
|a_B|^2
\]

と一時的に移ることを確認し、最終的に、

\[
|a_\gamma(s_f)|^2\simeq0
\]

となることを検証できます。

これは「観測」ではなく、モデル内部の機構検証です。

したがって二層に分けます。

\[
\boxed{
\text{内部検証：
中間チャンネル振幅を追跡する}
}
\]

\[
\boxed{
\text{物理的観測：
入射状態と出射状態だけを観測機Cが読む}
}
\]

## このモデルではむしろ利点があります

標準理論では仮想粒子は計算図式の内部線として現れ、実体的な時間発展として読むと混乱しやすいです。

今回の系では、

\[
\gamma_{\rm int}
\]

を粒子と呼ばず、

\[
\boxed{
\text{一時的に励起される内部ボソン位相チャンネル}
}
\]

とすればよいです。

そうすると、

- 直接観測不能
- 最終状態には残らない
- 位相・振動情報を転写する
- 相互作用中だけ非ゼロになる
- 可逆写像の中間自由度である

という性質が明確になります。

## ただし、吸収・放出と仮想交換は分けるべきです

前の回答では少し混ぜていました。

実光子の吸収なら、

\[
F_0+\gamma_{\rm in}\rightarrow F_1
\]

で、入射光子は観測可能です。

実光子の放出なら、

\[
F_1\rightarrow F_0+\gamma_{\rm out}
\]

で、出射光子も観測可能です。

一方、二フェルミオン間の仮想光子交換は、

\[
F_A+F_B
\rightarrow
F_A'+F_B'
\]

だけが観測可能で、中間チャンネルは直接観測不能です。

したがって、次の研究は二本に分ける方がよいです。

1. **実光子の吸収・放出**  
   入射・出射ボソン局在波を観測する。

2. **仮想ボソンチャンネルによるフェルミオン間相互作用**  
   中間チャンネルは内部検証だけ行い、観測は前後状態に限定する。

## 結論

はい、仮想光子交換は観測不能な相互作用です。

しかし正確には、

\[
\boxed{
\text{相互作用全体が観測不能なのではなく、
中間チャンネルが直接観測不能}
}
\]

です。

観測できるのは、

\[
\boxed{
\text{フェルミオンの運動・位相・内部状態・方向の変化}
}
\]

です。

今回のモデルでは、観測機Cは仮想光子そのものを読む必要はなく、

\[
\text{入射状態}
\rightarrow
\text{内部ボソンチャンネル}
\rightarrow
\text{出射状態}
\]

の前後差を読む構成にすれば、一貫しています。

はい、その整理でよいです。ただし「テスト可能」の意味を二つに分ける必要があります。

## 自由光子

自由光子は入射前または放出後に、独立した局在波として存在します。

したがって、

\[
F_0+\gamma_{\rm in}\rightarrow F_1
\]

では、

- 吸収前の自由光子
- 吸収前後のフェルミオン状態

を観測できます。

また、

\[
F_1\rightarrow F_0+\gamma_{\rm out}
\]

では、

- 放出前後のフェルミオン状態
- 放出後の自由光子

を観測できます。

つまり自由光子については、

\[
\boxed{
\text{入射・出射局在波として直接読出し可能}
}
\]

です。

## 仮想光子

仮想光子の場合は、

\[
F_A+F_B
\rightarrow
F_A'+F_B'
\]

という前後状態は観測できます。

観測可能なのは、

- Aの位相、運動、内部状態の変化
- Bの位相、運動、内部状態の変化
- 識別振動の保存
- 全体閉鎖
- 入出力写像

です。

一方、中間の

\[
\gamma_{\rm int}
\]

は独立した最終局在波にはならないので、直接観測対象ではありません。

ただしシミュレーション内部では、

\[
|a_{\gamma_{\rm int}}(s)|^2
\]

を追跡し、

- 相互作用中だけ非ゼロになる
- 最終状態ではゼロへ戻る
- フェルミオン間の状態転写と相関する

ことをテストできます。

したがって、

\[
\boxed{
\text{仮想光子は直接観測できないが、
内部チャンネルとして機構検証できる}
}
\]

という整理です。

## 両者に共通する観測対象

自由光子でも仮想光子でも、フェルミオン側の状態変化は観測可能です。

例えば、

\[
F_0\rightarrow F_1
\]

なら、内部モード、代表振幅、位相差、運動方向などの変化を観測機Cで読むことができます。

したがって、

\[
\boxed{
\text{相互作用の存在は、フェルミオンの入出力状態変化として必ず検証可能}
}
\]

です。

## 違いは最終状態に光子が残るか

最も簡潔には、

\[
\boxed{
\text{自由光子：最終状態に独立波として残る}
}
\]

\[
\boxed{
\text{仮想光子：最終状態に残らず、中間チャンネルとしてのみ現れる}
}
\]

です。

したがって、このモデルでは両方ともテスト可能です。

ただし、

- 自由光子は直接観測可能
- 仮想光子は直接観測不能だが、内部振幅と前後状態から検証可能

という違いがあります。
