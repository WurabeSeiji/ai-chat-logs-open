# 複素数の波と干渉だけで、粒子の衝突と観測を作ってみる

物理ではふつう、まず空間と時間があり、その中に粒子があり、粒子どうしがぶつかり、それを測定器が観測する、と考えます。

たとえば、二つの粒子 A と B が近づいて、完全弾性衝突をして、跳ね返る。そこに観測機 C があって、衝突の前後で A と B がどう動いたかを測る。

これはとても自然な絵です。

でも、今回やってみたかったのは、その絵を最初から仮定しないことでした。

つまり、

・まず背景空間がある  
・その中に粒子が置かれている  
・その中を時間に沿って動く  
・その外から観測機が見る  

という順番を、いったん使わない。

かわりに、A も B も C も、そして位置や時間に見えるものも、すべて「複素数で表した波の位相」と「波どうしの干渉」から作ってみる。今回のシミュレーションは、そういう構成実験です。

## 何を作ったのか

登場するのは、三つの波です。

A と B は、粒子のように局在した波です。局在している、というのは、空間全体にぼんやり広がっているのではなく、ある場所の近くにピークを持つ、かたまりのような波だという意味です。

C は観測機です。ただし、金属でできた装置を置いたわけではありません。C もまた波です。A や B よりずっと大きな代表振幅を持つ、重い観測波として置きます。

そして A、B、C は、すべて複素数の位相を持っています。

複素数で波を書くと、波には大きさだけでなく「向き」や「ずれ」が入ります。この向きやずれが位相です。波どうしを重ねると、位相がそろえば強め合い、ずれていれば弱め合います。これが干渉です。

今回の観測とは、この干渉を使って読む操作です。

つまり、C の波と A の波を重ねる。C の波と B の波を重ねる。その重なり方から、

・A はどこにあるように読めるか  
・B はどこにあるように読めるか  
・A と B はどちら向きに進んでいるように読めるか  
・衝突後も A と B を区別できるか  

を読み出します。

ここで重要なのは、外から「この座標が位置です」「この変数が時間です」と決めていないことです。位置や時間に見えるものは、C との相対的な位相の読み出しとして現れます。

## A と B をどう区別するか

単にプログラムの中で A、B という名前をつけただけでは、物理的な意味は弱いです。

そこで、A と B の内部に、別々の識別振動を持たせました。

イメージとしては、A には A 用の細かい内部リズム、B には B 用の別の内部リズムが入っている、という感じです。

数式では、内部識別位相 η に対して

　D_m(η) = e^{imη}

という振動を入れます。A と B では、この m の値を変えます。

すると、衝突後に「左にあるものが A なのか B なのか」を、単なる変数名ではなく、波の内部振動として読み直せます。

これはとても大事です。

なぜなら、二つの粒子がすれ違ったのか、跳ね返ったのかは、位置だけを見ると紛らわしいからです。

もし A と B が近づいて、その後左右に離れたとしても、

・A と B が通過した  
・A と B が跳ね返った  
・A と B のラベルだけが入れ替わった  

という複数の読み方がありえます。

今回のシミュレーションでは、内部識別振動まで読み出すことで、反射と通過とラベル交換を区別しました。

## 完全弾性衝突をどう作ったか

衝突は、点の一点で起こるイベントとしては扱いません。

かわりに、A と B が十分近づいたと読める有限のセルを作ります。空間位相でも近い。時間位相でも近い。その両方がそろったとき、A と B は相互作用セルに入った、と判定します。

そのセルの中で、進行方向を反転させます。

つまり、

・A は右向きから左向きへ  
・B は左向きから右向きへ  

変わります。

ただし、変えてよいのは向きだけです。

A の内部識別振動は A のまま。B の内部識別振動は B のまま。代表振幅も保存します。フェルミオン的な内部構造も保存します。

この意味で、今回の衝突は「完全弾性反射」として作られています。

## 何が確認できたか

最小実験では、A と B は相互作用セルに到達し、そこで進行方向が反転し、衝突後に離れていきました。

さらに、観測機 C で読み出すと、A と B の識別振動は保存されていました。つまり、単に左右の位置がそれらしく動いたのではなく、「A という内部振動を持った波が反転し、B という内部振動を持った波も反転した」と読めました。

また、通過させるだけの写像や、ラベルを交換する写像も対照実験として試しました。その結果、反射写像だけが、方向反転と識別振動保存を同時に満たしました。

さらに、条件を変えた実験も行いました。

・観測機 C が軽すぎる場合  
・セル解像度が細かすぎて飛び越える場合  
・時間位相がそろわない場合  
・識別振動が漏れる場合  
・識別位相 η の読み出しサンプルが足りない場合  

こうした場合には、ちゃんと破綻します。

これは、何でも成功する都合のよい模型ではなく、成立条件と失敗条件を持つ構成になっている、ということです。

複数回衝突も試しました。8回の衝突を繰り返しても、方向反転、識別振動、代表振幅、閉鎖条件は保たれました。

## どこが面白いのか

今回の面白さは、「粒子の衝突を再現した」というよりも、もう少し手前にあります。

背景空間を先に置かずに、

・複素数で表した波  
・位相  
・干渉  
・内部識別振動  
・観測波との相関  

だけから、粒子のようなもの、観測機のようなもの、位置や時間のように読めるもの、そして衝突のように読めるものを、ひとつの数値系の中で構成できた。

ここが一番のポイントです。

「空間の中で粒子がぶつかった」と考えるのではなく、

「複素波どうしの位相関係と干渉から、粒子様の二つの局在波が完全弾性反射した、と読める構造ができた」

という順番です。

これは、標準的な物理学を置き換える話ではありません。むしろ、いつも当然のように使っている「粒子」「位置」「時間」「観測」という言葉を、もっと少ない材料からどこまで作れるかを試した、構成実験です。

## 主張しないこと

誤解を避けるために、はっきり書いておきます。

・これは、標準的なフェルミ粒子散乱を導出したものではありません。  
・これは、量子力学の測定過程を導出したものでもありません。  
・これは、実在粒子の衝突断面積を計算するものではありません。  
・方向反転のルール自体は、有限セル内の構成規則として与えています。  

今回示したのは、その反転規則が、複素数の波、位相、干渉、内部識別振動、観測機 C による読み出しと両立し、通過やラベル交換とは区別できる、ということです。

## まとめ

今回のシミュレーションでは、フェルミオン的な局在波 A と B、測定を行う観測機 C、そして A・B・C が存在しているように見える位置と時間までを、外から背景空間として与えず、複素数の波の位相と干渉から構成しました。

その上で、A と B の完全弾性反射を数値的に実行し、C による観測で、方向反転・識別振動保存・代表振幅保存を確認しました。

ごく少数の公理と、シンプルな複素数の波と干渉だけで、粒子様の存在、衝突、観測までを一つの閉じた系として作れた。

まだ小さな構成実験ですが、背景空間を前提にしない物理の作り方を考えるうえで、かなり面白い一歩になったと思っています。
