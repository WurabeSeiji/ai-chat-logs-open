# 1. 第一原理

## 公理0: 成分無名性

分類: 公理

基本成分に、個別名、特権軸、特権符号、特権型を与えない。

添字 `n` は便宜上のラベルであり、成分の固有名ではない。

禁止:

```text
特定成分だけを負符号軸にする
特定成分だけを時間軸にする
特定成分だけを実数型にする
特定成分だけを複素型にする
特定成分だけに固有名を与える
```

---

## 公理0+: 定式化無名性

分類: 公理

第一原理層では、理論名、定式名、読出し論理名にも固有名を与えない。

物理名、対象名、相互作用名、既存理論上の分類名を理由として、第一原理層の方程式、射影、読出し規則を変更してはならない。

禁止:

```text
重力だから円運動型の式を採用する
クーロン力だから双曲線型の式を採用する
質量だから符号を消す
電荷だから符号を残す
エネルギーだから時間軸へ移す
二体系だから別の閉鎖式を使う
三体系だから別の閉鎖式を使う
ABC系だから特別な読出し規則を使う
欲しい物理名に合わせて右辺表示を選ぶ
```

許可:

```text
同一閉鎖条件に対する読出し演算の違い
同一閉鎖条件に対する対称性の破れの違い
同一閉鎖条件に対するゲージ安定性の違い
同一閉鎖条件に対する符号保持の違い
同一閉鎖条件に対する符号消失の違い
同一閉鎖条件に対する位相枝選択の違い
同一閉鎖条件に対する閉鎖対象集合の違い
```

順序:

```text
同一の全正符号ゼロ閉鎖を置く
読出し演算を先に定義する
対称性の破れを先に定義する
符号保持または符号消失を先に定義する
ゲージ安定性を確認する
読出し後に作業名を与える
```

対象集合:

```math
Q(P)=\sum_n p_n^2
```

```math
Q(A)=0
```

```math
Q(A+B)=0
```

```math
Q(A+B+C)=0
```

対象集合の違いは許される。

`Q` の定義変更は許されない。

## 公理0.5: 次元別中心投影読出し

分類: 補助幾何公理

単一軸上の読出しでは曲率補正を導入しない。

曲率補正候補は、独立な二方向以上が面積、体積、閉路、または輸送不一致を形成する場合に限り導入する。

## 公理1: 全正符号ゼロ閉鎖

分類: 公理

```math
\sum_{n=1}^{N}x_n^2=0
```

展開形:

```math
x_1^2+x_2^2+\cdots+x_N^2=0
```

係数符号:

```text
全項 +
```

非採用:

```math
\sum_n |x_n|^2=0
```

閉鎖に用いる項:

```math
x_n^2
```

閉鎖に用いない項:

```math
x_n\bar{x}_n
```

適用状態:

```text
定常閉鎖状態
安定閉鎖状態
```

準定常状態:

```text
外部影響直後
閉鎖回復過程
準安定状態
```

準定常状態における一時的な非ゼロ閉鎖残差:

```math
\sum_n x_n^2\ne0
```

定常化後:

```math
\sum_n x_n^2=0
```

## 公理3: 投影軸縮退と虚数方向読出し

分類: 公理

投影法により内在座標系が構成されるとき、投影軸方向は、その内在座標系の住民から方向として判別されない。

ただし、投影軸方向の値が閉鎖条件内に残る場合、その値を消去しない。

投影軸方向の補償量を `z` と読むとき、内在座標系ではこれを

```math
iz
```

として扱う。

この成分は一次方向としては観測不能である。

閉鎖式内で二乗されると、

```math
(iz)^2=-z^2
```

となる。

したがって、投影軸方向の観測不能な補償量は、二乗読出しを通じて、符号反転した補償量として内在座標系に現れる。

# 9. 観測選択・曲率射影

## 公理16: 二体位相干渉による一意観測選択

分類: 観測接続公理

本公理は、公理0および公理1から未導出の独立な観測原理である。

閉鎖系の内在観測において、観測可能な量または方向は、二体間の位相差および位相干渉から、追加の固有名、特権軸、外部基準を導入せずに一意に再構成できなければならない。

二体間の原始読出しは、公理6の位相差

```math
\Delta_{ij}=\theta_i-\theta_j
```

および、公理1の二乗形式

```math
q(X)=\sum_n X_n^2
```

から得られる双線形関係

```math
B(U,V)
=\frac{1}{2}\left(q(U+V)-q(U)-q(V)\right)
```

によって構成する。

三体以上の読出しは、二体読出しチャンネルの集合または合成として構成する。

物理名、対象名、次元名を理由として、独立な高次読出し規則を追加してはならない。

同一の二体位相関係から複数の候補方向が生じ、それらを関係量だけでは区別できない場合、いずれか一つを観測可能な単一方向として選択してはならない。

位相進行順序を含む同一の関係情報から、正の尺度倍に関する既定の同値性を除いて一つの向き付き方向だけが再構成される場合、その方向を内在観測可能方向として採用できる。

この公理は、観測可能な方向の数を直接指定しない。

観測可能次元数は、本公理を具体的な二体位相関係へ適用した結果として判定する。

## 公理17: 未来位相位置を中心とする曲率反力射影

分類: 力学射影公理

本公理は、公理0および公理1から未導出の独立な力学・射影原理である。

閉鎖系の状態列に、順序インデックス

```math
\tau\in\mathbb{N}
```

を与える。

状態更新

```math
X(\tau)\longrightarrow X(\tau+1)
```

において、`tau+1` 側の位相位置を、その状態列における未来位相位置と定義する。

観測可能な位相進行が、曲率半径読出し `rho_c` と角速度読出し `omega` を持ち、未来位相位置を関係的な仮想回転中心とする運動として表現できる場合、その仮想回転で生じる遠心力の反力を、位相進行方向の観測可能な加速度として射影する。

加速度の大きさは、

```math
|\alpha_{\mathrm{read}}|
=\rho_c|\omega|^2
```

とする。

位相進行方向を `t_hat_tau` とすると、読出し加速度は、

```math
\boldsymbol{\alpha}_{\mathrm{read}}
=\rho_c|\omega|^2\,\hat{\boldsymbol{t}}_\tau
```

とする。

ここで `rho_c`、`omega`、`t_hat_tau` は、第一原理層で物理名を持たない関係読出し量である。

本公理を、重力、クーロン力、質量、電荷その他の物理名を理由として変更してはならない。

同じ条件を満たす閉鎖モードには、同じ射影規則を適用する。

未来側と反対側の位相枝、加速度方向の反転、符号保持または符号消失を採用する場合は、物理名から選択せず、独立な位相関係、枝選択、対称性の破れ、または読出し演算として事前に定義しなければならない。

本公理は、読出し加速度を標準重力、標準クーロン力、または既知の外力と同一視しない。

物理的名称は、加速度写像、距離指数、符号、閉鎖保存、ゲージ安定性を確認した後にのみ与える。
