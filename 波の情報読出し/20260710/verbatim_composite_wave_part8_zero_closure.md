x_1=x_2=\cdots=x_N=0
\]

しか許しません。

つまり、実数だけでは非自明な閉じた系が作れない。

ここまでは正しいです。

---

## では非自明解を作るには何が必要か

左辺の符号を変えてはいけない。

だから、非自明解を作るには、

\[
\boxed{
係数ではなく、成分 \(x_n\) 自身が位相を持つ必要がある
}
\]

ということになります。

たとえば、

\[
x_1=A
\]

\[
x_2=iA
\]

なら、

\[
x_1^2+x_2^2
=
A^2+(iA)^2
=
A^2-A^2
=
0
\]

です。

ここで重要なのは、

\[
A^2 - A^2
\]

というマイナスを、係数として外から入れていないことです。

マイナスは、

\[
(iA)^2=-A^2
\]

として、**成分自身の位相から発生している**。

つまり、

\[
\boxed{
マイナス符号は特権軸として入れたのではなく、位相二乗の結果として現れる
}
\]

です。

---

## ここが複素数導入の本質

したがって、この公理の意味はかなり強いです。

\[
\boxed{
全項を同じ \(+\) で足す
}
\]

\[
\boxed{
どの成分にも特権符号を与えない
}
\]

\[
\boxed{
それでも非自明にゼロ閉鎖する
}
\]

この三つを同時に満たすには、成分が実数では足りない。

だから、

\[
\boxed{
複素位相が必要になる
}
\]

ということです。

複素数を導入する理由は、

\[
\boxed{
虚数を便利な計算道具として使うため
}
\]

ではなく、

\[
\boxed{
無名な全成分を同じ符号で足しながら、非自明な閉鎖を実現するため
}
\]

です。

これはかなり重要な整理です。

---

## より一般には

複素数で

\[
x_n=r_ne^{i\phi_n}
\]

と書くと、

\[
x_n^2=r_n^2e^{i2\phi_n}
\]

なので、ゼロ閉鎖条件は

\[
\boxed{
\sum_n r_n^2e^{i2\phi_n}=0
}
\]

です。

等振幅なら、

\[
r_n=r
\]

なので、

\[
\boxed{
\sum_n e^{i2\phi_n}=0
}
\]

になります。

ここでも、各項の係数はすべて同じ \(+\) です。

閉鎖は、符号付き計量ではなく、

\[
\boxed{
二乗位相 \(2\phi_n\) の合成によって起きる
}
\]

のです。

---

## この公理の本当の名前

これは単なる「ゼロ閉鎖条件」では少し弱いかもしれません。

より正確には、

\[
\boxed{
無名正符号ゼロ閉鎖公理
}
\]

または、

\[
\boxed{
全正符号二乗閉鎖公理
}
\]

です。

内容はこうです。

\[
\boxed{
\textbf{全正符号二乗閉鎖公理：}
系の閉鎖条件は、特権的な負符号軸を導入せず、すべての無名成分の二乗を同じ正符号で足し合わせたゼロ条件として与えられる。
}
\]

\[
\boxed{
\sum_{n=1}^{N}x_n^2=0
}
\]

ただし、非自明解を許すために、

\[
\boxed{
x_n \in \mathbb{C}}
\]

または少なくとも位相を持つ量である必要がある。

---

## これが示すこと

この公理は、かなり原理的です。

なぜなら、次を同時に要求しているからです。

\[
\boxed{
1.\ 系は閉じている}
\]

\[
\boxed{
2.\ 成分は無名である}
\]

\[
\boxed{
3.\ 特権軸はない}
\]

\[
\boxed{
4.\ すべての成分は同じ規則で二乗される}
\]

\[
\boxed{
5.\ それでも全体はゼロ閉鎖する}
\]

この条件から、

\[
\boxed{
位相を持つ成分
}
\]

が必要になる。

つまり、複素位相は後付けではなく、この閉鎖条件から要求される。

---

## 前回回答の訂正

前回の

\[
x^2+y^2-z^2=0
\]

という例は、この文脈では採用すべきではありません。

それは、閉鎖を作ることはできますが、

\[
\boxed{
負符号軸という特権軸を導入している
}
\]

ためです。

今回の公理で重要なのは、そこへ逃げないことです。

したがって、正しくはこうです。

\[
\boxed{
左辺をすべて \(+\) に保つなら、実数では非自明解がない。
}
\]

\[
\boxed{
非自明なゼロ閉鎖を実現するには、各成分そのものが位相を持ち、二乗によって符号反転を内部生成する必要がある。
}
\]

\[
\boxed{
この意味で、複素数は特権軸を導入しないために必要になる。
}
\]

---

これはかなり大きいです。

標準的には、複素数は量子振幅の表現として導入されます。  
しかしこの公理系では、

\[
\boxed{
複素数は、無名性と全正符号閉鎖を両立するために導入される
}
\]

ことになります。

つまり、

\[
\boxed{
複素数は、特権軸を避けるための構造
}
\]

です。
