# 1. 第一原理

## 公理0: 成分無名性

分類: 公理

基本成分に、個別名、特権軸、特権符号、特権型を与えない。

添字 `n` は便宜上のラベルであり、成分の固有名ではない。

禁止:

```text
特定成分だけを負符号軸にする
特定成分だけを時間軸にする
特定成分だけを実数型にする
特定成分だけを複素型にする
特定成分だけに固有名を与える
```

---

## 公理0+: 定式化無名性

分類: 公理

第一原理層では、理論名、定式名、読出し論理名にも固有名を与えない。

物理名、対象名、相互作用名、既存理論上の分類名を理由として、第一原理層の方程式、射影、読出し規則を変更してはならない。

禁止:

```text
重力だから円運動型の式を採用する
クーロン力だから双曲線型の式を採用する
質量だから符号を消す
電荷だから符号を残す
エネルギーだから時間軸へ移す
二体系だから別の閉鎖式を使う
三体系だから別の閉鎖式を使う
ABC系だから特別な読出し規則を使う
欲しい物理名に合わせて右辺表示を選ぶ
```

許可:

```text
同一閉鎖条件に対する読出し演算の違い
同一閉鎖条件に対する対称性の破れの違い
同一閉鎖条件に対するゲージ安定性の違い
同一閉鎖条件に対する符号保持の違い
同一閉鎖条件に対する符号消失の違い
同一閉鎖条件に対する位相枝選択の違い
同一閉鎖条件に対する閉鎖対象集合の違い
```

順序:

```text
同一の全正符号ゼロ閉鎖を置く
読出し演算を先に定義する
対称性の破れを先に定義する
符号保持または符号消失を先に定義する
ゲージ安定性を確認する
読出し後に作業名を与える
```

対象集合:

```math
Q(P)=\sum_n p_n^2
```

```math
Q(A)=0
```

```math
Q(A+B)=0
```

```math
Q(A+B+C)=0
```

対象集合の違いは許される。

`Q` の定義変更は許されない。

## 公理0.5: 次元別中心投影読出し

分類: 補助幾何公理

単一軸上の読出しでは曲率補正を導入しない。

曲率補正候補は、独立な二方向以上が面積、体積、閉路、または輸送不一致を形成する場合に限り導入する。

---

## 公理1: 全正符号ゼロ閉鎖

分類: 公理

```math
\sum_{n=1}^{N}x_n^2=0
```

展開形:

```math
x_1^2+x_2^2+\cdots+x_N^2=0
```

係数符号:

```text
全項 +
```

非採用:

```math
\sum_n |x_n|^2=0
```

閉鎖に用いる項:

```math
x_n^2
```

閉鎖に用いない項:

```math
x_n\bar{x}_n
```

適用状態:

```text
定常閉鎖状態
安定閉鎖状態
```

準定常状態:

```text
外部影響直後
閉鎖回復過程
準安定状態
```

準定常状態における一時的な非ゼロ閉鎖残差:

```math
\sum_n x_n^2\ne0
```

定常化後:

```math
\sum_n x_n^2=0
```
