**著者:** 木原 範昭  
**位置づけ:** 論文化前の定式化・数値検証メモ

## 1. 目的

本メモでは、曲率付き局所セルに置かれた奇数倍音複素波が、曲率の影響を受けないのか、または曲率の影響を閉鎖条件の内部へ吸収するのかを検討する。

問いは、曲率補正量そのものを評価することではなく、次の安定問題として定式化する。

```math
Q(x_K)=\sum_n x_{K,n}^2=0
```

```math
\mathcal U_K x_K=e^{i\alpha_K}x_K
```

ここで、`K` は局所セルの曲率パラメータ、`x_K` は曲率込みで再選別された閉鎖定常波、`\mathcal U_K` は曲率付き局所セルを一周または交換干渉後に戻る発展写像である。

---

## 2. 本メモで主張しないこと

本メモは、次を主張しない。

| 主張しないこと | 理由 |
|---|---|
| 実在時空の曲率効果の定量予言 | 標準的な時空計量や場の方程式を用いない |
| 曲率が常に観測不能であること | 過渡状態や非閉鎖状態では残差が出る構成を許す |
| 曲率が複素位相に入る唯一の方式 | 本稿では局所モデルとして相対位相・共通重みを置く |
| 連続ハミルトニアンの導出 | 本稿は閉鎖定常波の存在問題を最小写像で検査する |

---

## 3. 閉鎖零錐

閉鎖条件を、

```math
Q(x)=\sum_n x_n^2=0
```

とする。閉鎖状態全体を、

```math
\mathcal N
=\{x\mid Q(x)=0\}
```

と書く。

曲率付き局所セルの作用を `M_K` とすると、閉鎖条件は

```math
Q(M_Kx)
=
x^T M_K^T M_K x
```

となる。

したがって、`M_K^T M_K` が閉鎖零錐上で共通因子として作用する場合、

```math
M_K^T M_K=\alpha_K I
```

なら、

```math
Q(M_Kx)=\alpha_K Q(x)=0
```

であり、曲率作用は閉鎖条件を破らない。

---

## 4. 曲率の二つの作用

曲率作用を次の二つに分ける。

### 4.1 共通因子型

各閉鎖ペアに同じ複素重みが掛かる場合、

```math
x_n\mapsto g_{K,n}x_n,
\qquad
ix_n\mapsto g_{K,n}ix_n
```

である。このとき、

```math
(g_{K,n}x_n)^2+(g_{K,n}ix_n)^2=0
```

となり、曲率による振幅・共通位相は閉鎖条件の外へ漏れない。

### 4.2 相対位相型

閉鎖ペアの一方だけに曲率位相が掛かる場合、

```math
x_n\mapsto x_n,
\qquad
ix_n\mapsto e^{i\delta_{K,n}}ix_n
```

である。このとき、

```math
x_n^2+(e^{i\delta_{K,n}}ix_n)^2
=
x_n^2\left(1-e^{i2\delta_{K,n}}\right)
```

となり、一般に閉鎖残差が出る。

---

## 5. 定常閉鎖による繰り込み

曲率込みで安定に残る波は、固定された平坦波ではなく、曲率込みで再選別された閉鎖定常波 `x_K` であるとする。

このとき、相対曲率位相 `\delta_{K,n}` は、内部位相補正 `\beta_{K,n}` により、

```math
\delta_{K,n}+\beta_{K,n}=0
```

へ吸収される。

したがって、

```math
x_n\mapsto x_n,
\qquad
ix_n\mapsto e^{i(\delta_{K,n}+\beta_{K,n})}ix_n=ix_n
```

となり、閉鎖条件が回復する。

本メモでは、これを「曲率が消える」とは呼ばない。曲率は、許容される波長、内部位相、倍音構成の再選別へ繰り込まれる。

---

## 6. 完全反射条件

交換干渉で読まれる有効位相を、

```math
\Delta_{\mathrm{eff},n}
=
\Delta_F+\delta_{K,n}+\beta_{K,n}
```

とする。

完全反射条件は、

```math
\Delta_{\mathrm{eff},n}=\pi
```

である。

曲率位相を固定したままでは、

```math
\Delta_{\mathrm{eff},n}=\pi+\delta_{K,n}
```

となり、通過漏れが生じる。

一方、定常閉鎖条件によって `\beta_{K,n}=-\delta_{K,n}` が選ばれるなら、

```math
\Delta_{\mathrm{eff},n}=\pi
```

が回復し、

```math
R=1,
\qquad
T=0
```

が保たれる。

## 7. 数値検証の設計

最小検証では、奇数倍音

```math
h_m=2m+1
```

を持つ閉鎖ペア

```math
x_m,
\qquad
ix_m
```

を作る。

曲率位相を、

```math
\delta_{K,m}=\kappa h_m
```

として与える。これは実在曲率の定量式ではなく、奇数倍音が曲率由来の相対位相漏れに敏感であることを調べるための局所モデルである。

検証する状態は次の三つである。

| 状態 | 意味 |
|---|---|
| flat | 曲率なしの閉鎖状態 |
| conformal | 共通重みとしての曲率作用 |
| transient | 曲率相対位相を受けたが、内部位相が未補正の過渡状態 |
| stationary | `\beta_{K,m}=-\delta_{K,m}` によって閉鎖条件を回復した定常状態 |

測定量は次である。

```math
\mathcal R_Q
=
\left|\sum_n x_n^2\right|
```

```math
T_{\mathrm{leak}}
=
\left\langle
\cos^2\frac{\Delta_{\mathrm{eff},n}}{2}
\right\rangle_n
```

ここで、`\Delta_F=\pi` とするため、

```math
T_{\mathrm{leak}}
=
\left\langle
\sin^2\frac{\delta_{K,n}+\beta_{K,n}}{2}
\right\rangle_n
```

である。

---

## 8. 成功条件

本検証では、次を確認する。

1. flat 状態で `Q=0` となる。
2. conformal 状態で `Q=0` が保たれる。
3. transient 状態では、曲率位相により閉鎖残差と通過漏れが出る。
4. stationary 状態では、内部位相補正により閉鎖残差と通過漏れが消える。
5. 緩和列 `\delta_{K,m}\to0` に沿って、閉鎖残差と通過漏れが単調に低下する。
