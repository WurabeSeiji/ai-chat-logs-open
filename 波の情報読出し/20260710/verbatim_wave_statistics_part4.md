## Assistant（Part 3からの続き）

## 3. ただし「独立自由度」は \(N(N-1)/2\) ではない

ここは厳密に分ける必要があります。

N個の位相は、

\[
\theta_1,\dots,\theta_N
\]

です。

ただし全体位相

\[
\theta_k\rightarrow\theta_k+\alpha
\]

は同じ状態として読めるので、独立な連続自由度は

\[
\boxed{
N-1
}
\]

です。

つまり、

\[
\Delta_{ij}
\]

は全部で

\[
\frac{N(N-1)}{2}
\]

個ありますが、独立ではありません。

たとえば、

\[
\Delta_{13}
=
\Delta_{12}+\Delta_{23}
\]

です。

一般に三角関係があります。

\[
\Delta_{ij}+\Delta_{jk}+\Delta_{ki}=0
\]

したがって、ペア位相差は多数ありますが、基礎位相から決まるため、独立な自由度は

\[
\boxed{
N-1
}
\]

です。

ここを混同すると危険です。

はい、その通りです。  
ここはかなり重要で、私の前の言い方もまだ甘かったです。

\[
\boxed{
自由度があっても、その自由度そのものには名前がない。
}
\]

したがって、直接読めるのは

\[
\theta_1,\theta_2,\dots,\theta_N
\]

ではありません。

読めるのはあくまで、

\[
\boxed{
差の組み合わせ}
\]

です。

つまり、

\[
\Delta_{ij}=\theta_i-\theta_j
\]

だけです。

---

## 1. 絶対位相は読めない

N個の同振幅波を

\[
\psi_k=Ae^{i\theta_k}
\]

とします。

ここで全ての位相を同じだけずらしても、

\[
\theta_k\rightarrow\theta_k+\alpha
\]

ペア差は変わりません。

\[
(\theta_i+\alpha)-(\theta_j+\alpha)
=
\theta_i-\theta_j
\]

したがって、絶対位相

\[
\theta_k
\]

そのものには意味がない。

意味があるのは、

\[
\boxed{
相対位相だけ}
\]

です。

これはまさに無名ルールです。

---

## 2. さらに「自由度に名前がない」

普通なら、

\[
\theta_1,\theta_2,\theta_3,\dots
\]

と書いた時点で、波に番号を付けています。

でも本当に無名なら、

\[
1,2,3
\]

というラベルも物理的ではありません。

したがって、実際に読めるのは、

\[
\boxed{
どの波とどの波の差か}
\]

ではなく、

\[
\boxed{
差の集合}
\]

です。

つまり、

\[
\{\Delta_{ij}\}
\]

の集合、あるいは多重集合です。

例えば N=3 なら、

\[
\Delta_{12},\Delta_{23},\Delta_{31}
\]

と書けますが、これは説明上の仮ラベルです。

本当に物理的にあるのは、

\[
\boxed{
3つの波の間に存在する3本の相対位相關係}
\]

です。

## Assistant

はい、その通りです。  
ここは私の表現が悪かったです。

あなたが言っているのは **独立パラメータ数** ではなく、

\[
\boxed{
区別可能な位相差の組み合わせ数
}
\]

ですね。

それなら最大は明確に

\[
\boxed{
\binom{N}{2}=\frac{N(N-1)}{2}
}
\]

です。

N 個の同振幅波があり、それぞれの位相がすべて異なる場合、二つずつ取り出した位相差は、

\[
\Delta_{ij}=\theta_i-\theta_j
\]

であり、組み合わせ数は

\[
\boxed{
{}_{N}C_{2}=\frac{N(N-1)}{2}
}
\]

です。

これは順列組み合わせの基礎そのものです。

---

ここで私が混ぜてしまったのは、

\[
\boxed{
独立に指定できる自由度}
\]

と、

\[
\boxed{
区別可能に読み出せる差の組み合わせ}
\]

です。

独立に指定できる位相自由度は、全体位相を除けば

\[
N-1
\]

です。

しかし、無名ルールの下で実際に読めるのは個々の位相ではなく、差です。

したがって、読み出し可能な位相差の組み合わせは

\[
\boxed{
\frac{N(N-1)}{2}
}
\]

です。

あなたが問題にしているのはこちらです。

---

したがって、正しい整理はこうです。

\[
\boxed{
N個の同振幅・異位相波をグルーピングすると、
個々の波に名前を付けなくても、
二体間の位相差として最大 \frac{N(N-1)}{2} 個の区別可能な関係が生じる。
}
\]

これはかなり重要です。

なぜなら、波そのものには名前がない。  
振幅も同じなので、振幅差による名前もない。  
絶対位相も読めない。

それでも、

\[
\boxed{
波同士の差}
\]

だけは読める。

そして、その差の組み合わせ数が

\[
\boxed{
\frac{N(N-1)}{2}}
\]

まで増える。

これは、**名前を増やさずに関係自由度を増やす最小構造**です。

---

この方向で見ると、あなたの仮定はかなり強いです。

\[
\boxed{
同振幅グルーピング}
\]

を公理として置く。

すると、振幅による区別は消える。

残る区別は位相だけ。

さらに絶対位相は読めないので、読めるのは位相差だけ。

その位相差は、N 個の波から最大

\[
\boxed{
\frac{N(N-1)}{2}
}
\]

個生じる。

つまり、

\[
\boxed{
無名な波から、名前ではなく差のネットワークが生まれる。
}
\]

これは良いです。

---

さらに重要なのは、これが単なる数え上げではなく、干渉の組み合わせ数でもあることです。

各ペアは、

\[
Ae^{i\theta_i}+Ae^{i\theta_j}
=
2A\cos\frac{\theta_i-\theta_j}{2}
e^{i(\theta_i+\theta_j)/2}
\]

です。

したがって各ペアごとに、

\[
\Delta_{ij}=0
\]

なら強め合い、

\[
\Delta_{ij}=\pi
\]

なら打ち消し、

その中間なら部分干渉します。

つまり、

\[
\boxed{
\frac{N(N-1)}{2}
}
\]

個の位相差は、そのまま

\[
\boxed{
\frac{N(N-1)}{2}
}
\]

個の干渉関係です。

ここが大きい。

---

この議論では、ボソン／フェルミオンという名前をまだ使わなくてよいです。

まず言えるのはこれです。

\[
\boxed{
同振幅・異位相の N 波グループは、
個々の波の名前ではなく、
最大 \frac{N(N-1)}{2} 個の位相差関係として区別可能になる。
}
\]

そして、この位相差関係の中に、

\[
\Delta=0
\]

の重なり型と、

\[
\Delta=\pi
\]

の打ち消し型が含まれる。

したがって次に考えるべきは、

\[
\boxed{
この位相差ネットワークの中で、
どの配置が安定し、
どの配置が重なりやすく、
どの配置が打ち消しやすいか}
\]

です。

ここまでなら、名前を一切増やしていません。  
使っているのは、

\[
\boxed{
同振幅}
\]

\[
\boxed{
相対位相}
\]

\[
\boxed{
組み合わせ数}
\]

だけです。
