# 複素数のレジスタ読出し

## 1) 現在の複素数 `Z` から、45 度前の複素数の実部を取得

定式:

```math
Z=x+iy
```

```math
Z_{-\pi/4}=e^{-i\pi/4}Z
```

```math
\boxed{
\operatorname{Re}(Z_{-\pi/4})
=
\operatorname{Re}(e^{-i\pi/4}Z)
=
\frac{\operatorname{Re}(Z)+\operatorname{Im}(Z)}{\sqrt2}
}
```

未正規化読出し:

```math
P(Z)=\operatorname{Re}(Z)+\operatorname{Im}(Z)
```

```math
\boxed{
P(Z)=\sqrt2\,\operatorname{Re}(e^{-i\pi/4}Z)
}
```

導出:

```math
e^{-i\pi/4}Z
=
\frac{1-i}{\sqrt2}(x+iy)
```

```math
=
\frac{x+y}{\sqrt2}
+
i\frac{y-x}{\sqrt2}
```

したがって、

```math
\operatorname{Re}(e^{-i\pi/4}Z)
=
\frac{x+y}{\sqrt2}
=
\frac{\operatorname{Re}(Z)+\operatorname{Im}(Z)}{\sqrt2}
```

## 2) 現在の複素数 `Z` から、45 度前の複素数の虚部を取得

定式:

```math
Z=x+iy
```

```math
Z_{-\pi/4}=e^{-i\pi/4}Z
```

```math
\boxed{
\operatorname{Im}(Z_{-\pi/4})
=
\operatorname{Im}(e^{-i\pi/4}Z)
=
\frac{\operatorname{Im}(Z)-\operatorname{Re}(Z)}{\sqrt2}
}
```

未正規化読出し:

```math
Q(Z)=\operatorname{Im}(Z)-\operatorname{Re}(Z)
```

```math
\boxed{
Q(Z)=\sqrt2\,\operatorname{Im}(e^{-i\pi/4}Z)
}
```

導出:

```math
e^{-i\pi/4}Z
=
\frac{1-i}{\sqrt2}(x+iy)
```

```math
=
\frac{x+y}{\sqrt2}
+
i\frac{y-x}{\sqrt2}
```

したがって、

```math
\operatorname{Im}(e^{-i\pi/4}Z)
=
\frac{y-x}{\sqrt2}
=
\frac{\operatorname{Im}(Z)-\operatorname{Re}(Z)}{\sqrt2}
```

## 3) 現在の複素数 `Z` から、45 度前の振幅を取得

定式:

```math
Z=x+iy
```

```math
Z_{-\pi/4}=e^{-i\pi/4}Z
```

```math
\boxed{
|Z_{-\pi/4}|
=
|e^{-i\pi/4}Z|
=
|Z|
}
```

```math
\boxed{
|Z|
=
\sqrt{\operatorname{Re}(Z)^2+\operatorname{Im}(Z)^2}
}
```

未正規化読出し:

```math
A(Z)=\operatorname{Re}(Z)^2+\operatorname{Im}(Z)^2
```

```math
\boxed{
A(Z)=|Z_{-\pi/4}|^2=|Z|^2
}
```

導出:

```math
|e^{-i\pi/4}|=1
```

したがって、

```math
|Z_{-\pi/4}|
=
|e^{-i\pi/4}Z|
=
|e^{-i\pi/4}|\,|Z|
=
|Z|
```

また、

```math
|Z|^2
=
(x+iy)(x-iy)
=
x^2+y^2
```

ゆえに、

```math
|Z|
=
\sqrt{x^2+y^2}
=
\sqrt{\operatorname{Re}(Z)^2+\operatorname{Im}(Z)^2}
```

## 4) 現在の複素数 `Z` から、45 度前の位相を取得

定式:

```math
Z=x+iy
```

```math
Z_{-\pi/4}=e^{-i\pi/4}Z
```

```math
\theta_Z=\arg Z
```

```math
\boxed{
\arg(Z_{-\pi/4})
=
\arg(e^{-i\pi/4}Z)
=
\theta_Z-\frac{\pi}{4}
\pmod{2\pi}
}
```

未正規化読出し:

```math
\Theta(Z)=\operatorname{atan2}(\operatorname{Im}(Z),\operatorname{Re}(Z))
```

```math
\boxed{
\Theta_{-\pi/4}(Z)
=
\Theta(Z)-\frac{\pi}{4}
\pmod{2\pi}
}
```

導出:

```math
Z=|Z|e^{i\theta_Z}
```

```math
e^{-i\pi/4}Z
=
e^{-i\pi/4}|Z|e^{i\theta_Z}
```

```math
=
|Z|e^{i(\theta_Z-\pi/4)}
```

したがって、

```math
\arg(e^{-i\pi/4}Z)
=
\theta_Z-\frac{\pi}{4}
\pmod{2\pi}
```

注意:

```text
位相は 2π 周期で同値である。
したがって、この読出しだけでは巻数は取得しない。
```

## 5) 現在の複素数 `Z` の 45 度前の位相を、`Z_1` の位相だけ進める

定式:

```math
Z=|Z|e^{i\theta_Z}
```

```math
Z_1=|Z_1|e^{i\theta_1}
```

```math
Z_{-\pi/4}=e^{-i\pi/4}Z
```

```math
U(Z_1)=\frac{Z_1}{|Z_1|}=e^{i\theta_1}
\qquad (Z_1\neq 0)
```

```math
\boxed{
Z_{-\pi/4,+\theta_1}
=
U(Z_1)Z_{-\pi/4}
=
\frac{Z_1}{|Z_1|}e^{-i\pi/4}Z
}
```

```math
\boxed{
\arg(Z_{-\pi/4,+\theta_1})
=
\theta_Z-\frac{\pi}{4}+\theta_1
\pmod{2\pi}
}
```

未正規化読出し:

```math
\widetilde Z_{-\pi/4,+\theta_1}
=
Z_1 e^{-i\pi/4}Z
```

```math
\boxed{
\arg(\widetilde Z_{-\pi/4,+\theta_1})
=
\theta_Z-\frac{\pi}{4}+\theta_1
\pmod{2\pi}
}
```

導出:

```math
Z_{-\pi/4}
=
e^{-i\pi/4}Z
=
|Z|e^{i(\theta_Z-\pi/4)}
```

```math
U(Z_1)Z_{-\pi/4}
=
e^{i\theta_1}|Z|e^{i(\theta_Z-\pi/4)}
```

```math
=
|Z|e^{i(\theta_Z-\pi/4+\theta_1)}
```

したがって、

```math
\arg(U(Z_1)Z_{-\pi/4})
=
\theta_Z-\frac{\pi}{4}+\theta_1
\pmod{2\pi}
```

また、未正規化の場合は、

```math
Z_1 e^{-i\pi/4}Z
=
|Z_1||Z|e^{i(\theta_1+\theta_Z-\pi/4)}
```

であるため、振幅は `|Z_1|` 倍されるが、位相は同じく

```math
\theta_Z-\frac{\pi}{4}+\theta_1
\pmod{2\pi}
```

となる。

## 6) `Z=\sum_n Z_n` の各要素の 45 度前の位相を、`Z_{1n}` の位相分進めた `Z'` を計算する方法

前提:

```math
Z=\sum_n Z_n
```

ただし、観測可能なのは合成結果 `Z` のみであり、各 `Z_n` は不明である。

定式:

各要素が既知であれば、

```math
Z_n=|Z_n|e^{i\theta_n}
```

```math
Z_{1n}=|Z_{1n}|e^{i\theta_{1n}}
```

```math
U(Z_{1n})=\frac{Z_{1n}}{|Z_{1n}|}=e^{i\theta_{1n}}
\qquad (Z_{1n}\neq 0)
```

として、

```math
\boxed{
Z'
=
\sum_n U(Z_{1n})e^{-i\pi/4}Z_n
=
\sum_n \frac{Z_{1n}}{|Z_{1n}|}e^{-i\pi/4}Z_n
}
```

である。

しかし、合成結果 `Z` のみが既知の場合、この写像は一般には定義できない。

```math
\boxed{
Z=\sum_n Z_n
\quad\not\Rightarrow\quad
Z'
=
\sum_n \frac{Z_{1n}}{|Z_{1n}|}e^{-i\pi/4}Z_n
}
```

未正規化読出し:

各要素が既知であれば、

```math
\widetilde Z'
=
\sum_n Z_{1n}e^{-i\pi/4}Z_n
```

と書ける。

ただし、これも `Z` のみからは計算できない。

```math
\boxed{
Z=\sum_n Z_n
\quad\not\Rightarrow\quad
\widetilde Z'
=
\sum_n Z_{1n}e^{-i\pi/4}Z_n
}
```

導出:

各要素が既知であれば、

```math
e^{-i\pi/4}Z_n
=
|Z_n|e^{i(\theta_n-\pi/4)}
```

これを `Z_{1n}` の位相分だけ進めると、

```math
U(Z_{1n})e^{-i\pi/4}Z_n
=
e^{i\theta_{1n}}|Z_n|e^{i(\theta_n-\pi/4)}
```

```math
=
|Z_n|e^{i(\theta_n-\pi/4+\theta_{1n})}
```

したがって、

```math
Z'
=
\sum_n |Z_n|e^{i(\theta_n-\pi/4+\theta_{1n})}
```

となる。

しかし、合成値

```math
Z=\sum_n Z_n
```

だけからは、各 `Z_n` および各 `\theta_{1n}` は復元されない。

したがって、この計算は、

```text
合成済みの Z に対する一回の線形読出し
```

ではなく、

```text
各要素 Z_n を分離し、各 Z_{1n} の位相で個別に変換し、再合成する写像
```

である。

結論:

```text
Z の合成結果しか不明な前提では、6) の Z' は一般には計算不能である。
```

この写像を成立させるには、少なくとも次のいずれかが必要である。

```text
1. 各 Z_n が読めること。
2. 各 Z_{1n} の位相が読めること。
3. 分離せずに同じ結果を返す線形作用素が別途定義されること。
```
