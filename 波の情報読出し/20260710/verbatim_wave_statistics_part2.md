# 1. まず普通の波では二重被覆は出ない

普通の複素波なら、

\[
z(\theta)=e^{i\theta}
\]

です。

この場合、

\[
\theta\rightarrow \theta+2\pi
\]

で、

\[
e^{i(\theta+2\pi)}=e^{i\theta}
\]

です。

つまり、1周すると完全に元へ戻る。

これは一価構造です。

\[
\boxed{
2\pi 回転で元に戻る波}
\]

です。

この構造だけでは、交換で自然に \(-1\) は出ません。

---

# 2. 二重被覆では「物理的には同じ姿勢」でも内部波形は符号反転する

二重被覆の最小式は、

\[
\psi(\theta)=e^{i\theta/2}
\]

です。

このとき、

\[
\theta\rightarrow \theta+2\pi
\]

とすると、

\[
\psi(\theta+2\pi)
=
e^{i(\theta+2\pi)/2}
\]

\[
=
e^{i\theta/2}e^{i\pi}
\]

\[
=
-\psi(\theta)
\]

です。

つまり、

\[
\boxed{
2\pi 回転で符号が反転する}
\]

しかし、さらにもう1周して、

\[
\theta\rightarrow \theta+4\pi
\]

なら、

\[
\psi(\theta+4\pi)
=
e^{i(\theta+4\pi)/2}
=
e^{i\theta/2}e^{i2\pi}
=
\psi(\theta)
\]

です。

したがって、

\[
\boxed{
4\pi 回転で初めて元に戻る}
\]

これが二重被覆構造です。

---

# 3. これを「ラベル」ではなく「内部位相フレーム」として読む

ここで重要なのは、

\[
\psi=e^{i\theta/2}
\]

を「フェルミオンだからこう」と置かないことです。

そうではなく、局在波が内部に持つ向き、つまり内部フレームを考えます。

たとえば、物理的に観測される向きを

\[
\mathbf{n}
\]

とします。

この \(\mathbf{n}\) は普通の三次元方向です。

ところが、その方向 \(\mathbf{n}\) を作る内部状態を、二成分スピノル

\[
\xi=
\begin{pmatrix}
u\\
v
\end{pmatrix}
\]

で表すとします。

このとき、物理的な方向は

\[
\mathbf{n}=\xi^\dagger \boldsymbol{\sigma}\xi
\]

で与えられます。

ここで \(\boldsymbol{\sigma}\) はパウリ行列です。

重要なのは、

\[
\xi \rightarrow -\xi
\]

としても、

\[
\mathbf{n}
\]

は変わらないことです。

実際、

\[
(-\xi)^\dagger \boldsymbol{\sigma}(-\xi)
=
\xi^\dagger \boldsymbol{\sigma}\xi
\]

です。

つまり、

\[
\boxed{
\xi \text{ と } -\xi \text{ は、同じ物理方向 } \mathbf{n} \text{ を表す}
}
\]

しかし内部波形としては、

\[
\xi
\]

と

\[
-\xi
\]

は符号が違う。

これがまさに、

\[
\boxed{
物理的には同じだが、内部波形としては二重に覆っている}
\]

という構造です。
