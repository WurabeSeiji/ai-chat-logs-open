## 背景と問題設定

### 20260715 で確認されたこと

1. **R の全域スイープで二つの最深候補帯が出現**
   - 候補帯1: R=0.697177902... → α=137.036020...
   - 候補帯2: R=0.688363902... → α=129.394...

2. **これらは倍音数・初期条件に依存しない**
   - N_B=2, 3, 5, 15, 63 のいずれでも同じ二点に集約
   - 振幅、位相、波長を変えても不変

3. **31刻み四相系列が両システムで共通**
   - System A（局在性交換）と System B（灰色準安定）で同じ周期構造

### 20260717 思考実験の洞察

- **単なる共鳴ピークではなく、共通安定点である可能性**
  - 異なる調和条件でも同じ二点に来る
  - 散乱系の基本的な固有点を読み出している

- **外部仮定の存在**
  - Paper7 の R=3 を参照しているが、**それを第一原理から導出していない**
  - これが現在の「外部仮定」

### フェーズ2: 初期条件依存性の調査（Phase 2）

**主実験**: `verify_section18_harmonic_dependence_v1.py`

**三つの側面**:

#### 2a. 反復回数依存性（Section 18.2）
```
検査: step=1, 2, 3, 5, 10, 20, 50, 100, 250, 512, 1024

判定:
  初期から gray_depth が大きい
    → 構造は初期から埋め込まれている（写像の固有点）
    
  反復で単調増加
    → 反復が構造を形成している（アトラクター形成）
```

**期待**:
- 初期（step=1-5）から深化の兆候が見える
- 反復による増幅幅は比較的小さい（10倍程度）

#### 2b. 調和数依存性（Section 18.3）
```
検査: N=1 (単色基底), N=2, 3, 4

判定:
  N=1: peak なし
  N=2: peak 出現
  N=3,4: N=2 と同じピーク位置
  
  → 追加倍音の有無がランク（自由度）を変えている
```

**期待**:
- N=1 では両ピーク不出現
- N≥2 では同じ二点に集約
- 倍音の詳細には鈍感（N=2でも N=63 でも同じ位置）

#### 2c. 内部状態の同一性（Section 18.4）
```
検査: R_128 と R_137 での終状態を比較

判定:
  内部軌道が完全に同じ
    → 一つのアトラクターを二つの R が支えている
    
  A↔B対称
    → 対称な双対アトラクター構造
    
  完全に異なる
    → 二つの独立したアトラクター
```

**期待**:
- 終状態の内部軌道が同じ（ただし位相が異なる可能性）
- あるいは A_128 ≈ B_137, B_128 ≈ A_137（対称性）

## 失敗時のフォールバック戦略

### 全フェーズで実装なし場合

**根本的な問題**:
- 二つのピークが単なる倍音共鳴である
- または数値実装に問題がある

**対応**:
1. 20260715 の CSV データを直接検査
2. Paper7 のセル計数を再確認
3. 別の不変量（リアプノフ指数など）を試す

### 不変量は一致するが、調和依存性が弱い場合

**解釈**:
- 二つの R は確かに特別だが、理由が「倍音共鳴」にある可能性
- 閉塞条件以外の機構で二つのピークが決まっている

**対応**:
- 信号理論的な解釈を探索
- 散乱行列のスペクトル分解をより詳しく分析

### Paper7 接続は弱いが他は強い場合

**解釈**:
- R_128, R_137 の重要性は確実だが、Paper7 との直接対応は偶然の可能性

**対応**:
- 代替的な 4D 幾何学的意味を探索
- 離散基礎との接続を別のアプローチで検証
