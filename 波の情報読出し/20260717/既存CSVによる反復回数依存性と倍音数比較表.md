## 3. `31` 刻み四相系列と `124` 完全周期候補の既存CSV確認

ここでは、`31, 62, 93, 124, 155, 186, 217, 248, 279` が単なる推測上の目印ではなく、保存済みCSVの時系列上にどのように現れているかを確認する。

結論を先に述べると、CSVが直接示しているのは「31ステップ周期」ではない。`31` は四相系列の刻みであり、同種の位相状態が再来する完全周期候補は `124=4×31` である。

参照CSV:

```text
波の情報読出し/20260715/minimal_system_B_gray_bugcheck_result_v1/log_sensitivity_alpha_low_standard_theory_v4/center/minimal_system_B_gray_direct_time_series_v4.csv
波の情報読出し/20260715/system_A_localization_exchange_R_sweep_result_v1/odd_kernel_N_1_2_3_5_15_63_collision_terrain_v1.csv
```

この表では、`31k` の上に、

```text
S≈0 → S負ピーク → S≈0 → S正ピーク → S≈0
```

という4相の波形が現れている。これは推測ではなく、`S` と `relative_phase_cycles` のCSV値から直接読める。

同符号・同種の状態は `124` ステップごとに再来している。

```text
S(62)  ≈ S(186) ≈ -0.02
S(124) ≈ S(248) ≈ +0.02
```

したがって、`31` は完全周期ではなく四分周期、`124` が完全帰還周期候補である。

特に `248=2×124=8×31` では `relative_phase_cycles≈0` となり、位相がほぼ帰還している。一方で、最良誤差は `best step so far=247` に立つ。したがって、既存CSV上では、`248` は「2周期目の位相帰還点」、`247=248-1` はその直前の「誤差最小点」として分離している。

これは、状態の周期帰還点と読出し誤差の最適点が同一ではないことを示す。少なくともこのCSVでは、誤差最小は帰還点そのものではなく、帰還直前の位相に現れている。

System A では、`31, 93, 155, 217` が形状・有効倍音数の整列点として現れ、`62, 186` が `B_to_A_transfer=1` の交換最大点として現れる。`124, 248` は交換最小点として現れる。

したがって、System A でも `31k` は単なる番号ではなく、

```text
整列 → 交換最大 → 整列 → 交換最小 → 整列
```

という離散的な反復波形を作っている。

ここでも同種の状態は `124` ステップごとに再来する。

```text
62  → 186 : 交換最大相の再来
124 → 248 : 交換最小相の再来
```

したがって、System A と System B は異なる観測量を見ているにもかかわらず、共通して `31` 刻みの四相構造と `124` 完全周期候補を示している。

| 15 | 31, 93, 155, 217 | 62, 186 | `31` 刻みで整列・交換が交互に現れる |
| 63 | 31, 93, 155, 217 | 62, 186 | `31` 刻みで整列・交換が交互に現れる |

この一覧では、`N_B=2,3,5,15,63` のいずれでも、`31k` 系列が保存されている。したがって、少なくともこの既存CSVの範囲では、`31` 刻みの四相系列は倍音数に依存した偶然ではなく、反復散乱写像側の内部位相構造として現れている。

ただし、これだけで「アトラクターである」と断定しない。ここで確認できるのは、`31k` 上に整列・交換最大・交換最小が規則的に現れ、同種の状態が `124` ステップごとに再来するという事実である。

この事実に対応する仮説は、固定点アトラクターではなく、`124` ステップ周期の周期軌道候補である。吸引性まで主張するには、異なる初期条件から同じ周期軌道へ近づくことを別途確認する必要がある。
