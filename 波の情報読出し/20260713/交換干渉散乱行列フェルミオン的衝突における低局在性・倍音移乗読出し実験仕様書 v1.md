## 2. 基本写像

### 2.1 入射チャネル

右向き入射チャネルと左向き入射チャネルを、

```math
\Psi^{in}
=
\begin{pmatrix}
\psi_+^{in}\\
\psi_-^{in}
\end{pmatrix}
```

とする。

本実験では、

```math
\psi_+^{in}=A
```

```math
\psi_-^{in}=B
```

として実装する。

### 2.2 反射振幅と透過振幅

交換干渉位相 `Delta_F` から、

```math
t_\Delta
=
e^{i\Delta_F/2}\cos\frac{\Delta_F}{2}
```

```math
r_\Delta
=
-i e^{i\Delta_F/2}\sin\frac{\Delta_F}{2}
```

を定義する。

確率読出しは、

```math
T_\Delta=|t_\Delta|^2
```

```math
R_\Delta=|r_\Delta|^2
```

である。

### 2.3 二チャネル散乱行列

散乱行列を、

```math
S_\Delta
=
\begin{pmatrix}
t_\Delta & r_\Delta\\
r_\Delta & t_\Delta
\end{pmatrix}
```

とする。

出射チャネルは、

```math
\Psi^{out}
=
S_\Delta\Psi^{in}
```

である。

実装上は、

```math
\psi_-^{out}
=
r_\Delta A_{ref}
+
t_\Delta B_{trans}
```

```math
\psi_+^{out}
=
t_\Delta A_{trans}
+
r_\Delta B_{ref}
```

と読む。

ここで `A_ref`, `B_ref` は反射後の向きに対応する基底波であり、`A_trans`, `B_trans` は透過後の向きに対応する基底波である。

### 2.4 圧縮読出しとの区別

圧縮方向読出し、

```math
q_{out}=q_{in}(T-R)
```

は、二つの出射チャネルを単一の期待値へ圧縮した読出しである。

本仕様書では、この圧縮を主出力にしない。

主出力は、

```text
minus_out
plus_out
```

の二つの出射チャネルである。

## 3. 読出し量

各出射チャネル `s in {minus_out, plus_out}` について、次を記録する。

| 読出し量 | 意味 |
|---|---|
| `norm` | 出射チャネルノルム |
| `p_chi` | 空間位相勾配読出し |
| `P_m_A`, `P_m_B` | 識別振動分布 |
| `H(n)` | 倍音分布 |
| `N_eff`, `N_eff_2` | 有効倍音次数 |
| `L` | 局在性 |
| `expected_origin_A`, `expected_origin_B` | A/B 起因成分の期待配分 |
| `d_q` | 二チャネル出力と圧縮方向読出しの差 |
| `compressed_q_A`, `compressed_q_B` | 圧縮方向読出し |

名前の毛を除去した実験では、`P_m_A`, `P_m_B` を個体名判定に使わない。

## 4. 実験段階

### 4.1 Stage A: 加速度V2基底確認

まず、AB二体加速度読出しにフェルミオン型反跳写像を組み込んだV2実験を参照する。

この段階では、低奇数倍音底、片側高次倍音条件、波束集束様読出しはまだ問わない。

記録する量は次である。

```text
fermionic_delta_f
fermionic_reflection_rate
fermionic_transmission_rate
fermionic_q_out_factor
max_Q_closed_abs
label_free_pass_vs_fermionic_match_all_cases
fermionic_regular_cell_harmonic_consistent_nonstrong_modes
fermionic_c1_area_sweep_detected_all_cases
```

判定は次である。

```text
Delta_F = pi
R = 1
T ≈ 0
q_out_factor = -1
Q_closed = 0
label-free D_AB/V_AB が通過型表示と一致する
独立 tau_read により chi-tau 面が維持される
```

この基底が成立した場合に限り、以後の低奇数倍音底探索と片側高次倍音読出しを、加速度様応答を持つフェルミオン型反跳相互作用の追加実験として扱う。

### 4.2 Stage 0: 完全反射基底確認

条件は次である。

```text
A_A = A_B
N_A = N_B
m_A != m_B
Delta_F = pi
高局在性 N
```

判定は次である。

```text
minus_out が A_ref と一致する。
plus_out が B_ref と一致する。
p_chi が反転する。
d_q が 0 に近い。
norm が保存される。
```

### 4.3 Stage 1: 低奇数倍音底探索

`N_A=N_B=N` とし、奇数倍音次数 `N` を下げる。

```text
N = 99, 63, 31, 15, 7, 3, 1
```

名前の毛あり条件と、名前の毛なし条件の両方で実行する。

安定読出しが成立する最小 `N` を `N_min` とする。

`N_min` は、片側だけ奇数倍音次数を上げる実験の基準値である。

### 4.4 Stage 2: 観測停止対照

散乱行列写像そのものには、読出し波による包絡減衰モデルを入れない。

したがって、本仕様書での観測停止対照は、診断読出しの有無が散乱行列出力を変えないことを確認する対照である。

記録する量は次である。

```text
readout_enabled
p_chi
L
d_q
```

`readout_enabled=true` と `false` で差が出ない場合、散乱行列写像そのものは観測読出しに依存しない。

### 4.5 Stage 3: 名前の毛除去

識別振動を除去する。

```math
D_A=D_B=1
```

または、

```math
m_A=m_B
```

この段階では、個体名ではなく、出射チャネル、左右方向、倍音次数で読む。

### 4.6 Stage 4: 片側高次倍音条件

```text
N_A = N_min
N_B > N_min
```

を主条件とする。

逆向き対照として、

```text
N_A > N_min
N_B = N_min
```

も実行する。

候補は次である。

```text
(N_A, N_B) = (N_min, 7), (N_min, 15), (N_min, 31), (N_min, 63)
(N_A, N_B) = (7, N_min), (15, N_min), (31, N_min), (63, N_min)
```

主判定は次である。

```text
L_A_after > L_A_bottom
L_B_after < L_B_high_control
H_A_high_component > 0
H_B_low_component > 0
reverse_control_pattern = mirrored
```

### 4.7 Stage 5: 対照群比較

片側高次倍音条件について、次を比較する。

```text
fermionic_scattering_complete_reflection
bosonic_scattering_transmission
partial_scattering_R055
simple_reflection
compressed_reflection
compressed_transmission
```

判定は次である。

| 結果 | 読み |
|---|---|
| 完全反射と compressed_reflection の `q` が一致 | 圧縮方向読出しが完全反射極限で一致 |
| 透過と compressed_transmission の `q` が一致 | 圧縮方向読出しが透過極限で一致 |
| 片側高次倍音条件で `L_A`, `L_B`, `H_A(n)`, `H_B(n)` が変化 | 片側高次倍音条件の読出しが成立 |
| simple_reflection と partial が異なる | 単純反射対照と部分散乱対照の差を記録 |

### 5.4 片側高次倍音条件の記録


逆向き対照では A/B を入れ替えて同じ量を記録する。

### 5.5 対照群比較の成立

```python
out_minus = r * a_ref + t * b_trans
out_plus = t * a_trans + r * b_ref
```
