## 1. 目的

本仕様書の目的は、過去のフェルミオン的完全弾性反射系列で用いた保存コピー近似を、交換干渉から得られる二チャネル散乱行列へ置き換え、低局在性条件および非対称倍音次数条件での読出しを検査することである。

本仕様書では、単なる線形重ね合わせ

```math
Z=A+B
```

を衝突演算とはみなさない。

線形波は、相互作用核、境界条件、または散乱演算子を持たない限り、一般に透過する。

したがって、反射を表すには、`q -> -q` の保存コピー近似ではなく、交換干渉から得た反射振幅 `r` と透過振幅 `t` を、分離された入射チャネルへ作用させる必要がある。

## 4. 基本写像

### 4.1 入射チャネル

右向き入射チャネルと左向き入射チャネルを、

```math
\Psi^{in}
=
\begin{pmatrix}
\psi_+^{in}\\
\psi_-^{in}
\end{pmatrix}
```

とする。

本実験では、

```math
\psi_+^{in}=A
```

```math
\psi_-^{in}=B
```

として実装する。

### 4.2 反射振幅と透過振幅

交換干渉位相 `Delta_F` から、

```math
t_\Delta
=
e^{i\Delta_F/2}\cos\frac{\Delta_F}{2}
```

```math
r_\Delta
=
-i e^{i\Delta_F/2}\sin\frac{\Delta_F}{2}
```

を定義する。

確率読出しは、

```math
T_\Delta=|t_\Delta|^2
```

```math
R_\Delta=|r_\Delta|^2
```

である。

### 4.3 二チャネル散乱行列

散乱行列を、

```math
S_\Delta
=
\begin{pmatrix}
t_\Delta & r_\Delta\\
r_\Delta & t_\Delta
\end{pmatrix}
```

とする。

出射チャネルは、

```math
\Psi^{out}
=
S_\Delta\Psi^{in}
```

である。

実装上は、

```math
\psi_-^{out}
=
r_\Delta A_{ref}
+
t_\Delta B_{trans}
```

```math
\psi_+^{out}
=
t_\Delta A_{trans}
+
r_\Delta B_{ref}
```

と読む。

ここで `A_ref`, `B_ref` は反射後の向きに対応する基底波であり、`A_trans`, `B_trans` は透過後の向きに対応する基底波である。

### 4.4 圧縮読出しとの区別

旧実装の有効方向読出し、

```math
q_{out}=q_{in}(T-R)
```

は、二つの出射チャネルを単一の期待値へ圧縮した読出しである。

本仕様書では、この圧縮を主出力にしない。

主出力は、

```text
minus_out
plus_out
```

の二つの出射チャネルである。

## 5. 読出し量

各出射チャネル `s in {minus_out, plus_out}` について、次を記録する。

| 読出し量 | 意味 |
|---|---|
| `norm` | 出射チャネルノルム |
| `p_chi` | 空間位相勾配読出し |
| `P_m_A`, `P_m_B` | 識別振動分布 |
| `H(n)` | 倍音分布 |
| `N_eff`, `N_eff_2` | 有効倍音次数 |
| `L` | 局在性 |
| `expected_origin_A`, `expected_origin_B` | A/B 起因成分の期待配分 |
| `copy_distance_d` | 完全反射保存コピーとの距離 |
| `compressed_q_A`, `compressed_q_B` | 圧縮方向読出し |

名前の毛を除去した実験では、`P_m_A`, `P_m_B` を個体名判定に使わない。

## 6. 実験段階

### 6.1 Stage 0: 旧完全反射条件再現

条件は次である。

```text
A_A = A_B
N_A = N_B
m_A != m_B
Delta_F = pi
高局在性 N
```

判定は次である。

```text
minus_out が A_ref と一致する。
plus_out が B_ref と一致する。
p_chi が反転する。
copy_distance_d が 0 に近い。
norm が保存される。
```

### 6.2 Stage 1: 低局在性底探索

`N_A=N_B=N` とし、`N` を下げる。

```text
N = 99, 63, 31, 15, 7, 3, 1
```

名前の毛あり条件と、名前の毛なし条件の両方で実行する。

安定読出しが成立する最小 `N` を `N_min` とする。

### 6.3 Stage 2: 観測停止対照

散乱行列写像そのものには、読出し波による包絡減衰モデルを入れない。

したがって、本仕様書での観測停止対照は、診断読出しの有無が散乱行列出力を変えないことを確認する対照である。

記録する量は次である。

```text
readout_enabled
p_chi
L
copy_distance_d
```

`readout_enabled=true` と `false` で差が出ない場合、散乱行列写像そのものは観測読出しに依存しない。

包絡減衰まで問う場合は、別途、読出し波強度に依存する減衰モデルを導入する。

### 6.4 Stage 3: 名前の毛除去

識別振動を除去する。

```math
D_A=D_B=1
```

または、

```math
m_A=m_B
```

この段階では、個体名ではなく、出射チャネル、左右方向、倍音次数で読む。

### 6.5 Stage 4: 非対称倍音次数

```text
N_A < N_B
```

または、

```text
N_A << N_B
```

とする。

候補は次である。

```text
(N_A, N_B) = (3, 63), (7, 63), (15, 63), (3, 31)
```

主判定は次である。

```text
部分反射で N_eff が中間値になるか。
L が中間的に変化するか。
P_m_A, P_m_B が R,T に対応するか。
```

### 6.6 Stage 5: 対照群比較

非対称次数条件について、次を比較する。

```text
fermionic_scattering_complete_reflection
bosonic_scattering_transmission
partial_scattering_R055
copy_reflection
simple_reflection
copy_transmission
```

判定は次である。

| 結果 | 読み |
|---|---|
| 完全反射と保存コピー反射が一致 | 旧近似は完全反射極限で有効 |
| 透過と copy_transmission が一致 | 線形透過対照が成立 |
| 部分反射だけで中間 `N_eff` が出る | 散乱行列が配分読出しを保持 |
| simple_reflection と partial が異なる | 単純反射では部分移乗を説明できない |

## 9. 本仕様書の結論

本仕様書は、旧保存コピー反射を否定しない。

旧保存コピー反射は、完全反射極限における有効近似として保持する。

ただし、不完全反射、低局在性、非対称倍音次数、局在性移乗を問う場合、`q -> -q` または `q_out=q_in(T-R)` だけでは不十分である。

反射振幅 `r` と透過振幅 `t` を持つ二チャネル散乱行列として出射チャネルを保持する必要がある。

この仕様により、完全反射、透過、部分反射、保存コピー反射、単純反射、通過コピーを同じ読出し形式で比較できる。
