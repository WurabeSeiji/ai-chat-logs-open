# フェルミオン型反跳写像の加速度基底と低奇数倍音底・片側高次倍音実験への接続準備論文 v1

## 0. 目的

本稿の目的は、V2 系列で確立したフェルミオン型反跳写像を前提に、それを AB 二体加速度読出しから低奇数倍音底探索および片側高次倍音実験へ接続する実験基底として位置づけることである。

本論の主題は、次の追加実験である。

```text
1. AB ともに奇数倍音次数を下げ、加速度様読出しが成立する底を探す。
2. 観測読出しを止め、底と減衰がどう変わるかを読む。
3. 名前の毛を除去し、無名条件で底を読む。
4. 底を基準に、片方だけ奇数倍音次数を上げる。
5. 低次数側 A と高次数側 B の局在性 L と倍音分布 H(n) の変化を読む。
```

底探索で得た `N_min` を、片側だけ奇数倍音次数を上げる実験の基準条件とする。

作業仮説は次である。

```text
A を低奇数倍音底に置く。
B だけ奇数倍音次数を上げる。
フェルミオン型反跳後、A は B 側の高次数成分を受けて局在性を上げる。
B は A 側の低次数成分を受けて局在性を下げる。
```

上記を実験で読む対象とする。

V2 で用いた散乱行列写像を基底として、その出射チャネルから倍音次数と局在性を読む。

実験順序は、散乱行列版の反跳写像が加速度様読出しを維持することを確認し、その後に片側高次倍音実験へ進む。

波束集束様の読出しは、位置様読出し、エネルギー様読出し、加速度様読出しを同じ反跳写像の上に置いて検査する。

このため、AB二体加速度読出しにフェルミオン型反跳写像を組み込んだV2実験を基底として採用する。

この基底実験では、

```text
Delta_F = pi
R = 1
T ≈ 0
q_out_factor = -1
```

が読まれ、さらにラベルなし `D_AB`, `V_AB` と独立 `tau_read` による `chi-tau` 面が維持されることを確認する。

そのうえで初めて、低奇数倍音底探索、観測停止、名前の毛除去、片側高次倍音条件の検査へ進む。

## 1. 先行モデルの位置づけ

### 1.1 方向読出し反転モデル

先行する完全弾性衝突モデルでは、有限解像度セル内で次の写像を用いた。

```math
q_A''=-q_A'
```

```math
q_B''=-q_B'
```

一方で、識別振動および代表振幅は保存した。

```math
m_A''=m_A',
\qquad
m_B''=m_B'
```

```math
A_A''=A_A',
\qquad
A_B''=A_B'
```

この処理は、方向読出し量 `q` に対する完全弾性反射写像である。

### 1.2 逆相核交換干渉モデル

後続の逆相核モデルでは、直接経路と交換経路を、

```math
\Psi_{\mathrm{direct}}(1,2)=P_A(1)P_B(2)
```

```math
\Psi_{\mathrm{exchange}}(1,2)=P_A(2)P_B(1)
```

とし、

```math
\Psi_{\Delta}(1,2)
=
\frac{1}{\sqrt2}
\left[
P_A(1)P_B(2)
+
e^{i\Delta_F}P_A(2)P_B(1)
\right]
```

を用いた。

このとき、`Delta_F=pi` で完全重なり点に節が形成され、反射率 `R` と通過率 `T` から、

```math
q_{\mathrm{out}}
=
q_{\mathrm{in}}(T-R)
```

として方向読出し量を生成した。

### 1.3 V2 散乱行列基準

本稿で用いる基準は、V2 系列で採用した二チャネル散乱行列である。

入射チャネルを、

```math
\Psi^{in}
=
\begin{pmatrix}
\psi_+^{in}\\
\psi_-^{in}
\end{pmatrix}
```

とし、交換干渉位相 `Delta_F` から反射振幅 `r_Delta` と透過振幅 `t_Delta` を読む。

出射チャネルは、

```math
\Psi^{out}
=
S_\Delta \Psi^{in}
=
\begin{pmatrix}
t_\Delta & r_\Delta\\
r_\Delta & t_\Delta
\end{pmatrix}
\begin{pmatrix}
\psi_+^{in}\\
\psi_-^{in}
\end{pmatrix}
```

で与える。

完全反射極限では、

```text
Delta_F = pi
R = 1
T ≈ 0
q_out_factor = -1
```

が読まれる。

ここで `q_out_factor=-1` は、手で与えたスカラー反転ではない。散乱行列から読まれた完全反射極限を、進行方向読出し量へ圧縮表示した値である。

本稿では、圧縮表示だけに潰さず、二つの出射チャネルを保持する。

```text
psi_+^out
psi_-^out
```

追加実験では、この出射チャネルから次を読む。

```text
代表振幅
識別振動
有効奇数倍音次数
局在性 L
倍音分布 H(n)
```

したがって、本稿の実験基底は、V2 散乱行列出射チャネルである。

## 2. 全情報状態の定義

### 2.1 内部座標

内部読出し変数をまとめて、

```math
u=(\chi,\tau,\eta)
```

と書く。

ここで `chi` は空間位相読出し、`tau` は時間位相読出し、`eta` は識別振動読出しである。

### 2.2 一体波

対象 `X in {A,B}` の一体波を、

```math
\psi_X(u)
=
A_X
K_X(\chi,\tau)
D_X(\eta)
e^{i\Phi_X(\chi,\tau,\eta)}
```

とする。

局在カーネルは、

```math
K_X(\chi,\tau)
=
S_{N_{\chi,X}}(\chi-\chi_X)
S_{N_{\tau,X}}(\tau-\tau_X)
```

である。

識別振動は、

```math
D_X(\eta)=e^{i m_X\eta}
```

とする。

名前の毛を除去する場合は、

```math
m_A=m_B
```

または

```math
D_A(\eta)=D_B(\eta)=1
```

とする。

位相は最小形として、

```math
\Phi_X(\chi,\tau,\eta)
=
q_X p_0(\chi-\chi_X)
+
\omega_X e_0(\tau-\tau_X)
+
\phi_X
```

を用いる。

### 2.3 実装用ベクトル表示

数値実装では、共通格子または共通基底 `B` を取り、

```math
\psi_X
\longleftrightarrow
\mathbf x_X
\in
\mathbb C^M
```

と表す。

`A` と `B` の倍音次数が異なる場合も、共通基底上で不足成分をゼロ埋めする。

```math
(\mathbf x_X)_k=0
\quad
(k\notin \mathcal I_X)
```

これにより、`N_A != N_B` の場合でも同じ交換干渉写像を適用できる。

正規化は、

```math
\langle \mathbf x_X,\mathbf x_X\rangle=1
```

を標準とする。

代表振幅を別に保持する場合は、

```math
\mathbf a_X=A_X\mathbf x_X
```

を用いる。

## 3. 交換干渉と散乱行列

### 3.0 線形干渉だけでは反射は出ない

分離された二つの入射波を、

```math
A_{\mathrm{in}},
\qquad
B_{\mathrm{in}}
```

とする。

線形波としての単なる重ね合わせは、

```math
Z_{\mathrm{in}}
=
A_{\mathrm{in}}
+
B_{\mathrm{in}}
```

である。

この重ね合わせ自体は、衝突演算ではない。非線形な相互作用、境界条件、または交換干渉核を別に与えない限り、線形波は一般に透過する。

したがって、完全弾性反射を、

```math
q\mapsto -q
```

というスカラー反転だけで表す処理は、V2 基準では圧縮表示である。

V2 基準では、交換干渉から反射率だけを読むのではなく、反射振幅と透過振幅を持つ散乱行列を作り、分離された入射チャネルへ作用させる。

### 3.1 直接テンソルと交換テンソル

二体状態空間を、

```math
\mathcal H_{AB}
=
\mathcal H\otimes\mathcal H
```

とする。

直接テンソルを、

```math
\mathbf D
=
\mathbf a_A\otimes\mathbf a_B
```

交換テンソルを、

```math
\mathbf E
=
\mathbf a_B\otimes\mathbf a_A
```

とする。

### 3.2 交換干渉合成

全情報交換干渉状態を、

```math
\mathbf\Psi_{\Delta}
=
\frac{
\mathbf D
+
e^{i\Delta_F}\mathbf E
}{
\sqrt{\mathcal N_\Delta}
}
```

と定義する。

規格化係数は固定値 `2` ではなく、

```math
\mathcal N_\Delta
=
\left\|
\mathbf D
+
e^{i\Delta_F}\mathbf E
\right\|^2
```

で計算する。

これは、`A` と `B` の局在性、倍音次数、識別振動、振幅が異なる場合に必要である。

ただし、`Psi_Delta` はそのまま二つの出射波 `A',B'` ではない。

`Psi_Delta` は交換干渉核であり、反射率・透過率、または反射振幅・透過振幅を得るための中間状態である。

したがって、

```math
Z_{\mathrm{out}}
=
A'
+
B'
```

を得るには、次節の散乱行列が必要である。

### 3.3 フェルミオン的条件

フェルミオン的逆相条件は、

```math
\Delta_F=\pi
```

である。

このとき、

```math
\mathbf\Psi_{\pi}
=
\frac{
\mathbf D-\mathbf E
}{
\sqrt{\mathcal N_\pi}
}
```

となる。

同相条件は、

```math
\Delta_F=0
```

であり、

```math
\mathbf\Psi_{0}
=
\frac{
\mathbf D+\mathbf E
}{
\sqrt{\mathcal N_0}
}
```

となる。

本稿では、前者をフェルミオン的交換干渉、後者をボゾン的交換干渉の最小モデルとして扱う。

### 3.4 反射振幅と透過振幅

交換干渉位相 `Delta_F` から、透過振幅 `t_Delta` と反射振幅 `r_Delta` を次で定義する。

```math
t_\Delta
=
e^{i\Delta_F/2}
\cos\frac{\Delta_F}{2}
```

```math
r_\Delta
=
-i e^{i\Delta_F/2}
\sin\frac{\Delta_F}{2}
```

このとき、

```math
T_\Delta=|t_\Delta|^2
=
\cos^2\frac{\Delta_F}{2}
```

```math
R_\Delta=|r_\Delta|^2
=
\sin^2\frac{\Delta_F}{2}
```

である。

この定義では、

```math
\Delta_F=0
\quad\Rightarrow\quad
t=1,\ r=0
```

となり、透過のみである。

また、

```math
\Delta_F=\pi
\quad\Rightarrow\quad
t=0,\ r=1
```

となり、完全反射である。

### 3.5 二チャネル散乱行列

右向き入射チャネルと左向き入射チャネルを、

```math
\Psi^{\mathrm{in}}
=
\begin{pmatrix}
\psi_+^{\mathrm{in}}\\
\psi_-^{\mathrm{in}}
\end{pmatrix}
```

とする。

交換干渉による出射チャネルを、

```math
\Psi^{\mathrm{out}}
=
S_\Delta
\Psi^{\mathrm{in}}
```

で定義する。

ここで、

```math
S_\Delta
=
\begin{pmatrix}
t_\Delta & r_\Delta\\
r_\Delta & t_\Delta
\end{pmatrix}
```

である。

したがって、

```math
\psi_+^{\mathrm{out}}
=
t_\Delta \psi_+^{\mathrm{in}}
+
r_\Delta \psi_-^{\mathrm{in}}
```

```math
\psi_-^{\mathrm{out}}
=
r_\Delta \psi_+^{\mathrm{in}}
+
t_\Delta \psi_-^{\mathrm{in}}
```

となる。

この式が、V2 系列で用いる実装用の基本写像である。

完全反射では、

```math
\psi_+^{\mathrm{out}}
=
\psi_-^{\mathrm{in}}
```

```math
\psi_-^{\mathrm{out}}
=
\psi_+^{\mathrm{in}}
```

となる。

不完全反射では、二つの出射チャネルはいずれも `A` 起因成分と `B` 起因成分の線形結合になる。

このとき、係数は確率ではなく複素振幅である。

したがって、`0.7` と `0.3` の配分を波形に使う場合は、確率重みではなく、

```math
\sqrt{0.7},
\qquad
\sqrt{0.3}
```

に位相を含めた振幅係数として扱う。

## 4. 出力一体情報の読出し

### 4.1 出射チャネルを基本出力にする

本稿の基本出力は、縮約密度ではなく、散乱行列から得られる二つの出射チャネルである。

```math
\psi_+^{\mathrm{out}},
\qquad
\psi_-^{\mathrm{out}}
```

これらは、右向き出射読出しと左向き出射読出しであり、A/B の名前ではない。

完全反射では入射チャネルが交換され、不完全反射では各出射チャネルが A 起因成分と B 起因成分の線形結合になる。

### 4.2 出射チャネルから再読出しする

散乱行列モデルでは、衝突後の読出し量を出射チャネルから読む。

対象は次である。

```text
m
A
N_eff
L
H(n)
```

これらを、出射チャネル `psi_+^out`, `psi_-^out` から再読出しする。

### 4.3 縮約密度は補助読出しである

`Psi_Delta` を行列表示して、

```math
(\Psi_\Delta)_{ij}
```

と書く。

第一スロットの縮約密度を、

```math
\rho_1
=
\Psi_\Delta\Psi_\Delta^\dagger
```

第二スロットの縮約密度を、

```math
\rho_2
=
\Psi_\Delta^\dagger\Psi_\Delta
```

と定義する。

格子積分重みを使う場合は、

```math
\rho_1
=
\Psi_\Delta W_2\Psi_\Delta^\dagger
```

```math
\rho_2
=
\Psi_\Delta^\dagger W_1\Psi_\Delta
```

を用いる。

ただし、この縮約密度は補助読出しである。

縮約密度だけでは、一般に二つの出射チャネル `psi_+^out`, `psi_-^out` を一意に復元できない。

したがって、反射後の二波読出しを検査する主手順では、`S_Delta` による二チャネル出力を保持する。

### 4.4 純状態へ戻せる条件

`rho_s` の最大固有値を、

```math
\lambda_{1,s}
```

とする。

```math
\frac{\lambda_{1,s}}{\operatorname{Tr}\rho_s}
\geq
1-\epsilon_{\mathrm{pure}}
```

であれば、第一固有ベクトルを出力一体波として読んでよい。

```math
\psi_{s,\mathrm{out}}
=
\mathrm{eig}_1(\rho_s)
```

この条件を満たさない場合、出力は一体波ではなく密度読出しとして保持する。

```text
純状態へ潰してはならない。
```

これは、補助的に縮約密度を使う場合の判定である。

二チャネル散乱行列を使う主実装では、純状態化の可否ではなく、各出射チャネル内の起因成分、倍音分布、局在性を読む。

## 5. 出力読出し量

### 5.1 ノルム

出射チャネル `s in {+,-}` のノルムを、

```math
W_s
=
\langle \psi_s^{out},\psi_s^{out}\rangle
```

とする。

密度表示を補助的に使う場合は、

```math
W_s=\operatorname{Tr}\rho_s
```

と読む。

### 5.2 位相勾配読出し

運動量様読出しは、

```math
p_{\chi,s}
=
\frac{
\langle \psi_s^{out},\hat p_\chi\psi_s^{out}\rangle
}{
\langle \psi_s^{out},\psi_s^{out}\rangle
}
```

で読む。

ここで、

```math
\hat p_\chi=-i\partial_\chi
```

である。

時間位相勾配読出しは、

```math
e_{\tau,s}
=
\frac{
\langle \psi_s^{out},\hat p_\tau\psi_s^{out}\rangle
}{
\langle \psi_s^{out},\psi_s^{out}\rangle
}
```

```math
\hat p_\tau=-i\partial_\tau
```

で読む。

### 5.3 識別振動分布

識別モード `m` の読出しは、

```math
P_s(m)
=
\frac{
\langle \psi_s^{out},\Pi_m\psi_s^{out}\rangle
}{
\langle \psi_s^{out},\psi_s^{out}\rangle
}
```

とする。

名前の毛を除去した実験では、この分布はラベル判別に使わない。

### 5.4 倍音分布

倍音基底射影を `Pi_n` として、

```math
H_s(n)
=
\frac{
\langle \psi_s^{out},\Pi_n\psi_s^{out}\rangle
}{
\langle \psi_s^{out},\psi_s^{out}\rangle
}
```

を定義する。

有効次数は、

```math
N_{\mathrm{eff},s}
=
\sum_n n H_s(n)
```

または二乗重みで、

```math
N^{(2)}_{\mathrm{eff},s}
=
\left(
\sum_n n^2 H_s(n)
\right)^{1/2}
```

と読む。

### 5.5 局在性

純状態の場合の局在性は、

```math
L_s
=
\int |\psi_s(u)|^4\,du
```

で読む。

密度表示の場合は、対角密度

```math
\rho_s(u,u)
```

を使い、

```math
L_s
=
\int \rho_s(u,u)^2\,du
```

とする。

この `L_s` が、今回の片側高次倍音実験の主読出し量である。

## 6. 圧縮表示対照の確認条件

V2 散乱行列から得られる二つの出射チャネルを主出力とする。

### 6.1 方向読出しだけへ圧縮する近似

交換干渉から `R,T` だけを読み、

```math
q_{\mathrm{out}}
=
q_{\mathrm{in}}(T-R)
```

を計算する。

これは、二つの出射チャネルを保持せず、方向読出しの期待値だけへ圧縮する表示である。

完全反射の場合は、この圧縮でも、

```math
q_{\mathrm{out}}=-q_{\mathrm{in}}
```

が得られる。

しかし、不完全反射の場合、本来は、

```math
\psi_{\mathrm{out}}
=
t\psi_{\mathrm{trans}}
+
r\psi_{\mathrm{ref}}
```

という二成分波であり、単一の `q_out` へ潰すと出射チャネル構造は失われる。

### 6.2 圧縮表示の判定

```math
d_q
=
\frac{
|q_{\mathrm{channel}}-q_{\mathrm{compressed}}|
}{
|q_{\mathrm{channel}}|+\epsilon
}
```

ここで `q_channel` は二チャネル出力から読む進行方向読出し、`q_compressed` は `q_in(T-R)` による圧縮表示である。

完全反射極限では `d_q` が小さいことを確認する。

片側高次倍音条件では、圧縮表示ではなく、二チャネル出力から `L` と `H(n)` を読む。

## 7. 実装手順

### 7.1 入力

実装は次を入力に取る。

```text
grid or basis B
psi_A
psi_B
Delta_F
incoming channel assignment
projectors Pi_L, Pi_R, Pi_m, Pi_n
operators p_chi, p_tau
epsilon_pure
```

### 7.2 アルゴリズム

```text
1. 共通基底 B 上で psi_A, psi_B を作る。
2. psi_A, psi_B を正規化する。
3. 代表振幅を含める場合は a_A=A_A psi_A, a_B=A_B psi_B とする。
4. 交換干渉位相 Delta_F から t_Delta, r_Delta を計算する。
5. S_Delta = [[t_Delta, r_Delta], [r_Delta, t_Delta]] を作る。
6. 入射チャネルベクトル Psi_in = [a_A, a_B]^T を作る。
7. Psi_out = S_Delta Psi_in を計算する。
8. psi_plus_out, psi_minus_out を得る。
9. 各出射チャネルから p_chi, e_tau, P(m), H(n), L を読む。
10. 必要に応じて D=outer(a_A,a_B), E=outer(a_B,a_A) を作り、縮約密度を補助読出しとして計算する。
11. q_out = q_in(T-R) への圧縮結果と、二チャネル出力の差 d_q を記録する。
12. 片側高次倍音条件では、二チャネル出力から L と H(n) を記録する。
```

### 7.3 最小 Python 対応

散乱行列を用いる最小形は次である。

```python
t = np.exp(0.5j * delta_f) * np.cos(0.5 * delta_f)
r = -1j * np.exp(0.5j * delta_f) * np.sin(0.5 * delta_f)
psi_plus_out = t * a_A + r * a_B
psi_minus_out = r * a_A + t * a_B
```

補助的に交換テンソルを評価する場合の最小形は次である。

```python
direct = np.outer(a_A, a_B)
exchange = np.outer(a_B, a_A)
psi2 = direct + np.exp(1j * delta_f) * exchange
psi2 = psi2 / np.linalg.norm(psi2)

rho_1 = psi2 @ psi2.conj().T
rho_2 = psi2.conj().T @ psi2
```

格子重みを含む場合は、`W1`, `W2` を対角重みとして、

```python
rho_1 = psi2 @ W2 @ psi2.conj().T
rho_2 = psi2.conj().T @ W1 @ psi2
```

を用いる。

## 8. 判定実験の順序

### 8.1 加速度V2基底の確認

まず、AB二体閉鎖位相系の加速度読出しに、フェルミオン型反跳写像を組み込む。

この段階では、低奇数倍音底、片側高次倍音条件、波束集束様読出しをまだ問わない。

目的は、散乱行列版反跳を入れても、AB二体の加速度様調和読出しが実験基底として維持されるかを確認することである。

判定する量は次である。

```text
Delta_F = pi
R = 1
T ≈ 0
q_out_factor = -1
Q_closed = 0
label_free D_AB/V_AB が通過型と一致
非 strong 読出しで調和射影が維持
独立 tau_read で chi-tau 面が維持
```

この条件が成立する場合、フェルミオン型反跳相互作用は、片側高次倍音実験へ進むための加速度基底を持つ。

### 8.2 散乱行列での完全反射基底確認

まず、完全反射条件で散乱行列写像を実行する。

```text
N_A = N_B
m_A != m_B
A_A = A_B
Delta_F = pi
```

判定する量は次である。

```text
q 反転
p 読出し反転
E 読出し全体保存
R 読出し全体保存
m 分布全体保存
局在性 L
倍音分布 H(n)
二チャネル保持と q_out 圧縮の差
```

この条件で、散乱行列出射チャネルが加速度基底の読出しを維持することを確認する。

### 8.3 低奇数倍音底の探索

次に、`N_A=N_B=N` として奇数倍音次数 `N` を下げる。

```text
N = 99, 63, 31, 15, 7, 3, 1
```

観測する量は次である。

```text
相互作用セル到達
q 反転成立
調和読出し成立
振幅減衰
局在性 L
```

ここで、安定した読出しが成立する最小 `N` を底と呼ぶ。

底は、片側だけ奇数倍音次数を上げる実験の基準条件である。

### 8.4 観測波停止対照

観測読出し波を停止した条件で同じ `N` 掃引を行う。

判定は次である。

```text
底 N_min が下がるか。
振幅減衰が減るか。
局在性 L の変化が残るか。
```

### 8.5 名前の毛除去

識別振動を除去する。

```math
D_A=D_B=1
```

または、

```math
m_A=m_B
```

として同じ `N` 掃引を行う。

この実験では、A/B の個体名ではなく、スロット `1,2` または左右領域プロジェクタで読む。

### 8.6 片側高次倍音実験

最後に、

```text
N_A = N_min
N_B > N_min
```

とする。

逆向き対照として、

```text
N_A > N_min
N_B = N_min
```

も実行する。

名前の毛を除去した場合でも、倍音分布の違いにより初期状態は構造的に区別できる。

主判定は次である。

```text
A 低次数・B 高次数条件で、A の L_A が上がるか。
A 低次数・B 高次数条件で、B の L_B が下がるか。
A の H_A(n) に B 側高次数成分が現れるか。
B の H_B(n) に A 側低次数成分が現れるか。
逆向き対照で同じ構造が反転して現れるか。
```

これにより、片側高次倍音条件で、低次数側と高次数側の局在性および倍音分布がどう変化するかを判定する。

## 9. 判定分岐

### 9.1 片側高次倍音条件で変化が読まれない場合

```text
H(n) が保存される。
L が保存される。
```

この場合、フェルミオン型反跳は方向読出し反転を生むが、片側高次倍音条件による局在性変化は読まれない。

### 9.2 片側高次倍音条件で差が出る場合

```text
A 低次数・B 高次数条件で A の L_A が上がる。
A 低次数・B 高次数条件で B の L_B が下がる。
A の H_A(n) に B 側高次数成分が現れる。
B の H_B(n) に A 側低次数成分が現れる。
```

この場合、片側高次倍音条件が、低次数側と高次数側の局在性および倍音分布を変える読出しとして成立する。

### 9.3 無名化が生じる場合

名前の毛を除去した片側高次倍音実験で、

```text
H_1(n) ≈ H_2(n)
L_1 ≈ L_2
P_1(m) ≈ P_2(m)
```

となり、かつ純状態固有値比が低下するなら、A/B の区別は個体名としてではなく、相互作用後の読出し構造として縮退する。

これは、無名性の破れではなく、無名性への回復として読む。

## 10. 本稿の結論

V2 系列では、フェルミオン型反跳写像を、単なる `-1` スカラー反転ではなく、交換干渉位相から得られる反射振幅 `r` と透過振幅 `t` を用いた二チャネル散乱行列として扱った。

AB二体加速度V2では、この写像の完全反射極限が、加速度様調和読出しと `chi-tau` 面を維持することを確認した。

本稿は、V2 で確立したフェルミオン型反跳写像を、低奇数倍音底探索と片側高次倍音実験へ進むための加速度基底として位置づける。

この基底を用いる場合、出力は二つの出射チャネルとして保持する。

縮約密度は補助読出しであり、縮約密度だけから二つの出射波を一意に復元することを基本手順とはしない。

したがって、次の実験は、AB二体加速度V2基底を参照し、そのうえで同じフェルミオン型反跳写像を低奇数倍音条件へ拡張する。

まず、AB ともに奇数倍音次数を下げ、加速度様読出しが成立する底を探す。

次に、観測停止と名前の毛除去を行い、底がどう変わるかを読む。

最後に、その底を基準として片方だけ奇数倍音次数を上げ、低次数側と高次数側の局在性 `L` と倍音分布 `H(n)` の変化を読む。

この順序を踏むことで、波束集束様の読出しを、加速度様応答を持つフェルミオン型反跳相互作用の上で検査できる。
