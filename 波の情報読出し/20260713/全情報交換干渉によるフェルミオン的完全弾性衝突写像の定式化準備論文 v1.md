# 全情報交換干渉によるフェルミオン的完全弾性衝突写像の定式化準備論文 v1

## 0. 目的

本稿の目的は、過去のフェルミオン的完全弾性反射実験で用いた近似を明示し、局在性・倍音次数・識別振動を含む全情報を同一の交換干渉写像で処理するための定式化を与えることである。

本稿は、過去の実験を否定しない。

過去の実験は、背景空間を先に置かない閉鎖位相系において、進行方向読出し量の反転、識別振動保存、代表振幅保存、多ゲージ保存読出しを検証する目的には十分であった。

しかし、次の問いには不十分である。

```text
フェルミオン的相互作用によって、
一方の高次倍音構造または局在性が、
他方の読出しへ移乗するか。
```

この問いでは、識別振動、代表振幅、倍音次数、局在性を単に保存コピーしてはならない。全情報を同一の交換干渉写像へ入れ、出力側から再読出しする必要がある。

---

## 1. 先行モデルの位置づけ

### 1.1 方向読出し反転モデル

先行する完全弾性衝突モデルでは、有限解像度セル内で次の写像を用いた。

```math
q_A''=-q_A'
```

```math
q_B''=-q_B'
```

一方で、識別振動および代表振幅は保存した。

```math
m_A''=m_A',
\qquad
m_B''=m_B'
```

```math
A_A''=A_A',
\qquad
A_B''=A_B'
```

この処理は、方向読出し量 `q` に対する完全弾性反射写像である。

### 1.2 逆相核交換干渉モデル

後続の逆相核モデルでは、直接経路と交換経路を、

```math
\Psi_{\mathrm{direct}}(1,2)=P_A(1)P_B(2)
```

```math
\Psi_{\mathrm{exchange}}(1,2)=P_A(2)P_B(1)
```

とし、

```math
\Psi_{\Delta}(1,2)
=
\frac{1}{\sqrt2}
\left[
P_A(1)P_B(2)
+
e^{i\Delta_F}P_A(2)P_B(1)
\right]
```

を用いた。

このとき、`Delta_F=pi` で完全重なり点に節が形成され、反射率 `R` と通過率 `T` から、

```math
q_{\mathrm{out}}
=
q_{\mathrm{in}}(T-R)
```

として方向読出し量を生成した。

### 1.3 保存コピー近似

上記モデルでは、反射方向は干渉から生成された。

しかし、識別振動、代表振幅、倍音次数、局在波形は、同一の交換干渉写像から再計算されたわけではない。

実装上は、少なくとも次の量は保存コピー近似として扱われた。

```text
m_A, m_B
A_A, A_B
N_chi,A, N_chi,B
N_tau,A, N_tau,B
局在カーネル形状
```

したがって、先行モデルの分類は次である。

```text
方向読出し:
  干渉生成または構成規則により更新。

識別・振幅・倍音・局在性:
  保存コピー近似。
```

この近似は、方向反転、p/E/R 保存、多ゲージ読出しの検証には有効である。

しかし、倍音移乗または局在性変化を検証する実験には使えない。

## 2. 全情報状態の定義

### 2.1 内部座標

内部読出し変数をまとめて、

```math
u=(\chi,\tau,\eta)
```

と書く。

ここで `chi` は空間位相読出し、`tau` は時間位相読出し、`eta` は識別振動読出しである。

### 2.2 一体波

対象 `X in {A,B}` の一体波を、

```math
\psi_X(u)
=
A_X
K_X(\chi,\tau)
D_X(\eta)
e^{i\Phi_X(\chi,\tau,\eta)}
```

とする。

局在カーネルは、

```math
K_X(\chi,\tau)
=
S_{N_{\chi,X}}(\chi-\chi_X)
S_{N_{\tau,X}}(\tau-\tau_X)
```

である。

識別振動は、

```math
D_X(\eta)=e^{i m_X\eta}
```

とする。

名前の毛を除去する場合は、

```math
m_A=m_B
```

または

```math
D_A(\eta)=D_B(\eta)=1
```

とする。

位相は最小形として、

```math
\Phi_X(\chi,\tau,\eta)
=
q_X p_0(\chi-\chi_X)
+
\omega_X e_0(\tau-\tau_X)
+
m_X\eta
+
\phi_X
```

を用いる。

### 2.3 実装用ベクトル表示

数値実装では、共通格子または共通基底 `B` を取り、

```math
\psi_X
\longleftrightarrow
\mathbf x_X
\in
\mathbb C^M
```

と表す。

`A` と `B` の倍音次数が異なる場合も、共通基底上で不足成分をゼロ埋めする。

```math
(\mathbf x_X)_k=0
\quad
(k\notin \mathcal I_X)
```

これにより、`N_A != N_B` の場合でも同じ交換干渉写像を適用できる。

正規化は、

```math
\langle \mathbf x_X,\mathbf x_X\rangle=1
```

を標準とする。

代表振幅を別に保持する場合は、

```math
\mathbf a_X=A_X\mathbf x_X
```

を用いる。

## 3. 全情報交換干渉写像

### 3.1 直接テンソルと交換テンソル

二体状態空間を、

```math
\mathcal H_{AB}
=
\mathcal H\otimes\mathcal H
```

とする。

直接テンソルを、

```math
\mathbf D
=
\mathbf a_A\otimes\mathbf a_B
```

交換テンソルを、

```math
\mathbf E
=
\mathbf a_B\otimes\mathbf a_A
```

とする。

### 3.2 交換干渉合成

全情報交換干渉状態を、

```math
\mathbf\Psi_{\Delta}
=
\frac{
\mathbf D
+
e^{i\Delta_F}\mathbf E
}{
\sqrt{\mathcal N_\Delta}
}
```

と定義する。

規格化係数は固定値 `2` ではなく、

```math
\mathcal N_\Delta
=
\left\|
\mathbf D
+
e^{i\Delta_F}\mathbf E
\right\|^2
```

で計算する。

これは、`A` と `B` の局在性、倍音次数、識別振動、振幅が異なる場合に必要である。

### 3.3 フェルミオン的条件

フェルミオン的逆相条件は、

```math
\Delta_F=\pi
```

である。

このとき、

```math
\mathbf\Psi_{\pi}
=
\frac{
\mathbf D-\mathbf E
}{
\sqrt{\mathcal N_\pi}
}
```

となる。

同相条件は、

```math
\Delta_F=0
```

であり、

```math
\mathbf\Psi_{0}
=
\frac{
\mathbf D+\mathbf E
}{
\sqrt{\mathcal N_0}
}
```

となる。

本稿では、前者をフェルミオン的交換干渉、後者をボゾン的交換干渉の最小モデルとして扱う。

## 4. 出力一体情報の読出し

### 4.1 保存コピーを禁止する

全情報交換干渉モデルでは、衝突後に次を直接コピーしてはならない。

```text
m_A
m_B
A_A
A_B
N_A
N_B
局在カーネル
```

これらは、出力二体状態 `Psi_Delta` から再読出しする。

### 4.2 一体縮約密度

`Psi_Delta` を行列表示して、

```math
(\Psi_\Delta)_{ij}
```

と書く。

第一スロットの縮約密度を、

```math
\rho_1
=
\Psi_\Delta\Psi_\Delta^\dagger
```

第二スロットの縮約密度を、

```math
\rho_2
=
\Psi_\Delta^\dagger\Psi_\Delta
```

と定義する。

格子積分重みを使う場合は、

```math
\rho_1
=
\Psi_\Delta W_2\Psi_\Delta^\dagger
```

```math
\rho_2
=
\Psi_\Delta^\dagger W_1\Psi_\Delta
```

を用いる。

### 4.3 純状態へ戻せる条件

`rho_s` の最大固有値を、

```math
\lambda_{1,s}
```

とする。

```math
\frac{\lambda_{1,s}}{\operatorname{Tr}\rho_s}
\geq
1-\epsilon_{\mathrm{pure}}
```

であれば、第一固有ベクトルを出力一体波として読んでよい。

```math
\psi_{s,\mathrm{out}}
=
\mathrm{eig}_1(\rho_s)
```

この条件を満たさない場合、出力は一体波ではなく密度読出しとして保持する。

```text
純状態へ潰してはならない。
```

これは、全情報干渉によって A/B の無名化または混合が生じた場合に必要である。

## 5. 出力読出し量

### 5.1 ノルム

```math
R_s
=
\operatorname{Tr}\rho_s
```

### 5.2 位相勾配読出し

運動量様読出しは、

```math
p_{\chi,s}
=
\frac{
\operatorname{Tr}(\rho_s\hat p_\chi)
}{
\operatorname{Tr}\rho_s
}
```

で読む。

ここで、

```math
\hat p_\chi=-i\partial_\chi
```

である。

時間位相勾配読出しは、

```math
e_{\tau,s}
=
\frac{
\operatorname{Tr}(\rho_s\hat p_\tau)
}{
\operatorname{Tr}\rho_s
}
```

```math
\hat p_\tau=-i\partial_\tau
```

で読む。

### 5.3 識別振動分布

識別モード `m` の読出しは、

```math
P_s(m)
=
\frac{
\operatorname{Tr}(\rho_s\Pi_m)
}{
\operatorname{Tr}\rho_s
}
```

とする。

名前の毛を除去した実験では、この分布はラベル判別に使わない。

### 5.4 倍音分布

倍音基底射影を `Pi_n` として、

```math
H_s(n)
=
\frac{
\operatorname{Tr}(\rho_s\Pi_n)
}{
\operatorname{Tr}\rho_s
}
```

を定義する。

有効次数は、

```math
N_{\mathrm{eff},s}
=
\sum_n n H_s(n)
```

または二乗重みで、

```math
N^{(2)}_{\mathrm{eff},s}
=
\left(
\sum_n n^2 H_s(n)
\right)^{1/2}
```

と読む。

### 5.5 局在性

純状態の場合の局在性は、

```math
L_s
=
\int |\psi_s(u)|^4\,du
```

で読む。

密度表示の場合は、対角密度

```math
\rho_s(u,u)
```

を使い、

```math
L_s
=
\int \rho_s(u,u)^2\,du
```

とする。

この `L_s` が、今回の局在性移乗実験の主読出し量である。

## 6. 旧近似の再現条件

旧モデルは、全情報交換干渉モデルの次の近似として再現される。

### 6.1 方向読出しだけを使う近似

交換干渉から `R,T` だけを読み、

```math
q_{\mathrm{out}}
=
q_{\mathrm{in}}(T-R)
```

を計算する。

その後、

```math
m_X' = m_X
```

```math
A_X' = A_X
```

```math
N_X' = N_X
```

```math
K_X' = K_X
```

と置く。

これが保存コピー近似である。

### 6.2 近似成立の判定

全情報交換干渉の読出し `rho_s` と、保存コピー近似で作った読出し `rho_s^{copy}` を比較する。

```math
d_s
=
\frac{
\|\rho_s-\rho_s^{copy}\|_F
}{
\|\rho_s\|_F
}
```

全読出し量について、

```math
|O_s-O_s^{copy}|
<
\epsilon_O
```

が成り立つ場合、旧近似はその実験条件で有効である。

## 7. 実装手順

### 7.1 入力

実装は次を入力に取る。

```text
grid or basis B
psi_A
psi_B
Delta_F
projectors Pi_L, Pi_R, Pi_m, Pi_n
operators p_chi, p_tau
epsilon_pure
```

### 7.2 アルゴリズム

```text
1. 共通基底 B 上で psi_A, psi_B を作る。
2. psi_A, psi_B を正規化する。
3. 代表振幅を含める場合は a_A=A_A psi_A, a_B=A_B psi_B とする。
4. D = outer(a_A, a_B) を作る。
5. E = outer(a_B, a_A) を作る。
6. Psi = D + exp(i Delta_F) E を作る。
7. Psi を norm(Psi)=1 へ正規化する。
8. rho_1 = Psi @ Psi^dagger を作る。
9. rho_2 = Psi^dagger @ Psi を作る。
10. rho_1, rho_2 から R, p_chi, e_tau, P(m), H(n), L を読む。
11. 最大固有値比で純状態近似が許されるか判定する。
12. 保存コピー近似との差 d_s を測る。
```

### 7.3 最小 Python 対応

格子重みを省略した最小形は次である。

```python
direct = np.outer(a_A, a_B)
exchange = np.outer(a_B, a_A)
psi2 = direct + np.exp(1j * delta_f) * exchange
psi2 = psi2 / np.linalg.norm(psi2)

rho_1 = psi2 @ psi2.conj().T
rho_2 = psi2.conj().T @ psi2
```

格子重みを含む場合は、`W1`, `W2` を対角重みとして、

```python
rho_1 = psi2 @ W2 @ psi2.conj().T
rho_2 = psi2.conj().T @ W1 @ psi2
```

を用いる。

## 8. 判定実験の順序

### 8.1 旧条件再現

まず、過去の完全弾性衝突実験と同じ条件で全情報交換干渉を実行する。

```text
N_A = N_B
m_A != m_B
A_A = A_B
Delta_F = pi
```

比較対象は、保存コピー近似である。

判定する量は次である。

```text
q 反転
p 読出し反転
E 読出し保存
R 読出し保存
m 読出し保存
局在性 L
倍音分布 H(n)
copy 近似との差 d_s
```

この差が十分小さい場合、過去の実験は有効近似として保持される。

### 8.2 低局在性底の探索

次に、`N_A=N_B=N` として `N` を下げる。

```text
N = 99, 63, 31, 15, 7, 3, 1
```

観測する量は次である。

```text
相互作用セル到達
q 反転成立
調和読出し成立
振幅減衰
局在性 L
copy 近似との差 d_s
```

ここで、安定した読出しが成立する最小 `N` を底と呼ぶ。

### 8.3 観測波停止対照

観測読出し波を停止した条件で同じ `N` 掃引を行う。

判定は次である。

```text
底 N_min が下がるか。
振幅減衰が減るか。
局在性 L の変化が残るか。
```

### 8.4 名前の毛除去

識別振動を除去する。

```math
D_A=D_B=1
```

または、

```math
m_A=m_B
```

として同じ `N` 掃引を行う。

この実験では、A/B の個体名ではなく、スロット `1,2` または左右領域プロジェクタで読む。

### 8.5 非対称次数実験

最後に、

```text
N_A < N_B
```

または、

```text
N_A << N_B
```

とする。

名前の毛を除去した場合でも、倍音分布の違いにより初期状態は構造的に区別できる。

主判定は次である。

```text
H_1(n), H_2(n) が接近するか。
N_eff,1 と N_eff,2 が接近するか。
L_1 と L_2 が接近するか。
最大固有値比が下がり、純状態判別が失われるか。
```

これにより、フェルミオン的交換干渉が局在性または倍音構造を再配分するかを判定する。

## 9. 期待される分岐

### 9.1 保存コピー近似と一致する場合

```text
d_s が小さい。
H(n) が保存される。
L が保存される。
```

この場合、フェルミオン的反射は方向読出し反転を生むが、倍音移乗または局在性再配分は生まない。

### 9.2 全情報干渉で差が出る場合

```text
d_s が有意に大きい。
H_A(n), H_B(n) が接近する。
L_A, L_B が接近する。
lambda_1 / Tr(rho) が低下する。
```

この場合、過去の保存コピー近似は方向読出し実験には有効であっても、局在性実験には不十分である。

### 9.3 無名化が生じる場合

名前の毛を除去した非対称次数実験で、

```text
H_1(n) ≈ H_2(n)
L_1 ≈ L_2
P_1(m) ≈ P_2(m)
```

となり、かつ純状態固有値比が低下するなら、A/B の区別は個体名としてではなく、相互作用後の読出し構造として縮退する。

これは、無名性の破れではなく、無名性への回復として読む。

## 10. 本稿の結論

過去のフェルミオン的完全弾性反射モデルは、全情報干渉モデルではなく、方向読出し反転を中心とする保存コピー近似であった。

この近似は、背景空間なしの完全弾性反射、p/E/R 保存、多ゲージ干渉読出しの検証には有効である。

しかし、局在性、倍音次数、識別振動の移乗または再配分を問う実験では、この近似を使ってはならない。

本稿では、直接テンソルと交換テンソルを用い、全情報を同一の交換干渉写像へ入れる定式化を与えた。

この定式化では、出力は保存コピーされず、二体干渉状態から縮約密度として再読出しされる。

したがって、次の実験は、まず本稿の全情報交換干渉写像により旧実験条件を再現し、保存コピー近似との差が十分小さいことを確認する必要がある。

そのうえで、低局在性、観測停止、名前の毛除去、非対称次数の順に実験する。

この順序を踏まない場合、局在性変化または波束収縮様読出しを検査したことにはならない。
