## 1. 目的

本仕様書の目的は、全情報交換干渉写像を用いて、低局在性波および非対称倍音次数条件における局在性と倍音分布の再配分を検査することである。

前段の完全弾性衝突系列では、フェルミオン的逆相核による反射方向読出し、識別振動保存、代表振幅保存、p/E/R 保存読出しが検査された。

ただし、その系列では、反射方向は干渉または写像から生成されたが、識別振動、代表振幅、倍音次数、局在カーネルは保存コピー近似として扱われた。

したがって、過去の実験は次を検査していない。

```text
フェルミオン的交換干渉により、
高次倍音構造または局在性が、
相手側の読出しへ移乗するか。
```

本仕様書では、保存コピー近似を主実験に使わない。

全情報を同一の交換干渉写像へ入れ、出力二体状態から縮約密度を作り、そこから局在性、倍音分布、識別分布、位相勾配を再読出しする。

## 3. 本仕様書で主張しないこと

本仕様書は、次を主張しない。

| 主張しないこと | 理由 |
|---|---|
| 標準量子測定問題の解決 | 本仕様書は閉鎖位相系内の交換干渉読出し実験である |
| 波束収縮の導出 | 本仕様書の主対象は局在性 `L` と倍音分布 `H(n)` の再配分である |
| 観測と相互作用の分離 | 本系列では観測は相互作用読出しの一部である |
| 保存コピー近似を主実験に使うこと | 局在性変化を検査するには出力側から再読出しが必要である |
| `N_A`, `N_B` を外部ラベルとして固定判定すること | 倍音次数は出力密度から再読出しする |
| 名前の毛を個体実在とみなすこと | `m_A,m_B` は識別読出しチャネルである |
| ボゾン/フェルミオンを標準粒子種として同一視すること | 本仕様書では交換位相条件の作業名である |

## 4. 基本方針

### 4.1 保存コピー近似を対照群に下げる

過去の反射系列では、衝突後に次が保存された。

```text
m_A, m_B
A_A, A_B
N_A, N_B
局在カーネル形状
```

この処理は、方向読出し反転を検証するには有効である。

しかし、局在性または倍音移乗の検査では、これらを保存コピーしてはならない。

本仕様書では、保存コピー近似を対照群としてのみ使用する。

### 4.2 出力は縮約密度から読む

全情報交換干渉状態を

```math
\Psi_{\Delta}
```

として作り、そこから

```math
\rho_1
=
\Psi_{\Delta}\Psi_{\Delta}^{\dagger}
```

```math
\rho_2
=
\Psi_{\Delta}^{\dagger}\Psi_{\Delta}
```

を構成する。

出力読出し量は、`rho_1`, `rho_2` から読む。

### 4.3 純状態へ無理に戻さない

出力縮約密度の最大固有値比を

```math
\kappa_s
=
\frac{\lambda_{1,s}}{\operatorname{Tr}\rho_s}
```

とする。

```math
\kappa_s
\geq
1-\epsilon_{\mathrm{pure}}
```

を満たす場合のみ、第一固有ベクトルを出力一体波として扱う。

満たさない場合、出力は混合読出しとして保持する。

この場合、A/B の個体名へ強制的に戻さない。

## 5. 実験対象

### 5.1 一体波

対象 `X in {A,B}` の一体波を、

```math
\psi_X(u)
=
A_X
S_{N_{\chi,X}}(\chi-\chi_X)
S_{N_{\tau,X}}(\tau-\tau_X)
D_X(\eta)
e^{i\Phi_X(\chi,\tau,\eta)}
```

とする。

```math
u=(\chi,\tau,\eta)
```

である。

識別振動は、

```math
D_X(\eta)=e^{i m_X\eta}
```

とする。

名前の毛を除去する場合は、

```math
D_A=D_B=1
```

または、

```math
m_A=m_B
```

とする。

### 5.2 全情報交換干渉状態

直接テンソルを、

```math
D
=
a_A\otimes a_B
```

交換テンソルを、

```math
E
=
a_B\otimes a_A
```

とする。

ここで、

```math
a_X=A_X\psi_X
```

である。

全情報交換干渉状態を、

```math
\Psi_{\Delta}
=
\frac{
D+e^{i\Delta_F}E
}{
\left\|D+e^{i\Delta_F}E\right\|
}
```

とする。

## 6. 対照群

### 6.1 フェルミオン的全情報交換干渉

```math
\Delta_F=\pi
```

を用いる。

```math
\Psi_{\pi}
=
\frac{D-E}{\|D-E\|}
```

である。

これは本仕様書の主実験である。

### 6.2 ボゾン的全情報交換干渉

```math
\Delta_F=0
```

を用いる。

```math
\Psi_0
=
\frac{D+E}{\|D+E\|}
```

である。

これは同相交換干渉の対照群である。

### 6.3 保存コピー反射近似

旧反射系列の近似を対照群として用いる。

```text
q_A -> -q_A
q_B -> -q_B
m_A, m_B を保存
A_A, A_B を保存
N_A, N_B を保存
局在カーネルを保存
```

この対照群は、局在性移乗を検出するためには使わない。

全情報交換干渉との差を測るために使う。

### 6.4 単純反射対照

反射演算子 `R_chi` を用いて、

```math
\psi_A' = R_{\chi}\psi_A
```

```math
\psi_B' = R_{\chi}\psi_B
```

とする。

この対照群では、波形、倍音分布、局在性は保存される。

局在性変化が単なる反射操作から出ていないことを確認するために用いる。

### 6.5 通過コピー対照

相互作用セルを通過させ、

```math
\psi_A'=\psi_A
```

```math
\psi_B'=\psi_B
```

とする。

これは、波形保存型の通過対照である。

## 7. 読出し量

### 7.1 方向読出し

位相勾配読出しを、

```math
p_{\chi,s}
=
\frac{
\operatorname{Tr}(\rho_s \hat p_{\chi})
}{
\operatorname{Tr}\rho_s
}
```

とする。

ここで、

```math
\hat p_{\chi}=-i\partial_{\chi}
```

である。

旧実験の `q` に対応する量は、`p_chi` の符号読出しとして扱う。

### 7.2 時間位相勾配

```math
e_{\tau,s}
=
\frac{
\operatorname{Tr}(\rho_s \hat p_{\tau})
}{
\operatorname{Tr}\rho_s
}
```

```math
\hat p_{\tau}=-i\partial_{\tau}
```

である。

### 7.3 識別分布

```math
P_s(m)
=
\frac{
\operatorname{Tr}(\rho_s\Pi_m)
}{
\operatorname{Tr}\rho_s
}
```

を記録する。

名前の毛除去条件では、この値を個体ラベル判定に使わない。

### 7.4 倍音分布

倍音射影を `Pi_n` として、

```math
H_s(n)
=
\frac{
\operatorname{Tr}(\rho_s\Pi_n)
}{
\operatorname{Tr}\rho_s
}
```

を記録する。

有効次数を、

```math
N_{\mathrm{eff},s}
=
\sum_n nH_s(n)
```

および、

```math
N_{\mathrm{eff},s}^{(2)}
=
\left(\sum_n n^2H_s(n)\right)^{1/2}
```

で読む。

### 7.5 局在性

密度対角から、

```math
L_s
=
\int \rho_s(u,u)^2\,du
```

を読む。

純状態近似が成立する場合は、

```math
L_s
=
\int |\psi_s(u)|^4\,du
```

としてもよい。

### 7.6 混合度

最大固有値比

```math
\kappa_s
=
\lambda_{1,s}/\operatorname{Tr}\rho_s
```

を記録する。

`kappa_s` が低下する場合、出力は単一局所波として判別しにくくなる。

### 7.7 保存コピー近似差

全情報交換干渉の縮約密度 `rho_s` と保存コピー近似の密度 `rho_s^copy` の差を、

```math
d_s
=
\frac{
\|\rho_s-\rho_s^{copy}\|_F
}{
\|\rho_s\|_F
}
```

で読む。

## 8. 実験段階

### 8.1 Stage 0: 旧条件再現

目的は、全情報交換干渉写像が、過去の完全弾性反射系列の条件を再現するか確認することである。

条件は次である。

```text
A_A = A_B
N_A = N_B
m_A != m_B
Delta_F = pi
高局在性 N
```

記録する量は次である。

```text
p_chi 反転
e_tau 保存
R 保存
P(m) 保存
H(n) 保存
L 保存
kappa
d_s
```

`d_s` が小さい場合、過去の保存コピー近似は旧条件で有効近似として保持される。

### 8.2 Stage 1: 低局在性底探索

`N_A=N_B=N` とし、`N` を下げる。

最小候補は次である。

```text
N = 99, 63, 31, 15, 7, 3, 1
```

判定量は次である。

```text
相互作用セル到達
p_chi 反転
調和読出し成立
R 保存
H(n) 安定性
L 安定性
急激な振幅減衰の有無
d_s
```

安定読出しが成立する最小 `N` を、

```text
N_min
```

と呼ぶ。

### 8.3 Stage 2: 観測波停止対照

Stage 1 と同じ `N` 掃引を、観測読出し波を停止した条件で行う。

判定は次である。

```text
N_min が下がるか
振幅減衰が消えるか
L の変化が残るか
H(n) の変化が残るか
```

読出し波を停止しても全情報交換干渉による局在性再配分が残る場合、それは読出し波だけの効果ではない。

### 8.4 Stage 3: 名前の毛除去

識別振動を除去する。

```math
D_A=D_B=1
```

または、

```math
m_A=m_B
```

とする。

この段階では、個体名 `A/B` ではなく、次で読む。

```text
slot 1 / slot 2
left / right
low-N / high-N
```

名前の毛を除去しても安定読出しが成立する `N_min` を記録する。

### 8.5 Stage 4: 非対称倍音次数

```text
N_A < N_B
```

または、

```text
N_A << N_B
```

とする。

候補は次である。

```text
(N_A, N_B) =
(7, 31)
(7, 63)
(3, 31)
(3, 63)
(1, 31)
```

名前の毛を残す条件と、名前の毛を除去する条件の両方で実行する。

主判定は次である。

```text
H_1(n), H_2(n) が接近するか
N_eff,1 と N_eff,2 が接近するか
L_1 と L_2 が接近するか
kappa_1, kappa_2 が低下するか
保存コピー近似との差 d_s が増えるか
```

### 8.6 Stage 5: 対照群比較

Stage 4 の非対称次数条件について、次を比較する。

```text
fermionic_full: Delta_F = pi
bosonic_full: Delta_F = 0
copy_reflection: 保存コピー反射近似
simple_reflection: 単純反射対照
copy_transmission: 通過コピー対照
```

判定は次である。

| 結果 | 読み |
|---|---|
| `fermionic_full` のみで `H,L` が再配分 | フェルミオン的全情報交換干渉に特有 |
| `bosonic_full` でも同程度に再配分 | 交換対称化一般の効果 |
| `copy_reflection` でも同じ | 実験は保存コピーを読んでいるだけ |
| `simple_reflection` でも同じ | 単なる反射操作の効果 |
| `copy_transmission` でも同じ | 初期読出しまたは解析指標の問題 |

## 9. 成功条件

### 9.1 旧条件再現

Stage 0 で、次を満たす。

```text
p_chi 反転が成立
e_tau 保存が成立
R 保存が成立
P(m) 保存が成立
d_s が小さい
```

これにより、過去の保存コピー近似は旧条件で有効近似として保持される。

### 9.2 低局在性底の確保

Stage 1 で、少なくとも一つの低 `N` 条件において、

```text
相互作用セル到達
p_chi 反転
R 保存
L 読出し
H(n) 読出し
```

が同時に成立する。

### 9.3 観測停止対照の成立

Stage 2 で、観測波停止条件と観測波あり条件との差を記録できる。

これは、観測波が局在性または振幅減衰へ与える影響を分離するための条件である。

### 9.4 非対称次数での差分検出

Stage 4 または Stage 5 で、

```text
fermionic_full と保存コピー近似の d_s が有意に異なる
```

または、

```text
H(n), N_eff, L, kappa に有意差が出る
```

場合、過去の保存コピー近似では見えない全情報干渉効果が検出されたと判定する。

## 10. 破綻条件

| 破綻条件 | 意味 |
|---|---|
| Stage 0 が再現できない | 全情報交換干渉写像が過去実験条件を保持できない |
| `rho_s` の規格化が崩れる | 縮約密度構成または格子重みが不適切 |
| `R` が保存しない | 振幅または規格化処理が不適切 |
| `H(n)` が基底依存で大きく変わる | 倍音基底または射影が不適切 |
| `L` が格子解像度で大きく変わる | 局在性読出しが数値格子依存 |
| `copy_transmission` でも移乗が出る | 指標または初期条件が移乗を作っている |
| `simple_reflection` でも移乗が出る | 交換干渉でなく反射処理が原因 |
| 名前の毛除去で判定軸が消える | slot/left/right/次数による読出し設計が不足 |

```text
tau_A, tau_B

```

### 11.2 共通基底

`A` と `B` の次数が異なる場合、共通基底を作る。

```text
N_basis = max(N_A, N_B)
```

不足成分はゼロ埋めする。

```math
x_{X,n}=0
\quad
(n>N_X)
```

### 11.3 最小演算

最小実装は次である。

```python
a_A = A_A * psi_A
a_B = A_B * psi_B

direct = np.outer(a_A, a_B)
exchange = np.outer(a_B, a_A)

psi2 = direct + np.exp(1j * delta_f) * exchange
psi2 = psi2 / np.linalg.norm(psi2)

rho_1 = psi2 @ psi2.conj().T
rho_2 = psi2.conj().T @ psi2
```

格子重みを使う場合は、

```python
rho_1 = psi2 @ W2 @ psi2.conj().T
rho_2 = psi2.conj().T @ W1 @ psi2
```

とする。

## 12. 実験順序

実験は必ず次の順序で行う。

```text
1. Stage 0: 旧条件再現
2. Stage 1: 低局在性底探索
3. Stage 2: 観測波停止対照
4. Stage 3: 名前の毛除去
5. Stage 4: 非対称倍音次数
6. Stage 5: 対照群比較
```

Stage 0 が成立しない場合、Stage 1 以降へ進まない。

Stage 1 で `N_min` が確保できない場合、Stage 4 の非対称次数実験へ進まない。

Stage 5 で対照群との差が出ない場合、フェルミオン的交換干渉固有の局在性再配分とは判定しない。

---

## 13. 期待される成果

本仕様書で期待される成果は、次のいずれかである。

### 13.1 保存コピー近似が十分だった場合

全情報交換干渉と保存コピー近似の差が小さく、`H(n)` と `L` が保存される場合、過去の近似は局在性実験に対しても十分であったと判定する。

### 13.2 保存コピー近似が旧条件のみ有効だった場合

Stage 0 では差が小さいが、低局在性または非対称次数条件で `d_s` が増える場合、過去の近似は旧条件では有効だが、局在性・倍音移乗実験では不十分と判定する。

### 13.3 フェルミオン的全情報干渉でのみ再配分が出る場合

`fermionic_full` のみで `H(n)`, `N_eff`, `L`, `kappa` が有意に変化し、他の対照群では変化しない場合、フェルミオン的全情報交換干渉による局在性再配分候補として保持する。

### 13.4 同相交換干渉でも再配分が出る場合

`bosonic_full` でも同程度の再配分が出る場合、これはフェルミオン的逆相固有ではなく、交換対称化一般の効果として扱う。

---

## 14. 本仕様書の結論

本仕様書は、過去の完全弾性衝突系列を、保存コピー近似を含む有効モデルとして保持する。

ただし、局在性または倍音移乗を問う実験では、その近似を主実験として使わない。

本仕様書では、全情報交換干渉写像により二体状態を作り、縮約密度から全読出し量を再構成する。

この手順により、低局在性、観測波停止、名前の毛除去、非対称倍音次数、フェルミオン的逆相・ボゾン的同相・保存コピー近似・単純反射・通過コピーの対照比較が可能になる。

この仕様を満たして初めて、フェルミオン的相互作用により局在性または倍音次数が再配分されたかを検査したと言える。
