# 干渉計算プログラムの読み方

サンプルプログラム名：波の情報読出し/20260713/run_exchange_scattering_matrix_fermionic_localization_transfer_preliminary_v1.py

## 1. `Params` の読み方

このプログラムでは、実験条件を `Params` という `dataclass` にまとめている。

```python
@dataclass
class Params:
    chi_grid_n: int = 512
    eta_grid_n: int = 16
    high_n: int = 63
    chi_center: float = 0.0
    p0: float = 1.0
    q_A: float = 1.0
    q_B: float = -1.0
    A_A: float = 1.0
    A_B: float = 1.0
    m_A: int = 1
    m_B: int = 2
    delta_f_fermion: float = math.pi
    delta_f_boson: float = 0.0
    delta_f_half: float = math.pi / 2.0
    p_tol: float = 1.0e-2
    d_q_tol: float = 1.0e-2
    name_tol: float = 1.0e-8
    norm_tol: float = 1.0e-10
    recursive_collision_count: int = 128
    r_sweep_values: Tuple[float, ...] = (0.00, 0.51, 0.55, 0.60, 0.70, 0.90, 1.00)
```

`Params` は、波の定義、散乱条件、判定しきい値、再帰実験の回数をまとめた設定表である。

実際の実行では、`run()` の冒頭で次のように生成される。

```python
params = Params()
```

つまり、特に引数を渡さなければ、上に書かれた初期値で実験が実行される。

### 1.1 格子の設定

| プロパティ | 初期値 | 役割 |
|---|---:|---|
| `chi_grid_n` | `512` | 位置位相 `chi` 方向の分割数。波形、密度、局在性を読む主な格子数。 |
| `eta_grid_n` | `16` | 識別位相 `eta` 方向の分割数。A/B を区別する内部振動、つまり名前の毛を読む格子数。 |

`chi` は、位置のように読む位相方向である。

`eta` は、A と B の識別振動を入れるための内部位相方向である。

このプログラムでは、状態ベクトルは最終的に

```text
chi_grid_n * eta_grid_n
```

個の複素数成分を持つ一次元ベクトルとして扱われる。

ただし、読み出すときには `reshape_state()` によって、

```text
(chi_grid_n, eta_grid_n)
```

の二次元配列へ戻される。

### 1.2 波形と位置位相の設定

| プロパティ | 初期値 | 役割 |
|---|---:|---|
| `high_n` | `63` | 高次奇数倍音側の代表次数。局在した鋭い波を作るときの上限として使う。 |
| `chi_center` | `0.0` | 波形の中心位置位相。今回の実験では中心を `chi=0` に置く。 |
| `p0` | `1.0` | 位置位相方向の基準波数。進行位相 `exp(i q p0 chi)` の基準になる。 |

`high_n` は、片側高次倍音条件で重要になる。

低局在側では `N=1` のような低次数波を使い、高局在側では `N=63` のような高次数波を使う。

この差によって、

```text
広く広がった波
鋭く局在した波
```

の対照を作る。

`chi_center` は、波形をどこに置くかを決める中心位相である。

今回の実験では、A も B も同じ中心付近に置き、形と散乱による局在性の交換を読む。

`p0` は、A/B の進行方向位相を作る基準である。

実際の状態生成では、次のような位相が使われる。

```python
phase_chi = np.exp(1j * q * params.p0 * (chi - params.chi_center))
```

ここで `q` が正なら一方の向き、負なら反対向きの進行位相として読む。

### 1.3 A/B の向き、振幅、名前の毛

| プロパティ | 初期値 | 役割 |
|---|---:|---|
| `q_A` | `1.0` | A の初期進行方向を表す符号。 |
| `q_B` | `-1.0` | B の初期進行方向を表す符号。A と反対向きに置く。 |
| `A_A` | `1.0` | A の代表振幅。 |
| `A_B` | `1.0` | B の代表振幅。 |
| `m_A` | `1` | A の識別振動次数。 |
| `m_B` | `2` | B の識別振動次数。 |

`q_A` と `q_B` は、A と B が互いに向かい合う二体関係を作るための符号である。

今回の初期条件では、

```text
A: q = +1
B: q = -1
```

としている。

散乱後には、反射チャネルを作るために符号を反転した状態も作る。

```python
a_ref = make_state(params, n_a, -params.q_A, ...)
b_ref = make_state(params, n_b, -params.q_B, ...)
```

`A_A` と `A_B` は代表振幅である。

今回の実験では両方 `1.0` なので、A/B の差は主に振幅ではなく、倍音次数と散乱によって作られる。

`m_A` と `m_B` は、識別位相 `eta` に入れる内部振動次数である。

実装上は次のように入る。

```python
eta_phase = np.exp(1j * m * eta)
```

これが、A/B を区別する名前の毛である。

`hair_enabled=False` の場合は、この識別振動を入れず、すべて `1` にする。

```python
eta_phase = np.ones_like(eta, dtype=complex)
```

したがって、名前の毛を消した対照実験も同じ関数で実行できる。

### 1.4 散乱位相の設定

| プロパティ | 初期値 | 役割 |
|---|---:|---|
| `delta_f_fermion` | `pi` | フェルミオン型の完全反射極限を表す交換干渉位相。 |
| `delta_f_boson` | `0.0` | ボゾン型の完全透過極限を表す交換干渉位相。 |
| `delta_f_half` | `pi / 2` | 透過と反射が混ざる中間散乱の代表位相。 |

このプログラムでは、反射率や透過率を直接手で入れるのではなく、交換干渉位相 `delta_f` から散乱係数を作る。

対応する関数は `scattering_coefficients()` である。

```python
t = np.exp(0.5j * delta_f) * math.cos(0.5 * delta_f)
r = -1j * np.exp(0.5j * delta_f) * math.sin(0.5 * delta_f)
T = abs(t) ** 2
R = abs(r) ** 2
```

ここで、

```text
t: 透過振幅
r: 反射振幅
T: 透過率
R: 反射率
```

である。

`delta_f_boson=0` のとき、

```text
T = 1
R = 0
```

となり、完全透過として読む。

`delta_f_fermion=pi` のとき、

```text
T = 0
R = 1
```

となり、完全反射極限として読む。

`delta_f_half=pi/2` はその中間であり、透過と反射が混ざる条件を作る。

ただし、反射率掃引では `delta_f_half` だけでなく、指定した反射率 `R` から `delta_f` を逆算する。

それを行うのが次の関数である。

```python
def delta_from_reflection_rate(r_value: float) -> float:
    return 2.0 * math.asin(math.sqrt(r_value))
```

### 1.5 判定しきい値

| プロパティ | 初期値 | 役割 |
|---|---:|---|
| `p_tol` | `1.0e-2` | 進行方向・運動量様読出しの判定許容幅。 |
| `d_q_tol` | `1.0e-2` | 方向差や反転量の判定許容幅。 |
| `name_tol` | `1.0e-8` | 名前の毛、識別振動の判定許容幅。 |
| `norm_tol` | `1.0e-10` | ノルム保存や正規化の判定許容幅。 |

これらは、数値計算上の丸め誤差を許容するための値である。

厳密な数式ではゼロになる量でも、浮動小数点計算では完全なゼロにはならない。

そのため、実験の成功判定では、

```text
十分小さいならゼロとみなす
十分近いなら一致とみなす
```

という基準が必要になる。

`p_tol` と `d_q_tol` は、方向や運動量様読出しの判定に使う。

`name_tol` は、A/B の識別振動が保存されているか、または名前の毛を消した条件で不要な識別が出ていないかを判定する。

`norm_tol` は、状態ベクトルのノルムや確率密度の正規化が崩れていないかを見る。

### 1.6 再帰衝突と反射率掃引

| プロパティ | 初期値 | 役割 |
|---|---:|---|
| `recursive_collision_count` | `128` | 再帰散乱で衝突を繰り返す最大回数。 |
| `r_sweep_values` | `(0.00, 0.51, 0.55, 0.60, 0.70, 0.90, 1.00)` | 反射率掃引で調べる代表的な反射率。 |

`recursive_collision_count` は、時間発展的な効果を見るための回数である。

このプログラムでは、一回だけ散乱させて終わるのではなく、散乱後の出力チャネルを次の入力として戻す。

この処理によって、A/B の局在性が一回の相互作用でどう変わるかだけでなく、繰り返し相互作用したときにどう交換されるかを読む。

`r_sweep_values` は、反射率を変えた比較実験で使う。

特に重要なのは、

```text
R = 0.00: 完全透過
R = 1.00: 完全反射
0 < R < 1: 中間散乱
```

の比較である。

今回の論文で局在性交換が分かりやすく出たのは、完全透過でも完全反射でもなく、中間散乱の条件であった。

## 2. 観測の仕組み

### 2.1 観測の位置

このプログラムには、`observe()` という名前の単独の観測関数はない。

ここでいう観測は、現在の複素状態ベクトルを、位置位相、運動量様読出し、倍音分布、名前の毛、局在性などの数値へ変換する処理である。

その中心になる関数は、通常の散乱実験では `channel_metrics()`、再帰散乱実験では `recursive_state_metrics()` である。

メインループに相当する位置は `run()` である。

```python
def run() -> Dict[str, Any]:
    params = Params()
    acceleration_base = load_acceleration_base()
    rows: List[Dict[str, Any]] = []
    rows.extend(stage0_rows(params))
    rows.extend(low_n_rows(params))
    rows.extend(observation_stop_rows(params))
    rows.extend(one_side_high_harmonic_rows(params))
    rows.extend(control_comparison_rows(params))
    rows.extend(recursive_transfer_rows(params))
    rows.extend(recursive_r_sweep_rows(params))
```

`run()` 自身は、直接観測を行わない。

`run()` は、実験段階ごとの関数を順番に呼び出し、各段階の関数が観測結果の行 `rows` を作る。

つまり、観測の呼び出し位置は次の階層にある。

```text
run()
  stage0_rows(params)
  low_n_rows(params)
  observation_stop_rows(params)
  one_side_high_harmonic_rows(params)
  control_comparison_rows(params)
  recursive_transfer_rows(params)
  recursive_r_sweep_rows(params)
```

このうち、通常の一回散乱を扱う段階では、各 stage 関数が `rows_for_case()` を呼ぶ。

```text
stage*_rows()
  rows_for_case(...)
    scattering_outputs(...)
    channel_metrics(...)
    channel_metrics(...)
```

`rows_for_case()` の中では、まず `scattering_outputs()` によって出射チャネルを作る。

```python
out = scattering_outputs(params, n_a, n_b, hair_enabled, delta_f)
```

その後、二つの出射チャネルをそれぞれ `channel_metrics()` に渡す。

```python
channel_metrics(..., "minus_out", out["out_minus"], ...)
channel_metrics(..., "plus_out", out["out_plus"], ...)
```

ここが、通常の散乱実験における観測の入口である。

`scattering_outputs()` は、状態を作って散乱させる関数である。

```text
scattering_outputs(...)
  make_state(...)              # A 透過成分
  make_state(...)              # A 反射成分
  make_state(...)              # B 透過成分
  make_state(...)              # B 反射成分
  scattering_coefficients(...) # t, r, T, R
  out_minus = r * a_ref + t * b_trans
  out_plus  = t * a_trans + r * b_ref
```

この段階では、まだ観測値には変換していない。

作られているのは、観測前の出射複素ベクトルである。

その出射複素ベクトルを、読出し量へ変換するのが `channel_metrics()` である。

```text
channel_metrics(...)
  harmonic_distribution(...)
    chi_frequency_components(...)
  effective_n(...)
  eta_distribution(...)
    eta_frequency_components(...)
  chi_position_metrics(...)
  name_readout_metrics(...)
  pure_expect_p(...)
    spectral_p_chi(...)
  localization(...)
```

したがって、このプログラムでの観測の基本形は次である。

```text
複素状態ベクトル
  ↓
channel_metrics()
  ↓
読出し値の辞書
  ↓
rows に追加
```

再帰散乱の場合だけ、関数の入口が少し違う。

再帰散乱では、一回の散乱で終わらず、前回の出力を次回の入力として使う。

そのため、`rows_for_case()` ではなく、`recursive_transfer_rows()` または `recursive_r_sweep_rows()` の中で、直接 `recursive_state_metrics()` を呼ぶ。

```text
recursive_transfer_rows(params)
  make_state(...)      # 初期 A
  make_state(...)      # 初期 B
  for collision_index in range(...):
    recursive_state_metrics(..., a, ...)
    recursive_state_metrics(..., b, ...)
    a_next = normalize(r * a + t * b)
    b_next = normalize(t * a + r * b)
    a = a_next
    b = b_next
```

ここで重要なのは、観測と状態更新の順序である。

```text
1. 現在の a, b を観測する
2. その後で a_next, b_next を計算する
3. 次の衝突回では a_next, b_next が入力になる
```

つまり、再帰散乱では、観測は各衝突回の状態を記録する位置に置かれている。

状態を次へ進める処理そのものは、

```python
a_next = normalize(r * a + t * b)
b_next = normalize(t * a + r * b)
```

であり、観測値の `rows` から次状態を作っているわけではない。

観測は、現在の状態を読む処理であって、次状態を更新する主処理ではない。

### 2.2 `channel_metrics()` の分解

`channel_metrics()` は、通常の一回散乱で使う観測関数である。

入力された複素状態ベクトル `vector` から、次の読出し量をまとめて作る。

```text
倍音分布
実効倍音次数
名前の毛
位置位相
名前読出し誤差
運動量様読出し
局在性
```

関数の入口は次である。

```python
def channel_metrics(
    params: Params,
    stage: str,
    model: str,
    delta_f: float,
    n_a: int,
    n_b: int,
    hair_enabled: bool,
    channel: str,
    vector: np.ndarray,
    p_target: float | None,
    expected_origin_A: float,
    expected_origin_B: float,
    T: float,
    R: float,
    readout_enabled: bool = True,
    control_family: str = "scattering_matrix",
) -> Dict[str, Any]:
```

ここで最も重要なのは `vector` である。

`vector` は、`out_minus` または `out_plus` として作られた出射チャネルの複素状態ベクトルである。

つまり、`channel_metrics()` は、散乱前の A/B を直接読むのではなく、

```text
散乱後の片側チャネル
```

を読む。

#### 2.2.1 入力引数の役割

| 引数 | 役割 |
|---|---|
| `params` | 格子数、次数、しきい値などの実験設定。 |
| `stage` | どの実験段階の行かを記録するラベル。 |
| `model` | フェルミオン型、ボゾン型、中間散乱などのモデル名。 |
| `delta_f` | 散乱位相。 |
| `n_a`, `n_b` | 入力時の A/B の奇数倍音次数。 |
| `hair_enabled` | 名前の毛を入れているかどうか。 |
| `channel` | `minus_out` または `plus_out`。 |
| `vector` | 実際に観測する複素状態ベクトル。 |
| `p_target` | 運動量様読出しの比較対象。不要な場合は `None`。 |
| `expected_origin_A`, `expected_origin_B` | このチャネルに A/B 起源成分がどれだけ入るはずか。 |
| `T`, `R` | 透過率と反射率。 |
| `readout_enabled` | 読出し停止対照用の記録フラグ。 |
| `control_family` | どの系列の対照実験かを記録するラベル。 |

注意点として、この関数内では `readout_enabled` によって計算を止めてはいない。

`readout_enabled` は、この行が「読出しあり条件」か「読出し停止対照条件」かを記録するために返される。

#### 2.2.2 倍音分布を読む

最初に、位置位相 `chi` 方向の倍音分布を読む。

```python
h = harmonic_distribution(params, vector)
```

`harmonic_distribution()` の内部では、まず状態ベクトルを二次元配列へ戻す。

```python
arr = reshape_state(params, vector)
```

形は次である。

```text
(chi_grid_n, eta_grid_n)
```

その後、`chi` 方向へ FFT する。

```python
fv = chi_frequency_components(params, vector)
```

`chi_frequency_components()` の中身は次である。

```python
arr = reshape_state(params, v)
return np.fft.fft(arr, axis=0, norm="ortho")
```

`axis=0` なので、位置位相 `chi` 方向の周波数成分を読む。

各倍音次数 `n_abs` について、正負両方の周波数成分を足す。

```python
indices = frequency_index(freqs, n_abs)
if n_abs != 0:
    indices += frequency_index(freqs, -n_abs)
```

その次数に含まれる強度を、`eta` 方向の全成分について合計する。

```python
amount += float(np.vdot(fv[idx, :], fv[idx, :]).real)
```

最後に全体で正規化して、

```text
次数 n がどの割合で含まれているか
```

を辞書として返す。

この読出しは、入力時の `N_A` や `N_B` をそのまま返しているのではない。

散乱後の `vector` に実際に残っている倍音分布を読み直している。

#### 2.2.3 実効倍音次数を読む

次に、倍音分布 `h` から実効次数を読む。

```python
n_eff, n_eff_2 = effective_n(h)
```

`effective_n()` は二つの値を返す。

```python
n_eff = sum(float(n) * float(weight) for n, weight in distribution.items())
n_eff_2 = math.sqrt(sum(float(n * n) * float(weight) for n, weight in distribution.items()))
```

`N_eff` は、倍音次数の重み付き平均である。

```text
N_eff = Σ n P(n)
```

`N_eff_2` は、二乗平均平方根である。

```text
N_eff_2 = sqrt(Σ n^2 P(n))
```

高次成分が少し混じるだけでも、`N_eff_2` は反応しやすい。

そのため、局在化の兆候を見るときには、`N_eff` と `N_eff_2` の両方を記録している。

#### 2.2.4 名前の毛を読む

次に、識別位相 `eta` 方向の成分を読む。

```python
eta = eta_distribution(params, vector, [params.m_A, params.m_B])
p_m_a = eta.get(params.m_A, 0.0)
p_m_b = eta.get(params.m_B, 0.0)
```

`eta_distribution()` は、`eta` 方向へ FFT する。

```python
fv = eta_frequency_components(params, vector)
```

`eta_frequency_components()` の中身は次である。

```python
arr = reshape_state(params, v)
return np.fft.fft(arr, axis=1, norm="ortho")
```

`axis=1` なので、識別位相 `eta` 方向の周波数成分を読む。

この実験では、

```text
m_A = 1
m_B = 2
```

を名前の毛として使っている。

そのため、`eta_distribution()` は、`m_A` 成分と `m_B` 成分にどれだけ強度があるかを返す。

```text
P_m_A: A の名前の毛として読まれる成分
P_m_B: B の名前の毛として読まれる成分
```

これも、A/B を外からラベルとして復元しているのではない。

散乱後の `vector` に含まれる `eta` 方向の識別振動を読んでいる。

#### 2.2.5 位置位相を読む

位置位相まわりの読出しは、`chi_position_metrics()` が行う。

```python
chi_metrics = chi_position_metrics(params, vector, max(n_a, n_b))
```

内部では、まず `chi` 方向の確率密度を作る。

```python
arr = reshape_state(params, vector)
prob_chi = np.sum(np.abs(arr) ** 2, axis=1) / denom
```

ここでは `eta` 方向を足し合わせている。

つまり、名前の毛や内部識別方向を潰して、

```text
chi 方向にどこへ波が出ているか
```

を読む。

返される主な値は次である。

| 返り値 | 意味 |
|---|---|
| `chi_peak` | `chi` 密度が最大になる位置。 |
| `chi_peak_abs_error` | 中心 `chi_center` からのピークずれ。 |
| `chi_peak_contrast` | 一様分布に対してピークがどれだけ高いか。 |
| `chi_center_cell_mass` | 中心セル近傍にどれだけ質量があるか。 |
| `chi_effective_cell_count` | エントロピーから見た実効セル数。 |

`chi_peak_contrast` が大きいほど、鋭いピークを持つ。

`chi_effective_cell_count` が小さいほど、少数セルへ集中している。

#### 2.2.6 名前読出しの誤差を判定する

名前の毛の読出し結果は、`name_readout_metrics()` で判定する。

```python
name_metrics = name_readout_metrics(
    params,
    p_m_a,
    p_m_b,
    expected_origin_A,
    expected_origin_B,
    hair_enabled,
)
```

`hair_enabled=False` の場合、名前の毛は入れていないので、名前読出しは成功判定しない。

```python
if not hair_enabled:
    return {
        "name_hair_total": float(p_m_a + p_m_b),
        "name_readout_l1_error": float("nan"),
        "name_readout_ok": False,
    }
```

`hair_enabled=True` の場合は、A/B 起源の期待値と、実際の `eta` 成分を比較する。

```python
error = abs(float(p_m_a) - float(expected_origin_A)) + abs(float(p_m_b) - float(expected_origin_B))
```

通常の `rows_for_case()` では、期待値は散乱率から渡される。

```text
minus_out:
  expected_origin_A = R
  expected_origin_B = T

plus_out:
  expected_origin_A = T
  expected_origin_B = R
```

つまり、名前の毛は、

```text
この出射チャネルが A 起源をどれだけ含むか
この出射チャネルが B 起源をどれだけ含むか
```

を読むための内部振動として使われている。

#### 2.2.7 運動量様読出しを読む

運動量様読出しは `pure_expect_p()` で行う。

```python
p = pure_expect_p(params, vector)
```

内部では、`spectral_p_chi()` を作用させたものとの内積を取る。

```python
return float(inner(vector, spectral_p_chi(params, vector)).real / denom)
```

`spectral_p_chi()` では、`chi` 方向に FFT し、周波数 `freqs` を掛けてから逆 FFT する。

```python
transformed = np.fft.fft(arr, axis=0, norm="ortho")
p_arr = np.fft.ifft(freqs[:, None] * transformed, axis=0, norm="ortho")
```

これは、位置位相 `chi` 方向のスペクトルから、進行方向・運動量様の期待値を読む処理である。

`p_target` が与えられている場合は、誤差も計算する。

```python
p_abs_error = abs(p - p_target) if p_target is not None else float("nan")
```

`p_target=None` の場合は、比較対象を置かないので `nan` にする。

#### 2.2.8 圧縮方向読出し `d_q` を計算する

散乱率から、圧縮された方向読出しの期待値も計算する。

```python
compressed_q_A = params.q_A * (T - R)
compressed_q_B = params.q_B * (T - R)
compressed_q_channel = compressed_q_A if channel == "minus_out" else compressed_q_B
```

ここで `T-R` が効く。

完全透過なら、

```text
T = 1
R = 0
T - R = 1
```

完全反射なら、

```text
T = 0
R = 1
T - R = -1
```

中間散乱なら、その間の値になる。

その期待値と、実際に読んだ `p` の相対差を `d_q` として記録する。

```python
d_q = abs(p - compressed_q_channel) / (abs(p) + 1.0e-12)
```

これは、出射チャネルの進行方向読出しが、散乱率から期待される向きに合っているかを見る量である。

#### 2.2.9 局在性を読む

局在性は `localization()` で読む。

```python
"L": localization(vector)
```

中身は次である。

```python
prob = np.abs(vector) ** 2 / denom
return float(np.sum(prob**2))
```

これは、正規化された確率分布の二乗和である。

広く分散している波では、各セルの確率が小さいので `L` は小さくなる。

少数のセルへ集中している波では、確率の二乗和が大きくなるので `L` は大きくなる。

したがって、このプログラムでは、

```text
L が大きいほど局在的
L が小さいほど広域的
```

と読む。

今回の片側高次倍音実験では、この `L` が局在性交換を見る主要な値になる。

#### 2.2.10 返される観測行

最後に、読出し値を一つの辞書へまとめる。

```python
return {
    "stage": stage,
    "model": model,
    "delta_f": delta_f,
    "T": T,
    "R": R,
    "channel": channel,
    "N_A": n_a,
    "N_B": n_b,
    "hair_enabled": hair_enabled,
    "norm": norm2(vector),
    "p_chi": p,
    "p_target": p_target if p_target is not None else float("nan"),
    "p_abs_error": p_abs_error,
    "d_q": d_q,
    "L": localization(vector),
    **chi_metrics,
    "N_eff": n_eff,
    "N_eff_2": n_eff_2,
    "P_m_A": p_m_a,
    "P_m_B": p_m_b,
    **name_metrics,
    ...
}
```

この辞書一つが、CSV や JSON に保存される一行になる。

つまり `channel_metrics()` は、

```text
一つの出射チャネル vector
  ↓
複数の観測値をまとめた一行
```

を作る関数である。

この関数の中で、状態ベクトル自体は更新されない。

状態更新は散乱計算側で行い、`channel_metrics()` はその時点の状態を読むだけである。
