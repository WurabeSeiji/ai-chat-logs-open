## A. 10/23 複素数論文 §4.4 との整合（必須）

複素数論文 §4.4 は「正規化の割り算で捨てられる一次元がラピディティ、和は一般に $\cosh$ で $\varphi=0$ の断面でだけ 1、どこで割るかは力学から導けず公理として置く」と結論している。本稿 3.1 は最初に割り、3.2 で「二乗は仮定でない」と書く。P2 から出るのは「積 $a\,a^{*}$ が読める量」までで、確率に読む正規化は 3.1 の割り算そのものである。

### A1. 要旨
- 箇所：要旨 3 文目
- 現行：「これらから、ボルン則、二者相関 $E=\mp\cos n\theta$、CHSH 量の上限 $2\sqrt{2}$（ツィレルソン限界）、信号不能性が数行で導かれる。」
- 置換：「これらから、確率が振幅と共役振幅の積になること（ボルン則の形）、二者相関 $E=\mp\cos n\theta$、CHSH 量の上限 $2\sqrt{2}$（ツィレルソン限界）、信号不能性が数行で出る。確率として読むための正規化は大きさの比を落とす割り算であり、$\eta=0$ の断面の選択である[29]。」
- 理由：導出と読みの境界を要旨で宣言する。

### A2. 3.1 に一文追加
- 箇所：3.1「残るのは向き（視野角）だけになる。」の直後
- 現行：「残るのは向き（視野角）だけになる。」
- 置換：「残るのは向き（視野角）だけになる。この割り算で落ちる一次元が大きさの比の対数 $\eta=\log(D_B/D_A)$（[29] のラピディティ）であり、本稿の導出はすべて $\eta=0$ の断面で行う。$\eta\neq0$ の帰結は §6 の二点に残す。」
- 理由：P1 の非対称部分（大きさ）がどこへ行ったかを明示する。

### A3. 3.2 末尾

- 現行：「確率が振幅の二乗になる理由は、仮定ではなく、読出しが放射と吸収の同時成立であることから来る[17] [18]。」

## B. 導出と読みの境界（必須）

### B1. 3.3 の「反転 −u」
- 箇所：3.3 第 2 段落
- 現行：「スピン一重項のように関係が両端で対称に成立する場合、B 端の向きは A 端の向きの反転 $-\boldsymbol{u}$ として読まれる。これが反相関の符号の起源である。」
- 置換：「スピン一重項のように両端が互いに直交する向きで結ばれる場合、B 端は読出しの位相 $\varphi$ を $\pi/2$ ずらした向きとして読まれる（$n=1$ では空間の反転 $-\boldsymbol{u}$、$n=2$ では直交偏光）。A 端の $+$ と B 端の $+$ の重なりは $\cos^{2}(\varphi+\pi/2)=\sin^{2}\varphi$ で、これが反相関の符号の起源である。係数 $\tfrac12$ は、片側だけでは絶対の向きが読めない（P1 のゲージ）ことによる片側の一様分布である。」
- 理由：$-\boldsymbol{u}$ は $n=1$ でしか成り立たない（$n=2$ では 180° 回しても同じ偏光）。$\tfrac12$ が入力であることを明示する。

### B2. 3.4 内積の根拠
- 箇所：3.4 最終段落
- 現行：「(P1) の正規化のもとでは相関は必ず内積であるから、PR 型の相関は最初から現れない。上限が $2$ でも $4$ でもなく $2\sqrt{2}$ である理由は、比しか読めないことに帰着する。」
- 置換：「読出しは両端の向きに双線形（放射側と吸収側の積、P2）で、長さは 1 に正規化されている（P1）から、相関は必ず内積であり、PR 型の相関は最初から現れない。上限が $2$ でも $4$ でもなく $2\sqrt{2}$ である理由は、この双線形性と正規化の二つに帰着する。」
- 理由：PR 箱を排除するのは双線形性で、比だけでは足りない。

### B3. 3.5 の循環
- 箇所：3.5 式の直後
- 現行：「で、B の設定 $\beta$ に依存しない。片側だけでは比が閉じず、関係の絶対的な向きは読めない（P1 のゲージ）ので、片側の分布は一様になる。相関は双方の記録を突き合わせたときに初めて現れる。信号不能性は、読出し規則が比しか許さないことの帰結である。」
- 置換：「で、B の設定 $\beta$ に依存しない。これは 3.3 で係数 $\tfrac12$ を P1 のゲージから置いた時点で決まっており、ここでは $\sin^{2}\varphi+\cos^{2}\varphi=1$ と整合することを確かめた。相関は双方の記録を突き合わせたときに初めて現れる。信号不能性は、片側だけでは絶対の向きが読めないという P1 の帰結である。」
- 理由：$\tfrac12$ を入れて $\tfrac12$ を出しており、導出に見える書き方になっている。

### B4. P2 の「瞬時」
- 箇所：§2 (P2) 第 1 段落末尾
- 現行：「関係そのものは瞬時に同時に成立する。」

- 理由：二文後の null 間隔の論法と同じ内容。超光速と読まれる語を消す。

### B5. P1 の式 $d=D/\theta$ の位置づけ
- 箇所：§2 (P1) 式の直後
- 現行：「で与えられる。視野角が狭いほど遠く、同じ視野角なら相手が大きいほど遠い。」
- 置換：「で与えられる（第三思考実験 [11] の天体配置での読み）。視野角が狭いほど遠く、同じ視野角なら相手が大きいほど遠い。本稿の導出で使うのは、読めるのが比だけであること、全体の向きと大きさが読めないことの二つだけである。」
- 理由：この式は §3 で一度も使っていない。パルス系では距離は交差項の角そのもので、$R_j/R_i$ は別の読出しである。

### B6. P1 の「二体では距離は決まらない」
- 箇所：§2 (P1) 第 3 段落

- 理由：3 パルス実験では対で距離（商の角）は決まり、決まらないのは目盛りと向きである。語を合わせる。

### B7. §5 の「局所性の前提を採らない」

- 理由：「局所性を採らない」だけでは超光速の主張に読める。

## C. 倍音の一般化（追加、著者判断）

11/1 の検討：同じ軸の二つのパルスの交差項は倍音ごとに直交するので $E(\theta)=\sum_m w_m\cos m\theta$（自己相関）。上限 $2\sqrt{2}$ はどの重みでも成り立つが、等号は単一倍音のみ。矩形パルスの交差項は弧の重なり＝一様な $\lambda$ の局所隠れ変数模型で $S\le2$。軸の読みは $\kappa$ に一次で $n=1$ が倍音によらず厳密。これは本稿で標準理論と重ならない唯一の帰結になる。

### C1. P3 末尾に段落追加
- 箇所：§2 (P3)「ヘリシティ（½, 1, 2）の二倍が倍音次数に対応する。」の直後に新段落
- 追加文：「局在した関係は倍音の和である。パルスを $f(\psi)=c_0+\sum_{m\ge1}c_m\cos m(\psi-\theta_0)$ と書くと、同じ軸の二つのパルスの交差項は倍音ごとに直交し、相関はパルス形の自己相関
$$E(\theta)=\mp\sum_{m\ge1}w_m\cos m\theta,\qquad w_m=\frac{c_m^{2}}{\sum_{m'\ge1}c_{m'}^{2}}$$
になる。単一倍音 $w_m=\delta_{mn}$ が上の $n$ である。上限 $2\sqrt{2}$ はどの重みでも成り立つ（3.4 の単位ベクトルが $\mathbb{R}^{2M}$ に移るだけ）が、等号は単一倍音でだけ達成される。矩形パルスでは交差項が二つの弧の重なりの長さ、すなわち一様な $\lambda$ が両方の弧に入る確率に落ちて局所隠れ変数模型になり、$S\le2$ である。弦の半分を占める矩形パルス（奇数倍音、$c_m\propto1/m$）では $E$ は三角波 $1-2|\theta|/\pi$ で $S=2$ になる。軸の向きを回す読出しは交差項が $\kappa=\boldsymbol{n}_A\cdot\boldsymbol{n}_B$ に一次なので、倍音によらず $n=1$ である。」
- 理由：P3 の単一 $n$ が特別な場合であることと、本稿固有の帰結（局在と非局所相関のトレードオフ）を書く。

### C2. 3.4 の対照の文
- 箇所：3.4 ベルの不等式の段落
- 現行：「本稿の描像では、読出しは両側の設定がそろった三者の関係として同時に成立するので（P2）、この前提は満たされない。」
- 置換：「本稿の描像では、単一倍音の関係の読出しは両側の設定がそろった三者の関係として同時に成立するので（P2）、この前提は満たされない。矩形パルスの関係では前提が満たされ、$S\le2$ に戻る（P3）。」
- 理由：C1 と整合させる。

### C3. §4 の位置づけ
- 箇所：§4 節題と本文
- 現行：「## 4. 予言」
- 置換：「## 4. 帰結と既知との照合」
- 追加文（§4 冒頭）：「以下の三つの値はいずれも標準理論と一致し、本稿の判別点ではない。判別点は、P1〜P3 だけから 3.3 の $\tfrac12\sin^{2}\varphi$ が出るかどうか（数値実験 E1）、関係が単一倍音でないときの $E(\theta)$ の形と最大の破れ（P3）、§6 の二点である。」
- 現行：「前二者は既知の実験配置と一致する。重力波についての実験は現実には困難だが、「上限は不変、最適角は $1/n$」という形で明確な予言となる。」
- 置換：「三者とも標準理論のスピン・ヘリシティ ½, 1, 2 の値と同じである。重力波についての実験は現実には困難だが、「上限は不変、最適角は $1/n$」という形で照合点になる。」
- 現行：「予言として、上限は波の種類によらず $2\sqrt{2}$ であり」
- 置換：「帰結として、上限は波の種類によらず $2\sqrt{2}$ であり」
- 理由：重力波の値も標準理論の helicity 2 の値で、本稿固有の予言ではない。
