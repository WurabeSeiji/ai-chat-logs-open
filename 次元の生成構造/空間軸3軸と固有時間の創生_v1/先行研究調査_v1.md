# 先行研究調査 v1——「空間軸3軸と固有時間の創生」

調査日: 2026-08-06
形式: 従来どおり「独自検討の後に再調査したら見つけた」。対応は傍証であり証明ではない。

---

## 1. 時間の関係論——Page–Wootters機構（固有時間の創生の最近接）

Page–Wootters (1983): 大域的に定常な状態の中で、時計部分系との相関から
部分系の時間発展が現れる（evolution without evolution）。時間問題
（Wheeler–DeWitt の無時間性）への正統的応答の一つ。
- **対応**: 本稿の固有時間も関係的に現れる——凝縮体の集団時計との関係だけが
  時間を与え、大域の「ステップ」は規約（写像の向きは選択問題）。
- **差別化**: PWは量子的制約ともつれから条件付けで時間を得る。本稿は
  (1) 時計そのものが力学的に自己生成される（凝縮＋引き込みによる集団強制）、
  (2) 座標時間の非可読性が読出し構造の帰結として**導出**される、の2点が固有。

## 2. 座標時間はゲージ——Rovelli の部分観測量

一般相対論において座標時間が観測量でない（ゲージ）ことは正統な既知事実であり、
Rovelli の partial observables / evolving constants が定式化した：物理的なのは
時計変数との相関のみ。
- **対応**: 本稿の「唯一読めないのは座標時間 t」はこの主張と合流する。
- **差別化**: GRでは微分同相不変性が**原理として課され**、その帰結として
  座標時間が非物理になる。本稿では逆に、閉塞の錐の読出し構造（虚軸成分は
  スナップショットに痕跡を残さない）から「固有時間＝物理／座標時間＝規約」の
  区別が**導出**される。原理の向きが逆。

## 3. quadrature読出し＝ホモダイン検波（数理形式の最近接）

量子光学のホモダイン測定：信号を局部発振器（LO）と干渉させ、LO位相を基準に
直交位相成分（quadrature X, P）を読む。位相基準に対する直交2成分の読出しという
形式は、本稿の x, y 読出しと同一。
- **対応**: x = Re(c·e^{−iφ}), y = Im(c·e^{−iφ}) はホモダイン読出しそのもの。
- **差別化**: 光学ではLOは外部装置であり実験者が供給する。本稿では位相基準が
  **系自身の凝縮体**（引き込みで自己選択された固有時計）——宇宙が自分のLOを
  供給する。空間軸2本がホモダイン読出しの2 quadratureとして現れるという同定は
  本稿固有。

## 4. 質量＝非コヒーレンス——偏光のコヒーレンス行列（数学は既知・同定が新規）

Stokes (1852) / Wolf のコヒーレンス行列理論（Born & Wolf）：2×2コヒーレンス行列
J の Pauli 分解係数が Stokes パラメータ (S0,S1,S2,S3)、恒等式
det J = (S0²−S1²−S2²−S3²)/4 ≥ 0、等号は完全偏光。部分偏光は
完全偏光＋完全非偏光に一意分解され、偏光度 P で定量化される。
- **対応**: 本稿の質量読出し detΓ = T²−X²−Y²−Z² ≥ 0 は数学的に
  **偏光形式と同一**である（光錐束縛＝S0² ≥ S1²+S2²+S3² の恒等式）。
- **差別化と誠実な位置づけ**: 数学は完全に既知（本文で明示する）。新規なのは
  物理的同定——非偏光度（rank落ちからの逸脱）を**質量²**と読み、
  「光的＝完全コヒーレント（rank 1）／質量＝部分偏光」とする辞書、および
  凝縮体が実測で「質量あり」（光的固有モードの2.5×10⁴倍）になる事実。

## 5. 次元のスケール依存性——CDTのスペクトル次元

Ambjørn–Jurkiewicz–Loll (PRL 2005): 因果的動的単体分割で、時空のスペクトル次元は
スケール依存であり、短距離で次元が減る（running dimensional reduction）。
短距離次元縮減は量子重力の普遍的特徴の候補とされる。
- **対応**: 本稿の「次元の曖昧さ ~1/M、少数体（バリオン）領域では第3次元が
  結晶化しない」は、同じ方向——微小スケール／少数自由度で次元は非古典的——を指す。
- **差別化**: CDTの次元計は拡散過程（スペクトル次元）。本稿の次元計は
  回転軸と外積の一致度という構成的・代数的な量であり、次元の「鋭さ」が
  関係波の本数で定量化される。

## 6. 同期・引き込み——Huygens から同期理論へ

振り子時計の同期（Huygens 1665）以来、引き込み（entrainment）は非線形科学の
古典であり、Pikovsky–Rosenblum–Kurths が体系化した。結合振動子は集団リズムに
引き込まれる。
- **対応**: 本稿のK3（コヒーレント摂動が凝縮体の時計に同期させられる）は
  引き込みそのもの。
- **差別化**: 本稿は引き込みを**固有時間の存立機構**として読む——時計は
  個々の属性ではなく凝縮体が集団強制する秩序であり、その帰結として
  「静止は無質量摂動の運命、運動は質量（自前の時計）の特権」という
  運動学の分類が出る。同期理論にこの時空論的読みはない。

## 7. 物理系としての基準系——量子基準系（BRS）

Bartlett–Rudolph–Spekkens (Rev. Mod. Phys. 79, 555 (2007)): 方向や時刻は
物理系に相対的にのみ定義される（unspeakable information）。量子基準系の
資源理論、および近年の量子基準系変換（perspective-neutral framework 等）。
- **対応**: 「軸は読出しが作る（直交性・等方性は読出しの規約）」という本稿の
  立場は、基準系は物理系であるというBRSの立場の力学版。
- **差別化**: BRSは情報理論的資源論であり基準系は与えられる。本稿では
  基準系（時計と軸）が力学から自己生成される（凝縮＋引き込み）ことを実測する。

（Page–Wootters）、座標時間のゲージ性（部分観測量）、ホモダイン検波

偏光理論として完全に既知であり、本稿の寄与は物理的同定（非偏光度＝質量²）と
その模型内実測に限られることを明示する。」
