## 1. 訂正を受け入れる（独立に検算した）

### 1.1 A2 は八元数を使っていなかった

こちらは `../八元数のインフレーション試行_20261020/作用の定式化と探索空間_20261020.md` §3 で、

u_e = ½ Σ_{f≠e} Im(w_ef²) = Σ_{f≠e} Re(w_ef) Im(w_ef)

を「Σo = 0 で生き残る**最小の G₂ 共変**な作用」として提示した。G₂ 共変であることは正しいが、**それ以上に SO(8) 共変**で、八元数の非結合性をまったく使っていない。

**恒等式（独立に確認、差 8.2×10⁻¹³、N = 3〜8 のランダム 60 本）：**

> **u_e o_e = |o_e|² S o_e − (o_eᵀ S o_e) o_e、 S = Σ_f o_f o_fᵀ**

右辺に八元数の積は現れない（S は実対称行列）。直接の確認でも ‖F(XQᵀ) − F(X)Qᵀ‖ = 1.4×10⁻¹³（Q ∈ O(8) 任意）。

**したがって A2 は「八元数でなければならない理由」を一つも含んでいない。** こちらの §3 の位置づけ（最小の生き残る作用）は、「二要素の項だけで作る限り、何を作ってもアルティンの定理で結合的になる」という第 1 段の指摘の具体例にすぎなかった。これは定式化の骨格に関わる訂正である。

### 1.2 定理 B の正しい形

こちらは定理 B を「(a) 全対の角が 0/90/180°、(b) 各要素に直交する鏡映で集合が閉じる」と書いた。正しくは一本で書ける。

> **A2 = 0 ⟺ すべての要素が S = Σ o oᵀ の固有ベクトル**

独立に確認（8 配置）：

| 配置 | max\|A2\| | 固有ベクトル残差 |
|---|---|---|
| ORTHO16 | 0 | 0 |
| 正十六胞体 v/√3 | 0 | 0 |
| 24 胞体 | 0 | 0 |
| E₈ 240 | 4.7×10⁻¹⁶ | 3.5×10⁻¹⁸ |
| N4 {√3, e₁, e₂, e₄} | 0 | 1.7×10⁻¹⁶ |
| ORTHO_AB | 0 | 0 |
| NULL28 | 4.24 | 0.600 |
| RAND8 | 115 | 0.610 |

完全に一致する。**こちらの (a)(b) はこの条件の十分条件にすぎなかった。** 上の恒等式から直ちに出る（S o_e ∥ o_e なら右辺はゼロ）ので、恒等式を見つけた時点で定理 B は不要になる。

### 1.3 探索空間の条件も書き換わる

`作用の定式化と探索空間_20261020.md` §7 の条件 1（鏡映で閉じない）・2（角が 0/90/180 だけでない）は、**条件「S の固有ベクトルでない要素がある」一本に置き換わる**。そして A2 自体が SO(8) 共変なので、**八元数の探索空間の定義には使えない**。八元数でしか効かない作用（ASSOC）に対する条件に差し替える必要がある。

## 4. こちらから足せること

**(1) A2 の恒等式から、第二層の力学の正体が読める（読み、確認前）。**

u_e o_e = \|o_e\|² S o_e − (o_eᵀ S o_e) o_e

は、各要素を **S の固有ベクトルの方へ引き寄せる勾配流**の形をしている（球面上で二次形式 oᵀSo を増やす方向に動く、冪乗法の連続版）。固定点が「全要素が S の固有ベクトル」なのはこのため。そして S 自身が配置で決まるので自己無撞着な勾配流になる。**二乗閉塞の第二層は、配置が自分の慣性主軸に整列する流れ**という読みになる。整列が終われば静止するので、これだけでは回らない。これは「八元数でしか効かない作用が要る」という第 1 段の結論と整合する。

**(2) 持続性の検算に射影を入れることの提案は、まだ有効。** 第 2 段では離れる速さが dt と dt/4 で一致したので結論は変わらないと見るが、ASSOC は F ⊥ o の型なので各歩のあと半径を戻す射影でノルムのずれが 2.7×10⁻⁴ → 2.2×10⁻¹⁶ になる（検証済み）。50 例の「離れる」が射影つきでも変わらなければ、不安定性の結論が一段固くなる。

**(3) (ω, ω, 0) の 3 例について。** g₂ の重みは正六角形なので、(ω, ω, 0) は三つの重みのうち一つが t に直交する特別な方向で、D が **su(2) × u(1) か、より小さい部分代数**に入っている可能性が高い。D の中心化部分環の次元を測れば決まる（g₂ の一般元なら 2、特別なら大きくなる）。すぐ確かめられる。

**(4) 次の分かれ目。** 形を保つ 7 例が N = 4, 5 にしかなく、N ≥ 6 がすべて不安定だったことは、`../八元数閉塞と関係の分解_20261019/kのスペクトルと粒子への割り当て_20261019.md` の k = min(7, N − 2) と突き合わせる価値がある。N = 4, 5 は k ≤ 3 で、**内部空間が開く前**にあたる。k ≥ 4（N ≥ 6）で不安定になるなら、安定な自己無撞着状態と内部空間の有無が結びつく。これは今日いちばん照合したい点。
