# 八元数が自己無撞着になる作用と初期値の組（2026-10-20）

**問い（著者）：** まず八元数が自己無撞着になる作用（かなり初期値依存でもよい）と初期値の組み合わせを探さないと始まらない。
**前段：** `次元の生成構造/八元数のインフレーション試行_20261020/`（第 4 段）。そこで見つけた三つの型の組は、ℓ を一つ選んだ作用（ℝ⁸ = ℂ⁴ の複素構造）によるもので、八元数の積を使っていなかった。

## 解析（走らせる前に決めたこと）

1. **形：** 無名性（ℓ を置かない）・大きさの保存・積からの構成で、作用は dx_e = u_e x_e（左）、x_e v_e（右）、u, v は純虚。
2. **二つの要素だけの項は八元数を使わない：** Artin の定理で、o_e と o_f の二つで作った項は結合的。例：Im(w_f w̄_e) w_e = w_f − ⟨w_f, w_e⟩w_e（球面上の蔵本型＝Lohe 型、SO(8) 共変）。
3. **八元数でしか効かない材料は、三つの要素が一つの積に入る結合子 [a,b,c]。** ⟨[x,f,g], x⟩ = 0 なので大きさを保つ。重みなしの全員の和は [w_e, P, P] = 0 に潰れるので、f, g について反対称な重み ⟨w_e w_f, w_g⟩ を付ける。
4. **各相手について次数 2 以下の作用は、相手を二次のモーメント S = Σ w wᵀ を通してしか見ない。** S ∝ I（2-デザイン）なら、ASSOC の各項は二つの要素で生成される結合的な部分代数に入って 0 になる。

## 方法

`octonion_selfconsistent_actions_20261020.py`（docstring に定義と判定規則）。八元数の積は `../八元数閉塞と関係の分解_20261019/octonion_closure_check_20261019.py` の omul を読み込み、構造定数にして一括計算（対照：omul との差 2.8×10⁻¹⁵）。乱数シード 20261020。RK4、刻み dt = 2π/(200σ)、6000 歩。

| 作用 | 式 | 性質 |
|---|---|---|
| PAIR_L（PAIR_R は恒等） | dx_e = κ\|x_e\| Σ_{f≠e} Im(w_f w̄_e) w_e | 対だけ。Lohe 型と一致（差 1.3×10⁻¹⁴、1.4×10⁻¹⁴）。八元数を使わない対照 |
| ASSOC | dx_e = κ\|x_e\| Σ_{f,g} ⟨w_e w_f, w_g⟩ [w_e, w_f, w_g] | 八元数でしか 0 にならない項。2-デザインで 0（正軸体 0、E₈ 2.7×10⁻¹²） |

初期値：N4 = {√3, e₁, e₂, e₄}（Σo² = 0、e₁, e₂, e₄ は結合的でない三つ組）、N5（Σo = Σo² = 0 の解）、NULL28、ORTHO_AB（正軸体の ±1 を半径 2）、RAND8、RAND16（対称性なし）。κ = ±1。

## claude.ai の並行分析との照合

claude.ai が同じ問いで `../八元数のインフレーション試行_20261020/作用の定式化と探索空間_20261020.md` と `octonion_action_formulation_20261020 (1).py`（最新版。旧版は同名の `(1)` なし、旧 md は `作用の定式化と自己無撞着の条件_20261020.md`）を Drive に保存した。最新版をこちらで走らせ、表の値を再現した（`results/action_formulation.json` は向こうのフォルダに出力される）。

- **定理 A（G₂ 共変な双線形の作用は Σo = 0 で 0）：** 上の PAIR が Σw = 0 の配置で静止するのと同じ内容。一致。
- **第二層の作用 A2（u_e = Σ Re(w_ef) Im(w_ef)）：** 二つの要素だけの項なので Artin の定理で結合的で、厳密に
  u_e o_e = |o_e|² S o_e − (o_eᵀ S o_e) o_e（S = Σ o oᵀ）
  になる（`check_second_layer_identity_20261020.py`、`results/second_layer_identity.json`：定義どおりの計算との差 ≤ 1.2×10⁻¹²）。したがって A2 は SO(8) 共変で、八元数の非結合性を使っていない。
- **定理 B の正確な形：** A2 が厳密に 0 ⟺ **すべての要素が S の固有ベクトル**。11 の配置すべてで max|A2| = 0 と固有ベクトル条件の残差 = 0 が一致した（ORTHO16、正十六胞体、24 胞体、E₈、N4、ORTHO_AB が 0。NULL28、N5、ランダムは非零）。「鏡映で閉じる」はこの十分条件の一つ。
- **持続する相対平衡は g₂ で判定すべき（claude.ai の指摘は正しい）：** G₂ にだけ共変な作用（ASSOC）では、剛体回転が時間発展で保たれるのは D ∈ g₂ の場合。本プログラムの relEq は so(8) で判定している。今回 ASSOC の相対平衡は一つも見つかっていないので結果は変わらないが、次の段では g₂ で判定する。g₂ の振動数は符号付きで ω₁ + ω₂ + ω₃ = 0。

## 読み（確認前）

- **八元数を使わない作用（PAIR、A2）なら、自己無撞着な組はたくさんある。** 斥力（κ = −1）の PAIR は、どの一般の初期値からも、八元数のまま（結合子が 0 でない）静止した配置へ漸近する。ただしこれは SO(8) の球面上の力学で、八元数であることは使っていない。
- **八元数でしか効かない作用（ASSOC）で見つかった自己無撞着な組は、静止（固定点）だけ。** N4・NULL28・ORTHO_AB・2-デザインは ASSOC の固定点。動く自己無撞着な組（相対平衡・周期的・準周期的・漸近的）はまだ見つかっていない。
- N5 の ASSOC（κ = −1）は形の変化が後半に 0.0055 まで戻る時点があり、周期的か準周期的の候補。刻みを細かくした長い走行と、g₂ での相対平衡の判定で決める。

## 第 2 段：ASSOC の自己無撞着な組（2026-10-20）

`assoc_stage2_20261020.py`（結果 `results/assoc_stage2.json`、`results/assoc_stage2_log.txt`、N5 の時系列 `results/assoc_stage2_N5_k±1.npz`）、
`assoc_releq_persistence_20261020.py`（結果 `results/assoc_releq_persistence.json`、`results/assoc_releq_persistence_log.txt`）。

**(1) 固定点のまわりの線形化（N4・NULL28・ORTHO_AB、κ = ±1）：** 固有値はすべて 0（最大 2.5×10⁻⁹、差分の刻みを 1/10 にすると大きくなる＝差分誤差）。線形の振動数が無いので、これらの固定点からは周期軌道の族（Lyapunov の中心定理）は出ない。

**(2) g₂ の相対平衡（u_e(X) = D X_e、D ∈ g₂ を初期値と同時に解く、各 |x_e| = 1、κ = +1）：見つかった。**
- N = 4〜8 の 60 試行のうち 59 で、残差 ‖F − DX‖/‖F‖ ≤ 5.4×10⁻¹³（収束しなかった 1 例は N5 試行 4）。速さ ‖F‖/N は 0.19〜0.90 で静止ではない。
- すべて八元数のまま（結合子の最大 0.67〜1.9）。
- 振動数は全 59 例で ω₁ = ω₂ + ω₃（符号付きで和ゼロ、G₂ の拘束）を丸めの桁で満たす。3 例（N4 試行 7、N5 試行 11、N6 試行 10）は (ω, ω, 0) の形。
- 振動数の比は解ごとに連続に違う（例：N4 で 2.372 : 2.362 : 0.010、1.300 : 0.842 : 0.458）。

**(2′) 持続性：**
- ASSOC の G₂ 共変性：‖F(gX) − gF(X)‖/‖F(X)‖ ≤ 6.9×10⁻¹⁵、g の自己同型の誤差 ≤ 2.0×10⁻¹⁴。したがって解は厳密には X(t) = exp(tD)X で持続する。
- 積分（刻み dt と dt/4、同じ時間）：
  - **形を保つ（7 例）：** N4 の試行 0, 2, 3, 7, 9 と N5 の試行 5, 11。形の変化の最大は dt で 2.8×10⁻⁹〜4.3×10⁻⁶、dt/4 で 10⁻¹¹〜10⁻⁸（RK4 の誤差の縮み方）。厳密解との差も同じ桁。
  - **ゆっくり離れる（2 例）：** N4 の試行 4, 6。離れる速さ 0.10〜0.13 桁/時間が刻みによらない。
  - **離れる（残り 50 例、N ≥ 6 はすべて）：** 離れる速さ 0.32〜4.4 桁/時間が dt と dt/4 で一致し、刻みを細かくすると離れ始めが遅れるだけ（丸め・打ち切り誤差がシード）。解のまわりの不安定さで、自己無撞着な状態から離れていく。

**(3) N5 の ASSOC の長い走行（dt = 2π/(2000σ)、60000 歩、T = 737）：** 1e-8 ずらした二軌道の形の差が 8 桁育って飽和（κ = +1 で −7.6 → 0.72、κ = −1 で −7.7 → 0.61）。パワースペクトルは線に集中しない（スペクトルのエントロピー 0.44、最大の線でも全体の 7%）。**準周期的ではなく不規則。** 第 1 段で「周期的か準周期的の候補」とした読みは取り下げる。

**読み（確認前）：**
- 八元数でしか効かない作用 ASSOC に、動く自己無撞着な組（g₂ の相対平衡）が初期値に応じて多数ある。形は時間で変わらず、全体が exp(tD) で回る。全体の運動は三つの振動数（符号付きで和ゼロ）の準周期で、比が通約可能なら周期的。
- 解は連続な族を作っている（振動数の比が連続に違う）。どの比が選ばれるかは初期値で決まり、作用は決めない。
- 形を保つ解は N = 4, 5 にだけあり、N ≥ 6 で見つかった解はすべて解のまわりで不安定だった。
- (ω, ω, 0) の 3 例は、D が g₂ の中の小さい部分代数に入っている可能性がある（未確認）。

## claude.ai の第 2 報との照合と、ASSOC の縮約の恒等式（2026-10-20）

claude.ai が本フォルダに `定式化の突き合わせと走行の直し方_20261020.md` を保存した（dfbbd276 で、読む前に一緒にコミットしていた）。前提に照らした評価：

- **帰属の誤り：** 同 md は `../八元数のインフレーション試行_20261020/作用の定式化と自己無撞着の条件_20261020.md`（ω₁ + ω₂ = ω₃、最小比 1 : 1 : 2）を Claude Code の作としているが、このセッションの Claude Code は書いていない。書式と内容は claude.ai の旧版と同じ。
- **正当な指摘：** RK4 は各 |x_e| を厳密には保たない（N5 + ASSOC で 2.7×10⁻⁴）。改善策（PAIR 型は指数写像 exp(u dt)、ASSOC 型は各歩のあと半径を戻す射影）は妥当。第 2 段の「離れる」判定は、離れる速さが dt と dt/4 で一致した（大きさのずれは刻みとともに縮む）ので、ずれによる見かけではないと考えるが、射影を入れた走行での確認は未実施。
- **注意として妥当：** N5 の生成で自明解 o = 0 に落ちる危険（このシードでは最小ノルム 0.309 で起きていない）。大きさの拘束を足すのが安全。
- **古い指摘：** 「run_log.txt が 0 バイト」は走行中の状態。

**同 md §4 の未解明の問い「ORTHO_AB がなぜ ASSOC で静止するか」への解析**（`assoc_contraction_identity_20261020.py`、`results/assoc_contraction_identity.json`）：
重み ⟨w_e w_f, w_g⟩ は g について線形なので、g の和は単位ベクトルの二次のモーメント S_w = Σ_g w_g w_gᵀ に縮約できる。

ASSOC_e = κ|x_e| Σ_f [w_e, w_f, S_w(w_e w_f)]

- 縮約の式と F_assoc の差 ≤ 1.2×10⁻¹³（6 配置）。
- 各積 w_e w_f が S_w の固有ベクトルなら、各項は w_e, w_f の生成する結合的な部分代数に入り、作用は 0。S_w ∝ I（2-デザイン）はその特別な場合。
- ORTHO_AB と N4 は要素も積も基底 ±e_a の上にあり、S_w が対角なので、積は固有ベクトル（残差 0）→ 静止。
- NULL28 は積が固有ベクトルでない（残差 5.2）のに静止（max|F| = 4×10⁻¹⁸）。この十分条件とは別の理由で、未解明。
