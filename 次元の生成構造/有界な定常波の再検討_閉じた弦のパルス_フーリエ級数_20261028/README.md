# 有界な定常波の再検討：閉じた弦の上のパルス（フーリエ級数のみ）2026-10-28

閉じた弦（半径 R の円）の一周 2π に、中心 θ・幅 φ・高さ 1 のパルスを一つ置き、
その高さを **倍音の和だけ** で計算して 3D に描く。井戸関数は使わない。

## 式

弦に沿った角 ψ ∈ [0, 360)（度）。倍音 M 個で打ち切る。

    z_M(ψ) = φ/360 + (2/π) Σ_{m=1}^{M} [ sin(mπφ/360) / m ] · cos( mπ(ψ−θ)/180 )

3D の点は (R cos ψ, R sin ψ, z_M(ψ))。振幅は円筒の軸方向（R に直交）で、高さ 1 は絶対値、R に依らない。

- 直流 φ/360 が残る（パルス一個、全ての m が出る）
- 打ち切りの行き過ぎ（Gibbs）は M に依らず約 1.09、端の立ち上がり幅は約 360/M 度
- φ = 0 で z ≡ 0、φ = 360 で z ≡ 1

## 表示 index.html

- スライダー：θ [0, 360]（初期 180）、φ [0, 360]（初期 10）、R [0, 10]（初期 3）、M [1, 100]（初期 10）
- Auto（初期オン）：1 ティック（150 ms）ごとに θ ← θ + φ、360 を超えたら 0 に戻す
- 軸は等倍、x・y は ±10.5 に固定、z は −0.5〜1.5。薄い面は半径 R の円筒（高さ 0〜1）、細い線は z = 0 の弦の位置
- 題に max z と min z を出す
- ψ は 0.25° 刻み 1441 点、各点で M 項をそのまま足す

## 確認値（Python で同じ式を計算）

（θ = 180°, φ = 10°）

    パルス（OFF） z_M(ψ) = φ/360 + (2/π) Σ_{m=1}^{M} [ sin(mπφ/360) / m ] · cos( mπ(ψ−θ)/180 )        倍音 1, 2, …, M
    矩形波（ON）  s_M(ψ) = (4/π) Σ_{k=0}^{M−1} [ (−1)^k / (2k+1) ] · cos( (2k+1) N π(ψ−θ)/180 ),  N = 180/φ   倍音 N, 3N, …, (2M−1)N

- 矩形波のときの Auto は θ ← θ + φ_eff（一区間ずれるので毎ティック符号が反転する）

## V3：球面のパルス、ルジャンドル倍音（index_v3.html、2026-10-28）

閉じた弦を半径 R の球面に、倍音 cos(mψ) をルジャンドル多項式 P_l(cos γ) に置き換えた版。γ は基準点（経度 θlo、緯度 θla）からの角距離。
等振幅とフェイエール重みをボタンで切り替える（初期 OFF ＝ 等振幅）。

    cos γ = sin β sin θla + cos β cos θla cos(λ − θlo)
    等振幅        A(γ) = (1/N) Σ_{l=1}^{N} P_l(cos γ)
    フェイエール  A(γ) = Σ_{l=1}^{N} w_l P_l(cos γ) / Σ w_l,   w_l = 1 − l/(N+1),  Σ w_l = N/2
    3D の点  X = (R + A) · (cos β cos λ, cos β sin λ, sin β)       振幅は半径方向、絶対値で R に依らない

- 球面の軸対称な定常波は P_l(cos γ) で、基準点と対蹠点は常に腹（P_l(1) = 1、P_l(−1) = (−1)^l）。閉じた弦の sin(Nγ)（極が節）は球面では固有関数にならない（Δ sin(Nγ) に (N/R²) cot γ cos(Nγ) が残る）
- どちらのモードも A(基準点) = 1、球面上の平均 0（l = 0 を含まない）、N = 1 で A = cos γ（基準点 +1、対蹠点 −1、γ = 90° が節）
- 等振幅の和 Σ P_l は γ ≠ 0 で 1/(2 sin(γ/2)) − 1（源からの弦長の逆数 − 1）に収束する。1/N 倍しているので床と揺れは N とともに消える。対蹠点は N 奇数で −1/N、偶数で 0
- フェイエール重みは部分和 S_1 … S_N の平均。等振幅ではない。揺れが減る代わりに幅が広がる
- スライダー：θlo [0, 360]（初期 180）、θla [−90, 90]（初期 0）、R [0, 10]（初期 3）、N [1, 100]（初期 50）。Auto（初期オン）：150 ms ごとに θlo ← θlo + 5、360 を超えたら 0 へ。θla は手動
- 格子は経度 nL = min(721, max(181, 8N+1)) 点、緯度は同じ刻み（P_N の 1 周期あたり約 8 点）。面の色は A（−1〜+1 固定、0 が白、+1 赤、−1 青）、面の透明度 50%。赤点は基準点、青点は対蹠点、線はその軸。薄い面は半径 R の球。軸は等倍、±11.5 固定
- URL 引数 ?lo=&la=&R=&N=&fejer=1&auto=0 で初期値を与えられる（図の記録に使用）

## ブロック：鏡映群の市松（index_blocks.html、2026-10-28）

V3 の矩形波を球面に持ち込むと ±1 の区間は基準点の軸を一周する輪（帯）になり、ブロックにならない。
ブロックで ±1 を交互に敷き、境界が丸ごと大円で全部のブロックが合同になるのは、鏡映群の鏡で切った場合だけ：
二面体 4m、正四面体 24、立方体 48、正二十面体 120。球面三角形の面積は角の超過に比例し、
ブロック数 = 4 / (1/p + 1/q + 1/r − 1) なので、(2, 3, 5) の 120 が上限（(2, 3, 6) は超過 0 で平面）。V3 とは別プログラム。

    S_L(u) = Σ_{l 奇数 ≤ L} c_l P_l(u),   c_l = P_{l−1}(0) − P_{l+1}(0)      c_1 = 3/2, c_3 = −7/8, c_5 = 11/16, c_7 = −75/128, c_9 = 133/256
    F(x)   = Π_{i=1}^{M} S_L(n_i · x)        M は鏡の枚数、n_i は鏡の法線、x は球面上の単位ベクトル
    3D の点  X = (R + F) x

- 鏡 1 枚ごとに、その法線を軸にした半球 ±1 の矩形波（Nz = 1）をルジャンドル級数で作り、全部の鏡について掛ける。8 ブロックは sgn(x)·sgn(y)·sgn(z) の各因子を級数にしたもの（三方向の矩形波の積）
- 正規化なし。積は次数 M·L 以下の多項式なので球面調和関数の有限和。L = 1 なら F は法線の積、つまり最低次の倍音そのもの
- 鏡の組（群の軸は e_z）

## S³ 版：4 次元球殻の表面のパルス、倍音の位相読み（index_s3.html、2026-10-28）

V3 の S² を S³（半径 R の 4 次元球殻の表面）に上げた版。変えたのは三つだけ：中心位相が 2 角（θlo, θla）から 3 角（θlo, θla, σ）に、
倍音が P_l(cos γ) から sin((n+1)χ)/((n+1) sin χ) に、投影が「球面の半径方向の変位」から「球体の中の位置と色」に。R はスライダーで、球体の半径は πR。
あるのは倍音とその位相だけで、χ・R・距離はその読み方（空間を置かない）。

    観測者を中心に置いた主観座標系：表示点 p に対し ρ = |p|/R、u = p/|p|
    中心位相：方向 ŝ = (cos θla cos θlo, cos θla sin θlo, sin θla)、表示位置 σR ŝ。対蹠点は (π−σ)R(−ŝ)
    cos χ = cos ρ cos σ + sin ρ sin σ (u · ŝ)
    Z_n(χ) = sin((n+1)χ) / ((n+1) sin χ) = U_n(cos χ)/(n+1)      チェビシェフ第 2 種、U_{n+1} = 2x U_n − U_{n−1}
    等振幅        A(χ) = (1/N) Σ_{n=1}^{N} Z_n(χ)
    フェイエール  A(χ) = Σ w_n Z_n(χ) / Σ w_n,   w_n = 1 − n/(N+1)

- S³ の軸対称なラプラシアンは f = g/sin χ と置くと弦の方程式に落ち（Δ(g/sin χ) = (g″+g)/(R² sin χ)）、g = sin((n+1)χ) がそのまま固有関数になる。節は χ = kπ/(n+1) で厳密に等間隔、中心位相で 1、対蹠点で (−1)^n。分母の sin χ は波面の面積 4πR² sin²χ の集束の因子で、極を節から腹に変える。S² では節が等間隔にならなかったが、S³ では等間隔になる
- どちらのモードも A(中心位相) = 1、S³ 上の平均 0（重み sin²χ）、N = 1 で A = cos χ。等振幅の和は閉じた形 (π − χ)/(2 sin χ) − 1 に収束する（S² の 1/(2 sin(γ/2)) − 1 に対応、対蹠点の床 −1/2 は同じ）
- 表示：球体を中心位相の子午面（e_z と θlo 方向が張る面）と水平面の 2 枚で切った円盤に色を塗る（−1〜+1 固定、0 が白、+1 赤、−1 青。円盤は陰影なしで色がそのまま A、透明度 10%）。薄い面は半径 πR の球体の輪郭、赤点は中心位相、青点は対蹠点、黒点は観測者、線は三点を通る測地線（観測者を通る測地線は主観座標系で直線）。赤の半透明の面（透明度 30%）は半値の殻：A(χ) が中心位相から最初に 1/2 を切る角距離 χ½ の測地球面 χ = χ½。中心位相 S からの 4 次元の正規直交枠 (S, E1, E2, E3) で cos χ½ S + sin χ½ (…) を作り主観座標系に写すので、σ ≠ 0 でも正確。χ½ と半径 χ½R は題に表示（等振幅 N = 10 で 16.5°、50 で 4.0°、100 で 2.0°）。最初に零点の殻を描いたが、等振幅の和の零点は極限 (π − χ)/(2 sin χ) − 1 の零点 71.4° に固定され N で動かないので、局在を示さない指標だった（確認値の表の「最初の零点」列）。色バーは出さず、その位置に振幅曲線 A(χ) のパネル（横 A ∈ [−1, 1]、縦 χ ∈ [0°, 180°]、χ½ に赤の点線）を置く。軸は等倍、±32 固定
- スライダー：θlo [0, 360]（初期 180）、θla [−90, 90]（初期 0）、σ [0, 180]（初期 0）、R [0, 10]（初期 3）、N [1, 100]（初期 50）。フェイエールのボタン（初期 OFF）。Auto（初期オン）：150 ms ごとに θlo ← θlo + 5
- 格子は円盤の半径方向 nρ = min(405, max(181, 4(N+1)+1))、角方向 nα = min(721, max(361, 8(N+1)+1))。URL 引数 ?lo=&la=&sg=&R=&N=&fejer=1&auto=0（図の記録に使用）
