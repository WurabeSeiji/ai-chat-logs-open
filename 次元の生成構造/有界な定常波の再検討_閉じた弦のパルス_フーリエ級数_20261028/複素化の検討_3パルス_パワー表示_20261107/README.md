## 核心

    P(ψ) ＝ |Z(ψ)|² ＝ (Re Z)² ＋ (Im Z)²、　ψ 平均 ⟨|Z|²⟩ ＝ |C₀|² ＋ R²、　C₀ ＝ Σ_i c₀ᵢ e^{iφ₀ᵢ}

各パルス Z_i は正の倍音だけの和（解析信号）なので、内部位相 e^{iφ₀} を掛けても |Z_i|² は変わらない。原本の表示で見える「振動」は、φ₀ が δ ずつ進むたびに実部が山型（Re）と双極型（Im）の間を往復する脈動と、Gibbs のさざ波。二乗すると脈動が消え、パルスの形（局在）と、パルスどうしの干渉項 2 Re(Z_i Z̄_j)（cos(mΔ − Φ) の寄与）だけが残る。干渉項は物理なので残す。平均化は要らない。|Z|² は原本がパワー重心の計算に使っている量。
