# 四元数化の検討（3 パルス）パワー表示版：index_v4q3.html（2026-11-07）

`../四元数化の検討_3パルス_スケール固定_20261107/index_v3q3.html` の忠実コピーに、表示モードを一つ加えた。計算・読める量・Auto の規則・枠の固定は変えていない。

## 核心

    四元数ではパワーを軸方向ごとに定義する：W²、V_i²、V_j²、V_k²。合計が |Q|² ＝ W² ＋ V_i² ＋ V_j² ＋ V_k²

複素版（`../複素化の検討_3パルス_パワー表示_20261107/index_v4c3.html`）の |Z|² ＝ Re² ＋ Im² を四元数にすると、成分が 4 つになり、パワーは軸ごとの 4 本になる。表示は 4 成分と同じ置き方で、各成分を二乗する。

## 変更（`diff_v3q3_to_v4q3.txt`）

1. R× の行に「パワー表示」のチェックボックス（既定 OFF。OFF なら v3q3 と同じ表示）。URL 引数 `pow=1` で ON
2. ON のとき、4 成分（黒 W・赤 V_j・緑 −V_i・青 V_k）の代わりに、軸ごとのパワー W²・V_j²（半径方向、黒・赤）と V_i²・V_k²（垂直、緑・青）を同じ置き方で描く。基準円・円筒・中心の印・重心はそのまま
3. 「いま必要な枠」は ON のとき軸ごとのパワーの最大で計算する（枠の固定とスケール調整は v3q3 のまま。ON/OFF で枠は変えない）
4. 右上の読みに、ON のとき軸ごとの max と ψ 平均、合計の ψ 平均 ⟨|Q|²⟩_ψ を足す
5. タイトルと注記に一文
