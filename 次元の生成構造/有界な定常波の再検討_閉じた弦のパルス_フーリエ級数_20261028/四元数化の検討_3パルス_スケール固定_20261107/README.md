# 四元数化の検討（3 パルス）スケール固定版：index_v3q3.html（2026-11-07）

`../四元数化の検討_3パルス_20261031/index_v2q3.html`（同じ弦の上の三つの四元数パルス、観測者の時空）の忠実コピーに、`../複素化の検討_3パルス_スケール固定_20261107/index_v3c3.html` と同じ表示の変更を一つだけ加えた。計算・読める量・Auto の規則は変えていない。

## 変更の理由

原本は 3D の枠 ±L を描画のたびに「kR ＋ 4 成分の振幅の最大」から計算し直す。Auto のティックで和の R が脈打つと L も毎回変わり、円筒と曲線ごと図全体が拡大縮小して、R の変化そのものが見えない。

## 変更（4 か所、`diff_v2q3_to_v3q3.txt`。複素版 v3c3 と同じ）

1. 枠を固定する変数 `Lfix` を置く。最初の描画で一度だけ現在の値を入れ、以後の draw() は `Lfix` を使う。R が変わっても枠は動かない。スライダー操作のリセットでも枠は変えない
2. R× スライダーの横に「スケール調整」ボタン。押すと `Lfix = null` にして描き直し、その時点の kR と振幅に枠を合わせ直す。押さない限り枠は変わらない
3. 右上の読みの末尾に「枠 ±L（いま必要な枠 ±L′、はみ出し）」を足す。L′ ＞ L のとき「はみ出し」と出る
4. タイトルと注記に一文

右の観測者の時空の目盛書き換え（はみ出したら 180° ずつ）は別の仕組みで、触っていない。
