## 0. 要旨

相互作用なし版の 4 パルスは、原点から出る半直線（S³ の大円）を各自の角速度で進み、互いに何もしない（ボゾン、ゲージ粒子の振る舞い）。本稿はそこに相互作用を一つだけ足す。各ステップ、全対について重なりの核 F_ij を計算し、[S1] の二チャネル交換写像を核の分だけ掛ける。衝突判定・剛体半径・窓・セルは置かない。素通りと衝突は同じ式の両端である。交換が変えるのは各パルスの振幅四元数（大きさ・内部時計・軸）だけで、包絡（倍音の構成）と位置 θ と速さ v は変えない。したがって波形は構成で崩れず、軸が変わることが偏向として現れる。速さの変化（角運動量の配分）と 2r のワープは本稿では置かず、§7 に残す。

## 1. 状態（相互作用なし版と同じ）

パルス i（i ＝ 1…4）の状態は次の組で、v11q4 のスライダーそのものである。

| 記号 | 意味 | v11q4 の変数 |
|---|---|---|
| θ_i | 弦の上の中心位相（度、mod 360） | `u.th` |
| Θ_i | θ_i の持ち上げ（巻数込み、cum で累積） | `base[i][0] + cum[i][k][0]` |
| v_i | 角速度（度/tick、負も可） | `u.vv` |
| φ_i, M_i, 奇/偶 | 幅・帯域・偶奇 → 包絡の係数 c_{i,m} ＝ (2/π) sin(mπφ_i/360)/m、c_{i,0} ＝ φ_i/360 | `u.ph, u.mm, u.odd, u.even` → `co` |
| A_i | 振幅（大きさ） | `u.aa` |
| n_i | 単位純虚四元数（軸 ＝ 図での進行方向） | `nvec(u)` |
| φ₀_i, δ_i | 内部時計とその速さ（度/tick） | `u.phase0, u.dl` |

波形は q_i(ψ) ＝ A_i [c_{i,0} e^{n_i φ₀i} ＋ Σ_m c_{i,m} e^{n_i(φ₀i ＋ m(ψ − θ_i))}]。これを「位置 θ_i に置かれた包絡 c_{i,·}」と「振幅四元数」

a_i ≡ A_i e^{n_i φ₀i}　（|a_i| ＝ A_i、軸 n_i、角 φ₀i）

に分けて読む。相互作用が触るのは a_i だけである。a_i を書き換えれば A_i、n_i、φ₀i が同時に更新される（極分解）。

図の座標は r_i ＝ Θ_i n_i、球の半径は 2/√M_i（度）。

## 2. 重なりの核 F_ij（視野角）

### 2.1 距離

巻数まで数える立場（11/9：360° 以下の位相は読めない、読んでいるのは巻数）に従い、距離は図の座標の距離を使う。

d_ij ＝ |Θ_i n_i − Θ_j n_j|　（度）

S³ の余弦定理や弦の上の Δ ＝ θ_i − θ_j は 360° の周期を持ち、巻数の違う二波を近いと数えるので使わない。同じ軸・同じ巻数なら d_ij ＝ |Θ_i − Θ_j| ＝ |Δ_ij| で弦の上の距離に一致する。

### 2.2 包絡の重なり

二つの包絡の相互相関を、共有する帯域で取る。

C_ij(d) ＝ Σ_{m ≥ 1} c_{i,m} c_{j,m} cos(m d)，　F̃_ij ＝ C_ij(d_ij) / √(C_ii(0) C_jj(0))

同形のパルスなら F̃ は自己相関の形で、d ＝ 0 で 1、幅はおよそ 2/√M（cos² 型と読んだときの幅。sinc 型の現行包絡では実幅は φ と M で決まる）。遠ければ指数的に小さい。これが [S5] 第 I 部 §5 の「共有帯域で決まる相関」であり、11/9 朝の「cos² 型の分布の交差項がそのまま相互作用」の式である。直流 m ＝ 0 は重なりに入れない（局在に寄与しない）。

### 2.3 軸の因子

軸が違う二波の交差項のスカラー部には (1 ＋ n_i·n_j)/2 が掛かる（[S5] §4.2、11/9 の Sc の式）。軸が逆なら全く見えない。

F_ij ＝ (1 ＋ n_i·n_j)/2 · F̃_ij　∈ [−1, 1]

F̃ は符号を持ち得る（包絡の副峰）。符号は交換の向きとして残す。

### 2.4 核の性質

- F_ii は使わない（自分自身は観測できない、[S4] P1）。
- F_ij ＝ F_ji。
- 判定はない。F が小さければ交換が小さいだけで、式は一つ。

## 3. 二チャネル交換（衝突したときの写像）

### 3.1 原本 [S1]

全重なりの二波 a、b に対し、対称チャネル S ＝ (a ＋ b)/2 と反対称チャネル D ＝ (a − b)/2 に分け、D だけに内部核の位相差 Δ_F を転写して再合成する。

U(Δ_F) ＝ P_S ＋ e^{iΔ_F} P_D，　a′ ＝ r a ＋ t b，　b′ ＝ t a ＋ r b，　r ＝ (1 ＋ e^{iΔ_F})/2，　t ＝ (1 − e^{iΔ_F})/2

反射率 R ＝ |t|² ＝ sin²(Δ_F/2)。Δ_F ＝ 0 で恒等、Δ_F ＝ π で入替え（a′ ＝ b、b′ ＝ a）。

### 3.2 四元数化

i を、対で対称な共有軸に置き換える。

û_ij ＝ (n_i ＋ n_j)/|n_i ＋ n_j|

右から掛ける（左は無名性の側、11/8）。a′ ＝ a r ＋ b t、r ＝ (1 ＋ e^{û Δ_F})/2、t ＝ (1 − e^{û Δ_F})/2 で、|a′|² ＋ |b′|² ＝ |a|² ＋ |b|² は e^{ûΔ_F} が単位四元数であることから成り立つ。軸が逆（n_i ＝ −n_j）なら û が定義できないが、そのとき F_ij ＝ 0 で項がない。

### 3.3 Δ_F ＝ 内部時計の差

[S1] の Δ_F は二つの内部核の位相差である。本系では内部時計 φ₀ がそれに当たる。

Δ_F,ij ＝ s_ij (φ₀i − φ₀j)

s_ij は対の向きの規約で、名前に依らない量で決める。相対速度の向きを共有軸に射影した符号

s_ij ＝ sign( (v_i n_i − v_j n_j) · û_ij )

とする。i と j を入れ替えると φ₀ の差も s も符号を変え、Δ_F,ij は不変。相対速度が零（並走）の対は s ＝ 0 で交換角が零になる。これは [S1] で Δ_F を「進む側から見た核の位相差」として置いたことの一般化で、v0.7 §17 で |Φ| を使った点の訂正である。

### 3.4 核で重みづける

重なりが部分的なとき、交換は核の分だけ起こる。生成子で書くと U(Δ_F) ＝ exp(Δ_F · P_D ⊗ R(û)) なので、核を指数に掛ける。

U_ij ＝ exp( F_ij Δ_F,ij · P_D^{(ij)} ⊗ R(û_ij) ) ＝ P_S ＋ e^{û_ij F_ij Δ_F,ij} P_D^{(ij)}

重なり F ＝ 1 で [S1] に戻り、F → 0 で恒等。部分重なりでの実効反射率は sin²(F Δ_F/2) であって、R に F を掛けたものではない。

### 3.5 全対同時

6 対の生成子を足して一度に指数を取る（順序なし、名前なし）。

G ＝ Σ_{i<j} F_ij Δ_F,ij · P_D^{(ij)} ⊗ R(û_ij)，　U ＝ exp(G)，　(a_1′, …, a_4′) ＝ U (a_1, …, a_4)

P_D^{(ij)} は対称、R(û) は反対称なので G は 16 × 16 の実反対称行列、U は厳密に直交。Σ_i |a_i|² ＝ Σ_i A_i² は構成で保存される（後付けの正規化はない）。

## 4. 各ステップの順序

1. 自由運動：θ_i ← θ_i ＋ v_i、Θ_i ← Θ_i ＋ v_i、φ₀i ← φ₀i ＋ δ_i（v11q4 と同一）。
2. 核：全対で d_ij、F̃_ij、F_ij。
3. 交換：G → U → a_i′。
4. 読み戻し：A_i′ ＝ |a_i′|、n_i′ ＝ Vec(a_i′)/|Vec(a_i′)|、φ₀i′ ＝ atan2(|Vec|, Sc)。Vec が零なら n_i は前の値を保つ。
5. 描画と記録（相互作用なし版と同じ読み：関係・軌道・球）。

変わるもの：A_i、φ₀i、n_i。変わらないもの：θ_i、Θ_i、v_i、c_{i,m}。

## 5. 何が起こるか

- **素通り。** 遠い対は F ≈ 0、U ≈ I。ボゾンの振る舞いが既定。
- **正面衝突、同形同大。** 重なりの最大で F ＝ 1。Δ_F ＝ π なら a′ ＝ b、b′ ＝ a：内部状態が入れ替わる。位置と速さは入れ替わらないので、図では二つが通り抜けたように見え、内部時計と軸が交換される。同一の二波なら入替えと区別がつかない（11/9 の古典の解析）。
- **位相の回転。** 0 ＜ F ＜ 1 では a′ ＝ a r ＋ b t で a の角と軸が少し回る。これが「観測 ＝ 相互作用による位相の回転」で、量は F と Δ_F と相手の大きさ |b| で決まる（視野角 × 相手の大きさ）。
- **偏向。** 軸が違う二波では b t が a と別の軸を持つので a′ の軸 n_i′ が n_i と n_j の張る面の中で回る。回転の軸は n_i × n_j。図では以後、別の半直線を進む。
- **質量の違い。** |b| ≫ |a| なら a の方が大きく変わる。軽い方が大きく曲がる。
- **波形。** 包絡 c_{i,m} は触らない。崩れない。

## 6. 古典との対応

| 古典 | 本系 |
|---|---|
| 衝突径数 b | 軸の角 γ と Θ による d_ij ＝ Θ sin γ（同軸なら 0） |
| 剛体半径 r | 置かない。核の幅 2/√M がその役 |
| 衝突判定 | ない。F が連続に効く |
| 散乱角 θ(b) | n_i′ と n_i の角。F と Δ_F と大きさの比の関数 |
| 同質量の正面弾性衝突 ＝ 入替え | Δ_F ＝ π、F ＝ 1 の交換 |
| 2r のワープ（位相シフト） | §7 |
| 運動量保存 | 角運動量 Σ A_i v_i n_i（S³、SO(4)）。本版では v を変えないので Σ A_i n_i の成分として一部だけ試験できる |

## 7. 本版で置いていないもの（著者判断）

1. **速さ v の変化。** 角運動量 Σ A_i v_i n_i の配分規則。本版は v 固定。
2. **2r のワープ。** 重なりの間に位置 θ が受ける位相シフト。本版は θ を触らない。
3. **s_ij の規約。** 相対速度の射影の符号。並走（s ＝ 0）の扱い。
4. **F̃ の符号。** 包絡の副峰の負の値を交換の向きとして使うか、|F̃| にするか。本版は符号つき。
5. **核の距離。** 図の距離（巻数込み）を採った。S³ の余弦定理に替えると周期的になる。
