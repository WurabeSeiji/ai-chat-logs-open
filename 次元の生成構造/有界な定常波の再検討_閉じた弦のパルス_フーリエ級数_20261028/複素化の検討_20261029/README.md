## 式（index_v2c.html）

    Z(ψ) = φ/360 + (2/π) Σ_m [ sin(mπφ/360) / m ] · e^{imπ(ψ−θ)/180}    m は 1..M のうち奇・偶で選んだもの
    実部 = index_v2.html のパルスの高さ z と同じ式、虚部 = 同じ係数の sin の和
    R = √Σ_m c_m²（直流を含めない）、表示半径 kR（k = 1..20、初期 10）、実部の曲線 = ((kR + Re Z) cos ψ, (kR + Re Z) sin ψ, 0)、虚部の曲線 = (kR cos ψ, kR sin ψ, Im Z)

## 確認値の要点（θ = 180°, φ = 10°）

M = 10：max Re 0.5569 / min Re −0.1105（index_v2.html と一致）、max Im ±0.3985、R = 0.1675、線形重心 (−0.0277, 0) = c₁/2、パワー重心 (−0.1561, 0)、c₀/R = 0.1659、P(π)/R² = −0.0138、⟨m⟩ = 5.383。M = 100：max Re 1.0950 / min Re −0.0870、max Im ±1.1128、R = 0.2283。奇のみ P(π)/R² = −1、偶のみ +1 で重心二種とも 0。
