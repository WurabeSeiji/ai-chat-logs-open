## 要点

    R²(Δ) = R₁² + R₂² + 2 Σ_m c⁽¹⁾_m c⁽²⁾_m cos(mΔ) = R₁² + R₂² + 2 R₁ R₂ cos Θ
    同じパルス（φ=10°, M=10, R₁=0.1675）：Δ=0 で R=2R₁=0.3349、半幅 18° で Θ が 90° を切り、以後 R≈√2 R₁
    奇のみと偶のみ：全 Δ で cos Θ = 0、R = √(R₁²+R₂²) = 0.1675
    零閉塞 Σc²：同じパルスは基準を真ん中に置けば全 Δ で実、違うパルスは Δ∈{0, π} のみ
    対照：パルス 2 なしで単独の確認値に一致、同じパルス Δ=0 で和は単独の 2 倍
