## 指示（木原氏、11/9）

「現在粒子の位置としてプロットしている球体の大きさを 2/√k にしてみては。相互作用を考える前に、衝突可能性が理解できる」。背景：この表示空間は曲率 R の主観空間（S³ の指数座標、半直線は大円）。局在パルスの大きさを硬い大きさでなく cos² 型の分布として読むと、幅は 2/√k、二つの分布の重なり（交差項）がそのまま相互作用になる。球の重なり ＝ 衝突可能性。
