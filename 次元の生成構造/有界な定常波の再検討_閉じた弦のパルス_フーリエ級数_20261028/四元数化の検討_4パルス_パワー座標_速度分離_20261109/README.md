# 四元数化の検討（4 パルス）パワー座標版・速度分離：index_v11q4.html（2026-11-09）

`index_v10q4.html`（球の半径 2/√M）の忠実コピーに、位置の速度 v_i（°/tick、負も可）を幅 φ_i から切り離すスライダーを足した（差分 24 行、`diff_v10q4_to_v11q4.txt`）。そのうえで初期値を正面衝突の配置にし、右パネルの既定を「座標」にした（`set_defaults_headon_v11q4.py`、木原氏「初期値のままで実行すればよいように」）。相互作用は入っていない。

## 指示（木原氏、11/9）

「調整できるのは n だけでなく、初期の中心位相もステップ毎の位相も、マイナスも設定できる。いくらでも衝突軌道が作れるはず」「幅を兼ねているための制限で、設定項目が分かれればレンジの制限は無くなる。物理ではない制限」。v10q4 までは θ ← θ ＋ φ で φ が幅（c_m ＝ sin(mπφ/360)/m）を兼ねていたため 0 以上に縛られ、全パルスが原点から外へしか進めなかった。
