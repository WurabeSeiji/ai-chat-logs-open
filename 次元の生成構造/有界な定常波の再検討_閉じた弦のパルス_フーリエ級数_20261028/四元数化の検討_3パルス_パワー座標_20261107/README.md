`index_v7q3.html` の忠実コピーに、右パネルのパワー表示の切替「円周上／座標」と、R× の横のスライダー s（球の倍率）だけを足した。左パネル、読める量、枠、初期値は一切変えていない。差分 55 行。

## 指示（木原氏、11/7）

座標表示は位相空間。三つの中心位相 (θ₁, θ₂, θ₃) の点が光速で進む。波 i の点は、その点を波 i の軸 n_i ＝ (i_i, j_i, k_i) で成分ごとに写したもの：x₁ ＝ i₁ θ₁、y₁ ＝ j₁ θ₂、z₁ ＝ k₁ θ₃、x₂ ＝ i₂ θ₁、y₂ ＝ j₂ θ₂、z₂ ＝ k₂ θ₃、x₃ ＝ i₃ θ₁、y₃ ＝ j₃ θ₂、z₃ ＝ k₃ θ₃。巻数も含めて等速で並進する。右の枠は初期 ±360°、Auto でスケールを計算し直す。原点と結ぶ線分など不要、軌道だけ描く。波ごとに軌道の色を変える。現在位置に小さな同じ色の球を描く、半径は本来の波の振幅（q ＝ A(a ＋ n b) の A）に、R× の横の別のスライダー s を掛けたもの。s は 1〜100、初期 10（最初 1%〜100% で作ったら度の枠で小さすぎたので改めた）。n の初期値は使いづらいので (1, 0, 0)・(0, 1, 0)・(0, 0, 1) にする。（最初の指示 x ＝ P_i i_i sin θ_i は著者が「考えすぎ」と撤回。11/7）左パネルは変えない。影響があるのは右パネルのパワーを座標表示する場合だけ。

## 切替「右のパワー」（R× の行、既定 円周上。URL `rc=1` で座標）

    円周上：従来どおり（index_v7q3 と同じ）
    座標　：右パネルには波ごとの軌道だけ。Θ ＝ (Θ₁, Θ₂, Θ₃) ＝ 三つの中心位相の累積（度、360° で折り返さない。θ_i の初期値 ＋ ティック × φ_i）。
    　　　　波 i の点 ＝ (i_i Θ₁, j_i Θ₂, k_i Θ₃)、(i_i, j_i, k_i) ＝ n_i。点 (Θ₁, Θ₂, Θ₃) は 1 ティックに (φ₁, φ₂, φ₃) だけ進む（光速）。
    　　　　右の枠は初期 ±360°。軌道がはみ出したら max|点| に合わせて計算し直す（縮尺 1:1:1）。左の枠 ±L は不変。
    　　　　Auto のティックごとに 1 点を取り、波ごとの色（青・紫・緑）でつないだ三本の曲線。原点と結ぶ線分・円筒・弧・印は描かない。スライダーを動かすと軌道は消える
    　　　　現在位置（最後の点）には、その波の色の球を置く。半径 ＝ s × 振幅 A_i（q ＝ A(a ＋ n b) の A。スライダー A。s ＝ R× の横のスライダー s、1〜100、初期 10。度の枠で半径 s×A_i。表示倍率 k は掛けない。URL 引数 s=）

右上の読みに、座標のとき Θ・三つの波の現在の点・点数・右の枠を足す。

初期値の変更（11/7）：n₁ ＝ (1, 0, 0)、n₂ ＝ (0, 1, 0)、n₃ ＝ (0, 0, 1)（i, j, k）。index_v7q3 までは全部 k。対照の default・tri は URL で n ＝ 全部 k を明示して原本と比べる。山の範囲（クリップ）の読みは座標のときも計算する。

経緯：(1) 4 つ目の表示を足して左パネルを変えた、(2) 各パルスの P_i n_i を ψ の曲線として原点から描いた、(3) 一点 (kR sin θ₁, kR sin θ₂, kR sin θ₃) にまとめた（座標を選ぶと参照エラーで止まる不具合も）、(4) 軸ごとのパワーを使おうとした、のいずれも指示と違い廃棄。(5) 11/7 の最初の指示どおり x_i ＝ P_i i_i sin θ_i で作ったが、著者が位相空間の点 (i_i Θ₁, j_i Θ₂, k_i Θ₃) に改めた（球は半径 s×A_i のまま。s が % だと 0.1° で見えないので、s を 1〜100 の倍率に改めた）。
