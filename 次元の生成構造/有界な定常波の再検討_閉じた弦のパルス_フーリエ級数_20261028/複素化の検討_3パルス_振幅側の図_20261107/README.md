## 右パネル

左の描画要素（円筒・基準円・曲線・中心の印・重心・三角形。表示の 3 択も共通）を全部、観測者 o（右：観測者 1／2／3 で選ぶ）の中心位相の点 C_o ＝ kR(cos θ_o, sin θ_o) が原点に来るように −C_o だけ平行移動して描く。円の中心は反対側の円周上 −C_o へ。位相 ψ・振幅の向き（Re は各 ψ の半径方向、Im は垂直）・縮尺・枠 ±L はそのまま。パルスの位相幅は原点の周りで半径方向と直交する接線の向きに乗る。観測者の時空の図（光円錐・世界線）は外し、その読みは h2 の文字のまま残す。右上に「観測者 o の中心位相 θ を原点に（平行移動 (dx, dy)）」を出す。

枠は左と同じ ±L なので、平行移動した円の遠い側（原点から 2kR）が枠の外に出ることがある（figs/v6c3_tri.png）。枠は変えていない。
