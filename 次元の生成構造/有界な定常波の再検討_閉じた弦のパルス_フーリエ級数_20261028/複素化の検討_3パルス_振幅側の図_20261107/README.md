## 指示（木原氏、11/7）

複素数は全て原点にある。左側の図の、円周の中心と円周上の位相の中心を結ぶ線分を、半径の分だけ中心の方向へ平行移動して描画するだけ。円の中心をちょうど反対側の円周上にもってくる。他は一切変更しない。計算は一切変更が必要ない。

## 右パネル

パルス i ごとに、自分の中心位相の点 C_i ＝ kR(cos θ_i, sin θ_i) が原点に来るように −C_i だけ平行移動して、左と同じ描き方で Z_i（内部位相で回した各パルス、左の和の成分）を描く。各パルスの円筒・基準円も同じ平行移動で描くので、各円は原点を通り中心は反対側の円周上 −C_i。三つのパルスは全部原点にあり、それぞれの位相幅は原点の周りで自分の位相の向き θ_i と直交する接線の上に乗る。位相 ψ・振幅の向き（Re は各 ψ の半径方向、Im は垂直）・縮尺・枠 ±L・表示の 3 択（Re・Im／|Z_i|²／Re_i²・Im_i²）はそのまま。重心と三角形は和の量なので右には描かない。観測者の時空の図（光円錐・世界線）は外し、その読みは h2 の文字のまま残す。右上に各パルスの平行移動 (dx_i, dy_i) を出す。
