`../複素化の検討_3パルス_パワー表示_20261107/index_v4c3.html` の忠実コピーに、パワー表示を 3 択にした。計算・読める量・Auto の規則・枠の固定は変えていない。

## 3 択

    Re・Im　　　　：青 Re（半径方向）・橙 Im（垂直）。原本と同じ
    パワー合計　　：|Z|² ＝ Re² ＋ Im² を半径方向に 1 本（緑）。index_v4c3 のパワー表示と同じ
    パワー分離　　：軸ごとのパワー Re²（半径方向、青）・Im²（垂直、橙）を Re・Im と同じ置き方で。合計が |Z|²

四元数版 index_v4q3（軸ごと W²・V_i²・V_j²・V_k²）の複素数での対応が「パワー分離」。

## 変更（`diff_v4c3_to_v5c3.txt`）

1. チェックボックスを 3 択のラジオ（表示：Re・Im／パワー合計／パワー分離、既定 Re・Im）に。URL 引数 `pow=1` 合計、`pow=2` 分離
2. 分離のとき Re² と Im² の 2 本。「いま必要な枠」は描く量の最大で
3. 右上の読みに、分離のとき Re²・Im² の max と ψ 平均、合計 ⟨|Z|²⟩_ψ、|C₀|² ＋ R² を足す。合計の項目名は「パワー表示」→「パワー合計」
