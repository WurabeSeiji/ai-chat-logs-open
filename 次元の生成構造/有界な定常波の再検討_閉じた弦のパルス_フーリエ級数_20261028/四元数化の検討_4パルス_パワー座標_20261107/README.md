# 四元数化の検討（4 パルス）パワー座標版：index_v9q4.html（2026-11-07）

`index_v8q3.html`（3 パルス）の忠実コピーに、パルスを 1 つ足して 4 体にした。左右のパネル・読める量・計算は 3 パルス版と同じで、変えたのはパルス数に依存する箇所だけ。差分 67 行。複素数版は必要になった時点で作る（木原氏）。

## 指示（木原氏、11/7）

「現在の 3 体実験系を拡張して、4 体にした実験系を準備しましょう。複素数版は必要になった時点で作るので、まずは四元数版だけでよい」。背景：3 体では xyz の位置関係を読み出せない（関係は差だけなので独立な差は N − 1、xyz には N ＝ 4）。読める ＝ 相互作用が定義できる、なので、読めるための 4 体の相互作用を考えれば論文になる。本版はその準備（運動学のみ、作用は入れない）。

## 対照（`shoot.sh` → `control_html.py` → `results/control.txt`）

A₄ ＝ 0・n₄ ＝ k にすると 4 は和に寄与せず、巻き数の軸判定も変えない。1〜3 の配置（default・tri）は M・k・n を含めて URL で明示し（n は全部 k）、原本 index_v8q3.html と比べる。

- h1：v9q4 からパルス 4 の項（4: θ ＝ …、Θ の 4 つ目、軌道の 4:、平行移動の 4:、クリップの 4:）を除くと v8q3 と完全一致
- h2：対 12・23・13 の「対ごとの読み」、合成則〜鏡映対の条件、和の尾（c₀/R … 巻き数）が一致
- A₄ ＝ 0 では 4 を含む対の読み（cos Θ・vec V/(R_iR_j)）が R₄ ＝ 0 で割って NaN になるので、NaN の検査は 4 の項を除いた h1 と 12・23・13・和の尾に限る（4 の項が NaN なのは予定どおり）
- v9q4 自身：軌道 4 本 ＝ n_i ∘ (Θ₁, Θ₂, Θ₃)、Θ_i ＝ θ_i(初期) ＋ ティック × φ_i（4 本）、Θ_i ≡ θ_i (mod 360)、右の枠、点数 ＝ ティック ＋ 1。既定の初期値（4 を含む）。辺 6 本・対 6 組。NaN・undefined なし

    default・tri（A₄ = 0、n₄ = k）× 表示 0・1・2 × 円周上／座標：h1（4 の項を除く）・h2 の対 12・23・13・合成則〜鏡映対・和の尾、すべて v8q3 と一致。軌道 4 本 = n_i ∘ (Θ₁, Θ₂, Θ₃) 一致
