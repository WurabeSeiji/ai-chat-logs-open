弦に沿った角 ψ ∈ [0, 360)。高さは倍音の和だけで計算する（井戸関数は使わない）：
z_M(ψ) ＝ φ/360 ＋ (2/π) Σ_{m=1}^{M} [ sin(mπφ/360) / m ] · cos( mπ(ψ−θ)/180 )
3D の点は (R cos ψ, R sin ψ, z_M(ψ))。振幅は円筒の軸方向（R に直交）、高さ 1 は絶対値で R に依らない。軸は等倍。 Auto は 1 ティックごとに θ ← θ ＋ φ、360 を超えたら 0 に戻す。薄い面は半径 R の円筒（高さ 0〜1）、細い線は z ＝ 0 の弦の位置。
