## 1. 見つかった問題

交差項はまずい。コインのほうが大きくても、AND は同じ値を返す。

コインとコップの大きさを入れ替えても、交差項は同じ値になる（計算で確かめた。どちらも 0.021424 R²）。交差項が言うのは「重なっている」ことだけで、「コップがコインを覆っている」ことは言わない。

## 2. 行き詰まり

- 交差項が無いと、相手があるとは読めない。null と区別ができない。だから交差項は要る。
- しかし交差項だけでは、隠す側と隠される側の区別が出ない。
- 演算の順で結果が変わらないと、「隠れる」という表現ができない。
- 円周（S¹）では、特別な原点を持たない演算はすべて順序によらない。順序は原理的に出ない。
- 三体の演算にして観測者を入れても、読むのが交差項であるかぎり、コインのほうが大きい場合に同じように交差してしまう。

## 3. 出ている考え（どれも未確認）

**考え A：S³ が要る。**
想定していた思考実験（S¹）では、「隠れる」という演算ができないのかもしれない。S³ では、ずらす順番で結果が変わる。ただし変わるのは置く順番についてであって、大きさについてではない。

**考え B：隠れる必要はない。**
別々にあることが区別できれば、隠れていない。要るのは「二つが別々にあると区別できるか、できないか」だけかもしれない。これなら順序で変わる演算は要らない。

**考え C：観測者と距離が要る。**
どちらが手前で、どちらが大きいかは、観測者が別にいないと決まらない。近いと区別する基準が無い。観測者がいて、距離も読めないとだめなのかもしれない。S³ なら、交差している以外に距離が読めるのかもしれない。

## 4. 考え C についての覚え書き（Claude。未確認）

- 「隠れる」は三者の関係である。「観測者から見て、コップがコインの手前にある」は、入れ替えると成り立たなくなる。非対称はここにある。
- 「手前」は距離だけで書ける。観測者からコップまでと、コップからコインまでを足すと、観測者からコインまでになる、という条件である。
- 大きさは、実際の大きさではなく、観測者から見た見かけの大きさ（視野角）で比べれば済むかもしれない。遠くの大きなコインは、近くの小さなコップに隠れる。
- 隠れる条件の候補：「同じ向きにある」「コップのほうが近い」「コップの視野角のほうが大きい」。

## 5. あす決めること

1. 「隠れる」を表すのに何が要るか。順序で変わる演算（考え A）か、区別できるかどうかだけ（考え B）か、観測者と距離（考え C）か。
2. それは円周のままで書けるのか、S³ が要るのか。
3. 観測者を入れる場合、きょう決めた範囲（観測者には触れない。ずれに観測者は要らない）をどう直すか。ずれには観測者は要らないが、隠れるには要る、という分け方でよいか。
4. 論文の中心の文をどう直すか。今の「観測とは交差項が読めること」は不十分である。

## 6. きょうまでに確かなこと（あす崩さないための確認）

- 閉じていて端の無い系でなければ、コップを同じコップのまま動かせない（図と計算あり）。
- 窓は半波長であり、奇数倍音と偶数倍音の両方があって初めて山が一つになる（図と計算あり）。
- 分解能は全体 R に対する比で、位相と振幅の両方にある。
- 離れているときの交差項は 0 ではなく、分解能の下にあって読めない（null）。

これらは、交差項の対称性の問題とは独立に成り立つ。
