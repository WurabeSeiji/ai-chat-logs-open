## 1. 仮定

置いている仮定は三つである。

1. **作用が一意に定義でき、一意に読める。**（対話 18 番。コップは一つである、と言えること）
2. **窓は定常である。**（伏せてから開けるまで、窓が同じ大きさで在り続ける。定常波の仮定の中身）
3. **系に特別な方向も原点もない。**

「null の残りを許さない」は、1 と 3 から出る。読めない場所が残れば一意に読めず、その場所は特別な場所になるからである。

「全体の大きさが変わっても、中心位相の比は変わらない」は、3 と同義である。どこかを中心にして広げれば、その中心が特別な点になる。

## 2. 言葉の定義

### 2.1 null とゼロ

- **null**：交差項がそもそも立たない状態。情報が無い。無いことも分からない。
- **ゼロ**：交差項が立ったうえで、値がゼロである状態。

null は証明できない。分かるのは、区別がついたかどうかだけである。

### 2.2 交差項

(a + b)² = a² + b² + 2ab の 2ab。コップとコインの AND に当たる。コインだけ、コップだけを二乗しても、相手については何も出ない。相手についての知識は交差項にしかない。

### 2.3 窓と半波長

窓とは、零から零までの山一つ、すなわち半波長である。伏せると開けるは、その両端に当たる。

「窓の大きさ」とだけ書くと、全体を数える単位が半波長であること、つまり奇数倍音と偶数倍音の両方が在ることが落ちる。落ちると、180° の位置の相方を排除できない（§3.8）。論文では「窓」という言葉を使ってよいが、この定義を添える。

### 2.4 分解能

分解能は絶対値ではなく、全体 R に対する比である。位相と振幅の両方にある。

- **位相の分解能**：窓の幅 ÷ 円周。
- **振幅の分解能**：読める最小の高さ ÷ R。

どちらも分母は同じ R である。null でないと言うには、振幅の分解能が先に要る。山が、読める最小の高さを超えて初めて、null でないと言える。

**振幅の分解能の式（仮説）。** 位相の分解能（山の幅）は、おおよそ k × 2πR ÷ N である。同じ係数を使って、振幅の分解能を

振幅の分解能 = k × （最大の振幅）÷ N

と置く。k は重みで決まる無次元の係数（等振幅で 1、フェイエール重みで 2。山の幅が広がる倍率と同じ）、N は倍音の数である。k が無次元なので、分解能は長さの次元になる。根拠を導いたものではなく、仮説として置いておく。値をなんとなく決めるよりはまし、という位置づけである。§5.6 に計算がある。

## 3. 筋道

### 3.1 観測の条件は、交差項が読めること（仮説）

**この節は、このままでは不十分である。** 交差項は、隠す側と隠される側を入れ替えても同じ値になる。§8 を見よ。

これまで、可干渉であることが観測の条件だと読んでいたかもしれない。可干渉であれば交差項が読める、というのは正しいが、因果が違う。条件は交差項（情報の AND）が読めることであり、可干渉でなくても、交差項が読めればよい。

堀田先生のコインは古典的で可干渉ではないが、観測は成り立っている。コップを開ける行為とコインの状態の AND が読めているからである。非対角成分が無いことは弱点にならない。

対応する事実として、強度干渉（ハンブリー・ブラウンとトゥイス）は、振幅どうしを重ねずに同時計数で相関を読む。

### 3.2 分解能は上にも下にも動かせるが、情報が増えなくなる

この考え方は、必ず無限降下し、同時に無限上昇する。分解能はいくらでも下げられ、いくらでも上げられる。止まるのは分解能ではなく、情報の増え方である。

- 窓を相手の広がりより大きくしても、AND を取る相手は有限な広がりしか持たないので、読めるものは増えない。
- 窓を相手の最小の局在より小さくしても、相手の側にそれ以上の区別が無いので、読めるものは増えない。

上限と下限は、分解能の側ではなく、AND を取る相手の側にある。上も下も同じ形である。

### 3.3 系の定義

系とは、その作用に関係する関係がすべて包含されたものである。言い換えると、分解能を変えると読める情報が変わる範囲である。テーブルでも、部屋でも、地球でも、宇宙でもよい、という問題は、これで消える。

### 3.4 ずれに観測者は要らない

必要なのは、コップとコインのあいだでずれが起こせることだけである。読む第三者は要らない。

決まっているのは三つの比だけである。

- コップの大きさ ÷ 全体の大きさ
- コインの大きさ ÷ 全体の大きさ
- 二つの窓の中央のあいだの距離 ÷ 全体の大きさ

相対位置の原点は自由である。ずれに向きはない。巻き数も読めない。交差項は距離だけの関数であり、距離の符号を変えても、全体を一周ぶん足しても、値は変わらない。

### 3.5 閉じていて端が無いこと（帰結）

一番分かりやすい言い方は次である。

**端のある平らな系では、コップを同じコップのまま動かすことができない。動かせなければ、伏せることも開けることもできず、観測が成り立たない。**

円周では、山をずらすことは各倍音の位相を回すことで、振幅は一本も変わらない。両端を固定した直線では、定常波は sin(kπx/L) の一種類しかなく、回す位相が無い。振幅を変えれば、それは同じ窓を動かしたのではなく、別の波を作り直したことになる（§5.5 の計算）。

同じ結論の別の言い方が二つある。

- 窓を整数個並べてずらすと、端に窓より小さい余りが出る。余りは null である。端のある系で null の残りを許さないなら、置き始めは端に合わせるしかなく、端が原点を決めてしまう。
- 振幅の組を見れば、端からの絶対的な位置が読めてしまう。

また、仮定 3（特別な方向も原点もない）からも、閉じていて端が無いことが要請される。端はそれ自体が特別な場所であり、端に立てば内向きと外向きの区別ができる。

### 3.6 現実のテーブルでコップが動かせる理由

現実のテーブルでコップが動かせるのは、テーブルが本当は曲がっていて閉じているからである。R が大きいので、平らに見えているだけである。

「より大きな系の一部だから動かせる」と書いてはならない。無限に広い平らな面なら動かせる、と誤読される。

| 系 | 落ちる理由 |
|---|---|
| 端のある平らな系 | コップを同じコップのまま動かせない |
| 無限に広い平らな系 | 窓と全体の比が取れず、分解能が定義できない |
| 閉じていて端の無い系 | 落ちない。R が大きいと平らに見える |

現実のテーブルの縁は、系の端ではない。閉じた全体の上に載っている、別の物の輪郭である。平らに見えるかどうかも分解能の問題で、「平らである」は系の性質ではなく、曲がりが読めていないという読出しの側の事情である。

### 3.7 定常であることから、S¹ か S³（帰結）

局在した窓が置けるだけでは絞れない。位相を止めた実数の波はどの球面にも在る。

絞り込みが効くのは、窓が定常であると要請したときである。位相を止めた実数の波は、振れながら振幅が零を通る。大きさが一定のまま局在し続けるには、四分の一だけずれた相方が、全ての倍音について要る。

- 円周（S¹）には、その相方がある。
- 二次元球面では、相方はどこかで必ず零になる（毛玉の定理）。大きさを一定に保てない。
- 残るのは S¹、S³、S⁷ で、三つの関係が閉じる（結合律）のは S¹ と S³ だけである。

この条件は、同じフォルダの外にある原案「時空は 1＋3 でしか存在できない」（2026年10月30日）で得ていたものである。本稿では既刊を根拠にせず、コップの系の言葉で立て直す必要がある。

窓と定常波は別々の仮定ではない。有限で閉じた全体の上では、局在した窓は倍音の重ね合わせとして書け、倍音は窓の重ね合わせとして書ける。循環ではなく双対である。窓をずらすことは、m 番目の倍音の位相を回すことに当たる。

二次元球面が落ちる理由（相方がどこかで必ず零になる）と、端のある系が落ちる理由（相方がそもそも無い）は、同じ一つの条件の二つの現れ方である。

### 3.8 正反対の点と、奇数倍音・偶数倍音

- 偶数倍音だけ：180° の位置にも、同じ向きの山が立つ。
- 奇数倍音だけ：180° の位置に、逆向きの凹みが立つ。
- 両方ある：180° で打ち消し合い、山は一つになる。

窓が一か所にだけ在るためには、奇数と偶数の両方の倍音が要る。これは仮定 1（コップは一つ）がそのまま効いている。窓を半波長と定義した時点で、奇数と偶数の両方が入っており、追加の仮定ではない。

球殻の正反対の点どうしを同じ点とみなした形は、偶数倍音だけの世界に当たり、仮定 1 で落ちる。

### 3.9 凹み、頂点、辺

凸はあっても凹がないことの要請は、仮定 3 だけで出る。追加の仮定は要らない。

- **頂点**：特別な点そのものである。まわりに窓を並べると、ほかの場所より少ない数で一周する。
- **辺**：面を折っただけなので、面の中で距離の比を読むかぎり区別がつかない。読めないので在るとは言えない。読める辺があるなら、頂点と同じく仮定 3 で落ちる。
- **凹み**：まわりに並ぶ窓の数がほかの場所と違う。特別な場所である。

凹みのない穴は無いので、凹がないで十分である。対話 19 番の四条件（凸・有界・有限・穴がない）は、三つの仮定からすべて出る。19 番はすでに閉じていることを要請しており、端が無いという結論と矛盾しない。

### 3.10 位相と振幅の分解能は独立ではない

倍音の数を決めると、位相の細かさと振幅のきれいさを同時に良くすることはできない（§5.2 の計算）。同じ数の倍音を、どちらに使うかの配分になる。

離れているときの交差項は 0 ではなく、小さな負の値になる（§5.3）。振幅に分解能があれば、これは読めない。読めないものは 0 ではなく null である。定数項を入れるかどうかの判断は、これで不要になる。

### 4.1 波形の定義

円周の上の波形：

f(ψ) = a R Σ(m=1…N) w_m cos m(ψ − θ)

- コイン：N = 35、a = 1/72、θ = 90°
- コップ：N = 23、a = 1/36、θ は図ごとに指定
- 重みはフェイエール：w_m = 1 − m/(N+1)
- 定数項（m = 0）は入れていない

描き方は、中心からの距離 r(ψ) = R + f(ψ) である。表示のための縮尺は入れていない。

交差項は c(ψ) = 2 f(コイン) f(コップ) で、R² の次元を持つ。波形と同じ図に描くため、R で一度だけ割って r(ψ) = R + c(ψ)/R として描いた。次元を合わせるための割り算で、図ごとに高さを揃える操作はしていない。

例外が一つある。`fig_cup_s1_all_harmonics.svg` では、倍音一本ずつが小さくて見えないので、倍音の点線だけ半径方向に 5 倍して描いた。図にその旨を書いてある。

### 4.2 設定の経緯

- 最初は等振幅で、コイン 18 本、コップ 12 本とした（山の幅 18.9°、27.7°）。
- コインの山がコップからはみ出すので、コインの振幅をコップの半分にした。
- 山の脇の波（側波帯）を減らすため、フェイエール重みにした。山の幅が 2 倍に広がるので、倍音を 35 本と 23 本に上げた。山の幅は 720/(N+1) 度で、ちょうど 20° と 30° になる。
- 振幅は R に対する比で意味を持つので、「表示用の縮尺」をやめ、一本あたりの振幅を R/36、R/72 と書いた。

プログラム冒頭の `WEIGHT = "equal"` で等振幅に戻せる。

## 5. 計算で出たこと

### 5.1 窓の大きさ

| | 倍音 | 山の幅（底から底） | 山の高さ | 山の外の沈み |
|---|---|---|---|---|
| コイン | 1〜35 | 20.000° | 0.243 R | −0.0069 R |
| コップ | 1〜23 | 30.000° | 0.319 R | −0.0139 R |

山の外で波形が円周よりわずかに内側に沿うのは、定数項を入れていないためである。

### 5.2 山の外の波は、山の何割か

| 重み | 倍音 | 山の半幅 | 山の外の振れ幅 ÷ 山の高さ |
|---|---|---|---|
| 等振幅 | 18 | 13.9° | 0.36 |
| 等振幅 | 36 | 7.1° | 0.35 |
| フェイエール | 35 | 10.0° | 0.049 |
| フェイエール | 23 | 15.0° | 0.050 |

等振幅では、倍音を 18 本から 36 本に増やしても、脇の波の割合はほとんど変わらない。倍音を増やすだけでは振幅の側は良くならない。

### 5.3 交差項

円周全体で足した値を C = ∫ c(ψ) dψ とする。単位は R² である。数値積分と倍音の和は一致した（差は 10⁻¹⁷ の桁）。

| コップの中心 | C |
|---|---|
| 90°（重なる） | +0.02142 R² |
| 75°、105°（縁がかかる） | +0.00076 R² |
| 60°、120° | −0.00071 R² |
| 離れている | −0.0010 〜 −0.0012 R² |

- 重なったときの交差項の山は 0.155 R² で、コインの山の内側に収まる。
- 離れているとき、C は 0 にならず、−π a(コイン) a(コップ) = −0.00121 R² に近づく。定数項を入れていないことから来る。
- コップを 60° に置くと、コインの中心（90°）でのコップの値は、ちょうど山の外の沈みの値（−0.0139 R）になる。

まとめの図の帯は、振幅の分解能の式（仮説、§2.4）で決めた。C に当てるときは、最大の振幅に C の最大（重なったときの値）を、N に C に含まれる倍音の数（コインとコップの少ないほう、23）を使った。

振幅の分解能 = 2 × 0.02142 ÷ 23 = 0.00186 R²

離れたときの値（−0.00121 R²）は、この分解能の 0.65 倍で、帯の内側に入る。帯の外に C が出るのは、コップが 76.85°〜103.15°（コインの中心から ±13.15°）にあるときである。この幅（約 26°）は、コップの山の幅（30°）より狭く、コインの山の幅（20°）より広い。隠れているか見えているかの境目は、窓の幅だけでなく振幅の分解能でも動く。

N にどちらの倍音の数を使うかは、この記録を作るときに決めたもので、著者と確かめてはいない。コインの数（35）を使うと 0.00122 R² になり、離れたときの値とほぼ同じ大きさになる。

### 5.4 偶数倍音と奇数倍音

窓はコップ一つ、中心 90°。重みと一本あたりの振幅は三つとも同じで、足す倍音を選んだだけである。

| | 足した倍音 | 90° での値 | 270° での値 |
|---|---|---|---|
| 偶数だけ | 2、4、…、22（11 本） | +0.1528 R | +0.1528 R |
| 奇数だけ | 1、3、…、23（12 本） | +0.1667 R | −0.1667 R |
| 両方 | 1〜23（23 本） | +0.3194 R | −0.0139 R |

「両方」は「偶数だけ」と「奇数だけ」の和に等しい（差は 10⁻¹⁶ の桁）。

論文で「相方」と書くとき、偶数の場合は同じ向きの山、奇数の場合は逆向きの凹みと、区別して書く必要がある。

### 5.5 開いた系にできない理由

**270° で切り開けるか。** コップの中心を 90° に置くと、270° では 23 本の倍音すべてが、振れが最大の位置にある。奇数倍音は内向きに最大、偶数倍音は外向きに最大である。節になる倍音は一つもない。合成波形が 270° で小さい（−0.0139 R）のは、奇数と偶数が打ち消し合った結果であって、節ではない。全ての倍音が同時に 0 になる場所は、円周のどこにもない。

したがって、両端を節とする開いた系には、どこで切り開いても直せない。

**想定される反論。** 270° では、値は 0 にならないが、傾きは全ての倍音で 0 である。端が自由に振れる開いた系としてなら、条件は合ってしまう。これを退けるのは、コップを動かしたときである。コップの中心を 90° からずらすと、切り口での値も傾きも 0 でなくなり、固定端にも自由端にも合わなくなる。端のある系で条件が合うのは、窓がちょうど真ん中にあるときだけである。

**両端を固定した直線。** 長さ L = 2πR、定常波は sin(kπx/L)、k = 1〜16、一本あたりの振幅 R/36。

| | 山の高さ | 山の位置（全長に対して） | 山の先の波打ち | 中央での値 |
|---|---|---|---|---|
| 等振幅 | 0.332 R | 4.5% | ある | 0 |
| フェイエール重み | 0.150 R | 5.9% | 消える | +0.013 R |

- 山は直線の端に寄る。左右対称にならない。
- 重みを掛けると波打ちは消えるが、正の側に片寄った長い裾が残る。裾は (aR/2) cot(πx/(2L)) という曲線で、定常波を何番まで足しても、どんな重みを掛けても残る。
- 振幅の制御で直せるのは波打ちだけである。「端に寄る」「裾が全体に伸びる」は、端があることそのものから来ている。

**山を動かす方法は無い。** 別の場所 x₀ に山を作るには、k 番の振幅を sin(kπx₀/L) にする必要がある。これは移動ではなく作り直しである。作り直した山は、場所ごとに大きさまで変わる。

| 山の位置（全長に対して） | 振幅の二乗和 |
|---|---|
| 0（端） | 0 |
| 0.01 | 1.40 |
| 0.02 | 4.76 |
| 0.045 | 10.02 |
| 0.1 | 8.90 |
| 0.25 | 8.00 |
| 0.5（中央） | 8.00 |

円周なら、この値は場所によらず一定である。直線の上では、同じ大きさの窓を別の場所に持つことさえできない。

### 5.6 振幅の分解能（仮説の式での計算）

波形に式を当てると、k × A ÷ N は、倍音一本あたりの振幅にちょうど一致する。重みを変えても、倍音の数を変えても同じである。フェイエール重みでは山の高さが半分になり、k が 2 なので、打ち消し合う。

| | N | k | 山の高さ A | k × A ÷ N | 一本あたりの振幅 |
|---|---|---|---|---|---|
| コップ（フェイエール） | 23 | 2 | 0.3194 R | 0.02778 R | R/36 = 0.02778 R |
| コイン（フェイエール） | 35 | 2 | 0.2431 R | 0.01389 R | R/72 = 0.01389 R |
| コップ（等振幅） | 12 | 1 | 0.3333 R | 0.02778 R | 0.02778 R |
| コイン（等振幅） | 18 | 1 | 0.2500 R | 0.01389 R | 0.01389 R |

山の外の波を、この分解能を単位にして測ると次のようになる。

| | 山の外の最大 | 山の外の最小 | 読めるか |
|---|---|---|---|
| コップ（フェイエール） | +0.07 | −0.50 | 読めない |
| コイン（フェイエール） | +0.35 | −0.50 | 読めない |
| コップ（等振幅） | +1.13 | −3.23 | 読める |
| コイン（等振幅） | +1.89 | −4.53 | 読める |

フェイエール重みでは、山の外の波も、定数項を入れていないことによる沈み（−0.5）も、分解能の半分以下である。等振幅では、脇の波が分解能の数倍ある。

## 6. まだ確かめていない点

- **コップの系の言葉だけで立て直すこと。** §3.7 の S¹ か S³ への絞り込みは、原案の定常波の条件に対応させたものである。コップの系の言葉だけで立て直す作業は済んでいない。
- **振幅の分解能の式。** k × （最大の振幅）÷ N は仮説である。なぜこの形になるかは導いていない。交差項に当てるときの N の取り方も決まっていない（§5.3）。
- **時間の側の全体。** 空間ではテーブルが全体に当たる。伏せてから開けるまでの窓に対して、時間の側で全体に当たるものは定めていない。
- **二次元以上で窓を並べること。** 窓を並べてずらす議論は、線と輪の場合のものである。面では「隙間なく並べる」の意味を決め直す必要がある。
- **負の交差項。** 可干渉でなくても交差項が読めればよいとするとき、打ち消しに当たる負の交差項が、可干渉でない読み方のどこに現れるか。
- **コップをずらした場合の切り開いた図。** §5.5 の反論への答えを図で示すには、コップを 60° などにずらした場合の切り開いた図が要る。まだ作っていない。
- **裾の形（横道）。** 両端固定の直線の波形（`fig_line_fixed_ends_fejer16.svg`）は、左端を光円錐の上の自分の位置、右端（x/R = 2π）を無限遠と読むと、ポテンシャルカーブに見える、という著者の気づきがある。自分の位置で 0、すぐ近くに山があり、そこから遠くへ向かって単調に小さくなり、無限遠で 0 になる形である。これは形についての気づきであり、ここでは記録にとどめる。計算として分かっているのは次の二点だけである。裾は端の近くで 1/x の形になる（全長の 20% の位置で、違いは 3% ほど）。この波形は、端の一点に立てた山の、四分の一ずれた相方に当たる。ポテンシャルであることを導いたものではなく、S³ の上で同じ計算をした結果も無い。
- **両端固定の倍音で作れる曲線（後で考える）。** 両端を固定して倍音を足すと、このハット型の減衰曲線が作れる、ということ自体が重要で、どこかで使える気がする、という著者の覚え書き。使い道はまだ決めていない。

## 7. 対話の途中で直した読み方

Claude の言い直しのうち、著者が誤読として直したものを残す。同じ誤読は読者にも起こりうる。

- **干渉を振幅の足し算として読んだ。** 堀田先生のコインに非対角成分が無いことを弱点と見た。問うべきなのは、二つの行為のあいだに交差項があるかどうかである。
- **「どの場所から見ても」と書いて観測者を入れた。** そこに見る者は要らない。必要なのは、コインがどこにあってもコップとのずれが起こせることである。
- **ずれに向きを持ち込んだ。** ずれに向きはなく、巻き数も読めない。
- **著者の言う S² を二次元球面と取った。** 二次元の中の円周のことであった。
- **半波長を窓の大きさに置き換えても「半」の意味は残る、と書いた。** 残らない。奇数と偶数の両方が在ることが落ちる。
- **振幅の分解能を、何に対する比かで候補を二つ立てた。** 全体は一つで R である。
- **現実のテーブルでコップが動かせる理由を「より大きな系の一部だから」と書いた。** 無限に広い平らな面なら動かせると誤読される。正しくは、テーブルは曲がっていて閉じており、R が大きいので平らに見えるだけである。
- **著者の「ポテンシャルカーブに見える」を、裾が 1/x であることの指摘として受け取った。** 著者が言ったのは、左端を光円錐の上の自分の位置、右端を無限遠と読むと、全体の形がポテンシャルカーブに見える、ということである。

## 8. 交差項の対称性の問題と、「隠れる」という演算（2026年11月24日の終わりに出た問題。翌日に続く）

### 8.1 問題

著者の気づき：交差項はまずい。コインのほうが大きくても、AND は同じ値を返す。

計算で確かめた。コインとコップの大きさをそっくり入れ替えても、円周全体で足した交差項 C は同じ値になる。

| | コイン | コップ | C |
|---|---|---|---|
| 今の設定 | 20°（倍音 1〜35、一本あたり R/72） | 30°（倍音 1〜23、一本あたり R/36） | 0.021424 R² |
| 入れ替え | 30°（倍音 1〜23、一本あたり R/36） | 20°（倍音 1〜35、一本あたり R/72） | 0.021424 R² |

交差項は 2 × コイン × コップ という積なので、入れ替えても変わらない。交差項が言っているのは「重なっている」ことだけで、「コップがコインを覆っている」ことは言っていない。

対話 15 番では、「コインがコップより小さければ隠れ、大きければ開ける前から見えてしまう」から空間の分解能を定めた。これは、どちらが覆う側かという非対称な関係である。交差項だけでは、この非対称が出ない。

### 8.2 著者の指摘

コップで隠れるという写像のためには、演算の順に依存する、隠すほうと隠されるほうの関係のある交差項が必要ではないか。あるいは「隠れない」という演算なのかもしれない。いずれにしても、演算の順で結果が変わらないと、「隠れる」という表現ができない。

### 8.3 非対称が残っている場所（計算で確かめた範囲）

- **交差項に入らなかった倍音。** 交差項に入るのは、二つの窓に共通する倍音だけである。今の設定では 1〜23 番が入り、コインの 24〜35 番の 12 本は相手がいない。入れ替えると、相手がいないのはコップの側の 12 本になる。
- **自分だけの二乗の項。** 円周全体で足した値は、今の設定でコインが 0.0070 R²、コップが 0.0182 R²。入れ替えると逆になる。

どちらも、二つの窓の倍音の数や大きさが違うことから来る非対称である。演算の順序から来る非対称ではない。

### 8.4 円周（S¹）では、順序は原理的に出ない

円周では、ずらす操作どうしは順序を入れ替えても同じである。特別な原点を持たない操作（どこにずらしても同じ形で働く操作）は、すべて倍音ごとの掛け算になり、互いに順序を入れ替えられる。既知の事実である。

したがって、仮定 3（特別な原点がない）を守るかぎり、円周の上でコップとコインから組み立てられる演算は、どれも順序によらない。「相手の倍音だけを通す」という演算も例外ではない。

### 8.5 S³ では、ずらす順序が効く

S³ では、ずらす操作 a と b について、a のあとに b と、b のあとに a が違う結果になる。

ただし、丸い窓（中心からの距離だけで決まる窓）どうしでは、S³ の上でも、大きさについては順序を入れ替えられる。順序で変わるのは、窓の位置、つまりずらす操作の順番だけである。これも既知の事実である。

つまり S³ が与えるのは、「どちらが大きいか」の非対称ではなく、「どちらを先に置いたか」の非対称である。

現実のコップとコインでも、隠れるかどうかを決めるのは順番である。

- コインを置いてから、コップを伏せる：隠れる。
- コップを伏せてから、コインを置く：隠れない。

| | 何が決めるか | S¹ | S³ |
|---|---|---|---|
| 隠れる・隠れない | 置く順番 | 書けない | 書ける |
| どこまで細かく読めるか | 倍音の数（大きさ） | 書ける | 書ける |

### 8.6 著者の気づき（仮説）

想定していた思考実験（S¹）では、「隠れる」という演算ができないのかもしれない。だとすると、S³ が必要になる。

これが正しければ、円周の思考実験は「分解能と閉じた系」までを示す導入になり、「隠れる」という観測の核心は S³ で初めて書ける、という二段の構成になる。S¹ と S³ のどちらも残るというこれまでの結論が、S³ だけに絞られる可能性がある。

### 8.7 確かめていないこと

- S³ の上で「先に置いたものが、後から置いたものに隠される」が、掛け算の順序の違いとして、実際にどういう量に現れるか。順序で結果が変わることは確かだが、その違いが「隠れた」と読める量になっているかは計算していない。
- 丸くない窓まで考える必要があるかどうか。

### 8.8 翌日に考える問い（著者）

隠れる必要はないのかもしれない。別々にあることが区別できれば、隠れていない。

（Claude の覚え書き：この問いの立て方だと、要るのは「二つが別々にあると区別できるか、できないか」であり、これは入れ替えても変わらない関係である。もしそうなら、順序で変わる演算は要らず、円周のままで足りることになる。8.6 の仮説と、どちらが正しいかを決める問いになる。）

### 8.9 その場で出た行き詰まり（著者）

難しい点が二つ重なっている。

- 交差項が無いと、相手があるとは読めない。null と区別ができない。したがって、「別々にある」と言うためにも、交差項は要る。
- では二体ではなく三体の演算にして、観測者から二体が同時にあると判断できればコップは開いている、一体として重なって読める場合は伏せてある、としてはどうか。しかしこれでも、コインのほうが大きい場合に同じように交差してしまう。8.1 の問題が残る。

結論は出ていない。もっとよく考える。

### 8.10 観測者と距離が要るのではないか（著者）

S³ なら、交差している以外に距離が読めるのかもしれない。しかし、どちらが手前で、どちらが大きいかは、やはり観測者が別にいないと決まらない。近いと区別する基準が無い。観測者がいて、距離も読めないとだめなのかもしれない。

（Claude の覚え書き。あすの出発点の候補として。）

- 「隠れる」は、もともと三者の関係である。誰から見て隠れているかを言わないと意味が決まらない。観測者 O、コップ K、コイン C について、「O から見て K が C の手前にある」は、入れ替えると成り立たなくなる関係であり、探していた非対称はここにある。
- 「手前」は距離で書ける。K が O と C のあいだにあるとは、O から K までの距離と K から C までの距離を足すと、O から C までの距離になることである。これは距離だけで書け、順序で変わる掛け算は要らない。
- 「コインのほうが大きくても交差する」という問題は、実際の大きさではなく、O から見た見かけの大きさ（視野角）で比べれば解ける可能性がある。遠くにある大きなコインは、近くの小さなコップに隠れうる。
- そうだとすると、隠れる条件は「同じ向きにある」「コップのほうが近い」「コップの視野角のほうが大きい」の三つになる。
- この場合、§1 の範囲の断り（観測者には触れない）と、§3.4（ずれに観測者は要らない）は見直しが要る。ずれには観測者は要らないが、隠れるには観測者が要る、という分け方になる。
- 確かめていない。三者にすれば円周のままで足りるのか、S³ が要るのかも、まだ分からない。
