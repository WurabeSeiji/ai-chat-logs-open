# 凝縮体が存在する {zₙ} の実例――四元数 4 個・6 個、八元数 10 個（データと考察）

- 日付：2026-10-24
- 位置づけ：「四元数関係の結晶化とインフレーション」（2026-10-21、v1.1）と思考実験メモ2（結晶化の動力学へ）の続き。凝縮体の条件を理屈で並べるのではなく、凝縮体が存在する {zₙ} を実際の数字で作ることが目的
- 関連：思考実験「蔵本引き込みと割り算の罠」発言録 第一部・第二部（読み出しの原則、複素数・四元数・八元数の比較）

---

## 1. 記号と判定量

- 四元数 q = z₁ + z₂ j（z₁ = a + bi、z₂ = c + di → q = a + bi + cj + dk）。四元数 1 個 = 複素数 2 個
- 八元数 o = (q_a, q_b)（Cayley–Dickson、積 (a,b)(c,d) = (ac − d̄b, da + bc̄)、γ = −1）。八元数 1 個 = 複素数 4 個
- 閉塞：Σq = 0（線形閉塞）、Σq² = 0（真の自乗による二乗閉塞）
- 相対位相 u = q_a⁻¹ q_b、角 α = arccos Re(u)（等振幅）
- 結合係数 |k| = tan(α/2)、視野角距離 D = cot(α/2)。|k| = 1（α = 90°）がホライズン＝光円錐＝結合の閾値
- 三体の非可換性 Δ₃ = ¼|uv − vu|²（u = q₁⁻¹q₂、v = q₁⁻¹q₃）
- 四体の非結合性（八元数）|(uv)w − u(vw)|（観測者 o_a から見た三つの相対位相）
- 虚部の張る次元：虚部（ベクトル部）を並べた行列の特異値

## 2. 凝縮体の条件（今回の整理）

前の条件が満たされて初めて次が意味を持つ順に並べる。

1. 関係が一枚の複素面に収まらないこと（Δ₃ > 0）。ℂ では無名性のもとで何も読めないので凝縮体も作れない。凝縮は ℍ から始まる
2. 違いがあり、その違いがホライズンの内側にあること（|k| > 1、D < 1）。同じ状態どうしは読み出しがゼロで凝縮しない
3. 部分集合が自分で閉じること（部分閉塞）。閉じた部分集合は外からの線形な読み出しに寄与しない（外のどの状態から見ても、凝縮体との線形な関係の平均はゼロ）
4. 分配率を自分で決めた結果、ロックが閉じること（Uⁿ = I）。完全なロックは事象も時間もない剛体結晶なので、ロック限界のわずか内側の不完全なロックだけが寿命を持つ凝縮体になる
5. 外からの読み出しに対して非破壊であること。四元数で閉塞を保つのは両側から同じ単位で回す u q u⁻¹ だけ
6. 𝕆 では作られた順序が結合子の符号として記録される。結合子は完全反対称なので、三体の凝縮体には互いに異なる三つが必要

上限：十六元数では零因子のために「積がゼロ＝同じ」という読み出しの基準が壊れるので、安定な凝縮体の定義が成り立たない。凝縮体は ℍ で始まり 𝕆 で終わる。

## 3. 実例 1：四元数 4 個（複素数 8 個）

ファイル：condensate_example_20261024.py、condensate_example_results_20261024.json、plot_condensate_example_20261024.py、svg_condensate_example_20261024.py、condensate_example_20261024.svg

構成：ホライズン上のペア二組を結合させたもの。m = i、n = cos θ · i + sin θ · j として
q₁ = (1 + m)/√2、q₂ = (1 − m)/√2、q₃ = (−1 + n)/√2、q₄ = (−1 − n)/√2

θ = 90°（m ⊥ n）の値：

| | z₁ | z₂ | q |
|---|---|---|---|
| q₁ | 0.7071 + 0.7071i | 0 | (1 + i)/√2 |
| q₂ | 0.7071 − 0.7071i | 0 | (1 − i)/√2 |
| q₃ | −0.7071 | +0.7071 | (−1 + j)/√2 |
| q₄ | −0.7071 | −0.7071 | (−1 − j)/√2 |

結果：

- Σq = 0、Σq² = 0（q₁² = i、q₂² = −i、q₃² = −j、q₄² = j）
- (q₁, q₂) と (q₃, q₄)：α = 90°、|k| = 1（ホライズン上のペア）
- 交差する 4 組：α = 120°、|k| = √3、D = 1/√3（結合）
- 四つの三つ組すべてで Δ₃ = 1/2
- 対照：θ = 0（m ∥ n）でも閉塞は成り立つが Δ₃ = 0、交差の組は 180°（接触）に潰れる（ℂ の退化）。θ = 45° で Δ₃ = 0.25。Δ₃ は閉塞を保ったまま 0 から 1/2 へ連続に増える
- 結合の相対位相 (−1 + i + j − k)/2 は位数 3、q₁ は位数 8（q₁⁸ = 1）。すべて有限位数の元
- 複素数の段：Σz = 0 は成り立つが Σz² = 2

考察：

- メモ2 §18.2 の「準安定な二体中間体（ホライズン上のペア）を経由して逐次の二体反応で組み上がる」経路が、そのまま数字の配置として現れている
- ただし関係は非可換でも、各状態は一つずつ見ると別々の複素平面上の複素数で、虚部は ±i と ±j の二方向に収まる。u q u⁻¹ で回しても虚部が一枚の平面に乗る性質は変わらない。前稿の「読める方向の数は min(3, N − 2)」と一致し、N = 4 では空間の三方向は開かない（最小の四元数的凝縮体ではあるが、空間を持つ四元数の凝縮体ではない）

## 4. 実例 2：四元数 6 個（複素数 12 個）

ファイル：six_condensate_20261024.py、six_condensate_results_20261024.json、fig_six_condensate_20261024.py、six_condensate_20261024.svg

構成（厳密）：二つの三つ組。虚部は面の中で 120° ずつ開いた正三角形で、面が二つの三つ組で異なる。

- 三つ組 A（実部 −1/√2、虚部は i-j 面）：q = (−1 + n)/√2、n = i、−½i + (√3/2)j、−½i − (√3/2)j
- 三つ組 B（実部 +1/√2、虚部は j-k 面）：q = (+1 + n)/√2、n = ½j + (√3/2)k、−j、½j − (√3/2)k

| | z₁ | z₂ |
|---|---|---|
| A1 | −0.7071 + 0.7071i | 0 |
| A2 | −0.7071 − 0.3536i | +0.6124 |
| A3 | −0.7071 − 0.3536i | −0.6124 |
| B1 | +0.7071 | +0.3536 + 0.6124i |
| B2 | +0.7071 | −0.7071 |
| B3 | +0.7071 | +0.3536 − 0.6124i |

結果：

- Σq = 0、Σq² = 0。複素数 12 個で Σz = 0、Σz² = 3
- 虚部の特異値 1.225、0.866、0.866（i, j, k の三方向すべて）
- 20 組の三つ組すべてで Δ₃ > 0（最小 0.050、最大 0.844）
- A–B 間の 9 組：α = 93.8°〜158.9°（すべて結合）
- A 内・B 内の 6 組：α = 75.52°、|k| = 0.775、D = 1.291（ホライズンのわずかに外側）

考察：

- 実部 ±1/√2 の二群は閉塞から強制される。等振幅の単位元で Σq² = 0 ⇔ Σ(2s² − 1) = 0 ⇔ Σs² = N/2（N = 6 で Σs² = 3 → 全員 s² = 1/2）
- 交差の結合の深さは cos α = (−1 + n·n′)/2 で、二つの面の向きだけで決まる。n ≠ n′ なら交差の組は必ず結合する
- 各状態は相手側の三つ組の 3 個すべてと結合し、孤立した状態はない。全体は二部グラフ K₃,₃ 型の結合網として一つにつながった体になっている
- 三つが互いにわずかに離れたまま反対側の三つと強く結びつく形は、3 と 3̄ の束縛と同じ組み合わせ構造をしている（形の類似としての読みで、確かめたものではない）

## 5. 実例 3：八元数 10 個（複素数 40 個）

ファイル：octonion_condensate_20261024.py、octonion_condensate_results_20261024.json、fig_octonion_condensate_20261024.py、octonion_condensate_20261024.svg

構成（厳密）：同じ族の二群。

- 群 A（実部 −1/√2）：虚部は e₁〜e₄ の 4 次元の中の正 4 単体（5 点）
- 群 B（実部 +1/√2）：虚部は e₄〜e₇ の 4 次元の中の正 4 単体（5 点）。e₄ を A と共有
- 単体の頂点：(±√5/4, ±√5/4, ±√5/4, −1/4)（積が +1 の 4 通り）と (0, 0, 0, 1)

| | z₁ | z₂ | z₃ | z₄ |
|---|---|---|---|---|
| A1 | −a + bi | b + bi | −c | 0 |
| A2 | −a + bi | −b − bi | −c | 0 |
| A3 | −a − bi | b − bi | −c | 0 |
| A4 | −a − bi | −b + bi | −c | 0 |
| A5 | −a | 0 | a | 0 |
| B1 | a | 0 | b − ci | b + bi |
| B2 | a | 0 | b − ci | −b − bi |
| B3 | a | 0 | −b − ci | b − bi |
| B4 | a | 0 | −b − ci | −b + bi |
| B5 | a | 0 | ai | 0 |

a = 1/√2 ≈ 0.7071、b = √10/8 ≈ 0.3953、c = √2/8 ≈ 0.1768

結果：

- Σo = 0、Σo² = 0（八元数の積で計算）。複素数 40 個で Σz = 0、Σz² = 5
- 虚部の特異値 7 個すべて正（7 方向すべて）
- 群間の 25 組：α = 102.7°〜141.2°（すべて結合）
- 群内の 20 組：α = 67.98°、|k| = 0.674、D = 1.483（自由）
- 三体の非可換性 Δ₃：120 組すべて正（最小 0.100）
- 四体の非結合性：840 組すべて正（最小 0.331、最大 1.430）。八元数でしか出ない量が、すべての組でゼロでない

## 6. 全体の考察

### 6.1 一つの族

三つの実例は同じ族に属する。N = 2m 個、二群（実部 ±1/√2）、各群の虚部は (m − 1) 次元の正単体（和 0、|v| = 1/√2）。このとき

- 群内の角：cos α = (m − 2)/(2(m − 1))（m = 2 で 0、m = 3 で 1/4、m = 5 で 3/8）
- 群間の角：cos α = (−1 + n·n′)/2 ≤ 0（n ≠ n′ なら必ず結合）

m = 2 が「ペア二組」（実例 1）、m = 3 が「三つ組二組」（実例 2）、m = 5 が「五つ組二組」（実例 3）。

### 6.2 全体がどこまで凝縮できるか（上限）

閉塞 Σq = 0、Σq² = 0 のもとで「全対の最小角」を最大化した結果（SLSQP、多数の初期値）：

| N | 4 | 5 | 6 | 7 | 8 | 10 |
|---|---|---|---|---|---|---|
| 4 次元（ℍ） | 90.0° | 72.0° | 75.52° | 66.24° | 70.53° | – |
| 8 次元（𝕆） | – | – | 75.52° | – | 70.53° | 67.98° |

- 全対がホライズンの内側（境界を含む）に入れるのは N = 4 だけ。N = 6 以上では、閉塞を満たす限り必ず自由な組が残る
- 実例 1・2・3 はそれぞれ N = 4、6、10 の上限に一致する。どれも閉塞を満たす配置の中で最も凝縮に近い
- 上限は 4 次元でも 8 次元でも同じ値になる。等振幅の単位元では q² = 2s q − 1 の形で、閉塞 Σq = 0、Σq² = 0 は角の幾何（グラム行列）しか見ていない。全体がどこまで凝縮できるかは代数によらず N だけで決まる

### 6.3 形と中身の分業

- 凝縮の「形」（どの組が結合し、どの組が自由か）は閉塞が決め、代数によらない
- 凝縮の「中身」は代数が決める。ℍ では三体の非可換性 Δ₃、𝕆 ではさらに四体の結合子が、凝縮体の内部にゼロでない量として生じる
- ℂ の配置（実例 1 の θ = 0）は、閉塞と形を保ったまま中身（Δ₃）だけがゼロになる。複素数で凝縮体が作れなかった理由が、一つのパラメータで見える

### 6.4 修正した見方

- 「対ごとに |k| > 1」だけでは凝縮体の判定にならない。閉塞する集合では必ず鈍角の組が生じるので、凝縮体の単位を決めるのは部分閉塞と結合網のつながり方である
- 等振幅の単位四元数 3 個で Σq = 0、Σq² = 0 を満たすものは、必ず一枚の複素平面に収まる（Δ₃ = 0）。三つ組だけでは ℍ の凝縮体にならず、閉じた ℍ の凝縮体の最小は 4 個
- 2 個の部分閉塞（q₂ = −q₁）は Σq² = 2q₁² ≠ 0 で成り立たない。6 個を閉じた部分集合に分けることはできず、6 個の凝縮体は一つの体として閉じる

## 7. まだ満たしていないこと（次の課題）

1. 複素数の段の二乗閉塞 Σz² = 0。どの実例でも成り立っていない（実例 1 で 2、実例 2 で 3、実例 3 で 5）。四元数・八元数の閉塞と同時に満たす {zₙ} を作る
2. ロックの安定性。今回は静的な配置を示しただけで、F による動力学で凝縮体が保たれるか（不完全なロックとして寿命を持つか）は確かめていない
3. 真空への埋め込み。閉塞する背景（大半はゆるく、まれに固まる）の中に凝縮体を置いた {zₙ}
4. 振幅の分化。今回はすべて等振幅。ノルム R（質量）の違いを持つ凝縮体
