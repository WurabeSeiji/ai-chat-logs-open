# マジックナンバーの一覧（2026-10-17）

著者の整理（10-17）に従い、マジックナンバーに見える数を出どころで分ける。対になる文書は `対称性の一覧_保存量と固定点_20261017.md`（以下「対称性の一覧」）で、その §1d の公理の候補を数の側から並べ直したものである。

> 本質的な対称性には、保存量があるのではなく、かならず無次元のマジックナンバーがある。e、π、α の後ろに隠れている数で、ほぼ数論・群論・幾何構造から固定される。（著者、10-17）

## 0. 分け方と使い方

| 系 | 何が決めるか | 混同の注意 |
|---|---|---|
| **I 整数系** | 構造（次元、個数、位数、数え上げ）。数列として、特に数論から要求されることが多い | 3 次元・4 次元・1 個・2 個は、マジックナンバーとすら意識されず見落とされる |
| **II 結合定数系** | 単位の約束（G ＝ c ＝ q₀ ＝ 1 など） | 整数に見えるが、構造の数ではない。I と混同しない |
| **III 無理数系** | 幾何（空間）・発展（位相、時間）・統計 | 統計の系に数が多く、見落としやすい |
| **IV 導出系** | 外の数（I と III）から読出しの写像で導かれる | 一見マジックナンバーに見える。代表は α。断面積や相互作用の係数として現れる |

1. **数の出どころを先に決める：** 新しい数が出たら、まずどの系かを決める。IV の数を I や III と取り違えると、エディントンの罠（一致の要求）に落ちる。
2. **近いが一致しない組は §5 に集める：** 構造の数と観測値のずれは誤差ではなく中身として扱う（対称性の一覧 §1d、§9）。
3. **状態の欄：** 「確立」は数学・物理で確立した事実、「理論」はこの研究の理論の中の数、「候補」は対応の推測。
4. **番号の欄：** 対称性の一覧の行の番号（A・W・S・E・G・L・K）を付ける。

## 2. II 結合定数系（単位の約束で置く数）

マジックナンバーではない。単位の選び方で 1 や 3 に置いた数で、構造の整数と混同しやすい。

| 置き方 | 意味 | 由来 |
|---|---|---|
| G ＝ c ＝ q₀ ＝ 1 | 重力定数・光速・電荷の単位を 1 に置く（ガウス単位） | 万能相互作用 Einstein–Maxwell の設計（v3.1） |
| q₀ ＝ e/3 | 電荷の単位をクォークの電荷に置く | 同上 |
| J ＝ ħ/2 | 角運動量の単位をスピン 1/2 に置く | 同上 |
| ħ ＝ c ＝ 1、自然単位 | 標準理論の慣習 | ― |

注意：単位の約束で 1 に置けるのは、次元を持つ定数だけである。無次元の数（α など）は、単位の選び方で変えられない。
