# フェルミオンの存在確率計算

## 1. 目的

本稿は、有限分解能 \(N\) を持つ閉じた関係波系において、整数閉包可能な奇数倍音候補を数え、その相対密度をフェルミオン型自己波形の「存在見込み」として評価する計算方法を整理する。

ここでいう存在確率は、現段階では物理的な粒子生成確率そのものではない。

厳密には、

\[
\boxed{
\text{有限分解能 }N\text{ における、整数閉包可能な奇数倍音チャネルの相対密度}
}
\]

である。

この量が、論文6以降の数値モデルにおいて実際のフェルミオン型準安定構造の発生率と対応するかを検証することが、本稿の目的である。

---

## 2. 基本仮定

系の最小分解能を整数

\[
N\in\mathbb{N}
\]

とする。

系全体が \(N\) 個の最小単位で構成されるとき、全周期内に整数回だけ収まる倍音次数 \(k\) は、

\[
k\mid N
\]

を満たす。

すなわち、許容倍音次数は \(N\) の約数である。

さらに、フェルミオン型自己波形の候補を奇数倍音に限定すると、

\[
k>1,\qquad k\ \text{奇数},\qquad k\mid N
\]

を満たす \(k\) が候補になる。

---

## 3. \(N\) の奇数部分

任意の正整数 \(N\) は、

\[
N=2^\alpha m
\]

と一意に分解できる。

ここで、

\[
m\ \text{は奇数}
\]

である。

この \(m\) を \(N\) の奇数部分と呼び、

\[
N_{\mathrm{odd}}=m
\]

と書く。

別表現では、

\[
N_{\mathrm{odd}}
=
\frac{N}{2^{v_2(N)}}
\]

である。ここで \(v_2(N)\) は \(N\) に含まれる因子2の指数である。

奇数約数はすべて \(N_{\mathrm{odd}}\) の約数なので、奇数倍音候補の数は \(N_{\mathrm{odd}}\) の約数構造だけで決まる。

---

## 4. 約数個数関数

奇数部分を素因数分解して、

\[
N_{\mathrm{odd}}
=
\prod_{j=1}^{r}p_j^{\alpha_j}
\]

とする。

ここで \(p_j\) はすべて奇素数である。

正の約数の個数を表す約数関数は、

\[
\tau(N_{\mathrm{odd}})
=
\prod_{j=1}^{r}(\alpha_j+1)
\]

である。

この中には基底次数

\[
k=1
\]

も含まれる。

したがって、基底波を除いた非自明な奇数倍音候補数は、

\[
\boxed{
H_{\mathrm{odd}}(N)
=
\tau(N_{\mathrm{odd}})-1
}
\]

である。

---

## 5. 存在見込みの定義

全分解能 \(N\) に対して、奇数倍音候補が何個存在するかを相対化して、

\[
\boxed{
\rho_{\mathrm{odd}}(N)
=
\frac{H_{\mathrm{odd}}(N)}{N}
=
\frac{\tau(N_{\mathrm{odd}})-1}{N}
}
\]

と定義する。

本稿では、この \(\rho_{\mathrm{odd}}(N)\) を、

\[
\boxed{
\text{フェルミオン型自己波形の存在見込み}
}
\]

と呼ぶ。

ただしこれは、現段階では候補チャネル密度であり、観測宇宙のフェルミオン存在率と同一であることはまだ導出されていない。

---

\boxed{k=5}
\]

である。

\[
\rho_{\mathrm{odd}}(40)

\]

\rho_{\mathrm{odd}}(300)

## 8. 大きな \(N\) に対する挙動

約数関数 \(\tau(n)\) は、\(n\) よりはるかに遅く増加する。

したがって、

\[
\lim_{N\to\infty}
\frac{\tau(N_{\mathrm{odd}})-1}{N}
=
0.
\]

すなわち、

\[
\boxed{
\lim_{N\to\infty}\rho_{\mathrm{odd}}(N)=0
}
\]

である。

ただし、\(\rho_{\mathrm{odd}}(N)\) は単調減少ではない。

\(N\) の素因数構造に依存して、局所的には大きく上下する。

- \(N=2^\alpha\) のとき  
  \[
  N_{\mathrm{odd}}=1
  \]
  なので、
  \[
  H_{\mathrm{odd}}(N)=0.
  \]

- \(N_{\mathrm{odd}}\) が奇素数のとき  
  候補は1個だけである。

- \(N_{\mathrm{odd}}\) が多くの約数を持つとき  
  候補数は一時的に増える。

しかし、分母 \(N\) は線形に増加するため、長期的な相対密度はゼロへ向かう。

平均的な約数個数の成長は概ね対数的なので、典型的な目安として、

\[
\rho_{\mathrm{odd}}(N)
\sim
\frac{\log N}{N}
\]

型の減衰が期待される。

これは厳密な点ごとの近似ではなく、全体傾向を示す参考曲線である。

---

## 9. 両対数グラフの意味

横軸を \(N\)、縦軸を

\[
\rho_{\mathrm{odd}}(N)
\]

として、両対数グラフを作成する。

両対数表示では、

\[
\rho_{\mathrm{odd}}(N)\propto N^{-1}
\]

に近い挙動は、傾き約 \(-1\) の直線として現れる。

実際の点列は約数構造によってギザギザになるが、全体として右下がりの包絡線を持つ。

グラフには、次の三種類を重ねる。

1. 全整数 \(N\) に対する  
   \[
   \rho_{\mathrm{odd}}(N)
   \]

2. 比較用の参考曲線  
   \[
   \frac{\log N}{N}
   \]

3. 特別に確認したい点  
   \[
   N=5,\ 40,\ 300
   \]

---

## 10. グラフ生成用Pythonコード

以下のコードは、

\[
2\le N\le100000
\]

について、

\[
\rho_{\mathrm{odd}}(N)
=
\frac{\tau(N_{\mathrm{odd}})-1}{N}
\]

を計算し、両対数グラフを生成する。

```python
import numpy as np
import matplotlib.pyplot as plt


N_MAX = 100_000


def build_smallest_prime_factor_sieve(n_max: int) -> list[int]:
    spf = list(range(n_max + 1))

    for i in range(2, int(n_max**0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, n_max + 1, i):
                if spf[j] == j:
                    spf[j] = i

    return spf


SPF = build_smallest_prime_factor_sieve(N_MAX)


def odd_part(n: int) -> int:
    while n % 2 == 0:
        n //= 2

    return n


def divisor_count(n: int) -> int:
    if n == 1:
        return 1

    result = 1

    while n > 1:
        p = SPF[n]
        exponent = 0

        while n % p == 0:
            n //= p
            exponent += 1

        result *= exponent + 1

    return result


def odd_harmonic_count(n: int) -> int:
    n_odd = odd_part(n)

    return divisor_count(n_odd) - 1


def odd_harmonic_fraction(n: int) -> float:
    return odd_harmonic_count(n) / n


N = np.arange(2, N_MAX + 1)

H_odd = np.array(
    [odd_harmonic_count(int(n)) for n in N],
    dtype=float,
)

rho_odd = H_odd / N


special_N = np.array([5, 40, 300], dtype=int)

special_rho = np.array(
    [odd_harmonic_fraction(int(n)) for n in special_N],
    dtype=float,
)


plt.figure(figsize=(10, 7))


mask = rho_odd > 0

plt.loglog(
    N[mask],
    rho_odd[mask],
    ".",
    markersize=2,
    alpha=0.65,
    label=(
        r"$\rho_{\rm odd}(N)"
        r"=\frac{\tau(N_{\rm odd})-1}{N}$"
    ),
)


reference = np.log(N) / N

plt.loglog(
    N,
    reference,
    linewidth=1.5,
    label=r"reference $\log N/N$",
)


plt.loglog(
    special_N,
    special_rho,
    "o",
    markersize=8,
    label="N = 5, 40, 300",
)


for n, rho in zip(special_N, special_rho):
    plt.annotate(
        f"N={n}\n{rho:.4g}",
        (n, rho),
        textcoords="offset points",
        xytext=(8, 6),
    )


plt.xlabel("N")

plt.ylabel(
    r"Candidate fraction "
    r"$\rho_{\rm odd}(N)$"
)

plt.title(
    "Odd-harmonic candidate fraction "
    "versus system resolution"
)

plt.grid(
    True,
    which="both",
    alpha=0.3,
)

plt.legend()

plt.tight_layout()


plt.savefig(
    "odd_harmonic_candidate_fraction_loglog.png",
    dpi=220,
    bbox_inches="tight",
)

plt.savefig(
    "odd_harmonic_candidate_fraction_loglog.svg",
    bbox_inches="tight",
)


plt.show()
```

## 11. コードの計算手順

上のコードは、次の順序で処理している。

### 11.1 最小素因数表の作成

```python
build_smallest_prime_factor_sieve()
```

により、各整数の最小素因数を事前計算する。

これにより、各 \(N\) の素因数分解を高速化する。

### 11.2 奇数部分の抽出

```python
odd_part(n)
```

により、\(N\) から因子2をすべて除く。

数学的には、

\[
N_{\mathrm{odd}}
=
\frac{N}{2^{v_2(N)}}
\]

を計算している。

### 11.3 約数個数の計算

```python
divisor_count(n)
```

により、

\[
\tau(n)
\]

を計算する。

### 11.4 奇数倍音候補数

```python
odd_harmonic_count(n)
```

により、

\[
H_{\mathrm{odd}}(N)
=
\tau(N_{\mathrm{odd}})-1
\]

を計算する。

### 11.5 候補密度

```python
odd_harmonic_fraction(n)
```

により、

\[
\rho_{\mathrm{odd}}(N)
=
\frac{H_{\mathrm{odd}}(N)}{N}
\]

を計算する。

### 11.6 両対数描画

```python
plt.loglog()
```

を使って、横軸と縦軸を対数表示する。

## 12. 数値モデルでの検証方法

論文6以降の数値モデルでは、初期状態は `make_parent()` によって乱数初期値から自己無撞着な親状態へ収束させて生成される。

したがって、特定倍音を人工的に埋め込む必要はない。

検証は次の二段階に分ける。

### 12.1 親状態生成直後

`make_parent()` の出力直後にスペクトル解析を行う。

\(N=300\) なら、事前予測された候補

\[
k=3,\ 5,\ 15,\ 25,\ 75
\]

が、非候補次数よりも強く現れるかを確認する。

この段階で選択が見つかれば、

\[
\boxed{
\text{自己無撞着親状態生成が奇数整数倍音を選択している}
}
\]

と判断できる。

### 12.2 時間発展後

親状態から既存の力学発展を実行し、候補倍音について、

- 振幅が保存されるか
- 成長するか
- 消滅するか
- 散乱後に再構成されるか
- 準安定状態で残るか

を追跡する。

この段階で選択が現れれば、

\[
\boxed{
\text{力学発展が奇数倍音構造を選択している}
}
\]

と判断できる。

## 13. 推奨する観測量

各倍音次数 \(k\) に対して、時間依存振幅を

\[
A_k(t)
\]

とする。

候補次数の平均パワーを、

\[
P_k(T)
=
\frac1T
\int_0^T
|A_k(t)|^2\,dt
\]

で定義する。

離散時間なら、

\[
P_k
=
\frac1{T+1}
\sum_{t=0}^{T}
|A_k(t)|^2
\]

とする。

候補集合を、

\[
\mathcal K_F(N)
=
\left\{
k>1:
k\ \text{奇数},\
k\mid N
\right\}
\]

と定義する。

\(N=300\) では、

\[
\mathcal K_F(300)
=
\{3,5,15,25,75\}.
\]

比較対象として、

\[
\mathcal K_C(N)
\]

を、同程度の次数範囲にある奇数非約数から選ぶ。

例えば、

\[
\mathcal K_C(300)
=
\{7,9,11,13,17,21,27,31,49,73\}
\]

などである。

次に、候補群と対照群の平均パワーを比較する。

\[
\overline P_F
=
\frac1{|\mathcal K_F|}
\sum_{k\in\mathcal K_F}
P_k
\]

\[
\overline P_C
=
\frac1{|\mathcal K_C|}
\sum_{k\in\mathcal K_C}
P_k
\]

選択比を、

\[
\boxed{
R_{\mathrm{select}}
=
\frac{\overline P_F}{\overline P_C}
}
\]

とする。

\[
R_{\mathrm{select}}>1
\]

が乱数seedを変えても再現するなら、奇数整数倍音候補が力学的に選択されている可能性がある。

---

## 14. \(N\) を変えた予測検証

この仮説の強みは、\(N\) ごとに候補集合が実験前に完全に予測できることである。

例えば、

\[
N=299=13\cdot23
\]

なので、

\[
\mathcal K_F(299)=\{13,23,299\}.
\]

\[
N=300=2^2\cdot3\cdot5^2
\]

なので、

\[
\mathcal K_F(300)=\{3,5,15,25,75\}.
\]

\[
N=301=7\cdot43
\]

なので、

\[
\mathcal K_F(301)=\{7,43,301\}.
\]

ただし、最高次数 \(N\) 自身を物理候補から除外する場合は、各集合から \(N\) を除く。

この境界条件は、実験前に固定しなければならない。

\(N=299,300,301\) は系サイズがほぼ同じである一方、奇数約数構造が大きく異なる。

したがって、力学条件をほぼ変えずに整数閉包構造だけを変える対照実験になる。

## 15. 反証条件

次の結果が得られた場合、存在見込み仮説は否定または修正される。

1. 候補次数と非候補次数に統計的な差がない。
2. \(N\) を変えても、予測された候補集合が変化しない。
3. `make_parent()` の出力が候補集合と無関係な固定スペクトルを持つ。
4. 親状態では候補が現れるが、時間発展で直ちに消滅する。
5. 候補密度 \(\rho_{\mathrm{odd}}(N)\) と実際の準安定構造発生率に相関がない。
6. 結果が乱数seedに強く依存し、再現性がない。

## 16. 現段階の位置づけ

本稿で定義した、

\[
\rho_{\mathrm{odd}}(N)
=
\frac{\tau(N_{\mathrm{odd}})-1}{N}
\]

は、まだフェルミオンの物理的存在確率ではない。

現時点で確定しているのは、

\[
\boxed{
\rho_{\mathrm{odd}}(N)
=
\text{有限分解能 }N\text{ における奇数整数閉包チャネル密度}
}
\]

である。

この量が、

- 親状態に含まれる倍音候補数
- 時間発展で残る準安定倍音数
- 非線形散乱状態の生成率
- 観測宇宙におけるフェルミオン対ボゾン比

のどれに対応するかは、数値モデルによって検証しなければならない。

## 17. 結論

有限分解能 \(N\) における奇数倍音候補数は、

\[
\boxed{
H_{\mathrm{odd}}(N)
=
\tau(N_{\mathrm{odd}})-1
}
\]

である。

その相対密度は、

\[
\boxed{
\rho_{\mathrm{odd}}(N)
=
\frac{\tau(N_{\mathrm{odd}})-1}{N}
}
\]

である。

この密度は、\(N\) の素因数構造に応じて振動しながら、\(N\to\infty\) でゼロへ向かう。

したがって、

\[
\boxed{
\text{小さな実験系では複数の候補を直接検証でき、}
\text{巨大系では候補の相対密度が急速に希薄化する}
}
\]

という予測が得られる。

論文6以降の数値モデルでは、`make_parent()` が乱数から自己無撞着親状態を生成するため、特定倍音を人工的に与えずにこの仮説を検証できる。

最初の明確な試験対象は、

\[
N=300
\]

における、

\[
\boxed{
k=3,\ 5,\ 15,\ 25,\ 75
}
\]

の5候補である。
