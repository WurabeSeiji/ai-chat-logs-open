# N=300の場合の実証実験計画

## 1. 目的

本実験の目的は、有限分解能

\[
N=300
\]

の関係波閉鎖系において、整数閉包可能な奇数倍音候補として事前予測される

\[
\boxed{
k=3,\ 5,\ 15,\ 25,\ 75
}
\]

が、既存の数値モデル内で実際に特別な挙動を示すかを検証することである。

検証対象は、単なる初期スペクトルの存在ではない。

本実験では、

1. `make_parent()` による乱数初期値からの自己無撞着親状態生成
2. 親状態生成直後の倍音構造
3. その後の時間発展
4. 散乱・急拡大・準安定化後の倍音保存または再構成
5. 非候補奇数次数との統計的差

を段階的に測定する。

本実験の中心命題は次である。

\[
\boxed{
N=300\text{ の系では、}
3,5,15,25,75
\text{ の奇数倍音候補が、}
\text{非候補奇数次数よりも選択的に残存・増幅・再構成されるか}
}
\]

---

## 2. 理論的事前予測

### 2.1 \(N=300\) の奇数部分

\[
300=2^2\cdot3\cdot5^2
\]

なので、奇数部分は

\[
N_{\mathrm{odd}}=75
\]

である。

75の正の約数は、

\[
1,\ 3,\ 5,\ 15,\ 25,\ 75
\]

である。

基底次数

\[
k=1
\]

を除くと、非自明な奇数倍音候補は、

\[
\boxed{
\mathcal K_F(300)
=
\{3,5,15,25,75\}
}
\]

となる。

---

## 3. 存在見込み

候補数は、

\[
H_{\mathrm{odd}}(300)
=
\tau(75)-1
=
6-1
=
5
\]

である。

全分解能300に対する候補密度は、

\[
\rho_{\mathrm{odd}}(300)
=
\frac{5}{300}
=
\frac1{60}
\approx
1.6667\times10^{-2}.
\]

したがって、理論上の奇数整数閉包チャネル密度は、

\[
\boxed{
\rho_{\mathrm{odd}}(300)
\approx
1.67\%
}
\]

である。

ここでいう存在見込みは、物理的な粒子生成確率そのものではない。

厳密には、

\[
\boxed{
\text{N=300の有限分解能内で、整数閉包可能な奇数倍音チャネルの密度}
}
\]

である。

本実験では、この算術的候補密度が実際の数値力学における準安定構造の選択率と対応するかを検証する。

---

## 4. 検証仮説

### 仮説H1：親状態選択仮説

`make_parent()` が乱数初期値から自己無撞着親状態を構成する段階で、

\[
k=3,\ 5,\ 15,\ 25,\ 75
\]

の成分が非候補奇数次数よりも有意に強く現れる。

この場合、

\[
\boxed{
\text{自己無撞着閉鎖条件が奇数整数倍音候補を選択している}
}
\]

と解釈する。

---

### 仮説H2：力学選択仮説

親状態生成直後には候補成分が特別でなくても、時間発展後に、

\[
k=3,\ 5,\ 15,\ 25,\ 75
\]

が非候補奇数次数よりも残存・増幅・再構成される。

この場合、

\[
\boxed{
\text{時間発展または散乱力学が奇数整数倍音候補を選択している}
}
\]

と解釈する。

---

### 仮説H3：準安定保存仮説

候補次数が急拡大または散乱を経た後も、

\[
\omega_k/\omega_1=k
\]

という倍音関係を維持し、準安定領域で長時間保存される。

この場合、

\[
\boxed{
\text{候補倍音は一時的励起ではなく、内部自己相関を持つ準安定構造である}
}
\]

と解釈する。

---

### 帰無仮説H0

候補集合

\[
\{3,5,15,25,75\}
\]

と、それ以外の奇数次数の間に、統計的に有意な差はない。

この場合、奇数約数構造とフェルミオン型候補の対応仮説は支持されない。

---

## 5. 使用する既存数値系

本実験では、論文6以降で使用している既存の数値モデルを用いる。

初期状態は、

\[
\text{乱数初期値}
\longrightarrow
\texttt{make\_parent()}
\longrightarrow
\text{自己無撞着親状態}
\]

の順に生成される。

したがって、候補倍音

\[
3,\ 5,\ 15,\ 25,\ 75
\]

を人工的に埋め込んではならない。

本実験の重要な条件は、

\[
\boxed{
\text{候補次数を事前に入力せず、乱数から生成された親状態と時間発展だけを観測する}
}
\]

ことである。

## 7. 対照次数

候補集合は、

\[
\mathcal K_F
=
\{3,5,15,25,75\}.
\]

対照群は、奇数であるが300の約数ではない次数から選ぶ。

例えば、

\[
\mathcal K_C
=
\{7,9,11,13,17,21,27,31,49,73\}
\]

とする。

ただし、候補群と対照群の次数分布が大きく異なると、単純な高周波減衰の影響を受ける。

したがって、より厳密には各候補 \(k\) に対して、近傍の奇数非約数を対照とする。

例：

| 候補 \(k\) | 近傍対照 |
|---:|:---|
| 3 | 7, 9 |
| 5 | 7, 11 |
| 15 | 13, 17 |
| 25 | 23, 27 |
| 75 | 73, 77 |

77が計算範囲内で扱えない場合は、71または79を用いる。

最終的には、

\[
\boxed{
\text{候補と同程度の周波数帯にある奇数非約数}
}
\]

を対照にする。

## 8. 観測時点

最低限、次の時点で状態を保存する。

### T0：乱数初期値

`make_parent()` 適用前。

### T1：親状態生成直後

`make_parent()` 収束直後。

### T2：急拡大前

潜伏領域の終端直前。

### T3：急拡大中

主要振幅が幾何級数的に増加している区間。

### T4：急拡大停止直後

準安定構造形成の開始時点。

### T5：準安定領域

準安定振動が十分に成立した時点。

### T6：長時間発展後

一周期または複数周期後。

---

## 9. スペクトル抽出

各時点の状態から、候補次数ごとの複素振幅を、

\[
A_k(t)
\]

として抽出する。

具体的な抽出法は、既存モデルの座標構造に応じて次のいずれかを用いる。

1. 離散フーリエ変換
2. 既知の基底ベクトルへの射影
3. 固有モード分解
4. 位相差行列の周期成分分解
5. 関係行列の周波数別特異値分解

重要なのは、解析方法を候補集合を見た後で変更しないことである。

実験前に、

\[
\boxed{
A_k(t)\text{ の定義と抽出法を固定する}
}
\]

必要がある。

---

## 10. 基本観測量

### 10.1 瞬時パワー

\[
P_k(t)
=
|A_k(t)|^2
\]

---

### 10.2 時間平均パワー

観測区間 \([t_a,t_b]\) に対して、

\[
\overline P_k
=
\frac{1}{t_b-t_a}
\int_{t_a}^{t_b}
|A_k(t)|^2\,dt
\]

離散時間では、

\[
\overline P_k
=
\frac1M
\sum_{j=1}^{M}
|A_k(t_j)|^2.
\]

---

### 10.3 基底波に対する相対強度

\[
R_k(t)
=
\frac{|A_k(t)|^2}{|A_1(t)|^2+\varepsilon}
\]

ここで \(\varepsilon\) はゼロ除算回避用の固定微小量である。

---

### 10.4 候補群平均

\[
\overline P_F
=
\frac1{|\mathcal K_F|}
\sum_{k\in\mathcal K_F}
\overline P_k
\]

---

### 10.5 対照群平均

\[
\overline P_C
=
\frac1{|\mathcal K_C|}
\sum_{k\in\mathcal K_C}
\overline P_k
\]

---

### 10.6 選択比

\[
\boxed{
R_{\mathrm{select}}
=
\frac{\overline P_F}
{\overline P_C+\varepsilon}
}
\]

\[
R_{\mathrm{select}}>1
\]

が複数seedで再現すれば、候補群の選択性を示す。

---

## 11. 候補別の保存率

親状態直後のパワーを、

\[
P_k(T1)
\]

準安定領域のパワーを、

\[
P_k(T5)
\]

とする。

候補別保存率を、

\[
\boxed{
S_k
=
\frac{P_k(T5)}
{P_k(T1)+\varepsilon}
}
\]

と定義する。

- \(S_k\approx1\)：保存
- \(S_k>1\)：増幅
- \(S_k\ll1\)：消滅

である。

候補群と対照群の保存率を比較する。

---

## 12. 再構成率

ある次数 \(k\) が一度減衰した後、再び同じ倍音関係で現れる場合を再構成とする。

閾値を、

\[
P_k(t)>\theta_k
\]

と定める。

再構成率を、

\[
R_k^{\mathrm{reform}}
=
\frac{
\text{再出現したseed数}
}{
n_{\mathrm{seed}}
}
\]

とする。

候補次数でのみ再構成率が高いなら、

\[
\boxed{
\text{候補倍音は単なる初期残存ではなく、力学的に再生成されている}
}
\]

と判断できる。

---

## 13. 閉鎖残差

系の閉鎖量を、

\[
Q(t)=\sum_n x_n(t)^2
\]

とする。

閉鎖残差を、

\[
\epsilon_Q(t)
=
|Q(t)|
\]

と定義する。

各候補次数が強く現れた時点で、

\[
\epsilon_Q(t)
\]

が増大していないかを確認する。

候補倍音が現れても閉鎖残差が大きい場合、それは自己無撞着構造ではなく数値誤差または発散の可能性がある。

したがって、

\[
\boxed{
\text{候補倍音の増幅と閉鎖維持が同時に成立すること}
}
\]

が必要である。

---

## 14. 非線形性の検証

前稿の理論仮説では、フェルミオン型状態は散乱時に状態依存の非線形応答を示す。

これを検証するため、同じ親状態から次の三条件を比較する。

\[
X
\]

のみを発展させた結果を、

\[
F(X)
\]

とする。

\[
Y
\]

のみを発展させた結果を、

\[
F(Y)
\]

とする。

重ね合わせ初期状態

\[
X+Y
\]

を発展させた結果を、

\[
F(X+Y)
\]

とする。

非線形残差を、

\[
\boxed{
\Delta_{\mathrm{NL}}
=
\|F(X+Y)-F(X)-F(Y)\|
}
\]

と定義する。

候補倍音を含む状態で、

\[
\Delta_{\mathrm{NL}}
\]

が有意に大きく、非候補状態では小さいなら、

\[
\boxed{
\text{候補倍音構造と非線形散乱の対応}
}
\]

が支持される。

---

## 15. 倍音自己相関の検証

候補次数 \(k\) に対して、基底波との交差相関を、

\[
C_{1k}(t)
=
A_1^*(t)A_k(t)
\]

とする。

その位相は、

\[
\phi_{1k}(t)
=
\arg C_{1k}(t)
\]

である。

自己相関強度を、

\[
\boxed{
\Gamma_k
=
\left|
\frac1M
\sum_{j=1}^{M}
e^{i\phi_{1k}(t_j)}
\right|
}
\]

と定義する。

- \(\Gamma_k\approx1\)：安定位相同期
- \(\Gamma_k\approx0\)：位相関係がランダム

である。

候補次数で、

\[
\Gamma_k
\]

が対照群より有意に高いなら、基底波と倍音の自己相関構造が安定していると判断できる。

---

## 16. seed間統計

各seed \(s\) について、

\[
R_{\mathrm{select}}^{(s)}
\]

を計算する。

平均は、

\[
\mu_R
=
\frac1{n_{\mathrm{seed}}}
\sum_s
R_{\mathrm{select}}^{(s)}
\]

標準偏差は、

\[
\sigma_R
=
\sqrt{
\frac1{n_{\mathrm{seed}}-1}
\sum_s
\left(
R_{\mathrm{select}}^{(s)}-\mu_R
\right)^2
}
\]

とする。

候補群と対照群の差については、

- 対応ありt検定
- Wilcoxon符号順位検定
- permutation test
- bootstrap信頼区間

のいずれかを用いる。

分布形状を仮定したくない場合は、

\[
\boxed{
\text{permutation testまたはbootstrap}
}
\]

を推奨する。

## 17. 成功判定基準

以下のすべて、または大部分が成立した場合、仮説は強く支持される。

### 条件A

親状態生成直後に、

\[
\overline P_F(T1)
>
\overline P_C(T1)
\]

が複数seedで再現する。

### 条件B

準安定領域で、

\[
\overline P_F(T5)
>
\overline P_C(T5)
\]

が再現する。

### 条件C

候補群の保存率が対照群より高い。

\[
\overline S_F
>
\overline S_C
\]

### 条件D

候補群の位相同期指標が高い。

\[
\overline\Gamma_F
>
\overline\Gamma_C
\]

### 条件E

候補群を含む状態で非線形残差が増大する。

\[
\Delta_{\mathrm{NL},F}
>
\Delta_{\mathrm{NL},C}
\]

### 条件F

閉鎖残差が許容範囲に維持される。

\[
\epsilon_Q(t)<\epsilon_{\max}
\]

---

## 18. 棄却条件

次の場合、仮説は棄却または修正する。

1. 候補群と対照群に差がない。
2. 候補群より非候補群の方が安定する。
3. 結果がseed依存で再現しない。
4. 候補倍音の増大時に閉鎖残差が破綻する。
5. 候補次数が親状態でしか現れず、力学発展で完全に消滅する。
6. 非線形残差が候補集合と無関係である。
7. \(k=3,5,15,25,75\) のうち特定次数だけが現れ、約数構造全体との対応がない。
8. スペクトル抽出法を変えると結果が消える。

## 19. 追加対照実験

### 19.1 近接N比較

可能であれば、

\[
N=299,\ 300,\ 301
\]

を比較する。

\[
299=13\cdot23
\]

\[
300=2^2\cdot3\cdot5^2
\]

\[
301=7\cdot43
\]

である。

奇数倍音候補集合は、

\[
\mathcal K_F(299)
=
\{13,23,299\}
\]

\[
\mathcal K_F(300)
=
\{3,5,15,25,75\}
\]

\[
\mathcal K_F(301)
=
\{7,43,301\}
\]

となる。

最高次数 \(N\) 自身を除外する場合は、

\[
\mathcal K_F(299)=\{13,23\}
\]

\[
\mathcal K_F(300)=\{3,5,15,25,75\}
\]

\[
\mathcal K_F(301)=\{7,43\}
\]

となる。

近接N比較で予測集合が切り替われば、単なる周波数帯依存ではなく整数閉包構造の効果を示せる。

---

### 19.2 偶数倍音対照

偶数倍音群も同時に観測する。

例えば、

\[
\mathcal K_E
=
\{2,4,6,10,20,30,50,60,100,150\}

を対照とする。

奇数候補群だけが自己相関と非線形性を示し、偶数群が示さないなら、奇数倍音仮説が強化される。

## 23. 本実験の最も強い結果

最も強い結果は、乱数から生成された自己無撞着親状態とその時間発展から、

\[
\boxed{
3,\ 5,\ 15,\ 25,\ 75
}
\]

が事前予測どおり選択され、かつ、

- 位相同期
- 非線形散乱
- 閉鎖維持
- 準安定保存
- 散乱後再構成

を同時に示すことである。

この場合、

\[
\boxed{

という実証的証拠になる。

## 24. 結論

\(N=300\) に対する事前予測は、

\[
\boxed{
\mathcal K_F(300)
=
\{3,5,15,25,75\}
}
\]

である。

候補数は5、候補密度は、

\[
\boxed{
\rho_{\mathrm{odd}}(300)
=
\frac5{300}
=
\frac1{60}
\approx1.67\%
}
\]

である。

この予測は、既存の `make_parent()` による乱数初期値からの親状態生成を変更せずに検証できる。

したがって本実験は、

\[
\boxed{
\text{算術的な奇数倍音候補}
\longrightarrow
\text{自己無撞着親状態}
\longrightarrow
\text{非線形散乱}
\longrightarrow
\text{準安定フェルミオン型構造}
}
\]

という接続を直接試験する、反証可能な実証実験である。
