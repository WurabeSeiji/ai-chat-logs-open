## 0. 経緯（この調査が必要になった理由）

これまでの⑥⑦解析はチャネル内エルミート型（1種類）のみを「交差項」として扱っており、
調査指針§3.2が明記していた**状態間交差相関 C_AB = ab\*** を含む複数の交差項型が
未計測だった。また「双線形交差項は全ケースゼロ」という先の報告は η和後の総和に
ついてのみ正しく、η和前の構造を見ていなかった。本調査はその欠落を埋め、
「交差項」と読める全種類を同一条件で全系列比較する。

## 1. 計測した交差項の定義

| 型 | 定義 | 意味 |
|---|---|---|
| T1 | X_ch = Σ_{m≠n}\|C_mn\|², C_mn = Σ_η c_m c_n\*（チャネル内・共役つき） | ⑥⑦で解析済みの型（参照） |
| T3 | Y_AB = ‖a b†‖_F（状態間・共役つき） | 指針§3.2「状態間交差相関」 |
| T4 | h12_ch = \|⟨c̃(毛1), c̃(毛2)⟩_chi\|（チャネル内・毛モード間） | 毛1×毛2の相関（η軸FFT後） |
| T5 | C(η) = (A_η²−B2_η)/2 の ‖·‖₂ と max（双線形・η和前） | 理論文書の C のηスライス構造 |
| T6 | max_{m≠n}\|Σ_η x_m x_n\|（双線形・η和後） | 毛直交による構造的ゼロの検証 |

併せて凸結合転送位相 v(k)（⑥の手法）を各系列で取得し、
「転送の中間相」√(v(1−v)) との相関を検証した。

## 2. 中心結果

### 2.1 橋則: 状態間交差項と毛間相関は転送の中間相である【全系列成立】

非縮退175系列すべてで、

    corr( Y_AB(k),  √(v(1−v)) ) = 1.000
    corr( h12(k),   √(v(1−v)) ) = 1.000

**状態間交差項 C_AB と毛間相関は、網転送の中間状態（v=0 と v=1 の間）でのみ立ち上がり、
純粋状態の瞬間（v=0,1）に厳密にゼロへ戻る。** 2チャネルは「完全無相関 ↔ 強相関」を
転送位相に完全同期して往復する。例外は R=1.0（完全反射、v≡0、転送なし）の
縮退系列のみで、そこでは相関自体が定義されない。

### 2.2 R137厳密値でのケース間比較（max over 257衝突）

| ケース | T1 X_A | T3 Y_AB | T4 h12_A | T5 ‖C(η)‖_A |
|---|---|---|---|---|
| **B1（ボゾン×ボゾン対照）** | 0.500 | 0.612 | 0.250 | 0.207 |
| B12 | 0.750 | 0.661 | 0.177 | 0.125 |
| B2 fullM（偶数対照） | 0.682 | 0.707 | **0.0048** | 0.336 |
| B3 | 0.750 | 0.500 | 0.354 | 0.375 |
| B5 | 0.833 | 0.577 | 0.289 | 0.625 |
| B15 | 0.938 | 0.661 | 0.177 | 1.875 |
| B63 | 0.984 | 0.696 | 0.088 | **7.875** |

読み取れる事実:
1. **ボゾン×ボゾン（B1）でも T1/T3/T4/T5 はすべて非ゼロで大きく振動する。**
   倍音の有無は交差項の発生を切り替えない。倍音が変えるのは、
   T1の天井（モード数）、T5の振幅、そして局在性 L（B1では発生しない）である。
2. T4（毛間相関）の振幅はチャネル間 chi プロファイル重なりに従う:
   同一プロファイルの B1 で最大級（0.25）、chi支持が離散的に交わらない B2 でほぼ消滅
   （0.0048、広帯域床由来の残差のみ）。
3. T5（双線形ηスライス）は奇数系列で **‖C(η)‖_max = N_h/8** の厳密な整数則
   （B3: 3/8, B5: 5/8, B15: 15/8, B63: 63/8。B12 は 1/8）。
   η和前の双線形構造は倍音数に正比例して存在する。

### 2.3 双線形・η和後の構造的ゼロ【全系列確定】

    T6 最悪値 = 4.8e-16（全184系列・全衝突・全ペア）

毛位相 e^{imη}（m_A=1, m_B=2）により、あらゆる双線形積の η和
Σ_η e^{i(m+m')η} は16点格子上で厳密にゼロ。**理論文書の意味の双線形交差項総和 C は、
系統Aでは倍音の有無・集束の有無に関係なく、構造的に発生しない。**
発生しているのは η和前のスライス構造（T5）と、共役つきの相関（T1/T3/T4）である。

## 3. 「ボゾン的条件で交差項は発生しないのか、発散するのか」への系統A側の答え

- **双線形・総和（理論の C）**: 発生しない（全ケース、構造的ゼロ）。ボゾン×ボゾンに限らない。
  原因は倍音ではなく毛直交。
- **共役つき交差項（T1/T3/T4）と双線形スライス（T5）**: ボゾン×ボゾンでも発生し、
  転送位相に完全同期して振動する（消えも発散もしない、凍結された往復）。
- 系統Aには位相拡散機構（モード別周波数差）がないため、「発生して時間平均で消える」
  という理論のボゾン的シナリオは、この系ではそもそも実現しない。

## 4. 留保

- T5 の N_h/8 則の分母 8 は η格子（16点）と FFT 規約に依存する可能性があり、
  普遍係数と読むのは早い。整数比 3:5:15:63 の部分が本質。
- 本調査は系統A固有の構造の記録である。理論文書の C の生死（整数倍音閉包との関係）を
  検証できる系は、双線形閉鎖が生きているN体系のみ（別報告
  `analysis_nbody_C_persistence_v1/` 参照: 自然準安定状態で |C|=0.684 が13桁不変）。
- 毛モード番号（m_A=1, m_B=2）は 20260713 エンジンJSONの記録値。
