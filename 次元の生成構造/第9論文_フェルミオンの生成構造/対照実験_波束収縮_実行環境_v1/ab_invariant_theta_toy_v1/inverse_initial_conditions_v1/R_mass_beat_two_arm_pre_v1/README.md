# R質量うなり二腕干渉計・予備テスト v1

## 目的

R_read（質量様読出し）の異なる二状態が、発展とともに ΔR に比例する相対位相
（うなり）を蓄積するかを測る。位置づけは「4スロット×2面＝8」構造の
**第4共役対（スケール R – 質量 m）** の検証で、判定樹は次のとおり。

- **(a) 傾き Ω ∝ ΔR（普遍係数）**: 質量はスケール円の巻き面。台帳の
  p_R ↔ m は縮約前の文法として確定
- **(b) Ω ≡ 0（機械精度）**: 現行動力学は R–位相結合を持たない。
  零次 no-go 定理として証明対象化し、最小結合を保存的作業仮説として
  導入した v2 へ進む（逆二乗論文 v1→v2 と同じ手順）
- **(c) Ω が ΔR 以外に比例**: 共役変数の辞書を修正

本フォルダは**予備テスト（配管検証）**であり、本測定（1500衝突・E整合対・
セクター分解族による同R異分布対照）はこの結果を見てから設計を確定する。

## プロトコル：二腕干渉計

現行ランナーは θ を状態自身のパワー比から読むため、重ね合わせ状態の発展は
成分ごとの発展の和にならない（非線形）。よって重ね合わせは物理的に走らせず、

1. 各腕を同一の無変更前進処理で**別々に**発展させ、
2. 各衝突番号 j で重なり積分 O_ij(j) = ⟨ψ_i(j)|ψ_j(j)⟩
   （ペアエルミート内積 ⟨a_i|a_j⟩+⟨b_i|b_j⟩）を記録し、
3. unwrap した位相 arg O_ij(j) の傾き Ω を |O| ≥ 10⁻³ の点で一次フィットする。

腕は単位ペアノルムに規格化してから発展させる（θ 読出しは振幅比のみに依存
するため、規格化は動力学を変えない）。

## 腕の構成（6本・15対）

| arm_id | 目標 R | 備考 |
|---|---|---|
| R030 | 0.30 | 一般点 |
| R050 | 0.50 | 8衝突厳密閉鎖点 |
| R050_dup | 0.50 | R050 の複製。**ヌルテスト腕**（φ≡0・\|O\|≡1 必須） |
| R070 | 0.70 | 一般点 |
| R124_23 | cos²(23π/124) | 厳密根・周期248（α⁻¹≈137側） |
| R620_117 | cos²(117π/620) | 厳密根・周期1240（M_Z側） |

衝突回数は予備として 300。

## 設計境界（既存実験と同一）

- 散乱本体・θ 読出しは無変更。θ は毎衝突、現在の AB から再導出
- 目標 R は初期状態探索（`search_initial_conditions_and_plot_v1.py`）にのみ使用
- 前進処理へ R・θ を外部入力しない

## 対照テスト（シリーズ内完結の再現性規約）

実行冒頭で **R124_23 の 248 衝突厳密回帰**（residual ≤ 1e-8、R ドリフト ≤ 1e-10）
を再現し、`exact_finite_order_roots_longrun_v1` の公表結果と整合することを
確認してから本測定へ進む。FAIL の場合は本測定を実行しない。

## 出力

- `R_mass_beat_two_arm_pre_result_v1.json` — 対照テスト・腕情報・対ごとの
  フィット結果（傾き・R²・min|O|）・ヌルテスト判定
- `R_mass_beat_two_arm_pre_rows_v1.csv` — 全対×全衝突の |O| と unwrap 位相

- `overlap_phase_and_abs_pre_v1.png/svg` — 位相と |O| の時系列
- `beat_slope_vs_delta_R_pre_v1.png/svg` — 傾き vs ΔR 散布図

## 実行

```bash
python3 run_R_mass_beat_two_arm_pre_v1.py
```

## 既知の限界（本測定で対処）

- 腕間で E_read・p_read を揃えていない（ΔE 由来の位相が混入しうる）。
  本測定では E 整合対の探索、または ΔE を共変量とする回帰で分離する
- 同R・異振幅分布の対照（存在原理の直接検証）は現行の「B振幅のみ探索」族
  では作れない。セクター分解族（`R_0_to_1_longrun_sweep_v1` の初期状態機構）
  を流用して本測定に追加する
- 腕間の相対位相の「観測可能性」の主張には ABC 系の参照波 C による
  ゲージ不変読出しが必要。予備テストは数値表現上の位相で配管を検証する
