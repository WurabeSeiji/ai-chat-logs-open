# R=0.0–1.0 初期状態系列・1500衝突環境 v1

## 目的

次の11条件について、AB波だけから読み出されるRを保ったまま1500衝突まで追跡する。

$$
R=0.0,0.1,0.2,\ldots,0.9,1.0
$$

散乱本体 `../../run_ab_invariant_theta_toy_v1.py` は変更しない。目標Rは独立した
初期状態探索だけに使い、前進処理には完成した初期A/B複素配列だけを渡す。

## 初期状態族

従来の単位A基本波と、B63波全体の振幅だけを変える族では、

$$
0\leq R<\frac{61}{64}=0.953125
$$

であり、R=1へ到達できない。B63波自身が低域ボゾン成分を含むためである。

この全域対照では、元のA基本波・B63波を、現行 `theta_from_ab` が使うのと
同一のFFTマスクでボゾン／フェルミオン保存セクターへ分解する。各セクターの
ABペアノルムを1にそろえた後、候補初期配列を作り、無変更の `theta_from_ab`
が返すRと目標値の差だけを見て混合量を二分探索する。

これは散乱則の変更ではなく、R=0と1を含む比較用初期状態族の拡張である。

## 実行

```bash
python3 \
  ab_invariant_theta_toy_v1/inverse_initial_conditions_v1/R_0_to_1_longrun_sweep_v1/run_R_0_to_1_longrun_sweep_v1.py
```

各Rの長時間波形図、衝突0・1・2の全R比較図、1500衝突のR依存ヒートマップ、
全行CSV、JSON、Markdownレポートを生成する。
