# モードロック探査・予備テスト v1 —— ロック機構の存在証明（Z₆ タング発見）

## 目的

m = 23 生成則の唯一の残存候補「閉ループ動力学のモードロック」について、
**機構がモデル内に存在するか**の存在テスト。手順は逆二乗論文と同じ三段：

1. **零次 no-go（定理＋数値）**：現行 `theta_from_ab` はビン別パワー
   |A_k|²+|B_k|²（位相盲目）だけの関数で、実直交回転はこれを各ビンで厳密
   保存する。ゆえに θ は運動の定数＝動力学が存在しない。
   数値確認：400衝突×4振幅で最大ドリフト **2.2×10⁻¹⁶**
2. **保存的作業仮説**：位相感受的な θ 読出し2変種（挿入でなく、N体系列が
   基礎に置く関係波 f_AB 系の候補）
   - V1 coherent：対称チャネル X = A+B のマスク内パワー比
   - V2 relational：交差スペクトル A_k B_k* のマスク内比
3. **独立検証**：初期B振幅の掃引（61点×400衝突）で後期 θ/π の悪魔の階段を探す

## 結果（2026-08-02）

### V1 coherent：**厳密有理ロック θ/π = 1/3 のタングを発見**

粗スキャンで θ/π = 1/3 プラトー（1/3 との距離 2.3×10⁻¹²）を検出。
精密スキャン（800衝突・tail 300）で確定：

| 振幅 | tail平均 θ/π | \|平均 − 1/3\| |
|---|---|---|
| 2.4 | 0.28852 | 4.5e-02（外） |
| 2.5 | 0.31437 | 1.9e-02（外） |
| **2.6–3.3** | **0.333333333333** | **0.0（厳密）** |
| 3.5 | 0.33327 | 6.5e-05（外） |

- **タング幅 ≈ [2.55, 3.35]**：有限区間で回転数の tail 平均が**厳密に 1/3**
- tail 標準偏差 ~7×10⁻²：固定点でなく**周期軌道**（θ が振動しつつ平均回転数が
  厳密有理数にロック）——Arnold tongue の教科書的挙動
- 根の規約に翻訳：θ/π = 1/3 → m/n = 1/2 − 1/3 = 1/6 → **(m, n) = (1, 6)、Z₆ ロック**

### V2 relational：第二の no-go を発見

交差スペクトル読出しは tail 標準偏差 1.1×10⁻¹⁶ ——**これも運動の定数**だった。
位相感受に見える読出しでも保存されるクラスがある。no-go の範囲が拡大
（保存される読出しの分類、という新しい問いを生む）。

## 帰結

1. **モードロック機構はモデルに存在する**。「電荷量子化＝Arnold tongue 台地」
   の読みが、モデル内で初めて実体（厳密有理ロック＋有限タング幅）を持った
2. **Z₄ と Z₆ が揃った**：勘定則ロック直結実験の (m,n)=(1,4)（Z₄・構造的）と
   本実験の (1,6)（Z₆・動力学的）——判別レジスタ系列が主定理候補と名指しした
   **結晶学的制限の二つの位数 Z₄/Z₆ が、異なる二機構から独立に出現**した
3. 残る本丸は「(23, 124) のタングが存在するか・自然な状態族がそこに座るか」。
   タング幅は分母とともに急減するため、高分解能掃引と長時間発展の
   キャンペーン設計が必要
4. 正直な限定：V1 読出しは作業仮説であり導出されていない。次段では
   「どの読出しクラスが保存され（no-go）、どれがロックを生むか」の分類が
   仮説の恣意性を消す道になる（V2 の第二 no-go はその第一データ）
