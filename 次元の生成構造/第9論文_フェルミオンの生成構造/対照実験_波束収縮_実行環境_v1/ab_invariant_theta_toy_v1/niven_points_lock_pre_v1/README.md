## 目的

数え上げ有理数 R 族と有理角ロック族の交点は、Niven の定理により
R ∈ {0, 1/4, 1/2, 3/4, 1} の5点に限られる（counting_rule_lock_bridge README の
「唯一の交点」誤記の訂正に伴う完備化）。本テストは、到達可能な全交点で
「数え上げ構成（等重み・振幅探索ゼロ）→厳密ロック」の直結を検証する。
**全予言は測定前にコード内定数として固定した。**

## 帰結

1. **数え上げ→ロック直結は、到達可能な全 Niven 点で成立**。橋頭堡は
   1点（R=1/2）ではなく体系である
2. **実現した位数は n = 3, 4, 6**——2次元結晶学的制限の非自明な位数の
   **完全なメニュー** {3, 4, 6} と厳密に一致する。Niven の定理と結晶学的
   制限は同じ有理余弦制約の двух面であり、「数え上げが作れるロックは
   結晶学的位数に限られる」という形で、判別レジスタ系列の主定理候補
   （Z₄/Z₆ 制限）が Z₃ を加えた完全形で実証された
3. 混合パリティ支持（偶数と奇数の混合）が構造的に新しい状態クラスを
   開いた（P1 系列。従来実験は奇数のみ／偶数のみ）
4. 論文B（三部作第二部）の主張3「Niven 5交点とロック直結」の
   実験的裏付けが完備した
