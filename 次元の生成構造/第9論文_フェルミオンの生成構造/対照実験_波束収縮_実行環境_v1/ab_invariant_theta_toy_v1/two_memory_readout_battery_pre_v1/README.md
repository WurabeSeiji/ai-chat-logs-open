# 二記憶判別バッテリー・予備テスト v1

## 目的

波形の二種類の記憶——(1) 大きさの記憶＝ノルム、(2) 形の記憶＝倍音の存在集合
（support）——に対し、現行読出しがどちらに依存するかを分類する。

- **条件A**（同存在集合・異振幅分布・同ペアノルム）:
  構造層読出しなら不変のはず。現行パワー比 θ 読出しの可視層汚染を定量化
- **条件B**（同ノルム・異存在集合・等重み）:
  構造層読出しは離散的に変わるはず。数え上げ仮説 n = 4·N_rel の予言値を併記

## 設計境界

- `theta_from_ab`・`rotate_ab` は無変更で呼ぶだけ（複製・改変しない）
- 状態構築は既存の `explicit_packet_case` / `make_case_state` のみ。
  振幅分布は単一倍音状態（各単位ノルム）の重み付き和で構成
- 対照テスト: 等重み和で作った B63 が既存テンプレート構成と一致することを確認

## 実行

```bash
python3 run_two_memory_readout_battery_pre_v1.py
```

## 初回実行結果（2026-08-02）

- **対照テスト MATCH**（|ΔR| = 1.7e-16）: 等重み和構成はテンプレート構成と等価
- **発展不変性 PASS**（3系列×100衝突、ドリフト ≤ 3.3e-16）

### 条件A: パワー比読出しは可視層——ただし定量的に

| profile | R |
|---|---|
| A_equal（基線） | 0.476562500000 |
| A_linear_decay | 0.444719520873 |
| A_random_seed7 | 0.466324758380 |
| A_exp_decay | 0.377167152223 |
| A_inverse_k | 0.069473326629 |

spread = **0.407**。同じ存在集合でも振幅分布で R がほぼ全域動く。
現行パワー比読出しは構造層読出しの資格を持たない（数え上げ型への置換が必要）
ことが定量的に確定した。

### 条件B: 等重み点で読出しが厳密有理数になる（予備テストの主発見）

| support | R（実測） | 厳密値 | N_rel | 4·N_rel |
|---|---|---|---|---|
| odds 1..63（32本） | 0.4765625 | **61/128** | 31 | 124 |
| odds 1..31（16本） | 0.453125 | **29/64** | 15 | 60 |
| odds step4（16本） | 0.46875 | **15/32** | 15 | 60 |
| odds minus {3}（31本） | 0.4838709677 | **15/31** | 30 | 120 |
| evens control | 0.0 | **0** | 31 | 124 |

等重み（＝振幅情報を消した）点では、パワー比読出しが**支持集合の数え上げ比
（小さい分母の厳密有理数）に退化する**。分母は支持サイズを追跡し
（128 = 4×32、64 = 4×16、32 = 2×16、31 = |S|）、偶数倍音対照は厳密に 0
（パリティの構造的読出し）。つまり：

> 現行読出しは「数え上げ読出し＋振幅変形」に分解できる。等重み点が各支持
> クラスの構造代表であり、振幅変形が可視層汚染の全体である。

### 帰結

1. 二記憶の分離は現行系でそのまま観測された：構造成分（等重み点の有理数、
   支持だけの関数）と可視成分（振幅変形、spread 0.407）
2. m/n 生成則実験の入口が具体化した：構造読出しの候補は「等重み点への射影
   ＝支持の数え上げ比」。次段は等重み点の有理数の分子・分母の勘定則を
   閉じた形で書き、ord/wind（n, m）との対応を検証する
3. **注意（緊張点）**: 既存の α ロック状態（R₁₂₄,₂₃ = 0.697...）は
   B 振幅の連続調整＝可視層の操作で到達した値である。等重み点 61/128 とは
   別の場所に立っており、「存在だけが構造」原理とロック状態の関係は
   生成則実験で再検討を要する
