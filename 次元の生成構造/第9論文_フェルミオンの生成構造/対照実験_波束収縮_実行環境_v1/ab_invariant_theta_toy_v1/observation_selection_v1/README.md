- **P1 成立**: 厳密根で回帰忠実度は厳密に1。**時計選択性**: J=8観測者には124根の回帰が見えない（F_8=0.0026）が J=248 観測者には見える（F_248=1.000000000000001）——選択が観測時計の約数構造に継承されることを直接実証
