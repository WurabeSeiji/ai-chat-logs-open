# 勘定則検証と数え上げ→ロック直結・予備テスト v1

## 目的

二記憶バッテリー（`two_memory_readout_battery_pre_v1`）の等重み点5クラスから
解読した勘定則

$$R_{\mathrm{eq}}(S) = \frac{2|S| - c(S)}{4|S|}, \qquad
c: \{k{=}1 \to 2,\ k{=}3 \to 1,\ \text{偶数}k \to 2,\ \text{奇数}k{\ge}5 \to 0\}$$

を留め置き支持で予言検証し（Part 1）、勘定則が R = 1/2 を予言する
{1,3}-free 支持で「数え上げ構成だけ・振幅探索ゼロ」の厳密ロックを確認し
（Part 2）、ord/wind 読出しで (m, n) を整数として再構成する（Part 3）。

R = 1/2 = cos²(π/4) は「有理数 R 族（数え上げ）」と「有理角 θ 族（有限位数
ロック）」の唯一の非自明な交点であり、二つの整数の住所が出会う橋頭堡。

**※訂正（2026-08-03）**：「唯一の非自明な交点」は誤り。Niven の定理（有理角の
余弦の有理性）により、交点は R ∈ {0, 1/4, 1/2, 3/4, 1} の**5点**である。
R=1/4（cos²(π/3)、予言周期12）と R=3/4（cos²(π/6)、予言周期6）が未検証の
橋頭堡として残っており、検証は三部作第二部（姉妹稿B）で行う。なお規約監査
（convention_audit_pre_v1）の even≥2 マスク下で、数え上げ状態 odds 5..63 が
R=3/4 に厳密着地することは既に測定されている。

## 設計境界

- `theta_from_ab`・`rotate_ab` は無変更で呼ぶだけ
- 状態は `explicit_packet_case` / `make_case_state` の等重みパケットのみ
- **振幅探索は一切使用しない**（数え上げ→ロック直結が主張だから）
- 予言値は測定前にコード内定数として書き込む（仮説→反証の作法）

## 初回実行結果（2026-08-02）: 全パート PASS

### Part 1: 留め置き7支持すべてで勘定則の予言が的中（誤差 ≤ 5×10⁻¹⁶）

| support | 予言 | 実測誤差 |
|---|---|---|
| {1,3} | 1/8 | 2.8e-17 |
| {5} | 1/2 | 2.2e-16 |
| 奇数 5..63 | 1/2 | 3.9e-16 |
| {1,5,7} | 1/3 | 0.0 |
| {3,7} | 3/8 | 5.0e-16 |
| 奇数 1..15 | 13/32 | 5.0e-16 |
| **{1,2,5}（偶数混合）** | **1/6** | 3.6e-16 |

偶数混合の一般化 c 則まで含めて的中。勘定則は解読仮説から
**検証済みの閉じた式**に昇格した。

### Part 2: 数え上げ→ロック直結（振幅調整ゼロ）

{1,3}-free の3支持（奇数5..63、{5}単独、step4）すべてで：
- |R − 1/2| ≤ 3.9×10⁻¹⁶（勘定則どおり厳密に交点へ着地）
- **8衝突厳密回帰**（residual@8 ≈ 10⁻¹⁵、100衝突まで全周期倍数で回帰）

既存のロック状態はすべて振幅の連続調整（可視層操作）で作られていた。
これは**数え上げ（構造層）だけで作られた初の厳密ロック状態**である。

### Part 3: ord/wind 読出しが整数を返す

3状態すべてで ord = 8（実回転周期）、wind = 1（累積角/2π、誤差 ≤ 6×10⁻¹⁶）、
有理数再構成で **(m, n) = (1, 4)** を厳密再現。整数対を波の発展から読み出す
機構が動作した。

## 帰結と次段（本丸実験の仕様）

1. **勘定則は定理級**：支持→有理数の写像は閉じた式で、振幅に依存しない
   構造層読出しとして確立
2. **橋頭堡確保**：R=1/2 で「数え上げ構成＝厳密ロック＝整数読出し」が
   一気通貫した
3. **残る本丸**：(m, n) = (23, 124) は有理数 R 族の外にある（cos²(23π/124)
   は無理数）ため、この読出し族では到達できない。数えた整数を**比 R でなく
   角度 θ/π に運ぶ操作**——交換作用素の位数・巻き数が非自明になる拡張
   （候補：セクター間位相を持つ複素交換、B63 の関係構造 4×31=124 を位数と
   して実現する作用素——が本丸実験の対象。本テストで整備した ord/wind
   読出しはそのまま測定器として使える
