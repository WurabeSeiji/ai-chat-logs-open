# 混合結合・予備テスト v1 —— クーロン前係数の合成則判定（2026-07-30 提案の実行）

## 目的

メモリ「残る決定打」項目2（2026-07-30 提案、未実行だった実験）：
二閉包の固有透過分率 f_A, f_B に対し、実効交換強度 T_eff の合成則を判定する。
q_Aq_B/4π 型のクーロン前係数が立つには**積型** T_eff ∝ f_A f_B が必要。

## 方法

各側の固有分率を、全ボゾン単一倍音（f=0）と全フェルミオン単一倍音（f=1）の
二倍音混合 state(f) = √(1−f)·s_bos + √f·s_fer で**連続に厳密調整**
（当時懸念した合成則の恣意性は、この構成で消える——合成則を仮定せず測れる）。
状態準備検証：分率 0 / 1 が 10⁻³² 精度、交差重なり ≤ 1.3×10⁻¹⁶ で PASS。

## 結果（2026-08-02）: 合成則は厳密に「平均」——積ではない

6×6 グリッド（f_A, f_B ∈ {0, 0.2, …, 1.0}）で：

| 仮説 | max\|誤差\| | 判定 |
|---|---|---|
| **平均 (f_A+f_B)/2** | **7.2×10⁻¹⁶** | **厳密一致** |
| 積 f_A·f_B | 0.5 | 棄却 |
| √(f_A f_B) | 0.5 | 棄却 |

Part 2（チャネルノルム移乗・局在移乗のスイング、16衝突）も、どの合成則とも
相関せず（\|r\| ≤ 0.24）——移乗観測量にも積構造は隠れていない。

## 帰結：ゼロ次のクーロン no-go と、積構造の正しい住所

**ゼロ次結論**：位相盲目（対角）読出しの交換強度は加法的（平均合成）であり、
**q_Aq_B 型の頂点積はゼロ次に存在しない**。これは本日の保存則定理
（保存 ⇔ ビン別 |A_k|²+|B_k|² のみの関数）と同根で、一つの定理が三つの
no-go（θ凍結・平均合成・積不在）を同時に出す。

そして積構造の住所が確定する。パワーの恒等式

$$|A+B|^2 = |A|^2 + |B|^2 + 2\,\mathrm{Re}(A^*B)$$

の**干渉交差項 2Re(A*B) は、振幅の積 √f_A·√f_B·cos(Δφ) そのもの**——
振幅積（QED 頂点構造）と**符号**（相対位相 cosΔφ の±）を同時に含む。

> **統一像（本日の集大成）**：対角セクター＝θ保存・平均合成・符号なし＝
> 重力的性質（普遍・加法的・遮蔽不能——質量の加法性そのもの）。
> 積合成・±符号・量子化（ロック）・動力学は、すべて交差項
> 2Re(A*B)＝位相感受セクターに住む。**クーロン的なもの一式は交差項の物理**。
> モードロック（Z₆）が位相感受読出しでだけ現れた事実とも整合。

## 次実験への反証可能な予言

交差項を移乗観測量として測れば、合成則は
**√(f_A f_B)·cos(Δφ)（振幅積×符号）** に従うはず。
- 従えば：電荷 = 交差項振幅、符号 = 相対位相、が実測で確定し、
  残る決定打の項目2（前係数）と項目3（符号）が同時に閉じる
- 従わなければ：交差項読出しの設計を反証データとして記録
