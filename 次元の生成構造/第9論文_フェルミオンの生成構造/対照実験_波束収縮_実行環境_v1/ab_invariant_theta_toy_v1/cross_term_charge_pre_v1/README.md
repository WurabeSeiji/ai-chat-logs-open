# 実行記録（2026-08-02、三段）

## v1（搬送波あり・本ランナー）: ヌル——ただし定理として

全セルで変調 M ~ 10⁻¹⁶。診断の結果、**搬送波（q_A=+1/q_B=−1）が A/B を
厳密に直交部分空間へ分離**しており（全単一倍音対で |⟨A_j|B_k⟩| ≤ 3×10⁻¹⁷）、
コヒーレント流 dN_B = ±sin2θ·Re⟨a|b⟩ は恒等的にゼロ。測定失敗ではなく
**「搬送波分離＝コヒーレント（電荷的）チャネルの閉鎖」という定理**。
帰結：**電荷的相互作用の存在条件はモード（チャネル）共有**——
「電荷は共有チャネルの量」という関係的主張の明示的機構が出た。

## v2（搬送波なし＋パリティ反転マスク）: 無効（記録）

搬送波なしでは倍音が想定 χ ビンに乗らず（M4 分率が全てゼロ）、θ 読出しが
崩壊。**対角 θ 読出し（搬送波前提）とコヒーレント流路（共有前提）が
現行トイでは排他的構成に載っている**ことが判明。物理モデルは
「部分共有」（搬送波分離成分＋共有成分の混在）を要する、という設計要件。

## v3（搬送波なし・プローブ回転）: 電荷文法の成立

共有チャネル実測: ⟨A₁|B₁⟩ = ⟨A₅|B₇⟩ = 0.5（交差アンカー漏れ ≤ 5×10⁻¹⁶）。
プローブ角 θ_p ∈ {0.1, 0.2}（計器設定として宣言）、6×6 グリッド × 位相8点：

| 予言 | 結果 |
|---|---|
| 頂点積則 M = κ·sin2θ_p·√(f_Af_B)、κ=\|⟨A₅\|B₇⟩\| | **κ = 0.500000000000003、spread 9×10⁻¹⁴（50セル×2プローブ）— 厳密成立** |
| 中性性（f=0 で M=0） | **max M = 4×10⁻¹⁵ — 成立** |
| 位相 δ の普遍性 | **spread 9×10⁻¹⁴ — 成立** |
| 符号（φ 半回転で流れ反転） | **変調がオフセットに勝る全32セルで反転** |

注記：オフセット（ボゾンチャネル √((1−f_A)(1−f_B)) 項）の予言符号は
rotate_ab の回転規約の取り違えで逆（誤差最大 0.389 = sin0.4 と厳密一致＝
符号スリップの証拠）。変調則の判定には影響しない。

## 帰結

2026-07-30 メモリ「残る決定打」のうち：
