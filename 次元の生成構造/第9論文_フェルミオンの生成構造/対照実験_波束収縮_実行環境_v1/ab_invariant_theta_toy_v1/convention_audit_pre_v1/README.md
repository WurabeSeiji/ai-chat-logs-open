# 規約監査・予備テスト v1 —— 物理級と簿記級の分類

## 目的

本日の主張群を、フェルミオンマスクの定義を5通り（正準 even≥4／even≥6／
even≥2／パリティ無視 any≥4／パリティ反転 odd≥3）に振って再測定し、
**規約非依存（物理級）と規約依存（簿記級）に分類**する。

対照テスト：正準マスクの変種読出しは元実装 `theta_from_ab` と**厳密一致**
（差 0.00）。予言は各倍音の実測ビン表×マスクの勘定だけから立てた。

## 結果（2026-08-02）

### 物理級（全規約で生存）

| 主張 | 判定 |
|---|---|
| **C1 メタ勘定則**：等重み点の R はビン表×マスクの数え上げで予言可能 | **20/20 PASS**（誤差 ≤ 8×10⁻¹⁶、全5マスク×全4状態） |
| **C2 有理数性**：等重み点の R は小分母有理数 | 全マスクで PASS（61/128, 59/128, 95/128, 61/124, 59/124, 3/4, 1/4, 1/2, 0） |
| **C3 振幅依存性**：振幅変形で R が動く | M0–M3 で PASS（spread 0.20〜0.42）。例外：読出しが恒等的に0になる退化クラス（M4×奇数支持）のみ spread=0 |
| **C4 ロック橋頭堡**：全ビン通過倍音の等重み支持は振幅探索ゼロで R=1/2 着地・周期8厳密ロック・(m,n)=(1,4) | 橋頭堡が存在する全マスク（M0/M1/M3/M4）で PASS |
| **C5 役割の規約相対性**：パリティ反転マスクではロック支持が**偶数倍音側**へ移る | **PASS**——M4 で偶数倍音30本がロック（周期8、(m,n)=(1,4)）。「奇数倍音＝フェルミオン的」は規約ラベルであり、構造（数え上げ→ロック）は不変 |

### 簿記級（規約の産物）

- 勘定則の具体形 (2|S|−c)/(4|S|) の c 則（k=1→2, k=3→1 等）——正準マスクの |k|≤2 除外の反映。マスクを変えると c 則も変わる（が C1 のメタ則は生存）
- 等重み点の具体値（61/128 等）
- 「奇数＝フェルミオン／偶数＝ボゾン」の割り当てそのもの
- **橋頭堡の存在自体もマスク条件付き**：M2（even≥2）では A の ±2 ビンがマスクを通過して A が純ボゾンでなくなり、数え上げロック支持が消滅（正直に記録）

## 帰結

1. 本日の中心成果——「読出し＝数え上げ＋振幅変形」の分解、等重み点の
   有理数性、数え上げ→ロック直結、(m,n) 読出し器——は**規約を変えても
   生き残る構造**であり、トイの簿記ではない
2. 具体的な数（61/128、c 則）は簿記。論文化の際は C1〜C5 のメタ形で主張し、
   正準マスクの数値は「一例」として提示すべき
3. ボゾン/フェルミオンの役割まで規約相対（C5）というのは、
   「命名の後置原理」（軸の名前は読出しの後づけ）の読出し規約版に相当する
4. m=23 の生成則は本監査の対象外のまま：静的分解の反証（巻き数分光）と
   合わせ、**モードロック型動力学が唯一の残存候補**。次実験は自己整合
   ループ設計（零次 no-go 明示→保存的作業仮説→独立検証の手順厳守）
