# 読出し分類＋タング分光・予備テスト v1

## Part A: 読出し分類 —— 保存則の定理形と、昨日の主張の訂正

7種の θ 読出しを「自分自身が駆動する動力学の下で保存されるか」で分類：

| 読出し | 分類 | 自己ドリフト |
|---|---|---|
| R1 対角和 \|A\|²+\|B\|² | **CONSERVED（唯一）** | 2.2×10⁻¹⁶ |
| R2 X=A+B パワー（V1） | DYNAMICAL | 1.06 |
| R3 Y=A−B パワー | DYNAMICAL | 1.06 |
| R4 交差スペクトル（V2） | **DYNAMICAL（訂正）** | 0.43 |
| R5 A のみ / R6 B のみ | DYNAMICAL | 1.35 |
| R7 交差実部 | DYNAMICAL | 0.38 |

**訂正**：前実験（mode_locking_probe）で V2 を「第二の保存読出し」と報告したのは
誤り。V2 は初期から大きく動いた後に**固定点へ収束**する動力学級で、tail 標準偏差
1e-16 を保存と誤認した。保存されるのは R1 のみ＝**保存 ⇔ ビン別の回転不変量
|A_k|²+|B_k|²（平行四辺形恒等式）だけの関数**、という定理形が立った。

## Part B: 階段の収束性の注意

161点×400衝突の粗スキャンでは、プラトー平均が有理数に 1e-9 で届かない
（遷移が抜けきらない）。厳密判定には 900衝突以上が必要（Part C で確認）。

## Part C: 1/3 タング下端と (23,124)=ρ 39/124 の探索

- ズーム（49点×900衝突）：**1/3 タングの下端は amp ≈ 2.518**（2.520〜2.620 で
  ρ = 1/3 厳密、d = 5.6×10⁻¹⁷）
- 最接近点：amp 2.5133 で ρ = 0.31492、**39/124 = 0.31452 との距離 4.0×10⁻⁴**
- マイクロズーム（27点×1500衝突、amp 2.470〜2.522、Δamp = 0.002）：
  **39/124 プラトーは検出されず**。最接近 amp 2.5040 で d = 3.3×10⁻⁴
- **重要な観察**：タング下端の直下では ρ が隣接振幅点間で ~10⁻² 規模で
  非単調に暴れる。円写像の言葉では**超臨界領域（タングの重なり／カオス）**の
  挙動であり、この帯域で高位数タング（n=124、幅は指数的に狭い）を
  素朴な掃引で探すのは原理的に不適

## 帰結と次段の設計

1. (23,124) タングは**現分解能（幅 < 0.002）では不検出**——存在の否定ではなく
   探索領域が超臨界であることの診断
2. 円写像理論では、完全な悪魔の階段（全有理数のタングが分離して並ぶ）は
   **亜臨界（結合 K < 1）**でのみ現れる。現行 V1 は結合強度のノブを持たない
3. **次段の設計＝結合補間ノブ**：読出しパワーを
   P_λ = |X|² + λ(|A|²+|B|²)
   と補間する（λ→∞ で保存読出し＝結合ゼロ、λ=0 で V1）。λ が Arnold の
   K に相当する制御軸になり、亜臨界領域で階段の完全性・タング幅の
   分母スケーリングを測定→ n=124 タングの存在と可検出性を系統的に判定できる。
   補間パラメータは探査ノブであり主張には入らない（挿入問題と切り分け）
