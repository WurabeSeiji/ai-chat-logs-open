# 巻き数分光・予備テスト v1 —— 静的レジスタ仮説の反証

## 目的

公開論文の複素交換作用素の固有値構造 λ_a = e^{−2πim/n}（n = ord、m = 巻き数）
に対し、「B63 の関係構造（非共通倍音 31 × Z₄ 位相 = 124 スロット）の巡回
レジスタ上で、実状態の反対称成分が巻き数 k = 23 を占有する」という
**静的レジスタ版の生成則仮説**を検証した。

スロット順序の恣意性対策として正準順序4種を全て走らせ、写像だけの寄与
（等重み対照）と状態寄与を分離した。単一倍音基底の直交性は 2.7×10⁻¹⁵ で PASS。

## 結果（2026-08-02）: 仮説は反証された

1. **B63 等重み状態のスペクトルは「写像のみ対照」と全順序で完全一致**
   （O1: k=31 w=1.000、O2: k=1 w=0.811、O4: k=93 w=1.000 —— すべて一致）。
   つまり状態の反対称成分の倍音別複素振幅は特徴を持たず、
   **観測された巻き数構造は全てスロット写像の人工物**（i^q が4スロットで
   一周 → k = 124/4 = 31、順序反転で 93 = 124−31、位相優先で k=1）
2. **k = 23 の占有はどの状態・どの順序でも実質ゼロ**（w@23 ≤ 0.03、
   乱数対照と同程度）
3. 振幅変形状態（1/k、乱数重み）は写像ピークを広げるだけで、
   新しい選択構造を作らない

## 帰結

- **静的な初期状態の分解からは m = 23 は出ない。** 検討課題.md の
  「31×4 レジスタ＋位相巻き」案の素朴な実装は、この形では棄却
- 消去法による局在化：公開論文で R₁₂₄,₂₃ を選んだのは**掃引パラメータ空間
  での共鳴選択**（gray error の深さ）であり、静的構造ではなく
  **動力学的選択**だった。生成則が存在するなら、それは
  「閉ループの動力学が有限位数根に引き込まれる（モードロック）」型で
  なければならない —— 電荷量子化＝Arnold tongue 台地、という以前からの
  読みと整合する方向に絞られた
- 次段の設計対象：読出し（共鳴深さ）が力学へ逆作用する自己整合ループで、
  θ が有理角へロックするか。ただし逆作用項の導入は挿入リスクを伴うため、
  逆二乗論文 v1→v2 型の「零次 no-go 明示 → 保存的作業仮説 → 独立検証」の
  手順を踏むこと
