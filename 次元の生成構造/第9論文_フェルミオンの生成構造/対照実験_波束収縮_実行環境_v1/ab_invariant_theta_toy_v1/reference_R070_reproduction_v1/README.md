# 元論文 R=0.70 波形発展図の再現環境 v1

元論文の20260713エンジンを隔離環境内の無修正コピーからロードし、
提示された波形発展図を同じ条件で再生成する。

## 条件

- $R=0.70$
- $A$: 基本波 $N=1$
- $B$: 等振幅奇数倍音 $1,3,\ldots,63$
- 衝突回数: $0,1,2,3,5,10,20,42$
- 各パネルでA/Bそれぞれの $\rho_\chi$ を自身の最大値で除算
- 4行×2列、12インチ×12インチ、160 dpi

## 更新則

この再現図では新しいAB波由来の $\theta$ は使用しない。以前の論文と同じく、
外部指定した $R=0.70$ を

$$
\Delta_F=2\arcsin\sqrt{R}
$$

へ変換し、元エンジンの複素散乱係数とチャネル別正規化をそのまま使う。

したがって、新トイモデルと比較する前の「元実験を再現できるか」という基準線である。

## 実行

```bash
python3 \
  ab_invariant_theta_toy_v1/reference_R070_reproduction_v1/make_reference_R070_reproduction_v1.py
```

再生成後、元論文PNGとのバイト一致と画素配列一致を自動判定する。

このフォルダは外部 $R=0.70$ を使う元論文再現基準だけを保持する。
$R=0.50$ と $R_\alpha$ の新しい比較図は、外部R入力ではなく
`../inverse_initial_conditions_v1/` で探索した初期AB波から生成する。
