## 3. データ形式

### cross_term_summary_v1.csv（1行 = 1 (case, R) 系列）
- run / case_id / R_input: 系列の識別。R_input は交換係数（反射率）。
- L_A_max, L_A_final: A チャネル局在性（原本実験の L 列と同一定義）の最大・最終値。
- X_A_max, X_A_final: 交差項総量 X_A(t) の最大・最終値。
- Phi_A_mean: 符号整列度 Φ の時間平均。
- H_acq_A_max: 獲得倍音量（A の初期支持外モードの総強度）の最大値。
- corr_L_X_raw / corr_L_H_raw: L_A と X_A / H_acq_A の同時刻 Pearson 相関。
- tau_XL_raw, rho_XL_raw: 時間遅れ相関 ρ(τ)=corr(X_A(t), L_A(t+τ)) の
  最大位置 τ と値（τ 範囲 ±16）。_diff は一階差分系列版。
- R2_L_on_H / R2_L_on_HXPhi / R2_L_on_XPhi: 回帰 R²（L~H / L~H+X+Φ / L~X+Φ）。
- dR2_cross_terms = R2_L_on_HXPhi − R2_L_on_H（交差項の追加説明力）。

### series/*.csv（1行 = 1衝突）
collision, X_A/B, Phi_A/B, H_acq_A/B, L_A/B, N_eff_A/B, Gd1..4_A（|G_d| d=1..4）。

### identity_verification_v1.csv（1行 = 1系列、恒等式検証）
- V1_max_im_ratio: max|Im C_mn| / max|C_mn|（実数性）
- V2_eta_overlap: max_m |<a0_m, b0_m>_η|（η直交性）
- V3_convex_resid / V3_uv_minus_1 / V3_v_min / V3_v_max: 凸結合恒等式
  C^A(k) = u(k)C^A(0) + v(k)C^B(0) の最大残差・|u+v−1| 最大・v の範囲
- V4_period: v(k) の推定周期（衝突数）。NaN = 縮退系列（交換が観測量を変えない R）
- V5_R2_L_on_H / V5_R2_L_on_HX / V5_affine_defect: L のアフィン恒等検査
  （L 分散が機械ノイズ水準の縮退系列8本は NaN）
- V6_phi_span: Φ_A(t) の max−min（時間不変性）
- V7_n_modes / V7_x_ceiling_gap: union 支持モード数と X 天井 1−1/n との差（診断値）

### 一次データ npz（必要時。1ファイル = 1 (case, R)）
- coeffs: complex128, 形状 (記録数, 2, 倍音数, 16)。チャネル軸 = [A, B]。
  chi 方向 FFT（norm="ortho"）の複素係数。状態は各衝突後に単位ノルム。
- harmonics: 符号付き倍音番号（キャリアシフト込みの生の周波数インデックス）。
- collisions: 衝突番号。coverage: 捕捉パワー率（切り捨て監査、≈1）。
- meta: JSON（R, T, t, r 複素散乱係数、パケット仕様、格子、規約）。
- 交差相関行列の再構成: C = coeffs[k,ch] @ coeffs[k,ch].conj().T（η を Frobenius 縮約）。

## 4. 定義（モード基底に関する注意）

- 「倍音 m」は指示書の正整数倍音ではなく、キャリアシフト込みの符号付き chi 周波数
  （例: A=1 パケット → 支持 {0, −2}）。指示書の C_mn = a_m a_n* の忠実な一般化として
  η（毛）次元を Frobenius 内積で縮約している。
- X(t) = Σ_{m≠n}|C_mn|²（状態が単位ノルムのため規格化済み）。
- Φ(t) = |Σ_{m≠n}C_mn| / Σ_{m≠n}|C_mn|。ただし C が実数（後述）のため、
  複素位相整列ではなく符号(±)整列を測る量になっている。
- H_acq(t) = 自チャネル初期支持外モードの総強度（相手から移った倍音量）。

## 5. 確定済みの数値事実（全184系列、恒久検証スクリプトで再現可能）

1. C^A(t) は全系列・全衝突で実対称（max|Im C|/|C| ≤ 2.2e-15）。
2. η直交性: A,B 初期係数の η 内積 ≤ 3.0e-17（毛モード相違による干渉遮蔽）。
3. 凸結合恒等式: C^A(k) = u(k)C^A(0) + v(k)C^B(0)、u+v=1（≤2.8e-14）、
   v∈[0,1]、残差 ≤ 9.1e-15。全系列成立。v(k) の周期は R 依存で 2.01〜5.57 衝突
   （R137 近傍で ≈5.45）。
4. L は (H_acq, X) の厳密なアフィン関数（非縮退176系列、欠損 0.0）。
5. Φ の時間不変（Φ≡1）は奇数N系列（B1,3,5,15,63）のみ。B12/B2 は周期変動。
6. 更新則はユニタリ線形（normalize は恒等作用）。状態依存非線形性・外部選択写像は
   系統Aに存在しない（コード確認＋恒等式で整合）。
