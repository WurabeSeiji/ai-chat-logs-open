# フェルミオンについての理論検討

## 1. 目的

本稿は、ボゾンとフェルミオンを最初から別種の対象として定義せず、どちらも無名な波成分から構成されるという立場から、その差異が相互作用時にどのように現れるかを整理する。

中心となる問いは次の三点である。

1. 無名な波である以上、ボゾンとフェルミオンのいずれにも相互作用時の散乱写像が必要ではないか。
2. ボゾン的状態では散乱写像が恒等写像となり、結果として線形重ね合わせが保たれるのではないか。
3. フェルミオン的状態では、内部自己相関を読むために適切な倍音構造が必要となり、その散乱写像が非線形になるのではないか。

本稿では、これらを現段階の理論仮説として明示し、何が定義で、何が帰結で、何が未導出であるかを分けて記述する。

---

## 2. 無名性から見たボゾンとフェルミオン

第0公理の立場では、系を構成する各成分には、あらかじめ「ボゾン」「フェルミオン」という名前は与えられていない。

したがって、両者の差異は、成分そのもののラベルではなく、

\[
\text{相互作用時にどの写像を受けるか}
\]

によって初めて読み出されなければならない。

すなわち、ボゾンとフェルミオンの区別は、静的な存在分類ではなく、散乱時の応答構造の差として表現されるべきである。

このとき、任意の二つの入射状態を

\[
X,\qquad Y
\]

とし、散乱後の状態を

\[
(X',Y')
\]

と書く。最も一般的には、

\[
\begin{pmatrix}
X'\\
Y'
\end{pmatrix}
=
S(X,Y)
\]

という散乱写像を考える。

ここで重要なのは、無名性のために、散乱前から一方だけに特別な法則を割り当てることはできないという点である。

したがって、ボゾンとフェルミオンの差異は、入力状態の内部構造によって、同じ散乱原理から異なる有効写像が現れる形でなければならない。

---

## 3. ボゾン的散乱

### 3.1 仮説

ボゾン的状態は、相互作用時に内部構造の再編成を必要とせず、入射状態がそのまま保存される状態であると仮定する。

このとき有効散乱行列は恒等写像

\[
S_B=I
\]

で表される。

したがって、

\[
X'=X,\qquad Y'=Y
\]

であり、重ね合わせに対して

\[
S_B(X+Y)=S_B(X)+S_B(Y)
\]

が成立する。

すなわち、

\[
\boxed{
S_B=I
\quad\Longrightarrow\quad
\text{線形重ね合わせが保たれる}
}
\]

と読む。

### 3.2 解釈

ここでいう

\[
S_B=I
\]

は、散乱によって何も起こらないという意味ではない。

位相遅れ、進行方向の変更、座標表示の回転などが存在しても、内部波形の型が保存され、状態空間内で線形に追跡できる限り、ボゾン的散乱とみなす。

したがって、より一般には

\[
S_B=U
\]

であってもよい。ただし \(U\) は線形であり、単一波形の内部構造を新たに生成しない。

本稿では最小模型として、

\[
S_B=I
\]

を採用する。

---

## 4. フェルミオン的散乱

### 4.1 仮説

フェルミオン的状態は、相互作用時に内部自己相関の再読出しと再閉鎖を必要とする状態である。

そのため、散乱後の状態は単純な線形行列ではなく、

\[
S_F=S_F(X,Y)
\]

のように、入力状態そのものに依存する。

すなわち、

\[
\begin{pmatrix}
X'\\
Y'
\end{pmatrix}
=
S_F(X,Y)
\begin{pmatrix}
X\\
Y
\end{pmatrix}
\]

と表される。

このとき一般には、

\[
S_F(\alpha X+\beta Y)
\neq
\alpha S_F(X)+\beta S_F(Y)
\]

であり、散乱写像は非線形である。

したがって、

\[
\boxed{
\text{フェルミオン的散乱}
=
\text{内部自己相関を維持するための状態依存散乱}
}
\]

と仮定する。

### 4.2 非線形性の起源

零二乗和閉鎖を

\[
Q(X)=\sum_n x_n^2=0
\]

とする。

二つの状態 \(X,Y\) を重ねると、

\[
Q(X+Y)
=
Q(X)+Q(Y)+2X^T Y
\]

である。

各状態が個別に閉じていても、

\[
Q(X)=Q(Y)=0
\]

なら、

\[
Q(X+Y)=2X^T Y
\]

となる。

この交差項が非零であれば、単純重ね合わせ後の状態は閉鎖条件を満たさない。

したがって、フェルミオン的状態では、散乱後に閉鎖条件を回復する写像が必要になる。

この回復写像は交差項

\[
2X^T Y
\]

に依存するため、一般に状態依存であり、非線形になる。

この意味で、フェルミオンの非線形性は、外部から人工的に追加された非線形項ではなく、

\[
\boxed{
\text{重ね合わせによって生じた交差項を再閉鎖する必要性}
}
\]

から現れる候補がある。

---

## 5. 一つの複素波にも交差項は存在する

一つの複素波を

\[
z=a+ib
\]

とする。

その二乗は、

\[
z^2
=
a^2-b^2+2iab
\]

である。

したがって、一つの複素波の内部にも

\[
2iab
\]

という交差項は存在する。

しかし、交差項が数式上存在することと、それが系内部で独立に読み出されることは同じではない。

単一の基底波

\[
\psi_1=Ae^{i\theta}
\]

だけなら、

\[
\psi_1^2=A^2e^{i2\theta}
\]

となる。

ここには二倍角成分が現れるが、系内部には元の波と比較する独立な参照波が存在しない。

そのため、

\[
\theta
\longmapsto
2\theta
\]

という変換は存在しても、それを

\[
\text{自己交差項}
\]

として識別する内部基準がない。

したがって、

\[
\boxed{
\text{単一波には交差項はあるが、自己相関の読出し構造はない}
}
\]

と区別する必要がある。

---

## 6. 自己相関には倍音が必要である

### 6.1 最小二成分波形

基底波と一つの倍音を含む状態を

\[
\psi
=
A_1e^{i\theta}
+
A_ke^{ik\theta},
\qquad k\neq1
\]

とする。

その二乗は、

\[
\psi^2
=
A_1^2e^{i2\theta}
+
A_k^2e^{i2k\theta}
+
2A_1A_ke^{i(k+1)\theta}
\]

である。

ここで、

\[
2A_1A_ke^{i(k+1)\theta}
\]

は、どちらの自己項とも異なる関係成分である。

また、共役積を用いれば、

\[
\psi_1^*\psi_k
=
A_1A_ke^{i(k-1)\theta}
\]

となり、差周波数成分も現れる。

したがって、倍音を含む二成分系では、

\[
k+1,\qquad k-1
\]

という関係周波数が生成される。

この成分は、

\[
\boxed{
\text{基底波と倍音の相対関係そのもの}
}
\]

であり、内部自己相関の読出しに相当する。

### 6.2 倍音は内部観測器である

基底波だけでは、系は自分自身の位相状態を独立に比較できない。

しかし倍音が存在すると、

\[
\psi_1
\]

と

\[
\psi_k
\]

が互いの位相基準になる。

したがって倍音は、単なる波形の追加成分ではなく、

\[
\boxed{
\text{基底波の状態を読むための内部参照波}
}
\]

として働く。

このとき初めて、交差項は単なる代数展開上の項ではなく、系内部に残る相対情報として読み出される。

---

## 7. ボゾンとフェルミオンの区別

以上から、最小仮説を次のように整理できる。

### ボゾン型

\[
\psi_B=Ae^{i\theta}
\]

のように、単一の基底複素波として閉じる。

内部自己相関を読むための追加倍音を必要としない。

相互作用時の有効散乱写像は、

\[
S_B=I
\]

または一般の線形写像であり、

\[
S_B(\alpha X+\beta Y)
=
\alpha S_B(X)+\beta S_B(Y)
\]

を満たす。

したがってボゾン型では、線形重ね合わせが保たれる。

### フェルミオン型

\[
\psi_F
=
A_1e^{i\theta}
+
A_ke^{ik\theta}
+\cdots
\]

のように、少なくとも一つの適切な倍音を必要とする。

基底波と倍音の交差項によって自己相関が読み出される。

相互作用後には、その自己相関構造を再び閉鎖する必要があるため、

\[
S_F=S_F(X,Y)
\]

となり、有効散乱写像は非線形になる。

したがって、

\[
\boxed{
\begin{aligned}
\text{ボゾン} &: \text{自己相関を必要としない線形散乱波},\\
\text{フェルミオン} &: \text{倍音自己相関を維持する状態依存非線形散乱波}
\end{aligned}
}
\]

と表せる。

---

## 8. 奇数倍音の候補

フェルミオン型に必要な倍音が任意ではなく、奇数倍音に限定される可能性がある。

基底次数を \(1\)、奇数倍音を

\[
k=2m+1
\]

とすると、

\[
k-1=2m,
\qquad
k+1=2m+2
\]

であり、自己相関の読出し成分は偶数セクターへ現れる。

すなわち、

\[
\boxed{
\text{奇数自己波形}
\longrightarrow
\text{偶数関係波}
}
\]

という分離が可能になる。

これにより、

- 元の自己波形成分
- 自己相関の読出し成分

を異なる周波数セクターへ分けられる。

したがって奇数倍音は、フェルミオン型内部構造の有力候補である。

ただし、

\[
\text{奇数倍音を持つ}
\]

ことだけでフェルミオン性が導かれるわけではない。

少なくとも、

1. 倍音構造が自己無撞着に閉じること
2. 散乱後にも倍音関係が再構成されること
3. 非線形散乱写像が内部構造を保存すること
4. ボゾン型線形散乱との動的差が観測されること

が必要である。

## 9. 現段階の理論命題

本稿の理論検討を、現段階では次の作業仮説としてまとめる。

### 仮説1　無名散乱原理

ボゾンとフェルミオンはいずれも無名な波であり、差異は相互作用時の散乱写像としてのみ現れる。

### 仮説2　ボゾン線形散乱

ボゾン的状態の有効散乱写像は、

\[
S_B=I
\]

または線形写像であり、内部波形の再閉鎖を必要としない。

### 仮説3　フェルミオン非線形散乱

フェルミオン的状態の有効散乱写像は、交差項と内部倍音構造に依存し、

\[
S_F=S_F(X,Y)
\]

となるため非線形である。

### 仮説4　倍音自己相関条件

一つの複素波には交差項が存在するが、交差項を自己相関として内部読出しするためには、少なくとも一つの適切な倍音が必要である。

### 仮説5　奇数倍音候補

奇数倍音は、自己波形成分と偶数関係波を異なるセクターに分離できるため、フェルミオン型内部構造の有力候補である。

## 10. 未導出事項

現時点では、次の点はまだ導出されていない。

1. なぜボゾン散乱が厳密に \(I\) になるのか。
2. フェルミオン散乱写像 \(S_F\) の具体的な関数形。
3. どの倍音次数が自己無撞着閉鎖を満たすのか。
4. 奇数倍音条件と交換反対称性との関係。
5. 非線形散乱からパウリ排他則が導かれるか。
6. スピン半整数性および \(4\pi\) 周期との接続。
7. 数値モデル内で、倍音構造が初期親状態で選択されるのか、時間発展で生成されるのか。

これらは、論文6以降で用いられている乱数初期化と `make_parent()` による自己無撞着親状態生成、およびその後の時間発展を用いて検証可能である。

---

## 11. 結論

ボゾンとフェルミオンを最初から異なる粒子種として置くのではなく、どちらも無名な波であるとする。

その差異は、相互作用時の散乱応答として現れる。

ボゾン的状態は、内部自己相関を必要とせず、

\[
S_B=I
\]

によって線形に散乱する。

一方、フェルミオン的状態は、基底波と適切な倍音による自己相関を持ち、その交差項を散乱後にも再閉鎖する必要がある。

そのため、

\[
S_F=S_F(X,Y)
\]

となり、散乱写像は状態依存かつ非線形になる。

したがって本稿の中心仮説は、

\[
\boxed{
\text{フェルミオンとは、
適切な倍音によって自己相関を内部読出しし、
散乱時にその自己相関を非線形に再閉鎖する無名複合波である}
}
\]

である。
