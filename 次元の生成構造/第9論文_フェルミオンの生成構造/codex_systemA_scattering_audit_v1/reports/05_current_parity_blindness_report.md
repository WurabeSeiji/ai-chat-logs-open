## 2. 倍音指定が作用する場所

**[コード上の事実]** 倍音指定は次に作用する。

1. `HarmonicCase` の作成
2. `odd_harmonic_kernel` または explicit packet の状態生成
3. 出力メタデータ
4. FFTパワー分布と評価指標

次には作用しない。

1. \(\delta(R)\) の生成
2. \(r(R),t(R)\) の生成
3. 反射・透過の係数
4. 衝突ループの分岐
5. 正規化規則

## 3. 「even_packet」の実体

**[コード上の事実]** 組込み `even_packet` は、

```text
A = (1,)
B = (1,2,4,6)
```

である。

```text
System A:287-292
```

Bには奇数倍音1が含まれるため、これは純偶数セクター入力ではない。名称だけを根拠に純ボゾン型対照として扱うことはできない。

## 4. 搬送波と読出し

**[コード上の事実]** カーネルへ \(q=\pm1\) の搬送波を掛けた全状態をFFT評価するが、カーネル座標への逆シフトはない。

**[数学的帰結]** 半周期移動に対して、

\[
P(e^{iqu}\phi)
=e^{iq\pi}e^{iqu}P\phi.
\]

\(q\) が奇整数なら \(e^{iq\pi}=-1\) なので、カーネルのパリティ固有値は全状態で反転する。

**[数値観測]**

```text
odd kernel:                 c_pi = -1
q=+1 carrier applied:       c_pi ≈ +1
inverse carrier removed:    c_pi = -1
```

現行のFFT絶対倍音分布を、そのままカーネルの偶奇分類とみなすことはできない。

## 5. 型保存と型依存応答の分離

**[数学的帰結]** 現行散乱は \(\mathcal P=\operatorname{diag}(P,P)\) と可換する。

\[
\mathcal S_R\mathcal P=\mathcal P\mathcal S_R.
\]

したがって、

- A/Bとも純偶数なら出力も純偶数
- A/Bとも純奇数なら出力も純奇数
- Aが偶数、Bが奇数なら、各出力チャネルはR/Tに応じた奇偶混合
- 偶数から奇数、奇数から偶数へのセクター変換項は生成しない

となる。

**[数値観測]** \(R=0.6971778791282474\) の偶数×奇数入力では、

```text
A raw output: even=0.6971778791, odd=0.3028221209
B raw output: even=0.3028221209, odd=0.6971778791
```

となった。これは同一係数によるチャネル混合であり、型ごとに異なる散乱法則ではない。

## 6. 評価量による見かけの差

**[コード上の事実]** `L`, `N_eff`, `sim_to_A0`, `sim_to_B0` は入力波形に依存する。そのため、同じ散乱係数でも入力波形が異なれば評価値は異なり得る。

しかし `B_to_A_transfer` は、

\[
\text{A出力の倍音パワー分布}
\]

と

\[
\text{初期Bの倍音パワー分布}
\]

のコサイン類似度であり、反射・交換の経路ノルムではない。

したがって評価値の差を、散乱係数が偶奇を読んだ証拠として扱ってはならない。

## 7. 結論

**[コード上の事実]** 現行コードは入力の倍音構造を生成・評価するが、散乱係数は読まない。

**[数学的帰結]** 現行コードはパリティセクターを変換しないが、パリティ固有値に応じた反射率・透過率・交換率の差も生成しない。

**[未導出]**

```text
現行コードは、型を保存し得るが、型ごとの散乱応答差を生成しない。
```

偶数倍音ボゾン型・奇数倍音フェルミオン型仮説は、この結果によって否定されない。現行散乱核がその仮説を検証する入力依存構造を持っていないことが確定した。
