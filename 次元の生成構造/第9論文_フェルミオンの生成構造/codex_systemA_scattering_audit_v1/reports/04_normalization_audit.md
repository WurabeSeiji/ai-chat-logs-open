# 04 正規化監査

## 1. 正規化の定義

**[コード上の事実]** System Aが使用する正規化は、

\[
\operatorname{normalize}(v)=\frac{v}{\|v\|_2}
\]

である。

```text
散乱源:71-75
```

初期状態生成時と各衝突更新時に適用される。

```text
散乱源:88-101
System A:611-628
System A:718-736
```

各衝突では、

\[
\widetilde a=ra+tb,\qquad
\widetilde b=ta+rb
\]

を作った後、

\[
a'=\widetilde a/\|\widetilde a\|,
\qquad
b'=\widetilde b/\|\widetilde b\|
\]

と、チャネルごとに別々に正規化する。

## 2. 現行既定経路

**[コード上の事実]** AとBは異なる \(\eta\) モード \(m_A=1,m_B=2\) を持ち、System Aは `hair_enabled=True` を固定している。

```text
散乱源:42-47
System A:718-723
```

**[数学的帰結]** 16点周期格子上でA/Bは直交する。散乱行列もユニタリなので、反復中も

\[
\|a\|=\|b\|=1,\qquad \langle a,b\rangle=0
\]

が保存され、

\[
\|\widetilde a\|=\|\widetilde b\|=1
\]

となる。したがって現行既定System Aでは、衝突後のチャネル別正規化は丸め誤差を除き何も変えない。

## 4. 保存される量

### 生のユニタリ散乱

**[数学的帰結]**

\[
\|\widetilde a\|^2+\|\widetilde b\|^2
=
\|a\|^2+\|b\|^2
\]

を保存する。

パリティ演算子との可換性も保存する。

### チャネル別正規化後

**[数学的帰結]** 正の実数による各チャネルのスカラー倍なので、各チャネル内部の次は不変である。

- 正規化後の波形形状
- 位相分布
- パリティセクター比
- 正規化したFFTパワー分布
- 正規化した局在指標の形状依存部分

現行直交経路では倍率が1なので、生の値もそのまま残る。

## 5. 失われる量

**[数学的帰結]** 一般の非直交入力、または将来の状態依存散乱では、チャネル別正規化により次が失われる。

- 生のチャネル出力ノルム \(\|\widetilde a\|^2,\|\widetilde b\|^2\)
- チャネル間の出力強度比
- 経路干渉が作ったチャネル強度の増減
- 線形写像としての重ね合わせ関係
- 生の反射・交換経路ノルムとの直接対応

相対位相 \(i\) を持つ同一波形の独立診断では、生のチャネル比

\[
0.0810421 : 1.9189579
\]

が、正規化後には

\[
1:1
\]

へ置き換えられた。

## 6. 偶奇差を消しているか

**[数値観測]** 現行System Aの既定直交経路では、`normalize` が既存の偶奇差を消しているという証拠はない。正規化倍率が1だからである。

**[数学的帰結]** 一般入力では、正規化はパリティ重量そのものを消さないが、パリティ依存相互作用が**チャネル強度差として現れた場合**には、その強度差を消す。

したがって新散乱候補では、必ず正規化前の経路振幅・チャネルノルム・干渉項を保存してから、正規化位置を選択する必要がある。

## 7. System B

**[コード上の事実]** System Bはチャネル別ではなく、

\[
|a|^2+|b|^2=1
\]

への `normalize_pair` を使う。

```text
run_system_B_gray_cat_metastable_R_sweep_preliminary_v1.py:90-109
```

散乱行列単独は既にユニタリなので、この結合正規化も散乱直後には丸め誤差補正である。ただし安定化ゲインとノイズ付加後の正規化は別の非線形処理である。
