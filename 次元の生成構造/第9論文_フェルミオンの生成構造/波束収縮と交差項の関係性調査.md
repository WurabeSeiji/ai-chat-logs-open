# 波束収縮と交差項の関係性調査

## 1. 調査目的

本調査の目的は、倍音を持たない広い波束と、奇数倍音を含む局在波束との反復交換散乱において観察された「相手側波束の収縮」が、単なる倍音振幅の移乗ではなく、倍音間の交差項ネットワークの移乗・再閉鎖によって生じているかを、保存済みの実験生データから検証することである。

同時に、同実験で観察された微細構造定数逆数 \(\alpha^{-1}\approx137\) および高エネルギー側候補値 \(\alpha^{-1}\approx128\) 近傍の鋭い応答が、既に確認されている交換作用素の有限位数回帰

\[
U(R)^n\approx I
\]

と、倍音交差相関の再構成・移乗効率の極値として同一の現象を異なる観測量で読んだものかを慎重に調べる。

## 2. 現在の仮説

### 2.1 実験の基本構造

初期状態として、広い基底波束 \(A\) と、奇数倍音を含む局在波束 \(B\) を置く。

\[
A(\theta,0)=a_1(0)e^{i\theta}
\]

\[
B(\theta,0)=\sum_{m\in\mathcal H}b_m(0)e^{im\theta}
\]

ここで \(\mathcal H\) は、たとえば

\[
\mathcal H=\{1,3,5,\ldots,N_h\}
\]

である。

反復交換散乱後、もともと高次倍音を持たなかった \(A\) 側に、

\[
A(\theta,t)=\sum_m a_m(t)e^{im\theta}
\]

という複数倍音構造が現れ、波束幅が縮小する。

### 2.2 倍音移乗だけでは局在を説明できない

波束の局在は、高次倍音が存在するだけでは成立しない。各倍音の相対位相が整列し、交差項が適切に再構成される必要がある。

\[
|A(\theta,t)|^2
=
\sum_m|a_m(t)|^2
+
\sum_{m\ne n}a_m(t)a_n(t)^*e^{i(m-n)\theta}
\]

非対角成分

\[
C^A_{mn}(t)=a_m(t)a_n(t)^*,\qquad m\ne n
\]

が、局在波形を形成する交差項ネットワークである。

したがって本調査の中心仮説は、

\[
\boxed{
\text{波束収縮}
=
\text{倍音振幅の移乗}
+
\text{交差項ネットワークの移乗・再閉鎖}
}
\]

である。

### 2.3 \(\alpha\) 近傍の谷との接続仮説

交換係数 \(R\) により定まる作用素 \(U(R)\) が有限位数回帰条件

\[
U(R)^n\approx I
\]

を満たす近傍では、倍音間の相対位相が一定反復後に再現され、

\[
C_{mn}(t+n)\approx C_{mn}(t)
\]

となる可能性がある。

このとき、有限位数根近傍は、

\[
\boxed{
\text{交差項ネットワークを破壊せずに反復再閉鎖できる交換率}
}
\]

として読める。

## 5. 交差項の再構成

### 5.1 チャネル内交差相関

各時刻 \(t\) において、A側とB側の交差相関行列を作る。

\[
C^A_{mn}(t)=a_m(t)a_n(t)^*
\]

\[
C^B_{mn}(t)=b_m(t)b_n(t)^*
\]

対角成分は倍音強度、非対角成分は交差項である。

### 5.2 交差項総量

\[
X_A(t)=\sum_{m\ne n}|C^A_{mn}(t)|^2
\]

\[
X_B(t)=\sum_{m\ne n}|C^B_{mn}(t)|^2
\]

必要に応じて全エネルギーで規格化する。

\[
\widehat X_A(t)
=
\frac{X_A(t)}{\left(\sum_m|a_m(t)|^2\right)^2}
\]

### 5.3 位相整列度

局在には交差項の大きさだけでなく位相整列が必要である。

\[
\Phi_A(t)
=
\frac{
\left|\sum_{m\ne n}C^A_{mn}(t)\right|
}{
\sum_{m\ne n}|C^A_{mn}(t)|
}
\]

\[
0\le\Phi_A\le1
\]

\(\Phi_A\) が大きいほど、交差項が同じ局在方向へ協調していると読む。

### 5.4 差周波数別の集約

交差項は差周波数 \(d=m-n\) ごとに集約する。

\[
G^A_d(t)=\sum_{m-n=d}a_m(t)a_n(t)^*
\]

これにより、局在波形を作る和差モードが、どの順序でA側へ生成されたかを追跡できる。

## 6. 局在性との関係解析

### 6.1 基本相関

各 \(R\) について、

\[
L_A(t),\quad N_{\mathrm{eff},A}(t),\quad X_A(t),\quad\Phi_A(t)
\]

の時系列相関を調べる。

中心命題は、

\[
L_A\text{の増大}
\quad\text{または波束幅の縮小}
\]

が、

\[
X_A\text{および}\Phi_A\text{の増大に先行または同期するか}
\]

である。

### 6.2 時間遅れ相関

\[
\rho_{XL}(\tau)
=
\operatorname{corr}\left(X_A(t),L_A(t+\tau)\right)
\]

を計算する。

交差項形成が波束収縮の原因なら、最大相関は

\[
\tau\ge0
\]

側に現れるはずである。

### 6.3 倍音量と交差項の分離

高次倍音強度を

\[
H_A(t)=\sum_{m>1}|a_m(t)|^2
\]

とする。

次の二つを比較する。

\[
L_A\sim H_A
\]

\[
L_A\sim X_A,\Phi_A
\]

交差項仮説が正しければ、倍音総量だけよりも、交差項総量・位相整列度の方が局在性を良く説明するはずである。

回帰例：

\[
L_A(t)
=
\beta_0
+
\beta_1H_A(t)
+
\beta_2X_A(t)
+
\beta_3\Phi_A(t)
+
\varepsilon(t)
\]

## 7. BからAへの構造移乗量

### 7.1 交差相関行列の類似度

B初期状態とA出力状態の非対角相関行列の類似度を測る。

\[
T_{B\to A}(t)
=
\frac{
\operatorname{Re}\langle
\operatorname{OffDiag}C^A(t),
\operatorname{OffDiag}C^B(0)
\rangle_F
}{
\|\operatorname{OffDiag}C^A(t)\|_F
\|\operatorname{OffDiag}C^B(0)\|_F
}
\]

ここで \(\langle\cdot,\cdot\rangle_F\) はFrobenius内積である。

### 7.2 倍音スペクトル移乗との比較

倍音強度だけの類似度

\[
T^{\mathrm{amp}}_{B\to A}(t)
\]

と、交差相関を含む

\[
T^{\mathrm{cross}}_{B\to A}(t)
\]

を比較する。

\[
T^{\mathrm{cross}}_{B\to A}
>
T^{\mathrm{amp}}_{B\to A}
\]

かつ局在性との相関も強ければ、移っているのは単なる倍音量ではなく、局在を作る内部位相構造である。

### 7.3 方向性検査

\[
T_{B\to A}
\]

と

\[
T_{A\to B}
\]

を比較し、局在構造の移乗方向を確認する。

## 8. 有限位数回帰との比較

### 8.1 回帰誤差

各 \(R\) と候補次数 \(n\) について、

\[
\varepsilon_n(R)=\|U(R)^n-I\|
\]

を計算する。

複数のノルムで確認する。

- スペクトルノルム
- Frobeniusノルム
- 固有位相残差

### 8.2 主要比較量

各 \(R\) について次を集約する。

\[
\max_t L_A(t)
\]

\[
\max_t X_A(t)
\]

\[
\max_t\Phi_A(t)
\]

\[
\max_tT_{B\to A}(t)
\]

\[
\tau_C(R)
\]

\[
\min_n\varepsilon_n(R)
\]

### 8.3 α近傍での検証命題

α候補点近傍で、

\[
\varepsilon_n(R)\to0
\]

と同時に、

\[
T_{B\to A}(R)\to\text{極大}
\]

または

\[
\tau_C(R)\to\text{極大}
\]

または

\[
R_{\mathrm{residual}}(R)\to\text{極小}
\]

が起きるかを調べる。

成立すれば、α近傍の谷を

\[
\boxed{
\text{倍音交差相関の最適移乗・再閉鎖点}
}
\]

と読む根拠になる。

## 9. 対照実験・反証条件

### 9.1 位相シャッフル対照

各倍音の振幅を保ったまま位相をランダム化する。

\[
a_m\mapsto |a_m|e^{i\varphi_m^{\mathrm{rand}}}
\]

これにより倍音量は同じだが交差項整列を壊す。

局在性が消えれば、交差項の必要性を支持する。

### 9.2 交差項除去対照

再構成強度から非対角項を除く。

\[
|A|^2_{\mathrm{diag}}=\sum_m|a_m|^2
\]

これと完全強度を比較する。

### 9.3 倍音ゼロ対照

\[
N_h=1
\]

の基底波のみで同じ \(R\) 掃引を行う。

有限位数回帰誤差は小さいのに局在性応答が現れなければ、

\[
U^n\approx I
\]

だけでは波束収縮の観測量が立ち上がらず、倍音交差項が必要であることを示す。

### 9.4 倍音振幅のみ一致対照

Bの倍音強度分布を保ちながら位相関係だけを変更する。これにより、局在性が倍音強度ではなく位相相関に依存するか確認する。

### 9.5 非α有限位数根との比較

α137・128近傍だけでなく、同じ理論から得られる他の有限位数根も調べる。

他の根でも同じ交差相関増強が起きるなら、現象は一般的な有限位数共鳴であり、αとの一致は追加説明を必要とする。

α近傍だけ特別なら、その差を作る別条件を探索する。

## 10. 非線形性の検査

### 10.1 重ね合わせ残差

二つの入力 \(\psi,\phi\) に対して、

\[
\Delta_{\mathrm{NL}}
=
\|F(\psi+\phi)-F(\psi)-F(\phi)\|
\]

を計算する。

### 10.2 交差項との相関

\[
\Delta_{\mathrm{NL}}(R,t)
\]

と

\[
X_A(R,t),\quad X_B(R,t),\quad T_{B\to A}(R,t)
\]

の関係を調べる。

交差項が散乱写像へフィードバックされているなら、交差項が大きい領域で非線形残差も増えるはずである。

### 10.3 注意点

単に二乗強度を読むだけでも交差項は現れるが、それだけでは基礎発展が非線形とは限らない。

次を区別する。

1. 線形発展後の二乗観測で生じる交差項
2. 交差項が次時刻の散乱作用素を変える状態依存非線形性

元コードを確認し、どちらが実装されているかを明示する。

## 13. 判定基準

### 仮説を強く支持する結果

以下が同時に成立する場合である。

1. A側の収縮に先行して交差項総量または位相整列度が増える
2. B初期状態の交差相関構造がA側へ移る
3. 倍音強度だけより交差項指標の方が局在性を良く説明する
4. 位相シャッフルで収縮が弱まる
5. 有限位数根近傍で交差相関の持続時間・移乗量が極大になる
6. α近傍の谷位置と回帰誤差極小が一致する

### 部分支持

倍音移乗と局在性は相関するが、交差項の追加説明力が弱い場合、波束収縮は主にスペクトル広帯域化による可能性がある。

### 反証となる結果

- 交差項を壊しても同じ局在が得られる
- 交差項形成が収縮より常に後に起きる
- Bの交差相関構造がAへ移らない
- 有限位数根と交差項再閉鎖に関係がない
- α候補点がR刻み・数値精度・特定seedに依存して消える

## 14. 研究上の主張範囲

本調査で直接検証できるのは、

\[
\boxed{
\text{倍音交差項が波束収縮・局在性移乗に関係するか}
}
\]

および、

\[
\boxed{
\text{有限位数回帰点が交差項再閉鎖の極値になっているか}
}
\]

である。

これだけで微細構造定数の値そのものを導出したことにはならない。

慎重な主張は、

> 交換散乱作用素の有限位数根近傍において、局在波束の倍音交差相関構造が相手側チャネルへ効率よく移乗・再閉鎖される可能性を、保存済み生データから検証する。α逆数137および128近傍の応答がこの一般的有限位数共鳴の一部であるか、あるいは追加条件により特別に選択されるかを区別する。

である。

## 16. 最終的な統合仮説

検証が成功した場合、波束収縮実験は次の因果鎖で整理できる。

\[
\boxed{
\begin{aligned}
&\text{局在波束Bの倍音構造}\\
&\quad\downarrow\\
&\text{倍音間交差相関ネットワーク}\\
&\quad\downarrow\\
&\text{交換散乱によるA側への移乗}\\
&\quad\downarrow\\
&\text{有限位数回帰点での周期的再閉鎖}\\
&\quad\downarrow\\
&\text{A側波束の収縮・局在化}
\end{aligned}
}
\]

α近傍の鋭い谷は、その中で、

\[
\boxed{
\text{交差項ネットワークの移乗と再構成が特に安定する有限位数根候補}
}
\]

として再調査される。
