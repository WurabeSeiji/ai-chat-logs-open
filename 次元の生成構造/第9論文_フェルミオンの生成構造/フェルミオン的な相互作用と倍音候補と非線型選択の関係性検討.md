# フェルミオン的な相互作用と倍音候補と非線型選択の関係性検討

## 1. 検討の目的

本検討の中心課題は、同じ無名波の閉鎖系から、なぜボゾン的な波とフェルミオン的な波が区別可能になるのかを明らかにすることである。

ここで重要なのは、フェルミオンの発生比率がボゾンより極端に低いこと自体ではない。その低い比率は、整数倍音・位相閉包を満たす関係が全関係数の中で稀であることから、すでに合理的に説明できる。

本質的な問いは、次である。

\[
\boxed{
\text{どの内部構造が、交換・散乱時に区別可能な応答を生み、}
\text{フェルミオン的な非線形相互作用として現れるのか}
}
\]

---

## 2. 基本閉鎖式

基本系を、

\[
\sum_{n=1}^{N} x_n(\tau)^2 = B(\tau)^2
\]

と読む。

ここで、

- \(x_n(\tau)\)：左辺を構成する各内部成分
- \(B(\tau)^2\)：保存量方向、あるいは \(\tau\) 発展方向に対応する閉鎖量

である。

この系が定常であり、時間または \(\tau\) 方向に振動していないなら、内部関係の動的な位相差は生じない。したがって、差異を保持する非線形応答は生まれず、ボゾン的状態しか生じない。

\[
\boxed{
\sum_n x_n^2=B^2\text{ の定常・非振動状態}
\Longrightarrow
\text{ボゾン的状態}
}
\]

---

## 3. A側の合成波と交差項

左辺成分の合成波を、

\[
A(\tau)=\sum_{n=1}^{N}x_n(\tau)
\]

と置く。

この二乗は、

\[
A(\tau)^2
=
\left(\sum_{n=1}^{N}x_n\right)^2
=
\sum_{n=1}^{N}x_n^2
+
2\sum_{m<n}x_mx_n
\]

である。

閉鎖式 \(\sum_nx_n^2=B^2\) を用いると、

\[
\boxed{
A^2=B^2+2C
}
\]

ただし、

\[
\boxed{
C(\tau)=\sum_{m<n}x_m(\tau)x_n(\tau)
}
\]

である。

この \(C\) は、

\[
M=\frac{N(N-1)}{2}
\]

個の交差項の総和である。

したがって、A側と保存量方向B側の差は、交差項によって生じる。

\[
\boxed{
A^2-B^2=2C
}
\]

---

## 4. 位相差の発生条件

A側とB側の相対位相を、

\[
\Delta\phi_{AB}
=
\arg A^2-
\arg B^2
\]

とすると、

\[
\Delta\phi_{AB}
=
\arg\left(B^2+2C\right)-\arg B^2
\]

である。

したがって、

\[
\boxed{
\Delta\phi_{AB}
=
\arg\left(1+\frac{2C}{B^2}\right)
}
\]

となる。

交差項が小さい場合には、

\[
\Delta\phi_{AB}
\approx
\operatorname{Im}\left(\frac{2C}{B^2}\right)
\]

であり、交差項総和のうち、保存量方向 \(B^2\) に直交する位相成分がA-B間の位相差を生む。

この位相差を直接読む量として、

\[
\boxed{
J(\tau)
=
\operatorname{Im}\left[
B(\tau)^{*2}
\sum_{m<n}x_m(\tau)x_n(\tau)
\right]
}
\]

を定義できる。

- \(J=0\)：A-B間に新たな位相方向が生じない
- \(J\neq0\)：A-B間に区別可能な位相差が生じる

---

## 5. 整数倍音と交差項の再閉鎖

各成分を、

\[
x_n(\tau)=A_n\cos(\omega_n\tau+\theta_n)
\]

とする。

二成分の積は、

\[
x_mx_n
=
\frac{A_mA_n}{2}
\left[
\cos\bigl((\omega_m-\omega_n)\tau+\Delta\theta_{mn}\bigr)
+
\cos\bigl((\omega_m+\omega_n)\tau+\Sigma\theta_{mn}\bigr)
\right]
\]

となる。

一般の周波数関係では、各交差項の位相は時間とともに分散し、長時間平均で相殺される。

しかし、保存量方向の基準振動 \(\omega_B\) に対して、

\[
\omega_n=k_n\omega_B,
\qquad
k_n\in\mathbb Z
\]

という整数倍音関係を満たす場合、差周波数と和周波数も同じ基底周期上で再閉鎖できる。

さらに位相関係まで周期的に元へ戻るなら、交差項は平均消去されず、同じ位相方向へ繰り返し加算される。

\[
\boxed{
\text{整数倍音関係}
+
\text{位相再閉鎖}
\Longrightarrow
\text{持続する交差相関網}
}
\]

---

## 6. ボゾン的状態

大部分の内部関係は、保存量方向に対して整数倍音閉包しない。

この場合も瞬間的な干渉項は存在し得るが、その位相は時間とともに巡回し、交差項総和は平均的に相殺される。

\[
\left\langle C(\tau)\right\rangle_T
\longrightarrow0
\]

したがって、A-B間の持続的な位相差は形成されず、区別可能な内部自己相関は残らない。

\[
\boxed{
\text{ボゾン的波}
=
\text{保存量方向に振動していても、}
\text{交差項が整数・位相閉包せず、}
\text{持続的な内部干渉として残らない波}
}
\]

定常・非振動の場合は、より直接にボゾン的である。

---

## 7. フェルミオン的状態

ごくまれに、複数の内部成分が保存量方向に対して整数倍音関係を持ち、かつ交差項の位相関係が再閉鎖する。

この場合、\(M=N(N-1)/2\) 個の交差項のうち一部がランダムに相殺されず、周期ごとに同じ相関構造を再構成する。

その結果、

\[
J(\tau)
=
\operatorname{Im}\left[B^{*2}C\right]
\neq0
\]

となり、保存量方向Bと内部合成波Aの間に持続的または循環的な位相差が形成される。

この位相差が、A/Bの区別可能性、すなわち選択変数 \(S\) の非零化へ写る。

\[
\Delta\phi_{AB}\neq0
\Longrightarrow
S\neq0
\]

そして非線形選択則、

\[
\Delta S
=
gS(1-S^2)
\]

が有効になる。

したがって、因果鎖は次のように整理できる。

\[
\boxed{
\begin{aligned}
\text{まれな整数倍音閉包}
&\longrightarrow
\text{交差項の位相同期}\\
&\longrightarrow
\text{持続するビート／自己相関}\\
&\longrightarrow
A\text{-}B\text{間の位相差}\\
&\longrightarrow
S\neq0\\
&\longrightarrow
\text{非線形選択}\\
&\longrightarrow
\text{フェルミオン的相互作用}
\end{aligned}
}
\]

---

## 8. なぜフェルミオン的構造は崩れにくいのか

非整数関係の交差項は、微小な位相ずれが時間とともに蓄積し、最終的に平均消去される。

一方、整数倍音かつ位相閉包した交差項は、周期的に同じ位相配置へ戻る。そのため、外乱や散乱によって一時的に乱れても、再び同じ相関構造へ再集合できる。

したがって安定性の起源は、単なる振幅の大きさではない。

\[
\boxed{
\text{フェルミオン的安定性の起源}
=
\text{交差相関網の位相再帰性}
}
\]

この再帰性によって、散乱後にも同じ内部構造が再構成され、観測上は同一性を持つ粒子的存在として現れる。

\[
\boxed{
\text{粒子としての同一性}
=
\text{散乱後にも再構成される閉じた交差相関網}
}
\]

---

## 9. 発生比率との接続

\(N\) 個の内部成分には、

\[
M=\frac{N(N-1)}2
\]

個の関係候補がある。

しかし、その大部分は保存量方向に対して整数倍音・位相閉包しないため、持続的な内部干渉を形成しない。

ごく少数の関係だけが、

- 整数倍音関係
- 位相再閉鎖
- 交差項の非相殺
- 散乱後の再構成

を同時に満たす。

したがって、フェルミオン的状態の発生比率がボゾン的状態より \(10^{-10}\) 程度低くなることは、この希少な閉包条件から合理的に説明できる。

ただし、低い発生比率そのものは本検討の中心ではない。中心は、希少な閉包構造が区別可能性と非線形相互作用を生む機構である。

---

## 10. 現段階の中心仮説

\[
\boxed{
\text{フェルミオンとは、}
\text{保存量方向との整数倍音・位相閉包によって}
\text{持続的な交差相関網を形成し、}
\text{散乱後にもその相関網を再構成する無名複合波である}
}
\]

対して、

\[
\boxed{
\text{ボゾンとは、}
\text{保存量方向に振動していても、}
\text{交差項が整数・位相閉包せず、}
\text{持続的な内部自己相関を形成しない無名波である}
}
\]

この区別により、

- \(\sum_nx_n^2=B^2\) の離散閉鎖
- \(M=N(N-1)/2\) 個の交差項
- 整数倍音候補
- A-B間の位相差
- \(S\) の発生
- `stability_gain` による非線形選択
- 散乱後の再構成
- フェルミオン的粒子としての観測

が、一つの因果構造として接続される。

---

## 11. 今後の数値検証で記録すべき量

今後の実験では、少なくとも次を時系列で記録する必要がある。

\[
B(\tau)^2
=
\sum_nx_n(\tau)^2
\]

\[
A(\tau)^2
=
\left(\sum_nx_n(\tau)\right)^2
\]

\[
C(\tau)
=
\sum_{m<n}x_m(\tau)x_n(\tau)
\]

\[
J(\tau)
=
\operatorname{Im}\left[B(\tau)^{*2}C(\tau)\right]
\]

\[
\Delta\phi_{AB}(\tau)
=
\arg A(\tau)^2-
\arg B(\tau)^2
\]

\[
S(\tau)
\]

\[
gS(1-S^2)
\]

さらに、各交差項 \(C_{mn}\) を、

- 非整数関係
- 整数倍音関係
- 奇数倍音関係
- 位相閉包関係
- 散乱後に再構成される関係

に分類し、どの関係群だけが \(J\neq0\) と \(S\neq0\) を持続的に生むかを検証する。

---

## 12. 現段階での位置づけ

本検討は、標準模型のフェルミオンを導出したと主張するものではない。

現段階で得られたのは、無名波の閉鎖系において、

\[
\boxed{
\text{整数倍音・位相閉包した交差相関網}
}
\]

が、

\[
\boxed{
\text{区別可能性、非線形選択、散乱後の再構成}
}
\]

を同時に生むフェルミオン的相互作用の有力な候補機構である、という作業仮説である。
