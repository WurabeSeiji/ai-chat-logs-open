## 2. 2 次元正方配列の積（行列の自乗）では答えにたどり着かない理由

【確かめた】数学的事実として、2 次元正方配列 $M$ の普通の行列積と自乗 $M \mapsto M^2$ には次の構造的限界がある。

1. **8×8 行列どうしの積では、2 つの八元数の積を表現できない**
   - 1 個の八元数 $x$ を左から掛ける操作 $L(x)$（8×8 行列）は作れ、行列×ベクトル $L(x)y = x \cdot y$ および同じ八元数の累乗 $L(x)^m = L(x^m)$ は一致する。
   - しかし、異なる 2 個の八元数 $x, y$ に対して $L(x)L(y) = L(x \cdot y)$ は成り立たない。普通の行列積は必ず結合的 $(AB)C = A(BC)$ であるのに対し、八元数は非結合的 $(xy)z \neq x(yz)$ だからである（サイズをいくつにしても不可能）。
2. **「元の番号（行）」と「成分の軸番号（列）」を暗黙に同一視している**
   - $(M^2)_{ij} = \sum_k M_{ik} M_{kj}$ は行番号と列番号を同じ添字 $k$ で縮約する。行の並べ替えだけで「止まる／回る」が劇的に変わるのは、元どうしの関係ではなく行番号と列番号の対応付けが動力学を決めているためである。
3. **固有空間が永久に固定され、結晶融解（相転移・自発的停止）が原理的に起きない**
   - 単一行列の自乗 $H \to H^2 \to H^4 \to \dots$ は、初期値 $H$ で固定された固有空間の上を倍々の歩幅で進むだけであり、欠陥を入れても別の準安定状態へ移る非線形な相転移を起こせない。
4. **縦横和 0 の初期値 $M = \begin{pmatrix} B & -B \\ -B & B \end{pmatrix}$ の特異性**
   - 自乗すると $M^2 = 2 \begin{pmatrix} B^2 & -B^2 \\ -B^2 & B^2 \end{pmatrix}$ となり、実質は半分の大きさの $B$ のコピーであって、残りの半分は固有値 0 として潰れている。

【木原】「つまりこの路線では、答えにたどり着かないです。使える可能性が僅かにあるのは、3 次元正方配列のような高次元正方配列における積構造ではないのかな？と期待しています。」

## 3. 三次元正方配列の積構造への転換

### 3.1 対象とする演算（Bhattacharya–Mesner 積：BM 積）

背景時空・外部時間・外部演算子 $U$ を置かず、有限な状態空間 $\mathcal{H}$ の関係そのものを自己更新する演算の候補として、3 次元正方配列 $T$（大きさ $N \times N \times N$）上の三項の積（BM 積）を第一の検証対象とする。

$$T'_{ijk} = \mathrm{Prod}(T, T, T)_{ijk} = \sum_{t=1}^{N} T_{itk}\, T_{ijt}\, T_{tjk}$$

（軸の並べ替えによる表現 $\sum_w T_{wjk} T_{iwk} T_{ijw}$ との関係や、双対な三項積の候補も必要に応じて照合する。）

### 3.2 2 次元行列積には無い強み【確かめた／読み】

- **本質的な非線形性**：3 次の写像であり、2 次元行列のような線形な固有空間分解に還元できない。高対称な不変部分空間（結晶）と、そこから外れる欠陥方向の成長（融解）を同時に持ちうる。
- **無名性と非結合性**：3 本の軸 $(i, j, k)$ が完全に対等であり、演算そのものが非結合的である（[三次元正方配列の積_勉強ノート.md §3.4](../../関連研究/三次元配列の積/三次元正方配列の積_勉強ノート.md)）。
- **状態と積の規則の統一**：複素数（$2^3$）・四元数（$4^3$）・八元数（$8^3$）の積表 $f_{abc}$ はすべて 3 次元正方配列であり、状態と積の規則が同じ器に乗る。

### 3.3 既知の壁と未確認の点

- **単純積の消滅**：$X_{ijk} = z_i z_j z_k$ は $\sum z^3 = 0$ のとき 1 回で 0 に消える（勉強ノート §3.3）。消えずに生き残る構造を見つける必要がある。
- **対角だけでは混ざらない**：交差項（対角の外）が最初から必要である。
- **大きさの成長**：割り算・正規化を入れないため、0 にならない成分は 1 ステップで 3 乗の速さで大きくなる。比・向き・指数部で読む工夫が要る。
- **【未確認】自発的停止と溶け残り**：欠陥を入れたときに結晶が崩れ、ある割合で自発的に停止して溶け残り（粒子）ができるかは完全に未知である。

## 4. 自己無撞着の捉え方と検算の物差し（固定点）

### 4.1 乱数ではなく解析的手法を使う

【木原】「これを乱数を使って当てものゲームしても自己無撞着になる確率はほぼゼロだと思われるので、解析的手法で、形を保って戻る（自己無撞着な結晶になる）初期値を探そうとしています。」

### 4.2 $U^n = I$ を「点に戻る」ことに狭めない

【木原】「$U^n = I$ をシンプルに元の形に戻ると解釈すると誤りますよ。位相が回り続けていても、自己無撞着ではあります。いつか元に戻るかもしれない $n = \infty$ と、自己無撞着でないは極めて区別が難しいです。」

- 固定点（$T' = \lambda T$）や短い有限周期解だけでなく、**位相が無理数倍で回り続けて点としては二度と戻らない準周期軌道（閉じた軌道・トーラス）**も自己無撞着に含まれる（[木原理論の公理系.md 第 1 定義](../../関連研究/Chandrasekaran_Venkatesa/木原理論との比較/木原理論の公理系.md)）。
- 準周期（$n = \infty$ の自己無撞着）と非・自己無撞着（カオス・崩壊）を解析的に切り分ける視点：
  - 共通のスケールを除いた向き・比の空間で、**不変部分空間（閉じた面・保存量）**が存在するか。
  - 面内の最大リャプノフ指数が $\le 0$（準周期・秩序の維持）か、$> 0$（カオス・崩壊）か。
  - インフレーションの種となる結晶は、「面内では安定または準周期（$\le 0$）だが、面の外（欠陥方向）に不安定性（$> 0$）を持つ状態」として特徴づけられる【読み】。

### 4.3 検算の物差しとしての $\sum z_n^2 = 0$

【木原】「$\sum z_n^2 = 0$ はこれまでの経験で、多くの場合、検算に使いやすいです。過去の実験ではとくに拘束しなくても結果 0 になることが分かっていますよ。」

- 公理系・第 2 定義のとおり、$\sum z_n^2 = 0$ は外から強制する拘束条件ではなく、**自己無撞着な準安定状態かどうかを確認する「結果としての検算」**に使う。

## 5. 解析と検証のロードマップ（順序：Step 1 → Step 2 → Step 3）

### Step 1：既知の積表（複素数 $2^3$・四元数 $4^3$・八元数 $8^3$）の厳密確認

- 成分が $\{0, +1, -1\}$ の整数である積表 $f_{abc}$ そのものに対し、BM 積（および軸の並べ替え版）を割り算なし・浮動小数なしの厳密整数計算で適用する。
- 確認項目：0 に潰れるか、形を保って戻るか、準周期的に回るか、$\sum z_n^2 = 0$ が成り立つか。

### Step 2：完全無名（$S_N$ 不変）な不変部分空間の解析

第 0 公理（全要素の入れ替えに対して不変）を課した不変部分空間は、$N$ に依らず少数の変数に厳密に縮約される。

- **3 軸対称な 3 変数 $(a, b, c)$**（$a = T_{iii}$、$b = T_{iij} = T_{iji} = T_{jii}$、$c = T_{ijk}$）：
  $$\begin{aligned}
  a' &= a^3 + (N-1)\,b^3 \\
  b' &= b\bigl(a b + b^2 + (N-2)\,c^2\bigr) \\
  c' &= c\bigl(3 b^2 + (N-3)\,c^2\bigr)
  \end{aligned}$$
  【確かめた】固定点条件 $a' = \lambda a,\; b' = \lambda b,\; c' = \lambda c$（$b \neq 0, c \neq 0$）は、$u = c^2/b^2$ とおくと $(u - 1)^2 (u - (N + 1)) = 0$ と厳密に因数分解でき、
  - $a = b = 1,\; c = -1$（$\pm 1$ だけの結晶解、$\lambda = N$）
  - $a = -(N - 1),\; b = 1,\; c = \pm\sqrt{N + 1}$（非自明解、$\lambda = N(N - 2)$）
  が得られる。
- **調べること**：
  1. 3 変数・および $R_1, R_2, R_3$（2 つ一致の 3 通り）を区別した **5 変数 $(a, b_1, b_2, b_3, c)$** の縮約方程式を導く。
  2. 実数だけでなく**複素数**（位相を持つ成分）に広げ、固定点だけでなく**準周期軌道（回り続ける自己無撞着）**が存在するか、また $\sum z_n^2 = 0$ が結果として現れるかを解析する。

### Step 3：巡回対称・群不変（$T_{i+g, j+g, k+g} = T_{ijk}$）な縮約方程式の解析

完全無名から一段だけ対称性を緩め、有限群 $G$ に対する並進不変性を課すと、$F(u, v) = T_{0, u, v}$ として 2 次元上の閉じた方程式になる。

$$F'(u, v) = \sum_{s \in G} F(s, v)\, F(u, s)\, F(u - s, v - s)$$

距離（差 $u, v$）と位相の回転が入るこの枠組みで、準周期軌道と $\sum z_n^2 = 0$ の準安定解を解析的に探す（本命）。

### 7.2 理由と評価【確かめた】

- 対角成分 $(i,i,i)$ では $t = 0$（単位元）の項だけが残り、$f_{i0i} f_{ii0} f_{0ii} = f_{ii0}$ となるため、$i=0$ で $+1$、$i \ge 1$ で $e_i^2 = -1$ の符号そのままの $-1$ が出る。非対角はすべて 0 になる。

- ただし、1 回で非対角（交差項）がすべて消えてしまうため、積表 $f_{abc}$ そのものを初期値とした場合は、2 ステップ目以降に要素どうしが混ざり合うダイナミクスは残らない。

## 8. Step 2 結果：完全無名 ($S_N$ 不変) な 3 変数・5 変数縮約方程式の解析（2026-11-27）

- プログラム：[bm_product_sn_invariant_v0.py](bm_product_sn_invariant_v0.py)
- 結果：[results/bm_product_sn_invariant_v0.txt](results/bm_product_sn_invariant_v0.txt)

### 8.1 5 変数縮約方程式の導出と検算【確かめた】

5 つの同値類 $a = T_{iii}$、$b_1 = T_{jii}$、$b_2 = T_{iji}$、$b_3 = T_{iij}$、$c = T_{ijk}$（$i, j, k$ すべて異なる）に対する BM 積の厳密な縮約方程式は次のとおり。

$$\begin{aligned}
a' &= a^3 + (N - 1)\, b_1 b_2 b_3 \\
b_1' &= a\, b_1^2 + b_1 b_2 b_3 + (N - 2)\, b_1 c^2 \\
b_2' &= a\, b_2^2 + b_1 b_2 b_3 + (N - 2)\, b_2 c^2 \\
b_3' &= a\, b_3^2 + b_1 b_2 b_3 + (N - 2)\, b_3 c^2 \\
c' &= c\bigl(b_1 b_2 + b_2 b_3 + b_3 b_1 + (N - 3)\, c^2\bigr)
\end{aligned}$$

$N = 4, 5, 6$ の全成分 BM 積と 1 成分残らず厳密一致することを整数計算で検算した。

### 8.2 3 変数（3 軸対称：$b_1 = b_2 = b_3 = b$）の結果【確かめた】

- 固定点は (A) $c = 0$（$x^3 - x^2 - x + N - 1 = 0$ の 3 根）、(B) $a = b = \pm c$（倍率 $N$）、(C) $a = -(N-1)b,\; c = \pm\sqrt{N+1}\,b$（倍率 $N(N-2)$）ですべてである。
- 固定点の線形安定性（比座標 $x=a/b, y=c/b$ のヤコビアン固有値）：
  - (B) は固有値 $(1, 0)$（中立 1 方向＋超安定 1 方向）。
  - (C) は実の鞍点（$N=8$ で不安定方向 $> 3$、安定方向 $< 1$）。
  - (A) の実根・複素共役根はすべて $|\lambda| > 1$ の不安定方向を持つ。
- **$\sum T_{ijk}^2 = 0$ を満たす固定点は 3 変数（3 軸対称）では存在しない**（(B)(C) はすべて正、(A) も非ゼロ）。

### 8.3 5 変数（3 軸非対称：$b_1, b_2, b_3$ を区別）で見つかった構造【確かめた】

3 軸のうち 1 方向と対角が 0 の部分空間（$a = 0,\; b_1 = 0$）は BM 積のもとで厳密に不変であり、方程式は次へ落ちる。

$$b_2' = (N - 2)\, b_2 c^2, \qquad b_3' = (N - 2)\, b_3 c^2, \qquad c' = c\bigl(b_2 b_3 + (N - 3)\, c^2\bigr)$$

- **保存量**：比 $b_2 / b_3$ が厳密に保存される。
- **連続族の安定固定点**：比 $z = (b_2 b_3)/c^2$ は $z' = (N-2)^2 z / (z + N - 3)^2$ に従い、$z_0 = 1$（すなわち $b_2 b_3 = c^2$、倍率 $N - 2$）は任意の $N \ge 4$ で安定（$|dz'/dz| = \frac{N-4}{N-2} < 1$、特に $N = 4$ で超安定 $0$）。
- **$\sum T_{ijk}^2 = 0$ を厳密に満たす固定点が存在する**：
  - 条件 $b_2 b_3 = c^2$ と $\sum T^2 = N(N-1)(b_2^2 + b_3^2 + (N-2)c^2) = 0$ を連立させると、$u = (b_2/c)^2$ が $u^2 + (N-2)u + 1 = 0$ の負の実根となり、**任意の $N \ge 4$ で純虚数の厳密解**が存在する。
  - とくに **$N = 4$ では $a = 0,\; b_1 = 0,\; b_2 = +i,\; b_3 = -i,\; c = 1$**（成分が $\{0, +1, +i, -i\}$ のみ、倍率 $\lambda = 2$、$\sum T^2 = 0$、面内で超安定）となる。

### 8.4 現時点の整理と次のステップ【読み】

- Step 1・Step 2 により、BM 積が「対角（計量符号）への射影」や「$a=0, b_1=0$ 上での $\sum T^2 = 0$ 厳密固定点（特に $N=4$ の $\{0, 1, \pm i\}$ 解）」を持つことが確認できた。
- 一方、**位相が回り続ける準周期軌道（$n = \infty$ の自己無撞着）**は、完全無名（$S_N$ 不変）の固定点解析の範囲ではまだ出ていない。
- 次の Step 3 として、**巡回対称（並進不変 $T_{i+g, j+g, k+g} = T_{ijk}$）の 2 次元縮約方程式 $F(u, v)$** に進み、位相回転・準周期軌道・$\sum z_n^2 = 0$ の有無を調べる。

## 10. Step 3 結果：巡回対称（並進不変）2 次元縮約方程式 $F(u, v)$ の解析的パターン探索（2026-11-27）

### 10.1 見つけた厳密な周期結晶族（$U^n = I$ かつ $\sum T^2 = 0$）【確かめた】

$N = 5$ において、反対称な平面波の差
$$F(u, v) = \omega^{a u + b v} - \omega^{a v + b u} \qquad (\omega = e^{2\pi i / N})$$

- **解析的理由【読み・要厳密証明】**：BM 積は 3 次の写像であるため、巡回群 $\mathbb{Z}_N$ 上の波数 $(a, b)$ が 1 ステップで $(3a, 3b) \pmod N$ へ移る。$N = 5$ では $3^4 \equiv 1 \pmod 5$（位数 4）であるため 4 ステップで厳密に元に戻る。一般の $N$（3 と互いに素）では、3 の位数 $\mathrm{ord}_N(3)$ によって任意の長い周期 $U^n = I$ が構成できる可能性がある。

### 10.2 その他の観察と未確認点

- $N = 4, 8$ の 2 次位相 $\omega^{p u^2 + q v^2 + r u v}$ や $N = 8$ の反対称波で、40〜60 ステップ以内に厳密に戻らない `non_periodic` 軌道が複数現れた。
- ただし、2 次位相の `non_periodic`（`min_rec ~ 5e-4`）は固定点への遅い収束の途中である可能性が高く、$N = 8$ 反対称波（`min_rec ~ 0.15, 0.34`）が準周期かカオスかも 60 ステップでは判定できない【未確認】。

### 12.2 反対称波の厳密解析定理【確かめた】

任意の $N$ と $a \not\equiv b \pmod N$ に対し、巡回反対称平面波
$$F_{a,b}(u, v) = \omega^{a u + b v} - \omega^{a v + b u} \qquad (\omega = e^{2\pi i / N})$$
の縮約 BM 積を展開すると、$s$ の和が 0 にならない 4 項のうち 2 項が相殺し、厳密に次が成り立つ。

$$\mathrm{Prod}(F_{a,b}) = N\, F_{2a, 2b}$$

- **奇数 $N$**：2 と互いに素であるため、厳密な周期 $n = \mathrm{ord}_N(2)$（またはその約数）で元に戻る自己無撞着軌道 $U^n = I$ になる。$N = 3, 5, 7, 9, 11, 13$ について、定理誤差 $10^{-15} \sim 10^{-14}$、周期戻り誤差 $10^{-15} \sim 10^{-10}$ で検算合格（周期は順に $2, 4, 3, 6, 10, 12$）。
- **$\sum T_{ijk}^2 = 0$**：$N \ge 5$ の奇数（$a=1, b=2$）では全ステップで $|\sum F^2| / \sum |F|^2 \sim 10^{-17} \sim 10^{-16}$（厳密に 0）を満たす。
- **2 の冪の $N$（$N = 4, 8, \dots$）**：毎回波数が 2 倍されるため、高々 $\log_2 N$ ステップで $(2^k a, 2^k b) \equiv (0, 0) \pmod N$ となり厳密に 0 へ消滅する。

## 17. 8 マス溶け残りの解析的解明：厳密方程式・保存量・3 倍角回転・外部遮断（2026-11-28）

- プログラム：[tri_loop_8cell_analysis_v0.py](tri_loop_8cell_analysis_v0.py)
- 結果：[results/tri_loop_8cell_analysis_v0.txt](results/tri_loop_8cell_analysis_v0.txt)

### 17.1 解析定理【確かめた】

2 つの 2 要素集合 $I = \{i_0, i_1\}$ と $J = \{j_0, j_1\}$ の上で、各 $j \in J$ の 2×2 スライス $M_j = T[I, j, I]$ が複素回転行列 $\begin{pmatrix} a_j & b_j \\ -b_j & a_j \end{pmatrix} \leftrightarrow z_j = a_j + i b_j$ であり、それ以外の全成分が 0 のとき、三角形ループ積 $\mathrm{Tri}(T)$ はこの 8 マス部分空間を厳密に保ち（検算誤差 $1.39 \times 10^{-17}$、8 マス外は厳密に 0）、次の方程式に従う。

$$M_j' = \bigl(M_{j_0}^2 + M_{j_1}^2\bigr)\, M_j \quad \Longleftrightarrow \quad z_j' = \bigl(z_0^2 + z_1^2\bigr)\, z_j \qquad (j = 0, 1)$$

### 17.2 この方程式から導かれる性質と実測検算【確かめた】

1. **内部保存量（不変量）**：比 $z_1 / z_0$（すなわち振幅比 $r_1 / r_0$ と位相差 $\Delta = \theta_1 - \theta_0$）が厳密に保存される。八元数 `(0,1,0)+ε` の溶け残り（$I = \{6,7\},\; J = \{0,1\}$）では、step 500〜508 で 2×2 回転行列の誤差が $10^{-14}$ 台、位相差 $\Delta = -0.124^\circ$ が一定、ノルム比 $\|P\| = 0.49999894$ が 8 桁一定であった。
2. **共通位相の 3 倍角写像**：共通位相 $\theta_n = \arg(z_0)$ は、定数シフト $\delta = \arg(r_0^2 + r_1^2 e^{2i\Delta})$ を伴う 3 倍角写像
   $$\theta_{n+1} = 3\theta_n + \delta \pmod{2\pi}$$
   に従う（八元数で $\delta = -0.0858^\circ$ が毎ステップ一致）。
   - 軌道自体は厳密な円周 $S^1$ の上から一歩も外れないが、角度方向の 1 ステップ伸び率は厳密に **3.0000**（リャプノフ指数 $\ln 3 \approx 1.0986 > 0$）であり、数学的には $S^1$ 上の決定論的カオス回転（有理数角のときのみ厳密な有限周期 $U^m = I$）である。
3. **外部摂動に対する堅牢性（粒子としての安定性）**：
   - 8 マスの**外**（残り 504 マス）への微小摂動 $10^{-6}$ を与えたところ、**完全外部および 1 軸共有の位置では 1 ステップで厳密に $0$ へ消滅（完全遮断）**、**2 軸共有の位置では step 1〜10 で全く成長しない（中立安定）**ことが確かめられた。
   - すなわち、八元数結晶（64 マス）の崩壊後に残ったこの 8 マス溶け残りは、**外からの摂動で壊れず、内部の比 $z_1/z_0$ を保存量として保持しながら $S^1$ 上を回り続ける安定した塊**である。
