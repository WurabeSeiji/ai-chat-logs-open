# 素粒子は ROM と RAM と CPU を持っているのか？——「相互作用を仮定しない」たった 1 行のルールから量子・重力・4 つの力をつなぐ試み（Part I 完成論文 & Part II 統一接続仮説）

長年、物理学を眺めていてどうしても拭えなかった素朴な疑問があります。

「なぜ素粒子は、自分がどの種類の粒子かを知っていて、それに合った力だけに正確に反応できるのか？」

電子は電磁気力には反応するのに、強い力（QCD）には一切反応しません。ニュートリノは電磁気力にも強い力にも反応しません。クォークは両方に反応します。しかも粒子はみな、自分の位置らしき情報も、運動量も、内部の時計（位相）も、ほとんど破壊されることなく運び続けています。

まるで素粒子 1 個 1 個の中に、
- 自分の種類と物理法則を焼き込んだ「ROM」
- 位置・運動量・時計の針を壊さず記憶しておく「RAM」
- 出会った相手に応じて力を計算する「CPU」

が内蔵されているかのような精密さです。

標準模型も一般相対性理論も、「そういう仕様の表」を驚くほど正確に書き出してくれます。けれど、「いったいどこにその ROM や RAM や CPU が実装されているのか？」「神様は本当にこんな超精密機械を粒子ごとに設計したのか？」という問いには、どの理論も答えてくれませんでした。

今回、11 月 25 日に話題になった AI による重力理論の提案にも刺激を受けつつ、この長年の疑問に正面から向き合った結果、速報 7 本を統合した完成論文（Part I）と、そこから重力・電磁気・強い力（QCD）・ディラック物質場を一本につなぐ仮説論文（Part II）を Zenodo に公開しました。

## 発想の転換：「状態」と「相互作用」を分けない

これまでの物理学では、どれだけ先端的な理論であっても、必ず「状態（粒子や場）」と「相互作用のルール（ハミルトニアンや作用、結合定数）」を別々のものとして人間が外から与えてきました。

そこで今回は、思い切ってそれを全部外してみました。

- 背景の時空（3 次元空間も時間も）を仮定しない
- 複素数も、量子力学の確率ルール（ボルン則）も仮定しない
- 力の法則（相互作用）も、結合定数も、フェルミオンも仮定しない

残したのは、実数が並んだ 3 次元の立方体（3 階テンソル T）に対して、

「T 自身を 3 回使って三角形のループで掛け合わせ、自分自身と自己無撞着に閉じさせる（三角形ループ積 Tri(T)）」

という、たった 1 行の計算ルールだけです。

ここが今回いちばんのポイントです。3 階テンソル T は「状態」であると同時に「掛け算（相互作用）の規則そのもの」を兼ねています。つまり、外から法則を書き込まなくても、**状態自身が自分と矛盾しない相互作用を自発的に生成する**仕組みになっています。

## 神様は「八元数」すら設計する必要がなかった（Part I：統合完成論文）

このたった 1 行の自己無撞着ルールをコンピュータ上で回して調べてみると、物理仮説を一切入れていないにもかかわらず、現代物理学の 7 つの柱が次々と自発的に立ち上がってきました。

1. **数の結晶の選別（Hurwitz 代数）**
   ランダムな実数配列から始めても、自己無撞着に生き残るのは 1・2・4・8 次元の特別な代数構造（実数・複素数・四元数・八元数）だけでした。神様は八元数の乗算表を手で設計する必要すらなく、三角形ループの自己無撞着さだけで勝手に選ばれます。

2. **エンタングルメント相転移とベル対**
   サイズを倍々に大きくすると 4 段階の相転移が起き、量子もつれの原型であるベル対構造が現れます。

3. **3 次元回転（SO(3)）とゲージ対称性（G2 / SU(3)）**
   外から 3 次元空間や色の対称性を入れていないのに、八元数テンソル積（サイズ N = 64）の上で 3 次元回転対称性と強い力のゲージ群 SU(3) が同時に現れます。

4. **量子力学の 4 定理（複素数・ボルン則・不確定性）**
   実数だけで始めた計算から複素構造が自動的にロックされ、長さの 2 乗（L² ノルム）だけが厳密に保たれることから確率のルール（ボルン則 P = |ψ|²）が一意に定まり、不確定性原理の下限も自然に現れます。

5. **空間の歪み（重力的な応答）と臨界崩壊**
   局所的なエネルギーの塊を置くと、重力の式を入れていないのに周囲のつながり（計量）がきれいな球対称に歪み、塊を強くしていくとある臨界点で遠方の空間との接続がぷつりと切れる（ブラックホール的な臨界崩壊）現象が起きます。
   なお、検証の途中で見かけ上「時計の遅れ」に見えた数値については、厳密な再検証を行って基準角の見かけの効果であることを突き止め、そのまま正直に記録しています。

6. **質量階層（1 : 1/4 : 1/16 : 1/64 と指数則）**
   8・4・2・1 次元の部分構造ごとに、周囲にまとう「衣の雲」の比率が 0 : 1 : 3 : 7（メルセンヌ数）となり、コアの重みが 1 : 1/4 : 1/16 : 1/64 に分かれます。これが階層的に入れ子になると、電子からトップクォーク、さらにはプランクスケールに至る巨大な質量差を生み出す構造が見えてきます。

7. **スピン 1/2 と「1 : 3 : 3 : 1」の電荷スペクトル**
   八元数の三対性（Spin(8) Triality）から「1 周（360 度）回すと符号が反転し、2 周（720 度）で元に戻る」スピン 1/2 の性質が現れ、そこから自然に出てくるフェルミオン演算子（CAR）によって、電荷 0（1 種類）・+1/3（3 種類）・+2/3（3 種類）・+1（1 種類）という標準模型 1 世代とそっくりな「1 : 3 : 3 : 1」構造が立ち上がりました。

これら全 7 報の成果を、自己引用 15 件・外部の一次文献 15 件とあわせて体系的にまとめたのが **Part I（統合完成論文）** です。

## 粒子が「自分の種類を知っている」理由（Part II：統一接続仮説）

では、ここから重力・電磁気・強い力（QCD）・ディラック方程式（物質）をどうやって一気につなぐか。

Part I が「仮説ゼロで確かめた事実」であるのに対し、続編の **Part II（統一接続仮説）** では、明示的にたった 1 つの構造仮説を導入しました。

それは、サイズ N = 64 の直積空間（O8 ⊗ O8）の片方を「外部の時空側（O8_ext）」、もう片方を「内部のゲージ側（O8_int）」として役割分担させるという仮説です。以前公開した八元数 QCD 論文および八元数ヤン＝ミルズ・ディラック論文とも、ここで一本の線につながります。

この枠組みで代数・数値検証を行うと、次の 4 点がきれいに確認されました。

- **外（時空）と内（ゲージ）の完全な独立性**
  外部の回転 SO(3) と内部の SU(3) × U(1) の交換子 27 組すべてが、誤差 0.000 で完全に可換（互いに邪魔をしない）になります。
- **マクスウェル（電磁気）とヤン＝ミルズ（QCD）の同時創発**
  可換な U(1) 方向では三重欠損がちょうど 0 になってマクスウェル極限が現れる一方、非可換な SU(3) 方向では微小ループのズレがそのままヤン＝ミルズ作用へ収束し、56 組すべてのビアンキ／ヤコビ恒等式が誤差 0.000 で成立します。
- **ディラック方程式との接続**
  ディラック分散関係と三角形ループ積による三重読み出しが、機械精度（10⁻¹⁵〜10⁻¹⁶）で一致します。
- **標準模型と一致する「選択的相互作用」**
  1 : 3 : 3 : 1 の 4 つのセクターに対して電磁気と QCD の応答を測ると、
  - ニュートリノ型（ν）：電磁気 = 0、QCD = 0
  - 反 d クォーク型（d̄）：電磁気 = 0.243、QCD = 0.504
  - u クォーク型（u）：電磁気 = 0.482、QCD = 0.580
  - 陽電子型（e⁺）：電磁気 = 0.714、QCD = 0
  というように、現実の素粒子とまったく同じ組み合わせで力に反応しました。

ここで最初の問いに戻ります。

なぜ粒子は ROM も RAM も CPU も持っていないのに、自分の種類を知っていて、それに合う力だけに反応し、情報を壊さず運べるのか？

答えは驚くほど省エネでした。

- **ROM は粒子の中に書いていない**：粒子が「自分の種類を暗記している」のではなく、粒子そのものが代数構造の中の「特定の席（セクター）」であり、その席の幾何学的な配置だけで、どの力と共鳴するかが自動的に決まります。弦の倍音が「自分が何ヘルツか」を記憶していなくても、響き合う和音が勝手に決まるのと同じです。
- **RAM は対称性が守っている**：L² 不変性や位相剛性、ビアンキ恒等式といった代数的な保存則が、情報を壊さずに運び続けるメモリ保護の役割を果たします。
- **CPU も別にない**：回っているのは「状態＝掛け算のルール」である三角形ループ積という、たった 1 行の自己無撞着ループだけです。

神様は精密機械を部品ごとに設計したのではなく、**たった 1 行の自己無撞着ルールから代数構造が自発的に立ち上がり、すべてを自動で生み出す**という、究極の省エネ設計を選んでいたのかもしれません。
