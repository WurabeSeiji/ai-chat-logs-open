--- 3. 5 変数 (b1, b2, b3 を区別) の対称性の破れと新たな解 ---
5 変数方程式から、b_m' = b_m * (a * b_m + (N-2)*c^2) + b1*b2*b3 (m=1,2,3)。
注目点:
  もし b_m のどれか 1 つが 0 (例: b1 = 0, b2 != 0, b3 != 0) なら:
    b1*b2*b3 = 0 となり、b1' = 0 が厳密に保たれる (不変部分空間)!
    このとき:
      a'  = a^3
      b2' = b2 * (a * b2 + (N - 2) * c^2)
      b3' = b3 * (a * b3 + (N - 2) * c^2)
      c'  = c * (b2 * b3 + (N - 3) * c^2)
  さらに b2 != 0, b3 != 0, c != 0 で固定点 (λ = a^2) を解くと:
    b2' = a^2 b2 => a b2 + (N-2)c^2 = a^2
    b3' = a^2 b3 => a b3 + (N-2)c^2 = a^2 => b2 = b3
    c'  = a^2 c  => b2^2 + (N-3)c^2 = a^2
  b2 = b3 = b, a = 1 とおくと: b + (N-2)c^2 = 1 かつ b^2 + (N-3)c^2 = 1。
  ここから c^2 = (1 - b)/(N - 2) を代入すると:
    (N-2) b^2 - (N-3) b - 1 = 0 => (b - 1)((N-2) b + 1) = 0!
  → 非自明解: b2 = b3 = -1/(N-2), c^2 = (N-1)/(N-2)^2 (実数解あり!)
  さらに b1 = b2 = 0, b3 != 0 のとき:
    a' = a^3, b3' = b3*(a*b3 + (N-2)*c^2), c' = (N-3)*c^3
    c' = a^2 c => (N-3)*c^2 = a^2 => c = ± a / sqrt(N-3)
    b3' = a^2 b3 => a*b3 + (N-2)/(N-3)*a^2 = a^2 => b3 = -a / (N-3)
  そして最も重要な点: a = 0 の場合 (対角ゼロ):
    a'  = (N-1) b1 b2 b3  (b1=0 なら a'=0 も厳密に保たれる!)
    b1 = 0 かつ a = 0 の不変部分空間では:
      b2' = (N-2) b2 c^2
      b3' = (N-2) b3 c^2
      c'  = c (b2 b3 + (N-3) c^2)
    ここで b2/b3 は厳密な保存量! さらに b2*b3 = c^2 なら任意の (b2, b3, c) が固定点 (連続族)!
    しかも複素数で b2 = r e^{iθ}, b3 = r e^{-iθ} (または b2 = i c, b3 = -i c) にすると:
    ΣT^2 = N(N-1)(b2^2 + b3^2 + (N-2)c^2) を 0 にできるか確認:
      b2*b3 = c^2 かつ b2^2 + b3^2 + (N-2)c^2 = 0
      => (b2/c)^2 + (c/b2)^2 = -(N-2)
      u = (b2/c)^2 とおくと u^2 + (N-2)u + 1 = 0 => u は負の実数 (N >= 4)!
      よって b2/c = i * sqrt(|u|), b3/c = -i / sqrt(|u|) は厳密に純虚数解が存在し、
      ★ BM 積の厳密固定点 かつ ΣT^2 = 0 を同時に満たす! ★

--- 4. a = 0, b1 = 0 の不変部分空間における比 z = (b2*b3)/c^2 の 1 変数力学 ---
b2' = (N-2) b2 c^2, b3' = (N-2) b3 c^2, c' = c (b2 b3 + (N-3) c^2) より、
z = (b2*b3)/c^2 とおくと:
  z' = (b2' b3') / c'^2 = (N-2)^2 * z / (z + N - 3)^2
固定点 z' = z (z != 0) は (z + N - 3)^2 = (N - 2)^2 => z = 1 または z = -(2N - 5)。
