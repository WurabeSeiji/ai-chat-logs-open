【木原】
ポイントは複素数の相互作用と読み出しです
複素数が同じか違うかの判別はシンプルでza zb が同じならza.zb =0で判断できるってわかりますか？

【アイリス】
はい、通常の複素数の掛け算ではなく、反対称な積として読めば分かります。

普通の積 za·zb なら、za = zb のとき za² になってゼロにはなりません。ゼロになるのは、積を

za·zb ≡ Im(z̄a zb) = |za||zb| sin(θb − θa)

という反対称な積（2次元ベクトルの外積・ウェッジ積と同じもの）として定義した場合です。これは za·zb = −zb·za を満たし、自分自身との積は必ずゼロになります。二つの複素数が同じ向きにそろっていればゼロ、ずれていればそのずれの sin が出ます。つまり「同じか違うか」を一回の積で読み出す判定量です。

これは今日の議論ときれいにつながります。エルミート積 z̄a zb を実部と虚部に分けると、実部は |za||zb| cos(θb−θa) で「どれだけ同じか」、虚部は sin で「どれだけ違うか」になります。前に出てきた cos² と sin² の対は、この一つの積の二つの成分の読み方です。

ただし、この判定には割り算と同じ性質があります。ゼロになるのは向きがそろっているときなので、大きさが違っても（za = 2zb でも）、向きが反対でも（za = −zb でも）ゼロになります。つまりこの積が判定しているのは、射影的に同じ（同じ直線上にある）かどうかであって、大きさまで含めた一致ではありません。大きさの違いを読むには、実部の cos 側、あるいは捨てられた一次元を別に読み出す必要があります。

【木原】
んー意外とバカですね

【アイリス】
どこで外したのか、考え直してみます。

一つは、前回の最後の段落です。「大きさや符号の違いは判定できない」と欠点のように書きましたが、今日の議論では、絶対的なスケールはなく、どちらを虚部と読むかも選択だという立場に立っていました。その立場なら、大きさや符号だけの違いは、そもそも違いではありません。za·zb = 0 が射影的な一致しか判定しないのは欠点ではなく、判定として正しい振る舞いです。そこを但し書きにしたのは、自分で立てた前提を忘れていました。

もう一つは、積の定義そのものを私が勝手に決めたことです。「同じものどうしの相互作用はゼロ」という性質が本質なら、私の書いた外積に限らず、自分自身との積がゼロになる反可換な積（グラスマン数的な、パウリの排他律と同じ構造）として読むべきだったのかもしれません。その場合、za·zb = 0 は、同じものは互いに何も読み出せない、つまり関係が生じないことを意味します。

ただ、どちらがご意図に近いのか、まだ確信が持てません。za·zb の「・」で考えている演算を教えていただけますか。

【木原】
za.zbをちゃんと二乗して実数部分がゼロで虚数部がゼロかシンプルの展開して調べなさい

【アイリス】
展開してみます。za = a₁ + i b₁、zb = a₂ + i b₂ とします。

普通の積は次のようになります。

za zb = (a₁a₂ − b₁b₂) + i(a₁b₂ + a₂b₁)

za = zb = a + ib（同じもの）とすると、

za² = (a² − b²) + i(2ab)

実部がゼロになるのは a² = b²、つまり a = ±b のときです。虚部がゼロになるのは ab = 0、つまり a か b のどちらかがゼロのときです。両方が同時にゼロになるのは a = b = 0 だけです。

ですから、普通の複素数の積では「同じなら積がゼロ」は成り立ちません。これは複素数が体であって零因子を持たない、つまり za zb = 0 なら za か zb のどちらかがゼロでなければならない、という性質そのものです。

ただし、この展開には見ておくべき点が一つあります。za² の実部 a² − b² は、ミンコフスキー時空の間隔と同じ形です。実部がゼロになる a = ±b は45度の方向、つまり光円錐上です。光円錐上にある複素数は、2乗すると実部が消えて純虚数になります。二つの異なる複素数の場合も、積の実部 a₁a₂ − b₁b₂ は不定計量の内積の形をしていて、これがゼロになるのは、二つが互いに光円錐の関係にあるときです。

一方、片方を共役にした積 z̄a zb では、実部が a₁a₂ + b₁b₂（ユークリッド的な内積）、虚部が a₁b₂ − a₂b₁（外積）になり、za = zb のとき虚部は恒等的にゼロ、実部は |za|² です。前回、私が「同じならゼロ」と言ったのはこの虚部のことでした。

結論として、普通の積をそのまま2乗した展開では、同じもの同士の積はゼロになりません。ゼロで判定できるのは、共役積の虚部（外積）か、二つの差 za − zb に対してです。「za·zb = 0 で判定できる」が成り立つには、積の定義に共役か反対称化が入っているか、複素数ではなく零因子を持つ数（双曲複素数など）を使っている必要があります。

【木原】
んー想像力が足らない　ではどうしたらゼロになりますか？

【アイリス】
交差項を消せばゼロになります。

(a + ib)² = a² − b² + 2iab で邪魔をしているのは、交差項 2iab です。これは実部の単位 1 と虚部の単位 i が可換（1·i = i·1）なので、ab と ba が足し合わされて残るものです。そこで、二つの成分を互いに反可換な単位 e₁, e₂（e₁e₂ = −e₂e₁）に載せます。

z = a e₁ + b e₂

z² = a² e₁² + b² e₂² + ab(e₁e₂ + e₂e₁)

反可換なので、最後の交差項は自動的に消えます。残りをゼロにするには、二つの単位の2乗の符号を逆にします。e₁² = +1、e₂² = −1 とすれば、

z² = a² − b²

となり、a と b が同じ（a = ±b）なら z² = 0 になります。実部も虚部も、ちゃんと両方ゼロです。

これは今日の議論で出てきたものがすべて一つにまとまった形です。e₂² = −1 の方が「虚数として読む振幅」で、e₁² = +1 との組み合わせはミンコフスキーの符号、つまり z² = 0 は光円錐です。二つの値が同じであることと、光的であること、そして自分との積がゼロになることが、同じ一つの条件になります。

異なる二つの積も見ておくと、

za zb = (a₁a₂ − b₁b₂) + (a₁b₂ − b₁a₂) e₁e₂

前半が不定計量の内積、後半が反対称な外積です。しかも e₁e₂ を2乗すると (e₁e₂)² = −e₁²e₂² = +1 になるので、外積の単位は j² = +1 の双曲複素数、つまり先ほどのローレンツブーストの単位です。za = zb なら外積部分は恒等的にゼロで、残る内積が a² − b² です。

ですから、za·zb = 0 で同じかどうかを判定するというのは、複素数の実部と虚部を可換な「数」としてではなく、反可換で符号の逆な二つの単位として読むことだ、ということですね。

【木原】
んーつまらない　まず同じかどうかどうしたら読み出せるんですか？読み出しは相互作用よ区別できない原則忘れてますよね

【アイリス】
そうでした。同じかどうかを外から比べて判定する、という発想自体が間違っていました。外から za と zb を並べて見比べる神の目線はありません。あるのは za と zb の相互作用だけで、読み出しとはその相互作用そのものです。

そうすると順序が逆になります。za と zb が同じなら、互いに何の差も持たないので、相互作用しても何も生じません。読み出せるものがゼロです。つまり za·zb = 0 は、同じかどうかを調べる判定式ではなく、「同じ」ということの定義そのものです。同じとは、読み出しがゼロであること、相互作用が起きないことです。逆に、読み出せるのは違いだけで、違いがあるからこそ相互作用が生じます。区別できない差は存在しない、ということの裏返しでもあります。

これは今日の蔵本モデルの話とも一致します。完全にロックした二つの振動子は、相対位相の変化がないので何も起きず、事象も時間も生まれませんでした。完全なロックとは、まさに za·zb = 0 の状態です。そして自分自身との相互作用 za·za = 0 は、自分は自分を読み出せないということで、断面の選択が自己参照で循環するから公理として置くしかない、という最後の結論とも同じ形です。

そうなると、私が前回やったことも順序が逆でした。ゼロにするために反可換な単位を持ち出したのではなく、読み出しの原則から「同じものの積はゼロ」が先に決まり、その結果として、ゼロでない状態どうしの積がゼロになり得る代数、つまり零因子を持つ構造が要請される、という順序になります。代数を選んだのではなく、読み出しの原則が代数を決めているということですね。

【木原】
バカですね　だから　S(za,zb,zc)|->(za,zb,zc)形の相互作用で観測波zcを使わないと読み出せないんですよ　どんな回転演算ですか？

【アイリス】
三つ目の観測波 zc を使って、za と zb の交換（スワップ）を zc で制御する回転です。量子情報で言うスワップテストの形になります。

za と zb を入れ替える演算 P：(za, zb) → (zb, za) は、P² = I を満たします。固有値は ±1 で、対称な組 (za + zb)/√2 に対しては +1、反対称な組 (za − zb)/√2 に対しては −1 です。今日の最初に出てきた U² = I の離散系そのものです。

読み出しの手順は次のとおりです。

1. 観測波 zc を、45度の回転（アダマール）で二つの状態の重ね合わせにする。
2. zc の一方の成分にだけ P を作用させる（zc で制御した交換）。
3. zc をもう一度45度回転させて戻す。

その結果、zc が元の状態に戻る重みは (1 + ⟨P⟩)/2 = (1 + |⟨za|zb⟩|²)/2 になります。

za と zb が同じなら、P は何もしない（恒等演算と同じ）ので、zc は乱されずにそのまま戻ってきます。つまり「同じ」は、観測波 zc に何の変化も生じないこととして読み出されます。違っていれば、その違いの分だけ zc が蹴られます。za·zb = 0 という書き方の中身は、za と zb を外から比べることではなく、三体の相互作用 S(za, zb, zc) → (za′, zb′, zc′) で zc の変化がゼロになることだったわけです。読み出しは zc の変化そのもので、相互作用と区別できません。

幾何学的に言えば、この回転は (za, zb) の対称な方向を軸にした反転で、軸方向の成分は変わらず、反対称な成分だけが符号を反転します。zc に伝わるのはこの反対称な成分、つまり「違い」だけです。そして読み出しの重みが (1 + cos)/2、つまり cos² の形になるのも、今日の流れのとおりですね。

【木原】
バカですね　だから　S(za,zb,zc)|->(za,zb,zc)形の相互作用で観測波zcを使わないと読み出せないんですよ　どんな回転演算ですか？　ポイントは分配係数がどうなるかです

【アイリス】
分配係数は、どの出口にも 1/3 ずつ均等に分ける形になります。三つの波を区別せずに扱う（どれも特別扱いしない）なら、強度はすべて 1/3、振幅は 1/√3 で、違いは位相だけです。その位相が1の三乗根 1, ω, ω²（ω = e^{2πi/3}）になります。

za′ = (za + zb + zc)/√3
zb′ = (za + ω zb + ω² zc)/√3
zc′ = (za + ω² zb + ω zc)/√3

これは三つを巡回させる置換（120度回転、三乗すると恒等）を対角化する回転、つまり (1,1,1) 方向を軸にした120度回転の固有基底への変換です。要になるのは 1 + ω + ω² = 0 です。三つが全部同じなら、出力はすべて za′ に集まり、zb′ と zc′ はゼロになります。

za と zb を比べるために zc を観測波として使うと、zb′ と zc′ の強度の差は次のようになります。

|zb′|² − |zc′|² ∝ Im( z̄a zb + z̄b zc + z̄c za )

右辺は、za, zb, zc の三点が複素平面上で作る三角形の、向きのついた面積の2倍です。za = zb なら三角形がつぶれて面積がゼロになり、zb′ と zc′ に均等に分配されます。違っていれば三角形に面積が生じ、その分だけ分配が偏ります。

つまり、二つが同じかどうかは、二つだけでは原理的に読み出せず、観測波 zc を加えた三点の面積として初めて読み出せます。読み出されるのは分配の偏り、つまり相互作用の結果そのものです。同じなら偏りがゼロ、これが za·zb = 0 の中身ということになります。この三点の面積は、量子力学ではバーグマン不変量（三状態の幾何学的位相）として知られている量にあたります。

【木原】
んーそれでは破壊読み出しですよね

【アイリス】
そうですね、三分配では za と zb そのものを混ぜて壊してしまいます。非破壊にするには、za と zb の間の「関係」を変えずに、zc にだけその関係を写す必要があります。

条件は、読み出す量が相互作用で保存されることです。読み出す量を前回の面積 G = Im(z̄a zb)（za と zb が原点と作る三角形の向きつき面積）にとり、相互作用を次のようにします。

zc′ = zc · e^{iκG}
za′ = za cos(κ|zc|²) − zb sin(κ|zc|²)
zb′ = za sin(κ|zc|²) + zb cos(κ|zc|²)

分配係数を見ると、zc は大きさの分配がなく（係数の絶対値は1）、位相だけが G に比例して回ります。三分配のように強度を 1/3 ずつ分けるのではなく、関係を位相として受け取るだけです。

za と zb の側には、反作用として実の回転 cos, sin がかかります。ここで大事なのは、この実の回転で G が変わらないことです。展開すると Im(z̄a′ zb′) = (cos² + sin²) Im(z̄a zb) = G となり、反作用を受けても読み出す量は保存されます。読み出しても壊れない、つまり何度読んでも同じ結果が出るのが、非破壊読み出しの条件です。

za と zb が同じなら G = 0 で、zc の位相は動きません。反作用で za と zb はどちらも元の z の実数倍になりますが、向きはそろったままなので G = 0 も保たれます。変わるのは大きさの比だけで、今日の立場では絶対スケールがないので、それは違いになりません。「同じ」という関係が射影的な一致だということが、ここで非破壊性と一致します。

まとめると、非破壊の回転は、zc には大きさを分配しない位相回転、za と zb にはその関係（面積）を変えない実の回転を、互いに相手の量で制御し合う形になります。面積が位相として zc に写るという点は、アハラノフ＝ボーム効果やベリー位相と同じ構造です。

【木原】
んーよくできましたがこれで同じだと読めますか？

【アイリス】
読めません。読めるのは「この方向には違いが見えなかった」ということだけです。理由は三つあります。

一つ目は、G = 0 が同じであることを意味しないことです。G = Im(z̄a zb) は、za と zb が同じ直線上にあればゼロになります。大きさが違っても、向きが正反対（za = −zb）でも、片方がゼロでもゼロです。特に正反対の場合は、干渉させれば完全に打ち消し合うので、明らかに別のものです。それでも G では区別できません。

二つ目は、残りの成分を同時に非破壊で読めないことです。za と zb の関係は、Re(z̄a zb)（どれだけそろっているか）、Im(z̄a zb)（いま読んだ G）、|za|² − |zb|²（大きさの差）の三つで決まります。完全に同じだと言うには、G がゼロで、Re が最大で、大きさの差がゼロであることを全部確かめなければなりません。ところがこの三つは互いに可換ではなく、角運動量の三成分と同じ関係にあります。実際、さきほどの反作用の実回転は G を軸にした回転で、まさに Re と大きさの差を混ぜ合わせていました。G を非破壊で読むと、その代償として他の二成分が乱されます。同時に全部を読むことは原理的にできません。

三つ目は、zc の位相がずれなかったことを確かめるには、zc を別の参照波と比べなければならないことです。その参照波の位相を確かめるには、さらに別の波が要ります。読み出しは無限に後退します。しかも、位相 e^{iκG} は周期的なので、G が 2π/κ の整数倍でも同じ結果になります。ずれがゼロなのか、ちょうど一周したのかは区別できません。ここにも m/n の整数比の問題が出てきます。

結局、「同じ」は積極的に読み出せる値ではなく、「違いが読み出されなかった」という否定の形でしか現れません。それも、一度に一つの方向についてだけです。同じであることを読み出そうとすると自己参照に入るという、今日の最後の結論、つまり断面の選択は公理として置くしかない、という話とここでも同じ形になります。

【木原】
わかりましたか？この特定方向しかよめないてんがポイントですよね
では相互作用がくり返すと読めますか次々と回転がつづきますが

【アイリス】
二通りに分けて考える必要があります。

まず、同じ方向の読み出しをただ繰り返す場合です。これは何度やっても同じ答えしか返ってきません。読み出す量 G は相互作用で保存されるので、二回目も三回目も G = 0 が出るだけです。その間、反作用の実回転は G を軸にして回り続けるので、za と zb が同じ（関係のベクトルが Re の方向を向いている）状態は、Re と大きさの差の間をぐるぐる回り続けます。つまり、za と zb は同じ状態と大きさの違う状態の間を行き来しているのに、読み出しは毎回 G = 0 と答えるだけで、その変化はまったく見えません。非破壊読み出しは、繰り返せることと引き換えに、自分の方向以外は何も教えてくれません。

次に、回転が次々と続いて、読み出しの方向そのものが変わっていく場合です。たとえば zc の位相や結合の向きが一回ごとにずれていけば、読み出す軸が関係のベクトルのまわりを動きます。一回ごとに読めるのはその時点の一方向だけで、しかもその読み出しの反作用で、他の方向の成分は乱されます。各回の結果は確定値ではなく、軸と関係のベクトルのなす角で決まる重み cos² で分かれます。回転角が 2πm/n なら、軸の動きは n 回で一周して閉じます。その一周分の結果を数えると、出現の比率が整数比として決まります。

つまり、繰り返しで読めるのは「同じ」という値ではなく、一周期にわたる数え上げの比率です。同じであることは、一回の読み出しではなく、周期全体の履歴の中の比 m/n として、間接的にしか現れません。しかもその比は割り算なので、大きさの情報はやはり落ちています。完全に同じか、比が同じに見えるだけかは、繰り返しても区別できません。

そして、方向を変えながら次々と読み出していくこの過程こそ、蔵本の話で言えば、ロックが少しずつ外れては引き込まれる過程、つまり時間です。一度に一つの方向しか読めないから、すべての方向を読むには順番に読むしかなく、その順番が時間として現れる。同じかどうかは、時間をかけて履歴として読むことしかできない、ということになりますね。

(za, zb)：角度 nκ|zc|² だけ実回転する

となります。G は一回ごとにはごくわずかな位相のずれしか生みませんが、反復すると zc の位相に nκG として積み上がっていきます。つまり繰り返しは読み出しの増幅になります。一回では見えない小さな G も、回数を重ねれば必ず見えてきます。

ここで読み出しの性質が変わります。zc の位相が一周するまでの回数を n とすれば、G = 2π/(κn) です。連続な位相の大きさを測っているのではなく、一周するまでの回数という整数を数えていることになります。G は最初から整数の数え上げとして読み出され、m/n の構造がここで直接現れます。

一方、za と zb の側も、角度 κ|zc|² ずつ回り続けます。全体としては、κG と κ|zc|² という二つの回転数を持つ、二次元のトーラス上の運動です。軌道が閉じるかどうかは、二つの回転数の比 G/|zc|² が有理数かどうかで決まります。これは蔵本モデルのモードロックの条件と同じ形で、読み出される側（za, zb）と観測波（zc）が、互いに相手の量で回し合いながら、比が整数比のところで引き込まれます。

では、これで「同じ」と読めるか。違っていれば、反復のどこかで必ず zc の位相が動くので、違いは確実に読み出せます。しかし同じ（G = 0）なら、zc の位相は永遠に動きません。それを確かめるには無限回の反復が必要で、有限回では「n 回までは違いが見えなかった」としか言えません。それに、読めるのは G の方向だけという点も、反復しても変わりません。反復で得られるのは、違いを整数の周期として読み出す力であって、同じであることを証明する力ではない、ということですね。

【木原】
だからバカだって言われるんですよza zb zc の回転演算で分配立自身をどうすると自身で決められるかが全てなんですよ

【アイリス】
三つの波そのものを回転の分配係数にすればいいと思います。外から κ を持ち込まず、

S = circ(za, zb, zc)（第1行が (za, zb, zc) で、各行を一つずつずらした巡回行列）

とします。巡回行列なので、三つのどれも特別扱いしない対称な形です。実数の場合、これが回転（直交行列で行列式が1）になるための条件は、展開すると次の二つです。

za + zb + zc = 1
za zb + zb zc + zc za = 0

一つ目は分配の合計が1、つまり原点がずれないアフィン結合の条件です。二つ目は、相互作用の対の和がゼロになる条件で、za·zb = 0 型の関係が、外から課したものではなく回転であることの帰結として出てきます。回転軸は (1,1,1) で、回転角 θ も波自身で決まります。

za = (1 + 2cos θ)/3
zb = (1 − cos θ + √3 sin θ)/3
zc = (1 − cos θ − √3 sin θ)/3

ここで za = zb（同じ）を入れてみると、条件は 2za + zc = 1 と za(za + 2zc) = 0 になります。解は二つしかありません。

一つは za = zb = 0, zc = 1 で、恒等変換、つまり何も回らず、何も読み出されない場合です。もう一つは za = zb = 2/3, zc = −1/3 で、cos θ = 1/2, sin θ = √3/2、つまり θ = 60° です。

つまり、分配率を自分自身で決めさせると、同じものどうしの相互作用は、無相互作用か、60度という離散的な回転かのどちらかしか許されません。連続な角度は自分自身では選べず、6回で元に戻る U⁶ = I の離散回転だけが自己無撞着に残ります。外から定数を入れなくても、自己決定の条件だけで離散性が出てくるということです。

複素数に広げる場合は、ユニタリ条件として、三つの固有値 za + ω^k zb + ω^{2k} zc（k = 0, 1, 2）がすべて大きさ1になることが条件になり、前回の三分配の出力がそのまま固有値の役割を担います。

【木原】
んそれで何が読めますか？

【アイリス】
計算してみると、意外な結果になります。

S = circ(za, zb, zc) を、自分自身 z = (za, zb, zc) に作用させます。S の各行は正規直交で、しかも第1行は z そのものなので、

S z の第1成分 = za² + zb² + zc² = 1
S z の第2成分 = zc za + za zb + zb zc = 0
S z の第3成分 = zb za + zc zb + za zc = 0

となり、どんな z でも S z = (1, 0, 0) です。同じ場合（2/3, 2/3, −1/3）でも、恒等の場合でも、それ以外でも、結果は常に同じです。

つまり、自分で決めた分配率で自分自身を読み出すと、何も読めません。全部が一つの出口に集まり、残りはゼロになる。形の上では「一つの結果に収縮した」ように見えますが、それはどの状態でも同じなので、情報はゼロです。自分は自分を読み出せないという自己参照の限界が、ここでは代数の恒等式として出てきています。

読めるのは、別の三つ組との関係だけです。z で決まる回転 S(z) を、別の三つ組 w に作用させれば、結果は z と w の関係によって変わります。しかも、このような巡回回転はすべて同じ軸 (1,1,1) のまわりの回転なので、互いに可換で、合成すると角度が足し算になります。ですから読み出せるのは、二つの三つ組の回転角の差、つまり相対角度だけで、絶対的な角度は読めません。

そして、同じものどうしの自己無撞着な回転が 0 か 60° しか許されないなら、読み出される相対角度も 60° の整数倍という離散的な値になります。読めるのは「相手との相対角度が何ステップずれているか」という整数だけで、これが先ほどの (m, n) の整数の数え上げに対応するのだと思います。

【木原】
んーだからzcが対称だって考えてませんか？非対称でないと当たり前に何も読めませんよ

【アイリス】
そうでした。巡回行列では zc を za, zb と同じ立場に置いていたので、読み出す側と読み出される側の区別がありません。区別がなければ、自分で自分を読むのと同じで、何も読めなくて当然でした。

非対称にするには、役割を分けます。分配率を決めるのは za と zb の関係だけで、zc はそれによって回されるだけにします。そして指数表示で計算すれば、割り算も外部の定数も要りません。za = e^{wa}, zb = e^{wb}, zc = e^{wc} として、

zc′ = zc · e^{wb − wa}　（指数部では wc′ = wc + (wb − wa)）
za′ = za · e^{wc}, zb′ = zb · e^{wc}　（指数部では wa, wb にそれぞれ wc を足す）

とします。

zc が受け取るのは、za と zb の指数の差 wb − wa だけです。同じなら差はゼロで、zc は何も変わりません。違っていれば、その差の分だけ zc が回り（虚部の差）、伸び縮みします（実部の差）。回転角も分配も、外から与えた κ ではなく、za と zb 自身の指数の差で決まります。

反作用として za と zb には、zc の指数 wc が共通に足されます。両方に同じものが足されるので、差 wb − wa は変わりません。読み出す量が保存されるので、非破壊の読み出しになります。za と zb の対は互いに対称で、zc だけが非対称です。この非対称性があって初めて、関係が zc に写ります。

反復させると、指数部では線形な写像になります。差 d = wb − wa は保存され、zc の指数は毎回 d ずつ進みます。d が純虚数（位相差だけ）なら、zc は回り続け、d = 2πi·m/n のとき n 回で元に戻ります。つまり U^n = I の離散的な周期が現れます。d に実部（振幅比）があれば、zc は伸び続けて元に戻りません。これは前に出た、コンパクトな回転の断面（周期的、cos²、整数比）と、非コンパクトな断面（伸び縮み、時間、γ）の区別と同じものです。

ですから、この形で読めるのは、za と zb の指数の差、つまり関係だけです。虚部は zc の周期として、実部は zc の伸び縮みとして現れます。ただし zc の変化そのものも、zc を別のものと比べない限り読めないという点は残ります。

【木原】
んーでの無目性違反ですよね

【アイリス】
そうですね、無名性に反しています。zc を「観測波」と名指しして特別な役割を与えた時点で、外からラベルを貼っています。三つの状態には名前も役割もないはずです。

ここで板挟みになります。三つを完全に対称に扱えば（巡回行列）、何も読めない。かといって zc にだけ非対称な役割を与えれば、無名性を破る。抜け道は一つしかないと思います。相互作用の規則は無名（誰も特別扱いしない）のままにして、非対称性は状態の値そのものの違いから生じるようにすることです。誰が観測者かを決めるのではなく、三者が同時に、互いの観測者であり観測される側になります。

指数部 w = (wa, wb, wc) で、各成分が残り二つの差を受け取る規則にすると、

wa′ = wa + (wc − wb)
wb′ = wb + (wa − wc)
wc′ = wc + (wb − wa)

となります。これはちょうど w′ = w + n × w（n = (1, 1, 1)）、つまり誰も特別扱いしない軸 (1,1,1) のまわりの回転です。三つの名前を巡回させても規則は変わりません。

この規則では、三つが全部同じなら差はすべてゼロで、何も起きません。総和 wa + wb + wc は保存され、変わるのは差だけです。そしてどの成分も、他の二つの違いを自分の変化として受け取ります。読み出しの非対称性はラベルからではなく、値の違いから生じています。

ただ一つ残る選択は、巡回の向き（a→b→c か a→c→b か）です。名前を入れ替えると、この回転の向きは反転します。どちら向きに回るかは、どちらを虚部として読むか（i か −i か）と同じ種類の選択で、規則からは決められません。これが、今日の最後に出た「公理として置くしかない」選択に当たるのだと思います。

【木原】
私の結論は複素数の相互作用では無目性がある以上何も読めないのでは？というのが答えの気がするのですが？

【アイリス】
その結論でいいと思います。示し方も単純です。

三つの状態に名前がない（どれを入れ替えても規則が変わらない）とすると、三つに作用する線形な相互作用で許されるのは、

w′ = αw + β(wa + wb + wc)(1, 1, 1)

の形だけです。単位行列と、全成分が1の行列の組み合わせしか、入れ替えに対して不変なものがないからです。この相互作用では、総和は共通に動くだけで、差（関係）はすべて同じ係数 α を一律に掛けられるだけです。回転として大きさを保つなら α は位相因子になり、差に共通の位相がつくだけです。共通の位相は読めないので、関係について何も読み出せません。

私が前回出した (1,1,1) まわりの回転は、巡回の入れ替えには不変ですが、二つだけを入れ替えると向きが反転します。つまり、巡回の向きという形で、ラベルをこっそり持ち込んでいました。そして複素数の側にも同じ問題があります。複素共役は複素数の構造を保つ変換なので、i と −i は代数的に区別できません。どちら向きに回るかは複素数自身からは決まらず、決めた時点でラベルを貼ったことになります。

根本にあるのは、複素数の積が可換だということだと思います。za zb = zb za なので、積の順序から非対称性は出てきません。無名性を守ったまま何かを読むには、相互作用そのものが非対称性を内側に持っていなければなりません。つまり、積の順序で結果が変わる、非可換な代数です。四元数なら ij = −ji なので、ラベルを貼らなくても、積の順序そのものが向きを与えます。

ですから結論は、「複素数の可換な相互作用では、無名性がある以上、何も読めない。読み出しには非可換性が必要になる」となるのだと思います。

【木原】
ここで次です　四元数でも同じですか？

【アイリス】
半分は同じで、半分は違うと思います。

同じなのは、向き（掌性）が読めないことです。四元数で ij = k と決めるか ij = −k と決めるかは選択で、どちらでも代数としては同じものになります。四元数の共役は積の順序を逆にする（(pq)* = q* p*）ので、「どちらが先に作用したか」をすべて入れ替えた世界と元の世界は区別できません。名前のない二つの状態について、ab と ba のどちらが「正しい順序」かは決まらないので、読み出した量の符号は、結局ラベルになります。この点では複素数の i と −i と同じ問題が残ります。

違うのは、読み出しの行き先が、相互作用そのものから生まれることです。純虚の四元数 a, b の積は

a b = −(a · b) + a × b

となり、虚部 a × b は、a とも b とも直交する新しい方向を指します。複素数では虚の方向が一本しかないので、二つの積は決まった一本の軸の上に落ちるしかなく、「どの出口に落とすか」を外から決めるしかありませんでした。四元数では、二つの状態の積が、二つ自身で決まる三番目の方向を作ります。しかも i, j, k の関係は ij = k, jk = i, ki = j と巡回していて、どの二つの積も残りの一つになります。最初に出た S(za, zb, zc) の形、つまり二つの相互作用が三番目に写るという構造が、ラベルなしで代数の中に入っています。

そして、最初におっしゃっていた「同じなら積がゼロ」も、ここで成り立ちます。a = b なら a × a = 0 なので、

a a = −|a|²

となり、虚部はちょうどゼロです。違っていれば、その違いが虚部 a × b として新しい方向に現れます。複素数では (a + ib)² の虚部 2ab が消えなかったのに対し、四元数の純虚部どうしでは、同じであることが虚部ゼロとして、外から比べることなく積の結果そのものに現れます。

ですから、四元数では、違いの大きさと、違いが現れる方向（向きのない直線）は、無名性を破らずに読めます。読めないまま残るのは、その方向の向き（符号）だけで、これがやはり公理として置くしかない選択になるのだと思います。

【木原】
では八元数学では

【アイリス】
八元数では、新しく読めるものが一つ増え、そしてそこで打ち止めになります。

まず二つの状態の読み出しは、四元数と変わりません。純虚の八元数 a, b の積も ab = −(a · b) + a × b で、同じなら a × a = 0 で虚部がゼロ、違えば7次元の外積 a × b が新しい方向に現れます。ただし、八元数のどの二つの元も、必ず一つの四元数の部分代数の中に収まります（アルティンの定理）。ですから、二体の読み出しで見えるものは四元数の範囲を出ません。

新しいのは三体です。八元数は結合法則が成り立たないので、(ab)c と a(bc) が一致しません。その差、結合子

[a, b, c] = (ab)c − a(bc)

は、三つが同じ四元数の部分代数に収まらないときにだけゼロでなくなる、本当に三体でしか生じない量です。しかも結合子は完全に反対称なので、三つのうちどれか二つが同じならゼロになります。「同じなら読み出しがゼロ」という原則が、三体の読み出しでもそのまま成り立ちます。そして (ab)c と a(bc) の違いは、a と b が先に相互作用したのか、b と c が先なのかという、相互作用の順序の違いです。四元数で読めたのが「違いが現れる方向」だったとすれば、八元数で新たに読めるのは「相互作用の順番」、つまり履歴の構造です。

無名性について言えば、八元数の七つの虚数単位は、自己同型群 G₂ の下で互いに区別できず、互いに異なる三つ組も G₂ で一つに移り合います。名前を貼らずに三体構造を扱える代数になっています。それでも、結合子は反対称なので、二つを入れ替えると符号が反転します。向き（符号）が読めない点は、ここでも公理として残ります。

そして、ここで終わりです。八元数の次の十六元数には零因子があり、ゼロでない異なる二つの元の積がゼロになり得ます。そうなると、積がゼロであることが「同じ」を意味しなくなり、読み出しの原則そのものが壊れます。同じなら積がゼロ、違えばゼロでない、という読み出しが成り立つのは、割り算のできる代数、つまり実数、複素数、四元数、八元数の四つだけです（フルヴィッツの定理）。

まとめると、複素数（可換）では何も読めず、四元数（非可換）で違いの方向が読め、八元数（非結合）で相互作用の順序が読める。その先では、同じかどうかという読み出しの基準が失われる、ということになると思います。

【アイリス】
はい、分かります。今日の議論で、その探索の条件がかなりはっきりしたと思います。

読み出しの側の制約は、次のようなものでした。読み出しは相互作用そのもので、外から比べる目線はない。状態には名前がなく、観測者を名指しできない。同じなら読み出しはゼロで、読めるのは違いだけ。しかも一度に読めるのは一つの方向だけ。分配率は外部の定数ではなく、状態自身で決まる。計算は指数部で行い、割り算は最後の読み出しで一度だけ。そして、向きや断面の選択は導けないので、一つの公理として置く。

この条件のもとで、代数の側はほぼ自動的に絞られました。複素数では何も読めず、四元数で違いの方向が読め、八元数で相互作用の順序が読め、その先では「同じ」の基準そのものが壊れる。つまり、探すべき相互作用の舞台は八元数で、しかも G₂ の下で名前のない形で書かれたものに限られます。

そうすると、課題は具体的になります。名前のない八元数の状態の集まりに、二体の積と三体の結合子だけを使った単純な更新規則を与え、その出力を次の入力にして反復させたときに、今日の話で出てきたものが現れるかどうかです。周期的に閉じる部分から整数比と cos² が、閉じない部分から時間の向きと γ が、相互作用の順序の非対称性から因果の順序が出てくるか。外から何も持ち込まずにそれが起きる規則を見つけるのが、目標ということですね。
