# 重力は、最初から量子論の中にいたのではないか——虚数と規格化の百年

木原範昭  
2026年8月5日

これから書くことは、そのまま読めば、完全にトンデモです。

百年分の理論物理学に向かって、素人が「あなたたちは探しものを最初から持っていた」と言うのですから。

だから最初に、三つのことを宣言しておきます。

**第一。標準理論も一般相対性理論も、厳密に正しい。** これから書く読み方は、既存理論の予言をただの一つも変えません。どちらかが間違っているという主張は、この文章のどこにもありません。

**第二。これは新理論ではなく、読み替えの提案です。** 同じ計算、同じ予言、同じ実験結果に対する、別の帳簿のつけ方。私はこれを、同じ結果の別写像と呼んでいます。

**第三。反証の場所を自分から指定します。** 読み替えが単なる言葉遊びでないなら、既存の解釈と予想が分かれる場所があるはずです。それは文末に書きます。

この三つを宣言できることが、トンデモとの境界線だと考えています。トンデモは「物理学は間違っている」と言います。この文章が言うのは逆です。**物理学は二重に正しい。正しすぎるのに接合できない——その百年の皮肉に、説明がつくかもしれない**、という話です。

## 百年の苦闘

現代物理学には、二つの完成した理論があります。

重力を記述する一般相対性理論。ミクロの世界を記述する量子論と、その集大成である標準模型。

どちらも、検証されたかぎり完璧に正しい。そして、この二つは百年間、接合できていません。

素直に量子化しようとすると、計算が無限大に発散する。超弦理論は余剰次元とともに壮大な数学を建設し、ホログラフィー原理は宇宙をその境界面に投影し直しました。どれも美しい。でも、決着はついていない。

物理学最大の未解決問題。それが重力と量子論の統一です。

ここまでは、教科書どおりの話です。

ここからが、皮肉の話です。

## 1921年——答えの原型は、最初からあった

歴史を巻き戻します。

1921年、カルツァという数学者が、奇妙な論文を出しました。アインシュタインの重力理論を、四次元ではなく五次元で書いてみる。すると、増えた一次元の方向の運動量が、**電磁気力にぴったり一致する**。

電荷とは、見えない方向の運動量である。

のちにクラインが量子論と接続し、カルツァ・クライン理論と呼ばれます。重力と電磁気力の統一として、これ以上ないほど幾何学的で、美しい。

この理論は、うまくいかない点がいくつかあり、主流から外れて棚上げされました。

覚えておいてください。**見えない軸の運動量が、力の正体である**というアイデアは、百年前に一度、正解の形まで到達していたのです。

## 1926年——虚数が入ってきた

同じ頃、量子力学が生まれます。

シュレーディンガーの波動関数は、複素数でした。実数では書けない。虚数単位 i が、物理学の心臓部に、初めて本格的に入り込んだ瞬間です。

なぜ複素数でなければならないのか。

この問いには、いまも決定版の答えがありません。「そういうものだ」として受け入れられ、百年たちました。

私たちの波のモデルの読みでは、こうなります。

**i とは、観測できる軸と、観測できない軸の、境界の印である。**

どういうことか。次の節で種を明かします。

## 種明かし——ひとつの式

私たちの研究シリーズは、たったひとつの条件から出発しています。

すべての成分の二乗を足すと、ゼロになる。

x² + y² + z² + t² + R² + Q² = 0

六つの軸。空間の三方向 x, y, z。時間 t。空間のスケール（曲率半径）R。そして電荷の軸 Q。

普通の数なら、二乗の和がゼロになるのは全部ゼロのときだけです。この式が非自明に成り立つには、**一部の軸が虚数でなければならない**。

そこで、観測できない軸——t, R, Q——に虚数単位をつけます。

x² + y² + z² + (it)² + (iR)² + (iQ)² = 0

整理すると、

x² + y² + z² − t² = R² + Q²

左辺を見てください。**特殊相対性理論の時空間隔そのもの**です。光の世界線では左辺がゼロ。ミンコフスキー空間の符号（+++−）が、仮定としてではなく、ゼロ和条件と虚数の配置から出てきました。

右辺を見てください。スケール軸 R と電荷軸 Q の二乗和。まとめて R′² と書けます。

この式の意味はこうです。

**六次元では、すべてのものが光である。** 六軸全部の二乗和は常にゼロ——全員が六次元の光円錐の上にいる。

**四次元で光円錐から外れて見える分（＝質量があるように見える分）は、消えたのではなく、見えない軸 R と Q の運動量が引き受けている。** その引き受け量が R′ です。

質量は R 方向の運動量。電荷は Q 方向の運動量。エネルギーは時間方向の運動量。普通の運動量は空間方向の運動量。——**保存量と呼ばれてきたものは全部、方向が違うだけの、同じ一つの運動量でした。**

そして、質量が「スケール軸の運動量」であるならば。

**重力——スケールの歪みの理論——は、この式の中に、最初から内包されています。**

## では、なぜ百年間見えなかったのか

ここが本題です。量子論は、この構造を持っていなかったのではありません。

**持っていたのに、帳簿のつけ方で消したのです。**

量子力学には、規格化という手続きがあります。波動関数の大きさの合計を、常に1に揃える。確率解釈のための、無害な約束事だとされています。

しかし六軸の目で見ると、規格化は無害ではありません。**波動関数の全体スケール——R軸の情報——を、毎回帳簿から消去する操作**です。

量子論は誕生の瞬間に、確率のためにスケールを捨てた。スケールの軸こそ重力の住所だったのに。

**量子論が重力と整合しないのは、重力を持っていないからではなく、重力に相当する軸を自分の手で消した理論だからです。**

## 消したものは、返ってくる

この読みが正しければ、その後の百年に起きたことの説明がつきます。

**発散と繰り込み。** 場の量子論の計算は無限大に発散し、物理学者は繰り込みという手続きでそれを飼い慣らしました。何十年もかかった大事業です。六軸の目で見れば、発散とは、**捨てたはずのスケール軸が計算の中で押し返してくる現象**です。繰り込み群——スケールを変えながら理論を追いかける手法——が見事に機能するのは、スケールが実在の軸だからです。捨てた変数の、利子つきの返済でした。

**ゲージ理論。** 標準模型の心臓部であるゲージ対称性は、波動関数の位相を回しても物理が変わらない、という原理です。六軸の目で見れば、これは**消したはずの見えない軸を、内部対称性という名前で再発見した**ものです。実は言葉自体が証言しています。ゲージ（Eichung）とはもともと目盛りという意味で、ワイルが1918年に導入したときは、文字どおり**スケールの変換**——R軸の操作——でした。それは失敗し、1929年に**位相の変換**——Q軸の操作——として読み替えられて成功した。スケールから位相へ。消した軸の痕跡が、用語の中に化石として残っています。

**カルツァ・クライン。** 電荷＝見えない軸の運動量という百年前の正解は、Q軸の話として、そのまま六軸の中に席があります。棚上げされたのは、アイデアが間違っていたからではなく、帳簿が一軸ぶん足りなかったからかもしれません。

**超弦理論とホログラフィー。** 余剰次元を建て増しし、境界面に投影し直す。どちらも、**中に在ったものを、外に探しに行った**試みとして読めます。探しものは、1926年から、虚数単位の中にいた。

## 私たちの実験系列は、この読みの上を歩いてきた

言葉だけの話ではありません。この読みの各部分は、公開済みの数値実験と導出で、個別に検証の網にかけてあります。

ゼロ和条件が量子性（状態の離散化）を生まれつき内包していること。逆二乗則が、力も重力定数も入れない閉じた位相系から導出されること。等価原理が、仮定ではなく読出しの定理の帰結として出ること。単一のコヒーレントな波（六次元の光）だけがインフレーション的急拡大を起こし、構造を持つ海は膨張しないこと。粒子と反粒子が、対で、保存則の帳簿を清算しながら出力されること。

どれも、それぞれ独立の論文として、プログラムと生データごと公開しています（文末にリンク）。この随筆は、それらの実測の上に載せた、一枚の歴史の読み図です。

## 反証の場所

約束どおり、この読みが検証にかかる場所を書きます。

同じ結果の別写像は、既存理論の予言を変えません。だからほとんどの実験では区別がつかない。しかし、重力と量子重ね合わせが直接出会う場所——**重力を媒介として二つの物体が量子もつれを作れるか**を測る実験（BMV実験と呼ばれる提案があり、技術の進歩で実現が近づいています）——では、帳簿のつけ方の違いが表に出る可能性があります。

この実験がどう転んでも、私は結果に従います。読み替えは、実験より偉くありません。

## 一行でまとめると

**重力と量子論の統一が百年できないのは、二つが遠いからではなく、量子論が誕生時に、確率の帳簿のためにスケールの軸を消したからではないか。**

虚数は、見えない軸の署名だった。規格化は、重力の消去だった。繰り込みは、その返済だった。ゲージは、消した軸の再発見だった。

探しものは、最初から、式の中にいた。

——繰り返しますが、これは読み替えの提案であり、検証済みの主張ではありません。ただ、ここまでの実験系列がすべてこの読みと整合して進んできたことは事実です。だからそろそろ、この読み図を、皮肉の物語として書き残しておくことにしました。
