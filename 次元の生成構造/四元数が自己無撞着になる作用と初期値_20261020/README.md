# 四元数が自己無撞着になる作用と初期値の組（2026-10-20）

**枠組み（著者の指示）：** 四元数の塊は力学から自然に出ないので、初期値として与える。自己無撞着かどうかは作用と初期値の組で決まる。問いは「四元数として与えた初期値が、どの作用の下で、どの型の自己無撞着になるか」。
**対になる段：** 八元数の段は `../八元数が自己無撞着になる作用と初期値_20261020/`（結合子の作用 ASSOC と g₂ 相対平衡）。

## 材料と作用

ℂ では消え、ℍ で初めて残る材料は交換子 [a,b] = ab − ba（八元数の段の結合子に当たる一段下の材料）。w = x/|x|、κ = ±1。

| 作用 | 式 | 相手の次数 |
|---|---|---|
| C1 | dx_e = κ\|x_e\| [w_e, P_e]、P_e = Σ_{f≠e} w_f | 1 |
| C2 | dx_e = κ\|x_e\| Σ_{f≠e} ⟨w_e, w_f⟩[w_e, w_f] = κ\|x_e\| [w_e, S_w w_e]、S_w = Σ w wᵀ | 2 |

どちらも ⟨[w_e, ·], w_e⟩ = 0 で各 |x_e| を保ち、Aut(ℍ) = SO(3)（共役）で共変。四元数の積は `../八元数閉塞と関係の分解_20261019/octonion_closure_check_20261019.py` の qmul を読み込む（構造定数との差 0）。

**解析（C1）：** [w, P] = 2 Im w × Im P。各要素の虚部が Im P のまわりに歳差し、dP/dt = 2κ Σ Im w_e × Im P = 0 で P は保存する。したがって**どの四元数の配置も相対平衡**で、x_e(t) = exp(−tκ ad_P) x_e、振動数 2|Im P|。一つの複素平面上の配置、または Im P = 0 なら静止。

## 読み（確認前）

- **四元数は、作用と組にすれば自己無撞着になる。** C1 ではどの四元数の配置も、自分の虚部の和 Im P を軸に回る相対平衡になる。軸は外から与える参照の向きではなく、配置自身が決める（無名性を保つ）。八元数の段で ℓ を選んだ作用が回したのと同じ回転を、四元数では配置が自分で選ぶ。
- **C1 の相対平衡は自明に近い。** 全ての配置が同じ形で回るので、どの配置が選ばれるかを作用は決めない。配置の選別が起きるのは C2（相手について 2 次）からで、そこでは相対平衡が初期値に応じて存在し、N が大きいほど形を保つ解が減る（N = 3 で 7/8、N = 7 で 1/8）。八元数の段の ASSOC（N ≥ 6 でほぼ全て離れる）と同じ傾き。
- **高対称な配置は、四元数でも作用が消えて静止する。** 2-デザイン（S_w ∝ I）と Σw = 0 が作用を消すのは、八元数の段と同じ仕組み。
- **TWO_C（二つの複素クラスターを足したもの）は四元数を生成する（次元 4）が、C1・C2 ではどちらも静止する。** 各クラスターが自分の平面で閉じている（Σw = 0、S_w が平面ごとに閉じる）ため、二つの平面は四元数として互いに作用しない。ペアとして動くには、クラスターの閉じ方を崩す初期値が要る。
