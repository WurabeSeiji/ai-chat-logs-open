# K4 偶数倍音系 / 奇数倍音系：自己無撞着性・二乗和・U^n=I 検証

日付: 2026-09-15

## 0. 対象と定義

元データ `complex_states_animation_exact_i.csv` の 4 個の一意状態 `k=0,1,2,3` を解析した。forward/reverse は同じ4状態の順序違いなので、系全体の和では二重計上しない。

```text
U = i
S_k = (z_base, z_harmonic) = (U^k, U^(m k))
m=2 : 偶数倍音系
m=3 : 奇数倍音系
```

自己無撞着性は、二乗和ゼロとは分離し、まず次の代数的一貫性で検査した。

1. `|z_base|=|z_harmonic|=1`
2. `z_harmonic = z_base^m`
3. `S_(k+1) = (U z_base, U^m z_harmonic)`
4. forward と reverse の同じ k が同じ複素状態を与える
5. 4ステップ後に S0 に戻る

二乗和は各状態について

```text
Q_k = z_base^2 + z_harmonic^2
z_j = a_j + i b_j
Q_k = Σa_j^2 - Σb_j^2 + 2 i Σ(a_j b_j)
```

を計算し、さらに4状態全体の総和も求めた。

## 1. 自己無撞着性

- m=2: 最大残差 = 0
- m=3: 最大残差 = 0
- 4ステップ閉路残差: m=2 = 0, m=3 = 0

したがって、今回の離散状態生成則に対しては **偶数系・奇数系ともに代数的に自己無撞着**。これは `Σz^2=0` を意味しない。後者は別条件として次節で確認する。

`exp(iθ)` で生成した静的データとの最大差も丸め誤差レベルであり、離散 exact-i データと整合する。

- m=2: 4.00296604248672e-16
- m=3: 5.51091059616309e-16

## 2. 各状態の二乗和

| m | k | Σa² | Σb² | Σab | Re(Σz²) | Im(Σz²) | 状態ごとのΣz²=0? |
|---:|---:|---:|---:|---:|---:|---:|:---:|
| 2 | 0 | 2 | 0 | 0 | 2 | 0 | NO |
| 2 | 1 | 1 | 1 | 0 | 0 | 0 | YES |
| 2 | 2 | 2 | 0 | 0 | 2 | 0 | NO |
| 2 | 3 | 1 | 1 | 0 | 0 | 0 | YES |
| 3 | 0 | 2 | 0 | 0 | 2 | 0 | NO |
| 3 | 1 | 0 | 2 | 0 | -2 | 0 | NO |
| 3 | 2 | 2 | 0 | 0 | 2 | 0 | NO |
| 3 | 3 | 0 | 2 | 0 | -2 | 0 | NO |

観測された系列は次の通り。

```text
m=2 : Q_k = [ 2, 0, 2, 0 ]
m=3 : Q_k = [ 2,-2, 2,-2 ]
```

## 3. 4状態を系全体とした二乗和

まず、元の複素成分そのものの線形和も確認すると両系ともゼロ。

| 系 | ΣRe(z) | ΣIm(z) |
|---|---:|---:|
| m=2 (偶数) | 0 | 0 |
| m=3 (奇数) | 0 | 0 |

二乗和の分解は次の通り。

| 系 | ΣΣa² | ΣΣb² | ΣΣab | Re(ΣΣz²) | Im(ΣΣz²) | 全体二乗閉塞 |
|---|---:|---:|---:|---:|---:|:---:|
| m=2 (偶数) | 6 | 2 | 0 | 4 | 0 | NO |
| m=3 (奇数) | 4 | 4 | 0 | 0 | 0 | YES |

結果は明確に異なる。

```text
m=2 : Σ_loop z^2 = 4
m=3 : Σ_loop z^2 = 0
```

すなわち、**4つの離散位相状態をひとつの閉じた系として数えると、奇数倍音 m=3 は二乗ゼロ閉塞するが、偶数倍音 m=2 は閉塞しない。**

複素成分分解でも同じことが見える。

```text
m=2 : ΣRe(z)=0, ΣIm(z)=0;  Σa²=6, Σb²=2, Σab=0  -> Σz²=(6-2)+0i=4
m=3 : ΣRe(z)=0, ΣIm(z)=0;  Σa²=4, Σb²=4, Σab=0  -> Σz²=(4-4)+0i=0
```

これは今回の偶奇差の中でかなり強い構造差である。

## 4. U^n = I

はい。全状態対のループについては両系とも4ステップで閉じる。

ただし最小位数には重要な差がある。

| 系 | 基底 generator | 基底の最小位数 | 倍音 generator | 倍音の最小位数 | 2波状態全体の最小ループ |
|---|---|---:|---|---:|---:|
| m=2 | i | 4 | -1 | 2 | 4 |
| m=3 | i | 4 | -i | 4 | 4 |

したがって

```text
m=2 : harmonic は2周期で戻るが、base が4周期なので pair 全体は4周期
m=3 : base も harmonic も4周期で戻り、pair 全体も4周期
```

両者とも `G_m^4=I` は成立するが、**偶数系では倍音成分だけが先に2周期で縮退する**。これは偶奇差を考える上で重要。

## 5. 現段階の結論

1. 離散生成則・遷移・逆順・閉路という意味では m=2, m=3 とも自己無撞着。
2. しかし4状態全体の二乗和は、m=3 だけが厳密にゼロ閉塞する。
3. m=2 は倍音 generator の最小位数が2へ縮退し、m=3 は4を維持する。
4. よって、今回のデータでは `偶奇差 = 単なる図形差` ではなく、**位数構造と二乗閉塞の両方に現れている**。

注意: ここでいう『自己無撞着』は上記の有限離散生成則に対する代数的一貫性。これをより強い意味（例えば全関係波の同時固定点、追加保存則、力学的自己無撞着）で定義する場合は、その条件を追加して再検査できる。
