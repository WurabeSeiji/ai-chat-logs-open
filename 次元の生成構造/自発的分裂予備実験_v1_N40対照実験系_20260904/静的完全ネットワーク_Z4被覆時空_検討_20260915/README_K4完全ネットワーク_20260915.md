# U^4=I: 基底波 + 倍音1本の完全状態ネットワーク

## 定義
U = exp(2πi/4) = i

S_k = (U^k, U^(m k)),  k=0,1,2,3

比較:
- m=2: 偶数倍音
- m=3: 奇数倍音

各ケースとも4頂点すべての組を結ぶ完全グラフ K4 とし、辺は6本すべて描く。

## 辺長の意味
振幅は1に固定し、絶対中心位相は使わない。
辺長は2波の正規化複素状態空間 C^2 における chord distance:

d_ij = sqrt( |U^i-U^j|^2 + |U^(mi)-U^(mj)|^2 )

したがって、辺長は「時刻差」ではなく、2つの全状態の位相関係の差そのものを表す。

## 実測された辺長

### m=2
- d(0,2)=d(1,3)=2
- その他4辺 = sqrt(6)

### m=3
- d(0,2)=d(1,3)=2*sqrt(2)
- その他4辺 = 2

## 作図
6本すべてを描く。
- 実線: k と k+1 mod 4 の時間隣接関係
- 破線: それ以外の完全グラフ関係
- 3D座標は6辺長から classical MDS で再構成。4点なので距離を機械精度で再現。
