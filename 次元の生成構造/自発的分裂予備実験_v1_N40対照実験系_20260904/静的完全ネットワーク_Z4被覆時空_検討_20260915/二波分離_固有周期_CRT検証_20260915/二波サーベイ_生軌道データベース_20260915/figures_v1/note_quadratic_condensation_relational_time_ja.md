# 時計は相手の中にある――期待を裏切った99走行が見つけた二乗凝縮とケプラー方程式

公開: 2026-09-16　note: https://note.com/kiharanoriaki/n/n5f7376624629

「多波完全関係系における二乗凝縮と関係的局所時間――時空を基本変数として仮定しない関係閉塞からケプラー方程式と逆二乗中心力へ」
を公開しました。

この論文は、前回公開した論文1「時間発展を頂点化した有限完全関係閉系」の直接の続編です。前回は、時間を外から進めずに、異なる位相時点の状態そのものを頂点として扱う最小の閉じた系を、二つの波だけで厳密に解析しました。

今回はその二波構造を、多数の関係波を持つ完全ネットワークへ拡張しました。

## 動機：緩和曲線を探しに行った

系はこう作ります。有限巡回長 L に対して、完全グラフの各辺に複素関係波を1本ずつ置きます。初期状態は、二つの整数倍音の重ね合わせだけです。

　z(0) = ca U^(ma Δ) + cb U^(mb Δ)

力学のカーネルには、倍音番号も偶奇の区別も一切渡しません。頂点を共有する波同士の相対位相だけから実反対称の生成子を作り、全状態を一斉更新します。

条件は事前登録で凍結しました。系サイズ L と倍音対 (ma, mb) を系統的に変えた99走行、各4096ステップ、全状態保存。結果を見てから条件を変えることを禁じた、生軌道データベースの収集です。

![全99走行の初期状態カタログ](fig_initial_states_all99_v4_page1_main72_20260916.png)
全99走行の初期状態。各パネルが1走行で、二成分の合成路（実線がベース波、点線が倍音）と、辺の重複数、重心（緑×）、二乗和（橙×）を重ねて表示している。

狙いは、以前の高対称実験で観測した緩和型の時間構造でした。床にしばらく留まり、あるとき急に立ち上がり、飽和する。あのインフレーション的な緩和曲線が、どの条件で出るのかを網羅的に調べるつもりでした。

## 結果：緩和曲線は1本も出なかった

99走行のうち、5走行は厳密な固定点として静止したまま。残りの94走行は、最初の数ステップで初期平面から一気に離脱しました。床に留まってから立ち上がる走行は、ゼロ本です。

長時間後の状態はこうなります。

![全99走行の最終状態](fig_final_states_all99_page1_main72_20260916.png)
4096ステップ後の全99走行。L が大きい系はほぼ等振幅のリングへ凝縮する。一方、5走行だけは初期配置を厳密に保ったまま静止している。

期待した現象は出ませんでした。しかし、その失敗の代わりに、全99走行を貫く、より単純で強い構造が見つかりました。

## 発見：二乗和は厳密な保存量だった

各走行について、全部の波の「共役を取らない二乗和」

　Σ z² = C²

を全ステップで追跡すると、これが完全な水平線になります。重心 Σ z が激しく振動し、ときに初期値の1.3倍まで増幅されるのと対照的です。

![二乗和と重心の時系列](fig_residual_timeseries_all99_page1_main72_20260916.png)
二乗和（実線）と重心（点線）の全99走行時系列。実線は全パネルで水平線＝厳密保存。点線の重心だけが振動する。

これは数値の偶然ではありません。生成子が実反対称（K^T = −K）なので、一斉更新は実直交変換になり、共役なしの二乗和が代数的恒等式として保存されるのです。数値監査でも、全99走行・4097状態でのdrift は相対10のマイナス12乗以内でした。

ここで読み替えが起きます。この量を「ゼロからのずれ」として見るのではなく、

　多数の内部波を、一つの複素数 C² が厳密に代表している

と読む。これを二乗凝縮と呼ぶことにしました。近似でも平均でもなく、恒等式です。

しかも凝縮体をいくつ集めても、

　Σ Cn² = Σ z²（全体）

という同じ形の閉塞が階層をまたいで成立します。二乗閉塞は、凝縮による粗視化に対して形式不変です。

## 形は最初から決まっていた：形状指標 χ

エネルギー H と C² が同時に保存されると、状態の実部と虚部が張る2枚組の形（Gram 行列）が固定されます。その形を1つの数

　χ = |C²| / H　（0 ≦ χ ≦ 1）

で表せます。運動は形を変えません。固定された2枚組が、高次元の中で回転しているだけです。

![形状指標χのカタログ](fig_chi_all99_20260916.png)
全99走行の χ。赤枠の5走行だけが χ = 1（厳密）で、これが静止していた5走行と完全に一致する。

ここで定理が出ます。全成分が非零で結合が連結なら、

　χ = 1 ⟺ K = 0（厳密固定点）

つまり、静止していた5走行は偶然ではなく、χ = 1 の解析的な帰結でした。さらに χ は初期条件の整数 (L, ma, mb) だけの閉形式で書け、全99走行の実測と機械精度で一致します。4096ステップ走らせる前に、各走行の形は決まっていたのです。

## 時計は相手の中にある

C 自身には平方根の二価性（C と −C）があるので、基本の不変量は C² です。その偏角から、凝縮体 A と B の間の関係位相

　Ũ(A→B) = e^(i(ΘB − ΘA))

が一価に定義できます。逆向きはちょうど逆数。三体では合成則 Ũ(A→B) Ũ(B→C) = Ũ(A→C) が成り立ち、関係のネットワーク全体で時計が整合します。

絶対時計はどこにも要りません。A にとって B が時計であり、B にとって A が時計です。

そして最小の閉塞 C1² + C2² = 0 では Ũ = −1 となり、その平方根は +i と −i の二つ。関係の順序を逆にすると +i と −i が入れ替わります。時間の向きは、外から足した変数ではなく、二乗の平方根構造そのものが持っていた自由度でした。

## そして、ケプラーが出てくる

固定された2枚組を主軸で書き、補完成分 i√|C²| を加えた3成分は、二乗ゼロ閉塞 Σ V² = 0 を厳密に満たしたまま、楕円運動

　u(τ) = a cos ωτ + i b sin ωτ

を与えます。ここに二乗写像

　w = u²

を施すと、一方の焦点が原点にぴったり一致する楕円が現れます。そしてその離心率が、

　e = χ

に厳密一致します。形状指標は、二乗写像後のケプラー楕円の離心率そのものでした。C² = 0 は円軌道に対応します。

時計の読み出し規則として

　dt = r dτ

を一つだけ公理として置くと（ここは導出ではなく公理です。論文では明示しています）、

- ケプラー方程式　M = E − e sin E
- 面積速度一定（第2法則）
- 逆二乗中心力　d²r/dt² = −μ r / r³
- 第3法則　n² A³ = μ

がすべて導かれます。調和振動子とケプラー問題の二乗対応自体は Bohlin と Levi-Civita 以来の古典的な結果です。今回の相違点は、二乗写像を仮定して作ったのではなく、関係閉塞と固定 Gram 幾何から二乗写像が独立に現れたこと、そして時間変数 t 自体が外から与えられず、関係時計の読み出しとして現れることです。

## 何を確定し、何を仮定したか

論文では、確定した数学的・数値的結果16項と、確定していないこと8項を分けて明記しました。

確定しているのは、二乗和の厳密保存、二乗凝縮と階層閉塞の形式不変性、χ = 1 と固定点の同値、χ の閉形式、凝縮体間の反対称二乗流、関係位相の合成則と二重被覆、二乗写像による e = χ、そして読み出し公理の下でのケプラー方程式群です。

確定していないのは、凝縮体が現実の何に対応するか、読み出し公理 dt = r dτ 自体の導出、緩和曲線の発生条件などです。途中で試みて撤回した仮説（双曲角と軌道パラメータの同一視が周期性と矛盾する反証）も、検討の記録として本文に残しました。

## 結び

一本の鎖にまとめます。

　実反対称 → H と C² の保存 → 固定 Gram → 二乗凝縮と階層閉塞 → 関係の時計 → 二乗写像 → e = χ → dt = r dτ → ケプラー方程式 → 逆二乗力

物理時間も空間座標も基本変数として置かずに、保存幾何、局所時計、ケプラー方程式、逆二乗中心力が、一つの二乗構造でつながりました。

出発点は、期待した緩和曲線が1本も出なかったという失敗です。事前登録した99走行を、結果を見てから曲げずに全部保存したことが、この保存則を見つけさせてくれました。

次の課題は、二乗閉塞を保った複数凝縮体を明示的に構成し、高対称で重心が原点近傍にある中間領域で、以前のインフレーション型緩和曲線が再現されるかを独立に検証することです。
