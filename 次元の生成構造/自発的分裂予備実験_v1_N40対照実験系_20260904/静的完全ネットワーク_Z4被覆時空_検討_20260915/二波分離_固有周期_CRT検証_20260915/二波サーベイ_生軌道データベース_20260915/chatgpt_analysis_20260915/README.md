# Read-only analysis of the frozen 99-run relational-wave survey

## Contents
- analysis_report_ja.md: detailed Japanese results and limitations.
- overview_99.csv: one row per run, compact comparison.
- window_metrics.csv: 495 full/window rows.
- all_runs_metrics.csv, all_frame_metrics.csv, instantaneous_metrics.csv: detailed numerical tables.
- figures/: complete condition maps and diagnostics.
- per_run/, timeseries/, instantaneous/: auditable per-run numerical output.
- raw_hash_audit.json: all 99 original state hashes verified.
- source_records/: frozen specification, original manifest/QA/hashes and kernel.
- executed_code/: exact scripts used in this execution before path portability edits.

No original trajectory was altered or simulated again. The 1.7 GB original states
are deliberately excluded from this package and remain in the source Drive folder.
The collection was preregistered. This post-collection analysis is exploratory;
its new equal-length windows must not be described as preregistered hypotheses.
No evidence of physical particle identity or physical clock calibration is claimed.

## Reproduce on the source repository (Python, NumPy, SciPy, pandas, matplotlib)
Use a NEW output directory. The program caches previously processed runs.

```sh
export SURVEY_INPUT_DIR="/absolute/path/to/survey"
export SURVEY_RAW_DIR="$SURVEY_INPUT_DIR/runs"
export SURVEY_OUTPUT_DIR="/absolute/path/to/new_analysis_output"
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
python analyze_survey.py
python analyze_frames.py
python analyze_instantaneous.py
python verify_analysis.py
python summarize_results.py
```

`verify_analysis.py` writes local dense-reference checks. The executed audit JSON
also includes a subsequent comparison of low-rank and dense eigenvalues/weights.
The analysis report is a separately authored interpretation, not generated by the
numerical scripts. See the report for all definitions and limitations.

## Metrics
r99 counts covariance directions needed for 99% of sum-of-squares state norm;
it is NOT particle count, spacetime dimension or instantaneous generator rank.
W1=[0,1024), W2=[1024,2048), W3=[2048,3072), W4=[3072,4096).
Full includes 4097 states; final-state diagnostics use t=4096.
Instantaneous generator spectra are sampled at t=0,512,...,4096.
SVD coefficient phase increments are principal values, not uniquely established
physical winding. Frozen generator phase folding is documented explicitly.
