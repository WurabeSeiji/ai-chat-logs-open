## 1. 問い

【木原】「Q 軸 3 つは考えましたが、戻ってヒッグス場です。今の整理とヒッグス場って、どうなりますか？ 運動量を持たないなら x, y, z もゼロ、電荷がないなら電荷の位相もゼロなんですか？」

## 2. 「0」には意味が三つある

巻数は 0 である。ただし 0 なのは巻数であって、大きさでも、位相の値でもない。

| | 意味 | ヒッグス場の真空では |
|---|---|---|
| 巻数が 0 | その軸に沿って波が振れない。一様 | x, y, z の巻数は 0 |
| 位相が決まらない | 巻数を決めた代わりに、対になる位相は決まらない | 位置が決まらない。どこにでも同じようにある |
| 大きさが 0 | 状態がない | 0 ではない。v がある |

運動量を持たないことは、x, y, z の巻数が 0 であること。位相と巻数は対なので、位置はまったく決まらない。「空間に普遍的にある」ことの中身はこれである。【読み】

## 3. 電荷の合計が 0 であることと、Q がすべて 0 であることは別

【木原】「弱アイソスピンとハイパーチャージの 180°、これなんで Q₁ Q₂ Q₃ に入れないんですか？ 電荷の合計がゼロなのと、Q は全て 0 なのは別ですよね。」

その通りで、Q 軸の「0」も三通りある。Qᵢ の単位は素電荷の 1/3。

| | Q₁, Q₂, Q₃ | 中身 | 例 |
|---|---|---|---|
| 合計だけ 0 | (＋1, −1, 0) など | Q が不揃いなので色がある | グルーオン型（同じ電荷で色の違うクォーク 2 個の差） |
| 三つとも 0 だが、打ち消しの結果 | (0, 0, 0) | 各軸に半周が二つ載っていて、逆向き | 中性のヒッグス成分、左巻きのニュートリノ |
| 何も載っていない | (0, 0, 0) | 半周そのものがない | 光子、Z、右巻きのニュートリノ |

中性のヒッグス成分は 2 番目である。電荷 0 は T₃ ＋ Y/2 ＝ −1/2 ＋ 1/2 の打ち消しで、どちらの半周も消えていない。【標準模型】

### ここで起きた誤読

- Claude は、Q が全部 0 であることを「Q 軸には何もない」と読み、弱アイソスピンとハイパーチャージの 180° を (t, R) の面に置いた。
- 続けて、各 Q 軸の中身を ±1/2 の成分の足し引きで書いた。

【木原】「なんですぐ忘れるかな？ 指数にしないと積で足し算にならないの忘れた？ だから値を位相表現したんだけど？ 今は t, R の意味決めてないだけですよ。」

足し算で保存される量は、成分ではなく指数（位相・巻数）の側にある。これは前の思考実験で確かめたことで、以下はすべて位相で書く。

【取り下げ】
- 「180° の置き場所は (t, R) の面」
- 「t が弱アイソスピンの符号、R が左右の符号」
- 「R が差の成分を担う」

t と R の意味はまだ決めていない。以下の話は Q の 3 軸だけで閉じている。

## 4. 各 Q 軸に位相の因子を二つ載せる

各 Q 軸の状態は位相の因子 e^{iθ} で、積を取ると因子が掛かり、角度が足される。各軸には因子が二つある。

- **弱アイソスピンの分**：三つの軸に共通の角度。
- **ハイパーチャージの分**：軸ごとの角度。三つが揃えば色なし、不揃いなら色あり。
- **電荷**が読むのは、二つの因子の積の角度だけ。360° が Qᵢ ＝ 1 にあたる。

### 一覧【標準模型を位相に並べ直したもの。T₃ と Y の値との一致は確かめた】

角度は (Q₁, Q₂, Q₃) の順。クォークは色を 1 つ選んだ例。反粒子は全部の角度が逆向き。

| | 弱アイソスピンの分 | ハイパーチャージの分 | 積の角度 | 電荷 |
|---|---|---|---|---|
| ヒッグス（中性） | −180° 共通 | (＋180, ＋180, ＋180) | (0, 0, 0) | 0 |
| ヒッグス（荷電） | ＋180° 共通 | (＋180, ＋180, ＋180) | (360, 360, 360) | ＋1 |
| ν 左 | ＋180° | (−180, −180, −180) | (0, 0, 0) | 0 |
| e 左 | −180° | (−180, −180, −180) | (−360, −360, −360) | −1 |
| u 左 | ＋180° | (＋180, ＋180, −180) | (360, 360, 0) | ＋2/3 |
| d 左 | −180° | (＋180, ＋180, −180) | (0, 0, −360) | −1/3 |
| ν 右 | 0° | (0, 0, 0) | (0, 0, 0) | 0 |
| e 右 | 0° | (−360, −360, −360) | (−360, −360, −360) | −1 |
| u 右 | 0° | (360, 360, 0) | (360, 360, 0) | ＋2/3 |
| d 右 | 0° | (0, 0, −360) | (0, 0, −360) | −1/3 |
| W⁺ | ＋360° | (0, 0, 0) | (360, 360, 360) | ＋1 |
| Z、光子 | 0° | (0, 0, 0) | (0, 0, 0) | 0 |
| グルーオン（例） | 0° | (360, −360, 0) | (360, −360, 0) | 0 |

対応は T₃ ＝（弱の分の角度）/360°、Y/2 ＝（ハイパーチャージの分の角度の 3 軸の和）/1080°、電荷 ＝（積の角度の 3 軸の和）/1080°。

## 5. 頂点の検算【確かめた】

【木原】「ここでヒッグスの Q の位相ベクトルを考えたんで、ヒッグスと積をとって相互作用する他の粒子の Q も一覧にして、再度矛盾しないか検討してください。」

頂点ごとに「入る側の角度の和 ＝ 出る側の角度」を、二つの因子それぞれについて、軸ごとに確かめた。

| 頂点 | 弱の分 | ハイパーチャージの分 |
|---|---|---|
| e 右 ＋ ヒッグス（中性） → e 左 | 合う | 合う |
| e 右 ＋ ヒッグス（荷電） → ν 左 | 合う | 合う |
| d 右 ＋ ヒッグス（中性） → d 左 | 合う | 合う |
| d 右 ＋ ヒッグス（荷電） → u 左 | 合う | 合う |
| u 右 ＋ ヒッグス（中性）の逆向き → u 左 | 合う | 合う |
| u 右 ＋ ヒッグス（荷電）の逆向き → d 左 | 合う | 合う |
| ν 右 ＋ ヒッグスの逆向き → ν 左、e 左 | 合う | 合う |
| ヒッグス（中性） ＋ W⁺ → ヒッグス（荷電） | 合う | 合う |
| ヒッグス（中性） ＋ Z → ヒッグス（中性） | 合う | 合う |
| ヒッグス ＋ 光子 → ヒッグス | 合う | 合う |
| ヒッグス ＋ グルーオン → ヒッグス | 合う | 合わない（360, −360, 0 が余る） |

- 質量を与える頂点は、すべて二つの因子が別々に合う。
- u 型だけはヒッグスの逆向き（全部の角度を反転したもの）が要る。位相で書けば反転するだけなので、ヒッグスのベクトルは 1 種類で足りる。
- グルーオンとは合わない。ヒッグスがグルーオンと直接は作用しないことと一致する。
- 光子は角度が合うが、光子が読むのは積の角度で、中性のヒッグスでは 0° である。直接作用しないことと一致する。

### 真空の値を挟む場合【確かめた】

質量項は、ヒッグスの脚を真空の値に替えたものである。右巻きと左巻きを直接比べる。

| | 弱の分の差 | ハイパーチャージの分の差 | 積の角度の差 |
|---|---|---|---|
| e 右 → e 左 | 180° | −180° | 0° |
| d 右 → d 左 | 180° | −180° | 0° |
| u 右 → u 左 | −180° | 180° | 0° |

二つの因子は別々には合わず、積の角度だけが合う。真空が中性ヒッグスの分（∓180°, ±180°）を出し入れしているからである。真空のもとで残るのは電荷だけ、という事実と一致する。【標準模型】

- 和（積の角度）を回すのが光子。中性の成分は和が 0° なので、光子は真空を動かさない。
- 差を回すのが Z。中性の成分で差は 0 でないので、真空は動く。
- 真空の値 v は、和の方向では巻数 0。差の方向では位相が決まっていて、巻数（T₃ と Y の値）が決まらない。対称性が破れているというのは後者のこと。【読み】

## 6. 見つかったこと

### 6.1 2 周では区別が足りない。3 周で足りる。【確かめた】

角度を何周で同じと見なすかで、区別できなくなる粒子が変わる。

| 戻る周数 | 同じになってしまうもの |
|---|---|
| 1 周 | 左巻きとヒッグスが全部同じ。右巻きとゲージ粒子が全部同じ |
| 2 周 | ＋360° と −360° が同じ。e 右と反 e 右、W⁺ と W⁻、u 右とグルーオンが同じ |
| 3 周 | 6.2 と 6.3 だけ |

- 1 周では ＋180° と −180° が同じ −1 になり、中性と荷電の区別が消える。
- 2 周では ±180° は分かれるが、±360° が同じになり、電荷の正負が消える。
- 3 周（1080°）で、この一覧の粒子は 6.2 と 6.3 を除いてすべて分かれる。

### ここで起きた誤読

Claude は「2 周で戻る数え方にして初めて区別できる」と書いた。±180° までしか見ていない言い過ぎで、一覧を作って初めて ±360° の同一視に気づいた。

### 6.2 ヒッグスは反レプトンの左巻きと同じベクトルになる。【確かめた】

中性のヒッグスは反 ν 左と、荷電のヒッグスは反 e 左と、二つの因子まで含めて同じである。周数を増やしても区別できない。Q の 3 軸だけでは区別がつかず、違いはスピンの側にある。

### 6.3 ν 右、Z、光子はどれも全部 0°。【確かめた】

「何も載っていない」(0, 0, 0) にあたるのがこの三つで、Q の 3 軸だけでは区別がつかない。

### 6.4 因子の角度に偶奇の規則がある。【確かめた】

- 左巻きとヒッグス：二つの因子がどちらも 180° の奇数倍。
- 右巻きとゲージ粒子：どちらも 180° の偶数倍。
- どの粒子も、積の角度は軸ごとに 360° の整数倍。
- ヒッグスは、偶数倍の側と奇数倍の側をつなぐ唯一のものである。

## 7. 最初の問いへの戻り

「cos のスカラー波は、ヒッグス波・ヒッグス粒子の候補たりえるのか」について、ここまでで言えること。

- 運動量 0、電荷 0、色なしは、「持てない」のではなく「巻数 0 として持っている」と読める。`1` に M が付かない、という元の書き方は、その軸に倍音がないこと、と読み替えられる。【読み】
- ただし Q の 3 軸は空ではない。中性の成分でも、各軸に逆向きの 180° が二つ載っている。実数 1 個では足りない、という点は変わらない。

## 8. 分かっていないこと

- 一覧は標準模型の量子数を位相に並べ直したもので、八元数の積からは出していない。
- 3 周で足りるのは、この一覧の粒子についてである。
- 6.2 と 6.3 の区別を何が担うか。Q の 3 軸の外の話で、手を付けていない。
- t と R の意味。決めていない。（候補は §12.2、§12.7）
- 一様であること（巻数 0）から、局所的に励起されて粒子になること（x, y, z に倍音が立つこと）への移り変わりを、写像としては書けていない。
- 大きさ v が何で決まるか。ノルムの一定の部分、という所までである。

## 9. Q の 3 軸も、内部方向の運動量（位相の勾配）と読む

【木原】「八元数の Q 軸 3 つだけ検討しましたが、ヒッグス粒子を考えるのに、まだ 5 軸あります。x, y, z が空間方向の運動量の位相勾配と考えて良さそうですが、今の Q 軸 3 軸も、ある種、内部位相空間方向の運動量の位相勾配と解釈した方が理解しやすくないですか？」

| | x, y, z | Q₁, Q₂, Q₃ |
|---|---|---|
| 状態 | e^{ikx} | e^{iQᵢχᵢ}（χᵢ は内部の角度） |
| 読む量 | 運動量 ＝ 位相の勾配 | 電荷と色 ＝ 内部方向の位相の勾配 |
| 保存の理由 | その方向にずらしても変わらない | 内部の角度をずらしても変わらない |
| 勾配 0 | 一様。位置が決まらない | 電荷 0。内部の角度が決まらない |
| 勾配を重ねる | 位置が決まる（局在） | 内部の角度が決まる |

電荷を閉じた内部方向の運動量と読むのは、カルツァ＝クラインの理論と同じ既知の構造である。【標準の物理】

この読みでは、真空の値についての二つの言い方（§5）が一つになる。**真空は、空間の 3 方向と電荷の方向には一様で、差の方向にだけ局在している。**【読み】

### ここで起きた誤読

- Claude は、x, y, z を「閉じた系なら離散」と条件付きで書き、Q だけを「内部方向が閉じているので整数」と別扱いにした。

【木原】「まず私は、有限で有界な複素ヒルベルト空間という仮定をしているのを忘れました？ したがって空間も Q と同様に離散している前提ですよ？」

前提では、x, y, z も Q₁, Q₂, Q₃ も閉じた方向の上の巻数で、どちらも整数である。6 軸は同じ資格で、違いは一周の刻みの数だけである。

- Claude は「質量が電荷で決まってしまうので、x, y, z と同じ扱いにはできない」と書いた。連続な空間でのエネルギーと運動量の関係を黙って持ち込んだ議論で、【取り下げ】。残るのは事実の側だけである。同じ Q で質量が大きく違う粒子がある（u とトップ）ので、t の巻数は Q の巻数だけでは決まらない。
- Claude は「Q が 6 通りで x, y, z が大きな n である理由が要る」と書いた。

【木原】「理由ないです。そうなるから時空って読めるんでしょう。初期の高対称な状態ですよ。ガチガチに凍結した結晶状態が解けてスカスカになる、ってモデルを忘れてますよ？ 繰り返し全ての関係の積を取ると、巻き数が増えてスカスカになるだけでは？」

刻みの数に理由を求めるのは、出来上がった時空を先に置いて説明する向きで、モデルと逆である。【取り下げ】

### 独立な角度は 4 つある

§4 の一覧では、各粒子は独立な角度を 4 つ持つ。弱アイソスピンの分（3 軸に共通）が 1 つ、ハイパーチャージの分（軸ごと）が 3 つである。Q の 3 軸には 3 つしか入らない。真空のもとで保存される積の角度 3 つが Q の 3 軸を埋め、残る 1 つ（真空が局在している差の方向）には、もう 1 方向が要る。【数え上げ】

## 10. 巻数が増える積、減る積

前の思考実験で確かめた三つ組の写像では、三つ組の積 P は 1 回で P′ ＝ conj(P)² になり、位相は φ → −2φ で 1 回ごとに 2 倍になる。倍音の次数は m → m − Σm と移り、和が 0 の組は動かず、和が 0 でない組は和が 1 回ごとに 2 倍になる。【確かめた】

Claude は当時、この「2 倍になる」を、ずれが育ってしまう不都合として扱った。積を繰り返すと巻数が増えること自体が、融けて広がることの中身である、というのが木原の指摘である。

【木原】「巻数が減り続ける積もありえますよね？」

- 位相の因子の積では指数が足されるので、共役を挟めば引き算になる。z·w では m₁ ＋ m₂、z·conj(w) では m₁ − m₂。増えるか減るかは、積の取り方で決まる。
- 巻数を n を法として数えると、−2 倍の写像は、n の奇数の部分では並べ替えで、何回かで元に戻る。偶数の部分では戻れない。
- Q の 6 通り（180° 刻みで 3 周）に当てると、360° の倍数は動かず、180° の奇数倍は 1 回で偶数倍の側に落ちて戻らない。【手計算。プログラムでは確かめていない】

この写像と、「減り続けて 0 で止まる」という言い方は、§12.5 で候補から外れる。逆にたどれない写像だからである。

## 11. 左から掛ける、右から掛ける、挟む

【木原】「さらに、問題は、八元数は左からかけるか右からかけるかでも全く別な結果になるのを忘れてませんか？」

ここ数節の「積を取ると角度が足される」は、掛ける順番も括弧の付け方も気にしない書き方で、八元数ではそのままでは成り立たない。

### 左と右で何が変わるか【確かめた】

e₇ を選び、a ＝ cos θ ＋ e₇ sin θ を掛ける。8 軸は (1, e₇) の面と、残り 6 軸が作る 3 枚の面 (e₂, e₅)、(e₃, e₄)、(e₆, e₁) に分かれる。

| 掛け方 | (1, e₇) の面の回転 | 3 枚の面の回転 |
|---|---|---|
| 左から a x | ＋θ | ＋θ, ＋θ, ＋θ |
| 右から x a | ＋θ | −θ, −θ, −θ |
| 挟む a x a⁻¹ | 0 | ＋2θ, ＋2θ, ＋2θ |
| 両側 a x a | ＋2θ | 0, 0, 0 |

- 左と右の違いは、3 枚の面の回る向きがちょうど逆になることである。
- 左と右を組み合わせると、3 枚の面だけを回す掛け方（挟む）と、(1, e₇) の面だけを回す掛け方（両側）に分かれる。
- §9 の「独立な角度が 4 つ、もう 1 方向が要る」に対して、3 枚の面に共通の回転と、もう 1 方向の回転が、最初から別々に出てくる。【読み】

### 挟む掛け方が積を保つ角度【確かめた】

挟む掛け方 x ↦ a x a⁻¹ が八元数の積を保つのは、a の角度が 0°、60°、120°、180°、240°、300° のときだけである。3 枚の面の回転では 120° 刻みになる。前の思考実験で確かめた「0°・120°・240° だけ」と同じ事実を、a の側で見たものである。既知の数学（a³ が実数のとき）と一致する。

Q の検算（§6.1）で必要になった「6 通り」と数は合う。ただし、あちらは 180° 刻みで 3 周、こちらは 60° 刻みで 1 周で、同じ 6 なのかは確かめていない。

### 足し算が成り立つ範囲【確かめた】

| 場合 | 順番・括弧を変えた差 |
|---|---|
| 掛けるものが同じ軸（どちらも e₇）にある | 0（計算誤差の範囲） |
| 別の軸（e₇ と e₃）にある：a(xb) と (ax)b | 約 1.5 |
| 別の軸にある：a(bx) と (ab)x | 約 1.5 |

角度の足し算がそのまま使えるのは、掛けるもの同士が同じ軸にあるときだけである。§4〜§6 の一覧と頂点の検算は、各軸の角度を数として足している。別の軸を持つ粒子同士の積で同じ足し算になるかは、確かめていない。

### 14.1 確認 1：軸の名前を当てる【確かめた】

[QCD] (8.1) の対応 o ＝ q ＋ pℓ（ℓ ＝ e₇、q ＝ t ＋ x e₁ ＋ y e₂ ＋ z e₃、p ＝ R ＋ Q₁e₁ ＋ Q₂e₂ ＋ Q₃e₃）では、Q₁ ＝ e₆、Q₂ ＝ −e₅、Q₃ ＝ −e₄ になる。a ＝ cos 25° ＋ e₇ sin 25° を掛けた結果は次のとおり。

| 掛け方 | (t, R) | (x, Q₁) | (y, Q₂) | (z, Q₃) |
|---|---|---|---|---|
| 左から a o | ＋25° | −25° | −25° | −25° |
| 右から o a | ＋25° | ＋25° | ＋25° | ＋25° |
| 挟む a o a⁻¹ | 0° | −50° | −50° | −50° |
| 両側 a o a | ＋50° | 0° | 0° | 0° |

### 14.2 確認 2：Σo² ＝ 0 は何で保たれるか【確かめた】

Σo² ＝ 0 を満たす 7 個の八元数の組を作り、各変換のあとの Σo² の大きさを見た。比較の目安は Σ|o|² ≈ 73。

| 変換（全員に同じものを掛ける） | 変換後の Σo² の大きさ | 保つか |
|---|---|---|
| 挟む u o u⁻¹（u は任意の向き） | 10⁻¹⁴ | 保つ |
| 実数倍 | 10⁻¹³ | 保つ |
| 虚部 7 次元の任意の回転 | 10⁻¹⁴ | 保つ |
| 左から u o | 68 | 破る |
| 右から o u | 68 | 破る |
| 両側 u o u | 32 | 破る |
| 挟む（状態ごとに別の u） | 13 | 破る |

- [四元数] §6.4 の結果は、八元数にそのまま移せる。挟めば保たれ、片側だけでは破れる。
- 八元数では、保つ変換はもっと広く、1 の軸を動かさない回転なら何でも保つ。挟む掛け方はその一部である。
- 全員に同じ u を使うことが必要である。状態ごとに別の u で挟むと破れる。

|---|---|
| Σo² ＝ 0 を保つ | どの角度でも |

### 14.3 確認 3：左巻き・右巻きと左右の掛け方

**(a) 素朴な当て方は成り立たない。【確かめた】**

「左巻きは左から掛けるだけ、右巻きは右から掛けるだけ」とは置けない。左巻きの ν と e は、弱の分が ＋ と − で、ハイパーチャージの分が同じである。この 2 つは独立な 2 方向を張る。「左からだけ」は 1 本の線なので、2 つを同時には載せられない。§12.1 の読み（左巻きと右巻きを左右の掛け方に当てる）は、この形では【取り下げ】。

**(b) 弱の分を左から、ハイパーチャージの分を右から掛ける。【確かめた】**

前の思考実験での四元数の整理（SU(2) が左から、ハイパーチャージが右から）と同じ当て方である。各粒子を「左から e₇ の位相、右から e₇ の位相の共役」を掛ける操作とし、頂点を実際の八元数の積で合成した。

| 頂点 | 合成した結果と出る側の差 | 順番を逆にした差 |
|---|---|---|
| e 右 ＋ ヒッグス（中性） → e 左 | 10⁻¹⁶ | 10⁻¹⁶ |
| e 右 ＋ ヒッグス（荷電） → ν 左 | 10⁻¹⁶ | 10⁻¹⁶ |
| ν 右 ＋ ヒッグスの逆向き → ν 左、e 左 | 0 | 0 |
| ヒッグス（中性） ＋ W⁺ → ヒッグス（荷電） | 10⁻¹⁶ | 10⁻¹⁶ |
| e 左 ＋ W⁺ → ν 左 | 10⁻¹⁶ | 10⁻¹⁶ |

- 順番を変えても、括弧を付け替えても、結果は同じである。掛けるものがすべて同じ軸（e₇）にあるからで、§11 の「足し算が成り立つ範囲」の内側である。
- この当て方では、「左巻き」は左からの掛け算に応じるもの（弱の分が 0 でない）、「右巻き」は右からの掛け算だけに応じるもの、という意味になる。

仮定が二つ入っている。

- 単位を 60° にした。§6.1 の「180° 刻みで 3 周」を、1 周の中の 60° 刻みに読み替えたものである。挟む掛け方が積を保つ 60° 刻みと同じ数になるように、Claude が選んだ。
- 色を持つ粒子の軸ごとの角度は、e₇ の左右の積からは出ない。3 枚の面の回転として手で置いた。

**(c) 4 枚の面の角度に並べ直す。【確かめた】**

独立な角度 4 つ（弱の分 1 つ、ハイパーチャージの分 3 つ）は、4 枚の面の回転角 4 つに、過不足なく対応する。

- 荷電のヒッグスと e 左は、3 枚の面だけにいる。
- クォークの (t, R) の角度は、3 軸の平均を取るという Claude の置き方による。

**八元数の積を保つのは、(t, R) を動かさず、3 面の角度の和が 360° の整数倍のときだけである。** (b) の当て方では、和を 360° で割ったものが電荷なので、これは「電荷が整数」という条件になる。

- クォーク 1 個（電荷 ±1/3、±2/3）の回転は、積を保たない。
- 色の回転（グルーオン）と、電荷が整数で (t, R) を動かさないものは、積を保つ。

### 15.3 R について、その時点で書かれていたこと

- **(10/13)成分自身の二乗和で決める。** 【木原】「本来は Σxn^2=R^2 で決めますが?」「Σxn^2=0 はノルムではないですよ!」「円周の外なんてないですよ?」。虚数の振幅 xₙ ＝ iA cos(n(θ−θ₀)/2) なら R² ＝ −A²Σcos² で負になり、R は虚数で、振幅と同じ種類の量である。絶対値の二乗と実数の半径で解いた最初の数値実験(自己無撞着殻)は、この訂正で不採用になった。
- **(10/12)0 は保存量の値ではない。** Σx² ＝ R² は、値 R を軸 iR として足せば Σx² ＋ (iR)² ＝ 0。「0 そのものには情報がない。情報は、どの軸が値(R)を運んでいるかにある。」同じ節で、双曲空間 t² − Σx² ＝ R² を Σx² ＋ (it)² ＋ R² ＝ 0 と書く。t と R が一つの式に入る。
- **(10/14)光円錐の読みでは、全体の回転の予算。** R² ＝ k² ＋ m²。k は方向を持つ成分、m は張り付いた成分。
- **(10/29)単独のパルスでは、倍音のノルム。** R² ＝ Σ_{m≠0}|c_m|²。「何が R を与えるか」は、単独のパルスについては「自分自身」。値そのものはスケールで、物理なのは比。

- **(10/31)四元数では、R に効くのは交差項のスカラー部だけ。** 軸どうしの内積 nᵢ·nⱼ だけが入り、外積 nᵢ×nⱼ はベクトル部にしか現れない。軸が揃っていない対があると、親の R は内部の時計の一歩ごとに振動する。

### 15.4 t と τ について、その時点で書かれていたこと

## 付録 A：Q の位相ベクトルと頂点の検算のプログラム（§4〜§6）

```python
def P(w,y): return np.array([w,w,w]), np.array(y)
```

## 付録 B：左・右・挟むの検算のプログラム（§11）

```python
import numpy as np
rng=np.random.default_rng(3)
tri=[(1,2,3),(1,4,5),(1,7,6),(2,4,6),(2,5,7),(3,4,7),(3,6,5)]

    for (i,j,k),s in [((a,b,c),1),((b,c,a),1),((c,a,b),1),((b,a,c),-1),((a,c,b),-1),((c,b,a),-1)]: f[i,j,k]=s
```
