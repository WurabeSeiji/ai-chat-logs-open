## 2. ヒッグス場に要る性質

### 2.1 既知の性質

【既知】標準模型のヒッグス場は次の性質を持つ。

- スピン 0。
- 場は弱アイソスピンの 2 重項で、複素数 2 個、実 4 成分。
- 真空で、大きさ v/√2（v ≈ 246 GeV）の値を持つ。
- 4 成分のうち、位相の 3 方向は W⁺・W⁻・Z の縦の偏極になる。残る動径方向の 1 成分（振幅の揺らぎ）がヒッグス粒子 h である。φ = (0, (v+h)/√2)。
- h の結合は、相手の質量に比例する。光子・グルーオンとは直接は結合せず、ループを介して結合する。
- 陽子・中性子の質量の約 99% は、ヒッグス場ではなく QCD から来る。

### 2.2 「一様で 0 でない」は、ノルムを取っているだけである

Claude は最初に「真空で節のない一様な値を持つ」を条件に挙げ、cos 波には節があるから失格だと書いた。

> 【木原】真空で、節のない一様な値を持ち、その値が 0 でない。波打っていない、が条件なら、逆にスカラーしかありえないですよ？DC 成分しかないといっていますよ？

> 【木原】現在の cos 波でも、二乗すれば当たり前に、非ゼロになりますよ？？

> 【木原】だから、それただのノルムを取ってるだけですよね？複素数なら成り立ちますよ？半径 1 の S¹ にのってるだけですよね？？

**ここで起きた誤読。** Claude は、cos 波の「値」とヒッグス場の「二乗」を比べた。次に「90° ずれた相手がいればうねりが消える」と書いたが、同じ実軸の上の波は振幅が足されるだけで、cos θ + sin θ = √2 cos(θ − 45°) となり、うねりは消えない。パワーが足されるのは、相手が直交する別の軸（虚軸）にあるときだけで、それは複素数のノルムである。

整理すると次のとおりである。

- 【既知】ノルムが一定の集合は、成分の数で決まる。実 1 成分なら S⁰（±v の 2 点）、複素数なら S¹、実 4 成分なら S³。
- 【既知】実数の cos 波の二乗は ½ + ½cos 2θ で、定数部と同じ大きさのうねりを必ず持つ。
- 「φ†φ が一様で 0 でない」は、状態が決まった半径の球面に乗っている、と言っているだけである。位相は、ノルムを取った時点で捨てている。

### 2.3 素直に読めば、スカラーの cos の定常波である

> 【木原】これを素直に読むと、ただのスカラーの cos の定常波ですが？？

- 【既知】h は実 1 成分である。実数の波は cos にしかなれない。回る向きを持つ e^{iθ} には虚部が要る。cos = ½(e^{iθ} + e^{−iθ}) は、右回りと左回りが同じ重みで重なった、回らない波である。h が電荷 0 で、自分自身が反粒子であることと同じ事実である。
- 有界で閉じた系なら、定常波になる。これは標準模型ではなく、著者の前提から出る。
- 場の全体は v + h であり、h の節は場の節ではない。

### 2.4 位相に 3 方向が要るなら、四元数である

> 【木原】位相に、３方向がいるのなら、素直に、四元数ですよ？

【既知】実 4 成分を「実軸 1 本＋位相 3 方向」に分けた形は、四元数の極形式である。

$$
q = \rho\,(\cos\alpha + n\sin\alpha),\qquad \rho = v + h
$$

- ρ が大きさで実数。位相は角度 α と向き n ∈ S² の 3 方向で、これが W±・Z に吸われる。
- 真空の点を実軸の 1 に取ると、球面 S³ に接する 3 方向が虚軸、残る 1 方向が実軸である。

### 2.5 v はどこから来るか

> 【木原】ｖがどこからですか？？がなぜなぞなんですか？よめばすぐ分かるきがしますか？？|j (v + h)|² = (v + h)² = v² + 2vh + h² その通りでしょ？

**ここで起きた誤読。** Claude は「v が何から出るかは四元数の形からは出ない」と書いた。標準模型の書き方（値が 0 の所を出発点にして、ポテンシャルで v だけずらす）に引きずられていた。

- 【既知】|j(v+h)|² = |v+h|² は、ノルムの乗法性 |xy| = |x||y| である。W が読んでいるのは、ヒッグス場の四元数のノルムの二乗である。
- 状態があれば、ノルムの二乗は 0 でない。その一定の部分が v² である。v² が W の質量、2vh がヒッグス粒子と W の結合にあたる。
- cos の定常波なら、(A cos θ)² = ½A² + ½A² cos 2θ で、二乗した時点で一定の項が出る。
- 【仮説・未検証】クォークとレプトンの質量は v の一次で入る。A cos θ の平均は 0 なので、一次の量として何を読むのかは、決めていない。

## 3. 光子は、共役な複素数である

> 【木原】読みがいい加減、、もしそうなら、四元数ではなく、共役な複素数ですよ？

【既知】ヒッグス場を四元数 q と書くと、電弱の対称性は二つの掛け算になる。SU(2) は左から単位四元数を掛ける u q、ハイパーチャージの U(1) は、決まった虚数単位 i の位相を右から掛ける q e^{−iα} である。真空 q = v を動かさない組み合わせは、左右を逆向きに同時に掛けるものだけで、これが電磁気の U(1) である。q = z₁ + z₂ j と分けると、

| 操作 | 式 | 真空を動かすか | 対応する粒子 |
|---|---|---|---|
| 左からだけ | u q | 動かす | 混ざる前の W³ |
| 右からだけ | q u | 動かす | 混ざる前の B |
| 同じ向きに両側から | u q u = e^{2iα} z₁ + z₂ j | 動かす | Z |
| 共役で両側から | u q ū = z₁ + e^{2iα} z₂ j | 動かさない | 光子 |

- 光子の側にあるのは、複素数 u とその共役 ū だけである。虚軸は 1 本、自由度は位相 1 つで、j も k も要らない。**光子は共役な複素数である。**
- 共役の相手を持たない「ただの複素数」は、真空を動かす側、質量を持つ側になる。
- 電荷は、挟んだときに回る量である。i と可換な z₁ は動かず（電荷 0）、可換でない z₂ j だけが回る。
- 四元数が要るのは、光子の側ではなく、作用を受ける側である。

**ヒッグス粒子と光子の作用。** 実数は何とでも可換なので u(v+h)ū = v+h。光子は質量を持たず、ヒッグス粒子と直接は結合しない。結合できる経路は「電荷を持ち、かつ真空を動かすもの」を間に挟む一本だけで、既知の事実（W やトップクォークのループを介した 2 光子崩壊）と同じ形である。強さ（約 0.23%）は、この代数からは出ない。

**位置づけ。** ここまでは、標準模型が知っていることを、四元数と共役な複素数の言葉に書き直しただけである。新しく導いたことはない。

## 4. スピンとは何か

> 【木原】スピンとは？考えずに、スピンの議論してますよね

**ここで起きた誤読。** Claude は「虚軸があるからスピンがある」「実数だからスピン 0」「挟むと 2 倍角だからスピン 2」と書いた。数の中の回転に、スピンという名前を貼っただけだった。また、同じ四元数の虚軸 3 本を、ある場面では空間の方向、別の場面では W±・Z に吸われる位相として使った。標準模型では、前者はスピンの側、後者は弱アイソスピンの側で、別の回転である。

- 【既知】スピンは、空間を回したときに粒子の状態がどう変わるかを表す量である。スピン 0 は何も変わらない。スピン 1 は 360° で、スピン 2 は 180° で、スピン 1/2 は 720° で元に戻る。
- 【既知】質量があれば状態は 2s+1 個、質量が 0 なら進行方向に対する右回りと左回りの 2 個である。
- 【既知】内部の位相の回転はスピンではない。電荷を持つパイ中間子は複素数の場だがスピン 0、ヒッグス場は実 4 成分だがスピン 0 である。
- 背景の空間を置かない立場では、(1) 空間の方向をどう読み出すか、(2) 読み出した空間を回すとは状態への操作として何か、が決まらないと、スピンという言葉が使えない。

**スピン 0 の測り方。**【既知】2 光子への崩壊が見えたことがスピン 1 を排除する。スピン 0 と 2 は、崩壊で出る粒子の角度分布で分ける。スピン 0 の粒子は向きを持たないので、止まった立場で見ると、どの方向にも同じ確率で出る。

**生成。**【既知】生成は反射ではなく合体である。グルーオン 2 個が消え、エネルギーと運動量の全部が 1 個のヒッグス粒子になる。衝突の方向は、運動量として残る。衝突の軸を覚えられるのは角運動量だけで、軸に沿った合計が 0 の組み合わせだけが、スピン 0 の粒子を作れる。

> 【木原】つまり空間的に、エネルギの純粋な塊だけがあり、それがヒッグス的な塊にみえる？が正しいですね

【既知】ヒッグス粒子は、真空と同じ量子数を持つ。運動量、角運動量、電荷、色を持たず、エネルギーだけを持つ塊である。ただし、エネルギーが決まった値（125 GeV）であること、崩壊が相手の質量に比例することが、条件として付く。

## 5. 量子数と、必要な自由度

### 5.1 ヒッグス場の量子数

> 【木原】ヒッグス場がもつ量子数は？いくつあり、定義域は？

【既知】

| 量子数 | 定義域 | ヒッグス場の値 |
|---|---|---|
| スピン J | 0, 1/2, 1, … | 0 |
| 色（SU(3) の表現） | 1 重項, 3 重項, … | 1 重項 |
| 弱アイソスピン T | 0, 1/2, 1, … | 1/2（T₃ = ±1/2） |
| ハイパーチャージ Y | 標準模型では 1/3 の整数倍 | ＋1 |

電荷は Q = T₃ + Y/2 で決まる。場とその共役を合わせた 4 状態は、(T₃, Y) の符号の組で番号が付き、電荷は ＋1, 0, 0, −1 である。

### 5.2 スカラーでは足りない

> 【木原】つまりヒッグス粒子は、この量子数を全てレジストできる自由度がいるのでは？粒子として観測出来る以上すべて状態としてもっているのですよね、到底スカラーではないですよ？？

- 「スカラー」には二つの意味がある。スピン 0 であることと、実数 1 個であること。ヒッグス場は前者だが、後者ではない。
- 必要な成分の数は、量子数が多重項の中で取る値の数の積である。1 × 1 × 2 × 2 ＝ 実 4 成分。
- 【既知】4 成分はすべて観測されている。1 成分は h として、3 成分は W⁺・W⁻・Z の 3 番目の偏極として。弱アイソスピン 1/2 は、W と Z の質量の比で測られている。

### 5.3 位置と運動量を、状態が自分で持つ

> 【木原】背景時空を置く方はわすれていますが、粒子は自身の位置または運動量ベクトルを最低はもっていますよ

標準の書き方 φ(x) では、x は場の成分ではなく、背景の時空が用意した番地である。「実 4 成分」は 1 点あたりの数だった。背景を置かないなら、位置または運動量を状態が自分で持つしかない。

- ヒッグス粒子 h だけでも、実数 1 個には収まらない。
- ヒッグス場は、内部の 4 に位置または運動量の 4 が加わり、実 8 個分が下限になる。

**最初の問いへの答え（ここまで）。** cos のスカラー波（実数 1 個）は、背景時空を置かない立場では、ヒッグス場の候補にも、ヒッグス粒子の候補にもなれない。入る場所があるとすれば、より大きな入れ物の中の実軸の 1 本である。

### 5.4 8 でも足りない。もう一つの増やし方は倍音である

> 【木原】もし量子数という毛を全ての粒子がもつならば、最低八元数の自由度が必要なのでは？

> 【木原】八元数でもたらない、八元数 3 個で、24 ですが、あとは、もう一つ自由度を増やす方法は倍音ですが？

- 【既知】値の決まった状態一つを指定する、同時に決められるラベルは 8 個である。運動量 3、ヘリシティ 1、色 2、T₃ 1、Y 1。
- 【既知】重ね合わせまで含めた成分の数は、ヒッグス場 4、荷電レプトン 1 種類 8、クォーク 1 種類 24、フェルミオン 1 世代 64。
- クォーク 1 種類の 24 は、色 3 × カイラリティ 2 × スピノルの成分 2 × 実部と虚部 2。区別できる状態としては 12 個（3 色 × スピン 2 × 粒子と反粒子）。
- 自由度を増やす方法は、成分を増やすことと、倍音を増やすことの二つしかない。全体は「成分の数 × モードの数」で、`(8×3)M` はこの形である。
- 倍音が担えるのは、位置と局在の幅、運動量の大きさである。色・弱アイソスピン・ハイパーチャージは成分の側が持つ。世代の置き場所は、成分の側にない。

## 6. 色と電荷は、別に数えなくてよい

> 【木原】まず、色と、電荷は別に数える必要ないですよね？

> 【木原】つまり、色は、Q1 Q2 Q3 の符号付きの整数 -1 0 +1. 単位は素電荷の 1/3 で良いのでは？

【確かめた】電荷を Q = (Q₁ + Q₂ + Q₃) × (素電荷の 1/3) とすると、次の表になる。

| (Q₁, Q₂, Q₃) の型 | 並べ方 | 電荷 | 粒子 |
|---|---|---|---|
| (＋, ＋, ＋) | 1 | ＋1 | 陽電子 |
| (＋, ＋, 0) | 3 | ＋2/3 | アップ（3 色） |
| (＋, 0, 0) | 3 | ＋1/3 | 反ダウン（3 反色） |
| (0, 0, 0) | 1 | 0 | ニュートリノ |
| (0, 0, −) | 3 | −1/3 | ダウン（3 色） |
| (0, −, −) | 3 | −2/3 | 反アップ（3 反色） |
| (−, −, −) | 1 | −1 | 電子 |

- 和が電荷、差が色である。三つが全部等しければ色なし。
- 全部の符号を反転すると反粒子。アップとダウンの差は (＋,＋,＋) で、W⁺ が運ぶ量と一致する。
- 【既知】この数え方は、1979 年のハラリとシュープの模型と同じ形である。
- 27 通りのうち 15 通りを使う。(＋, 0, −) の型の 6 通りは、グルーオンが運ぶ色の量と一致する。(＋,＋,−) と (＋,−,−) の型の 6 通りは、対応する素粒子が観測されていない。
- ニュートリノと反ニュートリノは、どちらも (0,0,0) で区別できない。

> 【木原】これ四元数の n=(i,j,k) の符号の組み合わせとにていますね

整数の組は四元数の虚部 Q₁i + Q₂j + Q₃k として書ける。共役が反粒子、i → j → k の巡回が色の入れ替え、対角の方向 i + j + k への成分が電荷、対角に直交する成分が色である。ただし、電荷の合成はベクトルの足し算であって、四元数の掛け算ではない。

**符号ベクトル (t, x, y, z, R, Q₁, Q₂, Q₃) の軸は足りているか。** 内部の 5 本 (t, R, Q₁, Q₂, Q₃) に偶パリティを課すと 16 通りで、1 世代のフェルミオン 16 種類と数が一致する【既知の形】。足りないのは世代の置き場所である。t と R は、符号と大きさで二役になる。

## 7. 足し算の量は、指数の側にある

> 【木原】相互作用を、ベクトルの積で定義すると、足し算が難しいですね、、やはり O² |-> O' になる N 個の O の写像が曖昧なのが厳しいな、足し算型の保存量がつくれるんだろうか？

> 【木原】ですよね、、指数であれば、積が足し算になりますね

- 【既知】同じ虚軸の上では、位相が足され、倍音の次数が足される。z^m z^{m′} = z^{m+m′}。
- 【既知】電荷とは、位相を α 回したとき e^{iQα} 倍になるときの Q である。成分の値ではなく、回転に対する応答の次数である。
- 【既知】exp(X) exp(Y) = exp(X + Y + ½[X, Y] + …)。X + Y が足し算の部分で、保存量はここに住む。交換子の項が相互作用である。光子は可換なので自分どうしで作用せず、W とグルーオンは非可換なので作用する。
- 足し算が成り立つのは、互いに可換な回転の間だけである。実 8 成分では 4 個で、標準模型の内部の量（色 2、T₃、Y）の数と同じである。
- 【既知】八元数の自己同型 g は g(xy) = g(x)g(y) を満たす。積だけで作った写像は、全員を同じ g で回す操作と入れ替えられる。対称性は、写像の細部を決めなくても入っている。

## 8. クォーク 3 つが中性子であり続ける積

> 【木原】クオーク３つが、中性子でい続けられる、積ってとれますかね？

写像を「各自を、他の二つの積の共役に置き換える」とする。

$$
o_1' = \overline{o_2 o_3},\qquad o_2' = \overline{o_3 o_1},\qquad o_3' = \overline{o_1 o_2}
$$

【確かめた】

1. (o₁o₂)o₃ = 1 を満たす閉じた三つ組は、この写像の厳密な固定点である。三つが結合的でない一般の単位八元数で、ずれは 10⁻¹⁶。色の平面に一つずつ置いた (e₁, e₂, −e₃) も固定点である。
2. 三つ組の積 P = (o₁o₂)o₃ は、**P′ = (P の共役)²** に厳密に従う。P = A(cos φ + n sin φ) と書くと、向き n は変わらず、角度は φ → −2φ、大きさは A → A² になる。
3. 固定点のまわりでは、24 方向のうち 16 方向はずれが増減せず、8 方向は 1 ステップごとに 2 倍になる。10⁻⁸ のずれは 32 ステップで大きさが 0 に潰れた。

> 【木原】これ誤解がありますが、U^n=I で、n 回の相互作用で、もとに戻るでもよいのですよ？我々が中性子と観測しているのって、決して一瞬の観測ではないので、ある周期の範囲でローパスした結果が中性子なら中性子でいいですが、中性子はもともと寿命があるので、完全に安定だとかえってこまりますよ

**ここで起きた誤読。** Claude は、固定点であることと安定であることを条件にして調べた。

【確かめた】n 回で戻る解は、((−2)ⁿ − 1)φ が 360° の整数倍、という条件で、どの n にもある。1 回で戻るのは φ = 0°、120°、240°。

同じ軸の上で、三つを倍音の次数で書くと、写像は「各自の次数から、三つの和を引く」になる。

| 型 | 次数 | 振る舞い |
|---|---|---|
| 中性子型 | (＋2, −1, −1) | 和が 0。何回繰り返しても変わらない。どんな z でも成り立つ |
| 陽子型 | (＋2, ＋2, −1) | 和が 3 → −6 → 12 と毎回 −2 倍。基になる波が 9 回で戻る（40° 刻み）ときだけ、積が 120° に止まり、中身が 3 回周期で回る |

- 次数は、素電荷の 1/3 を単位にしたアップ、ダウン、ダウンの電荷である。「積が 1 になる」ことが「電荷の和が 0」である。
- 1 回で戻る解 0°、120°、240° が、全体の電荷 0、＋1、−1 に対応する。全体の電荷が整数なら積が止まり、分数なら積が回り続ける。
- この写像は、和が 0 のとき以外、足し算型の量を保存しない。
- 毎回 2 倍になる不安定さから、中性子の寿命（内部の周期のおよそ 10²⁶ 倍）は出ない。壊れるまでの回数が、最初のずれの大きさだけで決まるからである。崩壊は、他の状態との作用が入って初めて定義できる。

## 9. 符号ではなく、最初から位相である

> 【木原】符号で考えているのが間違いの気がしてきました。最初から位相では？360 度/3 と考えた方がシンプルなのかも

- 【既知】クォークは、電荷の位相を一周回しても元に戻らない。アップもダウンも 240°、反クォークは 120° のところに来る。このずれは、色の対称性の中心（3 色全部に同じ 120° を掛ける操作）と打ち消し合う。
- クォーク 3 個で 240° × 3 = 720°、クォークと反クォークで 360° となり、閉じる。観測される粒子がこの二通りの組み方だけであることと同じ形である。
- 符号は、位相の 180° 刻みの場合である。−1, 0, ＋1 は 240°、0°、120° の三つの位相である。

> 【木原】では２周して戻るようにしては

素電荷の 1/3 あたり 120° として、戻るまでの周回数ごとに区別できるものは次のとおり。複合粒子の大きな電荷は、いったん考えない。

| 戻るまで | 位相の値の数 | 素粒子の電荷 7 通り（−3 から ＋3）の区別 |
|---|---|---|
| 1 周 | 3 | 色の有無だけ |
| 2 周 | 6 | −3 と ＋3 だけが重なる（電子と陽電子） |
| 3 周 | 9 | 全部区別できる |

**弱い力を入れると。**

> 【木原】弱い力の相互作用を考えるとどうなるんですかね

- W は位相で 360°、ちょうど 1 周を運ぶ。1 周で戻す数え方では何も変えない（W が色を変えないことと合う）。2 周で戻す数え方では、360° 違いの二つが組になり、これが弱い力の 2 重項にあたる。
- 電荷の位相は、左巻きと右巻きを区別できない。区別を持っているのはハイパーチャージである。【既知】

| 粒子 | 色 | W が作用するか | ハイパーチャージの位相 |
|---|---|---|---|
| 左巻きクォーク | あり | する | 60°（240° ＋ 180°） |
| 右巻きアップ、右巻きダウン | あり | しない | 240° |
| 左巻きレプトン | なし | する | 180° |
| 右巻き電子 | なし | しない | 0° |
| ヒッグス場 | なし | する | 180° |

- 240° があるかないかが色、180° があるかないかが W の作用である。
- 質量は左巻きと右巻きをつなぐが、両者は位相が 180° 違う。この 180° を埋めているのがヒッグス場である。**位相の言葉では、ヒッグス場は半周の位相を持ち、左巻きと右巻きを閉じさせるものである。**

> 【木原】xyz の符号は、運動の向きを表す位相なんでしょう

- 【既知】波 e^{i(kx − ωt)} の進む向きは、空間の位相と時間の位相の、相対的な符号で決まる。
- スピンの向きは、運動に垂直な二つの軸の間の位相のずれの向き（x + iy か x − iy か）。左巻き・右巻きは、その回る向きと運動の向きの、符号の積である。
- 【仮説・未検証】左巻きだけが内部の 180° を持つことは、「時空の側の符号の積と、内部の側の符号の積が、いつも決まった関係にある」という一つの規則になる。偶パリティの条件を、時空の側まで広げた形である。

## 10. 8 個の実数は、実質すべて位相である

> 【木原】これでわかったのは、八元数の８個の実数は実質すべて位相なのでしょう、巻数も全てあるのでしょうが、読出し時に、巻数だけ読むか、位相だけよむか、両方読むかだけなのでは？

【既知】閉じた円周の上の量は、連続な位相 θ と、整数の巻数 m の対を持つ。片方をはっきり決めると、もう片方は決まらない。

| 読み方 | 見えるもの | 既知の例 |
|---|---|---|
| 巻数だけ読む | 整数の値。足し算で保存される | 電荷、色、ハイパーチャージ |
| 位相だけ読む | 連続な値 | 位置、向き |
| 両方を粗く読む | 幅を持った位置と、幅を持った巻数 | 局在した粒子。倍音を M 次まで重ねると、位置が 360°/M の幅で決まる |

> 【木原】A(cos θ ＋ n sin θ) これを絶対値するから面倒になるのですよ、それって、1+7 と読むときの読み方で、1+3 1+3 とよめば替わりますよ、2 2 2 2 でもよめますし、1 1 1 1 1 1 1 1 という読み方もありますよ

**ここで起きた誤読。** Claude は「独立な角度は 7 個」「同時に回せる位相は 4 個」と書いた。1＋7 の読み方と 2＋2＋2＋2 の読み方を、それぞれ唯一の数え方のように扱っていた。

| 読み方 | 大きさの数 | 位相にあたるもの |
|---|---|---|
| 1＋7 | 1 | 角度が 1 個、向き n（S⁶）。虚部の絶対値を取り、向きを n に押し込む |
| (1＋3)＋(1＋3) | 2 | 角度が 2 個、向きが 2 個 |
| 2＋2＋2＋2 | 4 | 連続な位相が 4 個。それぞれに整数の巻数 |
| 1 が 8 個 | 8 | 符号が 8 個。0° か 180° の位相。符号ベクトルそのもの |

- 絶対値を取るのは、かたまりの中の向きを一つにまとめる操作である。まとめる単位を小さくするほど、位相として読めるものが増える。
- **符号ベクトルは、4 つの位相を 90° の粗さで読んだものである。** 複素数の位相がどの象限にあるかは、実部と虚部の符号の組で決まる。

## 11. 読み方は、決めるものではない

Claude は「どの 2 本を組にするかは決まっていない」「120° の刻みは確かめていない」と書いた。

> 【木原】これ決まりませんよ、読んだ時にそうよめるから、そうだって解釈するだけですよ？？

**ここで起きた誤読。** 「どちらを時空と呼ぶかを先に決める必要がある」という、前の論文ですでに正された誤りと同じである。組み方は、決めるものではなく、読むときに選ぶものである。問うべきなのは、ある読み方で何が見えるか、読み方を変えても変わらないものは何か、である。

**120° の検算。**【確かめた】虚数単位を一つ（e₇）選び、複素数の i として使う。残りの 6 本は 3 枚の面になる。この 3 枚に同じ角度の位相の回転を同時に掛け、(1, e₇) の面は動かさない操作が、八元数の積を保つかどうかを調べた。

| 角度 | 30° | 60° | 90° | 120° | 180° | 240° |
|---|---|---|---|---|---|---|
| 積のずれ | 8 | 13 | 9 | 10⁻¹⁵ | 12 | 10⁻¹⁴ |

積を壊さないのは 0°、120°、240° だけである。120° は外から選んだ刻みではない。3 枚の面を同じだけ回す、という読み方をしたときに、八元数の積が許す角度がそれしかない。

## 12. 仮説

> 【木原】ようやく分かりましたね、実は読み方を固定しない、ということが極めて厳しい対称性を要求して、位相の離散性を要求します。実数のはずなのに、どの解釈でも矛盾しない組み合わせは極めて厳しく、それが結果的にどの粒子によめるかを決めているんだと思います。

**仮説。**【仮説・未検証】

1. 状態は実数 8 個の組で、値は連続に取れるはずである。
2. 読み方は複数ある。1＋7、(1＋3)＋(1＋3)、2＋2＋2＋2、1 が 8 個。組み方も一通りではない。
3. 読み方を固定しない。どの読み方で読んでも、積の規則と矛盾しないことを要求する。
4. この要求を満たす位相は、とびとびの値に限られる。
5. 残った組み合わせが、粒子として読めるものである。粒子の種類は、状態の側の性質ではなく、読み方と状態の組の性質である。

§11 の 120° は、この仮説の最初の実例である。位相は連続に選べるはずなのに、積と両立するのは 3 つだけだった。

**同じ向きの既知の事実。**【既知】掛け算でも足し算でも閉じていて、とびとびである、という条件を数に課すと、複素数では回転が 180°、120°、90°、60° の刻みに限られる。四元数では、掛け算で閉じる単位の集まりは最大 24 個、八元数では 240 個である。この対話に現れた刻みは、180°、120°、90°、60° がすべてだった。

## 13. まとめ

### 13.1 確かめたこと

- 共役対 (z, z̄) の二乗の和は 2A²cos 2θ で、消えるのは θ = 45° のときだけ。
- 3 個の八元数の積の実部は括弧によらない。4 個では差が Re([o₁,o₂,o₃]o₄) になる。
- 3 個が純粋に色の平面の中にあれば、積は ⟨1, e₇⟩ に閉じる。実部を持つと閉じない。
- (Q₁, Q₂, Q₃) ∈ {−1, 0, ＋1} の和で、クォークとレプトンの電荷がすべて出る。
- 閉じた三つ組は、§8 の写像の厳密な固定点である。三つ組の積は P′ = (P の共役)² に従う。固定点は 8 方向に 2 倍の不安定さを持つ。
- 中性子型の次数 (＋2, −1, −1) は写像で変わらない。陽子型は 9 回で戻る波の上でだけ周期解になる。
- 3 枚の複素面を同じ角度で回す操作が八元数の積を保つのは、0°、120°、240° だけである。

### 13.2 仮説であり、未検証のこと

- §12 の仮説の全体。確かめたのは 120° の一例だけである。
- −1, 0, ＋1 の量の置き場所が、成分の符号ではなく巻数であること。
- 左巻き・右巻きと内部の 180° の結び付きが、全体の閉じる条件であること。
- 世代の置き場所が倍音の側であること。
- 既知の離散的な集まり（24 個、240 個）と、粒子の量子数の表の対応。

### 13.3 分かっていないこと

- 「矛盾しない」が何を保つことなのか（積か、閉塞か、巻数か）。
- 写像 O² ↦ O′ の形。足し算型の量を保存し、ずれを毎回 2 倍にしない写像。
- 空間の回転を、状態への操作としてどう定義するか。これが決まらないと、スピンは議論できない。
- 一次で入る質量（クォークとレプトン）を、何から読むか。
- t が、時間の位相と、内部の符号の両方に現れること。

### 13.4 検討ノート v0.3 のうち、取り下げるもの

- 「光子はただの複素数 `2M`、グラビトンは共役な 2 複素数 `4M`」（§1.2 (e)）。光子は共役な複素数であり、共役で挟む操作は光子の側のものである。グラビトンは、この対話の対応の中には現れていない。
- 「90° 対で二乗閉塞するから光子」を、光子を `2M` に置く根拠にすること。
- 二乗ゼロ閉塞から出した残渣の条件 (H1)〜(H4)（§1.4）。
- 「倍音がなく、局在せず、回らない実数 `1` がヒッグス波」（§1.1）。実数 1 個は、背景を置かない立場では、ヒッグス場にもヒッグス粒子にも足りない。
- スピンについての記述のすべて。
- 「三つ組 1 個は安定な固定点になると予想される」（§4）。固定点ではあるが、§8 の写像では安定でない。

### 13.5 次に確かめられること

1. 虚数単位の選び方を変えて（e₇ 以外の 6 通りでも）、§11 と同じ検査をする。全部の選び方で同時に許される位相の組を数える。
2. 2＋2＋2＋2 の読みと (1＋3)＋(1＋3) の読みの両方で、積と両立する操作を数える。
3. 残った組を、ヒッグス場・光子・W・Z・グルーオンの量子数の表と突き合わせる。

## 付録：検算プログラム

§8 と §11 の【確かめた】を再現する。Python 3 と NumPy だけで動く。

```python
import numpy as np
rng = np.random.default_rng(1)
tri = [(1,2,3),(1,4,5),(1,7,6),(2,4,6),(2,5,7),(3,4,7),(3,6,5)]
f = np.zeros((8,8,8))
for a,b,c in tri:
    for (i,j,k),s in [((a,b,c),1),((b,c,a),1),((c,a,b),1),
                      ((b,a,c),-1),((a,c,b),-1),((c,b,a),-1)]:
        f[i,j,k] = s
def mul(x, y):
    z = np.zeros(8); z[0] = x[0]*y[0] - x[1:]@y[1:]
    z[1:] = x[0]*y[1:] + y[0]*x[1:] + np.einsum('ijk,i,j->k', f[1:,1:,1:], x[1:], y[1:])
    return z
conj = lambda x: np.r_[x[0], -x[1:]]
unit = lambda x: x/np.linalg.norm(x)
e = np.eye(8)

# §8：閉じた三つ組は固定点。三つ組の積は P' = conj(P)^2
def step(S):
    a, b, c = S
    return np.array([conj(mul(b,c)), conj(mul(c,a)), conj(mul(a,b))])
P = lambda S: mul(mul(S[0],S[1]),S[2])
a, b = unit(rng.normal(size=8)), unit(rng.normal(size=8))
S = np.array([a, b, conj(mul(a,b))])
print('固定点のずれ', np.abs(step(S)-S).max())
T = np.array([unit(rng.normal(size=8)) for _ in range(3)])
p = conj(P(T)); print('P′ と conj(P)² の差', np.abs(P(step(T)) - mul(p,p)).max())

# §8：固定点のまわりの成長率
def jac(S, h=1e-6):
    x0 = S.ravel(); M = np.zeros((24,24))
    for i in range(24):
        d = np.zeros(24); d[i] = h
        M[:,i] = (step((x0+d).reshape(3,8)).ravel() - step((x0-d).reshape(3,8)).ravel())/(2*h)
    return M
vals, cnt = np.unique(np.round(np.abs(np.linalg.eigvals(jac(S))), 6), return_counts=True)
print('成長率と個数', dict(zip(vals, cnt)))

# §8：倍音の次数。各自の次数から三つの和を引く
for m in [(2,-1,-1), (2,2,-1)]:
    m = np.array(m); out = [tuple(int(v) for v in m)]
    for _ in range(4):
        m = m - m.sum(); out.append(tuple(int(v) for v in m))
    print(out)

# §11：3 枚の複素面を同じ角度で回す操作が積を保つか
L7 = np.array([mul(e[7], e[i]) for i in range(8)]).T
def g(phi):
    M = np.eye(8)
    for i in range(1, 7):
        M[:,i] = np.cos(phi)*e[i] + np.sin(phi)*L7[:,i]
    return M
for deg in [30, 60, 90, 120, 180, 240]:
    M = g(np.deg2rad(deg)); err = 0
    for _ in range(20):
        x, y = rng.normal(size=8), rng.normal(size=8)
        err = max(err, np.abs(M@mul(x,y) - mul(M@x, M@y)).max())
    print(deg, '度：積のずれ %.1e' % err)
```
