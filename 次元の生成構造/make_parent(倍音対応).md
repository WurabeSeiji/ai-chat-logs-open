# make_parent（倍音対応）設計書

作成日: 2026-08-04
状態: 設計確定・単体実装とテストのみ。**指示があるまでインフレーションプログラム（abl.build_init 系）には実装しない。**

---

## 0. 目的と設計原則

インフレーション実験の M = N(N−1)/2 本の関係波に対し、倍音レジスタを持つ初期の海を生成する。ただし以下の原則を破る初期値は「作り込み」であり、論文の妥当性を毀損するため採用しない（2026-08-04 木原氏指示）。

**原則（現行 make_parent から継承する構成法）**:

1. **閉塞は課さず、構造から恒等的に出す。** Σx²=0 は射影・補正で満たすのではなく、実反対称生成子の円偏波固有モードという構造の帰結として厳密に成立させる（現行 make_parent と同一の原理。零閉塞 ⟺ ‖X‖=‖Y‖ ∧ X⊥Y）。
2. **初期値は選ばず、自己無撞着反復で導出する。** 位相場 → 生成子 → 固有平面 → 位相場の不動点として解かせる。乱数は盆地選択とカイラリティ枝にのみ入る。
3. **分解能の倍音しか存在させない。** 状態の周波数レジスタは倍音格子 n·ω₀（n = 1…H、H はレジスタ上限＝分解能に一致させる契約）のみ。K の固有周波数のような非整合連続値を状態の周波数として持ち込まない。
4. **スペクトル分布を手で置かない。** 段間の振幅分布は公理（無名等振幅複合波モデル）に従い等振幅とする。n 依存の重み（零点重み 1/√n 等）は導出されるまで採用しない。

## 1. 状態空間

- Z ∈ C^{M×H}。行 e = 辺（完全グラフ K_N の全辺、build_edges の上三角順）、列 n = 倍音番号（周波数 n·ω₀ のレジスタ段）。
- 本生成器が定めるのは**構造のみ**。周波数 n·ω₀ の力学的実現（段 n が n 倍速で回る時間発展）は動力学側の契約であり、本単体の範囲外。

## 2. 構成法

各段 n = 1…H について独立に、現行 make_parent（run_n_scaling_lowrank_v1.py 158–190行）と同一の自己無撞着反復を実行し、円偏波閉包 v⁽ⁿ⁾ ∈ C^M（‖v⁽ⁿ⁾‖=1）を得る。

**段あたりの反復（現行 make_parent と同一、枝選択のみパラメータ化）**:

1. θ ← rng.uniform(0, 2π, M)
2. 反復: K(θ) の小空間 JG の全固有対を解き、**branch = '−' なら argmin(Im ev)、'+' なら argmax(Im ev)** の枝を選択 → W で持ち上げ → 正規化 → v
3. θ ← angle((1−β)e^{iθ} + β e^{i·angle(v)})（β=0.5）
4. 10 反復ごとに残差 ‖iKv − μv‖（μ = Re v†(iKv)、θ=angle(v) で評価）を判定、tol 未満で終了。停滞時リスタート（最大 restarts 回）、最小残差を採用

**カイラリティ枝**: 段ごとに rng の硬貨投げ（integers(0,2)）で branch を決める。これは規約であることを明記する（両枝は対等。鏡像対称性はテスト T8 で検証）。乱数消費順序: 段 n につき「硬貨1回 → 反復用 uniform(M)×リスタート数」。

**合成**:

    Z[·, n] = (1/√H) · v⁽ⁿ⁾   （n = 1…H）

## 3. 保証される性質（期待分布＝テストの検証対象）

| # | 性質 | 根拠 |
|---|---|---|
| P1 | 各段の自己無撞着性: 残差 < tol | 反復の収束 |
| P2 | 段閉塞 v⁽ⁿ⁾ᵀv⁽ⁿ⁾ = 0（恒等） | 実反対称 K の円偏波固有モード |
| P3 | **総閉塞 Σ_{e,n} Z[e,n]² = 0（厳密）** | 閉塞は成分二乗の単純和なので段閉塞の和 = 0。段間交差項は存在しない |
| P4 | ‖Z‖_F = 1、段振幅 = 1/√H（等振幅） | 構成 |
| P5 | 各段 rank[Re v, Im v] = 2、‖Re v‖=‖Im v‖=1/√2、Re v ⊥ Im v | 円偏波構造 |
| P6 | 各段 全 M 成分非零 | parent_state_structure_check_v1 と同型 |
| P7 | 各段は自段 K の最上位（σ_max）固有平面のみを占有（占有率 ≈ 1） | 反復が σ_max 平面へ射影し続ける |
| P8 | 鏡像対称: branch 反転で μ の符号が反転し、他の全性質は不変 | 枝の対等性（規約性の検証） |
| P9 | 再現性: 同一 seed → 同一出力。異 seed → 別盆地でも P1–P7 成立 | 乱数契約 |

μ と σ₁ の符号対応（branch '−'/'＋' がどちらの μ 符号を与えるか）は解析的に断定せず、テストで実測して記録する（現行実測: argmin 枝で μ = −σ₁、parent_state_structure_check_v1）。

## 4. インターフェース

```
make_parent_harmonic(n_vertices, H, seed,
                     iters=1200, beta=0.5, tol=1e-12, restarts=3)
  → (Z, info)
Z: complex ndarray (M, H)
info: 段ごとの {branch, mu, sigma1, residual, restarts_used,
       closure_abs, min_amp, rank2_check}, 乱数消費記録, エンジン SHA-256
```

- エンジン（LowRankSystem 等）は read-only import。反復は本モジュール内で枝パラメータ付きに複製し、複製元の行番号と SHA-256 を記録する。

## 7. 実測記録（2026-08-04 実行済み）

**テスト v1（test_result_v1.json、反証記録として保存）**:
- v1 の T8 予想「固有値枝の反転＝カイラリティ反転（μ 符号反転）」は**反証**された。
  両枝とも μ < 0。枝の選択は**収束先の不動点族を変える選択子**であり、
  カイラリティのつまみではない。
- restarts=3 では一部盆地が非収束（N=5 段4/8、残差 0.36 で振動）。
  非収束でも閉塞・円偏波構造は厳密に保たれた（構造保証は反復収束と独立）。

**テスト v2（test_result_v2.json、restarts=10・iters=2000・T8=共役鏡像に訂正）**:
- **全テスト PASS**（N=5,H=8 / N=40,H=4、T1〜T9）。
  総閉塞 |ΣZ²| ~ 2e-16、‖Z‖=1（15桁）、全段 rank2・等ノルム直交・全成分非零・
  σ_max 平面占有率 1（10桁）、同 seed bit 一致・異 seed 全通過。
- 鏡像の正しい定義は**複素共役** v→v̄。μ は共役不変（代数と実測が一致）。
  μ < 0 は本構成法の不変量であり、閉包のカイラリティ標識は μ に現れない。
- **発見: 自己無撞着閉包は離散的な不動点族を成す**。
  N=5: σ₁ ∈ {√14 ≈ 3.741657（現行エンジンの親）, 4.000000 = N−1（厳密整数）}。
  N=40: σ₁ ∈ {38.835860, 38.866788, 39.000000 = N−1}。
  段ごとに異なる族へ落ちるため、生成される海は**複数種の閉包が混在する構造**を
  最初から持つ。族スペクトルの分類（どの σ 値が許されるか）は今後の検討課題。
