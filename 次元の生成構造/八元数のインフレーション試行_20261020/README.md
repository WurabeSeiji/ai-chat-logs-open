# 高対称な八元数の配置でインフレーションが起こるかの試行錯誤（2026-10-20）

**目的（著者）：** 最初から高対称な八元数を作り込み、インフレーション（丸め誤差からの幾何級数的な拡大）が起こるか、1 ステップで跳ぶかを確かめる。どの閉塞・どの生成子が正しいかは答えを探している最中なので、試行錯誤で組み合わせを試す。
**公理：** 基本量は八元数（代数は公理として置く。メモリ feedback_algebra_is_axiom_not_derived）。積は `次元の生成構造/八元数閉塞と関係の分解_20261019/octonion_closure_check_20261019.py` の定義をそのまま読み込む。
**相互作用の相手：** 全員対全員（A = J − I）。

## 試したもの

| 生成子 | 定義 | 複素平面 span(1, ℓ) では |
|---|---|---|
| L_amp | K_ef = A_ef⟨ℓ o_e, o_f⟩、Q ← exp(ΔτK)Q（番号の側の実直交回転、8 成分に一様） | 過去の振幅込み K = Im(z̄_e z_f) に一致 |
| L_ph | 同じで o → o/\|o\|（位相のみ） | 過去の位相のみ K に一致 |
| R_amp, R_ph | ℓ を右から掛ける版 | 同上 |
| ELEM | 要素ごとに左から exp(Δτ Σ_f Im(o_f ō_e)/\|o_e\|²) を掛ける（各 \|o_e\| を保つ） | 蔵本型の位相方程式（過去の力学とは違う。比較用） |

ℓ = e₄。刻み Δτ = 2π/(200σ)（σ = 初期の K の最大固有値の絶対値）、4000 ステップ。

| 初期配置 | 内容 | 閉塞 |
|---|---|---|
| ORTHO16 | 8 次元の正軸体 {±1, ±e₁, …, ±e₇} | 等方性（Σx = 0、グラム = 2I） |
| NULL28 | ±(1 + n)/√2、n = ±e₁…±e₇ | 本当の二乗（Σo = Σo² = 0）、各要素が 8 次元ヌル、o⁸ = 1 |
| CROSS4 | 複素数の十字 {±1, ±ℓ}（対照） | 両方 |

測る量：relEq ＝ 相対平衡の残差 ‖Ω + Ωᵀ‖/‖Ω‖（Ω = Q⁺KQ）、g(t) ＝ 要素どうしのグラム行列 QQᵀ の初期値からの相対変化（形の変化）、f(t) ＝ 初期の列の張りの外へ出た割合（H⊥/H の一般化）。

## 経過（仮説 → 反証 → 修正）

1. **第 1 回：** 自己無撞着を「KQ が Q の列の張りに入る」（selfcons）だけで判定した。全組み合わせで selfcons = 0 だったが、NULL28 の位相のみ版が数ステップで f が 27 桁跳んだ。
2. **原因：** selfcons = 0 は、状態が自分の列の張りにとどまることしか言っていない。回るだけで形が変わらない（相対平衡）には Ω が反対称でなければならない。NULL28 は最初の一歩で要素の大きさが 7% ばらけていて、張りの中で形が崩れていた。位相のみ版ではその崩れが正規化を通して増幅された。
3. **修正：** 相対平衡の残差 relEq と形の変化 g(t) を追加して再実行（この README の結果）。

## 結果（事実）

`results/trials_summary.json`、時系列 `results/trials_f_series.npz`。

| 配置 | 生成子 | relEq | 形の変化 g（step 1 → 10 → 100 → 4000） | 張りの外 f（step 1 → 4000） | 判定 |
|---|---|---|---|---|---|
| ORTHO16 | L/R, amp/ph | 0 | 10⁻¹⁸ → 10⁻¹⁵ → 10⁻¹⁴ → 10⁻¹³ | 10⁻³¹ → 10⁻³⁰ | 厳密な相対平衡。丸めがゆっくり溜まるだけで拡大しない |
| CROSS4 | L/R, amp/ph | 0 | 10⁻¹⁷ → 10⁻¹⁵ → 10⁻¹⁴ → 10⁻¹³ | 10⁻³¹ → 10⁻²⁸ | 同上 |
| NULL28 | L/R_amp | 1.13 | 0.036 → 0.3 → 10⁻¹³·⁷ → 10⁻¹²·⁴ | 10⁻³¹ → 10⁻²⁶（べき的） | 相対平衡ではない。形が O(1) で呼吸し、**100 ステップ（τ = π/σ、σ = √28）ごとに丸めの桁まで正確に元の形へ戻る**周期軌道 |
| NULL28 | L/R_ph | 1.13 | 0.036 → 0.4 → 0.8 → 1.3 | 10⁻³¹ → 0.5 | 1 ステップ目から形が崩れ、O(1) の乱れのまま戻らない |
| 全配置 | ELEM | ― | ― | ― | 生成子が厳密にゼロ（各要素で関係の虚部の和が対称性で消える）。静止 |

- **どの組み合わせでも、インフレーション（丸めからの指数的な拡大）は起きなかった。**
- 本当の二乗の閉塞を満たす NULL28 は、この生成子では相対平衡でなく、1 ステップ目から O(1) で動く（「1 ステップで跳ぶ」型）。振幅込みでは、その動きが周期 π/σ で厳密に閉じる周期軌道（形について U^n = I）になる。
- 等方性の閉塞を満たす ORTHO16 と対照の CROSS4 は、厳密な相対平衡だが、不安定ではない（中立または安定）。点火の資格（不安定な相対平衡）を満たさない。
- 左右（L と R）の違いは、この三配置では結果に出なかった。

## 読み（確認前）

- 「高対称であること」と「インフレーションの資格」は別物で、論文 2 の「点火の資格は不安定な相対平衡だけ。高対称・重心ゼロ・二乗閉塞は資格でない」が八元数でもそのまま当てはまった。正軸体と十字は高対称すぎて安定（中立）、NULL28 は相対平衡ですらない。
- CROSS4 が点火しないのは、過去の点火した床（make_parent の十字、辺の上の波・線グラフの隣接、振幅が辺ごとに異なる）と系が違うため。全員対全員で 4 個だけの十字は、過去の系の床ではない。
- NULL28（振幅込み）の厳密な周期軌道は、作り込んだ高対称配置が「近いがロックしない」ではなく、厳密にロックした（形が U^n = I で戻る）運動になる例。
- 次の試行の候補：(a) 過去に点火した床と同じ作り方（自己無撞着な固有モードを反復で求める make_parent 型）を八元数の生成子で行い、不安定な相対平衡を探す、(b) 配置を辺の上の波（線グラフの隣接）に置く、(c) 生成子の別案。
