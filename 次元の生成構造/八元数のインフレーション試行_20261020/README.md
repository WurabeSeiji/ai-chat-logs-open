# 高対称な八元数の配置でインフレーションが起こるかの試行錯誤（2026-10-20）

**目的（著者）：** 最初から高対称な八元数を作り込み、インフレーション（丸め誤差からの幾何級数的な拡大）が起こるか、1 ステップで跳ぶかを確かめる。どの閉塞・どの生成子が正しいかは答えを探している最中なので、試行錯誤で組み合わせを試す。
**公理：** 基本量は八元数（代数は公理として置く。メモリ feedback_algebra_is_axiom_not_derived）。積は `次元の生成構造/八元数閉塞と関係の分解_20261019/octonion_closure_check_20261019.py` の定義をそのまま読み込む。
**相互作用の相手：** 全員対全員（A = J − I）。

> **分類の訂正（2026-10-20、著者の指摘）：** 以下の第 1・3 段は、自己無撞着を「一定の振動数で回るだけの相対平衡」に狭く取っていた。自己無撞着は、状態が自分の作る運動によって同じ種類の中にとどまることで、発展の向きに何回で戻るかは一定とは限らない。形（要素どうしのグラム行列 QQᵀ）の軌道で次の四つの型に分ける：
>
> | 型 | 中身 |
> |---|---|
> | 相対平衡 | 形が変わらず、一定の振動数で回る |
> | 周期的 | 形が変わるが、一定の周期で正確に元に戻る |
> | 準周期的 | 二つ以上の振動数で、ある帯の中を準振動し、正確には戻らない |
> | 漸近的 | ある状態に近づいていく |
>
> インフレーションの条件も「不安定な相対平衡から離れる」ではなく、「何らかの型の不安定な自己無撞着集合から指数的に離れ、別の自己無撞着集合に近づく」と言い直す。判定は相対平衡の残差でなく、その集合からの離れ方の指数（周期軌道ならフロケ乗数、準周期ならリャプノフ指数）で行う。下の表と読みの該当箇所は、この型で書き直した（旧判定は取り消し線ではなく「旧判定」として残す）。

## 経過（仮説 → 反証 → 修正）

1. **第 1 回：** 自己無撞着を「KQ が Q の列の張りに入る」（selfcons）だけで判定した。全組み合わせで selfcons = 0 だったが、NULL28 の位相のみ版が数ステップで f が 27 桁跳んだ。
2. **原因：** selfcons = 0 は、状態が自分の列の張りにとどまることしか言っていない。回るだけで形が変わらない（相対平衡）には Ω が反対称でなければならない。NULL28 は最初の一歩で要素の大きさが 7% ばらけていて、張りの中で形が崩れていた。位相のみ版ではその崩れが正規化を通して増幅された。
3. **修正：** 相対平衡の残差 relEq と形の変化 g(t) を追加して再実行（この README の結果）。

## 第 2 段：探索空間を決めてからの解析（2026-10-20、著者の指摘を受けて）

**方針の訂正（著者）：** やみくもな組み合わせは無意味。自己無撞着では入力は作用で決まるので、入力と作用を独立に探すのは誤り（閉塞を入力の選択条件に使ったのはメモリの規則「Σx²=0 は結果」にも反していた）。基準は高対称性なので、作用に異方性があれば等方的な状態は自己無撞着になれない。状態の条件は等方性の閉塞（グラム ∝ I、N ≥ 8、線形の閉塞も課すなら N ≥ 9）。過去の複素数でも小さい N は特異解で、許される N は特定の数列になる可能性が高い。代数（八元数）は公理（feedback_algebra_is_axiom_not_derived）。

**解析の事実：**
1. 自己干渉（N = 1）は複素数に落ち（アルティンの定理）、閉塞できない。N = 2 で閉じる組は必ず一枚の複素平面の光子。N = 3 で閉じれば必ず結合的（k ≤ N − 1 = 2）。本当の二乗の閉塞だけなら非結合的に閉じる最小は N = 4（例 {√3, e₁, e₂, e₄}）、線形の閉塞も課すと N = 5。
2. 等モジュラーなら、Σx = 0 は球面 1-デザイン、グラム ∝ I は 2-デザインで、高次の閉塞は高い強さの t-デザイン。8 次元で高対称な候補：正単体 9（強さ 2）、正軸体 16（強さ 3）、E₈ の根 240（強さ 7、タイト）。
3. SO(n)（n ≥ 3）にも G₂ にも、二つのベクトルから作る反対称で不変なスカラーは無い。過去の型の作用（反対称スカラー K_ef を番号の側に掛ける）は参照の向き ℓ なしでは作れず、対称性は SU(3) に落ちる。第 1 段の L・R が異方的だったのはこの型の宿命。
4. 参照の向きを使わない G₂ 共変・大きさを保つ・3 次の作用は次の型（`covariant_generators_on_designs_20261020.py`）：F_A（要素ごとの SO(8) 回転）、F_B（要素ごとの左の掛け算 u_e = Σ Im(x_f x̄_e)）、F_C（要素どうしの振幅の移し替え、対称な純虚数 s_ef = Re(x_e)Im(x_f) + Re(x_f)Im(x_e) による反対称ブロック）。

**結果（`results/covariant_generators_on_designs.json`）：**

| 配置 | F_A | F_B | F_C（\|Re\| の類ごとの動径の変化率） |
|---|---|---|---|
| 正軸体 16（実 2・虚 14） | 0（厳密） | 0（厳密） | 実の類 −14、虚の類 +2。接線成分 0。振幅が実軸から虚部へ一方向に移る |
| E₈ の根 240（\|Re\| 大 28・中 128・0 84） | 0（10⁻¹⁴） | 0（10⁻¹⁴） | −90、0、+30。接線成分も大（1.1×10³） |

- F_A と F_B は、類ごとに半径を変えても 0 のまま（正軸体で厳密 0、E₈ で 10⁻¹³）。**静止した自己無撞着状態が、類ごとの半径の比という連続な族として存在する**（どちらも中心対称な集合なら成り立つ）。回転（時計、Ω ≠ 0）は無い。
- F_C は内部の固定点を持たず、実部の重い類から虚部の類へ振幅を一方向に移す（符号を反転すれば逆向き）。正軸体の縮約方程式は dr/dτ = −14rρ²、dρ/dτ = 2r²ρ（2r² + 14ρ² が保存）で、固定点は r = 0 か ρ = 0 の端だけ。

**読み（確認前）：**
- 参照の向きを持たない（G₂ で共変な）作用の下では、高対称な配置は「回らない」自己無撞着状態になる。回転する自己無撞着状態（時計、U^n = I）を持つには、虚数単位を一つ選ぶ（G₂ → SU(3)）しかない。時計は対称性の破れ（観測者の ℓ）と同時に現れる。
- 離散と連続が同時に出ている：許される配置（デザインの N と、その軌道の数・大きさ：16 = 2 + 14、240 = 28 + 128 + 84）は離散、軌道ごとの半径の比は静止解の連続な族。著者の言う「連続なのに離散」の形の候補（質量・エネルギーの階層との対応は数の一致で結びつけない、R5）。
- 次は、ℓ を選んだ SU(3) 共変の作用（過去の型）で、デザインの中から回転する自己無撞着状態を探す。SU(3) は Z₃ の中心を持つ（二つの三のメモ）。

## 第 3 段：ℓ を選んだ作用（SU(3)）での回転する自己無撞着状態（2026-10-20）

作用 K_ef = A_ef⟨ℓ x_e, x_f⟩（過去の型、ℓ = e₄）。`su3_rotating_families_20261020.py`、結果 `results/su3_rotating_families.json`。

**正軸体 16：** ℓ に対して {±1}（半径 a）、{±ℓ}（半径 b）、残り 12 個（ℓ で組になる三つの複素平面、半径 c）に分かれる。

| a, b, c | relEq | 複素平面ごとの回転の振動数 |
|---|---|---|
| 1, 1, 1 | 2×10⁻¹⁶ | 2, 2, 2, 2 |
| 1, 1, 2 | 2×10⁻¹⁶ | 2（平面 (1, ℓ)）、8, 8, 8 |
| 1, 1, 0.5 | 3×10⁻¹⁶ | 2、0.5, 0.5, 0.5 |
| 1, 2, 1 | 0.88 | ― |
| 1.3, 0.7, 1.1 | 0.49 | ― |

- 回転する相対平衡（形が変わらない）になる条件は a = b（平面 (1, ℓ) の中の二組の半径が等しい）だけ。c は自由で、連続な族になる。a ≠ b のときに相対平衡でないことは確かめたが、周期的・準周期的な自己無撞着状態かどうかは調べていない（訂正後の型での未判定）。
- 振動数は平面 (1, ℓ) が ω₀ = 2a²、残りの三つの平面（SU(3) の 3）がそろって ω₃ = 2c²。比 ω₃/ω₀ = (c/a)² は連続に動く。比が有理数なら全体が U^n = I で閉じる周期的な運動、無理数なら全体としては戻らない準周期的な運動になるが、どちらも自己無撞着（旧記述「ロックするのは有理数のときだけ」は、準周期的な場合を自己無撞着から外していた）。
- 丸め誤差から 8000 ステップ走らせても、c = 0.5, 1, √2, 2 のどれでも形の変化は丸めの蓄積（10⁻¹³ → 10⁻¹²·⁴）だけ。指数的な拡大は無い（中立）。

**E₈ の根 240：** span(1, ℓ) への射影の大きさで 4 類（4・48・128・60 個）に分かれる。

- 等しい半径で、厳密な相対平衡（10⁻¹⁶）。四つの平面がすべて振動数 30 で回る、完全にロックした一様回転。
- どの類の半径を 1.3 倍しても相対平衡のまま（10⁻¹⁵）。振動数は連続に変わる（例：射影 0 の類を 1.3 倍 → 30, 36.9, 36.9, 36.9）。射影 0.5 の類を変えたときは四つの振動数がそろったまま（41.04）。
- 丸め誤差から 3000 ステップで形の変化は 10⁻¹³ → 10⁻¹²·⁵（振幅込み）、10⁻¹²·⁷ → 10⁻¹¹·⁵（位相のみ）。指数的な拡大は無い。

**読み（確認前）：**
- ℓ を選ぶと、高対称な配置は回転する自己無撞着状態（時計）になる。回転は平面 (1, ℓ) の 1 と、三つの平面（SU(3) の 3）に分かれ、振動数は 1 + 3 の二つの値を取る。
- **連続の中の離散（訂正）：** 自己無撞着は半径（振幅）の比を連続に許し、比が無理数でも準周期的な自己無撞着状態になる。したがって離散性は「厳密なロック（有理数の比）の点」としては出ない。メモリの規則「近いが一致しない」のとおり、離散性は、近い値への引き込みとその近くの帯での準振動として現れるはずで、まだ観測していない。旧記述「全体がロックするのは有理数の点だけ、そこで離散が出る」は狭すぎた。確かなのは、配置の N と軌道の分かれ方（16 = 2 + 14、240 = 4 + 48 + 128 + 60）の離散と、半径の比の連続が同時にあること。
- **インフレーションは起きない：** 正軸体も E₈ の根も相対平衡で、中立。点火の資格（何らかの型の不安定な自己無撞着集合）を満たさない。論文 2 の「高対称は資格ではない」と同じ。
- **振動数の値について：** 等方的な配置（2-デザイン）では回転の振動数は N/d になる恒等式（正軸体 16/8 = 2、E₈ 240/8 = 30）。E₈ の 30 はコクセター数 h = 30 と一致するが、ルート系の「根の数 = h × 階数」から来る恒等式で、発見ではない。

## 第 4 段：番号の側の作用 K_ef = ⟨ℓ u_e, u_f⟩ の型を解析で決める（2026-10-20）

著者の問い：四つの型のそれぞれに、自己無撞着になる作用は見つけたのか。解析すれば見つかる。

**(1) 振幅込み（L_amp、R_amp も同じ形）— 解析で全部決まる。**
- K = Q Lᵀ Qᵀ（L は ℓ を左から掛ける 8×8 行列、Lᵀ = −L、L² = −I）。対角 ⟨ℓu, u⟩ = 0 なので「自分以外すべて」の制限は効かない。
- KQ = Q(LᵀS)、S = QᵀQ（成分の側のグラム行列）。**どの配置も自己無撞着**（状態はいつも自分の張りの中）。
- K は反対称なので S は保存。したがって解は厳密に Q(t) = Q₀ exp(−tLS)（刻み Δτ の離散の一歩でも厳密）。
- −LS は S^{1/2}(−S^{1/2}LS^{1/2})S^{−1/2} と反対称行列に相似なので、運動は有界で、振動数は S^{1/2}LS^{1/2} の固有値。

| 型 | 条件 | 配置（数値確認、`results/analytic_kernel_types_and_stability.json`） |
|---|---|---|
| 相対平衡 | [L, S] = 0 | 正軸体（S = 2I、振動数 2）、E₈（S = 30I、振動数 30）、十字（[L,S] = 0）。デザインは S ∝ I なので、どの L でも相対平衡 |
| 周期的 | [L, S] ≠ 0、振動数の比が有理数 | S の固有値の比で決まる（ℓ が結ぶ二成分の固有値 s_i, s_j で振動数 √(s_i s_j)） |
| 準周期的 | [L, S] ≠ 0、振動数の比が無理数 | NULL28：S = diag(14, 2, …, 2)、振動数 √28 と 2（比 √7）。形（グラム行列）は π/√28 ごとに戻る（第 1 段の 100 ステップ）が、状態は準周期 |
| 漸近的 | **起こらない** | 流れは線形で有界。引き込みも、インフレーション（指数的な離脱）も原理的に無い |

**(2) 位相のみ（L_ph）— 漸近的な型とインフレーションはこちらにしか無い。**
- 書き直すと dq_e/dt = T L q_e/|q_e|、T = Σ_f |q_f| u_f u_fᵀ（8×8 の対称行列。全要素が同じ T で駆動される平均場の形）。
- 大きさがそろい [L, T₀] = 0 なら相対平衡 q_e(t) = exp(T₀Lt) x_e。NULL28 は [L,S] ≠ 0 なので、最初は張りの中にいても大きさのそろいから外れる（第 1 段の「未判定」の理由）。
- 回転系での線形化は厳密に dε_e = δT L x_e − a_e T₀ L x_e（a_e = x_e·ε_e、δT = Σ_f (ε_f x_fᵀ + x_f ε_fᵀ − a_f x_f x_fᵀ)）。各 ε_e は δT（36 成分）と a_e を通してしか結合しない。
- **4-デザイン（E₈ の根）では解析で閉じる：** 2 次と 4 次のモーメントが等方的なので、(δT, A = Σ a_f x_f x_fᵀ) の方程式は ad_L（X ↦ [X, L]、固有値 0, ±2i）と 2×2 の実行列 M·[[9/80, 1/8], [1/80, 0]]（固有値 M/8 と −M/80）の積になり、固有値は純虚数 ±2i·M/8, ±2i·M/80。E₈（M = 240）で 60 と 6。**中立。**
- 数値（線形写像を基底に当てて作った厳密な行列、差分なし）：

- 実部の残り（10⁻⁸〜10⁻⁷）は、固有値 0 にジョルダン型の縮退がある（rank J > rank J²：大きさの差が位相のずれを線形に育てる剪断）ことによる固有値計算の誤差の桁。指数的な成長ではない。

**(3) 一つの作用（振幅込み）と一つの族で、三つの型の初期値をそろえる（`ortho16_ab_family_types_20261020.py`、`results/ortho16_ab_family_types.json`）。**

**漸近的な型の組（初期値と作用）はまだ見つけていない。** 振幅込みの作用では起こらないことが (1) で決まっている。位相のみの作用では、相対平衡（大きさがそろい [L,T₀] = 0）しか見つけておらず、周期的・準周期的・漸近的な組は未探索。

**読み（確認前）：**
- 振幅込みの作用は、どの配置も自己無撞着にするが、型は相対平衡・周期的・準周期的までで、漸近的な型とインフレーションを持たない。四つの型のうち三つはここで尽きる。
- 漸近的な型とインフレーションは、正規化（位相のみ）の非線形でしか起こらない。過去の複素数のインフレーションも位相のみの作用だった。
- 位相のみの作用でも、高対称な配置（正軸体・十字・E₈・正多角形）は中立。E₈ は 4-デザインなので解析で中立が決まる。過去の論文の「増幅 ⟺ 不安定な相対平衡」と合わせると、不安定な相対平衡は 4 次のモーメントが等方的でない、対称性の低い「大きさがそろい [L, T₀] = 0」の配置の側にあると読める（未確認）。
