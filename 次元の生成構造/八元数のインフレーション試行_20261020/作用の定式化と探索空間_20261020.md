# 作用の定式化と、自己無撞着になる配置の探索空間（2026-10-20）

**問い（著者）：** 高対称な八元数の初期値と、それが自己無撞着になりうる作用の組み合わせ・値を定式化せよ。

**プログラム：** `octonion_action_formulation_20261020.py`（本フォルダ。`次元の生成構造/八元数閉塞と関係の分解_20261019/octonion_closure_check_20261019.py` を読み込む。シード 20261020）。結果：`results/action_formulation.json`。

**位置づけ：** 定式化と、それを数値で裏づけた事実。読み（解釈）は分けて書く。前段は本フォルダの README（第 1〜3 段）。

---

## 1. 許される作用の形

無名性（番号の付け替えで不変）・ノルム保存・積からの構成、の三つを課すと作用の形は決まる。

**ȯ_e = u_e o_e、 u_e ∈ Im(𝕆)**

u_e が純虚なら、アルティンの定理（u と o は結合的な部分代数を張る）から

d|o_e|²/dτ = 2 Re((u_e o_e) ō_e) = 2 Re(u_e |o_e|²) = 0

で、**各要素の大きさが厳密に保存**する（数値：誤差 5.3×10⁻¹⁵）。

関係を **w_ef = o_f ō_e** と書く。G₂ 共変で純虚への双線形写像は**ちょうど 3 本**（𝕆⊗𝕆 = (1⊕7)⊗(1⊕7) の中に 7 が 3 回）で、

Im(x ȳ) = Re(y)Im(x) − Re(x)Im(y) − Im(x)×Im(y)

がその張る空間（誤差 2.2×10⁻¹⁵）。

## 2. 定理 A：双線形の作用は Σo = 0 で厳密に死ぬ

Σ_{f≠e} o_f = −o_e なので、3 本すべてが自己項に潰れる。

- Σ_{f≠e} Im(w_ef) = Im(−o_e ō_e) = Im(−|o_e|²) = **0**
- Σ_{f≠e} Im(o_e)×Im(o_f) = Im(o_e)×(−Im(o_e)) = **0**
- 残り二つは Re(o_e)Im(o_e) の定数倍に潰れる（相互作用ではなく自己項）

数値：ランダムな N = 9 の閉塞解で最大 6.9×10⁻¹⁶。

**これが README 第 2 段の F_A = F_B = 0 の正体。** 偶然でも配置の性質でもなく、線形の閉塞から出る定理である。

## 3. 生き残る最小の作用（第二層）

**u_e = (1/2) Σ_{f≠e} Im(w_ef²) = Σ_{f≠e} Re(w_ef) Im(w_ef)**

G₂ 共変（自己同型 g について u_e(g·o) = g·u_e(o)、誤差 8.5×10⁻¹⁴）、無名、ノルム保存で、Σo = 0 でも消えない。

**駆動因子（厳密）：**

**|Im(w_ef²)| = |o_e|² |o_f|² · |sin 2θ_ef|**　（θ は二要素の角、誤差 8.5×10⁻¹⁴）

0°・90°・180° で厳密にゼロ、45° で最大。これは二層二部の表の J = A|z_e|²|z_f|² sin 2Δφ の八元数版で、同じ式が再び出ている。

## 4. 定理 B：高対称な配置が静止する理由

| 配置 | N | 角度 | 鏡映で閉じる | max \|u\|（第二層） |
|---|---|---|---|---|
| ORTHO16（±1, ±e₁…±e₇） | 16 | 90°, 180° | はい | **0**（厳密） |
| 正十六胞体 v/√3 | 8 | 60〜180° | ― | **0**（厳密） |
| 24 胞体（ℍ 内） | 24 | 60, 90, 120, 180° | ― | **0**（厳密） |
| **E₈ の根 240** | 240 | 60, 90, 120, 180° | **はい** | **5.8×10⁻¹⁶** |
| **NULL28 ±(1±e_i)/√2** | 28 | 60, 90, 120, 180° | **いいえ** | **6.000** |

**二つの消え方がある。**

- **(a) 全対が 0°／90°／180°** なら sin 2θ = 0（ORTHO16）。
- **(b) 各要素 o_e に直交する鏡映 r_e(x) = x − 2⟨x,o_e⟩o_e/|o_e|² で集合が閉じる**なら、60° の寄与が対で打ち消される（E₈ の根、24 胞体）。

E₈ は 60° を持つのに消える。これが (b) である。NULL28 だけが鏡映で閉じず、u ≠ 0 になる。

**つまり「最も対称」であることが、そのまま作用がゼロになる条件になっている。鏡映群の軌道として作られた配置（正軸体・E₈・24 胞体）は、参照の向きを持たない作用では必ず静止する。**

## 5. 自己無撞着の条件

作用は G₂ 共変なので、**時間発展で条件が持続する**剛体回転は G₂ の中のものだけである。

**条件：ある D ∈ g₂ が存在して u_e o_e = D o_e（全 e）。**

このとき o_e(τ) = exp(τD) o_e(0)。D は自己同型なので閉塞もグラム行列も厳密に保存し、条件は τ によらず保たれる（数値：g u ḡ = u が 1.4×10⁻¹⁵）。

**振動数の拘束（G₂ から出る）：** D ∈ g₂ の虚 7 次元での重みは、正六角形の一つおきの三つ組とゼロ 1 本。したがって三つの振動数は**符号付きで和ゼロ**。

ω₁ + ω₂ + ω₃ = 0

数値：ランダムな D 6 本で「最大 = 他の二つの和」が相対誤差 10⁻¹⁶（固有値からは絶対値しか出ないのでこの形で検定した）。

**ロック（U^n = I）には三つが通約可能であることが要り、最小の比は 1 : 1 : −2。** 刻みは Δτ = 2π/(q·max|ω|)。

| 配置 | 作用 | g₂ 残差 | so(8) 残差 | 振動数 |
|---|---|---|---|---|
| ORTHO16 | B1 Σ⟨ℓo_e,o_f⟩Im(w) | 1.00 | **0** | **2** |
| ORTHO16 | C1 番号側 K = ⟨ℓo_e,o_f⟩ | 1.00 | **0** | **2** |
| ORTHO16 | A1, A2, A3, A6 | 0 | 0 | 静止 |
| NULL28 | A2（第二層） | 1.00 | 1.00 | ― |

| 正十六胞体 v/√3 | B1, C1 を含め A 系すべて | 0 | 0 | 静止 |
| 24 胞体 | 同上 | 0 | 0 | 静止 |
| ランダム閉塞 N = 9 | A2, A3, B1, C1 | 0.99〜1.00 | 0.30〜0.98 | ― |
| どの配置でも | B2 u_e = ℓ（一様） | 1.00 | **0** | 1 |

**読み取り**

- **ℓ を使う作用（B1, B2, C1）はすべて g₂ 残差 1.00。** ℓ を含む運動は自己同型ではない（1 を動かす）ので、so(8) の意味で剛体回転でも、**条件が時間発展で持続する保証がない**。README 第 3 段の回転解（正軸体で ω = 2、ここでも再現した）はこの型で、持続性は別に確かめる必要がある。
- **B2（u_e = ℓ 一様）は自明解。** どの配置でも so(8) 残差ゼロだが、これは「全体を同じ左掛け算で回す」だけで、配置の情報を持たない。自己無撞着の候補からは外す。
- **NULL28 の第二層は |u_e| がすべて 6 でそろうのに向きが要素ごとに違う。** 剛体回転にならない（so(8) 残差 1.00）。README 第 1 段で周期的と判定されたものがこれである。

## 7. 探索空間の定義（この定式化の結論）

参照の向きを使わずに**回る**自己無撞着状態を作るには、配置が次の二つを同時に満たす必要がある。

1. **鏡映で閉じない**（さもなくば定理 B で u ≡ 0、静止するだけ）
2. **ある D ∈ g₂ で u_e o_e = D o_e**（三振動数が符号付きで和ゼロ、ロックには通約可能）

鏡映群の軌道として作られた配置（正軸体 16、E₈ の根 240、24 胞体）は条件 1 で失格する。**探すべきは「高対称だが鏡映群の軌道ではない」配置**で、NULL28 はその一例だが条件 2 を満たさない。

これが README 第 2 段の「探索空間を決めてからの解析」に対する、正確な探索空間の定義になる。t-デザインの強さではなく、**鏡映閉包の有無**が一次の選別条件である。

## 8. 読み（計算結果ではない）

- 高対称であることが作用をゼロにする、という形は、論文 2 の「高対称・重心ゼロ・二乗閉塞は点火の資格ではない」の、作用の側からの言い換えになっている。資格がないのではなく、**作用そのものが消えている**。
- 駆動因子 sin 2θ が 45° で最大であることは、二層二部の表（`八元数閉塞と関係の分解_20261019/二層二部の表_相互作用の起源_20261019.md` §7）で「放射する関係は 45° だけ」としたのと同じ式である。複素の段で出した結論が、八元数の作用の定式化からそのまま再現した。
- ω₁ + ω₂ + ω₃ = 0 は、`二つの三_閉塞の三相と内部のZ3_20261019.md` の重み六角形（一つおきの三つ組が 120° で和ゼロ）の力学版。**三つの振動数が和ゼロで縛られる**ことが、G₂ を対称性に選んだことの直接の帰結として出る。
- README 第 3 段で正軸体の相対平衡が a = b のときだけで、三つの平面の振動数がそろうのは、この和ゼロの拘束と Z₃ の中心（三つの平面を同じ 120° で回す）の現れだと読める。**未確認。**

## 9. 次の検算

1. **鏡映で閉じない高対称配置を系統的に作る。** 候補：正多胞体の軌道のうち鏡映群の全軌道でないもの、NULL28 の変形、`kのスペクトルと粒子への割り当て_20261019.md` で定義した k が一般値より下にロックした配置。
2. **条件 2 を解く。** 配置を固定して u_e o_e = D o_e を D ∈ g₂ について最小二乗で解き、残差ゼロの配置を探す。逆に D を固定して配置を解く向きも可能。
3. **ℓ を使う解の持続性。** 正軸体＋B1（ω = 2）を実際に積分し、条件が τ とともに保たれるか、崩れるかを見る。g₂ の外の運動なので崩れる可能性がある。
4. **振動数の比。** 条件 2 を満たす配置が見つかったら、三振動数の比が有理数（ロック）か無理数（準周期）かを見る。1 : 1 : −2 が出るかが最初の照合点。
