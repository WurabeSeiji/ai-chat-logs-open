## 1. 許される作用の形

無名性・ノルム保存・積からの構成の三つを課すと、作用の形は次に限られる。

> **ȯ_e = u_e o_e、 u_e ∈ Im(𝕆)**

u_e が純虚なら、アルティンの定理（u と o は結合的な部分代数を生成する）により

d|o_e|²/dτ = 2 Re((u_e o_e) ō_e) = 2 Re(u_e |o_e|²) = 0

で、**各要素の大きさが厳密に保存される**（数値：誤差 5.3×10⁻¹⁵）。

関係を **w_ef = o_f ō_e** と書く。G₂ 共変で純虚への双線形写像は、表現の分解 (1⊕7)⊗(1⊕7) に 7 が三つ現れることから**ちょうど 3 本**で、

Im(x ȳ) = Re(y)Im(x) − Re(x)Im(y) − Im(x)×Im(y)

がその張る空間（誤差 2.2×10⁻¹⁵）。

---

## 2. 定理 A：双線形の作用は Σo = 0 で厳密にゼロ

線形閉塞のもとで Σ_{f≠e} o_f = −o_e だから、3 本すべてが自己項に潰れる。

- Σ_{f≠e} Im(w_ef) = Im(−o_e ō_e) = Im(−|o_e|²) = **0**（数値 6.9×10⁻¹⁶）
- Σ_{f≠e} Im(o_e)×Im(o_f) = Im(o_e)×(−Im(o_e)) = **0**（数値 1.1×10⁻¹⁵）
- 残り二つは Re(o_e)Im(o_e) の定数倍に潰れる（相互作用ではなく自己項）

**本フォルダ第 2 段の F_A = F_B = 0 はこの定理である。** 配置の性質でも偶然でもなく、線形閉塞から出る。

---

## 3. 生き残る最小の作用（第二層）と、その駆動因子

> **u_e = ½ Σ_{f≠e} Im(w_ef²) = Σ_{f≠e} Re(w_ef) Im(w_ef)**

G₂ 共変（自己同型 g に対し u_e(g·o) = g·u_e(o)、誤差 8.5×10⁻¹⁴）、無名、ノルム保存で、Σo = 0 でも消えない。駆動因子は厳密に

> **|Im(w_ef²)| = |o_e|² |o_f|² · |sin 2θ_ef|**　（θ は二要素の角、誤差 8.5×10⁻¹⁴）

**0°・90°・180° で厳密にゼロ、45° で最大。** これは二層二部の表の J = A|z_e|²|z_f|² sin 2Δφ と同じ量で、八元数でもそのまま成り立つ。

## 4. 定理 B：高対称な配置が静止する二つの仕組み

| 配置 | N | 角度 | 鏡映で閉じるか | max&#124;u&#124; |
|---|---|---|---|---|

消え方が二つある。

- **(a) 全対の角が 0/90/180°** → sin 2θ = 0 で各項がゼロ（ORTHO16）。
- **(b) 各要素に直交する鏡映 r_e(x) = x − 2⟨x,o_e⟩o_e/|o_e|² で集合が閉じる** → 60° の寄与が対で打ち消される（E₈、24 胞体）。E₈ は 60° を持つのに消えるのはこちら。

**鏡映群の軌道になっている配置（正軸体・E₈・24 胞体）は、参照の向きを持たない作用では必ず静止する。** NULL28 だけが鏡映で閉じず、u ≠ 0 になる。

**「最も対称である」ことが、そのまま作用がゼロになる十分条件になっている。** 本フォルダ第 2 段の「F_A・F_B が正軸体と E₈ で厳密に 0」は、この定理の特別な場合。

## 5. 自己無撞着の条件

作用は G₂ 共変なので、**時間発展で条件が持続する**剛体回転は G₂ の中のものだけである（自己同型は積も閉塞もグラムも保つ）。

> **条件：∃ D ∈ g₂ で u_e o_e = D o_e（全 e）**
>
> このとき o_e(τ) = exp(τD) o_e(0)。8N 本の式に対し未知数は 14 なので強く過決定で、特別な配置しか満たさない。

**振動数の拘束：** D ∈ g₂ の虚 7 次元での重みは正六角形の三組 ±ω₁, ±ω₂, ±ω₃ とゼロ 1 本。したがって

> **ω₁ + ω₂ = ω₃**（数値：一般の D で最大が他の二つの和に一致、誤差 2.7×10⁻¹⁵）

ロック U^n = I には三つが通約可能であることが要り、**最小は 1 : 1 : 2**。刻みは Δτ = 2π/(q·ω₃)。

**so(8) との違い：** ℓ を使う作用（B1、B2、C1）が作る運動は so(8) の剛体回転ではあるが**自己同型ではない**（1 を動かす）。形（グラム）は保つが、条件が持続する保証はない。第 3 段の回転解はこの型なので、持続性は別に確かめる必要がある。

## 7. 設計指針（この定式化から出る探索空間）

参照の向きなしで**回る**自己無撞着状態を作るには、配置が次を同時に満たす必要がある。

1. **鏡映で閉じない**（定理 B(b)。閉じると u = 0）
2. **全対の角が 0/90/180° だけでない**（定理 B(a)）
3. **u_e o_e = D o_e、D ∈ g₂** を満たす（8N 本の式、未知数 14）
4. ロックするなら三振動数が通約可能（ω₁ + ω₂ = ω₃、最小 1 : 1 : 2）

**鏡映群の軌道（正軸体、E₈、24 胞体）は条件 1 で失格。** これまで試されてきた「最も対称な配置」がすべてここに入っていたのが、第 1〜3 段で何も起きなかった理由である。

探すべきは **「高対称だが鏡映群の軌道ではない」配置**。NULL28 はその一例だが条件 3 を満たさない。

## 8. 読み（計算結果からの解釈、確認前）

- **対称性が高すぎると動かない、が定理になった。** インフレーションの資格の話（論文 2「高対称は資格でない」）の、八元数での厳密な形。しかも理由が二つに分かれ、どちらも配置の幾何（角と鏡映）だけで判定できる。
- **時計には参照の向きが要る、も定理に近づいた。** 参照なしの作用で回るには条件 1〜3 が全部要り、鏡映群の軌道は全滅する。ℓ を選べば ORTHO16 がすぐ回る（ω = 2）。本フォルダ第 2 段の読み「時計は対称性の破れ（観測者の ℓ）と同時に現れる」は、この意味で支持される。ただし ℓ 型の運動は自己同型でないので、持続性がまだ示されていない。
- **1 : 1 : 2 という最小のロック比**は、g₂ の重みが正六角形であることから出る。これは観測者が何を固定するかに依らない、代数だけから出る離散性。R5 に従い、既知の物理量とは結びつけない。
- **k（開く虚方向の本数）との関係は未検討。** `八元数閉塞と関係の分解_20261019/kのスペクトルと粒子への割り当て_20261019.md` の k と、ここでの条件 1〜4 がどう関係するかは次の課題。ロックした配置（十字 k=1、正十六胞体 k=3）はどちらもここでは静止側に入っている。
