# 走行 1：全順序対（M＝N²、自己対込み）・隣接重み 0/1 は残す（2026-10-25）

目的（木原、10/25）：現行の M＝N(N−1)/2（上三角の完全リスト）は、自分 (i, i) を除き i＜j で向きを固定している点で無名性に反する可能性が高い。
これを、自己相互作用を含む全順序対 M＝N² に**最小限の変更**で直す。一因子ずつ切るため、**隣接重み A（頂点共有の 0/1）は本走行では残し**、
別走行（走行 2）で A を外す。高対称の複素数は自分では何も読めないので、系の組織化を支える外部情報が A か Δτ かを切り分けるための設計。
本走行はインフレーションの有無を判別する実験ではなく、設定側の無名性違反を取り除く段階である（高対称と読出し不能は複素数の構造の別問題）。

記法：d(·) は大域位相を揃えた相対距離（無相関なら √2 ≈ 1.41）。C(s) は配列添字の巡回自己相関。AUC は |sin(θ_f−θ_e)|（または面積 |Im(v̄_e v_f)|）の大小で A_ef＝1 を言い当てる Mann–Whitney の AUC（0.5 で読めない）。

事実：
- 位相の束は全 N で 4 本、角度は 0, 90, 180, 270°。元の上三角の親と同じ十字。
- 振幅は対角 (i, i) が非対角のほぼ半分（比 0.51〜0.69）。|V_ij| と |V_ji| は一致しない（差の最大は平均の 1〜2 割）。
- 転置・共役転置・同時巡回シフトのどれにも親は不変でない（d ≈ 1.1〜1.4）。A が持つ対称性を親は破っている。
- 配列添字の自己相関は s＝1, N, N＋1 のどこにも山がない（N≥6 で 0.01〜0.16）。周期 N の構造は値の並びに現れない。
- 隣接対と非隣接対で |sin Δθ| の分布は同じ（4 束なので値は 0 か 1。|sin|＝0 の割合は N＝25 で 0.491 対 0.501）。AUC は N≥10 で 0.48〜0.50、小さい N でも 0.58〜0.67。**値と並びから隣接の 0/1 は読めない。**
