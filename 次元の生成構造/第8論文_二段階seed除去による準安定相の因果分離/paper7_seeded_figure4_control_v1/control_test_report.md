# 論文7・図4 現行二段階seed対照再実行報告

## 結論

論文7の原本プログラムを変更せず、初期seedと図4用横摂動seedをともに
有効にした現行条件で N=5, 40, 300 を再実行した。

再生成した数値CSV、メタJSON、PNG画像は、既存の論文7成果物と
すべてバイト単位で一致した。SVGも日時とMatplotlib内部IDを正規化すると
全文一致した。比較プログラムの総合判定は `all_passed=true` である。

したがって、現行の二段階seed条件から論文7の図4を同一に再現できる。
