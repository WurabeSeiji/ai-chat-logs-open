# 第8論文 本実験仕様書  
## 初期フラット領域における下位階層・方向生成・停止同時性の段階的検証

**対象シリーズ:** 「次元の生成構造」第8論文  
**目的:** 第7論文で観測された  
\[
\text{幾何級数的拡大}
\rightarrow
\text{2方向+1方向の成立}
\rightarrow
\text{ほぼ同時の拡大停止}
\rightarrow
\text{三方向準安定相}
\rightarrow
\text{追加方向の萌芽}
\]
という時間構造が、初期フラット領域のさらに下位にもスケール対称に存在するかを検証する。

---

# 0. この実験で判定する中心問題

本実験は、単なるseed除去実験でも、単なる分解能掃引でもない。

初期フラット領域で観測される微小な3方向構造が、次のどちらであるかを区別する。

## 仮説H1：下位階層の三方向閉包

初期フラット領域より前に、さらに小さい振幅領域で下位の幾何級数的拡大が存在し、その停止とほぼ同時に

\[
2方向+1方向
\]

が成立した。その結果として、現在フラットに見える領域は一段下の三方向準安定相である。

期待される時間順序：

\[
\text{下位フラット}
\rightarrow
\text{下位幾何級数的拡大}
\rightarrow
\text{3方向成立と下位拡大停止}
\rightarrow
\text{下位準安定相}
\]

この場合、第7論文の上位構造とスケール対称である。

## 仮説H2：準安定相内部の追加方向萌芽

初期フラット領域に入った後、一定時間を経てから3方向らしき微小成分が現れる。

この場合、その成分は下位拡大停止時に成立した三方向ではなく、第7論文の三方向準安定相で後から現れた「追加方向の萌芽」と同型である可能性が高い。

期待される時間順序：

\[
\text{下位拡大停止}
\rightarrow
\text{長い下位準安定相}
\rightarrow
\text{追加方向萌芽}
\]

## 仮説H0：下位階層を検出できない

測定可能範囲で下位の幾何級数的拡大も、その停止と方向成立の同時性も確認できない。

この場合、スケール対称性は支持も反証もされない。

# 1. 既報との関係と訂正

第5論文では、明示seedを \(\delta=0\) とした走行でも、浮動小数点数値床から指数増幅が起きることがすでに観測されている。

したがって、

> 明示seedなしでも立ち上がる

こと自体は第8論文の新規主張ではない。

第8論文の新規性は、初期フラット領域の下に、第7論文と同型の

\[
\text{拡大}
\rightarrow
\text{3方向成立}
\rightarrow
\text{停止}
\rightarrow
\text{準安定}
\rightarrow
\text{追加方向萌芽}
\]

が存在するかを、時間分解して検証することにある。

# 3. 実験上の重要原則

## 3.1 現在の初期状態を「真の最初」と仮定しない

初期状態として与えられた親状態の直後だけを観察してはならない。

下位階層が存在するかを調べるため、可能な限り深い数値精度から時間発展を記録する。

## 3.2 観測によって方向を作らない

rank判定、SVD、固有方向追跡は観測のみとし、状態更新へフィードバックしてはならない。

## 3.3 固定閾値rankだけで方向成立を判定しない

底付近では固定閾値を跨ぐだけでrankが揺れる。

方向成立には少なくとも以下を併用する。

- 特異値比
- 方向ベクトルの時間連続性
- 持続時間
- 数値床に対するS/N
- 複数精度間の再現性
- 量子化前後・再射影前後の一致

## 3.4 「萌芽」と「成立」を分ける

- **萌芽:** 微小な追加方向成分が一時的または断続的に現れる
- **成立:** 独立方向が一定期間持続し、方向ベクトルも連続し、数値床より十分大きい
- **閉包:** 方向成立と幾何級数的拡大停止が時間的に対応し、その後に準安定相へ移る

# 4. 数値精度と実験系列

各Stageで、少なくとも次の3系列を別々に行う。

## Series 1: 自然有限精度

- float64
- 明示seedなし
- 量子化なし
- 必要な閉鎖維持処理のみ
- 第5〜第7論文と最も近い更新則

目的：既報との直接比較。

## Series 2: 高精度

- float128相当または任意精度
- 推奨精度：80 bit、128 bit、256 bit相当のうち実装可能な複数水準
- 明示seedなし
- 量子化なし

目的：

- 観測された底がfloat64固有か
- 数値精度を上げるとさらに下位の拡大が現れるか
- イベント時刻が \(\log(1/\epsilon_{\rm machine})\) に従うか

を調べる。

## Series 3: 制御分解能

- 指定した \(\Delta\) で量子化
- 量子化前、量子化後、再射影後をすべて保存
- \(\Delta\) はStage Aで広く、Stage B/Cでは必要範囲だけ実施

目的：

- 人工的な分解能床が下位構造を再現するか
- 自然数値床と同型か
- 方向萌芽が量子化または再射影で作られていないか

## 5.1 目的

N=5は、全状態・全特異方向・全イベントを最も高密度に保存できる探索Stageとする。

ここで次を確定する。

1. 下位の幾何級数的拡大が存在するか
2. その開始時刻と終了時刻
3. 3方向成立時刻
4. 下位拡大停止と3方向成立が同時か
5. その後に追加方向萌芽が現れるか
6. 第7論文の上位時間構造との対応
7. 必要な精度・記録間隔・閾値

## 5.2 実行条件

- N=5
- \(M=N(N-1)/2=10\)
- 明示seedなし
- 初期親状態は既報と同一生成規則
- 全runで初期状態・生成子・乱数seedを保存
- 原則として決定論的run
- 同一条件を2回実行しbitwiseまたは許容誤差内一致を確認

最低限：

- float64
- 高精度1水準
- 高精度2水準

制御分解能：

\[
\Delta \in \{10^{-4},10^{-6},10^{-8},10^{-10},10^{-12},10^{-14}\}
\]

ただし、Stage Aの自然有限精度・高精度結果を見て範囲を調整してよい。

## 5.4 記録間隔

初期から上位準安定相まで、**毎step保存**する。

N=5では間引かない。

保存時間は、少なくとも以下を全て含むまでとする。

- 下位候補領域
- 上位の幾何級数的拡大
- 3方向成立
- 拡大停止
- 準安定相
- 追加方向萌芽が最低3回観測される期間、または上限時刻

## 5.5 N=5で保存する完全状態

毎step、可能なら以下を保存する。

- 複素状態ベクトル \(Z\)
- 生成子の低ランク表現
- 主要特異値・特異ベクトル
- 親平面・各候補方向への射影
- 方向間重なり行列
- 前stepからの方向回転角
- 方向ごとのエネルギー様配分
- 各更新段階の状態差

N=5では完全状態保存を優先する。

# 10. 方向判定

## 10.1 数値床推定

各stepで数値床を1個の固定定数にしない。

少なくとも以下から適応床を推定する。

- closure残差
- norm残差
- 最小非零成分
- 精度水準
- 再現run間差
- 量子化補正
- 再射影補正

\[
\eta_{\rm noise}(t)
\]

を定義して保存する。

## 10.2 萌芽判定

候補方向 \(j\) について、

\[
q_j(t) > c_{\rm sprout}\eta_{\rm noise}(t)
\]

を満たし、かつ方向ベクトルが少なくとも短期間追跡可能なら萌芽候補とする。

単発crossingは萌芽確定としない。

## 10.3 成立判定

以下をすべて満たすこと。

1. \(q_j/q_1\) が適応閾値以上
2. 一定step以上持続
3. 方向連続性が基準以上
4. 再現runで同じ相対時刻に出現
5. 精度変更で消失しない
6. 量子化・再射影だけで発生していない

閾値値はStage Aでデータから校正し、その後固定する。

# 11. 幾何級数的拡大の判定

単に閾値到達時刻だけを使わない。

\[
g(t)=\frac{d}{dt}\log a_{\rm outside}(t)
\]

を局所回帰で求める。

拡大区間は、

- \(g(t)>0\)
- 回帰決定係数が基準以上
- 一定長以上持続
- 振幅が数値床より十分大きい

を満たす区間とする。

下位拡大と上位拡大を別イベントとして検出可能にする。

---

# 12. 拡大停止の判定

拡大停止時刻は、単に閾値到達時刻ではない。

以下を併用する。

- \(g(t)\) の正値から0近傍への低下
- \(a_{\rm outside}\) の指数回帰からの系統的離脱
- 方向配分の再編
- 流入・流出の釣り合い
- 準安定振動開始

複数基準から停止区間を推定し、単一点ではなく信頼区間を出す。

---

# 13. 論文7との対称性判定

第7論文から上位イベント時刻を同じ定義で再計算する。

比較するイベント列：

```text
growth_start
direction3_sprout
direction3_established
growth_end
metastable_start
direction4_sprout
```

上位・下位それぞれで、イベント間隔を特徴時間で正規化する。

特に、

\[
\Delta t_{\rm close}
=
t_{\rm direction3\,established}
-
t_{\rm growth\,end}
\]

を主要判定量とする。

## H1支持

\[
|\Delta t_{\rm close}|
\]

が下位・上位とも小さく、正規化後に同程度。

## H2支持

下位拡大停止後、長い準安定期間を経て方向萌芽が現れ、その時間構造が第7論文の追加方向萌芽と対応。

## 未判定

下位拡大が検出できない、または方向判定が数値床と分離できない。

4. 下位拡大開始・終了

# 18. Stage継続判定

## Stage A → B

次のいずれかを満たす場合のみ進む。

- 下位拡大と方向イベントを識別できた
- 識別できなかった理由が精度・時間範囲に限定され、Stage Bに意味がある
- 観測定義が固定できた

## Stage B → C

次の条件をすべて満たす場合のみ進む。

- N=5とN=40で同じ判定量を計算できる
- 少なくともH1/H2のどちらかを識別できる見込みがある
- N=300で必要な最小条件が確定している

# 19. 禁止事項

- N=5、40、300を一括実行しない
- Stage報告前に次Stageを開始しない
- crossing時刻だけで結論を出さない
- 固定rank閾値だけで方向成立を判定しない
- 初期フラット領域を最初の底と仮定しない
- 量子化後だけを測定しない
- 再射影後だけを測定しない
- 第7論文と異なるイベント定義で比較しない
- 結果に合わせて閾値をrunごとに変更しない
- N=300を探索目的で大量掃引しない

# 20. 最終的に論文8が答える問い

本実験が成功した場合、論文8は次を答える。

1. 初期フラット領域より下に、さらに下位の幾何級数的拡大と停止があるか。
2. その停止と3方向成立は、第7論文と同様にほぼ同時か。
3. 初期フラット領域で見える3方向は、下位閉包の完成方向か。
4. それとも、下位準安定相内部に現れた追加方向萌芽か。
5. 上位と下位の事象列は、時間・振幅を正規化すると同型か。
6. この構造はN=5、40、300で維持されるか。

本実験の中心判定は次である。

\[
\boxed{
\text{初期フラット領域は、第7論文の三方向準安定相を縮小した同型階層か}
}
\]
