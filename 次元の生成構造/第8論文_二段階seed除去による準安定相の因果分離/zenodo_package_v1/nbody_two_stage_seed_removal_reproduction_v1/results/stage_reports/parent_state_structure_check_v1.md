## 代数的帰結の確認

Z = X + iY に対し Z^T Z = ‖X‖² − ‖Y‖² + 2i X・Y であるから、
零二乗閉鎖 Z^T Z = 0 は ‖X‖ = ‖Y‖ かつ X・Y = 0 と同値である。
上表はこの帰結（等ノルム・直交）と、全 M 成分非零のまま実 rank 2 に
集約される事実を、make_parent 出力に対して数値確認したものである。
