## 0. 問い

四元数の論文は、{zₙ}（2N 個）を二つずつ組にして {qₙ}（N 個）を作る段を「全投射」（情報の増減なし）とし、組の作り方を「実部・虚部と名前を付けるのと同じ種類の読み方の選択」として扱った（論文 §3）。集合としては ℂ^{2N} ＝ ℍ^N ＝ ℝ^{4N} で同じものである。

しかし、掛け算で見るとただの名前替えではない。同じ 2N 個の複素数でも、閉塞の条件が変わる。

- 複素数の配列として二乗：Σ(z₁² ＋ z₂²) ＝ 0
- 四元数として二乗：q² ＝ (z₁² − |z₂|²) ＋ 2Re(z₁)·z₂ j なので、Σ(z₁² − |z₂|²) ＝ 0 かつ Σ Re(z₁) z₂ ＝ 0

塊として読むことは「相互作用が四元数の積で働いている」という主張を含む。なぜそう読んでよいのかが問いである。

---

## 1. 塊の大きさは 1, 2, 4, 8 に限られる（フルヴィッツの定理）

**事実：** 塊として読むとは、二つの要素の関係 w ＝ ō_e o_f を作ることである。関係に次の二つを要求する。

- (a) 関係は要素と同じ種類の量である（無名性：関係もまた状態として読める）。
- (b) 関係の大きさは大きさの積になる：|ō_e o_f| ＝ |o_e||o_f|（そうでないと視野角の読み出しが全体のスケールに依存する）。

これを満たす積（ノルムを保つ合成代数）が存在するのは 1, 2, 4, 8 次元だけで、ℝ、ℂ、ℍ、𝕆 にあたる（フルヴィッツの定理。目録 §3 にも記載）。

**読み：** 配列の 2 次元のブロックを 4 次元・8 次元にまとめるのは、名札付けではなく「関係の掛け算をどの大きさのブロックで閉じさせるか」の選択であり、選べる段はこの四つしかない。

---

## 2. 四元数の塊：二つ目の虚数単位は相互作用 K と共役から出る

**事実（代数）：** 実ベクトル空間が四元数の塊として読めるのは、互いに反可換で二乗が −1 の写像が二つあるとき（複素ベクトル空間に二乗 −1 の反線形写像があるとき）である。この系には材料がそろっている。

- J₁ ＝ i（複素数そのものの虚数単位）
- J₂ ＝ C ∘ J_K（C は複素共役、J_K は生成子 K の極分解の直交部分。実反対称の K は像の上で二乗 −1 になる。論文 0 §7 の Ka ＝ μb、Kb ＝ −μa）

J₂² ＝ C J_K C J_K ＝ J_K² ＝ −1（C は実の J_K と可換、C² ＝ 1）。J₁J₂ ＝ i C J_K ＝ −C i J_K ＝ −C J_K i ＝ −J₂J₁。

**数値確認（2026-10-19、付録 A）：** ランダムな 6×6 の実反対称 K で、J₁²・J₂²・J₃² ＝ −1（誤差 4.4×10⁻¹⁶）、J₁J₂ ＋ J₂J₁ ＝ 0（厳密に 0）。i と K だけでは可換（交換子が厳密に 0）で四元数にならず、共役 C を挟んだときだけ反可換になる。

**読み：**
- **どの二つを組にするかは相互作用が決める。** K は ±iσ の固有値の対ごとに波の番号の空間を 2 次元のブロックに分ける。そのブロックの中で K が互いに回し合う二つの方向が、一つの四元数の z₁ と z₂ である。組は名札ではなく、相互作用が回し合う二つのモードである。
- **塊は状態とともに組み替わる。** K は状態から作られるので、インフレーションの最中は組み方が変わり続け、ロックして K が止まったときに塊が安定した単位として読める。
- **共役 C が要るのは、塊が向きを含むから。** C は検討ルール R7 で「外から入っていた選択」とした向き（K(z̄) ＝ −K(z)）と同じもの。四元数の塊は、複素数・相互作用・向きの三つがそろって初めて読める。

**数の注意（R5）：** 論文 0 では N ≥ 6 で rank K ＝ 2(N−1)。上の読みなら K が作る塊は N−1 個で、「自分と自分以外」の関係の数と同じだが、数の一致だけでは結びつけない。

---

## 3. 八元数の塊は作用からは原理的に出ない

**事実：** 配列に作用する線形写像の積は必ず結合的である。i・K・C をどう組み合わせても、出てくるのは結合的な代数（クリフォード代数）だけで、非結合的な八元数は作用素としては決して作れない。

**読み：** 八元数が現れるとすれば、状態に作用する写像としてではなく、**状態どうしの関係の積 ō_e o_f そのもの**としてである。§1 の (a)(b) を 8 次元のブロックで満たす積は八元数しかない。八元数は作用の側ではなく関係の側に現れる構造である。八元数のメモが関係 ō o′ の分解から始めていることと整合する。

---

## 4. 倍加の出来事：インフレーションは ℂ → ℍ の一段だった可能性

**事実（過去の記録）：** 論文 0（Concept 22729146）§7：複素数の配列の状態はどの瞬間も一枚の 2 次元平面（複素構造 1 つ）。インフレーションでその平面から離れ、終端の平面と初期の平面は二つの非零の主角で 4 次元を張る（累積写像は SO(4) ではない）。

**読み：** インフレーションは一枚の平面から二枚の平面への倍加で、ℂ → ℍ の一段（2 → 4）にあたる出来事だった、と読める。八元数にはもう一段の倍加（4 → 8）が要る。二度目のインフレーションのような出来事が起こるかは未確認。

**事実（八元数メモ §1.1）：** 八元数の関係の四元数部分は Vec(q̄q′) ＋ Vec(p̄′p)（誤差 0）。時空の半分は q̄q′ の順、内部の半分は p̄′p と逆の順で読まれる。

**読み：** 八元数になるには、二つの四元数の塊を束ねるだけでなく、片方を左からの積、もう片方を右からの積で読む必要がある。非結合性の源はこの順序の逆転。左と右が両方そろうことは、R6 の「格子と両立して光円錐に乗る一歩は左と右の組でしか作れない（位数 8）」と同じ構造に見えるが、形の類似で結びつけない（R5）。

---

## 5. 要るのは作用でも時空の対称性でもなく、関係の構造の対称性：三対性

**読み（著者との整理）：** この系には内部の位相空間しかなく、時空は読み出しなので、特殊な対称性が要るのは時空ではなく関係の構造の側である。

- 関係 w ＝ ō_e o_f には三つのものが登場する：自分 o_e、相手 o_f、関係 w。
- 複素数・四元数では関係は最初から状態と同じ種類の数なので、三つは自動的に同じ型。
- 8 次元で三つが同じ型であるためには、Spin(8) の**三対性**（ベクトル 8_v とスピノル 8_s・8_c の三つの 8 次元を入れ替える対称性）が要る。八元数の積は、そのうち二つを掛けて三つ目を作る写像である。
- 三対性があると、どれが状態でどれが関係かを区別できない。**「自分・相手・関係」の三角形を無名に扱う要求、すなわち無名性を関係にまで広げたもの**である（著者：状態と関係、頂点と辺を区別しない、入れ替え可能と考えるかなり特殊な対称性）。
- 三対性で三つを同一視したうえで残る積の対称性が G₂（14 次元）、観測者が自分の 1 をどこに置くか（分け方）を選ぶと SO(4) に落ちる（八元数メモの対称性の三段と同じ数え方）。

**双対性から三対性への階段（事実）：**

| 段 | 入れ替えの対称性 | 何と何を区別しないか |
|---|---|---|
| ℂ | Z₂（i ↔ −i、共役） | 回転の向き |
| ℍ | Z₂（左 ↔ 右。so(4) ＝ su(2) ⊕ su(2) の二つを入れ替える） | 左からの積と右からの積 |
| 𝕆 | S₃（三対性。D₄ の三本の足を入れ替える） | 自分・相手・関係の三つ |

**二つの so(4) を混同しないこと（2026-10-19 追記、`八元数閉塞と関係の分解_20261019/対称性の鎖と二つの三の訂正_20261019.md` §1）：** 上の表で ℍ の段に書いた so(4) は、**ℍ 自身に q ↦ aqb̄ で作用する**もので、左右の su(2) ⊕ su(2) に分かれる。八元数フォルダの so(4) は、**G₂ の中で四元数部分代数 H′ を固定する部分群**で、so(3)_空間 ⊕ su(2)_内部 に分かれる。次元はどちらも 6、代数の型も同じだが、別物。

二つを入れ替えるのが双対性、三つを入れ替えるのが三対性。三本の足を入れ替えられる対称なディンキン図形は D₄ だけなので、三対性は 8 次元（Spin(8)）にしかない。四元数の段の左右（双対性）が、八元数の段で三つ巴に広がる。

## 6. 過去の系列との関係（読み、確認前）

頂点と辺を入れ替える考え方はすでに使っていた。旧系列のインフレーションでは複素数の波を辺（関係）に置き、相互作用は辺どうしの隣接（線グラフ L(K_N)）で決めた。辺を状態として扱っていた。今の読み方は波を頂点（自分と自分以外）に置く。どちらでもインフレーションが出たのは、複素数の段では状態と関係が同じ型で入れ替えが自動的に許されていたから、と読める。八元数の段ではこの入れ替えが自動でなくなり、三対性という条件として現れる。旧系列と新系列が同じ結果を出した理由をこの入れ替えで説明できるかは、まだ何も確かめていない。

## 7. 確かめる計算（追加の仮定なし）

1. **K のブロックと四元数の塊。** 既存のインフレーションのデータ（ロック後）で K の ±iσ ブロックを取り、J₂ ＝ C ∘ J_K で組んだ四元数の塊が時間とともに安定するか（ロック前は組み替わり、ロック後は止まるか）。
2. **4 次元の張りが 8 次元まで広がる局面。** 既存のインフレーションのデータで、初期面と終端面が張る 4 次元（論文 0 §7）の先に、途中で 8 次元まで広がる局面があるか。二度目の倍加の有無の最も直接的な確認。
3. **関係の順序の逆転。** 二つの四元数の塊の関係を左右どちらの順で読むと閉塞（Σo ＝ 0、Σo² ＝ 0）と整合するか。

## 付録 A：§2 の数値確認（2026-10-19）

```python
import numpy as np
rng=np.random.default_rng(1)
M=6
A=rng.normal(size=(M,M)); K=A-A.T
U,s,Vt=np.linalg.svd(K); JK=U@Vt          # K の極分解の直交部分（二乗 -1）
Z=np.zeros((M,M)); I=np.eye(M); E=np.eye(2*M)
J1=np.block([[Z,-I],[I,Z]])               # i
C =np.block([[I,Z],[Z,-I]])               # 複素共役
JKr=np.block([[JK,Z],[Z,JK]])             # K は実部・虚部に同じく作用
J2=C@JKr; J3=J1@J2
# 結果：J1²,J2²,J3² = -1（最大誤差 4.4e-16）、J1J2+J2J1 = 0（0.0）、
#       J1JKr-JKrJ1 = 0（0.0：i と K だけでは可換）
# K の固有値は ±iσ の対（±4.802i, ±2.676i, ±0.727i）
```
