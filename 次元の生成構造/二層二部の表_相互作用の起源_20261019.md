## 0. 前段：ゼロ閉塞の解集合（数値ビューアの結論）

複素数 N 個 zₙ = aₙ + i bₙ について、三つの集合を数値で可視化した（各点は方程式を解析的に解いた厳密解。最大残差は倍精度で 10⁻¹⁶ 台）。

- S = {Σzₙ² = 0}（二乗和のゼロ閉塞）：実 2N − 2 次元。複素ヌル錐そのもの。実条件は Σa² = Σb² と Σab = 0 の 2 本。
- A = {Σzₙ = 0, Σaₙbₙ = 0}（線形閉塞＋積和閉塞）：実 2N − 3 次元。S より次元が 1 高い。
- S∩A = {Σzₙ = 0, Σzₙ² = 0}：実 2N − 4 次元（N ≥ 3）。N = 2 では原点のみ。N = 3 では c·(1, ω, ω²) と c·(1, ω², ω) の 2 本の複素直線（2 つのヘリシティ）。N ≥ 4 で既約。
- S と A は互いに他方を含まない。共通部分 S∩A の外側に、それぞれ 2N − 2 次元と 2N − 3 次元の部分がある。

**事実：** 線形閉塞 Σz = 0 は、ベクトル u = (1, …, 1) に直交する超平面での切断であり、u はヌルでないので、ヌル錐を 1 次元下げた非退化のヌル錐になる。S∩A は「u 方向を進行方向とする横波のヌル解」で、N = 3 の正三角形解は 2 つのヘリシティ（三相交流の正相・逆相）、N ≥ 4 で偏波面が u⊥ の中で自由になり 1 つの錐につながる。読めない λ ∈ ℂ*（2 次元）を除くと 2N − 6 = Q_{N−3} の実次元で、論文 §2.2 と一致する。

**事実：** 十字 (1, −1, i, −i) は「各成分が純実数か純虚数」の解で、45° 回すと各成分が個別にヌルになる（論文 表 3 の一行目「一つの複素平面、N = 4」）。複素数では位相原点が自由なので両者は同じもの、四元数では 45° に固定される（論文 §8.3）。

**R2 の宣言：** ビューアは各点を |z|（ℂ^N のユークリッドノルム、外の観測者の目盛り）で一度割って球面に載せている。3 集合は錐なので向きだけを読む射影的な読み出し。中心投影 u = v/q₀ とは逃げる成分が違う（球面への正規化は ± と赤道を残し、中心投影はそれらを捨てて比だけを読む）。

**論文への補足（式で閉じる）：** 等方閉塞（13 本）を満たす配置は、空間部分を v → v/√3 と縮めれば必ず本当の二乗の閉塞（8 本）を満たす（Σ|v|² = 3s → s、交差項と和零はスケールで不変）。等方閉塞の解集合は、本当の二乗閉塞の解のうち空間モーメントが等方な部分と 1/√3 で一対一に対応する。Σq₀² = Σ|v|² は「時間の広がり＝空間 3 方向の広がりの合計」で、開いた方向の数を k とすれば各方向の分散は Σq₀²/k（表 3 の 3 : 1 : 1 : 1 は k = 3、複素数の Σa² = Σb² は k = 1）。

## 1. 全員対全員は仕様であって実装ではない

全員対全員を「処理」として読むと宇宙の原理になり得ない（10⁶⁰ 対 10⁶⁰ は起きない）。自然が全員対全員を O(N) で済ませる方法は三つで、三つともこの系に入っている。

1. **閉塞は計算ではなく保存で保たれる。** Σz = 0 は N 個を足して確かめる量ではなく、二者の受け渡しが保存的なら局所の操作だけで保たれる（ガウスの法則が初期条件の拘束で、局所の発展がそれを壊さないのと同じ）。§2.3 の「自分以外の和はちょうど −z_k」は、各要素が自分だけを見れば全員の一次の情報を知っているという O(1) の事実。二乗の閉塞も同じで、自分以外の二乗和は −z_k²。閉塞が決めるのは塊の低次モーメントまでで、決めない残り（塊の中の分布）が局所の情報。
2. **場か凝縮体。** 場は c で局所伝搬し、遅延を代償に O(N) で全員の寄与を届ける。凝縮体は各要素が秩序変数（塊）とだけ結合する平均場（グロス＝ピタエフスキーは全員対全員の接触相互作用を自分対塊に書き換えたもの）。凝縮体に見えるのは、全員対全員が実装されるときの唯一の形。
3. **既知の模型との対応。** K_ef = A sin(φ_f − φ_e) は蔵本模型。Σz は蔵本の秩序変数、Σz = 0 は r = 0 の釣り合い、Σz² = 0 は第二調波の秩序変数（大同の一般化秩序変数）が 0、1 の N 乗根の解は巻き数付きのツイスト状態。全結合は平均場で解け、環や格子など疎な結合ではツイスト状態や位相の渦（欠陥）が現れる。局所の歪みは結合を疎にしたところに住む。

**読み：** 宇宙としては、全員対全員は種にだけ成り立つ。一つの地平線の中にすべてがある最初の小さな N（N = 5 の親）では自然。膨張で c の届く範囲が相対的に狭まり結合は局所になる。早い時期に確立した位相の一致は凝縮体として受け継がれ、地平線を越えて合わせられなかった分は量子化された欠陥として凍る（キブル＝ズレック機構）。「一度だけ全員で合わせ、あとは局所で保ち、合わせ損ねを欠陥として持つ」。

## 2. 0 + 0 + 0 = 0：閉塞の階層

**事実：** 各クラスター S が自分の重心 c_S のまわりで両閉塞を満たすとする（Σ_{n∈S}(zₙ − c_S) = 0、Σ_{n∈S}(zₙ − c_S)² = 0）。このとき

- Σ_all z = Σ_S |S| c_S
- Σ_all z² = Σ_S [ |S| c_S² + 2c_S Σ_S (z − c_S) + Σ_S (z − c_S)² ] = Σ_S |S| c_S²

で交差項は正確に消える。両閉塞は、重心たちが要素数 |S| を重みとして次の段で閉じる、という条件として自己相似に積み上がる。どの段でも足すのは枝の数だけ、全体で O(N)、深さは log N。0 + 0 + 0 = 0 が成り立つ条件は原点の共有で、原点が別（R3）なら上の段の閉塞になる。重心が次の段では「要素数を重みに持つ一点」として現れ、中の自由度は見えなくなる（R8）。

**事実（多重極）：** 平面上の点群の遠方展開 Σ_k log(z − z_k) = N log z − Σ_{p≥1} (1/p)(Σ_k z_k^p) z^{−p} で、係数は冪和 Σz_k^p。Σz = 0 は双極子が無いこと、Σz² = 0 は四重極が無いこと。両閉塞を満たしたクラスターは、遠くからは要素数（単極子）だけの一点に見え、最初に漏れるのは Σz³（八重極）。最小単位の正三角形 c·(1, ω, ω²) では Σz³ = 3c³。高速多重極法が O(N) で済むのと同じ理由。

**予言（読み）：** (1) 物質は局所に閉じたクラスターの階層になり、最小単位は両閉塞では N = 3、二乗閉塞だけなら 2 波。(2) クラスター間の相互作用は、重みつきの重心の閉塞と、三次以上の冪和（漏れ）だけを通る。(3) 局所の重力歪みは、閉じ損ねの残差 ε が上の段で釣り合わされる形で現れる：(0 + ε) + (0 − ε) + 0 = 0。ε の対をつなぐものが場。

**保留：** 重心の段の重み |S| が質量と読めるかは、R9 の三層（内部の値・換算比・非線形読み出し）を通してから。

## 3. 見えないものは相互作用せず、無限遠の吸収体になる

**定理（一行）：** 生成子は反対称 K_ef = −K_fe。e と f が読み出しで区別できないなら、入れ替えても何も変わらないので K_ef = K_fe。両方から K_ef = 0。無名性と反対称の帰結であり、仮定ではない。

**吸収体：** 全次数で閉じた一様な背景（Σz^p = 0 がすべての p、蔵本で言えば r = 0 の非干渉状態）は多重極を一つも持たず外から見えない。そこに局所の閉じ損ね ε を投げ込むと、無限個の区別できない要素に ε/N → 0 ずつ配られ、背景の読める量は何一つ変わらないが ε は消える。前節の −ε は、見える相手と対にするか（近接場）、無限遠の吸収体に捨てるか（放射）の二通り。

**既知の対応：** 電磁気ではホイーラー＝ファインマンの吸収体理論（無限遠の完全吸収体を置くと、時間対称な力学から遅延波と放射減衰が出る）。位相振動子では、非干渉状態が摂動を可逆な力学のまま不可逆に飲み込むランダウ減衰（ストロガッツ＝ミロロ 1991）。

**予言の正確な形：** 見えないものとの相互作用は、力としては現れず、減衰（時間の向き）として現れる。

**R7 への効き方：** 時間の向きの隠れた外部パラメータ（Δτ の符号、μ = −σ_max）は、吸収体理論では力学の中にはなく無限遠の吸収体の境界条件にあった（ホガース、ホイル＝ナーリカーの膨張宇宙の吸収体）。ランダウ減衰でも向きは規則にはなく、背景が最初に区別できない状態だったという初期条件にある。R7 の点検項目は「規則から外す」のではなく「吸収体の初期状態として宣言する」。

**読み出し側の無限遠：** 赤道 q₀ = 0。R2 の分母（相手の時計）が 0 なので、どの観測者からも無限に遠く無限に遅い。地平線の無限赤方偏移面と同じ形。吸収体が返すものがあるとすれば、区別できないもの（熱的なもの）のまま。

## 4. 見えないとは、視野角が分解能以下であること

**原語の訂正：** 系に距離はなく、読める幾何量は視野角だけ（§2.3）。「遠い」は u = tan θ という読み出しの派生量。見えないとは「視野角が、観測者自身の分解能より細かい」こと。分解能は外から置くものではなく、観測者自身の有限位数（A2 自己無撞着）：位数 m の観測者は自分の位相の刻み 2π/m より細かい角を読めない。

**帰結：**
- 見えるかどうかは観測者ごとに違う（分解能の階層）。「見えない」は「存在しない」ではない。
- 多重極の切り捨てはこれで決まる。クラスターの内部の角が δ より細かければ見えるのは単極子だけ。p 次の冪和が見えるかは、内部の角の p 乗が δ を超えるかで決まる。これは重力多体計算のバーンズ＝ハットの開き角の判定そのもの（視野角 < θ なら一点として扱う）。各要素が見分けるのは有限個の塊だけ（N でなく log N 程度）。
- 吸収体は「細かすぎるもの」の集まりで、方向はある。赤道 q₀ = 0 は原語では「θ の分解能を超えて互いに見分けられない殻」で、方向 n は残る。純虚単位四元数の球面 S² は深さのない方向だけの空、すなわち天球（相対論の天球は null 方向の空間、CG なら視差ゼロの環境マップ）。

**確かめるべき帰結（仮定を明示）：** 分解能 δ の観測者にとって θ ≥ π/2 − δ はすべて赤道と区別できず、像で言えば |u| ≥ cot δ の外側は全部が一つの殻。R6 のとおり観測者の刻みが位数 8 の一歩 π/4 だとすると cot(π/4) = 1 で、見える像の半径はちょうど光円錐の像 |u| = 1。光円錐の外（cos 2θ < 0、空間的）はまるごと分解能の外、つまり吸収体になる。§3 の K = 0 と合わせると、空間的に離れたものとは相互作用しない、という因果律の形が、分解能と中心投影から出る。2.3 で位数 8 の一歩だけが全面で null に乗る事実と整合する。数の一致ではなく、δ = 一歩という仮定を置いたときの計算結果なので、仮定ごと検証に出す。

**類比（主張しない）：** 粗い観測者ほど吸収体が大きく、見える領域は狭い。地平線とそこから返る区別できないもの（熱）が観測者の状態で決まる形は、ウンルー効果の構造と同じ。

## 5. 平坦は近似ではなく、読める関係の厳密解

**第一段（等価原理）：** 局所クラスターの原点をその重心に取ると（R3）、周囲から受ける一次の場（双極子）が消える。これが自由落下系で、Σz = 0 を局所で満たす原点を選ぶことが等価原理の内容。Σz² = 0 が局所で成り立てば潮汐項（四重極）まで消え、最初の破れは三次（Σz³）。一般相対論の局所平坦は一次まで（リーマン正規座標で二階にリーマンテンソル）だが、二次まで閉じた系では二次まで厳密に平坦。

**第二段（殻定理）：** 分解能の外に落ちた全部（吸収体）が一様な殻なら、内側の場はちょうど 0（ニュートンの殻定理、相対論ではバーコフ）。殻が有限の N 個でも 1 の N 乗根のように閉じていれば Σz^p は p = N まで 0 で、最初に残る N 次の寄与は視野角の N 乗に比例し、指数的に小さい。「極めて高精度」の定量的な中身。残る場は、見分けられる少数の塊（log N 個）が低次の冪和で作る分だけで、それが観測される重力（軌道・潮汐）。計算量の問題と精度の問題は、「閉じたものは外から見えない」の二つの顔。

**第三段（欠陥）：** ロックした格子の内部は曲率一定で、ずれは稜線の欠陥（欠損角）に量子化されて乗る。レッジ計算で各ブロックの中が完全に平坦なのと同じ。局所の物理（R8 の内側、クーロンの単純さ、標準理論の精度）が異常なほど正確なのは、欠陥に当たるまで一つも歪みがないから。重力は欠陥の密度を粗く見たときに連続に見える量。

**言葉の訂正：** 理論物理は「本当は曲がっているが局所では平坦で近似できる」と言うが、背景を置かない系では、二次まで閉じている局所に二次の歪みは存在しない。R4 で言えば、どの観測者の分解能でも読めない二次の曲率は、まだ読み出しとして定義されていない値であり、「あるが小さい」とは言えない。潮汐は分解能の内側の見分けられる塊（月）の単極子が作る相互作用で、殻の寄与ではない。幾何は平坦のまま、見える相手との相互作用として読む（重力を平坦な背景の上の場として書くテレパラレル重力・スピン 2 の場の理論と同じ内容で、一般相対論と観測上等価）。本当に幾何が平坦でなくなるのは欠陥の上だけ。

**観測との対応：** 局所の慣性系とは「分解能の外の殻が等方に見える系」（マッハの原理の内容）。その殻が実際に見えているのが宇宙背景放射で、背景放射の静止系が殻の重心系、観測される双極子は重心系から動いている分だけ一次の項が戻ったもの。予言：空に双極子の無い系が局所の自由落下系であり、双極子の大きさは殻に対する速度を測る（既に測られていて矛盾しない）。弱い等価原理の実験は 10⁻¹⁵ の桁まで破れを見つけていない（MICROSCOPE）。

**照合先（型として）：** 殻が二次まで閉じているなら、重心系で見た空の多重極は ℓ = 1 が系の選択で消え、ℓ = 2 が閉塞で抑えられ、ℓ = 3 から残る型になるはず。背景放射の四重極が理論の期待より小さいこと（低四重極問題）は知られている。数の一致ではなく「ℓ = 2 だけが抑えられ ℓ = 3 は抑えられない」という次数の型として突き合わせる。

## 6. 不確定性は読み出しの核：位相を捨てる演算

**事実：** 自分 e から相手 f への関係を w = q̄ₑ q_f（複素なら z̄ₑ z_f）と書くと、スカラー部は |自分||相手| cos θ、ベクトル部は |自分| ×（相手の、視線に垂直な成分）で、大きさは |自分||相手| sin θ（三角形の面積の 2 倍）。生成子 K_ef = A Im(z̄ₑ z_f) はベクトル部だけで駆動される。捨てているのはスカラー部、すなわち視線方向の奥行き。「位相を捨てる演算」とは関係のベクトル部を取ることで、その核が視線方向。

**事実（読み出し）：** u = ベクトル部／スカラー部 = n tan θ（論文 §5 の中心投影）。R2 の「最後に一度、分母を宣言して割る」の分母は、捨てたスカラー部そのもの。逃げるのは |自分||相手| のスケールと cos θ の符号（相手が前か後ろか）。前後の区別不能が A1′ の z と −z、R7 の隠れた選択にあたる。四元数では捨てるスカラー部が 1、読むベクトル部が 3。1＋3 の分かれ方は観測者自身の視線が決める。相手の時計 q₀ とは私の視線に沿った相手の奥行きであり、u = 空間／時間 = x/t、光円錐 |u| = 1 は |x| = t。**時間とは、捨てた方向のこと。**

**相補性：** 捨てる成分と読む成分は 90° 回転（Z₄ の i）で入れ替わる。視線を位相で 90° 回した観測者は、私が捨てた成分をそのまま読み、私が読んだ成分を捨てる。一本の視線には一つの核しかなく、二つの核を同時に空にはできない。Re² + Im² = |自分|²|相手|² が一定で、二つの成分が一つの総量を分け合う。相補性は「関係のうち読めるのはベクトル部だけ」という一つの事実から出る。

**ゼロになる場所は二つ：** (a) 相手がちょうど視線上（同位相か逆位相）で面積 0、相互作用も消える（§3 の式での姿）。(b) 閉塞 Σz = 0 のもとで Σ_{f≠e} Im(z̄ₑ z_f) = Im(z̄ₑ · (−zₑ)) = 0。全員対全員の総和は自分に対して恒等的にゼロ（閉じた全体は相対平衡）。作用するのは閉塞からのずれ ε だけ。

**重力の不確定性（読み）：** 不確定性とは部分投射で逃げた成分が読み出し側では分解能以下の区別不能として現れるもので、その胞（セル）の大きさが側によって桁違い。2.6 のとおりセルが結合に反比例するなら、内部側（電磁気）のセルは小さく離散や干渉として量子的に見え、重力側のセルは最弱の結合に反比例して巨大で、内側に読める構造が無い。重力は平坦で古典的で決定論的に見え、量子的な見え方は観測上存在しない。既知の相手：ボース凝縮体の治癒長 ξ は結合と密度の積の平方根に反比例し、ξ より細かい尺度では凝縮体は一様で硬く、位相の不確定性は全体で分かち合われ、量子性は渦や磁束の量子化のような位相的な量にだけ現れる（芯の大きさ ξ）。系の内側からも、四元数の段で読み出しから逃げる成分は閉塞を保つ対称性（全体の 3 次元回転とスケール）で、定義上クラスター全体の量なので、その不確定性は最初からマクロ。重力波は完全に古典的で可干渉な波として検出されており、集団変数の励起として整合。プランク尺度の重力の離散性はこの読みでは出ない。ディオシ＝ペンローズとは向きが逆だが、境目がプランク尺度でなくマクロにある点は同じ側。セルの尺度は 2.6 の換算比の導出待ちで、導出前にどの尺度に探すかを言わない。

## 7. パワーの分配：放射する関係は 45°、閉じた配置は放射しない

**事実：** 二乗量（パワー）の流れは二乗凝縮 §8.2 の反対称二乗流で、

J_ef = 2 K_ef Re(z̄ₑ z_f) = A |zₑ|² |z_f|² sin 2Δφ = (A/2) Im((z̄ₑ z_f)²)

自分のパワーと相手のパワーの積に相対位相の 2 倍の正弦が掛かる。読んだベクトル部（面積）と捨てたスカラー部（奥行き）の積が二乗の層の符号付き面積になり、放出と吸収の量を決める（A1′：エネルギーの流れは二乗の層で読まれる）。J_fe = −J_ef で、総和は保存する。

**帰結 1（45°）：** sin 2Δφ は Δφ = 0°、90°、180° で 0、45° で最大。同位相・直交・逆位相の相手とはパワーのやり取りがなく、最大になるのは光円錐の角 45° の関係。電磁気で縦成分が放射せずクーロンの近接場に残り横成分だけが放射する（双極子の sin² の指向性）のと同じ分かれ方。クーロンは捨てた奥行き、電磁波は読んだ面積。

**帰結 2（厳密ゼロ）：** 視野角が刻み δ より細かければ Δφ は 0 と読まれ J = 0。放射も吸収も起きない。遠い相手との交換が僅かなのは距離のせいではなく読める角が無いからで、下限の下では連続に漏れずに切れる。線スペクトルが鋭いのはこの切れ方。

**定理（閉じた配置は放射しない）：** 自分 e が全員から受け取る正味のパワーは

Σ_{f≠e} J_ef = (A/2) Im(z̄ₑ² Σ_{f≠e} z_f²) = (A/2) Im(z̄ₑ² · (−zₑ²)) = −(A/2) Im(|zₑ|⁴) = 0

で、二乗の閉塞 Σz² = 0 のもとで恒等的に消える。線形閉塞が「正味の力がゼロ」（相対平衡）を、二乗閉塞が「正味のパワー流がゼロ」を与える。二つの閉塞は定常状態の二つの条件そのもの。束縛状態が放射しないという古典論の破綻が閉塞から出る。放射が起きるのは閉塞が破れたときだけで、流れるのは ε に比例した量、通る経路は 45° の関係、読める量は刻み δ で量子化される。閉じた状態どうしの間を量子化された交換が結ぶのが離散化されたエネルギー階層で、階層の値を決めるのは閉じた状態の位数（マジックナンバー）。

## 8. 二層二部の表

関係 w = q̄ₑ q_f を、層（w とその本当の二乗 w²、A1′ の二層）と部（スカラー部とベクトル部）で分ける。

| | スカラー部（視線方向・奥行き・放射しない） | ベクトル部（横・面積・運ぶ） |
|---|---|---|
| 第一層 w | \|zₑ\|\|z_f\| cos Δφ — **クーロン力**（近接場） | \|zₑ\|\|z_f\| sin Δφ — 生成子 K — **電磁波** |
| 第二層 w² | \|zₑ\|²\|z_f\|² cos 2Δφ — 四元数では \|d₁\|²\|d₂\|²(q₀² − \|v\|²)、論文 §6 の (1, 3) の形 — **重力の静的な部分＝計量** | \|zₑ\|²\|z_f\|² sin 2Δφ — パワーの流れ J — **重力波** |

「重力は幾何」は、この表では「二乗の層の静的な部分がミンコフスキーの形になる」の一行。

**違い（型として既知の事実と合う）：**
- 第一層は z の符号（位相の ±）を持つので電荷に正負があり、双極子 Σz が振れれば放射する（双極子公式）。第二層の |z|² は正しかないので重力に斥力はなく、質量の双極子は重心系で消え、放射は四重極 Σz² から始まる（四重極公式、双極子の重力波が無いこと）。
- 角が 2Δφ に倍化することは、電磁波の偏光が 90° で直交し、重力波の ＋ と × が 45° で直交する、スピン 1 とスピン 2 の違い。
- どちらの層でも閉じた配置は正味の交換がゼロで放射せず、放射するのは閉塞が破れた分だけ。
- 桁が違う理由はどちらの側（R8）に属するか：第一層は内部側でセルが細かく強く結合し離散が見える、第二層は漏れた側でセルが巨大で局所では平坦に見える。両者をつなぐ比が 2.6 の内と外の換算比で、ここだけが未導出。

## 10. 確かめる計算（追加の仮定なし）

## 11. 検討ルールへの追加候補

- **R10（平坦）：** 平坦は近似ではなく、局所閉塞が成り立つ次数までの読み出しの厳密解である。曲率として読めるものは、分解能の内側の塊との相互作用か、閉塞の破れ（欠陥）の上にしか無い。背景の曲率を先に置かない。
