## 1. 中心テーゼ

**CP対称性の破れは、持ち込むべき相互作用ではなく、離散性の必然である。**

二段で構成される。

**第一段（反粒子の定義）**: 電荷の符号は 4次元体積要素 dx∧dy∧dz∧dt の**配向**である。反粒子とは t 配向が裏返った同一構造にほかならない。Feynman–Stückelberg 解釈（反粒子＝時間逆行する粒子）は計算上のトリックではなく、離散構造の配向反転として幾何学的に実体化される。

**第二段（破れの発生）**: 連続理論であれば t→−t は厳密な鏡映であり、粒子と反粒子は完全に合同、対消滅は完全である。しかし**離散構造のパッキングには埋め戻しの端数（fractional correction）が必ず残り、この端数の高次項は配向反転に対して厳密には対称になれない**。ゆえに:

- 主要次数: 対消滅はほぼ完全（粒子・反粒子はほぼ厳密な鏡映）
- 高次の端数項: t 周回と −t 周回でわずかに異なる → **対消滅が完全には閉じない** → 残留

## 2. なぜ小林・益川より単純か

| | 小林・益川機構 | 本機構（離散端数の配向奇性） |
|---|---|---|
| 前提1 | 世代数 ≥ 3 | 不要 |
| 前提2 | 世代間混合（ユニタリ行列） | 不要 |
| 前提3 | **非縮退の質量階層**（Jarlskog 不変量は質量差の積に比例——質量が縮退すれば CP 破れは観測不能） | **不要** |
| 破れの起源 | 3×3 ユニタリ幾何の消去不能位相（値は入力） | 離散パッキング端数の配向奇性（構造から従う） |
| 破れの大きさ | 入力（CKM位相の実測値） | 高次端数——小ささが構造的に出る |

決定的な差は前提3である。KM 機構は質量階層が先に存在しないと破れを表に出せないが、本機構は**質量階層の導出を必要としない**。閉鎖完走が離散端数を持つこと（＝離散であること）だけが要件であり、依存関係の鎖が一段で済む。

標準理論との関係は「同じ結果の別写像」の型に従う: KM 位相は、この配向奇端数を連続有効理論の側で帳簿づけしたときの現れ（影）と読む。標準理論の予言精度は一切損なわない——破れの「値」の導出を主張しない限り矛盾は生じない。

## 3. 整合性要件（この機構が自動的に満たすべきもの）

前段の議論（2026-08-04 対話）で確定した拘束条件と、本機構の適合:

- **R1: QED セクター無傷**——自由光子は配向の端数を持たない（毛なし・完全共有・固有時計なし＝t 配向の周回を持たない）。よって電磁過程に CP 破れは現れない。実測（QED の C・P・T 厳密対称）と整合。
- **R2: 破れの場所は粒子・反粒子の反応系のみ**——端数の差が効くのは対消滅・対生成・混合、すなわち ± 配向の突合せが起こる反応に限られる。K⁰/B⁰ 系でのみ破れが観測される現象論と同型。
- **R3: 微小性**——破れは主要次数でなく高次端数。観測される CP 破れの小ささと整合する構造。
- **R4: CPT は厳密に保存**——C＝Q軸反転、P＝xyz反転、T＝t反転の全反転（R不変）のもとでは端数項も込みで合同に戻ること。端数項は T 単独（および C 単独）で奇、CPT 全体で偶でなければならない。**これは定式化時の検証項目**（自動には仮定しない）。
- **R5: 強いCP問題と衝突しないこと**——中性子電気双極子能率の実測上限（θ_QCD < 10⁻¹⁰ 相当）は、静的な束縛状態に大きな CP 奇項が現れることを禁じる。本機構の破れが「反応（対消滅収支）」に限局し「静的構造」に漏れない理由を定式化で示す必要がある。**未解決の検証項目**。

## 6. η（バリオン・光子比）との関係——正直に書くべき緊張

第9論文は η ≈ 6×10⁻¹⁰ を「閉鎖完走できる整数比対の割合 f(N)」の読み値として扱った。本機構が立つと、η の説明は二因子に分解されうる:

    η ～ （閉鎖完走の発生率） × （不完全対消滅の残留率 ε_CP）

この場合、f(N)=η と直接置いた第9論文の N ≈ 8×10¹⁰ という読み値は**再解釈が必要になる**（読み値であって導出ではないと明記してあるため矛盾ではないが、二因子分解が確定したら第9論文の該当節の但し書きを更新すべきである）。標準宇宙論でも η は「対消滅の焼け残り」であり、本機構の読みのほうが標準側の描像に近い。

## 7. 検証課題（定式化の順序）

- **T1（配向奇性の定式化）**: レジスタ算術の中で、周回方向反転（m/n → −m/n、毛全反転と併用）に対する端数項（π/310 スリップ等）の変換性を厳密に計算する。判定: 端数が T 単独で奇・CPT で偶なら本機構は成立候補、偶／偶なら**反証**（破れはここに住めない）。
- **T2（残留率の見積り）**: T1 成立の場合のみ。± 周回の対消滅不完全率 ε_CP をレジスタ端数から見積り、K/B 中間子系の実測 CP 破れの階層（10⁻³ 前後）および η の二因子分解と桁で照合する。桁が大きく外れれば反証。
- **T3（R5 の検査）**: 静的束縛状態に端数の CP 奇項が漏れないこと（EDM 上限との整合）の構造的理由を示す。
- **T4（第9論文との接合）**: T2 まで通った場合、§6 の二因子分解で η の読みを再構成する。
