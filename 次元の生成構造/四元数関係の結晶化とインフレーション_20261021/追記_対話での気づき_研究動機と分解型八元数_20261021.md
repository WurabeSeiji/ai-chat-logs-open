## 1. 研究動機（著者の記述を整理）

### 1.1 出発点の問い

一般相対性理論と標準理論はうまく統合できないのに、局所的に平坦な近似を行うと極めて高い精度で成立する。なぜか。多くの任意パラメータを置かずに、これを説明できる方法はないか。

### 1.2 中心投影から光円錐へ（2026 年 4 月〜）

CG プログラマ・3D モデラとしての経験を生かし、中心投影（グノモン射影）という非線型写像を詳しく調べた。Σxₙ² = R² という写像で、中心投影の曲率半径 R が光円錐と接続される可能性に気づいた。そこから、Σxₙ² = 0 というゼロ閉塞と、波長 λ と振動数 ν の共役性から、どこまで理論物理学に接続できるかを研究した。

### 1.3 実数ではなく複素数を追いかけていた

その過程で、実は実数ではなく複素数を追いかけていたのではないかと気づき、清水明『新版 量子論の基礎』を学び直した。理論物理学の基礎が、複素ヒルベルト空間とその写像演算で組み立てられていることを知った。

### 1.4 三つの疑問

1. 極めて美しく構築された複素ヒルベルト空間を、我々の四次元時空としてどう読み出せばよいのかが明確に説明されておらず、背景の四次元時空が最初から仮定として置かれている。
2. 純粋な複素数は指数表現するとそのまま波として読めるが、そのままでは進行波は表現できず、暗黙に ωt という位相が持ち込まれている。
3. 自由度が実部と虚部の二つしかない、ただの複素波のどこに、その情報を保存する能力があるのか。これが基本的な疑問となった。

### 1.5 Σzₙ² = 0 と時空の式

中心投影と Σxₙ² = 0 の研究で、xₙ は実数では自明解しかなく、複素数 zₙ である必要があり、Σzₙ² = 0 であると気づいた。同時に、λν の研究と光円錐の研究から、時空は x² + y² + z² − t² = R² + Q² と表現でき、t を it と置けば x² + y² + z² + t² = R² + Q² であること、ローレンツ変換やウィック回転が実は t の読み出し問題であることに気づいた。これを進めて、現在は x² + y² + z² + t² = R² + Q₁² + Q₂² + Q₃² である可能性が高いと考えている。

### 1.6 無名性

ここまでの仮定で、無名性が極めて重要であることに気づいた。Σzₙ² = 0 において zₙ は無名で、x, y, z, t, R, Q₁, Q₂, Q₃ というラベルも、読み出し時にそのように読める量に後から付けた名前である。理論体系には無名性が重要である。

### 1.7 構造がないという行き詰まりと、二つの試行

複素数の集合 {zₙ}、つまり複素空間そのものには構造がなく、自律的に四次元時空が読み出せる構造が生み出せない。

- **複素シンプレックス：** 複素数を完全ネットワークと考え、シンプレックス対称性を使えば必然的に構造が生まれると考えた。頂点数 N に対して関係は M = N(N−1)/2 個で、M 個の複素数で構造が読み出せる可能性を検討した。しかし、M 個の関係（どの頂点とどの頂点か）を外から与える必要があり、無名性に違反するので行き詰まった。
- **M² の自己相互作用：** M 個の波が自己相互作用も含めて M² の作用を起こすと考え、極めて対称性の高い複素数の集合でこの自己相互作用を繰り返すと、インフレーション的な幾何級数発展が起こることを発見した。しかし、この過程で四次元時空を読み出すことはできなかった。

### 1.8 四元数へ

複素数 2 つを組み合わせると四元数、4 つで八元数が作れる（実数から数えて 1 → 2 → 4 → 8）。複素数はもともと 2 次元ベクトルにすぎず、実部・虚部という名前も後から付けたもので、無名性に違反しそうで違反していなかった。同様に、四元数は 4 次元ベクトル、八元数は 8 次元ベクトルにすぎず、構造はあるが無名性には違反しない。なぜ物理が八元数を選ぶのかは現時点ではわからない（E8 などの対称性から導出できる可能性はあるが、いまは公理として置く）。

### 1.9 本稿の主題

四元数を使うと何が解決できるか。無名性を守り、外から関係を与えなくても、自律的に構造が生まれる仕組みを解明できないか。手がかりは物性物理の結晶構造である。過冷却した対称性の高い構造にわずかなシードを与えると、幾何級数的に結晶またはガラスが構成される。これがイメージしている構造に類似している。

## 3. 冒頭の問いへの答え：局所平坦は近似ではなく、読み出しの性質

- 局在する観測者の読み出しは、観測者自身（u = +1）を原点とする立体射影（結合の地図 k）である。立体射影は角度を保つ（共形）。
- したがって、一様な曲率、全体の尺度、地図の選択（k と x = 1/k）、左右の枠の選択は、視野角だけで測る観測者には区別できない。
- 観測にかかるのは方向に依存する歪み（潮汐）だけで、トラスの継ぎ目の不足角として現れる。
- これは 2026-10-19 に固定した予言「見えない（区別できない）ものは相互作用しない」と同じ向きで、局所重力場の平坦近似が極めて高精度に成立する理由を、読み出しの構造そのものに帰着させる。

## 4. 時空の式は分解型八元数のヌル条件であり、等振幅の四元数の組と同値である（図 9）

### 4.1 対応

- a = t + x i + y j + z k（時空側）、b = R + Q₁ i + Q₂ j + Q₃ k（内部側）の二つの四元数をとる。
- ケーリー＝ディクソン構成 o = (a, b)、積 (a, b)(c, d) = (ac + γ d̄ b, da + b c̄)、共役 (a, b)* = (ā, −b) とすると、ノルムは N(o) = |a|² − γ|b|²。γ = −1 で通常の八元数、γ = +1 で分解型八元数（符号 (4,4)）。
- 分解型（γ = +1）では、
  x² + y² + z² + t² − (R² + Q₁² + Q₂² + Q₃²) = 0 ⇔ N(o) = 0 ⇔ |a| = |b|
  であり、a ≠ 0 なら相対位相 u = a⁻¹b は単位四元数（S³ 上の点）になる。

**宣言（R2・R3・R4・R7）：** 二乗の和の原点は a, b 共通の原点 O。割り算は最後に一度、分母は時空側 a（左除算）。a⁻¹b と b a⁻¹ のどちらで読むか、どちらを a に置くかは外から入る選択で、四元数の段での左右の選択と同じものである。

### 4.2 気づき

1. **時空の式 ＝ 等振幅の四元数の組：** 本稿で扱う「等振幅の二つの四元数の相対位相から関係を読み出す」構図は、時空の式（八次元のヌル条件）そのものである。
2. **ヌルからのずれ ＝ 振幅の不整合：** |a| ≠ |b| のとき、結合係数 k にスカラー部（振幅の不整合）が現れる。これが重力歪みの候補である。
3. **ゼロ閉塞が分解型を要求する：** 通常の（コンパクトな）八元数のノルムは正定値で、非自明なヌルを持たない。非自明解の存在を要求すると分解型が選ばれる。これは、Σxₙ² = 0 が実数では自明解しか持たず複素数を要求したこと（段①）と同じ論理である。
4. **既存の立場との整合：** 2026-10-19 の立場「(t, xyz) は四元数で読めるが、観測できない側 (R, Q₁Q₂Q₃) まで読むには八元数（四元数 2 つ）が必要」と一致する。内部側 b は、時空側からは相対位相 u とノルム比を通じてしか現れない。

### 4.3 未解決

- なぜ分解型の符号 (4,4) の分け方が「時空側 4 ／内部側 4」なのか（ウィック回転 t → it との関係）。
- 八元数の非結合性が、関係の連鎖（三角形の閉合）にどう現れるか。

- 「曲率は局所観測者に観測されない」→ 一様な部分だけ。潮汐は見える。

## 6. 先行研究（分野横断、書誌は本文執筆時に原典で確認）

- **Quantum Graphity：** Konopka, Markopoulou, Smolin（hep-th/0611197）、Konopka, Markopoulou, Severini（arXiv:0801.0861）。完全グラフ・置換不変・冷却による幾何の発生（geometrogenesis）。頂点にラベルがあり、外部熱浴が必要という問題が指摘されている。
- **Selection-Stitch Model：** R. Kulkarni（2026、Zenodo ほか）。四面体フォームのフラストレーション、幾何学的インフレーション、結晶化の潜熱による再加熱、物質を不完全な結晶化とみなす。ネットワークを前提にしている。
- **幾何学的フラストレーションと曲がった空間の雛形：** Frank（1952）、Sadoc & Mosseri『Geometrical Frustration』（1999）、Mosseri & Sadoc, C. R. Physique 15 (2014) 90–99、Nelson『Defects and Geometry in Condensed Matter Physics』（2002）。
- **拘束理論・ジャミング：** Phillips（1979）、Thorpe（1983）、Liu & Nagel（1998）。
- **核生成と結晶成長：** Avrami（JMAK）、古典的核生成理論。
- **宇宙論と凝縮系の橋：** Kibble（1976）、Zurek（1985）。
- **剛性理論：** Maxwell、Calladine（1978）、Henneberg、Laman。
- **計算幾何：** Edelsbrunner（ドロネー分割、正則分割、フリップ）。
- **準結晶・切断投影：** Elser & Sloane（1987）。
- **比較対象（接続を外から与える側）：** Regge 計算、Ponzano–Regge、因果的動的三角分割。

**新規性の主張候補：** ① 四元数の相対位相から観測者中心の立体射影として結合と距離を読む ② 接続を名前のない点集合の凸包から読む（無名性） ③ 非一意性を部分投射＝不確定性として原理に置く ④ 熱浴もハミルトニアンもなく、面の倍率で幾何級数的成長と e-fold 数が決まる ⑤ 状態空間そのものが S³ で、曲がった空間が道具ではなく出発点である。
