## 1. 問題の正体

論文はシードから四面体が面を共有して育つと書いたが、その**相互作用の機構はまだ何もない**。取り組んでいるのは次の問題である。

- 八元数の要素 N 個（等方性まで課すなら N ≥ 8）が、背景時空・外部時計・ハミルトニアン・熱浴なしに、自分と自分以外の全てとだけ、左右の積（八元数では括弧の順序も）だけで作用し合う。
- 作用が生む演算子の固有モードに、配置自身がなる（自己無撞着）。Σx² ＝ 0 は条件でなく結果。
- 同じ規則のまま、高対称の過冷却状態からの幾何級数的な成長、面が閉じることによる停止、その後の局所平坦で安定な構造、振幅の分化（質量）、動的なロックの全部が出る。インフレーションの頃だけ都合のよい規則は置けない。
- 刻みは外から置かず、系の時計で決める。

「A 体と B 体が十分に近いか」は 2 体では決まらない。原点は Σq ＝ 0 の重心で全員が決め、k の向きは観測者の枠で決まる。2 体で Σq ＝ 0 を満たすと必ず逆位相（接触）で k が発散し、関係が読めない。十分に近いかの判定は、N 体の自己無撞着な状態の性質（ロックが起こるか）であり、ロックは集団現象である。

この問題に前例も一般解法もない。標準の多体問題は背景とハミルトニアンの上にあり、群場理論は四面体を使うがポテンシャルを置き、蔵本型のロックは外部の固有振動数と固定した結合を前提にする。非結合代数の力学系は文献が存在しない（2026-10-21 検索）。

## 2. 解ける理由：対称性の拘束は、作用ではなく結果を縛る

- 無名性のもとで作れる作用は関係だけから組む。要素の置換、全体への左右からの単位の掛け算、実数倍に対して、作用は同変である。作用の中身をどう選んでもこれは外せない。
- したがって**結果は作用より先に決まる**。対称な配置は同変な写像で対称な配置にしか写らない。高対称な状態は多くの作用で固定点（相対平衡）になる（10/20 の C1 で全配置が相対平衡になったのは対称性の帰結）。発展が起こる唯一の道は、その固定点の不安定性（増幅 ⟺ 不安定な相対平衡）。作用が決めるのは、どの固定点がどの方向に不安定か、だけ。
- 到達できる結果は、閉塞を満たす配置を対称群で割った軌道空間の点に限られ、その空間は小さい。終端の形の候補は等方部分群の大きい軌道に絞られる。
- 論文の主張（倍率 r ≤ 3、欠損角、辺あたり四面体の平均 5.104）も、作用でなく幾何が決めている。インフラトン不要の主張はこの型に乗っている。
- **方法が反転する。** 作用を設計して結果を計算するのではなく、取りうる結果の目録（閉塞を満たす対称な配置、等方部分群、相対平衡の型）を先に作り、どの作用がどれを選ぶかを問う。目録は有限で、一般解法のない多体問題が有限の探索になる。
- これは物性物理では Landau 理論（Alexander–McTague）、数学では等変分岐補題、現代物理では共形ブートストラップとして確立している（ノート 1 §2、ノート 2 §2.2）。「対称性の一覧」（10/17）はこの目録そのもの。

## 3. 最小の系（10/20 の解析の復元）

| 要素の数 | 生成できる代数 | 閉塞 | 意味 |
|---|---|---|---|
| 1 | ℂ（自分の平面） | 閉塞できない | 自己干渉は複素数の時計 |
| 2 | 最大 ℍ（二元は必ず結合的） | Σo² ＝ 0 の解は o₂ ＝ ±n o₁ | 必ず一枚の複素平面の光子 |
| 3 | 閉じれば ℍ 止まり | 虚部は 2 方向以下 | 本物の四元数にはなるが八元数にならない |
| 4 | 𝕆 として閉じる最小 | 例 {√3, e₁, e₂, e₄}、Σo² ＝ 0 | 三つの虚部が非結合な三つ組 |

閉塞だけで決まる最小：ℂ は 2（Σo ＝ 0 も課すと 3）、ℍ は 3（4）、𝕆 は 4（5）。等方性の閉塞を状態の条件にすると 8×8 のグラム行列を張るのに N ≥ 8。空間として 7 方向を等方に開くには、前稿の min(3, N−2) の類推でさらに大きい。

**帰結：** 1 体・2 体では八元数の相互作用は書けない。最小の系（どの条件を課すか）を確定してから、その上で作用を網羅する。

## 4. 標準理論との類似：何を捨てるか

物性の方法は標準理論に似ている。水素原子は軌道を捨てて準位だけを見る。共通するのは「対称群が動かすものを捨て、不変量だけを残す」こと。

- 水素が捨てたもの：軌道（時間発展に沿った位相）。残ったのは固有値と、縮退に残る SO(4)。Fock（1935）は運動量空間を立体射影で S³ に写し、水素の準位が S³ の調和関数だと示した。水素が捨てていないもの：外部時計 t（固有値はそれに対する位相の速さ）。振幅は規格化で捨てる（一粒子だから）。
- Landau が捨てたもの：経路・速度論・揺らぎ・絶対値・原点。蔵本型が捨てたもの：振幅まるごと。時計と結合は外から。
- **こちらが捨ててよいもの：** 全体の振幅（スケール）、全体の位相と回転、絶対原点、外部時計（もともとない）、外部パラメータに沿った軌跡。
- **こちらが捨ててはいけないもの：** 振幅の**比**（質量、k のスカラー部）、相対位相（距離・電荷）、固有空間の**縮退**（柔らかいモード F ＝ 不確定性 ＝ 時間の住む場所）、モード間の速さの**比**（内部時計＝比だけのスペクトル）。
- 剛性の数え方 F − S がそのまま対応する。固有モードの目録は S（拘束、何が固まるか）を決め、捨てた側の F（縮退の中の自由度）に時間が住む。
- 水素との本当の違い：水素は準位間の遷移を外部の場で起こす。こちらには外部の場がなく、縮退した多様体の中の移動（組み替え、フリップ）を系が自分で起こさなければならない。インフレーションの問いはここ。目録を作る段までは水素と同じ道、遷移を自前で出す段は水素の方法にない。

## 5. 物性物理と自律系から持ち帰ったこと（詳細はノート 1・2）

1. 多体相互作用は解かない。対称性 → 秩序変数 → 取りうる相の目録 → 係数が選ぶ。
2. 成長の様式は二つ。準安定＋シード（核生成、前線が進む）か、線形不安定（スピノーダル、至る所で指数的）か。出発状態が線形に安定か不安定かで決まる。10/20 の C1（全配置が相対平衡）と C2（準周期）はこの二分法で読み直せる。
3. 数が指数的に増えるのは、生成物が次の生成の場所を増やすとき（自己触媒・二次核生成・分岐過程）。論文 §10 の数え方はこの型。
4. 理想構造（600 胞体）はできない。平らに読むと欠陥線が必ず残り、その配置が実際の構造を決める（Coxeter の統計的ハニカム 5.104、Kléman–Sadoc、Nelson、球面上のコロイド：リボン、12 の海と大陸）。欠陥は成長の担い手でもある（BCF）。
5. ロックは「差／結合」の比で、秩序変数を通して自己無撞着に決まる。全員対全員の球面上の系は Möbius 群の次元に縮約される（Watanabe–Strogatz、Lohe、Lipton–Mirollo–Strogatz；S³ では四元数 Möbius）。論文の k は Möbius 群の元。
6. 自律的に組織化する系の機構は、どの分野でも「対称な状態の線形不安定性」（Jeans、HMF、大域結合写像）か「縮退のある成長」（因果集合、スピングラス）。動的なロック（引き込まれるが固定されない）はカオス的遍歴として前例がある。名前によらないことを公理に置いて背景なしに育つのは因果集合（離散的一般共変性）。
7. 誰も持っていないもの：振幅の力学 ＋ 内部時計 ＋ 背景なし ＋ 非結合性の同時成立。

## 6. 振幅は複素位相の実部：論文の k はすでにその形

振幅と位相を分けるのは誤りで、振幅も位相表現にすれば e^z になるだけ（木原指摘）。論文 §4.4 の式はすでにそうなっている。ρ ＝ e^{Δa} と置くと

k ＝ [(1 − ρ²) − 2 Im u] / |1 + u|² ＝ −(sinh Δa ＋ n sin α) / (cosh Δa ＋ cos α) ＝ **−tanh(w/2)、w ＝ log u ＝ Δa ＋ nα**

振幅の不一致は複素位相 w の実部、位相差は虚部で、k はその半分の tanh 一つ。Δa ＝ 0 で −n tan(α/2) に戻る。

## 7. 複素化蔵本模型が土台の族

**蔵本模型（1975）：** θ̇ᵢ ＝ ωᵢ ＋ (K/N) Σⱼ sin(θⱼ − θᵢ)。秩序変数 r e^{iψ} ＝ (1/N) Σ e^{iθⱼ} で平均場の一体問題に落ち、|ωᵢ − Ω| ≤ K r でロック、外はすり抜け。r が r を決める自己無撞着方程式で K_c ＝ 2/(π g(0))。

**複素化（Thümler–Srinivas–Schröder–Timme, PRL 130, 187201 (2023)）：** zᵢ ＝ θᵢ ＋ i yᵢ、e^{izᵢ} ＝ e^{iθᵢ} e^{−yᵢ}。同じ式のまま

θ̇ᵢ ＝ ωᵢ ＋ (K/N) Σⱼ sin(θⱼ − θᵢ) cosh(yⱼ − yᵢ)
ẏᵢ ＝ (K/N) Σⱼ cos(θⱼ − θᵢ) sinh(yⱼ − yᵢ)

- 振幅の方程式は何も足さずに出る。同位相に近い組は振幅をそろえ、逆位相に近い組は引き離す。
- Σᵢ ẏᵢ ＝ 0。全体の対数振幅は保存され、動くのは比だけ（こちらの「全体のスケールは見えない」と同じ）。
- 強結合ではロック状態がアトラクタ。**弱結合では実の K_c より下でも複素ロック状態として同期が残る**（振幅を位相に含めるとロックは起こりやすい）。二振動子で弱結合に保存量。続編 Lee ほか Chaos (2024)、arXiv:2502.20614 (2025)。

**Z ＝ e^{iz} で書き直すと**

Żᵢ ＝ Zᵢ · [ iω ＋ (K/2N) Σⱼ (uᵢⱼ − uᵢⱼ⁻¹) ]、　uᵢⱼ ＝ Zᵢ⁻¹Zⱼ

「自分に、自分以外の全てとの相対位相の関数を掛ける」という、合意した形そのもの。振動子が同一なら回転系で ω は消え、K は時間の単位に吸収され、**外部パラメータは時間の単位だけ**になる。その単位を系自身の速さで決めるのが内部時計。

**ばらばらの状態 Σ e^{iθ} ＝ 0 は、こちらの線形閉塞 Σq ＝ 0。** 蔵本の同期転移はその状態の線形不安定性。

## 8. 残る選択（まだ決めていないこと）

1. **相対位相の関数の形。** 蔵本は (u − u⁻¹)/2 ＝ sinh(log u)（第一調和、逆位相で有界・力 0）。論文の k は (1 − u)/(1 + u) ＝ −tanh(log u / 2)（逆位相で発散＝接触・全反射）。同じ族の別の元で、どちらが結晶化に要るかは選択。
2. **四元数・八元数での左右と括弧。** u を左除算か右除算か、関数を左から掛けるか右から掛けるか。四元数は Lohe の S³ 版が一つの選び方。八元数は前例がなく括弧の順序が加わる。
3. **内部時計。** K を時間単位に吸収したあと、その単位を系の速さ（モード間の比）でどう決めるか。
4. **振幅を変える作用は設計で決める。** 勝手に変わるものではない。変えない作用を設計すれば変わらず、変える作用なら変わる。結晶に要る要件（重なった同じ波が一つに潰れない）から選ぶ。
5. **最小の系。** どの条件（閉塞だけ、線形閉塞も、等方性も）を課すかで N ＝ 4／5／≥ 8。

## 9. 同一の A と B、等方性と異方性（訂正を含む）

- まったく同じ A と B は一つであり、何も起こらない。理由は k ＝ 0 ではなく、入れ替えの対称性をどんな同変な作用も壊せないこと。問いは、わずかな差が増えるか（スピノーダル型）、0 でない差のまわりで準振動するか（動的ロック）、消えるか、という固定点の安定性。
- 等方性は結晶の対称性からではなく無秩序（三角形分割の非一意性）から出る。硬い結晶（600 胞体）はできない（論文 §8：全投射は排除、§9.3：N ≫ 120 で S³ でも閉じない）。600 胞体は比較例。正二十面体型 ℓ ＝ 6 の異方性という予言は撤回。
- 論文の中から出る異方性：(a) 潮汐（視野の地図の等角からのずれ＝シア、源は振幅の不均一 δρ、等振幅なら 0）、(b) 欠陥線のまわりの欠損角（辺あたり 5 なら ＋7.36°、6 なら −63.2°、平坦に読むには平均 2π/arccos(1/3) ≈ 5.104 が必要、V4 で確認可能、線の向きは網目ごとにばらばら）、(c) 有限の網目の統計揺らぎ n^(−1/2)。大きさは δρ が相互作用からどう生まれるかで決まる。

## 13. Σz ＝ 0 と Σz² ＝ 0、調和成分（追記 2026-10-21）

- 蔵本のばらばらの状態 Σ e^{iθⱼ} ＝ 0 は、等振幅の線形閉塞 Σzₙ ＝ 0 そのもの。Σzₙ² ＝ 0 は Σ e^{2iθⱼ} ＝ 0、第二調和の秩序変数（Daido の r₂）が 0 という条件で、Σz ＝ 0 から自動的には出ない。
  - N ＝ 2：z₂ ＝ −z₁ で Σz ＝ 0 だが Σz² ＝ 2z₁² ≠ 0。
  - 正 N 角形（N ≥ 3）：Σ e^{ikθⱼ} ＝ 0 が k ＝ 1…N−1 で成り立ち、両方が同時に成り立つ（最小 N の表の「ℂ は Σo ＝ 0 も課すと 3」と一致）。
  - 一般の Σz ＝ 0 の配置では r₂ ≠ 0 でありうる。Σz² ＝ 0 は高対称性を一段強く指定する追加条件。
- **力学が Σz² を見るかは関数の形で決まる。** 蔵本の sin は第一調和だけで、平均場は Σz（複素化版では Σz⁻¹ も）のみ。Σz² は駆動も保存もされず運ばれるだけ。論文の k ＝ (1−u)/(1+u) は tan(α/2) ＝ 2(sin α − sin 2α ＋ sin 3α − …)（総和の意味）と全奇数調和を含み、Σz²、Σz³、… が平均場として力学に入る。高調波つきの蔵本は Daido（1992–96）が一般化し、調和ごとの r_k が結合する。
- こちらの立場では Σz² ＝ 0 は条件でなく結果なので、関数の選択基準が一つ立つ：**二乗閉塞を仮定せずに生み出す関数であること。** 第一調和だけではその力がない。
- 同一振動子の蔵本（Ott–Antonsen）：ṙ ＝ (K/2) r (1 − r²)。Σz ＝ 0 は K > 0 で不安定、r は e^{Kt/2} で育ち r ＝ 1 で飽和。指数的な段の長さは (2/K) ln(1/r₀) で、**初期の揺らぎが小さい（対称性が高い）ほど長い**。「極めて高対称なので幾何級数的な拡大に緩和されている」の蔵本模型での形。残り N − 3 方向は Watanabe–Strogatz の保存量で中立＝縮退した多様体。

## 14. 関数の形の問題の正体と、「結晶にならない」は都合がよい（追記 2026-10-21）

**関数の形の問題は「芯の形」の問題。** 論文の距離 D ＝ cot(α/2) で書くと、|k| ＝ 1/D、sin α ＝ 2D/(1 ＋ D²)。遠く（D ≫ 1）はどちらも 1/D で同じ、直交（D ＝ 1）もどちらも 1 で同じ。違うのは D < 1（直交から接触まで）だけ：sin は接触で力が 0 に戻る柔らかい芯、k は接触で発散する硬い芯。原子間ポテンシャルの芯を選ぶ問題に相当する。

**蔵本の文献が教えること：** 第一調和だけの結合では、同一振動子の行き先は全員が一点に集まる（引力）か一様に散らばる（斥力）かの二択で、複数のクラスターが一定間隔で並ぶ状態（位相空間の格子）は出ない。クラスターには高調波が要る（Okuda, Physica D 63, 424 (1993)；Hansel–Mato–Meunier, PRE 48, 3470 (1993)；Daido, Physica D 91, 24 (1996)）。第 k 調和で k 個の等間隔クラスター。

**訂正（木原指摘）：「結晶にならない」はむしろ都合がよい。** 全部が結合して結晶になれば一塊の固体で粒子も光もない。求める姿は、
- 大半はゆるく結合し、距離だけが読み出せる（＝空間。論文の部分投射の層）。
- その中に結合の強さの階層：複素数のまま単独（ゲージ粒子・光）／複素数のペア（N ＝ 2 の光子解 o₂ ＝ ±n o₁）／四元数として閉じる（N ≥ 3）／八元数として閉じる（N ≥ 4、条件が厳しいほど少ない＝バリオンが少ない）／複合粒子。
- 一つの規則で、生成的な結果は「ゆるい」、まれに「固まる」、その比率が出る。これが設計の基準。

**この基準での関数の読み替え：** 遠く（D > 1）は sin も k も同じ第一調和で、距離だけが読めて何も固まらない。符号が斥力側なら Σz ＝ 0 の状態が安定で気体のように保たれる（引力側なら全員が一点＝「全部結晶化」の悪い側）。近く（D < 1）で分かれる：sin は近づいても固まれないので気体か一塊の二択で階層が出ない。k は高調波と硬い芯で近い関係だけが固まれる。**k はパラメータのない一つの関数の中に、遠くは蔵本的な気体、近くは結合、の二相を持つ。** 境目は |k| ＝ 1、D ＝ 1、α ＝ π/2 で、論文では光円錐上の関係（「光円錐より外はゆるく内側で固まる」は確かめる前の読み）。sin 単独が落ちる理由は「結晶にならないから」ではなく「近くでも固まれず粒子の階層が出ないから」。

**問いの形：** 高対称の Σz ＝ 0 の配置に揺らぎが入ったとき、D < 1 に落ちる組がどれだけあり、そのうち N ＝ 2・3・≥ 4 の閉塞を作るものがどれだけか。F を一つ決めれば比率が出る数え上げ。生成的にゆるく、まれに固まり、固まるほど少ない、の順序が出なければその F は落とす。

## 15. ゲル像（追記 2026-10-21、木原提示）

**像：液体の中に、ゆるい凝縮体が一部ちらばるゲル。** 結晶よりこちらが近い。物性のゲルの物理と細部まで対応する。

- **ゲルの定義：** 大半は液体のまま、ごく少ない結合のまばらな網目が全体を貫き（パーコレーション）、形は保つが柔らかい。結合数は剛性のぎりぎり（アイソスタティック点）の近く。Phillips–Thorpe の剛性パーコレーション [X11][X12] がこれで、論文 §8 の E ≈ 3V − 6 はゲルの数え方。節や糸に局所的に密な凝縮体。物理ゲルの結合は可逆（切れては結び直す）、緩和時間は連続スペクトル、動的不均一と老化。
- **ゲルのでき方＝止まったスピノーダル分解**（Lu, Zaccarelli, Ciulla, Schofield, Sciortino, Weitz, Nature 453, 499 (2008)；総説 Zaccarelli, J. Phys.: Condens. Matter 19, 323101 (2007)）：(1) 一様状態が線形不安定になり不均一が指数的に育つ → (2) 密な側がガラス化して分離が完了する前に止まる → (3) 密な塊がつながったまばらな網目と、それを満たす希薄な液体が残る。一様 → 指数成長 → 自分で止まる → 網目と凝縮体、がインフレーション → 停止 → 空間と粒子と一対一。止まる理由が「構造が自分を固めたから」である点も同じ。
- **ゲル点＝論文の r → 1：** Flory–Stockmayer（Flory, JACS 63, 3083 (1941)；Stockmayer, J. Chem. Phys. 11, 45 (1943)）は分岐過程。結合口 f 個、結合確率 p で、一つの単位から先に平均 p(f − 1) 個が続く。1 を超えるとゲル化、切ると有限の塊で止まる。四面体は f − 1 ＝ 3 で、論文の倍率 r ≤ 3 は 3p そのもの。**倍率が 1 に落ちる点がゲル点、インフレーションの終わりはゲル化の瞬間。**
- **凝縮体の階層：** 液体（距離だけ）の中に、ペア・四元数の塊・八元数の塊・複合体が少ない順にちらばる。コロイドでは急冷の深さが、こちらでは F と初期状態の対称性が比率を決める。
- **F への条件：** コロイドのゲル化には**引力が短距離**であることが要る。長距離だと全部が一つの密な塊に相分離する（全部結晶化の悪い側）。F の言葉では、遠く（D > 1）は結合させず距離だけ読ませ、近く（D < 1）で固める。k の形はこれに合い、sin 単独は液体のままで粒子が出ない。
- **確認前の観察：** N ＝ 2 の光子解 o₂ ＝ ±n o₁ は α ＝ 90°、|k| ＝ 1、D ＝ 1 で、結合の境目にちょうど乗る（ぎりぎり結合しない）。

## 16. F はどこから来るか：文献の手がかりと、スケール不変性による絞り込み（追記 2026-10-21）

木原指摘：蔵本模型は「作用の関数 F がある」と言うだけで F の形を書いていない。文献に F のヒントはないか。→ 二つある。こちらの原則と組み合わせると、候補が数個に絞れる。

### 16.1 手がかり 1：位相縮約では F は導出される
- 蔵本（1984）の位相縮約：結合関数 Γ(Δθ) ＝ (1/2π)∫ Z(θ)·g(θ, θ＋Δθ) dθ。振動子の位相感受性 Z（PRC）と物理的な結合 g のたたみ込み。
- sin になるのは、Hopf 分岐の近く（Stuart–Landau）で Z が正弦、かつ結合が**線形**（拡散型 K(zⱼ − zᵢ)）のとき。第一調和は「状態の線形な足し算で結合している」ことの印。
- こちらの検討ルール（積の系、加法は原点を動かす）では線形結合は根元で禁じられている。**sin が落ちる正しい理由は「足し算の結合だから最初から候補にない」。**

### 16.2 手がかり 2：標準の F は関係の不変量のポテンシャルの勾配
- 蔵本も Lohe も、結合は V ＝ −Σ cos α ＝ −Σ Re u、すなわち**二次**の不変量 |qᵢ ＋ qⱼ|² の勾配。
- 論文の二つの地図は、二つの**対数**の勾配（等振幅、|q| ＝ 1、α ＝ 相対位相の角）：
  - |q₁ − q₂|² ＝ 4 sin²(α/2) → d/dα ln|q₁ − q₂| ＝ ½ cot(α/2) ＝ **½ D**
  - |q₁ ＋ q₂|² ＝ 4 cos²(α/2) → d/dα ln|q₁ ＋ q₂| ＝ −½ tan(α/2) ＝ **−½ |k|**
  - 蔵本の sin α ＝ d/dα(−cos α) ＝ d/dα(−½|q₁ ＋ q₂|² ＋ 1)：二次。
- 複素化（振幅込み）でも同じ：w ＝ log u ＝ Δa ＋ nα として k ＝ −dΦ/dw、Φ ＝ ln[(1 ＋ u)(1 ＋ u⁻¹)] ＝ ln(2 ＋ 2 cosh w)（d/dw ln(2 ＋ 2cosh w) ＝ sinh w/(1 ＋ cosh w) ＝ tanh(w/2)）。i ↔ j で対称、和の「ノルム」の対数。
- **対数は 2 次元で唯一のスケール不変なペアポテンシャル**（2 次元クーロン、ラプラシアンのグリーン関数）。全体を定数倍しても力が変わらない。二次（蔵本）はスケールに依存する。**「比だけが物理」が二次を捨てて対数を選び、対数が k と D の族を選ぶ。F は任意ではなく、スケール不変性でほぼ決まる。**

### 16.3 手がかり 3：対数ガス＝円周上で結晶化する厳密に解ける N 体系
- −Σ ln|qᵢ − qⱼ| は Dyson の対数ガス（ランダム行列の固有値分布、Dyson 1962）。固有値の対数反発が円周上の点を等間隔に並べる（スペクトルの剛性＝位相空間の結晶）。
- その勾配流（Dyson のブラウン運動）の力は cot(α/2) ＝ D。ハミルトン版が Sutherland 模型（ポテンシャル g/sin²(α/2)）で、基底状態が同じ対数ガス。どちらも可積分。
- **Dyson の threefold way（1962）：** この集団は β ＝ 1, 2, 4、すなわち ℝ（COE）、ℂ（CUE）、ℍ（CSE）の三つだけ。反発の指数 β は代数の次元で決まり、自由パラメータでない。四元数版は存在し、八元数版は非結合性のためにない（ノート 2 の「八元数の力学系は文献にない」と整合）。
- 「全員対全員・円周上・パラメータなし・結晶化する・四元数まで厳密に解ける」系がすでにある。

### 16.4 候補の族（スケール不変・積と u だけ・パラメータなし）
1. **∇ ln|qᵢ − qⱼ| ＝ D**：一致（u ＝ 1）で発散。同じ状態どうしが反発し等間隔に並ぶ（Dyson、排他）。
2. **∇ ln|qᵢ ＋ qⱼ| ＝ −k**：ペアの閉塞 qᵢ ＋ qⱼ ＝ 0（N ＝ 2 の線形閉塞）で発散。特異点がちょうど「二体で閉じる」場所。
3. 1 と 2 の和・差（例：d/dα ln tan(α/2) ＝ 1/sin α、両端で発散）。
4. それぞれの符号。

sin は落ちる。「任意の F」が数個になった。残る問い：この中のどれが「大半はゆるく、まれに固まる」階層（§14）を出すか。四元数版は Dyson の β ＝ 4 と突き合わせられる。

## 17. §16 の訂正：対の和（2 体の F）への還元は保証されない（追記 2026-10-21、木原指摘）

**滑り込んだ場所：** Żᵢ ＝ Zᵢ · Σⱼ F(uᵢⱼ) と書いた時点で、作用を「対ごとの寄与の和」に限定していた。§16 の候補の族も対の関数として書いた。これは「自分と自分以外の全て」の特殊な形（対で加法的な場合）にすぎず、こちらの系で成り立つ根拠はない。多体問題でも「1 対 自分以外」と考えて解ける場合は 2 体問題で解けるが、1 対 1 の組み合わせが全体の解法になる保証はない（木原）。

**対の和では足りない証拠**
1. **閉塞のもとで一次の情報は縮退する。** Σq ＝ 0 なら、自分以外の全ての和は −qᵢ。「自分 対 残り全体の和」は u ＝ −1 で全員が逆位相（接触）、k の分母 Σq ＝ 0。一次のモーメントに情報はなく、情報は Σq²・グラム行列・高次の多体量にしかない。蔵本が一次の秩序変数だけで解けるのは、その状態が自明でない場合。
2. **八元数の構造は対では見えない。** 二つの元は必ず結合的な部分代数（四元数）を生成し、結合子 (ab)c − a(bc) は三つ以上で初めて現れる（§3）。対の関数の和はどの項も四元数の中にあり、八元数の構造を含まない。最小の系 N ＝ 4 と対の和は矛盾する。
3. **論文の対象が多体。** 四面体は 4 点、外接球の判定は 5 点、面が閉じるのは 3 ブロック以上、剛性の数え方は全体の量。
4. **物性でも、求める網目は対では作れない。** 四面体の網（ダイヤモンド型）は対ポテンシャルだけでは安定化できず、Stillinger–Weber, PRB 31, 5262 (1985) ○ は角度の三体項を要した。限定価数のゲルの模型も価数を f に制限するのに三体項を使う（Zaccarelli, Saika-Voivod, Buldyrev, Moreno, Tartaglia, Sciortino, PRL 94, 218301 (2005) ○）。

**蔵本が 2 体に落ちる理由と限界：** 結合が双線形なので Σⱼ sin(θⱼ − θᵢ) ＝ Im(e^{−iθᵢ} Σⱼ e^{iθⱼ}) と一つの集団変数で因数分解する。これが「1 対 全体」が 2 体に落ちる条件。対数ガスはそうならない（Σⱼ ln|qᵢ − qⱼ| ＝ ln ∏ⱼ|qᵢ − qⱼ| は一つの集団変数に因数分解しない）が、可積分性で厳密に解ける。**「解ける」≠「2 体に落ちる」。**

**積の系で「自分：自分以外の全て」が本来とるべき形：** 和ではなく、自分から見た全ての関係 {uᵢⱼ}ⱼ を多重集合として丸ごと見る。∏ⱼ (x − uᵢⱼ) の係数（基本対称式・特性多項式）、あるいは ∏ⱼ 自体。
- 複素数では対数をとると ln ∏ⱼ ＝ Σⱼ ln で対の和に見えるだけで、本体は積（Vandermonde）。§16 の対数ポテンシャルはこの形に読み直せば「自分 対 全体の積」として生き残る。
- 四元数・八元数では ∏ⱼ の順序と括弧が定義に入り、そこが多体構造そのもの。対の和には還元できない。
- 相手を一人選ばず自分以外の全てを対称に扱うので、無名性の規則（存在を共有する関係の結合の禁止）と整合する。

**結論：** sin が落ちる結論は変わらない。§16 の候補は「対の関数の和」ではなく「全ての関係の積（順序・括弧込み）の関数」として定義し直す必要がある。**そんなに簡単には解けない（木原）。** 解ける場合（蔵本の因数分解、対数ガスの可積分性）は特殊で、こちらがそのどちらかに入る保証はない。

## 18. ゲルなら逐次の 2 体反応に落ちる（ブラウン運動）、観測体は遠方の吸収体、温度は部分投射の性質（追記 2026-10-21、木原提示）

### 18.1 §17 の和らぎ：希薄なら 2 体で解ける
木原：ゲルであれば 2 体で解ける。まさにブラウン運動。2 体が出会って結合する確率。結合したものは 1 体と数えるだけ。凝縮体の数がどれだけ多くても、全ては 2 体問題で解ける可能性がある。

- 希薄な系では、同時に結合の範囲（D < 1）に入るのは二体だけで、残りは遠く（D ≫ 1）。二体が出会い、確率で結合し、結合したものを一体と数え直す。これは Smoluchowski の凝集方程式そのもの（Flory の模型がクラスター間の二体反応と整合する、という Hendriks–Ernst–Ziff の指摘、DLCA も同じ）。
- §17 の反論は**密な状態で全員が同時に作用し合う力の法則**についてのもので、希薄な逐次反応には当たらない。ゲル（empty liquid）はまさに希薄な側で、2 体近似が正確になる領域。

### 18.2 3 体性の居場所の点検
1. **八元数の非結合性：** 結合したペアを一体 q_ab と数えて次に c と出会えば積は (ab)c。a(bc) は b と c が先に結合した別の履歴。非結合性は 3 体の力ではなく、**逐次の 2 体反応の順序が結果を変える**こととして現れる。論文 §8.4（合成には過程が要る、履歴が時間の矢）と一致。2 体の枠組みは壊れず、順序を記録する必要が加わるだけ。
2. **クオーク型（3 体でしか成立しない関係）：** 2 体の中間体が一切なければ逐次反応では作れない。準安定な 2 体中間体（ダイクォークにあたるもの）があれば第三体と出会う経路がある。§3 の表で N ＝ 2 の閉塞が「必ず光子」で、それが結合の境目 |k| ＝ 1 に乗っていた（§15）のは、ゆるい中間体が存在すること。障害になるかは、中間体の寿命と次の出会いまでの時間の比で決まり、これは 2 体問題の中で計算できる。
3. **原点（Σq ＝ 0）：** 密な全体が決めていた重心を、遠方の吸収体が代わりに与える。散乱理論で二体と無限遠の検出器だけを置くのと同じ構成。
4. **面が閉じる（ループ）：** 成長した塊の面が同じ塊の別の面と出会う＝「自分との 2 体」。自己相互作用はもとから枠組みにある。Flory の木近似が落としていた部分も 2 体の形のまま拾える。
5. **Stillinger–Weber の三体項：** 向きを持たない点に対ポテンシャルしかないから要るもの。こちらの体は四元数で向きと位相を持ち、対の相互作用がすでに異方的。斑点粒子の模型は三体項なしに対だけで価数を制限している。**§17 の根拠 4 は向きを持つ体には当たらない（訂正）。**
6. **最初の高対称状態：** ここだけは密で全員が等距離、2 体近似は使えない。しかしこれは**線形**安定性の問題（Σq ＝ 0 の配置が不安定か、どのモードが育つか）で、対称性の方法（等変分岐）で扱える。

### 18.3 分業
- **開始：** 密・全員対全員・線形 → 対称性で解く。
- **成長とゲル化：** 希薄・逐次の 2 体反応・ブラウン運動 → Smoluchowski と Flory–Stockmayer で数える。入力は二つだけ：出会う率（相対位相のブラウン運動の核）と、出会ったときに結合する確率（2 体の F でロックするか）。
- **観測：** 遠方の等方な完全吸収体。有限面積 N 個からなり、向きを読むためにごく僅かに非等方（木原の過去の論文：第十一思考実験・吸収体基準）。

難しい「密で非線形で全員対全員」の領域を通らずに済む。ノート 3 で「使える」とした分岐過程・限定価数・パーコレーションは、この 2 体反応の側から正当化される。

**解ける条件：** 3 体でしか成立せず、かつ準安定な 2 体中間体を経由できない関係がある場合だけが障害。

### 18.4 温度は部分投射の性質（「温度がない」の訂正、木原指摘）
「温度がない」は誤り。正しくは「外から置く温度はない」。質量があればエネルギーがあり、エネルギーがあってかつ読めない状態の数があれば、温度は内部に定義できる。

- **温度とは：** 1/T ＝ ∂S/∂E（エネルギー一単位あたりのエントロピーの増え方、エントロピーで測ったエネルギーの値段）。統計力学では e^{−E/kT} の係数、接触した系の間で等しくなる量。等分配 ½kT は平衡・二次自由度の特殊な場合。温度の傾斜が熱の流れを起こすが、温度そのものは比。**温度は一つの微視状態の性質ではなく「どの微視状態かを読めない」ことの性質。** 一つの質量はエネルギーを持つが温度を持たない。
- **こちらの系の二条件：** (1) 交換される保存量＝質量（振幅の比、仮説 1）を動く枠から読んだエネルギー（仮説 2）、流れの保存量（Σq、Σq²、複素化蔵本の Σ ln 振幅）。(2) 読めない状態の数＝部分投射そのもの（大きさ・符号・赤道・全体の回転が逃げる、柔らかいモード F）。
- **したがって温度は部分投射の性質：** 全投射（剛体結晶）は S ＝ 0、T ＝ 0（絶対零度の完全結晶、論文が排除）。部分投射（ゲル）は有限 T。ゼロ投射（液体）は高 T。結晶・ゲル・液体の三相＝温度の三段階。
- **スケール不変の系での読み出し：** 温度も比としてしか出ない。候補は「相対位相がさまよう幅（揺らぎ）／ロックの深さ（結合）」。蔵本では固有振動数の幅 Δ が温度の役で K_c ∝ Δ、ロック条件 |Δω| ≤ K r は「温度が結合より低いときだけ固まる」。ゲルの結合の寿命は Kramers 型 e^{−（結合の深さ）/T} で、この比が「大半はゆるく、まれに固まる」の比率を直接決める。
- **揺らぎの源：** 吸収体の内部状態は読めない。読めない部分がペアの相対位相にかかる揺らぎの源。吸収（散逸）と揺らぎが同じ遠方の体から来るのは熱浴と同じ構造だが、揺動散逸関係はここでは仮定でなく、部分投射から導くべき命題。

## 19. 二度の相転移：完全結晶の融解がインフレーション、過飽和からの凝縮が粒子（追記 2026-10-21、木原提示）

**公開後の訂正を含む。** 論文 v1.1 §10 の筋書き（過冷却の高対称状態にシードが入って結晶化する）は、向きが逆だった可能性が高い。論文の本文は変えない（次の論文で扱う）。

### 19.1 第一の相転移：完全結晶の融解＝インフレーション
- 初期状態は**極めて対称性の高い硬い結晶**。§2 の「高対称配置は全ての作用で相対平衡」、論文 §8 の「全投射＝剛体結晶、発展しない」、§18.4 の「全投射は S ＝ 0、T ＝ 0」がこれ。
- わずかな欠陥から融け始める。一要素が外れると隣の拘束が外れて外れやすくなる。一つ外れるごとに新たに不安定になる隣の数が分岐比 r。論文の「一つ付くと面が三つ出る」の数え方は、そのまま**融解の雪崩**として読み替える。欠陥の面積（結晶と融けた相の境界の要素数）が幾何級数的に増える。
- 境界では放出（外れる）と吸収（再び付く）が競う。融けた相が希薄なうちは放出が勝つ。
- **結晶が尽きたところで止まる。** インフレーションの終わりは、面が閉じることではなく**貯蔵庫（初期結晶）の枯渇**で与えられる。

### 19.2 第二の相転移：過飽和した溶液からの凝縮＝粒子
- 全部が融けた直後は自由な要素が多すぎる**過飽和**（過冷却と同じ）。再び付く先の結晶がない。
- わずかなシードから凝縮が始まるが、小さなシードは捕まえる力（質量、ロックの深さ）が小さく、ぶつかってもほとんど合体しない（溶解の逆：吸収する側の質量が小さすぎる）。過飽和状態は準安定でしばらく保たれる。
- 合体が進むと放出（溶解）と吸収（合体）が釣り合う。可逆な凝集（Smoluchowski ＋ 断片化）の定常状態、**詳細釣り合い**。自由な要素・ペア・四元数の塊・八元数の塊が、結合の深さと揺らぎの比で決まる割合で共存する。クラスターの分布は結合の深さに対して指数的に減り、「大半はゆるく、まれに固まり、固まるほど少ない」（§14）がここから出る。核種の存在比が凍結で決まるのと同型。

### 19.3 この向きが熱力学的に正しい理由
- 外に熱浴がない閉じた系ではエントロピーは増えるしかない。論文の筋書き（無秩序 → 結晶化）は系全体のエントロピーが減る向きで、潜熱を捨てる先がない。木原の筋書き（完全結晶 → 融解 → 溶液）は増える向きで、閉じた系で起こりうる唯一の方向。
- 第二段の局所的な凝縮が可能なのは、溶液の残り（遠方の吸収体、§18.3）が潜熱の捨て場になるから。
- 論文の「再加熱＝結晶化の潜熱」は読み替わる：**再加熱とは、エントロピー 0 の結晶が高エントロピーの溶液になること、温度が生まれることそのもの**（§18.4）。

### 19.4 相互作用は共通でなくてよい（木原：「全て共通である必要があると考えていたが多分間違い」）
- 規則は一つのまま、**効く形が相の状態で変わる**。§17 のとおり作用は「自分 対 自分以外の全ての関係の積」で、「全て」とは分布そのもの。完全結晶では全てが対称で各要素の正味の作用は 0（固定点）、欠陥の近くだけ 0 でない。溶液では全ては等方な背景（ブラウン運動と吸収体）に落ち、効くのは出会った二体だけ。同じ規則が相によって別の法則に見える。
- 要素には名前を付けず、**集団の状態（分布・対称性・どの相か）が反応の名前になる**。Landau が相を等方部分群で分類したのと同じで、無名性は保たれる。

### 19.5 二つの状態と、その間
- 状態 I：完全結晶（全投射、T ＝ 0）。
- 状態 II：溶液と、その中に釣り合いで共存する凝縮体（部分投射、有限の T）。
- 相転移 1（I → II）＝融解＝インフレーション。相転移 2（II の中）＝核生成＝粒子の形成と凍結。
- §18.3 の分業はそのまま、状態 I の雪崩（密・線形・対称性）と状態 II の 2 体反応（希薄・ブラウン運動・Smoluchowski）に対応する。

### 19.6 論文 v1.1 との差分（次の論文で扱う項目）
| 論文 v1.1 | 本メモの読み替え |
|---|---|
| 過冷却の高対称状態 → シードで結晶化 | 完全結晶 → 欠陥で融解 |
| 面が閉じて r → 1 で止まる | 結晶の枯渇で止まる（面の閉じは第二段のゲル化へ） |
| 再加熱＝結晶化の潜熱 | 再加熱＝融解でエントロピーと温度が生まれること |

| 相互作用は一つの関数 | 規則は一つ、効く形は相で変わる（相が反応の名前） |

## 20. 外は無知の産物ではなく、内と同時に生まれる双対の側（追記 2026-10-21、木原指摘）

**誤り：** §18 で「遠方の完全吸収体」を外の部品として置き、次に「外はない」として容器・溶媒・無限遠・吸収体を全部否定し、Boltzmann の分子的混沌（無知）や Wheeler–Feynman で説明しようとした。これは弱い版だった。**外は消すものではなく、内と同時に生まれる双対の側**（木原）。

**式で言うと：** x² ＋ y² ＋ z² ＋ (it)² ＝ R² ＋ Q₁² ＋ Q₂² ＋ Q₃²
- 左辺＝観測できる側（時空、ビーカーの中）。右辺＝観測できない側（内部空間、ビーカーの外）。
- **Σzₙ² ＝ 0 とは左辺 ＝ 右辺のこと。** 論文 §11 の「分解型八元数のヌル条件 ＝ 時空側と内部側の四元数が等振幅 |a| ＝ |b|」そのもの。
- 一つの成分を 90° 回す（i を掛ける）と二乗の符号が変わり、その成分は式の反対側へ移る。中の在庫が増えれば外の在庫も増える。両辺は常に等しいまま、中身が行き来する。
- **ビーカーは実在ではなく、この等式そのもの。** 壁も溶媒も外の物体でなく、同じ閉塞の反対側。

**二度の相転移は二度の 90° 回転：**
1. 最初の完全結晶は**右辺（内部空間）**にある。観測できる時空はまだない。融解とは内部空間の内容が 90° 回って**左辺（時空）へ溶け出す**こと。空間が結晶から生まれ、両辺が等しいまま観測できる側の在庫が増える。これがインフレーション。
2. 第二の相転移は時空側の内容が**再び 90° 回って右辺（内部空間）へ戻る**こと。イベント・ホライズンを越える。戻ったものが質量であり電荷（「質量は内部空間を外から読んだもの」「粒子は RQ 空間の住民」）。

**一か所に集まるもの：**
- 論文は |k| ＝ 1、α ＝ π/2 を光円錐上の関係と同定。§14 で同じ |k| ＝ 1 が「ゆるい／固まる」の境目。90° の回転はまさにこの点。**光円錐 ＝ ホライズン ＝ 結合の閾値 ＝ 式の左右を分ける面。** 固まるとは関係がホライズンを越えて内部空間に入ること。
- N ＝ 2 の光子解が |k| ＝ 1 に乗っていたのは、ホライズンの上に住みどちらの側にも属さない関係だということ。
- 「完全吸収」とは Boltzmann の無知の仮定でなく、**ホライズンを越えた内容が観測側の写像では読めない**こと（「地平線＝観測写像の切替」）。右辺から見れば鏡像で何も失われない。
- 「吸収体がペアに揺らぎを与える」とは右辺（内部空間）が左辺（時空）に作用すること＝「何が R を与えるか」という未解決の核心と同じ問い。
- §18 で言った「ループを自己無撞着に閉じる」の閉じ方は、別の運動論を立てることでなく**左辺 ＝ 右辺の等式を保つこと**。出て行ったものは反対側に計上される。

**残ること：** 90° 回転の**速さ**を何が決めるか（論文 §6.4「運動は左右の不釣り合い」、t を it と読むか R′ に吸収するかの射影軸の選び方がここに関わる）。第一の転移は右→左、第二は左→右と、回転の向きが逆になる理由。

## 21. 2026 年 4 月の初期モデル（超立方体の在庫、マイナス在庫、倉庫スペースの上限）との対応（追記 2026-10-21、木原提示）

### 22.2 ビッグクランチと 0 次元の在庫（木原：トイモデルの前から考えていたが、トンデモになるので書かなかった。後に近い note を出している）
- ビッグクランチ＝全部が 90° 回って右辺に戻りきること。観測できる側の次元は 0 に縮退する。左辺 ＝ 右辺は保たれ、何も失われず、**全部がホライズンの向こうに在庫として残る。** この 0 次元に縮退した情報がまさに在庫（§21）。
- 次元が 0 になるのは次元が読み出しだから（前稿：読める方向の数 min(3, N − 2)、全要素が区別できない完全対称では 0）。読める次元は消えても要素の数と中身（情報）は残る。
- **§19 の「最初の完全結晶」の出どころ：前の周期のクランチで 0 次元に縮退した在庫。** 完全に対称なのは、新しい観測側から見て区別が一つも読めないから。欠陥（揺らぎ）で読める方向が一本開き、新しい原点から新しい中心投影が始まる。周期的な宇宙。
- **エントロピーのリセット：** 周期宇宙の古典的難点（Tolman 以来、周期ごとにエントロピーが増え続ける）。§18.4 で温度とエントロピーは部分投射の性質。クランチで観測側の広がりが 0 になると読み出し自体がなくなり、隠れた微視状態を数える主体が消える。次の周期は S ＝ 0、T ＝ 0 の結晶から始まる。**情報は右辺に残り保存され、エントロピーは読み出しとともにリセットされる。** Penrose の共形周期宇宙が目指したことが、部分投射の定義から出る（Claude の導出、要検討）。
- **局所版：** ブラックホール＝局所的なクランチ。内容がホライズンを越えて右辺に移り、外からは 0 次元の在庫に見える（「BH ＝ R 共有の複合粒子」「地平線＝観測写像の切替」と整合。Claude の延長）。
- §20 で「閉じた有限の系では吸収体は不完全でいつか戻る」と言った「戻る」が**クランチそのもの**。吸収体は一周期の中では完全で、周期の終わりに全部を返す。

### 22.3 Uⁿ ＝ I：宇宙が有界なら時間も有界（木原、2026 年 4 月時点の気づき）
**議論：** 倉庫に上限がある（有限の N、有限の解像度）ので取りうる状態は有限個。一歩の発展 U は単位の積で逆があり、有限集合の上の可逆写像は置換。置換は有限の位数を持つ。よって Uⁿ ＝ I。時間は組み替えの列（論文 §8.3）で、有限個の配置しかなければ列はいつか繰り返す。**宇宙が有界なら時間も有界。** 余計な仮定なし。

**帰結：**
1. 周期が一つの宇宙。クランチ → 0 次元の在庫 → 新しい中心投影 → 融解 → 粒子 → クランチ、が U の一周期 n。
2. U の固有値は e^{2πi m/n}。全モードの速さの比が有理数 m/n。**Uⁿ ＝ I の宇宙ではロックは必ず有理**（残課題「有理ロック」への答え）。「近いが一致しない」＝分母 n が大きい有理比を短い時間で見ていること。量子化（離散準位）も有限性から出る。
3. 離散か連続かの判定になる：位相が連続なら有界でも状態は無限個で、戻りは近似（Uⁿ ≈ I、準周期）。厳密に Uⁿ ＝ I なのは状態空間が離散のときだけ。「基礎は離散（Z⁴、π なし）、連続幾何は創発」とつながる。

**公開済みの論文に出ていた形：** 前稿の最も対称な配置 q ＝ ±e^(πn/4) は q⁸ ＝ 1（位数 8）。600 胞体の頂点は位数 120 の群。第十一思考実験の有限位数根 R_{n,m}、137 の格子。いずれも Uⁿ ＝ I の局所的な現れ。

**注意：** 振幅の動力学（複素化蔵本）を入れると一歩は単位の積でなくなり U は大きさを保たない。全体の対数振幅は保存され比は倉庫の上限で押さえられるので、離散なら有限の位数のまま。要確認。

## 23. 二本の思考実験記録（10/22–23）から次の論文に持ち込むもの（追記 2026-10-23）

### 23.5 確率・時間・ベルの整理（発言録）
- **ボルン則は難所でない：** U² ＝ I の射影で cos²、U^n ＝ I の一周期の m/n の数え上げ。ランダムに見えるのは周期のどこにいるかを知らないから（§22.3 と同じ）。
- **時間＝不完全な引き込み：** 完全ロックでは事象がなく時間が立たない。ロックの限界をわずかに超えると位相スリップが間欠的に起こり、各スリップと再引き込みが離散的な事象。引き込みは位相空間が縮む向きにしか進まず部分投射は発展方向にだけ起こる→因果。**スリップ頻度 ∝ √(Δ − Δ_c)**（サドルノード則）が「時計の刻み」の基本法則の候補（検証可能）。信号はスリップだけが運び、ロックした相関は信号にならない（信号不可能性）。
- **ベル：** 時空距離と内部状態距離（共役・双対）を一つの局所性として混同したことが根。ロックした二体は時空で遠くても内部状態空間では一点＝一つのモード。さらに光円錐距離自体がスリップの数え上げ（m/n）の粗視化で、部分投射の不確定性を含む創発量。破れているのは「背景を連続で確定したものとみなす前提」。

### 23.6 割り算の罠（検討ルール 10/19 の根拠と、実験での守り方）
- m/n は規模 n を捨て、離散を連続に見せ、確率と区別できなくする。正規化・mod 2π・巻き数も同じ。割り算できる＝比を変えない対称性（スケール変換）があり、その軌道を同一視している。回数 n を消すと共役な位相が連続で不確定なものとして浮かぶ。
- CG の同次座標：次元を一つ足し、積和だけで回し、割るのは最後の透視除算一回。点の重み付き和は和が 1 でないと原点が動く（積和の危険）。蔵本の秩序変数 (1/N)Σe^{iθ} は円周上の点の積和を N で割ったもので、r < 1 がその原点側へのずれ。
- **実験の設計規則：** (m, n) の整数の組を保持し割り算は読み出しで一度。秩序変数は Σe^{iθⱼ} と N を別々に記録。発展は複素指数部の足し算で線形に回し、和（干渉）は読み出しの瞬間に一回。途中で log を取ると節で発散するが、指数部だけなら発散しない。位相の巻き数、どちらを虚部と読むかも読み出しの選択。
- 中心投影 X ＝ R tan θ は等間隔でない（dX/ds ＝ 1 ＋ X²/R²）。違う投影基準 φ_A、φ_B の値の間は X_B ＝ (X_A − R tan δ)/(1 ＋ (X_A/R) tan δ) の分数線形変換で、**異なるゲージの値を割っても観測者によらない意味はない**。R ≠ |q|、振幅は曲率方向と直交する別の読めない方向（全記録 §25–27）。

### 23.7 論文の位置づけに使える言い回し（全記録）
- 最大の気づき：進行位相すら仮定しない純粋な定常波二つが、内在的に三次元の位置ベクトルを記憶できる。背景がなければ状態自身が位置を記憶するしかなく、読み出しゲージとの干渉で初めて位置が読める（§03）。
- インフレーションを主題にした理由：時空と粒子がなぜ存在するかを主題にする学問分野が、現状ではインフレーションだけだから（§09）。Guth・佐藤の初期理論も終わり方（graceful exit）が未解決のまま公表された（§10）。
- 複素数だけでは凝縮体が作れず四か月止まった。可換で相対位相に方向がないから。四元数では相対位相が方向 n を持ち、ab − ba ＝ 2a×b で三角形・四面体が組める。自由度の数でなく関係を作る代数の対称性が変わったことが決定的（§22）。
- 大統一の本質は「全てを同じものにすること」でなく「同じものがなぜ異なるものとして区別可能になるか」を説明すること（§14）。0 と 1 しかない世界で XOR により初めて区別が成立する、という問題意識の物理への拡張（§15）。

## 24. 振幅の置き場所と Q 軸の由来、質量＝時空曲率 R・電荷＝内部曲率 Q（追記 2026-10-23、木原提示、§14 の訂正を含む）

### 24.1 振幅はどこに住むか（木原）
- 平面の円 z ＝ a ＋ ib では振幅 |z| と円の半径 R が同じ数で、二つが別物だと気づかない。振幅は動径方向の成分だと思って済んでいた。
- 状態が S³（半径 R の 4 次元球殻）に乗るとすると、局所座標は 3 次元で R は見えない。測地線（大円）に沿う並進では曲率の効果はゼロ、**面積を掃く 2 次元の移動（閉路・回転）で初めて観測される**（ホロノミー、Gauss–Bonnet、幾何学的位相。回転量＝掃いた面積／R²）。
- 振幅 A の行き場：動径方向はすでに曲率半径 R が占め、R は閉路でだけ読める曲がり。振幅をそこに入れると振幅の変化が曲率の変化になり、おかしい（R ≠ |q|、全記録 §25、検討ルール）。**振幅は円周とも R とも直交する別の読めない方向に住む**＝円平面の外へ立つ軸。円は螺旋・円柱 S¹ × ℝ、S³ なら S³ × ℝ_Q。これが **Q 軸の由来**。読めない方向なので虚数で書き (iQ)² ＝ −Q²。
- x² ＋ y² ＋ z² ＋ (it)² ＋ (iR)² ＋ (iQ)² ＝ 0 は、接方向 3（読める＝空間）＋ 法方向 3（読めない＝時間 t、曲率 R、振幅方向 Q）。六軸動力学の R′² ＝ R² ＋ Q²、C⁶ の放射投影模型（ℝ⁶ → S⁵）と同じ形。新しいのは由来の説明。Q が三つなら法方向は t・R・Q₁・Q₂・Q₃、全部で八成分＝八元数。

### 24.2 二つの読みと、B を採る理由（木原指摘：質量と電荷を逆に読んでいないか）
- **読み A（Claude の前の読み、§14 と同系）：** 振幅は Q に住み、質量＝振幅、電荷＝その向き。
- **読み B（木原）：質量＝時空曲率 R そのもの、電荷＝内部曲率 Q そのもの。** 電荷は時空曲率に影響せず、内部曲率にだけ影響する。
- B が整合する理由：(1) 一般相対論そのもの。R の不均一が潮汐で、論文 §6.3「重力の源はノルムの不均一」は「R の不均一」と読み直すだけで GR の言い方になる。(2) 電荷＝内部幾何は Kaluza–Klein の読み。(3) 内部記録と一致：粒子の種類＝tRQ₁Q₂Q₃ の符号ベクトル（Q_em ＝ −(1/6)ΣQ − t/2）、質量の階層は R の三相、粒子は RQ 空間の住民、R′² ＝ R² ＋ Q²、論文 §11 の |a| ＝ |b|。
- **B を採る。**

### 24.3 B の辞書：同じ 1 ＋ 3 が両側で繰り返される
分解型八元数 (a, b)。a ＝ t ＋ xi ＋ yj ＋ zk（時空側）、b ＝ R ＋ Q₁i ＋ Q₂j ＋ Q₃k（内部側）。

| 側 | スカラー部 | ベクトル部 |
|---|---|---|
| 時空側 a | t ＝ 時間 | (x, y, z) ＝ 空間 |
| 内部側 b | **R ＝ 質量（時空曲率）** | **(Q₁, Q₂, Q₃) ＝ 電荷（内部曲率）** |

- 振幅＝内部側のノルム |b| ＝ √(R² ＋ ΣQ²) ＝ R′。ヌル条件 |a| ＝ |b| は「時空側の在庫＝内部側の在庫」（§20・§21）。
- 仮説 1「質量 ∝ |q|²」は、B では「質量 ∝ 内部側のスカラー部 R」に精密化。振幅のうち Q の部分は質量でなく電荷として読む。

### 24.4 B から出る帰結（確かめる前の読み）
- **電荷は量子化、質量は連続に見える：** 電荷は内部 3 ベクトルの向きと符号で離散（符号ベクトル 16 通り）、質量はスカラーの大きさで連続。電荷が e の整数倍、質量に階層はあっても量子化規則が見えないことと合う。
- 「透過率＝素電荷 1 − R ＝ sin²θ ＝ √(4πα)」は電荷の**大きさ**が普遍（内部ベクトルの長さが固定）、符号と向きが Q の選択、と分けて読む。
- **§14 の訂正：** 論文の k は時空側 a から作るので、そのベクトル部は**空間の向き**であって電荷ではない。「k のスカラー部＝質量、ベクトル部＝電荷」は誤り。電荷を読むには内部側 b の k_内部 が要る。§23.4 の「論文の分母＝γ の正規化」は時空側の話としてそのまま成り立つ。
- 複素化蔵本（§7）の振幅の動きは、B では内部側 b の動き（R と Q）であり、時空側の曲率を壊さない、ではなく**R の変化がそのまま質量＝時空曲率の変化**。「振幅の力学が曲率を壊さない」（§24.1 の Claude の言い方）は B では成り立たず、むしろ振幅の R 成分の分化が質量の生成＝曲率の生成。

### 24.5 変わらないこと・決め手
- 状態の S³ に法方向が二つ（R と Q）あり、どちらも接方向からは読めない、という幾何は A・B で同じ。変わるのは質量・電荷という名前をどちらの法方向に付けるかで、これは読み出しの選択（成分に色はない）。
- 決め手は「どちらの割り当てが R 側で GR 型、Q 側でゲージ型の読み出しを無矛盾に出すか」。B は両方に合う。
- 次：内部側の k_内部 ＝ (1 ＋ u_b)⁻¹(1 − u_b)、u_b ＝ b₁⁻¹b₂ を書き、そのスカラー部（R の比＝質量比）とベクトル部（Q の向きの差＝電荷の関係）が、時空側の k と |a| ＝ |b| でどう結ばれるかを確かめる。

## 25. 振幅の虚数読みを ℂ → ℍ → 𝕆 と上げると、区別できないものが一段ずつ区別できるようになる（追記 2026-10-23、木原提示）

**ℂ：振幅と位相が区別できない。** z ＝ e^{a ＋ iθ} で振幅の指数 a を虚数に読むと i(a ＋ θ) となり位相と一つになる。虚数単位が一つなので、虚数読みした振幅は位相の π/2 のずれと見分けがつかない。残るのは符号の反転（二乗が負＝Wick 回転）だけ。発言録はここで止まっていた。

**ℍ：振幅と位相が区別でき、その非可換性が空間を生む。** 振幅に位相と別の虚数単位 m（m ⟂ n）を与え q ＝ e^{m a ＋ n θ}。
- 指数が純虚なので |q| ＝ 1 のまま、全部が S³ 上の回転。振幅が動いてもノルムは動かない。「全体のスケールは読めない」が公理でなく構造になる。
- m ⟂ n なので振幅と位相が区別できる。
- 可換でない：e^{ma} e^{nθ} ≠ e^{nθ} e^{ma}、差は交換子 [m, n] ＝ 2 m × n ＝ 第三の方向。**振幅と位相の二つの虚数読みが掛け算の順序を通して三つ目の方向を生み、三つで 3 次元の虚部＝空間が埋まる。** 論文の k ＝ −n tan(α/2) が 3 次元ベクトルになる根。掛ける順序の違い＝左右の除算＝観測者の枠（§2.2）。
- 前稿の本当の二乗 q² ＝ (q₀² − |v|²) ＋ 2q₀v が (1, 3) の符号を持つのはこの段の虚数読み。
- 注意：e^{ma ＋ nθ} と e^{ma} e^{nθ} は別物（BCH の補正）。どちらを「振幅と位相を合わせた状態」と呼ぶかにも順序の宣言が要る。

**𝕆：質量型の振幅と電荷型の振幅が区別できる。** 振幅の虚数単位を二つ（R の m、Q の l）、位相の n と合わせて三つの独立な虚数方向にすると、初めて結合子 (ab)c − a(bc) ≠ 0。
- ℍ では R と Q に別の単位を与えても二つの虚数は必ず結合的な部分代数に収まり、どちらを質量と呼ぶかは名前の付け替えにすぎない。
- 𝕆 では R・Q・位相の三つ組が非結合になり、**R 型の振幅と Q 型の振幅は代数的に別物**になる。全記録 §14 の「なぜ質量と電荷を区別して測れるのか」に、「三つ目の虚数読みで初めて結合子が立つから」という代数の答え。§24 の読み B（質量＝R、電荷＝Q）が名前の選択でなく構造になるのはこの段。
- 内部側の振幅 (R, Q₁, Q₂, Q₃) を全部虚数に読むことが論文 §11 の分解型（γ ＝ ＋1、符号 (4, 4)）を選ぶことそのもので、ヌル条件 |a| ＝ |b| がそこから出る。
- 最小の系の表（§3：八元数は 3 個で結合子、閉塞まで課すと 4 個）と同じ数え方。

**帰結：** 振幅の変化が回転になったので、§19〜§21 の融解と凝縮（右辺と左辺の間の 90° 回転）は e^{mπ/2} のような**有限位数の回転**。インフレーションはノルムの成長でなく回転で、Σ ln 振幅の保存と U^n ＝ I（§22.3）に矛盾しない。

## 26. 隠れていた対称性：振幅と位相は共役・双対で、その双対は指数空間の 90° 回転（追記 2026-10-23、木原指摘）

- 指数の平面 w ＝ a ＋ iθ で i を掛けると i w ＝ −θ ＋ i a。**振幅と位相が入れ替わる。** 振幅 ↔ 位相の双対＝指数空間の 90° 回転。どちらを振幅と呼ぶかはこの回転のどこで軸を止めるかの選択（成分に色はない）。
- 同じ一つの回転の現れ：数と位相の共役（[N, φ] ～ i、発言録「回数 n と位相は共役」）、時間と振動数、位置と波数、Wick 回転（実の減衰 ↔ 虚の振動、統計力学 ↔ 量子力学）、Laplace 変数 s ＝ σ ＋ iω。
- **ℍ では、振幅軸 m と位相軸 n を入れ替える回転は第三の軸 m × n のまわりの 90° の空間回転。** 振幅と位相の双対が空間の一つの回転と同じものになる。𝕆 では R・Q・位相の三つ組の各対にそれぞれ第三の軸があり、全体は虚部 7 次元の回転（自己同型は G₂）。
- **自己双対点：** k と 1/k（結合と距離、和の対数 ∇ln|q₁＋q₂| と差の対数 ∇ln|q₁−q₂|、§16）が入れ替わって一致するのは |k| ＝ 1、α ＝ π/2 ＝ **光円錐＝ホライズン＝結合の閾値**（§14・§20）。双対の固定点が左辺と右辺を分ける面。
- 振幅は内部側（右辺、§24 の b）、位相は時空側（左辺、a）の量なので、この双対は **§20 の「内と外は双対」の指数空間での現れ**。|a| ＝ |b| は双対の両側の在庫が等しいこと。
- 実験の設計への含意（§23.6 と同じ）：振幅と位相は一つの複素指数の二成分として同時に保持し、どちらかを割り算や正規化で落とさない。落とすと共役な片割れが「不確定」に見える。
