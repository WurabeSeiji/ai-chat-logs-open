# 設計の崩れの点検（2026-10-16）

著者の指示「前回の公開済みの実験の見直し部分から、全チャットを自分で読み直し、どこから設計を崩したかを確かめる」に従い、統合仮説論文 v1.1 公開後の見直し（「この論文の課題を順番に解決します」）から現在までの対話（著者の発言 174、全 359 発話）を読み直した。番号 U は著者の発言の通し番号。

## 1. 対話で立て直した骨格（設計が守るべきもの）

1. **閉塞は結果**（U004〜U008）：自己無撞着な状態なら Σz² ＝ 0 が結果として出る。定義・条件として課さない。
2. **指数表現の四行**（U009〜U027）：一つの波は閉じない、倍音 n ≥ 2 で自明でない閉塞。線形和・本当の二乗・ノルム（位相を捨てる＝2π で量子化を強制）・R を独立な自由度とした (iR)²。倍音だけの構造は曲率を持たない（質量なし、平坦）。
3. **背景のヒッグス波 z_h**（U028）：倍音を持たない一本の波。自己無撞着でなく、z_h² ＝ R₀²（真空エネルギー）。自由度は振幅 A_h と分解能 N_h（2πR₀ を何等分するか）。等間隔か、三方向で異方的か（N_hx, N_hy, N_hz）が悩み。Σz_n² が自己無撞着しない分が質量に見え、それが R(n, θ) の波形になる。
4. **局在した波が背景の波長を変える＝ゲージが変わる＝重力**（U030）。それは**ローレンツ因子 γ そのもの**で、空間と時間の読める傾斜が生まれる。γ ＝ 1 なら平坦で、空間の向きも時間も読めない（U031）。
5. **三次元の γ(θx, θy, θz) と、等間隔でない θ のためのゲージの不変量**（U032）→ **クリフォード平行移動**：空間を定義せず、単位四元数との演算だけで、時空の読めるゲージの傾斜が生まれる（U033）。ヒッグス波でなくクリフォード平行移動が実体かもしれない（U034）。標準ゲージ場との違いは三点（群を空間そのものに置く、接続は読み出し、閉包は本当の二乗）（U035〜U036）。
6. **目的：マクロな R₀ と局所の R を状態の演算から生み出す**（U037）。0 ＋ 0 ＝ 0 で部分の閉塞が全体の閉塞になる。分解は困難、合成は容易（U038〜U039）。
7. **水素一個で閉塞、放射は無限遠の完全吸収体（R₀、分解能 N₀）へ**（U040〜U043）。記録は境界の空隙（面積）に乗る。真空エネルギーは歪みから生じる（U045）。
8. **最小の閉じた系 ＝ 陽子＋電子の二体、無限遠の吸収体（N₀）、近傍のクリフォード平行移動が作るゲージ場の傾斜＝ヒッグス場**（U047）。観測されなければ広がっている。倍音はスケールを変えず、局所の閉塞に効くのは N ＝ 10〜100（U048）。
9. **K の調整は一次・二次まで**（U091）、**S³ の三次元表面の住民**（U092）、**視野角の三角形で無名に距離を定義**（U094）、**三角形が局所曲率を決め、全体の固有振動の R₀ が局所を打ち消して零に閉じる。閉じなければ干渉できず系が壊れる**（U095）。
10. その後の材料：正軸体と R ＝ 3 の殻（U098〜U111）、八方向と符号ベクトル（U131〜U144）、弱い力、左右の掛け算（U145〜U147）、**右＝交換 R ≈ 0.7、左＝ローレンツ因子 γ**（U149）。

## 2. どこで崩したか

1. **仕様 v0.1（U097「慎重にモデルを作って」の直後）で、骨格の 3〜8 を書き落とした。** v0.1 は 600 胞体の標本点・視野角の三角形・重みの付いた K から始め、**背景の波 z_h、それとのビート、ビートによる原点 θ₀ の回転＝並進、背景の波長の伸び＝γ＝ゲージの傾斜、クリフォード平行移動を等間隔のゲージの基準とすること、無限遠の吸収体 N₀、陽子＋電子の最小系**のどれも入れていない。U028〜U048 の立て直しの中心が、仕様の段で消えた。
2. **v0.2・v0.3 は v0.1 の上に材料（E₈・137・正軸体・符号ベクトル・左右の掛け算）を積み増しただけで、欠けた骨格を戻さなかった。** v0.3 §5 では U149 の「左＝ローレンツ因子 γ」を、**粒子に一度掛けるブースト演算子**と読み替えた。対話の γ は U030〜U031 のとおり、**局在した波が背景の波長を伸ばした結果として読める傾斜（ゲージの伸び）**で、外から掛ける演算子ではない。
3. **設計書 v2 と段 1〜5c は、背景のない粒子に演算子を掛ける形で組まれた。** そのため並進（段 3b：左を実数の角で入れた）、時計（段 3c・3d：ブーストを時間成分に掛けた）、歪み（段 5a：|ρ| から辺を伸ばす独自の規則）、自己無撞着（段 5c：静止した粒子、固有モードが広がる）と、各段で骨格にない部品を置き、結果が合わないたびに別の部品を足した。段 5c の「静止した粒子」は U172 の指摘どおり、骨格 3〜4（背景とのビートで θ₀ が回る＝並進、静止した粒子はない）に反する。

## 3. 作り直すときに最初に置くべきもの

- 場は「背景の波 z_h（倍音なし、振幅 A_h、分解能 N_h）」と「局在した波（倍音 n ＝ 1〜N）」を同じ一つの閉塞の中に持つ。
- 等間隔のゲージの基準はクリフォード平行移動（単位四元数の掛け算、ハール測度、不変量は巻き数と一歩の回転角）。
- 局在した波が背景の波長を変え（位相勾配の変化）、その伸びが γ(θ)。γ の勾配が空間の向き・時間・重力として読める。γ ＝ 1 なら何も読めない。
- 粒子と背景のビート（交差項）で原点 θ₀ が回り、それが並進。速さと内部時計（質量）はビートの予算の配分として読む。運動を外から入れない。
- 右の交換（R ＝ cos²θ、実数の角）と左の γ（背景の伸びとして読まれる傾斜）の役割は U149 のとおりだが、左の γ は演算子として掛けるのでなく、背景の波長の伸びとして生成子に入る。
- 最小の系は陽子＋電子＋無限遠の吸収体（N₀）。局所の三角形の曲率と全体の R₀ が打ち消して零に閉じることを、課さずに結果として確かめる。

この点検の後、仕様を上の骨格から書き直し、照合表とあわせて著者に見せてから実装する。段 1〜5c は「確かめた範囲」と「骨格を欠いた設計の記録」として残す。

### 4.2 ここから決まる、R ＝ 3 の系を使う条件

1. **背景の波は、格子の単位（24 方向）に沿った等間隔の一歩で位相が進む波として置く。** 背景の等間隔は外から決めるのでなく、格子の対称性（単位の群）が与える。N_h は単位の群の位数とその倍数で決まる。
2. **粒子（R ＝ 3 の球、137 個のセル）は、中心が単位の位置にある局在で、背景のゲージの上を単位の一歩ずつ動ける。** 並進は背景とのビートで θ₀ が回った結果として、単位から単位への移動として読む。
3. **局在した波が背景の波長を伸ばす（γ）とは、背景の一歩（単位の掛け算）に対する、粒子の近くの位相の進みの比が 1 からずれること。** 格子の上の一歩は等長なので、ずれは場の側（位相の進み）にだけ現れ、それが読める傾斜になる。
4. **交換の回転（23/124）は格子の対称性でないので、格子に読むたびに丸めが起き、引き込み（ロック）が起こる。** 背景のゲージ（左、単位）と交換（右、23/124）の不整合が、α の窓を選ぶ側の候補。
5. R が奇数（3）であることは、格子の点が住民の S³ の上に乗る条件。R ＝ 3 では超立方体と内接 16 胞体の数が 137 ＝ 137 で一致する（R ＝ 5 では 1545 と 1673 で一致しない。R ＝ 7 以上は未確認）。

### 4.3 前の設計がここを外していた点

- 仕様 v0.1〜v0.3 と段 1〜5c は、600 胞体（二項正二十面体群）や連続の倍音を舞台にし、**R ＝ 3 の格子のゲージ（単位の 24 方向）を背景の等間隔の基準として使っていない**。舞台（どの群の上の等間隔か）と、粒子（R ＝ 3）と、背景の波が、別々のところに置かれていた。
- 600 胞体（120 の単位イコシアン）はフルヴィッツの 24 単位を含むが、二十面体の対称性（5 回）を持ち込み、Z4 と Z6 が共存する格子（結晶学的に許される整数の回転）とは別の構造になる。R ＝ 3 の系を使うなら、等間隔の基準は 24 単位（あるいはその格子の上の一歩）にそろえるべきだった。
