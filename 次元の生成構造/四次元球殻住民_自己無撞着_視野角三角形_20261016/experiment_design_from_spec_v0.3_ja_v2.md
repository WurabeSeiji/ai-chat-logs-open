## 1. 状態の表現：S³ の倍音の係数

- 住民の世界は S³（単位四元数の全体）。場 f(q) を S³ の調和関数で展開する。次数 n の調和関数の空間は次元 (n ＋ 1)² で、SU(2)_L × SU(2)_R の表現として**左の部分（次元 n＋1）と右の部分（次元 n＋1）の積**に分かれる（ピーター・ワイルの定理：S³ ＝ SU(2) の行列要素 D^{n/2}_{mm′}(q)）。
- 状態は各次数 n ＝ 0, 1, …, N の係数行列 C_n（(n＋1) × (n＋1) の複素行列）。N ＝ 18 で総数 2,470 成分（円周の住民の実験の最大次数と同じ）。
- 本当の二乗：Σz² ＝ ∫_{S³} f(q)² dq（共役をとらない）を係数の双線形形式として計算する。ノルム ∫|f|² は記録するが判定に使わない。
- 振幅は虚数方向（円周の住民と同じ）：f の各成分を iA で始める。

## 2. 演算（すべて係数の行列演算で厳密）

- **並進（左の掛け算、実数の角）**：f(q) → f(a⁻¹ q)、a ＝ exp(φ u)。係数は C_n → D^{n/2}(a) · C_n（左の添字だけを回す）。**任意の角 φ で誤差なく実装できる。** 一様で固定点がない（クリフォード平行移動）。
- **右の交換の回転（実数の角）**：f(q) → f(q b)、b ＝ exp(θ u_R)、θ ＝ πm/n。係数は C_n → C_n · D^{n/2}(b)ᵀ（右の添字だけを回す）。
- **ブースト（左の掛け算、虚数の角）**：a ＝ exp(iη u_L)。D^{n/2} を複素四元数（SL(2,ℂ)）へ正則に延長した行列で左の添字を回す。γ ＝ cosh η。Σz²（双線形）は保存、ノルムは保存しない（仕様 §5、10-16 確認済みの一点版を係数へ拡張）。
- 左と右は添字が別なので可換。並進とブーストは同じ左の側の実数の角と虚数の角。
- **奇偶が自動的に出る**：四元数 −1（対蹠点への移動、測地線の角 π の並進 exp(πu)）は次数 n の空間に (−1)ⁿ で作用する。**奇数次の倍音は対蹠点で符号が反転し、偶数次は同符号。測地線の角 2π（大円一周）で全次数が戻る。** 円周の住民の「奇数は二周、偶数は一周」（位相が半角 nφ/2 で進む）の S³ 版で、v1.1 第 6 章の「偶数成分は対蹠点に同符号、奇数成分は逆符号の山」と同じ。[10-16 訂正：初稿は「2π で反転、4π で戻る」と書いていたが、測地線の角では π で反転、2π で戻る]

## 3. 標本点（読み出しと数え上げ）

- 600 胞体の 120 頂点（単位イコシアン）：頂点そのものが群なので、頂点への左の掛け算は頂点の並べ替え。場の値の読み出し点、離散の並進の検査に使う。
- R ＝ 3 の殻（16 胞体の敷き詰め、表面 248 頂点・内部 8 頂点）と E₈：数え上げ（137、248、16 の種類）と、山の位置・欠損角の読み出しに使う。力学には使わない。

## 4. 段 1：一点の代数（v1 §2 と同じ、すぐ着手できる）

## 5. 段 2：倍音の表現と並進の資格審査（すぐ着手できる）

**問い**：係数の表現で、並進・交換の回転・ブーストが正しく実装されているか。

**検査（事前固定、すべて実装の正しさ）**
1. 並進の合成：角 φ₁ の並進の後に φ₂ ＝ 角 φ₁ ＋ φ₂ の並進（同じ軸）。係数の差 ≤ 10⁻¹²。
2. 奇偶：角 π の並進（対蹠点、四元数 −1）で、奇数次の係数が −1 倍、偶数次が不変。角 2π で全次数が不変。[10-16 訂正]
3. 左右の可換：並進（あるいはブースト）と交換の回転の順序を入れ替えて係数の差 ≤ 10⁻¹²。
4. 保存：並進・交換の回転で Σz² とノルムの両方が保存。ブーストで Σz² が保存しノルムは変わる。
5. 標本点との整合：係数から 600 胞体の頂点で場の値を計算し、頂点への左の掛け算（頂点の並べ替え）と係数の並進が同じ値を与える（誤差 ≤ 10⁻¹²）。
6. 有限位数：θ ＝ 2π·23/124 の交換の回転を 124 回で恒等（奇数次は符号に注意して記録）。

## 6. 段 3：局在した住民の並進と光円錐（段 2 の後）

**問い**：等振幅の倍音の和で局在した住民（山）を作り、並進させたとき、(a) 山の中心が並進の角どおりに動き、形（幅 ∝ 1/N）が崩れないか（位相の進みが次数に比例する場合）、(b) 質量に当たる項（進みが次数に比例しない部分、右の交換の回転）を入れると山が崩れ（分散）、有理数の時刻に戻るか（リバイバル）、(c) 同じ場の中に観測者の山を置き、粒子の山との交差項から v と 1/γ を読んだとき、v² ＋ (1/γ)² ＝ 1 が状態の読み出しとして成り立つか。

- 時間の刻みは外に置かない。観測者の山自身の位相の進み（ビートの数）を時計にする。[仕様 §9-6 の暫定の扱い、著者の確認待ち]
