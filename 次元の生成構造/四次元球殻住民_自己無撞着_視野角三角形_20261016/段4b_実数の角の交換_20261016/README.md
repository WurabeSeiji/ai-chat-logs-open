# 段 4b：読める側と読めない側の実数の角の交換（2026-10-16）

段 4a の論文の U_R（ユニタリ）は本当の二乗を保存しなかった。著者の確認（10-16）：交換は **R ＝ cos²θ の実数の角の回転**で、R はそれで決まる。段 4a からの変更はこの一点だけ。

## 走らせる前に固定したこと

- 交換：毎ステップ、全係数に (f_A, f_B) → (cos θ f_A − sin θ f_B, sin θ f_A ＋ cos θ f_B)。θ ＝ 23π/124（R ＝ cos²θ ＝ R_{124,23}）、対照 θ ＝ arccos √0.7（有限位数でない）。
- 初期状態・ブースト・記録は段 4a と同じ（A に粒子の住民、s₀ ＝ 0.01、η ∈ {0, 0.3}、248 ステップ）。
- **判定（実装の正しさ）**：(1) 本当の二乗 Σz²（A と B の和）の保存 ≤ 1e-12。(2) ノルムの保存 ≤ 1e-12。(3) θ ＝ 23π/124 で、124 ステップ後に −1 倍（回転角 23π）、248 ステップ後に初期状態（≤ 1e-12）。
- **記録**：配分差 S_k の時系列とその閉形式、A の場の形の変化。

## 結果

**判定（実装の正しさ）はすべて通過**：本当の二乗の保存（最大 2.0e-14）、ノルムの保存（2.0e-14）、θ ＝ 23π/124 で 124 ステップ後に −1 倍（3.3e-15）、248 ステップ後に初期状態（7.2e-15）。対照 θ ＝ arccos √0.7 は戻らない（0.18、0.39）。

**記録**
- 配分差 S_k は閉形式（回転した重みの二乗の差）と一致（5.4e-14）。**A と B の配分は −0.9998 〜 ＋0.9998 まで振れ、ほぼ完全に入れ替わる**。段 4a の U_R では振れが 0.02 の幅しかなかったのと対照的。
- A の場の形は変わらない（2.4e-14）。ブースト η ＝ 0.3 でも配分の振る舞いは同じ。

## 読み取れること

1. 実数の角の交換（R ＝ cos²θ）は本当の二乗を保存し、仕様の原則（閉塞は保存される）と両立する。周期は 2n ＝ 248（124 で −1 倍＝対蹠点）。
2. 交換は A と B の重みを完全に入れ替えながら回り、周期の半分で符号が反転する。読める側と読めない側のあいだを、状態が行き来し続ける形。
3. 交換は全ての倍音に同じように掛かるので、S³ の上の形（住民の位置と形、ブースト）とは切り離されたまま。交換と運動が結びつくのは、生成子に歪み（仕様 v0.3 §7、重力の対称な重み）が入り、交換の掛かり方が場の状態によって変わる段（段 5）になる。

## 確かめていないこと

- 歪み（重力の重み）を入れた自己無撞着な生成子での交換と運動の結びつき（段 5）。
