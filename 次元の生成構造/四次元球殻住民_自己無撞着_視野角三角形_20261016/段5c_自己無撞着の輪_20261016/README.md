# 段 5c：自己無撞着の輪（静止した粒子、2026-10-16）

著者の指摘（10-16）：曲率の総和への寄与の規則を新しく置くのではなく、場 → 幾何 → 生成子 → 固有モード → 場 の輪が閉じる状態を探す。空間の結合は左の生成子（並進・ブースト、γ の側）がもともと持ち、新しい項は足さない。歪みは左右の生成子に掛かる局所の重みとして入る：右（時計）に e^{−u}、左（空間）に e^{＋u}。

## 走らせる前に固定したこと

- 舞台：600 胞体の 120 頂点。状態は各頂点の A_p、B_p（240 成分の複素ベクトル）。幾何（辺・四面体・欠損角・ポテンシャル）は段 5a・5b のプログラムを無変更で複製して使う。
- **生成子 K**（実反対称、240×240）：
  - 右の時計：各点の A と B の交換（段 4b）に重み W_p ＝ 1 − u_p ＋ ½u_p²（e^{−u} の二次まで）を掛けたもの θ W_p。
  - 右の並進（時計の側の、場を運ぶ部分）：頂点の群の元 g（実部 φ/2 の単位イコシアン、隣の頂点）を右から掛ける置換 P_g から作る離散の微分 D ＝ (P_g − P_gᵀ)/2 を、A と B それぞれに、重み W で対称化して ½(W D ＋ D W) として入れる。係数 θ。
  - 左（空間の並進・運動）：**静止した粒子なので係数 0**（運動の項は入れない）。e^{＋u} の重みはこの段では使わない。
  - いずれも実反対称なので、K の固有モードは Σz² ＝ 0（インフレーション第 2 版の定理）。
- **輪**：
  1. 初期の場：頂点 0 に局在した山（段 5a と同じ、σ ＝ 0.6、s₀ ＝ 0.01）。
  2. 場から ρ_p ＝ A_p² ＋ B_p²、w_p ＝ 1 ＋ κ(|ρ_p| − ⟨|ρ|⟩)/⟨|ρ|⟩、辺の長さ、欠損角、曲率 s_p、ポテンシャル u（L u ＝ ＋(s − ⟨s⟩)、対蹠点で 0）、W_p。
  3. K を組み、固有ベクトルのうち、前の場とのエルミートの重なりが最大のものを新しい場とする（ノルム 1 に正規化）。
  4. 新しい場と前の場の差（重なりの 1 からのずれ）が 1e-10 未満になるか、200 回で止める。
  κ ∈ {0, 1e-4, 3e-4}。
- **判定（実装の正しさだけ）**：(1) K の実反対称（‖K ＋ Kᵀ‖ ＝ 0）。(2) 選んだ固有モードの |Σz²|/ノルム ≤ 1e-12。(3) κ ＝ 0 で W ≡ 1。
- **記録**：輪が収束したか（回数）、収束した状態の局在（中心での |ρ| の割合）、曲率のずれの総和（単極子）とその絶対値の和、u と W の距離による分布、固有値。

## 結果

**判定（実装の正しさ）はすべて通過**：K の実反対称、選んだ固有モードの |Σz²|/ノルム ≤ 3.6e-15（閉塞は固有モードの結果として成り立つ）、κ ＝ 0 で W ≡ 1。

| κ | 輪の収束 | 最後の変化 | 固有値 | 中心の |ρ| の割合 | |ρ| 最大の頂点 | 曲率のずれの総和（絶対値の和） |
|---|---|---|---|---|---|---|
| 0 | 2 回 | 0 | ±0.2402i | 0.136 | 118 | 6.5e-13 |
| 1e-4 | 200 回で未収束 | 2.2e-7 | ±0.5816i | 0.171 | 33 | 1.4e-5（0.22） |
| 3e-4 | 200 回で未収束 | 4.1e-6 | ±0.5795i | 0.128 | 118 | 1.3e-4（0.66） |

時計の重み W（中心からの角ごと）は単調でなく、0°・72°・144° で下がる（κ ＝ 3e-4 で 0.9965、0.9991、0.9989）。

**事後の確認（判定ではない）**：歪みのない K（κ ＝ 0）の固有値は 5 種類しかなく、それぞれ 24 重に縮退している（600 胞体の対称性）。

## 読み取れること

1. **単一の固有モードは局在した粒子にならない。** 頂点 0 に局在した山から始めても、選ばれた固有モードは S³ に広がり、|ρ| の最大は別の頂点（118 や 33）に移る。この K の固有モードは 600 胞体の対称性に沿って広がった定在波で、一点に局在した山は多くの固有モードの重ね合わせとしてしか作れない（倍音の和で局在を作った段 3 と同じ）。
2. **固有モードの選び方が定まらない。** 固有値が 24 重に縮退しているので、「前の場と重なりが最大の固有ベクトル」は縮退した空間の中の一つの向きにすぎず、輪が一つの状態に決まらない。κ ＞ 0 で歪みが対称性をわずかに破ると、輪は 1e-7〜1e-6 の変化で行き来し続け、200 回で収束しなかった。
3. 曲率のずれの総和は依然として絶対値の和の 1e-4 程度で、全体としての質量（単極子）は出ていない。

## 何が足りないか

- この K は、場の状態に歪みの重み W を通してしか依存しない。インフレーション第 2 版の自己無撞着な状態（親）は、生成子が状態の関係の位相そのもの（K_ef ＝ Im(z̄_e z_f)、交差項）から作られ、その非線形性で局在した固有モードが選ばれていた。粒子として局在した自己無撞着な状態を得るには、生成子に**場自身の交差項（関係の位相）**が入る必要がある。左右の掛け算と歪みの重みだけでは、生成子が対称性で決まってしまい、状態を選ぶ力が弱い。
