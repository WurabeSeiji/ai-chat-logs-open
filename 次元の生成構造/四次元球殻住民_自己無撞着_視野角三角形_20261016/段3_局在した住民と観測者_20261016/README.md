# 段 3：局在した住民と観測者（2026-10-16）

設計書 v2 §6 に、10-16 の著者決定を反映：(1) ブーストは毎ステップ掛けず、**一度だけ（観測者の取り替えとして）**掛ける。(2) 時計は外に置かず、**観測者の山自身の位相の進み**で数える。共通モジュール `s3_harmonics.py` は段 2 から無変更で複製（`SHA256_copied_module.txt`）。

## 走らせる前に固定したこと

**住民（局在した波）**：中心 q₀ の等振幅の倍音の和 f(q) ＝ iA Σ_{n=0}^{N} χ_n(q₀⁻¹q)、χ_n は次数 n の指標（tr D_n）。N ＝ 12。中心 q₀ で鋭い山、幅は 1/N 程度。粒子の山を q₀ ＝ 1、観測者の山を q₀′ ＝ exp(0.9 j)（測地線の角 0.9 離れた点）に置く。

**時間の進め方**：場全体（粒子と観測者の両方）に右の交換の回転 b ＝ exp(θ i)、θ ＝ 2π·23/124 を毎ステップ掛ける。時刻は「観測者の山の位相が何回進んだか」で数える（外部の時計は置かない）。

**試験 (a) 並進**：k ステップ後の場が、中心を q₀ b^{−k} に移した住民と一致するか（係数の相対差）。248 ステップ。

**試験 (c) 観測者による読み出し**：粒子の山に一度だけブースト Λ(η) ＝ exp(iη u)（u ＝ i, j, k）を左から掛ける。η ∈ {0, 0.05, 0.1, 0.2, 0.3}。観測者の山 g との交差項 X(η) ＝ B(Λf, g)（本当の二乗の双線形形式）を、次数ごと X_n(η) と全体で記録し、X(η)/X(0) を cosh η（＝γ）と並べる。粒子自身の本当の二乗 B(Λf) が η によらないことも記録。

**判定（実装の正しさだけ、事前固定）**
1. (a) 係数の相対差 ≤ 1e-12（全ステップ）
2. (c) B(Λf) の η による相対変化 ≤ 1e-12（η ≤ 0.3、N ＝ 12 は段 2 の事後診断で倍精度の範囲内）
3. (c) 時計：観測者の山の位相は右の回転で毎ステップ θ 進み、124 ステップで元に戻る（係数の相対差 ≤ 1e-12）

**記録のみ（成功条件にしない）**：X(η)/X(0) と cosh η の関係、次数ごとの X_n(η) の振る舞い、粒子と観測者の相対位置による違い。

**この段に入れないもの**：分散（質量項）を倍音の位相の進みとして手で入れること（例えば ω_n ＝ √((n＋1)² ＋ μ²)）。質量は外から置かず左右の交差項として読む、という原則（仕様 v0.3 §6）に反するため、設計書 v2 §6 (b) はこの段から外した。

## 結果

**判定（実装の正しさ）はすべて通過。**

| 判定 | 値 |
|---|---|
| 1 (a) 並進：k ステップ後の場 ＝ 中心を q₀b^{−k} に移した住民（248 ステップ） | 最大相対差 5.9e-14 |
| 2 (c) 粒子自身の本当の二乗 B(Λf) が η によらない | 最大 2.7e-15 |
| 3 時計：観測者の山が 124 ステップで元に戻る | 3.9e-14 |

住民の山：粒子の中心で f ＝ 91i（＝ Σ(n＋1)、N ＝ 12）、観測者の位置で −0.021i。観測者の山も自分の中心で 91i。

**記録（成功条件ではない）：観測者との交差項 X(η) ＝ B(Λf, g) の比 X(η)/X(0)**

| ブーストの向き | η ＝ 0.05 | 0.1 | 0.2 | 0.3 | cosh η（＝γ） |
|---|---|---|---|---|---|
| i（観測者の方向に直交） | 1.00171 | 1.00696 | 1.02977 | 1.07425 | 1.00125 / 1.00500 / 1.02007 / 1.04534 |
| j（観測者の方向） | 0.977＋0.086i | 0.900＋0.172i | 0.437＋0.326i | −1.151＋0.276i | 同上 |
| k（観測者の方向に直交） | i と同じ | | | | |

次数ごとに分けると（η ＝ 0.3）：
- **次数 1（四元数そのもの、四元ベクトル）では、実部がちょうど cosh η ＝ γ**。直交する向き（i, k）では X₁(η)/X₁(0) ＝ cosh η（＝1.0453）、観測者の方向（j）では cosh η ＋ i sinh η tan 0.9（＝ 1.0453 ＋ 0.3837i、0.9 は粒子と観測者の測地線の角）。四元ベクトルのミンコフスキー内積がブーストで変わる形そのもの
- 次数 0 は 1（ブーストに不変）
- 次数 2 以上は γ と一致しない（直交する向きで 1.263, 0.716, 0.973, 1.190 …）。高い次数ほどブーストの e^{nη} 程度の成分が混ざる

## 読み取れること

1. 局在した住民（倍音の和）は、右の交換の回転で形を崩さず並進し、観測者の山は 124 ステップで元に戻る。外部の時計を置かずに、観測者自身の位相の進みで時刻を数えられる。
2. 観測者との交差項の中で、**ローレンツ因子 γ がそのまま読めるのは次数 1 の成分だけ**。全体の交差項は次数の和なので、γ より大きく（直交する向き）、あるいは複素で振動する（観測者の方向）。局在した山（多くの次数の和）では、交差項の比は γ にならない。
3. 次数 1 の成分で、観測者の方向へのブーストは cosh η に虚部 sinh η tan(角) が加わる。粒子と観測者の位置関係（角）が交差項の位相として現れる。

## 確かめていないこと

- 交差項から v と 1/γ を別々に読む読み出しの形（今回は比 X(η)/X(0) だけ）。次数 1 の成分を取り出す読み出しが、観測者にとって自然な手続きかどうか。
- 質量（左右の交差項）を持つ住民。今回の住民は右の回転の片側だけで、質量を持たない形。
