# 段 5a：欠損角による歪みと時計（静止した粒子、2026-10-16）

著者の決定（10-16）：重力の重みは**欠損角**から作り、**三角形（正四面体）**で読む。段 4b の実数の角の交換（R ＝ cos²θ、θ ＝ 23π/124）を、各点で局所の重みを掛けた角 θ_p ＝ W_p θ で行う。

## 舞台と状態

- S³ を正四面体で埋めた 600 胞体：頂点 120（単位イコシアン）、辺 720、正四面体 600。歪みがなければ各辺の周りに 5 個の四面体、欠損角 7.3561°（一様な正の曲率）。
- 状態：各頂点 p に読める側 A_p と読めない側 B_p（複素数、虚数方向の振幅）。段 4b の場を頂点の値で持つ形（各点ごとの交換を掛けるため）。
- 粒子：頂点 0 を中心とする局在した山 A_p ＝ i√(½＋s₀) e^{−d_p²/σ²}、B_p ＝ i√(½−s₀) e^{−d_p²/σ²}（d_p は頂点 0 からの測地線の角、σ ＝ 0.6、s₀ ＝ 0.01）。

## 歪みの規則（この段で置いた仮定、判定ではない）

1. **局所の本当の二乗** ρ_p ＝ A_p² ＋ B_p²（各点の交換で不変）。
2. **辺の長さ**：ℓ_pq ＝ d_pq · ½(w_p ＋ w_q)、w_p ＝ 1 ＋ κ (|ρ_p| − ⟨|ρ|⟩)/⟨|ρ|⟩。κ は歪みの強さ（重力の結合に当たる自由な数）。κ ∈ {0, 0.02, 0.05, 0.1}。
3. **欠損角**：各四面体を辺の長さから平らな四面体として作り、各辺の周りの二面角の和を 2π から引いたもの δ_e。
4. **頂点の曲率** K_p ＝ Σ_{p を端とする辺} δ_e ℓ_e ／ Σ ℓ_e（辺の長さで重みを付けた欠損角の平均）。歪みなしの値 K₀ ＝ 7.3561°。
5. **時計の重み**：u_p ＝ (K_p − K₀)/K₀、W_p ＝ 1 − u_p ＋ ½u_p²（e^{−u} の二次まで、EIH の静的項と同じ形）。曲率が大きいところで時計が遅れる向き。
6. **発展**：毎ステップ、各頂点で (A_p, B_p) を実数の角 W_p θ だけ回す（直交、各点の本当の二乗とノルムを保つ）。248 ステップ。

## 判定（実装の正しさだけ、事前固定）

1. κ ＝ 0 で全ての辺の欠損角が 7.3561°（±1e-9）、全ての W_p ＝ 1。
2. 全 κ で、本当の二乗 Σ_p (A_p² ＋ B_p²) とノルムが保存（相対 ≤ 1e-12）。
3. 各点の ρ_p が発展で不変（相対 ≤ 1e-12）。

## 記録（成功条件にしない）

- 粒子の中心（頂点 0）と最も遠い点（対蹠点）での曲率 K_p と W_p。
- 時計の進みの比：頂点 0 での交換の位相の進み ÷ 対蹠点での進み（248 ステップ平均）。κ による変化。
- 欠損角の分布（最小・最大）。

## 読み取れること

1. **場が集まったところで曲率が増え、時計が遅れる。** 粒子の中心では、場の本当の二乗が作る物差しの伸び（w_p）の勾配によって欠損角が大きくなり（正の曲率が集中）、時計の重み W が 1 より小さくなる。展開の範囲内（κ ≤ 3e-4）で、中心の時計は対蹠点に比べて 4〜11% 遅れる。向きは重力による時計の遅れ（重力赤方偏移）と同じ。
2. **曲率の集中の周りに、曲率が減る環ができる。** 欠損角の最小値が歪みなしの 7.356° より小さくなり、そこで W が 1 よりわずかに大きい（時計がわずかに速い）。集中した正の曲率を周りの負の変化が補う形。全体の曲率の総和がどれだけ保たれるかは、まだ数えていない。
3. 時計の遅れは、規則 5（W ＝ e^{−u} の二次まで）で曲率を時計に写すところで置いた。**場 → 物差し → 欠損角 → 曲率** の部分は三角形から計算で出たもので、曲率が場の集まったところで増えるという向きは置いたものではない。

## 置いた仮定（判定ではない）と、確かめていないこと

- 物差しの伸び w_p を局所の本当の二乗 |ρ_p| から作る式と、その強さ κ（重力の結合に当たる）。
- 曲率を時計に写す W ＝ e^{−u}（二次まで）。
- 粒子が静止している場合だけ。各点の交換は ρ_p を変えないので、歪みは時間で変わらない。粒子が動いて歪みが場と一緒に更新される自己無撞着な発展（段 5b）はまだ。
- 曲率の総和の保存、連続極限での一般相対論の値（時計の遅れと質量・距離の関係）との比較。
