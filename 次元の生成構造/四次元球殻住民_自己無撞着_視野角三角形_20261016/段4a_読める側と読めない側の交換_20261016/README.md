# 段 4a：読める側と読めない側の交換（2026-10-16）

著者の決定（10-16）：読める側 A と読めない側 B を、有限位数共鳴の論文の交換作用素 U_R（反射率 R、二つの通り道のあいだの分配）で結ぶ（設計の候補 1）。

## 走らせる前に固定したこと

- 状態：A の場 f_A と B の場 f_B（S³ の倍音の係数、N ＝ 12）。共通モジュールは段 2 から無変更で複製。
- 交換：毎ステップ、全係数に同じ U_R を掛ける：(f_A, f_B) → (r f_A ＋ t f_B, t f_A ＋ r f_B)。t ＝ e^{iθ}cos θ、r ＝ −i e^{iθ} sin θ、θ ＝ arcsin √R（論文 §2.1 と同じ定義）。R ＝ R_{124,23} ＝ cos²(23π/124)、対照 R ＝ 0.7（有限位数根でない）。
- 初期状態：A に粒子の住民（中心 1、f ＝ i Σ D_n(q)[0,0]、段 3c と同じ）を置き、論文の System B と同じく配分差 s₀ ＝ 0.01（A に √(½＋s₀)、B に √(½−s₀) の重み）。A の粒子にだけ最初に一度ブースト Λ(η)（u ＝ i、η ∈ {0, 0.3}）。
- 248 ステップ。記録：A と B のノルムの配分差 S_k ＝ (|f_A|² − |f_B|²)/(|f_A|² ＋ |f_B|²)、本当の二乗 Σz²（A と B の B(·) の和）、A の場の形（係数を全体の重みで割った形）が初期の形からどれだけ変わるか。
- **判定（実装の正しさだけ）**：(1) ノルム（|f_A|² ＋ |f_B|²）の保存 ≤ 1e-12。(2) R ＝ R_{124,23} で 124 ステップ後に初期状態へ戻る ≤ 1e-12。
- **記録**：本当の二乗の振る舞い。S_k が論文の閉形式 S_k ＝ 0.02 cos[k(π ＋ 2 arcsin √R)] と一致するか。A の場の形が交換で変わるか（交換が場所に依らないなら形は変わらないはず）。

## 結果

**判定（実装の正しさ）はすべて通過**：ノルムの保存（最大 2.6e-14）、R ＝ R_{124,23} で 124 ステップ後に初期状態へ戻る（3e-15。対照 R ＝ 0.7 は戻らず 2〜3e-3）。

**記録**
- 配分差 S_k は論文の閉形式 0.02 cos[k(π ＋ 2 arcsin √R)] と全条件で一致（最大差 5e-15）。**有限位数共鳴の論文の System B が、S³ の場の上でそのまま再現された。**
- **A の場の形は交換でまったく変わらない**（初期の形からのずれ 1e-15）。ブースト η ＝ 0.3 を掛けても S_k は同じで、変わるのは本当の二乗の大きさだけ。
- 本当の二乗 Σz² は保存しない：|Σz²| が相対 2.0e-4 の幅で振れる（R によらずほぼ同じ）。U_R はユニタリでノルムを保つが、反対称の成分（A − B）を毎回 −e^{2iθ} 倍するので、その二乗の位相が回る。初期の配分差 s₀ ＝ 0.01 が小さいので振れも小さい。

## 読み取れること

1. **場所に依らない交換は、幾何と完全に切り離される。** U_R は全係数に同じように掛かるので、場は「交換の部分（A と B の重み）」と「幾何の部分（S³ の上の形）」の積に分かれたまま進む。読める側と読めない側の分配は論文どおりの周期 124 で回るが、運動（並進・ブースト）とは関係しない。質量が B 側、運動が A 側に分かれて読める、という形にはならなかった。
2. **論文の U_R は本当の二乗を保存しない。** 交換を本当の二乗の閉塞と両立させるには、U_R ではなく、A と B を実数の角で回す直交の交換（cos²φ ＝ R）にする必要がある。これは仕様 v0.3 の原則（閉塞は保存される）に関わる選択で、著者の判断が要る。
3. 交換と幾何が結びつくには、交換の強さ R が場所や状態に依存する必要がある。例えば、各点で読んだ場の比（A と B の本当の二乗の比）から R を決め、その R で交換する（自己無撞着）。これが仕様の「K は状態から作る」に当たり、段 4b の中身になる。

## 確かめていないこと

- 状態から R を読む交換（段 4b）。R の読み方は著者の判断が要る。
- 実数の角の直交の交換で本当の二乗を保つ形。
