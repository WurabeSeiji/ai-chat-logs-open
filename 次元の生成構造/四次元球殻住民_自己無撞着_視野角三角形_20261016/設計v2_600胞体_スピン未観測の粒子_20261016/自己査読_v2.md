# 自己査読 v2（2026-10-16）

設計書 v2（v1 の模型と合格基準のまま、粒子の定義と S4 の選び方だけを変更）の走行を、v1 と同じ手順で判定する。

## 2. 骨格に照らした結果の読み

1. **閉塞は結果として出る。** 実の反対称な K のもとで、正の振動数の状態はどれも Σψ² ＝ 0 で、時間発展（非線形な Φ の更新を含む）でも一段ごとに厳密に保たれる。負の振動数を混ぜると閉じない（S1 の対照で 0.020）。
2. **等間隔のゲージは群そのもの。** 左の掛け算の置換と生成子の指数が 10⁻¹⁵ で一致する。運動の生成子はこのゲージと可換で、運動量は保存する。
3. **並進と時計は一つの回転の配分。** 右の交換がカイラリティを混ぜることで、速さ v と時計 1/γ が分かれ、モードの中で v² ＋ (1/γ)² ＝ 1 が厳密に成り立つ。ゲージの目盛で読んだ波束の速さは予算の比と 0.05 以内で一致する。運動量 0 の波束も時計は進み（1/γ ＝ 0.30）、広がりながら S³ の反対側に集まり直す。止まった粒子は現れない。
4. **局在した波が背景を伸ばし、時計が遅れる。** 伸びは質量密度から Φ を経て、左の生成子の √(N/s) と右の交換の hN にだけ入る。外から掛ける演算子はない。時計の比は源に近いほど小さい。
5. **三角形が局所の曲率を決め、全体が打ち消す。** 四面体の辺の欠損角の変化は、同じ伸びから計算した連続の曲率と相関 0.92 で一致し、総和は絶対値の和の 0.3% に収まる。
6. **自己無撞着な基底は、結合が弱いと広がっている。** κ ≤ 30（G ＝ 1 の κ ＝ 4π を含む）では、自己無撞着な最低の準位は S³ 全体に一様に広がる。骨格 U047 の「観測されなければ広く広がる」と同じ姿である。局在した自己無撞着状態は κ ＝ 100 で現れるが、そのとき |Φ| は 1 を超え、二次までの展開の範囲の外にある。
7. **二体は引き合う。** 対照との距離の差は κ に比例し、符号で反転する。

## 3. 外から手で入れた部品と、残る限界

- **粒子の局在は初期条件。** 頂点に局在した波束から出発している。局在は自己無撞着からは出ない（上の 6）。骨格では局在は観測の側の出来事なので矛盾はしないが、局在そのものはこの模型の結果ではない。
- **分解能 N ＝ 5。** 600 胞体が厳密に表せるのは 5 次までで、骨格 U048 が局所の閉塞に効くとした N ＝ 10〜100 に届かない。波束は β ≈ 2 で S³ 全体に広がり、位置の読み（密度の平均ベクトル）は大きさが 0.03 まで落ちて壊れる（補足 S5b）。判定時刻 β ＝ 1.25 では大きさが 0.38（電子役）・0.52（陽子役）で、読みは有効だった。二体の結果は短い時間の線形応答で、軌道や束縛は見ていない。
- **質量比 2。** 右の交換の一歩あたりの角 θ ＝ h·36° が π/2 を超えないように、陽子役を 2 倍の質量にとどめた。陽子と電子の比 1836 は、この分解能では表せない。
- **κ は自由な定数。** 掃引して比例を確かめたが、値は決めていない。
- **θ ＝ 23π/124 は設定値。** 模型の中で R ＝ cos²θ ≈ 0.7 を選ぶ仕組みは現れない（設計どおり、探していない）。
- **位置と距離の読み**は、密度の平均ベクトルと S³ 上の測地距離で、住民の視野角からの読みではない。
- **扱っていないもの**：無限遠の吸収体と記録の空隙、電荷（ホップの巻き数）と電磁的な交換、α のロック（設計書 §5）。

## 4. 著者の判断が要る点

**U149 の「右＝交換、左＝γ」の割り当て。** この模型では次の三つを分けている。

| 演算 | 何に掛かるか | 役割 |
|---|---|---|
| 左の平行移動 P_g（q → gq） | 位置 | 等間隔のゲージ。力学の対称性。γ はこの目盛の伸びとして入る |
| 右の平行移動の微分 Y_i（q → q e^{uε}） | 位置 | 運動の生成子。左のゲージと可換にするために右の側を使う |
| 交換 M | 波の値（4 成分） | 右の交換。強さ h、一歩あたりの角 θ、R ＝ cos²θ |

U149 の「右から掛ける ＝ 交換」を、位置の右の掛け算ではなく、値の側の回転として実装した。位置の右の掛け算は、運動の生成子に使っている。この割り当てが著者の意図と合っているかは、ここでは決められない。

## 5. 結論

v2 は、設計書の合格基準をすべて満たした。基準を満たさない段は残っていないので、自己査読の繰り返しはここで止める。次に進めるかどうかは、上の限界（分解能、局在が初期条件であること、質量比、吸収体と電荷）と第 4 節の割り当てについて、著者の判断を受けてから決める。
