## 2. 不合格の原因

1. **S3：源の波束が非等方。** 時計の比は各点の Φ にほぼ比例していた（比 − 1 ≈ 0.87 Φ）。逆転は Φ そのものの逆転（60° の点で −0.0022、72° の点で −0.0030）から来ている。源の波束は、頂点のデルタ関数にスピンの向き η ＝ (1,1,1,1)/2 を一つだけ掛けて作った。そのため質量密度が頂点のまわりで回転対称にならず、同じ距離の殻の中で Φ がばらつく。時計の機構の失敗ではなく、源の作り方の失敗である。
2. **S4：選び方の規則に原理がない。** 「直前の状態と重なりが最大のモード」を選んだ。どの準位も 2 重に縮退している（クラマース対。Γ ＝ A₁A₂A₃M が K と反可換で、Γ と複素共役の組が K と可換になる。乱数の Φ でも 91 組すべてが対になる）。そのため、対の中の組み合わせが動く中立な方向が残り、収束が止まる。さらに、重なり最大の規則は、出発点の局在した波束が多く含む高い準位（ω ≈ 4.10）に状態を留め、基底を選ばない。

## 3. 外から手で入れた部品の点検（照合表の各行）

- **スピンの向き η の固定**：骨格のどこにもない選択で、S3 の非等方と S2 の系統的なずれ（運動量 0 でも v_read が ＋0.08）の原因の候補。観測していない粒子のスピンは決まっていない、と読むのが骨格（U047 の「観測されなければ広がっている」）に沿う。
- **κ（重力の結合の強さ）**：自由な定数として掃引している。G ＝ 1 の単位なら κ ＝ 4π だが、v1 では固定していない。合否には使っていないので、v2 でも掃引のまま残す。
- **θ ＝ 23π/124**：設計書どおりの設定値で、探索していない。
- **位置の読み**：密度で重みを付けた点の平均を正規化したもの。S³ の上の測地距離で比べているが、住民の視野角からの読みではない。読出しの近似として記録する。
- **γ を演算子として外から掛けていないか**：掛けていない。γ は質量密度 → Φ → 左の生成子の伸び √(N/s) と右の交換の hN、の経路だけで入る。
- **閉塞を条件として課していないか**：課していない。全段で Σψ² ＝ 0 は、正の振動数の状態と直交な時間発展の結果として出ている。
- **静止した粒子を前提にしていないか**：S2・S5 の波束は運動量 0 でも内部の時計（右の交換のビート、1/γ ≈ 0.30）が進み、広がりながら動く。S4 の固有モードの選び方だけが、静止した状態を探す形になっている。v2 では S4 を基底の準位（閉殻）の自己無撞着として定義し直し、動く状態の自己無撞着は S5 の時間発展で見る、と役割を分ける。

## 4. v2 への修正（原因に対応するものだけ）

1. **粒子はスピンを観測していない混合状態とする。** 頂点のデルタ関数に 4 つのスピンの向き η ＝ e₁〜e₄ を掛け、それぞれ正の振動数に射影して等しく混ぜる。密度・質量密度・速さの読みは混合の和で取る。すべての段（S2・S3・S4・S5）で同じ粒子の定義を使う。
2. **S4 の選び方は、最も低い正の振動数の準位を、クラマース対ごと占める（閉殻）。** 閉殻の密度は対の基底の取り方によらないので、中立な方向がなくなる。出発点の Φ は v1 と同じく局在した波束から作る。
3. 合格基準は v1 と同じものを使う（S4 も「全 κ で収束し、Σψ² ＝ 0」）。

S0・S1 は粒子の定義に依存しないので、v2 でも同じ結果になるはずである。全段を v2 のプログラムで走らせ直す。
