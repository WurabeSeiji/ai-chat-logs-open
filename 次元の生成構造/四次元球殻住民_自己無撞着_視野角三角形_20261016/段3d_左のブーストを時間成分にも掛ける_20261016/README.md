# 段 3d：左のブーストを時間成分にも掛ける（2026-10-16）

段 3c で、時計（右の交換の回転）の進みはブーストに依らず、時計の遅れが出なかった。原因は、時計の目盛りを全員共通のステップ数（絶対時間）で数え、時間を読める側の四元数 A ＝ t ＋ x i ＋ y j ＋ z k の成分として扱っていなかったこと。著者の指示（10-16）：**左から空間方向にブースト（γ）を掛けるなら、時間方向にも左から掛ける。**

## 走らせる前に固定したこと

- 粒子の内部時計：右の交換の回転（θ_p ＝ 2π·23/124、段 3c と同じ）。刻み k ごとに位相が θ_p 進む（次数 1 の成分）。
- 刻み k の出来事を、粒子の静止系で読める側の四元数 A_k ＝ (i_c·kΔ)·1 ＋ 0·i ＋ 0·j ＋ 0·k に置く。i_c は複素単位、実部の係数が i_c·t（閉包の (it)² の t）、Δ ＝ 1。空間成分は 0（静止）。
- 観測者の取り替え：A_k に左からブースト Λ(η) ＝ exp(iη u)（u ＝ i, j, k、η ∈ {0, 0.1, 0.3, 0.6, 1.0}）を掛ける：A′_k ＝ Λ A_k。
- 観測者の読み：時間 t′_k ＝ A′_k の実部の i_c の係数、位置 x′_k ＝ A′_k の u 成分の実数の係数。
- 観測者の時計で測った粒子の時計の周波数 ω′ ＝ θ_p／(t′_{k+1} − t′_k)。静止の周波数 ω₀ ＝ θ_p／Δ。速さ v′ ＝ (x′_{k+1} − x′_k)／(t′_{k+1} − t′_k)。
- **判定（実装の正しさだけ）**：(1) 本当の二乗 A′_kᵀA′_k ＝ A_kᵀA_k（不変な間隔 −(kΔ)²）が保存（相対 ≤ 1e-12）。(2) 右の時計の回転と左のブーストが可換（四元数の順序を入れ替えて差 ≤ 1e-12）。
- **記録**：ω′/ω₀ と 1/cosh η、v′ と tanh η、ω′/ω₀ と √(1 − v′²)。

## 読み取れること

1. **左のブーストを時間成分にも掛けると、時計の遅れがそのまま出る。** 粒子の時計の一刻みは、粒子の静止系で読める側の四元数の時間成分（実部の i_c t）に置かれた出来事で、左からのブーストはその時間成分と空間成分を混ぜる（t′ ＝ γt、x′ ＝ −γvt）。観測者の時計で測ると、粒子の時計の周波数は 1/γ 倍、速さは tanh η。時計の進みと速さの関係は √(1 − v′²) ＝ 1/γ。
2. **右の時計（交換の回転、内部の位相）とブーストは可換のまま。** 粒子自身の時計の一刻みあたりの位相の進み（固有時）は速さに依らない。遅れて見えるのは、観測者の時間の目盛り（左の四元数の時間成分）で測るから。段 3c で遅れが出なかったのは、観測者の時計を左の四元数の時間成分ではなく、全員共通のステップ数にしていたため。
3. 役割の分担：**右＝固有時（内部の位相の進み、ロックと α の側、速さに依らない）**、**左＝観測者の時間と空間（ブーストで混ざる、γ が掛かる）**。

## 注意（何を確かめたか）

- この段で確かめたのは、時計の刻みを読める側の四元数の時間成分に置けば、左からのブーストで時計の遅れが式どおりに出る、という左右の役割の組み立てである。ローレンツ変換の代数そのものは既知で、ここに新しい物理の予言はない。
- 時計の刻みの出来事を「時間成分に置く」ことは、この段で手で置いた。どの成分が時間か（観測写像の選び方）は仕様 v0.3 §1 の読み方による。これを場（倍音の住民）の自己無撞着な状態から出すことは、まだしていない。
