# 段 1：一点の代数（2026-10-16）

設計書 `../experiment_design_from_spec_v0.3_ja_v2.md` §4（判定は v1 §2）。一つの複素四元数に、右の交換の回転 exp(θR_u)（実数の角）と左のブースト exp(iηL_w)（虚数の角）を同時に掛ける。生成子 G ＝ θR_u ＋ iηL_w、初期状態は G の固有ベクトル、exp(G) を 2n 回掛ける。θ ＝ 2π·23/124（対照 2π/4、2π/6）、u, w ∈ {i, j, k} の 9 通り、η ∈ {0, 0.3, 0.8, 1.5}、記録 432 件。

## 結果（事前固定の判定どおり）

| 判定 | 結果 |
|---|---|
| (a) Σz² の変化／初期ノルム ≤ 1e-13 | **η ＝ 0 は成立（最大 2.9e-15）、η ≠ 0 は不成立**（下の注） |
| (b) η ＝ 0 で n 回後に戻る（≤ 1e-12） | 成立（最大 4.8e-15） |
| (b) η ≠ 0 で戻らない | 成立（最小のずれ 0.70） |
| (c) 右の回転の固有位相が η によらない | 成立：G の固有値は ±η ± iθ（θ ＝ 1.16543）。虚部（右の回転の位相）は η によらず、実部 ±η が左のブーストの伸縮 |
| (d) v_read・1/γ_read（記録のみ） | すべての固有ベクトルで v_read ＝ ±1、1/γ_read ＝ 0 |

## 判定 (a) の不成立について

事前に固定した基準は、Σz² の変化を**初期の**ノルムで割っていた。ブーストの固有ベクトルは毎回 e^{±η} 倍に伸縮する（固有値の実部 ±η）ので、248 回で e^{±74}〜e^{±372} になり、浮動小数点の丸め誤差（そのときのノルムに比例）を初期ノルムで割った値は意味を失った（一部はオーバーフロー）。**基準の書き方の誤りで、事前固定の判定としては不成立のまま記録する。**

事後診断（判定ではない、`stage1_posthoc_relative_closure.py`）：Σz² をそのときのノルムで割ると、
- 伸びる固有ベクトル（実部 ＋η）：最大 4.0e-16。閉塞は保たれている
- 縮む固有ベクトル（実部 −η）：0.12〜0.99。丸め誤差で混入した「伸びる」成分が e^{2ηk} で増え、縮む成分を追い越すところで、二つの零ベクトルの和になり Σz² がノルムと同じ大きさになる

ブーストは光円錐の二つの零方向の一方を伸ばし他方を縮める（双曲的）ので、縮む側は数値的に不安定である。これは実装の誤りではなく、ブーストを毎回掛け続ける設計（加速を続けることに当たる）から出た性質。

## 読み取れること

1. 一つの固有モードは、右の回転の片方の向きだけを持つ（v_read ＝ ±1、1/γ_read ＝ 0）。交差項を持たないので、読み出しでは質量ゼロ・光速になる。質量（交差項）を読むには二つ以上のモードの重ね合わせが要る。円周の住民で「一つの波は自明でない閉塞を持たない」とした事実と同じ形。
2. 右の交換の回転は有限位数で閉じ、ブーストはその周期を変えない（固有値の虚部は η によらない）。左右が独立であることは代数として確認された。
3. ブーストを毎ステップ掛けるのは「速さ一定」ではなく「加速し続ける」ことに当たる。速さ一定の状態は、ブーストを一度だけ掛けた（観測者を取り替えた）状態として扱うべきで、段 3 の設計で直す必要がある。

## 確かめていないこと

- 二つのモードの重ね合わせでの v、1/γ の読み出し（段 3 で扱う）。
- 縮む側の不安定を避ける数値の扱い（多倍長、あるいはブーストを一度だけ掛ける設計）。
