# 段 2：倍音の表現と並進の資格審査（2026-10-16）

設計書 `../experiment_design_from_spec_v0.3_ja_v2.md` §5。S³ の倍音（調和関数）の係数で場を持ち（N ＝ 18、総 2,470 成分、乱数種 20261016）、並進（左の掛け算、実数の角）・交換の回転（右の掛け算）・ブースト（左の掛け算、虚数の角）を係数の行列演算で実装した（`s3_harmonics.py`）。検査は事前固定、基準はすべて 10⁻¹² 以下（実装の正しさ）。

## 不通過の原因（事後診断 `stage2_posthoc_boost_conditioning.py`、判定ではない）

- **検査 5（走行 1）**：600 胞体の頂点座標を 9 桁に丸めていた実装の誤り（|N(p) − 1| ＝ 8e-10）。丸めをやめて走行 2 で通過。
- **検査 3・4 のブースト**：式の誤りではなく倍精度の条件の問題。ブーストは次数 n の空間でノルムを e^{nη} 程度に伸ばし（η ＝ 0.8、N ＝ 18 で 3.1e10 倍）、丸め誤差は伸びたノルムに比例する。B の相対誤差は「2.2e-16 × 伸び × H/|B|」で予測される大きさに一致し、η ＝ 0.1 では全次数で 5e-15、η ＝ 0.3・N ≤ 12 で 3e-14。可換性の差を係数の最大値で割ると全条件で 2〜4e-16（機械精度）。**ブーストの実装は正しく、倍精度では大きい η と高い次数の組み合わせで精度が落ちる。**
- **検査 6**：124 回の積み重ねの丸め。次数ごとの相対誤差の最大は 3.9e-13。基準 1e-12 をわずかに超えたのは絶対値で測ったため。

## 確かめたこと

- 並進（クリフォード平行移動）は任意の角で係数の回転として正確に実装できる（合成、可換、保存、600 胞体の頂点の並べ替えとの一致）。
- 奇偶は表現から自動的に出る：対蹠点（角 π）で奇数次の倍音は符号が反転し、偶数次は同符号。大円一周（2π）で全次数が戻る。交換の回転 23/124 は 62 回で四元数 −1（対蹠点）、124 回で恒等。
- ブーストは本当の二乗を保存しノルムを保存しない（η が小さい範囲で機械精度、大きい範囲は条件の問題）。

## 確かめていないこと・次の段への申し送り

- 大きい η と高い次数のブーストを扱うには、多倍長（mpmath）か、ブーストを状態に掛けずに観測者の側の読み替えとして扱う設計が要る。段 1 で分かった「ブーストを毎回掛けるのは加速し続けることに当たる」とあわせ、段 3 では**ブーストは一度だけ（観測者の取り替えとして）掛ける**設計にするのが筋。
- 段 3 の時計（観測者の山の位相の進みを時計にする）は著者の確認待ち。
