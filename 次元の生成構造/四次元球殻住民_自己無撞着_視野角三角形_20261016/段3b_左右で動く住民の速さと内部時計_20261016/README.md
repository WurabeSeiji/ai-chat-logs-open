# 段 3b：左右で動く住民の速さと内部時計（2026-10-16）

段 3 の申し送り「質量を持つ住民（左右の交差項）を作り、その質量と速さを読む」。共通モジュール `s3_harmonics.py` は段 2 から無変更で複製。

## 走らせる前に固定したこと

**発展の規則**：毎ステップ、場全体に q → a·q·b を掛ける。右 b ＝ exp(θ_R i)、θ_R ＝ 2π·23/124（交換の回転、仕様 v0.3 §5）。左 a ＝ exp(−θ_L i)（右と同じ軸で逆向き、実数の角）。θ_L ∈ {θ_R, 0.75θ_R, 0.5θ_R, 0.25θ_R, 0}。
- θ_L ＝ 0：右だけ（段 1 で質量ゼロだった片側の形）
- θ_L ＝ θ_R：左右が釣り合い、点 1 を動かさない共役 a q ā（仕様 §5 の「両側同じ」、実部を固定して向きだけ回す）

**住民**：中心 1 の、向きの偏った局在波 f(q) ＝ i Σ_{n=0}^{12} D_n(q)[0,0]（最高ウェイト成分の和）。段 3 の住民（指標の和）は共役で不変なので内部の位相を持たない。こちらは共役で位相が回る（内部時計を持つ）。

**読み出し（すべて場から読む）**：
- 山の位置：大円 exp(s i) の上で |f| を最大にする s（4,000 点の格子＋放物線補間）。1 ステップあたりの移動角 Δs。光速の基準は θ_L ＝ 0 の移動角。v_read ＝ Δs／（θ_L ＝ 0 の Δs）。
- 内部時計：山の位置での f の位相の 1 ステップあたりの進み ω。静止の基準は θ_L ＝ θ_R の ω。比 ω/ω_rest。
- 並べて記録：√(1 − v_read²)（特殊相対論の時計の遅れ）と ω/ω_rest。

**判定（実装の正しさだけ、事前固定）**
1. 本当の二乗 B が 124 ステップで保存（相対 ≤ 1e-12）
2. θ_L ＝ θ_R で山が動かない（|Δs| ≤ 1e-9）
3. θ_L ＝ 0 で山が 1 ステップあたり θ_R 動く（相対 ≤ 1e-6、格子補間の精度）

**記録のみ（成功条件にしない）**：ω/ω_rest と √(1 − v_read²) が一致するか、v_read と θ_L の関係。

## 走行 1 の不通過と、走行 2 の前に行った修正（走らせる前に記録）

走行 1（`stage3b_moving_resident_clock_run1.py`、`stage3b_results_run1.json`）：判定 1・3 は通過、**判定 2 は不通過**。原因は実装と設計の誤りで、物理の結果ではない。
1. **符号**：`translate_left(C, a)` は点を a·q へ、`rotate_right(C, b)` は点を q·b⁻¹ へ動かす。a ＝ exp(−θ_L i) では点 1 が exp(−θ_L i)exp(−θ_R i) へ動き、左右の移動が足し合わされた（θ_L ＝ θ_R で 2θ_R 移動、v_read ＝ 2）。README の意図（θ_L ＝ θ_R で共役、点 1 を固定）に合わせ、**a ＝ exp(＋θ_L u)** とする。
2. **軸**：住民 f ＝ i Σ D_n(q)[0,0] の位相は k 軸のまわりの回転（V(exp(s k)) が対角）で回り、i 軸のまわりでは回らない（走行 1 では全条件で位相の進み 0）。**発展の軸と読み出しの大円を k 軸**にする（u ＝ k）。

走行 2 はこの二点だけを変え、他（θ_R、θ_L の比、住民、判定、読み出しの手順）は変えない。

## 読み取れること

1. **速さは左右の角の差に比例する**：v_read ＝ 1 − θ_L/θ_R（直線）。左右とも実数の角の回転で動かしたので、速さは角の差のガリレイ的な足し算になり、相対論的な合成にはならない。
2. **内部時計はこの読み方では読めない**：全条件で ω ＝ 0。左右の掛け算は場の値を形を変えずに運ぶ（剛体的な写像）ので、山の位置での場の値はいつも同じになる。共役（静止）は中心を固定し、中心の値を変えない。**「山の位置での位相」を内部時計とした読み出しの設計が誤り**で、内部時計は場の値そのものではなく、他の住民（観測者）との関係（交差項の位相）としてしか読めない。この系の原則（読めるのは関係だけ）と同じ結論になった。

## この段の設計の問題（著者への報告）

- **仕様 v0.3 §5 の決定（左＝ブースト、虚数の角、γ）に反して、左を実数の角の並進で動かした。** 速さが角の差に比例するガリレイ的な結果になったのはこのため。ブーストを一度だけ掛ける段 3 の形と、実数の角の左右の掛け算を混ぜた設計で、段 3b は仕様の決定どおりの実験になっていない。
- 内部時計の読み出しは、観測者との交差項の時間変化（ビート）として設計し直す必要がある。

## 確かめていないこと

- 左＝ブースト（虚数の角）、右＝交換の回転の組で、観測者との交差項のビートから内部時計と速さを読む実験。
