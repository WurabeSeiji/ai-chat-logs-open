## 0. 設計の原則

1. 段ごとに一つの問いだけを確かめる。前の段が通るまで次の段に進まない。
2. 判定規則は走らせる前に固定する。予想（23/124、137、α）は成功条件にしない。
3. 閉塞 Σz² は課さない。初期状態を生成子の固有モードとして作り、Σz² ＝ 0 を判定に使う（|Σz²|/H ≤ 10⁻¹³）。
4. 各段は専用サブフォルダに、md・py・結果・README・SHA256・run_all.sh を一式で置く。既存プログラムに依拠する場合は複製して対照走行で一致を確認してから使う。
5. 計算資源：ファンのない MacBook Air M4。各段は 1〜2 コアで数分〜1 時間以内に収まる大きさから始める。

## 1. 状態の表現（全段共通）

- 各点に**複素四元数**を一つ置く：A ＝ a₀ ＋ a₁ i ＋ a₂ j ＋ a₃ k、aₙ ∈ ℂ（読める側）。読めない側も同じく B。実装では 4 成分の複素ベクトル。
- 本当の二乗：Σz² ＝ Σ_n aₙ²（共役をとらない）。ノルム Σ|aₙ|² は記録するが判定には使わない。
- 右の交換の回転：A → A · exp(θ u_R)、θ ＝ πm/n（実数の角、実直交）。
- 左のブースト：A → exp(iη u_L) · A（虚数の角、複素直交、γ ＝ cosh η）。
- 両者は可換。合成した生成子 G ＝ θ R_{u_R} ＋ iη L_{u_L} は複素反対称で、exp(G) は Σz² を保存する（仕様 §5、10-16 確認済み）。

## 2. 段 1：一点の代数（未決事項なしで実装可）

**問い**：右の交換の回転と左のブーストを同じ一つの複素四元数に掛けたとき、(a) Σz² が保存されるか、(b) 右だけが有限位数で閉じ左は閉じないか、(c) 左を加えても右の閉じ方（周期 n）が変わらないか、(d) 右と左の交差項から v、1/γ が読め、v² ＋ (1/γ)² ＝ 1 が恒等式ではなく状態の読み出しとして成り立つか。

**手順**
1. u_R、u_L を i, j, k から選ぶ全 9 通り（同じ軸 3、違う軸 6）。θ ＝ 2π·23/124 と対照 θ ＝ 2π/4、2π/6。η ＝ 0、0.3、0.8、1.5。
2. 初期状態：生成子 G の固有ベクトル（非零固有値）。Σz² を記録。
3. exp(G) を 1〜2n 回（n ＝ 124 なら 248 回）掛け、毎回 Σz²、ノルム、初期状態との重なり（本当の二乗の内積 vᵀv₀）を記録。
4. 読み出し：状態を右の回転の固有成分（e^{＋iθ} 側と e^{−iθ} 側）に分け、その重み a, b と交差項 2ab から v ＝ (a² − b²)/(a² ＋ b²)、1/γ ＝ 2ab/(a² ＋ b²) を計算し、入力の η との関係を記録する。

**判定（事前固定）**
- (a) |Σz² の変化|/|初期のノルム| ≤ 10⁻¹³（全組）
- (b) η ＝ 0 で n 回後に初期状態へ戻る（重なりの誤差 ≤ 10⁻¹²）。η ≠ 0 では戻らない（ブーストは周期を持たない）
- (c) 右の回転の固有位相（周期 n）が η によらない
- (d) 読み出した v と 1/γ の組が η とどう結びつくかを記録。tanh η、sech η と一致するか否かは記録するだけ（一致を成功条件にしない）

**意味**：(d) が手置きでない光円錐の読み出しの最小の形。v1.1 第 7 章の係数の恒等式との違いは、こちらは生成子の固有モードの上で読むこと。

## 3. 段 2：二枚の接着（未決 §6-1, 6-2 の決定が要る）

**問い**：読める側 A と読めない側 B を接着した一組（一つの E₈ の点）で、A に左右の掛け算、B に右の掛け算（内部の交換）を掛けたとき、固有モードの Σz² ＝ 0 が保たれ、A と B のあいだの交差項から質量（B の内部時計）と速さ（A のブースト）が分かれて読めるか。

**決める必要があること**：A と B を結ぶ項（接着の関係）を生成子にどう入れるか。候補：A と B の成分のあいだの実反対称の結合を、同じ剰余類にある組だけに置く。

## 4. 段 3：格子の上の場（未決 §6-3, 6-4 の決定が要る）

**問い**：R ＝ 3 の殻（各枚 256 点）の上に複素四元数の場を置き、点どうしの関係を視野角の三角形の重みで生成子に入れたとき、(a) 固有モードの Σz² ＝ 0、(b) 場の本当の二乗の分布に山（住民）が現れるか、(c) 欠損角の分布と R₀ の読み出し。

## 5. 段 4・5：歪みと種類（段 3 の後）

- 段 4：重力の歪み（対称な重み W、二次まで）を入れ、Φ（または欠損角）を固有モードと交互に更新して収束させる（自己無撞着の反復）。収束の有無を記録。
- 段 5：安定に残る状態を t, R, Q₁, Q₂, Q₃ の符号ベクトルとして読み、偶パリティの 16 が出るか（仕様 §8-1）。(t, R) の同時反転が同符号の組だけに働くか（§8-4）。
