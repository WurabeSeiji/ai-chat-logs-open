## 確認 1：本当の二乗とノルム（`check1_true_square_and_norm.py`）

- **命題**：本当の二乗の和 Σz²（zᵀz）とノルム Σ|z|²（z†z）の両方を保つ線形変換 T は、実の直交変換に限る。
- **証明**：TᵀT ＝ I かつ T†T ＝ I から Tᵀ ＝ T†、つまり T̄ ＝ T で T は実。実で TᵀT ＝ I なので直交。生成子では、複素反対称 ∩ 反エルミート ＝ 実反対称。
- **数値**：複素直交変換は Σz² を保ち（3.6×10⁻¹⁴）ノルムを変える（100）。ユニタリーはノルムを保ち（1.8×10⁻¹⁵）Σz² を変える（2.9）。実直交は両方を保つ（10⁻¹⁵）。生成子の交わりの次元 28 ＝ 8 次元の実反対称行列の次元 28。
- **項の置き場所の入替**：座標に i を掛ける D ＝ diag(1,…,i,…) で、符号 (4,0)・(3,1)・(2,2) の群 O(p,q) の元 Λ を DΛD⁻¹ に写すと、すべて同じ O(4,ℂ) の元になる（誤差 10⁻¹⁶）。空間と時間の入替は、同じ複素の二次曲面の、違う実の切り口にあたる。

## 候補 4（R の上の尺度）についての著者の修正

zₙ ＝ aₙ ＋ i bₙ とすると Σzₙ² ＝ Σ(aₙ² − bₙ²) ＋ 2i Σ aₙbₙ なので、Σzₙ² ＝ 0 は Σaₙ² ＝ Σbₙ² と Σaₙbₙ ＝ 0 を要求する。どちらも同次の式なので、すべての zₙ を同じ複素数 λ 倍しても成り立つ（Σ(λzₙ)² ＝ λ² Σzₙ²）。尺度の不変性（と全体の位相の不変性）は、閉塞の式に最初から自明に入っている。したがって閉塞は物差しの単位を決めない。物差しの単位が何から決まるかは、別に問うべきこととして残る。
