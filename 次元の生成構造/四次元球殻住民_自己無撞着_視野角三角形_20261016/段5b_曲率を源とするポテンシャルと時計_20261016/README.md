# 段 5b：曲率を源とするポテンシャルと時計（2026-10-16）

段 5a では時計の重み W を各点の曲率（欠損角）から直接作ったため、時計が遅れるのは場が集まった場所だけで、粒子の外では遅れなかった。一般相対論では曲率（物質）は局在しても、時計の遅れ（ポテンシャル）は物質を源とする方程式（弱い場ではポアソン方程式 ∇²u ＝ 源）を解いて外へ広がる。段 5b はこれを直す。段 5a のプログラムは無変更で複製し（`stage5a_geometry_copy.py`）、600 胞体・辺・四面体・欠損角の計算をそのまま使う。

## 走らせる前に固定したこと

- 源：段 5a と同じ静止した粒子（頂点 0）、κ ∈ {1e-4, 3e-4}（展開の範囲）。各頂点の曲率のずれ s_p ＝ (K_p − K₀)/K₀。
- **ポテンシャル**：600 胞体のグラフのラプラシアン L（隣どうし重み 1、歪みなしで全辺が同じ長さなので一様）で L u ＝ −(s − ⟨s⟩) を解く。閉じた S³ ではポアソン方程式が解を持つのは源の総和が零のときだけなので、源から平均を引く（一様な分は全体の曲率 R₀ が受け持つ）。u は定数の自由度があるので、対蹠点（最も遠い点、観測者の位置）で u ＝ 0 と決める。
- **時計の重み**：W_p ＝ 1 − u_p ＋ ½u_p²（二次まで）。
- 発展：段 5a と同じく各点で実数の角 W_p θ の交換（θ ＝ 23π/124）、248 ステップ。
- **判定（実装の正しさだけ）**：(1) 源が零のとき u ≡ 0。(2) ポアソン方程式の残差 ≤ 1e-10。(3) 本当の二乗とノルムの保存 ≤ 1e-12。
- **記録**：u と W の距離による分布（600 胞体の頂点の殻ごと：中心からの角 0°, 36°, 60°, 72°, 90°, 108°, 120°, 144°, 180°）。S³ の上のラプラシアンのグリーン関数の形 G(d) ∝ (π − d) cot d との比較（振幅一つを合わせた残差）。源の総和（曲率のずれの総和が最初から零に近いか）。

## 読み取れること

1. ポアソン方程式で曲率からポテンシャルを作ると、時計の遅れは物質の外にも少し広がる（段 5a では場が集まった点だけだった）。中心で遅れる向きは正しい。
2. **ただし遠くまでは届かない。** 物差しの伸びを場の本当の二乗の大きさから作る規則（段 5a の規則 2）では、中心の正の曲率を周りの環の負の曲率がほぼ完全に打ち消し、曲率のずれの総和（全体としての質量、単極子）がほぼ零になる。単極子のない源のポテンシャルは遠くで急に落ちる（双極子・四重極の型）。**重力の 1/r 型の遠くまで届く場（ニュートンの重力）は、この規則からは出ない。**
3. 物差しを点ごとに伸ばすだけの変形は、曲率の総和をほとんど変えない。全体としての質量を持つには、場が曲率そのものの総和を変える（欠損角の総和を変える）規則が要る。これは閉じた S³ では「全体の曲率 R₀ と局所の曲率の配分」の問題で、局所が正の質量を持てば、その分の負の曲率を全体（一様な背景、R₀）が受け持つ形になる（ポアソン方程式で源から平均を引いたのはその操作）。

## 確かめていないこと・次への申し送り

- 曲率の総和を変える規則（局所の本当の二乗が欠損角に直接寄与する形など）。どんな規則にするかは著者の判断が要る。
- 粒子が動き、歪みが場と一緒に更新される自己無撞着な発展。
