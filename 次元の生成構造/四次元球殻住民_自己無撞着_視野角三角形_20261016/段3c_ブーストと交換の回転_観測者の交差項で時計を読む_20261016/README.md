# 段 3c：ブーストと交換の回転、観測者との交差項で時計を読む（2026-10-16）

段 3b の誤り（左を実数の角で動かした、内部時計を場の値で読んだ）を直した実験。仕様 v0.3 §5 の決定どおり、**左＝ブースト（虚数の角、一度だけ）、右＝交換の回転（実数の角、毎ステップ）**。内部時計は**観測者の山との交差項の時間変化**で読む。共通モジュールは段 2 から無変更で複製。

## 走らせる前に固定したこと

- 住民：粒子 f ＝ i Σ_{n=0}^{12} D_n(q)[0,0]（中心 1、右の k 軸の回転で次数ごとに位相 e^{inθ} が回る形）。観測者 g は同じ形で中心 exp(0.9 j)。
- 粒子にだけ、最初に一度ブースト Λ(η) ＝ exp(iη u) を左から掛ける。η ∈ {0, 0.1, 0.2, 0.3}、u ∈ {i, j, k}。
- 毎ステップ、右の交換の回転を掛ける。二つの場合：
  - **A（同じ規則）**：粒子と観測者に同じ回転 b ＝ exp(θ k)、θ ＝ 2π·23/124
  - **B（粒子と観測者で回転の速さが違う）**：粒子 θ_p ＝ 2π·23/124、観測者 θ_o ＝ 2π·29/156（窓の隣の根、内部時計の速さが違う住民の代わり）
- 読み出し：交差項 X(k) ＝ B(f_k, g_k)（本当の二乗の双線形形式）を k ＝ 0〜247 で記録し、フーリエ変換で周波数ごとの振幅を求める。時刻 k は観測者の回転の回数（観測者の時計）。
- **判定（実装の正しさだけ）**：(1) 粒子の本当の二乗 B(f_k) が全ステップで保存（相対 ≤ 1e-12）。(2) ブーストと右の回転の可換（ブーストを最初に掛けても最後に掛けても X(k) が同じ、相対 ≤ 1e-10）。
- **記録のみ**：A で X(k) が時間変化するか。B で X(k) の周波数が η によって変わるか（時計の遅れが見えるか）。

## 走行 1 と、走行 2 の前の修正（走らせる前に記録）

走行 1（`stage3c_boost_exchange_beat_run1.py`、`stage3c_results_run1.json`）：判定 1・2 は通過。ただし交差項 X(k) は A・B の全条件で完全に一定（変動 0）だった。原因は設計の誤り：本当の二乗の双線形形式 B は、右の回転の向きが逆の成分どうし（右の添字のウェイト m と −m）しか結ばない。粒子と観測者をどちらも右の添字 0 の成分（同じ向き）だけで作ったため、次数 0 以外の交差項が恒等的に零で、残った次数 0 の項は時間変化しない。

**走行 2 の修正**：観測者を逆向きの成分で作る：g(q) ＝ i Σ D_n(q₀′⁻¹ q)[0, n]（右の添字 n、ウェイト −n/2）。他（粒子、回転、ブースト、判定、読み出し）は変えない。

## 結果（走行 2、`stage3c_results_run2.json`）

**判定（実装の正しさ）はすべて通過**：粒子の本当の二乗の保存、ブーストと右の回転の可換（ブーストを最初に掛けても最後に掛けても交差項が同じ）。

**記録**
- **A（粒子と観測者に同じ右の回転）**：交差項 X(k) は全条件で一定（相対変動 1e-14）。ブーストの強さで値（振幅）は変わる（η ＝ 0 で 1.941、u ＝ i・η ＝ 0.3 で 1.577）が、時間変化はしない。
- **B（回転の速さが違う）**：X(k) は時間変化する（相対変動 0.11〜0.18）。248 ステップのフーリエでは、周波数がフーリエの分解能（1/248）より小さく、η による違いを判別できなかった。

**事後診断（判定ではない、`stage3c_posthoc_per_degree_beat.py`）**：次数ごとの交差項 X_n(k) は単一の周波数の指数関数で、1 ステップの位相の進みは n(θ_p − θ_o) と全次数で一致した（n ＝ 1 で −0.00259851）。**この周波数は η とブーストの向きに依らない**（全 12 条件での最大の違い 1.7e-15）。ブーストで変わるのは次数ごとの振幅だけ（u ＝ i、η ＝ 0.3 で次数 1 の振幅 0.392 → 0.315、次数 5 で 0.049 → 0.017）。

## 読み取れること

1. **同じ規則で回る二つの住民の交差項は時間変化しない。** 右の回転は本当の二乗の形式を保つ対称性なので、全体に同じ回転を掛けても関係は変わらない。時計の読み出し（ビート）には、住民ごとに回転の速さ（内部時計の速さ＝質量）が違うことが要る。
2. **ブーストは時計の進み（ビートの周波数）を変えない。** 左のブーストと右の交換の回転は可換なので、観測者が読む粒子の内部時計の周波数は粒子の速さに依らず、変わるのは振幅だけ。**この構成では特殊相対論の時計の遅れ（周波数が 1/γ 倍になること）は出ない。** 左右の可換性は「α が速さに依らない」ことを保証したが、同じ理由で「右の側の時計は速さに依らない」ことも意味する。
3. 時計の遅れが出るためには、時計が左（ブーストと同じ側）にあるか、相互作用（状態に依存する生成子）がブーストと時計を混ぜる必要がある。どちらにするかは、仕様 v0.3 の左右の役割の中身に関わる。

## 確かめていないこと

- 時計を左の側に置いた構成、あるいは相互作用でブーストと時計が混ざる構成での時計の遅れ。
- 粒子の内部時計の速さ（θ_p）を、置くのではなく相互作用の結果として出すこと（今回は窓の隣の根 29/156 を観測者に置いた）。
