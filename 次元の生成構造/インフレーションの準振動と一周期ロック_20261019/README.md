# インフレーション図の準振動と「一周期で円周に張り付く」の検証（2026-10-19）

**問い（著者）：** 図「関係波の膨張＝インフレーション（N=40・M=780本の波）」（K4 論文 図4、note n6f3dfc53df36）で、縦軸が対数なのに等間隔に見える準振動がある。またある時点で、その振動が一周期で拡大して円周に張り付く。これは何か。
**方法：** 既存データの読み出しのみ（新しい走行なし）。図の読み出し（共回転フレーム w ＝ z·e^(−iθ₀)、H⊥/H）を忠実コピーし（`readout_copied_20261019.py`）、同じ親から刻み den ＝ 38〜42、124 で回した N ＝ 40 の走行で比べた。
**入力：** `次元の生成構造/電子の反跳実験/seed除去による準安定相追試/chatgpt追試/干渉保存力学_資格審査とシード無し系列_20260831/N3_N40_stage123_sweep_20260905/results/hm_N40_den_{den}_states_500.npz`。図の元データ（make_parent 型スイープの npz）は容量の都合で削除済み。stage123 の den=40 は図の H⊥/H 系列と一致（step500 で 0.1005、対数で最大 0.002 桁差）。

1. **波打ちの周期 ＝ 見かけの一回転の周期。** どの刻みでも、波打ちの周期は 2π/|ω_app| と一致する。ω_app は、床の回転 σ ＝ 38.905（全刻みで共通）を刻み Δτ ＝ 2π/den で拾った σΔτ mod 2π（ストロボ的な見かけの回転）。波打ちは全波がそろって動く位相の揺れで、振幅は 0.001〜0.02 rad。
2. **対数軸で等間隔に見える理由。** 指数成長の区間では log H⊥ が step に比例し、見かけの回転も step あたり一定なので、波打ちは対数軸で等間隔になる。間隔（桁/波打ち）は刻みで 0.8〜3.0 と変わり、力学の不変量ではない。
3. **成長率そのものも刻みに依存する。** τ あたりの成長は den=38〜42 で 0.38〜0.90、den=124 で 5.05。刻み 2π/N は生成子に対して粗く（9/18 報告書の指摘）、離散写像として別の力学になっている。
4. **遷移の長さは一周期ではない。** log₁₀(H⊥/H) が −3 から最終値 −0.1 に達するまでは 38〜73 step で、見かけの周期に対して 1.2〜18 倍とばらつく。den=40 で一周期程度に見えたのは、その刻みでたまたま周期（36.5 step）と遷移の時間（73 step、約 2 周期）が近かったため。

## 読み（確認前）

- 図の準振動と「一周期で張り付く」見え方は、外から置いた刻み Δτ ＝ 2π/N が作るストロボ効果で説明がつく。力学の内側の時計（対数周期的な構造や一周期のロック）を示す証拠にはならない。
- 一方、床の回転の振動数 σ ＝ 38.905 はどの刻みでも同じで、これは系の量。見かけの回転 −2π/N 付近の値は σ と刻みの組で決まる（検討ルール R6・R7：外の刻みが読める数を作る実例）。準安定状態の σ ＝ N − 1 と Δτ ＝ 2π/N からは、一歩の回転 2π − 2π/N ≡ −2π/N が恒等的に出る（論文 0 の「終端の一歩の回転 −2π/N の普遍化」はこの恒等式）。
- 対数周期的な構造（拡大と回転が一つの複素数の掛け算になっているか）を本当に調べるには、刻みを生成子に対して十分細かくした走行（9/18 の den ＝ 200L 系列のような）で、刻みを変えても残る量だけを見る必要がある。

## 追加：軌道に四元数として読める組が生じているか（2026-10-19）

**問い（著者）：** この波のデータから、四元数・八元数として読める組み合わせが生じているか。
**判定の基準（事前に固定）：** J₂ ＝ C∘J_K が i と反可換であることは代数的恒等式なので測らない。測るのは、(1) 各段の窓で軌道が掃く張りの次元が倍加の段（実 2 → 4 → 8）に乗るか、(2) 育つ第 2 モード u₂ が第 1 モードの四元数の相手 J₂u₁ ＝ conj(J_K u₁) か、(3) 窓の複素の張りが J₂ で閉じるか。生成子は stage123 の位相のみ K。入力は N ＝ 40、den ＝ 40 と 124。結果 `results/quaternion_pairing_N40.{md,json}`、プログラム `analyze_quaternion_pairing_20261019.py`。

**事実：**
- 床と終端（den＝124）では複素の張りは 1（剛体回転する一本の複素ベクトル）。指数成長・遷移で第 2 以下の複素モードが育つ。
- 実の特異値は**等しい二つずつの対**で増える（例：遷移前半 2.7e-2 と 2.6e-2、1.1e-3 と 6.2e-4）。つまり張りは複素モード一本ずつ（実 2 次元ずつ）増え、強さは段ごとに約 1〜2 桁ずつ下がる階層になる。実 2 → 4 → 8 で止まる段の構造は見えない（遷移中の複素の張りは 5〜11）。
- 第 2 モードは第 1 モードの四元数の相手と**直交**：|⟨J₂u₁, u₂⟩| ≤ 0.010、|⟨ū₁, u₂⟩| ≤ 0.004（全窓）。窓の張りは J₂ で閉じない（閉じない割合 0.70〜1.00）。

**読み（確認前）：**
- このデータ（位相のみの生成子・粗い刻み）では、インフレーションで育つ方向は、気づきメモ §2 の意味での四元数の相手（J₂u₁）ではない。複素数の配列は、四元数の塊として組まれずに、複素モードの階層として広がっている。
- 閉塞 Σz² ＝ 0 のため、床の状態 v と共役 v̄ は直交していて、四元数の直線 span(v, v̄) の候補はある。しかし軌道は v̄ の方向へは育たない（top 6 の張りに入る v̄ の割合 0.006〜0.165）。
- 否定的な結果だが、限定がある。(a) 生成子は旧来の位相のみ K（振幅込みの正本 K ではない）、(b) 刻みは粗い、(c) 9/18 の振幅込み・細分系列では終状態が厳密に複素ランク 2（星の上の二モード）だったが、その状態データは削除済みで、二つのモードが J₂ の対かどうかは確かめられない。(d) 判定は J₂ ＝ C∘J_K という一つの読み方に対するもので、別の対の作り方は試していない。
