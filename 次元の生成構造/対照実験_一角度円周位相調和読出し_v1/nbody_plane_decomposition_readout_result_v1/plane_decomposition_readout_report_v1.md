## 実験F: 平面AB運動学的同型性

| 検査量 | 全構成最大値 |
|---|---:|
| 平面振幅の変動 | $1.21\times10^{-13}$ |
| 位相進行の1ステップ変動（単一周波数性） | $1.89\times10^{-13}$ |
| **符号付き**平均進行と理論値 $+2\arctan(\gamma\sigma_j)$ の偏差 | $4.49\times10^{-15}$ |
| 面内 $SO(2)$ ゲージによる符号付き進行の変化 | $1.52\times10^{-13}$ |
| 向き規約 $(Kp_j)\cdot q_j/\sigma_j-1$ の偏差 | $7.64\times10^{-14}$ |
| 名称置換後の周波数集合の偏差 | $2.00\times10^{-15}$ |
| 名称置換後の平面エネルギー集合の偏差 | $3.30\times10^{-15}$ |

ランク則（平面数 = min(N,⌊M/2⌋)、核次元 = M−2r）は全試行成立。周波数非縮退（独立の一般位置仮定）は全224試行で成立し、最小周波数ギャップは 2.0×10⁻³（N=9）〜5.4×10⁻²（N=4）。低振幅により除外された平面は0枚。

面内 SO(2) ゲージで絶対位相は動くが符号付き位相進行は不変（公理5の導出量レベルでの再現）。反射を含む O(2) では符号が反転するため、検査は SO(2) に限定している。

## 実験G: 零次調和二階構造の平面確認

各平面座標の離散二階差分は $\Delta^2 c_j = -4\sin^2(\theta_j/2)\,c_j$ を満たす。回帰傾きと理論係数の**絶対偏差は全構成最大 $1.27\times10^{-16}$**（機械精度）。相対偏差の増幅（最大 2.5×10⁻⁹）は最遅平面で理論係数自体が微小なことによる指標の条件数であり、判定は絶対偏差で行う。

最遅平面を基準とする連続スペクトル再表示（比 θ_j/θ_min は**一般に非整数**）での調和係数の指数は、平面2枚以上の全構成（N=4〜9）・全試行で $-1.99999 \le$ 指数 $\le -1.99988$（−2、定義に基づく帰結の確認）。

**注意:** 本実験が確認したのは零次の調和二階構造であり、公理17の観測加速度（ρ_c・未来位相位置・接線方向射影）の平面上での構成・検証ではない。また指数は規格化された調和係数 g_j のものであり、平面加速度振幅 a_j = ρ_j g_j のものではない。

## 実験H: エネルギー様分解と閉鎖分解

| 検査量 | 全構成最大値 |
|---|---:|
| 各平面エネルギー $H_j$ の変動 | $2.41\times10^{-13}$ |
| 核エネルギー $H_{\ker}$ の変動 | $4.55\times10^{-14}$ |
| 恒等式 $\sum_j H_j + H_{\ker} - H$ の偏差 | $2.00\times10^{-15}$ |
| **各平面閉鎖量 $Q_j=(p_j^{\mathsf T}X)^2+(q_j^{\mathsf T}X)^2$ の変動** | $1.81\times10^{-13}$ |
| **核閉鎖量 $Q_{\ker}$ の変動** | $4.03\times10^{-14}$ |
| **閉鎖分解恒等式 $\sum_j Q_j + Q_{\ker} - R^2$ の偏差** | $1.89\times10^{-15}$ |

固定生成子のもとで、エネルギー様量だけでなく**二乗閉鎖そのものも平面別・核別に分解され、各項が個別に保存される**。したがって固定生成子では、閉鎖量もエネルギー様量も平面間を移動しない（自発的分裂に対するno-go。分裂には固定生成子を超える動力学が必要）。

## 実験I: 残余部分空間の読出し制限

| 検査量 | 全構成最大値/最小値 |
|---|---:|
| 核成分の時間変動（静的性） | $4.57\times10^{-14}$ |
| 核射影子のゲージ変動（一意性） | $7.77\times10^{-16}$ |
| 独立核基底の第一方向間角度（標準基底の非選択性） | 最小 $13.6^\circ$（N=6）〜 $50.9^\circ$（N=9） |

核成分は位相進行を持たない（静的）。したがって**進行に基づく**位置・調和加速度読出しは核からは成立しない。射影子と核二乗量は一意に読め、状態射影 P₀X は共変に定義できる。静的な P₀X を位置方向として読めるか否かは本実験の対象外（未検証）。

## 結論

- 各回転平面は、一定振幅の単一周波数二次元回転として、AB二体の**回転運動学**と同型に読める（位相進行・周波数・振幅・エネルギー・零次調和二階構造）。
- 固定生成子は平面別・核別の**二重の保存レジスタ**（H_j と Q_j）を持ち、平面間でどちらの量も移動しない。
- 残余部分空間では進行に基づく読出しが成立しない。
- AB二体の同時刻二波間の位置位相読出し（D_AB）の平面対応量、および公理17の観測加速度の平面上での構成は、本実験の対象外（接続課題）。
