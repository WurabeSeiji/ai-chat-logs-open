# 媒介頂点の一意化と多体アーキテクチャ v1

作成日: 2026-08-05
状態: 理論ノート（段階1の前提宿題）。導出＋数値検証（test_mediated_vertex_closure_v1.py）。

---

## 1. 目的

二体toyで確立した閉塞保存頂点 δa = ig(|b|²a − b²ā)（g₂=−g₁の一意化）を、
N体関係波系（K_N グラフ、辺ごとのN点レジスタ）へ、無名性と閉塞保存を
保ったまま拡張する。GATE-0の教訓（γ反証・凝縮体媒介）と、演算量 O(M) の
要請を同時に満たす形を導出する。

## 2. 仮定（二体の導出と同一系列）

- A1（点ごと）: 頂点はレジスタ点 n ごとに独立に作用する（点ごとの積。
  スペクトル空間では和則 k₁+k₂−k₃=k₄ の四波混合が自動成立）。
- A2（共通位相不変）: z → e^{iφ}z（全辺一斉）で不変。
- A3（自己散乱なし）: δz_e は z_e 単独の三次項（|z_e|²z_e 型）を含まない。
- A4（グラフ局所）: 相互作用は頂点を共有する辺対に限る（K と同じ局所性。
  新しい局所性を導入しない）。
- A5（三次・二波）: 各隣接対 (e,e′) ごとに二波型三次頂点。
- A6（強度の状態読出し）: 対強度 R_{ee′} は状態から読む（結合定数を新設しない）。

この下で最も一般な形は

$$\delta z_e = i\sum_{e'\sim e} R_{ee'}\left(g_1\,|z_{e'}|^2 z_e + g_2\, z_{e'}^2\,\bar z_e\right)$$

（レジスタ点 n は省略。全て同一点上の積。）

## 3. 定理（閉塞保存による一意化）

**定理.** 場の閉塞 $C=\sum_e z_e^2$（各レジスタ点ごと）が任意の状態で
保存される（$\dot C\equiv 0$）ための必要十分条件は

$$g_2=-g_1 \quad\text{かつ}\quad R_{ee'}=R_{e'e}\ (\text{対対称}).$$

**証明.** $\dot C \propto \sum_e z_e\,\delta z_e
= i\sum_e\sum_{e'\sim e} R_{ee'}\left(g_1|z_{e'}|^2 z_e^2 + g_2 z_{e'}^2|z_e|^2\right)$。
隣接対 $\{e,e'\}$ ごとに二項をまとめると、その対の寄与は

$$R_{ee'}\left(g_1|z_{e'}|^2z_e^2+g_2z_{e'}^2|z_e|^2\right)
+R_{e'e}\left(g_1|z_e|^2z_{e'}^2+g_2z_e^2|z_{e'}|^2\right).$$

$g_2=-g_1$ かつ $R_{ee'}=R_{e'e}$ なら括弧内が交換反対称となり対ごとに
恒等的にゼロ。逆に任意状態でゼロであるためには、単項式
$|z_{e'}|^2z_e^2$ と $z_{e'}^2|z_e|^2$ の独立性から両条件が必要。∎

**系1（二体への還元）.** M=2チャネル（a,b）では
δa = iR g₁(|b|²a − b²ā)——二体v3の頂点そのもの。g₂=−g₁ は二体の一意化、
R の対対称性は二体混合結合実験の実測「交換強度＝厳密平均・積は no-go」
（コミット fd7a3745）の定理化である。対対称の自然な実装は算術平均
$R_{ee'}=\tfrac12(R_e+R_{e'})$（積 $R_eR_{e'}$ も対対称だが、二体実測は
平均を選択した——段階2でどちらが力学的に正しいかを再検証可能。
閉塞保存だけなら両者とも許される点は正直に残す）。

**系2（O(M)因数分解）.** 算術平均強度のとき

$$\delta z_e = \tfrac{i g_1}{2}\Big[
R_e\big(\mathcal A_e z_e-\mathcal B_e\bar z_e\big)
+\big(\mathcal A^R_e z_e-\mathcal B^R_e\bar z_e\big)\Big]$$

ここで頂点モーメント $A_v=\sum_{e\ni v}|z_e|^2$、$B_v=\sum_{e\ni v}z_e^2$、
$A^R_v=\sum_{e\ni v}R_e|z_e|^2$、$B^R_v=\sum_{e\ni v}R_e z_e^2$ を用いて
$\mathcal A_e = A_{u(e)}+A_{v(e)}-2|z_e|^2$（自己項控除）等。
**隣接対和は厳密に頂点集約で書け、1レジスタ点あたり O(M)**。
懸念された演算爆発（対数~N³/2）は三次項には存在しない。
爆発するのは対ごとのスペクトル読出しだけであり、それは A6 の設計
（辺ごとの読出し R_e、O(M·N log N)/step）で回避する。

## 4. 多体アーキテクチャ（段階1〜2の状態空間と更新）

**状態**: レジスタ行列 $W\in\mathbb C^{M\times N}$（辺 e × レジスタ点 n）。
倍音表示 $C = \mathrm{FFT}_n(W)/N$。

**線形部（段階1）**: 倍音スライスごとに独立に既存Cayley一歩を適用：
各 k について $Z_k=C[:,k]$、$Z_k \leftarrow \mathrm{Cayley}_{K(\arg Z_k)} Z_k$。

- **対応原理（bitwise）**: 単一スライスのみ占有された状態では既存力学
  （第7・8論文・E-M9r）と厳密一致。E-M9r のセクター個別注入は、
  実はこのアーキテクチャのスライス毎検査だった。
- **線形無生成が設計定理になる**: 線形部はスライスを混ぜない（構成上）。
  開始様式論文 §5 の未証明仮説（不変部分空間の保存）は、この状態空間では
  アーキテクチャの恒等的性質に昇格する。倍音を混ぜられるのは頂点だけ。

**非弾性部（段階2）**: レジスタ点 n ごとに §3 の頂点を適用
（点ごと→倍音空間では隣接対ごとの四波混合和則）。強度 R_e は
辺 e のレジスタと頂点集約レジスタの合成スペクトルから
theta_from_ab と同文法で読む（フェルミオン/ボゾン関係量比→θ_e→R_e=sin²θ_e）。
積分は部分刻み ODE 流（h_max 制御）。**積分器はここで刻み収束またはシンプレク
ティック化を行い、二体v3で残った零閉塞ドリフト 2.9e-3 を同時に解消する。**

**抑制の二因子が完結する**: ゲート（凝縮：GATE-0のフレーム/時計計器）×
種（レジスタ内容の奇数倍音占有＝f）——段階1の計装で初めて種因子が
軌道上で直接測れる。

## 5. 段階1の受入基準（実行前固定・実装前に宣言）

1. 対応原理: 単一スライス初期条件で既存 abl 軌道と bitwise 一致（T=1000）。
2. 多スライス白色初期条件で、各スライスの f_k(t) が単独走行の値と一致
   （線形部の非結合の実証）。
3. 開始様式二分の再現（controlスライス=潜伏バースト／白色スライス=即時）。
4. 種因子計装: P_f/P_b（奇偶レジスタ内容比）の軌道記録が全系列で取得できる。

## 6. 段階2の事前登録判定（4系統・実装前に宣言）

1. 点火則 C·f² の多体版（局所凝縮点火）が出るか。

3. **E8特殊値判別**: 特殊N（120/124/128/137/240/248等）vs 近傍対照で

   （線形相は全帯nullを実測済み——GATE-0b/0c/0g——なので、
   出れば「レジスタ力学の算術」の直接証拠、出なければE8接続仮説の後退）。
4. **二カイラリティ検証**: +枝の一様安定海に頂点を載せ、生成が起こらない
   （または時間反転側の挙動を示す）か——真空対の物理的実在の検定。

## 7. 正直な未決事項

- 強度実装の平均 vs 積（系1）: 閉塞保存だけでは決まらない。二体実測は
  平均を支持。段階2で多体でも判別する。
- 読出し R_e の正確な定義（辺スペクトル×頂点集約スペクトルの合成規約）は
  段階1の計装実験で候補比較の上で固定する（事後変更禁止の対象）。
- 線形部の「スライス独立」は設計選択である（共有生成子 K(arg ΣC) 案との
  比較は、対応原理を壊すため採らなかったことを記録する）。
