# 上流論文監査報告 v1

**日付:** 2026-08-11  
**対象:** 論文Aへ至る、波数論文 → 白色親生成器 → インフレーション開始様式論文 → 多体接続論文  
**結論:** 論文Aだけを直しても不十分である。上流に、少なくとも二つの具体的誤りと一つの未導出接続がある。ただし、関係ベクトル空間における不安定相対平衡の指数離脱という数理結果まで否定されたわけではない。

## 1. 結論を先に示す

1. **最初の定義不整合は白色親生成器にある。** 直前の論文は、倍音分解能 $\mathcal N$ と物体数 $N$ を別の外部仕様として明確に区別した。しかし生成器は「理論入力は $N$ のみ」とし、各関係波の標本数を $N$ に固定した。$\mathcal N=N$ を導く式はない。
2. **開始様式論文は、完全波を発展させていない。** $N$ 点波形をDFTした後、各列 $C[:,k]\in\mathbb C^M$ を一本ずつ取り出し、スカラー関係ベクトルとして別々に発展させた。したがって実測したのは「各DFT切片の初期状態分類」であり、倍音を同時に持つ一個の波の力学ではない。
3. **多体接続論文の $M\times N_{\mathrm{reg}}$ は導出ではなく設計選択である。** 論文自身がそう明記する。実装は $N_{\mathrm{reg}}=5$ で、ポンプ $k=2$ と種 $k=1$ だけを使う。第63次までの奇数・偶数倍音族との対応写像はない。
4. **多体GENESISの旧初期値は、点ごとの零二乗和閉包を満たさない。** 実測した初期閉包誤差は $\delta=10^{-6}$ で $7.71\times10^{-7}$、$\delta=10^{-2}$ で $7.74\times10^{-3}$ である。これは説明不足ではなく、論文が頂点導出の根拠とする閉包に対する初期条件の不整合である。
5. **純粋インフレーションは残るが、物質生成接続は残らない。** 閉包を保つ種と第63次までの倍音族を入れても、インフレーション crossing は旧値から5%以内で再現した。一方、旧実験で見えた奇数パワーの正味増加は、閉包修正後に約3,083分の1、全偶奇倍音候補では約316分の1になった。

## 2. どこで構造が変わったか

| 段階 | 実際の状態 | その段階での操作 | 監査判定 |
|---|---|---|---|
| 波数論文 | 分解項数 $\mathcal N$ と物体数 $N$ | 両者を別の外部仕様と定義 | ここは区別が正しい |
| 白色親生成器 v3 | $M$ 本の各関係波に $N$ 標本 | `sample_count_per_relation_wave=N` | $\mathcal N=N$ の無導出同一視 |
| 開始様式論文 | $Z\in\mathbb C^M$ | $N$ 点DFTの一列 $C[:,k]$ だけを個別発展 | 完全波発展ではなく切片試験 |
| 多体接続論文 | $C\in\mathbb C^{M\times N_{reg}}$ | 実装では $N_{reg}=5$, $k=2$ pump, $k=1$ seed | 本稿固有の設計。完全倍音との写像なし |
| 二体・周期表側 | $512\times16$ 波形、$H=63$ | 奇数32本・偶数31本を同時に持つ | 多体接続とは別枝のまま |
| 論文A v1 | 各関係に $16\times8=128$ 係数 | 有限巡回レジスタの奇偶帯を物質解釈 | 上流の未接続を継承し、さらに別解像度へ変更 |

したがって、論文Aの「128か所」は波が内部に持つ物理的番地ではないだけでなく、先行する第63次倍音波から導出された状態空間でもなかった。なお、論文Aの記述は **$16\times8=128$ 個**であり、$128\times8$ ではない。もし別の $128\times8$ 配列を指すなら別途区別が必要である。

## 3. リポジトリ上の直接証拠

### 3.1 倍音分解能と物体数は、元来別だった

`次元の生成構造/波の数は系の分解能である_完成論文_v1.md:15-18` は、$\mathcal N$ を分解項数・最大倍音番号、$N$ を実験モデルの体の数として明記する。同論文 `:107-124` は、$\mathcal N$ は系内部で決まらず表現仕様に属すると論じる。

ところが `次元の生成構造/make_parent_white_managed_v1/make_parent_white_harmonics_n_only_v3.py:21-30` は、各関係波が $N$ 個の標本を持つと定義する。manifestも `:385-401` で `sample_count_per_relation_wave=N`、独立な `harmonic_count_H=None` と固定する。これは直前の区別からは導けない。

**判定:** 数値実験用の便宜的規約として明記するなら許される。しかし「$N$だけが理論入力」「$N$から導出」と呼ぶのは定義のすり替えであり、具体的な対応誤りである。

### 3.2 「白色倍音の海」の実験は全波を発展させていない

開始様式論文は `次元の生成構造/幾何級数的急拡大は不安定な自己無撞着閉包に固有である_完成論文_v1.md:33-41` で、実際の力学状態を $Z\in\mathbb C^M$ と定義する。`同:47-55` で各関係波を $N$ 標本とし、`同:65-67` でDFTの各 $k$ 成分を一つずつ関係振幅として取り出す。

実装 `次元の生成構造/第8論文_二段階seed除去による準安定相の因果分離/paper8_em9r_white_harmonics_inflation_v1/run_paper8_em9r_profile_v1.py:145-172` も、`C=fft(W)` の後に `Zk=C[:,k]` として各列を別々に `profile` へ渡す。複数倍音列を同時に発展させる処理はない。

**判定:** 「一般零閉包ベクトルは即時離脱し、不安定自己無撞着親は潜伏指数離脱する」という関係空間の分類を支持する。一方、「倍音を持つ海全体は増幅しない」まで一般化するには、全列を同時に進める力学が必要である。

### 3.3 多体接続のレジスタは論文固有の仮定だった

多体論文 `次元の生成構造/万能相互作用多体接続_v1/インフレーションの終わり方が物質生成の始まり方である_完成論文_v1.md:69-82` は、$C\in\mathbb C^{M\times N_{reg}}$ と点ごと頂点を「本稿固有の埋め込み選択」と明記する。実装 `同フォルダ/run_genesis_v1.py:68-77` は $N_{reg}=5$ とし、$k=2$ と $k=1$ の二列だけを占有する。

対して二体側の `次元の生成構造/万能非弾性写像_managed_v1/universal_inelastic_map_v1.py:36-38` は偶数 $2,4,\ldots,62$ と奇数 $1,3,\ldots,63$ を持ち、元の系A設定 `次元の生成構造/第9論文_フェルミオンの生成構造/対照実験_波束収縮_実行環境_v1/20260715/run_system_A_localization_exchange_R_sweep_preliminary_v1.py:54-59` は $512\times16$, $H=63$ である。

**判定:** 多体論文は二体頂点の代数形を移植したが、二体波の状態空間を移植していない。「二つの物理を一つの系で接続した」という主張には、欠けた状態空間対応がある。

### 3.4 公開済みGENESIS自身の事前条件は不成立だった

`次元の生成構造/万能相互作用多体接続_v1/genesis_result_v1.json:1-46` では、

- P-G1のみ成立。
- P-G2, P-G3, P-G4は不成立。
- `all_pass=false`。
- $\delta=10^{-6}$ の奇数率は全3窓で負、$f_{odd}$ は $1.000000000064\times10^{-12}$ から $9.999999520\times10^{-13}$ へ減少。

多体論文 `:146-152` はP-G4の予言失敗を明記し、$\varepsilon$則との近さから「種の統一」と読み替える。同時に、$\delta=10^{-6}$ の生成は測定限界以下とも記す。

**判定:** crossingの説明候補としては成立し得る。しかし、その同じ走行で種が物質へ成長したわけではない。「同じ種がインフレーションを点火し、物質になる」は、二つの異なる振幅系列をまたいだ解釈であり、一本の走行による実証ではない。

## 4. 今回の訂正対照

### 4.1 閉包を保つ種

親 $Z=p+iq$ の実平面に直交する実単位ベクトル $a,b$ を作り、

$$
S_{cl}=\frac{a+ib}{\sqrt{2}}
$$

とした。実測は

$$
|S_{cl}^T S_{cl}|=2.39\times10^{-16},\qquad
|Z^T S_{cl}|=1.55\times10^{-16}.
$$

旧種は

$$
|S_{old}^T S_{old}|=0.3352,\qquad |Z^T S_{old}|=0.3856
$$

であり、重ね合わせ波の点ごと閉包を満たさない。

### 4.2 条件

| 記号 | 内容 |
|---|---|
| L-old | 公開済み5点、旧種 |
| L-cl | 5点、閉包種 |
| O63-cl | 512点、$k=2$ポンプ＋奇数32倍音種 |
| EO63-cl | 512点、偶数31倍音ポンプ＋奇数32倍音種 |

総偶数パワーと総奇数パワーを条件間で一致させた。EO63-clは欠落した接続を検査する一候補であり、理論から一意に導出した正解ではない。また今回は $\chi$ 倍音軸だけであり、二体模型の $\eta=16$ 毛軸まで多体力学へ接続した実験ではない。

### 4.4 種なし対照

5点の単一偶数ポンプと512点の偶数31倍音ポンプは、どちらもcrossing 1166だった。したがって、今回のコヒーレント偶数族候補では純粋なインフレーション開始時刻は保たれた。

ただし追加事前条件4項のうち、「crossingまでの軌道差 $\le10^{-10}$」は不成立だった。親エンジンでも最大差は $3.23\times10^{-5}$ である。不安定軌道が、表現変更に伴う丸め差を指数増幅したためと読むのが自然だが、これは推論である。crossing分類は一致し、点ごと閉包は基準内だった。

## 5. 主張ごとの最終判定

| 主張 | 判定 | 理由 |
|---|---|---|
| 不安定な自己無撞着関係ベクトルは潜伏指数離脱する | **存続** | 元実験は波レジスタに依存せず、今回の種なし候補でもcrossing 1166 |
| 一般零閉包ベクトルは相対平衡でなければ即時離脱する | **限定して存続** | 40一般状態を含む関係ベクトル試験の結果。完全波全体の定理ではない |
| $N$ が各関係波の倍音分解能を決める | **根拠なし／上流定義と矛盾** | $\mathcal N$ と $N$ は直前論文で別仕様 |
| $N_{reg}=5$ が第63次倍音模型の多体表現である | **不成立** | 導出・縮約写像がなく、論文自身が設計選択とする |
| 旧GENESIS初期値は零二乗和閉包を満たす | **不成立** | 初期閉包誤差 $7.7\times10^{-7}$ / $7.7\times10^{-3}$ |
| 同じ微小種がインフレーションを点火し物質になる | **実証されていない** | 微小種系列の奇数パワーは増えておらず、旧大種の増加は閉包修正で約3,083分の1 |
| 完全偶奇倍音候補でもインフレーションが起きる | **今回の候補では成立** | crossing 544 / 175。旧555 / 180から5%以内 |
| 完全偶奇倍音候補でも旧物質生成率が再現する | **不成立** | 奇数パワー終端増加は旧値の約316分の1、窓率の符号と大きさも一致しない |

## 6. 論文改訂の順序

1. **論文A v2をいったん保留する。** 現在の作業稿には上流監査中の注意書きを入れた。
2. **先に多体接続論文 v2を出す。** $N_{reg}=5$ は物理導出でなく有限レジスタtoyだったこと、旧種の閉包違反、事前登録 `all_pass=false`、今回の再実験を正直に記載する。
3. **開始様式論文は限定訂正する。** 相対平衡不安定性の結果を残し、「白色倍音の海全体」ではなく「DFTで得た各関係ベクトル切片」と表現を直す。
4. **白色親生成器の契約を直す。** 入力を $(N,\mathcal N)$ に分離するか、`sample_count=N` を単なる計算規約として明記する。理論からの導出とは呼ばない。
5. **その後に論文A v2を再構成する。** $16\times8$ を使うなら有限toyと明記する。完全波へ接続するなら、少なくとも $\chi$ 倍音と $\eta$ 毛の両軸について閉包保存埋込みと縮約誤差を導出・実測する。
