# ロックした刻みで、四元数として読める組ができるか（2026-10-20）

**問い（著者、2026-10-19）：** 四元数になるには U^n = I（有限位数）と自己無撞着が要り、時間発展方向の格子間隔（刻み）が重要ではないか。ロックが外れていると四元数にならないのではないか。まず、できるかどうかを調べる（理由は後で）。
**前段：** `次元の生成構造/インフレーションの準振動と一周期ロック_20261019/`。ロックしていない刻み（den = 40、124）では、育つ方向は四元数の相手 J₂u₁ と直交し、組はできなかった。

## 方法

- 元プログラム `N3_N40_stage123_sweep_20260905/run_N3_N40_stage123_v1.py` の関数を文字どおりコピー（`run_N40_locked_step_20261020.py`）。唯一の変更は刻みを Δτ = 2π/den でなく直接与えること。
- 刻みを系自身の回転にロック：Δτ = 2π/(qσ)。σ は床（親 Z0）の iK 固有値 = 38.904662998（固有値残差 6.2×10⁻¹³）。床は一歩ごとにちょうど 2π/q 回り、U^q = I。q = 8（検討ルール R6 の位数 8）と q = 4（十字の Z₄）。
- 総時間は元の den = 40 走行と同じ τ = 25π（q = 8 で 3890 step、q = 4 で 1945 step）。
- 判定は前段と同じ量（`analyze_locked_pairing_20261020.py`）。窓は床の回転ちょうど 4 周（4q step）。

## 対照テスト（元の den = 40 の再走行）

- step 0 はビット一致。step 1 で 3×10⁻¹⁶ の丸め差（保存走行と現在の環境の固有値分解の差）が出て、床の不安定さで増幅し、step 500 で状態の最大差 3.9×10⁻⁴。
- H⊥/H の系列は全区間で一致（最大 0.042 桁、立ち上がり step 316 は同じ、最終値 0.1006 と 0.1005）。丸めをシードとする走行は計算機ごとに個別の軌道までは再現しない（既知、2026-08-28 の記録）が、力学は同じものを再現している。`results/run_meta_control.json`。

## 読み（確認前）

- 「ロックが外れていると四元数にならない」は、逆向き（ロックすれば四元数になる）には成り立たなかった。この力学（位相のみの K、複素数の配列の上の実直交回転）では、ロックの有無にかかわらず、育つ方向は四元数の相手ではない。
- ロックの効果ははっきり出た：終端が、揺れの残らない厳密な相対平衡（一本の複素モード）になる。U^q = I は、終端を「きれいに閉じる」側に効いている。
- 四元数の塊（複素の張り 2 で J₂ で閉じる）は、ロックした終端にも現れない。終端はむしろ複素数の段（{zₙ}）に戻る。四元数の段へ進むには、配列に作用する複素数の力学の外側の何か（気づきメモ §3・§4：作用ではなく関係の積、二度目の倍加、左右逆向きの読み）が要るという前の整理と整合する。
