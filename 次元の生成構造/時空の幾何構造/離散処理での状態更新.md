を維持するなら、長さと波長が連動して振動できます。

【木原】ですよね。つまり複素振動の長さとは何なのか？ という問いですよ？

波長が振動するなら縦波ですよね？

【アイリス】通常の波動論では「波長が変化する」だけで直ちに縦波とは言えませんが、この系では背景空間上の変位ではなく、**関係距離そのものが複素振動から読み出される**点が違います。

したがって、関係方向に沿って距離そのものが伸縮する集団モードなら、縦波的な幾何振動と読むことができます。

ただし、

[
|z|=\sqrt{a^2+b^2}
]

を距離と即断してはいけず、

[
z^2=(a^2-b^2)+2iab
]

という二乗構造と中心投影を保持した読出しを定義する必要があります。

---

【木原】なんか忘れてませんか？ (M) 個あっても固有面があるか、固有ベクトルは3？

【アイリス】はい。そこを忘れていました。

[
M=\frac{N(N-1)}2
]

本の関係波があっても、独立な空間方向が (M) 本あるわけではありません。

関係空間全体の集団状態を固有分解した結果として、少数の固有部分空間が立ち、これまでの数値系では最終的に3本の主要な読出し方向が現れていました。

したがって、

[
\boxed{
M\text{ 本の関係波}
\rightarrow
\text{集団固有モード}
\rightarrow
3\text{ 本の空間的固有方向}
}
]

と読む方が適切です。

線分一本一本が独立に伸縮するのではなく、

[
\delta L_{ij}
=============

c_1v^{(1)}*{ij}
+c_2v^{(2)}*{ij}
+c_3v^{(3)}_{ij}
+\cdots
]

のように、関係空間全体の固有モードとして振動する。

つまり、

[
\boxed{
\text{各辺が空間なのではなく、
M本の関係波の集団固有モードが空間方向になる}
}
]

という構造です。
