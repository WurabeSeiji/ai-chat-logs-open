## 1. 出発点の訂正：Σz² = 0 はレジスタの定義である

零二乗和は波への拘束ではなく、系が虚軸1本のレジスタ R′ を携えて閉じている帳簿の恒等式：

$$\sum_n z_n^2 + (iR')^2 = 0 \quad\Longleftrightarrow\quad \sum_n z_n^2 = R'^2 = t^2+R^2+Q^2$$

系は t,R,Q の三半径楕円体の上に乗っている。「何がゼロを担保しているか＝R′ レジスタ」が本体。

**投入の算術**（未検証・実測可能）: 第二クラスタ z′ を投入すると

$$R'^2_{\rm tot} = R'^2 + R''^2 + \sum_{e\,\in\,\text{界面}} z_e^2$$

界面の関係辺が無ければ曲率は厳密に加法。**界面レジスタ＝相互作用＝結合エネルギー＝曲率の非加法分**。
加法からのずれを測れば相互作用エネルギーが帳簿の一項として直接読める。

## 2. 棄却された中間案：状態側の六軸進行波

一時案として「全六軸に進行波 $e^{i(k\chi-\omega\tau)}$ を立て、
閉包恒等式を六次元ヌル条件 $k_\mu k^\mu=0$ と読む」を出した。
軸別解釈（$k_t$=エネルギー、$k_R$=静止質量、$k_Q$=電荷、$k_{xyz}$=運動量）は
会話録7-8の「毛＝軸方向運動量、電荷＝KK型」と整合し、CR7 の no-go も
「$k_{xyz}$ だけ動かして $k_t$ を連動させない違法ブースト」と診断できた。

**しかしこの案は二重に棄却される（木原指摘）**:

1. **τ は時間ではない**。ただの処理ステップであり、時間は質量→固有時計→時間の順で
   創発する側。存在しない時間軸を前提にした進行波表現は根本表現として失格
2. **進行波方向は無名性違反**。特定の波が特定方向に走るという状態側記述は、
   暗黙に方向を私有させる。実測も既に示していた：片側並進は r を壊し中心を動かし、
   大域並進だけが無害——系の対称性が状態側の方向づけを最初から拒否している

CR6/7 は「状態側並進は空虚（全量凍結）」かつ「非対称なら違法（無名性破れ）」の二重棄却だった。

軸別解釈そのもの（何が質量・エネルギー・電荷・運動量に見えるか）は生きる。
死んだのは「それを状態側の進行波で表す」という表現の選択である。

## 3. 採用方針：ゲージそのものが並進する

状態は静的で無名な関係配置 {z_e} のまま一切動かさない。各体 A の読出しゲージにドリフトを持たせる：

$$g_A(\chi,\tau)=\chi-\theta_A(\tau),\qquad \dot\theta_A = v_A\ \text{（各軸に）}$$

- 観測可能なのは差 $\theta_A-\theta_B$ とその率だけ。全ゲージ共通ドリフトは何も変えない
  ＝無名性が構成から自動成立（大域並進無害の実測と一致）
- 軸別読み：**t 方向ドリフト率＝エネルギー、R 方向＝質量（固有時計の刻み）、
  Q 方向＝電荷、xyz 方向＝運動量**。「質量＝固有時計」が「質量＝R方向ゲージドリフト」に一本化
- 時間は A のゲージドリフトの累積＝関係量（Page–Wootters 型。大域には時間が無い）
- 運動量はゲージ整合の共役量として**導出**する案（Barbour の best matching 型）:
  衝突イベント前後の関係配置のずれを最小にするゲージ再整列量がドリフト。
  整合操作が群作用なので保存則は Noether 恒等式として出る見込み
- 相互作用の役割：衝突は状態側で共変のまま。反射率 r が**ゲージ対に作用**し、
  相対ドリフトを $\sin^2\theta=1-r$ の角で回転させる（反跳＝ゲージ空間の回転）。
  なお CR1 では κ＝反射率 r が時間方向の唯一の結合定数だった——r は時間方向と
  空間方向の両方の結合定数になる
- 設計分岐：ドリフトを導出する（best matching・状態追加ゼロ）か格納する
  （per-body レジスタ・自由度追加）か。**導出側を推す**——無名性が自動で立ち、
  保存則が定理になる可能性があるため

実装の穴は新設不要：対話録末尾で特定済みの「D/G のゲージ読出し機構の不在」と同じ穴に、
速度・時間・運動量が全部収納される。

## 4. 核心問題：スカラーとベクトル

t,R,Q は左辺空間から観測できない虚数方向なので、そのゲージドリフトは**スカラー率**でよい。
問題は空間運動量——これはベクトルである。

直近の検討方針：$x^2+y^2+z^2-t^2=R^2+Q^2$ の空間部を $r^2$ と置き、

$$\sum r^2 = t^2 + R^2 + Q^2$$

の**四次元恒等式**として扱う。すると一体の帳簿は動径スカラー r で完結する。
では波の空間方向ベクトルはどこにレジストされているのか。

## 5. 解決案：ベクトルは関係対に分散して登録されている

**空間方向ベクトルは、どの一体のレジスタにも無い。** 孤立した一体に方向は定義不能
（方向は二体を要する関係概念）だから、四次元恒等式が r² しか持たないのは欠陥ではなく、
方向が一体の私有財産でないという帳簿の正直な表現である。

体 A の空間運動量は、対ごとの相対ドリフト率の族としてレジストされる：

$$\{v_{AB}\}_{B\neq A},\qquad v_{AB}=-v_{BA}$$

この族がベクトルに見えるのは、勝手な値を取れず低ランクのパターンに拘束されるからである。
創発空間への埋め込みが存在するなら

$$v_{AB}=\hat n_{AB}\cdot\left(\frac{\vec p_A}{m_A}-\frac{\vec p_B}{m_B}\right)$$

に因数分解できる。距離幾何学（Cayley–Menger）の古典定理：
**対距離とその変化率の族は、大域等長変換を除いて配置と運動量ベクトルを一意に決める。**
「大域等長変換を除いて」の剰余が無名性ゲージ（全体並進・回転）に過不足なく一致する。

**ベクトルとは、関係スカラー族のランク3パターンの名前である。**

この読みが無料で配るもの：

1. **運動量保存が公理不要**。$v_{AB}=-v_{BA}$ の反対称性から総運動量ゼロは恒等式
2. **空間3次元＝対ドリフト行列のランク**。N体の対スカラー族は最大ランク N−1 まで
   許されるのに実測は3で止まる（インフレーション系列「方向は三つで止まった」、
   v4 のランク3射影）。「なぜ3次元か」が「なぜ対行列のランクが3で飽和するか」という
   定量問題に変換される
3. **既存構造との整合**。符号付き面積 M(i,j)=v_i·v_j も対ごとのスカラー積で幾何を
   登録する同じ文法。CR1 の χ=Δθ は族の N=2 成分を既に測っていた

まとめ：**t,R,Q＝一体私有のスカラードリフト。空間運動量＝関係対に分散した
スカラー族のランク3パターン。ゲージ＝族の共通モード。**
四次元恒等式 Σr²=t²+R²+Q² は一体の帳簿として完結し、ベクトルは対の帳簿に住む。

## 6. N体→2体還元との関係

保持済み恒等式 $B_A=-\sum_{e\not\ni A}z_e^2$ は、任意の分割 {A, Ā} で
Ā の内部構造を消去した有効2体系（Schur 補元型の厳密縮約）を毎步定義する。
対話録が「O(M²)→O(M) の最適化」と見たものの正体の候補。

**縮約定理（候補・未検証）**: 万能相互作用 F の A への作用は、Ā の内部変数に、
少数の集約量 $(B_A,\ A_A=\sum_{e\ni A}\lvert z_e\rvert^2,\ldots)$ を通してのみ依存する。

成立すれば「N体は (N−1)+1 の2体で解ける」が定理になる。数値で直ちに白黒がつく：
Ā の内部を集約量固定でスクランブルし、A の軌道が不変かを見る。

$(A,\bar A)$ の2体縮約は動径成分（1スカラー）を与え、完全なベクトルには
対ごとの細分（§5 の族）が要る——両者は矛盾せず粗視化の階層をなす。

注意：$B_A$ の物理同定（曲率・エネルギーテンソル）は課題2で撤回済み。
本ノートでの使用は縮約のインターフェース変数（集約量）としてであり、
使う場合は事前登録つき受動診断の規約に従う。

## 10. 標準ゲージ理論との対応辞書（2026-08-19 追記）

本模型の構成は標準格子ゲージ理論と構造単位で一対一に対応する。
出典はゼロ閉塞 v4 主張案（DOI 10.5281/zenodo.21902806）の主張0。

| 局所ゲージ変換 $g_v$ | 体ごとの読出しゲージ（無名性群） | §3 |

| Wilson 線（ゲージ不変な対観測量） | 対スカラー $\Delta\theta_{AB}$・反射率 r | 共変性は実測済み（ゲージ監査） |
| **Gauss 拘束（各頂点）** | $B_v=\sum_{e\ni v}z_e^2=-\sum_{e\not\ni v}z_e^2$ | 保持済み恒等式（物理同定は課題2で撤回、構造上の席は一意） |

| **背景格子（固定）** | **なし——幾何は関係から創発**（距離幾何で頂点位置を再構成） | 標準構成から外れる唯一の点＝予言の源泉 |

**楕円体予言**：M 本の関係（辺＋対角線の長さ）→ Gram 行列 $B=-\frac12 JDJ$ →
固有分解で頂点配置が合同変換を除いて一意（v4 主張3。剰余の合同変換群＝無名性ゲージ）。
そして再構成した N 頂点が、半径 $(t,R,Q)$ の楕円体面に乗る。
過剰決定の勘定：4次元二次曲面は10自由度、N=16 頂点は16条件で**6本過剰**——
にもかかわらず v4 実測は機械精度 3×10⁻¹⁶ で乗った。

**v4 自身の限定（混ぜない）**：楕円面到達は五段仮定（S）→（C固定）→（U）→（R）下の定理。
数値模型の成分層では（S）不成立（拘束は実2本）。$\dot C=0$ は零閉鎖から出ず、
過渡・準安定では**楕円体は呼吸する**（$\dot G$形・$\dot C$スケール・$\dot X$面上運動の三分離）。
保存量は運動を決めず、許される運動の空間を決めるだけ。

**CR9d への判定基準追加**：
> (d) **楕円体検定**：対スカラー族から距離幾何で再構成した頂点が、レジスタ値
> $(t,R,Q)$ を三半径とする楕円体面に乗るか（過剰決定ぶんが検定力）。
> 定常状態で鋭く、過渡では $\dot C$ の呼吸として時系列で追う。

一体の帳簿（スカラー t,R,Q）が容器の形を決め、対の帳簿（関係族）が容器面上の
頂点位置を決める。ゲージ理論の言葉なら：Casimir（C 固定）が軌道を選び、
リンク変数が配置を選ぶ。標準理論との違いは背景の有無だけ——
「同じ結果の別写像」テーゼのゲージ理論版の言明になる。

## 11. 万能相互作用関数は既に (N−1)+1 の2体縮約を実装している（2026-08-19 追記）

§6 で候補として立てた縮約定理は、**F のレベルでは定理＋実装＋数値検証の三点セットで
既に存在する**。近似や最適化ではなく、閉塞保存が強制する厳密因数分解である。

**所在**：
- 定理：`万能相互作用多体接続_v1/媒介頂点の一意化と多体アーキテクチャ_v1.md` §3＋系2
  （2026-08-05、数値検証 `test_mediated_vertex_closure_v1.py`）
- 実装：`run_stage2_vertex_engine_v1.py` の `_vertex_rate`（115–133行）
- 継承：`統一万能関数_v1/unified_interaction_v2.py` の `UnifiedEngineV2` は
  `VertexEngineV2` を継承——現行の万能相互作用関数はこの因数分解の上で動く

**三段の構造**：

1. **一意化定理**：閉塞 $C=\sum_e z_e^2$ が任意状態で保存される必要十分条件は
   $g_2=-g_1$ かつ $R_{ee'}$ 対対称。頂点の形は閉塞保存に強制されている
2. **厳密因数分解（系2）**：算術平均強度のとき、辺 e の隣接対和（相手約 2(N−2) 本）が
   頂点モーメント $A_v=\sum_{e\ni v}|z_e|^2$、$B_v=\sum_{e\ni v}z_e^2$、$A^R_v$、$B^R_v$ に
   厳密に畳まれる。実装は `np.add.at` 集約 → `cA = A[ia]+A[ib]−2|z_e|²`（自己控除）
3. **演算量**：素朴な隣接対和 O(N³)/レジスタ点（辺対全部なら O(N⁴)）→
   集約で **O(M)=O(N²/2)**、スペクトル読出しは **O(M·N log N)/step**

**帰結**：辺 e が補集合を見る窓口は両端点の $(A_v,B_v,A^R_v,B^R_v)$ **だけ**。
CR8b（補集合スクランブル）は F については実験不要で構成から真。
残る本当の問いは書き換わる：

> **読出し層（D/G）と創発幾何も同じ集約量を通して閉じるか。**
> 対スカラー族 $\{v_{AB}\}$ の best matching 抽出が頂点集約と可換か——これは自動では出ない。
> CR8b はこちらへ向け直す。

**正直な限定**：厳密因数分解は強度の算術平均選択に乗っている（積 $R_eR_{e'}$ も
対対称で閉塞保存は許す。二体実測が平均を選んだ——系1が「段階2で再検証可能」と残す未決）。

**次回への持ち越し（2026-08-20 以降）**：この縮約構造の上に、§3〜§5 の
ゲージドリフト（速度・時間・運動量）と §10(d) の楕円体検定をどう実装するかを検討する。
実装候補の入口は D の per-body ゲージ登録と G の対読出し（§3 実装の所在）＋
頂点集約 $(A_v,B_v)$ を D/G の読出し窓口として再利用できるかの検討。
