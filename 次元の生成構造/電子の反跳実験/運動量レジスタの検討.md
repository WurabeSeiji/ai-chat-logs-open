## 1. 出発点の訂正：Σz² = 0 はレジスタの定義である

零二乗和は波への拘束ではなく、系が虚軸1本のレジスタ R′ を携えて閉じている帳簿の恒等式：

$$\sum_n z_n^2 + (iR')^2 = 0 \quad\Longleftrightarrow\quad \sum_n z_n^2 = R'^2 = t^2+R^2+Q^2$$

系は t,R,Q の三半径楕円体の上に乗っている。「何がゼロを担保しているか＝R′ レジスタ」が本体。

**投入の算術**（未検証・実測可能）: 第二クラスタ z′ を投入すると

$$R'^2_{\rm tot} = R'^2 + R''^2 + \sum_{e\,\in\,\text{界面}} z_e^2$$

界面の関係辺が無ければ曲率は厳密に加法。**界面レジスタ＝相互作用＝結合エネルギー＝曲率の非加法分**。
加法からのずれを測れば相互作用エネルギーが帳簿の一項として直接読める。

## 2. 棄却された中間案：状態側の六軸進行波

一時案として「全六軸に進行波 $e^{i(k\chi-\omega\tau)}$ を立て、
閉包恒等式を六次元ヌル条件 $k_\mu k^\mu=0$ と読む」を出した。
軸別解釈（$k_t$=エネルギー、$k_R$=静止質量、$k_Q$=電荷、$k_{xyz}$=運動量）は
会話録7-8の「毛＝軸方向運動量、電荷＝KK型」と整合し、CR7 の no-go も
「$k_{xyz}$ だけ動かして $k_t$ を連動させない違法ブースト」と診断できた。

**しかしこの案は二重に棄却される（木原指摘）**:

1. **τ は時間ではない**。ただの処理ステップであり、時間は質量→固有時計→時間の順で
   創発する側。存在しない時間軸を前提にした進行波表現は根本表現として失格
2. **進行波方向は無名性違反**。特定の波が特定方向に走るという状態側記述は、
   暗黙に方向を私有させる。実測も既に示していた：片側並進は r を壊し中心を動かし、
   大域並進だけが無害——系の対称性が状態側の方向づけを最初から拒否している

CR6/7 は「状態側並進は空虚（全量凍結）」かつ「非対称なら違法（無名性破れ）」の二重棄却だった。

軸別解釈そのもの（何が質量・エネルギー・電荷・運動量に見えるか）は生きる。
死んだのは「それを状態側の進行波で表す」という表現の選択である。

## 3. 採用方針：ゲージそのものが並進する

状態は静的で無名な関係配置 {z_e} のまま一切動かさない。各体 A の読出しゲージにドリフトを持たせる：

$$g_A(\chi,\tau)=\chi-\theta_A(\tau),\qquad \dot\theta_A = v_A\ \text{（各軸に）}$$

- 観測可能なのは差 $\theta_A-\theta_B$ とその率だけ。全ゲージ共通ドリフトは何も変えない
  ＝無名性が構成から自動成立（大域並進無害の実測と一致）
- 軸別読み：**t 方向ドリフト率＝エネルギー、R 方向＝質量（固有時計の刻み）、
  Q 方向＝電荷、xyz 方向＝運動量**。「質量＝固有時計」が「質量＝R方向ゲージドリフト」に一本化
- 時間は A のゲージドリフトの累積＝関係量（Page–Wootters 型。大域には時間が無い）
- 運動量はゲージ整合の共役量として**導出**する案（Barbour の best matching 型）:
  衝突イベント前後の関係配置のずれを最小にするゲージ再整列量がドリフト。
  整合操作が群作用なので保存則は Noether 恒等式として出る見込み
- 相互作用の役割：衝突は状態側で共変のまま。反射率 r が**ゲージ対に作用**し、
  相対ドリフトを $\sin^2\theta=1-r$ の角で回転させる（反跳＝ゲージ空間の回転）。
  なお CR1 では κ＝反射率 r が時間方向の唯一の結合定数だった——r は時間方向と
  空間方向の両方の結合定数になる
- 設計分岐：ドリフトを導出する（best matching・状態追加ゼロ）か格納する
  （per-body レジスタ・自由度追加）か。**導出側を推す**——無名性が自動で立ち、
  保存則が定理になる可能性があるため

実装の穴は新設不要：対話録末尾で特定済みの「D/G のゲージ読出し機構の不在」と同じ穴に、
速度・時間・運動量が全部収納される。

## 4. 核心問題：スカラーとベクトル

t,R,Q は左辺空間から観測できない虚数方向なので、そのゲージドリフトは**スカラー率**でよい。
問題は空間運動量——これはベクトルである。

直近の検討方針：$x^2+y^2+z^2-t^2=R^2+Q^2$ の空間部を $r^2$ と置き、

$$\sum r^2 = t^2 + R^2 + Q^2$$

の**四次元恒等式**として扱う。すると一体の帳簿は動径スカラー r で完結する。
では波の空間方向ベクトルはどこにレジストされているのか。

## 5. 解決案：ベクトルは関係対に分散して登録されている

**空間方向ベクトルは、どの一体のレジスタにも無い。** 孤立した一体に方向は定義不能
（方向は二体を要する関係概念）だから、四次元恒等式が r² しか持たないのは欠陥ではなく、
方向が一体の私有財産でないという帳簿の正直な表現である。

体 A の空間運動量は、対ごとの相対ドリフト率の族としてレジストされる：

$$\{v_{AB}\}_{B\neq A},\qquad v_{AB}=-v_{BA}$$

この族がベクトルに見えるのは、勝手な値を取れず低ランクのパターンに拘束されるからである。
創発空間への埋め込みが存在するなら

$$v_{AB}=\hat n_{AB}\cdot\left(\frac{\vec p_A}{m_A}-\frac{\vec p_B}{m_B}\right)$$

に因数分解できる。距離幾何学（Cayley–Menger）の古典定理：
**対距離とその変化率の族は、大域等長変換を除いて配置と運動量ベクトルを一意に決める。**
「大域等長変換を除いて」の剰余が無名性ゲージ（全体並進・回転）に過不足なく一致する。

**ベクトルとは、関係スカラー族のランク3パターンの名前である。**

この読みが無料で配るもの：

1. **運動量保存が公理不要**。$v_{AB}=-v_{BA}$ の反対称性から総運動量ゼロは恒等式
2. **空間3次元＝対ドリフト行列のランク**。N体の対スカラー族は最大ランク N−1 まで
   許されるのに実測は3で止まる（インフレーション系列「方向は三つで止まった」、
   v4 のランク3射影）。「なぜ3次元か」が「なぜ対行列のランクが3で飽和するか」という
   定量問題に変換される
3. **既存構造との整合**。符号付き面積 M(i,j)=v_i·v_j も対ごとのスカラー積で幾何を
   登録する同じ文法。CR1 の χ=Δθ は族の N=2 成分を既に測っていた

まとめ：**t,R,Q＝一体私有のスカラードリフト。空間運動量＝関係対に分散した
スカラー族のランク3パターン。ゲージ＝族の共通モード。**
四次元恒等式 Σr²=t²+R²+Q² は一体の帳簿として完結し、ベクトルは対の帳簿に住む。

## 6. N体→2体還元との関係

保持済み恒等式 $B_A=-\sum_{e\not\ni A}z_e^2$ は、任意の分割 {A, Ā} で
Ā の内部構造を消去した有効2体系（Schur 補元型の厳密縮約）を毎步定義する。
対話録が「O(M²)→O(M) の最適化」と見たものの正体の候補。

**縮約定理（候補・未検証）**: 万能相互作用 F の A への作用は、Ā の内部変数に、
少数の集約量 $(B_A,\ A_A=\sum_{e\ni A}\lvert z_e\rvert^2,\ldots)$ を通してのみ依存する。

成立すれば「N体は (N−1)+1 の2体で解ける」が定理になる。数値で直ちに白黒がつく：
Ā の内部を集約量固定でスクランブルし、A の軌道が不変かを見る。

$(A,\bar A)$ の2体縮約は動径成分（1スカラー）を与え、完全なベクトルには
対ごとの細分（§5 の族）が要る——両者は矛盾せず粗視化の階層をなす。

注意：$B_A$ の物理同定（曲率・エネルギーテンソル）は課題2で撤回済み。
本ノートでの使用は縮約のインターフェース変数（集約量）としてであり、
使う場合は事前登録つき受動診断の規約に従う。

## 11. 万能相互作用関数は既に (N−1)+1 の2体縮約を実装している（2026-08-19 追記）

3. **演算量**：素朴な隣接対和 O(N³)/レジスタ点（辺対全部なら O(N⁴)）→
   集約で **O(M)=O(N²/2)**、スペクトル読出しは **O(M·N log N)/step**

**帰結**：辺 e が補集合を見る窓口は両端点の $(A_v,B_v,A^R_v,B^R_v)$ **だけ**。
CR8b（補集合スクランブル）は F については実験不要で構成から真。

## 12. ゼロ閉塞 v4 精読で立った論点（2026-08-19 追記）

**(a) 記号衝突の警告——「B」が二つある。** 本ノート §6・§11 の $B_v=\sum_{e\ni v}z_e^2$
（頂点モーメント、相互作用エンジンの集約量）と、v4 の $B=-\frac12 JD^{\circ2}J$
（二重中心化 Gram 行列、読出し幾何）は**別の対象**である。さらに v4 主張5・14 は
三つの符号（複素の実/虚・面次元符号 $s_e$・Gram 固有値符号）を結ぶ写像がいずれも
未導出と明示している。辞書を書くとき混同しないこと。

**(b) v4 18-f 選択肢3は本ノートのゲージ読みと同型。** 主軸の向きは約2000ステップで
乱数基準まで拡散する（18-a 実測）。v4 はこの読み方を三つ挙げ、
「**純関係系には向きを固定する外部基準が無いのだから、絶対座標系が拡散するのは
欠陥ではなく当然の帰結**」（選択肢3）が関係性の前提から自然としている。
これは本ノート §3〜§5 の「絶対方向は無名性ゲージであり、物理は対スカラー族と
向きに依らない量だけ」という設計と独立に同じ結論である。
実際 v4 18-b は、向きが拡散しても**向きに依らない二次形式
$\sum_e\lvert x_e\rvert^2$ と $\sum_e x_e^2$（複素）が転移を貫通して保存する**
（$10^{-8}$〜$10^{-7}$ 精度・読出し層のみ）ことを実測している——
「向きは帳簿に無い、大きさは帳簿にある」の直接証拠。

**(c) 解析的保存則の導出候補——v4 の宿題は媒介頂点定理で部分的に討てる可能性。**
v4 は主張13・18-b の保存を「数値精度内の保存であって解析的証明ではない。
更新則からの導出は未実施」と分類し、§3「F は導出していない。
$X^{\mathsf T}F(X)=\frac12\dot C$ を満たす F の特定が動力学への最初の関門」と結ぶ。
一方 `媒介頂点の一意化` §3 定理は、非線形頂点部について**閉塞 $C=\sum_e z_e^2$
（レジスタ点ごと）の厳密保存を証明済み**である。残る検討は二段：
①線形部（倍音スライスごとの Cayley）が読出し層の $\sum_e x_e^2$
（$x_e=$ 倍音を先に和した量 ≈ レジスタ点 $n=0$ の値）を保存するか、
②スライス間クロス項の扱い。通れば v4 18-b/18-c の保存が**定理に昇格**し、
F の資格条件 $X^{\mathsf T}F(X)=\frac12\dot C$ の検証が実装済み F で閉じる。
**未検証の導出候補**として登録する。

**(d) v4 が動力学設計に指定した出発形。** 呼吸する楕円体は
$X^{\mathsf T}\widehat GX=\rho^2$、$\det\widehat G=1$ で書き、
$\dot{\widehat G}$（体積を変えない変形＝形・向き）／$\dot\rho$（スケール）／
$\dot X$（面上運動）を分離する（0-c′）。本ノート §3 のゲージドリフトを実装するとき、
ドリフトの置き場所はこの三分離のどこかに対応するはずである
（候補：並進＝$\dot X$、加速度＝$\dot{\widehat G}$ の向き成分、
インフレーション＝$\dot\rho$）。**対応の確定は明日以降の実装検討の入口に置く。**

## 13. 体ゲージの定式化（2026-08-19 追記。実装の根拠となる定義）

### 13.1 定義（体ゲージ）

各体 $A$ に、読出し層の対象として**体ゲージ**（body gauge）

$$\Phi_A \;=\; \big(\ \theta_A,\ \ O_A,\ \ (\widehat G_A,\ \rho_A),\ \ (\phi^t_A,\ \phi^R_A,\ \phi^Q_A)\ \big)$$

を与える。成分と役割：

| 成分 | 空間 | 役割 | 変化率の読み |
|---|---|---|---|
| $\theta_A$ | 創発3次元フレーム内のオフセット | **並進**（位置） | $\dot\theta_A$＝速度ベクトル |
| $O_A$ | $SO(3)$ | **方向の回転**（枠の向き） | $\dot O_A O_A^{-1}$＝角速度 |
| $\widehat G_A$（$\det=1$）・$\rho_A$ | 正定値対称／正スカラー | **間隔**（局所計量の形・向きとスケール） | $\dot{\widehat G}_A$＝加速度・潮汐（歪み）、$\dot\rho_A$＝スケール変化 |
| $\phi^{t,R,Q}_A$ | スカラー3本 | 虚軸方向のドリフト（観測不能方向） | 率＝エネルギー・質量（固有時計）・電荷の読み（§4） |

**ゲージは状態 $\{z_e\}$ の一部ではない。** D（万能次元読出し）が保持・更新する読出し層の対象であり、
F（万能相互作用）はゲージを参照しない。状態は相互作用でのみ変わり、
運動学（位置・速度・時間）はすべてゲージ側に住む（§3）。

**ゲージ群と無名性**：全体ゲージ変換（全 $A$ に共通の $(\theta,O,\rho)$ 作用）は
観測量を変えない——これが無名性の正確な定式化である。群は並進と回転の半直積に
スケールを添えたもの（相似変換群の型）。**観測可能なのは差
$\Phi_A\Phi_B^{-1}$ だけ**（相対位置・相対速度・相対向き・時計率の比）。
距離幾何の「合同変換を除いて一意」（v4 主張3）の剰余群と過不足なく一致する。

### 13.2 接続と曲率（ゲージの隣への移り方）

Cartan の意味の接続に対応するのは次の二つの規則である（いずれも仮説・実装対象）：

1. **平行移動＝best matching**（§3）。イベント間で $\Phi_A$ を、関係配置の読出し差を
   最小化するよう再整列する。相互作用がなければ再整列量は一定率＝**測地線（慣性）**。
   判定は CR9b
2. **曲率＝計量歪みの源**。他体の局所レジスタ（界面 $\sum z_e^2$、頂点モーメント $B_v$ が候補、
   §12(a) の記号注意）が $\widehat G_A$ を歪ませる。歪んだ物差しで等速ドリフトを読むと
   加速度が現れる——「速度も加速度もゲージで表現する」の正確な意味。
   相互作用イベントは対ゲージに反射率回転（$\sin^2\theta=1-r$）を掛ける＝**離散接続係数**

### 13.3 先行研究との対応（Cartan 動標構の系譜）

「間隔を変え、並進し、方向も回転するゲージ」は、微分幾何では
**Cartan の動標構（moving frame）＋アフィン接続**（1923–25）として定式化済みの型である。
Einstein の用いた Riemann 幾何はその**間隔（計量）成分**にあたる。

| 標準理論の概念 | 本模型の対応物 | 資格 |
|---|---|---|
| 多様体の点 | 体（頂点） | — |
| 計量 $g_{\mu\nu}$（Riemann 1854） | 読出し二次形式 $G$（v4 0-c: $X^{\mathsf T}GX=C$）＝区間ゲージ | 条件付き定理（五段仮定） |
| **Weyl のスケールゲージ（Eichung 1918）** | $\rho$。**「ゲージ」の語の原義＝間隔の較正**（課題3 §3.6 の語源指摘と同じ） | 対応関係 |
| vierbein／tetrad（正規直交枠の場） | 体ゲージの $(\theta_A, O_A)$ | 定義 13.1 |
| Levi-Civita／スピン接続 | 衝突イベントの対ゲージ更新則（反射率回転） | 仮説 |
| 平行移動 | best matching によるイベント間再整列 | 仮説 |
| 測地線 | 相互作用なしのドリフト等速性 | CR9b で検定 |
| 曲率テンソル | $\dot{\widehat G}$（v4 0-c′ 三分離の形・向き成分） | 対応候補 |
| **捩率（torsion）＝並進ゲージ場** | 並進ドリフトの非可換部 | **未検討** |
| ポアンカレゲージ理論（Utiyama 1956・Kibble 1961・Sciama）：重力＝並進⋊回転のゲージ化 | 体ゲージ群の連続版 | 対応関係 |
| 遠隔平行性（Einstein 1928）：重力を並進ゲージ（捩率）だけで書く | 並進ドリフト主体の定式化と比較対象 | 未検討 |

**位置づけ**：標準理論はこの一つの対象を、GR 側（計量・枠・接続）と内部ゲージ側
（位相・Yang-Mills）に**分割した**。1918年に間隔較正だった Eichung が 1929 年に
位相変換へ読み替えられた経緯（課題3 §3.6）はその分割の痕跡である。
本模型の体ゲージは分割前の Cartan 型——並進・回転・間隔を一個の枠が担う——を
**関係だけの空間で離散的に再構成する**位置にある。基礎の違いは一点：
標準理論の枠は背景多様体の各点に立つが、本模型の枠は**体（関係の端点）に立ち、
枠の間の幾何そのものが関係から創発する**（§10 の辞書最終行と同じ相違点）。
関係主義側の先行系譜としては Penrose スピンネットワーク（v4 §4 が引用済み）、
Regge 計算（離散曲率）、Barbour の best matching（§3）が対応する。

### 13.4 未決の定式化課題（実装前に決める順）

1. **創発フレームの基底問題**：$\theta_A$ の住む「創発3次元フレーム」は対スカラー族の
   距離幾何再構成（§5）で得るが、v4 18-a により軸の向きは拡散する。したがって
   $\theta_A$ は絶対枠でなく**配置自身に相対的な枠**（shape space 型）で定義しなければ
   ならない。Littlejohn–Reinsch のシェイプ空間分解（v4 §4 引用済み）が参考
2. **best matching の距離関数** $d$：ゲージ監査で共変と確定した量から組む（§8-2）
3. **反射率回転の作用面**：対ゲージのどの2平面に $\sin^2\theta=1-r$ を掛けるか
4. **c=1 の起源**：ゲージ側設計での速度上限。状態側分散による説明は使わない（§2 棄却）。
   候補：$\rho$ と $\dot\theta$ を結ぶ楕円体拘束（v4 0-c の C 固定が率にも効くか）——未検討
5. **捩率の有無**：並進ドリフトを非可換にする構造があるか
