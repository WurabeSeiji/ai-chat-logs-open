物理学には、少し不思議なところがあります。

理論が深くなるほど、対称性が増えていきます。

ローレンツ対称性。
ゲージ対称性。
SU(3)。
SU(2)。
U(1)。

置換対称性。
シンプレクティック構造。

どれも現代物理を支える重要な構造です。

しかし、ここで一度、逆向きに考えてみました。

**これらは本当に、それぞれ別々の原理として最初から置かなければならないのでしょうか。**

今回の論文で調べたのは、かなり極端な問いです。

> **ごく少数の閉包条件だけを置いたとき、現代理論物理が要求している対称性のどこまでが、後から自動的に現れるのか。**

結果は、私自身が予想していたより強いものでした。

時空の負符号も、曲率半径も、有限量子化も、Born型の二乗重みも、simplex幾何も、固定点対称性も、そして条件付きではありますが標準模型の

SU(3)×SU(2)×U(1)

に対応する大域ゲージ群まで、かなり長い範囲を同じ公理系から一本の導出鎖として並べることができました。

しかも、この系には既導出範囲で連続的に調整する自由パラメータがありません。

外から指定する本質的な量は、離散整数 N だけです。

今回は、その全体像を一般向けに紹介します。

## 出発点は、たった一つの奇妙な式です

第一公理は、

Σxₙ² ＝ 0（n ＝ 1 … M）

です。

ただし、xₙ は複素数です。

実数だけなら、二乗を全部足してゼロにするには、全部ゼロにするしかありません。

しかし複素数なら違います。

最小の例では、

x² + y² ＝ 0

から、

y ＝ ±ix

が出ます。

つまり虚数方向は、計算を便利にするために後から入れた道具ではありません。

**非自明な二乗閉包を成立させるために必要な方向として現れます。**

ここが今回の論文の出発点です。

## 「虚数」は、見えない方向の符号なのではないか

たとえば、

(x, y, z, iR)

という四成分を考えます。

第一公理は、

x² + y² + z² + (iR)² ＝ 0

なので、

x² + y² + z² ＝ R²

になります。

これは見慣れた球面です。

重要なのは、右辺の R² を後から追加していないことです。

最初からあった iR という複素方向を、観測者が直接読まないだけです。

すると、その見えない方向の座標値が、見える三方向からは**曲率半径**として現れます。

さらに、

(x, y, z, it)

なら、

x² + y² + z² + (it)² ＝ 0

ですから、

x² + y² + z² − t² ＝ 0

になります。

ローレンツ型の負符号は、外から (+, +, +, −) という計量を置いたから出たのではありません。

単に、

(it)² ＝ −t²

です。

この見方では、時間の負符号と曲率半径の負符号は、同じ起源を持ちます。

## 時間・曲率・内部量は、最初から別物ではない

さらに、

(x, y, z, it, iR, iQ)

とすると、

x² + y² + z² ＝ t² + R² + Q²

です。

ここで私は、t、R、Q を最初から時間・曲率・内部量という別々の存在だとは置きません。

基礎構造では、どれも同種の観測不能な複素方向です。

ある観測写像で時計として読まれるものを t と呼ぶ。

曲率尺度として読まれるものを R と呼ぶ。

内部量として読まれるものを Q と呼ぶ。

つまり、

> **名前が先にあるのではなく、読まれ方によって名前が付く。**

という順序です。

これはかなり重要です。

## では、何でも好きに読める理論なのか

ここは最も誤解されやすいところです。

答えは逆です。

**この模型は、かなり窮屈です。**

基礎成分には名前を付けませんが、だからといって何でも好きに解釈できるわけではありません。

許される構造は同時に、

- 複素二乗の零閉包
- 有限回で完全に戻る位相閉包
- simplex としての距離整合
- 倍音構造
- 自己無撞着な固定点

を満たさなければなりません。

概念的には、

S(許容) ＝ S(零閉包) ∩ S(有限回帰) ∩ S(simplex) ∩ S(倍音) ∩ S(自己無撞着)

です。

つまり、候補は多くても、全部の条件を同時に通過しなければ残れません。

この理論の方向は、何でもあり、ではありません。

むしろ、

**極めて少ない入力 ＋ 極めて強い拘束 ⟹ 非常に豊かな構造**

です。

私は今回、ここが最も重要な結果の一つだと考えています。

## 第二公理は「有限回で必ず元へ戻る」

第二公理は、

Uᴺ ＝ I

です。

N 回作用させれば、完全に元へ戻る。

すると固有値は λᴺ ＝ 1 を満たすので、

λₘ ＝ e^(2πim/N)

になります。

つまり、

- 有限回帰
- 位相の離散化
- 巡回群 Zₙ
- 円分構造

が一度に出ます。

以前の研究で見つけた

cos²(πm/N)、sin²(πm/N)

という Born 型二乗重みも、この有限回帰を二チャネルから読んだときに現れます。

確率を最初から入れたのではありません。

まず有限回帰する位相構造があり、その二乗読出しとして Born 型の重みが出ます。

これは以前の記事で詳しく扱った部分です。

## 第三公理で、関係が「空間」になります

次に同じ N を、今度は頂点数として読みます。

すると全二体関係の数は、

M ＝ N(N−1)/2

です。

この全二体距離が simplex として整合することを要求します。

すると、絶対座標を最初から置かなくても、距離関係だけから幾何が立ち上がります。

しかも simplex には境界作用素があり、

∂² ＝ 0

です。

双対化すれば、

d² ＝ 0

です。

つまり、一つの simplex 条件から、

- 距離幾何
- homology
- cohomology
- discrete differential form

への入口まで同時に現れます。

ここまで来ると、空間を最初から置くという考え方そのものが必要なのか、かなり怪しくなってきます。

## 第四公理は「自分で作った世界と、自分自身が一致する」

第四公理は、

X ＝ F(X)

です。

自己無撞着条件です。

生成した状態をもう一度生成規則へ入れても、自分自身へ戻る。

この固定点 X* に対して、それを変えない変換だけを集めれば、

G(X*) ＝ { g ∈ G ｜ g·X* ＝ X* }

という stabilizer が現れます。

つまり、対称性を最初から、この群です、と宣言しなくても、

> **自己無撞着に存在できた構造を変えない変換**

として対称性を読むことができます。

ここで第二公理 Uᴺ ＝ I との関係も見えてきます。

一方は作用の有限自己回帰。

もう一方は状態の自己回帰。

どちらも、より上位には**自己閉包**という同じ構造を持っています。

## そして、三次元は偶然ではなかった

以前の数値実験 make_parent では、自己無撞着なコヒーレント波を発展させると、多数の候補方向から三つの主軸が選択的に卓越することを確認しました。

しかし今回整理すると、三次元性には数値実験とは別の幾何学的な導出経路もあります。

第一公理 Σxₙ² ＝ 0 を実部と虚部に分けると、

aᵀa ＝ bᵀb、aᵀb ＝ 0

です。

つまり、

‖a‖ ＝ ‖b‖、a ⊥ b

という等長直交構造が出ます。

直交する平面があり、その法線方向がある。

さらに位相閉包と simplex 幾何を重ねると、三つの識別可能な主軸を持つ楕円構造へつながります。

数値側では三主軸へのスペクトル集中。

幾何側では三次元楕円構造。

別々の道から、同じ 3 が出てきました。

残っているのは、三方向を作れるかどうかではありません。

**なぜこの三方向選択が広い N、初期条件、seed に対して普遍的なのかを一般定理にすること**です。

## ここから、標準模型のゲージ群まで見えてきた

今回、最も驚いた部分の一つです。

零閉包を六つの複素レジスタで読むと、

ΣXₙ² ＝ 0（n ＝ 1 … 6）

です。

これは複素6自由度に複素拘束が1本ですから、

複素次元 ＝ 6 − 1 ＝ 5

です。

ここは単純な次元計数です。

そして、この5複素自由度が自己無撞着な

V ＝ V₃ ⊕ V₂

という Hermitian 分解を保存する sector に入ると、保存群は

U(3)×U(2)

です。

さらに全体位相の冗長性を除くと、

S(U(3)×U(2))

になり、既知の群論として、

S(U(3)×U(2)) ≅ ［SU(3)×SU(2)×U(1)］/Z₆

です。

これは標準模型の忠実な global gauge group と同じ形です。

ここは慎重に区別する必要があります。

**私は、第一公理だけから標準模型を完全導出した、と言っているのではありません。**

厳密に出ているのは複素5自由度までです。

そこから 3⊕2 の Hermitian 分解が自己無撞着に選択された場合、標準模型と同じ大域ゲージ群が数学的に現れる。

残る問題は、

> **なぜ自己無撞着な動力学が、その stabilizer を選ぶのか。**

です。

しかし逆に言えば、標準模型の三つのゲージ群を最初から別々に置かなくても、**一つの5複素自由度構造の保存群として同時に現れ得る**ところまで来ています。

## しかも SU(3) への道は一つではなかった

さらに内部量を、

Q² ＝ Q₁² + Q₂² + Q₃²

と細かく読むこともできます。

すると内部三重項 (Q₁, Q₂, Q₃) が現れます。

これに Hermitian structure を入れれば、内部 U(3)、そして SU(3) への別経路が見えます。

また、(R, Q₁, Q₂, Q₃) を四成分として読むと、

SU(4) ⊃ SU(3)×U(1)

という既知の群論へ接続します。

一方で四次元側には、

Spin(4) ≅ SU(2)×SU(2)

があります。

すると、

SU(4)×SU(2)×SU(2)

という Pati–Salam 型構造への経路まで、同じ零閉包の別読出しとして見えてきます。

私はこれを、Pati–Salam が導出された、とは分類していません。

重要なのは別の点です。

**異なる読出し方をすると、既知の大統一的群構造へ向かう複数の経路が、同じ零閉包から現れる。**

ここが面白いのです。

## 「読み方が複数ある」は弱点ではない

普通なら、

と思います。

しかし、この模型ではそこが逆です。

基礎成分には名前がありません。

simplex として整合しなければならない。

つまり対称性すら、外から選ぶものではなく、

**強い閉包条件を生き残った構造の自己同型**

として現れる可能性があります。

この順序の逆転が、今回の論文の本当の主題です。

## なぜ、こんなに多くの対称性が必要だったのか

現代物理を見ると、自然界には驚くほど多くの対称性があります。

普通は、それぞれに深い物理的意味があると考えます。

もちろん、それは正しいと思います。

しかし今回の模型からは、別の見方が出てきます。

**対称性が多いのは、自由だからではない。自由が極端に少ないからではないか。**

閉じなければ存在できない。

元へ戻らなければならない。

距離が互いに矛盾してはいけない。

自分自身を生成しても自分自身でなければならない。

そのような極端に強い条件を全部同時に満たそうとすると、残った構造は必然的に高い対称性を持つ。

つまり、

**高い対称性 ＝ 高い自由度の結果ではなく、高い拘束性の結果**

なのかもしれません。

私は今回、この可能性がかなりはっきり見えてきたと考えています。

## N は宇宙の個数ではなく、顕微鏡の分解能に近い

ここは誤解されやすいところです。

この模型で現れる N は、宇宙が本当は N 個の要素でできている、という意味ではありません。

もっと近いのは、**顕微鏡の分解能**です。

同じ対象でも、低い倍率なら粗く見えます。倍率を上げれば、それまで一つに見えていた構造がさらに細かく分かれて見えます。

この模型でも同じで、

Uᴺ ＝ I

という有限回帰の N は、その閉包構造をどの細かさで読んだかを表す有限の読出し次数として扱います。

**N ＝ 存在する要素数ではなく、読出しの分解能**

です。

したがって、N を大きくすれば、同じ閉包構造をさらに細かく読んでいくことができます。

そのとき、

M ＝ N(N−1)/2

も、世界に本質的に M 本の関係が存在する、という意味ではありません。

その分解能で N 個の区別をしたときに、読出し可能になる全二体関係数です。

顕微鏡の倍率を上げたからといって、観測対象そのものに新しい構成要素を追加したわけではありません。

同じように、この模型でも N を細かくすることは、新しい物理自由度を追加することではなく、**同じ閉包構造をより高い解像度で読むこと**です。

したがって、この模型には、正しい N を決める方法、という問題はありません。

どの N で読むかは、観測・選択の問題です。

重要なのは N の値そのものではなく、どの有限解像度で読んでも、その背後で同じ閉包原理が働いていることです。

また、この模型には、

- 曲率を合わせるための R
- 時間を合わせるための t
- 内部対称性を合わせるための Q
- Born 型二乗重みを合わせるための角度
- ゲージ群を合わせるための連続係数

を独立な調整パラメータとして置いていません。

R、t、Q も、N も、基礎存在へ外から貼り付ける調整ノブではなく、観測・読出しの側で現れる量として扱います。

## 100年かけて積み上げた対称性を、逆向きに読んでみる

> **なぜ自然は、これほど整った数学だけを何度も使うのか。**

すると、そこから現代理論物理で見慣れた構造が次々に姿を現す。

もしこの方向が正しいなら、自然界が対称性を選んでいるのではないのかもしれません。

**閉じて存在できる構造が、そもそもほとんど残っていない。**

だから、残ったものが美しく見える。

今回の論文は、その可能性をかなり本気で検討したものです。

## 論文について

論文では、この記事よりはるかに厳密に、

- 本稿内で厳密に導出したもの
- 既知数学との接続
- 過去の自己論文で構成・数値確認済みのもの
- 条件付き導出
- 未一般化
- 未導出の動力学

を分けています。

特に、SU(3)×SU(2)×U(1) については、出た、という一言で済ませず、どこまでが厳密な群論で、どこからが自己無撞着な物理的選択の問題なのかを分離しました。

一般向けの記事ではかなり強く書きましたが、論文側では反証可能な形に切り分けています。

今回の一番短い要約は、これです。

**少ない公理から多くの構造が出たのではない。**

**強すぎるほどの閉包条件を課したら、許される構造が少なくなり、その残り方が現代物理の対称性に似てきた。**

もしこの読み方がさらに一般化できるなら、物理学で、基本法則、と呼んできたものの一部は、独立な法則ではなく、

**自己無撞着に存在するための幾何学的な生存条件**

だったのかもしれません。
