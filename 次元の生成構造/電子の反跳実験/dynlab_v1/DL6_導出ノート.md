## 1. 命題 DL6-1（離散 Gauss 定理——厳密恒等式・新規）

頂点集合の任意の分割 $\{S,\bar S\}$ について、頂点モーメント $B_v=\sum_{e\ni v}z_e^2$ は

$$\boxed{\;\sum_{v\in S}B_v\;=\;2\!\!\sum_{e\subseteq S}\!z_e^2\;+\;\sum_{e\in\partial S}z_e^2\;}$$

を満たす（$e\subseteq S$：両端点が $S$ 内の辺、$\partial S$：$S$ と $\bar S$ を跨ぐ辺）。

**証明**　$\sum_{v\in S}B_v=\sum_{v\in S}\sum_{e\ni v}z_e^2$ で、辺 $e=\{a,b\}$ は
両端点が $S$ 内なら2回、片方だけなら1回、どちらも外なら0回数えられる。∎

**読み**　左辺＝領域 $S$ の「電荷総和」、右辺第一項＝内部エネルギー、
第二項＝**境界を貫く流束**。すなわち

$$\text{境界流束}\;=\;\sum_{e\in\partial S}z_e^2\;=\;\sum_{v\in S}B_v-2\!\!\sum_{e\subseteq S}\!z_e^2$$

**界面レジスタ（[F1] §3.3 の曲率非加法項）とは、この境界流束そのものである。**
閉塞 $C=0$ の下では $S=V$ 全体で両辺が $2C=0$ となり、[F1] の
「閉空間で総電荷ゼロ」がこの恒等式の特別な場合として出る。
格子ゲージ理論の Gauss 法則との**写像の構成**（[F1] §8 の課題）は、
この恒等式を出発点とする。

## 2. 経路A（独立な第二経路）：流束保存＋3次元 ⇒ 逆自乗

**位置づけの訂正（2026-08-19）**：主経路は §3 の [AB] 調和閉鎖経路（二体で導出・検証・公開済み）
である。本経路はそれと独立な N 体側からの経路であり、成立すれば二経路収束の証拠になる。
なお本経路の予備計算として、海の静的場方程式 $z_e^2=(B_u+B_v)/2$ の自己無撞着固定点は
$N\ne4$ で自明（$\phi\equiv0$、固定点写像の固有値 $(N-2)/2$——`verify_derivation_checks_v1.py` V7 で保存・再現済み）であり、
**非自明な場は源（物質）があって初めて立つ**ことが分かっている。

**条件付き導出**　次の二前提の下で逆自乗則が従う：

- **前提 A1（流束保存）**：体 $A$ を含む領域 $S_r$（創発空間で半径 $r$ の「殻」の内側）を
  拡げるとき、境界流束 $\Phi(r)=\sum_{e\in\partial S_r}z_e^2$ が $r$ に依存しない区間が存在する
- **前提 A2（等方3次元）**：創発空間の読出しが3次元で（DL3）、流束が殻上に
  等方に分配される

このとき殻の面積は $\propto r^2$ だから、**単位立体角あたりの流束密度は $\propto1/r^2$**。
対結合の強度がこの流束密度で決まる（媒介頂点の $R$ 重み付き集約が担う）なら、
対加速度は $\propto1/r^2$。∎（条件付き）

**判定への分解**　逆自乗の検定は「1/r² が出るか」の一発勝負ではなく、
前提を独立に測る三段にする：
(i) $\Phi(r)$ の $r$ 依存性（A1 の直接検定——**恒等式 DL6-1 により
$\Phi(r)$ は毎瞬厳密に計算できる**）、
(ii) 流束の角度分布（A2）、
(iii) 加速度（$\widehat G$ 歪み・DL5 の反跳）の距離依存性。
(i)(ii) が通って (iii) が $1/r^2$ なら経路Aの導出が閉じる。
(i)(ii) が通って (iii) がずれるなら、結合と流束の関係（$R$ 集約の形）が特定される。

## 3. 経路B（主経路・導出済み）：AB二体論文の逆二乗則【2026-08-19 原典精読で訂正】

**逆二乗則は二体系で既に導出・数値検証・公開済みである**（[AB] v4、DOI 10.5281/zenodo.21441081）。
初版の本ノートはこれを「移植課題」とだけ書き中身を記載していなかった。訂正して主経路に置く。

**[AB] v4 の導出（原典 §5〜§7）**：

$$\alpha_n=R\lvert\omega_n\rvert^2\ \text{（未来位相位置中心の加速度写像）},\qquad
\lvert\omega_n\rvert\,\Delta\theta_n=2\pi\omega_1\equiv\Omega\ \text{（調和閉鎖：}\Delta\theta_n=2\pi/\lvert n\rvert,\ \omega_n=n\omega_1\text{）}$$

$$\Longrightarrow\quad \alpha_n=\frac{R\Omega^2}{\Delta\theta_n^2},\qquad
L_{\rm read}=\kappa\Delta\theta_n\ \Rightarrow\ \alpha=\frac{R\Omega^2\kappa^2}{L_{\rm read}^2}$$

- 距離指数：零次で**厳密 −2**、速度フィードバック $d\omega/d\tau=\kappa\alpha$（κ=0.2）下で
  **−1.999937891** で存続。運動学的整合 $\omega-\omega_0=\kappa\int\alpha\,d\tau$ は $8.61\times10^{-16}$
- 逆二乗を生むのは**二条件の同時成立**：加速度写像 $\alpha=R\omega^2$ と、
  角速度・位相セル幅が独立に選べないという調和閉鎖の双対
- $1/L^2$ の外部入力・球殻希釈・三次元背景・重力定数は不使用（原典 §7.2）
- 保存量 $\mathcal I$（原典 §13.4）による有界性、零次 no-go 定理、RK4 連続極限判別まで込み
- **原典が明記する未検証範囲**：任意の閉鎖系・任意の倍音配置・非調和更新・
  任意の距離読出しへの一般化

**したがって DL6 の課題は「逆二乗の導出」ではなく「[AB] 機構の N 体・体ゲージ枠組みへの
一般化」である**。移植辞書：

| [AB] の部品 | 体ゲージ語法の対応 | 状態 |
|---|---|---|
| 位相セル幅 $\Delta\theta_n$／読出し距離 $L=\kappa\Delta\theta$ | 対位相差レジスタと創発空間距離（DL2 の $\mp30^\circ$ 配置は位相距離そのもの） | 対応の成立が移植の核心 |
| 加速度写像 $\alpha=R\omega^2$ | 対ゲージの計量歪み $\dot{\widehat G}$／誘導レート（Dyn-1） | 対応候補 |
| 調和閉鎖 $\omega_n=n\omega_1$ | 集団時計 $\omega_1=\pi/72$ と倍音構造（[F1] §4.1） | 対応候補 |
| 速度フィードバック $\kappa=r$ | 離散接続係数（反射率回転） | 対応候補 |
| 保存量 $\mathcal I$・零次 no-go | 構造定理 Dyn-5（一階誘導＋ゲージ記憶） | 整合確認要 |

経路A（下記・流束経路）は**独立な第二経路**に位置づけを訂正する。
両経路が N 体で同じ $1/r^2$ に到達すれば独立二経路の収束になる。

## 4. 三角閉路ホロノミー（曲率の第一候補）

**定義候補**（DL6 実装時に一意固定・事後変更しない——[F1] §7）：
対 $(A,B)$ の**輸送作用素** $U_{AB}\in SO(3)$ を、$A$ の局所枠を $B$ の局所枠へ
重み付き Procrustes（DL4-3 の閉形式）で整列する回転とする。三角閉路の積

$$W_{ABC}=U_{AB}U_{BC}U_{CA}$$

の恒等からのずれ（回転角 $\varepsilon_{ABC}$）が**離散ホロノミー＝曲率の読み**である。

**導出できる基準点**：真空（正単体・完全縮退）では局所枠が定義されないため
$W$ は未定義——**曲率の読みも物質と共に生まれる**（規約1の局所版）。
物質相での予言（条件付き）：$\varepsilon_{ABC}$ は三角形の「面積×局所物質密度」に
一次で比例するはずである（連続極限で曲率2形式の面積分に対応する型）。
比例の成立自体が Cartan 対応（[F1] §5.2 curvature 行）の検定になる。

## 7. 第3編からのプロトコル追補（実行前固定・2026-08-19）

DL4 追補1〜4（枝検出つき輸送・測定区間 τ≥15000・局所虚方向の記録・判定設計規約）を
そのまま継承する。DL6 固有の追補は次の3件。

**追補7（経路Aの「3次元」前提の定量化）**。経路A（流束保存＋3次元⇒逆自乗）の
前提「3次元」は、第3編の実測により「厳密 rank-3」ではなく
**正方向内の上位3軸優勢**（λ3>0 全区間 100%・η_3+=0.728・W_-=0.304）である。
経路Aの前提判定にはこの三条件の実測値を書き込み、
「逆自乗の成立域＝この前提が満たされる領域」として登録する。

**追補8（三角閉路ホロノミーの二成分登録）**。曲率候補の三角閉路ホロノミー（§4）は、
第3編の π_parity: D↦det D 分離をそのまま輸入し、
**Z₂ パリティ成分**（χ 型・離散）と **SO(3) 回転成分**（連続角）の
二成分に分けて事前登録する。第3編の χ（時間方向の閉路）に対し、
これは空間方向（体間三角形）の閉路量であり、直接の後継観測量である。

**追補9（真空基準点の確認済み事項）**。§4 の「真空では局所枠が定義されない」は
第3編 J1/K5（代数的不存在・数値的非持続）で実測確認済み——導出から実測事実へ昇格。

**追補10（U_AB の一意固定・2026-08-19。事後変更しない）**。§4 の定義候補を次のとおり
一意化する。対 (A,B) の輸送作用素は

  U_AB = 無重み Procrustes（Kabsch）で A の局所枠を B の局所枠へ整列する SO(3) 回転

とする（det=+1 へ射影。無重みの根拠：第3編 M7 で Σx=ΣΔx=0 が機械精度、DL4 追補の
基準線確定）。あわせて対 (A,B) の**枝パリティ** χ_AB = sgn det(Q_A^T Q_B) を
Z₂ 成分として別途記録する（追補8 の二成分登録の対レベル対応）。
**定義可能条件**：両体の局所枠が λ3>0 かつ局所軸ギャップ>0 を満たすときに限り
U_AB を定義する。不成立の対は「未定義」として計数し、判定から除外でなく記録する
（真空基準点＝全対未定義、が §4 の基準と整合する）。

**追補11（局所枠の構成の一意固定・2026-08-19。事後変更しない）**。[F1] 定義2.4
「各体 A の局所枠を A の星から同じ処方で組む」の実装を一意化する：

  体 A の局所配置 = 全体配置 X3 に A の星重み w_j^(A)=|x_{Aj}|²（j≠A。
  A 自身は w_A^(A)=Σ_j w_j^(A)）を掛けたもの。局所中心 c_A = 重み付き平均。
  U_AB は重み付き**配置**間の無重み Kabsch でなく、A 重み配置→B 重み配置の
  Kabsch 回転として計算する（固有ベクトル符号の任意性を回避——配置は点集合であり
  符号自由度を持たない。追補10 の U_AB 定義の実装形）。

Q5 の適用範囲の明記: 標準宇宙（δシード・毛0）は電荷中立（全体の巻き w=0）であり、
引力/反力の電荷判別は巻きラベル付き物質を要する——**Q5 の ± 判別の実体は DL7 が
遂行する**（[F1] §7 DL6 の「引力型／反力型の判別」の電荷側）。本走行の Q5 は
中立物質での符号（普遍引力側）と φ^Q≈0 の確認を記録する。
