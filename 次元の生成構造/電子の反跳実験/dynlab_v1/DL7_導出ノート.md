## 0. 位置づけ——導出は済んでいる。残るは点別評価と実測である

シリーズの統一主張（重力＋クーロン＝同一相互作用の二復調）の理論部は完備である：

1. **力の読出し機構（[F1]）**：加速度は局所ゲージ場の傾きとして読む——「周囲の物質分布が
   局所枠を広域枠に対して傾ける（傾きの場＝重力場）」（§2.5）、「歪んだ物差しで等速
   ドリフトを読むと加速度が現れる」（§3.3）。**引力型／反力型の判別は [F1] §7 の DL6 に
   最初から事前登録されている。**
2. **力の法則（[F2] 定理4.1・導出済み・7.1e-15 検証済み）**：
   $\dot d_e^2=g_1[R_e\,\mathrm{Im}((B_{u}{+}B_{v})\bar x_e^2)+\mathrm{Im}((B^R_u{+}B^R_v)\bar x_e^2)]$
   ——力は「荷 $B_v$×場」の双一次であり、$\mathrm{Im}(\cdot)$ の中の**相対位相が符号を運ぶ**。
3. **レジスタ点ごとの成立（[F1] §6・[F2] 補題3.1）**：媒介頂点はレジスタ点 $(n,\eta)$
   ごとに作用し保存する。定理4.1 の代数はレジスタ点を選ばない——したがって
   **復調セクターの力法則は、同じ閉形式を η 点で読んだものである。新しい導出は要らない。**
4. **符号構造（[F2] §5）**：交差項の位相 $e^{i(w_A-w_B)\eta}$（定理5.1）・選択則（定理5.2）・
   復調弁別 0.9999（命題5.3）。

残る作業は（a）定理4.1 の η 点版の機械精度検算（S0——[F2] 図G2 検証の η 版）、
（b）mod 3 整流ラベルでの符号評価と実測（[F2] §8 追加行の「導出・実測」の遂行）。
符号の割当（同電荷が斥力型か）は式の評価の出力であり、事前に仮定しない。

## 1. 点別力法則と符号の評価手順（実行前固定）

1. **η 点別力法則**：W 表現のレジスタ点 $(0,\eta$モード$)$ ごとに定理4.1 と同一の閉形式
   $\dot d_e^2(\eta) = g_1[\,R\,\mathrm{Im}((B_u(\eta)+B_v(\eta))\,\bar x_e^2(\eta))+\cdots]$
   を書き、実装レートとの一致を機械精度で検算する（S0）。
2. **符号の評価**：純巻きラベル $w_A,w_B$ の対について、点別式に定理5.1 の位相
   $e^{i(w_A-w_B)\eta}$ を代入し、復調レート $r_\eta$ の符号を mod 3 整流ラベル
   （同電荷／異電荷）別に評価する——荷 $B_v$ の複素位相が $\mathrm{Im}(\cdot)$ を通して
   符号をそのまま与える。
3. **距離依存**：[AB] 調和閉鎖（指数厳密 −2）の η チャネルでの成立を同じ点別式で検査
   ——[F1] DL6 の「距離依存性から逆自乗の検定」の電荷側。
4. **重力側との同時読み**：同一走行で周辺化読出し（重力・束縛振動型）と復調読出し
   （電荷・符号分岐）を並記——命題5.3「二つの復調」の動力学水準の直接実証。

## 2. 統一主張の完成条件（[F2] §8 の登録どおり）

## 3. 観測量の定義（実行前固定）

対 (A,B) について：
- **復調位置** $\theta_\eta(A,B;\tau)$：η モードスペクトルの重心位相
- **復調レート** $r_\eta=\Delta\theta_\eta/\Delta\tau$（後期窓平均）
- **整流電荷** $q_A$：毛巻き数 $w_A$ の mod 3 整流値（[F2] §5）
- **対照（重力側）**：同一走行・同一対の周辺化分離角（[F2] G5 型）

## 7. DL7 実行記録（2026-08-19。v1: `run_dl7_charge_force_v1.py`／v2: `probe_dl7_exchange_observable_v2.py`／S3解析: `analyze_dl7_s3_growth_v1.py`）

**±則（S2/X2）の現状——8観測量すべてが mod3 分岐を示さず**：

  自モード射影が周辺化像に因数分解（|F(:,w)|²=ne²|φ(χ)|²）——毛ゲージ不変性が適用。
  S4 の完全共変が「符号割当でなく観測量定義の誤り」を切り分け（事前登録の診断どおり）。
- v2（交換チャネル4種: 交換占有 E・交換位置 r_x・干渉位相レート・スペクトル距離）:
  E と r_x は全ケース差 1e-11（丸め増幅ノイズ）＝依然盲目。干渉位相レートは O(1) で
  ラベル依存だが **mod3 クラスで組にならない**（同電荷内の差が異電荷間の差と同程度）。
- 判定式の系譜: v2 初版の X2 比判定は絶対有意床を欠き 1e-11 差で形式成立した——
  「分岐＝クラス間差>10×クラス内差 かつ >1e-6×スケール」に訂正後、全観測量で分岐なし。

**訂正（本ノート自身の誤り）**：§0 旧版の「復調力法則は同じ閉形式の η 点読み——
新導出不要」は誤読だった。η 点力法則（S0）は確かに恒等だが、それは**状態層の

（mod 3↔η・観測量の関数形）の導出が [F2] §9 登録の残作業そのものである。

**帰結（統一主張の水準判定・DL7 §2 の固定条件どおり）**：
条件(i)成立・(ii)不成立（符号情報の存在は厳密〔S1〕だが、力観測量として mod3 分岐を
示す関数は8候補すべて否定）・(iii)は二体厳密（DL6-Q7）／復調側は(ii)待ち。
**第4編の主張は「関係波動力学の読出し実験」とし、±則の完成は [F2] §9 の登録課題
「巡回時計 mod 3 と η モードの写像の確定」として残る**——ただし本走行により
「写像は自明な位置・占有・位相観測量のどれでもない」という8件の保存済み否定結果で
