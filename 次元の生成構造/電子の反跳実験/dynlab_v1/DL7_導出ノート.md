# DL7 導出ノート——電荷セクターの力観測量：復調読出しにおける±則の検定設計

## 0. 目的

[F2] 命題5.3 は「重力とクーロンは別の力ではなく、同じ相互作用の二つの復調である」
と導出し、復調側（η モードスペクトル）が Δw の符号を桁一（0.9999）で区別することを
実測した（stage4 プローブ）。残された課題は**力の観測量**である：符号の区別可能性
（情報）から、引力/斥力の符号則（動力学）へ進む。

## 1. 導出済みの土台（[F2]・第3編）

- 毛ゲージ不変性：周辺化読出しは巻き符号に厳密盲目（1e-17）——重力セクター
- 巻き一致選択則：等巻き対は追加チャネルを持つ（4.3°）
- 復調読出しの符号弁別：Δw=+2 と −2 で η モードスペクトルが桁一の差
- 第3編プロトコル：測定は物質相後期・枝検出つき輸送・(W_-, η_3+, λ3>0) 記録

## 2. 観測量の定義（実行前固定）

対 (A,B) について：
- **復調位置** θ_η(A,B; τ)：η モードスペクトルの重心位相（復調読出しの分離角）
- **復調レート** r_η = Δθ_η/Δτ（後期窓の平均変化率）
- **整流電荷** q_A：毛巻き数 w_A の mod 3 整流値（[F2] §5 の三価読出し）

## 3. 仮説（導出でなく検定対象であることを明記）

H7-1（±則）：mod 3 整流後の同電荷対（q_A=q_B≠0）と異電荷対（q_A≠q_B）で、
復調レート r_η の符号が分かれる（同電荷＝分離増大（斥力型）／異電荷＝分離減少（引力型））。
H7-2（重力側の不変）：同じ対の周辺化読出し（重力セクター）は符号に依らず
束縛振動型（[F2] G5 型）のまま——セクター分離の直接実証。

## 4. 事前登録判定（実行前固定）

| # | 判定量 | 資格 | 合格条件 |
|---|---|---|---|
| S1 | stage4 復調弁別の再現 | 実装検算（正本 import） | Δw=±2 の η スペクトル差が既存値（0.9999）を再現 |
| S2 | r_η の符号分岐 | H7-1 の検定 | 同電荷対と異電荷対で r_η の符号が系統的に分かれる（対の組合せを事前列挙・多数決でなく全対記録） |
| S3 | 重力側の不変 | H7-2 の検定 | 同じ走行の周辺化読出しが符号に依らない（既存 CR1/G5 型） |
| S4 | 符号則の巻き反転共変性 | 対称性検算 | 全巻き符号の一斉反転で r_η のパターンが不変（毛ゲージ不変性の復調版） |

**判定の意味**：S2 が成立すれば±則が実測で完成し、[F2] の統一（重力＋クーロン）の
実験検証が閉じる。不成立なら「復調観測量の定義（§2）」か「H7-1 の符号割当」の
どちらが誤りかを S4 で切り分ける——どちらでも次の導出課題が特定される。
