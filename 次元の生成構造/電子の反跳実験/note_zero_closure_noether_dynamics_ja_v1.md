少し驚く結果になりました。

今回、調べたかったのは動力学です。

これまで私は、

Σ Xₙ² = 0

という「零閉包」と、

Uᴺ = I

という「有限回帰」を基本条件として、背景となる時空や既成の対称性を最初から置かずに、波の関係だけからどこまで物理的な構造が出てくるかを調べてきました。

ところが、ここまで研究を進めると、大きな問題が残ります。

では、その世界で物はどう動くのか？

つまり、動力学です。

## きっかけはネーターの定理だった

そこで改めて調べ始めたのが、ネーターの定理でした。

物理学では非常に有名な定理です。

簡単に言えば、

**対称性があるところには、保存則がある**

というものです。

時間をずらしても物理法則が変わらないならエネルギー保存。

空間をずらしても変わらないなら運動量保存。

回転しても変わらないなら角運動量保存。

現代物理の動力学のかなり深いところに、この考え方があります。

ところが、私のモデルには少し困った事情があります。

最初から時間を置いていない。

空間も置いていません。

あるのは、まず

Σ Xₙ² = 0

という閉じた関係だけです。

ならば、ネーターの定理はいったいどこから出てくるのでしょう？

## 波の振幅を変える必要がなかった

ここで重要だったのが、これまで使ってきた等振幅波です。

振幅が同じなら、波を区別する本質的な量は位相です。

そこで、

**零閉包を壊さずに、位相だけを少し進める**

ことを考えました。

すると有限の分解能では、零閉包を保存する条件が

Σ Xₐ² (e^(2iΔφₐ) − 1) = 0

という有限差分の式になります。

ここまでは連続微分を使っていません。

時間微分もありません。

偏微分方程式もありません。

あくまで、離散的な位相の更新です。これは今回の論文で得た厳密な有限式です。

## では、分解能を無限に細かくしたら？

ここで、ふと思います。

この離散系の分解能をどんどん細かくして、

N → ∞

としたら、どうなるのか。

すると有限位相差は、連続的な位相勾配へ近づきます。

そして、

Σ Xₐ² ∂φₐ = 0

という局所保存構造が現れました。

つまり順序が逆だったのです。

普通は、

連続な時空 → 微分方程式 → 保存則

と考えます。

今回のモデルでは、

**離散閉包 → 有限位相差 → 高分解能化 → 連続的な保存構造**

となります。

連続な物理法則のほうが、離散構造を非常に細かい分解能で見た極限なのではないか？

という見方ができるようになりました。

## そして、ここからが予想外だった

私はもともと、ネーターの定理との関係を調べていただけでした。

ところが、この連続極限を追っていくと、これまで別々に見えていた標準的な動力学との接続経路が見え始めました。

さらに、位相勾配から current を構成していけば、

マクスウェル方程式との接続も同じ延長線上に置ける可能性があります。

ここはまだ「導出した」と言う段階ではありません。

実際、今回の論文でも、標準的なネーターの定理

∂μ Jμ = 0

との完全な同一化には、current の構成と変分対称性との対応をさらに示す必要がある、と明示しています。

でも、少なくとも道筋はかなりはっきりしてきました。

## では、相対性理論はどうするのか？

残る大きな接続先が、相対性理論です。

ただ、これは以前から入口があります。

零閉包を実成分と虚成分に分けて、

x² + y² + z² − t² = R² + Q²

のように読めば、左側にはすでにミンコフスキー型の計量が現れます。

つまり、

**量子論や場の動力学とは別に相対論を後から貼り付ける**

必要があるとは限りません。

同じ零閉包の「読み方」の違いとして、相対論的な時空を導ける可能性があります。

ここは次の重要な課題です。

## 今回は、わざと「現在の標準物理」に近づけた

今回の論文では、比較のためにあえて非常に特殊な極限を見ています。

一つは、

N → ∞

という連続極限。

もう一つは、曲率半径 R が非常に大きく、局所的にはほとんど平坦に見える領域です。

これは、現在の標準的な物理理論が極めて高い精度で成功している領域に対応させるためです。

ここは大事です。

私は標準理論が間違っていると言いたいのではありません。

むしろ逆です。

平坦に近く、連続近似が非常によく成立する領域では、標準理論は驚くほど正確です。

今回見えてきた可能性は、

**なぜその標準理論がそこまで正確なのかを、その一段下にある離散構造から説明できるかもしれない**

ということです。

## ただし「正規化」はもう一度考え直す必要がある

そして、ここには少し厄介な問題もあります。

標準的な量子論では、状態を

⟨ψ|ψ⟩ = 1

のように正規化します。

これは計算上あまりにも普通なので、普段はほとんど意識しません。

しかし私のモデルでは、R は単なる邪魔なスケールではなく、曲率や系の大きさに関係する量として残っています。

したがって R で割って単位化してしまうと、本来そこにあった幾何学的情報まで見えなくなる可能性があります。

以前の検討でも、R を用いた単位化は「曲率半径を持つ空間を単位球面へ写す相似変換」として読むことができました。

これは今後、標準理論との式の対応を調べるときに、かなり注意しなければならない点だと思っています。

## いま見えている全体像

研究を始めたとき、ここまで来るとは考えていませんでした。

出発点は、とても単純でした。

Σ Xₙ² = 0

という閉じた関係を置いたら、何が起こるのか。

そこから波を調べ、位相を調べ、対称性を調べ、そしてネーターの定理を追いかけました。

すると今、

離散的な零閉包
↓
位相差による離散動力学
↓
N → ∞
↓
連続的な保存則・場の動力学
↓
標準理論

という一本の道が見え始めています。

そして横には、

Σ Xₙ² = 0 ⟶ x² + y² + z² − t² = R² + Q²

という、相対論への別の道があります。

もしこの二本が同じ場所でつながるなら、かなり面白いことになります。

## 一行でまとめると

今回分かったことを一行にするなら、

**ネーターの定理を追いかけていたら、離散的な零閉包の連続極限から、標準的な動力学へ向かう道が見えてきた。**

ということです。

そして次に調べるのは、

**この道がマクスウェル方程式、そして相対性理論まで本当に切れずにつながっているのか。**

です。
