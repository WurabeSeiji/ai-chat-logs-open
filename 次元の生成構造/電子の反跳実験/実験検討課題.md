### 3.1 保持する数学と、旧中心前提の境界

閉包には**二つの読みが同時に成立している**。

```
Σz²  = 0            二乗読み（複素対称双一次形式）
Σ|z|² = 一定         ノルム読み（エルミート形式）
```

`make_parent_white_harmonics_n_only_v3.py` の**特定の QR 構成**が両方を同時に作る。

**そして Σz² = 0 は 2 次の同次式なのでスケール不変である。**

Σ(λz)² = λ²·Σz² = 0

## 課題5: 符号付き面積 $P=-1$ に選択則はあるか
