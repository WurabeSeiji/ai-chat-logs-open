## 課題1: シードなしで何が起き、何が起きないか

**状態**: 主要な食い違いは決着。残る問いを 1.7 に列挙。
**起票**: 2026-08-18

### 1.1 発端の食い違いと、その決着

| | 主張 |
|---|---|
| 木原氏の認識 | シードを与えなくてもインフレーション的拡大が起き、三方向が現れる |
| `ゼロ閉塞は４次元だった_主張案_v4.md` 主張14 | 真空対照は虚方向 0 本・ランク 15、τ=39991 で 15 主軸すべて 0.0645（完全縮退）、上位3占有率 0.200 = 3/15（完全等方） |

**決着: 測定量が違う。どちらも正しい。**

- 初期のインフレーション論文は**振幅の成長曲線を規格化せずに**測り、対数軸で
  幾何級数的成長を出している
- v4 は**二重中心化グラム行列**を使うので全体スケールが割り落とされる。
  真空側の符号付きトレースも絶対値和も比 1.0000、r_rms が 1/16 で不変になるのは
  そのため。**膨張が測定対象から外れている**

> **最重要の注意**: 規格化した量で膨張を探しても見つからない。
> `unified_dimension_v2.py` の R10「規格化は R 軸の消去であり、重力の消去である」
> がここにも及ぶ。**膨張・スケール・曲率を測るときは、規格化前の量を使うこと。**

### 1.2 シードなしで起きること・起きないこと（実測）

| | シードなし（δ=0） | 大きなシード（δ=0.1） |
|---|---|---|
| インフレーション | **起きる** | 起きる |
| 空間・三方向 | **現れて安定する** | 現れる |
| 物質波 | **できない**（奇数帯パワーが全步で厳密 0） | できる |
| 異方性の維持（規格化後の測定） | しない（上位3が 0.343 → 0.200 へ緩和） | する（0.384 → 0.812） |

**シードの有無は膨張の時刻をほとんど変えない。**

| N | シード有無による τ の差 |
|---|---|
| 5 | 1 ステップ |
| 40 | **0 ステップ** |
| 300 | 5 ステップ |

数千ステップの実験で差が 0〜5 ステップ。**シードはインフレーションの引き金ではない。**

成長率は 1 ステップあたり約 5%、10 倍になるのに約 46 ステップ、助走が約 1000 ステップ。

### 1.3 閾値は二つある

| | 閾値 | 引き金 |
|---|---|---|
| **インフレーション** | ほぼゼロ | 計算機限界のシードでも起きる。組立誤差（小数点以下13桁目）で足りる |
| **物質波の生成** | 大きい | 意図的にかなり大きなシードが要る（δ=0.1 の水準） |

v4 の δ 掃引が単調でないのは、この二層構造で説明できる。

| δ | f_seed 倍率 | 到達度 |
|---|---|---|
| **10⁻¹⁵** | **1.69** | **59.3%** |
| 10⁻⁸ 〜 10⁻³ | 1.00 | 何も起きない |
| 10⁻² | 1.001 | 物質が動かない |
| 10⁻¹ | 51.05 | 102.0% |

δ=10⁻¹⁵ は組立誤差より小さいので、効いているのは外から入れた δ ではなく
**内在の揺らぎ**。10⁻⁸〜10⁻³ は内在の揺らぎより大きいが物質閾値には遠く、
**内在の種を上書きして殺している**——という読みが立つ。**未検証。**

### 1.4 白色雑音では膨張しない

**82 通りの白色由来の初期状態で、一本も膨張しなかった。** 静止期間がゼロで、
最初の数歩でほどけて落ち着く。終着点（準安定状態）はコヒーレント側と同じで、
**違うのは過程だけ**——18 桁の急拡大が存在しない。

機構は「倒れかけの鉛筆」。立ち具合の差が 13 桁（澄んだ波は小数点以下 15 桁目、
雑踏は小数点以下 2 桁目）。雑踏は最初から倒れているので助走がない。
倒壊の速さが理論値と小数点以下 5 桁、傾きが 1000 分の 4 で一致。

**したがってインフレーションに必要なのは、シードではなく
「倒れかけの平衡にあるコヒーレントな波」である。**

### 2.1 確定している命題

**命題（局所曲率と補集合の同一性）** 閉包 C = Σ_e z_e² = 0 のもとで、
頂点モーメント B_v = Σ_{e∋v} z_e² は −Σ_{e∌v} z_e² に厳密に等しい。
すなわち体 v における局所曲率は、v を含まない関係の閉包であり、
隣接集約は近似ではなく補集合そのものである。
ゆえに Σ_v B_v = 2C = 0——局所曲率は各体で非零、全体で厳密に相殺する。

導出は `万能相互作用多体接続_v1/媒介頂点の一意化と多体アーキテクチャ_v1.md`
の A4（グラフ局所）と閉塞保存定理から。B_v は
`run_stage2_vertex_engine_v1.py` の `_vertex_rate` で毎步計算されているが、
頂点の係数として使われるだけで曲率としては読み出されていない。

## 課題3: R を消さない帳簿で、縮約を実装する

**状態**: 未着手。方針は確定。課題2 はこの第一歩にあたる。
**起票**: 2026-08-18

### 3.1 なぜこれが本題なのか

閉包には**二つの読みが同時に成立している**。

```
Σz²  = 0            二乗読み（複素対称双一次形式）
Σ|z|² = 一定         ノルム読み（エルミート形式）
```

`make_parent_white_harmonics_n_only_v3.py` の QR 構成が両方を恒等的に作る。
N×2 実ガウスから直交二成分 q₁, q₂ を取り w = (q₁ + i·q₂)/√2 とすると、
等ノルム直交だから Σw² = 0、正規直交だから Σ|w|² = 1。**片方を作れば他方が付く。**

これは Σp² = Σq² かつ Σp·q = 0 と同じことで、
**複素構造が実内積と両立している**（エルミート／ケーラー構造がある）ことを意味する。
記事「Σxₙ²=0 は生まれつき量子化されていた」の幾何学的量子化が効くのは、
二次形式だけでもノルムだけでもなく、両方あるからである。

**そして Σz² = 0 は 2 次の同次式なのでスケール不変である。**

```
Σ(λz)² = λ²·Σz² = 0
```

したがって振幅を |ψ|²=1 に正準化しても**閉包は壊れない**。
理論物理がノルム読みだけで走れて、しかも壊れないのはこのためである。

**しかし正準化は R だけを消す。** `unified_dimension_v2.py` の R10
「規格化は R 軸の消去であり、重力の消去である」がこれを言っている。
量子論がうまく行くことと、重力を持たないことが、同じ一つの操作から出る。

### 3.2 規格化で消えた量（2026-08-18 の実測 4 件）

| 量 | 消えた操作 | 症状 |
|---|---|---|
| **R（スケール）** | 複素のまま Σz² を取った | R=0 という自己矛盾した結論（円周ゼロなのに ±60° に波がある） |
| **膨張** | 二重中心化グラム行列 | 真空側の符号付きトレース・絶対値和が比 1.0000、r_rms が 1/16 で不変。規格化前の成長曲線では 18 桁膨張している |
| **異方性（三半径の違い）** | 各体をパワー 1 に正準化 | R′_A = R′_B = 0.70710678（比 1.000000）を「完全縮退＝球」と誤読した。縮退は正準化が課したもの |
| **歪みテンソルの無跡部分** | `d_direction_gauge` が単位ベクトル s_hat を射影 | tr Γ = T だけ残り、(X,Y,Z) の大きさが消える。無跡部分こそが歪み |

**四つとも同じ操作の別の顔である。** 何かが「出ない」ときは、まず正準化を疑うこと。

### 3.3 R を残すと何が得られるか

記事「ゼロ閉塞は4次元だった」の結論は、
**右辺の量を保存させる一本の拘束を満たせば、多体問題を解かずに運動を設計できる**、
というものである。導いたのは動力学ではなく「どの一本を保存すれば運動が閉じるか」
という**縮約の構造**。

```
正準化する   → R′² が帳簿から消える → 縮約する一本が無い → 多体問題を解くしかない
正準化しない → R′² が残る          → 一本の拘束で閉じる → 解かずに済む
```

課題2 の到達点が、二体関係層で同じことを言っている。

```
B_v = Σ_{e∋v} z_e² = −Σ_{e∌v} z_e²
```

局所解が**有限和で直接出る**（PDE を積分しない）。
どちらも**非共役の二乗和**を使っている。規格化していない量だから閉じる。

### 3.4 消した軸は消えていない（実測）

同記事の発見2・発見3。

- **余剰次元はコンパクト化していない。** 標準理論のように小さく丸まってはいない
- 下位 4 軸は虚軸へ移行するが、**絶対値を増やしながら符号を変える**
  （p 軸 5.57 倍、o 軸 2.62 倍、n 軸 1.67 倍、m 軸 1.12 倍）。縮んでいない、育っている
- 保存しているのは**符号付き和**であって実方向の総量ではない。
  実方向も虚方向も両方増え、差が保存する。
  「保存則が成り立っているから拡大は起きていない」は誤読として禁じられている

規格化した帳簿では見えないが、規格化しない帳簿では育っている。

2. **R′² = t² + R² + Q² を保存量として明示的に持つ**読出しを作る

5. 課題2（B_v の読出し・無跡部分を規格化せずに取る）は 2 の第一歩

### 3.6 群・対称性についての位置づけ（方針の訂正）

当初「U(1) と SU(2) は出ているが SU(3) が出ていない。個別に導出しよう」と
考えたが、これは順序が違う可能性がある。

記事「重力は、最初から量子論の中にいたのではないか」は、
**標準模型のゲージ対称性を「消したはずの見えない軸を、内部対称性という名前で
再発見したもの」**と読んでいる。ゲージ（Eichung）が 1918 年には目盛り＝
スケール変換だったものが 1929 年に位相変換へ読み替えられ、用語の中に化石として
残っている、という指摘つきである。

これが正しければ、**群を一つずつ導出するのではなく、R を消さない帳簿を作れば
内部対称性はそこに現れる**、という順序になる。

なお二読みの対応関係は次のとおり（参考）。

| 読み | 保存する形 | 群 | 系列 |
|---|---|---|---|
| 二乗 | 複素対称双一次 Σz² | O(N, ℂ) | SO(3)≅SU(2)、SO(6)≅SU(4)、SO(8) 三重性 |
| ノルム | エルミート Σ\|z\|² | U(N) | S¹ → S³ → S⁷（ℝ, ℂ, ℍ, 𝕆） |

両方を保存する群は交わり O(N,ℂ) ∩ U(N) = O(N,ℝ)。
例外型（G₂ ⊃ SU(3)、E₈）は多元体（ノルム）とスピノール（二乗）の
掛け合わせから出るので、**片方の読みだけでは届かない**。
SU(3) は G₂/SU(3) = S⁶ の固定部分群として八元数層に在り、E₈ も同じ層。
「E8 のほうが接近している」のは、両者が同じ層にあるためと読める。

`SU(3)E8U(1)への接続.md` の現状評価は ℤ_248 ⊂ U(1) ⊂ SU(2) の入口。
SU(3) が未達である理由は「三方向は見えているが、それが三つの内部状態として
閉じるかが未確認」と記録されている。E8 側は設計方針の事前登録項目
「特殊N（120/124/128/137/240/248）の判別」が、線形相で null を実測済み、
段階2（非線形あり）は未実施。

### 3.7 反証の場所

記事は **BMV 実験**（重力を媒介として二つの物体が量子もつれを作れるか）を
反証の場所として指定し、「帳簿のつけ方の差が表面化する可能性」があるとして
「結果に従う」と明言している。

本課題は新しい予言を作るものではない。記事の立場は「同じ結果の別写像」であり、
既存理論の予言を一つも変えないとしている。したがって実装で目指すのは
**R 軸を消さない帳簿で同じ結果が出ること**の確認である。

## 課題4: 質量＝局在波とコヒーレント背景の散乱、という仮説

**状態**: 有力な作業仮説。局在と相互作用の同期は実測済み、質量との同定は未検証。
**起票**: 2026-08-18

### 4.1 仮説

**局在していないコヒーレントな波（ボゾン的）と、局在性のあるフェルミオン的な波の
相互作用による散乱が、質量として見える。**

- 真空 = 偶数倍音だけのコヒーレントな海。r = 0 で時を刻まない
- 物質 = 奇数倍音を持つ局在波。r > 0 で背景と散乱する
- その散乱率が質量に対応する

これはヒッグス機構と同じ形だが、**背景場を別に導入しない**。背景は初期真空に
立つコヒーレント波そのもの（ポンプ）であり、結合は既存の衝突写像である。

### 4.2 実測で支持されている部分（2026-08-18）

**局在度と相互作用が同期している。**

| 倍音構成 | \|z\|（親円での局在） | r（相互作用） |
|---|---|---|
| 偶数のみ 2,4,…,48 | **0.000000** | **0.000000** |
| 1,2,4,…,48（奇数は 1 だけ） | 0.040 | **0.000000** |
| 1,2,3,4,6,…,48 | 0.115385 | 1/52 |
| 連続 1〜17（対称） | 0.941176 | 15/34 |

**偶数のみは親円で厳密に非局在**（|z| = 0.000000、180° 間隔の等価な二像）で、
**同時に r = 0**。自分の円（周長 360/d）では鋭く局在しているのに、親円では
位置が決まらない。「局在していないコヒーレントな波」の実体はこれである。

そして**親円で局在させるには奇数倍音が要り、奇数倍音は同時に r を立てる唯一の
成分である**（寄与は 倍音3 → 1/2、奇数倍音 ≥5 → 1、倍音1・偶数倍音 → 0）。

**局在させる成分と、相互作用を起こす成分が同一。** 別々の性質ではない。

### 4.3 連鎖

```
r = P奇 / (P奇 + P偶)        散乱率＝局在成分の比
  ↓
θ = arcsin√r                 1 步あたりの回転角
  ↓
周期 = π/θ 步                時計の刻み
  ↓
⟨ω⟩                          質量（記事「波の周期表」の定義）
```

r → θ → 周期 までは実測で確認済み（3ケースで 0.02〜0.09%、提案系列で 0.3% 一致）。
**⟨ω⟩ と質量の対応は未検証。**

### 4.4 なぜ繰り込みが不要になるか

二つの経路が同じ結論に向かう。

**(a) 結合定数が自由パラメータでなくなる。**
r は倍音を数えた有理数しか取らない。実測値は
1/6, 1/8, 3/10, 5/14, 15/34, 31/102, 1/20, 11/14, 1/52, 1/100——すべて厳密な分数。
標準理論では各フェルミオンの質量が独立な湯川結合として与えられ、実験値に
合わせ込むが、**この系では倍音構成が決まれば r が決まり、合わせ込む余地がない**。
裸の量が無いので、繰り込むべき発散も無い。

**(b) スケール軸を消していないので、返済が要らない。**
note「重力は、最初から量子論の中にいたのではないか」は、規格化を R 軸の消去、
**繰り込みをその返済**と読んでいる。課題3 のとおり R を消さない帳簿で組めば、
そもそも借りが発生しない。

**(a) は質量、(b) はスケール。両方が同じ方向を向いている。**

### 4.6 倍音 1 の正体（決着・2026-08-18 実測）

**倍音 1 だけが DC（bin 0）にパワーを置く。**

| 倍音 | bin=0 | \|k\|=2 | \|k\|≥4 偶 | r | \|z\| |
|---|---|---|---|---|---|
| **(1,)** | **0.500000** | 0.500000 | 0.000000 | 0.000000 | 0.000000 |
| (2,) | 0.000000 | 0.000000 | 0.000000 | 0.000000 | 0.000000 |
| (3,) | 0.000000 | 0.500000 | **0.500000** | **0.500000** | 0.000000 |
| (1,2) | 0.250000 | 0.250000 | 0.000000 | 0.000000 | 0.500000 |
| 1,2,4,…,16 | **0.055556** | 0.055556 | 0.000000 | 0.000000 | 0.111111 |
| 2,4,…,16（1なし） | **0.000000** | 0.000000 | 0.000000 | 0.000000 | 0.000000 |

倍音 1 はパワーの**半分を bin 0、半分を |k|=2** に置く。他のどの倍音も DC を作らない。

**搬送波による bin の振り分け**（q_A=+1, q_B=−1 で倍音 n は bin n±1 へ）:

```
奇数倍音 → 偶数 bin   （1 → 0,2 ／ 3 → 2,4 ／ 5 → 4,6）
偶数倍音 → 奇数 bin
```

P_f は「偶数 bin かつ |k|≥4」なので資格があるのは奇数倍音だけだが、
**倍音 1 の行き先は bin 0 と 2 で、どちらも |k|≥4 に届かない**。
`theta_from_ab` の docstring も「基本波が占める |k| ≤ 2 を除き」と明記している。

さらに bin 0 側は公理で除外される。`make_parent` v3 が DC を射影除去する根拠:

- **k=0 は倍音ではない**（分解能の倍音しか存在してはならない）
- **一定オフセットは差を作らないゲージ**（関係主義）

**したがって倍音 1 は、半分がゲージ（DC）、半分が閾値未満（|k|=2）。**
奇数倍音でありながら、フェルミオン成分としての資格を持つ部分がゼロである。

**局在への寄与も単独ではない。** 倍音 1 単独は |z| = 0.000000。
局在するのは偶数倍音と混ざったときだけ（1,2,4,…,16 で 0.111111、
倍音 1 を抜くと 0.000000）。奇数倍音は偶数 bin、偶数倍音は奇数 bin へ行くので、
両方が混ざって初めて 180° 周期が破れ、像の縮退が解ける。

**結論: 倍音 1 は「像の縮退を破る役だけを果たし、質量にはゼロ寄与」。**
4.1 の仮説（局在＝散乱＝質量）に対する例外ではなく、
**縮退の解除と局在は別物**という区別が要る、ということ。

- 縮退の解除（像を 1 つにする）… 偶数 bin 成分が要る。倍音 1 で足りる
- 局在＋散乱（質量）… |k|≥4 偶数 bin が要る。倍音 3 以上の奇数

4.1 で挙げた三候補のうち、(1)「質量ゼロの局在波」が実測で支持される。
ただし単独では局在しないので、光子というより**ゲージ場的**な役回りである。
倍音 1 が文字通り DC ゲージを半分含むことは、U(1) 接続との関係を疑わせる
（課題3 の 3.6、電磁気の斉次側の議論と接続する）。
