## 読み取り

- **底はさらに深くなる。** 倍精度の床 10⁻³¹ の下でも、5 つの N すべてで **H⊥/H_total = (r·τ)² が 5〜7 桁一致**（10⁻³⁵ まで）。多倍長では床は精度で決まり（50 桁なら ~10⁻¹⁰⁰）、そこまで同じ法則が続く。
- したがって 0 近傍の立ち上がりは、丸め誤差でも N の物理でもなく、**親の自己無撞着残差 r による決定論的ドリフト** ‖δ‖ = r·‖v‖·τ そのもの。刻みを細かくして τ を小さくすれば H⊥ は (rτ)² で際限なく下がる。
- 保存則：H_total のドリフトは 50 桁で 10⁻⁵⁰ 台（厳密保存の実証）。
- 帰結：もし親を多倍長で r → 10⁻⁵⁰ まで磨けば、H⊥ ≈ (10⁻⁵⁰ τ)² となり、厳密な固定点からは何も起きない（不安定モードが精度雑音を増幅するまで）。倍精度の実験で見えていた「弾道相」は、親の残差 10⁻¹¹〜10⁻¹² が種になった線形ドリフトであり、その後の指数相（N=5 で 0.0089/step）が固定点の不安定性の現れ。
