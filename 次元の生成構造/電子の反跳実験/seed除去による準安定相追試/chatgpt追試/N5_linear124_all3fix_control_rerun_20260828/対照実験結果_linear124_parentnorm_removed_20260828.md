## 0. 参照実験の要約

N=5, M=10, 5000 step, seed 40260721+5000。更新は Cayley でなく厳密な指数回転 exp((2π/124)K)（自然時間 1 step = 2π/124）。二本の枝：
- **baseline**：位相のみの K_ij = sin(θ_j−θ_i)（公開エンジンと同じ生成子）
- **treatment**：振幅込みの K_ij = Im(z̄_i z_j) = |z_i||z_j| sin(θ_j−θ_i)（**別の模型**）

今回の変更点は `make_parent` 内の `v = v/‖v‖` 削除のみ。報告値：parent residual 0.487、H_total 0.8596、treatment は等分配せず（PR/M 0.489、振幅 0.18〜0.59）。

## 2. 「正規化除去」の解析的予言と検証（`scale_and_engine_check.py`, `parent_symmetry_check.py`）

**残差 0.487 は収束失敗ではなく残差式のアーティファクト。** `_eigenmode_residual` は μ = v†(iKv) を単位ノルム前提で使うので、|v| = c の厳密固有モードに対して

$$\text{res}=\sigma\,c\,|1-c^2|=3.7417\times0.92717\times0.14035=\mathbf{0.486900}$$

（報告値 0.486900 と一致、c² = 0.859649 = H_total）。したがって収束判定 `res < tol` は決して真にならず、400 反復×3 リスタートを走り切って「最良」を選ぶ——選ばれる親は正規化版と**頂点置換 (0,3,1,2,4) ＋ 辺 3 本の符号反転**で厳密に一致する（重なり 1.000000000000；振幅多重集合 {1/√12 ×6, 0.3086 ×3, 0.4629} も同一）。辺の符号反転は K′ = DKD なので力学の対称性であり、H 観測量は不変。

**スケール則：** 位相のみ K は z のスケールに依らない → baseline は正規化版軌道の c 倍。振幅込み K は |z|² に比例 → treatment は正規化版の**時間を c² = 0.8596 倍**したもの。検証：正規化親で回転角を (2π/124)·c² にして走らせた treatment と、参照（非正規化、角 2π/124）の H 系列の最大差は **1.5×10⁻⁸**（時間再尺度化で完全一致）。baseline は §1 の丸め敏感性のため軌道レベルでは比較できない（不変量は一致）。

$$\boxed{\text{正規化除去は、スケール }c\text{ と時間の }c^2\text{ 倍以外に物理的内容を持たない}}$$

参照レポートの「正規化は残差評価・固定点反復とスケールの関係に影響している可能性」は、上の残差恒等式で完全に説明される。

## 3. 生成子とエンジンの同一性

- 参照の `dense_K_phase_only` と公開エンジン `kmatvec` の行列は一致（最大差 2.7×10⁻¹⁶）。
- 公開エンジン（正規化親）＋指数写像 L=124 の baseline：成長率 0.197862/step（参照 0.197857）、final σ₁ = 4.000000、PR/M = 1.000000。自然時間あたり成長率 0.1979/(2π/124) = 3.905（Cayley L=144 の 3.953、L=288 の 4.141 と整合：一次の刻み依存）。
- **final σ₁ = 4 = N−1** は指数写像・L=124 でも成立——`../tau_direction_sigma_N_minus_1/` の定理の独立確認。

## 4. treatment（振幅込み K）について

- treatment は等分配しない（PR/M 0.489、振幅 0.18〜0.59、σ₁ = 3.61 ≠ 4）。これは σ = N−1 定理の前提（等モジュラー）が成り立たない**別の力学**であり、「修正」ではなく模型の変更。位相のみ K の等分配・σ=N−1・ヌル錐単体という結果は振幅込み K には引き継がれない。
- H_total は両枝で 1e-13 保存（exp(αK) は直交なので当然）。
- treatment の成長 fit（slope 0.0025、R² 0.35）は「指数成長がない」ことを示しており、参照 §分析の「線形位相回転＋振幅保持」は seedless インフレーションの機構（親の線形不安定性）を消している可能性がある。親が振幅込み K の固定点になっていない（onset 76 で即動く）ため、そもそも相対平衡から出発していない。

## 5. 結論

1. 参照実験は treatment について 1e-8 で再現、baseline は不変量（成長率・等分配・σ=N−1）が再現し、軌道と onset は丸め依存で再現しない（seedless 固定点出発の本質的性質）。
2. 「正規化除去」の効果はスケール c と時間 c² の再尺度化に尽きる。残差 0.487 は σc|1−c²| の恒等式。追試の結論「正規化が固定点反復に影響」は撤回してよい。
3. 振幅込み K は別の模型で、等分配も σ=N−1 も成り立たない。これを採用するなら「なぜ位相のみ K が正しいか／振幅込みが正しいか」を公理から決める必要があり、数値結果からは決まらない。
