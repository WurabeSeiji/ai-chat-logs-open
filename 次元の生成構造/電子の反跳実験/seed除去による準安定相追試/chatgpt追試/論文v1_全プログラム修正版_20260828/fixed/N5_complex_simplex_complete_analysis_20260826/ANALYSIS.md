# N=5 関係波の a²・b²・ab による複素距離分類

## 対象
直前の N=5 raw-K 5000 step 実験で保存済みの全10関係波について、各stepの

z = a + ib

から

a², b², ab

を直接計算した。物理時間発展は変更していない。

複素二乗距離は

z² = (a²-b²) + 2iab

である。

## 1. 全stepで成立する恒等構造

各関係ごとに、正規化した三成分

A = a²/(a²+b²)
B = b²/(a²+b²)
C = ab/(a²+b²)

は数値精度内で

A+B=1
C²=AB

を満たす。

全5001 stepでの最大誤差:
- |A+B-1| <= 2.220e-16
- |C²-AB| <= 1.110e-16

したがって三成分は独立3自由度ではなく、位相1自由度の代数曲線上にある。

## 2. 初期自己無撞着状態

step 0 では正規化三成分は2種類だけ:

Class P:
(a²/r², b²/r², ab/r²)
= (0.1652987353, 0.8347012647, +0.371449...)

Class -P:
= (0.8347012647, 0.1652987353, -0.371449...)

両者は

T(A,B,C) = (B,A,-C)

で入れ替わる。

これは複素二乗距離では厳密に符号反転

z² -> -z²

に対応する。

したがって初期自己無撞着親では、複素二乗距離の方向は本質的に1組の ± 対である。

## 3. 時間発展後の分類

decompactification の進行とともに一時的には各辺が異なる三成分を取るが、後期には明瞭な4群へ再編成する。

step 5000 では全10辺の振幅二乗が

|z|² = a²+b² ≈ 0.1

へ等分配している。

実測範囲:
0.099999999886 <= |z|² <= 0.100000000086

このとき10辺は次の4群に分類される。

### A+
edges: 1-2, 1-3, 4-5
(a²,b²,ab) ≈
(0.028397, 0.071603, +0.045092)

z² ≈ -0.043206 + 0.090184 i

### A-
edges: 1-4, 1-5, 2-3
(a²,b²,ab) ≈
(0.071603, 0.028397, -0.045092)

z² ≈ +0.043206 - 0.090184 i

したがって

z²(A-) ≈ - z²(A+).

### B+
edges: 2-4, 3-5
(a²,b²,ab) ≈
(0.020942, 0.079058, +0.040689)

z² ≈ -0.058117 + 0.081378 i

### B-
edges: 2-5, 3-4
(a²,b²,ab) ≈
(0.079058, 0.020942, -0.040689)

z² ≈ +0.058117 - 0.081378 i

したがって

z²(B-) ≈ - z²(B+).

## 4. 最終パターン

最終的な10関係は

3 + 3 + 2 + 2

の4群に分かれる。

しかし複素二乗距離として見ると4群は

±A, ±B

なので、本質的には

**2種類の複素距離方向 × 符号反転**

という構造である。

辺の組合せは

A+ : (12),(13),(45)
A- : (14),(15),(23)
B+ : (24),(35)
B- : (25),(34)

であり、単なる値のクラスタではなく K5 の辺集合上に固定された組合せパターンを持つ。

## 5. 収束

この最終4群の内部一致と ± 補対関係を同時に評価すると、

- tol 1e-4 で以後ずっと成立: step 2627
- tol 1e-6: step 3791
- tol 1e-8: step 4923

である。

したがって4群構造は一時的な偶然ではなく、後期に漸近的に形成されている。

## 6. 全体ゼロ閉塞との整合

同時に全stepを通して

Σa² ≈ Σb² ≈ 0.5
Σab ≈ 0

が維持される。

step 5000:
- Σa² = 0.5000000000000018
- Σb² = 0.5000000000000041
- Σab = 6.939e-16

したがって4群の複素距離分布全体はゼロ閉塞と整合している。

## 7. 現時点の読み

今回の分類から直接言えるのは、N=5 の関係波は後期に任意の複素距離へ散らばるのではなく、

**等振幅化しながら、2種類の複素二乗距離方向とそれぞれの符号反転という4群へ自己組織化する**

ということである。

これは直前まで見ていた「二つの面」「rank 4」の構造と対応する可能性がある。ただし、この対応そのものは今回の a²,b²,ab 分類だけからはまだ同一視せず、別途幾何対応を照合する必要がある。
