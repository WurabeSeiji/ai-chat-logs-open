# N=3 / N=4 seedless 複素simplex比較解析
## raw-K・K/σ正規化なし・5000 step

**作成日:** 2026-08-26

## 1. 条件

N=3,4について、N=5およびN=16と同じ基本条件で実行した。

- seedless `make_parent`
- raw-K Cayley
- `K/σ` 正規化なし
- 5000 physical steps
- 各関係波 \(z=a+ib\) について \(a,b,a^2,b^2,ab,z^2\) を全step保存
- 中心化複素Gramによるsimplex rank
- Takagi主軸
- 親平面外成分 \(H_\perp\)
- 辺振幅 \(|z|^2\)
- 位相・複素二乗距離クラス
を解析した。

---

## 2. N=3

\[
N=3,\qquad M=3.
\]

step 5000の複素Gram rankは

\[
\boxed{2=N-1}
\]

であり、3頂点は複素2次元simplex、すなわち三角形として閉じる。

ゼロ閉塞も維持され、

\[
\sum a^2 \simeq 0.5,\qquad
\sum b^2 \simeq 0.5,\qquad
\sum ab \simeq 0.
\]

ただしN=3は5000 stepでも完全な等振幅化にはまだ到達していない。

step 5000:

\[
0.322504\le |z|^2\le0.348992.
\]

3本の辺は tol=1e-8 ではまだ3クラス（1+1+1）である。

相対位相差 \(|\Delta\theta|/\pi\) は

- 0.319926
- 0.337728
- 0.342347

で、3本とも \(1/3\) の近傍にあるが、最大偏差は

\[
\boxed{1.34\times10^{-2}}
\]

であり、5000 step時点では厳密な三等分とは言えない。

したがってN=3では、三角simplexは成立しているが、
その三辺の等振幅化・三等位相化はかなり遅い準安定過程として残っている。

---

## 3. N=4

\[
N=4,\qquad M=6.
\]

step 5000の複素Gram rankは

\[
\boxed{3=N-1}
\]

であり、4頂点は3次元simplex、すなわち四面体として閉じる。

全6辺はほぼ

\[
|z|^2\simeq 1/6
\]

へ等振幅化している。

実測範囲:

\[
0.166664345\le |z|^2\le0.166670346.
\]

さらに最終的な6辺は、非常に明瞭に

\[
\boxed{2+2+2}
\]

の3群へ分かれる。

- Class 0: (12),(34)
- Class 1: (13),(24)
- Class 2: (14),(23)

これはまさに**四面体の3組の対辺**である。

各組の2辺は、step 5000で位相差 mod \(\pi\) が機械精度でゼロ:

\[
\max |\Delta\theta|/\pi
\simeq 4.24\times10^{-16}.
\]

そして3群の位相 \(\theta\) は mod \(\pi\) 上でほぼ

\[
\boxed{\pi/3}
\]

ずつ等間隔に並ぶ。

3 gap は

\[
0.33332725,\quad
0.33333717,\quad
0.33333558
\]

(\(\pi\)単位)で、\(1/3\)からの最大偏差は

\[
\boxed{6.09\times10^{-6}}.
\]

複素二乗距離

\[
z^2=|z|^2e^{i2\theta}
\]

で見ると位相は2倍されるため、3つの対辺クラスは複素平面上で

\[
\boxed{2\pi/3=120^\circ}
\]

ずつ離れた3方向になる。

したがってN=4では、

\[
\boxed{
\text{四面体}
+
\text{3組の対辺}
+
\text{複素二乗距離の120°三方向}
}
\]

が一致している。

これはN=4で初めて、simplexの3次元構造と位相分類が非常に直接的に対応していることを示す。

## 4. 急拡大と準安定化

### N=3

\(H_\perp\) は最終値に対して、

- 50%: step 786
- 90%: step 798
- 95%: step 800
- 99%: step 801

で急拡大をほぼ終了する。

しかし辺振幅の相対spreadは5000 stepでも1%以下にはならず、
構造の整列は非常に遅い。

### N=4

\(H_\perp\) は、

- 50%: step 370
- 90%: step 376
- 95%: step 377
- 99%: step 378

で急拡大をほぼ終了する。

その後、全6辺の等振幅化がゆっくり進み、

- relative spread < 1e-1 : step 1326
- < 1e-2 : step 2401
- < 1e-3 : step 3475
- < 1e-4 : step 4549

となる。

したがってN=4でも、

\[
\boxed{
\text{急拡大が先}
\rightarrow
\text{距離・位相秩序化が後}
}
\]

という二段階性が明瞭である。

## 5. N依存性として見えるもの

今回のN=3,4と既存N=5,16を並べると、少なくとも次の区別が重要である。

- N=3: rank 2、三角simplex。3辺はまだ完全整列前だが、位相差はおおむね \(\pi/3\) 近傍。
- N=4: rank 3、四面体simplex。6辺は3組の対辺 2+2+2 に縮退し、その3群の \(z^2\) 位相は120°配置。
- N=5: rank 4、4-simplex。10辺は3+3+2+2に縮退し、3次元四角錐として読める位相構造を形成。
- N=16: rank 15、15次元complex simplex。120辺は等振幅化するが、5000 stepでは少数位相群へ縮退しない。

したがって、**位相構造はseedだけでなくNにも強く依存している**ことが今回の低N比較から明瞭になった。

特にN=4の 2+2+2 は、任意の数値クラスタではなく、
四面体の対辺という組合せ幾何そのものと一致している。

これは「simplexが先に成立し、そのsimplex固有の組合せ対称性に従って位相距離が分類される」
という読みを強く支持する。

一方N=3は5000 stepでまだ準安定化途上なので、
最終的に完全な三等位相・等振幅三角形へ収束するかは、この実験範囲だけでは断定しない。

## 6. 現時点の重要な発見

N=4で得られた

\[
\boxed{(12,34),\ (13,24),\ (14,23)}
\]

という3群は、四面体の全6辺を3組の対辺へ完全分解する自然な構造である。

さらに各対辺内は同位相、3群間は \(\theta\) で約60°、
\(z^2\) で120°ずつ離れる。

したがって、

\[
\boxed{
\text{simplexの組合せ幾何}
\longleftrightarrow
\text{複素距離の位相分類}
}
\]

がN=4では直接可視化された。

これはN=5の四角錐的分類、N=16の高次元非縮退との比較において、
次元選択・位相秩序がN依存であることを考える重要な基準点になる。
