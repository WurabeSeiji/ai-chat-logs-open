# N=16 複素simplex完全解析
## N=5と同一条件による raw-K・seedless・5000 step 比較

**作成日:** 2026-08-26

## 1. 実験条件

- N = 16
- M = N(N-1)/2 = 120
- seed = 40276722
- raw K Cayley 更新
- K/sigma 正規化なし
- seedless `make_parent`
- 5000 step
- `make_parent` residual = 3.028e-13
- 解析以外の物理変更なし

N=5解析と同じく、各関係波 z=a+ib から a², b², ab, |z|², z² を保存し、
複素距離Gram、Takagi主軸、位相分布、時間発展を解析した。

## 2. 複素simplex

step 5000 の中心化複素Gram行列は rank=15=N-1 であり、
120本の完全二体関係は16頂点の15次元複素simplexとして閉じる。

これはN=5で rank=4=N-1 だった結果の自然な延長である。

## 3. 全120関係の等振幅化

step 5000では全120関係で

|z_ij|² = a_ij² + b_ij² = 1/120

まで等振幅化している。

実測範囲:

0.00833333333333387 <= |z_ij|² <= 0.00833333333333389

同時に、

Σa² = 0.5000000000000329  
Σb² = 0.5000000000000326  
Σab = -6.25e-17

であり、二乗ゼロ閉塞も維持される。

## 4. 急拡大期間

親平面外二乗振幅 H_perp の最終値は 0.127351098927。

最終値への到達は、

- 50%: step 138
- 90%: step 161
- 95%: step 169
- 99%: step 181

である。

したがってN=16では、N=5よりもさらに短時間で decompactification がほぼ完了した。

## 5. 等振幅化

120辺の |z|² の相対spreadが以後ずっと閾値以下になる時刻は、

- < 1e-1 : step 173
- < 1e-2 : step 203
- < 1e-3 : step 235
- < 1e-4 : step 273
- < 1e-6 : step 340
- < 1e-8 : step 418
- < 1e-10: step 497

である。

したがって、指数急拡大から全120関係の等振幅化までは約500 step以内でほぼ完了する。

## 6. N=5との決定的な違い：位相群の縮退がない

N=5では準安定期に 3+3+2+2 の4群へ複素距離が縮退し、
3次元四角錐として読める位相構造が形成された。

しかしN=16では step 5000 において、正規化三成分

(a²/(a²+b²), b²/(a²+b²), ab/(a²+b²))

を tol=1e-6 で分類すると、120関係すべてが別クラスである。

- tol=1e-2 : 64クラス
- tol=1e-4 : 118クラス
- tol=1e-6 : 120クラス
- tol=1e-8 : 120クラス

したがってN=16 seedless系では、振幅は完全に等方化するが、
位相は少数の離散群へ縮退しない。

## 7. 位相・複素二乗距離の分布

step 5000 の120関係の位相は mod π 上に広く分布する。

- 最小位相間隔 = 6.479e-06 π
- 最大gap = 1.185e-01 π
- 平均gap = 8.333e-03 π

z²/|z|² を複素平面に描くと、少数点群ではなく単位円上に多数の方向が残る。
これはN=5で見えた ±A, ±B の4点縮退とは明瞭に異なる。

## 8. Takagi主軸

15本すべての非零Takagi主軸が立ち上がる。
先行N=16解析でも全15軸が指数増幅し、特定の3または4方向だけが選択されなかった。

したがってN=16 seedless系は、
15次元複素simplexが等方的にdecompactifyし、等振幅化する一方、
N=5で見えたような低次元位相閉包への縮退は少なくとも5000 stepでは生じていない。

## 9. N=5との比較から得られる考察

N=5:
- rank 4
- 全10辺等振幅化
- その後 3+3+2+2 の4位相群へ縮退
- 3次元四角錐として読める位相閉包が形成

N=16:
- rank 15
- 全120辺等振幅化
- 急拡大はより早く完了
- しかし120関係の位相は多数方向を保ち、少数群へ縮退しない

したがってseedless自己無撞着系に普遍的なのは、

**複素simplexの形成 + ゼロ閉塞 + 等方的急拡大 + 等振幅化**

であり、

**少数の巨視的方向へ位相が縮退することは普遍的ではない**

と読める。

これは次の倍音シード実験の対照として重要である。
シードが本当に次元選択を担うなら、N=16のような高次元系で、
120関係の多数位相分布が少数群へ崩れ、
巨視的方向とcompact方向へ分離することを確認すべきである。

## 10. 現時点の結論

N=16 seedless実験は、N=5の「四角錐的3次元位相構造」が
seedless系一般の必然ではないことを示した。

一方で、

- rank=N-1 の複素simplex
- 二乗ゼロ閉塞
- 全関係の等振幅化
- 全非零主軸のdecompactification

は明瞭に再現した。

したがってN=16は、
**異方性を持たない高次元の均質な単一振動数波空間**
というseedless対照系として、次のシード依存性分類に適している。
