# N=5 γ→0 連続刻み極限テスト

作成日: 2026-08-25

## 目的

原本コードの

\[
\gamma=	an(\pi/144)
\]

に含まれる `144` が物理的な周期・離散位相条件なのか、それとも Cayley 更新の数値刻みなのかを検証する。

N=5 を固定し、

\[
n_\gamma = 144, 288, 576, 1152, 2304
\]

として

\[
\gamma=	an(\pi/n_\gamma),\qquad
\Delta\phi=2rctan\gamma=rac{2\pi}{n_\gamma}
\]

を変えた。

比較横軸は step 数ではなく累積位相

\[
	au=t\,\Delta\phi
\]

とした。

## 結果

親平面外占有率 `f` の指数成長率を累積位相あたりで評価すると、

- nγ=144: 1.131171 / rad
- nγ=288: 1.145300 / rad
- nγ=576: 1.152475 / rad
- nγ=1152: 1.156090 / rad
- nγ=2304: 1.157905 / rad

となり、刻みを細かくするほど一定値へ収束した。

`f=0.05` に到達する累積位相も、

- 144: 50.919981 rad
- 288: 50.287299 rad
- 576: 49.960050 rad
- 1152: 49.812788 rad
- 2304: 49.747338 rad

と収束した。

2304 を基準とする曲線差も、

- 144: RMSE 0.057013
- 288: RMSE 0.028035
- 576: RMSE 0.012819
- 1152: RMSE 0.005242
- 2304: 0

と系統的に減少した。

## 判定

このテスト範囲では、`144` だけに特別な物理的安定性・閉包性は確認されなかった。

むしろ

\[
n_\gamma	o\infty,\qquad\gamma	o0
\]

で `f(τ)` が一つの連続軌道へ収束する。

したがって現状では

\[
oxed{144 は物理自由度ではなく、Cayley 時間発展の有限位相刻み}
\]

と読むのが最も自然である。

重要なのは、この極限でも自己無撞着親、二乗ゼロ閉塞、ノルム保存に基づく現象自体は消えず、累積位相に対して有限の成長率へ収束していることである。
