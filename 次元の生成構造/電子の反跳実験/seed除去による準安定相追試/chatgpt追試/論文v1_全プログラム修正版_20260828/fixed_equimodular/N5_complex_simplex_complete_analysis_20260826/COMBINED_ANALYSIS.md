# N=5 複素simplex：急拡大・準安定化・3次元的位相秩序の総合考察

**作成日:** 2026-08-26

## 1. 基本構造

N=5 では M=10 の完全二体関係を持つ。step 5000 の複素二乗距離
\(z_{ij}^2=(a_{ij}^2-b_{ij}^2)+2ia_{ij}b_{ij}\)
から中心化複素Gram行列を再構成すると rank=4 であり、5頂点は4次元複素simplexとして閉じる。

同時に全10関係の \(|z_{ij}|^2\) は 0.1 に等長化するため、距離絶対値だけを見れば高対称な正4-simplex的外郭を持つ。

## 2. 位相による4群分類

最終的な10辺は

- A+ : 12, 13, 45 （3本）
- A- : 14, 15, 23 （3本）
- B+ : 24, 35 （2本）
- B- : 25, 34 （2本）

の 3+3+2+2 に分かれる。

A- は A+ に対し位相差 π/2、B- は B+ に対し π/2。
複素二乗距離ではそれぞれ符号反転 ±A, ±B となる。

したがって4群は本質的に「2種類の複素距離方向 × 符号反転」である。

## 3. 3次元的な読み

頂点1を頂点、(2, 4, 3, 5) を底面と読むと、

- 四角錐の外郭8辺:
  12,13,14,15,24,25,34,35
- 底面対角線2本:
  23,45

となり、K5の10関係が「8外郭辺 + 2対角線」として3次元四角錐に自然に読める。

ただし複素距離行列そのものの rank は4であり、これは4次元simplexが3次元へ縮退したという意味ではない。
高対称な4-simplex外郭の上に、位相分類が3次元的に読める内部構造を刻む、と解釈するのが現データに忠実である。

## 4. 急拡大期

raw-K の正規化なし物理発展では、親平面外二乗振幅 H_perp が初期に指数率約 0.1725/step で急増する。

最終 H_perp の到達時刻は:

- 50%: step 357
- 90%: step 395
- 95%: step 430
- 99%: step 449

したがって空間的スケールの急拡大は、おおむね step 450 までにほぼ完了する。

この段階では最終的な3+3+2+2構造はまだ形成されていない。
つまり急拡大そのものと最終的な位相秩序化は同時現象ではない。

## 5. 準安定期の自己組織化

急拡大終了後も、4群構造は数千stepかけてゆっくり収束する。

4群構造の最大誤差が以後ずっと閾値以下になる最初のstepは:

- < 1e-1 : step 814
- < 1e-2 : step 1531
- < 1e-3 : step 2099
- < 1e-4 : step 2627
- < 1e-6 : step 3791
- < 1e-8 : step 4923

したがって、

## 6. 時間発展の物理的読み

時間順序は現データから、

1. 自己無撞着な初期親状態
2. 親平面外方向の指数的急拡大
3. 全10関係の振幅二乗がほぼ0.1へ等分配
4. ±A, ±B の4群へ位相秩序化
5. 3+3+2+2 の安定な辺分類
6. 3次元四角錐として読める8外郭辺+2対角線構造

と整理できる。

したがって現時点では、インフレーション様急拡大が先に起こり、その後に次元・位相構造の選択が進む二段階過程に見える。

## 7. シード実験への予測

seedless では急拡大後に等長・高対称なsimplexが形成され、その内部位相がゆっくり秩序化する。

したがって次の倍音シード実験では、シードが急拡大そのものを生むのではなく、
**準安定期にどの方向を選び、どの方向をcompactなまま残すか**
に効く可能性が高い。

この意味で予測される役割分離は、

- 基本自己相互作用 → decompactification
- 倍音関係 → 異方性・次元選択

である。
