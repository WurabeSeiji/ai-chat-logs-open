# N=14,15,16 非自明部分ゼロ閉包の全次数探索

## 目的

前回の不足を補い、各 N について自明な頂点閉包サイズ N-1 より小さい全次数を探索した。

- N=14: k=2..12
- N=15: k=2..13
- N=16: k=2..14

各候補 B の閉包残差は

C(B)=|Σ z_e²| / Σ|z_e²|

で評価し、C<1e-6 を数値的閉包候補とした。

k<=N-2 なので、各候補は少なくとも「1頂点の N-1 本 star 閉包そのもの」ではない。

## 探索方法

組合せ数が急増するため、探索方法を次数に応じて段階化した。

- k=2,3,4: 全組合せ完全総当たり。ここは global exact。
- k=5,6: meet-in-the-middle + nearest-neighbor 探索。
- k>=7: 大規模 multi-start simulated annealing + 1-swap local descent。
- 閾値近傍候補には追加局所探索を実施。
- 全候補は保存済み元の複素数 z² で再評価した。

したがって k=2..4 については「最良値」を厳密に確定している。
k>=5 は広範な数値組合せ探索であり、NP困難な全部分集合完全列挙の数学的証明ではない。この区別を意図的に残している。

## N=14

全 k=2..12 を探索した。

1e-6 を下回ったのは k=6 の候補:

C = 9.249993e-7

辺集合:
{1-7, 2-14, 4-10, 5-9, 5-14, 10-13}

ただし時間履歴ではこの候補は 1e-6 近傍で準安定化し、N=5のように1e-8,1e-10へ収束しない。

したがって N=14 k=6 は
**threshold-level quasi-closure**
と分類する。

k=7..12 の広範探索では 1e-6 を下回る候補は得られなかった。

## N=15

全 k=2..13 を探索した。

1e-6 を下回る候補は見つからなかった。

代表的最良値:
- k=4: 2.893e-5
- k=5: 2.904e-5
- k=6: 4.763e-6
- 高次数側の最良も数e-6程度

したがって今回の全次数探索では、N=15にN=5型の明瞭な追加閉包は確認されない。

## N=16

全 k=2..14 を探索した。

1e-6 を下回る候補は見つからなかった。

高次数側では k=13,14 が比較的閾値に近いが、今回の最良値は約1.4e-6以上であり、追加局所探索でも1e-6を突破しなかった。

したがって現データでは、N=16にも明瞭な追加閉包は確認されない。

## N=5との比較

N=5では非自明2辺閉包の最良残差が

1.88e-10

まで連続的にゼロへ収束し、さらに10辺全体を

2+2+2+2+2

に分割する exact-cover が12通り存在する。

これに対して、
- N=14: 約9.25e-7で停止
- N=15: 1e-6未満なし
- N=16: 1e-6未満なし

である。

したがって現在までのデータで最も強い非自明閉包特異性は依然として N=5 にある。

## 結論

今回の追加調査により、N=14,15,16について「k<=6しか見ていなかった」という不足は解消した。

- N=14: k=2..12 全次数を探索。k=6に quasi-closure 1件。
- N=15: k=2..13 全次数を探索。明瞭な追加閉包なし。
- N=16: k=2..14 全次数を探索。明瞭な追加閉包なし。

重要なのは、高次数へ行けば自動的に新しい閉包が大量に現れる、という結果ではなかったこと。

外側の simplex / vertex-star 線形合成閉包は一般則として続く一方、その上に追加される独立閉包は N に強く依存し、現時点では N=5 が突出している。
