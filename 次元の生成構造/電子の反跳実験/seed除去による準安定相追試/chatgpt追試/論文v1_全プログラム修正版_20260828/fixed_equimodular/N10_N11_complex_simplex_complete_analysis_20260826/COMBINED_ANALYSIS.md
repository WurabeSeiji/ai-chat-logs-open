# N=10 / N=11 seedless 複素simplex比較解析
## raw-K・K/σ正規化なし・5000 step

**作成日:** 2026-08-26

## 条件

N=8/9までと同じ実験・分析系をそのまま使用した。

- seedless `make_parent`
- raw-K Cayley
- `K/σ` 正規化なし
- 5000 physical steps
- 各関係波 \(z=a+ib\) の \(a,b,a^2,b^2,ab,z^2\) を全step保存
- 中心化複素Gram rank
- Takagi主軸
- \(H_\perp\)
- \(|z|^2\) 等振幅化
- 位相・複素二乗距離クラス
- クラス分裂の時間発展

## N=10

\[
N=10,\quad M=45,\quad \operatorname{rank}=9=N-1.
\]

45本の関係は9次元複素simplexとして閉じた。

step 5000では

\[
0.02222222222222274\le |z|^2\le0.022222222222222907,
\]

すなわち全辺が

\[
\boxed{|z|^2=1/45}
\]

へ極めて高精度に等振幅化している。

ゼロ閉塞も

\[
\sum a^2\simeq0.5,\quad
\sum b^2\simeq0.5,\quad
\sum ab\simeq0
\]

で維持された。

\(H_\perp\) の最終値に対する到達は50%=step 281、90%=328、95%=333、99%=340。
その後、辺振幅spreadは step 1202 で \(10^{-10}\) 未満まで収束した。

位相・距離分類はstep 5000で、

- tol \(10^{-2}\): 39クラス = 3+2+2+2+2 + 36本の単独辺
- tol \(10^{-3}\): 44クラス = 2 + 43本の単独辺
- tol \(10^{-4}\) 以下: 45クラス

である。

したがって厳密な少数群縮退はなく、高精度では45辺すべて非縮退である。

## N=11

\[
N=11,\quad M=55,\quad \operatorname{rank}=10=N-1.
\]

55本の関係は10次元複素simplexとして閉じた。

step 5000では

\[
0.01818181817871555\le |z|^2\le0.01818181818473649,
\]

すなわち

\[
\boxed{|z|^2\simeq1/55}
\]

へ非常に高精度に等振幅化している。

ゼロ閉塞も数値精度で維持された。

\(H_\perp\) は50%=step 192、90%=216、95%=258、99%=288。
等振幅化はN=10より遅い尾を持ち、spread \(10^{-8}\) 未満はstep 3978、
\(10^{-10}\) 未満には5000 step内では到達していない。

位相・距離分類はstep 5000で、

- tol \(10^{-2}\): 42クラス = 3+3 + 2が9群 + 31本の単独辺
- tol \(10^{-3}\): 53クラス = 2+2 + 51本の単独辺
- tol \(10^{-4}\) 以下: 55クラス

である。

したがってN=11も厳密には55辺すべて非縮退である。ただし粗い精度ではN=10より多くの近接群が残り、位相整列の遅い尾と対応している可能性がある。

## N=10 / N=11 の比較

両方とも、

\[
\boxed{\operatorname{rank}=N-1}
\]

と

\[
\boxed{|z_{ij}|^2\to1/M}
\]

が再現された。

一方、少数の厳密な位相クラスへの縮退は見られず、N=7以降の高次元非縮退型を継続している。

ただし粗い位相近接群はNに対して単調には減少しない。N=11ではN=10より多く残っている。このため「Nが増えれば単純に位相が一様散開する」とまでは言えず、N固有の組合せ構造または収束時間を分離して調べる必要がある。

現時点で最も安定している系列的結果は、simplex rank \(N-1\)、ゼロ閉塞、全辺等振幅化であり、位相縮退はそれとは別のN依存現象として扱うのが妥当である。
