## 2. 結果の要点

### 2.1 baseline（線形回転＋位相のみ K）は原本を再現する

回転を Cayley から exp に替え、正規化を全て外しても、位相のみ K の力学は原本と同じ：潜伏相（onset 100〜660 step）、指数成長率（N=5: 0.172、N=16 decompact: 0.251 vs 原本 0.236）、等分配（最終 |z|² 相対幅 10⁻¹³〜10⁻¹⁴）、rank N−1、Floquet 乗数 1.0903 / 1.0528（原本 1.0901 / 1.0526）。**原本の結果は Cayley や正規化のアーティファクトではなく、「位相のみ K」の性質**である（ただし位相のみ K 自体が隠れた振幅正規化＝A4）。

### 2.2 修正版（振幅込み K）は原本と質的に違う

| 量 | 原本 | 修正版 |
|---|---|---|
| 出発 | 親 v（正規化、|v|=1）が位相のみ K の固定点。潜伏 100〜600 step | 親 v（|v| = 0.45〜1.90、N 依存）は振幅込み K の固定点ではない。**N=3, 4 だけは厳密な固定点**（H⊥/H ≈ 10⁻¹⁶ のまま 5000 step 不動）。N≥5 は **step 1 から離脱**（潜伏なし） |
| 急拡大 | 10⁻³² から指数成長（一直線） | 指数成長域なし（decompact の当てはめ窓 None、γ 掃引の rate が刻みとともに減少して収束しない、tol 掃引の成長率 NaN） |
| 移送の到達 | H⊥/H 最大 0.07〜0.83（N 依存） | **H⊥/H 最大 0.93〜0.999**（N≥6）。N=16 では H_total 3.62 のうち 3.59 が親平面を離れる |
| 最終状態 | 等分配（|z|² = 1/M、相対幅 10⁻¹⁴）、等モジュラー・ヌル錐単体、rank N−1 | **極端な不均一**（|z|² 相対幅 ≈ 2 ＝ 最小がほぼ 0）、rank N−1 は維持、|ZᵀZ| ≤ 10⁻¹³ は維持 |
| N=5 の 3+3+2+2 | 8 seed 全て | 8 seed 中 7 seed で崩れる（6;2;1;1 等）、一方の距離族のモジュラスが 0 になる seed あり |
| σ₁（実際の生成子） | 3.74 → 4.00（=N−1、位相のみ読出し） | 0.355 → 0.391（N=5、振幅込み K）。σ=N−1 は成り立たない |
| 保存則 | H_total・|ZᵀZ| 厳密保存 | **同じく厳密保存**（ドリフト ≤ 10⁻¹³、|ZᵀZ| ≤ 10⁻¹³）——実直交回転の定理は生き残る |
| 部分閉包 | N=5 の非自明 2 辺閉包 1.9e-10、N=14 k=6 quasi-closure 9.2e-7 | N=14〜16 に 1e-6 未満の候補なし（N=5 は入力が原本のまま） |

### 2.4 注意点（結論の限界）

1. **親探索の汚染**：A1 の副作用で `_eigenmode_residual`（単位ノルム前提）が壊れ、収束判定と最良リスタート選択が無効。N=6, 7, 10, 11 は未収束の親（真残差 0.47 / 0.39 / 0.081 / 1.4e-3）。修正版の定性的結論（即離脱・不均一化）は収束した親の N（8, 9, 12〜16）でも同じなので影響しないが、**baseline の N=6, 7, 10, 11 は対照として無効**（潜伏相が消えている）。summary.json の `parent_residual` は意味のない数。残差判定のスケール不変化は次回の判断項目。
2. **未同梱プログラムの入力**：`N5_all_steps_a_b_a2_b2_ab.csv`（エントロピー図・N=5 部分閉包・N5 4 群解析の入力）、N16 の位相構造 4 件、N3/N4 の位相クラス、閉包評価表は原本データのまま（`不足プログラム一覧と依頼文_20260828.md` の B 群）。これらに依存する図・表は修正版の結果ではない。
3. **修正版の親は修正後の力学の固定点ではない**（判断で意図的に無変更）。「潜伏→急拡大」を修正後の力学で再検証するには、振幅込み K で自己無撞着な親を別途構成する必要がある。N=3, 4 で親が厳密な固定点になっているのは、その手掛かり。
4. 修正版では H_total = |v|² が N とともに増える（0.2 → 3.6）。振幅込み K は |z|² に比例するので実効的な回転速度も N で変わり、5000 step の意味が N ごとに違う。

## 3. 修正方針の決定に向けた論点

1. 振幅込み K の下で自己無撞着な親（K(v)v = iσv を振幅込みで解く）を導入するか。
2. 親探索の残差判定をスケール不変にするか（数値判定のみ、状態は不変）。
3. 「急拡大」の定義：潜伏＋指数成長（旧）か、親平面からの移送の到達量（修正版で観測されるもの）か。
4. 不足プログラム B 群の回収後に、3+3+2+2・時間分離・N16 位相構造を修正版で再評価。
