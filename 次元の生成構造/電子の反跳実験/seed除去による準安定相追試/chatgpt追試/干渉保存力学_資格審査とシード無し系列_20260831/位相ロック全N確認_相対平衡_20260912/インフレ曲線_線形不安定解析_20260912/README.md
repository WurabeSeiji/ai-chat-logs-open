# インフレ曲線 線形不安定解析（2026-09-12）

インフレーション曲線 H⊥/H(t) を、微小シードの床線形不安定性から解析導出・検証したパッケージ。読出しのみ・物理無変更。

- H⊥/H(t) ≈ (seed)²·|μ_max|^{2t}, onset ≈ ln(1/seed)/(2ln|μ_max|)
- |μ_max|: 床ヤコビアンJの最大固有値。N増で減少＝インフレ減速。
- 固定床Jのδ発展傾き = 2log10|μ_max|（線形式は厳密）。実測はさらに~18-30%急＝床Jが非正規で時変積が上乗せ。
