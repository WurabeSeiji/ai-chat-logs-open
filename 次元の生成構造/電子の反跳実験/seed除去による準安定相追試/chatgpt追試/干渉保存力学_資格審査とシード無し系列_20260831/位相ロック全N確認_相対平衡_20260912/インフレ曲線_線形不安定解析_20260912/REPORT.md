# インフレーション曲線＝微小シードの線形不安定性（床ヤコビアンからの解析導出）

日付: 2026-09-12（木原指示「波の力学が解けたならインフレ曲線も微小シードから解析的に導けるはず。確認せよ」）。
読出しのみ・物理無変更。単一波EOM／SSB の続き。

## 主張

床は不安定な相対平衡。微小シード δ が床の線形化写像 J（z→exp(ΔτK(φ))z を床で線形化した 2M×2M 実行列）の
不安定固有方向で指数増幅する:
$$\frac{H_\perp}{H}(t)\approx(\text{seed})^2\,|\mu_{\max}|^{2t},\qquad \text{onset}\approx\frac{\ln(1/\text{seed})}{2\ln|\mu_{\max}|},\qquad
\text{ランプ傾き}=\frac{d\log_{10}(H_\perp/H)}{dt}=2\log_{10}|\mu_{\max}|.$$

## 二段構造の結論（探究型物理学者ロール）

- **導ける（形・機構・N依存・onset）**: インフレ曲線は床の線形不安定モードの指数増幅。
  - **[B] 線形不安定式は厳密に正しい**: 固定床Jで微小δを発展させた H⊥ 傾きが 2log10|μ_max| に一致（N=6で0.2935 vs 0.2937）。
  - **N依存を再現**: |μ_max| は N増で減少（1.402→1.269→1.185）＝インフレが遅くなり onset が伸びる。
  - onset ≈ ln(1/seed)/(2λ) が桁・スケールで一致。

- **精密化（非正規補正）**: 実測ランプ傾きは床解析より一貫して **~18-30%急**（実測/床解析 = 1.18〜1.31）。
  - **[D] 床Jは強い非正規行列**（非正規度 0.53〜0.76）。
  - 局所増幅率はランプ上でほぼ一定（別途確認: N=6で床0→飽和前まで|μ_max|≈1.402一定）だが、実ランプは
    K(φ) がdriftする**時変・非可換な非正規Jの時間順序積** ∏J(φ_t) の増幅で、これは各行列の固有値より速い
    （同時スペクトル半径 ≥ 個別スペクトル半径）。床固有値は初期・凍結rate＝下界。

**一文**: インフレ曲線は微小シードの線形不安定増幅で解析的に導け、**床ヤコビアンの最大固有値 λ=ln|μ_max| が
主要予測（傾き 2λ/ln10・onset・N依存）**を与える。正確な傾きは時変非正規Jの時間順序積の増幅で、床固有値に
~20-30%上乗せされる（非正規補正）。
