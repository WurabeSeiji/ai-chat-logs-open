# 自発的対称性の破れ(SSB)：90°格子は不安定・非唯一の対称平衡、シードが縮退真空を自発選択

日付: 2026-09-12（木原指摘の訂正を受けて）。読出し＋厳密one_stepの制御実験（初期条件のシードのみ制御変数、物理式不変）。

## 訂正（重要）

前パッケージ（単一波EOM §7）は「90°格子は全項個別0の唯一の最大対称配置＝必然」を強調したが、
**強調が誤り**。物理の核心は「90°格子が**唯一の平衡ではない**こと」。木原指摘のとおり:

> 唯一の平衡点でないから、自発的対称性の破れが僅かなシードで起こってインフレーションを起こし、
> 別な（振幅が一定で位相が分散した）傾いた平衡点に落ちる。

これはメキシカンハット型のSSBそのもの: 90°格子＝最大対称だが**不安定**な平衡（頂上）、
安定な縮退真空（等振幅・位相分散・傾いた平衡）が別に存在 → 微小シードで対称性が破れ、
系は転がり落ち（インフレーション）、縮退真空の一つへ落ちる。

## 結論（探究型物理学者ロール）

- 分類: 新仮説の実測支持（SSB像）。判定: 保持。
- **SSB確認**: 全シードが inflation を起こし、**同じ型**（等振幅・Δ=−2π/N 厳密）の安定平衡へ落ちるが、
  **位相配置（＝真空の向き）はシードごとに異なる**（seed間差 中央 1.6°〜112.7°）。
  ＝縮退した真空の一つを微小シードが**自発的に選ぶ**。これが自発的対称性の破れ。
- インフレーション＝不安定な最大対称平衡（90°格子）からの転がり落ち。ロック＝縮退真空への着地。
- 前パッケージの「90°格子の必然性」は、正しくは「**唯一でない**ことがSSBを可能にする」と読むべき。
  90°格子は order parameter が0の対称相（不安定）、ロック真空は order parameter≠0 の破れた相。
  不変量（Δ=−2π/N・等振幅）は真空共通、破れた自由度（位相配置の向き）がシードで選ばれる。
