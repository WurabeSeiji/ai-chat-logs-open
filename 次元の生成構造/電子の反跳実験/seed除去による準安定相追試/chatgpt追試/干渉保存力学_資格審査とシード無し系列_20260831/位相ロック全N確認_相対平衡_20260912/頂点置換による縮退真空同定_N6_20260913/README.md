# 縮退真空の頂点置換軌道テスト（N=6・決定的）

日付: 2026-09-13。読出しのみ・物理無変更・新規走行は既存床からの再現のみ。論文5 の SSB/multistability 境界確定。

## 目的

論文5 の SSB（メキシカンハット型：不安定な対称極大→縮退した谷→微小シードの自発選択）は実測事実。本テストは
その**縮退真空多様体（谷）の構造**を特定する：谷が (A) 有限離散な写像対称性軌道（$S_N$＋大域位相）か、(B) より大きな
（連続）モジュライ（傾いた相対平衡の連続族。メキシカンハットの谷の一般形）か。どちらでも SSB は成り立つ（谷は本来
連続縮退多様体で有限離散軌道である必要はない）。$N=6$ の $6!=720$ 頂点置換総当たりで (A) の有限軌道に尽きるかを判定する。

## 実行

```
bash run_all.sh
```

`verify_vacua_permutation_orbit_N6_20260913.py`：正本 `run_N3_N40_stage123_v1.py`（SHA `1abf2353…`）の
adjacency/one_step を import。make_parent 床 step0 に batch と同一シード5通りを与え 20000 step で相対平衡へ
強収束させ、720 頂点置換＋大域位相（＋複素共役）で全ペアの最小一致残差を測る。numpy 依存。

## 結果（要約）

終状態は真の相対平衡（相対配置変化率 $\le3.4\times10^{-8}$ rad/step、振幅比 $\approx1.0000000$）。
720 頂点置換＋大域位相のどれでも全10ペアが一致せず（最小残差 $4.9\times10^{-2}$–$8.3\times10^{-1}$、複素共役込みでも同程度）。
**判定：(B) 谷は有限離散 $S_N$ 軌道ではなく連続モジュライ**（傾き $H_\perp/H=0.19$–$0.38$ が連続的）。これは SSB を否定せず整合する
（メキシカンハットの谷は本来 連続縮退多様体）。有限離散軌道仮説 (A) のみ排除。詳細は `分析_縮退真空の頂点置換軌道テスト_N6_20260913.md`。
