# 縮退真空は写像対称性軌道上か——N=6 の 720 頂点置換総当たりテスト（決定的）

日付: 2026-09-13（木原レビュー反映）。読出しのみ・物理無変更・新規物理式なし。論文5 の SSB/multistability 境界の確定。

## 問い

論文5 は同一 make_parent 床＋向きの異なる微小シード5通りから、$\Delta_{\rm tail}=-2\pi/N$・等振幅を共通に持ちつつ相対位相配置の異なる終端相対平衡へロックすることを示した（メキシカンハット型 SSB：不安定な対称極大→縮退した谷→微小シードによる自発選択、は実測事実）。本テストは、この**縮退した真空多様体（谷）の構造**を特定する：谷は
(A) **有限離散な写像対称性軌道**（頂点置換 $S_N$＋大域位相の軌道）か、
(B) **より大きな（連続）モジュライ**（傾いた相対平衡の連続族。メキシカンハットの谷の一般形）か。
どちらでも SSB 構図は成り立つ（メキシカンハットの谷は本来 連続縮退多様体で、有限離散軌道である必要はない）。本テストは谷が (A) の有限軌道に尽きるかを判定する。

## 方法（$N=6$、$6!=720$ 頂点置換総当たり）

1. $N=6$ の5終状態を batch と同一シード（`default_rng(1000\cdot6+s)`, amp $10^{-8}$, $Z_0$＝make_parent 床 step0）で作り、正本 `one_step` を **20000 step** かけて相対平衡へ強収束（batch の $3\times10^{-4}$ lock よりはるかに深く）。
2. 各終状態 $z^{(a)}$ を頂点置換 $P\in S_6$ の誘導辺置換で写し、大域位相 $\theta$ を最適化して
   $$\mathrm{res}(a,b)=\min_{P\in S_6}\min_\theta \frac{\|z^{(b)}-e^{i\theta}Pz^{(a)}\|}{\|z^{(b)}\|}$$
   を全10ペアで測る。補助として複素共役も許した残差も測る。

$L(K_6)$ の自己同型は Whitney により $S_6$ に尽きる（$N\ge5$）ので、大域位相・共役を加えれば写像の対称性を尽くしている。

## 結果

- **終状態は真の相対平衡**：相対配置変化率（1step）$7.7\times10^{-9}$–$3.4\times10^{-8}$ rad/step、振幅比 $1.00000002$–$1.00001621$。収束は十分。
- **720 頂点置換＋大域位相のどれでも一致しない**：全10ペアの最小残差は **$4.9\times10^{-2}$–$8.3\times10^{-1}$**（機械精度 $10^{-6}$ の遥か上、収束レベル $10^{-8}$ の $6$–$7$ 桁上）。複素共役を許しても $4.9\times10^{-2}$–$8.1\times10^{-1}$。
- 最小残差ペア（0-1: $0.088$、2-4: $0.049$、いずれも恒等置換で最小）は互いに**近い**が一致はしない＝モジュライ上の近接点。

## 判定（探究型物理学者ロール）

- 分類：決定的テスト（$S_6$ 全数）。判定：**(B) 谷は有限離散 $S_N$ 軌道ではなく、より大きな（連続）モジュライ**。5つの終端真空は $S_6$ 頂点置換＋大域位相（＋複素共役）で互いに写らない別々の相対平衡で、共通なのは $\Delta_{\rm tail}=-2\pi/N$・等振幅。傾き $H_\perp/H=0.19$–$0.38$ が連続的に見えることと合わせ、真空多様体は**傾いた相対平衡の連続モジュライ**である。
- **これは SSB を否定しない。むしろ整合する。** メキシカンハットの谷は本来 連続縮退多様体（古典的には U(1) リング＝Goldstone）で、有限離散軌道である必要はない。したがって「$S_6$ 置換で写らない」は「SSB でない」ことを意味せず、**谷が連続モジュライである**ことの肯定的特徴づけである。有限離散軌道仮説 (A) だけが排除された。
- SSB 構図（不安定な対称極大 $r=0$ →縮退した谷 $r_{\rm vac}$ →微小シードによる自発選択）は実測事実として保持。$r=\sqrt{H_\perp/H}$ は谷への転落を表す1次元有効座標で、$V(r)$ はその方向の有効ポテンシャル（アンサッツ）。真空多様体の連続性ゆえ、$r$ は全真空共通の厳密動径ではない（谷は $r$ 以外の方向にも広がる）。
- 破れているのは対称性（対称な不安定床→対称性の低い縮退した相対平衡の連続族の一点をシードが選ぶ）。谷が有限離散軌道でなく連続モジュライである点が、本テストで確定した追加構造である。

## 未決 / 留保

- モジュライの次元・計量（傾き $H_\perp/H$ が $0.19$–$0.38$ と連続的に見える）の同定は本テストの範囲外。
- $N=6$ で確定。他 $N$ でも同様か（$N!$ が大きく総当たりは $N$ 増で不可）は、傾き $H_\perp/H$ のシード連続性から示唆されるが本テストは $N=6$ のみ。
