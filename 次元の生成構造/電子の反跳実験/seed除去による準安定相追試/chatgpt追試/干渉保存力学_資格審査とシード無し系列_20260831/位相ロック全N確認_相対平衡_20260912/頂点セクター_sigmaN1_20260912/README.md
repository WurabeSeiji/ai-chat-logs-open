σ=N-1 定理の一致は要検証仮説」を既存 10000step 終端状態で検定。


## 結果（詳細は REPORT.md）

大半は残余セクター（0.93+）。→「σ=N-1(値) ↔ 頂点セクター(次元)」は次元ラベルの偶合で対応せず（否定）。
