# 追試A：インフレ実ランプの床値超過は時変・非可換ヤコビアン積の増幅である（直接検証）

日付: 2026-09-12。読出しのみ・物理無変更・新規走行なし（既存 den=N 500step 軌道を使用）。
動機: 論文6 で「実ランプが床固有値予測 2log10|μ_max| を ~18-31% 上回る分は時変非正規 J の
時間順序積が担う」を**物理的解釈**として書いたが、直接 Lyapunov 照合が未実施だった。既存データで確定させる。

## 方法

各辺波の状態を $[\Re z;\Im z]\in\mathbb R^{2M}$ に埋め込み、one_step の $2M\times2M$ 実ヤコビアン $J(z)$ を
有限差分（$\varepsilon=10^{-8}$、analyze_inflation_linear_instability と同一構成）で求める。同一の微小 $\delta$ を
床平面直交成分 $H_\perp$ で追跡し、共通窓（実測ランプの $[\max(\text{lo},12),\text{hi}]$）で $\log_{10}$ 傾きを比較する:

- **(a) 床凍結**: $J_0=J(z_0)$ を固定して $\delta$ を発展（床固有値予測 $2\log_{10}|\mu_{\max}|$ に一致するはず）。
- **(b) 時変積**: 実軌道 $\varphi_t$ 上の $J(z_t)$ を順に掛けた時間順序積 $\prod_t J(z_t)$ で $\delta$ を発展。
- **(c) 実測**: 実軌道そのものの $H_\perp/H$ ランプ傾き。

正本 `run_N3_N40_stage123_v1.py`（SHA256 `1abf2353…`）から adjacency/one_step を import（忠実）。

## 判定（探究型物理学者ロール）

- 分類: 導出済み帰結（機構の直接数値確認）。判定: 断定（物理的解釈から格上げ）。
- **(b) 時変積の傾きは (c) 実測ランプと一致**（時変/実測 = 0.999 / 1.004 / 1.019、$N=6,8,10$）。
- **(b) 時変積は (a) 床凍結を 18–31% 上回る**（時変/床 = 1.177 / 1.311 / 1.253）——実測の超過（実測/床 = 1.178 / 1.306 / 1.230）と定量一致。
- したがって**実ランプが床固有値予測を上回る 18–31% は、時変・非可換ヤコビアンの時間順序積 $\prod_t J(z_t)$ の増幅で説明される**（床凍結の単一 $|\mu_{\max}|$ を超える分は時変性が担う）。線形の時間順序積で再現するので、超過は非線形性や測定由来ではない。

## 未決 / 留保

- 増幅率の**閉形式**（$\prod_t J(z_t)$ の有限時間 Lyapunov の解析式）は本追試の範囲外（未導出）。本追試が確定したのは「超過分＝時変積の増幅」という機構であって、その閉形式ではない。
- $N=6,8,10$・$D=N$ の数値観測。$N=40$（$2M=1560$）は重く未計算だが、小 $N$ で機構は確立。
