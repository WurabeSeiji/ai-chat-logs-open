# 追試A：ランプ超過＝時変非正規ヤコビアン積（直接Lyapunov照合）

日付: 2026-09-12。読出しのみ・物理無変更・新規走行なし。論文6 の「実ランプが床固有値を18-31%上回る分は
時変非正規Jの時間順序積が担う」という物理的解釈を、既存軌道データで直接検証して確定させる追試。

## 実行

```
bash run_all.sh
```

`analyze_ramp_lyapunov_20260912.py` が正本 `../../N3_N40_stage123_sweep_20260905/run_N3_N40_stage123_v1.py`
（SHA256 `1abf2353…`）から adjacency/one_step を import（SHA照合）し、既存 den=N 500step 軌道
（`../../make_parent型初期値_自己無撞着構造_20260907/full_N3_N40_sweep/states/`）を読み込んで、
床凍結 $J_0$・時変積 $\prod J(z_t)$・実測ランプの $H_\perp$ 傾きを $N=6,8,10$ で比較する。

## 結果（詳細は REPORT.md）

時変積の傾きが実測ランプに一致（時変/実測 = 0.999/1.004/1.019）し、床凍結を18-31%上回る
（時変/床 = 1.177/1.311/1.253）＝**超過分は時変非正規Jの時間順序積の増幅**（確定）。

## 依存・入力

- numpy。scipy 不要（one_step は正本 import、J は有限差分）。
- 入力は読み取りのみ（正本コード＋既存 states npz）。出力は `results/` のみ。
