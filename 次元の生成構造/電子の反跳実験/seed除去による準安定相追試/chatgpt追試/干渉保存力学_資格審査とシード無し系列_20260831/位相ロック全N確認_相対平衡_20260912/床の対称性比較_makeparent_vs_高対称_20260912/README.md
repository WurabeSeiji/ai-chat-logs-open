# 床の対称性比較: 乱数make_parent vs 意図的高対称床（同一N・複素平面＋定量）

日付: 2026-09-12。読出しのみ・物理無変更・新規走行なし。動機（実験台帳）: 初期に使った make_parent は
乱数シードから自己無撞着固定点 KZ=iσZ を作るが、その床は全Nで自然に90°二軸位相格子になった（実験4-1・検討28）。
位相は自然に90°だが振幅は辺ごとにバラバラで対称性は高くない。そこで「90°位相差骨格の上に極めて対称な
自己無撞着床を作れるか」を問い、高対称床を意図的に構成した。本パッケージは同一Nで並べ対称性増加を定量する。

## 実行
```
bash run_all.sh
```
`compare_floor_symmetry_20260912.py` が3床（make_parent床＝full_N3_N40_sweep step0／高対称v2＝最も対称性の高い初期値／
整数K解析床＝90度理論床）を N=6,12,17,40 で読み込み、複素平面図（`fig_floor_symmetry_compare.png`）と
対称性指標（振幅値数・CV・|Σz|・|Σz²|、`results/floor_symmetry_summary.csv`）を出す。

## 結果（詳細は figP/CSV）
位相はどれも90°。振幅値数は make_parent が N=6→40 で 9→699（ほぼM値）、高対称v2 は≤2値（重心は最大級 √(M/2)
＝実験12のNG要因）、整数K解析床は≤3値かつ小重心（|Σz|≈0）で相対平衡（論文3）。＝乱数→意図的高対称の進行が一目瞭然。

## 依存・入力
numpy, matplotlib。入力は読み取りのみ（既存 床 npz 3種）。出力は本フォルダ（図・results/）。
