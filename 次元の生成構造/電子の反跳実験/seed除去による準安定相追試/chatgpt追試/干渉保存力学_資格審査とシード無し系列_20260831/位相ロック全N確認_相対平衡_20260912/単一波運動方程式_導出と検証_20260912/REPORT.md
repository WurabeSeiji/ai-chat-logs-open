# 単一波の運動方程式：導出と数値検証

日付: 2026-09-12（木原指示「なぜ1つの波が今回の軌道を取るのか＝物理。剛体回転を除いた τ発展方向の
位相変位と振幅変化を説明できる定式化がポイント」）。読出しのみ・物理無変更。

## 1. 出発点：正本 one_step（厳密）

`../../N3_N40_stage123_sweep_20260905/run_N3_N40_stage123_v1.py`（SHA256=1abf2353…）の力学:

```
H = H_of(exp(i·angle(z)), A)            # H_ef = A_ef · e^{i(φ_f - φ_e)}   （u=exp(i·angle z)＝単位振幅）
H ← i·Im(H)                              # H_ef = i·A_ef sin(φ_f-φ_e) = i·K_ef
z_{n+1} = exp(-iΔτ·H) z = exp(Δτ·K) z    # Δτ = 2π/den
```

- **A**: 辺グラフ L(K_N) の隣接（辺 e,f が頂点を共有すれば A_ef=1）。
- **K_ef = A_ef sin(φ_f − φ_e)**: φ=angle(z)。**位相のみ**で決まり、振幅 |z_e| は生成子に入らない。
- K は実反対称 ⟹ exp(Δτ·K) は**実直交行列**。Re z と Im z に同一作用し、‖z‖ と閉塞 z^T z（Σz²）を厳密保存。

## 2. 単一波の運動方程式（導出）

生成子の流れ dz/dτ = K z を成分で書くと（f~e は e と頂点共有の辺）:
$$\frac{dz_e}{d\tau} = \sum_{f\sim e}\sin(\varphi_f-\varphi_e)\,z_f
 = \sum_{f\sim e} r_f\,\sin(\varphi_f-\varphi_e)\,e^{i\varphi_f}.$$

z_e = r_e e^{iφ_e} として左辺 = e^{iφ_e}(ṙ_e + i r_e φ̇_e)、右辺の e^{iφ_f}=e^{iφ_e}e^{i(φ_f-φ_e)} を使い e^{iφ_e} を約すと、
ψ ≡ φ_f−φ_e に対し RHS = Σ r_f sinψ(cosψ + i sinψ)。実部・虚部を分けて:

$$\boxed{\ \dot r_e = \frac{dr_e}{d\tau} = \frac{1}{2}\sum_{f\sim e} r_f\,\sin\!\big(2(\varphi_f-\varphi_e)\big)\ }\tag{振幅}$$

$$\boxed{\ r_e\,\dot\varphi_e = r_e\,\frac{d\varphi_e}{d\tau} = \sum_{f\sim e} r_f\,\sin^2(\varphi_f-\varphi_e)\ }\tag{位相}$$

各辺波は「頂点を共有する隣接辺」とのみ、**蔵本型 sin(位相差) 結合**で相互作用する。

## 3. この式が軌道を説明する

- **位相（回転と、剛体回転を除いた変位）**: sin² ≥ 0 ゆえ全波の φ_e は単調前進＝回転。
  共通分が剛体回転、波ごとの (1/r_e)Σ r_f sin²(Δφ) の**差**が剛体回転を除いた位相変位。
- **振幅（増減）**: 駆動は**第2高調波 sin(2Δφ)**。隣接辺との位相差の2倍の正弦の重み付き和で増減する。
- **床（0/90/180/270 の90°格子）**: 位相差が全て90°の倍数 ⟹ sin(2Δφ)=0 ⟹ ṙ_e=0（振幅凍結＝相対平衡）。
  さらに全波同率回転。これは平衡だが**不安定**：微小な位相ずれ δ で sin(2Δφ)≈2δ≠0 となり振幅が動き出す。
- **不安定→再ロック**: 振幅が動くと位相前進率（式中の r_f）が変わり位相がさらに格子から外れ、振幅を一層駆動
  （＝インフレーション、剛体回転を除いた枠では位相の再配置＝歳差として見える）。停止条件は再び ∀e で ṙ_e=0、
  すなわち **Σ_{f~e} r_f sin(2(φ_f−φ_e)) = 0**。等振幅 r_e=r では Σ_{f~e} sin(2(φ_f−φ_e))=0。
  ここに落ちると振幅変化も歳差も止まり、傾いた新軸で剛体回転が回復＝再ロック。

要するに: **90°格子は第2高調波駆動 sin(2Δφ) がちょうど消える不安定平衡**で、系はそこを離れ、
**第2高調波駆動が再び消える等振幅の新平衡**（傾いた軸）へ落ちる。これが位相変位と振幅変化の定式化。
