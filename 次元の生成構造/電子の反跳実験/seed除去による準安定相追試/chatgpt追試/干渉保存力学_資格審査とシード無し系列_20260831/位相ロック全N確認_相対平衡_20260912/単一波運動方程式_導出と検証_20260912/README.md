# 単一波運動方程式 導出と検証（2026-09-12）

正本 one_step から「なぜ1つの波がこの軌道を取るか」を導出・検証したパッケージ。読出しのみ・物理無変更。

- 生成子 K_ef = A_ef sin(φ_f−φ_e)（位相のみ）、写像 z→exp(Δτ K)z（実直交）
- 振幅 dr_e/dτ = ½Σ_{f~e} r_f sin(2(φ_f−φ_e))
- 位相 r_e dφ_e/dτ = Σ_{f~e} r_f sin²(φ_f−φ_e)
- 90°格子で sin(2Δφ)=0 → 振幅凍結（不安定平衡）。離脱→等振幅新平衡へ再ロック。

詳細は REPORT.md。再現は `bash run_all.sh`（要 numpy, scipy）。
