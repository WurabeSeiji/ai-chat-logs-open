# 全N（3–40）位相ロック確認：相対平衡→インフレーション→相対平衡ロック

日付: 2026-09-12（木原指示「全Nで確認」）。読出しのみ・物理無変更・走行/親生成の再実行なし。
入力: `../make_parent型初期値_自己無撞着構造_20260907/full_N3_N40_sweep/states/hm_N{N}_den_{N}_states_500.npz`（den=N, 500step, 全38本）。
θ0・H⊥/H・PC 等の物理式は正本 `plot3d_makeparent_selectedN_v1.py` から取得（本パッケージで再実装しない）。

## 測定量（すべて既存状態 npz の読出し）

- 剛体回転残差 `rig(τ) = 1 − |⟨z(τ),z(τ+1)⟩|² / (‖z(τ)‖²‖z(τ+1)‖²)`。相対平衡（固定形が一定角速度で回る）なら 0。
- 末尾50step の rig 中央値 `rig_tail`、1step回転角 `Δ_tail = arg⟨z,z'⟩`。
- ゲージ不変な相対位相 `φ_m − φ_0` の末尾変化率 `rel_rate_tail`（θ0非依存＝物理のロック指標）。
- 末尾振幅の等半径度 `amp_ratio_tail = max/min`。
- 末尾100step の `log(rel_rate)` の傾き（収束途中か否かの判別）。

## 結論（CONFIRMED, 全N)

1. **相対平衡の床は普遍**。onset前の床で `rig_floor ≈ 2.2×10⁻¹⁶`（機械ゼロ）が全N。床は厳密に剛体回転している。

2. **インフレーション＝剛体回転からの離脱**。inflation区間で `rig_peak` が 10⁻²〜10⁻⁴ に立ち上がる（振幅再配分で形が一時的に崩れる）。ピーク高はNとともに減少。

3. **ロック後の回転角は厳密に −2π/N（普遍・den=N）**。`Δ_tail = −2π/N` が全N=3–40で4桁一致（例 N=6: −1.0472=−2π/6, N=40: −0.1571=−2π/40）。ロック状態は「1周= N step」で回る単一の相対平衡。

4. **振幅は等半径にロック**。ロック済みNで `amp_ratio_tail = 1.0000`。

5. **ロックは普遍だが整定時間律速**。しきい値（rel_rate_tail<1e-4 かつ rig_tail<1e-6）での完全ロック成立は 26/38。残り12本は主に大N（22,30–40）。ただしこれらは「ロックしない」のではなく「500stepでは整定時間不足」:
   - onset は N とともに遅くなる（N=6: step64 → N=40: step316）。onset後の整定時間 `T−onset` が短いほど末尾のロックが浅い（`fig_phaselock_allN.png` 左下、単調関係）。
   - 末尾100step の `log(rel_rate)` の傾きは 35/38 が負（＝まだ減少中＝同じロックへ収束中）。正の3本は N=3,4,5 で、うち N=3,4 は既に rel_rate_tail~10⁻¹³（機械ゼロ、傾きは床ノイズ）。
   - つまり全N が同一のロック（Δ=−2π/N・等半径の相対平衡）へ単調に収束しており、大Nは 500step 打ち切りで途中。

## 判定（探究型物理学者ロール）

- 分類: 導出済み帰結（相対平衡アトラクタへの収束）。判定: 保持。
- 「大N=ロックしない」は棄却（理由: 末尾 rel_rate 傾きが負で単調収束、整定時間 T−onset との単調関係）。
- N=3,4,5 は既知の例外系（rank一般式 N≥6 の域外）で、N=3,4 は即時ロック、N=5 は近ロック。

## 未検証課題

- 大N（22,30–40）の完全ロック確認には step 数を延長した走行が要る（本パッケージは既存500stepの読出しのみ。走行は含まない）。実施はインフレ機構の忠実コピー実験として別途要指示。
- 床の相対平衡の回転角（onset前）は −2π/N と一致しない（例 N=6 床 ≈ −1.185 → ロック −1.0472）。「別の相対平衡から −2π/N の相対平衡へ乗り換える」機構の同定は未了。
