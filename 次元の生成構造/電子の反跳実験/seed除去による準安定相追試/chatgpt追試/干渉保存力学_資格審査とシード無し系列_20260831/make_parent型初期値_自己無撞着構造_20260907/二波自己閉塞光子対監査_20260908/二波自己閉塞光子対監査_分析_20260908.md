# 二波自己閉塞（光子型 ±i 対）の自発生成監査 — make_parent vs 高対称理論床

**実験日:** 2026-09-08  
**対象:** N=3..40、各 N の M=N(N-1)/2 関係波  
**主判定:** 親 `v`、独立確認: 実初期状態 `Z0`

## 1. 目的

二つの非零複素波が

$$z_i^2+z_j^2=0$$

を満たすことは

$$z_j=+iz_i\quad\text{または}\quad z_j=-iz_i$$

と同値である。本監査では、この「等振幅・相対位相 ±90°」の二波自己閉塞対が、(A) ランダム初期位相から自己無撞着固定点だけで生成した canonical `make_parent` 親と、(B) 幾何的に作り込んだ高対称理論床のどちらに、どの N で出現するかを全 pair 総当たりで測定した。

## 2. 判定量

スケールに依存しない主残差を

$$\epsilon_{ij}=\frac{|z_i^2+z_j^2|}{|z_i|^2+|z_j|^2}$$

とし、`strict` を $\epsilon_{ij}\le10^{-12}$ とした。併せて振幅不一致、±90°からの位相残差、$z_j\mp iz_i$ の直接残差を記録した。候補グラフについて最大マッチングも計算し、全波を重複なしの二波閉塞対へ分割可能かを確認した。

## 3. 入力の固定

- make_parent: `make_parent型初期値_自己無撞着構造_20260907/parents_actual_N3_N40/` の canonical 38親。
- 高対称: `対称親v2_500step走行_20260906/parents_symmetric_staged/` の 38親。
- 両者とも保存 NPZ の `v` と `Z0` を直接解析し、再生成していない。

## 4. 結果1 — make_parent には N=3..40 で厳密な光子型二波閉塞対は無い

`v` と `Z0` の双方で、N=3..40 の全系列について $\epsilon\le10^{-12}$ および $\epsilon\le10^{-9}$ の pair は **0** だった。したがって、少なくとも本 canonical seed=0 系列では、自己無撞着条件だけから機械精度の $z_j=\pm iz_i$ 対が完成しているとは言えない。

## 5. 結果2 — 高対称理論床では N=8の倍数だけに厳密な二波閉塞対が大量発生

`Z0` でも strict N と pair 数は同一で、$\delta=10^{-15}$ の seed 摂動はこの分類を変えなかった。

## 6. なぜ高対称系で N=8k に出るか

高対称親の生成コード `make_parents_theoretical_floor_v1.py` は位相を

$$\theta_e=\frac{2\pi(a_e+b_e)}{N}$$

とし、振幅を頂点間の巡回距離クラス $d$ ごとの $r_d$ で与えている。したがって、同一距離クラスで位相差が $\pi/2$ になる辺対が存在すると、等振幅と±90°が同時に成立して $z_j=\pm iz_i$ が厳密に出る。今回の全探索ではその整合が N=8k にだけ現れた。

よって高対称系列の厳密 pair は「自己無撞着性だけから未知の光子が発生した」という証拠ではなく、**作り込んだ円周位相と距離クラス等振幅の幾何が二波閉塞を自動包含していたことの発見**である。これは高対称初期化の内部構造として重要である。

## 7. 比較から得られる主要発見

1. `make_parent` は全 N で全体の二乗和閉塞を満たすが、N≤40 では厳密な二波部分閉塞へ因数分解されていない。
2. しかし `make_parent` は位相をほぼ Z4（90°格子）へ自発的に固定するため、二波光子条件のうち **位相条件は既に自然に形成**されている。
3. 高 N の `make_parent` では振幅差が小さくなり、N=27以降に $10^{-6}$ 以下、最良 N=30 で $3.7\times10^{-8}$ の近似二波閉塞が出る。残差のほぼ全ては振幅不一致である。
4. 高対称理論床は N=8k で完全な二波閉塞 pair 分解を持つ。これは高対称構成の位相格子＋距離クラス等振幅が作る厳密な部分構造である。
5. よって次の本質的な問いは「自己無撞着性が±90°を作るか」ではなく、**自己無撞着力学が等振幅化をさらに進め、近似 pair を厳密 pair へロックする機構を持つか**である。

## 8. 光子仮説への含意（現段階）

本実験は光子同定を証明しない。しかし、二波閉塞 $z_j=\pm iz_i$ を「検出可能な部分構造」として定量化できた。特に高対称 N=8k では全波を二波閉塞対へ完全分割できるため、今後の相互作用実験では各 pair の左右符号（+i / -i）、pair の保存・交換・崩壊、固定 $R_{124,23}$ 散乱追加時の pair 生存率を直接追跡できる。
