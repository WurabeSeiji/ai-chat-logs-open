# 三方向の区別と安定性（2026-09-06）

木原の問い: 初期条件で 90°位相差の複素平面が明確に立っている。三方向を初期条件に錨を置いて
区別せよ。法線方向が一番安定ではないか。元の複素平面で保存される方向があれば、法線と合わせて
3軸が安定して読み出せるのではないか。

## 三方向の定義（本パッケージの規約）

- X̂ = p = Re Z₀/‖Re Z₀‖（初期実軸）
- Ŷ = q = Im Z₀ の p 直交化・正規化（初期虚軸）。Π₀ = span(p,q) が「元の複素平面」
- Ẑ = Π₀ の法線（N=3 では p×q。生成子回転軸 n(0) と p×q の一致は測定で確認: 0.00°）

定義の厳密性（実測）: 90°ずれ ≤ 2×10⁻¹⁵、振幅比 Im/Re = 1.000000（全N）。
さらに親の面内方向は円偏光固有ベクトル ê₊=(1,i)/√2 に**厳密一致**（c₊(0)=1.00000000、全N）。
面内回転 SO(2) の複素固有ベクトルは ê± のみで固有値は純位相——**90°位相差構造（円偏光の
組み合わせ）そのものが、面内回転で向きを変えない唯一の方向**。木原仮説の代数的根拠。

- 増幅期は面の向きがほぼ凍結（剛体回転は位相差を変えないので K も面も動かない）。

- **結晶 N=3,4 の終傾角は両方とも厳密に 35.264° = arccos√(2/3)**（マジック角、tan⁻¹(1/√2)）。
- N=5 だけ終盤も揺れ続ける（安定な3軸枠が存在しない）。ガラスは凍結するが傾角は小さめ。

### 終状態の面内楕円（検査3）と閉じた形

- **N=3: 位相差は厳密に 90.0000°（std 6e-14）のまま、振幅比 |b/a| = √(3/2) 厳密（1.00000000、std 6e-16）**。
  複素平面は「立ったまま」、振幅バランスだけが 2:3 に移る。
- h1=5/6 と合わせると **エネルギー台帳は X:Y:Z = 1/3 : 1/2 : 1/6 = (2:3:1)/6（六分割・厳密）**。
- N=4 は別経路: 振幅比 ≈1.0097 だが位相差 78.476°（90°から −11.52°）。それでも
  **c₊ は N=3 と同一値 0.994936 = (√2+√3)/√10**（√: 5+2√6=(√2+√3)²）。
  結晶2種が異なる微視的変形（N=3=振幅路、N=4=位相路）で同じ円偏光純度に着地する。
- ガラス: 位相差 ≈89.1–89.5°、振幅比 ≈0.97–1.00、すべて凍結。N=5 のみ全量が揺れ続ける。

## 結論（木原の問いへの答え）

1. 三方向は初期条件で厳密に定義できる（X̂,Ŷ = 90°平面、Ẑ = 法線）。親の面内方向は
   円偏光固有方向 ê₊ に厳密一致し、**これが面内で保存される方向**（増幅期は c₊=1 を機械精度維持）。
2. 法線（面の向き）は増幅期・終盤で凍結。ただし「一番安定」には但し書きが要る——
   **遷移が一度だけ面を蹴り、結晶はマジック角 35.264° 傾いた向きで再凍結する**。
3. よって 3軸の安定読出しは可能: Ẑ=法線（遷移以外凍結）、面内は ê₊（連続保存 ≥99%）＋
   ロック後は実軸 X,Y もストロボ剛体（CP¹ドリフト機械0）。**例外は N=5**（枠が立たない）。
