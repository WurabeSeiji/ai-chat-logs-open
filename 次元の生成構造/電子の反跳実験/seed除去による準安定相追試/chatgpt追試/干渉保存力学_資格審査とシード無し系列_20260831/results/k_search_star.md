## 外接半径の照合（記録）

- N=5：衛星正四面体（辺 ρt/2）の外接半径/辺 = √(3/8) = 0.612372。ハブ外心一致条件 s/(ρt) = 0.612372 は無理数のため整数 (s,t) で厳密到達不可。s=3,t=1 は s/(ρt) = 0.763932 > 0.612372 で非縮退成立。
- N=12：衛星正 10 単体（11 点）の外接半径/辺 = √(10/22) = 0.674200。c/(ρd) ≥ 外接半径が必要 → d=1 で c ≥ 33.5661 → 最小整数 c=34（一様表と一致）。

注：N=5 の ρ は理論値 3/(3−√5)（実測 3 タグとの差 1.3〜4.0e-4、sideband_theory_check.csv）を使用。

結論：無理数の波長比のままでも、{k} の整数選択で実単体は成立する（埋め込みは開条件）。全整合解は k_search_star_solutions.csv に全数保存。
