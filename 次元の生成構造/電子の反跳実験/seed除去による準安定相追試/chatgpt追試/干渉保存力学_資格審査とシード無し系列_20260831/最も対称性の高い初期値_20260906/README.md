# 最も対称性の高い初期値（N=3〜40）v2——生成パッケージ（2026-09-06）

木原仕様（合意済み3項）: (1) 位相は 0°/90° のみ (2) 本数が等しくできない場合は族ごとに統一した
2値の振幅でパワーバランス n_A r_A² = n_B r_B²（=閉塞） (3) 全 N で合計パワー同一 P_tot=1。
⇒ 閉形式 r_A=√(1/2n_A)、r_B=√(1/2n_B)。割当は（巡回距離 d, i, j）辞書順で先頭 ⌈M/2⌉ 本を 0°族。
