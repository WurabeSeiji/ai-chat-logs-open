# 最も対称性の高い初期値（N=3〜40）——生成パッケージ（2026-09-06）

木原の依頼: N=3〜40 について、最も対称性の高い初期状態をどうセットするかを文書化し（M 個の複素数
a+ib の計算根拠と全一覧）、複素平面図を作り、生成データをそのまま新系の初期値として使えるようにする。

## 判定の根拠（現行データから）

- 現行の親は全 N で**厳密な 90° 二族**（検討28）。閉塞は振幅の不均衡（P_A=P_B）で達成。
- 族の割当は乱数的で正則でない（`../初期値の位相族と振幅_20260906/check_parent_family_graph_v1`）。
  それでも固定点なのは、固有関係 KZ=iσZ の和則 (Σ_f r_f sin²φ_ef)/r_e = σ を**振幅の調整**で
  満たしているから（全 N で CV≈10⁻¹⁴）。
- 木原要件「全て等振幅・相対位相差 90°」を課すと調整代が消える。等振幅の固定点条件は
  「各辺の隣接 2(N−2) 本のうち反対族がちょうど N−1 本」⇔ 0°族が (N−1)/2 正則 ⇔ **N≡1 mod 4**。

## 規則（`make_symmetric_parents_N3_N40_v1.py`）

| 規則 | N | 構成 | 閉塞 | 固定点 | D_N 対称 |
|---|---|---|---|---|---|
| **B** | 5,9,13,17,21,25,29,33,37 | 巡回距離 d≤(N−1)/4 → 0°、残り → 90° | 厳密 | **成立（残差 ≤7e-14）、σ=N−1 ちょうど** | 2N/2N（全） |
| **SC** | 4,8,…,40 | 自己補グラフ（P4 再帰）→ 0°、補 → 90° | 厳密 | 不成立（残差 0.5〜9） | 2（N=4,8）／1 |
| **T** | M 奇数（3,6,7,10,11,…,39） | 三角形{0,1,2}=(0°,60°,120°) ＋ 残り (d,i,j) 順に 0°/90° 交互 | 厳密 | 不成立（N=3 のみ成立、σ=3/2） | 1 |

全辺 r = 1/√M（‖Z‖=1 規約）。辺順はエンジン `run_n_scaling_lowrank_v1.build_edges(N)` と同一。

**注目**: 規則B の σ = N−1（4,8,12,…,36）は、実験9で測った結晶化後のロック値 σ_max→N−1 と一致。
N=3 の三つ組 σ=3/2 も N=3 のロック値 3/2 と一致。等振幅・90° の対称固定点は**結晶終状態と同じ σ** を持つ。
