# hm 系列 rank=3 幾何・独立監査（2026-08-31）

## 1. 目的

従来の `pass17_hm_series_k.py` は、同じ波長群へ同じ整数 `k` を与える群一様アンザッツを置き、中心化 Gram 行列が PSD であれば rank に関係なく「成立」としていた。そのため、`rank=N-1` が得られた既報は「何らかのユークリッド埋込みが存在する」ことの確認であり、「N>4 でも3次元幾何が自発的に選択される」という仮説の検定ではない。

本監査では数値入力を `data/hm_N*/states_treatment.npz` の生データだけに戻し、波長読出しと幾何判定を分離する。

## 2. 生データの扱い

生データは 0〜40000 step を持つが、支配波長の推定に全区間を一括使用しない。時間発展中に相転移・周波数分裂があるためである。再現性確認用として、終端 4096 / 8192 / 16384 step の3窓を同じ FFT + Hann 窓 + 8倍 zero padding + 1次元周波数精密化で読み出す。

本パッケージでは 4096 step を「最も相混合の少ない終端読出し」として baseline geometry audit に使用する。ただし、これは全 N に対する最終的な準定常区間判定規則ではない。今後は移動窓による安定性判定を追加し、N ごとに stable suffix をデータから決定する必要がある。

## 3. N=6 独立再計算

使用した raw source:

`data/hm_N6/states_treatment.npz`

`Z.shape = (40001, 15)` であり、N=6 の完全グラフ 15 辺に一致する。

終端4096 step で得た規格化波長は `results/validation_hm_N6_edge_wavelengths.csv` に全15辺を保存した。短波長群（約1）と長波長群（約7.4〜7.6）が明瞭に分離する。

## 4. 幾何判定

各辺長を

`L_ij = k_ij * lambda_ij / 2`

とし、距離二乗行列から中心化 Gram 行列

`B = -1/2 J D^2 J`

を作る。固有値を最大絶対値で規格化し、

- PSD: `min(eigenvalue)/scale >= -1e-9`
- numerical rank: `eigenvalue/scale > 1e-9`

で診断する。

本監査の物理的成功条件は、N>4 について **rank(B)=3** である。

## 5. N=6 baseline 結果

旧 pass17 と同じ 2% 波長群化・群一様 `k` アンザッツを、比較のためだけに再現した。ただし、最初の PSD 解で停止せず、rank=3 の有無を検査した。

結果:

- rank=3 PSD 解: **0**
- PSD 候補の中で最小 rank: **5**
- その候補: `k_group=(100,1)`
- 第4正固有値比 `mu4/mu1 ≈ 3.382593225e-3`

したがって、この baseline の探索範囲内では N=6 の3次元縮退は確認されない。

## 6. この結果が「否定」ではない理由

この 0 解は、辺ごとに独立な `k_ij` を探索した結果ではない。旧コード由来の「同じ波長群は同じ k」という制約を残した baseline に過ぎない。したがって、3次元創発仮説そのものを否定する結果ではない。

次の本試験では、少なくとも以下を満たす必要がある。

1. `k_ij` は各辺で独立な自然数とする。
2. `min(k_ij)=1` を基底規格化とする。
3. rank=3 を目的関数に「近づける」のではなく、PSD と rank=3 を同時に満たす整数解として判定する。
4. 同波長群・星群・衛星群へ同一 k を強制しない。
5. 解が得られた場合は3正固有値比を保存し、3軸異方性を測る。
6. Gram 分解から3次元座標を復元し、共通3軸楕円体表面への適合度を検査する。

## 7. 再現性上の結論

このフォルダ以降の rank=3 判定では、旧 `hm_series_k.csv` を入力に使用しない。旧 pass13〜17 は探索史として残すが、数値的な正本は生 NPZ から再計算した出力とする。

現時点で確定しているのは N=6 baseline のみであり、N=3〜16 全系列の rank=3 結論は未確定である。
