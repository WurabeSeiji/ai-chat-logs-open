# hm_N6 任意精度・底深さ独立監査（2026-08-31）

## 目的

hm_N6 を float64 保存値から昇格せず、1-factor/root-of-unity 定義から mpmath 任意精度で再生成し、

- `H_ef = A_ef conj(z_e) z_f`
- `z <- exp(-i delta H(z)) z`
- 初期 rank-2 実平面に対する `H_perp/H`

を全て同じ任意精度で評価した。1 macroscopic step `Delta=2pi/124` は `sub=1,2,4,8` に分割し、各 substep で H を再計算した。

## 読み

1. 有限の物理的な「底」は検出されない。精度を 30 -> 50 -> 80 decimal digits と上げると、線形 transverse amplitude `sqrt(Hperp/H)` は概ね 1e-30 -> 1e-50 -> 1e-80 へ下がる。
2. `Hperp/H` は二乗量なので概ね 1e-60 -> 1e-100 -> 1e-160 へ下がる。
3. tau 分割を 1 -> 8 に増やしても桁スケールは変わらず、O(1)-10 程度の係数差に留まる。有限の下限へ収束する兆候はない。
4. したがって exact arithmetic 極限では hm は相対平衡上に厳密に留まり、transverse floor は 0 へ落ちる。有限精度では、その精度が任意微小摂動を供給する。
5. これは「不安定性が偽物」という意味ではない。線形不安定固有値は力学に属する。ただし、発火 seed を物理と主張するには、数値丸め以外の物理的揺らぎの根拠が別途必要。

## 注意

保存済み float64 `parent_v.npz` を高精度演算へ単に変換するテストでは、初期 1e-16 級誤差を保持してしまうため、この底深さテストにはならない。必ず hm を定義から各精度で再生成する必要がある。
