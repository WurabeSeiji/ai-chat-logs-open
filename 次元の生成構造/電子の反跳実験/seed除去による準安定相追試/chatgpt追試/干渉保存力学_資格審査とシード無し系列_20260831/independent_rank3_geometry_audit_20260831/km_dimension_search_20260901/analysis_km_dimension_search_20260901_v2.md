# hm 実数距離 km 次元探索（独立再解析）2026-09-01

## 入力
- hm_N5 / hm_N6 の `states_treatment.npz` 生時系列のみ。
- 終端4096 step の複素位相を unwrap し、各辺の位相傾きから波長を推定。
- 全体スケールは無意味なので `min(lambda_m)=1` に規格化。
- 距離は `L_m = k_m lambda_m / 2`, `k_m` は辺ごとに独立な自然数。
- `gcd(k_1,...,k_M)=1` の primitive 解に規格化。
- 以前の条件を維持し target dimension d>=3。

## 判定
距離二乗行列 D2 から `B=-1/2 J D2 J` を作り、B が PSD かつ rank(B)=d のとき d 次元ユークリッド実現。

## 固定 lambda（終端4096 step）での第1段探索
- N=5, d=3: exact 0。最良は rank=3 だが PSD 違反。相対距離 RMS 2.78e-4、最小固有値/最大固有値=-1.08e-4。
- N=5, d=4: exact 37。最小の単純解は k=(1,...,1)、rank=4。ほぼ正4単体。
- N=6, d=3: exact 0。最良は rank=4/PSD違反。
- N=6, d=4: exact 0。最良 PSD だが rank=5、相対距離 RMS 1.61e-3、5番目固有値/最大=1.03e-3。
- N=6, d=5: exact 15。単純な解の一つは kmax=7、k=[1,1,1,5,1,1,1,7,1,1,6,1,6,1,6]。

## 波長の時間変動
終盤8192 step を4つの2048-step窓で測定。
- N=5: 辺別規格化 lambda の peak-to-peak/mean は中央値2.87e-4、最大5.25e-4。
- N=6: 同値は中央値0.247、最大0.554。N=6 は終盤でも波長が大きく動いており、単一の「最終 lambda」で次元を確定するのは不適切。

## 誤差区間を独立に許した探索（参考・非物理的な上限テスト）
- N=6 d=4 は、各辺 lambda を各辺の観測レンジ内で独立に動かすと RMS 2.49e-14 まで落ち、rank=4 を構成可能。
- N=5 d=3 も interval-aware 探索で RMS 1.60e-12 の候補を発見：
  k=[103,91,104,115,58,57,45,52,38,33]
  lambda=[1.00000176,1.00000978,1.00000507,1.00024337,1.00014682,1.00001415,1.00001151,1.00014716,1.00001126,1.00013092]

### 重要な限定
この interval fit は各辺 lambda を独立にレンジ内で選んでおり、同じ観測窓・同じ時刻で同時に現れた lambda ベクトルとは限らない。従って「N=5 に物理的3次元解がある」とはまだ言えない。

## 現時点の結論
1. 固定された終端4096-step波長ベクトルだけなら、N=5 は d=4、N=6 は d=5 の実現が容易で、低次元解は未発見。
2. しかし低次元候補のずれは N=5 の波長時間変動と同程度で、N=6 は波長自体が非定常。このため「次元=N-1」と確定するのも早い。
3. 次の正しい検証は、同一時間窓ごとに lambda_m(t) を一括で取得し、その各スナップショットに対して d=3..N-1 の整数 km 探索を行う「時間分解 d(t)」である。辺ごとの誤差を独立に混ぜてはいけない。

## 同一時間窓ごとの時間分解探索（2048-step窓、軽量第1段探索）
各窓内の lambda ベクトルをそのまま一括使用し、辺ごとの誤差混合はしない。探索強度は N=5 各 d 10 restart、N=6 各 d 8 restart の軽量スクリーニング。

### N=5
end=33856,35904,37952,40000 の全4窓で d=3 exact は 0、d=4 exact は各窓で複数発見（6,5,2,5）。
従って、少なくともこの軽量探索では N=5 は各同時刻波長ベクトルに対して d=4 が安定して見つかり、d=3 は未発見。

### N=6
end=33856: d=5 exact 5、d=3/4 exact 0。
end=35904: d=5 exact 3、d=3/4 exact 0。
end=37952: この軽量探索では d=3/4/5 exact 0（波長が強く非定常で探索難度が高い）。
end=40000: d=5 exact 1、d=3/4 exact 0。
従って N=6 でも、解が見つかる窓では d=5 が優勢。d=4 の区間独立候補は作れたが、同一時間窓ではまだ exact を発見していない。

### 暫定的読み
- N=5 は d=N-1=4 がかなり頑健。
- N=6 は d=N-1=5 が現時点で最も自然に見える。
- したがって「3次元へ自発固定」は hm_N5/N6 の波長×整数距離読みでは支持されていない。
- ただしこれは有限 kmax=100・有限 restart の存在探索であり、低次元解不存在の証明ではない。
