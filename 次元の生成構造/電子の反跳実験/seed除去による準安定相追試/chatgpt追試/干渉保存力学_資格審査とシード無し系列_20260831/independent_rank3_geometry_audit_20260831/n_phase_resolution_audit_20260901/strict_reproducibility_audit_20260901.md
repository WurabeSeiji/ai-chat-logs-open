# 厳密再現性監査 2026-09-01

対象: `干渉保存力学_資格審査とシード無し系列_20260831`

## 1. 正本と最新コードの構造差

正本 `program/pass2_run.py`:
- `parent_v.npz` を直接ロード。
- `original_engine.LowRankSystem(N)` を使用。
- `LowRankSystem` の辺順序は `np.triu_indices(n,k=1)`。
- adjacency を `s.ea,s.eb` から構築。
- `H=A*(conj(z)[:,None]*z[None,:])`。
- Hermitian 検査後 `np.linalg.eigh(H)`。
- `Z_next = V @ (exp(-i*(2*pi/L)*w)*(V^H@Z))`。
- `p,q` を parent `v` から構築。
- 元系列は L=124, 40000 steps。

最新 `run_den124_recheck_500.py` / `run_denominator_controls_Npm2_500.py`:
- 元の保存済み `states_treatment.npz` の `Z[0]` を入力に使用。
- `LowRankSystem` を呼ばず `np.triu_indices` から辺を再構築。
- adjacency, H, `eigh`, exponential update は数式・演算順序とも正本と同型。
- Hermitian チェック等の診断列を省略。
- 500 steps。

N=6について `parent_v.npz` と元 `states_treatment.npz['Z'][0]` は `np.array_equal=True`, max diff=0。

## 2. 正本コードを最小変更した対照の検証

過去の `pass2c_run_L12400.py` と `pass2d_run_L124000000.py` は、正本 `pass2_run.py` のコピーであり、実質変更は `STEPS`、`L`、出力名/key_steps のみ。相互作用・初期値ロード・LowRankSystem・Hermitian検査・eigh・観測法は保持されている。

これに対し今回の deltaN/N±2 系はコードを再実装したため、実験管理上は正本の「一行変更」ではなかった。ただし N=6, L=6 について正本 `pass2_run.py` をそのまま複製し `STEPS=500, L=6` のみ変更した厳密版を実行したところ、既存 `deltaN_only_clean` N=6 と全 501 状態が bitwise 完全一致した (`np.array_equal=True`, 各 step max diff=0)。したがって N=6 の deltaN 力学結果自体は再実装差で生じたものではない。

## 3. 重大点: 同じ正本コードでも保存済み元軌道を bitwise 再現しない

N=6, L=124 について、現在環境で正本 `pass2_run.py` をそのまま用い、`STEPS=500` のみ変更して再実行した。

元保存軌道 vs 現在環境・正本コード再実行の state max absolute difference:
- step 0: 0
- step 1: 5.974731160962075e-16
- step 100: 8.939062221096038e-15
- step 500: 4.863333076119646e-14

この現在環境・正本コード再実行は、最新 `denominator124_recheck` N=6 と bitwise 完全一致した。従って最新再実装の差ではなく、元データ生成時と現在環境の数値線形代数差が step 1 から seed を変えている。

## 5. 結論

1. 最新 N±2 の力学式は正本と数式上同一で、N=6 deltaN について正本最小変更版と bitwise 一致した。
2. しかし、元の L=124 保存軌道は、同一 parent と同一正本コードを現在環境で再実行しても step1 から ~1e-16 の state 差が入る。
3. この差は 30000 step 付近で O(1) の軌道差に増幅される。系は数値線形代数が生成する machine-level perturbation に本当に敏感。
4. よって「コードが同じ」だけでは trajectory-level 再現性はない。元実験時の NumPy/LAPACK/BLAS/CPU/threads を凍結していないことが再現性の最大の欠陥。
5. 一方、最終 Hperp/H は元 0.711、現在再実行 0.727 と近く、少なくとも N=6 では macro attractor の一部は比較的頑健に見える。
6. 10^-30付近以下の floor と最初の1-step jump は物理量として扱わず、数値床として分離すべき。
