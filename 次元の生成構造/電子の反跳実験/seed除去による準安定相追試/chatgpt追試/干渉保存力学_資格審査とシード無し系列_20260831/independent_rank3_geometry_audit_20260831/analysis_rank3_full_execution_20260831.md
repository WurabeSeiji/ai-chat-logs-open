# 独立 rank=3 幾何監査 実行結果（2026-08-31）

## 入力
Google Drive の `data/hm_N3` 〜 `data/hm_N16` にある各 `states_treatment.npz` 生データのみを使用した。旧 `hm_series_k.csv` の k 値は入力に使用していない。

## 読出し
各系列について終端から 8192/4096/2048/1024 step の隣接窓を比較し、辺別位相周波数の相対変化の median<=2%, p90<=5% を満たす最長候補を優先し、満たさない場合は最小変動窓を fallback とした。各辺の規格化波長は `lambda = max(nu)/nu`。

## k 探索
各辺 k_ij は独立整数。`1 <= k_ij <= 100`、かつ `min k_ij = 1` を要求する。長さは `L_ij = k_ij lambda_ij / 2`。3次元座標 X と整数 k を交互に更新し、最終的に整数長さ行列そのものから中心化 Gram 行列 B を構成して rank と PSD を独立判定した。

成功条件は N>=4 で `rank(B)=3`, `B>=0`, 3D座標残差 rms<1e-7, max<1e-6。N=3 は最大 rank=2 を成功条件とする。

## 実行結果
- N=3: rank=2, PASS（期待どおり）
- N=4: rank=3, PASS
- N=5: 候補 rank=3 だが負固有値比 3.14e-3、距離 rms 3.04e-3。PSDでないため FAIL。
- N=6: rank=4, FAIL
- N=7: rank=5, FAIL
- N=8: rank=5, FAIL
- N=9: rank=6, FAIL
- N=10: rank=5, FAIL
- N=11: rank=6, FAIL
- N=12: rank=7, FAIL
- N=13: rank=7, FAIL
- N=14: rank=8, FAIL
- N=15: 縮小探索で rank=9, FAIL
- N=16: 縮小探索で rank=8, FAIL

N=3〜13 は starts=8, max_outer=12。N=14 は 4+4 restarts を2バッチ（seed 20260831, 20270831）で実行。N=15,16 は実行時間上限のため max_outer=4 の縮小探索を完了し、未発見は「不存在証明」ではない。

## 結論
現時点の独立辺 k 探索では、N>4 に対して厳密な 3次元ユークリッド実現は発見できていない。したがって旧報告の `rank=N-1` 成立を 3次元創発の証拠として扱うことはできない。

ただしこれは有限探索の非発見であり、数学的な不存在証明ではない。特に N=5 は rank=3 に非常に近いが、整数化後の距離行列が PSD 条件を破っているため現候補は不成立。

## 次の検証
1. kmax を拡大した探索。
2. 波長測定誤差を区間として持つ区間制約探索。
3. 3D距離幾何の Cayley-Menger / EDM rank 条件を直接使う整数枝刈り。
4. 時間窓ごとの lambda で同じ k パターンが安定するか検査。
5. rank=3 解が得られた場合のみ、3固有値比と楕円体表面適合を検査。
