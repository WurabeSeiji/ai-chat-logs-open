# hm 系列：λそのものを辺長とした実ユークリッド幾何監査（2026-09-01）

## 目的
整数巻き数 k_m を完全に外し、各辺の実測支配波長をそのまま実距離として読む。

- 辺長: L_ij = λ_ij ∝ 1/|ν_ij|
- 全体スケールは無意味なので各時間窓で min λ = 1 に規格化
- 4096-step 同一時間窓ごとに全辺の支配線を読み出す
- 距離二乗行列 D^2 から中心化 Gram B = -1/2 J D^2 J を構成
- B PSD なら実ユークリッド点配置が存在
- rank(B) が最小埋め込み次元
- 主軸長は正固有値 μ_i の sqrt(μ_i)
- 異方性は最大/最小主軸長比、および重心から頂点までの半径 CV で読む

## 結果の要点

### 1. インフレーション前
N=3..16 の全 hm 系列で λ_ij は全辺等しい（測定精度内）。
したがって、N 頂点は正 (N-1) 単体を作る。

- rank = N-1
- 主軸固有値は全て縮退
- axis ratio = 1
- 全頂点の重心距離は同一
- 従って preferred axis は存在しない（縮退しているので軸方向自体が一意でない）

### 2. N=3,4,5
終端 35905..40000 でも λ は全辺等しく、実ユークリッド配置は維持。
- N=3: rank 2 正三角形
- N=4: rank 3 正四面体
- N=5: rank 4 正4単体
異方性は検出されない。

### 3. N>=6 のインフレーション後
終端 35905..40000 では λ 比が大きく分裂する。

N=6: λmax/λmin=7.58
N=7: 12.07
N=8: 17.55
N=9: 24.09
N=10: 31.64
N=11: 40.23
N=12: 49.84
N=13: 60.40
N=14: 72.22
N=15: 84.79
N=16: 98.62

しかし、この λ をそのまま辺長とすると、全て N>=6 で三角不等式を破り、Gram 行列も強く非PSDとなる。
終端の負固有値比 |μ_min|/μ_max は N=6 の 0.610 から N=16 の 0.874 まであり、測定誤差では説明できない。
したがって、インフレーション後の λ 集合は「異方的な実ユークリッド単体」ではなく、そもそも通常の実ユークリッド距離集合ではない。

### 4. 異方性・重心・軸方向
実ユークリッド配置として成立している安定窓では、ほぼ常に λ は等長で axis ratio=1、重心半径 CV≈0。
つまり、実数 λ だけからは安定した異方的楕円体/優越軸は確認できない。

遷移中の一部窓では axis ratio > 1 の一時的な値が出るが、同じ窓で周波数の前半/後半差が大きく、定常な波長としての解釈ができない。安定した異方的実ユークリッド幾何の証拠とはしない。

## 結論
λ をそのまま辺長とする最も単純な読みでは：

1. インフレーション前は正 (N-1) 単体（完全等方）。
2. N=3..5 はそのまま維持。
3. N>=6 では λ 分裂後、実ユークリッド simplex の異方化ではなく、距離整合性そのものが破れる。
4. よって「λそのもの」が3次元/楕円体の幾何を直接与える、という読みは現データでは支持されない。

これは重要な負の結果であり、k_m 案を保留した状態では、λ は「距離」そのものではなく、別の写像を介して幾何へ読まれる量である可能性を示す。
