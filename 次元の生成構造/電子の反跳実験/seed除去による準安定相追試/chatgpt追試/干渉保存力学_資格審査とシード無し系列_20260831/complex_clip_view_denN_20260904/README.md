# den=N・step2000 状態の複素平面クリップ図（抑圧max 正規化、2026-09-04）

## 目的

分母コントロール実験（`../ChatGPT_denominator_controls_N3_N33_legacyparent_20260903/results_2000steps`）
の den=N ケース（N=3..33）について、step2000 の状態は凝縮成分（振幅 ≈ 0.495 の N−1 成分）が
振幅スケールを桁で支配しており、通常表示では抑圧背景の構造が見えない。

そこで**全成分（複素数）を各ケースの抑圧max で正規化して複素平面に打点し、
表示範囲を実部・虚部とも ±1（= ±抑圧max）に固定**する。範囲を超える凝縮成分は
視野外にトリムされ、抑圧背景の内部構造（振幅と位相の分布）だけが見える。

## 定義

- 生存（凝縮）成分: |Z| ≥ 0.1 × |Z|max。抑圧成分: それ未満。
- 抑圧max: 抑圧成分の最大振幅（ケースごと）。
- 赤破線: |z| = 抑圧max（半径1）の参照円。
- N=3 (den=3) は抑圧成分が存在しない（凝縮なし）ため正規化不能、パネルに注記。

## 観察（図の読み）

1. **N=4〜13（深抑圧域）**: 背景のほぼ全成分が原点に潰れ、単位円近傍に数点だけ残る。
   この帯の抑圧max は倍精度イプシロン床（≈0.5ε）にあり、見えている数点の配置は
   丸め雑音の可能性を含む（底は精度であって物理ではない）。
2. **N=14〜20（遷移域）**: 背景構造が離陸し、非等方なクラスタ状の雲が出現する
   （例: N=14 の上下二群、N=15 の上半平面偏在、N=19 の中心集中＋上方偏り）。
3. **N=21〜33（浅抑圧域）**: 中心集中の稠密な雲。ただし等方ではなく、
   N=26 は対角方向、N=29・N=31 は虚軸方向に伸びるなど、ケースごとに
   明確な異方性（位相の組織化）が残る。凝縮が未完了で背景に構造が生きている。
4. 単位円（=抑圧max）上に張り付く成分は各 N とも少数で、背景の大部分は
   それより十分内側にある。
