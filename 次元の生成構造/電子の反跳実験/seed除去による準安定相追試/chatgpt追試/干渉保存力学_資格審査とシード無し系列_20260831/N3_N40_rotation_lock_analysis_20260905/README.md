# 回転数ロック全系列調査（N=3..40、den=N 系列、読み出しのみ）

作成日: 2026-09-05

## 目的

N=3 ストロボ実験（`../N3_den3_stroboscope_40frames_20260905/`）で確定した
「増幅期＝回転数 √2−1 の相対平衡 → 飽和後＝有理数 1/2 への回転数ロック」が
全系列（N=3..40、den=N の38走行）で成り立つかを、既存データの読み出しだけで判定する。
事前予想（木原）: 奇数系列は N=3 とほぼ同じパターン。

## 入力と再現性ゲート

- 入力はコピーせず正本パッケージ `../N3_N40_stage123_sweep_20260905/` を相対パス参照。
  実行時に全38 npz の SHA256 を正本 SHA256SUMS.txt と照合（**入力ゲート 38/38 合格**）。
- エンジン（edges/adjacency/H_of/one_step）は run_N3_N40_stage123_v1.py からの逐語コピー。
  対照テストとして全38系で Z[0] から10歩再ステップし保存 Z[1..10] との bit 一致を要求
  （**対照テスト 38/38 合格**。不一致なら即 abort する設計）。
- onset（H⊥/H>0.05 交差 step）と H⊥/H 時系列は正本 CSV から引用（再実装しない）。

## 測定の定義

- 剛体回転テスト: r(s) = min_φ ‖Z[s+N] − e^{iφ}Z[s]‖/‖Z[s]‖、φ = arg⟨Z[s], Z[s+N]⟩。
  s+N ずらしは Δτ=2π/N の時計1回転に相当。回転数 x = φ/2π（単位: 回転/時計1回転）。
- スペクトル同定: 初期生成子 H = i·K（Z[0] から構成）の固有対。時計1回転でモード k は
  位相 e^{−i2πw_k} を得るので予測回転数は (−w_k) mod 1。
- 有理ロック判定: x_late の最良有理近似 p/q（q≤48）、残差 < 10⁻⁹ 回転でロック認定。
  認定 q で厳密周期テスト ‖Z[s+qN] − Z[s]‖/‖Z[s]‖。
- 等振幅偏差: 終状態 |z| の ‖Z‖/√M からの最大相対偏差（M=N(N−1)/2）。
- プレートー: H⊥/H の onset+50..500 平均と最良有理近似（q≤200）。

## 結果（rotation_lock_table_v1.csv / rotation_lock_analysis_v1.json）

1. **全38系で親は初期生成子の固有状態（占有率 1.0）**。したがって増幅期は厳密な
   相対平衡で、実測回転数 x_early と予測 (−w_dom) mod 1 の円距離は全系で ≤ 3×10⁻¹⁴。
   N=3 の √2−1 はこの一般則の N=3 での値である。
2. **w_dom の代数値**: |w_dom(3)| = √2、|w_dom(4)| = √8 = 2√2、|w_dom(5)| = √14
   （いずれも偏差 10⁻¹⁵〜10⁻¹⁶）。N≥6 は √整数でない（w²(6) = 23.70046…）。
   |w_dom| は論文の σ_max(N) ≈ N−1.1 に一致する系列。
3. **ロック先は奇偶で分かれない**: N=4 と N=6..19 は奇偶によらず **1/1（ストロボ固定点、
   時計1回転で正味回転ゼロ）** にロック（残差 10⁻¹⁶〜10⁻¹¹）。N=20,21 も 10⁻⁹ 級まで接近。
   N≥22 は同じく 1/1 へ向かうが step 500 時点で未収束（残差が整定時間 500−onset と
   きれいに逆相関）。N=32,39,40 は onset が遅く飽和後窓が不足（判定不能）。
4. **N=3 は例外**（唯一の 1/2 ロック＝符号反転周期2、機械精度）。
   **N=5 は別種の異常**: ロック未達（残差 4×10⁻⁴）、終状態が非等振幅（相対偏差 6×10⁻²）、
   プレートー 0.3666（他系と桁違いに高い）。
5. **プレートーの有理ロックは N=3 と N=4 のみ確定**: どちらも **1/6**
   （残差 3.8×10⁻¹³ / 6.1×10⁻¹²）。N≥5 は最良有理の残差が 10⁻⁵ 級で未収束・未判定。
6. 等振幅偏差も整定時間と相関し、深く整定した系ほど 1/√M へ深く収束
   （N=3: 4×10⁻¹⁶、N=10: 3×10⁻¹⁴、N=40: 3×10⁻²）。

事前予想の判定: 「奇数系列は N=3 型」は**不成立**。N=3 の 1/2 ロックは奇数系列の
テンプレートではなく例外で、奇数 N=7..21 も偶数と同じ 1/1 に向かう。
偶奇ではなく「N=3 と N=5 だけが特別」という構図。
