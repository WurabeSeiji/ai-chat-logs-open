# 高対称理論床・奇数N系のゼロ閉塞因数分解監査

日付: 2026-09-08

## 目的

高対称理論床の奇数 `N=3,5,...,39` について、全波 `M=N(N-1)/2` のうち二波自己閉塞

`z_i^2 + z_j^2 = 0`  （同値に `z_j/z_i = ±i`）

を作る波が大部分を占めるのか、それとも二波pairはほぼ存在せず、3波・4波・5波以上のゼロ閉塞凝縮体が主体になるのかを判定する。

## 対象と方法

高対称理論床を保存近似値からではなく、定義

`z_ij = r_d exp(i 2π(i+j)/N)`

と距離クラス縮約Hermitian固有値問題から毎回再構成した。

各奇数Nで以下を実行した。

1. 全 unordered pair を総当たりし、相対二波閉塞残差が `1e-10` 未満のpairを列挙。
2. pair graph の最大matchingから、二波pairで覆える波の最大比率を測定。
3. 全3波組合せをハッシュ探索し、厳密3波閉塞の存在を監査。
4. 全4波組合せを meet-in-the-middle で探索し、厳密4波閉塞の存在を監査。
5. 高対称床の距離クラス内では振幅が等しく、奇数Nでは `gcd(4,N)=1` なので、`z^2` 位相が各距離クラスでN個のN乗根を一巡することを利用し、Nの最小素因子 `p` ごとの正p角形へ構成的に完全分解。
6. 全ブロックの閉塞残差、被覆率、余り波数を独立検証。

## 主結果

### 1. 奇数Nでは二波自己閉塞pairが完全にゼロ

`N=3,5,...,39` の全19系列で、厳密二波pair候補は **0組**だった。

したがって最大matchingも常に0で、

`2-wave pair coverage = 0%`

である。つまり「大部分が光子型pairで、一部だけ余る」という像は奇数高対称床では成立しない。**全波が二波pairになっていない。**

### 2. それでも全体系は100%ゼロ閉塞ブロックへ因数分解できる

奇数Nでは各距離クラスの `z^2` がN乗根を一巡するため、各距離クラス単独で

`Σ z_e^2 = 0`

を満たす。

さらに `p = smallest_prime_factor(N)` とすると、各距離クラスのN波を、重複なしの正p角形閉塞へ分解できる。

全Nで

- 構成的因数分解被覆率 = **100%**
- 因数分解後の余り波 = **0**
- 最大ブロック閉塞相対残差 = `1.2e-15` 以下

だった。

### 3. 最小凝縮体サイズはNの最小素因子に従う

| Nの型 | 最小ブロック | 例 |
|---|---:|---|
| `3 | N` | 3波 | N=3,9,15,21,27,33,39 |
| `3 ∤ N, 5 | N` | 5波 | N=5,25,35 |
| その他の合成奇数 | 最小素因子p波 | N=7×5=35ではp=5 |
| 奇素数N | N波 | N=7,11,13,17,19,23,29,31,37 |

特に、奇素数Nでは距離クラス内のN波がそれ以上小さい正多角形閉塞へ分解されないため、最小構成はN波そのものになる。

### 4. 3波・4波・5波の挙動

3波閉塞は全実波を対象とする探索で、**ちょうど `3|N` の系列だけ**に現れた。

4波閉塞は `N=3..39` の全奇数系列で **0件**だった。

5波閉塞は、距離クラス内の巡回根構造から **`5|N` なら必ず存在**する。したがって N=5,15,25,35 には5波閉塞が存在する。ただし N=15 では3波閉塞の方がさらに小さいため、原始的最小因子は3波である。

## 偶数系との対比

直前の偶数系監査では、`N=8k` で全波を `z_j=±i z_i` の二波閉塞pairへ完全分解できた。

今回の奇数系では対照的に、

- 二波pair候補 = 0
- 二波被覆率 = 0%
- 全波がp波以上の閉塞ブロックを構成

となった。

したがって高対称床の閉塞因数分解には明瞭な偶奇差がある。

`偶数の特定系列 -> 2波閉塞が基本単位になり得る`

`奇数系列 -> 2波閉塞は存在せず、最小素因子pに対応するp波閉塞が基本単位`

という構造である。

## 凝縮体としての読み

今回の結果だけから粒子種を同定することはしない。しかし数学的には、奇数高対称床は「pairの海＋余り」ではなく、**最初から多波ゼロ閉塞凝縮体の完全な海**になっている。

特に `3|N` 系では全波が三波閉塞へ分解できるため、N=3で現れた三波最小閉塞が大Nでも多数コピーとして埋め込まれていると読める。

一方、奇素数Nでは各距離クラスのN波全体が最小閉塞単位となるため、凝縮体サイズがNとともに成長する。
