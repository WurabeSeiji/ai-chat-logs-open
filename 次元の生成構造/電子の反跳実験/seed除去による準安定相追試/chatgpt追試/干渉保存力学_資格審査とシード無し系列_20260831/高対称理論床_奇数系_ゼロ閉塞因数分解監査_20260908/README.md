# 高対称理論床・奇数Nゼロ閉塞因数分解監査

対象: `N=3,5,...,39`。

目的は、二波 `±i` 自己閉塞pairが奇数系でどれだけの波を覆うか、およびpairに入らない波が3/4/5/...波のゼロ閉塞凝縮体へ因数分解できるかを判定すること。

## 実行

```bash
bash run_all.sh
```

`analyze_highsym_odd_closure_factorization_v1.py` は高対称床を定義式から再構成し、全pair、全3波、全4波を監査した上で、各距離クラスのN乗根構造をNの最小素因子pの正p角形へ構成的に完全分解する。

`verify_results_v1.py` は、二波pair全0件、3波閉塞 iff `3|N`、4波閉塞全0件、p波因数分解100%被覆、余り0、閉塞残差を検証する。

主結果: 奇数Nでは二波pair被覆率は全系列0%。全波は `p=smallest_prime_factor(N)` 波の閉塞ブロックへ100%分解可能。
