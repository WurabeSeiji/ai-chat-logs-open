# 位相ピッチ・占有数・振幅保護の全系列調査（N=3..40、den=N、読み出しのみ）

作成日: 2026-09-05

## 検証した仮説（木原 2026-09-05）

- (H-a) 終状態の位相は pitch=180°/N の格子にロックする（N=3 の 60° の一般形）。
- (H-b) 1位置あたり (N−1)/2 本。偶数 N は整数で割れないため、偶数系は格子オフセットが
  1/2 ピッチずつ旋回するのではないか。
- (H-c) 初期は 90° 格子。増幅中は占有数・振幅分布とも凍結か。
- (H-d) 遷移で振幅は保護されるか（波1本ごと／初期位置グループごと）。

## 入力とゲート

正本スイープ `../N3_N40_stage123_sweep_20260905/`（全 npz を SHA256 台帳照合）、
N=5 は `../N5_den5_long10000_20260905/`（同様に照合）。新規走行なし。

## 結果

### 初期状態（H-c）— 確認

- 全38系で step0 は **90° ピッチ格子に機械精度（偏差 10⁻¹¹〜10⁻¹⁴ 度）で載る**。
  位置は4つ（N=3,4,5 のみ3つ）。占有数はほぼ M/4 だが不均等
  （例 N=7: 7|6|4|4、N=40: 200|194|193|193）。
- 振幅は位置内でも不均一（N=3: {1/2,1/2,1/√2}、N=4: {1/(2√2)×4, 1/2, 1/2}）。
- **増幅の全期間、占有数は全38系で不変**（クラスタ数・占有多重集合が onset×0.6 時点で
  step0 と一致）。振幅分布も凍結。

### 終状態の格子（H-a）— 180/N は棄却、凍結2系は「60° 格子の N サイト鎖」

- step500 時点で内部運動が機械精度まで死んでいるのは N=3（剛体残差 10⁻¹⁵）と
  N=4（10⁻⁹）だけ。この2系の終状態は:
  - N=3: ギャップ {60°,60°,240°}、占有 1|1|1、全振幅 1/√3 — 60°格子の3連続サイト。
  - N=4: ギャップ {60°,60°,60°,180°}、占有 1|2|2|1、全振幅 1/√6 —
    **ピッチは 180/4=45° ではなく 60°**。60°格子の4連続サイト鎖。
- したがって (H-a) の 180/N 形は N=4 で棄却。凍結した系はどちらも同じ 60°
  （Z₆ の結晶学的角度）を使う。(H-b) の均等占有 (N−1)/2 も N=4 の 1|2|2|1 で棄却。
- N≥5 は step500 で剛体残差 10⁻³〜10⁻² の内部運動が残っており、位置はまだ終幾何で
  ない（π/N 格子への偏差は半ピッチ近くまで飽和＝格子性なし）。
- 格子オフセットのドリフト: 整定済み系では |Δu| ≈ 0（偶奇とも）。**1/2 ピッチ旋回は
  観測されない**（ただし前提の格子ロック自体が N≥5 で不成立のため、この検定が意味を
  持つのは凍結系のみ）。

### N=5 の終状態幾何（長時間走行の読み出し）

step500 の7クラスタ（ギャップ 65°/24°/66°/91°/24°/66°/26°）から、step10000 では
**4クラスタ・ギャップ {92°, 89°, 86°, 93°}（≈90°±4°）・占有 4|3|2|1・非等振幅
[0.304, 0.330]** に粗大化。N=5 は 60° 鎖にも 36° 格子にも向かわず、初期と同じ
「4位置・約90°」の構造へ冪則で漂っている。

### 遷移期の振幅保護（H-d）— 保護されない。厳密等分配へ再分配

- N=3: 初期グループエネルギー {1/2, 1/4, 1/4} → {1/3, 1/3, 1/3}。
- N=4: {1/4, 1/2, 1/4} → {1/6, 2/3, 1/6}（4本パックが増える側）。
- どちらも波1本あたりエネルギーは厳密に 1/M へ等分配（等振幅 1/√M と同値）。
  振幅は波単位でもグループ単位でも保護されず、遷移の6〜7 step で再分配される。

## 軸構造（方向 = 位相 mod 180°）の検定 — check_axis_structure_v1.py

木原仮説「90°ピッチの2次元（2軸）構造 → 60°ピッチの3次元（3軸）構造への移行では
ないか」を、各波の軸角 arg(z²)/2 のクラスタで機械検定した結果:

- **step0 は全38系で厳密に「2軸・90°」**（軸間隔の90°偏差 10⁻¹²〜10⁻¹⁵ 度）。
  初期構造は普遍的に2方向である。
- **凍結2系の終状態は厳密に「3軸・60°・軸あたり波数 M/3 の等分配」**:
  N=3 = 軸 {20.51°, 80.51°, 140.51°}×各1本（偏差 0.00°）、
  N=4 = 軸 {29.26°, 89.26°, 149.26°}×各2本（偏差 0.00°）。
  すなわち移行は文字どおり 2軸(90°) → 3軸(60°)＋軸等分配 である。
- 3軸等分配には 3|M が必要（M=N(N−1)/2。N≡2 mod 3 のとき M≡1 mod 3 で不成立）。
  **N=5（M=10）はその最小例**であり、10000歩の終状態は「約90°離れた2本の太い軸
  （各5本ずつ＝2軸等分配）が、それぞれ約6°の2+3に微細分裂した」構造。3軸に入れず
  2軸型へ冪則で戻っている——周辺性（非双曲性）の構造的対応物とみられる。
- N≥5 の step500 の軸は散乱したまま（60°偏差 18〜28°）。回転数ロック（速い）と
  幾何の結晶化（遅い）は別の時間スケールである。
- 反証可能な予言: N≡2 mod 3（N=8, 11, 14, …）は長時間でも3軸等分配に入れないはず。
  N=6, 7（3|M）との長時間比較で判定できる（要・新規長時間走行）。

## 等角射影読みとパリティ構造検定 — check_parity_class_v1.py（検討7）

幾何学的読み（木原 2026-09-05、台帳・検討7）:
- 初期2軸90° = A面＋その虚数方向のB面。閉塞は Σ_A a² = Σ_B b² の符号相殺
  （(1,1)符号ペア＝時間的相殺）。
- **終状態の3軸60°は、ℝ³ の直交3枠を体対角 (1,1,1) 方向から射影した等角射影の影と
  厳密に同型**（直交3軸の影は120°間隔＝軸60°）。閉塞機構は 1+ω+ω²=0 の三重対称相殺
  （空間シンプレックス相殺）へ乗り換わる。mod 3 選択則は「M 本を3直交方向へ等分できるか」
  という3次元等方性条件になる。
- 「+1」は軸でなく S¹（全体位相）の巻数。log 読出しの必要性は、凝縮体内部の振幅が
  1/√M に固定され（空間座標ゼロ）、空間尺度が凝縮体間の乗法比からしか読めないこと
  （log の一意性、DOI 22282218 付録A）と、(log f, 巻数) 平面でインフレーションが
  等速直線運動になる（0.68回転/桁）ことに対応する。

この読みの検定: 等角射影の符号構造が正しければ、結晶化した終状態の二乗の6方向占有は
**単一パリティ類**（占有方向が相互120°）に落ちるはず。全 N の step0/step500
（＋N=5 の step10000）で純度 purity = |n_even − n_odd|/M を測定した結果:

- **N=3: purity = 1.0、格子誤差 E/ρ = 0.0**（占有 [0,1,0,1,0,1] 型・単一類）
- **N=4: purity = 1.0、E/ρ = 0.0**（[0,2,0,2,0,2]・単一類）
- **N=5: purity = 0.0**（step500/step10000 とも。10000歩で [0,0,5,0,0,5] =
  1偶+1奇の完全均衡＝2軸型）——3次元枠を張れない系の反対側の型
- N≥6 は step500 で E/ρ = 3.5〜180 と格子割り当て自体が信頼できず（溶融）、
  **判定保留**。全系の判定は 10,000歩スイープ（実験5）完了後に同じプログラムで行う。

判定: 検定可能な全ケース（結晶化2系＋N=5）で等角射影読みの符号構造予言と一致。

## 開かれた問い（この読み出しから）

- 凍結2系（N=3,4）の「60°格子 N サイト鎖」は N=6 で一周（6×60°=360°）する。

  90°型4位置へ冪則で向かうことと、鎖の閉じ（N=6）の直前という位置は符合する。
