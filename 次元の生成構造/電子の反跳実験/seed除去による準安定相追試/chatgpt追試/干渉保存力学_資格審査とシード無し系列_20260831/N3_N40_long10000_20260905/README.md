# 全系列 10,000 歩スイープ（N=3..40、den=N、全状態保存）

作成日: 2026-09-05（走行完了・分析 2026-09-06）

## 目的と設計

500歩の正本スイープでは N≥5 の幾何が溶融のままだったため、木原指示により全38系を
10,000歩・Δτ=2π/N・全状態保存で走行（判定規則は力学に入れない）。判定対象:
mod 3 選択則（3|M の系だけが3軸等分配に入れるか）、終状態の因数分解型、結晶化時間。

- `run_N3_N40_steps10000_v1.py` は正本 run_N3_N40_stage123_v1.py の忠実コピーからの
  最小変更版（den=N のみ／STEPS=10000／出力先、の3点。作成時に全 diff 確認済み）。
- **対照ゲート合格**（check_control_sweep10000_v1.py）: 全38系で Z[0..500] が正本と
  bit 一致、N=5 は既存10,000歩走行と全10,001歩 bit 一致。
- 状態 npz（38本・約1.5GB）は GitHub 100MB 制限のため git 管理外（.gitignore）。
  Drive 上を正本とし SHA256SUMS.txt で固定。timeseries/summary CSV・図・分析出力は
  コミット対象。

## 主結果: 三相の確定 —— 結晶（N=3,4）／周辺（N=5）／ガラス（N≥6）

### (1) 全系が回転数ロックと厳密等振幅に到達（N=5 を除く）

check_final_states_10000_v1.py（step 10000）:
- **固定点残差 ‖Z[s+N]−Z[s]‖/‖Z‖ が N=4 と N≥7 で機械精度（10⁻¹⁵〜10⁻¹³）**——
  時計1回転写像の厳密な固定点に凍結（N=3 は符号反転周期2、N=6 は 10⁻⁹ でほぼ凍結）。
- **等振幅偏差（1−S）も機械精度**——全系が振幅最大無名（等振幅 1/√M）に到達。
- 例外は N=5 のみ: 剛体残差 1.7×10⁻⁵、1−S = 9.5×10⁻⁴、冪則で漂い続ける。

### (2) しかし 60° 3軸格子に結晶したのは N=3, 4 だけ —— mod 3 選択則は棄却

analyze_axis_crystallization_v1.py:
- N=3: 3軸・1|1|1、N=4: 3軸・2|2|2（60°偏差 0.00°、3軸等分配 True）。
- **N≥6 は 3|M の系（6,7,9,10,12,…）でも3軸等分配に入らない**（60°偏差 21〜30°で飽和
  ＝格子性なし、軸数 6〜51）。M mod 3 は判別子ではなかった。
- N≥6 の終状態は **「2本の支配軸クラスタ＋多数の小クラスタ」**（例 N=40:
  319|279|30|25|…——支配2軸で77%）。初期の2軸90°構造の記憶を保持したまま凍結している。

### (3) 三相の分類（最終）

| 相 | N | 特徴 |
|---|---|---|
| **結晶** | 3, 4 | 60°格子・パリティ純度1.0・Z[ω]証明書つき因数分解（N=3素/elementary、N=4合成3+3）・全代数値ロック |
| **周辺（ガラス化不全）** | 5 | 凍結せず（冪則）・非等振幅・素な閉塞・負温度読み |
| **ガラス** | ≥6 | **厳密な凍結固定点＋厳密等振幅**だが位相は無秩序（E/ρ=3.6〜178で格子証明書不成立）。2支配軸の初期条件記憶 |

読み: 結晶化（位相の格子秩序）は N=3,4 の特権であり、一般の N は「振幅は完全に
熱化（最大無名）、位相は無秩序のまま凍結」という**位相ガラス**に落ちる。
凝縮体の言葉では、ガラスも単一の共巻き体（回転数 1/1 厳密）だが、内部の位相配置に
格子秩序がない。
