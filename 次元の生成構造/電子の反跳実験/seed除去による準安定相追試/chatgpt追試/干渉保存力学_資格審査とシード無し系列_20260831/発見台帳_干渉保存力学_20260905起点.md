## 未決着の問い（2026-09-05 時点）

1. mod 3 選択則: N≡2 mod 3（N=8,11,14,…）は長時間でも3軸等分配に入れないか（実験5で判定）。
2. 60°格子 N サイト鎖は N=6 で一周（6×60°=360°）する。N≥6 の真の終幾何は何か。
3. N=5 の H⊥/H 漸近値（0.403 通過後どこへ行くか）。素な閉塞は永遠に結晶化しないのか。
4. プレートー値の N 依存則（1/6 は N=3,4 のみ確定。一般則は不明）。
5. 実2重固有値（N=6..9 の縮退整数対 √3,√5,√8,√10）の起源——論文 v2 残課題と同一。
6. 増幅レートの解析的定式化（相対平衡まわりの Floquet 理論。方針提示済み・実装保留中）:
   予言4点 = レート、f(1) 注入則 f(1)≈Δτ²‖P⊥r‖²、段2/3必要性の定量化、den 共鳴構造。
7. w²=6N−16（N≤5）の等差則がなぜ N=6 で破れるか。倍音の家族入れ子の一般則。
