# 90度自己無撞着床：固有モード局在性解析

日付: 2026-09-10

## 方法上の注意

縮退固有空間では、個々の固有ベクトルは基底回転で変わるため、通常の IPR をそのまま比較すると基底依存になる。
本解析では各縮退固有空間のスペクトル射影子

$$
P=UU^\dagger
$$

の対角成分を用い、基底不変な support / participation ratio を計算した。

辺 e に対する重みを

$$
p_e=P_{ee},\qquad w_e=p_e/d
$$

（d は縮退度）とし、

$$
PR_e=\frac{1}{\sum_e w_e^2}
$$

を計算。頂点 v については接続辺の projector weight を集約し、同様に $PR_v$ を求めた。

## 結果1：偶数 N は全モード族が完全に global

偶数 N>=6 では正固有値族は2族のみ。

- 低モード族: 多重度 N-2
- 支配モード族: 多重度 1

両者とも頂点 participation ratio は全Nで数値的に

$$
PR_v/N = 1
$$

であり、頂点重みは完全一様。つまり特定頂点に局在するモードではなく、全頂点に等しく広がる global mode である。

辺空間でも N が増えるほど一様化し、例えば N=40 では両族とも

$$
PR_e/M \simeq 0.999343.
$$

したがって偶数系列には、FEMでいう「局所共鳴・応力集中」に対応する強い局在モードは90度理論床の線形固有空間には見えない。

## 結果2：奇数 N は二つの交互サブ格子型モード + 1つの global 支配モード

奇数 N>=7 では3族。

低い2族は頂点重みが一様ではなく、頂点番号の偶奇に沿って二値に交互配分される。

例 N=7:

- 第1族: vertex weights = 0.0625, 0.25, 0.0625, 0.25, ...
- 第2族: vertex weights = 0.1875, 0.083333..., 0.1875, 0.083333..., ...
- 第3族（支配）: 0.128676, 0.161765, ... と弱い交互差のみ

N=39でも同じ交互構造が残る:

- 第1族: 0.0125 / 0.03947368 が交互
- 第2族: 0.0375 / 0.01315789 が交互
- 第3族: 0.025017 / 0.026298 が交互でほぼ一様

つまり奇数Nでは、低2族はランダムな局所モードではなく、**二つの互いに補完的なサブ格子／パリティ型 global pattern** に分かれている。

局在度は有限で、N=39でも

- 第1族: PR_v/N = 0.7834
- 第2族: PR_v/N = 0.8162
- 第3族: PR_v/N = 0.99938

となる。したがって「一点・小領域への局在」ではなく「全体を二群に分けた交互モード」である。

## 結果3：支配固有モードは奇偶ともほぼ完全な global carrier

最大固有値の非縮退モードは、Nが大きくなるほど頂点・辺の双方で一様化する。

N=40（偶数）:

$$
PR_v/N=1,
\qquad PR_e/M=0.999343.
$$

N=39（奇数）:

$$
PR_v/N=0.999378,
\qquad PR_e/M=0.997995.
$$

これは現在探している「宇宙全体が共調するベース carrier」という読みと最も相性が良い固有モード族である。
ただし、これを物理的ベース波と同定するには、時間発展・巻数・倍音分解との一致を別途確認する必要がある。

## 結果4：Z4象限への偏りはほぼ無い

各固有空間の projector weight を Z4 ラベル 0,1,2,3 ごとに集計すると、participation はほぼ4に近い。
大Nでは支配モードだけでなく低モード族でも Z4 四象限へほぼ均等に広がる。

従って固有モード族の差は「90度象限のどこに住むか」ではなく、主に頂点側の偶奇／二群構造に宿る。

## 暫定結論

FEM的な分類で読むと、90度自己無撞着床の固有空間は次のように整理できる。

1. **偶数N**: 2つの global mode family。局所共鳴は見えない。
2. **奇数N**: 2つの交互サブ格子型 extended mode + 1つの global carrier。
3. **最大固有値モード**: 奇偶とも大Nでほぼ完全な全体モード。
4. したがって、現在の90度床は「局所構造の集まり」というより、極めて高対称な全体共鳴構造を持つ。

これは「状態空間から物理構造を逆推定する」問題を大幅に簡約する。少なくとも線形化された固有モード支持を見る限り、候補構造は任意の複雑なFEM構造ではなく、**二部的／パリティ的対称性を持つ高対称構造**に強く制約される。

## 次段

次に調べるべきは、固有値族と projector pattern の**厳密閉形式**である。
特に奇数Nの頂点重み二値パターンは明瞭な有理数列になっており、解析式を推定・証明できる可能性が高い。
これができれば「固有振動数 + モード形状」の両方を N の閉形式で記述できる。
