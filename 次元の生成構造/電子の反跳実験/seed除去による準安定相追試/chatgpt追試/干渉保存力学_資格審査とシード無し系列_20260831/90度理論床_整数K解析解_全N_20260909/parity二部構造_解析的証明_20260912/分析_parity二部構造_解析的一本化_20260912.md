# 90度整数K床の parity 二部構造による解析的一本化——sympy 記号（任意 N）＋数値（N=3–40）検証

日付: 2026-09-12（木原レビュー反映）。読出しのみ・物理無変更・新規走行なし。論文1 $D^{-1}KD=iW$ を使った論文3の格上げ。

## 発見（主張・導出済み）

種ラベル $k_e=(i+j)\bmod4$ の **mod 2**（parity）$p_e=(i+j)\bmod2$ だけで生成子が決まる：

$$\sin^2\!\Big[\tfrac{\pi}{2}(k_f-k_e)\Big]=\begin{cases}1&p_e\neq p_f\\0&p_e=p_f\end{cases}
\quad\Longrightarrow\quad W_{ef}=A_{ef}\,\mathbf 1_{p_e\neq p_f}.$$

すなわち論文1の $W$ は $L(K_N)$ を頂点番号和の偶奇 $p_e$ で二分した**二部グラフの隣接行列**。ここから：

1. **床は種ラベルから一発で構成できる（§3 の反復は不要）。** 論文1より連結 $W$ の Perron ベクトル $r>0$ に対し $z=Dr$（$D=\operatorname{diag}(e^{i\frac{\pi}{2}k_e})$）が $Kz=i\rho(W)z$ を厳密に満たす。反復床の $W$ が種 parity の $W$ と機械精度一致（‖差‖ $\le3\times10^{-27}$、全 $N=3$–$40$）することを確認したので、反復は parity を変えず、床の構成には不要。反復床と種直接床は $\pm1$ 符号ゲージ（$z_e\to-z_e$、$k\to k+2$、$K\to SKS$、$W$ 不変）を除いて同一（ゲージ整合後 ‖差‖ $\le8\times10^{-15}$）。

2. **$\sigma$ の閉形式は縮約 Perron 問題で任意 $N$ に証明される。** Perron ベクトルは parity クラスで一定値をとる。
   - 偶数 $N=2m$：異偶間辺（$p=1$、本数 $N^2/4$）と同偶奇内辺（$p=0$、本数 $N(N-2)/4$）の2クラス。各異偶間辺は同偶奇辺を $N-2$ 本、各同偶奇辺は異偶間辺を $N$ 本隣接に持つ。縮約は
     $$\omega x=(N-2)y,\quad \omega y=Nx\ \Rightarrow\ \boxed{\sigma^2=N(N-2)},\quad \boxed{x^2=\tfrac{2}{N^2}},\ \boxed{y^2=\tfrac{2}{N(N-2)}}.$$
   - 奇数 $N$（$a=\frac{N+1}2$ 偶頂点、$b=\frac{N-1}2$ 奇頂点）：異偶間（$ab=\frac{N^2-1}4$）・偶側内部（$\binom a2=\frac{N^2-1}8$）・奇側内部（$\binom b2=\frac{(N-1)(N-3)}8$）の3クラス。縮約は
     $$\omega x=\tfrac{N-1}2y+\tfrac{N-3}2z,\quad \omega y=(N-1)x,\quad \omega z=(N+1)x\ \Rightarrow\ \boxed{\sigma^2=N^2-2N-1},$$
     $$\boxed{x^2=\tfrac{2}{(N-1)(N+1)}},\ \boxed{y^2=\tfrac{2(N-1)}{(N+1)(N^2-2N-1)}},\ \boxed{z^2=\tfrac{2(N+1)}{(N-1)(N^2-2N-1)}}.$$
   これらを sympy で記号（任意 $N$）検証（`results/実行ログ`末尾）。

3. **未決だった「振幅クラスの辺割当」は parity クラスそのもの**：$i+j$ 奇（異偶間）＝$x$、$i+j$ 偶かつ両偶（偶側内部）＝$y$、$i+j$ 偶かつ両奇（奇側内部）＝$z$。数値で全辺一致（誤差 $\le1.2\times10^{-16}$、$N=3$–$40$）。

4. **全スペクトルの閉形式**：$W=\begin{pmatrix}0&B\\B^{\mathsf T}&0\end{pmatrix}$ の非零固有値は $\pm\sqrt{\operatorname{eig}(BB^{\mathsf T})}$。異偶間辺を（偶頂点)×(奇頂点) の $a\times b$ 格子で添字づけると $BB^{\mathsf T}=(a-2)I_a\otimes J_b+(b-2)J_a\otimes I_b+2J_a\otimes J_b$、固有値は $4ab-2(a+b)$（$\times1$）、$b(a-2)$（$\times(a-1)$）、$a(b-2)$（$\times(b-1)$）、残り0。$a,b$ 代入で §6 のスペクトル式（偶 $N\ge6$：$\lambda_{\max}^2=N(N-2)$・$\lambda_1^2=\frac{N(N-4)}4$ 多重度 $N-2$／奇 $N\ge7$：$\lambda_{\max}^2=N^2-2N-1$・$\lambda_1^2=\frac{(N-5)(N+1)}4$ 多重度 $\frac{N-3}2$・$\lambda_2^2=\frac{(N-1)(N-3)}4$ 多重度 $\frac{N-1}2$）に一致。数値で全 $N$ 一致（偶 $N\ge6$/奇 $N\ge7$）。

5. **活動次元 $O(N)$**：非零固有値は $a+b-1=N-1$ 個（$\pm$ ペアで $2(N-1)$）。よって
   $$\boxed{\operatorname{rank}K=\operatorname{rank}W=2(N-1)},\qquad \dim\ker=M-2(N-1)=\boxed{\tfrac{(N-1)(N-4)}2}\quad(\text{偶}N\ge6,\ \text{奇}N\ge7).$$
   $M=\frac{N(N-1)}2=O(N^2)$ の関係波空間のうち、90度床の生成子で活動するのは $O(N)$ 次元だけ。小 $N$ は退化（固有値族が消える）で例外：$N=3$（rank2, 核1）、$N=4$（rank2, 核4；$\lambda_1^2=0$）、$N=5$（rank6, 核4；$\lambda_1^2=(N-5)(N+1)/4=0$）。

6. **未決だった奇数 $N$ の残差重心も閉形式**（$D=N^2-2N-1$）：
   $$|\textstyle\sum z|=\begin{cases}0&N\equiv0\ (4)\\[1mm]\sqrt2/N&N\equiv2\ (4)\\[1mm]\sqrt{\frac{N-1}{2(N+1)D}}&N\equiv1\ (4)\\[1mm]\sqrt{\frac{N+1}{2(N-1)D}}&N\equiv3\ (4)\end{cases}$$
   全 $N=3$–$40$ で実測と一致（誤差 $\le10^{-9}$。例 $N=5$：0.154303、$N=6$：0.235702、$N=7$：0.140028）。

7. **二乗閉塞 $\sum_e z_e^2=0$ は追加条件でなく二部構造の帰結（一般証明・Perron に限らず全非零固有モード）。** $W=\begin{pmatrix}0&B\\B^{\mathsf T}&0\end{pmatrix}$ の非零固有モード $r=(x,y)$ は $By=\sigma x,\ B^{\mathsf T}x=\sigma y$ より $\sigma\|x\|^2=x^{\mathsf T}By=(B^{\mathsf T}x)^{\mathsf T}y=\sigma\|y\|^2$、$\sigma\neq0$ ゆえ $\|x\|^2=\|y\|^2$（規格化で各 $1/2$）。一方 $z_e=e^{i\pi k_e/2}r_e$ より $z_e^2=(-1)^{k_e}r_e^2=(-1)^{p_e}r_e^2$（実数）だから
   $$\textstyle\sum_e z_e^2=\sum_{p_e=0}r_e^2-\sum_{p_e=1}r_e^2=\|x\|^2-\|y\|^2=0.$$
   数値：全非零固有モードで $|\sum z^2|\le1.0\times10^{-15}$、$|\|x\|^2-\|y\|^2|\le1.0\times10^{-15}$（$N=3$–$40$）。実部・交差項虚部が別々にゼロになる（$z_e^2$ が実）のも同時に説明される。**Perron 床に限らず、二部 $W$ の任意の非零固有モードで閉塞が成り立つ。**

8. **二部 $W$ の連結性は任意 $N\ge3$ で証明できる（論文1の未決を回収）。** 偶頂点集合 $U$・奇頂点集合 $V$（$N\ge3$ で $|U|=\lceil N/2\rceil\ge2$）。異偶間辺 $(u,v)$ と $(u',v')$：$u\neq u'$ なら $(u,v)-(u,u')-(u',v')$（$(u,u')$ は偶側内部、$|U|\ge2$ で存在）、$u=u'$（$v\neq v'$）なら $|V|\ge2$ で $(u,v)-(v,v')-(u,v')$。ゆえ全異偶間辺は同一成分。任意の同偶奇辺 $(u,u')$ は $(u,u')-(u,v)$（任意 $v\in V$）でその成分に接続。よって $W$ は $N\ge3$ で連結＝既約、Perron–Frobenius が任意 $N\ge3$ で適用可能。数値でも連結成分数 $=1$（$N=3$–$40$）。

9. **符号ゲージ族の数え上げ $2^{M-1}$。** 各辺独立に $k_e\to k_e+2t_e$（$t_e\in\{0,1\}$）、$S=\operatorname{diag}((-1)^{t_e})$ で $K\to SKS$・$z\to Sz$、parity と $W$ は不変。ゆえラベルは $2^M$ 通り。全辺同時反転 $S=-I$ は大域位相 $\pi$（$z\to-z$）で同一視できるので、相対符号ゲージは $\boxed{2^{M-1}}$。頂点置換など他の同値で商を取ればさらに減る（本追試では純粋な辺独立 $\mathbb Z_2$ 符号ゲージ modulo global sign の数のみ）。
