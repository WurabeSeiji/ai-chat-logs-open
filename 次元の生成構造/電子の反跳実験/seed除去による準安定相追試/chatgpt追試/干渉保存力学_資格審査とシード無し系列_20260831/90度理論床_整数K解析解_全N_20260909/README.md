2026-09-09（木原指示）。90度系（位相 0/90/180/270）の理論床を、make_parent の近似
（反復上限・許容カット・damping）ではなく **整数固有値問題として解析的に厳密に**構成した一式。
初期データ作成のみ（走行なし）。

## 原理（要約）

床の位相は 0/90/180/270（Z4ラベル k_e）に量子化 → 生成子 K_ef=A_ef·sin(90°(k_f−k_e)) は
**整数行列（成分 0,±1）**。床はその σ_max 固有モード＝代数的厳密解。ラベルは決定論的種から
離散反復で自己無撞着に決める（許容カット無しで厳密収束）。

## 代数的閉形式（N=3..20 厳密検証済み）

- σ²: **偶数N = N(N−2)**、**奇数N = N²−2N−1**（整数）。
- 振幅²（‖Z‖²=1規格）:
  - 偶数N（2クラス・各1/2パワー・重心厳密ゼロ）: 2/N²×(N/2)²本、2/(N(N−2))×N(N−2)/4本
  - 奇数N（3クラス・重心最小）: 2/((N−1)(N+1))×(N²−1)/4本、2(N−1)/((N+1)σ²)×(N²−1)/8本、2(N+1)/((N−1)σ²)×(N−1)(N−3)/8本
- 床は「σ=√整数・各辺振幅=√有理数・位相∈{0,90,180,270}」で完全に代数的に書ける。

## 結果

全N=3..40 で one_step 相対平衡残差 ~1e-15〜1.2e-14（make_parent の ~1e-13 を上回る）。全て軸上・閉塞ゼロ。
4|N は重心厳密ゼロ、それ以外は最小化された小重心。奇数も全て床。
