# make_parent 振幅選択の診断（round 5）

## 結論
`make_parent` が返す絶対振幅は、現行方程式だけから物理的に一意選択されていない。
段階1で `np.linalg.eig(JG)` が返す固有ベクトルのユークリッド規格化 `||y||=1` が絶対スケールを固定し、段階2はユニタリなのでノルムを保存し、段階3は毎回候補固有ベクトルを現在の `||v||` に合わせているため、その規約スケールを引き継ぐ。

したがって保存系列の `r_N` は「その位相枝に対して、NumPy の固有ベクトル規格化を採用した代表振幅」であり、自己無撞着方程式から導出された絶対振幅ではない。

## 線形代数上の理由
段階1は

`JG(theta) y = -i sigma y`, `v = W(theta)y`

を使う。固有ベクトル方程式は任意の非零複素数 `c` に対して

`y -> c y`

を許すため、

`v -> c v`, `||v|| -> |c| ||v||`

となる。一方 `theta_new = arg(v)` は `c>0` なら完全に不変である。従って位相反復は絶対振幅を決めない。

`np.linalg.eig` が返す固有ベクトルを通常の Euclidean norm 1 に規格化するため、実装上だけスケールが一つ選ばれる。

## 後段がこのスケールを固定する理由
- 段階2 `_exp_step` は Hermitian `iK` の固有分解から位相因子 `exp(-i angle w)` を掛けるユニタリ発展なので `||z||` を保存する。
- 段階3では候補 `u` を `u *= ||v||/||u||` としてから混合する。よって新しい物理的絶対スケールを導入しない。
- docstring にも「振幅の正規化は行わない（全体スケールは段階1の親のまま）」と明記されている。

## beta=0.5 特殊性の追加検証
同じ位相写像を `beta` だけ外部診断で変更し、N=3..8、各3 seed、1200反復で比較した。

`beta=0.5` のみ、中央値で
- projective 2-cycle spread ~ 1.86e-15
- cube relation spread ~ 8.40e-15
- `K(phi) = -2 K(theta)` relative error ~ 1.07e-15

となった。

他 beta ではこれらは一般に成立しない。したがって 120° 三値構造、射影的2周期、`K(phi)=-2K(theta)` は少なくとも現実装では `beta=0.5` に特有の反復構造であり、元の自己無撞着方程式だけの普遍的帰結とは区別する必要がある。

## beta を変えた場合の絶対振幅
canonical seed を用いた1200反復後の `Nr^2` は beta に大きく依存した。例:

- N=4: beta=.45 -> 0.0179, beta=.50 -> 0.4444, beta=.55 -> 0.6508
- N=6: beta=.45 -> 0.3395, beta=.50 -> 0.4800, beta=.55 -> 0.7680
- N=8: beta=.45 -> 0.0908, beta=.50 -> 0.4693, beta=.55 -> 0.5703

従って観測された `Nr^2 -> 1/2` を、現段階で理論固有の振幅則として読むことはできない。

## 残る意味のある解析対象
絶対振幅ではなく、以下はスケール不変であり理論的対象として残る。

1. 位相枝そのもの / projective orbit
2. `mu/r^2`（等振幅・局所閉包枝では `-(N-1)`）
3. スペクトル比、固有空間、カイラリティなどの無次元量
4. `beta=1/2` を物理公理として別途正当化できる場合のみ、その反復が選ぶ代表スケール系列

## 判断
振幅を理論的に一意にしたいなら、現在の公理・自己無撞着条件に加えて「絶対スケールを固定する追加条件」が必要。
候補は正規化条件、保存量、外部尺度との結合、量子化条件などだが、現コードの `np.linalg.eig` 規格化をそのまま物理法則と解釈してはいけない。
