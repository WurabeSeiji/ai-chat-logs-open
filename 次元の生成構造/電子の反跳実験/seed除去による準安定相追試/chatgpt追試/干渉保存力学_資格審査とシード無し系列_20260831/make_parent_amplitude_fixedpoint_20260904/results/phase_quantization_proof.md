# make_parent 段階1: beta=1/2 位相軌道の量子化と 2 倍則（第3検証）

## 目的
第2検証で得られた

- `sigma_self / sigma_gen = 2`
- `||y_self||^2 = 1/4`

の背景を、段階1の入力位相 `theta` と出力位相 `phi=arg(v)` の関係から調べる。

## 実行条件
- 原本 `source_snapshot/original_engine.py` は無変更。
- `beta=0.5`。
- N=3..10。
- 各 N 20 seed。
- 各 seed 2000 反復。
- 第2検証で出力位相 `phi` に対する自己無撞着残差が 1e-9 未満だった 128 ケースだけを解析。

## 数値検証結果
128/128 ケースで次を同時に確認した。

1. 出力位相での自己無撞着残差

   max = 2.90e-13

2. 位相のみ生成子の行列関係

   `K(phi) = -2 K(theta)`

   相対誤差 max = 5.30e-14

3. 隣接辺対について入力位相差が量子化

   `sin(theta_f-theta_e) in {-1/2, 0, +1/2}`

   最大量子化誤差 = 9.56e-14

4. 隣接辺対について出力位相差が量子化

   `sin(phi_f-phi_e) in {-1, 0, +1}`

   最大量子化誤差 = 2.25e-13

5. 各辺の差 `delta_e = phi_e-theta_e` は 120 度クラスに分かれる。

   `exp(3 i delta_e)` が全辺で共通。

   最大 spread = 5.65e-13

6. beta=1/2 の円周中点恒等式

   `exp(2 i theta_next) = exp(i(theta+phi))`

   最大誤差 = 1.13e-14

## 解析的補題 1: beta=1/2 の中点式

非対蹠点について

`theta_next = arg[(e^{i theta}+e^{i phi})/2]`

なので

`e^{2 i theta_next} = e^{i(theta+phi)}`

が厳密に成り立つ（枝の符号は 2 倍位相で消える）。

## 解析的補題 2: 120 度クラスと -2 倍則が位相差量子化を強制する

隣接辺 e,f に対し

`a = theta_f-theta_e`

`delta_f-delta_e = 2 pi k/3`, k=0,+1,-1

とする。すると

`phi_f-phi_e = a + 2 pi k/3`。

さらに

`K(phi)=-2K(theta)`

は各隣接要素について

`sin(a+2 pi k/3) = -2 sin(a)`

を意味する。

- k=0: `sin a=0`
- k=+1: `tan a=-1/sqrt(3)` よって `a=-pi/6 (mod pi)`
- k=-1: `tan a=+1/sqrt(3)` よって `a=+pi/6 (mod pi)`

したがって

`sin a in {0,+1/2,-1/2}`。

対応する出力差は

`sin(phi_f-phi_e) in {0,+1,-1}`

となる。

これは数値で観測された量子化と一致する。

## 解析的補題 3: sigma の 2 倍則

同じ `v` に対し、生成時の theta では

`K(theta) v = -i sigma_gen v`

が `JG(theta)` 固有対の構成から厳密に成り立つ。

128 ケースで成立した行列関係

`K(phi) = -2 K(theta)`

を用いると

`K(phi) v = +2 i sigma_gen v`。

従って出力位相側の固有値の絶対値は

`sigma_self = 2 sigma_gen`。

よって第2検証の 2 倍則は、行列レベルの `K(phi)=-2K(theta)` に還元された。

## 解析的補題 4: 1/4 規格化則

出力位相側で

`y_self = (i/sigma_self) J W(phi)^T v`

と定義すると `W(phi)y_self=v` である。

第2検証では全128ケースで

`||y_self||^2=1/4`

だった。従って単位規格化固有ベクトルは `2 y_self` であり、その edge-space 像は `2v`。

したがって現在の stage1 出力は、その出力位相における単位規格化自己無撞着モードの振幅のちょうど 1/2 である。

## 現時点で証明済み / 未証明の境界

解析的に証明できたもの:
- beta=1/2 の中点恒等式。
- `120 度差クラス + K(phi)=-2K(theta)` から入力/出力位相差量子化が導かれること。
- `K(phi)=-2K(theta)` から `sigma_self=2 sigma_gen` が導かれること。

128 ケースで数値的に普遍確認したが、まだ一般証明していないもの:
- 収束した自己無撞着軌道で `exp(3i(phi_e-theta_e))` が全辺共通になる理由。
- そこから、または beta=1/2 の位相写像単独から `K(phi)=-2K(theta)` が必然になる理由。
- `||y_self||^2=1/4` の一般 N に対する直接証明。

したがって次の核心は、位相写像の収束軌道について

`exp(3i(phi_e-theta_e)) = const`

を解析的に導くことである。これが得られれば、観測された 30/90/120 度構造を閉じた形で説明できる可能性が高い。
