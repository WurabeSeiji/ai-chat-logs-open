## 1. 目的

種なし系論文（第8論文系、Version DOI 10.5281/zenodo.21614402）の図3「方向ごとの配分」
（5色占有: P1 / direction 3 / direction 4 / remaining other-rotation / kernel）は、
単なる図化ではなく、**「方向」という分解＝解釈装置**を測定に持ち込んでいる。
この装置の数学的定義・実装行番号対応・再現ゲートを本稿で固定しなければ、
後続の解釈（三方向構造・第3方向の実在性・空間読出しとの関係）の理論的背景が
読めなくなる。本稿の記述目的はこの仕様の固定であり、
**観測事実を超える物理的解釈は含まない**。

本稿が固定する対象は次の3つである。

1. 5色方向分解の全数式（式1〜式14）と、その実装（原本プログラム）の行番号対応。
2. 同じ読出しを段1+2+3 の 10,000 歩データ（別力学・同一親）へ適用した再現実装と
   対照ゲート。
3. この装置が持ち込む解釈上の前提の明示的列挙（§5）。

## 2. 記号と設定

状態は K_N の辺上の複素ベクトル Z ∈ ℂ^M、M = N(N−1)/2。親 v は
make_parent（乱数種 40260722 + 1000N、iters=1200、tol=1e-12）による固有状態、
初期状態は Z₀ = normalize(v + 10⁻¹⁵ g)（g = zero_closure_kernel_seed）。
これらはシリーズ第1章（式1〜式9）と同一であり、本稿の対照ゲート（§6）で
段1+2+3 スイープの静的親と bit 一致することを確認している。
実ベクトル空間 ℝ^M への射影は、複素 Z の実部・虚部それぞれに実基底を適用する
（式10 参照）。以下「方向」とは、断りのない限り**状態空間 ℝ^M の部分空間**を指し、
複素平面の位相軸（シリーズ既報の 60°3軸）ではない。両者の関係は §7 の読出し事実。

## 3. 5色方向分解の数学

### 3.1 固定親基底（P1・other 回転・核）

親位相 θ⁰ = arg v における生成子行列 K（辺空間 M×M、実反対称）を密に構成し、
固有分解する:

**式1**  K v_i = i σ_i v_i、 σ_i ∈ ℝ（実反対称なので固有値は純虚数 ±iσ の対）

**式2**  正の σ_i を6桁丸め round(σ, 6) で群化し、各群の固有ベクトルの
{Re v_i, Im v_i} を集める（丸めで 0 になるものは核へ）。

**式3**  P1 基底 B_P1 = 最大 σ 群の QR 正規直交化（|R_jj| > 10⁻⁸ の列のみ採用）。

**式4**  other 回転基底 B_rot = 残りの正 σ 群を P1 直交補に射影
（R₀ − B_P1 B_P1ᵀ R₀）してから QR。核は基底を作らず残差
E_ker = ‖Z‖² − E_P1 − E_other で扱う。

注意: N=3 では正 σ 群が1つしかなく **B_rot は空**（M=3 = P1 の2次元＋核1次元）。
したがって N=3 に direction 3/4 は定義されず、垂直成長はすべて核に計上される。

### 3.2 時間依存の支配平面（グラム縮約）

現在状態 Z の位相 θ = arg Z における縮約生成子を、グラム行列経由で構成する:

**式5**  G = (1/2)(G + Gᵀ) を固有分解し λ > τ_G λ_max（τ_G = 10⁻¹²）の成分を保持、
S = V_r diag(√λ_r)、K_r = (1/2)(SᵀJS − (SᵀJS)ᵀ)、(μ, U_r) = eigh(iK_r)。

**式6**  支配平面: 最大 μ のモード u_r を辺空間へ持ち上げ
u = W(V_r (u_r/√λ_r))、B_dom = QR[√2 Re u, √2 Im u] の先頭2列。
持ち上げ残差 ‖Ku + iσu‖/|σ| を診断量として記録する。

### 3.3 新方向 e₃, e₄ と direction 3/4

**式7**  B₀ = 親状態での支配平面（式6 を Z=v に適用。B_P1 と同一平面）。
新方向は R = B_dom − B₀B₀ᵀB_dom の QR の先頭2列 e₃₄（P1 直交補内の2方向）。

**式8**  other 空間への射影と正規直交化: f₃₄ = QR(B_rot B_rotᵀ e₃₄) の先頭2列。

**式9**  連続整列（色反転防止の規約）: O = f_prevᵀ f_new、SVD O = UΣVᵀ、
f_new ← f_new (UVᵀ)ᵀ。**この整列は d3/d4 の割り振りだけに影響し、
平面 span(f₃,f₄) には影響しない。**

### 3.4 占有と分裂量

**式10**  占有 E_B = ‖BᵀRe Z‖² + ‖BᵀIm Z‖²（B は実正規直交基底）。
E_d3 = E_{f₃}、E_d4 = E_{f₄}、E_rem = max(0, E_other − E_d3 − E_d4)。

**式11**  分裂量 f = 1 − E_P1/‖Z‖²（第6論文と同一。シリーズの H⊥/H と同じ対象を
固定親基底側から読んだもの）。

**式12**  5色の名称対応: direction 1, 2 = B_P1 の2列、direction 3, 4 = f₃₄ の2列、
remaining other-rotation = E_rem、kernel = E_ker。

### 3.5 成分分解と成分別位相軸（本稿の追加読出し）

**式13**  直交成分分解 Z = Z_P1 + Z_new + Z_rem + Z_ker、
Z_B = B(BᵀZ)（実基底を複素ベクトルへ列ごとに適用）。

**式14**  成分別位相軸: 各成分の波ごとの軸角 arg(z_e²)/2 を、|z_e| >
10⁻⁶·max|z| の成分についてクラスタ化（2θ 空間ギャップ 0.15 rad）し、
軸角・エネルギー重み・本数を記録する。

## 5. この装置が持ち込む解釈上の前提（明示）

1. 「方向」は状態空間 ℝ^M の部分空間であり、複素平面の位相軸ではない。
   位相軸との対応は自明でなく、§7 のとおり干渉を介した条件付きの対応である。
2. P1/other/核 の3分割は、**親位相での** K のスペクトルの6桁丸め群化に依存する
   （式2。連続閾値パラメータは持たないが、丸め桁は規約である）。
3. B_dom は時間依存で、グラム縮約の打ち切り τ_G = 10⁻¹² に依存する（式5）。
4. 連続整列（式9）は d3/d4 の個別ラベルの規約であり、物理は span のみが持つ。
5. シリーズ★★★留意（等振幅収束の循環導出の疑い）は本読出しにも波及する:
   段2内在エンジンの帰結の上での読出しであり、ノルム形式の独立傍証ではない。

## 6. 対照ゲート（再現性）

1. 入力 npz（10,000 歩スイープ）は SHA256 台帳と照合（全一致）。
2. 旧フレームワーク make_parent の v・初期 Z₀ が、段1+2+3 スイープの静的親 npz
   および states[0] と **bit 一致**（N=3, 4, 5, 40 で確認）。両フレームワークの
   親は同一物である。
3. 図の様式（5色・log・床 10⁻⁶・crossing 点線・共通横軸）は正本図化プログラムと同一。

## 7. 読出しの事実（解釈なし）

段1+2+3・10,000 歩データ（fig3_compare_stage123_N5_N40.png、
check_direction_axes_mapping_v1.json）:

1. N=40: crossing（step 358）とともに direction 3/4 が床から立ち上がり
   0.022/0.025 で定着。remaining other-rotation は床 10⁻⁶ のまま
   （成長は新1平面＋核に閉じ込め）。E_ker = 0.062、f 終端 = 0.109。
2. N=5: d3 = 0.11、d4 = 0.075、E_ker = 0.21、f ≈ 0.40。同型の構造。
3. 旧エンジン（σ時計＋Cayley）の正本図と定性的に同一——**三方向構造は
   エンジン・読出し実装に依存しない**。
4. 結晶（N=3, 4）: E_new = 0 で垂直成長は核に住み、**E_P1 : E_ker = 5/6 : 1/6
   （両系とも厳密）**。成分別軸は P1 = 2軸90°、核 = 1軸（親軸の1本と一致）で、
   総和の 60°3軸はどの成分単独にも無く、**成分間の波ごとの干渉で生成される**。
5. ガラス（N=40）: Z_new・Z_ker は各々単一軸のコヒーレントベクトルだが親軸の
   近傍（7.4°/1.2°）に整列し、第3の位相軸を作らない。

## 8. 主張範囲と反証可能性

本稿は読出し装置の仕様固定である。主張は次に限定する。

1. 5色方向分解は式1〜式12 で完全に定義され、実装と行番号レベルで対応する。
2. 段1+2+3 データへの適用は §6 のゲートの下で正本と同一の装置である。
3. §7 の読出し事実。

「方向」の物理的意味づけ（空間次元との同一視、凝縮体との対応など）は本稿では
行わない。反証条件: (i) 同一入力で式1〜式12 の実装が本稿の行対応と異なる出力を
与えること、(ii) §7 の数値が run_all.sh の再実行で再現しないこと。
