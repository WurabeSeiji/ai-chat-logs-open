## 修正1: 時計統一（den=N → den=124、run_R124_23_den124_N3_N16_v1.py、差分1行＋出力先）

動機（木原 2026-09-08）: 回転の時計 Δτ=2π/N と散乱の時計 φ=2π·101/124 が非通約で競合している。
散乱側の位数を実測すると G=½(D−A) の固有値は厳密に {0, N/2, N−1} で、
**偶数 N: U¹²⁴=I（1e-11）／奇数 N: U²⁴⁸=I** — 124 時計は R の有理性 φ/2π=101/124（既約）そのもの。

結果（テスト1、事前登録の4検査）:
1. 蹴りの den 非依存性: f(1) は den=N 版と同桁（比 0.1〜5.7）→ 予測どおり。床は回復せず、正常型インフレーションは戻らない。
2. **124 歩再帰＝時計同期が成立**: 終盤 |⟨z_t,z_{t+124}⟩| ≈ 1.0000 が 11/14 系（例外 N=4: 0.33、N=6: 0.80、N=12: 0.98 漸減）。
   **奇数 N も 124 で再帰**（248 を待たない）— 状態が G の半整数セクターを避ける配置に落ちると読める。
3. **閉塞が大幅回復**: 機械精度保存 {3,5,9,10,11,15,16}、微小 {8,14}、有界振動 {6,7,12,13}、完全開放は N=4 のみ
   （den=N 版では 5,6,8,10,12 が大破れだった）。破れが蓄積せずコヒーレントに戻る型へ移行。
4. 結論: **R は「系の時計」として機能する**（閉塞保存＋124 周期ロックの駆動軌道）。ただし床は失われたまま。

## 修正2: 床免疫（相互作用集合 I を全対へ、run_R124_23_allpairs_den124_N3_N16_v1.py、G構成1箇所）

鍵の恒等式（木原の (b) 提案の実現）:
$$G_c=\sum_{\text{全対}}P_-=\tfrac12\big((M-1)I-(J-I)\big)=\tfrac{M}{2}\big(I-|u\rangle\langle u|\big),\qquad |u\rangle\propto(1,\dots,1)$$
固有空間は{一様モード=重心 Σz, その直交補}の2つだけ。**Σz=0 ⇔ 厳密固有ベクトル ⇔ 散乱は大域位相のみ（完全免疫）**。
理論床は構成により全 N で Σz=0 厳密なので、免疫が設計で保証される（N=3 の偶然免疫の一般化）。

結果（テスト2）:
1. **床免疫の実証**: f(1)=1e-31〜4e-26（頂点共有版の 4e-3〜0.45 から復帰）。f(1) が N とともに増えるのは、
   床の重心残差（~1e-15）を散乱が毎歩差動回転して**有効シード化**するため — シードの正体が丸めから重心残差へ移った。
2. **インフレーション復活**: N=6..16 の大半で床からの指数ランプ。増幅率は Control とほぼ一致
   （N=10: 0.1025/0.1024、N=14: 0.1051/0.1057）。onset は Control よりやや早い（例 N=9: 256/281）＝励起は R を感じている。
3. 閉塞: N=3..7 機械精度、N=8..15 は 1e-9〜1e-5。**例外 N=12, 16 は暴走型**（onset 155/115・率1.5〜2倍・
   f(500)=0.99/0.90・閉塞 0.73/0.52）。同じ N≡0 mod 4 の N=4,8 は正常なので単純 mod 則ではない（要監査）。
   N=4, 5 は 500 歩内で未点火（Control 比で遅延）。
4. 124 歩再帰は励起後も概ね維持（≈1.0000、例外 N=7: 0.79、N=12: 0.83）。

## 総括

- 修正1で **R時計への同期**、修正2で **床免疫＋インフレーション復活** が段階的に実証された。
- 到達点: **「重心ゼロの背景は散乱に透明、重心成分を持つ励起だけが R 散乱を受ける」**分業の実現。
  R 時計（124 歩）・零閉塞・インフレーションが初めて共存した。
- 重心ゼロ条件（理論床設計で要求した Σz=0）が、そのまま全対散乱に対する免疫条件だった —
  床設計と R 導入が一本の線でつながった。
- 未決着: N=12, 16 の暴走と閉塞破れの機構／N=4, 5 の遅延／124 再帰の例外（N=7）。
  次段候補: STEPS=496/620（124 の整数倍）での周期精査、N=8k の二波対の時間発展追跡、N=12/16 の監査。
