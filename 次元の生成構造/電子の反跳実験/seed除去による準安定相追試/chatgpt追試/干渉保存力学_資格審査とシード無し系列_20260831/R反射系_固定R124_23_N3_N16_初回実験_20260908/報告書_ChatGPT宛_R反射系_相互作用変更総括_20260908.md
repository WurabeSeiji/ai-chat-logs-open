## 2. 相互作用の変更点（3段階）— これが全て

### 段階0（初回・指図書準拠）: I = 頂点共有対（辺グラフ隣接）

```python
G = 0.5*(np.diag(A.sum(axis=1)) - A)      # G = Σ_{A_ef=1} P−^(ef) = ½(D−A)
```
時計は正本どおり den=N（Δτ=2π/N）。

**結果: 正常なインフレーション消失。** 床が第1歩から O(1) 励起（f(1)=4e-3〜0.9）。
機構: 辺グラフは 2(N−2)-正則なので G = (N−2)I − A/2、spec(G) = {0, N/2, N−1} 厳密。
床（N≥4）は G の複数固有成分に分裂しており、散乱が毎歩 O(1) の差動位相を与える（キック）。
N=3 のみ床が G の厳密固有ベクトルで免疫（残差 3e-16）。
副産物: 偶数 N で U¹²⁴=I（1e-11）、奇数 N で位数 248 — R の有理性 φ/2π=101/124 が散乱の位数を厳密に決める。

物理的意味: 段回転 Δτ=2π/N と散乱時計 φ=2π·101/124 の非通約競合を解消し、**R の 124 格子に全系を統一**。

- しかしキックは den 非依存（f(1) 同桁）なので床は失われたまま。**R は「系の時計」として機能するが、床免疫はない。**

### 修正2: 相互作用集合 I を全対へ（木原「(b)が本質では？」の実現）— 決定打

```python
# 置換: G = ½(D−A)  →
M_ = A.shape[0]
G = 0.5*((M_-1)*np.eye(M_) - (np.ones((M_,M_)) - np.eye(M_)))
```
鍵の恒等式:
G_c = Σ_{全対} P− = ½((M−1)I − (J−I)) = **(M/2)(I − |u⟩⟨u|)**、|u⟩ ∝ (1,…,1)。
固有空間は {一様モード＝重心 Σz, その直交補} の 2 つだけ。
**Σz=0 ⇔ 厳密固有ベクトル ⇔ 散乱は大域位相のみ（完全免疫）。**
理論床は構成により全 N で Σz=0 厳密なので、免疫が設計で保証される（N=3 の偶然免疫の一般化）。
den=124・対称分割・φ は修正1と同一。

**結果: 床免疫＋インフレーション復活。**
- f(1) = 1e-31〜4e-26 に復帰（シードの正体は丸めから重心残差 ~1e-15 の差動回転へ移行）。
- N=6..16 の大半で床から指数ランプ、増幅率は Control とほぼ一致（N=10: 0.1025/0.1024、N=14: 0.1051/0.1057）。
- onset は Control よりやや早い（例 N=9: 256/281）＝励起（重心成分を持つ）だけが R を感じる。
- **R 時計（124 歩再帰）・零閉塞・インフレーションが初めて共存。**
  「重心ゼロの背景は散乱に透明、励起だけが R 散乱を受ける」という分業が実現した。
  床設計で要求した Σz=0 が、そのまま全対散乱への免疫条件だった — 床設計と R 導入が一本の線でつながった。
