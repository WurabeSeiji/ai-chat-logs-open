# 固定 R_{124,23} 反射散乱 × Stage1+2+3（対称分割合成）N=3〜16 初回実験 分析

実施 2026-09-08。数値の出所: `compare_R124_23_vs_control_N3_N16.csv`（analyze_R124_23_vs_control_v1.py、
入力は results/ と Control=../対称親v2_500step走行_20260906/results/ の timeseries）。
指図書の検証群は木原指示（2026-09-08）で簡素化し、走行＋標準図化＋本分析に絞った。

## 確定事実（コードとデータから直接）

1. **代数的恒等式**: 辺共有グラフは 2(N−2) 正則なので
   G_scatter = Σ_{A_ef=1} P₋ = ½(D−A) = (N−2)I − A/2。
   したがって U_half = e^{iφ(N−2)/2}·exp(−iφA/4)（大域位相 × 隣接行列生成の複素回転）。
   今回の候補 I=A の R 散乱は、実効的に「隣接行列 A を虚指数化した一様回転」に等しい。
2. **ノルムは保存**（U_half ユニタリ）: H_total ドリフト ≤ 7e-13（全14系・全500歩）。
3. **ゼロ閉塞 Σz² は一般に保存されない**: exp(iθA) は複素直交でないため。
   実測の閉塞最大値（|Σz²|/H、全期間）は N 依存が激しい:
   - 機械精度で保存: N=3(4e-13), 9(1.6e-13), 13(3.4e-14), 14(9.9e-14), 16(4.1e-14)
   - 小破れ: N=15(3.0e-10), 11(1.8e-8)
   - 大破れ: N=7(8.5e-2), 12(0.32), 8(0.52), 10(0.52), 6(0.81), 5(0.83), **N=4 は 1.00（完全開放）**
   Control は全系 ≤5e-14。破れの N 依存則は本実験では特定しない（観測記録のみ）。
4. **インフレーションの型が消える**: R 反射ありでは、N=4 を除き線形ランプが観測されず、
   step1 で f(1)=4e-3〜0.92 へ跳ぶ即時励起型（onset 1〜41 歩）。散乱は理論床に対して
   毎歩の強い摂動として働く（床 1e-31 の維持は N=3 のみ）。
   Control（理論床のみ）の onset 65〜394・整った指数ランプとは別レジームである。
5. 終値 H⊥/H は Control（0.048〜0.223）より大きく 0.24〜0.96。飽和先も別物。
6. N=8k（今回範囲では 8, 16）だけの特別な応答は見えない: N=8 は大破れ・N=16 は保存側と、
   同じ 8k 系列内で閉塞応答が割れた（初期二波完全被覆の帰結は単純には現れない）。

## 実装上の候補（物理と峻別）

- I=A（頂点共有辺対）、全 pair 一括の G、対称分割合成、φ=2π·101/124 固定 — いずれも研究ノートの第一候補。
- G=(N−2)I−A/2 の恒等式により、この候補は「散乱ネットワークの選択」というより
  「A 生成子の複素回転を毎歩挟む」ことと等価。別候補（非隣接対・距離クラス限定など）は未実施。

## 物理解釈（仮説どまり）

- 閉塞が保存される N の集合 {3,9,13,14,16}（+準保存 11,15）に単純な mod 則は当てはまらない。
  理論床の距離クラス構造と A 固有値の整合（どのクラス組合せが exp(2iφA/4) の下で
  零和を保つか）で決まると予想されるが、本実験では検証しない。
- 即時励起は「R 散乱が理論床の中立性を破る」ことを意味し、点火資格（不安定な相対平衡）を
  経由しない別経路の励起。旧タイプのインフレーションとは区別して扱うべき。
