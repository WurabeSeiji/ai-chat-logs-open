## 実験設計

### 目的
元のプログラムでは分母が N に依存して変化：
- Δτ ∈ {2π/(N-2), 2π/(N-1), 2π/N, 2π/(N+1), 2π/(N+2), 2π/124}

本実験：
- **固定** Δτ = 2π/124 をすべての N に適用
- 他のパラメータは同一
- 分子数依存性を単一スケールで比較

### ハミルトニアン進化
```
H(z) = A ⊗ (conj(z) ⊙ z)    [隣接行列と外積]
Z_{t+1} = V @ exp(-i·Δτ·λⱼ) @ (V† @ Z_t)    [固有値分解による進化]
```

## 物理的解釈

### 1. 固定分母 124 の役割

- **N=3～16 に対する相対的サイズ**: 124 >> N
  - N=3: 124/3 ≈ 41.3
  - N=16: 124/16 ≈ 7.75
  
- **位相進化の粒度**:
  Δτ = 2π/124 ≈ 0.0507 [rad]  
  これは各固有値に対して小刻みな位相回転を印加

### 2. 安定性の物理的背景

**固定分母実験の発見**:
```
Δτ = 2π/N    → onset あり（小分母で不安定）
Δτ = 2π/124  → onset なし（大分母で安定）
```

**解釈**: 
- 分母が大きい（位相進化が遅い）
- 状態の緩やかな圧延
- Hperp/H の成長が 500 ステップ範囲内では抑制

### 3. 層別分析（N サイズ別）

#### 小 N (3～5)
- Initial: 10^-32～10^-69 レベル（ほぼゼロ）
- Max at step 500: 10^-29～10^-27

#### 中 N (6～10)
- Initial: 10^-32～10^-30
- Max: 10^-27～10^-28
- 緩やかな成長

#### 大 N (11～16)
- Initial: 10^-35～10^-31
- Max: 10^-27 付近（収束傾向）
- N=15 で最小 max 値 (1.66e-27)

## 元のプログラムとの比較

### 元の実験（分母可変）

```
分母が N 近辺の場合:
- Δτ = 2π/N   : 強い摂動
- Result: onset ~ 50～300 ステップ

分母 = 124:
- Δτ = 2π/124 : 弱い摂動
- Result: onset = -1 （500 ステップ内で未到達）
```

### 本実験（分母固定 124）

```
すべての N に統一:
- Δτ = 2π/124 一定
- Result: **全 N で onset = -1**
```

## 結論

### 主張
**Δτ = 2π/124 は universal suppressor として機能する**

1. **分母サイズ効果の確認**
   - 分母が大きいほど系は安定
   - 124 は N=3～16 すべてに対して十分大

2. **摂動強度の階層構造**
   - Δτ = 2π/N     : 強（準安定相へのonset あり）
   - Δτ = 2π/124   : 弱（安定相に留まる）

3. **準安定相のメカニズム**
   - onset が生じるのは分子と分母が近い場合
   - 分母が十分に大きい場合は干渉保存が優位
