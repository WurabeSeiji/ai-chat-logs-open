# シード型（ボゾン帯／フェルミオン帯）が効く物理量（2026-09-06）

木原の問い: ボゾン型／フェルミオン型のシードはインフレーションには効かないが読出しには効く
——それ以外にどの物理に差が出るか。論文A正本の δ=10⁻²・T42000・N=12 の5系＋真空腕
（既存データ・読み取りのみ・新規走行なし）で、記録済み全観測量を窓 [21000,42000] 中央値で横並びにした。

## 結論（一言）

**ボゾン帯（偶数 k）だけのシードは「真空と区別がつかない」。** 空間（インフレーション・
f₂・n_eff）は作るが、物質・電荷・時間・帳簿・凝縮体の閉塞破れを一切作らない。すべては
**奇数帯（フェルミオン）シードが解錠**する。差は読出しの都合ではなく**偶奇選択則という保存則**。

## 物理の差（5点）

1. **偶奇選択則（保存則）**: ポンプ k=2（偶）と3次相互作用 k_i+k_j−k_l のもとで帯の偶奇は保存
   される。偶数帯だけから出発すると奇数帯は永久に厳密零。ゆえにボゾンシードからフェルミオン相棒
   （物質）は生まれない。読出しの都合ではなく代数的な禁止。
2. **時間はフェルミオンが点ける**: ω̂（時計の周波数）と時間の担い手パワーは、奇数帯を含む4モードで
   ω̂≈0.0437 に**ほぼ同値**、boson_family と真空で厳密零。時計の周波数はシードの種類に依らず
   「奇数帯があるか否か」の二値で立つ。
3. **電荷＝凝縮体の閉塞欠損**: ボゾンシードは凝縮体セルの閉塞残差を機械零（3.6e-15、真空と同水準）
   のまま保つ。フェルミオンシードは 1e-6〜1e-4 の残差を凝縮体セルに**持ち込む**。
   ボゾンは閉塞保存、フェルミオンは閉塞破り——電荷 Q̂ が立つのは後者だけ。
4. **生成性（帳簿の連鎖）**: ボゾンシード3つは置いたまま**子孫ゼロ**（占有4＝ポンプ＋種）、
   偶数帯の梯子すら k=6 自身以外は立たない（V6）。フェルミオンシード1つで 5 セル、5つで 61、
   混合で 128 全部。**偶数帯の梯子を登らせるのにも奇数帯が要る**。
5. **α根への接近は多種混合だけ**: r_nopump は単一種で 1.000、boson で 0、**mixed で 0.631**
   （α根 R_α=0.6972 まで 0.066）。α根は種の共存が作る（論文A本体の主張と整合）。

**インフレーション（空間）は上記すべてに盲目**（検討20・21）——f₂・n_eff は全モードで同程度。
空間の誕生と物質・電荷・時間の誕生は別機構で、後者の鍵が「奇数帯」。

## 帳簿の幾何（fig_mode_ledger.png の観察）

- **vacuum**: ポンプ (k=2, η=0) の1セルのみ。
- **boson_family**: ポンプ＋種3セル (k=6, η=0,3,5) の**4セルだけ**、他は全て機械零＝真空と同型（種が置かれただけで子孫を作らない）。
- **neutral**（種 η=0）: η=0 の**1列**だけが全帯 k に立つ。和則 m*=2m_pump−m で m_pump=0・m_seed=0 なら生成される巻きは 0 のまま——**巻き（電荷）保存**の可視化。
- **electron**（種 η=3）: (k, η) 平面に**市松模様**。巻き 3 の合成 {0,3,6,1,4,7,2,5} が帯 k と連動する偶奇則で並ぶ。
- **fermion_family**（5種）: 全列が立ち帯方向に縞。**mixed**: 128セル全面。
- Q̂ の時系列（fig_mode_timeseries.png）: electron は全期間 −1（電子電荷）。fermion_family は −1 → step≈28000 で −1/3（優勢種が e型から d型へ交代）、mixed も step≈33500 で同じ交代——**多種共存では優勢電荷が長時間で入れ替わる**。
