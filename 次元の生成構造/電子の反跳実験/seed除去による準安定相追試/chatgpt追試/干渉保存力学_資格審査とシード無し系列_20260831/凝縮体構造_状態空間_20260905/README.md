# 凝縮体構造の状態空間内調査（読み出しのみ）

作成日: 2026-09-05

## 目的（木原の方向づけ）

時空区間への写像は一筋縄ではいかないため、先に「状態空間のなかで凝縮体がどうなるのか」
を固める。凝縮体の作業定義は実験6の「零閉塞＋共巻き」（保存量: ブロックエネルギー・
ブロック閉塞・巻数レート）。検討9のゲージ場読み（波= K_N の辺のリンク変数）から、
格子ゲージ理論の類推で**頂点のガウス束縛の対応物**が第一の検定対象になる。

## 結果1: 頂点スター閉塞 — N=4 だけが厳密な局所保存量を持つ

check_vertex_star_closure_v1.py: G_v(s) = Σ_{e∋v} z_e(s)²（頂点 v に接続する N−1 辺の
二乗和）を全 N=3..40 の全時間で測定。

- **N=4: 全4頂点で G_v = 0 が全501歩・機械精度で成立**（初期 3.1×10⁻¹⁵、
  全時間ドリフト最大 4.0×10⁻¹⁴）。インフレーションと遷移を貫いて保存される
  **厳密な局所ガウス束縛**である。K_4 では star(v) の補集合が対面三角形なので、
  これは実験4-7 の「N=4 の 3+3 分解（star+triangle）」が**力学的不変量として
  保護されている**ことを意味する。
- **他の全 N（N=3 含む）: G_v(0) ≠ 0（相対 0.3〜1.8）かつ時間発展でドリフト**。
  局所頂点電荷は存在しない。N=5 の10000歩でも同様。
- 帰結: 「保存量を持つ塊」としての部分凝縮体が**グラフ局所（頂点）構造で保護される
  のは N=4 のみ**。N=4 の異常な完全性（最深ロック・機械精度の全代数値）の構造的
  起源はこれとみられる。一般の N では凝縮体の同一性は大域的で、3軸ブロックは
  創発構造（保存はされない——実験4-6 の振幅非保護と整合）。

## 結果2: 遷移期に凝縮体は分裂しない — 単一共巻き体のままレートが滑る

check_transition_cowinding_v1.py: N=3, 4 の遷移窓で波1本ごとの瞬時位相速度
v_e(s) = arg(z_e(s+1)/z_e(s))/2π を測定（円環スプレッドで判定）。

- 遷移前: 全波が固有値予測レートに一致（N=3: √2/3 = 0.471405、N=4: 2√2/4 の
  エイリアス −0.292893）、スプレッド 10⁻⁷ 級。
- 遷移中: スプレッドは最大でも **0.042（N=3, step44）／0.038（N=4, step49）**。
  旧レート帯と新レート帯の**共存（相分離）は起こらず**、全波が一体のまま
  連続的にレートを滑らせて新値（N=3: 1/2、N=4: −1/4/step = 時計1回転で −1 ≡ 0）
  に着地する。遷移後スプレッドは 0。
- N=4 の波別レートは全遷移を通じて [a,b,c,c,b,a] の**対辺ペア対称**
  （K_4 の対辺 (0,1)-(2,3), (0,2)-(1,3), (0,3)-(1,2) が常に同レート）。
- 帰結: この力学の凝縮体は**分裂・共存を経ずに変態する**。「旧凝縮体の死と
  新凝縮体の誕生」は同一の共巻き体の連続変形である（一次転移的な相共存ではない）。

## 結果3: 無名性（振幅エントロピー）の H定理型単調流 — check_anonymity_entropy_v1.py

背景（木原）: 宇宙の初期値は振幅も含めて極めてコヒーレントで無名性が高く情報量が
極めて少ない波の集合だったのではないか。現在のシードは振幅非等分で情報を持つため
初期値として疑わしい。

正規化振幅エントロピー S = −Σp ln p / ln M（S=1 ⟺ 等振幅=最大無名）を全系・全時間で測定:

- **全38系が S=1（最大無名）へ流れる**。整定系は 1−S = 0〜10⁻¹²、遅い大 N も 10⁻⁶ 台
  へ接近中。**ほぼ完全な単調増加**（逆行は最大でも 1.4×10⁻⁴、多くは機械精度）——
  この力学は振幅無名性についての H 定理型の流れである。最大上昇は各系の遷移 step に一致。
- **例外は N=5**: 1−S = 9.2×10⁻⁴（step500）→ **9.5×10⁻⁴（step10000、微減=逆行）**。
  最大無名に到達できない唯一の系。
- **シードの情報量は 1−S₀ ≈ O(N⁻²) で消える**: N=3: 0.054、N=5: 0.025、N=7: 0.0030、
  N=10: 0.0019、N=40: 0.0003（N 3→40 で係数 180 ≈ 13.3²）。
- 読み: 木原仮説「初期値=最大無名」は連続極限で回復する——正しい初期条件の描像は
  「最大無名状態＋無限小の種」であり、現在の親の振幅非等分は小 N でのみ大きい
  有限 N 人工物。**小 N の例外現象群（√2 族・1/2 ロック・N=5 周辺性）が、ちょうど
  シード情報量の大きい領域に集中している**ことは、この疑いを裏書きする。

決定的な対照実験の提案（要承認・新規走行）: **等振幅シード対照**——90°格子の位相構造は
保ち、振幅だけ全て等しくした親（Σz²=0 は保持）から同じ力学を走らせる。
小 N の例外現象（1/2 ロック・N=5 停滞・√2 レート）がシード起源か力学起源かを分離できる。
