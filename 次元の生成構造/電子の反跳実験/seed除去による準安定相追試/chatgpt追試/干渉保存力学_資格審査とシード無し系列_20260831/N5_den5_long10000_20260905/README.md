# N=5・Δτ=2π/5 長時間走行（10,000 step）

作成日: 2026-09-05

## 目的と設計

回転数ロック全系列調査（`../N3_N40_rotation_lock_analysis_20260905/`）で N=5 だけが
「ロック未達・非等振幅・接近後に反転」という異常を示した。木原指示により
**10,000 step・Δτ=2π/5 で最後まで走行し、判定規則は力学に一切組み込まず、
分析は走行後に行う**設計とした。

- `run_N5_den5_steps10000_v1.py` は正本 run_N3_N40_stage123_v1.py の忠実コピーからの
  最小変更版（変更は N∈{5}・den=5 のみ／STEPS=10000／出力先と単走行用の図、の3点。
  全 diff は作成時に確認済み）。初期データは正本スイープの静的親 Z0 を同パスから使用。
- 対照ゲート（`check_control_first501_v1.py`）: 新走行の Z[0..500] が正本
  hm_N5_den_5_states_500.npz（SHA 台帳照合済み）と **bit 一致**、timeseries 同区間も一致。

## 結果（analyze_N5_long10000_v1.py / n5_long10000_frames_v1.csv）

1. **H⊥/H は 500 step 時点の値（0.3666）が漸近値ではなかった**: その後も単調増加を続け、
   step 10000 で 0.40276（末尾5000 step 平均 0.3998 ± 0.0019、なお微増中）。
2. **回転数は 1/1 に向かうが、収束が冪則**: dist(x, 1/1) ∝ t^(−1.10)
   （steps 2000..9995 の log-log フィット、rms 残差 0.0068 桁）。剛体残差も t^(−1.31)
   （rms 0.0019 桁）。他の全系が数百 step で機械床まで指数収束するのと対照的に、
   **N=5 だけは指数でなく代数的（周辺的・非双曲的）な接近**をする。
   step 9995 時点: dist = 8.66×10⁻⁵、剛体残差 = 1.70×10⁻⁵。
3. **非等振幅の変形は減衰しない**: 等振幅相対偏差は step 500 の 6.2% から step 2000 頃に
   4.5% へ下がった後は凍結し、log-log 勾配 **+0.026 ≈ 0**（末尾5000 step で 4.44〜4.49%）。
   終状態は等振幅リングではない構造を保ったままである。
4. 500 step 調査で見えた「接近→反転」（step 325 で最接近後に遠ざかる）は、
   この長時間データでは初期過渡（〜step 800 の振動）の一部であり、その後は
   単調な冪則接近に移行している。

## 読み出しのまとめ

N=5 は他の全系と同じくストロボ固定点（回転数 1/1）へ向かうが、接近則が
指数（双曲的）でなく冪則（周辺的）であり、かつ等振幅化が起こらない。
接近則と終状態の形の両方で、N=5 のアトラクタは他系と型が異なる。
H⊥/H の漸近値は 10,000 step ではまだ確定しない（0.403 を通過して微増中）。
