# 巻数時間と凝縮体定義（読み出しのみ・新規走行なし）

作成日: 2026-09-05

## 背景（木原の方向づけ）

- 凝縮体の基本は零閉塞（Σz²=0）だが、0+0=0 は無数に作れるため不足。凝縮体は
  「状態空間で何かの保存量を持つ塊」であるべき。3+1次元なら空間重心＋時間発展での
  重心測地線方向の並進に当たるものが、この系の3軸（60°）読み＋時間読みで何になるか。
- 処理ステップ τ が時間に比例するとは考えられない。**時間の実体は位相でなく巻数**
  （全体位相の 2π に対する巻数）ではないか。

## 操作的定義の候補（本フォルダの作業仮説）

**凝縮体 = 零閉塞 ＋ 共巻き（ブロック全体が剛体として一様レートで巻く）**。
このとき保存量は3つ: ブロックエネルギー Σ|z|²・ブロック閉塞・巻数レート
（3+1次元の「重心＋並進速度」に対応）。上部凝縮構造は、複数ブロックの巻数レートが
有理比（倍音）のときに合成周期を持つ複合凝縮として定義できる。同一 N 内のスペクトルが
共鳴フリー（check_spectrum_harmonics_v1.py）であることは、単一周波数が全体を取る
実測（増幅期も飽和後も全系が単一の共巻き体）と整合する。

## 検定と結果（analyze_winding_rates_v1.py）

### (1) 直接巻数積算の検証（N=3, den=3）

隣接ステップの平均位相前進を逐次和した巻数レートは、増幅期で
**√2/3 回転/step に偏差 1.0×10⁻¹¹ で一致**（固有状態の予言どおり。方法の健全性確認）。
500歩の総巻数 119.72 回転。ロック後の1歩平均は 0.2159 回転/step だが、周期6軌道は
1歩単位では剛体でないため、この量は 3歩ストロボの 1/2 回転と単純に整合しない
（ロック後の巻数の正しい読みはストロボ枠で行う必要がある——未決着の注意点）。

### (2) 「時間=巻数」collapse 検定（全228走行）

増幅レートを「ステップあたり」と「巻数あたり」（巻数レート = |w_dom|/den 回転/step、
親が固有状態なので厳密）で比較した変動係数 CV:

| 系列 | n | steps/decade CV | turns/decade CV |
|---|---|---|---|
| 全体 | 228 | 0.585 | 0.750 |
| **den=124（流れ領域）** | 38 | **0.767** | **0.390（半減）** |
| den=N（ストロボ領域） | 38 | 0.478 | 0.517 |
| den=N±1,±2 | 152 | 0.566 | 0.617 |

**判定: 「時間=巻数」は流れ領域で強く支持され（散らばり半減、平均 0.68 回転/桁）、
ストロボ領域では機能しない。** これは仮説の破綻ではなく整合的な読みができる:
巻数時間は連続極限（流れ領域）の概念であり、Δτ≈2π/N のストロボ領域では
エイリアシングが巻数の読みを壊す。

## 追記（同日）: エイリアス巻数による精密化 — check_aliased_winding_v1.py

時間の量子化度を q = w_dom/den（1目盛りあたりの巻数）と定義すると:

| 系列 | q の範囲 | CV steps/dec | CV 素巻数 | CV エイリアス巻数 |
|---|---|---|---|---|
| den=124（流れ） | 0.011–0.314 | 0.767 | **0.391** | 0.391（恒等） |
| den=N（ストロボ） | 0.471–0.973 | 0.478 | 0.517 | **0.321** |
| den=N±1,2（中間） | 0.283–1.414 | 0.566 | 0.617 | 0.645 |

- q≪1/2 では素の巻数が時計（流れ領域、0.68 回転/桁）。
- q≈1 では**最近整数を除いたエイリアス巻数 |q−round(q)| が時計**（ストロボ領域、
  0.40 回転/桁、CV 0.478→0.321 に改善）。
- 中間 q はどちらの時計も機能しない＝**時間の読みが定義できない帯**。
結論: 時間の連続性は q→0 の極限でのみ成立する近似。低 N・粗い時計では時間は
q（目盛りの巻数）と有理ロック先（1/2, 1/1）の 双方で強く量子化される。

## 追記（同日）: 2時計レート比検定（検討10-5） — check_clock_ratio_v1.py

仮説「t が単一の導出時間なら、結晶化域で質量時計レート（ロック接近の減衰）と
電荷時計レート（巻数）の比は N によらぬ定数」を、N=4..37 の29系（指数ロック系、
N=5 除外）で検定した。

結果: **最単純形は棄却**。ロック 1桁あたりのエイリアス巻数は 0.97〜9.0 と分布し
CV = 0.584（steps/decade 単独の CV 0.498 より悪い）。増幅域の定数 0.399 とも一致しない。

代わりに新構造を検出:
- **ロックレートに N=9→10 の不連続**（steps/decade: N=6..9 は 40〜59、N=10 で 13 に急落、
  以後 N とともに漸増して N=37 で 100）。境界は**スペクトル整数構造の消滅点
  （2重縮退整数対 √3,√5,√8,√10 が N=6..9 にのみ存在、N≥10 で消滅——発見2-9）と一致**。
  縮退整数対を持つ系は巻数あたりの結晶化が3〜4倍遅い。
- 解釈の含み: 仮説が死んだのではなく、結晶化域の正しい電荷時計は増幅期の固有振動数
  でなく**減衰モードの Floquet 乗数の偏角（歳差レート）**である可能性が残る。
  これは保留中の Floquet 定式化（未決着6）で判定できる。
