# 巻数時間と凝縮体定義（読み出しのみ・新規走行なし）

作成日: 2026-09-05

## 背景（木原の方向づけ）

- 凝縮体の基本は零閉塞（Σz²=0）だが、0+0=0 は無数に作れるため不足。凝縮体は
  「状態空間で何かの保存量を持つ塊」であるべき。3+1次元なら空間重心＋時間発展での
  重心測地線方向の並進に当たるものが、この系の3軸（60°）読み＋時間読みで何になるか。
- 処理ステップ τ が時間に比例するとは考えられない。**時間の実体は位相でなく巻数**
  （全体位相の 2π に対する巻数）ではないか。

## 操作的定義の候補（本フォルダの作業仮説）

**凝縮体 = 零閉塞 ＋ 共巻き（ブロック全体が剛体として一様レートで巻く）**。
このとき保存量は3つ: ブロックエネルギー Σ|z|²・ブロック閉塞・巻数レート
（3+1次元の「重心＋並進速度」に対応）。上部凝縮構造は、複数ブロックの巻数レートが
有理比（倍音）のときに合成周期を持つ複合凝縮として定義できる。同一 N 内のスペクトルが
共鳴フリー（check_spectrum_harmonics_v1.py）であることは、単一周波数が全体を取る
実測（増幅期も飽和後も全系が単一の共巻き体）と整合する。

## 検定と結果（analyze_winding_rates_v1.py）

### (1) 直接巻数積算の検証（N=3, den=3）

隣接ステップの平均位相前進を逐次和した巻数レートは、増幅期で
**√2/3 回転/step に偏差 1.0×10⁻¹¹ で一致**（固有状態の予言どおり。方法の健全性確認）。
500歩の総巻数 119.72 回転。ロック後の1歩平均は 0.2159 回転/step だが、周期6軌道は
1歩単位では剛体でないため、この量は 3歩ストロボの 1/2 回転と単純に整合しない
（ロック後の巻数の正しい読みはストロボ枠で行う必要がある——未決着の注意点）。

### (2) 「時間=巻数」collapse 検定（全228走行）

増幅レートを「ステップあたり」と「巻数あたり」（巻数レート = |w_dom|/den 回転/step、
親が固有状態なので厳密）で比較した変動係数 CV:

| 系列 | n | steps/decade CV | turns/decade CV |
|---|---|---|---|
| 全体 | 228 | 0.585 | 0.750 |
| **den=124（流れ領域）** | 38 | **0.767** | **0.390（半減）** |
| den=N（ストロボ領域） | 38 | 0.478 | 0.517 |
| den=N±1,±2 | 152 | 0.566 | 0.617 |

**判定: 「時間=巻数」は流れ領域で強く支持され（散らばり半減、平均 0.68 回転/桁）、
ストロボ領域では機能しない。** これは仮説の破綻ではなく整合的な読みができる:
巻数時間は連続極限（流れ領域）の概念であり、Δτ≈2π/N のストロボ領域では
エイリアシングが巻数の読みを壊す。

## 未決着（次の精密化）

1. 流れ領域の残差散らばり（CV 0.39）は、正しい巻数が親モード w_dom でなく
   成長モードの振動数（または両者の差）である可能性を示唆——Floquet 定式化と合流する。
2. ロック後・遷移中の巻数の正しい読み（ストロボ枠での巻数、遷移での巻数欠損の有無）。
3. 共巻きブロック検出器（凝縮体判定器 v2）: 零閉塞＋剛体共回転の部分集合走査。
   証明書つき因数分解判定器（check_certified_factorization_v1.py）に共巻き条件を追加する形。
