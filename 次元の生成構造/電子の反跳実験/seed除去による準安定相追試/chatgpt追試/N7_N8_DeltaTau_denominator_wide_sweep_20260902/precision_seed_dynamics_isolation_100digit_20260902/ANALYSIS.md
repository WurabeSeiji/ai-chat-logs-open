## §14 の 10 問への回答

### 1. A は既存 float64 sweep を再現したか

再現した。onset は N=8: 157=157、N=7: 137=137 で完全一致。全 step の H⊥/H 相対差は
最大 4.2e-12（N=8）/ 4.5e-12（N=7）で約12桁一致。bitwise 同一ではなく、差は step 0 の
観測量計算から既に存在する（同一環境・同一入力での Accelerate BLAS のプロセス間 ulp
非決定性）。onset 一致と 1e-12 水準の一致をもって §2 の再現成立と判定し、続行した。

### 2. A/B の初期状態は exact binary64 lift により数学的に同一か。検証方法は

同一である。各成分（N=8: 56、N=7: 42 の実数）を `as_integer_ratio()` →
`mp.mpf(num)/mp.mpf(den)` で lift し、(a) `float(lifted) == 元の binary64` の全成分一致、
(b) `lifted == mp.mpf(x)` 直接変換との全成分一致、を確認した
（`lift_verification.json`、roundtrip 最大差 0.0）。

### 3. A と B の onset・growth rate・飽和はどの程度一致するか

- growth rate: γ_τ 相対差 4.0e-8（N=8）、1.3e-5（N=7）— 実質同一。
- onset: 両 N とも B が **+6 step**（157→163、137→143）。原因は fit 切片差
  Δa = 3.11（N=8, ln 単位）= 1.35 桁で、Δstep = Δa/γ_step = 6.4 step と定量的に一致。
  すなわち毎 step の float64 丸め注入は実効 seed を約 1.3 桁引き上げ、onset を
  6 step 早めるだけの二次的効果である。
- 飽和: 同一プラトー（N=8: 0.793922、N=7: 0.746032）。

### 4. B と C の初期 H⊥/H・closure・自己無撞着残差は何桁違うか

- 初期 H⊥/H: 両者とも自分の平面に対する 100 桁丸め床 ~1e-200 で同水準
  （seed は H⊥ ではなく状態の閉塞・自己無撞着からのずれに宿る）。
- global closure: B（lifted IC64）3.37e-17（N=8）/ 1.52e-16（N=7）に対し
  C は 6.08e-102 / 8.14e-102 — **約 85 桁**低い。
- 自己無撞着残差（H 固有残差）: C は 7.9e-102 / 7.7e-102（資格審査値）。
  B の初期状態は float64 親そのものなので ~1e-16 水準であり、同じく約 85 桁差。

### 5. B と C の onset 差は何 step / 何 τ か

N=8: 804 step（Δτ = 631.5）。N=7: 728 step（Δτ = 653.5）。
これは床の深さ差 ≈167 桁 ÷ 成長率 0.2101 桁/step（N=8）≈ 795 step、
≈166 桁 ÷ 0.2330 桁/step（N=7）≈ 713 step と、床離脱の形状の細部を除き整合する。

### 6. B と C の γ_τ は一致するか

一致する。N=8: 0.6159454990 vs 0.6159454900（相対差 1.5e-8）。
N=7: 0.5976399903 vs 0.5976392514（相対差 1.2e-6）。

### 7. C の seed 床から巨視的 onset まで、単一指数則で説明できる範囲は

床離脱（f⊥ ≈ 1e-180、N=8 で step 117 / N=7 で step 104）から onset 閾値 0.05 の直前まで、
約 **179 桁**にわたり単一指数則が成立する。深部窓（1e-160..1e-40）と共通窓（1e-20..1e-6）
の γ_step が相対差 2e-7（N=8）/ 5e-6（N=7）で一致し、両窓とも R² ≈ 1。
床領域（step 0〜約100、f⊥ ≈ 1e-200）のみ指数則の外にある。

### 8. 「seed」と「不安定性そのもの」を数値的に分離できたと言えるか

言える（本実験の N=7,8・D=N の範囲で）。分離の実体は次の2点である。
(1) 成長率 γ は演算精度（64bit/100桁）にも seed 深さ（1e-16 級/1e-102 級）にも
依存せず、A/B/C で最大 8 桁一致した — 指数不安定性は力学に内在する（Case 4）。
(2) 精度が決めるのは実効 seed の大きさだけであり、それが onset の位置を
Δstep = Δ(seed 桁数)/(γ_step/ln10) の形で平行移動する（問 3・5 の定量一致、図 P3/P6 で
onset 整列後に B と C の軌跡が重なることでも確認）。
判定ロジックでは Case 1（IC64 seed が主要発火源、発展中注入は二次的）かつ
Case 4（不安定性は力学側）に該当する。

### 9. N=7 replication は N=8 の結論を再現するか

再現する。A→B の onset 遅延 +6 step（両 N で同値）、γ の A/B/C 一致、C の床 1e-200 からの
単一指数成長と発火、onset 遅延の seed 桁数換算の整合 — すべて同型である。
唯一の相違は飽和プラトー: N=7 では A/B が 0.746032 に対し **C は 0.936508** に飽和した
（N=8 は A/B/C とも 0.793922）。onset までの線形段階は同一のまま、飽和後の到達枝だけが
異なる。数値観測として記録する（0.746032 は 47/63、0.936508 は 59/63 と 6 桁一致するが、
厳密な有理値かは未検証）。

### 10. 100桁にして初めて見えた数値的不安定性・solver 依存性・残差問題はあるか

新たな問題は観測されなかった。mpmath.eighe は self-test 残差 ~2e-100、実走行の
ノルム drift ≤ 8.5e-98（2000 step）、IC100 資格審査は全項目 ~1e-102 で合格。
100 桁側の f⊥ 床が 1e-200 = (1e-100)² に現れることは精度理論どおり。
一方、float64 側では A の bitwise 非再現（Accelerate のプロセス間 ulp 非決定性、問 1）が
今回の対照によって明確に記録された。

## 最重要判定（§16）への回答

**巨視化を始動する微小 seed は「初期 IC64 に既に含まれる誤差」が主である。**
時間発展中に毎 step 注入される float64 丸めは、実効 seed を約 1.3 桁引き上げ onset を
6 step 早めるだけの二次的寄与に留まる（A vs B）。
**そして seed を 100 桁級（closure ~1e-102）まで下げても、同じ growth rate
（γ_τ 一致 8 桁）を持つ指数不安定性が残り、onset が seed 桁数に比例して遅れるだけで
必ず発火する**（B vs C、N=7/8 で再現）。すなわち有限精度は seed の大きさを決めるが、
指数不安定性そのものは干渉保存力学の側に存在する。

表現上の注意: 上記は N=7,8・D=N・2000 step の数値観測であり、証明ではない。
onset=0.05 は巨視化閾値であり指数不安定性の開始時刻ではない。飽和は H⊥/H の飽和で
あり状態 z の固定点を意味しない。
