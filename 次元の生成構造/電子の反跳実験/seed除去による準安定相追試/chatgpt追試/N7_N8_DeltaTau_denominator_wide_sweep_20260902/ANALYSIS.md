# 分析（指図 §14 への回答）

作成日: 2026-09-02
データ源: `results/stageA_summary.csv`, `results/stageB_summary.csv`, 各 run の時系列 CSV。
以下、数値はすべて Stage B（同一 τ 窓、τ_max(N)=500·2π/N: N=7 で 448.8、N=8 で 392.7）から引用し、
Stage A は D の密な整数走査（局所構造検査）に使用した。観測と解釈は分けて書く。

## 問 1. τ 軸に直すと D ごとの曲線はどこまで重なるか

重ならない。onset_τ（f⊥=H⊥/H>0.05）は N=7 で D=2 の 125.7 から D=32 の 400.4 まで単調に増加し、
初期指数成長率 γ_τ も D=3 の 0.686 から D=48 の 0.119 まで単調に減少する（N=7、fit 窓
10⁻¹²≤f⊥≤10⁻⁴、全 fit R²>0.9999）。τ 再尺度化で消えるのは「step 数の見かけの差」だけであり、
成長率そのものが D に依存する。→ H0（単純な時間再尺度化）は本データでは成立しない。

## 問 2. D=124 は同一 τ でもフラットか

フラットではなく、成長が遅い。同一 τ 窓の終端で f⊥ = 1.36e-22（N=7、8858 step 走行）、
2.90e-23（N=8、7750 step 走行）であり、初期床 ~1e-30 から約 8 桁上昇している。
γ_τ の滑らかな D 依存（問 6）を D=124 に外挿すると γ_τ ≈ 0.81·7/124 ≈ 0.046（N=7）で、
onset までに τ ≈ 70/0.046 ≈ 1.5e3 を要する。これは今回の同一 τ 窓 448.8 の約 3.4 倍、
従来の 500 step 窓（τ = 500·2π/124 = 25.3）の約 60 倍である。
→ 従来観測の「124 フラット」は、(a) γ_τ が D/N とともに真に減少すること、
(b) 従来窓が τ で極端に短かったこと、の複合であり、成長ゼロではない。

## 問 3. D=124 は 96,112,128,160 と比べて異常か

異常なし。同一 τ 窓終端の f⊥（N=7）: D=96: 1.73e-20 → 112: 6.68e-22 → **124: 1.36e-22** →
128: 5.01e-23 → 160: 2.20e-23。単調減少列の途中にあり、内挿トレンドから外れない。
N=8 では D≥112 で全て 1e-23 前後の床レベル揺らぎ内。機械的異常検出
（Stage A ±2 近傍中央値から 20% 超逸脱、および 124 vs {96,112,128,160} 範囲外判定）は 0 件。
→ H3（124 固有性）は棄却。124 は「N から遠い D」の一般的挙動に完全に埋もれる。

## 問 4. N=7 と N=8 は D/N 軸で重なるか

D/N ≳ 0.9 で重なる。同一 D/N での比較:
- D/N=1（N7 D=7 / N8 D=8）: onset_τ 122.97 / 123.31（差 0.3%）、γ_τ 0.598 / 0.616（差 3.0%）
- D/N=2（N7 D=14 / N8 D=16）: onset_τ 189.8 / 194.4（差 2.4%）、γ_τ 0.3742 / 0.3769（差 0.7%）
- D/N=4（N7 D=28 / N8 D=32）: onset_τ 366.4 / 358.1（差 2.3%）、γ_τ 0.20066 / 0.20041（差 0.1%）

D/N < 0.75 では分離する: γ_τ は N=7 で最大 0.700（D=4, D/N=0.57）、
N=8 で最大 0.750（D=4, D/N=0.50）と、ピーク高さ・位置とも N で異なる（fig04）。

## 問 5. D/N=1 に局所特徴は存在するか

存在しない。onset_τ(D) は D/N≈0.5 付近に幅広い極小（N=7: D=4 で 108.4、N=8: D=4 で 102.1）を
持ち、D/N=1 は単調増加領域の途中の点である。γ_τ・飽和値にも D/N=1 での屈曲・不連続はない。
Stage A の全整数 D 走査（2..256）でも局所異常フラグは 0 件。→ H2（D=N 特異）は棄却。

## 問 6. γ_τ は D に依存するか、D/N に依存するか、ほぼ一定か

一定ではない。大 D/N 側では積 γ_τ·D/N が N=7: 0.816（D=48）、N=8: 0.811（D=48）に収束し、
D=8→48 で単調に漸近する（N=7: D=8 で 4.46/7=0.64、D=24 で 5.57/7=0.80、D=48 で 0.816）。
すなわち観測範囲では

  γ_τ ≈ 0.81 · N/D  （D/N ≳ 3）

であり、支配変数は D/N である。等価表現として γ_step = γ_τ·2π/D ≈ 5.1·N/D²、
つまり 1 step あたりの成長は Δτ=2π/D に対して 2 次で減少する（数値観測。
γ_τ = γ_step·D/2π の恒等式は全 run で相対差 <1e-3 のクロスチェック済み）。
小 D/N 側（<0.75）はこのスケーリングから外れ、N ごとのピーク構造を持つ（問 4）。

## 問 7. 飽和後 Hperp/H の平均・範囲は D で変わるか

変わる。ただし単調ではない。N=7 の tail 20% 平均は D=5..14 の広い範囲で共通値
0.7460317（付記: 47/63 = 0.746031746... と 8〜9 桁一致する。厳密に 47/63 かは未検証の数値観測）
を取り、D=15,17,23 では 0.9999 前後、D=25..27 では 0.56〜0.77 と分岐する。
N=8 は D=5..21 の多くで 0.79392、他で 0.79〜0.97。
tail 窓が onset より前に始まる run（N=7: D≥28、N=8: D≥28 の各一部以降）は規則どおり NA とし、
飽和統計には追加走行が必要である。tail 窓では closure・PR/M も変動しており
（例: N=7 D=7 の closure_tail_std ~ 0.1 台）、H⊥/H の飽和は状態 z の固定点を意味しない。

## 問 8. N=7 と N=8 の差は奇偶差と呼べるか

現データでは判定不能。差が現れるのは小 D/N 域の γ_τ ピーク（0.700 vs 0.750）と onset 極小値
（108.4 vs 102.1）で、いずれも量的差であり質的分岐ではない。奇数 N（距離クラス）と
偶数 N（1-factor）という構成の差に帰すには、N=5,6,9,10 以上の系列で同じ向きの差が
再現することの確認が必要である。1 ペアでは N 個別差と区別できない。

## 問 9. χ 軸にすると N=7/8 の差は縮小するか

固定 D の比較では縮小する。γ を χ=2r²(N−2)τ 軸に換算（γ_χ = γ_τ/(2r²(N−2))）すると、
D=4: N=7 で 1.061、N=8 で 1.065（差 0.4%。τ 軸では γ_τ 差 7.2%）。
ただし D=7: 0.907 vs 0.934（差 3.0%）、D=8: 0.845 vs 0.875（差 3.6%）であり、
完全な collapse ではない（fig06）。大 D/N 域の collapse は D/N 軸（問 4・6）の方が良い。

## 問 10. 現データだけで「D=N は自然な時間刻み」と言えるか

言えない。D=N に局所特徴は検出されず（問 5）、観測されたスケーリングは連続変数 D/N の
滑らかな関数である。D=N はその曲線上の一点にすぎない。不足しているのは:
(1) N を広く振った走査（D/N スケーリング γ_τ·D/N→0.81 の普遍性と、奇偶判別）、
(2) 大 D/N 側で onset まで届く長時間走行（外挿 γ_τ ≈ 0.81N/D の直接検証、
    特に D=124 を τ≈1.5e3 まで）、
(3) γ_τ·D/N ≈ 0.81 という値の導出（現状は数値観測であり理論値ではない）。

## 仮説判定のまとめ

- H0（単純な時間再尺度化）: 棄却。γ_τ 自体が D/N に依存する（問 1・6）。
- H1（D/N 支配）: 支持。D/N ≳ 0.9 で N=7/8 が onset_τ・γ_τ とも重なる（問 4・6）。
- H2（D=N 特異／準特異）: 棄却。D/N=1 に局所特徴なし（問 5）。
- H3（124 固有性）: 棄却。近傍 D と同一トレンド上（問 2・3）。

## 最重要判定（指図 §16）への回答

D=124 がフラットだった理由は、124 自身の特殊性ではない。第一に γ_τ ≈ 0.81·N/D により
D/N が大きいほど τ あたりの成長自体が遅く、第二に従来の 500 step 窓は τ=25.3 しかなく
onset 必要時間 τ≈1.5e3（N=7 外挿）の約 1/60 だった。すなわち「Δτ が小さく観測窓が短すぎた」が
主因であり、さらに「D を大きくすると τ あたりの成長率も真に下がる」という
時間再尺度化では消えない D/N 依存が重なっている。一方、D=N に固有の力学的構造
（ピーク・谷・屈曲・不連続）は、全整数 D 走査でも同一 τ 窓比較でも検出されなかった。

表現上の注意（指図 §14）: 上記の onset=0.05 は巨視化閾値であり指数不安定性の開始時刻では
ない。飽和は H⊥/H の飽和であり z の固定点を意味しない。γ_τ·D/N ≈ 0.81 は観測値であり、
導出・証明はされていない。
