# 復元プログラム（patched）を影響実験に適用した再検証

**作成日:** 2026-08-28　**入力:** ChatGPT 復元パッケージに最小パッチ（`results/patch_reconstruction.diff`、4 hunk：B1 に `--trajectory-csv`（各 root 自身の `N5_phase_by_edge_5000steps.csv` から軌道を読む、engine 再実行なし）、B5 rebuild に「N5／N14 の閉包候補が無い軌道ではスキップ」の分岐）。B1' は original の `phase_by_edge` から original の B-1 表 7 本を 10⁻¹⁶ で再現することを確認済（`results/b1prime_check/`）。
**適用先（修正の影響を受ける実験）:** 生成プログラム未同梱のため「原本データのまま」だった項目を持つ 3 root：
- `論文v1_全再現テスト_20260828/rerun/`（原本プログラムをこの計算機で再実行、旧力学）
- `論文v1_全プログラム修正版_20260828/fixed_baseline/`（位相のみ K・線形回転・正規化なし）
- `論文v1_全プログラム修正版_20260828/fixed/`（振幅込み K＝修正後の力学）
各 root で B1'→copy_A→B2→B3→B4→B5(MITM＋rebuild)→partial 再実行→B7→followup analyze を実行（`apply_reconstruction_to_roots.sh`、ログ `results/logs_apply_*/`）。数値は `results/affected_experiments_comparison.txt`。

## 結果（original / rerun / fixed_baseline / fixed）

### N=5 の 3+3+2+2 秩序化（記事図 7・L154、論文 §22.2）
| root | 4群誤差 < 10⁻⁴ 到達 | < 10⁻⁸ 到達 | step 5000 の群位相 |
|---|---|---|---|
| original | 2627 | 4923 | ±0.642/−0.358π ×3、+0.697/−0.303π ×2（符号対が π 離れる） |
| rerun（同じ旧力学・この計算機） | 未到達（< 10⁻² が 1893 で最後） | 未到達 | ±0.5π 付近に散る（群内ずれ 10⁻²π） |
| fixed_baseline | 未到達（< 0.1 が 944） | 未到達 | −0.692/+0.321π ×3、+0.315/−0.667π ×2 |
| fixed（修正後） | **一度も 0.1 未満にならない** | — | 群ごとに |z|² が 0.059〜0.136 と不均一、B± が同位相（群構造なし） |

### N=5 非自明 2 辺閉包（論文 §22.7 の 13 個・12 通り）
| root | hits < 10⁻⁶（非自明） | 最良残差 | exact cover |
|---|---|---|---|
| original | 59（54） | 1.88×10⁻¹⁰ | 12 通り |
| rerun | **0（0）** | なし（最良 1.5×10⁻⁴） | 0 |
| fixed_baseline | **59（54）** | 1.42×10⁻¹⁰ | **12 通り** |
| fixed | 0（0） | なし（最良 0.42） | 0 |

→ 13/12 は**位相のみ K の力学では別の親・別の計算機（fixed_baseline）でも再現する**構造だが、同じ旧力学でも rerun のように 5000 step 時点で秩序化が 10⁻² 止まりの軌道では現れない。すなわち「旧力学の到達構造としては実在するが、5000 step で到達するかは軌道依存」。修正後の力学（fixed）では群構造も閉包も現れない。

### スペクトルエントロピー（記事図 6）
| root | S/lnM final | min | 0.999999 到達 |
|---|---|---|---|
| original | 1.000000 | 0.9732 | 1439 |
| rerun | 1.000000 | 0.9732 | 1228 |

以前の三者比較で「三者同一」だった値は原本データの流用によるもので、今回の再生成で修正版の真の値（不均等分配）が得られた。

### N16 位相構造（論文 §20）・N3/N4（§21）
- N16：original／rerun／fixed_baseline は同型（triplet クラスタ 64／62／62、gap std 0.015）。fixed は別構造（クラスタ 84、gap std 0.0076）。
- N3 の 1/3 収束：旧力学 3 root は final 誤差 0.0134（同型）。fixed は 0.333＝収束せず。N4 対辺位相順序は 4 root とも gap = 0.5/0.5（構造は保持）。

## 判定
1. 復元プログラムは（パッチ 4 hunk 込みで）3 root すべてで完走し、以前「原本データのまま」だった B 群の表・図が各 root 自身の力学の値に置き換わった。以前の三者比較・差異分析 md の該当箇所（N5 4 群、entropy、部分閉包 N5、N16 位相構造）はこの文書の値で上書きして読むこと。
2. 論文 v1・記事の N=5 主張（3+3+2+2、2627/4923、13 個・12 通り、S/lnM = 1）は旧力学の構造としては fixed_baseline で再現されるが、同一力学でも軌道によっては 5000 step で到達しない。修正後の力学では現れない。
3. 復元コードの残課題：B6 の焼きなまし（historical steps/seed 未回収、推測で埋めない方針は正しい）、`bits/stdc++.h` 依存。
