# 実験結果——最新 N=5 プログラムの `make_parent` を振幅込み K で自己無撞着にした版（アボート）

**作成日:** 2026-08-28　**ベース:** `N5_linear124_all3fix_decisions_applied_20260828`（最新版に判断 1〜6 を適用、力学は最新版と 0.0 差）
**変更:** `program/original_engine.py` の `make_parent` のみ（`results/diff_engine_vs_decisions_applied.patch`、1 hunk）。`run_amplitude_only_fix.py` は無変更（diff なし）。

## 変更内容（make_parent）

- 自己無撞着条件を実際の相互作用で閉じる：K_amp(v) = Im(v̄ᵢvⱼ)（隣接辺）に対して K_amp(v)·v = iσ_max·v。
- 反復：v → K_amp(v) の最大固有モード u（縮退時は現在の v と重なり最大のもの、大域位相を v に整合）→ v ← (1−β)v + βu、β=0.5。位相も振幅も未知数。
- 振幅の正規化なし（固定点は c·v の族、スケールは固有値ソルバの返す ‖u‖=1 をそのまま使用、明示的な正規化行は無い）。
- 収束判定はスケール不変残差 ‖iKv − μv‖/‖v‖ < 1e-10。iters=2000、restarts=20。全リスタート失敗で RuntimeError → 実験は走らせない。

## 結果：アボート（自己無撞着解が得られず）

20 リスタート全てで残差が **1.33×10⁻¹** に停滞（`results/run_progress.log`）。反復は発散も振動もせず、リスタートによらず同じ残差の状態に収束する——固有モードではない共通のアトラクタに落ちる。RuntimeError により実験は未実行（data/・figures/ は空）。

```
make_parent: 振幅込み K に対する自己無撞着解が得られず（restarts=20, iters=2000, tol=1e-10）: r1:1.33e-01, …, r20:1.33e-01
```

## 解釈（事実のみ）

- この反復法（最大固有モードへの単純混合）では N=5 の振幅込み K に対する自己無撞着状態は見つからない。
- 20 回とも同じ残差に落ちるので、反復の不動点（v = (1−β)v + βu ⇔ u = v）が存在せず、代わりに残差 0.133 の状態に引き込まれている。これは「解が存在しない」ことの証明ではなく、「この解法では見つからない」ことを示す。
- 位相のみ K の親を振幅込み K で評価した残差は 0.050（前回測定）。反復後の 0.133 はそれより悪い。
