# 時計依存性の検討結果——σ=N−1 と急拡大は時計に依存しないが、第2段階（秩序化）の速さは γ に比例する

**作成日:** 2026-08-27〜28　**発端:** 「144 はサンプリング格子であり、エイリアスと Cayley の frequency warping が入る」という指摘（ChatGPT との対話）。
**方法:** 論文 v6 と同一エンジン（無変更）、γ = tan(π/L) を L = 144, 288, 576, 1152 と変えて**自然時間 s = 2γ·step を揃えて**走らせる。さらに Cayley 更新を厳密な指数写像 e^{2γK}（同じ状態依存 K）に置き換えて比較。seed は公開系列と同じ（40260722 + 1000N）。

---

## 0. 指摘の整理（何が正しく、何が違うか）

- **正しい**：θ_d = 2 arctan(γσ) ≠ 2γσ（bilinear の frequency warping）。step 数で数えた周期（例：36.0855 step/周）は時計の量で、物理的主張には使えない。局在波で高調波を積むなら L は σ_max に対して十分大きくなければならない。
- **違う**：「σ ～ σ + mL のエイリアスで高調波が低調波へ折り返す」。Cayley 写像は σ ∈ ℝ を (−π, π) へ**単調・一対一**に写すので、生成子の動力学で異なる σ が同一化されることはない。折り返しが起きるのは z² の位相差を mod 2π で**読む**ときで、条件は θ_d > π/2、すなわち σ > 1/γ ≈ 45.8（L=144）。ChatGPT の「36」は線形近似値。
- **36.0855 の正体**：指数写像なら 1 周は L/σ = 144/4 = **36 step ちょうど**。0.0855 は warping。よって「U^n = I が step 単位で成り立つか」は L と σ の整除性の問題（σ | L のとき n = L/σ）で、時計の性質。時計に依らない主張は σ ∈ ℤ（`../tau_direction_sigma_N_minus_1/`）。

- 急拡大（onset）は s ≈ 9.8（N=5）、7.6（N=8）へ**収束**する：物理。
- σ² のロックと等分配の完成時刻は **L に比例して遅れる**（N=8 の等分配：40 → 67 → 119 → 218、比 1.67, 1.78, 1.83 → 2 に漸近）。自然時間あたりの秩序化速度 ∝ γ ∝ 1/L。
- 最終値は全 L で σ² = (N−1)²、等分配誤差 ~1e-14 に到達する（十分待てば同じ状態に落ちる）。

## 3. 決め手：体積収縮率は γ → 0 で消える（`floquet_vs_L.py`）

親相対平衡まわりの rotating-frame Jacobian を L ごとに計算し、自然時間あたりに換算した。

- **λ₁/s は収束**（N=5: 1.98 → 2.14、N=8: 2.63 → 3.12）：線形不安定性は物理。
- **Σ ln|μ| / s は L を倍にするごとに正確に半減**（−1.96 → −0.98 → −0.49 → −0.24）：収縮率 ∝ γ。step あたりでは ∝ γ² で、これは一次分割法の局所誤差の次数そのもの。**連続極限では体積収縮は消える**。指数写像でも同じ値なので、原因は Cayley ではなく生成子の凍結。
- 中立モードの角の整数倍性（{0,1,2}×Δφ）は全 L・両積分器で不変：物理。

## 4. 結論と論文への影響

$$
\boxed{
\begin{array}{ll}
\text{時計に依存しない（物理）:} & \text{onset 時刻・成長率 }\lambda_1\text{・rank 選択・}\sigma_{\rm final}=N-1\text{・中立 Floquet 角の整数倍性・最終状態そのもの}\\
\text{時計に依存する（数値）:} & \text{step 単位の周期・}\Sigma\ln|\mu|<0\text{ の体積収縮・秩序化（等分配・位相クラス形成）の速さ}
\end{array}}
$$

- 論文 v6 §18–19（スペクトルエントロピーの上昇、四群への秩序化が数千 step かかること）と §26.2 の「局所体積収縮＝アトラクタ的解釈と整合」は、**離散化が駆動する数値散逸**として読み直す必要がある。連続力学は（少なくとも親近傍では）体積を保存し、秩序化は γ→0 で無限に遅くなる。
- ただし最終状態（等モジュラー・ヌル単体、σ=N−1）自体は L に依らない。連続力学において「到達する」かどうかは別問題（到達時間 → ∞）。つまり準安定状態は連続力学の**中立安定な多様体**であり、数値散逸がそこへ落とす、という描像。
- 論文 v6 §27 に「第2段階の γ 依存性」を追加し、v2 で §18–19・§26.2 を訂正すべき。§16 の厳密保存（ノルム・Z^TZ）は影響を受けない。
- 局在波（奇数倍音）実験の設計条件：L ≫ 4·h_max·(N−1) は妥当だが、根拠は「エイリアス」ではなく「分割誤差 ∝ γ σ_max」と「z² 読出しの折返し σ < 1/γ」。
