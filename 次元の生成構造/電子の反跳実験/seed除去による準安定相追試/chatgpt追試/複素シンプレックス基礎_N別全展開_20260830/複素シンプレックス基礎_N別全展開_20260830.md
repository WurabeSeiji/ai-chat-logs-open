## 0.1 用語の定義（この文書内で使うもの）

- **波**：このテキストでは「波」を **1 個の複素数 z = a + b·i** で表す（a=実部、b=虚部。大きさ |z| = √(a²+b²)、位相 θ = 角度）。空間に広がる波形や、時間の関数として振動する量を指すのでは**ない**——大きさと位相を持ち、発展（下記）のもとで回転する複素数そのものを、このテキストでは波と呼ぶ。波は 2 つの点の組（関係）ごとに 1 個ある。そして複素シンプレックス（下記）では、**この波（複素数）が辺や対角線の長さを表現する**（2 乗距離 d² = z²）。
- **発展**：このテキストでは、一般的な「時間発展」の意味では**なく**、公理 3 の規則——行列 K の指示どおり全ての波を少しずつ回す——を 1 刻みとして、**それを繰り返し適用すること**の意味で使う。刻みの通し番号を τ と書くが、**τ は時間ではない**（時間に相当する量は、状態自身の位相の進みとして別に定義されるべきもので、幾何を扱う本文書では踏み込まない）。
- **状態ベクトル v**：M 本の波の値を 1 列に並べたもの。N=3 なら v = (z(0,1), z(0,2), z(1,2))。
- **ノルム ‖v‖**：状態ベクトルの大きさ。‖v‖² = 各波の (a²+b²) の総和。系全体の大きさを表す（力学で厳密に保存される量）。
- **2 乗距離 d²**：その組の「距離の 2 乗」を d² = z² = (a²−b²) + (2ab)i と定める（複素数）。
- **シンプレックス（単体）**：N 個の頂点をすべて互いに結んだ図形。N=3 なら三角形、N=4 なら四面体、N=5 以上はその高次元版。形は「全ての 2 点間の距離」を与えれば決まる。
- **複素シンプレックス**：シンプレックスの「距離の 2 乗」を、実数から複素数に広げたもの。すなわち **N 個の頂点と、全ての 2 点組に与えられた複素数 d²_ij の組**。本文書では d²_ij = z_ij²、つまり**各組の波の 2 乗を、その組の 2 乗距離として読む**。波の側面（大きさと位相を持ち回転する）と幾何の側面（距離と形）は、同じ z の 2 つの読み方である。
- **閉塞**：Σz² = 0（全組の 2 乗距離の総和が零）。
- **局所閉塞**：1 つの頂点に集まる組だけで Σz² = 0。
- **B 行列**：B = −½ J D² J（J = I − 11ᵀ/N、D² は d² を並べた N×N 行列）。実の距離幾何の標準手順（Schoenberg）の複素化。
- **Takagi 値 σ_k・軸スケール r_k=√σ_k**：B の特異値と、そこから作る「配置が方向 k にどれだけ広がっているかの幅」。
- **埋め込み座標 x_i**：(x_i−x_j)·(x_i−x_j) = d²_ij を厳密に満たす頂点座標（Autonne–Takagi 分解 B = Σσ_k v_k v_kᵀ から x_ik = √σ_k v_k[i]）。
- **rank**：非零の σ_k の本数＝配置が張る複素次元。上限は N−1（中心化で 1 消える）。
- **相互作用（行列 K）**：この系では、波どうしが互いを回し合う。波 e が波 f から受ける押しの強さを、点を共有する組（例：(0,1) と (0,2) は点 0 を共有）についてだけ
　　K_ef = Im(z̄_e · z_f) = a_e·b_f − b_e·a_f
　と定める（共有しない組は 0。N=3 では全 3 本が互いに点を共有する）。右辺は 2 つの複素数が張る平行四辺形の符号付き面積で、**波 e と f の位相が直交（90° 差）のとき最強、平行（0° か 180° 差）のとき零**。K をこの数を並べた M×M の実行列とすると、力学は「各刻みで全部の波を K の指示どおり少しずつ回す」ことになる。
- **回転速度 μ と自己無撞着状態**：一般の状態では、波ごとに受ける押しがバラバラなので、時間とともに形が変わる。ところが特別な状態では、**全部の波が受ける押しがちょうど「全体を同じ速さで一様に回せ」という指示に一致**する。式で書くと、ある 1 個の実数 μ（全体の回転速度）が存在して
　　i·K·v = μ·v　（v は状態ベクトル、左辺＝押しの効果、右辺＝一様回転）
　が成り立つ。これを**自己無撞着状態**と呼ぶ（μ ≠ 0 のものだけを指す。μ = 0 は回っていない）。自己無撞着状態は力学のもとで**形を一切変えず、全体が速さ μ で回転し続ける**。実験ではこれを初期状態に用いる（実験シリーズ内の略称は「親」だが、本文書では使わない）。
- **等モジュラー**：全ての波の大きさ |z| が等しいこと。本文書の各 N の具体例は「等モジュラーな自己無撞着状態」である。
- **和則**：等モジュラーな自己無撞着状態について、方程式 i·K·v = μ·v を波 1 本ぶんの成分で書き下すと現れる 2 つの条件の総称。φ をその波と隣接する波（点を共有する波）との位相差として
　　実部条件：Σ_隣接 sin²φ = −μ/r²　　虚部条件：Σ_隣接 sin 2φ = 0
　（和は隣接する波すべてにわたる。どの波についても同じ形で成り立つ。）導出の全展開は §2.2 の導出 3。

## 0.2 何が公理で、何が選択・規約で、何が定理か

この文書に現れる主張は次の 4 種類に必ず分類される。各節でもどれに当たるかを明記する。

**公理（この系の定義。仮定であり、証明しない）**

- **公理 1（波）**：N 個の点があり、その全ての 2 点組（M = N(N−1)/2 組）に複素数の波 z = a + b·i が 1 個ずつある。
- **公理 2（相互作用）**：点を共有する組どうしだけが、強さ K_ef = Im(z̄_e·z_f)（§0.1）で互いを回し合う。
- **公理 3（発展）**：各刻みで、全ての波が行列 K の指示どおりに少しずつ回る。（この規則から ‖v‖² が厳密に保存されることは定理として従う。）

**選択（公理ではない。無数にある状態の中から、この文書が調べる対象を絞る条件）**

- **自己無撞着**：i·K·v = μ·v（μ ≠ 0）を満たす状態だけを初期状態に選ぶ。これは方程式であり、**解が存在するかどうかは自明でない**——各 N の節で解を実際に構成して見せる（そこは定理側の仕事）。
- **等モジュラー**：さらに、全ての波の大きさ |z| が等しい解だけを選ぶ。
- **等モジュラー自己無撞着状態**＝両方を満たす状態。本文書の各 N の具体例はすべてこれ（等しくない解——星型など——は対象外と明記した上で除外）。

**規約（どちらに決めても物理が変わらない取り決め）**

- **スケールの規約**：この系にはスケール対称性がある——全波を一斉に λ 倍しても、K の各成分が λ² 倍になるだけで、状態の形（大きさの比・位相差）と発展の軌跡は変わらない（回転が λ² 倍速く進むだけ）。よって共通の大きさ r の値は規約で決める。本文書は r² = 1/15。
- **全体回転の規約**：全波の位相を一斉にずらしても何も変わらないので、基準の組を θ = 0° に置く。

**定理（公理＋選択から計算だけで導かれるもの。各節で全展開する）**

- ‖v‖² の保存（公理 2 の K が実反対称——K_ef = −K_fe——であることの帰結）。
- **和則**（実部条件 Σsin²φ = −μ/r²、虚部条件 Σsin2φ = 0）：自己無撞着の方程式の成分展開（§2.2 導出 3）。
- **閉塞 Σz² = 0**：自己無撞着（μ≠0）だけから従う。証明（3 行）：K は実行列なので、i·K·v = μ·v の両辺の複素共役を取ると i·K·v̄ = −μ·v̄。つまり v̄ も解で、回転速度は −μ。μ ≠ 0 なら v と v̄ は異なる速さの固有方向だから直交し、その内積 v̄†v… 正確には (v̄, v) の内積 = Σ z_e² = 0。∎（各 N の節では数値でも確認する。）
- 位相間隔の一意性（N=3 の 60° など）、μ/r² の値、B の rank と形——各 N の節の計算結果。

## 1. 数え上げの方法（一般式のみ。各 N の数値はそれぞれの N の節に置く）

N 個の頂点に対して：

- **波（関係）の総数** M = N(N−1)/2 —— 2 点の組の数。
- **辺と対角線の区別**：頂点を円周に並べたとき、隣どうしを結ぶ組を「辺」（N 本）、それ以外を「対角線」（M − N 本）と呼ぶ。これは絵を描くための呼び分けにすぎず、**複素シンプレックスとしては全ての組が対等に波を持つ**（対角線にも波がある）。
- **面（三角形）の数** = C(N,3) = N(N−1)(N−2)/6 —— 3 頂点の選び方の数。
- **位相の種類の数・d² の角度の種類の数・rank**：これらは一般式ではなく、各 N の状態を構成して初めて決まる量。各 N の節の数え上げ小節に記載し、全 N を終えた最終節で一覧表にまとめる。

### 2.0 N=3 の複素シンプレックスの定義

§0.1 の一般定義を N=3 で具体化する。

- 頂点：3 個。番号 {0, 1, 2}。

### 2.2 波の値 (a, b) の一覧と、その導出

まず結果の一覧。N=3 の等モジュラー自己無撞着状態（§0 で定義。以下この節では単に「この状態」と書く）は、次の 3 個の複素数で全てが決まる：

| 組 | a（実部） | b（虚部） | \|z\| | θ |
|---|---|---|---|---|

| (1,2) | +0.129099445 | +0.223606798 | 0.258198890 | 60° |

この値は選んだのではなく、以下の 4 段でほぼ一意に**導出される**。

**導出 1：3 本の波の大きさを等しく取ること（等モジュラー）。** 「大きさ」とは各波の |z| = √(a²+b²)（§0）のこと。自己無撞着状態（§0：i·K·v = μ·v を満たし、形を変えず一様回転する状態）は 1 種類ではない。同じ方程式を満たす状態の中には、3 本の波の大きさ |z(0,1)|、|z(0,2)|、|z(1,2)| が互いに異なるものも存在する。本文書では、その中から**3 本の大きさがすべて等しいもの（これを等モジュラーと呼ぶ、§0）だけを選んで**調べる。等しいその共通の値を r と書く。つまりこの段は計算による導出ではなく、§0.2 の「選択」に当たる。

**導出 2：記号 r・v・‖v‖ の定義と、r の値の設定。** 記号を定める：

- **r**：導出 1 で共通とした、全ての波の大きさ。|z(0,1)| = |z(0,2)| = |z(1,2)| = r。
- **v**：3 本の波の値を 1 列に並べた状態ベクトル v = (z(0,1), z(0,2), z(1,2))（§0）。
- **‖v‖**：その大きさ。定義どおり展開すると
　‖v‖² = |z(0,1)|² + |z(0,2)|² + |z(1,2)|² = (a²+b²)の総和 = r² + r² + r² = **3r²**

この系はスケール対称（§0.2 の規約の項）なので、**r の値そのものは物理を決めず、1 個だけ自由に選んでよい定数**である（§0.2 の「規約」）。本文書では数値例として

　r² = 1/15 = 0.066666667、 r = 1/√15 = **0.258198890**、 したがって ‖v‖² = 3r² = 1/5、‖v‖ = 0.447213595

を採る。この選び方だと以下の全ての量が簡単な分数になる（例：μ = −1/10）。

**導出 3：位相の間隔が 60° になること（ここが本体）。** 3 本の波の位相を θ₁, θ₂, θ₃ と書く（それぞれ組 (0,1), (0,2), (1,2) の θ）。自己無撞着の方程式 i·K·v = μ·v（§0）を、等モジュラーの場合に成分で全展開する。

まず K の成分（§0 の定義）。波 e = r·e^{iθ_e}、波 f = r·e^{iθ_f} なら

　K_ef = Im(z̄_e·z_f) = Im( r e^{−iθ_e} · r e^{iθ_f} ) = r²·sin(θ_f − θ_e)

方程式の左辺の第 e 成分は、e と点を共有する波 f にわたる和で

　(i·K·v)_e = i·Σ_f K_ef·z_f = i·Σ_f r² sin(θ_f−θ_e)·r e^{iθ_f}

これが右辺 μ·z_e = μ·r e^{iθ_e} に等しい。両辺を r e^{iθ_e} で割り、位相差 φ_f = θ_f − θ_e とおくと

　i·r²·Σ_f sinφ_f·e^{iφ_f} = μ

左辺を e^{iφ} = cosφ + i·sinφ で展開：

　i·r²·Σ_f ( sinφ_f cosφ_f + i·sin²φ_f ) = r²·( −Σ_f sin²φ_f ) + i·r²·( Σ_f sinφ_f cosφ_f )

μ は実数だから、**実部と虚部が別々の条件になる**：

　実部：Σ_f sin²φ_f = −μ/r² （どの辺 e でも同じ値。「和則・実部条件」と呼ぶ）
　虚部：Σ_f sinφ_f cosφ_f = 0、すなわち Σ_f sin 2φ_f = 0 （「和則・虚部条件」。sin2φ = 2 sinφ cosφ を使った）

N=3 では全 3 組が互いに点を共有するので、各辺の「隣接」は残り 2 本。u = 2(θ₂−θ₁)、w = 2(θ₃−θ₂) とおいて虚部条件を 3 辺分書くと：

　辺1: sin u + sin(u+w) = 0
　辺2: −sin u + sin w = 0
　辺3: −sin w − sin(u+w) = 0

辺2 より sin w = sin u。対称解 w = u を取ると辺1 は sin u + sin 2u = 0、すなわち

　sin u (1 + 2cos u) = 0 → **cos u = −1/2**（sin u = 0 は全同位相＝凍った μ=0 の自明解で、閉塞も破れるので除外）

よって u = ±120°、位相差 θ₂−θ₁ = θ₃−θ₂ = **±60°**。実部条件は自動的に揃う：どの辺も Σsin²φ = sin²60° + sin²120° = 3/4 + 3/4 = 3/2（→ μ/r² = −3/2）。つまり **60° 間隔は方程式の解**であり、鏡映（±）と組のラベル替え・全体回転を除いて一意である。

**導出 4：基準（全体回転）の固定。** 全波を一斉に回す自由度は物理に効かない（大きさ・位相差・d² の角度差すべて不変）。§0.2 の全体回転の規約により、組 (0,2) を θ=0° に置く。以上で θ = 0°, 60°, 120°、そして

　a = r·cosθ、b = r·sinθ

から冒頭の一覧が出る。検算（各行）：

- (0,2)：a = r×cos0° = 0.258198890×1 = +0.258198890、b = r×sin0° = 0
- (1,2)：a = 0.258198890×(1/2) = +0.129099445、b = 0.258198890×(√3/2 = 0.866025404) = +0.223606798
- (0,1)：a = 0.258198890×(−1/2) = −0.129099445、b = +0.223606798
- どの行も a²+b² = 0.066666667、|z| = √0.066666667 = 0.258198890 ✓

### 2.5 閉塞の判定（N=3）

**前提。** N=3 の複素シンプレックスの定義は §2.0。閉塞の 2 つの定義（§0.1）を N=3 の記号で書くと：

- **閉塞（大域）**＝ 3 つ全部の和が零：d²(0,1) + d²(0,2) + d²(1,2) = 0
- **局所閉塞（頂点 i の）**＝ 頂点 i を含む組だけの和が零。たとえば頂点 0 なら d²(0,1) + d²(0,2) = 0

どちらも**公理でも仮定でもない**。状態が与えられたら計算して零かどうかを判定する**導出量**である（§0.2）。大域閉塞は、自己無撞着（μ≠0）から**必ず**従う【定理。証明は §0.2 の 3 行】。局所閉塞には、そのような一般保証は**ない**。

**N=3 の判定。**

- 局所閉塞：**成り立たない**【定理】。しかもこの状態に限らず、N=3 では零でない波で全頂点の局所閉塞を満たすことが不可能である。証明：d₁ = d²(0,1)、d₂ = d²(0,2)、d₃ = d²(1,2) とおく。3 頂点の局所閉塞は d₁+d₂ = 0、d₁+d₃ = 0、d₂+d₃ = 0。第 1 式から第 2 式を引くと d₂ = d₃、同様に d₁ = d₂ = d₃。これを第 1 式に入れると 2d₁ = 0、よって d₁ = d₂ = d₃ = 0、すなわち全ての波が零。∎

### 4.6 補足：N=5 だけの特別な性質——実の擬ユークリッド空間に置ける

位相が 0° と 90° の 2 種類しかないため、d² = z² は +r²（辺の 5 組）と −r²（対角線の 5 組）の**実数**になる。距離の 2 乗が実数なら、複素空間を使わずに**実の空間で符号だけ混ぜた幾何**（擬ユークリッド空間）に置ける。実測（機械精度）：

- 埋め込み先は空間的方向 2 本＋時間的方向 2 本の 4 次元空間 R^{2,2}（B が実行列になり、固有値が +2 個・−2 個・0 が 1 個）。
- 5 頂点の座標は「2 枚の円」に載る：空間的 2 平面では角度 144°×j（対角線＝五角星の回り方）、時間的 2 平面では角度 72°×j（辺＝五角形の回り方）、**半径は同じ**。これはユークリッド 4 次元の正五胞体（4 次元の正単体）の標準座標そのもので、違いは片方の円が時間的であることだけ。
- 全 5 頂点で x·x = 0（光円錐上）。この光円錐は 4 次元空間の中の 3 次元の面で、その光的方向の全体は球面ではなく**トーラス**（2 つの円の積）。5 頂点は共通半径のトーラス上、時間円 1 周につき空間円 2 周の**巻き数 1:2 の 1 本の閉曲線**の上に等間隔で並ぶ。
- 辺の組（+r²）は空間的間隔、対角線の組（−r²）は時間的間隔——「対角線は長さでなく**間隔の種類**で辺と区別される」。

この読み替えができるのは（N=3〜16 の設計の中では）N=5 だけである【実測】。他の N は d² が本当に複素になり、複素シンプレックスが必須になる。

### 15.4 閉塞の判定・B 行列と形

- **大域閉塞【定理・実測】**：全体では各角度が 8 本ずつ → 8×r²×（15 乗根の和）= 0。実測 |Σz²| = 2e-16。
- **局所閉塞【定理・実測】**：各頂点は 15 色を 1 本ずつ持つ。d² の角度は色 c で c×24° = c×360°/15、つまり **1 の 15 乗根がちょうど 1 個ずつ**。冪根の総和は零なので局所和 = r²×(15 乗根の和) = 0。実測 max|局所和| = 7e-17。よって**全頂点が光円錐上**（埋め込みで max|x·x| = 9e-17）。
- **B = −½JD²J の Takagi 軸【実測・機械精度】**：軸スケールの相異なる値は 0.683130051、0.365148372、0.182574186 （等長でない。相異なる値 3 種：長い軸あり）。rank = 15。頂点のエルミート半径：0.353553391、0.259272486。埋め込みの距離再現誤差 max = 2e-16。

### 15.5 N=16 のまとめ（種別）

- 【選択＋実測】完全マッチング分解に位相を等間隔で配った等モジュラー状態は自己無撞着（残差 2e-16）。
- 【定理・実測】大域閉塞・局所閉塞とも成立。全頂点が光円錐上。
- 【定理】μ/r² = −(N−1) = −15。
- 【実測（機械精度）】rank = 15（最大次元）、軸は等長でない（1 本だけ長い軸を持つ）。
- 【規約の帰結】大きさに制限はない（スケール対称性）。
