## 7. N=8 の全展開

### 7.0 N=8 の複素シンプレックスの定義

頂点 8 個 {0,…,7}。2 点の組は M = 8×7/2 = 28 個。各組に波 z が 1 個（実数 56 個が状態の全て）。2 乗距離は d² = z²。**N=8 の複素シンプレックスとは、8 頂点とこの 28 個の複素 2 乗距離の組**。

### 7.2 波の値 (a, b) と構成、自己無撞着の検証

**構成（偶数 N の設計＝完全マッチング分解）**。8 人で全員に相手がいるペアの組ませ方（完全マッチング、1 組 4 本）が、ちょうど 7 セットで全 28 組を重複なく覆う（総当たり戦の 7 節）。セット（色）c = 0..6 の波に位相 θ = c×25.7143°（= c×180°/7）を与える。各頂点はどの色の波もちょうど 1 本ずつ持つ。
スケールは規約 r² = 1/15（§0.2。‖v‖² = 28r² = 28/15）。同じクラスの波は同じ (a, b) を持つので、クラスごとに列挙する：

**自己無撞着の検証【定理・実測】**：和則（§0.1）を全 28 組で数値検査——実部条件 Σsin²φ の値は全組で 7.000000（= N−1 = 7、ばらつき 9e-16）、虚部条件 |Σsin2φ| ≤ 1e-15。方程式の残差 5.2e-17。よって μ/r² = −(N−1) = −7、**μ = −7/15 = -0.466666667**。

### 7.4 閉塞の判定・B 行列と形

- **大域閉塞【定理・実測】**：全体では各角度が 4 本ずつ → 4×r²×（7 乗根の和）= 0。実測 |Σz²| = 1e-16。
- **局所閉塞【定理・実測】**：各頂点は 7 色を 1 本ずつ持つ。d² の角度は色 c で c×51.4286° = c×360°/7、つまり **1 の 7 乗根がちょうど 1 個ずつ**。冪根の総和は零なので局所和 = r²×(7 乗根の和) = 0。実測 max|局所和| = 4e-17。よって**全頂点が光円錐上**（埋め込みで max|x·x| = 7e-17）。
- **B = −½JD²J の Takagi 軸【実測・機械精度】**：軸スケールの相異なる値は 0.447213595、0.307051957、0.182574186 （等長でない。相異なる値 3 種：長い軸あり）。rank = 7。頂点のエルミート半径：0.287220806、0.250542084。埋め込みの距離再現誤差 max = 2e-16。

### 7.5 N=8 のまとめ（種別）

- 【選択＋実測】完全マッチング分解に位相を等間隔で配った等モジュラー状態は自己無撞着（残差 5e-17）。
- 【定理・実測】大域閉塞・局所閉塞とも成立。全頂点が光円錐上。
- 【定理】μ/r² = −(N−1) = −7。
- 【実測（機械精度）】rank = 7（最大次元）、軸は等長でない（1 本だけ長い軸を持つ）。
- 【規約の帰結】大きさに制限はない（スケール対称性）。
