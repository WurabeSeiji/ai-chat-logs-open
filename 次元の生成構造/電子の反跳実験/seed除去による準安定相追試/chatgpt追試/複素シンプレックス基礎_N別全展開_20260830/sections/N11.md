## 10. N=11 の全展開

### 10.0 N=11 の複素シンプレックスの定義

頂点 11 個 {0,…,10}。2 点の組は M = 11×10/2 = 55 個。各組に波 z が 1 個（実数 110 個が状態の全て）。2 乗距離は d² = z²。**N=11 の複素シンプレックスとは、11 頂点とこの 55 個の複素 2 乗距離の組**。

### 10.2 波の値 (a, b) と構成、自己無撞着の検証

**構成（奇数 N の設計＝距離クラス分解）**。頂点を円周に並べ、組 (i,j) の「距離」を d = |i−j| を N で折り返した値（1〜5）とする。距離 d のクラスは各頂点にちょうど 2 本ずつ属する（11 本、全 5 クラスで 55 組を覆う）。クラス d の波に位相 θ = (d−1)×36°（= (d−1)×180°/5）を与える。
スケールは規約 r² = 1/15（§0.2。‖v‖² = 55r² = 11/3）。同じクラスの波は同じ (a, b) を持つので、クラスごとに列挙する：

**自己無撞着の検証【定理・実測】**：和則（§0.1）を全 55 組で数値検査——実部条件 Σsin²φ の値は全組で 10.000000（= N−1 = 10、ばらつき 2e-15）、虚部条件 |Σsin2φ| ≤ 2e-15。方程式の残差 6.2e-17。よって μ/r² = −(N−1) = −10、**μ = −2/3 = -0.666666667**。

### 10.4 閉塞の判定・B 行列と形

- **大域閉塞【定理・実測】**：全体では各角度が 11 本ずつ → 11×r²×（5 乗根の和）= 0。実測 |Σz²| = 3e-16。
- **局所閉塞【定理・実測】**：各頂点は 5 クラスを 2 本ずつ持つ。d² の角度は (d−1)×72° = (d−1)×360°/5、つまり **1 の 5 乗根が 2 個ずつ**。冪根の総和は零なので局所和 = 2r²×(5 乗根の和) = 0。実測 max|局所和| = 6e-17。よって**全頂点が光円錐上**（埋め込みで max|x·x| = 9e-17）。
- **B = −½JD²J の Takagi 軸【実測・機械精度】**：軸スケールの相異なる値は 0.395116115、0.372366066、0.340937944、0.217578398、0.204837607 （等長でない。相異なる値 5 種：長い軸あり）。rank = 10。頂点のエルミート半径：0.301605015。埋め込みの距離再現誤差 max = 2e-16。

### 10.5 N=11 のまとめ（種別）

- 【選択＋実測】距離クラス分解に位相を等間隔で配った等モジュラー状態は自己無撞着（残差 6e-17）。
- 【定理・実測】大域閉塞・局所閉塞とも成立。全頂点が光円錐上。
- 【定理】μ/r² = −(N−1) = −10。
- 【実測（機械精度）】rank = 10（最大次元）、軸は等長でない（1 本だけ長い軸を持つ）。
- 【規約の帰結】大きさに制限はない（スケール対称性）。
