## 9. N=10 の全展開

### 9.0 N=10 の複素シンプレックスの定義

頂点 10 個 {0,…,9}。2 点の組は M = 10×9/2 = 45 個。各組に波 z が 1 個（実数 90 個が状態の全て）。2 乗距離は d² = z²。**N=10 の複素シンプレックスとは、10 頂点とこの 45 個の複素 2 乗距離の組**。

### 9.2 波の値 (a, b) と構成、自己無撞着の検証

**構成（偶数 N の設計＝完全マッチング分解、位相は等モジュラー版と同一）**。10 人で全員に相手がいるペアの組ませ方（完全マッチング、1 組 5 本）が、ちょうど 9 セットで全 45 組を重複なく覆う。セット（色）c = 0..8 の波に位相 θ = c×20°（= c×180°/9）を与える。各頂点はどの色の波もちょうど 1 本ずつ持つ。
**振幅（等モジュラー版との唯一の違い）**。クラス c の振幅二乗を a_c = r̄²(1 + 0.6·cos(4πc/9))、r̄² = 1/15 とする（§0.2 の選択 (A)）。値は a_0 = 0.106666667、a_1 = 0.073612594、a_2 = 0.029078962、a_3 = 0.046666667、a_4 = 0.097308444、a_5 = 0.097308444、a_6 = 0.046666667、a_7 = 0.029078962、a_8 = 0.073612594（平均は r̄² = 1/15 = 0.066666667、‖v‖² = 45r̄² = 3 で等モジュラー版と同じ）。

**この振幅が自己無撞着を保つ理由（導出）**。組 e（クラス c）から見て他の各クラス c′ に隣接組が 2 本、同じクラスの隣接組は位相差 0 で寄与しない。一般和則（§0.1）に代入し、実部条件と虚部条件を 1 本の複素条件にまとめると ω^{−c}·Σ_{c′} a_{c′} ω^{c′} = Σ_{c′} a_{c′} + μ/1（全ての c で同じ実数）。q = 9 ≥ 3 でこれが全 c について実になるのは **Σ_c a_c ω^c = 0** のときだけで、そのとき μ = −1·Σ_c a_c = −(N−1)·r̄²。a_c = r̄²(1+0.6cos(4πc/q)) は三角和の直交性で Σ_c a_c ω^c = 0 を厳密に満たす（実測 |Σ a_c ω^c| = 1e-16）。つまり**必要なのは「振幅二乗を重みとした 1 の 9 乗根の重心が原点」であって、振幅が等しいことではない**。
スケールは規約 〈|z|²〉 = r̄² = 1/15（§0.2。‖v‖² = 45r̄² = 3、等モジュラー版と同じ）。同じクラスの波は同じ (a, b) を持つので、クラスごとに列挙する：

### 9.4 閉塞の判定・B 行列と形

- **大域閉塞【定理・実測】**：全体では各色が 5 本ずつ → 5×Σ_c a_c ω^c = 0。実測 |Σz²| = 1e-16。
- **局所閉塞【定理・実測】**：各頂点は 9 色を 1 本ずつ持つ。d² は色 c で a_c·ω^c（ω = e^{i·360°/9}）なので局所和 = Σ_c a_c ω^c = 0（§9.2 の条件そのもの）。実測 max|局所和| = 3e-17。よって**全頂点が複素ヌル錐上**（埋め込みで max|x·x| = 8e-17）。
- **B = −½JD²J の Takagi 軸【実測・機械精度】**：軸スケールの相異なる値は 0.517045596、0.344705043、0.342973613、0.336430083、0.218897863、0.185178474、0.180971885、0.159383417、0.154860237 （等長でない。相異なる値 9 種）。**等モジュラー版**：0.516397779、0.324667915、0.182574186（相異なる値 3 種）。rank = 9。頂点のエルミート半径：0.318280974、0.280597015、0.280557300、0.278521812、0.272776080、0.264473162。埋め込みの距離再現誤差 max = 3e-16。

### 9.5 N=10 のまとめ（種別）

- 【選択＋実測】クラス重み付き（振幅二乗 a_c = r̄²(1+0.6cos(4πc/q))）の状態は自己無撞着（残差 1e-16）。等モジュラーは**使っていない**。
- 【定理・実測】大域閉塞は成立。局所閉塞は成立（全頂点が複素ヌル錐上）。
- 【定理】μ = -0.600000000 = −(N−1)·〈|z|²〉：等モジュラー版と同一（μ は平均振幅二乗だけで決まる）。
- 【実測（機械精度）】rank = 9（最大次元）、軸は等長でない（等モジュラー版：相異なる値 3 種）。**等モジュラー版との差は形（Takagi 軸）だけ**。
- 【規約の帰結】大きさに制限はない（スケール対称性）。
