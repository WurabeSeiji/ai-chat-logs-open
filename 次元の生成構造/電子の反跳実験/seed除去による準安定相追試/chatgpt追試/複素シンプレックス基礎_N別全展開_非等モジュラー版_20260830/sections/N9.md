## 8. N=9 の全展開

### 8.0 N=9 の複素シンプレックスの定義

頂点 9 個 {0,…,8}。2 点の組は M = 9×8/2 = 36 個。各組に波 z が 1 個（実数 72 個が状態の全て）。2 乗距離は d² = z²。**N=9 の複素シンプレックスとは、9 頂点とこの 36 個の複素 2 乗距離の組**。

| rank | 8 = N−1 | §8.4 の計算結果（等モジュラー版：8） |

### 8.2 波の値 (a, b) と構成、自己無撞着の検証

**構成（奇数 N の設計＝距離クラス分解、位相は等モジュラー版と同一）**。頂点を円周に並べ、組 (i,j) の「距離」を d = |i−j| を N で折り返した値（1〜4）とする。距離 d のクラスは各頂点にちょうど 2 本ずつ属する（9 本、全 4 クラスで 36 組を覆う）。クラス d の波に位相 θ = (d−1)×45°（= (d−1)×180°/4）を与える。
**振幅（等モジュラー版との唯一の違い）**。クラス c の振幅二乗を a_c = r̄²(1 + 0.6·cos(4πc/4))、r̄² = 1/15 とする（§0.2 の選択 (A)）。値は a_0 = 0.106666667、a_1 = 0.026666667、a_2 = 0.106666667、a_3 = 0.026666667（平均は r̄² = 1/15 = 0.066666667、‖v‖² = 36r̄² = 12/5 で等モジュラー版と同じ）。

**この振幅が自己無撞着を保つ理由（導出）**。組 e（クラス c）から見て他の各クラス c′ に隣接組が 4 本、同じクラスの隣接組は位相差 0 で寄与しない。一般和則（§0.1）に代入し、実部条件と虚部条件を 1 本の複素条件にまとめると ω^{−c}·Σ_{c′} a_{c′} ω^{c′} = Σ_{c′} a_{c′} + μ/2（全ての c で同じ実数）。q = 4 ≥ 3 でこれが全 c について実になるのは **Σ_c a_c ω^c = 0** のときだけで、そのとき μ = −2·Σ_c a_c = −(N−1)·r̄²。a_c = r̄²(1+0.6cos(4πc/q)) は三角和の直交性で Σ_c a_c ω^c = 0 を厳密に満たす（実測 |Σ a_c ω^c| = 1e-17）。つまり**必要なのは「振幅二乗を重みとした 1 の 4 乗根の重心が原点」であって、振幅が等しいことではない**。
スケールは規約 〈|z|²〉 = r̄² = 1/15（§0.2。‖v‖² = 36r̄² = 12/5、等モジュラー版と同じ）。同じクラスの波は同じ (a, b) を持つので、クラスごとに列挙する：

**自己無撞着の検証【定理・実測】**：一般和則（§0.1）を全 36 組で数値検査——実部条件 Σ_f |z_f|² sin²φ の値は全組で 0.533333333（ばらつき 3e-16。= −μ）、虚部条件 |Σ_f |z_f|² sin2φ| ≤ 6e-17。方程式の残差 1.7e-16。よって **μ = -0.533333333** = −(N−1)·r̄² = −8/15——**等モジュラー版と同じ値**（-0.533333333）。
※この族は q−3 = 1 個の実パラメータを持つ連続族で、等モジュラー版はその 1 点（ε=0）である。

**特記**：N=9 では一部の距離クラスが複数の輪に分かれるが、必要なのは「各頂点に各クラスが 2 本ずつ」だけなので結論は変わらない（残差 2e-16）。

### 8.4 閉塞の判定・B 行列と形

- **大域閉塞【定理・実測】**：全体では各クラスが 9 本ずつ → 9×Σ_c a_c ω^c = 0。実測 |Σz²| = 1e-16。
- **局所閉塞【定理・実測】**：各頂点は 4 クラスを 2 本ずつ持つ。d² はクラス c で a_c·ω^c（ω = e^{i·360°/4}）なので局所和 = 2Σ_c a_c ω^c = 0（§8.2 の条件そのもの）。実測 max|局所和| = 3e-17。よって**全頂点が複素ヌル錐上**（埋め込みで max|x·x| = 9e-17）。
- **B = −½JD²J の Takagi 軸【実測・機械精度】**：軸スケールの相異なる値は 0.400000000、0.371846407、0.291620830、0.222462429 （等長でない。相異なる値 4 種）。**等モジュラー版**：0.349660915、0.335255203、0.316227766、0.221771922（相異なる値 4 種）。rank = 8。頂点のエルミート半径：0.310126136。埋め込みの距離再現誤差 max = 2e-16。

### 8.5 N=9 のまとめ（種別）

- 【選択＋実測】クラス重み付き（振幅二乗 a_c = r̄²(1+0.6cos(4πc/q))）の状態は自己無撞着（残差 2e-16）。等モジュラーは**使っていない**。
- 【定理・実測】大域閉塞は成立。局所閉塞は成立（全頂点が複素ヌル錐上）。
- 【定理】μ = -0.533333333 = −(N−1)·〈|z|²〉：等モジュラー版と同一（μ は平均振幅二乗だけで決まる）。
- 【実測（機械精度）】rank = 8（最大次元）、軸は等長でない（等モジュラー版：相異なる値 4 種）。**等モジュラー版との差は形（Takagi 軸）だけ**。
- 【規約の帰結】大きさに制限はない（スケール対称性）。
