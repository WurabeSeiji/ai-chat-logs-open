# 検討記録：手作り自己無撞着親の 3 分類、対称性とインフレーション、倍音と関係数の曖昧さ

**作成日:** 2026-08-29　**状態:** 検討途中の保存（木原「一旦ここまでの検討で保存」）。定理として書けるものと、観察・未決を分けて記す。
**再現:** `bash run_all.sh`（`construct_and_analyze.py`、既存パッケージのデータを読み、構成・線形化・直接走行を行う。約 3 分）。数値は全て `results/`。
**前提の系:** 辺 e ∈ K_N（M = N(N−1)/2）に z_e ∈ ℂ、生成子 K_ef = A_ef Im(z̄_e z_f)（A = 線グラフ隣接、辺 1 本あたり 2(N−2) 本）、流れ ż = K(z) z（実直交回転）、自己無撞着 iK(v)v = μv（μ<0 側）。閉塞 Σz²=0 は定理（`../公理見直し_ゼロ閉塞定理と固有時計_20260829/`）。

## 1. 自己無撞着の和則（定理、等モジュラー親）

|v_e| = r で共通なら、iK(v)v = μv は各辺 e について隣接辺 f にわたる 2 つの和則に等価（φ_ef = θ_f − θ_e）：

  Σ_f sin² φ_ef = −μ/r²、　Σ_f sin 2φ_ef = 0

導出：(iKv)_e / (r e^{iθ_e}) = i Σ_f sin φ_ef e^{iφ_ef} = −Σ sin²φ + i Σ sin φ cos φ。
実測（`results/sum_rules_and_neighbor_angles.csv`、fixed_equimodular step 0）：N=4〜16 で −μ/r² = N−1 として誤差 ≤ 2e-9。N=3 は −μ/r² = 3/2（§6）。

## 2. 手作り設計の 3 分類（定理＋構成、残差 1e-15〜1e-16）

**(A) 偶数 N：1-因子分解設計。** K_N を N−1 個の完全マッチング（円法）に分解し、辺の位相を θ_e = c_e·π/(N−1)（c_e = マッチング番号）、辺ごとの 0/π 符号は自由。各辺は他の色を両端で 1 回ずつ見るので Σ sin² = 2Σ_{k=1}^{N−2} sin²(kπ/(N−1)) = N−1、Σ sin2φ = 0（1 周期の和）。1-因子分解は偶数 N でのみ存在。N = 4, 6, …, 20 で残差 ≤ 3e-15、μ/r² = −(N−1)。**N=4 の make_parent 親は正確にこれ**（隣接位相差 60°/120°、sin² = 3/4）。

**(B) N ≡ 1 (mod 4)：直交 2 族設計。** 辺を 2 族に分け、族内 0/180°、族間 ±90°。各辺が他族の隣接辺をちょうど N−1 本持つ条件は「全頂点対で d_i + d_j = N−1」（d = 族 1 の次数）⇒ 族 1 は (N−1)/2 正則 ⇒ N 奇数かつ N(N−1)/4 ∈ ℤ ⇒ N ≡ 1 (mod 4)。(N−1)/2 正則グラフなら何でもよい（N=9: circulant(1,2), (1,3), (1,4)；N=13: Paley=circulant(1,3,4), (1,2,3)；N=17: Paley）。符号自由。N = 5, 9, 13, 17 で残差 ≤ 1e-15。**N=5 の make_parent 親はこれに δ（A/B 族間の相対位相、自由モジュラス）が乗ったもの**。

**(C) N ≡ 3 (mod 4)（3, 7, 11, 15）：(A)(B) とも不可能。** (A) は奇数で 1-因子分解なし。N 色の近 1-因子分解 θ = c·π/N は各辺で sin²x + sin²y = 1 を要求し π/2 が π/N の倍数でないため破綻（N=5,7,9,11 で残差 0.6〜0.7、`colorN_fail`）。(B) は辺数半整数（N=7 circulant で残差 2）。make_parent はこのクラスでも親を生成する（N=7, 11, 15 の族は空でない）が、対称な設計点は見つかっていない。

分類の帰結：「偶数は作りやすい」は (A)＝完全マッチング分解の存在そのもの。奇数のうち N ≡ 1 mod 4 は (B) がある。**真に難しいのは N ≡ 3 mod 4**。

## 3. 等モジュラーは必須でない（定理＋構成）：星型解

閉塞 Σa² = Σb² は「全辺実」も「全辺虚」も許さないので、最も非対称な閉塞状態＝**1 本だけ純虚、残り実**を考える。辺 e₀ に b_{e₀} = β、他は実 a_i とすると K は e₀ の行・列にしか値を持たず、Ka = μb、Kb = −μa は
- μ = −Σ_{i 隣接 e₀} a_i²
- 隣接辺：β² = Σ_{j 隣接 e₀} a_j²（＝閉塞そのもの）
- **非隣接辺：a_i = 0**（μ ≠ 0 より強制）

に解ける。つまり e₀ に接する 2(N−2) 本だけが光る自己無撞着解が存在し、振幅は隣接辺で任意（2N−5 次元の族）、|z|² 相対幅は 7.5（N=6）〜60（N=16）。残差 0〜2e-15、閉塞 1e-16、σ は 1 本（K の rank 2）。
**make_parent の受理条件 EQUI_SPREAD_FINAL（段階3 後も等モジュラー）はこの族を丸ごと捨てている。** N=6, 7 の最初の移植で「非零辺 6 本・σ₂≈0・|z|² 幅 4.8」として捨てた縮退解はこの型だった可能性が高い（未照合）。

## 4. 対称性とインフレーション（観察。仮説は半分逆）

木原の仮説：「理論的に作った高対称な親からはインフレーションが起こらない。丸め誤差だけでは起こらず、対称性の何かに依存する」。
検証：共回転線形化 L_rot = DF(v) + μJ（解析ヤコビアン、有限差分と 6e-9 で一致；N=6 make_parent 親で H⊥ 率 0.2986 ＝ 並行チャットの値、N=5 で 0.176、N=10 で中立、と較正済み）。流れは 3 次なので成長率は r² に比例し、**a/r² で比較**する（`results/stability_by_parent_type.csv`）。線形化に依らない直接走行（種なし、exp(ΔK) 厳密回転、直接読出し）も併記（`results/direct_runs.csv`）。

| 親の型 | N | a/r²（振幅レベル） | 不安定モード周波数/\|μ\| | 直接走行 |
|---|---|---|---|---|
| make_parent | 5 / 6 / 7 | 1.02 / 1.87 / 1.06 | 0.32 / 0.37 / 0.37 | （既存 40000 step：飽和） |
| make_parent | 8, 10, 16, 20 | ≤3e-5 | — | N=10（r²=1 に拡大）τ=40 で 2.7e-18 |
| **設計 A** | 4 | 3e-8 | — | — |
| **設計 A** | **6 / 8 / 10 / 12 / 14 / 16 / 20** | **1.97 / 2.98 / 3.99 / 4.99 / 5.99 / 6.99 / 8.99** | **0.390 / 0.424 / 0.442 / 0.453 / 0.460 / 0.466 / 0.473** | N=10：τ=10 で 0.90 に飽和。N=6：τ=20 で 0.91 |
| 設計 B | 5 / 9 / 13 / 17 | ≤1.4e-7 | — | N=5：τ=100 で 1.7e-19 |
| 星型 | 6 / 10 / 16（等振幅・乱振幅） | ≤6e-7 | — | N=6：τ=60 で 2.7e-23 |

読み：
1. **「最高対称点では起こらない」は成り立たない。** 設計 A は偶数 N 全部で強く不安定（a/r² ≈ N−1 に比例、a/|μ| → 0.47）。**並行チャットの予想「N ≥ 11 でどんな親でも不安定親なし（0/25）」は反証**：N = 12, 14, 16, 20 に不安定親が構成的に存在し、make_parent の生成測度がそこを踏まないだけ。
2. **中立なのは「各辺が純実か純虚」の親**（設計 B、星型）。すなわち z_e² が全辺で実＝第 2 倍音の位相が 0 mod π にロックされた状態。設計 A は z_e² の位相が 2kπ/(N−1) に散っていて不安定。ただし N=4 設計 A（z² は散っているが中立、横断セクターが無い）と make_parent N ≥ 8（散っていて中立）があるので、「z² 実 ⇒ 中立」は十分条件の候補に留まり、必要条件ではない。**対称群の大きさではなく、位相が実軸・虚軸に乗っているかが効いている**、というのが現時点の観察。
3. 設計 A の不安定モードは周波数/|μ| が N とともに **1/2 に単調収束**（1/2 − 約0.6/N）。make_parent の不安定親（0.32〜0.37）、並行チャットの「不安定親は σ_max/2 付近の低周波」も同じ帯。**この系の不安定化チャネルは親の回転率の 1/2 の分数倍音（周期倍加＝パラメトリック共鳴）**である。
4. 符号自由度（0/π）は a を変えない（設計 A、符号ランダムで同値）。対称性のうち効くのは位相の集合であって符号ではない。

## 5. 倍音とは何か、関係数とは何か（未決、木原提起）

旧系（シード編）では、倍音関係（λ = nλ′ か θ = θ′/n かは未確定）にある波が 1 本でも混じると、振幅にも位相にも依らず「存在するだけで」特殊な挙動が出た。今の系での対応と限界：

- **今の状態空間に倍音は存在しない。** M = N(N−1)/2 は「対」の数で、各対は複素数 1 個＝単色波 1 本の枠しかない。関係 e の倍音を入れる変数はなく、z_e² は派生量。倍音が顔を出せるのは (i) 集団固有モード σ_k と μ の周波数比（§4 の 1/2 はこれ）、(ii) 双線形の派生量 z_e z_f（和周波、2μ）——今の K は差周波 Im(z̄_e z_f) だけで組まれ、和周波は閉塞 Σz²=0（＝全体の第 2 倍音成分ゼロ）という制約としてだけ存在する。
- **「存在するだけで効く」の機構**は双線形性：K は周波数 μ と nμ の積から (n±1)μ を作るので、倍音成分の効果は振幅の 1 次で現れ、共鳴条件は周波数比だけで決まる。ただし今の系の中立親は線形次数で成長率 0 なので、倍音の効果は非線形（有限振幅）でしか出ない可能性があり、旧系と同じ形で再現するかは未確認。離散化 exp(ΔK) 自体が ANGLE·σ_k ≡ 2π/n のエイリアス（U^n=I・有理ロックの問い）という別の倍音構造を持ち込む。
- **倍音を波として持たせるなら M の数え方が変わる**（決めるべき点）：(i) 各関係にフーリエ塔 z_e^{(n)}（M × n_max、同じ関係の別モード）、(ii) 巻き数付き関係 (i, j, n)（別の関係、隣接 A を巻き数ごとに再定義）、(iii) 関係の関係：A は線グラフで、K_ef は「関係 e と f の関係」。今はそこに差周波だけを置いている。和周波 z_e z_f を置けば第 2 倍音が 2 次の関係として入る（数は A の非零数 M(N−2)）。今の枠組み（閉塞＝第 2 倍音の消滅、K＝差周波）と最も連続的なのは (iii)。
- 判定実験案：中立親（設計 B N=9 など）に、横断固有モードのうち μ との比が有理（1/2, 1/3）のものと無理数比のものを同じ振幅・位相で少量混ぜ、成長の有無を比較。有理比だけ成長すれば旧系の現象の再現。
- シード編の設計指針：種の周波数内容（親との比）を振幅・位相より先に指定する。

## 6. N=3 の解決（−μ/r² = 3/2）

M=3 では各辺の隣接辺は 2 本しかなく、3 本が互いに 90° にはなれない（φ₁₂=φ₂₃=90° なら φ₁₃=180°）。取れるのは 120° 間隔で Σ sin² = 2·(3/4) = 3/2。実測：fixed_equimodular N=3 親の位相は 21.29°, 81.29°, 141.29°（60° 間隔、Z₃）、隣接 |Δθ| = 60°/120°。σ = N−1 が N ≥ 4 でしか成り立たないのは、N−1 本の 90° 隣接辺を確保できるのが N ≥ 4 からだから。

## 7. 未決の一覧

1. 「z_e² 実 ⇒ 中立」の証明または反例。N=4 設計 A と make_parent N≥8 が中立な理由の統一。
2. 設計 A の a/r² ≈ N−1、周波数/|μ| → 1/2 の解析的導出（Z_{N−1} 対称でフーリエ対角化できるはず）。
3. 星型族（非等モジュラー）と等モジュラー族の間に連続な自己無撞着族があるか。make_parent の受理条件を外した場合に何が出るか。
4. 倍音と関係数の定義（§5 の (i)(ii)(iii) のどれか）。シード編の前に決める。
5. N ≡ 3 (mod 4) の対称設計点の有無。
6. 並行チャットの「N ≥ 11 で 0/25」を、設計 A を含む測度で再評価する。
