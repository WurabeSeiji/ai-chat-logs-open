## 1. 定理：ゼロ閉塞は自己無撞着の帰結（証明可能）

**前提**
- (P1) 生成子 K は実行列。相互作用は符号付き面積 K_ij = a_i b_j − b_i a_j = Im(z̄_i z_j)（隣接辺）で作られ、結合に i が入らない。
- (P2) K は反対称（‖z‖² = H_total の保存）。
- (P3) 自己無撞着：v = a + ib が自分の生成子の固有モード iK(v) v = μ v、かつ μ ≠ 0（凍っていない）。

**主張** Σ_e v_e² = 0。すなわち aᵀa = bᵀb かつ aᵀb = 0。

**証明** iK(a + ib) = iKa − Kb = μa + iμb の実部・虚部から Ka = μb、Kb = −μa。
μ aᵀa = −aᵀKb、μ bᵀb = bᵀKa = −aᵀKb（反対称）⇒ μ(aᵀa − bᵀb) = 0 ⇒ aᵀa = bᵀb。
μ aᵀb = aᵀKa = 0（反対称行列の二次形式は零）⇒ aᵀb = 0。∎

使うのは P1・P2・P3 だけ。正規化・振幅分布・N・隣接構造は登場しない。

**系**
1. Ka = μb、Kb = −μa は「K を平面 (a, b) に制限すると μ·J（90° 回転 × μ）」。自己無撞着性 ⇔ 親平面が K の不変シンプレクティック平面。「実部・虚部が平面を張る」は自明だが、「その平面で K が 90° 回転として閉じる」が非自明で、これが rank 2 の実体。
2. v̄ は固有値 −μ の固有モード（カイラリティ対。−σ_max / +σ_max の取り違えの正体）。閉塞 ⇔ v ⊥ v̄。
3. μ = 0 の縮退解では aᵀa = bᵀb を保証するものがない。閉塞の成否が「回っている固有モード」と「凍った縮退解」の判別式（N=6, 7 の最初の移植で落ちた縮退 rank-2 解がその例）。
4. 力学は閉塞面を保存する（P1・P2 のみ）：d/dt(aᵀa − bᵀb) = −2aᵀKb + 2aᵀKb = 0、d/dt(aᵀb) = aᵀKa − bᵀKb = 0。等価に、exp(ΔK) は実直交行列なので ZᵀZ は不変量。

### 1.3 注意（証明の射程）

Σz² = 0 が出る証明は「K が実反対称」しか使わないので、任意の実反対称生成子の非縮退固有モードで閉塞する。非自明なのは、K が v 自身から作られる非線形写像の固定点がそれでも自動的に閉塞面に乗る点であって、閉塞の成立自体は振幅込み相互作用の正しさの証拠にはならない（旧エンジンでも成立、§1.1）。逆に、閉塞の全内容は「K が実＝結合が i を含まない」に尽きるので、「閉塞 ⇔ 虚軸は 1 本」という主張はこの証明の形そのものである。

## 2. σ = N−1 のスケール不変形（`results/sigma_spectrum_equimodular_parent.csv`）

等モジュラー親では K_amp = r²·K_phase（r² = |z_e|² = ‖v‖²/M）なので、旧エンジンで整数だった σ は μ = −(N−1)·r² として生き残る。実測（fixed_equimodular step 0 の親から K_amp を組んで固有値計算）：

| N | r² | μ/r² | N−1 |
|---|---|---|---|
| 3 | 0.066667 | **−1.500000** | 2 |
| 4 | 0.111111 | −3.000000 | 3 |
| 5 | 0.085965 | −4.000000 | 4 |
| 6 | 0.071672 | −5.000000 | 5 |
| 7 | 0.069772 | −6.000000 | 6 |
| 8 | 0.060514 | −7.000000 | 7 |
| 9 | 0.053205 | −8.000000 | 8 |
| 10 | 0.049081 | −9.000000 | 9 |

N ≥ 4 で μ/r² = −(N−1) が 6 桁で成立。**N=3 は −3/2（= −(N−1)·3/4）で例外**。N=3 の等モジュラー親は rank 1（σ が 1 本、記録 md §2.1）であり、σ=N−1 定理の前提（ヌル単体の縮退しない固有モード）を満たしていない可能性がある。原因は未確認（本ノートでは事実のみ記録）。

正規化（r² = 1/M で ‖v‖ = 1、または |z_e| = 1）は整数に見せるための規約であり、本体はスケール不変な比 μ/r² である。

## 3. U^n = I の三層分解と、τ ≠ 時間

### 3.1 τ が等間隔の時計であるのは親の上だけ（`results/phase_advance_summary.csv`）

directHperp 40000 step の `measured_phase_advance`（連続 step 間の実測位相進み）：

| N | 親の間（step 1〜1000） | 40000 step 内の変動 | H⊥/H 最大 |
|---|---|---|---|
| 5 | 0.01742366 rad/step | 0.01742 → 0.01751（step 5000）→ 0.01944（10000）→ 0.02147（20000）→ 0.02177（38000）：**+25%**、σ₁(step 生成子) も 0.34386 → 0.42963 | 0.989 |
| 8 | 0.02080621 | 7.8e-12 | 8.3e-11 |
| 10 | 0.02237057 | 1.3e-11 | 5.4e-15 |
| 16 | 0.02310004 | 4.2e-12 | 1.6e-15 |
| 20 | 0.02359948 | 1.8e-11 | 4.0e-15 |

親の上（自己無撞着・全辺等価）では K が固定され一歩の位相進みが Δ·μ で一定＝τ は等間隔の時計。H⊥ が立ち上がると K(Z) が変わり、一歩あたりの位相進みは単調に伸びて頭打ちになる。**τ が等間隔なのは「相互作用がまだ何も変えていない」間だけ**。

### 3.2 三層分解

| 層 | 内容 | 位置づけ |
|---|---|---|
| (a) 親の周期性 | 自己無撞着なら U(t)v = e^{−iμt} v。固有時計 φ が 2π 進めば親は自分に戻る | 定理（P3 だけから）。ただし「n ステップで戻る」の n はスケール r² とともにゲージ |
| (b) 整数固有値 | μ = −(N−1)·r²（§2） | 定理（スケール不変形）。整数は正規化の規約 |
| (c) 作用素恒等式 U^n = I（全モードで戻る） | 親の固有値で数えた横断スペクトルは非通約（§3.3）だが、それは親近傍の線形化の話。成長後は σ_k(Z) も δφ_t も状態依存で、「τ で n 回」で戻りを問うこと自体が無意味 | 公理にできない。戻りの有無は固有時計 φ(τ) = Σ_t δφ_t で判定する。成長相では H⊥/H が 0.4 → 0.86 → 0.66 → 0.77 と揺れて戻らない（N=5 実測） |

### 3.3 親における横断スペクトル（参考、線形化の範囲でのみ有効）

σ/r²（N=5〜10、`results/sigma_spectrum_equimodular_parent.csv`）：N=5 は [4, 1.08662, 1, 1, 0.90512]（1/4 が 2 本は有理、他 2 本は分母 50 以上でも 1e-4〜5e-4 残る）。N=6 は核 1 本（σ=0）。N=7〜10 は分母 19〜59 の近似で 4e-4〜1.4e-3 の残差＝小さな有理数に乗らない。親の点では有理ロックは無い。ただし §3.1 の通り、これは軌道上の通約性を決めない。

## 4. 版上げでの公理構成（提案）

| 層 | 内容 | 位置づけ |
|---|---|---|
| 公理 | P1 生成子が実（符号付き面積で結合、i が入らない）／P2 反対称（H_total 保存）／P3 自己無撞着（μ≠0 の固有モード） | 残す。P1 は「差異の判別」（順序の符号＝面積の符号）から出せる可能性があり、出せれば公理は P2・P3 だけ |
| 定理 | ゼロ閉塞 Σz²=0（§1）／閉塞の力学的保存（§1 系 4）／μ = −(N−1)r²（§2、N≥4）／親の周期性（§3.2 (a)、固有時計で述べる） | 証明を本文に置く |
| 準安定相の条件 | 等モジュラー（非保存。N=6, 7 で崩れ始める） | 公理でも定理でもなく、相の定義 |
| 撤回 | U^n=I を作用素恒等式として置くこと／τ を時間刻みとして扱うこと | §3.1 の実測を反証データとして載せる |
| 未決 | スケール r² を決めるものは何もない（私有スケール）／N=3 の μ/r² = −3/2／横断スペクトルと固有時計の関係（軌道上の通約性）／P1 の導出 | 未決として明記 |

旧版で U^n=I が公理に見えたのは、正規化が r²=1 に固定して整数化し、2π/L のステップ刻みが周期を L ステップに見せていたから。正規化と種を外した今、残るのは「親は回る（定理）」「整数は N−1（定理、スケール不変形）」「系全体は戻らない、τ は時間でない（実測）」の三つ。

## 5. 並行チャットの結果との接続（`../飽和ステップ数とNの関係_固定点ヤコビアン解析_20260829/`、コミット 80a34f6b・482d9a32）

並行して進んだ固定点ヤコビアン解析（相対平衡の共回転モノドロミー G = R(−φ)·DF(v)、λ_f = 2 ln|μ_G|max が実測成長率と 4 桁一致）は、本ノートの §3 を別の側から裏付け、§4 の「未決」を具体化する。

1. **λ_f = a·ANGLE + ANGLE²/8 の二層分離**：流れ自体の不安定性 a（τ あたり、刻み不変）と、線形回転 exp(ANGLE·K) の刻み由来 ANGLE²/8（全 N で普遍、連続極限で消える）。N ≥ 11 の 40000 step 走行で見えていた微小成長（1e-14〜1e-15、§3.1 表の N=10, 16, 20）は後者＝離散化アーティファクトで、流れとしては中立。**τ を時間と読むと、この刻み由来の成長を物理と誤認する**——§3.1 の「τ ≠ 時間」の実害がここに出ている。
2. **不安定性は N でなく親の位置で決まる**：連続流れの線形化で a > 0 となる親は N=6, 7（5/5）、N=5, 8, 9, 10（2/5, 1/5, 4/25, 1/25）、N ≥ 11（0/25）。エネルギー・カシミール法は全 N ≥ 5 で鞍点（慣性 +N−1／−2N／零 多数）のため使えず、「N ≥ 11 でインフレーション不在」は定理でなく数値的予想。隠れパラメータは **make_parent の生成法が moduli 空間のどこをサンプルするか**（N=20 でヘッセ行列の零モード 378 中 319 本＝親の連続族が巨大）。本ノート §1 前段で見つけた「同じ N・同じ seed でも CSV 親と npz 親が overlap 0.25（N=8）／0.03（N=10）の別固定点」は、この生成測度の非一意性の直接の実例である。
3. **整合性の確認**：ヤコビアン解析の t50 = 44.4/λ_f は step 単位だが、線形化は親の上（位相進みが一定の領域）で行われており、§3.1 の位相進みの伸び（N=5 で +25%）は 50% 到達後に起きるので、t50 の予測には矛盾しない。飽和後の挙動（H⊥/H の揺れ）を step で語ることだけが不適切。
4. **N=3 の μ/r² = −3/2**（§2）は並行チャットの N=3 親でも同値（σ_amp = 0.1、‖v‖² = 0.2、r² = 1/15）。rank 1 で「σ_max ＋ N−2 本の下位 σ」の構造を持たない特殊例、という以上の説明は両チャットとも持っていない。

したがって版上げの「未決」欄には、§4 の項目に加えて **「不安定親と中立親を分ける moduli 空間内の構造（Krein 符号の衝突集合）」と「make_parent の生成測度」** を明記する。
