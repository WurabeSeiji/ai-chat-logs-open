# 飽和 step 数と N の関係——相対平衡の共回転モノドロミーによる定式化

**作成日:** 2026-08-29　**対象:** 等モジュラー自己無撞着親からの seedless 走行（振幅込み K、線形回転 exp((2π/L)K)、正規化なし、H⊥ 直接読出し）
**問い:** 全 N のデータを揃えずに、飽和までの step 数と N の関係を定式化できるか。
**答え:** できる。ただし「N の滑らかな関数」ではなく、**流れ自体の不安定性（小 N・親依存）**と**線形回転の刻み由来の成長（全 N 共通、ANGLE²/8）**の二層になる。

## 1. 定式化

親 v は 1 step 写像 F(z) = exp(ANGLE·K_amp(z))·z の**相対平衡**：F(v) = e^{iφ}v、φ = ANGLE·σ_max（実測 φ = ANGLE·σ_max に 16 桁一致、残り欠損 2e-12）。
したがって線形安定性は DF(v) ではなく**共回転モノドロミー G = R(−φ)·DF(v)** で決まる（R は全体位相回転の実 2M 表現）。

- 振幅の成長率 λ_G = ln|μ_G|max、H⊥/H_total（振幅の 2 乗）の成長率 **λ_f = 2λ_G**
- 飽和 step：**t50 = (ln 0.5 − ln f_seed) / λ_f**、f_seed は指数窓を step 0 に外挿した切片。7 走行で ln f_seed = −44.3〜−46.6（平均 −45.1、f_seed ≈ 3e-20 = 丸め誤差床）。つまり **t50 ≈ 44.4 / λ_f**
- 刻み角依存（`data/angle_dependence.csv`、L=62〜1984）：**λ_f = a·ANGLE + b·ANGLE²**
  - a：連続時間の流れの成長率（τ あたり、刻みに依らない）
  - b·ANGLE²：線形回転の刻み由来。N=16 で **b = 0.1250**（L=62〜496 で 4 桁一致）＝ **ANGLE²/8**

### 検証（`data/empirical_growth.csv`：走行の親 Z[0] で計算した 2λ_G と実測 λ_emp）

| N | λ_emp（実測 指数窓） | 2λ_G（走行の親） | 実測 t50 | 予測 44.4/λ_f |
|---|---|---|---|---|
| 5 | 8.903e-3 | 8.902e-3 | 5029 | 4985 |
| 6 | 1.5094e-2 | 1.5094e-2 | 2933 | 2940 |
| 7 | 7.046e-3 | 7.048e-3 | 6564 | 6297 |
| 8 | 5.381e-4 | 5.393e-4 | 未飽和 | **82300** |
| 10 | （窓なし）末尾 2.90e-4 | 3.380e-4 | 未飽和 | 131000 |
| 16 | 2.751e-4 | 3.210e-4 | 未飽和 | 138000 |
| 20 | 2.920e-4 | 3.185e-4 | 未飽和 | 139000 |

N=5〜8 は 4 桁一致。N=16, 20 の 15% 差は、40000 step 時点でまだ弾道項 (rτ)² から指数へ移行中（末尾傾きが上昇中）のため。

## 2. 二層構造（`data/flow_vs_discretization.csv`、N=4〜20 × 親 5 実現、L=124/248 の 2 点で a, b を分離）

| N | a（流れの成長率 /τ、H⊥/H）親 5 実現 | b |
|---|---|---|
| 4 | ≈0（≤3e-4） | ≈0（厳密固定点） |
| 5 | **0.176, 0.066**, 0, 0, 0（2/5 が不安定） | 0〜0.14 |
| 6 | **0.30, 0.22, 0.14, 0.14, 0.15**（5/5 不安定） | ≈0 |
| 7 | **0.14, 0.15, 0.29, 0.18, 0.13**（5/5 不安定） | ≈0 |
| 8 | 0, 0.001, 0, 0, **0.099**（1/5） | 0.11〜0.39 |
| 9 | ≈0 | 0.12〜0.25 |
| 10 | 0, 0, 0, **0.0064**, 0 | 0.13〜0.49 |
| 11〜12 | ≈0（≤2e-5） | 0.12〜0.20 |
| **13〜20** | **≈0（≤2e-6）** | **0.113〜0.137、中央値 0.118〜0.127 ≈ 1/8** |

読み：
1. **N=6, 7 は流れ自体が不安定**（全親）。成長率 a ≈ 0.13〜0.30 /τ。飽和は τ50 ≈ 44.4/a ≈ 150〜340 τ ＝ 2π/124 で 3000〜6600 step（実測 2933 / 6564 と一致）。刻みを細かくしても τ 単位の飽和時刻は変わらない。
2. **N=5, 8, 10 は親次第**：不安定な親（N=5 seed0 の a=0.176 が走行に使われた親）と中立な親が混在。走行の N=8 親は中立側（λ_f = 5.4e-4 は主に刻み由来 b=0.21）。
3. **N ≥ 11（および N=9）では流れは中立**（a ≤ 2e-5、数値床）。観測される指数成長は**全て線形回転の刻み由来** λ_f = ANGLE²/8 で、N・親によらない普遍値。t50 = 44.4·8/ANGLE² = **355/ANGLE² step ＝ 9.0·L² step**（L=124：1.38e5 step、L=144：1.86e5 step）。τ 単位では τ50 = 355/ANGLE → 刻み → 0 で無限大、**連続極限では飽和しない（急拡大が起きない）**。

## 3. 「40000 step で飽和していない最低の N」への答え

N=8（走行の親）。予測 t50 ≈ 82000 step。ただし N=8 のこの成長は b=0.21 の刻み由来が主で、流れの不安定性ではない。**流れ自体の不安定性で飽和する N は 5〜8（親依存）、確実なのは 6, 7 だけ**である。

## 4. 未検証・限界

- a, b の分離は L=124, 248 の 2 点解。a ≤ 1e-5 は中心差分（h=1e-6）の数値床で「0 と区別できない」の意味。
- 「b = 1/8」の解析的導出は未着手（exp(ANGLE·K(z))z の 2 次の項が相対平衡の周りで作る非ユニタリ成分と推定、未検証）。
- N=5, 8, 10 で不安定な親と中立な親を分ける構造（σ スペクトルの縮退パターン？）は未調査。
- 飽和後の帯（0.8〜0.99）の形と N の関係は本解析の範囲外。
