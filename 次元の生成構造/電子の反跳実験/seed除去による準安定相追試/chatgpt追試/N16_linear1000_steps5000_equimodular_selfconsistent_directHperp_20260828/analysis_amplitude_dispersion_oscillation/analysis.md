# 振幅分散 std(|Z_m|) の振動（figures/N5_amplitude_std_compare.png、10⁻¹² スケール）の原因

**作成日:** 2026-08-28　**入力:** `../data/states_treatment.npz`（N=16、L=1000、5000 step、等モジュラー自己無撞着親、振幅込み K）。力学は再実行せず状態列を解析。スクリプト `analyze_oscillation.py`、数値 `results.json`、図 `oscillation_analysis.png`。

## 結果（results.json の数値）

1. **定数部分（4.6×10⁻¹³）は親自身の非等モジュラー性**：親 v = Z[0] の |v_m| のばらつき std = 4.64×10⁻¹³（max 偏差 1.37×10⁻¹²）。make_parent 段階 2 の停止条件（|z|² 相対幅 < 10⁻⁹、実測 3.1×10⁻¹¹）に対応する残留値。
2. **振動と上昇は、親からの偏差 δ(t) = Z(t) − e^{iθ_t}v の運動**：‖δ‖ は 2.2×10⁻¹⁹（t=0）から 5.4×10⁻¹¹（t=5000）へ**線形に**増える（d‖δ‖/dt = 1.06×10⁻¹⁴/step、t>100 の直線 fit）。|Z_m| = |v_m e^{iθ} + δ_m| の交差項 Re(v̄_m δ_m) が振幅分散を変える。
3. **δ はどこにいるか（訂正済）**：t=0 の δ は 2×10⁻¹⁹ の丸め誤差なので、その分解（核モードが上位）は意味を持たない。**δ(final) を K_amp(v) の固有基底で分解すると、核（w=0、88 次元）の割合は 0.035% に過ぎず、99.9% は w_k ≈ −0.18〜−0.21 のモード群（親と同じ符号側の第 2 群）にある**（results.json: delta_final_share_by_eigenvalue）。
4. **振動周期の起源（実測）**：δ の各支配成分の位相は、親と共回転する系で **0.00286〜0.00293 rad/step** で回る（t>1000 の直線 fit、上位 5 成分とも）。これは ANGLE·σ_max = 2π/1000 × 0.45588 = **0.002864** と 2% 以内で一致し、周期は L/σ_max = **2194 step**。実測の振幅分散の極値（1342, 2384, 3915, 4458）から周期 ≈ 2100〜2600 step、FFT 主周期 2500（分解能内）で整合。
   一方、凍結 K の固有値から予言される相対回転率 ANGLE·(w_k − w₀) = 0.0016 rad/step（周期 ≈ 3800〜4100 step）は**実測と合わない**。つまり δ は K_amp(v) の固有モードとして回っておらず、実験室系ではほぼ静止した方向（回転率 ≈ ANGLE·(w₀ + σ_max) ≈ 0）に留まり、親がその前を σ_max で回っている。凍結 K の固有基底は偏差の線形化基底ではない（K の状態依存＝Jacobian が効く）。**δ が実験室系で静止する機構は本解析では未解明。**
5. **δ の成長源**：親の固有モード残差 r = 9.4×10⁻¹³（summary.json の parent_residual、スケール不変残差）が毎 step ANGLE·r·‖v‖ の偏差を生んで線形に蓄積する、という仮説の検算：予言 1.13×10⁻¹⁴/step、実測 1.06×10⁻¹⁴/step（比 0.94）。**一致**。したがって上昇は丸め誤差のランダムウォーク（√t）ではなく、親が完全な固有モードでない分（残差 10⁻¹²）による決定論的な線形ドリフト（H⊥ ∝ t² と整合）。
6. 保存量：Σ|z|² のドリフト 5.2×10⁻¹²、H_int の相対変動 2.9×10⁻¹²（5000 step、刻み 2π/1000）。

## 結論

振動の原因は、**親の固有モード残差（9.4×10⁻¹³）が毎 step 生む偏差 δ が線形に蓄積し（ドリフト率は予言 ANGLE·r·‖v‖ の 0.95 倍）、その δ が親に対して角速度 ANGLE·σ_max（周期 L/σ_max ≈ 2194 step）で相対回転すること**。振幅分散は |v_m + δ_m| の交差項として、親自身の残留非等モジュラー性 4.6×10⁻¹³ の上に、線形に成長する振動として現れる。読出しのアーティファクトではない。

未解明：δ が凍結 K の固有モードの回転率（0.0016 rad/step）ではなく、実験室系で静止（親に対して σ_max で相対回転）する理由。Jacobian（K の状態依存を含む線形化）の固有解析が必要。
