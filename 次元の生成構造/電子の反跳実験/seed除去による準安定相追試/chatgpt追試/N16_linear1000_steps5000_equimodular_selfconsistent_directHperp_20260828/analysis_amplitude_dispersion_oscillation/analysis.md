# 振幅分散 std(|Z_m|) の振動（figures/N5_amplitude_std_compare.png、10⁻¹² スケール）の原因

**作成日:** 2026-08-28　**入力:** `../data/states_treatment.npz`（N=16、L=1000、5000 step、等モジュラー自己無撞着親、振幅込み K）。力学は再実行せず状態列を解析。スクリプト `analyze_oscillation.py`、数値 `results.json`、図 `oscillation_analysis.png`。

## 結果（results.json の数値）

1. **定数部分（4.6×10⁻¹³）は親自身の非等モジュラー性**：親 v = Z[0] の |v_m| のばらつき std = 4.64×10⁻¹³（max 偏差 1.37×10⁻¹²）。make_parent 段階 2 の停止条件（|z|² 相対幅 < 10⁻⁹、実測 3.1×10⁻¹¹）に対応する残留値。
2. **振動と上昇は、親からの偏差 δ(t) = Z(t) − e^{iθ_t}v の運動**：‖δ‖ は 2.2×10⁻¹⁹（t=0）から 5.4×10⁻¹¹（t=5000）へ**線形に**増える（d‖δ‖/dt = 1.06×10⁻¹⁴/step、t>100 の直線 fit）。|Z_m| = |v_m e^{iθ} + δ_m| の交差項 Re(v̄_m δ_m) が振幅分散を変える。
3. **δ はどこにいるか**：δ(t) を K_amp(v) の固有基底で分解すると、上位成分はすべて **固有値 w_k = 0（K_amp(v) の核、次元 = results.json の kernel_dim）**にある（|δ(final)|² の核内割合 = fraction_of_|delta(final)|^2_in_kernel）。
4. **振動周期の起源**：親は w₀ = −σ_max = −0.45588 のモードで回転している。核モード（w=0）は親と共回転する系で相対角速度 ANGLE·(0 − w₀) = 2π/1000 × 0.45588 = 0.002864 rad/step で位相が回る。実測した各成分の位相回転率は 0.0025〜0.0030 rad/step（予言 0.002864）。予言周期 L/σ_max = **2194 step**。実測：std の極値は 1342（極大）・2384（極小）・3915（極大）・4458（極小）で半周期 1042〜1531 step（周期 ≈ 2100〜2600）、|Z_m| 偏差の FFT の主周期は 2500 step（5000 step 窓の分解能で 2500 と 1667 の間は判別不能）。**予言と整合**。
5. **δ の成長源**：親の固有モード残差 r = 9.4×10⁻¹³（summary.json の parent_residual、スケール不変残差）が毎 step ANGLE·r·‖v‖ の偏差を生んで線形に蓄積する、という仮説の検算：予言 1.13×10⁻¹⁴/step、実測 1.06×10⁻¹⁴/step（比 0.94）。**一致**。したがって上昇は丸め誤差のランダムウォーク（√t）ではなく、親が完全な固有モードでない分（残差 10⁻¹²）による決定論的な線形ドリフト（H⊥ ∝ t² と整合）。
6. 保存量：Σ|z|² のドリフト 5.2×10⁻¹²、H_int の相対変動 2.9×10⁻¹²（5000 step、刻み 2π/1000）。

## 結論

振動の原因は、**親の固有モード残差（9.4×10⁻¹³）から生じる偏差 δ が K_amp(v) の核（固有値 0 のモード群）に蓄積し、親（σ_max で回転）に対して周期 L/σ_max ≈ 2194 step で歳差すること**。振幅分散はその交差項として、親自身の残留非等モジュラー性 4.6×10⁻¹³ の上に、線形に成長する振幅の振動として現れる。読出しのアーティファクトではなく、「親が固定点に 10⁻¹² だけ届いていない」ことの決定論的な帰結。

未確定：核モードの歳差は線形（凍結 K）の予言であり、非線形効果（K の状態依存）による周期のずれ（実測 2100〜2600 vs 予言 2194）が有意かどうかは、5000 step 窓の分解能では判定できない。
