# 監査結果——現行相互作用（振幅込み K・指数回転）と統一万能相互作用関数 F の差分の確定

**作成日:** 2026-08-31　**目的:** シード実験の設計前に、インフレーション v2 系列の現行力学と、直前まで使っていた統一万能相互作用関数（`統一万能関数_v1/unified_interaction_v1.py`、仕様書 v2 で F はこの版に固定）の作用の違いを確定する。これを確定しないと実験系の固定点がぶれる（木原指示）。
**方法:** コードが正（仕様書 v2 規約 R0）。実装（unified_interaction_v1 → stage3 共有O → stage2 頂点 → 第8論文 abl → 第5論文原本エンジン）を読み、数値検証 3 件で照合した。`bash run_all.sh` で再現（約 1 分）。

## 2. 確定した 3 つの差分（数値検証つき、`results/audit_results.json`）

### 2.1 統一 F の線形部は、インフレーション v2 論文が訂正した 3 条件を全て持つ

位相のみ K（v2 論文の変更 1(b)）、Cayley（変更 2）、K/σ 正規化（v1 論文 §11 で廃止した枝）が、統一 F の線形部にはそのまま生きている。振幅が力学に入る経路は**頂点（R 経由）だけ**である。したがって：

- **真空宇宙（奇数帯が空）では R≡0 で頂点が厳密に零**（実測：R_max=0、|頂点レート|max=0）。真空の統一 F ＝ 純粋な位相のみ K の Cayley 力学＝ v2 論文の baseline／原本系。等分配・σ=N−1 へ向かう性質はこちらの力学の性質。
- シード（奇数帯 δ）を入れた瞬間に $R\propto\delta^2$ で非弾性頂点が点火する。**統一 F では「シード有り／無し」は文字どおり「反射（非弾性）が入るか入らないか」**であり、現行系列の「常時可動の弾性力学に摂動を選ぶ」とは意味が違う。

実測（N=12、$N_n=5$、$N_\eta=8$、step 0）：

| δ | R_max | P_odd/P_even |
|---|---|---|
| 0 | 0（厳密） | 0 |
| 1e-4 | 1.53e-8 | 1e-8 |
| 1e-3 | 1.53e-6 | 1e-6 |
| 1e-2 | 1.53e-4 | 1e-4 |
| 1e-1 | 1.50e-2 | 1e-2 |

$R(\delta)\propto\delta^2$（比 100.0）。**倍音（奇数帯）パワー分率がそのまま反射係数**である。

### 2.2 固定点の共通部分は「等モジュラー自己無撞着状態」だけ

- 等モジュラー状態では恒等式 $K_{\rm amp}(v)=\langle r^2\rangle\,K_{\rm phase}(\theta)$ が成り立つ（実測 N=8 で相対偏差 **1.4e-16**）。よって**等モジュラー自己無撞着親は両方の線形力学の固有モード（共通の相対平衡）**。
- 非等モジュラー自己無撞着状態（v2 補完の ne/rb 親）は $K_{\rm amp}\ne c\,K_{\rm phase}$（N=8 で偏差 0.31）で、**位相のみ K に対する残差 1.51**——統一 F の線形部の固定点では全くない。統一 F の上に載せれば step 1 から位相のみ力学で流される。

**帰結（実験系の固定点のアンカー）：シード実験で両フレームを跨いで固定点を共有できるのは等モジュラー自己無撞着親のみ。** 非等モジュラー親・乱数均衡親は現行力学専用であり、統一 F 側の対照には使えない。

### 2.3 時計が違う（スケール依存 vs スケール非依存）

同じ等モジュラー親（N=8、⟨r²⟩=1/15 スケール）での 1 step の全体位相進み：

- 現行：$\Delta|\mu|=\frac{2\pi}{124}\cdot(N-1)\langle r^2\rangle=0.023646$。**振幅 2 倍で 4 倍**（0.094586、実測一致）——振幅二乗が時計。
- 統一線形部：K/σ 正規化のため固有モードの位相応答は $2\arctan(\gamma\sigma/\sigma_{\max})$。等モジュラー親は位相のみ K の最上位モード（$\mu_{\rm phase}=\sigma_{\max}=N-1=7.000000$、実測）なので進みは $2\arctan(\tan(\pi/144))=2\pi/144=0.043633$——**N にもスケールにも依らない固定時計**（仕様の物質時計 ω=π/72＝この半分/步 と整合）。

同じ親でも回転速度の意味が異なる：現行は「振幅がスケールファクター（速い波は速く回る）」、統一 F は「最上位モードは常に 2.5°/步」。倍音比較実験の周波数比（§C の有理/無理比）はどちらの時計で定義するかで別物になる。

## 3. シード実験設計への帰結

1. **フレームの宣言が先**：シード実験は (i) 現行フレーム（振幅込み K・指数回転・倍音レジスタなし）か (ii) 統一 F フレーム（帯レジスタ・R 経由の非弾性）かを実験ごとに宣言する。両者の結果は直接比較できない（力学・時計・固定点が違う）。
2. **倍音への応答を見るなら統一 F**：現行フレームには倍音レジスタが存在せず、「倍音が反射係数に効く」経路そのものがない。現行フレームで見えるのは集団固有モード周波数比（μ との比）だけで、これは倍音の代理であって倍音ではない（8/29 検討 §5 の整理どおり）。
3. **親は等モジュラーに固定**：両フレーム共通の相対平衡は等モジュラー自己無撞着親だけ（§2.2）。統一 F 側の真空（δ=0）はその上で位相のみ力学＝v1 的な等分配へ向かう力学であることも織り込む。
4. **make_parent（白色倍音親）は「全倍音にシード済み」**：gen3 の親は許容倍音全部に乱数振幅を持つ（DC・ナイキストのみ除去）。統一 F 上でこの親を使う実験は「シード無し」ではない——シード無しを名乗るには帯を単一（偶数帯のみ）にした真空構成（build_standard_universe δ=0）を使う。木原指摘「make_parent は N 全てにシードを仕込んでいた」はこの実装事実の指摘であり、正しい。
5. **統一 F の版**：仕様書 v2 §1.1 により F は v1 で固定（v2 分岐は不採用。真空の厳密ゼロを壊すため）。本監査も v1 を対象にした。
