# 相互作用関数差分監査_現行K_vs_統一万能F_20260831

シード実験の設計前提として、現行相互作用（振幅込み K_ij=Im(z̄ᵢzⱼ)・凍結生成子の指数回転、インフレーション v2 系列）と統一万能相互作用関数 F（`統一万能関数_v1/unified_interaction_v1.py`、仕様書 v2 で固定）の作用の差分をコード読解＋数値検証で確定した。

**確定 3 点**：(1) 統一 F の線形部は位相のみ K＋Cayley＋K/σ 正規化（= v2 論文が訂正した 3 条件）で、振幅は頂点（反射係数 R）経由でのみ効く。R = scale·P_odd/(P_odd+P_even)＝奇数帯（倍音）パワー分率、真空で R≡0・頂点厳密零、シード δ で R∝δ²。(2) 両フレーム共通の固定点は等モジュラー自己無撞着親のみ（K_amp=⟨r²⟩K_phase、1.4e-16。非等モジュラーは位相のみ残差 1.51）。(3) 時計が違う：現行は振幅二乗比例、統一は最上位モード 2π/144 の固定時計。
