## 4.6 球面とヌル錐（木原の問い「N−1 次元で表現すると球面になっているか」への回答）

**なっています——2 重の意味で。** Takagi 座標 x_i ∈ ℂ^{N−1}（重心中心）で全親を検査（`figures/N*/N*_sphere_nullcone.png`＋`data/N*/sphere_nullcone.csv`）：

1. **ヌル錐**：全頂点で x_i·x_i = 0（複素計量の中心距離² が零）。B_ii = (1/N)Σ_j z_ij²（大域閉塞で交差項消滅）なので、これは**頂点ごとの局所閉塞**。設計 A/B/C では冪根和で厳密（1e-18）、**make_parent 親でも残差水準（1e-10〜1e-12）で成立**——「局所閉塞は自己無撞着から出る」は定理候補（未証明、§5 へ）。
2. **実球面**：エルミート半径 ‖x_i‖ は奇数 C と N=4 で厳密に一定（幅 1e-16、完全な球面）、偶数 A は 7〜14% 割れ（極頂点）、make_parent 親は 1〜9% 割れ。

**力学**：中立走行は球面もヌル錐も 40000 step 保存（1e-11）。**インフレーションは局所閉塞を破り**（頂点ヌル錐逸脱 0.02→0.5）、**球面を砕く**（半径幅 1.5〜1.9）——大域閉塞（厳密保存の定理）と局所閉塞（破れる）の階層が観測された。

**判別量候補の連続反証（記録）**：(i) §4.5 の「等方 ⇔ 中立」に続き、(ii)「親の球面が割れている ⇔ 不安定」も make_parent で反証（不安定 N=5 が幅 0.0095 でほぼ球面、中立 N=8〜20 が 0.04〜0.085）。不安定親の判別量は依然未同定。

## 4.9 飽和後の行き先と U^n=I の階層（木原の指摘 2 件に基づく実測）

**(1) インフレーションの行き先は「別の自己無撞着状態」**。飽和後（τ=35000 基準）の状態は、5000 step 先まで 1−|⟨Z_t0,Z_t⟩|/‖Z‖² ≤ 2e-4（N=8）／3e-2（N=6）＝ほぼ剛体回転。自己無撞着残差は単調減少：N=8 で 0.177（τ=1万）→0.0073（τ=4万）、N=6 で 0.123→0.0138。**力学が自発的に第 2 の自己無撞着状態へ収束しつつある**（到達は未確定、残差 1e-2〜1e-3 台）。
**(2) 新状態の時計は親の倍音**：μ'/μ = 0.8471/0.4236 = **2.000**（N=8）、0.5367/0.3584 = **1.498 ≈ 3/2**（N=6、収束途中）。
**(3) U^n=I は多層で、n は定数でない（実測）**：実測位相進みから n(τ)=2π/δφ を追うと、N=8 で n = 292.7（親）→ 連続的に変化 → **146.4 = n₁/2**（新状態）、N=6 で 346.0 → **231.0 = 2n₁/3**。基底には刻み 2π/124（k=124）が最初から埋まっており、その上に親の時計（~300 step）・新状態の時計（有理比で乗り換え）・包絡線の振動（f の飽和後の揺れ、主要周期 ~1.1〜3.4 万 step）が入れ子になる。
**公理の置き方への帰結**（木原）：U^n=I は「固定 n の大域公理」ではなく、「発展は入れ子の周期構造からなり、各階層の n はそこに住む状態の動的な量。乗り換えは有理比（倍音）で起こる」。I の担い手は全体でなく特定の状態。
