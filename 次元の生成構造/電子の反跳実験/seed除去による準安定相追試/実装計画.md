## 解決策

### フェーズ1: 原本フォルダで基準実行（Stage A2aそのもの）

```bash
cd ~/OneDrive/GitHub/ai-chat-logs-open/次元の生成構造/第8論文_二段階seed除去による準安定相の因果分離/paper8_stage_A2a_seedless_N5

python3 compare_execs.py  # ビット一致確認
```

- `raw/A2a_N5_seedless_f64_e1/` — 実行1の結果
- `raw/A2a_N5_seedless_f64_e2/` — 実行2の結果
- `processed/` — 比較表
- `logs/execution_manifest.json` — 成功記録

### フェーズ2: 追試フォルダで独立実行

reproduction_run/を簡潔にして、原本とのハッシュ値・パス依存を解消。
verify_sources.pyは不要（原本で実施済み）。

新規に `run_reproduction_independent.py` を作成：
- 同じconfig_locked.jsonを使用
- 原本のverify_sources結果を参照（read-only）
- 独立実行を行う
- 結果を raw/ に保存

### フェーズ3: 結果比較

reproduction_run/内で以下を実行：

```bash
python3 compare_with_original.py
```

比較項目：
1. ビット一致性（f, q, 占有）
2. 数値健全性（規格化誤差、閉鎖誤差）
3. 物理量（crossing、準安定開始）
4. 報告書生成
