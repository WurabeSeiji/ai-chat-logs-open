# 条件A/B 系列（第8論文 予備実験）—— シードあり・なしを1本で扱う

N=5 の二系列（`../paper7_f_projection_v1/` と `../paper8_a2a_seedless_v1/`）を
フォルダごと分けたのに対し、本系列は**1本のプログラムで両条件を扱う**。
原本がそう作られているからである。

## なぜ1本で足りるか

原本 `run_preliminary_seed_ablation_v1.py` の `build_init(n, initial_seed)`：

```python
if initial_seed:
    g = zero_closure_kernel_seed(sys_lr, rng)      # 乱数消費
    Z0 = v + DELTA * g; Z0 = Z0 / np.linalg.norm(Z0)     # 条件B
else:
    Z0 = v.copy()                                   # 条件A（乱数を消費しない）
wp = rng.normal(size=M)
```

親状態 v は両条件で同一（`default_rng(40260722 + 1000*n)`, iters=1200, tol=1e-12）。
条件B は kernel seed 生成で乱数を消費するため、以後の warm-start `wp` が条件A と異なる。
これはシードを置くことの不可避な帰結ではなく、**同じ乱数流を seed 生成と `wp` 生成に
共用した実装上の変更条件**である。別乱数流または共通 `wp` で制御できる。
`sigma_max_power` は3回だけ冪反復し、その推定値を Cayley 更新に使うため、`wp` は診断値ではなく
軌道へ入る。したがって原本A/Bは公開データの再現対としては有効だが、シード単独の因果対ではない。

条件D（準安定シード注入）は本版では扱わない。

## 断絶点は第7論文だけの問題ではなかった

本系列の原本も、**射影形を持ちながら引き算形を記録している**。

| プログラム | 射影形（記録されない） | CSV に記録される式 |
|---|---|---|
| `run_paper7_5color_timeseries.py` | `fval`（86–88行、crossing 判定のみ） | 118行 `f = 1.0 - E_P1 / totZ` |
| `run_preliminary_seed_ablation_v1.py` | `fval`（101行、crossing 判定のみ） | 161–162行 `fmt % (1 - E_P1 / totZ)` |

**同じ形が2本の独立したプログラムに現れている。** 一回の書き間違いではなく、
「crossing 判定には良い式、記録には素朴な式」という書き方が繰り返されている。

## 実測（N=40、射影形を追加記録）

| 条件 | 引き算形 f(0)（公開記録） | 射影形 f(0) | crossing |
|---|---|---|---|
| A（無シード） | 2.220446e-16 | **3.639888e-32** | 2011 |
| B（δ=1e-15） | 4.440892e-16 | **1.009280e-30** | 2011 |

N=5 との比較：

| N | 条件A f(0) | 条件B f(0) | 差 | crossing A/B |
|---|---|---|---|---|
| 5 | 3.274787e-33 | 1.066015e-30 | 2.5桁 | 1166 / 1167 |
| 40 | 3.639888e-32 | 1.009280e-30 | 1.4桁 | 2011 |

**条件B の f(0) は N によらず ≃ δ² = 1e-30（種が決める）。
条件A の f(0) は N=5 で 1e-33、N=40 で 1e-32 と系が決めている。**

図の下段（0–25、1ステップ刻み）では2本が step 5 前後で近づいて見えるが、
**数値的には完全一致しない**。射影形は step 5 で
`1.2218713081e-29`（A）対 `1.3302356560e-29`（B）、step 5000 で
`0.1894963122` 対 `0.1929165968` であり、0–5000 の一致行はない。
しかも `wp` が異なるため、この差または接近をシード効果へ単独帰属しない。

### N=5 系列との違い: 27列すべてを照合できる

第7論文の5色時系列は `align_2d(f_prev, ...)` により方向3・4 が記録間隔に依存するため、
毎ステップ版では10列しか照合できなかった。本系列にはその依存が無い
（`q1..q4` は毎回その場の `Bdom` から `qsv4(B0, Bdom)` で計算され、前回記録に依存しない）。
したがって**毎ステップ版でも27列すべてを照合できる**。

## N の選び方について（主張16、ゼロ閉塞 v4）

平行多面体族として零閉鎖を実現する場合、分解能は **N = 2^d**（16-a）。
ただし v4 が明示的に限定している：

> N = 2^d は「平行多面体族として零閉鎖を実現する場合」の条件であって、
> **全ての零閉鎖解に対する必要条件であることは未導出**である。

そして 16-e：

> **N=12 の走行が無効なのではなく、幾何の言明と突き合わせる対象にならない**ということである。

動力学系列（5 / 40 / 300）に 2^d は一つも無いが、**動力学が走らないという意味ではない**。
幾何側の言明（楕円面・平行多面体）と突き合わせるときだけ N ∈ {2,4,8,16,32,…} が要る。
CSV は .gitignore（*.csv）で追跡外。上記で決定論的に再生成できる。
