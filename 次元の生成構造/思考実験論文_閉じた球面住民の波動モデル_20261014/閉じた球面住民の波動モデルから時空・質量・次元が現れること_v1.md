# 閉じた球面住民の波動モデルから時空・質量・次元が現れること

Oct 14, 2026 · @木原範昭

## 要旨

背景時空・時間・ハミルトニアンを一切置かずに、閉じた球面（S¹ および S³）の上の虚数振幅の波から出発し、公理 Σxₙ² = R² だけを用いて、量子化（節数 n）・フェルミオン／ボゾンの区別（奇偶）・局在・光速一定・ローレンツ因子・固有時・相対論的速度合成・ヒッグス的背景場・三次元の必然性・スピン・電荷・不確定性・量子化が順に導かれることを、思考実験と数値実験により確認した。

さらに、一様な並進が群をなすこと（結合法則）、尾を引かずに伝わること（ホイヘンス原理）、住民が読める曲率で質量ギャップが生じることの三条件をすべて満たす球面が S³ だけであることを示し、空間の次元が三次元に限定される理由を提示する。

## 1. 問題の設定

標準的な物理学は、時間 t・空間座標・ハミルトニアン・背景計量のいずれかを前提に構築される。本研究の問いは「それらを一切置かずに出発したとき、物理的に意味のある構造はどこまで現れるか」である。

採用した公理はただ一つ。閉じた円周（S¹）または四次元球殻（S³）の上に、本当の二乗（共役をとらない）の和として次を要求する。

```latex
\sum_n x_n^2 = R^2
```

ここで xₙ は虚数振幅を持つ波の各成分、R² は正値のノルムではなく本当の二乗の和である。背景空間はなく、外から与える半径もない。R は波自身が決める量である。

この一行から出発し、以下の節で段階的に構造を確認した。

## 2. 円周住民モデル（S¹）

半径 R の円周に住む住民を考える。背景時間も背景空間もなく、住民が読める量は位相 θ と虚数振幅 A だけである（外から見た R は内在曲率を持たないため住民には読めない）。

**振幅の方向** 接線直交方向が存在しないため、振幅は虚数方向に置く。すると波は虚数振幅の横波のみである。

**節と量子化** 振幅がゼロになる位相を節と定義し、一周あたりの節の数を n とする。n は整数のみを取り、ここで量子化が生じる。

**偶奇の区別** n が奇数のとき、一周（360°）で振幅の符号が反転し、二周（720°）で初めて閉じる。n が偶数のとき、一周で閉じる。これはフェルミオン的／ボゾン的回帰の区別に対応する。

**局在の発生** 各成分を等振幅で重ねると、合成振幅は一か所に鋭い山を持つ局在した波形になる。局在が生まれることと基準点 θ₀ が決まることは同じ一つの出来事である。奇数成分がゲージとなり原点を与え、高次成分が整数倍の位相で従う。

**偶奇の釣り合いと一点への局在** 偶数成分だけでは対蹠点（θ₀ + π）にも同符号の山が立ち、位置が二点の間で曖昧になる。奇数成分だけでは対蹠点に逆符号の山が立つ。両方がそろって釣り合ったとき初めて山が一点に決まる。

## 3. 指数表現と E 関数

振幅 α = ln A、位相 φ = θ − θ₀ として、合成波を指数表現で書く。

```latex
f(N,\theta_0) = e^{\alpha + i\pi/2} \cdot \frac{e^{i(N+1)\varphi/2} - e^{-i(N+1)\varphi/2}}{2(e^{i\varphi/2} - e^{-i\varphi/2})}
```

E 関数を E = ln f と定義すると、実部 Re(E) = ln|f| は節で −∞ に発散し、虚部 Im(E) は +π/2 か −π/2 の二値のみを取り、節ごとに π 跳ぶ。

この表現の重要な性質は次の二つである。

- 振幅 α は加算定数であり、勾配 ∂E/∂θ には効かない。物理的な読出しは比（勾配）のみで決まる。
- ∂E/∂θ₀ = −∂E/∂θ が成り立ち、θ₀ の動きは位相の勾配として読める。

基準点 θ₀ は外から置いた原点ではなく、全成分の位相が揃う点を合成により一意に確定したものである。局在の発生と原点の確定は同一の出来事である。

## 4. S³ への拡張

四次元球の表面 S³ は三次元閉空間であり、SU(2) ≅ S³ の同型から、円周の代わりに用いることができる。

**内在曲率の登場** S³ は内在曲率 1/R² を持つ。固有値は n(n+2)/R² = (n+1)² − 1 となり、「−1」の項が曲率に由来する。これは円周にはなかった質量ギャップの起源となる。

**座標** 測地距離 ψ（ψ = s/R）を用いると、S¹ の式の φ/2 → ψ で同形の式が書ける。三つの基準点（χ₀, θ₀, φ₀）が生じ、ゲージ自由度は三つになる。

**ホップ座標と η の性質** (z₁, z₂) = (cos η · e^{iξ₁}, sin η · e^{iξ₂}) 表示では、ξ₁₀、ξ₂₀ は純粋な位相（ゲージ）であるが、η₀ は二つの円の混合角であり位相ではない。三つ同時に位相にすることはできない。

**S³ の対蹠点での対称性** 対蹠点 ψ = π での成分の値は (−1)ⁿ である。奇数成分だけでは対蹠点に逆符号の山、偶数成分だけでは同符号の山が立つ。両方が釣り合うと対蹠点は消え、局在は一点に限定される。これは S¹ の場合と同じ偶奇の構造が三次元空間の配置として現れたものである。

## 5. 自己無撞着殻と Σxₙ² = R²

R を外から与えず、Σxₙ² = R²（つまり Σxₙ² + (iR)² = 0）という条件で決める。これは殻が波の形を決め、波が殻の形を決める循環を一本の式に内包したものである。

各成分を xₙ = iA·cos(n(θ−θ₀)/2) とすると、本当の二乗を取ると xₙ² = −A²·cos²(n(θ−θ₀)/2) は負の実数であり、Σxₙ² は負となる。したがって R² < 0、R は虚数（振幅の方向）であり、外の空間に「半径」として置いたものではない。

**数値実験についての注記** 初期の数値実験では、殻の式に各成分の絶対値の二乗 |xₙ|² を用い、R を実数の半径として実空間に描き、その中で重心を計算した。これは本当の二乗の公理から外れ、排除したはずの背景空間を持ち込んでいたため、そこで得られた重心のずれ・針状構造・対称性の破れの候補は公理の帰結ではない。本稿ではこれらを結果として採用せず、以降の節は本当の二乗に基づく読出しのみを用いる。

## 6. ゲージ間隔と測地線長の不等間隔

住民には曲率は読めない。読めるのは、位相のゲージ間隔（最高次成分の節で刻まれる等間隔の位相目盛）と、それに対応する測地線長 Δs = ∫|R|dθ の比である。

定義：R² = Σxₙ² = −A²·Σcos²(n(θ−θ₀)/2)（負のため R は虚数）。測地線長は Δs = i∫|R|dθ であり、i は全区間共通の因子なので Δs/⟨Δs⟩ の比は実数となる。

**主な数値結果（全次数 N=18）**

| 系 | ピーク区間の比 | 対蹠点の区間の比 |
| --- | --- | --- |
| 全次数 N=18 | 1.245 | 0.988（普通） |
| 奇数次 N=17 | 1.252 | 0.835（短い） |
| 偶数次 N=18 | 1.236 | 1.236（対称） |

**住民への読出し** 外から見た曲がり方ではなく「同じ一目盛りなのに長さが違う」という形で局在が読める。偶数系だけでは対蹠点と区別がつかない。奇数成分があるとき初めて、ピークと対蹠点の長さが非対称になり、位置が一意に読めるようになる。

対数の勾配 ∂θ ln|R²| をテンソルとして読むと、R² の符号（正か負か）は傾斜の向きを変えるだけで、傾きの大きさは変わらない。これは計量の符号が時間的・空間的の区別を与えるだけで、勾配の情報は共通であることと対応する。

## 7. 光円錐読出し：速さ・質量・固有時

成分を xₙ = iA·(a·e^{inφ/2} + b·e^{−inφ/2}) とする（a, b ≥ 0、a + b = 1）。本当の二乗を取ると

```latex
x_n^2 = -A^2(a^2 e^{in\varphi} + b^2 e^{-in\varphi} + 2ab)
```

R² = Σxₙ² をフーリエ展開すると三つの成分に分かれる。

- 方向成分 k = P₊ − P₋（正・負の回転の係数差）
- 張り付いた成分 m = P₀（φ によらない交差項 2ab·N の和）
- 全体 R = P₊ + P₋

読出しは v = k/R、1/γ = m/R。

**恒等式** (a² + b²)² = (a² − b²)² + (2ab)² が代数的に成り立つため、v² + (1/γ)² = 1 が正確に（数値残差 < 10⁻¹⁵）成立する。これは Σxₙ² = R² を光円錐 R² = k² + m² として読んだものそのものである。

**速さと重み比** v = tanh(ln(a/b))、1/γ = sech(ln(a/b))。ln(a/b) がラピディティに対応する。

**速度合成** 重み比を掛け合わせた合成波の速さは、相対論の速度合成則 (v₁ + v₂)/(1 + v₁v₂) と小数点以下 6 桁まで一致した。ガリレイ的な単純和とは異なり、光速を超えない。

**ヒッグス的背景の自然な出現** 交差項 2ab·N（φ によらない項）は、逆回りの回転項が混在するとき自動的に生じる。これは空間に張り付いた静的な位相の背景であり、外から置く必要がない。この背景とのビートが固有時の進みを与える。

z = a + ib（実数 a, b で構成される複素数）と読むと、z² = (a² − b²) + i·2ab であり、実部が方向成分 k、虚部が背景成分 m、絶対値が R に対応する。光円錐の分解は z の一乗の代数に内在している。

## 8. 位相回転の作用と時間発展

背景の時間 t を置かないまま、次の三段の作用を定義する。

1. **回転の総量**：任意のパラメータ β を一段進める。
2. **配分**：光円錐の比 (v, 1/γ) に従い、β を空間方向の並進 v·dβ と内部時計の進み dβ/γ に割り振る。
3. **適用**：全成分を一度に θ₀ を v·dβ だけずらす（S³ では四元数の左積）。交差項 2ab は θ₀ を含まないため張り付いたまま動かない。

S³ での並進は、四元数 q = cos(v·dβ) + u·sin(v·dβ) を左から掛けるクリフォード平行移動であり、固定点を持たない。この操作は群をなし、二回の並進は一回にまとめられる（速度合成則と一致）。

**「t なし」で見える時間発展** この系に入っているのは、位相・虚数振幅・Σxₙ² = R²・θ₀ のずらし操作だけである。その中から次が読み出せる。

- **速さ v**：± 回転項の重みの比から決まる。
- **固有時 τ**：背景（交差項）とのビートを積み上げた数 τ = β/γ として現れる。光子的状態（b = 0）では τ = 0 のまま進まない。
- **光速一定**：どの状態でも v² + (1/γ)² = 1 が成り立ち、住民の物差しで測った速さは常に 1 になる。
- **速度合成**：ラピディティの加法 ln(a₁a₂/b₁b₂) として相対論的合成則に従う。

「時間が経つ」ことはどこにも書いていない。見えているのは、並進距離・回転の総量・ビート数の三つの間の固定した比の関係である。その関係が相対論で「時間」と呼ばれるものと同じ形をしている。

**Page–Wootters 機構との違い** Page と Wootters（1983）は全体としては静止した量子もつれ状態から、内部の相関として時間発展を導いた。本モデルはハミルトニアンもヒルベルト空間も置かず、位相の回転とその配分だけから同様の構造が現れる。

**観測者は系の内側にいる** β を「外の時計で刻む」という問いへの答えがここにある。観測者も同じ球面の住民であり、自分の波を持つ。観測者の重み比 ln(a\_obs/b\_obs) が観測者自身のラピディティを決め、観測者のビート数 β\_obs = β·(1/γ\_obs) が観測者の固有時になる。他の粒子の速さや固有時は、二つのラピディティの差 Δη = ln(a\_particle/b\_particle) − ln(a\_obs/b\_obs) から読み出される。

これにより特殊相対性理論の思考実験が直接再現できる。

- **観測者を粒子に合わせる**（Δη = 0）：v' = tanh(0) = 0 で粒子が止まって見える。
- **観測者を逆向きにする**（Δη が大きくなる）：v' が大きく見え、粒子の固有時が縮む。
- **二人の観測者が同じ粒子を測る**：どちらの観測者から見ても v'² + (1/γ')² = 1 が成り立つ。光円錐の形はどの観測者からも変わらない。

速度の合成は v' = tanh(η\_particle − η\_obs) として出てきて、相対論の合成則 (v\_p − v\_o)/(1 + v\_p·v\_o) と厳密に一致する。神の目線はなく、優先系もない。これが、閉じた球面の住民たちの間で自然に成り立つ相対性原理である。

**S³ 版でも同じ構造が成り立つ** S¹ の観測者の議論は、そのまま S³ に拡張できる。S³ 版では観測者も粒子と同じ球面上に局在した波として存在し、ピーク位置（χ\_obs, θ\_obs, φ\_obs）を S³ 上の任意の場所に置ける。観測者のラピディティ ln(a\_obs/b\_obs) が観測者自身の運動状態を決め、観測者が読む粒子の速さは tanh(η\_particle − η\_obs) で与えられる。

S³ 上の観測者のピーク位置は速さの読出しに影響しない。速さはラピディティの差のみで決まり、二つの局在波が S³ のどこにいるかには依存しない。これは均質な空間——どこから見ても同じ法則が成り立つ——をこのモデルが自動的に持っていることを意味する。v'² + (1/γ')² = 1 は、どの観測者のラピディティを選んでも、またピーク位置をどこに置いても、常に成り立つ（数値実験で v'² + (1/γ')² = 1.000000 を確認）。

**観測者は系の一部であり、観測は交差項を通じた相互作用である（修正と次の課題）**

本節で示した観測者の実装には、公理から外れた点がある。観測者のラピディティをスライダーで直接設定し（神の手による加速）、観測者と粒子の R を別々に計算し、観測をラピディティの差の計算で済ませていた。公理 Σxₙ² = R² は系全体に対する条件であり、観測者も同じ和に入らなければならない。

粒子の成分 x^(p) と観測者の成分 x^(o) を合わせて本当の二乗をとると、

```latex
\sum (x^{(p)} + x^{(o)})^2 = \sum (x^{(p)})^2 + \sum (x^{(o)})^2 + 2\sum x^{(p)} x^{(o)}
```

交差項 2Σx^(p)·x^(o) が相互作用であり、これが観測そのものである。交差項の中の a\_p·b\_o と b\_p·a\_o の比が e^{η\_p − η\_o} になるので、観測者が読む相対ラピディティは、本来この交差項から読み出すべき量である。

**読めること、放射すること、エネルギーが分配されることは同じ出来事**

R² は公理により一定だが、その配分は変わる。観測者が粒子を読めるのは交差項がゼロでないからで、その分だけ粒子の自己項と観測者の自己項から R² が引かれる。読出しが起きた時点で、R² は三つに分配されている。

- 粒子の自己項（粒子の質量・運動）
- 観測者の自己項（観測者の質量・運動）
- 交差項（相互作用＝放射）

交差項がゼロなら読めず、読めるなら必ず交差項があり、その分が放射として出ている。観測者の加速（a\_o/b\_o の変化）も、閉じた系では交差項を通じた R の再配分としてしか起こらない。放射なしに加速はできず、交差項なしに観測はできない。標準的な量子論では測定の反作用は別に置かれた原理だが、本モデルでは公理の帰結になる。

交差項を展開すると、二種類の項に分かれる。

- **位置に依存する項**（a\_p·a\_o·e^{in(2φ−φ\_o)/2} など、同じ向きの回転項の積）：空間の位相に乗って伝わる放射の波。
- **位置に依存しない項**（a\_p·b\_o、b\_p·a\_o など、逆向きの回転項の積）：相対ラピディティに依存するビート項。観測者が読む速さそのもの。

**次の課題：電磁波・重力波の放射と吸収、反跳、引力**

この交差項の構造から、次の現象が同じ枠内で描ける可能性がある。

1. **放射と吸収**：交差項の位置依存部分が一方の波から他方へ移ることが放射・吸収に当たる。
2. **重力波と電磁波の区別**：R は空間の読みなので、交差項による R の再配分は計量の変化、つまり重力的な相互作用である。一方、ホップ・ファイバーの巻き数（電荷、第 11 節）が交差項を通じてやり取りされる部分が電磁気的な相互作用である。同じ交差項のどの部分を読むかで、重力波か電磁波かに見える。
3. **反跳**：放射で交差項が R を持ち去れば、残った自己項の配分（k と m の比）が変わる。これが反跳である。
4. **引力**：二つの局在波の交差項が、両者の距離によってどう変わるかを調べれば、距離に依存した R の配分、すなわち力として読める可能性がある。
5. **スピンと電荷の相互作用**：交差項は奇偶（スピン）とファイバーの巻き数（電荷）の両方を含むので、スピンと電荷が相互作用にどう寄与するかも同じ式から出る。

いずれも Σxₙ² = R² を系全体に課し、交差項を読むだけで到達できる見込みがあり、新しい仮定は要らない。本稿ではここまでを課題として記し、数値実験は次の段階に回す。

## 9. なぜ三次元か

本モデルが S³ を用いたことは、作業上の仮定ではなく次の三つの条件から唯一に絞られる。

**条件 A：一様な並進が群をなす球面** 全点で向きのそろった一様な流れを張れる球面は、Adams の定理（1960）により平行化可能な S¹、S³、S⁷ のみである。このうち二回の並進を一回に合成できる（群をなし速度合成則を持てる）のは、リー群の構造を持つ S¹ と S³ だけで、S⁷（八元数）は結合法則 (pq)r = p(qr) を満たさないため合成が閉じない。したがって条件 A を満たすのは S¹ と S³ のみとなる。

**条件 B：ホイヘンスの原理（尾を引かない伝播）** 奇数次元球面でのみ成立する。波が対蹠点で鋭く再収束し、尾を引かずに打ち消し合う。偶数次元（S²、S⁴ 等）では波が広がって残留し、対蹠点での打ち消し合いが不完全になる。これが「次元が合わないと系が安定しない」理由の本体である。

**条件 C：住民が読める曲率（質量ギャップと左右の区別）** 固有値に曲率の項が現れ、質量のギャップが生じること。S³ の固有値は (n+1)² − 1 で、「−1」が曲率に由来する。また S³ では左からの並進と右からの並進が別物になり、左右の手の区別が生じる。S¹ には住民が読める内在曲率がなく、質量ギャップも左右の区別も生じない。

**結論** 条件 A を満たすのは S¹ と S³、条件 B を満たすのは奇数次元の球面（S¹, S³, S⁵, …）、条件 C を満たすのは S¹ を除く球面である。A・B・C の三つがすべて成り立つのは S³、すなわち三次元空間だけである。局在した質量のある粒子が安定に存在できるのは、三次元だけということになる。

**S⁷ の位置づけ** S⁷ は条件 A の「一歩手前」まで行ける。一様な並進の場は張れるが結合法則がないため群にならない。八元数の自己同型群 G₂ の中で一つの虚数単位を固定する部分群は SU(3) であり、S⁷ の構造は空間にはなれないが内部の色自由度として残る可能性がある（Furey らの先行研究と方向が一致）。

**z² の制約との対応** フルヴィッツの定理（1898）により、二乗で大きさの関係が保たれる数の体系は実数（方向 0）・複素数（1）・四元数（3）・八元数（7）の四つのみ。結合法則まで満たすのは複素数と四元数だけであり、方向の数はそれぞれ 1 と 3 に対応する。S¹ と S³ の選択は、z² から光円錐を閉じる代数的要請と一致している。

## 10. スピンの読出しとヒッグス場のスピン 0

**スピンはすでにモデルの中にある**

第 2 節で確認した偶奇の区別が、そのままスピンの読出しになる。

- 奇数成分を含む → 360° 回転で符号が反転し、720° で初めて元に戻る → スピン 1/2
- 偶数成分のみ → 360° で元に戻る → 整数スピン

S³ ≅ SU(2) なので、左からの四元数乗算の三つの生成子 i, j, k がそのままスピン演算子 Sₓ, Sᵧ, S\_z に対応する。図で「進行方向 i / j / k」と選んでいた軸は、空間の並進方向であると同時にスピンを向ける軸でもある。

さらに、左からの乗算（SU(2)\_L）と右からの乗算（SU(2)\_R）は独立で、合わせて SU(2)\_L × SU(2)\_R ≅ SO(4) になる。この二つの SU(2) の一方が空間回転（スピン）、もう一方が別の内部自由度（弱い相互作用の SU(2) の候補）に対応する可能性がある。

**位置の確定とスピンの確定は両立しない**

奇数成分と偶数成分を混在させると、局在が一点に確定する。しかしそのとき、360° 回転後の状態は、偶数部分はそのまま、奇数部分だけが反転した状態になり、元の状態でも −1 倍でもない。スピンは既約表現の重ね合わせとなり不定になる。逆にスピンを確定させようとすると（純粋に奇数か偶数だけにすると）、局在が崩れる。

位置の確定とスピンの確定が同時に成り立たないこの構造は、自然界で半整数スピンと整数スピンの重ね合わせを持つ粒子が存在しない（超選択則）ことと方向が一致している。

**ヒッグス的背景がスピン 0 になる理由**

交差項がスピン 0 になる理由は一行で言える。xₙ = iA(a·e^{inφ/2} + b·e^{-inφ/2}) を本当の二乗にすると、交差項は a·e^{inφ/2} × b·e^{-inφ/2} = ab となる。+ の回転項の角運動量 +n/2 と − の回転項の角運動量 −n/2 が打ち消し合い、すべての n について交差項は φ にも ψ にも依存しない定数になる。

S³ 上の定数関数は、SU(2)\_L × SU(2)\_R のすべての元に対して不変である。これはスピン 0 のスカラー場の定義そのものである。外から置いたのではなく、+ と − の回転項が同じ閉じた空間の上に同居しているという構造から自動的に出てくる。

標準理論でヒッグス場がスピン 0 になる理由も本質的に同じで、左巻きと右巻きの成分の角運動量が打ち消し合ってスカラーを作る。本モデルではそれが波の本当の二乗の交差項として自然に現れる。

**三つの読出しが整合する**

スピンとヒッグス場を合わせると、一つの整合した像になる。

- 粒子の波（奇数 + 偶数の混在）：局在しているが、スピンは既約表現の重ね合わせで不定。
- ヒッグス的背景（交差項 2ab·N）：空間全体に張り付いており、スピン 0 確定。
- ビート（粒子と背景の干渉）：固有時を与え、質量を生む。スピン 0 の背景との相互作用なので、粒子のスピンは変わらない。

これは標準理論でヒッグス機構により質量を得てもスピンが変わらないという性質と一致している。また、スピンが不定な局在波とスピン 0 の背景が別々に存在するのではなく、一つの閉じた条件 Σxₙ² = R² の中に同居していることが、このモデルの特徴である。

**スピン固有状態は二点局在であり、粒子の局在と矛盾しない**

奇数成分だけの合成波（スピン 1/2 固有状態）は、θ₀ に +i の山、対蹠点に −i の山を持つ二点局在である。これは「局在していない」のではなく「二点に局在している」のであり、スピノルが 360° 回転で符号反転するという性質が、S³ 上では空間の二点の符号の差として幾何学的に現れたものである。整理すると次のようになる。

- 奇数成分のみ（スピン 1/2 固有状態）：θ₀ に +i、対蹠点に −i。二点局在でスピン確定。
- 偶数成分のみ（整数スピン固有状態）：θ₀ に +i、対蹠点にも +i。二点局在でスピン確定。
- 奇数と偶数が釣り合う（一点局在）：対蹠点の山が打ち消されて θ₀ 一点に局在。スピンは既約表現の重ね合わせで不定。

**世界の反対側に逆スピンがある——しかし誰も観測できない**

スピン 1/2 固有状態では、粒子が θ₀ にいるとき、対蹠点に必ず逆スピン（−i）の山が立つ。これは「粒子を生成するとき、S³ の反対側に逆スピンの対が生まれている」という構造である。

しかし観測者も同じ S³ の住民であり、θ₀ に局在した波を持つ。観測者の波と対蹠点の山の間には測地距離 πR がある。S³ が宇宙全体であれば対蹠点は観測可能な地平線の外にあり、ビートの読出し（第 7 節）は二つの波が同じ位相を共有する場所でのみ意味を持つため、対蹠点の情報は原理的に読み出せない。粒子の局在と対蹠点の逆スピンは矛盾せず共存する。

ディラック方程式の正エネルギー解と負エネルギー解（反粒子の解釈）が、S³ 上のピークと対蹠点の山として幾何学的に実現されているという読み方もできる。

**質量を持つことと、反対側の影を消すことは同じ出来事**

奇数と偶数を混ぜて一点局在にすると、対蹠点の山が打ち消される。このとき同時に、交差項（ヒッグス的背景）が生じて質量が現れる。つまり、対蹠点の逆スピンの影を消す操作と、質量を与える操作は同じ一つの出来事である。

スピンが確定していた状態（対蹠点に影がある、質量ゼロ）から、一点に局在した状態（対蹠点の影が消え、スピン不定、質量あり）へ。この移行が、光子的な状態から質量のある粒子への移行と対応している可能性がある。

## 11. 電荷の読出し：ホップ・ファイバーの巻き数

電荷は外から置くものではなく、閉じた空間の位相の巻き数という位相的な不変量として読み出せる。

**ホップ・ファイバーの巻き数が電荷**

S³ には自然なホップ・ファイバー S¹ → S³ → S² が備わっている。(z₁, z₂) = (cos η·e^{iξ₁}, sin η·e^{iξ₂}) の表示で、位相 ξ₁ と ξ₂ の和または差が S¹ ファイバーを回る。波 x\_n がこのファイバーを何周するかという巻き数が電荷である。

成分 e^{inφ/2} はファイバーを +n/2 巻き、e^{-inφ/2} は −n/2 巻きする。全成分の純の巻き数は次のようになる。

| 状態 | ファイバーの巻き数 | 電荷 |
| --- | --- | --- |
| 純粋に + の回転項（b = 0） | +Σn | 正 |
| 純粋に − の回転項（a = 0） | −Σn | 負 |
| 釣り合った定在波（a = b） | 0 | 中性 |
| 交差項（ヒッグス的背景） | 0（ファイバーを巻かない） | 0 |

交差項の電荷が 0 であることは、第 10 節のスピン 0 と整合している。

**電荷の量子化は位相の巻き数の整数性から出る**

これは E 関数（第 3 節）の中にあった構造である。Im(E) は節ごとに π 跳び、一周あたりの位相の総巻き数は整数になる。この整数が電荷の量子化の起源であり、Σxₙ² = R² を閉じた空間の上で要求したことの帰結である。

**ヒッグス機構との対応**

第 7 節で見たように、a ≠ b のとき交差項（ヒッグス的背景）が生じる。これと同時に、SU(2)\_L × SU(2)\_R の対称性が破れ、残った U(1) が電磁 U(1) になる。この残った U(1) の生成子の固有値がファイバーの巻き数、すなわち電荷である。標準理論の電弱統一における対称性の自発的破れと同じ構造が、本モデルでは + と − の回転項の重みの偏りとして現れる。

**ラピディティの偏り k との区別**

電荷の読出しを確立するには、ファイバーの巻き数と k = P₊ − P₋（第 7 節）を区別する必要がある。k は「どちら向きに並進するか」という運動量の情報であり、巻き数は「ファイバーを何周するか」という位相的な情報である。静止状態（a = b）では k = 0 だが、巻き数はそれとは別に定まる。この区別が、電荷と運動量が異なる量であることの幾何学的な根拠になる。

**読出しの全体像**

本モデルで読み出せる量を整理すると、次のように一つの条件 Σxₙ² = R² の異なる読み方に対応する。

| 量 | 読出しの起源 |
| --- | --- |
| 量子数 n | 節の数（第 2 節） |
| 速さ v、固有時 τ | 光円錐の分解 z² = k + im（第 7 節） |
| 質量 m | 交差項 2ab（第 7 節） |
| スピン | 奇偶の区別と SU(2)\_L の生成子（第 10 節） |
| 電荷 | ホップ・ファイバーの巻き数（第 11 節） |
| 空間の次元 | 結合法則・ホイヘンス原理・曲率の三条件（第 9 節） |

## 12. 不確定性と量子化は公理の帰結である

不確定性は「読出しが比でしか行えない」ことから、量子化は「閉じた空間で位相が閉じなければならない」ことから、どちらも別の原理を置かずに Σxₙ² = R² から出ている。

**不確定性：三種類**

| 種類 | 内容 | 出どころ |
| --- | --- | --- |
| 位置と倍音数 n | 単一の n では一様で位置が定まらず、多数の n を重ねると幅 πR/(N+1) に局在する。Δθ·Δn ≈ 一定 | フーリエ共役（第 2 節） |
| 位置とスピン | 一点局在には奇偶の混在が必要で、そのときスピンは既約表現の重ね合わせで不定。スピン固有状態は二点局在 | 表現論（第 10 節） |
| 読出しと反作用 | 読めるなら交差項があり、交差項があるなら R が再配分されている。乱さずに読む方法は原理的にない | 系全体の本当の二乗（第 8 節） |

一つ目は n を運動量と読めば、ハイゼンベルクの位置と運動量の不確定性そのものである。二つ目は標準的な量子論にはない形で、三つ目は標準理論では別に置かれる測定の反作用が公理の帰結になっている。

**量子化：五種類**

| 量 | 離散性 | 出どころ |
| --- | --- | --- |
| 倍音数 n | 整数 | 円周上で閉じる条件（第 2 節） |
| 電荷 | 整数（ホップ・ファイバーの巻き数） | 位相的不変量（第 11 節） |
| 定在波の位相 | Im(E) ∈ {π/2, 3π/2} の二値 | E 関数（第 3 節） |
| 位相の周回積分 | ∮（位相）= 2π × 整数（偶数は一周、奇数は二周で閉じる） | 閉じる条件（第 2 節） |
| 読出し単位 | 位置はゲージ目盛の区間、固有時はビートの回数 | 住民の物差し（第 6 節、第 8 節） |

四つ目は、成分 n が一周で位相 2π·(n/2) を積み上げるという形で、ボーア・ゾンマーフェルトの量子条件 ∮p·dq = nh と同じ構造になっている。五つ目は、連続的な θ₀ や τ は住民には見えず、どの目盛の区間か、何回のビートかだけが読めるという、読出しの側の離散性である。

**示唆にとどまるもの：相対速度の量子化**

ラピディティ a/b は現段階では連続である。しかし観測者を同じ Σxₙ² = R² に入れると、交差項 e^{i(n\_p ± n\_o)φ/2} も閉じる条件を満たす必要があり、そこから a/b に離散的な制約が出る可能性がある。もしそうなら相対速度が量子化されることになり、標準理論にない予言になる。第 8 節末尾の課題（二つの波の交差項）の数値実験で同時に確かめられる。

## 13. 先行研究との比較

| 先行研究 | 共通点 | 相違点 |
| --- | --- | --- |
| Shanahan（2014）定在波→進行波でLT導出 | 逆向き二波の重み比が速さを決める。v = (a²−b²)/(a²+b²) はドップラー比と同形 | Shanahan は t・x を前提に置き γ を仮定。本モデルは t も γ も置かず、交差項から 1/γ が出る |
| Feynman チェッカーボード（1965）／Jacobson–Schulman（1984） | 右向き R・左向き L の二成分で \|R\|²/\|L\|² = (E+p)/(E−p)、v・1/γ・光円錐の関係が同形 | 離散時空格子と時間刻みを前提。本モデルは連続で t なし |
| Page–Wootters（1983）「evolution without evolution」 | t なしの全体から相関として時間発展が現れる | ハミルトニアンと量子もつれを前提。本モデルはそれらなし |
| de Broglie の内部時計（1924）・Hestenes のツィッターベヴェーグング | 質量を内部振動数と結びつける | 背景時空の上での記述 |
| Furey ら（八元数と標準模型） | S⁷・G₂・SU(3) の構造が色自由度と結びつく可能性 | 本モデルは S⁷ を「空間にはなれない内部自由度」として同様に位置づけ |

本モデルが既存の研究に対して持つ独自の特徴は次の点である。

- 時空・時間・ハミルトニアン・背景計量を一切置かず、閉じた球面と Σxₙ² = R² だけから出発する。
- 光速一定・ローレンツ因子・固有時・速度合成がすべて恒等式として成立し、仮定でない。
- ヒッグス的背景（交差項 2ab）が外から置かれるのではなく、逆回りの回転項の混在から自動的に生じる。
- 三次元の特殊性が、結合法則（代数）・ホイヘンス原理（伝播）・曲率による質量ギャップ（幾何）の三条件の交差として論理的に導かれる。

## 14. 結論と今後の課題

閉じた球面の上の虚数振幅の波と公理 Σxₙ² = R² だけから、次の構造が順に現れることを確認した。

- 波の量子化（節数 n の整数値）
- フェルミオン的／ボゾン的回帰の区別（n の偶奇）
- 倍音合成による局在と基準点の確定
- 本当の二乗による光円錐 R² = k² + m²（代数的恒等式）
- ローレンツ因子・固有時・相対論的速度合成
- ヒッグス的背景の自然な出現（交差項として）
- 三次元の特殊性（結合法則 × ホイヘンス原理 × 曲率による質量ギャップ）

これらはいずれも「仮定」ではなく、出発点の公理から導かれる帰結である。

**今後の未解決課題**

1. **β を進める基準の内側からの導出**　現時点では β は外から刻むパラメータである。系の内側からある量を β に選ぶ条件を決めれば、「時間発展が見える」から「時間発展が導かれる」に変わる。
2. **電荷に相当する量の読出し**　第 11 節でホップ・ファイバーの巻き数を電荷の候補として示した。ファイバーの巻き数と運動量 k を数値的に分離して読み出す実験と、巻き数の整数性の確認が次の課題である。
3. **S⁷ の役割の明確化**　S⁷ が空間ではなく内部自由度（色）として現れるかどうかを、本モデルの枠内で検証する。
4. **複数の局在した状態の相互作用**　現時点では単一の局在した山だけを扱っている。第 8 節末尾に示した通り、二つの波を同じ Σxₙ² = R² に入れたときの交差項が相互作用であり、放射・吸収・反跳・引力・スピンと電荷の寄与がすべてそこから読める見込みがある。これが本研究の次の主題である。
5. **自己無撞着殻の安定性解析**　数値実験で見つかった非対称解（自発的対称性の破れの候補）の安定性を厳密に示す。

**この思考実験の意義**　時間・空間・質量がそれぞれ別の場所から「置かれた」のではなく、一つの閉じた条件 Σxₙ² = R² の異なる読み方として同時に現れることを、インタラクティブな数値実験と段階的な構成によって視覚的に確認した。この構成は、背景を持たない物理の基礎を探る上で有力な思考実験の枠組みを提供する。
