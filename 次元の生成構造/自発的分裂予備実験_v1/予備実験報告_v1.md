# 自発的分裂 予備実験 v1 報告

実行日: 2026-07-21
スクリプト: `run_spontaneous_splitting_preliminary_v1.py`

## 1. 目的と設計

第5論文「複数の波は、閉鎖条件のもとで自発的に分裂しうるか」のための予備実験。

- 状態: 複素ベクトル Z ∈ C^M（N=4, M=6 完全関係波）
- 更新: 実直交 Cayley 行列 U = (I−γK)^{-1}(I+γK)、γ = tan(π/144)。
  実直交更新は複素双線形二乗和 Z^T Z（閉鎖量）とエルミートノルムを同時に厳密保存する
- 統制（実験N）: K を τ=0 の位相で凍結（固定生成子）
- 実験O1: K_ef = A_ef sin(θ_f−θ_e) を毎ステップ現在の位相から再構成（凍結解除）。
  位相差のみの関数なので零次同次＝公理0.5（スケール無名性）に適合
- 自発性の操作的定義: 親状態の力学的不安定性。
  種振幅 δ によらない固有成長率での指数成長 ＋ 到達時刻の log(1/δ) 比例

## 2. 理論的発見（実装過程で確定した構造）

### 発見A: 自己無撞着な親状態は円偏波固有モードに限る

実係数の平面内状態は全成分位相が共線（ψ, ψ+π の二値）となり、
sin 位相差が消えて生成子が退化する。自己無撞着な親は固有モード
v = (p+iq)/√2 でなければならない。固有モードなら更新は共通位相回転
（U v = e^{−iθ} v）なので位相差が不変、K(arg Z) が不変となり、
δ=0 で厳密な周期軌道になる（数値検証: 1周期の K 変動 9.2e-14、f=0 を維持）。

### 発見B: 自己無撞着な親の生成子は rank 2

K(arg v) は回転平面を一つしか持たず（σ=1）、残り M−2 次元は核（静的部分空間）。
親状態は「自分の平面」だけを見ており、休眠方向はすべて核に属する。
したがって休眠種 δ は核方向へ複素係数で置く。

### 発見C: 閉鎖保存力学の全体は Ẋ = K(X)X（K 反対称）で尽くされる

閉鎖球面の接ベクトル場は反対称行列の作用で書けるため、
「状態依存生成子」は候補の一つではなく閉鎖保存力学の全空間である。
固定生成子はその特殊例 K(X)=K₀ にすぎない。

## 3. 数値結果

### 3.1 統制（実験N）: no-go の再確認

固定生成子のもとで参照レジスタ比率の最大変動 6.5e-12（機械精度）。
休眠核成分は δ² のまま一切成長しない。帰結16.5/16.6 と整合。

### 3.2 実験O1: 自発的分裂の開始が成立

- 休眠フラクション f(τ) = 1 − h_親平面/h_total が指数成長
- 成長率（中央値）: δ = 10⁻² → 4.004e-2/step、10⁻³ → 4.011e-2、
  10⁻⁴ → 4.011e-2、10⁻⁵ → 4.010e-2 — **3桁の δ にわたり不変**
- 閾値到達時刻 τ_c(f≥10⁻²) の中央値: 133 → 217 → 300.5 → 384.5
  （δ 1桁につき約84ステップの等間隔シフト＝log(1/δ) 比例）
- 相対閾値（f ≥ 10 f(0)）の到達時刻は δ 非依存（約77ステップ）
- δ=0（厳密周期軌道）でも、浮動小数の丸め誤差だけを種として
  τ≈850 で f > 10⁻¹⁰ に成長 — 任意に小さい摂動で崩れる

以上は「親状態の力学的不安定性」の操作的基準をすべて満たす。

### 3.3 閉鎖の厳密保存

全モードで Re(Z^T Z)、Im(Z^T Z)（§13の実部・虚部二条件）、|Z|² の
最大偏差 ≤ 2e-14。分裂開始は閉鎖を破らずに進行する。

### 3.4 スケール無名性（公理0.5）の数値検証

- λ = 1024 = 2¹⁰（まるめ誤差ゼロのスケール変換）: 比率観測量が **bitwise 一致**
- λ = 987.654、共通位相 e^{i0.7}: 最大偏差 ~1e-13（まるめ差の緩慢な増幅のみ）
- 双子摂動 1e-13 の発散率 2.5e-4/step（弱い鋭敏性、固定統制では発散なし）

### 3.5 分裂は開始するが固定しない（FPUT型再帰）

- f は普遍的な天井 ≈ 0.335–0.338 で飽和し、その後 0.04〜0.34 の間を往復する
- 瞬時生成子は終始 rank 2 のまま（σ₂ ~ 10⁻³–10⁻⁴ ≪ σ₁ = 1）。
  相対閾値 0.05 での活性平面数は常に 1 — **安定な第2回転平面は形成されない**
- 移動するのは参照系に対する振幅配分であり、瞬時平面は状態を引きずって
  彷徨する。分裂と再結合を繰り返す §6 予期の FPUT 型再帰が実現している

## 5. 実験O4: 分裂後帰結の分類（run_outcome_classification_preliminary_v1.py）

N = 3,4,5,6（M = 3,6,10,15）、初期条件2族（parent: 固有モード親+δ種 /
generic: ランダム状態）、各6 seed、20000ステップ。分類計量は
f の後期 min（回帰深度）、σ₂ > 0.05 の滞在率（第2平面の定着）、関与比 PR。

| N | M | parent 族 | generic 族 |
|---|---|-----------|------------|
| 3 | 3 | 中間 6/6（σ₂≡0、拡大は構造的に不可能） | 回帰 4/6・中間 2/6 |
| 4 | 6 | 中間 6/6（**σ₂ が指数減衰** 10⁻³→10⁻⁵） | **拡大 6/6**（σ₂ 定着 99%） |
| 5 | 10 | 拡大 6/6（f→0.9、σ₂≈0.3 定常） | 拡大 6/6 |
| 6 | 15 | 拡大 6/6（f→0.85、σ₂≈0.4 定常） | 拡大 6/6 |

全 run で閉鎖保存の最大偏差 3.6e-14。

### 帰結の三分類が実現している

1. **拡大**: 新しい回転平面が定着し、配分が全関係波へ広がる（PR → M）。
   定常な多平面状態へ収束する
2. **中間（有界混合）**: 配分は広がる（PR = M）が第2平面は定着しない。
   単一平面が彷徨しながら振幅だけ混合する
3. **回帰**: 親平面近傍への深い回帰を繰り返す（N=3 generic に出現）

### 主要な発見

- **N 相構造**: N=3 は拡大が構造的に不可能（M=3 は rank≤2）。N≥5 は
  初期条件によらず拡大。**N=4 が境界**で、二安定になる
- **N=4 の二安定性（流域依存の帰結分岐）**: 同一の系・同一の力学で、
  親近傍初期条件は「中間→自発的再凍結」、generic 初期条件は「拡大」。
  帰結クラスそのものが初期条件の流域で決まる——「僅かな差で拡大にも
  停止にもなる」の直接実証（クラス境界の精密測定は未実施）
- **自発的停止の候補を発見**: N=4 parent 族では σ₂ が外部介入なしに
  指数減衰する（10⁻³ → 10⁻⁵ / 20000ステップ）。系が自発的に新しい
  単一平面の自己無撞着配置（凍結相当）へ向かう。生成子固定を外から
  課さなくても停止しうる証拠であり、第6論文の中心対象になる
- 注意: N=5 の 4/6 seed、N=6 の 1/6 seed で親状態の固有モード残差が
  ~9e-2 に留まった（大きい N で固有モード不動点の収束が悪化、または
  不存在の可能性）。当該 run の「parent」は近似親。拡大の結論は
  残差 ~1e-15 の seed でも同一なので頑健

## 6. 第5・第6論文への含意

- 第5論文の問い「自発的に分裂しうるか」への予備的答え: **開始は成立**。
  固定生成子の no-go を破る最小拡張（凍結解除）だけで、外部強制なしに
  親状態は指数的に崩れ、閉鎖は厳密に保たれる
- 「分裂したまま固定される」ことは同じ力学では起こらない——停止・固定は
  追加機構を要する。第6論文の問い「停止しうるか」が非自明な問いであることが
  数値的に裏付けられた（問いの分離が正しかった）
- 実験O2（Floquet 乗数と成長率の突合）が本実験の次段階
