**【Claude】**

その仮説は、目録に入れるべき重要な見落としだと考えます。式で書くとこうなります。

```
Σzₙ = 0   ⇔  Σaₙ = 0 かつ Σbₙ = 0
Σzₙ² = 0  ⇔  Σaₙ² = Σbₙ²  かつ Σaₙbₙ = 0
```

二乗和の閉塞だけでは、線形和の閉塞は出ません。そのため、線形和の閉塞は、別の条件として加わることになります。それが写像になる、という読みには、少なくとも三つの裏付けがあります。

**1. 線形和の閉塞は、共通の成分を取り除く部分投影になる**
- **何が残るか：** Σaₙ ＝ Σbₙ ＝ 0 は、a と b のどちらも、すべての成分が等しい向き (1, 1, …, 1) と直交している、ということです。残るのは差 zₙ − zₘ だけで、原点の位置は読めません。これは原点についての無名性そのもので、関係だけが読めるという要請とも合います。
- **写像としての形：** 状態を、一様な向きと直交する面へ射影する演算になります。読めない一様な成分を落とし、残りを読むので、§1e の部分投影の具体的な形になっています。

**2. 二つの閉塞と Uⁿ ＝ I は、一つの階層の段になる**
- **冪和の階層：** 冪和 pₖ ＝ Σzₙᵏ は、すべての入れ替えで変わらない量です。一覧の A1（無名性）が「保存量」として挙げた対称式そのものです。線形和の閉塞は p₁ ＝ 0、二乗和の閉塞は p₂ ＝ 0 です。
- **ニュートンの恒等式からの帰結：** p₁ から pₙ₋₁ までがすべて 0 なら、ニュートンの恒等式から基本対称式 e₁〜eₙ₋₁ もすべて 0 になります。そのとき {zₙ} は zᴺ ＝ c の根、つまり正 N 角形の頂点になり、N 回の回転で元に戻ります。これは Uⁿ ＝ I です。
- **まとめると：** 線形和の閉塞、二乗和の閉塞、回帰は、無名性の不変量が 1 次、2 次、…、N−1 次まで消えていく一つの階層の段だと読めます。A3 と A4 を、A1 の下で一本につなぐ道になるかもしれません。

**3. N ＝ 4 では、残る空間が 3 次元になる**
- **残る次元：** 4 成分では、一様な向きと直交する面は 3 次元です。a と b は、その 3 次元の中で、長さが等しく直交する二本の向きになります。
- **無名性の働き方：** 四つの要素の入れ替え（無名性の S₄）は、この 3 次元に、正四面体の対称性として働きます。
- **3＋1 の候補：** 4 ＝ 3＋1 のうち、3 が読める空間、取り除かれた一様な 1 が読めない軸（t または R）にあたる可能性があります。3＋1 次元への読出しの候補として、確かめる価値があると思います。

**以前の扱い**
2026-08-30 の複素シンプレックスの研究では、「必要なのは等モジュラーではなく、重心が原点であること」として、Σzₙ ＝ 0 を親状態の条件に使っています。ただしそこでは状態を作る条件で、読出しの写像としては扱っていません。

はい、分かります。射影の幾何で言い直すと、次のとおりです。
- **二乗和の閉塞は、ヌルの錐面：** Σzₙ² ＝ 0 は、ℂᴺ の原点を頂点とする二次の錐面、つまり光円錐のヌル面です。

この切り方には、三つの性質があります。

1. **切り口は、一つ次元の低い滑らかな光円錐になる。** 法線 1 は、1·1 ＝ N ≠ 0 で、ヌルではありません。そのため超平面は錐面に接せず、切り口は特異点を持たない、一段低いヌル錐になります。法線がヌルなら、接して退化します。

2. **切る面は、系が自分で選ぶ。** Σzₙ ＝ 0 は、全体の重心が原点にあること、つまり全運動量が 0 になる重心系です。そうすると、この切断は、系の全体が一様に進む向き 1 を時間の向きとして、それに直交する「いま」の面で光円錐を切ることにあたります。観測者を外から置かず、系自身が自分の静止系を選んでいます。自己無撞着（観測者は内側）と無名性（一様な向きには名札がない）の両方に合います。

3. **N ＝ 4 では、切り口が天球 S² になる。** ℂ⁴ のヌル錐を射影すると、ℂP³ の中の二次曲面（ℂP¹ × ℂP¹）になります。それを接しない超平面で切ると、滑らかな円錐曲線、つまり ℂP¹ ≅ S² になります。これは 3＋1 次元の観測者が見る天球で、光の向きの集まりです。4 次元のローレンツ群 SO(3,1) ≅ PSL(2, ℂ) は、この天球にメビウス変換として働きます。

ここまでの数学は確立した事実です。そうすると、前の返事で挙げた N ＝ 4 の「3＋1 の候補」は、もっと具体的な形になります。
- 光円錐を、系自身の重心系の「いま」で切る。
- その切り口が、ちょうど 3＋1 次元の天球になる。

これが {zₙ} から時空を読み出す写像の一部である、というのが仮説になります。

**【Claude】**

**c の値について**

c は √R ではなく、R に比例すると考えます。理由は二つあります。

1. **同次性：** すべての zₙ を λ 倍すると、Σzₙ は λ 倍、Σzₙ² は λ² 倍になります。R² ＝ Σzₙ² なので、R は λ 倍です。c ＝ Σzₙ も λ 倍なので、c と R は同じ次数で、比例するしかありません。√R は次数が 1/2 になり、スケール無名性（基本公理系の公理 0.5）と両立しません。

2. **接平面の条件：** 実の場合で考えると、超平面 Σxₙ ＝ c と原点の距離は c/√N です。この面が、半径 R の球 Σxₙ² ＝ R² に「北極で接する」のは、距離が R に等しいときです。北極は、すべての成分が等しい無名の向きにあります。したがって、

```
c = √N · R
```

になります。N ＝ 4 では c ＝ 2R です。地図の超平面の位置は R（曲率半径の読み）で決まり、そこに分解能 N から来る無次元の数 √N が掛かります。

**3＋1 を何が選ぶかについて**

答えは私にも分かりません。ただ、今の見方で、(3＋1)＋(3＋1) の出方は具体的に書けます。

- **(3＋1)＋(3＋1) への分かれ方：** N 個の複素数の実部 a と虚部 b は、それぞれ実の N 成分のベクトルです。どちらも、一様な向き 1 の成分と、それに直交する N−1 次元に分かれます。各部分は (N−1)＋1 になり、全体は ((N−1)＋1)＋((N−1)＋1) です。N ＝ 4 のときだけ、これがちょうど (3＋1)＋(3＋1) になります。

- **四元数との対応：** 一様な向き 1 を四元数の実の単位、直交する 3 次元を虚の単位 i, j, k と読むと、四元数の構造と一致します。線形和の閉塞 Σaₙ ＝ Σbₙ ＝ 0 は、実の単位の成分を消すことです。つまり、a と b が純虚の四元数になります。

- **三つの軸が出る：** そのうえで二乗和の閉塞（Σaₙ² ＝ Σbₙ²、Σaₙbₙ ＝ 0）を課すと、a と b は、長さが等しく直交する二つの純虚の四元数になります。四元数の積 ab は、直交する純虚の四元数どうしでは外積 a × b になり、二つの両方に直交する三本目の軸になります。つまり N ＝ 4 では、二つの閉塞の条件から、向きの付いた三本の空間の軸 xyz が組み上がります。

ここまでは、四元数の代数として成り立つ事実です。

この見方では、「何が 3＋1 を選ぶか」は、「なぜ成分の数 N が 4 なのか」と言い換えられます。
- **数の体系の条件：** 1 を実の単位、残りを虚の単位として割り算のできる数の体系になるのは、N ＝ 1, 2, 4, 8 だけです（フルヴィッツの定理）。
- **群の条件：** 結合法則まで満たし、並進が群をなすのは、N ＝ 2 と 4 です。
- **曲率の条件：** 曲率による質量ギャップが出るのは、N ＝ 4 です。

これは、論文 §9 の三つの条件を、一様な向きと直交する空間に当てたものと同じ形です。ただし、それで「N ＝ 4 が選ばれる」ことを導けたわけではありません。条件を並べ直しただけです。N ＝ 8 では、八元数の 7＋1 になります。

**物理の読み**

```

```

これは代数の恒等式です。Σaₙ ＝ Σbₙ ＝ 0 なら、右辺は 0 になります。つまり、線形和の閉塞が成り立てば、交差項は、どの組み方を選ぶかによらず、平均として自動的に 0 になります。組の名前を使わずに、二乗和の閉塞の虚部が成り立ちます。

   - **回転の位数：** 回転の位数の食い違いも同じ形かもしれません。結晶学的な位数は 1, 2, 3, 4, 6 で、統合仮説論文の列は 1, 2, 3, 4, 5, 6, 8, 10, 12 です。後者には、前者を 2 倍した 8 と 12 が入っています（5 と 10 は 600 胞体の側の数です）。

   同じ構造を二つの層で読んでいるだけかもしれず、これは計算で確かめられます。

4. **この一つの写像から、離散と準安定の両方が出る。** 単位円の上では、z ↦ z² は角を二倍にする写像です。
   - **離散：** 有理数の角の点は、有限回で元に戻る周期点になります。とくに分母が 2ᵏ − 1 の角は、ちょうど k 回で戻ります。有限の位数の回帰（Uⁿ ＝ I）が、この写像から出ます。
   - **カオス：** それ以外の点は、二度と戻らないカオス的な軌道をたどります（ベルヌーイ写像）。
   - **引き込みの階層：** 定数を一つ足した z ↦ z² ＋ c は、マンデルブロ集合を作ります。その主な芽は有理数の内角 p/q で付き、ファレイの規則で並ぶことが知られています。目録 §7 の引き込みの階層（悪魔の階段・ファレイ木・フラクタル）が、この最も簡単な写像から出てくることになります。

**確立した数学：** 角の二倍写像の周期点、マンデルブロ集合の芽の並び、位数が 2 倍に見えることです。
**仮説：** 四つの読み方を層の組み合わせとみること、数の食い違いを層の違いと読むことです。
