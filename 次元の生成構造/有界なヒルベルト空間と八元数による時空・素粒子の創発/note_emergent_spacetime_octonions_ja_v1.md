# 背景の時空を仮定せずに、時空と素粒子を立ち上げる――光子の静止から中心投影、四元数・八元数へ至る思考実験

私は、あらかじめ 4 次元の背景時空を舞台として置かず、有界・有限なヒルベルト空間の状態関係と、四元数・八元数の代数構造だけから、時空・粒子・相互作用を再構成できないかという思考実験を続けています。

一見すると標準的な教科書から大きく離れた試みに見えますが、問題意識と数学的道具立ての両面で、現代の理論物理学における「創発的時空（Emergent Spacetime）」や「多元体代数による素粒子記述」などの研究潮流と接点を持っています。

今回、初期の中心投影モデルから最新の四元数・八元数動力学の課題整理までを一本の流れにまとめた思考実験・対話記録の論文を Zenodo に公開しました（Concept DOI: https://doi.org/10.5281/zenodo.24267347）。この記事では、思考が進んだ 4 つの段階と、残された未解決課題の境界を順にたどります。

## 全体構造：4 つの段階

本稿では、確立された数学的構造を足場にしつつ、以下の 4 段階で作業仮説を組み上げています。

- 第 1 段階：ミンコフスキー計量 (x, y, z, t, τ) と 5 次元光円錐の断面 → 光子の固有時ゼロ（ds = 0）と物質の時間進行
- 第 2 段階：虚時間 R² = t² + (iτ)² による中心投影（ベルトラミ座標） → ド・ジッター時空・事象の地平面 R と重力歪み
- 第 3 段階：四元数 ℍ（共役な 2 複素数）とホップ写像 S¹ ↪ S³ → S² → 外部座標を借りない 3 方向位相勾配の保持（光子）
- 第 4 段階：八元数 𝕆（共役な 2 四元数）とホップ写像 S³ ↪ S⁷ → S⁴ → 閉じた 4 次元時空 S⁴ と内部 3 自由度・凝縮体の自己組織化

## 第 1 段階：光子の四次元時空における静止

出発点は「なぜ光子は常に光速で飛ぶように見えるのか」という素朴な問いです。

特殊相対性理論のミンコフスキー計量

　ds² = −(cdt)² + dx² + dy² + dz²

において、光子は常に ds = 0 を満たします。これは、4 次元時空の固有時 τ の立場から見ると、光子は固有時が進まず「四次元時空の中で静止している」のと同じ状態にある、と読むことができます。

ここで固有時 τ を用いて (x² + y² + z²) + τ² = t² と書き換えると、5 次元の光円錐の断面として 4 次元時空を捉える視点が開けます。

## 第 2 段階：中心投影とド・ジッター時空

さらに虚時間 iτ を導入して

　t² − τ² = t² + (iτ)² = R²

という関係を置くと、半径 R の球面からの中心投影（ベルトラミ座標）として空間 x² + y² + z² = R² が現れ、ド・ジッター時空と事象の地平面 R の構造に接続します。

この枠組みでは、内部の観測者にとって主観空間は無区別に見える一方、物質の存在によって局所的な曲率半径 R が縮小する効果として重力を解釈する余地が生まれます（作業仮説）。

## 第 3 段階：複素数から四元数・八元数への拡張

次に、「外部の背景座標を借りずに、空間の 3 方向の情報をどう保持するか」を考えます。

複素数 ℂ は 2 自由度しかなく、外部の 3 次元方向を保持するには自由度が足りません。そこでケイリー＝ディクソン構成によって数体系を拡張します。

共役な 2 つの複素数 (z₁, z₂) ∈ ℂ² を並べた四元数 ℍ（4 自由度）は、大きさ 1 に規格化すると 3 次元球面 S³ をなし、ホップ写像 S¹ ↪ S³ → S² によって 2 次元球面 S² の 3 方向を外部座標なしに保持できます。これは、1 量子ビットの純粋状態とブロッホ球表現（および光子の偏光を表すポアンカレ球）と数学的に同じ写像です（補遺 1）。

さらに時空 4 自由度と内部自由度を同時に扱うため、共役な 2 つの四元数を並べた八元数 𝕆（8 自由度）へ進みます。フルヴィッツの定理により、実ノルム多元体は 1, 2, 4, 8 次元に限られるため、八元数がこの拡張の終着点となり、次のホップ写像 S³ ↪ S⁷ → S⁴ が現れます。

## 第 4 段階：背景時空の排除と自己組織化

ここで視点を反転させ、「あらかじめ時空を置くのではなく、有界・有限なヒルベルト空間の状態関係だけを出発点にする」ことを考えます。

曲率半径 R の存在は空間が有界で閉じていること（コンパクト球面 S⁴）を要請します。状態数 N の全結合（N²）から出発しても、八元数の非結合性・トライアリティ・極小イデアル・ピアース分解といった代数構造を通じて、相殺を免れて局所的に浮かび上がる「凝縮体」へ因子分解されるのではないか、というのが第 4 段階の作業仮説です。

## 倍音との接続課題（補遺 2）

私の初期からの研究では、波に「局所性」を与えるためには奇数倍音和などの倍音構造が必要であり、倍音循環が質量や粒子寿命の持続性に関わることを検討してきました。

本稿の八元数モデルだけでは、異なる質量階層や多様な粒子種を表現する自由度が不足する可能性があります。八元数による代数的因子分解（個体と対称性の枠組み）と、倍音による局在化・スペクトル構造（凝縮体の空間プロファイルと質量階層）をどう統合するかが、今後の重要な接続課題です。

## どこまでが確立され、どこからが仮説か

独立研究の思考実験では、確立された数学と作業仮説の境界を明確にすることが不可欠です。論文末尾では、以下の 4 区分で境界線を引いています。

- 恒等式・定理：ミンコフスキー計量（ds = 0）、ケイリー＝ディクソン構成、フルヴィッツの定理（1, 2, 4, 8 次元）、ホップ写像 S³ → S² および S⁷ → S⁴
- 読み・解釈：光子の静止と 5 次元光円錐の断面、中心投影とド・ジッター時空との対比、複素数→四元数→八元数への自由度要請、コンパクト球面の要請
- 仮説：局所曲率半径 R の縮小としての重力、有界ヒルベルト空間と八元数の非結合性・トライアリティ・極小イデアルによる凝縮体の因子分解
- 未解決：内部位相を書き換える動力学の具体的更新則、N² 全結合から局所凝縮体へ因子分解される数学的証明、倍音（局在波・倍音循環）と八元数凝縮体・質量階層・粒子種の統合
