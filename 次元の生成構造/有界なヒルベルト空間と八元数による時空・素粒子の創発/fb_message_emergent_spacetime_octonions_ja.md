背景の時空を仮定せず、有界なヒルベルト空間と八元数から時空・素粒子を立ち上げる思考実験

詳細はコメント参照

背景の時空を前提とせず、有界なヒルベルト空間の状態関係と代数構造だけから時空と粒子を再構成する思考実験の論文を公開した
4次元ミンコフスキー計量において光子は ds = 0 を満たし、固有時 τ の観点からは4次元時空の中で静止している状態に対応する
虚時間 R² = t² + (iτ)² による中心投影から空間 x² + y² + z² = R² が現れ、ド・ジッター時空と事象の地平面 R、および物質による R の縮小としての重力に接続する
複素数（2自由度）では外部座標なしに3次元方向を保持できないため、ケイリー＝ディクソン構成により四元数（4自由度）へ拡張する
共役な2複素数から成る四元数はホップ写像 S¹ ↪ S³ → S² を通じて3方向の位相勾配を保持でき、1量子ビットのブロッホ球表現と数学的に同型である
さらに時空4自由度と内部自由度を扱うため八元数（8自由度）へ進み、ホップ写像 S³ ↪ S⁷ → S⁴ から閉じた4次元時空 S⁴ と内部3自由度が分離する
フルヴィッツの定理により実ノルム多元体は 1, 2, 4, 8 次元に限られるため、この数体系の拡張は八元数で閉じる
N² の全結合状態から出発しても、八元数の非結合性・トライアリティ・極小イデアルによる因子分解で局所的な凝縮体が自己組織化するという作業仮説を置く
質量階層や粒子種には八元数だけでは自由度が不足する可能性があり、局在波と倍音循環の理論との統合を未解決課題として明示した
確立された恒等式・定理と作業仮説・未解決課題の境界を厳密に区分して整理した研究プログラム概観である
