# なぜ波の数は無限に拡大してみえるのか

思考実験ノート（2026-07-21）。
「状態（波）の自発的分裂と停止」の検討から派生した基礎的考察。論文化を前提としない内部記録である。予言力に乏しいテーマであることを最初に明記する——本稿の主命題は反証可能な予言を出すものではなく、問いの形そのものを組み替えるものである。

---

## 1. 出発点の問い

第5論文系列の中心問題は「一本の波は自発的に複数の波に分裂しうるか」であった。数値実験は、固定次元の状態空間内でのレジスタ再配分・モード活性化・熱化を示したが、「1が2になる」ことは示していない。与えた部屋（N）が埋まる数は N であり、入力を出力と呼ぶことはできない。

この行き詰まりは、実験の不足ではなく、問いの形の誤りに由来していた。

## 2. 分裂は代数的に自明である

閉鎖

\[
\sum_n x_n^2 = R^2
\]

は n を指定しない。

\[
5^2 = 5^2,
\qquad
3^2 + 4^2 = 5^2,
\qquad
\left(\tfrac{3}{5}\right)^2 + \left(\tfrac{4}{5}\right)^2 = 1^2
\]

整数・分数・実数・複素数・虚数——任意の比の分解が成立する。分解の組み合わせは無限にある（球面上の連続体）。整数であるべき制約はどこにも入っていない。

さらに、状態数を「非零成分の個数」と読むなら、直交回転一発で

\[
(5,0) \longrightarrow (3,4)
\]

と分割できる。固定次元の力学でも非零成分の数は保存されない。**分裂を禁じるものは代数には無い。したがって、難しいのは分裂ではなく、分裂が止まる理由の方である。**

## 3. 波の同一性は共通周期で決まる

分解のうち、特別な場合が一つだけある。娘成分がベース振動の倍音関係（整数倍 \(n\omega_0\)）にある場合、合成は**同じ一本の波の波形変化**にすぎない。基本振動数も振幅も変わらない。フーリエ成分をいくつ持とうが、共通周期を持つ限りそれは一つの状態である。

それ以外——共通周期を持てない（非可約な振動数比の）成分——はすべて独立の波である。

したがって整数比は外から課す制約ではなく、**「同じ波か、別の波か」の判定条件**である。

## 4. 閉鎖塊＝共通基本波長族（定理候補）

閉鎖が全ての \(\tau\) で持続することを要求する。各成分が \(x_n(\tau) = a_n e^{i\omega_n\tau}\) と進むなら、

\[
\sum_n a_n^2 e^{2i\omega_n\tau} = R^2 \quad \forall\tau
\]

異なる振動数の指数関数は線形独立なので、この式は振動数クラスごとに別々に成立するしかない。共通周期を持たない成分同士は互いの閉鎖を助けられない。ゆえに：

\[
\boxed{
\text{既約な閉鎖塊は、必ず共通の基本周期を共有する（倍音族である）}
}
\]

「\(\sum x_n^2 = R^2\) と書き直せること」＝「閉じた系であること」＝「基本波長を共有すること」が同値になる。\(R^2\) をベース振動と読めば、左辺は必然的にその倍音族である。固定生成子の各回転平面のレジスタ保存（帰結16.5）は、この定理の線形極限（純正弦波、n=1 のみ）にあたる。

## 5. 閉鎖の塔——フラクタルとスケール不変性

\[
\sum_n x_n^2 = X^2,\quad
\sum_n y_n^2 = Y^2,\quad
\sum_n z_n^2 = Z^2,\qquad
X^2 + Y^2 + Z^2 = R^2
\]

第4節の議論は各階層にそのまま適用される。\(X^2+Y^2+Z^2=R^2\) が持続するには \(X, Y, Z\) が共通周期を共有するしかない——**\(X, Y, Z\) は \(R\) の倍音である**。帰納的に任意の深さへ伸び、同じ一つの法則（閉じて足せる）が全階層で反復される。構造は自己相似——フラクタルであり、そのままスケール不変になっている。各塊は自分の基本振動（＝自分のスケール）だけを「1」として持ち、上の階層とは倍音番号（比）でしか繋がらない。

系1：一つの全体閉鎖の内部では、すべての成員が頂点の基本振動の整数倍音である。真の無理数比は存在せず、連続に見えるものは巨大な整数比の見かけである（離散整数基礎テーゼへの独立経路）。

系2：\(X^2+Y^2+Z^2=t^2\) を塔として読めば、共通時間 \(t\) は最上位閉鎖の基本振動であり、空間レジスタはその倍音である。閉鎖部分系ごとに局所時計が生じる根拠もここにある——塊は基本振動を共有するから、塊には時計が在る。

## 6. 平坦化——塊分けは選択である

倍音の倍音は倍音なので、塔は常に平坦化できる：

\[
\sum_n x_n^2 + \sum_n y_n^2 + \sum_n z_n^2 = R^2
\]

\(X, Y, Z\) への塊分けは中間基底の選択にすぎない。すると波の数は：

- \(R\) をベースに数えれば 1（全体が一本の波の波形構造）
- \(X, Y, Z\) をベースに数えれば 3
- 個々の成分まで割れば多数

**粒子（状態）の数は、どこをベース波長として数えるかで変わる。**

## 7. 最小単位は存在するか

最小単位とは、それ以上因数分解ができない関係である。共役な複素数対を波としている以上、

\[
a^2 + b^2 = r^2
\]

まで割った倍音一個が究極の波に見える。しかし、その下に階層が**無い**とは誰にも言えない。観測できないなら、在るのか無いのか分からない——存在の有無ごと未決定である。

波形は、解像されなかった下位階層の痕跡である。正弦波でない波は、その下に構造がある証拠。純正弦波に見える波は、その解像度で下位構造が見えないだけで、素元かどうかは未決定である。

ゆえに、波は数えるまでもなく無限にある——というより、細かく観測することが可能なら、どこまでも細かく見える可能性がある。数は観測の深さ（最低波長の選択）の関数である。

（標準理論側の対応物：深非弾性散乱におけるパートン数は分解能の関数であり、細かく見るほど多く見える。粒子数が観測者に依存することも既知である。「同じ結果の別写像」の姿勢と整合する。）

## 8. 主命題：計数の無名性

\(\sum x_n^2 = R^2\) の \(n\) は任意である。\(n=1\) なら \(R^2=R^2\) となるだけで、これも正当な表示である。不変な言明は \(n \ge 1\) のみ。

\[
\boxed{
\text{スケール無名な閉鎖系において、波の数は観測量ではない}
}
\]

数えるという操作自体が床（最低波長）の指定＝スケール無名性の破りを要求する。床を指定しない限り「数」は定義されない。数は系の属性ではなく、読出しの属性である。

床の取り替えに対して不変なものだけを残すと：

1. **\(n \ge 1\)**——非自明な存在（公理2がすでに置いていた、数について言える唯一の床不変量）
2. **関係構造**——振動数の比（可約性の構造）、閉鎖内の配分比。床を細かくしても既にある比は保存される

公理系の0層はこれで四つの無名で完結する：**名前・スケール・数・床**。読めるのは関係・比率・選んだ基底に対する分割だけである。公理2が存在だけを置いて個数を置いていないこと、公理5が絶対位相を、公理0.5が絶対スケールを読めないとしていることと合わせて、数が読めないことはこの系列の欠落ではなく完成である。

## 9. 表題の問いへの答え

**なぜ波の数は無限に拡大してみえるのか。**

波の数が増えているのではない。観測の床が下がる（分解能が上がる）たびに、畳み込まれていた倍音がほどけて独立の波として数え直されるからである。数の「拡大」とは観測床の降下の読出しであって、存在の増加ではない。床に内在的な底が無い（最小単位の存在が未決定である）以上、この見かけの拡大に終わりはない。

## 10. 分裂問題への帰結

- 「1が2になるか」は絶対数を前提とした不良な問い
- 正しい問い：**どの床の選択に対して、どの因数分解が力学的に読出し可能（安定・ロック）になるか。それはいつ組み替わるか**
- 生成子の凍結＝因数分解の固定＝数の確定（帰結16.5の二重レジスタ）
- 凍結解除＝因数分解の融解＝数が定義されない状態（等分配・熱化はこの状態の読出し）
- 再ロック（停止）＝新しい因数分解の確定＝数の変化。分裂・停止は存在の増減ではなく、読出し可能な分割の組み替えである
- 観測選択（公理16）とは、どのベースで数えるかを選ぶ操作である

第6論文（停止）の問いは「数が確定する条件＝ロック則（振動数の有理比への引き込み）」、第7論文（分化）は「確定した分割の成分の交換対称性による分類」となり、三部作の骨格は変わらず、土台の存在論だけが差し替わる。

## 11. 分類

### 導出済み（証明スケッチ付き、厳密化必要）

- 閉鎖の持続 ⇒ 振動数クラスごとの個別閉鎖 ⇒ 既約閉鎖塊は共通基本周期を共有する（第4節）
- 塔の再帰：上位閉鎖の持続 ⇒ 下位基底同士の可約性（第5節）
- 直交回転による非零成分数の変化（(5,0)→(3,4)）：固定次元でも「非零成分の数」は保存されない

### 主命題（定義・公理候補）

- 計数の無名性：スケール無名な閉鎖系で波の数は観測量でない。不変なのは存在（n≥1）と比のみ

### 作業仮説

- 停止＝振動数の有理比ロック（結合位相系の引き込み）。整数構造はロックの帰結として内側から出る
- 波形＝未解像下位階層の痕跡

### 未決定（原理的）

- 最小単位の存在（観測床の下は存在の有無ごと未決定）

### 未解決（技術的）

- 持続性議論の離散 τ・非線形（振動数が動く場合）への厳密化
- 既約分解の一意性補題
- 床変更に対する記述の整合条件（この枠組みの繰り込み群方程式）の定式化

### 本ノートの限界

- 反証可能な予言を含まない。問いの形の組み替えと不変量の特定に留まる
- 論文化する場合は、閉鎖塔定理（第4・5節）だけを切り出して数学的命題として書くのが唯一の経路と思われる。計数の無名性は定理の系として一段落で述べるに留めるべきである
