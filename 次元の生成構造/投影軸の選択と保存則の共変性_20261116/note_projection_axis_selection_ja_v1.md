# どの軸を空間と呼び、どの軸を内部と呼ぶのか――全波が乗る「2つの R」と保存則の共変性

前回の記事では、背景の時空を仮定せず、有界なヒルベルト空間と四元数・八元数から時空や素粒子を立ち上げる思考実験の全体地図を紹介しました。

しかし前回の論文はあくまで全体像の整理であり、具体的な物理的予言までは踏み込んでいませんでした。今回、その直後に実施した四元数の「2つの R」の検討から明確な予言が引き出せたため、新しい論文として Zenodo に公開しました（Concept DOI: https://doi.org/10.5281/zenodo.24273723）。

この記事では、その核となる 4 つの主張を順を追って紹介します。

## 1. 全波が 2 つの R に同時に乗っている

四元数の極形式

　o = A(cos θ + n sin θ)　（n ∈ S², n² = −1）

には、性質の異なる 2 つの半径が含まれています。

- R₀（投影軸・1 次元位相円 S¹ の半径）：実部 cos θ と虚部の大きさ sin θ が乗る円周の半径
- R₁（空間側・純虚 3 次元空間 Im(ℍ) ≅ ℝ³ 内の 2 次元方向球面 S² の曲率半径）：純虚数単位ベクトル n が張る空間側の半径

当初はスカラー cos 波（ヒッグス的な一様場）だけを R₀ に置き、3 次元空間を R₁ に置く役割分担を考えていました。しかし精査の結果、**特定の波だけが R₀ に乗る理由はなく、ヒルベルト空間のすべての波が最初から R₀ と R₁ の両方に同時に乗っている**という結論に達しました。

あらゆる波が R₀ と R₁ の両成分を持つため、2 つの波の掛け算 o₁ o₂ を計算すると、3 次元方向の向き（内積 n₁ · n₂）が R₀ 側の振幅を変え、逆に R₀ 側の位相が 3 次元方向のねじれ（外積 n₁ × n₂）を制御するという相互干渉が自然に生まれます。

## 2. ホップ束の投射非対称性

全波が R₀ と R₁ の両方に同時に乗っているとき、両者の間の写像は対称ではありません。ホップ束 S¹ ↪ S³ → S² の構造により、次の非対称性が生じます。

- R₁（方向球面 S²）側へは、S³ のすべての点が漏れなく写る完全投射（全射）になる
- R₀（1 次元位相 S¹ ファイバー）に沿って位相を回しても、S² 上の像は 1 点に潰れたまま動かず、空間移動としてはゼロ投射になる
- 位相 θ は方向を決められないまま、R₁ 側に現れる重み sin θ だけを制御する部分投射になる

この非対称性のため、R₁（空間側）から世界を読む観測者には、R₀ 側の自由度は空間の方向としては見えず、一様な背景（スカラー基準や時間的進行）として現れます。また標準的なリーマン沈め込みでは、幾何学的必然として R₀ : R₁ = 2 : 1 の比率に固定されます。

## 3. 投影軸の 1, 2, 4 次元選択と時空・内部空間の切り替え

ここで、R₀ の次元を 1 次元に固定する必要はありません。乗算で閉じた部分多元体を投影軸 R₀ として選ぶなら、フルヴィッツの定理（実ノルム多元体は 1, 2, 4, 8 次元に限る）により、八元数 𝕆（8 次元）の中で選べる投影軸の次元は **1, 2, 4（ℝ, ℂ, ℍ）** の 3 通りに限られます。

- 投影軸 = 1 次元（ℝ 基準）：空間側は 3 次元（ℍ）または 7 次元（𝕆）
- 投影軸 = 2 次元（ℂ 基準）：四元数では ℂP¹ ≅ S²、八元数では残りが ℂ³ になり、自己同型群 G₂ の部分群として SU(3)（カラーの 3 対称性）が現れる
- 投影軸 = 4 次元（ℍ 基準）：八元数では残りが四元数射影直線 ℍP¹ ≅ S⁴（閉じた 4 次元時空）になる

つまり、**時空と内部状態空間の区別そのものが固定された舞台ではなく、どの次元の部分多元体を投影軸に選ぶかによって入れ替わる**ことになります。

## 4. 保存則の共変性と最小系への縮約

第 4 章・第 5 章では、これを 4 月最初期のヌル条件 ∑ xₙ² = 0 と直結させます。全成分の平方和がゼロの等式から、投影軸 R₀ に選んだ成分を右辺へ移項すること自体が、相対的なマイナス符号（ローレンツ計量符号）を生み出します。

そして元の等式はどの軸を右辺へ括り出すかについて完全に対称であるため、本稿は次の原理を予言します。

**軸選択に対する保存則の共変性**：ある投影軸を選んだときに成り立つ保存量があるなら、別の軸（あるいは別の 1, 2, 4 次元部分多元体）を投影軸として選び直したときも、対応する量が同じように保存される。

これは背景時空上の S 行列を前提とするコールマン＝マンドゥーラの定理（時空対称性と内部対称性は非自明に混ざらない）が成立する前の段階における、一段上位の対称性です。

さらにこの原理は、理論を解析するうえで極めて強力な帰結をもたらします。最初から 8 次元すべてを同時に解かなくとも、まず 5 軸を右辺の R'² に圧縮したシンプルな最小系

　x² + y² + z² = R'²

で成り立つ R'² の保存則を検討すれば、高次元を開いたときもそれは

　R'² = t² + R² + Q₁² + Q₂² + Q₃²

という**圧縮された残りの 5 次元全体の合成保存量**としてそのまま引き継がれます。八元数 𝕆 でもノルムの乗法性 |o₁ o₂| = |o₁||o₂|（デゲン＝グレーブスの 8 平方の恒等式）が厳密に成立するため、全体の保存は破れず、非結合性はその内部での軸間のエネルギー配分・振動を駆動します。
