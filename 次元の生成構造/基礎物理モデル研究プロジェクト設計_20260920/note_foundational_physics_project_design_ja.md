# 答えを探す前に、探し方を設計する

――物理の基礎を探す研究を、ひとつのプロジェクトとして立て直した話

木原範昭

## 面白い発見が、いちばんの落とし穴でした

私はこの数年、時空・粒子・質量・電荷・時間を最初から与えずに、もっと少ない材料――名前のない「状態」と、状態のあいだの「関係性」――だけから、それらが自然に生まれてこないかを数値実験で探してきました。

この探し方には、罠があります。

候補の数式を作って走らせると、特異点、閉じた構造、準安定状態、指数的な成長など、面白い現象が次々に見つかります。すると、見つかった現象そのものが研究の目的であるかのように見えてきて、研究の方向がそのたびに変わってしまうのです。

面白い数値現象と、本来探している基礎構造は、同じではありません。

## そこで、研究そのものを設計対象にしました

今回公開した文書は、物理の論文ではありません。完成した理論も、新しい方程式も、一切出てきません。

書いたのは、研究プロジェクトの設計図です。

ゴールも方法も最初から確定できない探索型プロジェクトには、通常の計画遂行とは違う管理方法が必要である――これはプロジェクトマネジメント研究の分野で昔から指摘されてきたことです。私自身の40年のITコンサルティングとシステム設計の経験則も、まったく同じことを言っています。

そこで、この研究を次の繰り返しとして定義し直しました。

哲学的原則 → ゴールイメージ → 予備設計 → 実装可能性検証 → 数値実験 → 設計とゴール像の修正

大事なのは、ゴールイメージ自体も固定しないことです。実験や数学的検討で不可能と分かれば、ゴールの方を直します。

## 出発点は、名前のない状態です

初期に存在するものは、極力少なくします。

第一原則の候補はひとつだけ。名前は存在しないが、互いに区別可能で、数を数えられる状態が存在する。それだけです。

状態には、電子とか光子とか、質量とか電荷とか、位置とか時刻とか、そういう属性を最初から与えません。状態そのものを直接読むこともできず、何かを読み出すには他の状態との相互作用が必要だと考えます。つまり、観測とは相互作用を伴う読み出しのことです。

そこから先に何が生まれてほしいか――全体の保存量、空間に見える方向の自発的な広がり、時間に見える方向の単調な累積、局所的な凝縮としての粒子――は、公理ではなく、あくまで暫定的なゴールイメージとして書き、検証で棄却されうる立場に置きました。

## 自分への禁止事項も書きました

探索の途中で、望ましい結果を得るためだけに補正を入れたくなる誘惑があります。だから、禁止事項も文書に明記しました。

- 初期状態に粒子の名前を与えない
- 空間軸や時間軸を外から固定しない
- 結果ありきの正規化や飽和関数で発散を隠さない
- 見つかった数値現象を、既知の物理と照合せずに発見と呼ばない

そして成功条件には、こう書きました。実装不可能性の発見も研究成果である。うまくいかないことが証明できたなら、それも前進です。

## この文書の役割

この立案書は、これからの探索を迷走させず、かつ必要以上に早くひとつの理論に固定しないための地図です。

標準模型と一般相対性理論は、置き換える対象ではなく、最終的に再現すべき既知の成功として扱います。何を発見したかだけでなく、なぜその計算を行ったのかを保存する。限られた資源で長く探索を続ける独立研究者にとって、これがいちばん大事な規律だと考えています。
