ゼロ閉塞の解集合：複素ヌル錐と線形閉塞の切断（N = 1〜4）

S = {Σzₙ² = 0}（二乗和閉塞・複素ヌル錐）、A = {Σzₙ = 0, Σaₙbₙ = 0}（線形閉塞＋積和閉塞）、S∩A = {Σzₙ = 0, Σzₙ² = 0}。各点は方程式を解析的に解いて生成した厳密解で、切断は |q(z) − v| ≤ ε を満たす点だけを描きます。

生成と切断の方法

S：z₁…z_{N−1} をガウス乱数で与え、最後の成分を z_N = ±√(−Σ_{k<N} z_k²) で解析的に解きます。

A：a は和が 0 になるよう最後の成分で閉じ、b は和零と a·b = 0 の線形 2×2 系を最後の 2 成分について厳密に解きます（N = 2 は 2 本の直線を直接生成）。

S∩A：z₁…z_{N−2} を与え、残り 2 成分を p = −Σz_k、q = −Σz_k² から t = (p ± √(2q − p²)) / 2（2 次方程式の解の公式）で解きます。N = 3 では自動的に正三角形 c·(1, ω, ω²) と c·(1, ω², ω) になります。

生成後に添字をランダムに置換し、|z| = 1（球面）または |z| ≤ 1（錐）に正規化します。「最大残差」は全生成点について Σz、Σz²、Σab を倍精度で評価した絶対値の最大値です。描画は、選んだ 3 つの量を直交射影し、切断量 q(z) が |q(z) − v| ≤ ε を満たす点だけを描きます。
