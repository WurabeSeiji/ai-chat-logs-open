# 残った穴の正体 ― 二者性ではなくテンソル積（2026-10-20）

**前段：** `双線形性が八元数の積から出た_20261020.md` の §4「読み」と、そこで残した「二者性はどこから来るか」。
**プログラム：** `octonion_entanglement_gap_20261020.py`。
**結論：** 前段の §4 の読みは言い過ぎだった。訂正する。そして残った穴は「二者性」ではなく「**テンソル積が無いこと**」だと特定できた。

---

## 1. 訂正：2√2 の起源は「ノルムの乗法性」ではない

前段 §4 でこう書いた。

> 2√2 の起源は「ノルムの乗法性」だ、という読みになる。…ノルムが乗法的な実代数は 1, 2, 4, 8 次元の四つしかない（フルヴィッツ）。

**これは言い過ぎである。**

- CHSH ≤ 2√2 は、単位ベクトルどうしの内積であれば**どの次元の内積空間でもコーシー・シュワルツから出る**。八元数は要らない。
- 線形で等長な設定写像 a ↦ L_a x（クリフォード加群）は、ラドン・フルヴィッツの意味で多くの次元に存在する。パウリ行列が ℂ² 上で同じことをしている。
- **八元数がしているのは「上限を決めること」ではなく「設定写像を自然に供給すること」だけ。** 1, 2, 4, 8 の話を 2√2 に結びつけるのは、査読で崩される。

§4-1 が閉じたこと（設定が線形に入る理由が代数から出ること）自体は変わらない。**変わるのは、それが 2√2 の起源だと言えない点である。**

## 2. 仮定は消えていない。⟨ax, by⟩ という形の中に移った

Alice のベクトルと Bob のベクトルを同じ 8 次元空間に置いて内積で比べる、という手続きそのものが、**最大もつれ状態を構成で入れていること**に相当する。数値で確定させた。

### 2.1 相関行列は 6 個が 1 に張り付き、7 番目だけが |⟨x,y⟩|

| 試行 | 特異値 | \|⟨x,y⟩\| |
|---|---|---|
| 0 | 1, 1, 1, 1, 1, 1, **0.029148** | 0.029148 |
| 1 | 1, 1, 1, 1, 1, 1, **0.663258** | 0.663258 |
| 2 | 1, 1, 1, 1, 1, 1, **0.139667** | 0.139667 |
| 3 | 1, 1, 1, 1, 1, 1, **0.456186** | 0.456186 |
| 4 | 1, 1, 1, 1, 1, 1, **0.161098** | 0.161098 |

**7 番目の特異値はちょうど \|⟨x,y⟩\|。** 理由は幾何で説明がつく。A = {L_{e_i} x} と B = {L_{e_j} y} はそれぞれ R⁸ 内の正規直交 7 本で、その直交補空間はそれぞれ x と y である（L_a が反対称なので ⟨x, L_a x⟩ = 0）。7 次元部分空間 x⊥ と y⊥ の交わりは 6 次元なので主角が 6 個ゼロ、残る 1 個が x と y の角になる。

**x, y をどう選んでも 6 個は 1。** 著者の「どの x, y でも直交行列（特異値すべて 1）」は厳密には 7 個目が外れるが、**指摘の実質（最大もつれを構成で入れている）はそのとおり**である。

### 2.2 局所期待値は恒等的にゼロ

| 量 | 最大 |
|---|---|
| ⟨x, a x⟩（左乗算） | 1.2×10⁻¹⁶ |
| ⟨x, x a⟩（右乗算） | 1.2×10⁻¹⁶ |

L_a も R_a も反対称なので、**一回の乗算で作る観測量は局所期待値を持てない**。これも最大もつれの署名である。

### 2.3 左右を入れ替えても何も変わらない

| 形 | 特異値 |
|---|---|
| ⟨a x, b y⟩ | 1, 1, 1, 1, 1, 1, 0.6053 |
| ⟨a x, y b⟩ | 同じ |
| ⟨x a, y b⟩ | 同じ |
| ⟨x a, b y⟩ | 同じ |

四つとも同じスペクトル。左右の選び方は効かない。

## 3. 結合子を入れても解けなかった（著者の候補の検証）

著者の指摘のとおり、ここまでの計算は交代性とクリフソード関係しか使っておらず、**どちらも結合的な代数で成り立つ**（ℍ の中で結合子は 4.7×10⁻¹⁵ で消える）。八元数固有の結合子 [a, x, b] を入れてみた。

| 形 | 特異値 | 階数 |
|---|---|---|
| ⟨[a,x,b], y⟩ | 1.4924 × 4 個、0 × 3 個 | **4** |
| ⟨[a,x,y], b⟩ | 同型 | 4 |
| ⟨[a,b,x], y⟩ | 同型 | 4 |

**常に階数 4 で、非ゼロの 4 個は完全に縮退する**（5 試行すべて）。これも調整できる族ではない。

混ぜた族 E_λ(a,b) = (1−λ)⟨ax, by⟩ + λ⟨[a,x,b], y⟩ では、

| λ | 最大特異値 | 最小 | 1 に張り付く数 | \|E\| ≤ 1 か |
|---|---|---|---|---|
| 0 | 1.0000 | 0.3300 | 6 | はい |
| 0.1 | 1.0765 | 0.2970 | 0 | **いいえ** |
| 0.5 | 1.4120 | 0.1650 | 0 | いいえ |
| 1.0 | 1.8675 | 0.0000 | 0 | いいえ |

λ > 0 で 1 への張り付きは解けるが、**最大特異値が 1 を超えて \|E\| ≤ 1 を破る**。規格化し直すと、λ = 1 では (1,1,1,1,0,0,0) の縮退に戻る。**結合子だけでは部分もつれを作れない。**

## 4. 穴の正体：テンソル積が無い

### 4.1 到達できる相関行列の族が薄すぎる

(x, y) ∈ S⁷ × S⁷ は 14 パラメータ。そこから到達する相関行列 M の張る次元を測ると **22**。7×7 の相関行列の全体は 49 次元なので、**22/49 の薄い部分集合**しか届かない。

**階数 1（直積状態）への最小距離は 2.2361**（目標のノルム 1.0 に対して）。6 個の特異値が 1 に張り付いたままなので、構造的に届かない。

### 4.2 問題は「二者性」ではなかった

前段 §4 では「Alice と Bob を分けているのが何か」が残った穴だと書いたが、**それは問題の立て方が違った**。二者は x と y として置けている。足りないのは**状態空間**である。

> **二つの八元数の対 (x, y) は、テンソル積ではない。** 量子力学の二体状態は H_A ⊗ H_B の元で、シュミット係数を持つ。ここでは x と y が別々の八元数なので、**シュミット係数を入れる場所がない**。だから相関行列が最大もつれの一点（と |⟨x,y⟩| の一方向）に張り付く。

### 4.3 これは既知の障害である可能性が高い

八元数の量子力学では、例外ジョルダン代数 J₃(𝕆)（27 次元）が状態空間にあたるが、**J₃(𝕆) は自分自身とのテンソル積を許さない**ことが知られている。これが「八元数の量子力学は複合系を記述できない」と言われる理由である。ここで出た穴は、その既知の障害の一例と見える。**書誌は未確認。照合が要る。**

## 5. 絞り込まれた問い（著者の §3 を数値で裏づけた形）

著者が挙げた三つは、計算でこう確定した。

1. **局所期待値 ⟨a,n⟩ がゼロでない読み出しを作れるか** → 一回の乗算では不可（§2.2）。反対称でない成分が要る。参照の向き c を入れて O_a = L_a L_c とすれば ⟨x, O_a x⟩ = −⟨a,c⟩\|x\|² で非ゼロになるが、これは観測者の ℓ を入れることであり、無名性を一つ捨てる。
2. **特異値が 1 未満の相関行列を作れるか** → 6 個が 1 に張り付くので、現状の状態空間では不可（§2.1、§4.1）。結合子でも不可（§3）。
3. **信号を送れないことが保たれるか** → §2.2 により局所期待値が恒等的にゼロなので、現状では自明に保たれる。ただしそれは「片側だけでは何も見えない」という極端な形である。

## 6. 次の検算

1. **J₃(𝕆) にテンソル積が無いという定理を文献で確認する。** 本当に既知の障害なら、この筋は「八元数だけでは複合系を書けない」という no-go に突き当たったことになり、それ自体が結論になる。
2. **配置の部分集合を二者とする道。** この枠組みの状態は N 個の八元数の配置なので、二者を「配置の二つの部分集合」として取れば、状態空間はもっと大きい。シュミット係数に相当する自由度が出るか。**これが残る唯一の道だと思う。**
3. **参照の向き c を入れたときの局所期待値。** 無名性を一つ捨てる代償で、非ゼロの局所期待値と部分もつれが作れるか。`内と外の選択問題_20261019.md` の「観測者が自分の 1 をどこに置くか」が、ここで具体的な自由度として効く可能性がある。
