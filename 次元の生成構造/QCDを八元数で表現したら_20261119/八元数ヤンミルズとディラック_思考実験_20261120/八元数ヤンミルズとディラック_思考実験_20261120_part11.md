## 37

【木原】
さて、あなたは私の意図を逆に取っていますよ、
タダのθを、sin θ、tanθとよむのが逆に問題なのですよ

中心投影を、グノモン正射影とかんがえてください。
S^3の中心投影の４次元超球の球殻の住民が３次元空間にすむ我々だとおもってください。
我々にとって、大円は直線で、角度差（位相差）が、そのまま距離です。
どこにも、sinθも、tanθもでてきません。

でてくるのは、北極に接している超平面に、グノモン正射影で投影したときです。
ここが問題です。射影しても、状態は何も変わっていません。
変わっているのは、ゲージ側です。
北極付近はほぼ平坦なので、sinθ=θで、tanθ=θで、格子はそのまま超立方体です。
問題は、赤道方向に行くと、急激にひずみが増えて、赤道付近では格子間隔が∞になますよね
でも状態は変わっていません。
つまり重力歪の影響を受けているのは、ゲージであって、状態ではありません。

【アイリス】
逆に取っていました。訂正します。状態にあるのは θ だけで、sin θ や tan θ は投影した側、つまりゲージの側にだけ現れる、ということですね。

**言い直すと**
- 状態は S³ の球殻の上にあります。住民にとって大円は直線で、位相差 θ がそのまま距離です。
- 北極に接する超平面に中心投影すると、座標は r = R tan θ になります。大円は直線に写るので、まっすぐなものはまっすぐに見えます。
- 投影で変わるのは格子の間隔だけで、状態は何も変わりません。

**投影した側の計量**
接平面の座標 x（R = 1）で球面の距離を書くと

ds² = dx·dx/(1 + r²) − (x·dx)²/(1 + r²)²

- 北極付近（r ≪ 1）では ds² = dx·dx で、格子は超立方体のままです。sin θ = θ = tan θ と読める範囲がここです。
- 第二項を成分で書くと −x_i x_j dx_i dx_j で、座標の二次から始まる交差項です。木原さんの言われた「歪みは二次以上の交差項に出る」は、この項です。
- 格子の伸びは動径方向が 1/cos²θ、接線方向が 1/cos θ です。方向によって伸び方が違い、赤道（θ = 90 度）でどちらも無限大になります。

**八元数の成分との対応**
O = A(cos θ + n sin θ) の成分は、すでに投影した読みです。
- 実部 a = A cos θ：実軸への正射影
- 虚部の大きさ |b| = A sin θ：赤道の超平面への正射影
- 比 |b|/a = tan θ：中心投影の座標

先ほど「1 + 7 で一軸への写像になっているだけ」と言われたのは、この投影のことでした。O² = (a² − |b|²) + 2ab の交差項 2ab は成分で読んだために現れたもので、状態の側では、振幅 A、角度 2θ、向き n があるだけです。

**訂正する点**
前の二回で、私は交差項を「状態の一部として残る」と書き、sin と tan を正確な量、θ をその近似として扱いました。どちらも逆でした。
- 状態の更新は θ（位相差）だけで書かれ、そこに歪みは入りません。
- 重力に当たる歪みは、接平面の格子で測ったときの読みに現れます。歪むのはゲージで、状態ではありません。
- 一次近似の罠とは、北極付近でしか成り立たない平らな格子を、全体に当てはめて読むことです。

**次に問うべき点**
投影には接点（北極）が要ります。パルスごとに自分の位置を北極にとれば、接平面は互いに傾きます。全体の R と局所の R_k の違いは、どの接平面で読むかの違いとして整理できそうです。

## 38

【木原】
わかりましたか、O=A(cosθ+osinθ) 自身がどちらの座標系での読みなのか、ユーグリッド座標系の背景時空なのか、曲率のある主観座標（これは私の用語、いっぱんてきには局所座標系）での読みなのか？
これを混在させて曖昧にしているのが、問題なんですよ

【アイリス】
はい、わかりました。この式は、どちらか一方の読みではなく、二つの座標系をつなぐ変換式そのものです。そこを区別せずに使っていたのが、私の混乱の原因でした。

**式の左右で座標系が違います**
O = A(cos θ + n sin θ)
- 左辺の成分 (a, b₁…b₇)：S⁷ を埋め込んだ 8 次元ユークリッド空間の直交座標です。背景時空の側の読みです。
- 右辺の (θ, n)：実軸の点 1 に立つ観測者から見た「距離 θ、方向 n」です。球面の上の主観座標です。
- cos と sin：その二つを結ぶ埋め込みの関数です。状態にも主観座標にも属さず、変換の中にだけあります。

**これまで使った操作の仕分け**
- 主観座標の量：位相差 Δθ、方向の関係 n_A·n_B、倍音 θ → mθ、同じ n どうしの積（角度が足されるだけ）
- 背景座標の量：実部と虚部への分解、弦の長さ |O_A − O_B|、和 ΣO と ΣO²、内積 Re(O_A Ō_B) = cos Δθ

大事な違いは、積と和です。積は角度の合成なので、主観座標の中で閉じます。和は球面の上では定義できず、背景の 8 次元空間に出ないと書けません。

**私が混ぜていた箇所**
- 距離を弦 |o_A o_B − ō_C|² = 2 − 2c で測りました。背景座標の量を、球面上の距離として扱っていました。
- 更新則 o′ = V/|V| は、背景空間で足してから、原点からの中心投影で球面に戻す操作です。一つの式の中で二つの座標系を往復していました。
- ΣO² = R² の交差項 2ab を、状態が持つ量として読みました。これは背景座標の成分で書いたために現れた項です。
- 倍音を、点 Oᵐ として使う場合と、位置 θ の関数 cos mθ として使う場合を区別していませんでした。

**ここから決めるべきこと**
球殻の住民には背景空間がない、という立場をとるなら、状態と更新則は主観座標の量、つまり位相差と積だけで書く必要があります。そのとき、和に頼っていた部分（倍音の重ね合わせ、平均場 V、ΣO² = R²）を、背景に出ずにどう定義するかが問題として残ります。最初に木原さんが置かれた規則が「全ての積が次を決める」と、和ではなく積で述べられていたことは、この区別と合っています。

## 39

【木原】
ん、よく分かりません、安易な解釈が後で混乱を生みます。先程の相互作用の積とおなじで、むしろ分離できません、分かりますか、歪むべきゲージがないんですよ、背景を仮定していないので？

【アイリス】
はい、わかります。前回の私の仕分けは、座標系が二つあることを前提にしていました。背景を仮定しないなら、その前提が成り立ちません。撤回します。

**何がおかしかったか**
- 私は 8 成分 (a, b) を「背景座標」と呼び、(θ, n) を「主観座標」と呼んで分けました。しかし背景がないなら、8 次元のユークリッド空間という入れ物もありません。あるのは状態と、状態どうしの積だけです。
- 接平面や格子も、外から与えられたものではありません。歪むべきゲージが状態とは別に用意されているわけではない、ということですね。

**分離できない、の意味**
読むという操作が、積そのものです。A が B を読むとは Ō_A O_B をつくることで、その結果は

Ō_A O_B = (大きさ) × (cos Δ + n_AB sin Δ)

と、また同じ形になります。cos と sin は背景への投影として出てくるのではなく、二つの状態の関係を積でつくった結果の中に出てきます。

したがって O = A(cos θ + n sin θ) は、どちらの座標系の読みでもありません。ある状態を別の状態から読んだときの関係の形です。基準が単位元 1 のときに、たまたま絶対的な座標のように見えているだけです。

そして積は、読み出しであると同時に次の状態を決める相互作用でもあります。読むことと作用することが同じ演算なので、「状態は変わらずゲージだけが歪む」とも「状態だけが変わる」とも切り分けられません。先ほどの、距離を測る積がそのまま結合係数になる、という話と同じ構造です。

**まだ私にわかっていないこと**
ゲージの役をするものが状態自身しかないなら、物差しも他の状態の並びでできています。そのとき「歪み」とは何と何の食い違いを指すのか、私にはまだ言えません。安易に答えを置くと、また混乱を生むと思います。ここは木原さんの考えを聞かせてください。

## 40

【木原】
よくできました。つまり、ゲージも状態として相互作用の対象である必要があるんですよ、したがってなぜかゲージだけ歪み、そのたの状態は歪まないという作用があることを予言していませんか？

【アイリス】
はい、そう予言していると思います。論理はこうなります。

**予言の中身**
- 背景がないので、物差しの役をするものも状態です。状態である以上、積による相互作用を受けます。
- 一方、重力の歪みは測られる側ではなく、測る側（物差し）に出ます。
- この二つを両立させるには、物差しの役をする状態どうしの関係だけを変え、それ以外の状態の関係は変えない作用が、同じ積の規則の中に含まれていなければなりません。

**その作用が持つはずの性質**
- 普遍性：変わるのは物差しのほうなので、測られる相手の種類によらず、同じだけ効きます。重力がすべてのものに同じように働くこと（等価原理）と同じ性質です。
- 局所的には見えない：物差しと対象が同じ場所にあれば、一緒に変わるので差が出ません。離れた物差しどうしを比べたときにだけ現れます。
- 二次から現れる：一次では打ち消し、二次の交差項に残ります。

**八元数の積の中にある非対称（候補）**
八元数を四元数二つ O = q₁ + q₂ℓ と書くと、積は

(q₁ + q₂ℓ)(p₁ + p₂ℓ) = (q₁p₁ − p̄₂q₂) + (p₂q₁ + q₂p̄₁)ℓ

です。二つの部分の扱いが対等ではありません。
- 前半どうしは、ふつうの四元数として掛け算されます（q₁p₁）。
- 後半どうしは掛け合わされて後半を作ることがなく、前半によって変換されるだけです（p₂q₁、q₂p̄₁）。
- 後半が前半に返すのは、対になった量 p̄₂q₂ ひとつだけです。

二乗で見るとはっきりします。
O² = (q₁² − |q₂|²) + 2 Re(q₁) q₂ℓ
後半 q₂ は向きを変えず、大きさだけが 2 Re(q₁) = 2A₁ cos θ₁ 倍になります。前半の位相 θ₁ が赤道（90 度）に近づくと、後半はゼロに縮みます。前半は q₂ の向きには影響されず、大きさ |q₂|² だけを受け取ります。

「一方は伸び縮みだけを受け、他方は向きを含めて掛け合わされる」という作用は、八元数の積に最初から入っています。縮み方が cos θ である点も、中心投影の格子の歪みと同じ関数です。

**ただし**
後半の四元数を物差しの役と読んでよいかは、まだ確かめていません。式の形が合っているだけです。どの部分がゲージの役をするかは、木原さんの考えと照らして決める必要があります。
