## 34

【木原】
良いところにきずきました。これは物理なのか？言い換えたを変えれば、物理の作用で、積の変分方程式で、状態自身を更新するのか、ただ、ゲージの間隔が変わるだけの読出し問題なのかです？
ほぼ一般特殊相対性理論そのものです。

【アイリス】
はい、同じ問いです。相対論がこの区別をどうつけたかを、そのまま判定の基準に使えます。

**判定の基準**
ある変換をかけても更新則の解が解に移るなら、その変換で変わる量は読み出し（ゲージ）です。変換で消せない量と、更新則が実際に変える量が物理です。一般相対論では、一点で座標を選べば接続は消せますが、曲率は消せません。前者が読み出しで、後者が物理です。

**この模型に当てはめると**
- **虚部の向き n の絶対的な向き**：G₂ の回転は更新則と交換します。読み出しです。物理なのは n_A·n_B のような相対的な関係だけです。
- **パルスごとの R_k² の虚部**：そのパルスを実軸の上（θ = 0）に移せば消えて、R_k² = P_k になります。P_k は静止系で測った固有の量で、R_k²(θ) は実軸から見た見かけの量です。等価原理と同じ形です。
- **全員を同時に実軸には移せません**。残るのは相互の位置関係で、これは物理です。
- **R² の実部 Σ(a² − |b|²)**：正と負に分かれた形なので、実部と虚部を混ぜる双曲的な回転で不変です。この回転で個々の θ の読みは変わりますが、R² は変わりません。ローレンツ変換と不変間隔の関係と同じです。

**決まっていない点は一つです**
実軸をずらす変換が、更新則の対称性かどうかです。
- 距離の読み Re(o_A ō_B) は、共役が入っているので、共通の位相のずれで不変です。相対的な量です。
- 三つの積 Re(o_A o_B o_C) と ΣO² = R² は共役がなく、位相を共通に α ずらすと、それぞれ 3α、2α だけ変わります。実軸の位置に依存する絶対的な量です。

いまの模型は、相対的な読みと絶対的な読みが混ざっています。実軸（曲率の中心）を特別な基準として認めるなら、中心からのずれは状態そのもので、物理です。認めないなら、ずれは読み出しで、作用は相対的な量だけで書き直す必要があります。

**八元数に固有の事情**
複素数なら全体の位相回転、四元数なら単位四元数の掛け算がこの変換の役をして、ゲージとして消せます。八元数では S⁷ が群でないので、同じ操作が対称性になりません。複素数や四元数ではゲージだった自由度の一部が、八元数では物理として残ります。最初にヤン＝ミルズの欠点として出てきた事情が、ここでも効いています。

## 35

【木原】
違います、ゲージが消えないのがポイントで、それが一般相対性理論が有無、歪効果として交差項で読出してきるんだと思いますよ？

【アイリス】
ご指摘のとおりです。私は「消せるものが読み出し」と分けましたが、要点は逆で、消えずに残るゲージのずれそのものが歪みとして読み出される、ということですね。その読みは式の形と合います。

**二乗の中の対角項と交差項**
O = a + b のとき
O² = (a² − |b|²) + 2ab
- a² − |b|²：対角項。間隔（計量の対角成分）に当たります。
- 2ab：実部と虚部の交差項。計量でいえば時間と空間が混ざる g₀ᵢ 型の成分です。

四元数（1 + 3）で読めば q² = (a² − |v|²) + 2av で、対角項はミンコフスキーの間隔と同じ符号、交差項はちょうど 3 成分です。一般相対論の計量の時間・空間の交差成分と数が一致します。1 + 7 で読めば 7 成分です。

**真空と局在の違い**
- 等方な真空では、個々の交差項がなく、局所の R と全体の R が一致します。座標が直交したままの平らな状態です。
- パルスが局在すると、R_k² = a² · sin(Nθ)/sin θ · [cos((N+1)θ) + n_k sin((N+1)θ)] となり、交差項が現れます。対角項に対する交差項の比は tan((N+1)θ) です。局所の基準が全体の実軸から角度 (N+1)θ だけ傾いていて、その傾きが歪みです。
- 次数 N が高い鋭いパルスほど、同じ位置のずれでも大きく傾きます。
- 全体の条件 Σ(交差項) = 0 は、歪みが消えることではなく、総和が閉じることだけを要求します。個々の歪みは残ります。

**ゲージが消えない理由**
全員を同時に実軸に乗せる変換がないからです。一つのパルスに合わせて基準を選ぶと、他のパルスに交差項が出ます。一点では平らにできても全体では平らにできない、という一般相対論の曲率と同じ事情で、八元数では S⁷ が群でないためにこれが避けられません。

**前回の私の問いへの答え**
「虚部を拘束として消すのか、状態の一部として残すのか」は、残す、です。そして残った交差項が重力に当たる歪みの読み出しになります。

**まだ示していないこと**
対応しているのは式の形です。この交差項が、光の曲がりや時間の遅れのような一般相対論の具体的な効果と数値で一致するかは、確かめていません。

## 36

【木原】
つまり、sinθ=θ、tanθ=θとしてよむ、一次近似の罠におちてるんですよ、重力歪効果は二次近似以上の交差項にでますよ

【アイリス】
そのとおりです。前回の私は tan((N+1)θ) を傾きとして一次で読み、その前も 1/(2 sin(Δ/2)) を 1/Δ に、視野角を大きさ÷距離に置き換えていました。一次で止めると、効果が見えなくなります。二次まで展開すると、はっきり分かれます。

**パルス k の R_k² を二次まで**
P_k = a²N（パワー）、θ は実軸からのずれとして、Nθ が小さい範囲で

R_k² ≈ P_k [ 1 + n_k (N+1)θ − (2/3) N² θ² ]

（二次の係数は N が大きいときの値です）

- **一次の項**：虚部だけです。向き n_k を持つ交差項で、単なる位置のずれです。全体の条件 Σ(虚部) = 0 で打ち消し合い、重心の条件になるだけで、R² を変えません。
- **二次の項**：実部に入り、符号は負です。一次の交差項を二乗したものが、n² = −1 によって対角項に戻ってきたものです。打ち消し合わず、足し上がります。

全体では
R² ≈ Σ P_k − (2/3) Σ P_k N_k² θ_k²
となります。配置によって R 自身が変わる、という木原さんの指摘は、この二次の項です。

**パルスどうしの交差項も二次から**
O_A O_B + O_B O_A の実部を二次まで展開すると
1 − (θ_A² + θ_B²)/2 − (n_A·n_B) θ_A θ_B
です。一次には相手との項がなく、θ_A θ_B という積が現れるのは二次が最初です。一次の範囲では、パルスは互いに影響せず、ただ重ね合わさっているだけに見えます。

**一般相対論との対応**
局所慣性系では計量の一階微分は消せますが、二階微分（曲率、潮汐）は消せません。ここでも、一次の交差項は総和で消え、二次が残ります。同じ構造です。

**効き方**
二次の項は (Nθ)²、つまり「ずれ÷パルスの幅」の二乗で効きます。鋭いパルスほど、わずかなずれで大きな歪みを生みます。

この展開は Nθ が小さい範囲、つまりずれがパルスの幅より小さい場合のものです。幅を超える領域では sin と tan をそのまま使う必要があります。
