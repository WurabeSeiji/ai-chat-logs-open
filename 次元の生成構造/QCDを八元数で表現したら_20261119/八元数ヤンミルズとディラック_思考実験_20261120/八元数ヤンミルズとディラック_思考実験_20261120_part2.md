## 5

【木原】
𝔉 の八元数ノルムの二乗

としないで　そのまま　八元数の二乗と考える方がむしろ交差項の意味がわかりやすいのでは？

【アイリス】
おっしゃるとおりです。𝔉² をそのまま計算すると、ノルムの二乗では見えなかった交差項が「色の非可換性」として現れます。

**展開**
𝔉 = Σ e_i F_i（i = 1〜7、F_i は su(3) などのゲージ代数に値をとる）とおきます。八元数の積は e_i e_j = −δ_ij + f_ijk e_k です。これを使うと
𝔉² = −Σ F_i F_i + ½ f_ijk [F_i, F_j] e_k
となります。

- 実部 −Σ F_i² は、トレースをとると作用密度 −|𝔉|² です。前回の「ノルムの二乗」はこの部分です。
- 虚部 ½ f_ijk [F_i, F_j] e_k が交差項です。

**交差項の意味**
- 可換（U(1)）なら [F_i, F_j] = 0 なので消えます。虚八元数を実数の係数で二乗すると純実数になるのと同じことです。
- 非可換ゲージ場では消えません。色の交換子を、八元数の構造定数 f_ijk（G₂ の3形式 φ）で縮約したものになっています。いわば 𝔉 が自分自身ととる八元数クロス積 𝔉 × 𝔉 で、普通のベクトルなら 0 になるはずのものが、色の非可換性のおかげで残っています。
- ゲージ代数のトレースをとると、交換子のトレースは 0 なので消えます。そのため作用には寄与しません。ただし局所的な場の量としては存在しています。

つまり 𝔉² は、八元数の積の構造を通して一つの式の中で次のように分かれています。
- 実部：エネルギー（作用）
- 虚部：自己相互作用の向き

**その先**
八元数は交代的なので冪結合的でもあり、𝔉³ も曖昧さなく定義できます。tr Re(𝔉³) をとると、交差項と 𝔉 の縮約から f_ijk tr(F_i F_j F_k) 型の三次不変量が出てきます。四元数（4次元）に制限すると ε_ijk tr(F_i[F_j, F_k]) になり、QCD でいう3グルーオン演算子 f^abc G^a G^b G^c（次元6）と同じ形をしています。二乗で分かれた「交差項」が、三乗で初めて作用に入る、という読み方ができます。

## 6

【木原】
んーこれ基本的には　ただのつの複素数の積または３つの複素数の積　の実物と虚部と考えても虚数iが7成分oになるだけで？何も複雑な演算ではないのでは？

【アイリス】
はい、計算としては基本的にそのとおりで、複素数の積の実部と虚部を読むだけです。各 e_k は 1 と組めばそれぞれ一つの複素平面 ℂ をつくり、𝔉² の実部 −ΣF_i² は「i² = −1 が7方向ぶんある」というだけのことです。

複素数に追加されるものは、実質的に次の二点だけです。

**1. 虚数単位どうしの掛け算表**
複素数には虚数単位が i 一つしかないので、「異なる虚数単位どうしの交差項」はそもそも存在しません。八元数では e_i e_j（i ≠ j）が第三の e_k になります。どの組がどれになるかを決めるのが f_ijk、つまりファノ平面の7本の線です。前回の交差項 ½ f_ijk[F_i, F_j] e_k は、この表を引いているだけです。この表が G₂ 構造そのもので、e₇ を固定すると SU(3) が残る、という意味のある部分もここに入っています。

**2. 三つの異なる方向を掛けたときの結合子**
アルティンの定理により、任意の二元が生成する部分代数は結合的（四元数と同型）です。そのため 𝔉² や 𝔉³ のように同じものを掛ける限り、計算は四元数の中で閉じ、何も難しくなりません。非結合性が顔を出すのは、ファノ平面の同じ線上にない三方向 e_i, e_j, e_k を掛けたときだけです。ヤン＝ミルズ方程式ではそれが e_ρ(ē_μ e_ν) の項として現れ、ビアンキ恒等式で消えました。

まとめると、「複素数の積 ＋ ファノ平面の掛け算表 7本」で全部書けます。複雑に見えるのは記号のせいで、演算そのものは単純です。中身として新しいのは、その掛け算表がどの方向をどう結ぶかという点だけです。

## 7

【木原】
ここで作用に関係する八元数oがnこあってその全ての積が次のoを決める積による変分を定義できますか？

【アイリス】
はい、定義できます。格子ゲージ理論のウィルソン作用と同じ骨組みになり、八元数では三個の積（三角形）を基本単位にするのがいちばんきれいです。

**n = 3 なら曖昧さがない**
八元数では Re((xy)z) = Re(x(yz)) が成り立ち、しかも巡回的です。そのため三角形の三辺 o₁, o₂, o₃（|o| = 1、S⁷ 上）に対して
S = Σ_三角形 Re(o₁o₂o₃)
は、括弧の付け方によらず一意に決まります。

**変分＝「残りの積が次を決める」**
S は各 o について一次なので、o₁ を含む三角形をすべて集めると
δS = Re(δo₁ · V)、V = Σ (o₂o₃)
となります。|o₁| = 1 の拘束をつけた停留条件は o₁ ∥ V̄、つまり
o₁ = V̄ / |V̄|
です。「他の o の積の和の共役が次の o を決める」という式が、そのまま離散的な運動方程式になります。これはウィルソン作用でいうステープルの和と同じ形です。

**n ≥ 4 の場合**
実部が括弧の付け方に依存し、その差は結合子の項 Re((a,b,c)d) になります。ただし o = exp(εA) の連続極限では、作用の主要項 F² は ε² の交換子から出るのに対し、結合子は ε³ から始まります。主要項は変わらず、括弧の選び方は高次の補正として効きます。どの括弧を選ぶかは、それ自体がモデルの選択（データ）になります。

**対称性：ゲージ群の代わりに三対性**
S⁷ は群ではないので、通常の局所ゲージ変換 o → g o h⁻¹ はそのままでは閉じません。代わりに、Re(xyz) は Spin(8) の三対性で不変です。(x, y, z) をそれぞれ三つの 8 次元表現として同時に回すと、値が変わりません。さらに、全体に G₂ をかける大域的な自己同型でも不変です。三角形ごとの三対性を格子全体で矛盾なく貼り合わせて、局所対称性として扱えるかどうかは、私の知る限り確立した答えのない問題です。

整理すると、こうなります。
- 作用：三つ組の積の実部の和
- 運動方程式：各 o が残りの積の和の共役に揃う
- 対称性：ゲージ群の代わりに三対性

## 8

【木原】
んー8元数3個なら　矛盾なく　積が定義できる　この定義できる八元数3個の積の変分式で次の八元数3個になる式を展開して表現できますか？

【アイリス】
はい、展開できます。八元数を o = a + b（a は実部、b ∈ ℝ⁷ は虚部）と書けば、必要なのは内積と7次元クロス積だけです。

**二つの積**
xy = (a_x a_y − b_x·b_y) + (a_x b_y + a_y b_x + b_x × b_y)
ここで (b × c)_k = f_ijk b_i c_j です（ファノ平面の掛け算表）。

**作用（三つの積の実部）**
S = Re(o₁o₂o₃)
　= a₁a₂a₃ − a₁(b₂·b₃) − a₂(b₁·b₃) − a₃(b₁·b₂) − φ(b₁, b₂, b₃)
φ(b₁, b₂, b₃) = f_ijk b₁^i b₂^j b₃^k は G₂ の3形式です。複素数の場合にない項はこの φ だけです。

**変分から得る更新式（次の三つ組）**
Re(xy) = ⟨x, ȳ⟩ なので、∂S/∂o₁ = conj(o₂o₃) です。o₁, o₂, o₃ を順に更新すると、次のようになります。
- o₁′：a₁′ = a₂a₃ − b₂·b₃、b₁′ = −(a₂b₃ + a₃b₂ + b₂ × b₃)
- o₂′：a₂′ = a₃a₁′ − b₃·b₁′、b₂′ = −(a₃b₁′ + a₁′b₃ + b₃ × b₁′)
- o₃′：a₃′ = a₁′a₂′ − b₁′·b₂′、b₃′ = −(a₁′b₂′ + a₂′b₁′ + b₁′ × b₂′)

ノルムは積で保たれるので、正規化は要りません。

**注意：三角形が一つだけだと一手で止まる**
o₁′ = conj(o₂o₃) とした時点で o₁′o₂o₃ = 1、つまり S は最大値 1 に達します。さらに交代性 x(x̄y) = |x|²y から o₂′ = o₂、o₃′ = o₃ となり、そのまま固定点です。三つ組が一つだけでは「真空 o₁o₂o₃ = 1 に落ちる」だけです。

**意味のある時間発展にする二つの方法**
1. 勾配流にして途中経過を見る（ε は刻み幅）。
　o₁ ← normalize(o₁ + ε G₁)、G₁ = conj(o₂o₃) − S·o₁
　成分で書くと次の二式で、o₂, o₃ も巡回置換で同じ形です。
　da₁/dt = (a₂a₃ − b₂·b₃) − S·a₁
　db₁/dt = −(a₂b₃ + a₃b₂ + b₂ × b₃) − S·b₁
2. 三つ組どうしが八元数を共有する格子にする。o₁ を含む三角形 T すべてについて足し合わせ、
　o₁′ ∝ Σ_T conj(o₂^T o₃^T)
　とします。隣の三角形と引っ張り合うので、真空に一手では落ちず、非自明な配位や波が生じます。

どちらの場合も、八元数に固有の寄与はクロス積 b × b と φ の項だけです。そこが G₂ 構造、つまり SU(3) を含む部分の入口になります。
