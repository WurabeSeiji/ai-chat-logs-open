## 1

【木原】
ヤンミルズの方程式とはなんですか

【アイリス】
ヤン＝ミルズ方程式は、マクスウェル方程式を非可換なゲージ群（SU(2)、SU(3) など）に拡張した場の方程式です。1954年にヤン（楊振寧）とミルズが提案しました。

**基本形**
- 場の強さ：F_μν = ∂_μA_ν − ∂_νA_μ + g[A_μ, A_ν]
- 運動方程式：D_μF^μν = J^ν（D_μ = ∂_μ + ig[A_μ, ·] は共変微分）
- ビアンキ恒等式：D_[λ F_μν] = 0
- ラグランジアン：L = −(1/2) tr(F_μν F^μν)

ゲージ群が U(1) なら交換子 [A, A] が消え、そのままマクスウェル方程式に戻ります。非可換群では交換子の項が残るので、方程式は非線形になります。そのため、光子と違ってゲージ粒子自身が色荷を持ち、ゲージ粒子どうしが直接相互作用します（3点・4点の自己結合）。

**物理での役割**
- SU(3) にとると量子色力学（QCD）になり、グルーオンの力学を表します。漸近的自由性（高エネルギーで結合が弱くなる）とクォークの閉じ込めは、どちらもこの非線形な自己相互作用から生じます。
- SU(2)×U(1) にとると電弱理論の土台になります。
- 量子化した純ヤン＝ミルズ理論に正の「質量ギャップ」があることの数学的証明は、クレイ研究所のミレニアム問題の一つで、まだ解かれていません。格子QCD はこの理論を非摂動的に数値計算する主な方法です。

幾何学の言葉で言えば、A は主束上の接続、F はその曲率で、方程式は曲率が「調和的」であるという条件になります。SU(2) は単位四元数の群、つまり S³ と同じものなので、SU(2) ヤン＝ミルズ場は四元数に値をとる接続として書き直せます。インスタントン（反自己双対解 F = −*F）もこの形で扱うと見通しがよくなります。

## 2

【木原】
八元数で書き直すと

【アイリス】
八元数でも書き直せますが、四元数のように「単位八元数＝ゲージ群」とはなりません。S⁷ は群にならないからです。それでも、八元数の構造を使った正しい書き方が三つあります。

**1. そのまま書くと壊れる理由**
A_μ = A_μ^a e_a（a = 1〜7、虚八元数）とおき、F = ∂A − ∂A + (g/2)[A, A] と書くことはできます。しかし八元数は結合法則を満たさないので、ヤコビ恒等式が成り立ちません。
[[x,y],z] + 巡回 = 6(x,y,z)（右辺は結合子で、0 にならない）
このため次の三つが成り立ちません。
- ゲージ変換の合成が閉じない
- [D_μ, D_ν] = ad F_μν が成り立たない
- ビアンキ恒等式が成り立たない

数学的には、虚八元数はリー代数ではなくマルツェフ代数です。そのままではヤン＝ミルズ理論になりません。

**2. 自己同型群 G₂ を使う（QCD との接続）**
八元数の積を保つ変換全体の群 G₂ = Aut(𝕆)（14次元）は、普通のリー群です。そこで G₂ をゲージ群にとります。
- 虚単位 e₇ を一つ固定すると、それを動かさない G₂ の部分群がちょうど SU(3) になります。
- 𝕆 = ℂ ⊕ ℂ³ と分かれ、虚八元数の 7 は SU(3) のもとで 1 + 3 + 3̄ に分解します。
- リー代数も g₂ = su(3) ⊕ 3 ⊕ 3̄（14 = 8 + 3 + 3）と分かれます。

つまり、グルーオンの 8 生成子は「e₇ を保つ八元数の微分（derivation）」です。ギュナイディン＝ギュルセイ（1973）による八元数クォーク模型の出発点がここにあります。QCD はこの形で八元数から読み出すのが筋がよい方法です。

**3. 八元数的自己双対（インスタントンの拡張）**
四元数が 4 次元の自己双対 F = ±*F を与えるのと同じように、八元数は高次元の一階方程式を与えます。
- 8 次元では、八元数の構造定数から作るケイリー4形式 Φ（Spin(7) 構造）を使い、F_μν = (λ/2) Φ_μνρσ F^ρσ とします。
- 7 次元では、f_abc を G₂ の 3 形式 φ とみなし、φ^abc F_bc = 0（同じことを *(φ∧F) = −F とも書けます）とします。

どちらの解も、ビアンキ恒等式によって自動的に D_μF^μν = 0 を満たします。4 次元と同じ仕組みです。BPST インスタントン A = Im(x̄ dx)/(ρ² + |x|²) の x を八元数に置き換えたものが、フビーニ＝ニコライの 8 次元八元数インスタントンです（コリガン＝デヴシャン＝フェアリー＝ナイツ 1983、フビーニ＝ニコライ 1985）。

整理すると、八元数そのものを「場の値」にするのではなく、八元数の積の構造（G₂、Φ、φ）を「ゲージ場がどう振る舞うかを決める幾何」として使うと、矛盾なく書けます。

## 3

【木原】
運動方程式を八元数で表すと

【アイリス】
運動方程式 D_μF^μν = J^ν は、八元数を使うと一本の方程式 𝔇𝔉 = 𝔍 にまとまります。8次元ユークリッド空間で組み立てると次のようになります。

**記号**
- 微分：𝔇 = Σ e_μ D_μ（μ = 0〜7、e₀ = 1）
- 場：𝔉 = ½ Σ ē_μ e_ν F_μν（虚八元数に値をとる）
- 源：𝔍 = Σ e_ν J_ν

ゲージ群の生成子（su(3) など）は八元数単位とは別の因子なので、互いに可換です。

**運動方程式**
𝔇𝔉 = 𝔍

この式の e_ν 成分が D_μF_μν = J_ν にちょうど一致します。

**非結合性が消える理由**
𝔇𝔉 を展開すると、e_ρ(ē_μ e_ν) D_ρF_μν が出てきます。八元数の積は次のように分解できます。
e_ρ(ē_μ e_ν) = δ_ρμ e_ν − δ_ρν e_μ + δ_μν e_ρ + χ_ρμνσ e_σ
（χ は完全反対称で、ケイリー4形式 Φ から決まります。符号は規約によります）

非結合性はこの完全反対称部分 χ にだけ現れます。一方 D_[ρ F_μν] = 0 なので、χ との縮約は消えます。つまり、八元数の結合子をビアンキ恒等式がちょうど打ち消すので、一本の式が矛盾なく成り立ちます。

**構造的な意味**
- 8次元の F_μν（28成分）は Spin(7) のもとで 7 + 21 に分かれます。𝔉 はこのうち 7 成分だけを拾います。
- それでも運動方程式は書けます。ビアンキ恒等式から D_μF^μν = 4 D_μF^(7)μν が成り立ち、源と結合するのは 7 成分だけだからです。
- 𝔉 = 0（F が 21 にだけ値をもつ）がちょうど八元数インスタントンの条件で、このとき 𝔍 = 0 の運動方程式が自動的に成り立ちます。

**次元と符号の注意**
- 7次元では x₀ を落とせば G₂ 版になります。
- 物理の4次元では、四元数の部分代数 ℍ ⊂ 𝕆 に制限すると、同じ形 𝔇𝔉 = 𝔍 が四元数版のヤン＝ミルズ（マクスウェル）方程式になります。このとき 𝔉 は反自己双対部分の3成分です。
- ミンコフスキー計量にするには、分解型八元数（split-octonions）か複素化が必要です。

## 4

【木原】
𝔇𝔉 = 𝔍
ってずいぶんシンプルですが、 変分式で考えるとどういう解釈になるのですか？

【アイリス】
変分で見ると、作用がほぼ「𝔉 の八元数ノルムの二乗」になっているので、𝔇𝔉 = 𝔍 はその作用の極値条件そのものです。

**作用の分解**
F を Spin(7) 成分に分けて F = F^(7) + F^(21) とします。演算子 ½Φ· の固有値は 7 成分で 3、21 成分で −1 なので、
|F|² = |F^(7)|² + |F^(21)|² = 4|F^(7)|² − F·(½Φ·F)
となります。最後の項を積分すると ∫ tr(F∧F)∧Φ です。tr(F∧F) は閉形式で、dΦ = 0 でもあるので、これは表面項、つまり位相不変量になります。したがって、定数倍を除いて
S_YM = ∫ |𝔉|² + （位相不変量）
が成り立ちます。

**解釈**
1. 局所的な変分に効くのは 𝔉（7 成分）だけです。21 成分の寄与は全微分になり、極値条件には入りません。21 成分は消えたわけではなく、ビアンキ恒等式を通じて 7 成分に従属しています。これが方程式が一本にまとまる理由です。
2. 𝔉 は 𝔄 から一階の作用素 𝔄 ↦ Im(𝔇̄𝔄) でつくられます。𝔇 はその随伴作用素です。そのため ∫ |𝔉|² − Re(𝔄̄𝔍) を変分すると、部分積分で δ𝔄·(𝔇𝔉 − 𝔍) が残り、𝔇𝔉 = 𝔍 が出ます。構造はディラック作用素と同じで、𝔇𝔇̄ = □ という「ラプラシアンの平方根」になっています。
3. 可換の場合、Re(𝔇̄𝔄) = ∂·A はローレンツゲージ条件です。八元数で書くと、ゲージ固定が実部として自然に組み込まれます。

**BPS 下限**
S ≥ |位相不変量| が成り立ち、等号は 𝔉 = 0 のときだけです。つまり八元数インスタントンは、各位相セクターでの作用の絶対最小です。𝔇𝔉 = 𝔍 は二階の方程式ですが、その真空解は一階の条件 𝔉 = 0 で尽くされます。

**4次元の場合**
四元数（4次元）でも同じ構造で、S = 2∫|F⁻|² + 8π²k（k はインスタントン数）となります。八元数版は、この古典的な議論を Spin(7)/G₂ に持ち上げたものです。
