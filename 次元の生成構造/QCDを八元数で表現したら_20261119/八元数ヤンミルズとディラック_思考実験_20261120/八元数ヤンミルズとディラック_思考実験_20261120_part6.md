## 18

【木原】
んー簡単ですよ　ここで系が有界で閉じてるって仮定すると　位相が360度で閉じるので節ができて定常波になる拘束条件が効くので距離も有界でですよ？

【アイリス】
その点はおっしゃるとおりで、しかも仮定する必要すらありません。|o| = 1 と決めた時点で状態空間は S⁷ で、有界で閉じています。距離の最大は対蹠点の 180 度で、それより遠くはありません。

**定常波はすでに式に出ていました**
無名な和の結果 Re(P³) = R³ cos 3θ は、閉じた位相の上のモード数 3 の定常波そのものです。
- 腹は θ = 0°、120°、240°（o³ = 1 の解）の三つです。
- 節は cos 3θ = 0 の六か所です。
- 三つ組の積で閉じるという条件が、360 度の周期と組み合わさって、整数 3 を決めています。

つまり落ち着く先は「一点」ひとつではなく、整数で番号がつく離散的な状態です。八元数では θ = 120° の解は虚部の方向が自由なので、点ではなく S⁶ の広がりを持ちます。重み w = (1 + c)/2 も、ちょうど対蹠点に節を持つ定常波型の関数です。

前回の「一点に潰れる」という心配は、開いた空間での引き込みの見方を持ち込んだもので、閉じた系では問いの立て方が違っていました。問うべきは「潰れるかどうか」ではなく「どのモードが残るか」です。

**まだ決まっていないこと**
有界で閉じていることは、定常状態が離散的になることを保証しますが、どのモードが安定かまでは決めません。円周上の二体の引き込みでは、閉じていても安定なのは全員が揃った状態だけ、という結果が知られています。三体の場合は目標が「全員同じ」ではなく「三つの和が閉じる」なので事情が違い、三つの腹に分かれた状態が安定に残る可能性があります。ただし 0°、0°、120° のように腹をまたぐ組は閉じないので、そこでの重みがどう効くかで結果が変わります。ここは計算で確かめる部分です。

## 19

【木原】
だから蔵本モデルですよ　繰り返し積の変分すると自己無撞着になり準定常になるんでしょう

【アイリス】
はい、そのとおりです。構造は蔵本モデルの自己無撞着方程式と同じで、しかも収束は保証されています。

**自己無撞着の形**
無名性があるので、系は「どの値にどれだけいるか」という分布 ρ だけで書けます。
- 各 o が受ける場：V[ρ](o) = ∬ w(Re(o o′ o″)) conj(o′ o″) ρ(o′) ρ(o″)
- 更新：各 o は V[ρ](o) の方向へ動く
- 定常条件：ρ が乗っている全ての o で o ∥ V[ρ](o)

場は分布から決まり、分布は場で動きます。繰り返すと両者が一致するところに落ち着きます。蔵本が秩序変数 r e^{iψ} について解いたのと同じ閉じ方で、秩序変数が円周上の一つの複素数から、S⁷ 上の三体の場に変わっただけです。

**収束する理由**
更新は S_f の勾配流で、S_f は単調に増えます。状態空間は有界で閉じているので S_f には上限があります。したがって必ず定常状態の集合に近づきます。ここは計算するまでもなく言えます。

**「準」定常になる理由**
- 定常状態は孤立した点ではありません。腹 θ = 120° が S⁶ の広がりを持ち、全体に G₂ の回転の自由度もあるので、その方向には押し戻す力がなく、ゆっくり漂います。
- 離れた塊どうしは重みが小さいので、合体するまでに長い時間がかかります。そのあいだ、ほぼ止まって見える状態が続きます。

**距離の重みが要る理由**
重みが一定だと V は全員に共通の conj(P²) になり、全員が同じ一点に揃います。自己無撞着な解は o³ = 1 の一点だけで、構造は残りません。w が距離に依存して初めて V が o ごとに違う値になり、複数の塊が共存する解が可能になります。木原さんが言われた「距離が結合係数になる」ことが、構造が残るための条件になっています。

残っているのは、自己無撞着な解のうちどれが実際に現れるかです。これは初期分布と w の形で決まります。

## 20

【木原】
つまり初期状態だけが系に与える外部パラメータで、あとは決定論的に動きますよ

【アイリス】
はい、そうなります。整理すると次のとおりです。

**規則の側（数値パラメータなし）**
- 八元数の掛け算表。フルヴィッツの定理で候補が四つしかなく、その最大のものです。
- 三つの積の実部を読むこと。括弧によらない最大の個数として決まります。
- 重み w。距離そのもの（w = (1 + c)/2）とすれば、調整する定数はありません。
- 更新を o′ = V/|V| の反復にすれば、刻み幅もありません。

ただし「距離をそのまま重みにする」という関数形だけは、定理から出たものではなく、規則として選んだものです。

**外から与えるもの**
初期状態だけです。中身は個数 N と、S⁷ 上の N 個の値です。無名性があるので、順番には意味がなく、値の集まり（分布）だけが情報です。さらに全体を G₂ で回しても同じ系なので、実質的な自由度は「初期分布を G₂ の回転で同一視したもの」です。

**決定論から出てくる帰結**
- 更新は入れ替えと G₂ 回転に対して対称なので、初期状態が持つ対称性は最後まで保たれます。全員が同じ値なら永久にそのままです。現れる構造は、すべて初期分布の非対称性が展開したものです。
- 前に量子化の説明で使った「ノイズを加える」は、外からの入力になるので使えません。確率的に見える部分は、初期状態を知らないこと、または粗く読むことから出る、と読み出しの側で説明する必要があります。
- 定常状態の漂い（S⁶ や G₂ の方向）も偶然ではなく、初期状態で決まります。

つまり、「どんな初期分布から、どんな準定常の構造が読み出せるか」が、この系について問えることの全部です。

## 21

【木原】
「距離をそのまま重みにする」という関数形だけは、定理から出たものではなく、規則として選んだものです。

誤読ですよ　これがヤンミルズやディラックと近い結果を生むなら選択ではなく物理ですよ？

【アイリス】
ご指摘のとおりです。「選んだ」という言い方は、恣意的に決めたように読めるので不適切でした。物理法則はどれも、結果が自然と合うことで法則になります。この規則も同じ立場です。

**すでに決まっている部分**
重みの形は自由ではなく、これまでの議論でかなり絞られています。
- 無名性と G₂ 不変性から、重みは c = Re(o_A o_B o_C)、つまり距離だけの関数です。
- 一定の重みでは全員が一点に揃って構造が消えるので、距離に依存しなければなりません。
- 有界で閉じた系なので、最も遠い対蹠点で結合が切れるのが自然です。

距離そのものを重みにする形は、この三つを満たすいちばん単純なものです。

**「物理である」ことの確かめ方**
確かめ方は二通りあり、どちらに転んでも「選択」ではなくなります。
- 重みの細かい形を変えても準定常の構造が変わらない場合。臨界現象の普遍性と同じで、形は効いておらず、そもそも選択の余地がなかったことになります。
- 形によって構造が変わる場合。ヤン＝ミルズとディラックに一致する形がひとつに決まり、それが法則です。

**現時点で言えること**
ヤン＝ミルズとディラックの型が出ることを示したのは、三つ組の配列を私が与えた場合と、三重積の代数的な構造についてでした。距離の重みで配列が自然に生じ、その上で同じ型が現れるかは、まだ示していません。ここが示されれば、木原さんの言われるとおり、重みは規則の一部ではなく物理です。

## 23

【木原】
つまり標準ゲージ理論より劇的に計算量が少ないです　背景時空を仮定しないのが逆にメリットですね

【アイリス】
はい、その比較は妥当です。少なくなる理由は三つあります。

- **空の空間に計算を使いません。** 格子QCD は 64³×128 で約 3000 万点を用意し、その大半は真空の揺らぎの記述に使われます。こちらは N 個すべてが状態そのものです。
- **確率的なサンプリングが要りません。** 格子では配位を数千個つくって平均します。こちらは決定論的なので、一つの初期状態につき一回の走行で済みます。
- **フェルミオン行列の逆を解きません。** 格子QCD の計算時間の大半はここです。こちらは三つの積の読み方の違いなので、別の計算になりません。

背景時空を置かないことで、格子間隔をゼロに近づける外挿、体積の外挿、正方格子に由来するダブリングといった、格子を置いたことから生じる作業もなくなります。

**規模の見通し**
- N = 100：一回の更新で 100 万組。瞬時です。
- N = 1000：10 億組。MacBook で一回数秒程度です。
- N = 1 万：1 兆組で重くなります。ただし遠い組は結合が切れるので、近い組だけ残せば大きく減らせます。

**一点だけ**
格子QCD の計算量は、ハドロンの質量のような具体的な数値を出すための量です。こちらは、同じ種類の量を読み出すのに N がいくつ要るかがまだわかっていません。「劇的に少ない」が確定するのは、読み出す量を決めて、それが N = 100〜1000 で安定することを確かめたときです。
