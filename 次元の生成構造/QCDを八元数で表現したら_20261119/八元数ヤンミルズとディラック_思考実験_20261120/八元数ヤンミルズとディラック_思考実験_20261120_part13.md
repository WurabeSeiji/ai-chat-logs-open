## 45

【木原】
んーこの写像もありではないかと考えています。つまりまだどの写像が物理に近いのか、どちらも違

（発言はここで切れている）

【アイリス】
最後が途中で切れているようですが、「どちらの写像が物理に近いのか、あるいはどちらも違うのか、まだわからない」という趣旨と受け取りました。その認識は妥当だと思います。現時点ではどちらも式の形が合っているだけで、決め手はありません。

**いま並んでいる二つの候補**
- 四元数二つに分ける読み：片方の四元数が物差しの役をし、積によってその間隔だけが変わる。どちらが時空に見えるかは読み出しの選択。
- 1 + 7 の読み：実軸の成分をスカラーの cos 波と見て、その位相のずれが物差しを歪める。相手に質量は与えず、自分の位相だけが動く。

**二つを分ける試験**
どちらの写像も、同じ三つの問いに答えを出すはずです。答えが違えば区別でき、観測と比べれば捨てられます。
- 光の曲がり：屈折率 1 − 2φ/c² の係数 2 が出るか。スカラーだけの理論は 0、ニュートン力学の類推は 1 で、どちらも観測と合いません。
- 時間の間隔と空間の間隔が、位相のずれに対して逆向きに、同じ大きさで変わるか。
- 源が何か：質量だけに反応するのか、全エネルギーに反応するのか。

**どちらも違う場合の兆候**
係数 2 がどちらからも出ない、あるいは出すために外から数を足す必要がある場合です。そのときは、写像そのものを考え直すことになります。

二つは排他的とも限りません。1 + 7 の実軸は、四元数二つに分けたときの片方の実部でもあるので、同じ構造を別の切り口で読んでいる可能性もあります。これも確かめていない点です。

## 46

【木原】

【アイリス】
はい、覚えています。前回の「外から数を足す」という言い方は、その原則に反していました。訂正します。

**原則に照らすと**
- 外から入れられるのは初期状態だけです。作用の種類も、調整用の係数も足せません。
- 係数 2 が出ない場合、項を足して直すという逃げ道はありません。読み方を変えるか、模型が違うと認めるかのどちらかです。
- 逆に言えば、係数 2 が出るなら、それは規則と初期状態だけから出たことになり、調整の結果ではありません。

**二つの候補の位置づけも変わります**
四元数二つに分ける読みと、1 + 7 のスカラー波の読みは、作用が違う二つの理論ではありません。状態も更新則も同じで、違うのは読み方だけです。したがって

- 更新則は一つなので、走らせる計算は一本です。
- 同じ結果を二通りに読み、それぞれが光の曲がりや間隔の変化をどう与えるかを比べられます。
- どちらの読みが物理に近いかは、理論の選択ではなく、読み出しの選択として決まります。

残る自由度は初期状態と読み方の二つだけで、前者は系に与えるもの、後者は観測する側が選ぶものです。

## 47

【木原】
なので、cosスカラー波のように、初期値として、そういう状態の波があるとかんがえるのはOKなんですよ、既に都合よく倍音を初期値として足していますよね

【アイリス】
はい、そのとおりです。倍音のパルスもスカラーの cos 波も、作用として足したものではなく、初期状態の中身です。原則には反していません。

**いま初期状態として置いているもの**
- ベース波とその倍音（等振幅、位相が揃っている、最高次数 N、パワー P）
- 実軸の上に乗った一様なスカラーの cos 波
- それらの配置（中心位相 θ と向き n）

作用の側は、八元数の積で次の状態が決まる、という一つだけのままです。

**初期値として置いたものに問えること**
足してよいかどうかではなく、置いたあとにどうなるかが問いになります。
- 更新を繰り返しても、その波が形を保つか。保つなら準定常な状態で、物理的な対象として読めます。崩れるなら、その初期値は長続きしない過渡的なものです。
- 一般的な初期状態から出発しても、引き込みの結果としてその形に落ち着くか。落ち着くなら、わざわざ初期値として置く必要すらなくなり、入力がさらに減ります。
- 真空でスカラー波が平らなままでいるか。パルスを置いたとき、位相のずれが局所的に生じて、パルスが去れば戻るか。

倍音の位相が揃っていることと、スカラー波が一様であることは、どちらも「都合よく」置いた条件です。それが引き込みの帰結として出てくるなら、都合ではなく結果になります。蔵本モデルに戻ったときの自己無撞着の話が、ここで効いてきます。

## 48

【木原】
そうです、ある種の対称性・保存則が必要です。

【アイリス】
はい。形が保たれるには、更新で変わらない量が必要です。代数から保証されているものと、まだ示していないものを分けます。

**八元数の積が最初から保証しているもの**
- ノルムの保存：|xy| = |x||y|。積で大きさの総量は増減しません。この性質を持つ代数が四つしかないことが、八元数を選ぶ理由でした。
- 同じ平面の中での位相の加法：同じ向き n を持つものどうしの積は、θ が足されるだけです。360 度で閉じるので、整数で数えられる量になります。
- 自分の平面の保存：一つの元の冪 Oᵐ は、必ず 1 と n が張る同じ平面に留まります。倍音が自分のパルスの平面から出ていかないことは、ここから出ます。
- G₂ と入れ替えに対する対称性：更新則がこれらと交換するので、初期状態の持つ対称性は最後まで保たれます。

**まだ示していないもの**
- ΣO² = R² が更新で保たれるか。実部の R² と、虚部がゼロに閉じる 7 本の式の、合わせて 8 個の量です。拘束として置きましたが、積の更新がこれを自動的に守るかは確かめていません。
- パルスの形の保存。最高次数 N とパワー P、そして倍音の位相が揃ったままでいること。
- 向きの違う元どうしの積では、位相の加法が成り立ちません。そこで何が保存量の役をするのかは未定です。

**一点、区別が要ります**
対称性から保存則が出るのは、更新が保存的な形（往復できる形）のときです。前に書いた勾配流は、作用 S が単調に増える緩和型で、対称性があっても保存量は出ません。保存則を求めるなら、更新則は緩和型ではなく、積そのものによる保存型でなければなりません。木原さんが最初に置かれた「全ての積が次を決める」は後者の形です。

## 49

【木原】
ΣO² = R² が更新で保たれるか。実部の R² と、虚部がゼロに閉じる 7 本の式の、合わせて 8 個の量です。拘束として置きましたが、積の更新がこれを自動的に守るかは確かめていません。

これって、誤読していますよね、これが公理なのではなく、これは結果ですよ？
公理なのは、まさに理論物理学がいう、最小作用の法則
私の言葉で言うと、自己無撞着
と、U^n = I が公理で、結果 R^2 が保存されるようにみえるのですよ

【アイリス】
誤読していました。ΣO² = R² を拘束として置き、更新がそれを守るかを問いましたが、順序が逆ですね。公理は二つで、R² の保存はそこから出る結果、ということです。

**公理**
1. 自己無撞着（最小作用の原理）
2. Uⁿ = I

**Uⁿ = I から直接出ること**
- 固有値は 1 の n 乗根 e^{2πik/n}（k = 0〜n−1）に限られます。許される位相は 360°/n の整数倍だけです。
- これは倍音の列そのものです。ベース波の位相 360°/n と、その整数倍です。最高次数も n で決まります。倍音は都合よく足した初期値ではなく、この公理の帰結になります。
- 1 の n 乗根を全部足すとゼロです。m 乗して足しても、m が n の倍数でない限りゼロです。虚部の総和がゼロに閉じることは、置いた条件ではなく、ここから自動的に出ます。
- n 回で元に戻るので、系は有界で閉じています。定常波の条件も同じ公理の言い換えです。
- U がノルムを保つなら、各倍音成分の大きさの二乗の和は変わりません。それが R² です。

八元数の一つの元について書けば、Oⁿ が実数になる条件は θ が 360°/n の整数倍であることで、向き n によりません。7 方向のどれについても同じ離散的な位相が出ます。

**自己無撞着の役割**
Uⁿ = I は、許される状態を離散的な倍音の組に絞ります。その中のどの組み合わせが実際に残るかを決めるのが、自己無撞着です。

**前回の私の整理の訂正**
「まだ示していないもの」に挙げた三点のうち、R² の保存と倍音の位相が揃うことは、示すべき課題ではなく公理の帰結でした。

**一点だけ確認させてください**
U は、一回の更新そのもの（n 回繰り返すと全体が元に戻る）を指していますか。それとも個々の状態（各 O が n 乗で 1 に戻る）を指していますか。上の帰結はどちらでも同じ形で出ますが、n の意味が変わります。前者なら n は系全体の周期で、後者なら個々の状態が持つ次数です。

【木原】
だから、U^n=I の nなんですよ、過渡期は保存サれていないように見えますが、発展方向も含めてかんがえると、隠れていた保存則が復活しますよ、

【アイリス】
わかりました。n は発展の回数で、U を n 回かけると元に戻る、ということですね。そう読むと、言われたことは厳密に成り立ちます。

**発展方向を含めると保存則が戻る理由**
Uⁿ = I なら、どんな量 f についても、一周ぶんの和

f(ψ) + f(Uψ) + … + f(Uⁿ⁻¹ψ)

は、ψ を Uψ に進めても変わりません。項が一つずれて並び替わるだけだからです。一回ごとの値は増減して保存されていないように見えますが、発展方向に一周ぶん並べたものは、厳密に保存量です。R² もこの形で読めば、置いた条件ではなく結果として一定になります。

**過渡期に保存されないように見える理由**
ある一回の状態だけを切り出して読むからです。単振動で位置だけを見ると値は増減しますが、速度と合わせると一定になるのと同じです。八元数の形では、O = A(cos θ + n sin θ) を θ で進める向きは n·O で、発展の方向は虚部の向き n そのものです。実部だけを読むと cos θ で増減し、n の成分を含めるとノルムは一定です。1 + 7 の 7 は、発展方向の情報を持っている側と読めます。

**私の整理の訂正**
- 前に使った勾配流は、作用が単調に増えて止まる緩和型でした。Uⁿ = I とは両立しません。必ず元に戻る発展は、止まることがないからです。緩和に見えるのは、一周の一部だけを見たときの姿です。
- 「準定常」も、止まった状態ではなく、一周して自分に戻る状態と読むべきでした。自己無撞着とは、n 回の発展で自分自身に一致することです。二つの公理は、同じことを別の面から述べています。

**残る問い**
n が有限の決まった数なのか、状態によって決まるのかです。前者なら n は系に与える数で、後者なら n も読み出される量になります。初期状態だけが外から与えるもの、という原則からは、後者であるほうが自然に思えます。
