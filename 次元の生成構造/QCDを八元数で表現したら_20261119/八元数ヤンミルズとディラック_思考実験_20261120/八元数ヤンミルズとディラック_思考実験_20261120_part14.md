## 51

【木原】
ん、nが初期値で与えられるというのも幻想ですよ、あたえるものではなく結果です。
場合によっては、n=∞という結果もあります。
つまり極めて長周期の場合、∞と区別ができません。宇宙がビッグクランチするかどうかなんで、確かめられない（観測できない）のとおなじで、区別できません。

【アイリス】
そのとおりですね。n も与えるものではなく、状態と発展から決まる結果です。

**n がどう決まるか**
- 各成分の位相の進みが 360 度の有理数倍なら、それらが同時に元に戻る回数、つまり各周期の最小公倍数が n です。
- 比が有理数でなければ、厳密には二度と戻りません。n = ∞ です。
- 成分が増えると、最小公倍数は急激に大きくなります。個々の部分の周期は短くても、全体の n は桁違いに長くなります。

**区別できないことの中身**
有界で閉じた保存的な系は、どれだけ小さな誤差を指定しても、その範囲内には必ず戻ってきます（ポアンカレの再帰）。厳密に戻るか、限りなく近くに戻るだけかは、有限の精度の観測では区別できません。有理数と無理数を有限桁で区別できないのと同じです。

したがって、観測される n は読む側の精度に依存します。粗く読めば短い周期で閉じて見え、細かく読むほど n は延びます。n そのものが読み出しの量です。

**公理の読み替え**
Uⁿ = I は「ある決まった n が存在する」という主張ではなく、「系は有界で閉じていて、発展で何も失われない」という主張と同じ内容になります。n が有限か無限かは、その公理からは決まらず、決める必要もありません。

**局所と全体**
- 一つのパルスの倍音が揃って戻る周期は短く、観測できます。局所的な閉じ方です。
- 全体が戻る周期は、確かめようのない長さです。宇宙が再び縮むかどうかと同じ種類の問いです。

局所の R_k と全体の R の関係も、同じ形で読めます。局所では閉じていることが確かめられ、全体については閉じていると仮定するしかありません。

## 52

【木原】
既に誤読していますよ、有界で有限だと定義しているので、nは必ず有限です。
でも、極めておおきければ、たとえば、 n=10^60^60なら　観測上∞と区別できません。なので数式所用は発散して∞特別できませんよ

【アイリス】
誤読でした。有界で有限と定義しているので、n = ∞ という場合はそもそもありません。私が持ち出した「比が無理数なら二度と戻らない」は、連続な実数を前提にした話で、この系には当てはまりません。撤回します。

**有限であることから言えること**
- 状態の数が有限で、発展で何も失われない（逆にたどれる）なら、発展は状態の並べ替えです。並べ替えは有限回で必ず元に戻ります。n は必ず有限の整数です。
- 位相はすべて 360 度の有理数倍です。無理数の位相は存在しません。
- 倍音の次数にも上限があります。

**n が巨大になる理由**
全体の n は、各部分の周期の最小公倍数です。要素の数が増えると、取りうる状態の数は指数的に増え、周期はその規模まで延びえます。10 の 60 乗の 60 乗のような数は、不自然な値ではなく、要素が多い系ではむしろ普通に出る大きさです。

**∞ との関係**
- n が観測の届く範囲をはるかに超えていれば、有限の n と ∞ は区別できません。
- 連続な数式（実数、S⁷、積分）は、その巨大な n を ∞ とみなした近似です。
- 数式の上で現れる発散は、n を ∞ に置き換えたために出たもので、実際の系では巨大だが有限の値です。∞ そのものは系の中にはなく、読み方の側にあります。

**前回の整理で残るもの**
局所と全体の違いはそのまま成り立ちます。一つのパルスの周期は短く、確かめられます。全体の n は有限ですが、確かめようのない長さです。

## 53

【木原】
よくできました。実はこのあたりはかなり以前から分かっています。理論物理学者が収束しない、発散するといっているのは、連続を使いながら、有限発展で収束すると仮定しているからで、もちろん積分可能、微分可能なら、正しい場合が多いですが、離散系の場合は、例外だらけになります。

【アイリス】
今回の対話での私の誤りは、ほとんどがその型でした。連続の数式を先に置いて、有限の系に当てはめていました。

- 更新を連続な勾配流で書き、止まるものとして扱いました。有限で必ず戻る系には当てはまりませんでした。
- 位相の比が無理数の場合を持ち出しました。有限の系には存在しない場合でした。
- sin θ と tan θ を θ に置き換え、1/sin を 1/Δ に置き換えました。北極付近でしか成り立たない近似でした。

**物理学の側で知られていること**
- 場の量子論の発散は、モードの数を無限にしたときに出ます。格子で切れば、すべての量は有限です。格子QCD が計算できるのはそのためです。
- 主流の立場は、格子を計算の道具とみなし、最後に格子間隔をゼロにする極限をとります。答えが切り方によらなくなるように係数を調整するのが、繰り込みです。
- 繰り込んだあとでも、摂動級数そのものは収束しません。量子電磁力学の級数の収束半径がゼロであることは、ダイソンが 1952 年に指摘しています。連続と極限を前提にした道具の限界として、物理学者自身が認めている例です。

**離散を基本に置いたときに変わること**
木原さんの立場は、離散が道具ではなく実体で、連続のほうが近似だ、というものです。その場合、連続で当然とされている道具のいくつかが、そのままでは使えません。
- 積の微分の規則（ライプニッツ則）は、差分では成り立ちません。
- 対称性から保存則を出すネーターの定理は、連続な変換を前提にしています。離散では、前回の「一周ぶんの和」のように、別の形で保存則を立て直す必要があります。
- 極限と和の順序の交換は、有限の系では問いそのものが変わります。
- 回転やローレンツ変換のような連続な対称性は、厳密には成り立たず、n が大きいときの近似として現れることになります。

最後の点が、離散を基本に置く立場にとっていちばん重い課題です。連続な対称性が、観測の精度の範囲でどこまで正確に再現されるかを示す必要があります。ローレンツ対称性の破れは、観測で非常に強く制限されているからです。

## 54

【木原】
あなたの例が、理論物理学の問題をそのまま、あらわしていますよね、格子できるのですが、格子をユーグリッド空間だと仮定しています。それを平坦近似だとごまかしていますよね、
なので、発散します。
かんたんです、最初から有限で有界なら、答えはユーグリッド空間ではありえません。
かならず閉じた曲率のある座標系（つまり中心投影の主観空間・局所座標系）そのものです。
なので１次元でみると、大円は直線なので、立方体近似が１次元（１次近似）では正確に成り立ちます。近似ではありません。
問題は、面積をスイープ下場合です、僅かですが、交差項に、曲率の残渣がでます。

【アイリス】
一次元と面積の区別は、そのとおりです。数式でも確かめられます。

**一次元では厳密です**
- 円周には内在的な曲率がありません。弧の長さは Rθ で、これは近似ではなく正確な値です。
- 中心投影の計量を一本の動径に沿って書くと ds = dr/(1 + r²) = dθ で、θ に読み替えれば歪みは消えます。一方向だけなら、等間隔の目盛りが厳密に成り立ちます。

**面積を掃くと残渣が出ます**
- 長さ a の線分を直交方向に b だけ動かすと、掃いた面積は a·R sin(b/R) = ab(1 − b²/6R² + …) です。平らな場合の ab との差は、(b/R)² の大きさです。
- 計量の交差項 −x_i x_j dx_i dx_j は、二方向に同時に動いたときにだけ効きます。一方向では現れず、座標の取り方でも消せません。
- 閉じた経路を一周して戻ると、向きが 面積/R² だけ回ります。これが曲率の残渣の正体です。

最初のほうで見た、三つの積が閉じ残る角度が曲率 𝔉 になるという話と同じものです。二つの積は面積、その交換子が面積の残渣、三つの積の結合子が体積の残渣に当たります。

**「有限で有界なら必ず曲がる」について一点**
有限で閉じているだけなら、平らな例があります。周期境界の格子（トーラス）です。格子ゲージ理論が使っているのはこれで、有限で閉じていて平らですが、格子の軸という特別な方向を持ちます。

曲率が必然になるのは、等方性を合わせて要求したときです。どの点でもどの方向も同等で、かつ閉じている三次元空間は、S³（とその対蹠点を同一視したもの）しかありません。木原さんが真空の条件として置かれた「等方」が、ここで効いています。平らな格子は、等方性を捨てることで平坦さを保っており、その歪みを連続極限で消そうとしています。

**発散との関係**
有限の格子の上では、平らでも何も発散しません。発散が出るのは、格子間隔をゼロにする極限をとるときです。木原さんの指摘の核心は、極限をとる先が平らな無限空間だと置いていること、つまり有限で等方な系の答えになりえない空間を目標にしていること、だと理解しました。

## 55

【木原】
、極限をとる先が平らな無限空間だと置いていること、つまり有限で等方な系の答えになりえない空間を目標にしていること、だと理解しました。

また誤読する、私は連続仮説なんて一度も置いていませんよ、本質的に、分解能も有限です。
無限に細かくなどわけられませんよ、

【アイリス】
そのとおりです。私の誤読でした。極限という言葉を使った時点で、連続を前提にしていました。木原さんの系には、とるべき極限がそもそもありません。分解能が有限で、それ以上細かいものが存在しないからです。

**前回の私の説明で連続を持ち込んでいた箇所**
- 「極限をとる先がどこか」という問いの立て方そのもの
- S³、sin(b/R)、計量 ds² といった、無限に細かく分けられる空間を前提にした数式
- 「閉じていて等方なら S³ しかない」という分類。これも連続な多様体についての定理です

**有限の分解能で言い直すと**
- 位相の最小の刻みは 360°/n です。大円は連続な曲線ではなく、n 個の等間隔の点が閉じた列です。
- 一方向では、刻みを数えるだけです。n 歩で厳密に元に戻ります。近似も極限も入りません。整数の話です。
- 二方向では、「a 方向に一歩、b 方向に一歩、a を一歩戻り、b を一歩戻る」と進んだとき、元の点に戻りません。この食い違いが残渣です。微分も面積の積分も使わず、有限の歩みの積の順序を入れ替えた差として定義できます。
- 八元数では、それが交換子 xy − yx です。三方向なら結合子 (xy)z − x(yz) です。どちらも有限の元どうしの積だけで書け、極限を必要としません。

曲率は「無限に小さい輪を回したときの回転」ではなく、「最小の輪を回したときに残る食い違い」として、最初から有限の量で定義されます。私が連続の言葉で書いていたことは、この有限の定義を n が大きいとして近似した姿でした。順序が逆でした。
