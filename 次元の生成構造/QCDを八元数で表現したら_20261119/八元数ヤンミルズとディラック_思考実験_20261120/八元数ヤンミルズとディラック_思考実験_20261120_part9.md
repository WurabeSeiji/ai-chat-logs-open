## 30

【木原】
問題はここからですよ　ではこの中心位相ってなんですか？

複素数なら
Z=A(cosθ+isinθ)のθです

八元数なら複素記号がo=(ijklmno)
と七次元になるだけです
O=A(cosθ+nsinθ)
で中心位相はやはりθです

【アイリス】
はい、そのとおりです。八元数でも中心位相は θ ひとつです。

**分解**
O = A(cos θ + n sin θ)
- A = |O|：振幅
- θ：実軸（1）から測った角度。cos θ = Re(O)/A
- n：虚部の向き。n² = −1 を満たす単位虚八元数で、S⁶ 上の一点です

倍音も同じ形で、Oᵐ = Aᵐ(cos mθ + n sin mθ) です。一つの八元数の倍音はすべて同じ平面（1 と n が張る複素平面）に乗るので、パルスはその平面の円周の上にでき、中心は θ です。

**複素数と違う点**
- 虚数単位が i ひとつではなく、S⁶ の連続な向き n になります。自由度は θ の 1 に対して n が 6 です。
- (θ, n) と (−θ, −n) は同じ八元数です。位相の符号は独立な情報ではなく、n の向きに吸収されます。θ は 0〜180 度で足ります。
- θ はいつも実軸から測ります。どの八元数の円周も必ず ±1 を通り、n が違う二つの円周は ±1 でしか交わりません。

**すぐに出る帰結**
n が同じ二つなら、位相差は θ_A − θ_B で複素数と同じです。n が違うと、位相差は一つの数になりません。m 次の倍音どうしの干渉の実部は

cos²(ψ/2) · cos m(θ_A − θ_B) + sin²(ψ/2) · cos m(θ_A + θ_B)

です（ψ は n_A と n_B のなす角）。差の位相と和の位相の二つが、n の向きの関係で決まる重みで混ざります。虚部には n_A × n_B の方向、つまりどちらとも違う第三の向きの成分が現れます。

距離を「中心位相の差」と定義するなら、n が違う相手に対して差をどうとるかが、次に決めることになります。

## 31

【木原】
つまり1＋7で一軸での写像になってるだけですよ

【アイリス】
はい、そのとおりです。中心位相を読む操作は、八元数の実成分ひとつを見ているだけです。

**写像として書くと**
- θ = arccos(Re(O)/A)。使っているのは 1 の軸の成分だけです。
- 残りの 7 成分は、大きさ |b| = A sin θ にまとめられ、向き n は読まれません。
- S⁷ 全体が 0〜180 度の一本の区間に写されます。同じ θ に写る点の集まりは、半径 sin θ の S⁶ です。

言い換えると、八元数ひとつは「自分の n を虚軸とする複素数」です。7 次元は、どの軸を虚軸に使うかを決めているだけで、位相の読みには関わりません。

**この写像で見えなくなるもの**
- 同じ θ で n が違う二つは、位相差がゼロと読まれます。実際には S⁷ の上で離れていて、n が正反対なら 2θ 離れています。
- n の情報（6 自由度）は、一つの八元数を読むだけでは出てきません。現れるのは二つを掛けたときで、n_A·n_B が差と和の重みを決め、n_A × n_B が第三の向きをつくります。

つまり、位相は一つずつ読めますが、向きは相互作用の中でしか読めません。

## 32

【木原】
問題はこれがS^1の曲率半径Rの上に乗ってます

つまり
ΣO^2=R^2
(二乗はノムルではないですよ)

になっています

わかりますか？

【アイリス】
はい、わかります。ノルムの二乗 |O|² ではなく八元数の積としての二乗なので、虚部が負に効き、交差項が残ります。

**展開**
O = a + b = A(cos θ + n sin θ) とすると
O² = (a² − |b|²) + 2ab = A²(cos 2θ + n sin 2θ)
です。したがって ΣO² = R² は、実部と虚部の二つの条件に分かれます。

- 実部：Σ(a² − |b|²) = Σ A² cos 2θ = R²
- 虚部：Σ 2ab = Σ A² sin 2θ · n = 0（7 成分それぞれについて）

**読み取れること**
- 円の式 x² + y² = R² の x、y を八元数に置き換えた形です。全員が実数なら、ふつうの球面 ΣA² = R² に戻ります。
- 実部の式は Σa² − Σ|b|² で、符号が正と負に分かれます。ノルムなら全部が正ですが、二乗をとったために不定符号の計量が、仮定なしに入っています。純虚（θ = 90 度）の成分は R² を減らす向きに効きます。
- 虚部の式は、実部と虚部の交差項の総和が 7 方向すべてでゼロに閉じる、という条件です。個々の八元数は交差項を持っていてよく、全体として打ち消し合います。
- O² は二次の倍音です。この条件は「二次の倍音の総和が実軸に乗り、その大きさが R²」と言っています。位相が 2θ で効くので、θ と θ + 180 度は区別されません。

**R の位置づけ**
R は外から与える数ではなくなります。虚部がゼロに閉じていれば、R² は実部の総和として状態から読み出される量です。拘束として実際に効いているのは、虚部の 7 本の式です。

また、この式は入れ替えで不変なので無名性を保ち、G₂ の回転でも保たれます（実部は不変、虚部の和は回るだけでゼロはゼロのままです）。

## 33

【木原】
問題は真空宇宙なら、等方なので、Σon^2 = R^2 でおわりで、局所的な曲率 = 全体の曲率R です。

こころが倍音で局在しているとどうなるのかです。
配置によっては、重心が全体の曲率Rの中心とかんたんにズレます。
R自身が局所的に変わると考えてもただしそうです。

さらには、あるパルスk について、 Σokn^2 = Rk^2 という別なRkもよめます。

ここがどうなるのか？

さらに不思議なのは、1+7 と読んだときの、 R Rk ですが、
(1+3)(1+3) とよむと、さらに別の Rの読み方もあります。

難しさがわかりますか？

【アイリス】
はい、わかります。難しさは、R が一つの数ではなくなることです。同じ式 ΣO² = R² が、何について足すか、どこから測るか、8 をどう分けるかで、違う R を返します。

**1. パルスごとの R_k は実数になりません**
パルス k の倍音は o_kn = a(cos nθ + n_k sin nθ) です。二乗して足すと

Σ_n o_kn² = a² · sin(Nθ)/sin θ · [cos((N+1)θ) + n_k sin((N+1)θ)]

- θ = 0（実軸の上）なら、a²N で実数です。これはパルスのパワー P_k そのものです。
- 実軸から離れると虚部が現れ、R_k² は八元数になります。実数に戻るのは θ が 180°/N や 180°/(N+1) の整数倍の位置だけです。
- 大きさも位置によって変わります。幅の外では a²/sin θ 程度まで下がります。

局所の R_k は、そのパルスが実軸からどれだけ離れているかに依存します。これが「重心が曲率中心からずれる」ことの式の上での姿です。

**2. 全体の R との関係**
全体の式は R² = Σ_k R_k² です。
- 実部を足したものが R² になります。
- 虚部は、パルスどうしで打ち消し合うことだけが要求されます。個々の R_k² は虚部を持っていてかまいません。

真空なら全員が等方で虚部がなく、局所と全体が一致します。局在すると、各パルスが「R² への取り分」と「ずれの向き」の両方を持ち、ずれの総和がゼロに閉じることが全体の条件になります。配置を変えると取り分も変わるので、R 自身が変わるという読みも成り立ちます。

**3. 分け方による違い**
- 1 + 7 と読むと、O² の実部は a² − |b|² です。正が 1、負が 7 です。
- 四元数二つ O = q₁ + q₂ℓ と読むと、O² = (q₁² − |q₂|²) + 2 Re(q₁) q₂ℓ です。値は同じ八元数ですが、位相が θ₁、θ₂ の二つになり、実軸も 1 と ℓ の二本になります。
- 四元数をそれぞれ単独で二乗すると、実部は a² − |v|² で、正が 1、負が 3 です。Σq₁² と Σq₂² を別々に読むと、八元数として読んだときと a₂² の符号が逆になり、違う R が出ます。

分け方には対称性の選択が伴います。1 + 7 は G₂ を保ち、四元数二つに分けると SO(4) まで、1 + 1 + 6 と分けると SU(3) まで下がります。

**まとめると**
決まっていないのは次の三点です。
- 局所の R_k と全体の R のどちらを曲率と呼ぶか
- 虚部（ずれ）を、拘束として消すのか、状態の一部として残すのか
- どの分け方で読むか

どれも代数からは一意に決まりません。読み出しの規則として定める必要があります。
