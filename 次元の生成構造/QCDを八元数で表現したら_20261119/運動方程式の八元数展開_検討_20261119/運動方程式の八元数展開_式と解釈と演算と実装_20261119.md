## 1. 記号と基本演算

### 1.1 八元数の積 【定義】

- **式：** 基底 $1, e_1, \dots, e_7$。$e_ie_j = -\delta_{ij} + f_{ijk}e_k$。$f_{ijk}$ は完全反対称で、$(ijk) = (123),(145),(176),(246),(257),(347),(365)$ のとき $+1$。
- **解釈：** 二つの八元数から一つの八元数を作る演算。順番を入れ替えると結果が変わり、三つの積では括弧の位置でも結果が変わる。
- **演算：** $x = (x_0, \vec x)$、$y = (y_0, \vec y)$ に対し、$(xy)_0 = x_0y_0 - \vec x\cdot\vec y$、$(xy)_k = x_0y_k + y_0x_k + f_{ijk}x_iy_j$。
- **実装：** 実数 8 個の配列。関数 `mul(x, y)`。共役は `conj(x)`＝第 0 成分以外の符号を反転。
- **検算：** [V1] $|xy| = |x||y|$。

### 1.2 複素数の $i$ と、$\mathbb{C}\oplus\mathbb{C}^3$ への分解 【定義】

- **式：** $i\,x := e_7x$（左から掛ける）。$\mathbb{O} = \mathbb{C}\oplus\mathbb{C}^3$、$\mathbb{C} = \langle 1, e_7\rangle$、$\mathbb{C}^3 = \langle e_1,e_2,e_3\rangle_{\mathbb C}$。$\psi = \psi^1e_1+\psi^2e_2+\psi^3e_3$（係数は左から掛ける）。
- **解釈：** 虚数単位を 1 つ選ぶと、8 成分が「複素数 1 つ」と「複素数 3 つ」に分かれる。
- **演算：** $e_7e_1 = -e_6$、$e_7e_2 = e_5$、$e_7e_3 = e_4$ なので、$\psi^a = \alpha+i\beta$ は $\alpha e_a + \beta(e_7e_a)$。
- **実装：** `to_c(v)`、`to_c3(v)`（8 成分 → 複素数）、`emb(p)`（複素 3 成分 → 8 成分）。複素数の配列で計算してもよい。その場合、$i$ を掛ける操作が $e_7$ の左掛けと同じであることを [V2] で保証している。
- **検算：** [V2] 左から掛けると $[a\psi] = a\psi$。右から掛けると $[\psi a] = \bar a\psi$（反線形）。
- **注意：** 右から掛ける操作は別の演算である。混ぜて使わない。

### 1.3 内積 【導出】

- **式：** $\psi^\dagger\chi = [\chi\psi^*]_{\mathbb C}$。
- **解釈：** 二つの値の積の、$\mathbb{C}$ 成分。
- **演算：** `mul(chi, conj(psi))` の第 0 成分と第 7 成分を複素数として読む。
- **実装：** `to_c(mul(emb(chi), conj(emb(psi))))`。複素配列なら `np.vdot(psi, chi)`。
- **検算：** [V3]。

### 1.4 時空とスピノル 【定義】（外から置いたもの）

- **式：** 時空の添字 $\mu = 0,1,2,3$。計量 $\eta = {\rm diag}(+,-,-,-)$。$\gamma^\mu$ はディラック表示の $4\times4$ 複素行列で $\{\gamma^\mu,\gamma^\nu\} = 2\eta^{\mu\nu}$。クォークは $q_\alpha \in \mathbb{C}^3$（$\alpha = 1..4$ がスピノルの添字）。$\bar q = q^\dagger\gamma^0$。
- **解釈：** 八元数の側から出たものではない。標準の定式をそのまま使っている。
- **実装：** `q[alpha, color]` の複素配列（$4\times3$）。
- **検算：** [V11]。

## 2. 回転（ゲージ場）の表し方

### 2.1 生成子 $G_a$ 【定義・検算】

- **式：** $G_a := -\tfrac{i}{2}\lambda^a$ を $\mathbb{C}^3$ に作用させ、$\mathbb{C}$ では 0 としたもの（$a = 1..8$、$\lambda^a$ はゲルマン行列）。
- **解釈：** 八元数の積を保ち、1 と $e_7$ を動かさない無限小の回転。8 個ある。
- **演算：** 八元数の 8 成分に掛ける $8\times8$ の実反対称行列。
- **実装：** `G[a] = as_real(-1j * lam[a] / 2)`。
- **検算：** [V4] 積を保つこと、1 と $e_7$ を動かさないこと、反対称であること。[V6] $[G_a, G_b] = f_{abc}G_c$。

### 2.2 生成子を八元数の積だけで書く 【検算】

- **式：** $D(a,b)\,x := [[a,b],x] - 3\{(ab)x - a(bx)\}$ とすると、

| | 八元数の積での式 |
|---|---|
| $G_1$ | $\tfrac{1}{12}\{-D(e_1,e_5) + D(e_2,e_6)\}$ |
| $G_2$ | $\tfrac{1}{12}\{D(e_1,e_2) + D(e_5,e_6)\}$ |
| $G_3$ | $\tfrac{1}{12}\{D(e_1,e_6) + D(e_2,e_5)\}$ |
| $G_4$ | $\tfrac{1}{12}\{-D(e_1,e_4) + D(e_3,e_6)\}$ |
| $G_5$ | $\tfrac{1}{12}\{D(e_1,e_3) + D(e_4,e_6)\}$ |
| $G_6$ | $\tfrac{1}{12}\{-D(e_2,e_4) - D(e_3,e_5)\}$ |
| $G_7$ | $\tfrac{1}{12}\{D(e_2,e_3) - D(e_4,e_5)\}$ |
| $G_8$ | $\tfrac{1}{12\sqrt3}\{D(e_1,e_6) - D(e_2,e_5) + 2D(e_3,e_4)\}$ |

- **解釈：** 回転は、二つの八元数 $a, b$ と相手 $x$ の積の「順番を入れ替えた差」と「括弧の位置を変えた差」だけでできている。
- **演算：** $D(a,b)x$ に入っているのは八元数の積と引き算だけである。$[a,b] = ab - ba$。
- **実装：** `D_act(a, b, x)`。行列にするなら `Dab(a, b)`。
- **検算：** [V5]。

### 2.3 ゲージ場 $A_\mu$ と場の強さ $F_{\mu\nu}$ 【定義】

- **式：** $A_\mu = A^a_\mu G_a$、$D_\mu = \partial_\mu + A_\mu$、$F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu + [A_\mu, A_\nu] = F^a_{\mu\nu}G_a$、$F^a_{\mu\nu} = \partial_\mu A^a_\nu - \partial_\nu A^a_\mu + f_{abc}A^b_\mu A^c_\nu$。
- **解釈：** 時空の各点・各方向に、無限小の回転が 1 つ置かれている。
- **演算：** $[A_\mu,A_\nu]$ は $8\times8$ 行列の積の順番を入れ替えた差。
- **実装：** `A[mu]` は実数 8 個の係数（または $8\times8$ 行列）。
- **注意：** 講義の式と同じく、結合の強さ $g$ は $A$ に吸収し、$1/g^2$ をラグランジアンの前に出す規約である。

## 3. ラグランジアンと運動方程式

### 3.1 ラグランジアン 【原文】

$$
\mathcal{L} = -\frac{1}{4g^2}F^a_{\mu\nu}F^{a\,\mu\nu} + \bar q\,(i\gamma^\mu D_\mu - m)\,q
$$

出典：講義 [大野木 2026]。八元数での形は論文 (5.1)。

### 3.2 クォークの項を $A$ について開く 【導出・検算】

- **式：** $\bar q\,i\gamma^\mu A_\mu q = A^a_\mu\,j^{\mu a}$、$j^{\mu a} := \bar q\gamma^\mu T^a q$（$T^a = \lambda^a/2$）。
- **手順：** $A_\mu = -iA^a_\mu T^a$ を代入すると $i\cdot(-i) = 1$。
- **検算：** [V12] 結合項。$j^{\mu a}$ が実数であることも確認。

### 3.3 値の方程式（ディラック方程式）【原文・導出】

$$
(i\gamma^\mu D_\mu - m)\,q = 0
$$

- **手順：** $\bar q$ について変分する。
- **出典：** 共変な形 $(i\slashed{D} - M)\psi = 0$ は標準の文献と一致する。

### 3.4 回転の方程式（ヤン＝ミルズ方程式）【原文・導出】

$$
(D_\mu F^{\mu\nu})^a = \partial_\mu F^{a\,\mu\nu} + f_{abc}A^b_\mu F^{c\,\mu\nu} = -g^2\,j^{\nu a}
$$

行列で書くと $D_\mu F^{\mu\nu} = \partial_\mu F^{\mu\nu} + [A_\mu, F^{\mu\nu}] = -g^2 J^\nu$、$J^\nu := j^{\nu a}G_a$。

- **手順：**
  1. $\delta F^a_{\mu\nu} = (D_\mu\delta A_\nu)^a - (D_\nu\delta A_\mu)^a$。
  2. $\delta\mathcal{L}_{\rm gauge} = -\tfrac{1}{g^2}F^{a\,\mu\nu}(D_\mu\delta A_\nu)^a$。部分積分で $+\tfrac{1}{g^2}(D_\mu F^{\mu\nu})^a\delta A^a_\nu$。
  3. 3.2 より $\delta\mathcal{L}_{\rm quark} = j^{\nu a}\delta A^a_\nu$。
  4. 合わせて $\tfrac{1}{g^2}(D_\mu F^{\mu\nu})^a + j^{\nu a} = 0$。
- **出典：** $D_\mu F^{a,\mu\nu} = -j^{a,\nu}$ の形は標準の講義録と一致する（$g^2$ は 2.3 の規約による）。
- **未検算：** 手順 2 の部分積分は連続の微分の操作で、数値では確かめていない。符号は上の手順で導いたものである。

## 4. 値の方程式を、項ごとに演算へ落とす

$(i\gamma^\mu D_\mu - m)q = 0$ を開くと、$i\gamma^\mu\partial_\mu q + i\gamma^\mu A_\mu q - mq = 0$。

### 4.1 項 $\gamma^\mu(\cdots)$ ― スピノルの混ぜ合わせ 【定義】

- **解釈：** 4 つのスピノル成分 $q_\alpha$ を、複素数の係数で一次結合する。
- **演算：** $(\gamma^\mu q)_\alpha = \sum_\beta(\gamma^\mu)_{\alpha\beta}q_\beta$。係数の複素数は、各 $q_\beta \in \mathbb{C}^3$ に左から掛ける（1.2）。**和と、$e_7$ の左掛けが入っている。**
- **実装：** `np.einsum("ab,bc->ac", gam[mu], q)`。
- **未確定：** $\gamma^\mu$ と 4 成分のスピノルが八元数の側の何にあたるか。

### 4.2 項 $A_\mu q$ ― 値を回転で回す 【検算】

- **解釈：** 値 $q_\alpha$（$\mathbb{C}^3$ の八元数）に、その点・その方向に置かれた無限小の回転を作用させる。色の成分だけを混ぜ、スピノルの添字には触れない。
- **演算（3 通り。同じ結果）：**
  1. 複素 $3\times3$ 行列 $-iA^a_\mu T^a$ を、複素 3 成分に掛ける。
  2. 実 $8\times8$ 行列 $A^a_\mu G_a$ を、8 成分に掛ける。
  3. 八元数の積だけで：$A_\mu q = A^a_\mu\,G_a(q)$、$G_a(q)$ は表 2.2 の $D(e_i,e_j)q$ の組み合わせ。
- **実装：** 1 は `A3 @ q[alpha]`、2 は `A8 @ emb(q[alpha])`、3 は `G_act(a, emb(q[alpha]))`。
- **検算：** [V7] 三つが一致する。
- **注意：** これは無限小の回転である。有限の回転は 6.1 のリンク $U$。

### 4.3 項 $\partial_\mu q$ ― 隣との差 【定義】（外から置いたもの）

- **解釈：** 時空の 4 方向それぞれについて、隣の点の値との差を間隔で割ったもの。
- **演算：** 引き算と、間隔での割り算。$\mu$ について和をとる。
- **未確定：** 背景の時空を置かない場合に、「隣」「間隔」「4 方向」が何にあたるか。

### 4.4 時間方向について解いた形 【導出・検算】

- **式：** $\gamma^0$ を左から掛けて $\partial_0 q$ について解くと、
$$
\partial_0 q = \underbrace{\left(-A_0 - \alpha^k(\partial_k + A_k) - i\,m\,\beta\right)}_{\mathcal{G}}\,q,\qquad \alpha^k := \gamma^0\gamma^k,\ \beta := \gamma^0
$$
- **解釈：** 値の時間変化の割合は、「回転の生成子 $\mathcal{G}$ を値に掛けたもの」に等しい。
- **演算：** $\mathcal{G}$ の中身は、色の無限小回転 $A_0$、スピノルと色を同時に混ぜる $\alpha^kA_k$、空間の差分 $\alpha^k\partial_k$、質量の項 $-im\beta$ の**和**である。
- **検算：** [V13] $\alpha^k$ と $\beta$ はエルミート。差分を除いた $-A_0 - \alpha^kA_k - im\beta$ は反エルミート（$12\times12$）。
- **実装上の帰結（既知の数学）：**
  - 有限の一歩は $q(t+\Delta t) = \exp(\Delta t\,\mathcal{G})\,q(t)$。反エルミートな生成子の指数関数はユニタリで、ノルムを保つ。[V13]
  - 一次の足し込み $q + \Delta t\,\mathcal{G}q$ はノルムを保たない。[V13]
  - したがって、**足すのは生成子の段階だけ**で、状態に施すのは指数関数（回転）である。状態に足して後から正規化する、という実装は、この方程式からは出てこない。

## 5. 回転の方程式を、項ごとに演算へ落とす

$\partial_\mu F^{\mu\nu} + [A_\mu, F^{\mu\nu}] = -g^2J^\nu$。

### 5.1 項 $\partial_\mu F^{\mu\nu}$ 【定義】（外から置いたもの）

- **解釈：** 場の強さの、隣との差。$F$ が $A$ の 1 階微分を含むので、$A$ については 2 階になる。
- **未確定：** 4.3 と同じ。

### 5.2 項 $[A_\mu, F^{\mu\nu}]$ ― 回転が回転を回す 【検算】

- **解釈：** 回転 $F$ を、別の回転 $A$ で無限小だけ回したときの変化。グルーオンが自分自身と相互作用する項。
- **演算：** $8\times8$ 行列の積の順番を入れ替えた差 $AF - FA$。成分では $f_{abc}A^bF^c$。
- **八元数の積での形：** 回転が対 $D(c,d)$ で書けているとき、別の回転 $D$ による変化は
$$
[D,\ D(c,d)] = D(Dc,\ d) + D(c,\ Dd)
$$
  すなわち「対を作っている二つの値 $c, d$ を、それぞれ $D$ で回す」ことに等しい。
- **実装：** `A8 @ F8 - F8 @ A8`。
- **検算：** [V8] 上の恒等式、成分の式、交換子が 7 本の条件をまた満たすこと。

### 5.3 二つの値から回転を作る 【検算】

- **式：** $\psi, \chi \in \mathbb{C}^3$ に対し、$P$ を「$e_7$ を動かさない部分への射影」として、
$$
P\,D(\psi,\chi) = -3\,{\rm tl}\!\left(\psi\chi^\dagger - \chi\psi^\dagger\right),\qquad D(\psi,\chi)\,e_7 = 2i\,(\bar\psi\times\bar\chi)
$$
$$
D(\psi,\ e_7\psi) = 6i\,{\rm tl}\!\left(\psi\psi^\dagger\right)\quad(\text{これは } e_7 \text{ を動かさない})
$$
  ${\rm tl}(M) := M - \tfrac13({\rm tr}M)\mathbf{1}$。射影は $P\,D = D + \tfrac14\sum_{k=1}^{6}(De_7)_k\,D(e_k, e_7)$。
- **解釈：**
  - 二つの値の対から作った回転は、一般には $e_7$ も動かす。$e_7$ を動かす分は、二つの値の外積 $\bar\psi\times\bar\chi$ である。
  - $e_7$ を動かさない部分は、二つの値の「外向きの積」$\psi\chi^\dagger$ の反エルミート部分である。
  - 値 $\psi$ と、それに $e_7$ を掛けた $e_7\psi$ の対からは、$e_7$ を動かさない回転がちょうど出る。
- **実装：** `Dab(emb(psi), emb(chi))`、`proj_su3(D)`。
- **検算：** [V9]、[V10]。

### 5.4 源 $J^\nu$ ― 値の対から作られる回転 【導出・検算】

- **式：** $w := \gamma^0\gamma^\nu$、$N^\nu_{ij} := \sum_{\alpha\beta}w_{\alpha\beta}\,q_{\beta i}\,\overline{q_{\alpha j}}$ とすると、
$$
J^\nu = j^{\nu a}G_a \ \leftrightarrow\ -\tfrac{i}{2}\,{\rm tl}(N^\nu)\quad(\mathbb{C}^3 \text{ 上の行列として})
$$
- **八元数の積だけでの形：** $w_{\alpha\beta} = u_{\alpha\beta} + iv_{\alpha\beta}$ として、
$$
J^\nu = -\sum_\alpha\frac{w_{\alpha\alpha}}{12}\,D(q_\alpha,\ e_7q_\alpha)\ -\ \sum_{\alpha<\beta}\left\{\frac{u_{\alpha\beta}}{6}\,P\,D(q_\beta,\ e_7q_\alpha) + \frac{v_{\alpha\beta}}{6}\,P\,D(q_\beta,\ q_\alpha)\right\}
$$
- **解釈：** 回転の方程式の右辺（源）は、値 $q$ の対から 5.3 の規則で作った回転を、スピノルの重み $w$ で足し合わせたものである。$J^0$（$w = 1$）は、各スピノル成分 $q_\alpha$ について $D(q_\alpha, e_7q_\alpha)$ を足したものになる。
- **演算：** 八元数の積（順番の差、括弧の差）、$e_7$ の左掛け、射影 $P$、スピノル成分についての和。
- **実装：** 直接には `N = einsum("ab,bi,aj->ij", w, q, q.conj())`、`J = as_real(-0.5j * tl(N))`。八元数の積だけの形は検算用。
- **検算：** [V12] $\nu = 0,1,2,3$ のすべてで、三つの形（$j^{\nu a}G_a$、$-\tfrac{i}{2}{\rm tl}N$、八元数の積の形）が一致する。

### 5.5 時間方向と空間方向の役割の違い 【導出・数値未検算】

- **式：** $\nu = i$（空間）： $D_0F_{0i} = D_jF_{ji} + g^2J^i$。 $\nu = 0$： $D_iF_{0i} = -g^2J^0$。
- **解釈：** 空間成分の式は $F_{0i}$ の時間変化を与える。時間成分の式（ガウスの法則）には時間微分がなく、各時刻で満たすべき拘束である。
- **未検算：** 符号は 1.4 の計量から導いたが、数値では確かめていない。実装に使う前に確かめること。

## 6. 格子の上での形

### 6.1 リンク変数 $U$ ― 有限の回転 【原文・検算】

- **式：** $U_\mu(x) = \exp(a\,A_\mu(x))$。
- **解釈：** 隣り合う二つの点の八元数を見比べる規則。無限小ではなく有限の回転。
- **演算：** $8\times8$ の直交行列。八元数の積を保ち、$e_7$ を動かさない。
- **実装：** `expm(sum(coef[a] * G[a]))`。
- **検算：** [V14]。

### 6.2 値の項 【原文・検算】

- **式：** 共変な差分 $\dfrac{U_\mu(x)\,q(x+\hat\mu) - U^\dagger_\mu(x-\hat\mu)\,q(x-\hat\mu)}{2a}$ に $\gamma_\mu$ を掛け、4 方向について足す。
- **解釈：** 隣の点の値を、リンクの回転で自分の点の枠に持ってきてから、前と後ろの差をとる。
- **演算：** 回転を掛ける（積）、前後の引き算、間隔での割り算、4 方向の和。
- **検算：** [V14] $q(x)^\dagger U q(y)$ が点ごとの基底の取り替えで変わらない。

### 6.3 回転の項（ウィルソン作用）【原文・検算】

- **式：** $S_G = \dfrac{1}{g^2}\sum_P{\rm Tr}_{\mathbb O}(1 - U_P)$、$U_P$ は最小の四角を一周したリンクの積。
- **解釈：** 一周して見比べたとき、元に戻らない度合い。
- **演算：** 回転の積を 4 つ続けて掛け、恒等からのずれのトレースをとり、全部の四角について足す。**足すのは最後の読出し（作用の値）だけ**で、回転どうしを足すことはない。
- **検算：** [V14] 点ごとの取り替えで不変。

### 6.4 格子の計算では、状態を方程式で更新しない 【原文】

- **内容：** 格子の計算は、配置の全体に重み $e^{-S}$ を付け、すべての配置について足す（経路積分）。講義では「経路積分を有限次元の多重積分にし、モンテカルロ法で積分する」と説明された。
- **解釈：** 時間発展はない。計算機の中の「一歩」は、配置を標本するための手続きで、物理の時間でも相互作用の更新でもない。
- **帰結：** 格子の形で「相互作用がある」とは、重みが部分ごとの積に分解できないことである。

## A.1 本文（1〜10 章）の位置づけについて

【著者の立場】

## A.2 相互作用は一回の演算である

【著者の立場】
- 処理はすべて 1 ステップで完結する。
- 二つを選ぶのではない。N 個の八元数があったら、N² の状態を N×N で演算して、結果を一回の演算で N′ に戻す。
- 相互作用には「相互作用する相手を選ぶ」「相手と演算する」「自分と相手を更新する」の三つがある。この三つが、たった一回の演算で、IF 文なしに実行される。
- 標準理論のゲージ場も、なぜ相手を選べるのか、なぜ近傍なのかを、簡単に無視している。

【既知】標準理論で相手を選んでいるのは時空である。ラグランジアンは同じ点にある場どうしの積で書かれ、微分は隣の点との差で、格子ではリンクが隣り合う点を結ぶ。選ぶ仕組みは方程式の中にはなく、方程式を書く前の舞台として置かれている。

【これまでの実装との照合】

- 格子：誰が隣かを、格子の表として外から与えている。
- 本文 9 章の 4 番「誰と誰の対から回転を作るのか」：選ぶ段階があると前提した問いの立て方だった。
- 骨格写像の八元数化：N×N の関係を作って N に戻す外形は一回の演算だが、戻し方が回転になっていない和と正規化だった。

## A.3 積和演算と、最小作用

【著者の立場】
- これは最小作用 δS の定義そのものである。
- 宇宙の果てにある相手とも作用する。自分自身とも作用する。
- しかし作用の結合定数（放射と吸収、反射と透過と呼んでもよい）が極めて小さくなるので、結果として相互作用しなかったのと同じになる。
- それを積算した結果である。つまり積和演算である。

【既知】標準の定式にも同じ形がある。新しい状態は、すべての点の状態に核を掛けて足したものであり（伝播関数の形）、核は二点を結ぶすべての経路について作用から決まる。ある点の場は、すべての源に、遠いほど小さくなる係数を掛けて足したものである。微分方程式は、これを各点の近くで読んだ姿である。

【本文の訂正】本文は微分の形だけを展開し、積分の形（積和）を落としていた。7 章の「状態どうしを足す演算は現れない」は誤りで、注記で訂正した。

## A.4 回転ならパワーは変わらない。正規化は要らない

【著者の立場】
- 回転演算の場合、いくら回転してもパワーが変わらないから、正規化する必要はない。
- 透過率を k とすると、k ＝ 1 なら事実上相互作用しないのと同じ。k ＝ 0 だと反射率が 1 になる。
- 二つの八元数の間で放射と吸収が起こっていると考えても同じである。すべて自己放射して自己吸収すれば透過、すべて相手と交換すれば反射。
- 積和してもパワーが変わらない理由：二つの間で放射・吸収しているのではなく、**自分も含めた全員との間で一気に放射・吸収するから、総和が変わらない**。二個のペアを繰り返しやるのではない。そんなことをしたらパワーは保存されない。

【検算 W1】N ＝ 4 で確かめた。

| やり方 | パワー（元は 15.579454） |
|---|---|
| 全員と一度に（一つの N×N の回転） | 15.579454（不変） |
| 対ごとに別々に計算して足す | 12.973518（変わる） |
| 対ごとに順番に施す | 15.579454（不変）。ただし順番を逆にすると結果が 2.277 ずれる |

全員と一度に作用する場合、行列の各行で $|U_{ij}|^2$ の和がちょうど 1 になる。対角の成分（自分に残る分）は、相手に渡さなかった残りで、この例では 0.19〜0.36 だった。

【整理】保存は対ごとの性質ではない。自分を含めた全員への分け前が、一つの釣り合いになっていることから出る。ある相手への分け前は、ほかの全員への分け前と、自分に残す分とを同時に決めて初めて決まる。自分自身との作用を外すと、分け前の合計が 1 にならない。対ごとに順番に施せばパワーは保たれるが、順番という外の決めごとが要り、一回の演算でもなくなる。

【著者の文書との対応】検討ルール 2.1「exp(ΔτK) は直交行列で、全体の量を保存する。閉じた系で波どうしが及ぼし合える作用は、分け合うことだけである」「K_ef ＝ −K_fe は作用と反作用」。第十三思考実験の二波の交換。方針メモ（10/24）§11「作用はほぼ分かっている。シンプルな回転配列演算（分配率＝反射率 R）」。

## A.5 回転は外から与えられない

【著者の立場】
- 回転の行列を誰も与えない。八元数の状態から回転が自発的に決まる。外から反射率も回転率も与えられない。
- これが一回の演算でできるのか、よく分からない。自己無撞着になるまで繰り返すのかもしれない。ここのイメージがまず分からない。

【既知・整理】回転を作る材料と、回転を受ける対象が同じである。状態から決まった回転で状態を書き換えると、状態が変わるので、そこから決まる回転も変わる。書き換えに使った回転と、書き換えた後の状態が決める回転が食い違わない点に、一回で着けるのか、繰り返して近づくのかが問いになる。係数が状態によらない場合は、繰り返しの総和が一回の演算に畳める（光学の多重反射）。係数が状態そのものに依存する場合は、一般には閉じた式にならない。

【著者の文書との対応】複素数の系では、正本の生成子 K_ef ＝ A_ef Im(z̄_e z_f)（係数 1、外の定数なし）がこの形で、「K は状態自身の関係から作られるので、分配の結果が次の分配を決め、全体として非線形になる」（検討ルール 2.1）。Noether 論文は、求めるものを「時間に沿って状態を書き換える規則ではなく、全配置について公理を保つ自己無撞着解を選ぶ写像」とし、反復のパラメータは物理の時間ではないとしている。

【未確定】一回か、繰り返しか。八元数では二つの状態の関係が 8 成分になるので、それを N×N の回転としてどう働かせるか。

## A.6 回転の角度を決めるのはヤン＝ミルズ方程式のはずである

【著者の立場】この回転角度をどう計算するのかに、ヤン＝ミルズ方程式が答えているはずである。

【本文の読み直し】$D_\mu F^{\mu\nu} = -g^2J^\nu$ は、次のことを指定している。
1. 回転を作る材料は値の対である（右辺の $J$。本文 5.4）。
2. 強さを決める数は $g^2$ 一つだけである。
3. 回転がどう広がるかは左辺の微分が決める。積分の形に直すと、全員についての積和になる。
4. 交換子の項により、回転自身も源になる。

【著者の立場】ポイントは「$g^2$ × 伝わり方の係数」である。伝わり方の係数は減衰率の関数、つまり距離の関数である。では距離とは何か。

【未検算】3 の積分の形は、この対話の中で述べただけで、符号も係数も導出・検算していない。

## A.7 距離

【著者の立場】
- 距離とは何かは、すでに分かっている。相互の視野角と相手の大きさで決まる。
- 3 次元の方向まで含めた距離を決めるためには、最低 4 体いる。

【著者の文書との対応】11 月 1 日の論文の前提 P1「距離 ＝ 大きさ ÷ 視野角、読めるのは比だけ」。4 パルス実験の README「3 体では xyz の位置関係を読み出せない。関係は差だけなので独立な差は N − 1、xyz には N ＝ 4」。

【整理】二つの状態の間の伝わり方の係数は、その二つだけでは決まらない。A.2（選ばない）、A.4（対ごとでは保存しない）と同じことを、距離の面から言っている。

## A.8 ただの八元数は局在していない

【著者の立場】
- ただの八元数は局在していない。中心位相はあるが、広がりがない。
- 振幅を大きさと言うなら、おかしなことになる。あちこちに山が立ち、存在することになる。巻数の数だけ存在ができる。

【整理】八元数 1 個 $A(\cos\theta + n\sin\theta)$ が持つのは、振幅・角度・軸だけで、幅にあたる量がない。巻き数 m の成分は、同じ形が円周の上で m 回繰り返す。標準理論では「どこにいるか」を時空の点が肩代わりしているので、値そのものに広がりが要らない。背景を置かないなら、広がりは状態の側が持たなければならない。

## A.9 倍音は下に積む

【著者の立場】
- ある巻数の分解能で一つだけ山が立つためには、倍音を上に積むのではなく、逆に、有界な閉じた円周が 1 周期になるまで、下向きに倍音を積む。
- 振動数が 1, 2, 3, 4 分の 1 になり、波長が 1, 2, 3, 4 倍になっていく必要がある。
- かつ定常波になるため、もともと有界で閉じている円周であれば、波長は必ず円周の整数分の 1 である必要がある。

【検算 W2】巻き数 12 の場合。

| 積み方 | 最大の山の数 | 2 番目の山／最大の山 |
|---|---|---|
| 巻き数 12 の波だけ | 12 | 1.000 |
| 上に積む（12, 24, 36, 48 次） | 12 | 1.000 |
| 下に積む（12 次から 1 次まで全部） | 1 | 0.094 |
| 下に積む（12 の約数だけ：1, 2, 3, 4, 6, 12） | 1 | 0.333 |

上に積んでも山の数は減らない。下に積み、波長が円周 1 周分の波まで届いたとき、山が一つになる。

【Claude の問い】「波長が整数倍」と「波長は円周の整数分の 1」を同時に満たすのは、巻き数の約数にあたる次数だけである。下に積むのは 1 次までの全部の次数か、約数の次数だけか。

【著者の立場（2026-11-20 の回答）】
- これはシンプルで、全部の次数である可能性が高い。そうでないと、側波帯が多数立つ。
- ただし、波形については仮説である。シンプルにすべての倍音が等しい振幅なのか。側波帯を減らすなら、別に作り込んだ、側波帯が減りやすい波形もある。
- したがって、この倍音の波形（振幅）は課題である。

【検算 W2 との対応】上の表は、どちらもすべての倍音を等しい振幅で積んだ場合である。2 番目の山は、全部の次数で 0.094、約数だけで 0.333 で、約数だけのほうが側波帯が大きい。著者の「全部の次数でないと側波帯が多数立つ」と向きが合う。等しい振幅以外の波形は、まだ計算していない。

【検討課題】倍音の振幅の並び（波形）。等しい振幅か、側波帯の小さくなる別の並びか（A.15 の検討課題 2）。

中心は M によらない。幅は M にほぼ反比例する。中心を一か所に決められるのは 1 次の波だけで、m 次の波は山が m か所ある。

【Claude の読み】どのパルスも円周全体に広がるベース波を成分に持つので、どれだけ離れたパルスどうしも必ず重なっている。全員と作用する（A.3）ことの中身は、これではないか。

## A.11 1＋7 の読みでは、θ が中心位相で、方向は読めない

【著者の立場】
- 3 次元空間でも、八元数を 1＋7 と読んで $o = A(\cos\theta + n\sin\theta)$ と表現した場合の θ が、この中心位相である。
- $n$ は 7 次元ベクトルの虚数である。
- 位相 θ は位置を表すが、方向が分からない。つまり S¹ になっている。

【著者の文書との対応】10 月 18 日の論文 §12.1「一つの軸に沿って倍音を重ねると、空間の 1 方向にしか局在しない」。4 パルス実験の写像「自分の位相を自分の軸に乗せる（Θᵢnᵢ）」。

【整理】

| 読みたいもの | 何が担うか | 1 個で読めるか |
|---|---|---|
| 位置（進んだ量） | ベース波の中心位相 θ | 差としてなら読める |
| 広がり（大きさ） | 分解能（最大の巻き数） | 読める |
| 方向 | 軸 n | 読めない。相手との関係が要る |

## A.12 180° にいる自分の分身

【著者の立場】
- 複数の八元数の中心位相の差が、そのまま視野角・自身の大きさになるのかは、よく分からない。距離ではある気がする。
- 自己相関は位相差 0° である。しかし倍音が奇数＋偶数でないと、ちょうど反対位相の 180° のところにも、自分の影のピークができる。一番遠い 180° に、自分の分身が隠れている。

【検算 W4】12 次まで。

| 倍音の組 | 自己相関の 180° での値（0° を 1 として） |
|---|---|
| 奇数と偶数の両方 | 0.000 |
| 奇数だけ | −1.000 |
| 偶数だけ | ＋1.000 |

m 次の波を 180° ずらすと $(-1)^m$ が掛かる。奇数だけなら真裏に符号の逆の自分が、偶数だけなら真裏に同じ自分がいる。両方そろうと打ち消し合い、分身が消える。

【整理】自分との作用は位相差 0° だけではない。閉じた円周では、最も遠い所に自分と完全に相関する相手がいる。片方の偶奇だけでは一つの存在になれない。ベース波（1 次）自身が奇数次なので、位置を決める波が、真裏に符号の逆の谷を持つ。

【著者の文書との対応】「奇数の倍音は二周で閉じ、偶数は一周で閉じる」「奇数倍音の反周期性」。

## A.13 結合を決めるのは視野角である

【著者の立場】
- 距離は位相差だが、視野角は違う。
- 遠くにあっても、相手の分解能が低いと広がりが大きいので、視野角は大きくなる。つまり近くに見える。
- 逆に近くても、相手の分解能が高いと広がりが狭いので、視野角は小さくなる。つまり遠くに見える。
- 相互作用の結合定数を決めているのは視野角だと思う。近くても小さいものはほとんど相互作用しないし、遠くても大きいものは相互作用するのではないか。
- これがヤン＝ミルズでどう表現されているのかが気になる。

【仮説（2026-11-20 著者の指定）】以下の対応は、現時点では仮説である。Claude が当てはめたもので、導出も検算もしていない。**ヤン＝ミルズ方程式がこの仮説と一致しているかどうかが、判断のポイントである。** 検討課題として残す（A.15 の検討課題 1）。
1. ガウスの法則（ヤン＝ミルズ方程式の時間成分。本文 5.5）：源から出る流れの総量は源の強さと $g^2$ で決まり、全方向に広がる。相手が受け取る量は、相手が全方向のうち占める割合、すなわち大きさを距離で割った量（視野角）で決まる。$g^2$ は全体に掛かる一つの数で、相手ごとの違いを決めているのは視野の割合である。全方向についての割合の合計は 1 である。
2. 交換子の項：流れ自身が源になり、流れどうしが引き合う。標準理論では「結合の強さは見る細かさで変わる。細かく見るほど弱く、粗く見るほど強い」と表現される。著者の「分解能の高い相手とは作用が弱く、低い相手とは強い」と向きが同じである。
3. ヤン＝ミルズに入っていないもの：相手の大きさ。標準理論では源は点に置かれた強さで、広がりを持たない。

【検討課題】「結合を決めるのは視野角である」という著者の考えと、ヤン＝ミルズ方程式の内容が一致するかどうか。上の 1〜3 が数量として成り立つかを、ヤン＝ミルズ方程式の側から確かめる。一致しなければ、上の対応は捨てる。

## A.14 S¹ だが、視野角は面積である

【著者の立場】不思議だが、S¹ だが、視野角は面積である。

【検算 W5】交差項の虚部は、二つの状態が張る平行四辺形の面積に等しい。
$$
|{\rm Im}(\bar a\,b)| = |a|\,|b|\,\sin(\text{二つの間の角}),\qquad {\rm Re}(\bar a\,b) = |a|\,|b|\,\cos(\text{二つの間の角})
$$
複素数でも八元数でも成り立つ（八元数 1000 組で確認）。

【整理】円周 S¹ は 1 次元だが、それが乗っているのは実数の 1 と軸 n が張る 2 次元の平面である。二つの状態の間の角は、その二本が張る面積として現れる。視野角は、角度だけの量ではなく、二辺（二つの状態の大きさ）を掛けた面積として読まれる。

【著者の文書との対応】検討ルール 2.2「Im(z̄_e z_f) は三角形（中心, z_e, z_f）の符号付き面積の 2 倍で、視野角の正弦に二辺を掛けたもの」。正本の生成子 K_ef ＝ A_ef Im(z̄_e z_f) は、この符号付き面積そのものである。したがって「結合を決めるのは視野角」（A.13）は、複素数の系ではすでに式になっている。

【既知】場の強さ $F^{ij}$ の添字の対は平面で、$F$ は面の上に乗る量である。ガウスの法則は面を通る流れの総量についての式で、ラグランジアンの第 1 項は面の成分の二乗の和である。

【未確定】倍音を積んだパルスどうしの場合に、分解能から来る広がりが、この面積にどう入るか。

## A.15 固定点：ここまでで決まったことと、決まっていないこと

### 決まったこと（著者の立場として固定）

1. 相互作用は一回の演算である。N 個 → N×N → N′。相手を選ぶ・演算する・更新するは分かれていない。IF 文はない。
2. その演算は積和である。全員と作用する。自分自身とも、果ての相手とも作用する。効かない相手は、係数が小さいだけである。
3. 積和は回転でなければならない。回転だからパワーが保存され、正規化は要らない。
4. 保存は、自分を含めた全員と一気に放射・吸収することから出る。対ごとに処理してはならない。
5. 回転は外から与えられない。状態から自発的に決まる。
6. 回転の角度の決め方は、ヤン＝ミルズ方程式が答えているはずである。要は「伝わり方の係数」である。
7. 距離は、相互の視野角と相手の大きさで決まる。方向まで含めるには最低 4 体いる。
8. 八元数 1 個は局在していない。振幅は大きさではない。
9. 局在は、倍音を下に積み、円周全体が 1 周期になる波まで含めて初めて成り立つ。
10. ベース波の中心位相が中心を決め、分解能（巻数）が広がりを決める。
11. 八元数 1 個から読める位置は S¹ の上の角度で、方向は読めない。
12. 奇数と偶数の倍音がそろわないと、180° に自分の分身ができる。
13. 結合を決めるのは視野角である（著者の考え）。視野角は面積である。

### 実装するときの規則（本文 0 章の規則に加える）

- 相互作用する対を、条件分岐で選ばない。
- 対ごとに順番に処理しない。対ごとに別々に計算して足さない。
- 後から正規化しない。正規化が要るなら、その更新は回転になっていない。
- 回転の行列、反射率、回転角を、外から与えない。
- 距離を座標として与えない。
- 振幅を大きさ（広がり）として読まない。
- 状態は、倍音を下に積んだパルスとして置く。八元数 1 個を点として置かない。積む次数は 1 次までの全部とする。振幅の並びは仮説なので、等しい振幅を使う場合は、仮説であることを明記する。
- 方向を読む実験は、4 体以上で行う。

## A.27 ヤン＝ミルズ方程式とディラック方程式は、全然違うものなのか（2026-11-20）

【著者の問い】ヤン＝ミルズの方程式と、ディラック方程式は、全然違うものなのか。

【既知】全然違うものではない。同じ一つのものを、二つの側から見た式である。
1. **出どころが同じ。** どちらも、同じ一つのラグランジアンから出る。回転 $A$ について変分するとヤン＝ミルズ方程式、値 $\bar q$ について変分するとディラック方程式になる（本文 3 章）。
2. **同じ $D_\mu$ を使っている。** ディラック方程式は $D_\mu$ を値 $q$ に働かせた式、ヤン＝ミルズ方程式は同じ $D_\mu$ を場の強さ $F$ に働かせた式である。$F$ そのものも $D_\mu$ から作られる（$F_{\mu\nu} = [D_\mu, D_\nu]$）。
3. **働かせ方が、片側か両側か。** 値は片側から回される（$q \to Uq$）。場の強さは両側から挟まれて回される（$F \to U F U^{-1}$）。源 $J$ は値の対から作られ、これも両側から挟まれる側である。
4. **二乗すると相手が現れる。** ディラック方程式の演算を二回行うと、$D_\mu$ を二回働かせる項のほかに、場の強さ $F$ とスピンの積の項が現れる。
5. **同じ形に書ける。** 電磁気の場合、マクスウェル方程式は、ディラック方程式と同じ一階の演算を、値ではなく場の強さに働かせた一本の式「（演算）$F = J$」にまとめられることが知られている。
6. **違う点。** ディラック方程式は微分が一階で、値について一次である。ヤン＝ミルズ方程式は $A$ について二階で、交換子の項があるので一次でない。値はスピン 1/2、回転はスピン 1 である。

【整理】二つの式の違いは、「何に働かせるか（値か、値の対か）」と「片側から掛けるか、両側から挟むか」にまとめられる。A.23 の「左から掛けるか、右から掛けるか、両側から挟むか」の選択は、標準の定式では、この二つの式の違いにあたる。
