## 5. 11 月 22 日の時点の到達点

**決まっていること（著者の定義と要請）。**

- 状態は、円周の上の八元数の波形。倍音を下に積んだパルス。1＋7 の読みで O = A(cos θ + n sin θ)、θ がベース波の中心位相。
- 距離は、二つの中心位相の差 Δθ。
- 結合係数 k は、全天空に占める相手の面積の割合。0 から 1、無次元、自分自身は 0。
- どの状態から見ても Σ_b k_ab = 1.0。背景を置かないことから出る。正規化で合わせてはいけない。
- R は {O} から決まる。外から与えない。
- 波に重なりも隠れもない。線形和である。
- 写像は、全員との一回の積で N 個に書き戻す。結合係数は演算の入力で、先に読む。割り戻しは一度だけで、途中で割らない。
- 外から与えてよいのは、初期状態（初期の Δθ）だけ。
- 最初の目標は、単純な系で、標準理論に近い数を一つ出すこと（§22.3）。

**決まっていないこと。**

- 天空の次元（1・2・4・6 乗のどれか）。著者は「全部やってみて、正しそうなのを選ぶ」としている。
- k を、積のどこに、どう入れるか。
- 書き戻しで一度だけ割る、その相手。
- Σk = 1.0 で動くのが R か M か、両方か。
- Δθ → 0 と 180° の扱い（§7 で一部がつながる）。
- 倍音の振幅の並び、振幅の単位、パワーの定義。
- 右から掛けるか、左から掛けるか。1＋7 で読むか、(1＋3)(1＋3) で読むか。
- v0.3 の §5 の三項目（初期配置、更新写像、測る量）。

**写像 Ψ の候補。** これまでに四つ書かれた。どれも作業者の置き方を含み、採否は決まっていない。

1. 勾配流と o′ = V/|V|（11/20）。著者が退けた。
2. 三つ組の写像 oᵢ′ = （他の二つの積の共役）（11/21）。三つを手で選んでいる。固定点のまわりで、24 方向のうち 8 方向が毎回 2 倍になる。

## 7. 距離の問題と、コインとコップ

### 7.1 Claude が読んでいて気づいた点

11 月 20 日の距離は三つの積の実部で、11 月 22 日の距離は Δθ である。軸 n が同じ二つの状態では、どちらも同じ角度になる。軸が違う場合は、思考実験 2 §16.3 の式（二つの半分の距離を配分 χ で混ぜたもの）になり、Δθ だけでは決まらない。二つの「距離」のつなぎ方は、どこにも書かれていない。

### 7.2 著者の指摘

【木原】「あなたが読んでいて気づいた距離の問題、これが迷走の原因で、1 週間別なことを検討した原因です。なぜ私が、コップとコインのおかしな思考実験をしたかにも接続しているんですよ。」

### 7.3 つながり【承認】

Claude の読みを著者に示し、「よいです」と認められたものである。

思考実験 2 の §26 は、結合係数 k を「自分から見える相手の面積の割合」と定義した所で止まった。そこに残った未解決は、どれも「見えるとは何か」の問いだった。コインとコップは、その問いだけを、波二つと掛け算一つの最小の系で解いたものである。

| §26 に残った問題 | コインとコップで出た答え |
|---|---|
| Δθ → 0 で比は大きくなるのに、自分自身は 0 と置く。二つがつながらない（§26.3） | コップを重ねると、交差項は分解能以下になる。重なった相手は見えない。近づくほど強く結合するのではなく、見えなくなる |
| 「区別できる分だけが見える」は、確かめていない読みだった（§26.13） | 見えるか見えないかを、交差項の振幅が分解能以下かどうかで判定する方法になった |
| 自分自身も、無限遠の相手も、視野角は 0（§26.1）。二つの 0 は同じか | 隠れたコインと、最初から無いコインは、交差項では区別できない。「見えない」と「無い」の区別は諦める |
| 相反則。k_ab と k_ba は一般に違う（§26.12）。どちらがどちらを見ているのか | 山と山の積は入れ替えても同じ値で、どちらが隠しどちらが隠されるかが書けなかった。コップを井戸型にして、役割の違いを波の形に入れた |
| どの波も全天空を覆っていて、位相が局在しているだけ（§26.13） | 井戸型の波は、井戸の外で円周全体に一定の高さを持つ。コップがない所を波にする、という発想そのもの |
| 波に重なりも隠れもない（§26.13）。では隠れるとは何か | 遮る面は置かない。積がゼロになることが、隠れることである |
| R は外から与えない。系は有限で閉じている（§26.11） | コップを同じコップのまま動かせるためには、系は有限で、閉じていて、端が無い |

もう一点。思考実験 2 の §18.2 で、自分との積で形が変わらない唯一の波形として「0 か 1 の実数の矩形の窓」が出ていた。そのときは「何にあたるのか分からない」とされたままだった。コインとコップの井戸型は、この窓と同じ形である。

**まとめ。** 距離の問題の中身は、距離の式ではなく、「A から B が見える」を波と積だけでどう書くか、だった。それが決まらないと k が書けず、k が書けないと Ψ が書けない。コインとコップは、k の定義の土台を作る作業だった。

コインとコップの論文は `次元の生成構造/堀田先生のnoteとコインとコップの思考実験_20261124/コインとコップの思考実験.md`（Concept DOI 10.5281/zenodo.24562867）。要点：null は情報がない状態で、直接は読めない。「あるか無いか」を「見えるか見えないか」に置き換え、交差項 c(ψ) = 2 f_coin f_cup の振幅が、振幅の分解能以下なら見えない、と判定する。存在の null は残る。倍音の構成を知っているのは神の目線で、系の中から読めることと分ける。

### 7.4 まだ分からない点【読み】

コインとコップは、S¹ の上で、波二つ、掛け算一回の話である。そこから、N 個の八元数のパルスの k の配列へ、どう上げるかは、論文には書かれていない。とくに次の点である。

- 井戸型の波を、各状態が自分で持つのか、相手の全体が作るのか。
- 軸 n が違う相手の「見える」を、どう読むか（§7.1 の問題）。
- 交差項の振幅と分解能による判定を、k（0 から 1 の割合）にどうつなぐか。

## 8. Claude が気づいたこと【読み】

著者の確認を得ていないものを含む。

1. **10 月 20 日の結論とのつながり。** 10 月 20 日には、インフレーションは正規化の非線形でしか起こらない、という結論だった。11 月 22 日に、正規化は禁じられた。二つを合わせると、新しい実験でインフレーションが起こるなら、非線形は正規化以外から来なければならない。候補は、写像が積（二次）であることと、結合係数が中心位相の差で変わることである。三つ組の写像（§5 の 2）では、正規化なしで 8 方向が毎回 2 倍になることが確かめてある。ただし、その写像に §26 の結合係数は入っていない。
2. **無名な和が潰れることと、候補 1。** 11 月 20 日の論文 (9.1) は、同じ重みで全部足すと、八元数に固有の項（クロス積と φ）が消える、という結果である。候補 1 は同じ重みの和だが、状態が倍音の波形なので、重みが広がりから自分で出た（思考実験 2 §18.3）。一方、候補 1 では、自分と相手の向きの関係が使われていない、という事実が残っている（§19.3）。§26 の k を入れた写像でここがどうなるかは、まだ誰も見ていない。
3. **写像を決めなくても、いま計算できるもの。** §26 の定義だけで、状態を動かさずに、k の配列を読むことができる。配置（Δθ と M）を与え、四通りの天空の次元について k を計算し、行ごとの Σk が 1 からどれだけ外れるか、1 にするには R か M がどう動かなければならないかを見る計算である。割り算も書き戻しも入らない。ただし、§26.3 の二つの角度（360°/M と Δθ）から見かけの半角 α をどう作るかは、著者の式で確定する必要がある。§7 のとおり、Δθ → 0 の側は、コインとコップの判定で読み直すことになる。

## 10. 2026-11-27 追記：Chandrasekaran の論文から拾ったヒント

### 10.1 著者の指摘

【木原】「重要なのは、事実上 Σzₙ² = 0 と、x² + y² + z² + (it)² = R² + Q₁² + Q₂² + Q₃² という私の写像（公理にも、定義にも入れていませんが）は、事実上、光円錐の null 解だって分かりますか。だから気になっているんですよ。」

- x² + y² + z² + (it)² = R² + Q₁² + Q₂² + Q₃² は、その実の切り口で、8 成分のヌルベクトルの条件である。

## 14. 2026-11-27 追記：相互作用は自乗か、三つの積か

【木原】「選ぶのは、まず、相互作用です。これが最大の問題です。八元数の集合 {Oₙ}² ↦ {Oₙ}′ となるのですが、ただの自乗ですかね。これが一番の悩みです。三つの八元数 A、B、C の全ての積の組み合わせなのでは。ABC、ACB、…」

プログラム `triple_product_orderings_v0.py`、結果 `results/triple_product_orderings_v0.txt`。

【確かめた】

1. 三つの積は、順序 6 通り × 括弧 2 通りの 12 通りある。実部は 12 通りとも同じ。括弧による違いはどの順序でも同じ大きさで、符号だけが順序の入れ替えで反転する（結合子 [A, B, C] = (AB)C − A(BC)。実部を持たない）。
2. 12 通りを同じ重みで全部足すと、括弧の違いは消え、(A + B + C)³ の交差項に一致する。
3. N 個を無名のまま全部足すと、P = ΣO として、三つの積は P³、二つの積は P² に潰れる（八元数の全成分で）。P³ は P 自身の複素平面の中に収まる。
4. 自分 O_i を一つ、残り二つを全員の和 P として N 個に書き戻すと、括弧の選択は消え（交代性）、三つの形 O_i P²、P O_i P、P² O_i だけが残る。三つは互いに違う。三つの和は、P³ を O_i の向きに微分したものである。
5. 結合子が生きるのは、相手の和が二種類ある（重みの違う和 P₁、P₂）ときだけである。同じ和を二度使うと、括弧の差は 0。
6. P̄P は実数で |P|² である。三つの形のどれも、P̄P で一度割ると、|O_i′| = |O_i| が厳密に成り立つ。全員の総量も変わらない。

【既知】二つの元の積は、いつも結合的である（アルティンの定理）。括弧の付け替えの差が出るのは、三つからである。

【読み】

- 二つの積（自乗）で止める限り、八元数に固有の中身（括弧の差）が入る場所がない。
- 三つの積なら、「掛け算をすれば次元は上がる。どこかで一度だけ割り戻す」（思考実験 2 §25.8）の割る相手が、面積 P̄P になる。状態どうしの積そのもので、外から持ち込む数がない。割った結果は回転である。
- ただし、同じ重みのままでは相手が和 P ひとつに潰れる。中身が残るには、状態ごとに違う重みが要る。

## 15. 2026-11-27 追記：N³ の配列と、自己無撞着の判定

【木原】「積和ですが、イメージとしては、交差項を全て残すので、N³ の立方体の配列になりますよ。」

**ここで起きた誤読。** Claude は、著者の次の一文「これを繰り返し演算したら、対角成分だけが残ると自己無撞着な状態では？」を受けて、非対角が消えること（デコヒーレンス、無矛盾な歴史、配列の対角化）を自己無撞着の条件として論じた。

【木原】「もう少し違う読み方ですよ。実は対角にならなくてもよいです。つまり、繰り返し演算しても、N³ の配列が大きく変わらない、または準振動状態になれば、それが自己無撞着 Uⁿ = I ですよ。」

**固定点。**

- 交差項は捨てない。同じ重みで足して潰さず、N³ の配列 X_ijk（三つの積の全部の組み合わせ）として持つ。
- 自己無撞着の判定は、配列が対角になることではない。**繰り返し演算しても、N³ の配列が大きく変わらないこと、または準振動の状態になること**である。これが Uⁿ = I である。
- 対角だけが残る状態は、そのうちの特別な一つにすぎない。

【読み】

- 判定の対象は、個々の状態ではなく、関係の配列である。10 月 20 日の試行で、状態そのものは回り続けても、形（要素どうしのグラム行列）が戻れば自己無撞着とし、相対平衡・周期的・準周期的・漸近的の四つの型に分けたのと、同じ判定である。今回は二体のグラム行列ではなく、三体の N³ の配列になる。
- インフレーションは、ある型の不安定な自己無撞着の配列から指数的に離れ、別の自己無撞着の配列に近づくこと、と言い直せる（10 月 20 日の README の言い方）。
- 【既知】八元数 1 個ずつでは、|O_i O_j O_k| = |O_i||O_j||O_k| なので、0 でない状態の積は 0 にならない。配列の成分の大きさは、状態の大きさだけで決まる。変わるのは向き（角度と軸）である。
