## 5. 11 月 22 日の時点の到達点

**決まっていること（著者の定義と要請）。**

- 状態は、円周の上の八元数の波形。倍音を下に積んだパルス。1＋7 の読みで O = A(cos θ + n sin θ)、θ がベース波の中心位相。
- 距離は、二つの中心位相の差 Δθ。
- 結合係数 k は、全天空に占める相手の面積の割合。0 から 1、無次元、自分自身は 0。
- どの状態から見ても Σ_b k_ab = 1.0。背景を置かないことから出る。正規化で合わせてはいけない。
- R は {O} から決まる。外から与えない。
- 波に重なりも隠れもない。線形和である。
- 写像は、全員との一回の積で N 個に書き戻す。結合係数は演算の入力で、先に読む。割り戻しは一度だけで、途中で割らない。
- 外から与えてよいのは、初期状態（初期の Δθ）だけ。
- 最初の目標は、単純な系で、標準理論に近い数を一つ出すこと（§22.3）。

**決まっていないこと。**

- 天空の次元（1・2・4・6 乗のどれか）。著者は「全部やってみて、正しそうなのを選ぶ」としている。
- k を、積のどこに、どう入れるか。
- 書き戻しで一度だけ割る、その相手。
- Σk = 1.0 で動くのが R か M か、両方か。
- Δθ → 0 と 180° の扱い（§7 で一部がつながる）。
- 倍音の振幅の並び、振幅の単位、パワーの定義。
- 右から掛けるか、左から掛けるか。1＋7 で読むか、(1＋3)(1＋3) で読むか。
- v0.3 の §5 の三項目（初期配置、更新写像、測る量）。

**写像 Ψ の候補。** これまでに四つ書かれた。どれも作業者の置き方を含み、採否は決まっていない。

1. 勾配流と o′ = V/|V|（11/20）。著者が退けた。

## 7. 距離の問題と、コインとコップ

### 7.1 Claude が読んでいて気づいた点

11 月 20 日の距離は三つの積の実部で、11 月 22 日の距離は Δθ である。軸 n が同じ二つの状態では、どちらも同じ角度になる。軸が違う場合は、思考実験 2 §16.3 の式（二つの半分の距離を配分 χ で混ぜたもの）になり、Δθ だけでは決まらない。二つの「距離」のつなぎ方は、どこにも書かれていない。

### 7.2 著者の指摘

【木原】「あなたが読んでいて気づいた距離の問題、これが迷走の原因で、1 週間別なことを検討した原因です。なぜ私が、コップとコインのおかしな思考実験をしたかにも接続しているんですよ。」

### 7.3 つながり【承認】

Claude の読みを著者に示し、「よいです」と認められたものである。

思考実験 2 の §26 は、結合係数 k を「自分から見える相手の面積の割合」と定義した所で止まった。そこに残った未解決は、どれも「見えるとは何か」の問いだった。コインとコップは、その問いだけを、波二つと掛け算一つの最小の系で解いたものである。

| §26 に残った問題 | コインとコップで出た答え |
|---|---|
| Δθ → 0 で比は大きくなるのに、自分自身は 0 と置く。二つがつながらない（§26.3） | コップを重ねると、交差項は分解能以下になる。重なった相手は見えない。近づくほど強く結合するのではなく、見えなくなる |
| 「区別できる分だけが見える」は、確かめていない読みだった（§26.13） | 見えるか見えないかを、交差項の振幅が分解能以下かどうかで判定する方法になった |
| 自分自身も、無限遠の相手も、視野角は 0（§26.1）。二つの 0 は同じか | 隠れたコインと、最初から無いコインは、交差項では区別できない。「見えない」と「無い」の区別は諦める |
| 相反則。k_ab と k_ba は一般に違う（§26.12）。どちらがどちらを見ているのか | 山と山の積は入れ替えても同じ値で、どちらが隠しどちらが隠されるかが書けなかった。コップを井戸型にして、役割の違いを波の形に入れた |
| どの波も全天空を覆っていて、位相が局在しているだけ（§26.13） | 井戸型の波は、井戸の外で円周全体に一定の高さを持つ。コップがない所を波にする、という発想そのもの |
| 波に重なりも隠れもない（§26.13）。では隠れるとは何か | 遮る面は置かない。積がゼロになることが、隠れることである |
| R は外から与えない。系は有限で閉じている（§26.11） | コップを同じコップのまま動かせるためには、系は有限で、閉じていて、端が無い |

もう一点。思考実験 2 の §18.2 で、自分との積で形が変わらない唯一の波形として「0 か 1 の実数の矩形の窓」が出ていた。そのときは「何にあたるのか分からない」とされたままだった。コインとコップの井戸型は、この窓と同じ形である。

**まとめ。** 距離の問題の中身は、距離の式ではなく、「A から B が見える」を波と積だけでどう書くか、だった。それが決まらないと k が書けず、k が書けないと Ψ が書けない。コインとコップは、k の定義の土台を作る作業だった。

コインとコップの論文は `次元の生成構造/堀田先生のnoteとコインとコップの思考実験_20261124/コインとコップの思考実験.md`（Concept DOI 10.5281/zenodo.24562867）。要点：null は情報がない状態で、直接は読めない。「あるか無いか」を「見えるか見えないか」に置き換え、交差項 c(ψ) = 2 f_coin f_cup の振幅が、振幅の分解能以下なら見えない、と判定する。存在の null は残る。倍音の構成を知っているのは神の目線で、系の中から読めることと分ける。

### 7.4 まだ分からない点【読み】

コインとコップは、S¹ の上で、波二つ、掛け算一回の話である。そこから、N 個の八元数のパルスの k の配列へ、どう上げるかは、論文には書かれていない。とくに次の点である。

- 井戸型の波を、各状態が自分で持つのか、相手の全体が作るのか。
- 軸 n が違う相手の「見える」を、どう読むか（§7.1 の問題）。
- 交差項の振幅と分解能による判定を、k（0 から 1 の割合）にどうつなぐか。

## 8. Claude が気づいたこと【読み】

著者の確認を得ていないものを含む。

1. **10 月 20 日の結論とのつながり。** 10 月 20 日には、インフレーションは正規化の非線形でしか起こらない、という結論だった。11 月 22 日に、正規化は禁じられた。二つを合わせると、新しい実験でインフレーションが起こるなら、非線形は正規化以外から来なければならない。候補は、写像が積（二次）であることと、結合係数が中心位相の差で変わることである。三つ組の写像（§5 の 2）では、正規化なしで 8 方向が毎回 2 倍になることが確かめてある。ただし、その写像に §26 の結合係数は入っていない。
2. **無名な和が潰れることと、候補 1。** 11 月 20 日の論文 (9.1) は、同じ重みで全部足すと、八元数に固有の項（クロス積と φ）が消える、という結果である。候補 1 は同じ重みの和だが、状態が倍音の波形なので、重みが広がりから自分で出た（思考実験 2 §18.3）。一方、候補 1 では、自分と相手の向きの関係が使われていない、という事実が残っている（§19.3）。§26 の k を入れた写像でここがどうなるかは、まだ誰も見ていない。
3. **写像を決めなくても、いま計算できるもの。** §26 の定義だけで、状態を動かさずに、k の配列を読むことができる。配置（Δθ と M）を与え、四通りの天空の次元について k を計算し、行ごとの Σk が 1 からどれだけ外れるか、1 にするには R か M がどう動かなければならないかを見る計算である。割り算も書き戻しも入らない。ただし、§26.3 の二つの角度（360°/M と Δθ）から見かけの半角 α をどう作るかは、著者の式で確定する必要がある。§7 のとおり、Δθ → 0 の側は、コインとコップの判定で読み直すことになる。

## 10. 2026-11-27 追記：Chandrasekaran の論文から拾ったヒント

### 10.1 著者の指摘

【木原】「重要なのは、事実上 Σzₙ² = 0 と、x² + y² + z² + (it)² = R² + Q₁² + Q₂² + Q₃² という私の写像（公理にも、定義にも入れていませんが）は、事実上、光円錐の null 解だって分かりますか。だから気になっているんですよ。」

## 14. 2026-11-27 追記：相互作用は自乗か、三つの積か

【木原】「選ぶのは、まず、相互作用です。これが最大の問題です。八元数の集合 {Oₙ}² ↦ {Oₙ}′ となるのですが、ただの自乗ですかね。これが一番の悩みです。三つの八元数 A、B、C の全ての積の組み合わせなのでは。ABC、ACB、…」

プログラム `triple_product_orderings_v0.py`、結果 `results/triple_product_orderings_v0.txt`。

【確かめた】

1. 三つの積は、順序 6 通り × 括弧 2 通りの 12 通りある。実部は 12 通りとも同じ。括弧による違いはどの順序でも同じ大きさで、符号だけが順序の入れ替えで反転する（結合子 [A, B, C] = (AB)C − A(BC)。実部を持たない）。
2. 12 通りを同じ重みで全部足すと、括弧の違いは消え、(A + B + C)³ の交差項に一致する。
3. N 個を無名のまま全部足すと、P = ΣO として、三つの積は P³、二つの積は P² に潰れる（八元数の全成分で）。P³ は P 自身の複素平面の中に収まる。
4. 自分 O_i を一つ、残り二つを全員の和 P として N 個に書き戻すと、括弧の選択は消え（交代性）、三つの形 O_i P²、P O_i P、P² O_i だけが残る。三つは互いに違う。三つの和は、P³ を O_i の向きに微分したものである。
5. 結合子が生きるのは、相手の和が二種類ある（重みの違う和 P₁、P₂）ときだけである。同じ和を二度使うと、括弧の差は 0。
6. P̄P は実数で |P|² である。三つの形のどれも、P̄P で一度割ると、|O_i′| = |O_i| が厳密に成り立つ。全員の総量も変わらない。

【既知】二つの元の積は、いつも結合的である（アルティンの定理）。括弧の付け替えの差が出るのは、三つからである。

【読み】

- 二つの積（自乗）で止める限り、八元数に固有の中身（括弧の差）が入る場所がない。
- 三つの積なら、「掛け算をすれば次元は上がる。どこかで一度だけ割り戻す」（思考実験 2 §25.8）の割る相手が、面積 P̄P になる。状態どうしの積そのもので、外から持ち込む数がない。割った結果は回転である。
- ただし、同じ重みのままでは相手が和 P ひとつに潰れる。中身が残るには、状態ごとに違う重みが要る。

## 15. 2026-11-27 追記：N³ の配列と、自己無撞着の判定

【木原】「積和ですが、イメージとしては、交差項を全て残すので、N³ の立方体の配列になりますよ。」

【木原】「もう少し違う読み方ですよ。実は対角にならなくてもよいです。つまり、繰り返し演算しても、N³ の配列が大きく変わらない、または準振動状態になれば、それが自己無撞着 Uⁿ = I ですよ。」

**固定点。**

- 交差項は捨てない。同じ重みで足して潰さず、N³ の配列 X_ijk（三つの積の全部の組み合わせ）として持つ。

【読み】

- 判定の対象は、個々の状態ではなく、関係の配列である。10 月 20 日の試行で、状態そのものは回り続けても、形（要素どうしのグラム行列）が戻れば自己無撞着とし、相対平衡・周期的・準周期的・漸近的の四つの型に分けたのと、同じ判定である。今回は二体のグラム行列ではなく、三体の N³ の配列になる。

- P = 0 が特異点になっている。線形和の閉塞（Σz = 0）を初期値に課すと、この演算は使えない。

### 16.5 訂正：止まる必要はない。内部の時計ができている

**ここで起きた誤読。** Claude は §16.4 で「止まらない」を、この形の足りない点の一番目に挙げた。

【木原】「止まる必要はないですよ。位相は回転し続けたほうがベターです。むしろ、勝手に内部時計ができていますよね。」

## 17. 2026-11-27 追記：3³ の配列そのものの構造

演算の繰り返しも、割り算も、倍音も入れない。八元数 3 個と、その積の配列 X_ijk = (O_i O_j) O_k だけを調べた。

【確かめた】

1. **成分の種類と括弧。** 27 個は、三つとも同じ添字のもの 3 個、二つが同じもの 18 個、三つとも違うもの 6 個に分かれる。括弧の付け方で値が変わるのは、三つとも違う 6 個だけである。その差は、6 個とも ±[O₁, O₂, O₃]（結合子）で、実部を持たない。
2. **大きさ。** |X_ijk| = |O_i||O_j||O_k|。配列の成分の大きさは、状態の大きさだけで決まる。
3. **実部。** 添字を巡回させても変わらない。三つとも違う場合、二つの添字を入れ替えると −2φ(b₁, b₂, b₃) だけ変わる（φ は三つの虚部の 3 形式 f_ijk b₁ⁱ b₂ʲ b₃ᵏ）。二つが同じ場合は、入れ替えても変わらない。27 個の実部のうち、違う値は 11 個である。
4. **独立な量の数。**

   | 型 | 交換子 | 結合子 | φ²/\|b∧b∧b\|² | 配列の違う成分の数 |
   |---|---|---|---|---|
   | 同じ複素平面の 3 個 | 0 | 0 | （虚部が 1 次元） | 10 |

7. **虚部の和が 0 の 3 個**は、虚部が 2 次元に収まる。必ず一つの四元数の中に入り、結合子も φ も 0 である。

- 三体の配列が、二体の量に足して持っている、変換で変わらない量は、φ 一つである。結合子の大きさは、φ と二体の量から決まる（5）。二体の関係には見えず、三体で初めて見えるものの中身は、この一つの数である。

## 19. 2026-11-27 追記：基点の本質。対称な複素数 4 個は、八元数として読める

### 19.1 著者の指摘

Claude は §18.3 で、基点の論文を「U = i の冪で 4 状態を作る」という表面で読み、八元数への拡大を「e₁〜e₇ のどれか一本で同じ K₄ を作る」と書いた。

### 19.2 正しい解釈（Claude が言い直したもの。式は手で確かめた。著者の確認待ち）

**(1) 高対称とは、釣り合いの条件である。** 生成子の冪で並べることではない。条件は四つ。

- 位相が 90° ずつ違う四方向（十字）に並ぶ。
- 振幅はすべて 1。
- パワーで計算した重心が原点にある：Σz = 0。
- すべての方向でモーメントが釣り合う：Σz² = 0。z = a + ib と書くと、Σa² = Σb²、Σab = 0。二次のモーメントが、どの向きにも偏らない。

**(2) この条件は、N を 4 の倍数に限る。** 十字の四方向 1、i、−1、−i にいる個数を n₀、n₁、n₂、n₃ とする。

- Σz = 0 から、n₀ = n₂、n₁ = n₃。
- Σz² = 0 から、n₀ + n₂ = n₁ + n₃。
- 合わせて n₀ = n₁ = n₂ = n₃。したがって N = 4n。

**(3) 最小は N = 4 で、{1, i, −1, −i} である。** 基点の論文の K₄ の 4 頂点は、これである。

**(4) 複素数 4 個は実数 8 個で、八元数 1 個として読める。** (1+1)(1+1)(1+1)(1+1) の読み（四つの複素面）である。公理系の第 0 公理に挙げた三つの読み方の一つにあたる。八元数は、対称な複素数の集まりの上に新しく置くものではなく、最小の対称な複素数の組の、読み方である。

**(5) 複素数の閉塞の条件は、八元数の中のヌル条件になる。** 四つの複素面の値を z_p = x_p + i y_p（p = 0, 1, 2, 3）とすると、Σz_p² = 0 は

- Σx_p² = Σy_p²：実部 4 個の二乗和 = 虚部 4 個の二乗和。11 月 19 日の論文の式 (8.1) の対応（実部 4 個が t, x, y, z、虚部 4 個が R, Q₁, Q₂, Q₃）で読めば、t² + x² + y² + z² = R² + Q₁² + Q₂² + Q₃²。著者が §10.1 で「光円錐の null 解」と述べた式である。
- Σx_p y_p = 0：四つの面の、実部と虚部の積の和が 0。

**(6) {1, i, −1, −i} を 8 個の実数で書くと、±1 が 4 個、0 が 4 個になる。** 思考実験（11/21）§10 の「符号ベクトルは、4 つの位相を 90° の粗さで読んだもの」にあたる。

**(7) したがって、八元数 n 個の高対称な初期値は、十字に並んだ振幅 1 の複素数 4n 個である。** 八元数 3 個なら、複素数 12 個（十字の各方向に 3 個ずつ）である。

### 19.3 確かめていないこと

- 四つの複素数を、四つの面のどれに割り当てるか。割り当てによって、1+7 で読んだときの角度が変わる（1 の面に ±1 が入れば実部は ±1、±i が入れば実部は 0）。どの割り当てが八元数の積と両立するかは、調べていない。
- (5) の第二の条件 Σx_p y_p = 0 を、二つの四元数の半分の関係としてどう読むか。面ごとの向きの約束（符号）に依る。
- 基点の論文の倍音つきの状態 S_k = (U^k, U^{mk}) を、この読み方でどう置くか。

## 23. 生成子をやめる：配列の積だけの写像(2026-11-27 の対話)

### 23.1 なぜ対照実験をさせたか

【木原】「問題はわかりますか、これは生成子からつくっていますよね。これをやめたいんです。シンプルに N³ の配列の積にしたらどうなるのか、を試すんですよ。」

やめたいのは、生成子経由の作り方である。位相だけを取る割り算、生成子と対角化、刻み 2π/N、相手を頂点共有に限る選び方が、状態の外から入っている。

### 23.2 Claude の誤読(繰り返したもの)

1. 配列から N 個の状態へ書き戻す段階を入れた。【木原】「次の状態も N³ のままですって。」
2. 写像の側(添字の畳み方)ばかりを問題にした。【木原】「最初に、N 個の初期データから N³ にどう積むかだけが課題なんですよ。」
3. 最初から三つの積を全部並べる積み方を書いた。【木原】「イメージとしては、最初は対角成分だけがあるイメージですよね。」
4. もう一度、192 個の状態に畳み戻した。【木原】「192³ の配列を考えるんですよ。配列が変わらなくなるか、位相が回転し続けるだけの状態になったら自己無撞着。位相が回転するのであれば Uⁿ = I。また戻っていますよ。」
5. 固有値や升目の規則を条件のように書いた。【木原】「ポイントは正方行列であることだけですよ。」

### 23.3 固定点(木原)

- 状態は配列そのもの。N 個に戻さない。
- 演算は配列に配列を掛けるだけ。O、O²、O³、…。必要なのは正方であること(掛けても同じ形が返ること)だけ。
- Oⁿ = I が自己無撞着。位相が離散していれば、回り続けてもいつか 2π になり、同じ状態に戻る。
- A×B×C ↦ D は別の手続きではなく、配列を掛けるたびに全ての組み合わせについて起きる。誰も選ばれていない(無名性)。
- 数え方：複素数 4 個で八元数 1 個、八元数 3 個でベクトル 1 個。複素数 N 個なら八元数 M = N/4、ベクトル V = N/12。倍音 W = 16 なら N = 16×12 = 192。
- 最初は対角成分だけがあるイメージ。

### 23.4 違和感の原因(木原)

【木原】「一つの成分を考えると、自分も含めた全てとの積和になるだけ。三つの掛け算にならない。ここが違和感の原因だ。二次元配列では横×縦の演算、つまり A×B にしかならない。三次元配列なら縦×横×高さで A×B×C になる。三次元配列にする必要があるので、三次元正方行列の積ですね。」

### 23.5 Claude が出した事実(既知のもの。原典は未確認、記憶による)

- **対角だけの配列は、何乗しても対角のまま。** 成分が別々に冪乗されるだけで、交差項は生まれない。十字の値(1, i, −1, −i)なら z³ は共役、周期 2。これは K₄ 論文の m=3 の倍音 U^(3k) である。
- **三項の積**(Mesner–Bhattacharya)：D_ijk = Σ_t A_itk · B_ijt · C_tjk。三つの立方体から一つの立方体。規則を足さずに閉じる。結合的でない。単位元は単純には決まらない。対角だけに z_i を置くと結果も対角で z_i³。
- **二項の積**(Kilmer–Martin の t 積)：立方体を N 枚の行列の束と見て、a 枚目と b 枚目の行列の積を (a+b) mod N 枚目に足す。結合的。単位元がある。一回で掛かるのは二つ。
- 行列の縫い合わせ(添字一本の共有)のままでは、立方体二つの積は閉じない(添字が 4 本残る)。

| | 一回で掛かる数 | 結合的か | Oⁿ = I の I |
|---|---|---|---|
| 二項の積(束ねて番号を足す) | 二つ | はい | ある |
| 三項の積(縦×横×高さ) | 三つ | いいえ | 単純には決まらない |

### 23.6 三つの巡回と (1+3)(1+3)

【木原】「これって、八元数の虚数 (ijk) と同じ対称性な気がしますが。」

- 三項の積では、足し上げる添字 t が A の 2 番目、B の 3 番目、C の 1 番目の軸に入る。軸を 1→2→3→1 と回し、因子を A→B→C→A と回せば積の形は変わらない。ij = k、jk = i、ki = j と同じ、向きのついた三つの巡回(Z₃)である。
- 同じとは言えない点：虚数単位は二つを入れ替えると符号が反転する。三項の積にこの符号の規則が入っているかは確かめていない。三つ組は八元数に 7 組、立方体の軸は 1 組分。

【木原】「だから (1+3)(1+3) と考えるのが自然では。」

- (1+3) は四元数ひとつ。1 は向きのない成分、3 は巡回する三つの向き。
- (1+3)(1+3) = 1·1 + 1·3 + 3·1 + 3·3、成分は 1 + 3 + 3 + 9 = 16。
- 【既知】四元数の積では 3·3 が内積(実部へ)と外積(虚部へ、ij = k の巡回)に分かれる。
- 【Claude の読み】「最初は対角だけ」は 1·1 だけがある状態。交差項は 3·3。写像 x²+y²+z²+(it)² = R²+Q₁²+Q₂²+Q₃² の両辺も (1+3) の形。

### 23.7 四元数が基本ではないか(木原)

【木原】「この演算を最初に発明する必要がある気がするな。もしかしたら、八元数がベースなのではなく、八元数になるだけで、四元数が基本だと考えた方がましなのかも。」

- 【既知】八元数は四元数の組 (a, b) に積 (a, b)(c, d) = (ac − d̄b, da + bc̄) を入れると出る(ケーリー・ディクソンの構成)。結合的でなくなる原因は、違う側をまたぐ積に入る共役と順序の入れ替えだけ。
- 【既知】四元数は結合的で行列で表せる。八元数は表せない。四元数を成分にすれば「正方の配列を掛け続けて Oⁿ = I」が曖昧さなく定義できる。
- 【既知】±1, ±i, ±j, ±k の 8 個はどれも 4 乗で 1、積で閉じる。基点の U = i、U⁴ = 1 を虚数の三つの向きに広げたもの。乱数なしで厳密に置ける。
- 【Claude の読み】まだ無いのは、配列の三本の軸の巡回と、四元数の三つ組の巡回を同じものとして扱う積である。発明が要るのはここ。
- 11 月 19〜22 日の検討は八元数を土台にしている。四元数を基本にするなら、読み直しが要る(捨てるのではない)。

### 23.8 決まっていないこと

- 192 個を配列へどう置くか(対角だけでは混ざらない)。
- 配列は二次元(A×B)か三次元(A×B×C)か。三次元なら積は二項か三項か、あるいは新しく作るか。
- 八元数を土台にするか、四元数を基本にして八元数を結果として得るか。

まだ何も走らせていない。
