## 読出し境界

- `振幅二乗R0` は単時点の $\sum_n|Z_{e,n}|^2$。質量型候補に必要な安定性・多ゲージ再構成は未測定。
- `S(0), S(π/2)` は外部軸との相関応答であり、内在スピン固有値ではない。
- 電荷と寿命は、現生成器に倍音段間相互作用を含む時間発展がないため、この初期表からは読めない。
- `行零閉鎖残差` は各関係波について $|\sum_n Z_{e,n}^2|/\sum_n|Z_{e,n}|^2$ を直接測った値。
