# N=5 採用seed記録

- 探索方法: 整数seedを1から1ずつ増やし、各seedを1回だけ実行する。
- 採用条件: 全5周波数波の自己無撞着残差が固定許容値未満になること。
- seed 1〜10: 少なくとも一つの周波数波が未収束。
- 最初に全波が収束したseed: **11**。
- 疑似乱数生成器: NumPy `default_rng` / PCG64（NumPy 2.0.2）。

採用後の本計算は `make_parent(5, seed=11)` の1回であり、同じseedから白色雑音近似の
疑似乱数入力を再生成できる。seed探索後に位相・振幅を手で変更していない。
