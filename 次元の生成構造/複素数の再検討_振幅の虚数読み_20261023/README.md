**題名：** 複素数を正しく理解していたか ― 振幅はどこに住むか、虚数読み、ℂ → ℍ → 𝕆 の帰属 ―（英題 Did We Understand Complex Numbers Correctly? Where the Amplitude Lives, the Imaginary Reading, and Attribution across ℂ → ℍ → 𝕆）

## 主旨（§29）
ℝ → ℂ → ℍ → 𝕆 と構造のある数の体系に取り組んできたが、複素数の段階で存在している対称性を見落としていないかを点検する。点検しないと、高次の構造（四元数・八元数）固有の対称性が低次の時点から存在していたことを誤認する。判定規則：**ある性質が段 L のものだと言ってよいのは、段 L − 1 の代数だけでは述べられないことを示したときだけ。**

## 動機の連鎖（§28、この順に書く。結論から書かない）
振幅はどこに住むか？ → 動径は曲率 R が占める（R は閉路の面積でしか読めない）→ 円周とも R とも直交する読めない（虚数）方向にあるはず → 振幅を虚数に読むと？ → cos²（ボルン則）と γ（ローレンツ因子）が同じ複素角の二つの断面として出る → 四元数に拡張すると振幅と位相が区別でき、その非可換性が第三の方向＝空間を生む → 八元数に拡張すると質量型と電荷型の振幅が結合子で区別される → 質量＝R、電荷＝Q、|a| ＝ |b|。各段で「数学的に自明（恒等式）」と「物理の読みとして選択（どの断面、どこで割るか）」を分ける。
