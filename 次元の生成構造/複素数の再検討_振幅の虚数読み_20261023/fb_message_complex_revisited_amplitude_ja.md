複素数を、正しく理解していたか。振幅の置き場所を問い直すと、ボルン則と光速度不変が一つの公理の二つの断面になる

詳細はコメント参照

四元数・八元数へ進む前に複素数へ戻り、複素数の段階にすでにある対称性を見落として四元数や八元数の手柄にしていないかを点検しました
規則は一つ。ある性質が段 L のものだと言ってよいのは、一つ下の段の代数だけでは述べられないことを示したときだけです
振幅は半径（曲率半径）に住めません。曲率半径は閉路の面積でしか読めず、振幅を半径に置くと振幅の変化が曲率の変化になるからです
振幅は円周とも半径とも直交する読めない方向に住みます。これが時空方程式 x² ＋ y² ＋ z² ＋ (it)² ＋ (iR)² ＋ (iQ)² ＝ 0 の Q 軸の由来です
その振幅を虚数に読むと、同じ複素指数の φ ＝ 0 の断面に cos²（ボルン則の形）が、θ ＝ 0 の断面に cosh φ ＝ γ（ローレンツ因子）が出ます
確率に見せる正規化は γ で割ることで、そこで捨てている一次元がラピディティです。ボルン則と光速度不変は、一つの公理の二つの断面です
前回の論文の分母 |1 ＋ u|² ＝ 2e^φ(cosh φ ＋ cos θ) はボルン則の正規化と同じ割り算で、|k| ＝ 1 の光円錐は結合と距離の自己双対点でした
複素数では虚数読みした振幅と位相が区別できません。四元数が別の単位で区別し、その非可換性が第三の方向、つまり空間を生みます
八元数では R と Q の二つの振幅の単位と位相の三つ組で初めて結合子が立ち、質量型と電荷型の振幅が代数的に別物になります。質量＝時空曲率 R、電荷＝内部曲率 Q と読みます
帰属の台帳にすると、四元数と八元数が足すものは空間と質量・電荷の区別だけで、残りは複素数にすでにありました。恒等式 11 件は数値で確認済みです
