## 事実の読み（表から直接読めること）

- **第 1 歩のずれ f(1) は w とともに単調に増え、w＝1 の床（全対 1）のずれに収束する。** 例 N＝6 den＝6：0.3 で 1.5e-2 → 1.0 で 7.9e-2。N が大きいほど小さい。
- **二つの領域がある。**
  - **小さい w**：ずれは 1e-2 前後の育たない台地になり、その下で走行 1 と同じ増幅が進み、同じ step で表に出る（N＝6 den＝6：onset 145/145/141 for w＝0/0.3/0.5、N＝8 den＝8：209/208/205）。final も走行 1 と同じ範囲。
  - **大きい w**：ずれが step 数歩で 0.2〜0.4 の高い水準に再配置され、そのまま止まる。final は 0.2〜0.46 で、走行 1 の到達値（0.04〜0.12）とは別の終状態。増幅は見えない。
- **領域の境界は N と den に依存する。** den＝124：N＝4 は 0.7→0.9 の間、N＝6, 8 は 0.5→0.7、N＝10 は 0.7→0.9。den＝N：N＝10 は 0.9→0.95、N＝12 は 0.5→0.7、N＝6, 8 は w＝1.0 でも台地 0.03〜0.04 のまま低い（final 0.08〜0.11）。
- onset の欄は f(1) ＞ 0.05 のとき自動的に 1〜数歩になるので、大きい w では増幅の指標として読まない。
- 保存量：全走行で丸めの範囲。初期値はどの w でも Σz²＝0 を満たす。
