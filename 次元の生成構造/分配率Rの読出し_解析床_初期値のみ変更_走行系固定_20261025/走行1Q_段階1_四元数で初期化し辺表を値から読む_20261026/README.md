## 符号化と復号

関係 e＝(v, w)（v＝始点、w＝終点）を

```
q_e = e^(i·πv/N) · r_e · e^(j·πw/N)
```

で表す。一周 2π は 2N 目盛り、頂点は 0..N−1 の N 目盛り、r_e の符号は残りの N 目盛り（e^(iπ)＝−1）。
r_e は走行 1 の床から Z0_e ＝ e^(iφ0) · r_e · i^((v+w) mod 2) で取る符号つき実数、φ0 は全体位相 1 個。

復号は配列の添字 e も e＝v·N＋w の規則も使わず、各 q_e の 4 成分 (a, b, c, d) と N・φ0 だけを使う。
- α ＝ (a, b) と (c, d) のノルムの大きい組の atan2 を π で割った余り、v ＝ round(αN/π) mod N
- β ＝ (a, c) と (b, d) のノルムの大きい組の atan2 を π で割った余り、w ＝ round(βN/π) mod N
- r ＝ Re(e^(−iπv/N) · q · e^(−jπw/N))、z ＝ e^(iφ0) · r · i^((v+w) mod 2)
