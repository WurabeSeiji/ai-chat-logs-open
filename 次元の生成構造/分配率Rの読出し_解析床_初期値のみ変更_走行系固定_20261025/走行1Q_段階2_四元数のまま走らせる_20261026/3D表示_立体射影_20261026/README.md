# 段階 2 本走行の 3D 表示（立体射影、2026-10-26）

`index.html` をブラウザで開く（ローカルのファイルのまま動く。Plotly 2.34.0 を cdnjs から読むのでネット接続が要る）。

## 操作
- **N・den**：N ∈ {3,4,5,6,8,10,12,15,20,25}、den は N か 124。
- **スライダー**：step 0〜500。
- **Auto**：1 歩ずつ自動で進み（60 ms ごと）、500 の次は 0 に戻る。もう一度押すと止まる。
- マウスで視点を回せる（N・den を替えても視点は保つ）。

## 表示の定義
- 色：初期状態で 1–i 面にいた関係（終点 w が偶数）＝青、j–k 面にいた関係（w が奇数）＝橙。走行中も同じ色で追う。
- 位置：u ＝ q/|q|、u′ ＝ p·u（p ＝ (1+i+j+k)/2、固定の回転）、(x, y, z) ＝ (b′, c′, d′)/(1 + a′)（−1 を極とする立体射影）。p を掛けるのは、初期値が ±1, ±i, ±j, ±k に乗っていて −1 が無限遠に飛ぶため。p は等長変換。
- 大きさ：|q|（その走行の全歩での最大に対する比）。
- 半径 4 を超えた点は向きを保って半径 4 に寄せる（全点の 1〜2％）。

## ファイル
- `make_3d_data_v1.py`：`../results_main/hm_N*_den_*_states_500.npz` と `../states_main/`（群の判定用）から `data/run_N{N}_den{den}.js` を作る。座標と振幅を int16 に量子化して base64 で埋め込む（座標の分解能 4/32767）。
- `data/index.json`：走行ごとの M と、半径 4 に寄せた点の数。

再生成：

```
~/.venvs/stage123_control_py39/bin/python3 make_3d_data_v1.py ../results_main ../states_main data 3 4 5 6 8 10 12 15 20 25
```
