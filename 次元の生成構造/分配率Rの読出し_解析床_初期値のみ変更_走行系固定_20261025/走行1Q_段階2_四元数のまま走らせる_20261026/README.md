# 走行 1Q 段階 2：四元数のまま走らせる（2026-10-26）

段階 1（`../走行1Q_段階1_四元数で初期化し辺表を値から読む_20261026/`）で、走行 1 の床を四元数で初期化し、辺表を値だけから読めることを確かめた。段階 2 は走行系を四元数に変える。**この段階は走行系の変更である。**

## 初期状態（`make_state_quaternion_v2.py`）

段階 1 の四元数 q＝e^(iπv/N)·r₁·e^(jπw/N) から、段階 1 の復号（`make_initial_quaternion_v1.py`、段階 1 とバイト同一）で v, w, r₁ を読み、次の 2 種類を作る。辺表は段階 1 で値から読んだもの。

- **main**：q ＝ e^(iφ0) · i^v · r · j^w、 r ＝ r₁·(−1)^⌊(v+w)/2⌋。j を i に潰すと走行 1 の床 Z0 になる（ずれ ≤ 3.9e-16、`results_main/log_states.txt`）。成分のエネルギー比は 1, i, j, k で各 0.25（N 奇数で 0.36/0.25/0.25/0.14 など）。|Σq²|/H は 0.29〜0.50（走行 1 の床の |Σz²| は 0）。
- **control**：q ＝ Re Z0 ＋ i·Im Z0（走行 1 の床を 1–i 面に置く。j, k 成分 0）。

## 走行系（`run_quaternion_sweep_v1.py`）

走行 1 の `run_sweep_from_parents_v1.py` を土台に、one_step と読出しを変えた。A の作り方（関数 adjacency）は走行 1 と同一。

```
u_e = q_e/|q_e|,  R_ef = ū_e u_f（四元数の積）
K^(c)_ef = A_ef · (R_ef の c 成分),  c = i, j, k   （実反対称、対角 0）
Q ← exp(Δτ K^(k)) · exp(Δτ K^(j)) · exp(Δτ K^(i)) · Q   （同じ実直交行列を 4 列 1, i, j, k すべてに掛ける）
```

- exp の計算は走行 1 の one_step と同じ式（H＝iK を eigh、V·diag(e^(−iΔτw))·V^H）を、複素列 a＋ib と c＋id に掛ける。K がすべて 0 の回転は飛ばす（恒等写像）。
- 状態が 1–i 面にあるとき K^(i) は走行 1 の K と一致し、K^(j)＝K^(k)＝0 なので、走行 1 と同じ一歩になる。
- **選択として固定したもの：** K は一歩の初めの状態から一度だけ読む。回転の順序は i → j → k。
- 読出し：Π＝初期状態の 4 列が張る部分空間（SVD、相対 1e-10 で階数を切る。main は階数 4、control は 2）。Hperp_frac ＝ ‖Q − P_Π Q‖²/‖Q‖²。成分ごとの f_1, f_i, f_j, f_k（和が Hperp_frac）。global_closure ＝ |Σq_e²|/‖Q‖²。

N ∈ {3,4,5,6,8,10,12,15,20,25} × den ∈ {N, 124} × 500 step。所要 741 秒（control と main の合計）。
