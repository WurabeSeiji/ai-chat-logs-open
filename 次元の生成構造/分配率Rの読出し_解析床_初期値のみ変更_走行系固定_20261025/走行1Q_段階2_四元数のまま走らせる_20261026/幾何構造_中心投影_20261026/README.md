# 四元数の中心投影 ― 幾何構造の図（2026-10-26）

`index.html` をブラウザで開く（Plotly 2.34.0 を cdnjs から読む）。走行データではなく、構造そのものを描く。

## 写像
単位四元数 q ＝ cos θ ＋ n sin θ（n は純虚の単位四元数）を、球の中心から、1 で接する 3 次元空間へ投影する。

```
q ↦ n · tan θ        成分では (x, y, z) = (b, c, d) / a
```

- q と −q は同じ点（符号は見えない）。10/18 の四元数論文の q ＝ ±e^(πn/4) の ± に当たる。
- 大円は直線に写る。左右の掛け算の軌道が直線になる。
- θ ＝ π/4 は単位球面（ホライズン）。e^(±πn/4) ↦ ±n。
- θ ＝ π/2（純虚）は無限遠。箱の縁に向きだけ描く。

## 鞍面
段階 1 の符号化 q ＝ e^(iπv/N) · r · e^(jπw/N) は、全部が次の鞍面に乗る。

```
x = tan(πv/N),  y = tan(πw/N),  z = x · y
```

成分で書くと ad ＝ bc の面（k 成分は従属）。鞍面は二重線織面で、
- 始点 v を固定した母線 x＝一定 … 右から e^(jψ) を掛けた軌道（青）
- 終点 w を固定した母線 y＝一定 … 左から e^(iφ) を掛けた軌道（橙）
- 関係 (v, w) ＝ 二本の母線の交点（黒）
- 自己対 (v, v) ＝ 放物線 z ＝ x² の上（赤）
- 転置 (w, v) ＝ 面 x ＝ y での鏡映

頂点を共有する二つの関係は同じ母線の上にある。三角の反対辺は共通の母線を持たない。

走行 1 の床（四分回転 i^v·r·j^w）は、この画面の N＝2 に当たる。v, w の偶奇で、原点／i 軸の無限遠／j 軸の無限遠／k 軸の無限遠の 4 点に写る。

## 操作
N（2〜12）、表示範囲（±2, 4, 8）、各要素の表示切替（ホライズン、鞍面、母線、関係、自己対、鞍面の外の大円の例＝q₀ に左から e^(kφ) を掛けた軌道）。マウスで回転。

## 追加：球面投影一枚と符号の読み（`central_projection_simple.html`、2026-10-26 夜）

上の鞍面の図を、論文「中心投影による 4 次元空間の幾何学的定式化」定義 2.1 の構成そのものに書き直したもの。曲面は球面 S²(R) 一枚だけ。
- 投影中心 O ＝ 原点、接超平面 Π_R ＝ 面 Y³ ＝ R（R ＝ 1）、主観座標 (x¹, x²) は接平面の上。l² ＝ R² ＋ |x|²、Y ＝ (R x¹/l, R x²/l, R²/l)。接平面の直線は大円に写る。
- 読み：誘導計量 g ＝ R²[(R² ＋ |x|²)|dx|² − (x·dx)²]/(R² ＋ |x|²)²、曲率 ＋1/R²。R² を −R² と読めば同じ式で曲率 −1/R²。切替で変わるのは注記と破線の円の意味だけで、点・直線・投影線は動かない。符号を逆に読んだときは、円 |x| ＝ R（球面上の θ ＝ π/4 の緯線、ホライズン）が到達できない境界＝光円錐。
- 格子：関係 (v, w) を x¹ ＝ tan(πv/N)、x² ＝ tan(πw/N) に置く。始点を固定した線（青）、終点を固定した線（橙）、自己対は対角線（赤）。濃い点は球面上の像。四元数の第 3 座標 z ＝ x¹x² は従属量なので落としている。
- 画面の記録：`fig_simple_N4_{plus,minus}.png`。
- `central_projection_two_readings.html` と `fig_two_readings_*.png` は、擬球面（一葉双曲面）をもう一枚描いた版。符号は読みであって別の曲面は要らない、という木原氏の指摘で置き換えた（記録として残す）。
