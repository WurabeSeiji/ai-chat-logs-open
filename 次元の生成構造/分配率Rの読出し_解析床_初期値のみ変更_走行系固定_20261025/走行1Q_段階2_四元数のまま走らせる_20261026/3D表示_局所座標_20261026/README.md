同じフォルダ階層の `3D表示_立体射影_20261026/`（立体射影版）を置き換えるもの。

## 操作
- **N・den**：N ∈ {3,4,5,6,8,10,12,15,20,25}、den は N か 124。
- **スライダー**：step 0〜500。
- **−1／+1**：1 歩戻る／進む（0 の前は 500、500 の次は 0）。
- **Auto**：60 ms ごとに +1、500 の次は 0 に戻る。もう一度押すと止まる。
- マウスで視点を回せる（N・den を替えても視点は保つ）。

## 表示の定義
四元数を極形式 q ＝ |q| e^(θn) で読む。
- 位置：局所 3 次元座標 θn。θ ＝ atan2(|(b,c,d)|, a) ∈ [0, π]（1 からの角度）、n ＝ (b,c,d)/|(b,c,d)|（虚軸の単位ベクトル）。軸は i, j, k の向き。原点が 1、半径 π の球面全体が −1（同じ一点）。
- 大きさ：振幅 |q|（その走行の全歩での最大に対する比）。
- 色：初期状態で 1–i 面にいた関係（終点 w が偶数）＝青、j–k 面にいた関係（w が奇数）＝橙。
- n が決まらない点（(b,c,d) がほぼ 0）：q ≈ +|q| は原点、q ≈ −|q| は (π, 0, 0)。該当するのは全走行で初期状態（step 0）の点だけ（`data/index.json` の undefined_at_step0）。

## 初期の二つの面の写り方
- 1–i 面の点 ±e^(iθ) は n ＝ ±i なので、i 軸上の線分（−π〜π）に乗る。初期値は 1→原点、±i→(±π/2, 0, 0)、−1→(π, 0, 0)。
- j–k 面の点は実部 0 なので θ ＝ π/2、n が j–k 面内で回る。半径 π/2 の j–k 面内の円に乗る。初期値は ±j→(0, ±π/2, 0)、±k→(0, 0, ±π/2)。
