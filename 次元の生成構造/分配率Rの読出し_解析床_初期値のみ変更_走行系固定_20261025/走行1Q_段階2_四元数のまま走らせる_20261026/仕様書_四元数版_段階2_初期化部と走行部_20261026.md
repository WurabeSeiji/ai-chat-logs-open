## 1. 記号

- 頂点：0, 1, …, N−1。
- 関係（状態の添字）：e ＝ (v, w)。v＝始点、w＝終点。全順序対で M ＝ N²。
- 四元数：q ＝ a ＋ b i ＋ c j ＋ d k。配列では `[a, b, c, d]`。
- 積の規則：i² ＝ j² ＝ k² ＝ −1、ij ＝ k、jk ＝ i、ki ＝ j、ji ＝ −k。
- 共役：q̄ ＝ a − b i − c j − d k。
- 二乗：q² ＝ (a² − |v⃗|²) ＋ 2a·v⃗。v⃗ ＝ (b, c, d)。
- 刻み：Δτ ＝ 2π/den。den ∈ {N, 124}。

## 3. 初期化部

### 3.1 段階 1：符号化（`encode`、46〜55 行）

入力は走行 1 の床 npz の Z0, ea, eb。

```python
  47      p = (ea + eb) % 2
  48      m = int(np.argmax(np.abs(Z0)))
  49      phi0 = float(np.angle(Z0[m]) - 0.5*math.pi*p[m])
  50      w = Z0 * np.exp(-1j*phi0) * (1j)**(-p)
  51      r = w.real
  54      Q = qmul(qmul(exp_i(math.pi*ea/N), rq), exp_j(math.pi*eb/N))
```

数式：

```
p_e = (v + w) mod 2                 偶奇
Z0_e = e^{iφ0} · r_e · i^{p_e}      床の書き方（r_e は符号つき実数）
q_e = e^{iπv/N} · r_e · e^{jπw/N}   段階1の四元数
```

- φ0 は全体位相 1 個。最大振幅の関係から決める（48〜49 行）。
- 50〜51 行で r_e を取り出す。虚部の残りが丸めの範囲であることを検査する（52 行）。走行 1 の全 N で 1.2e-14 以下だった。
- 一周 2π は 2N 目盛り。頂点 v は半周 π を N 等分した v 番目。r_e の符号が残りの半周（e^{iπ} ＝ −1）。

### 3.2 段階 1：復号（`decode`、58〜74 行）

配列の添字 e も、e ＝ v·N ＋ w の規則も使わない。q の四成分と N、φ0 だけを使う。

```python
  58  def _angle_mod_pi(x1, y1, x2, y2):
  60      ang = np.where(n1 >= n2, np.arctan2(y1, x1), np.arctan2(y2, x2))
  61      return np.mod(ang, math.pi)
  66      alpha = _angle_mod_pi(a, b, c, d)
  67      beta  = _angle_mod_pi(a, c, b, d)
  68      v = np.mod(np.rint(alpha*N/math.pi).astype(np.int64), N)
  69      w = np.mod(np.rint(beta*N/math.pi).astype(np.int64), N)
  70      core = qmul(qmul(exp_i(-math.pi*v/N), Q), exp_j(-math.pi*w/N))
  71      r = core[:, 0]
```

q ＝ e^{iα} r e^{jβ} を成分で書くと：

```
a = r cosα cosβ     b = r sinα cosβ
c = r cosα sinβ     d = r sinα sinβ
```

ここから：

```
(a, b) = r cosβ · (cosα, sinα)   → α = atan2(b, a) mod π
(c, d) = r sinβ · (cosα, sinα)   → α = atan2(d, c) mod π
(a, c) = r cosα · (cosβ, sinβ)   → β = atan2(c, a) mod π
(b, d) = r sinα · (cosβ, sinβ)   → β = atan2(d, b) mod π
v = round(αN/π) mod N,   w = round(βN/π) mod N
r = Re( e^{−iπv/N} · q · e^{−jπw/N} )
```

- 二組のうちノルムの大きい方を使う（60 行）。cosβ ＝ 0 などで片方が消えても読める。
- mod π にするのは、r の符号と半周のずれが区別できないため。頂点は 0..N−1 の半周に乗るので衝突しない。
- k 成分は ad ＝ bc で他の三つから決まる従属成分。

### 3.3 段階 2：本走行の初期状態（`make_state_quaternion_v2.py` 29〜33 行）

- 頂点の名前（π/N 刻み）は段階 1 で辺表を読むためだけに使う。走らせる状態は四分回転（π/2 刻み）。
- r の符号の付け替え（31 行）は、j を i に潰したときに走行 1 の床と一致させるため。

潰す検査（34〜35 行）：


```
j → i で  a + b i + c j + d k  →  (a + b i) + i (c + d i)
```

### 3.5 初期状態の検査値（38〜43 行）

```
|Σ q_e²| / Σ|q_e|²           sqsum：二乗和の大きさ（R² に当たる）
Σ_e (成分 c)² / Σ|q_e|²       Em：成分ごとのエネルギー比
```

| | 対照 | 本走行 |
|---|---|---|
| \|Σq²\|/H | 1e-15 程度（0） | 0.29〜0.50 |
| 成分比 1, i, j, k | 1–i 面だけ | N 偶数で 0.25 ずつ |

本走行の 0.5 は次の式で出る。

```
Re Σq² = Σa² − Σb² − Σc² − Σd²
       = (Σa² − Σb²) − (Σc² + Σd²)
       = 0 − 0.5H
```

一つ目の括弧は複素数の閉塞 Σz² ＝ 0 から 0。二つ目は j, k 成分のエネルギー。

### 4.3 一歩（`one_step_q`、41〜52 行）

```python
  42      U = Q / np.linalg.norm(Q, axis=1)[:, None]
  43      Ubar = U * np.array([1.0, -1.0, -1.0, -1.0])
  44      R = qmul(Ubar[:, None, :], U[None, :, :])
  46      for c in (1, 2, 3):
  47          K = A * R[:, :, c]; np.fill_diagonal(K, 0.0); Ks.append(K)
  48      z1 = Q[:,0] + 1j*Q[:,1]; z2 = Q[:,2] + 1j*Q[:,3]
  49      for K in Ks:
  50          if np.any(K != 0.0):
  51              z1, z2 = rotate(K, (z1, z2), den)
  52      return np.stack([z1.real, z1.imag, z2.real, z2.imag], axis=1)
```

数式：

```
u_e = q_e / |q_e|                          (42)
R_ef = ū_e · u_f                           (43〜44)
K⁽ⁱ⁾_ef = A_ef · (R_ef の i 成分)          (46〜47)
K⁽ʲ⁾_ef = A_ef · (R_ef の j 成分)
K⁽ᵏ⁾_ef = A_ef · (R_ef の k 成分)
Q ← exp(ΔτK⁽ᵏ⁾) · exp(ΔτK⁽ʲ⁾) · exp(ΔτK⁽ⁱ⁾) · Q   (49〜51)
```

- **K は実反対称。** ū_f u_e ＝ conj(ū_e u_f) なので虚部の三成分は符号が反転する。対角は 0。
- **回転は関係の添字に掛かる。** 同じ実直交行列を、四つの列 1, i, j, k すべてに掛ける。成分どうしは混ぜない。
- **計算の仕方。** 列を複素数二本 z₁ ＝ a＋ib、z₂ ＝ c＋id にまとめて掛ける（48 行）。実直交行列は実部と虚部を別々に回すので、これは四列に掛けるのと同じ。
- **K がすべて 0 なら回転を飛ばす**（50 行）。恒等写像なので結果は同じ。

### 4.4 回転の計算（`rotate`、35〜38 行）

```python

  37      w, V = np.linalg.eigh(H); phase = np.exp(-1j*np.float64(2.0*math.pi/den)*w)
```

### 4.5 走行 1 に戻る場合

状態が 1–i 面にある（c ＝ d ＝ 0）とき、u_e ＝ e^{iθ_e} なので：

```
ū_e u_f = e^{i(θ_f − θ_e)}
K⁽ⁱ⁾_ef = A_ef sin(θ_f − θ_e)   ＝ 走行1の K
K⁽ʲ⁾ = K⁽ᵏ⁾ = 0                 → 回転を飛ばす
```

実直交回転は c, d 列を 0 のまま保つので、この状態はずっと 1–i 面にある。対照の走行はこの場合で、走行 1 と一致した。

### 4.6 保存量（式から出るもの）

各歩の写像は、四列すべてに同じ実直交行列を掛けるだけ。したがって四列のグラム行列 G ＝ QᵀQ（4×4）が厳密に保存する。

```
H = Σ|q_e|² = tr G                         保存
Σq_e² = (G₁₁ − G_ii − G_jj − G_kk)
        + 2(G₁ᵢ i + G₁ⱼ j + G₁ₖ k)          保存
```

二乗和 Σq² はグラム行列で書けるので、R² ＝ Σq² は初期値で決まり、走行中は動かない。本走行で |Σq²|/H が初期値のまま動かなかったのはこのため。

## 5. 選択として固定した点

決めないと作れないので決めた。物理の主張ではない。

1. **K は一歩の初めに一度だけ読む。** 三つの回転の途中で読み直さない。
2. **回転の順序は i → j → k。** 四元数は非可換なので順序で結果が変わり得る。
3. **走らせる状態は四分回転 i^v r j^w。** j を i に潰すと走行 1 の床になる。頂点の名前（π/N 刻み）は辺表を読むためだけに使う。
