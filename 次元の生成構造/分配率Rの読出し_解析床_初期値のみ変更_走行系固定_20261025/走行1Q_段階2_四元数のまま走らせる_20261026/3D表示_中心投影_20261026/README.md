# 段階 2 本走行の 3D 表示（複素図形式、中心投影、2026-10-26）

`index.html` をブラウザで開く（ローカルのファイルのまま動く。Plotly 2.34.0 を cdnjs から読むのでネット接続が要る）。
`3D表示_立体射影_20261026/`（立体射影）と `3D表示_局所座標_20261026/`（θn）を置き換えるもの。

## 表示の定義（複素図と同じ考え方）
- **位置**：各関係の四元数 q ＝ a ＋ bi ＋ cj ＋ dk を、実軸 1 から接する局所 3 次元空間へ中心投影した座標 (b, c, d)/a に、振幅 |q| を掛けたもの。
  ```
  X = |q| · (b, c, d) / a
  ```
  複素図で原点からの長さが |z| であるのと同じく、振幅は位置に入っている。q と −q は同じ点なので、a ＜ 0 なら −q に置き換えてから計算する。
- **◯の大きさ**：同じ位置に乗っている関係の数（複素図の「×n」と同じ。2 個以上は数字も表示）。同じ位置の判定は、表示範囲の 10⁻⁹。
- **色**：初期状態で 1–i 面にいた関係（終点 w が偶数）＝青、j–k 面にいた関係（w が奇数）＝橙。
- **軸**：毎歩、全点が収まるように自動で決める（立方体、原点中心）。範囲の切り落としはしない。
- **無限遠**：|a| ≤ 10⁻¹⁴|q| の関係は実部が丸めの範囲で 0（純虚）とみなし、X ＝ ∞ として描かない。題に個数を出す。走行 1 の床の純虚の関係（N＝6 なら 36 個中 27 個）がこれに当たり、増幅が始まると数歩で有限の位置に現れる。
- **原点からの線**：各点へ原点から引く線（切替可）。

## 操作
N（3〜25 の 10 通り）、den（N か 124）、スライダー、−1／+1（0 の前は 500、500 の次は 0）、Auto（60 ms ごとに +1、500 の次は 0。もう一度押すと止まる）。マウスで視点を回せる。

## ファイル
- `make_3d_central_data_v1.py`：`../results_main/hm_N*_den_*_states_500.npz` と `../states_main/`（群の判定用）から `data/run_N{N}_den{den}.js` を作る。X を倍精度で計算して float32 で保存（1 点 3 値、無限遠は Infinity）。
- `data/index.json`：走行ごとの M、歩数、無限遠の個数（0 歩目と全歩）。
