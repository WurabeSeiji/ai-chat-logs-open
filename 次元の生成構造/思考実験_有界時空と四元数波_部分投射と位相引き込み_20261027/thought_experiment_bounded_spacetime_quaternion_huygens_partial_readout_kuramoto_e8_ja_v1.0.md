## 0. この思考実験で新たに見えたこと（要旨）

出発点は「複素数を一次元の定常波と読めるなら、四元数は何次元の定常波か」という問いであった。単位複素数が円周 S¹、単位四元数が球面 S³ だから、それぞれ一次元と三次元の定常波に対応する、という素朴な説明は誤りである。**代数の実次元、位相多様体の次元、物理空間の次元、定常波の伝播次元を同一視してはいけない。**

四元数の虚数基底 i,j,k が反交換することから、三方向の微分演算子 D=i∂x+j∂y+k∂z の二乗が -Δ₃ になる。この構成は三次元波動演算子との接点を示すが、x,y,z を導入した時点で三方向を仮定している。そこで木原は、波動方程式から三次元を「説明したことにする」のを退け、アインシュタインの原理的な理論構築に倣い、次の要請を出発点にした。

1. 時空は有界である。
2. ホイヘンス型の伝播条件と、自己整合した定常波の成立条件は等価である。
3. 時空は倍音を含む波で表現できる。
4. （第四の候補）時空には自らを計量して読み出せる内部ゲージがある。その成立構造は「ゆるい結晶」のように見える。

これらは単に既存の時空上で波を解く条件ではない。波の相互作用から距離・曲率・局在・ゲージが現れ、その幾何学が許される波を逆に変える、**未知の幾何学の自己整合問題**である。

次の転回が重要である。自己整合解は一意とは限らず、観測可能な複素数への読み出しは高位の構造の**部分投射**である。異なる完全状態は同じ読み出しに写り得るが、相互作用後には異なる読み出しとなり得る。そのとき、相互作用順序の区別、発展、因果的な秩序、不確定性、統計的に見える観測結果が、より高位の構造の読み出しの性質として現れる可能性がある。

確率を事象発生の物理的な乱数として仮定する必要はない。cos²θ は複素位相の二乗射影として自然に現れるし、位相比が簡単な整数比にロックしない場合、決定論的な反復でも長期の選択頻度は確率分布に見え得る。**「確率的に観測される」と「事象自体が確率的に発生する」は別である。**

最終目標は美しい三次元幾何を作ることではない。**複数の対称性が要求する近接したマジックナンバーが、互いの引き込み窓に入る一方、完全には一致・整合しないために準安定な振動や発展が続く**という構造から、微細構造定数のスケール依存、離散的な質量の非整数比、質量階層に接続することである。八元数・E8はこの選別を支える候補だが、まだ導出されたわけではない。

## 1. 原理として仮定すること／結果として求めること

### 1.1 第一原理：時空の有界性

> 時空は有界である。

現時点では「有界」の数学的意味は未確定である。コンパクト性、有限直径、有限情報量、有限の関係数、境界の有無、有限の内部計量可能範囲などは同義ではない。**既存の座標空間の中の有限箱を先に置くのではなく、最終的に読み出される時空に対する条件**として扱う。

### 1.2 第二原理：ホイヘンス伝播と定常波の等価性

> 許容される構造において、ホイヘンス型の伝播条件と非自明な閉鎖定常波の自己整合条件は等価である。

記号的に H ⇔ S と記す。ただし通常の波動理論の定理ではなく、**候補となる根源構造を選別するために置く強い仮説**である。すべての通常の有界領域で成り立つという主張ではない。特に、通常の二次元膜でも定常波は存在する一方、厳密なホイヘンスの原理は成立しない。曲率や反射による伝播の尾も無視できない。

H と S の定義は後に精密化が必要である。「一つの固有モードが存在する」より強い、全体の伝播・反射・閉鎖と整合した条件を想定するが、まだ定義を与えていない。

### 1.3 第三原理：倍音表現可能性

> 時空そのものは、倍音を含む波によって表現できる。

これは「すでにある時空の上で波を展開する」ことではない。複数倍音の位相関係・相互作用・閉鎖が、距離・局在・曲率・ゲージの読み出しを決める。倍音が通常の整数倍周波数を意味するのか、共通の内部位相に対する整数次数なのか、局所固有モードの共鳴系列なのかは分けて定義する必要がある。

### 1.4 第四原理の候補：自己計量と「ゆるい結晶」

> 時空の内部関係から、自身の計量と読み出しゲージが成立する。

反復可能な位相関係が物差しの役割を持ち、そこからの局所的なずれが、曲率・局在・準振動の候補となる。完全に硬い結晶を公理として与えるのではなく、**自己計量可能性を要請し、結晶的な秩序は解として出るかを問う**のが適切である。

この候補は第一〜第三原理と同格の確定した公理ではなく、検討中の要請である。

### 1.5 原理ではなく、結果として扱うもの

本研究で従来用いてきたゼロ閉塞 Σzₙ²=0、有限回帰 Uⁿ=I は、ここでは**最初の原因・公理に戻さない**。より根源的な自己無撞着性から現れる読み出し結果・存在条件の候補として扱う。安定性、位相ロック、マジックナンバー、三次元性、量子統計なども原則として導出対象である。

## 2. 四元数の幾何：二乗、計量、相互作用

四元数を q=a+bi+cj+dk=a+u と書く。u=bi+cj+dk は純虚部であり、i²=j²=k²=-1、ij=-ji=k 等を満たす。

### 2.1 自己二乗は共役ノルムと違う

```
q² = (a²-b²-c²-d²) + 2a(bi+cj+dk)
q q̄ = a²+b²+c²+d²
```

虚数三方向の混合交差項 bc(ij+ji) 等は反交換によって消える。純虚部 u だけなら u²=-|u|² となる。前者の実数部は符号数 (1,3) の二次形式を与えるが、これだけでローレンツ時空が生成したことにはならない。後者は正定値ノルムである。

### 2.2 二つの四元数の関係

q=a+u、p=b+v とすると、

```
qp=(ab-u·v)+(av+bu+u×v)
(qp-pq)/2 = u×v
Re(q p̄)=ab+u·v        （正定値の四次元内積）
Re(qp)=ab-u·v          （(1,3) 型の双線形形式）
```

共役相対積 r=q̄p には、内積成分と相対的な向き・面積の情報が入る。二つの四元数で四次元のすべての「外積」を普通の三次元ベクトルとして表すことはできない。交換子は純虚三方向間の外積であって、四次元全体のウェッジ積の六成分をすべて含むわけではない。

### 2.3 複素数と定常波の次元の混同を修正

複素数は実二次元、四元数は実四次元である。単位集合の S¹ と S³ の次元をそのまま「物理空間内の定常波の次元」と呼ぶのは論理の飛躍だった。

一方、

```
D₁=i∂x                   => D₁²=-∂x²
D₃=i∂x+j∂y+k∂z          => D₃²=-(∂x²+∂y²+∂z²)
```

は、四元数の反交換性から直接得られる。三方向の交差微分が相殺され、三次元ラプラシアンが出る。ただし、ここでは x,y,z という独立変数を初めから与えている。**この等式は三次元が必然的に生成する証明ではなく、四元数が三方向の波の演算子を自然に構成するという事実**にとどまる。

必要なのは「三次元の波が書ける」ことではなく、「有界性・伝播と閉鎖の等価性・倍音の自己整合性を同時に満たすとき、読み出される次元が選ばれる」ことである。

## 3. ホイヘンス伝播と定常波閉鎖――何を選別できるか

通常の自由波動方程式 ∂t²ψ=c²Δψ では、厳密なホイヘンス原理（伝播の後方に尾を残さない）は自由空間の奇数空間次元 3,5,7,... で成立する。二次元や四次元では一般に尾が残る。一次元は、通常の意味での厳密なホイヘンス原理とは区別すべきである。

一方、n 次元の球対称波の方程式は、

```
∂t²ψ=c²[∂r²ψ + (n-1)/r ∂rψ]
```

となる。u=r^((n-1)/2)ψ と置いたときの有効式には、(n-1)(n-3)/(4r²) に比例する項が現れ、任意形状の進行波を歪ませない特別な場合として n=1,3 が現れる。これは「厳密なホイヘンス原理が n=1 でも成立する」という命題とは別の条件である。

有限領域の定常波は、形状・境界条件・スペクトルの整合を要求する。しかし有限領域なら三次元に限らず固有波は一般に存在し、**有界性＋通常の定常波の存在だけで三次元を一意に選べない**。今回の第二原理 H⇔S は、その不足を補うための新たな強い選別条件として提案された。

さらに曲率のある系では波の伝播が変わり、境界の反射は閉鎖と再帰を生む。そのため、局所的な自由波のホイヘンス性と、大域的な有界系での閉鎖性の意味を混同してはならない。

## 4. 倍音は局在・曲率と自己循環する

三次元の箱を与えて固有波を求めるのではなく、倍音波 q 自身が幾何 g を定めると考える。

```
g = G[q]          （未定義の内部計量読み出し規則）
E_g[q] = 0        （g に依存する波の自己整合条件）
```

この連立系が「曲率を生む波」と「曲率によって変わる波」の循環である。アインシュタインの物質・エネルギーと時空の相互依存に似た問題だが、一般相対論の既存の計量構造も最初には置かない点が異なる。

最小の例として、内部位相 φ に対し実振幅 A,B を用いて

```
q(φ)=A exp(iφ) + B exp(2jφ)
|q(φ)|²=A²+B²+2AB cosφ cos(2φ)
       =A²+B²+AB(cosφ+cos3φ)
```

となる。最初の一次・二次の四元数位相項から、二次不変量に三次の調和成分が現れる。これは代数的事実。ただし、この三次項が実際に曲率を表すという主張は**まだ仮説**である。

幾何の変化が固有振動数を変えれば、さらに倍音がずれ、元の波に戻る。一般の有界領域の固有振動数は全てが整数比になるとは限らない。**厳密な倍音関係を要求するのか、近接した引き込み窓での準整合を許すのか**が、次の重大な分岐点となる。

## 5. 自己計量と「ゆるい結晶」

規格化された二つの四元数 qₐ,qᵦ に対して、

```
cos θₐᵦ = Re(q̄ₐ qᵦ)
```

とすれば、状態空間の相対角度を外部座標なしに記述できる。ただしこれはまず S³ 上の角距離であり、物理時空の間隔とはまだ同一でない。

三つの四元数から単純に作る相対積の閉路では、

```
(q̄ₐ qᵦ)(q̄ᵦ q𝒸)(q̄𝒸 qₐ)=1
```

が成立する。したがって、単純な相対積だけでは非自明な曲率ホロノミーを作れない。相互作用の結果として独立に構成される輸送操作 Uₐᵦ 等が必要な可能性がある。閉路 Uₐᵦ Uᵦ𝒸 U𝒸ₐ ≠ 1 なら非自明な位相輸送を表すが、それが幾何曲率に対応するかは未確定である。

「ゆるい結晶」の役割を暫定的に次のように分ける。

- **反復する相対位相・倍音比**：内部の相対的な物差しの候補。
- **局所的な位相不整合**：区別可能な位置・局在・歪みの候補。
- **閉路の輸送不整合**：曲率や捩率に対応し得る候補。
- **完全一致しない引き込み**：準安定性を保ちながら発展する仕組みの候補。

完全結晶を初めから仮定すると強すぎる。全く無秩序でも物差しが成立しない。秩序がありながら固定しきらない構造を、自己整合解として求める。

また、ゲージが単なる表示の冗長性なのか、観測不能だが相互作用後の読み出しを変える実在の自由度なのかを区別しなければならない。

## 6. 複素数は高位構造の部分投射として不完全になる

四元数 q=a+bi+cj+dk の i 平面への数学的投射を

```
Pᵢ(q)=a+bi
```

と定義する。観測される複素数 z=a+bi を固定したとき、

```
Pᵢ⁻¹(z)={z+cj+dk | c,d∈R}
```

には無限個の四元数がある。|q|=1 を課しても |z|<1 なら c²+d²=1-|z|² で円周の自由度が残る。

さらに

```
Pᵢ(j)=Pᵢ(k)=0
Pᵢ(jk)= i
Pᵢ(kj)=-i
```

なので、投射前に区別不能な成分が、非可換相互作用後には区別される。

```
Pᵢ(qp) ≠ Pᵢ(q)Pᵢ(p)    （一般に）
```

これは数学的事実。**複素数そのものが数学的に不完全なのではない。高位の四元数関係を複素数へ部分投射する表現が、相互作用に関して閉じていない**という意味で、本研究では「複素数の本質的な不完全性」を論じる。

ただし、外部の神の視点で Pᵢ を任意に選ぶことは最終理論として許さない。読み出し方向の選択も、相互作用する第三の観測波を含む関係から成立させる必要がある（従来の研究の観測＝相互作用の立場）。この Pᵢ は部分投射の非閉性を示す玩具モデルであり、観測機構の完成形ではない。

### 6.1 時間・因果が生まれる可能性

完全状態 Q の自己整合構造が部分投射 P により一意に読めないとする。異なる相互作用順序 UV, VU の後に P(UVQ) ≠ P(VUQ) となれば、内部の読み出しから順序差が現れる。これは、時間パラメータを先に置かずに発展の**順序構造**を得る候補となる。

しかし「順序が読める」だけでは、物理的な時間、因果円錐、無信号性、時間の向きは導けない。これらは追加で検証する。非可換性は必要な候補であって十分条件ではない。

### 6.2 不確定性が生まれる可能性

異なる局所読み出しゲージや相互作用が両立しない場合、複数の読み出しの同時確定可能性に制約が生じ得る。部分投射の多対一性だけでハイゼンベルク不確定性の数値的下限が出るわけではない。実際の下限には読み出し演算子・相互作用・分解能の定量的モデルが要る。

## 7. 確率を事象発生の公理にしない

この対話で特に強調された区別は、次の二つである。

> A. 事象自体が確率的に発生する。  
> B. 決定論的であっても、選択的な読み出し結果が確率分布に見える。

B から A を結論してはならない。「確率は観測と選択を記述する量であり、物理の根本の乱数法則とは限らない」というのが本研究の立場である。観測・選択の実装は物理的な相互作用である。

複素数 z=Ae^{iθ} の実軸射影について、

```
Re(z)=A cosθ
[Re(z)]²/|z|²=cos²θ
[Im(z)]²/|z|²=sin²θ
```

となる。cos² 自体は基本的な射影幾何であり、確率過程の導入を必要としない。二つの等振幅波の干渉でも |e^{iα}+e^{iβ}|²=4cos²[(α-β)/2] が得られる。

次に局所ゲージとの相対位相が

```
φₙ=(φ₀+nΔ) mod 2π
```

で変わり、Δ/(2π) が無理数なら、位相列は一様分布する。観測窓が円周全体の割合 w を占めれば、長期の観測頻度は w に近づく。**決定論的な無理回転だけで、窓選択の頻度を統計的に表現できる**。乱数の仮定は不要である。

ただし、w=cos²θ という窓を置けば cos²θ の頻度が出るのは当然である。これは「量子的な選択頻度を自動的に導出した」という証明ではない。射影二乗と実際の選択窓・測定頻度の一致を物理的読み出し規則から示す必要がある。無理回転はランダム列ではなく、より精密な時系列相関では区別できる場合がある。またベル相関を説明するには、局所的な古典的隠れ変数だけでは不足するという制約を踏まえる。

## 8. 蔵本理論：完全一致ではなく「近いが一致しない」ことが鍵

本思考実験の最後で木原が明確に修正した点は、**安定解を完全な位相ロックと同一視してはいけない**ということである。

異なる対称性は、それぞれ固有周期・無次元数・望ましい位相差を要求する。要求値が近いほど相互引き込みが働く。しかし**それらが完全に一致・整合してしまうと、相対位相から読める発展・準振動の自由度が消え得る**。近接しているのに完全には同期できない構造が、長寿命の準安定性、位相スリップ、準周期性を生むのではないか、という予想である。

### 8.1 二振動子の最小模型

位相差 ψ、固有周波数差 Δω、有効結合 K に対する Adler 型方程式を、数学的パラメータ s を使って

```
dψ/ds=Δω-K sinψ
```

と書く。|Δω|<K なら静的な位相ロックが可能で、|Δω|>K なら位相スリップが続く。後者では平均スリップ速度は、K の定義を上式としたとき

```
Ω_slip = sqrt[(Δω)²-K²]
```

であり、引き込み境界の近くでは極端に遅くなる。ここでの s は計算・更新のパラメータであって、導出した物理的な時間ではない。

### 8.2 三つ以上の対称性の競合

互いに望ましい位相差 δ₁₂,δ₂₃,δ₃₁ を持つ三者の閉路では、すべてを厳密に満たすなら

```
δ₁₂+δ₂₃+δ₃₁ ≡ 0  (mod 2π)
```

が必要である。合計にずれ ε があれば、すべての要求を同時に厳密には満たせない。これは位相フラストレーションの候補である。

**注意：** フラストレーションがあっても、妥協した静止解に落ち着くことはある。周波数が違っていても結合が強ければ位相ロックは可能である。「近いが異なる」だけで永続準振動が保証されるわけではない。非完全同期の持続解が存在する条件と、その安定性を実際に証明・計算する必要がある。

### 8.3 四元数・内部ゲージとの関係

蔵本模型の位相は通常 S¹ の角である。四元数の単位位相は S³ / SU(2) に属し、異なる虚数軸の回転は非可換である。従って四元数の引き込みを単に独立な三つの通常角度と同一視してはならない。最初に複素平面上の最小模型で現象を確かめ、次に四元数の非可換な結合作用へ移す。

## 9. マジックナンバー、八元数、E8、微細構造定数、質量階層

### 9.1 狙い：幾何学で終わらず、数値を予測する

三次元性・曲率・因果だけを説明しても、微細構造定数 α、質量階層、粒子の離散的な存在条件、寿命の違いに接続できなければ、物理理論としての到達点は不十分である。

狙いは、複数の対称性が**近接するが一致しない**特性値を要求するため、引き込み窓・準同期・スリップによって有効な観測値が選ばれるという機構である。整数比の固有値が最終的な観測質量比に直接現れる必要はない。格子の固有ベクトル、幾何投射、相互作用固有値の比は一般に無理数となり得る。

### 9.2 既知の数学との接点

- ノルムの乗法性 N(xy)=N(x)N(y) を持つ有限次元実ノルム付き可除代数は、適切な仮定のもと R,C,H,O に分類される（Hurwitz）。したがって八元数は有力候補だが、今回の原理だけから現れたわけではない。
- 単位四元数の構造やイコシアンを通じて E8 格子に至る既知の構成がある。八元数からも E8 格子に関係する構成があるが、「八元数＝E8 対称性」ではない。八元数の自己同型群は G₂ である。
- 八次元正定値の偶・ユニモジュラー格子は E8 に一意に対応する。ただし**八次元、偶性、整数性、自己双対性**を今回の自己整合要請から導かなければ、E8 の導出にはならない。
- E8 の根の数240、リー代数次元248、コクセター数30、指数 1,7,11,13,17,19,23,29 は既知の数学的な数である。これらの数だけから微細構造定数を決めたことにはならない。
- E8 と関連する二次元可積分模型では、励起の質量比に 2cos(π/5)=黄金比のような無理数が現れる。しかし標準模型の素粒子質量を説明したわけではない。

### 9.3 既往の「三つの137」「23/124」との接続

過去の検討には、四次元の稠密配置に関連する 137 近傍の値、23/124 に関係する回帰安定性、さらに別の対称性からの拘束という候補がある。**23/124 自体を 1/137 と同一視しない。** それぞれ異なる構造に由来する拘束として働くかもしれず、それらの不一致が準安定な引き込みを生むというのが今回の予想である。

最も避けるべきなのは、既知の観測値に厳密一致するよう選んだ数字を、後から基本構造の証拠とすることである。むしろ**一致しないことが構造的に必要か**を確かめる。

### 9.4 微細構造定数のエネルギー依存性

実際に α は測定エネルギーに依存し、低エネルギー極限の 1/α ≈137.036 と電弱スケールの有効値は異なる。既存の量子電磁力学では真空偏極と繰り込み群によって定量的に説明される。今回の仮説では、この変化を「異なる読み出し分解能で準同期した構造を読むため」と再解釈できる可能性がある。

例えば

```
α_read(μ) = R_μ[相互引き込み中の内部位相関係]
```

という形式を考える。ただし関数 R_μ は未定義。標準理論の α(μ) を**数値精度・スケール依存性・測定可能量の定義まで**再現しなければ、仮説の裏づけにはならない。単なる時間的な位相スリップとエネルギー依存の繰り込み群を混同してはならない。

## 10. 今回の対話での転換点（重要な修正の順序）

1. **S¹ と S³ の次元を定常波の物理次元と同一視した誤りを修正。** 複素数が一次元定常波を表せること自体、なぜなのかを問うた。
2. **四元数の反交換と D²=-Δ₃ の関係を確認。** ただし三方向の座標導入で循環しているので、これを三次元の証明とはしない。
3. **有界性とホイヘンス伝播条件の強い等価性を原理として置く。** 定常波が解ける既存の空間を仮定してはいけない。
4. **倍音を含む波として時空を表現する原理を追加。** 曲率と局在が波を変え、波が曲率を変える循環へ進む。
5. **自らを計量できる局所ゲージ／ゆるい結晶という第四原理候補を追加。** 完全な固定結晶を最終解として仮定しない。
6. **全体解の一意性を要請しない。** 高位解の多数性と部分投射こそが、発展や因果の読み出しに関係し得る。
7. **確率発生と確率的観測を区別。** cos² は複素位相の二乗射影、無理数比の位相進行は決定論的でも長期頻度を生む。乱数は原理に不要。
8. **E8 やマジックナンバーを一つの観測値に完全一致させる方向を否定。** 蔵本型の相互引き込みで、近いが一致しない対称性拘束が、準安定構造と発展を生むという見方へ変更。
9. **物理への接続先を明確化。** 三次元の存在だけでなく、αのエネルギー依存、離散質量の非整数比、質量階層を説明することが最終目標。

## 11. 現段階での数学的な課題（研究課題を混同しない）

### 11.1 定義すべき対象

- **根源的な状態：** 最初から時空座標を与えない四元数・複数関係波。必要なら八元数に一般化するが、最初から決め打ちしない。
- **相互作用：** 他の波との関係により読み出しが成立する操作。観測波の関与を無視しない。
- **内部の位相更新：** 計算の反復パラメータと、後に読み出される物理的時間を混同しない。
- **自己計量：** 内部から距離、分解能、曲率、局所ゲージを取り出す規則。外部座標の持ち込みを禁止する。
- **閉鎖性：** 有界性、伝播、反射、定常性、準定常性、有限／近似回帰の関係を定義する。
- **倍音：** 整数次数と非整数周波数比、引き込み窓、準同期の関係を明確にする。

### 11.2 証明・実験すべき命題

**命題 A（存在）**：空間と時間の座標を前提にせず、第一〜第三原理および自己計量条件に整合する非自明な有限／有界構造が存在するか。

**命題 B（次元選別）**：同じ定義で一次元・二次元・三次元・より高次元の候補を比較したとき、三次元（または三つの可読方向）が選別されるか。事後的に三軸を入れた式では証明にならない。

**命題 C（非完全同期の持続）**：競合する位相拘束と近接した固有周期から、外部乱数なしで、静止しきらず散逸もしない準安定振動・位相スリップが存在するか。

**命題 D（部分投射と因果）**：非可換な相互作用と選択的読み出しから、相互作用の順序だけでなく物理的な因果円錐・局所性・無信号性に相当する条件が現れるか。

**命題 E（読出し統計）**：有限解像度と局所ゲージの読み出しから、単なる cos² の代数形ではなく、具体的な測定選択頻度・不確定性の下限・ベル／CHSH相関まで整合できるか。

**命題 F（数値の予言）**：候補対称性を外から選ばなくても、魔法数と非整数の固有値比が選ばれるか。α(μ) の既知の走りと、少なくとも一組の質量比を追加の当てはめなしに再現できるか。

**命題 G（E8への必然性）**：八元数・E8 格子が本当に必要か。もしそうなら、八次元・離散性・偶性・自己双対性などの仮定を現行の公理から導けるか。それ以外の構造が排除されるか。

### 11.3 最小の検証系列（提案）

1. 四元数相互作用の**無座標・無名の関係系**を定義し、外部から空間軸や物差しを初期化しない。
2. 内部の観測波を含めた読み出しを定義し、単純な Pᵢ の例との違いを記録する。
3. 倍音と反交換の最小系から、二次・三次の相互作用に伴う位相閉鎖条件を列挙する。
4. 独立な二つ、三つ、複数の競合する位相拘束について、静的ロック・引き込み窓・位相スリップ・散逸の領域を区別して求める。
5. 得られた関係系から計量・可読次元・固有値数え上げを読み、標準的なスペクトル次元の基準と比較する。
6. マジックナンバー候補（既往の137近傍系列、23/124、E8の指数等）を**事後調整なしの予測**として照合し、偽陽性対照を置く。
7. 最後に観測量 α(μ)、質量比、干渉やCHSH相関への接続を評価する。

## 13. 結論：ここで発見された研究問題

**問題の核心は、完全な解と観測される時空を一対一に対応させることではない。**

有界で、倍音を含み、ホイヘンス型の伝播と閉鎖が同じ自己整合条件として働く構造が、自己計量可能な局所ゲージを生む。その**全体解の多数性と部分投射の非閉性**が、観測される発展・因果・不確定性・選択頻度に関係する。そして複数の対称性が要求する値が近接しながらも完全には一致しないために、蔵本型の引き込みと位相スリップが続き、準安定な物理構造やスケール依存する観測値が現れる可能性がある。

**完全に一致することを成功とみなさない。むしろ、矛盾せず存在し続けられる程度には引き込み合い、それでも完全にはロックできないことを条件として問う。**

この構造から八元数・E8 的なマジックナンバーと、離散的なのに簡単な整数比にならない質量階層、微細構造定数のエネルギー依存性が導けるか。ここが幾何学と物理をつなぐ最重要課題である。

本思考実験は**証明済みの理論ではなく、何を原理として置き、何を導くべきかを整理した発見記録**である。最初に答えである「三次元」「E8」「137」「完全な位相ロック」を仮定しないことが、その研究方法の核心である。
