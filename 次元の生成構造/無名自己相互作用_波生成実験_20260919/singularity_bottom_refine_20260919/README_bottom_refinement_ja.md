# 0.808076近傍・特異点候補の底の多段細密スイープ（2026-09-19）

## 固定した更新則

初期値は実数1波 `z1 = r`。各世代で、現在存在する N 波すべてについて自己相互作用を含む全順序対 `(i,j)` を文字どおり二重ループし、

`T_ij = (conj(z_i) * z_j) * z_j`

を計算する。全項の総和の符号を反転し、新しい1波として追加する。

`z_(N+1) = - sum_i sum_j T_ij`

古い波は残す。正規化・簡約式・外部時間刻み・指数写像は使用しない。

## 数値精度

前半は C `long double`（64-bit mantissa, `LDBL_DECIMAL_DIG=21`）。
より深い底の探索では GCC `__float128` / libquadmath（binary128, 約34桁）に切り替えた。

`__float128` 版でも相互作用の計算は同じ N^2 二重ループであり、解析的簡約はしていない。

## 多段スイープ

粗い 1e-8 から始め、1e-19 まで long double で縮小。その後 binary128 で 1e-21 から 1e-34 まで逐次縮小した。
深部では最終振幅が指数範囲下限へ近づくため、140世代で統一した深部系列 `quad_deep_140_best.csv` を作成した。

## 現在得られた数値的な底

binary128 の隣接表現値を ±30 ULP 走査した結果、140世代の `|z_140|` を最小にする表現値は

`r = 0.8080759710485481360243945032956635280658`

16進表現:

`0x1.9dbc2238ac85a32d2496e18fe34p-1`

この点で

`log10 |z_140| = -4.506501771917978609979330106648568800e+03`

後半40世代の平均対数減衰比は

`mean log10(|z_n|/|z_(n-1)|) = -3.362103402970013127969038611469230107e+01`

であった。

## 解釈上の注意

これは「数学的に特異点を証明した値」ではない。固定更新則を文字どおり数値実行し、有限世代の振幅を観測量としてスイープしたときの numerical bottom である。

ただし、刻みを 1e-8 → ... → 1e-34 と細かくするにつれて最小点が系統的に同一の桁列へ収束し、binary128 の隣接 ULP 走査でも単一の鋭い極小を形成した。したがって、少なくとも数値的には非常に強い特異点候補である。
