# 4点長時間走行テスト（2026-09-19）

更新則は全順序対を文字どおり計算した。

`T_ij = (conj(z_i) * z_j) * z_j`

`z_new = - sum_i sum_j T_ij`

自己相互作用 `i=j` を含み、既存波は保持する。4点はいずれも実軸初期値なので、long double 実数演算で同じ順序対和を逐次評価した。和の因数分解は行っていない。

## 結果

- 1/sqrt(2): 完了世代=3807, 最終 log10|z_new|=-1897.3390189107001, 第3世代以降の振幅増加回数=0
- 0.8081: 完了世代=3768, 最終 log10|z_new|=-4950.438278694171, 第3世代以降の振幅増加回数=0
- 0.8260: 完了世代=3742, 最終 log10|z_new|=-4351.122135011323, 第3世代以降の振幅増加回数=0
- 1.0000: 完了世代=2000, 最終 log10|z_new|=-inf, 第3世代以降の振幅増加回数=0

### 観測

- 1/sqrt(2): 第2世代以降は負符号のまま、少なくとも走行範囲では単調減衰。
- 0.8081: 第6世代以降はほぼ符号交互で急速減衰。long double の最小サブノーマル付近に到達すると数値床で見かけ上飽和する。
- 0.8260: 第5世代以降は符号交互で単調減衰。走行範囲では再増大なし。
- 1.0000: z2=-1, z3=0、その後2000世代まで厳密に0。

注意: 0.8081 の後半の「飽和」は long double の表現限界による数値床であり、物理的飽和とは解釈しない。
