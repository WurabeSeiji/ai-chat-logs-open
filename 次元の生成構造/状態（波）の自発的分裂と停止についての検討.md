# 状態（波）の自発的分裂と停止についての検討

## 1. 検討目的

本稿では、閉鎖位相系に存在する状態（波）が、

\[
A,B
\longrightarrow
A,B,C,D,E,\ldots
\]

と自発的に分裂していく機構と、その分裂が有限個の状態で停止し、安定する機構を分けて検討する。

扱う中心問題は、次の二つである。

1. 閉鎖を破らずに、一つまたは少数の状態から複数の状態が生じるのはなぜか。
2. 分裂可能な状態数が際限なく増えず、有限個の安定状態で停止するのはなぜか。

この二つは同じ問題ではない。分裂を可能にする写像が得られても、それだけでは停止条件は得られない。

## 2. 最小の非自明閉鎖

最小の非自明な閉鎖状態として、

\[
A^2+(iB)^2=0
\]

を考える。これは、

\[
A^2=B^2
\]

という二状態間の関係である。

この段階では、空間軸も観測時間もまだ導入されていない。存在するのは、状態の更新順序を区別する処理インデックス

\[
\tau=0,1,2,\ldots
\]

だけである可能性がある。ただし、この \(\tau\) を観測される時間と同一視することは、現段階では行わない。

また、\(A\) と \(B\) の二状態だけでは、系の外部から両者を比較する観測者も存在しない。したがって、この最小閉鎖は関係を持つことはできても、その関係が観測可能であることまでは意味しない。

## 3. 現在の線形更新では分裂しない

現在までに用いている固定生成子による線形更新では、状態ベクトルの成分数は更新前後で保存される。

したがって、初期状態が

\[
X=(A,B)
\]

であれば、線形更新だけから

\[
X'=(A',B',C')
\]

のように新しい成分 \(C'\) が生成されることはない。

よって、

\[
A,B
\longrightarrow
A,B,C,D,\ldots
\]

という自発的分裂には、閉鎖を保存しながら状態数を変化させる非線形写像、分岐則、または状態生成規則が必要である。

## 4. 分裂後にも要求される閉鎖

分裂前の保存量を

\[
\sum_n X_n^2=R^2
\]

と読むなら、分裂後にも同じ閉鎖が保たれなければならない。

例えば、

\[
A^2=R^2
\]

であった状態が三状態へ分裂する場合には、

\[
A'^2+B'^2+C'^2=R^2
\]

を満たす必要がある。

ここで起きるのは保存量の生成ではなく、同じ \(R^2\) の内部での状態成分への再配分である。

## 5. 倍音閉鎖という作業仮説

閉鎖系の内部で複数の状態が安定して共存するなら、それぞれの状態は、系のベース振動に対して無関係な周波数を持つのではなく、全体系の閉鎖と両立する必要がある。

その最も単純な候補は、各状態がベース振動数 \(\omega_0\) の整数倍音として存在することである。

\[
\omega_n=n\omega_0,
\qquad
n\in\mathbb Z\setminus\{0\}
\]

この場合、状態間の関係は連続的な任意値ではなく、閉じた周期を共有できる整数関係として選択される。

ただし、状態分裂によって倍音関係が必然的に選ばれることは、まだ導出されていない。本節は分裂後の安定条件に関する作業仮説である。

## 6. 分裂を生む候補機構

二波から多波が生じる既知の数理構造として、変調不安定性が候補になる。

非線形波動系では、搬送波と微小な摂動波の組合せが不安定化し、複数のモードまたは局在波へ分裂する場合がある。周期境界を持つ系では許容波数が離散化されるため、成長可能なモード数も整数として選択される。

これは、

\[
\text{少数波}
\longrightarrow
\text{複数の離散モード}
\]

という構造を与える。

しかし、変調不安定性を本閉鎖系へ適用できることは、まだ確認されていない。また、純粋な保存系では、分裂した状態が固定されず、分裂と再結合を繰り返すFPUT型再帰になる可能性がある。

したがって、変調不安定性は分裂開始の候補であり、停止機構そのものではない。

## 7. 停止機構の問題

閉鎖

\[
\sum_n X_n^2=R^2
\]

が複数成分への再配分だけを要求するなら、形式的にはさらに細かい状態への分裂を続けられる可能性がある。

したがって、分裂が可能であることよりも、なぜ有限個で停止するのかを説明する方が難しい。

現在の候補は次のとおりである。

- 閉鎖可能な整数倍音が有限個しか存在しない。
- 非線形相互作用によって、一定振幅以下のモードが成長できなくなる。
- 分裂後の状態が新しい安定閉鎖を形成し、それ以上の分裂に対して安定になる。
- 保存系では停止せず、分裂と再結合を繰り返す周期状態そのものを安定状態と読む。
- 保存量の一部が別の自由度へ移り、分裂可能な成分に残る量が閾値以下になる。

これらのうち、どの条件が本系から生じるかは未確定である。

## 8. 既存の \(\alpha\) 系との接続候補

以前の \(\alpha=137,128\) 系の検討では、低い \(R\) で限られた安定配置が現れる一方、\(R\) を大きくすると候補状態数と空隙が急激に増加する構造が見られた。

この結果は、ある閉鎖状態が安定して存在できる限界を超えたとき、より小さい複数の閉鎖状態へ分裂する可能性を示唆する。

ただし、現在得られているのは構造上の類似であり、\(\alpha\) 系の充填構造が状態分裂を実際に引き起こすことは未証明である。

## 9. N体関係波との接続

これまでのN体検討から、状態または関係波の数が増えても、それらすべてが新しい空間軸として読まれるわけではないことが分かっている。

したがって、

\[
\text{状態成分数の増加}
\]

と、

\[
\text{観測可能な空間次元数の増加}
\]

は区別しなければならない。

五体目以降の状態が生じても、それは第四、第五の空間軸になるのではなく、同じ三方向表示の内部で増える位相モードまたは関係モードとして読まれる可能性がある。

この区別により、多数の状態が生成されることと、観測可能な空間方向が三方向で飽和することは両立できる。

## 10. 現段階の分類

### 導出済みまたは確認済み

- 固定次元の線形更新だけでは、状態成分数は自発的に増えない。
- 分裂前後で同じ閉鎖を要求するなら、分裂は \(R^2\) の生成ではなく内部再配分である。
- 状態数または内部モード数の増加と、空間方向数の増加は同じではない。

### 作業仮説

- 分裂後の安定状態は、ベース振動に対する整数倍音として選択される。
- 変調不安定性に相当する非線形機構が、少数波から多波への分裂を開始する。
- 閉鎖可能性または安定可能性の閾値が、分裂の開始と停止を決める。
- 高い \(R\) で増える候補状態または空隙が、分裂不安定性に関係する。

### 未解決

- 状態数を増やしながら二乗閉鎖を厳密に保存する最小写像。
- 分裂が開始する臨界条件。
- 分裂数を決定する整数選択則。
- 固定多波状態と周期的な分裂・再結合を区別する安定性の定義。
- 分裂を有限個で停止させる内部機構。

## 11. 次の検討方針

次の理論および数値実験では、最初から粒子生成を仮定せず、次の二過程を独立に検査する。

\[
\boxed{
\text{閉鎖を保存する一モードから多モードへの自発的分岐}
}
\]

\[
\boxed{
\text{分岐を有限個の安定モードで停止させる選択条件}
}
\]

最初に必要なのは、最小二状態閉鎖に微小摂動を与えたとき、新しい成分が成長するかを判定できる非線形写像である。その後、分裂後の各成分について、二乗閉鎖、倍音関係、再帰性および安定性を個別に測定する。

## 12. 追加検討：左辺と右辺は分裂前に固定されていない

第4節では、閉鎖を

\[
\sum_n X_n^2=R^2
\]

と表示した。しかし、これは零二乗和

\[
\sum_n X_n^2=0,
\qquad
X_n\in\mathbb C
\]

を、実方向と虚数方向へ分けて書き直した表示である。

例えば、

\[
A^2+(iR)^2=0
\]

は、

\[
A^2=R^2
\]

と書ける。しかし、\(R\) が本来的に右辺に属する別種の存在になったわけではない。

\[
(iR)^2=-R^2
\]

なので、負に寄与する虚数成分を右辺へ移しただけである。

したがって、分裂して生じる娘波が、最初から左辺の観測波であるとは限らない。娘波が純虚数

\[
Y=iQ
\]

なら、

\[
Y^2=-Q^2
\]

となり、整理後の表示では右辺の保存・補償側に現れる。

左辺と右辺の区別は分裂以前の存在分類ではなく、複素成分を観測可能方向と観測不能方向へ分けた後に生じる表示上の区別である。

## 13. 複素二乗和を保存する分裂の厳密条件

親波 \(X_P\) が娘波 \(Y_1,\ldots,Y_m\) へ分裂する場合、全体系の零二乗和を保つための局所条件は、

\[
\boxed{
X_P^2=\sum_{k=1}^{m}Y_k^2
}
\]

である。

分裂前に、

\[
X_P^2+\sum_{n\ne P}X_n^2=0
\]

であれば、分裂後には、

\[
\sum_{k=1}^{m}Y_k^2+\sum_{n\ne P}X_n^2=0
\]

となり、全体閉鎖は変化しない。

親波と娘波を、

\[
X_P=a+ib,
\qquad
Y_k=a_k+ib_k
\]

と書くと、この条件は実部と虚部の二条件へ分かれる。

\[
\boxed{
\sum_k\left(a_k^2-b_k^2\right)=a^2-b^2
}
\]

\[
\boxed{
\sum_k2a_kb_k=2ab
}
\]

したがって、分裂写像は実二乗和だけでなく、複素二乗和の虚部まで同時に保存しなければならない。

## 14. 実方向への分裂と虚数方向への分裂

親波が純実数

\[
X_P=A
\]

である場合、娘波に対する条件は、

\[
\sum_k\left(a_k^2-b_k^2\right)=A^2,
\qquad
\sum_k a_kb_k=0
\]

となる。

### 14.1 娘波がすべて実方向へ生じる場合

\[
A^2=B^2+C^2
\]

なら、

\[
A^2+(iR)^2=0
\]

は、

\[
B^2+C^2+(iR)^2=0
\]

へ変わる。この場合、娘波 \(B,C\) は同じ実方向、すなわち整理後の左辺に現れる。

### 14.2 娘波に純虚数成分が含まれる場合

\[
A^2=B^2+(iQ)^2
\]

なら、

\[
A^2=B^2-Q^2
\]

であり、整理すると、

\[
B^2=A^2+Q^2
\]

となる。\(Q^2\) は右辺の保存・補償側に現れる。

この分裂では、観測可能な実方向の波が単に細分化されるのではない。実方向の成分と虚数方向の成分が同時に再構成される。

したがって、状態分裂は、

\[
\boxed{
\text{状態数の増加}
+
\text{観測側と保存・補償側の再配分}
}
\]

として扱う必要がある。

## 15. 厳密閉鎖部分系と保存配分の区別

「閉鎖モード」という語には二つの異なる意味が混在しうる。

成分集合 \(S\) が単独で、

\[
\sum_{k\in S}Y_k^2=0
\]

を満たすなら、それは厳密な閉鎖部分系である。

一方、固定生成子の平面分解で得られる各回転平面については、

\[
Q_j
=
\left(p_j^{\mathsf T}X\right)^2
+
\left(q_j^{\mathsf T}X\right)^2
=
\text{const.}
\]

が成立するが、一般には、

\[
Q_j\ne0
\]

である。

したがって、各回転平面は単独で零閉鎖する「閉鎖モード」ではなく、全体閉鎖に対する保存配分である。

全体の二乗閉鎖は、

\[
\sum_jQ_j+Q_{\ker}=R^2
\]

と分解できる。固定生成子のもとでは、各 \(Q_j\) と \(Q_{\ker}\) は個別に保存される。

このため、固定生成子動力学だけでは、

\[
Q_P
\longrightarrow
Q_1+Q_2+\cdots
\]

という平面間の保存配分移動は起こらない。

## 16. 分裂問題の再定義

以上から、本稿で探すべき分裂は、単なる実数二乗和の因数分解ではない。

\[
\boxed{
\text{一つの複素二乗寄与を、零二乗和を保つ複数の複素二乗寄与へ再配分する写像}
}
\]

である。

その写像には、次の条件が必要である。

1. 分裂前後で全体の零二乗和を厳密に保存する。
2. 実部条件と虚部条件を同時に保存する。
3. 固定生成子が個別保存している \(Q_j\) 間に配分移動を生じさせる。
4. 分裂後に生じた各成分について、実方向に読まれる成分と虚数方向に読まれる成分を、物理名ではなく関係構造から決める。
5. 分裂後の複数成分が、同じ全体閉鎖の中で持続できる更新則を持つ。

したがって、候補となる最小機構は、固定生成子ではなく、状態に依存して再構成される生成子、非線形な平面間結合、または分岐時に状態空間の成分数そのものを増やす写像である。

## 17. 追加後の分類

### 導出済みまたは確認済み

- 左辺と右辺は、複素二乗和を実方向と虚数方向へ分けた後の表示であり、本来的な成分分類ではない。
- 親波 \(X_P\) を娘波 \(Y_k\) で置換して閉鎖を保存する局所条件は、\(X_P^2=\sum_kY_k^2\) である。
- 複素分裂では、実部二乗差と実部・虚部交差項の二条件を同時に保存する必要がある。
- 固定生成子の各回転平面は一般には独立零閉鎖系ではなく、全体閉鎖に対する保存配分である。
- 固定生成子のもとでは各保存配分が個別に保存されるため、平面間再配分としての自発的分裂は起こらない。

### 新たな作業仮説

- 状態分裂は、実方向の観測成分だけを増やす過程ではなく、実方向と虚数方向を同時に再構成する過程である。
- 観測可能な波の生成と、保存・補償側の成分生成は、同じ複素分裂写像の異なる射影として生じる。

### 追加された未解決問題

- 分裂後の各娘波を、実方向または虚数方向として選択する関係条件。
- 保存配分 \(Q_j\) を平面間で移動させる最小非線形更新則。
- 成分数の増加と同時に複素二乗和を厳密保存する可逆写像の有無。
- 虚数方向へ移った配分が、次の分裂に利用可能な保存量として働く条件。
- 観測側の波数増加と、保存・補償側の自由度増加を区別して測定する方法。

## 18. 分裂による対称成分と反対称成分の生成

一つの親状態が二つの娘波へ分裂する最小の場合を、

\[
P\longrightarrow Y_1,Y_2
\]

とする。

この二つの娘波から、交換に対して対称な成分 \(S\) と反対称な成分 \(D\) を、

\[
S=\frac{Y_1+Y_2}{\sqrt{2}},
\qquad
D=\frac{Y_1-Y_2}{\sqrt{2}}
\]

と定義する。このとき、

\[
Y_1=\frac{S+D}{\sqrt{2}},
\qquad
Y_2=\frac{S-D}{\sqrt{2}}
\]

であり、厳密に、

\[
\boxed{
Y_1^2+Y_2^2=S^2+D^2
}
\]

が成立する。

これは動力学を仮定した式ではなく、二つの娘波を共通成分と相対成分へ分けた代数恒等式である。

分裂前には \(Y_1\) と \(Y_2\) の区別そのものが存在しない。分裂後にはじめて、二つに共通する対称成分 \(S\) と、二つの差を担う反対称成分 \(D\) が同時に生じる。

したがって、分裂とは観測可能な波の本数を増やすだけではなく、新しい相対成分を生成する操作でもある。

## 19. 反対称成分の虚数化と \(Q\) 軸

ここで、分裂によって生じた相対成分 \(D\) が、観測可能な空間方向としては読み出されず、観測不能な虚数方向として表示される場合を考える。

その最小の表現を、

\[
\boxed{D=iQ}
\]

と置く。

すると、前節の恒等式は、

\[
Y_1^2+Y_2^2
=S^2+(iQ)^2
=S^2-Q^2
\]

となる。

既存の閉鎖成分 \(iR\) を含む二乗閉鎖が、

\[
Y_1^2+Y_2^2+(iR)^2=0
\]

であるならば、

\[
S^2-Q^2-R^2=0
\]

すなわち、

\[
\boxed{S^2=R^2+Q^2}
\]

と読める。

この写像では、\(Q\) は外部から新たに追加した物理軸ではない。分裂によって必然的に生じる反対称な相対成分 \(D\) を、観測不能な虚数方向へ射影したときの表示である。

ただし、\(D=iQ\) は現時点では導出済みの帰結ではない。反対称成分が観測可能な空間方向に採用されず、虚数方向として読まれるという新しい仮説である。

## 20. 交換対称性による \(R\) 軸と \(Q\) 軸の区別

娘波を交換すると、

\[
Y_1\longleftrightarrow Y_2
\]

対称成分と反対称成分は、

\[
S\longrightarrow S,
\qquad
D\longrightarrow-D
\]

と変換される。

したがって、物理名を先に与えなくても、二つの成分は交換対称性だけで区別できる。

- \(R\) の候補：娘波交換に対して不変な、共通閉鎖側の成分。
- \(Q\) の候補：娘波交換に対して符号が反転する、相対閉鎖側の成分。

これは、無名性のもとで \(R\) と \(Q\) を別々に扱うための有力な関係的区別である。両者を最初から重力軸・電荷軸と名付けるのではなく、交換に対する偶成分と奇成分として先に分離できる。

さらに、

\[
Q\longrightarrow-Q
\]

という符号反転が分裂後の関係構造から生じるため、正負二方向を持つ量の候補にもなる。

## 21. \(Q\) 軸の生成を分裂停止として読む作業仮説

この構造は、分裂の開始だけでなく、分裂が停止する条件にも接続できる可能性がある。

作業仮説として、次の過程を考える。

1. 親状態の既存の保存配分だけでは、状態を安定して維持できなくなる。
2. 親状態が二つの娘波へ分裂する。
3. 分裂と同時に、対称成分 \(S\) と反対称な相対成分 \(D=iQ\) が生成される。
4. 新たな保存配分 \(Q^2\) を含む
   \[
   S^2=R^2+Q^2
   \]
   が成立し、分裂後の状態が閉鎖する。
5. 分裂後に生成子が固定されれば、既に示した固定生成子系の保存則により、各保存配分は個別に固定され、その後の平面間再配分は停止する。

この場合、分裂が止まる理由は外部から停止則を加えたためではない。分裂によって新しい相対閉鎖成分が生成され、閉鎖条件を満たした後は、固定生成子の保存則がそれ以上の再配分を許さなくなるためである。

再分裂が起こるには、固定された保存配分を再び変更する別の不安定な相対モード、状態依存生成子、または非線形結合が必要になる。この再分裂閾値は未導出である。

## 22. クーロン力への接続境界

反対称成分 \(D=iQ\) が正負の符号を持つことは、電荷に似た構造を与える。しかし、これだけでクーロン力が導出されたことにはならない。

特に、

\[
Q^2
\]

だけでは \(Q\) の符号情報が失われる。二つの系の間で引力と斥力を区別するには、少なくとも、

\[
Q_AQ_B
\]

のように両系の符号を保持する双線形な関係量、または同等の向き付き相対位相が必要である。

したがって、クーロン力への接続には、今後少なくとも次を示す必要がある。

1. 反対称成分 \(D\) が観測不能な虚数方向 \(iQ\) として読まれる条件。
2. 二つの閉鎖系の相互作用が \(Q_AQ_B\) に依存すること。
3. \(Q_AQ_B\) の符号によって加速度方向が反転すること。
4. \(Q\) に対応する曲率と位相セル幅から逆二乗則が生じること。
5. \(R\) と \(Q\) の曲率スケールの比を決める関係条件。

現段階で得られたのは、\(Q\) 軸を任意に追加せず、状態分裂に伴う反対称成分として生成できる可能性である。

## 23. 本思考実験の分類

### 導出済み

- 二娘波の対称・反対称分解
  \[
  S=\frac{Y_1+Y_2}{\sqrt{2}},
  \qquad
  D=\frac{Y_1-Y_2}{\sqrt{2}}
  \]
  に対して、
  \[
  Y_1^2+Y_2^2=S^2+D^2
  \]
  が厳密に成立する。
- 娘波交換 \(Y_1\leftrightarrow Y_2\) に対して、\(S\) は不変、\(D\) は符号反転する。

### 新しい仮説

- 分裂によって生じた反対称成分が、観測不能な虚数方向として
  \[
  D=iQ
  \]
  と表される。

### 作業仮説

- \(Q\) は分裂後の新しい相対閉鎖成分であり、その生成によって分裂後の閉鎖が安定する。
- 閉鎖成立後に生成子が固定されることで、保存配分の再配分が止まり、分裂が停止する。

### 物理的接続仮説

- 交換に対して奇である \(Q\) が、正負を持つ電荷またはクーロン曲率に対応する。
- 二つの系の間の相互作用方向は、\(Q_AQ_B\) または同等の向き付き相対位相によって決まる。

### 未解決問題

- 反対称成分を虚数方向へ送る観測・射影条件。
- 分裂を開始させる不安定条件と、再分裂を起こす閾値。
- \(Q_AQ_B\) 型の相互作用を生成する最小結合則。
- \(Q\) 軸からクーロン型逆二乗加速度を読み出す具体的写像。

## 24. 二乗閉鎖の部分系分解

全体系の成分を、互いに異なる三つの成分群、

\[
\{x_n\},\qquad \{y_n\},\qquad \{z_n\}
\]

へ分ける。

各群の二乗和を、

\[
\sum_n x_n^2=X^2,
\qquad
\sum_n y_n^2=Y^2,
\qquad
\sum_n z_n^2=Z^2
\]

と置けば、加法性だけから、

\[
\boxed{
\sum_n x_n^2+\sum_n y_n^2+\sum_n z_n^2
=X^2+Y^2+Z^2
}
\]

が厳密に成立する。

さらに、各群を、

\[
\sum_n x_n^2+(iX)^2=0,
\]

\[
\sum_n y_n^2+(iY)^2=0,
\]

\[
\sum_n z_n^2+(iZ)^2=0
\]

と読めば、各群はそれぞれ独立した零二乗和閉鎖を持つ。

三つを加えた全体系も、

\[
\boxed{
\sum_n x_n^2+\sum_n y_n^2+\sum_n z_n^2
+(iX)^2+(iY)^2+(iZ)^2=0
}
\]

と閉じる。

ここで重要なのは、\(X^2\)、\(Y^2\)、\(Z^2\) が単なる三つの数ではなく、それぞれ異なる閉鎖部分系の保存・補償成分として読めることである。

## 25. 内在する \(\tau\) と時間 \(t\) の区別

現在までの数値実験に現れる \(\tau\) は、状態更新の前後関係を与える処理インデックスである。

\[
\tau=0,1,2,\ldots
\]

この段階の \(\tau\) は、時計で読み出される時間ではない。

- 長さを持たない。
- 時間単位を持たない。
- 観測波との干渉によって直接読み出されていない。
- 状態を順序付けるが、その順序間隔に物理的な時間幅を与えていない。

したがって、

\[
\boxed{
\tau\ne t
}
\]

である。

一方、閉鎖部分系が周期的な位相運動を持つなら、\(\tau\) に沿って蓄積する位相、

\[
\theta_X(\tau),
\qquad
\theta_Y(\tau),
\qquad
\theta_Z(\tau)
\]

を定義できる。

その位相速度は、

\[
\omega_X(\tau)=\frac{d\theta_X}{d\tau},
\qquad
\omega_Y(\tau)=\frac{d\theta_Y}{d\tau},
\qquad
\omega_Z(\tau)=\frac{d\theta_Z}{d\tau}
\]

である。

このとき、\(\tau\) は各位相を更新する共通の順序変数にすぎず、時計として読まれる候補は、それぞれの累積位相、

\[
\theta_A(\tau)
=
\theta_A(0)
+
\int_0^\tau\omega_A(s)\,ds
\qquad
(A=X,Y,Z)
\]

である。

## 26. 各閉鎖部分系が持つ局所時計

右辺の保存・補償成分 \(X^2\)、\(Y^2\)、\(Z^2\) のベース振動を、それぞれの閉鎖部分系の時計源と読む。

すると、各部分系の局所的な時間読出しは、その位相巻数として、

\[
t_X\propto\theta_X,
\qquad
t_Y\propto\theta_Y,
\qquad
t_Z\propto\theta_Z
\]

と定義できる。

したがって、この仮定のもとでは、一つの全体系に最初から一つの絶対時間 \(t\) が置かれるのではない。

\[
\boxed{
\text{閉鎖部分系 }X,Y,Z
\text{ は、それぞれ固有の局所時計 }
t_X,t_Y,t_Z
\text{ を持つ}
}
\]

という構造になる。

これは、\(X\)、\(Y\)、\(Z\) の時計が無条件に異なる速さで進むという意味ではない。それぞれに独立な時計変数を定義できるという意味であり、実際の進行率は閉鎖条件によって拘束される。

各部分系の状態を、

\[
X=X(t_X(\tau)),
\qquad
Y=Y(t_Y(\tau)),
\qquad
Z=Z(t_Z(\tau))
\]

と書けば、全体閉鎖は、

\[
\boxed{
X\!\left(t_X(\tau)\right)^2
+Y\!\left(t_Y(\tau)\right)^2
+Z\!\left(t_Z(\tau)\right)^2
=0
}
\]

となる。

これを \(\tau\) で微分すると、

\[
X\frac{dX}{dt_X}\frac{dt_X}{d\tau}
+
Y\frac{dY}{dt_Y}\frac{dt_Y}{d\tau}
+
Z\frac{dZ}{dt_Z}\frac{dt_Z}{d\tau}
=0
\]

を得る。

したがって、三つの局所時計の進行率は任意ではない。全体閉鎖を維持するように関係付けられる。

この意味で予想されるのは、互いに無関係な複数時間ではなく、

\[
\boxed{
\text{一つの更新順序 }\tau
\text{ の上で、閉鎖によって結合された複数の固有時間}
}
\]

である。

## 27. 零二乗和閉鎖が持つ共通位相自由度

零二乗和閉鎖、

\[
\sum_n U_n^2=0
\]

に対し、全成分へ同じ位相を掛ける。

\[
U_n\longrightarrow e^{i\varphi}U_n
\]

すると、

\[
\sum_n\left(e^{i\varphi}U_n\right)^2
=
e^{2i\varphi}\sum_nU_n^2
=0
\]

である。

したがって、共通位相回転は零二乗和閉鎖を厳密に保存する。

\[
\boxed{
\sum_nU_n^2=0
\quad\Longrightarrow\quad
\{U_n\}\sim\{e^{i\varphi}U_n\}
}
\]

関係波の相対位相だけを読む観測では、この共通位相そのものは直接観測できない。しかし、その巻数または振動数は、状態変化の周期として読み出せる。

この構造は、

- 絶対位相は観測できない。
- 位相の進行回数は時計として読める。
- \(\tau\) は位相を進める順序である。
- \(t\) は共通位相の累積として創発する。

という時間解釈を与える。

したがって、時間 \(t\) は、\(\tau\) と同一ではない。

\[
\boxed{
t
\text{ は }\tau\text{ に沿って蓄積した共通位相の読出しである}
}
\]

## 28. 共通時間成分と相対時間成分

三つの局所時計位相を、

\[
\theta_X,\qquad\theta_Y,\qquad\theta_Z
\]

とする。

これらは、交換に対して完全に対称な一つの共通成分と、二つの相対成分へ直交分解できる。

\[
t_{\mathrm c}
=
\frac{\theta_X+\theta_Y+\theta_Z}{\sqrt{3}},
\]

\[
q_1
=
\frac{\theta_X-\theta_Y}{\sqrt{2}},
\]

\[
q_2
=
\frac{\theta_X+\theta_Y-2\theta_Z}{\sqrt{6}}.
\]

この変換は直交変換なので、

\[
\boxed{
\theta_X^2+\theta_Y^2+\theta_Z^2
=
t_{\mathrm c}^2+q_1^2+q_2^2
}
\]

が厳密に成立する。

ここで、

- \(t_{\mathrm c}\)：すべての部分系に共通する、交換対称な時間成分。
- \(q_1,q_2\)：部分系どうしの時計の進みの差を表す相対成分。

である。

観測される一つの時間 \(t\) は、最初から全体系の外部に置かれた絶対軸ではなく、この交換対称な共通成分 \(t_{\mathrm c}\) に対応する可能性がある。

一方、相対成分 \(q_1,q_2\) は、共通時計からは読み出せない内部の位相差として残る。

ただし、この相対時間成分を直ちに \(Q\) 軸と同一視することはできない。現段階で示せるのは、時間の共通成分と相対成分が、物理名を与えずに代数的に分離できることまでである。

## 29. 二分裂では共通時間と相対成分が一つずつ生じる

一つの親状態が二つの娘状態へ分裂し、それぞれが局所時計位相、

\[
\theta_1,\qquad\theta_2
\]

を持つ場合、対称・反対称分解は、

\[
t
=
\frac{\theta_1+\theta_2}{\sqrt{2}},
\qquad
q
=
\frac{\theta_1-\theta_2}{\sqrt{2}}
\]

となる。

このとき、

\[
\boxed{
\theta_1^2+\theta_2^2=t^2+q^2
}
\]

である。

親状態の段階でも、共通位相の進行は存在できる。しかし、二つの時計の差 \(q\) は、分裂して二つの状態が生じるまで定義できない。

したがって、論理的な生成順序は、

\[
\boxed{
\text{共通位相としての時間候補 }t
\quad\longrightarrow\quad
\text{分裂後の相対位相候補 }q
}
\]

である。

ただし、実際の二分裂の瞬間には、娘状態の共通成分 \(t\) と相対成分 \(q\) は同じ分解から同時に得られる。ここでいう「\(t\) が先」とは、\(t\) は一つの閉鎖状態にも定義できるが、\(q\) は二つの状態がなければ定義できない、という論理的先行性を意味する。

この \(q\) が観測不能な虚数方向として、

\[
q=iQ
\]

と読まれるなら、前節までに検討した \(Q\) 軸は、二つの固有時間の相対位相から生成されることになる。

これは新しい接続仮説であり、現時点では未導出である。

## 30. \(t\) 軸を虚数方向として読む場合

共通時間成分 \(t\) が直接観測できず、虚数方向または二乗閉鎖の右辺側として表示されるなら、最小形は、

\[
X^2+Y^2+Z^2+(it)^2=0
\]

すなわち、

\[
\boxed{
X^2+Y^2+Z^2=t^2
}
\]

となる。

この式で \(t\) を時間と呼ぶ根拠は、負符号を持つこと自体ではない。

根拠となる候補は、

1. \(t\) が全閉鎖部分系の共通位相成分である。
2. 絶対値として直接読めず、位相巻数または振動数としてのみ読める。
3. \(\tau\) に沿って単調に累積できる。
4. 部分系交換に対して不変である。

という関係構造である。

したがって、\(t\) 軸は、\(XYZ\) に続く第四の空間軸として追加されるのではない。閉鎖部分系に共通する位相進行を、観測不能方向へ表示したものとして生じる可能性がある。

## 31. 時間分離が分裂を停止させる可能性

状態の変化を表現する方法が、成分数を増やすことしかなければ、位相進行のたびに新しい状態分裂が必要になる。

しかし、分裂後の各閉鎖部分系が固有の局所時計を持てば、その後の変化は、

\[
X=X(t_X),
\qquad
Y=Y(t_Y),
\qquad
Z=Z(t_Z)
\]

として、成分数を増やさずに表現できる。

このため、時間成分の分離は、

\[
\boxed{
\text{状態変化を、追加分裂ではなく位相進行として保持する自由度}
}
\]

になり得る。

分裂停止の作業仮説は、次のように整理できる。

1. 分裂前の状態では、変化を保持できる独立な閉鎖モードが不足している。
2. 状態が複数の閉鎖部分系へ分裂する。
3. 各部分系に固有の位相進行 \(t_A\) が生じる。
4. 共通位相成分が時間 \(t\) として分離される。
5. 相対位相成分が固定または有界化されれば、状態は成分数を増やさず周期運動を続けられる。
6. その結果、追加分裂は停止する。

この機構では、\(Q\) 軸の生成が停止原因であるとは限らない。より先に生じる時間成分 \(t\) が、変化を位相進行として収容することで分裂を止め、その後に残った相対位相成分が \(Q\) 軸の候補になる可能性がある。

## 32. この検討から得られる予言

「右辺のベース振動が各閉鎖部分系の時計源である」という仮定を採用すると、次が予言される。

\[
\boxed{
\text{固有時間は全体系に一つだけ与えられるのではなく、
各閉鎖部分系の位相から個別に生じる}
}
\]

観測上、一つの共通時間が得られるのは、

\[
\theta_X-\theta_Y=\text{const.},
\qquad
\theta_Y-\theta_Z=\text{const.}
\]

のように、各局所時計が位相固定された場合である。

位相固定が破れるなら、

\[
\frac{dt_X}{d\tau}
\ne
\frac{dt_Y}{d\tau}
\ne
\frac{dt_Z}{d\tau}
\]

となり、各部分系は異なる固有時間の進行率を持つ。

したがって、この枠組みでは、

- 一つの絶対時間は前提ではない。
- 各閉鎖部分系に局所時計が生じる。
- 共通時間は局所時計の同期成分である。
- 固有時間差は相対位相成分として残る。

という構造が得られる。

## 33. 追加検討の分類

### 代数的帰結

- 部分二乗和を \(X^2\)、\(Y^2\)、\(Z^2\) と置けば、全二乗和は \(X^2+Y^2+Z^2\) と粗視化できる。
- 零二乗和閉鎖は、全成分の共通位相回転によって厳密に保存される。
- 三つの局所時計位相は、一つの交換対称な共通成分と二つの相対成分へ直交分解できる。
- 二つの局所時計位相は、一つの対称成分と一つの反対称成分へ直交分解できる。

### 時間読出し仮説

- 内在する \(\tau\) は処理順序であり、時間そのものではない。
- 各閉鎖部分系のベース振動の累積位相が、その部分系の固有時間として読まれる。
- 観測される共通時間 \(t\) は、複数の局所時計の交換対称成分である。
- \(t\) 軸は直接観測されず、虚数方向または二乗閉鎖の右辺側として表示される。

### 分裂停止の作業仮説

- 時間成分の分離により、状態変化を新たな分裂ではなく位相進行として保持できるようになる。
- 相対位相成分が固定または有界化されたとき、追加分裂が停止する。

### \(Q\) 軸への接続仮説

- 二分裂後に生じる固有時間差
  \[
  q=\frac{\theta_1-\theta_2}{\sqrt{2}}
  \]
  が虚数方向へ射影されるとき、\(q=iQ\) と読める。
- この場合、\(t\) は交換対称な共通位相成分、\(Q\) は交換反対称な相対位相成分として区別される。

### 未解決問題

- ベース振動の累積位相を固有時間として読む観測写像。
- 共通位相成分が虚数方向 \(it\) として表示される条件。
- 各局所時計を同期または非同期にする結合則。
- 相対位相の有界化が分裂停止を保証する安定性条件。
- 複数の相対時間成分から一つの \(Q\) 軸が選ばれる条件。
- \(Q\) 軸が電荷およびクーロン型加速度へ接続する具体的機構。
