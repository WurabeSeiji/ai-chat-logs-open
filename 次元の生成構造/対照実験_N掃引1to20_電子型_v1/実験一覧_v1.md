## 2. 再現手順

```bash
cd 次元の生成構造/対照実験_N掃引1to20_電子型_v1
python3 run_nsweep_electron_v1.py 1 20     # 引数省略時も 1 20
```

- 本フォルダを `次元の生成構造` 直下に置くこと。`run_tb_nsweep_1to20_v1.py` が
  `UF = HERE.parent / "統一万能関数_v1"` で依存を解決するため、階層が変わると
  import が失敗する（パスの書き換えは禁止）。
- 出力は全て本フォルダに出る。`run_nsweep_electron_v1.py` は起動時に
  `assert ns.HERE == HERE` で**出力先が原本フォルダでない**ことを検査する。
- 決定論。乱数は `abl.build_init`（`default_rng(40260722+1000N)`）と
  `gen3.make_parent(N, seed=2)` のみで、実験側に乱数はない。

## 5. 条件（すべて宣言値・中性版と完全同一）

| 項目 | 値 |
|---|---|
| 万能関数 | F=`unified_interaction_v2` / D=`unified_dimension_v1` / G=`unified_readout_v3` / S=`selection_v1` |
| レジスタ | 帯 Nn=16・毛 Nη=8 |
| 走行 | T=4000・準安定窓 τ∈[2000,4000] |
| シード振幅 | δ=1e−2（各 N で真空対照 δ=0 も走行） |
| 親シード | seed=2 固定（退避しない・失敗は失敗として記録） |
| D の宣言引数 | cell=(2,0)・order=6 |
| N | 1〜20 |

**電子型レシピ（本実験の唯一の物理的変更）**

和則 **m\* = 2·m_pump − m_seed**、`(m_pump, m_seed) = (0, 3)` → **m\* = −3**
（電荷 Q = m/3 = −1・3∣m ゆえ単独可読）。Nη=8 なので毛インデックスは
−3 mod 8 = **5**。ポンプ巻きは中性版と同一の 0 であり、**差はシード巻きの1点のみ**。

## 6. 追加した記録項目（力学・条件には非干渉）

`RecordingEngine.step()` が毎步 1 回だけ追記する（`_readout`／`_nonlinear` が内部で
`C2()` を複数回呼ぶため、`C2()` 側での記録は步と対応しない）。記録数が T と一致する
ことを `assert` で検査する。

| ID | 記録 | 定義 |
|---|---|---|
| E1 | `conc_k3` / `conc_all` | 相棒帯 k=3 における P(m\*=−3)/ΣP（V2a と同型）／全帯版 |
| E2 | `dom_m` / `q_hat` / `readable` | k=3 帯の優勢巻き m̂（符号付き）／Q̂ = m̂/3／3∣m̂ の指示値 |
| 補助 | `k3_power` | 相棒帯 k=3 の総パワー（真空対照では ~0） |

npz には `hair_m_*`（物質）・`hair_v_*`（真空）として全步時系列を保存する。
JSON には準安定窓の中央値（`conc_k3_med` 等）を記録する。

## 7. 事前登録（実行前に固定）

- **P1** 構成できない N は中性版と同一（= [1, 2, 8, 10]）。シードの巻きは
  `make_parent`／`build_init` に影響しないため。不一致なら異常。
- **P2** 空間側（f2・tau_space・align・n_eff・closure）は中性版と一致するか、
  一致しない場合はその差を記録する。
- **P3** E1 の k=3 帯集中度が ≥0.9 なら「電子型を狙って作れた」と記録する
  （中性版 V2a の閾値と同じ）。判定は記録であり合否ではない。

## 8. 既存データの保全

- 原本フォルダ `電子の反跳実験/` には**一切書き込まない**（出力は全て本フォルダ）。
- 中性版の結果は静止点 `929554cf`（`対照テスト_N掃引1to20_v1/`）に保存済み。

### 9.2 電子の特性値（構成成功 16 点：N=3,4,5,6,7,9,11〜20）

| 量 | 実測 |
|---|---|
| E1 集中度 P(m\*=−3)/ΣP（k=3 帯・窓中央値） | **1.0000（全 N）** |
| E2 優勢巻き m̂ | **−3.0（全 N・全步）** |
| E2 電荷 Q̂ = m̂/3 | **−1.000（全 N）** |
| E2 単独可読率（3∣m̂） | **1.00（全 N）** |
| τ_wind（集中度が初めて 0.9 を超えた步） | **1（全 N）** |
| k=3 帯パワー（窓中央値） | 物質 δ=1e−2: 1e−7 台／**真空対照 δ=0: 0（下限 1e−40 で表示）** |

**τ_wind = 1 は記録に残すべき事実**である。巻き（＝電荷）は構成の第1步から m\*=−3 に確定しており、
その後 4000 步まで一切動かない。これに対し空間は τ_space = 145〜313、時間は τ_time = 2 である。
すなわち本系では**電荷は「生まれる」量ではなく、和則によって構成時に決まり厳密に保存される量**として
振る舞っている（判定ではなく記録）。

### 9.3 中性版との空間側比較（N 別・相対差）

| N | τ 一致 | align | n_eff | closure | ω | f_seed |
|---|---|---|---|---|---|---|
| 3 | 3種全一致 | 1.5e−14 | 2.5e−03 | 5.7e−11 | 1.9e−13 | 3.4e−13 |
| 4 | 同 | 1.2e−14 | 3.6e−04 | 6.2e−11 | 3.4e−14 | 4.8e−13 |
| 5 | 同 | 3.7e−10 | 3.6e−03 | 2.5e−10 | 8.7e−11 | 1.2e−12 |

差の起源は、巻きの置き場所が変わることで頂点 RK4 の部分步数と σ 冪反復の丸めが変わる点にある。
桁は全 N で一致する。**n_eff だけ N=3・5 で 10⁻³〜10⁻⁴ 台**であり、低 N（第3次元が結晶化しない／
曖昧さが最大の領域）で敏感になっている——本系の既知の性質（N=4,5 特異性）と整合する。
