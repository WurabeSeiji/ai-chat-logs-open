## 0. 目的と経緯

現行の万能相互作用（theta_from_ab → rotate_ab）は、AB 合成スペクトルの
フェルミオン/ボゾン関係量比から θ を読み、全成分同一の 2×2 実直交回転を行う。
この回転は **AB 合成のビン別パワーを厳密保存**するため弾性であり、
倍音内容（倍音関係）を変えるチャネルを持たない——生成（ボゾン凝縮→フェルミオン対）
には非弾性チャネルの追加が必要（2026-08-04 木原氏との検討で確定）。

要件（木原氏指示）:
1. テスト系は別コピーで、万能相互作用演算の部分だけを変更する
2. 万能性を失わない——**IF 文（種による分岐）を使わない**
3. 「倍音関係を変える」複雑な処理を写像として実装する

## 1. 写像の定義（v1）

衝突一回 = 弾性部（現行・無変更）∘ 非弾性部（新設）:

    弾性部:   readout = theta_from_ab(a, b);  (a,b) ← rotate_ab(a, b, readout.theta)
    非弾性部: a' = a + i·g·( |b|²·a + b²·ā )
              b' = b + i·g·( |a|²·b + a²·b̄ )      （同時更新・点ごと演算）

- **点ごと（χ×η 格子の各点での積）** ⇒ スペクトル空間では
  k₁+k₂−k₃ = k₄ 型の**和則保存する四波混合（χ³型）**が自動的に成立。
  保存則は格子の算術であり、IF 文は存在しない
- 第1項（|b|²a 型）＝相互位相変調（XPM）: 倍音関係の位相書き換え
- 第2項（b²ā 型）＝**パラメトリック変換項**: 積振幅平面の混合＝倍音関係の変更本体
  （2+2→1+3 型の対生成チャネルはここに含まれる）
- 二波間のみ（|a|²a 型の自己散乱項は置かない——操作代数「単一波の自己散乱は存在しない」に従う）
- g: 新設の**万能結合定数**（全対に同一・種非依存）。値は実験の掃引対象であり、
  無次元閾値（占有率×g）と α の接続（tQ 構成案 A1）が将来の照合点

## 2. 自動的に成り立つ性質

- **対応原理**: 非弾性項は振幅の3次 ⇒ 希薄極限で消え、現行弾性演算に還元。
  g=0 で現行パイプラインと恒等一致（E-B3 アンカーがそのまま対照になる）
- **閾値の自然発生**: 実効強度 ∝ g×占有率 ⇒「占有率が無次元比を超えたとき」
  という分裂定理の閾値構造が、手置きの閾値なしで頂点の次数から出る
- **パリティ定理（設計段階で証明済み・テストで機械検証）**:
  純偶ポンプ（白猫×白猫）だけからは奇内容は恒等的に生じない
  （χ³ の指数和は生の bin パリティ類を保存する）。
  ⇒ 生成は必ず**種付き（誘導）過程**: 微小な奇シード＋強い偶ポンプ → パラメトリック利得。
  自発版（シードなし）は零点揺らぎの領分であり、本写像の範囲外と明記する。
  海（白色 50:50）には奇素材が常在するため、物理的シードは自然に存在する

## 3. 保存量の帳簿（テスト項目）

| 量 | 弾性部 | 非弾性部 | 備考 |
|---|---|---|---|
| AB 合成ノルム | 厳密保存 | O(g²) ドリフト（陽的一段の積分器誤差） | 実測・記録。g 小で制御 |
| 合成 χ 運動量 Σk·P_k | 厳密保存 | 和則により保存（実測で確認） | 点ごと演算＝並進不変 |
| 零閉塞 Σa²+Σb² | 厳密保存 | **保存は自明でない——最重要測定項目** | 保存が破れる場合、閉塞保存要求で写像を拘束できるか（一意化の可能性）を次版で検討 |

## 4. 単体テスト計画（実行前固定）

- T1 対照（g=0）: E-B3 の三対（even-even / odd-odd / even-odd）200衝突を
  本写像経由で走らせ、原本パイプラインと**軌道が bitwise 一致**
  （アンカー: 偶偶 θ≡0・F=1、偶奇 θ₀=0.7619520718）
- T2 保存（g=1e-3・希薄）: ノルム・Σk・閉塞のドリフトを200衝突で実測記録
- T3 パリティ定理: 純偶×純偶・g 大で奇関係量 P_f が恒等 0（<1e-25）
- T4 種付き利得（本命・探索記録）: 偶ポンプ＋奇シード（振幅 1e-8）、
  占有率スケール s を掃引し、P_f(j) の成長率（利得）を実測。
  利得が占有率とともに立ち上がるか（閾値様挙動）を記録——結果は開いている
- T5 IF 監査: 写像コードに種分岐が存在しないこと（コードレビュー明記）

## 5. 禁止事項

- シードなしでの「自発生成」の主張（パリティ定理により不可能・零点揺らぎの領分）
