## 0. 出発点：四元数では自由度が足りない（著者の判断）

同じ四元数から「重力読み」と「クーロン読み」が二つ出るのは不自然である。四元数一つが与えるのは (t, xyz) の読み出しだけで、第二層のスカラー部 q₀² − |v|² は「もう一つの力」ではなく同じ時空側の計量（光円錐）だった。独立な結合が一つしかなく、重力とクーロンの強さの比（α と α_G の比）が入る場所が無い。**自由度が不足しており八元数にする必要がある**（著者の立場、2026-10-19）。前メモ §8 の「二層二部の表」は、この点で不十分だった。

八元数の分割：o = q + pℓ、q = (q₀, v) ↔ (t, xyz)、p = (R, Q₁, Q₂, Q₃) ↔ (R, Q₁Q₂Q₃)。

## 1. 数値で確認した事実

### 1.1 関係 ō o′ の分解（誤差はすべて倍精度の丸めの範囲）

- 実部 = ⟨q, q′⟩ + ⟨p, p′⟩（誤差 3.6e-15）。**時空側の内積と内部側の内積が、別々の項として同時に入る。** 四元数には無かった構造。
- 四元数虚部 = Vec(q̄q′) + Vec(p̄′p)（誤差 0）、ℓ 部 = p′q̄ − pq̄′（誤差 0）。
- 自己関係 ō o は純実（誤差 8.9e-16）。**自己関係は常に 1 を指す。**

### 1.2 対称性は三段に分かれる（無限小写像の核の次元）

| 固定するもの | 残る対称性 | 次元 |
|---|---|---|
| 閉塞 Σo = 0, Σo² = 0 のみ | SO(7) × ℝ⁺ | 21 + 1 |
| 積（代数の自己同型） | G₂ | 14 |
| 積 ＋ 観測者の時空 ℍ | SO(4) = so(3)_空間 ⊕ su(2)_内部 | 6 |
| 積 ＋ ℓ（R の軸） | SU(3) | 8 |
| 積 ＋ ℍ ＋ ℓ | SO(3)（v と Q を一緒に回す） | 3 |
| 積 ＋ ℍ、かつ ℍ に自明に作用 | su(2)_内部（R と Q を混ぜる） | 3 |

四元数では閉塞の対称性と積の対称性が一致（so(3)）するが、八元数で初めて分かれる。su(3) の元は ℍ を保たない（max |D[4:8,0:4]| = 0.50）。

### 1.3 閉塞の解の次元（形の空間 = 解の次元 − 対称性の軌道）

C：2(N−3)。H：N ≥ 4 で 4(N−3)（N = 3 は 1：平面内の位相。四元数論文 §8.3 が 45° に固定している角）。O：N ≤ 5 では H と同じ、N = 6 で 4 本目の虚方向が開き、N = 9 で 7 本すべてが開いて 8N − 38。**(R, Q₁Q₂Q₃) 側が開くには N ≥ 6 が要る。** 閉塞は 7 本の虚方向を同等に扱い、3 + 4 の分かれ方は閉塞からは出ない。

### 1.4 換算比 κ の居場所

p → κp は線形閉塞と Σo² のベクトル部を保ち、実部だけが κ² = Σ(q₀² − |v|²)/Σ|p|² を要求する。確認：閉塞解の p を 2 倍にすると二乗閉塞の残差 8.56、式で κ を戻すと 1.6e-15。**内と外の換算比（2.6）の居場所は閉塞の中にあり、閉塞が値を縛る。**

### 1.5 三角形の枠ホロノミー

比の一歩 s_ef = o_f ō_e を三角形で一周したとき：

- 四元数に埋め込んだ三角形（p = 0）：時空の枠は厳密に戻る（max |H_qq − I| = 9.0e-16、混合 0）。内部の枠が回り、小さな三角形で 角／面積 = 3.9994 → **4**（可換子 [A,B] = 2A×B から厳密）。
- 八元数の一般の三角形：三角形自身の四元数部分代数 H_T = span(1, A, B, AB) の中では枠は厳密に戻り（max 1.2e-15）、H_T と補空間の混合は無く（max 7.7e-16）、**補空間（4 次元）は 4 × 面積で回る**（角／面積 ∈ [3.9748, 4.0000]）。三角形によらず普遍。
- 観測者の時空半分が H_T と整合していれば時空の枠は戻り、不整合の分だけ時空の枠が回り、時空と内部が混ざる。
- 大きな三角形：枠の回転角 中央値 1.955 / 最大 2.892 rad。基点は常に戻る（逆元性、7.5e-16）。

### 1.6 内と外の分割はどこまで自由か

- 時空側として選べる四元数部分代数 H′ = span(1, A, B, AB) の集合は **G₂/SO(4)、8 次元**（6 + 5 − 3 = 8 = 14 − 6、数値で一致）。
- **どの分け方でも和則 Σ(q₀² − |v|²) = Σ|p|² が厳密に成立する**（10⁻¹⁵）。線形閉塞も各分け方で成立（Σq₀, Σv, Σp すべて 10⁻¹⁶）。
- しかし**要素ごとの m² = q₀² − |v|² は分け方で大きく変わる**（最大ずれ 3.10、和だけが一致）。
- q ↔ p の入れ替えは**積を保たない**（自己同型でない、誤差 26.8）。ノルムだけは保つ（7.1e-15）。ジョルダン積も保たない（20.0）。
- **構造的な非対称は 1 の位置だけ。** H′ は積で閉じ（漏れ 3.8e-15）、補空間は閉じない（漏れ 11.06）。補空間どうしの積は 100 % H′ に落ちる（0.99999999999999996）。1 は必ず H′ の側にある（補空間成分 0）。

## 2. 読み出せる量（1.2 からの帰結）

以下の §2 は、**各要素が 8 次元の光円錐に乗る（q₀² − |v|² = |p|² が要素ごとに成り立つ）という追加の仮定のもと**での読み出しである。閉塞から出るのは和則 Σ(q₀² − |v|²) = Σ|p|² だけで、要素ごとの等式は出ない（§1.6）。この仮定は四元数論文 §8 の「最も対称な形」の八元数版にあたる。

時空 ℍ だけを固定した観測者に残る対称性は su(2)_内部（p に右から掛かる四元数回転、R と Q を混ぜる）。残る対称性で消されない量だけが読める。

- **質量に見える量：** 内部の 4 つのうち残るのは |p|² = R² + |Q|² の一つだけ。8 次元の光円錐 q₀² − |v|² = |p|² と合わせて E² − p² = m²。読み出しは |p|/q₀ = √(1 − |u|²) = 1/γ（論文 §7 の「1/γ = m/R が交差項から読める」と同じ量）。
- **質量側の内部時計（R）：** ℓ を相手と共有しない限り Q と混ざって単独では読めない。R/q₀ が質量として単独に見えるのは Q = 0 のときだけ。電荷があれば m² = R² + |Q|² で、**電荷が質量に寄与する**。
- **Q₁Q₂Q₃ は三つ読めない。** 時空だけを固定した観測者には個々の成分も |Q| も R と分離できない。ℓ を共有すると R と |Q| が別々に読め、さらに v·Q（内部ベクトルと空間方向の揃い、スピン的な量）が読める。Q₁, Q₂, Q₃ を個別に読むには内部の枠を丸ごと共有する必要があり、無名性のもとでそれはできない。**三つの成分は色で、個別には読めず、そろって初めて一つの整数電荷として現れる。閉じ込めは「読めない」の形で出る。**
- **電荷側の時計：** 内部の時計は p を回す su(2) の位相（論文 §12 のホップ・ファイバーの位相）。連続な速さは残る対称性で消されて読めない。読めるのは、外の一周のあいだにファイバーを何回巻いたかという**整数だけ**。
- **質量が連続で電荷が離散である理由が、同じ一つの残る対称性から出る。** 質量は内部のノルム（連続）、電荷は内部の時計（位相的にしか読めない）。

標準理論が内部対称性を「ゲージ」として外から置いているものが、ここでは「観測者が固定していない残りの対称性」として内側から出る（R8 の内と外の座標系が別、に対応）。

## 3. 内と外の選択問題（1.6 からの帰結）

**自由な部分：** どれを時空として読むかは 8 パラメータ（G₂/SO(4)）の自由な選択で、閉塞も和則も分け方に依らない。「時間の広がり＝内部の広がり」は配置の性質、分け方は読み出し側の選択。内と外の対称性はここまでは本当にある。

**自由でない部分：** 二つの半分は入れ替え可能ではない。入れ替えは積を保たず、構造的な非対称は **1 がどちらにあるか**の一点だけ。H′ は積で閉じ、補空間は閉じない。1 は必ず H′ の側。そして自己関係 ō o は常に 1 を指す。

**選択問題の正体：** どちらを時空と呼ぶかではなく、**自分の 1 をどの部分代数に載せるか**。観測者は自分を含む側を時空として読むしかなく、残りが内部になる。R4 の「どの観測者の座標か」が、8 パラメータの選択に化ける。

**読み（確認前）：**
- 別の分け方を選んだ観測者にとって、こちらの電荷の一部は空間に、こちらの空間の一部は電荷に見える。和則が分け方に依らないので全体の整合は壊れないが、各要素の m² は分け方で変わる。**質量は観測者の分け方に依る量で、分け方に依らないのは配置全体の和だけ**（R9 の「質量は内部を外から読んだ値」の、より強い形）。
- 二つの観測者が同じ物理を共有できるのは、互いの H′ が一致するときだけ。一致しないと片方の空間方向が相手の内部方向に混ざる。これが 1.5 の「不整合があるほど時空の枠が回る」で、**重力として見えていたものの正体が、分け方の不一致**だということになる。内と外の対称性は破れているのではなく、どこで破るかが観測者ごとに違い、その食い違いが重力。
- 局所平坦は三角形自身の H_T の中で厳密に成り立ち、歪みは補空間に面積比例で乗る。同じ一つの回転（4 × 面積）を、観測者の分け方が時空側と内部側に配分していて、整合した分がゲージ、ずれた分が重力に見える。四元数では観測者の分け方とずれようがないので重力側が出ず、**八元数の非結合性が初めてこれを許す**。

## 4. 読めない側：光円錐の外・地平線の向こう・補空間

**共通している構造：** どれも「ある観測者が 1 を置いた側が読める側になり、残りが読めない側になる」という同じ一つの分割。光円錐の外は分解能 δ を超えて互いに見分けられない殻（|u| ≥ cot δ）、地平線の向こうは q₀ = 0 の側、八元数の補空間は積で閉じず自分の時計を持てない側。**読めない側はどれも「時計がない側」**。

**同型が効く向き：** 読めない側は消えているのではなく、こちらから見て内部自由度として現れる。地平線の向こうが外から見ると面積に比例した自由度に見えること、光円錐の外が相互作用せず減衰としてだけ効くこと（吸収体）、八元数の補空間が質量と電荷という内部量に見えること。三つとも「読めない側が、こちら側では内部状態として勘定される」という同じ形。

**完全な対称ではない点：**
- 1 の位置。読める側は積で閉じ、読めない側は閉じない。「向こう側の住人がこちらを内部として読む」と言えるのは、向こう側が自分の 1 を持てる場合だけ（落下する観測者には自分の 1 があり、外に留まる観測者から見た地平線の向こうにはこちらの 1 が届かない＝相補性）。
- 時間の向き。向きは規則にはなく殻の初期条件にある（前メモ §3）。同型でも向きまで対称とは言えない。

**読み：** ブラックホールは、読めない側が大きくなった極限で、分け方の不一致が最大になった状態。面積が自由度を数えるのは、読めない側の次元が境界で決まるから。Λ = 3/R²、吸収殻＝裏返しの BH（統合仮説論文 追記 §25〜）とも、同じ分割の両側として並ぶ。

## 5. 相互作用と対になる操作

**ポイント（著者）：** 対称性の破れ方が読み方の違いに依存していて、どこまでが物理か境界が曖昧。相互作用と読み出しはほぼ同じだが、相互作用と対をなす操作があるのかもしれない。

**候補 1：積と結合子。** 読める側 H′ は積で閉じ、補空間は閉じず、補空間どうしの積は 100 % H′ に落ちる（補空間は代数ではなく加群）。積が二項で内部に閉じる操作だとすれば、対になるのは外へ落とす操作で、**結合子 [x, y, z] = (xy)z − x(yz)** がそれ。結合子は三つ組にだけ現れ、三角形のホロノミーとして出てきた量そのもの。前者が相互作用、後者が「相互作用がどれだけ分け方に依っているか」を測る。

**候補 2：読み出しと書き込み（生成子）。** 読み出しは関係 ō o′ のベクトル部を取ってスカラー部で割る写像。対になるのは、ベクトル部の値を受け取って状態を回す写像＝生成子 K。片方が状態から値を作り、片方が値から状態を変える。**読み出しは片方向、相互作用はその往復。** 往復が閉じるかどうかが、物理と読み方の境目。

**注意：** 対になる操作を「読み出しの逆」として定義したくなるが、N:M の関係（同じ読み出しを与える状態が複数ある、2026-09-22 の著者の立場）だと逆写像は存在しない。存在するのは随伴であって逆ではない。往復が恒等に戻らないのは誤差ではなく、N:M がある限り必ず残るもので、その残りが不確定性とホロノミーの両方になっている。

**物理と読み方の線引きの基準（この枠組みの主張）：** 分け方に依る量と依らない量で分ける。

| 分け方に依らない（物理） | 分け方に依る（読み方） |
|---|---|
| 閉塞 Σo = 0, Σo² = 0 | 各要素の m² = q₀² − \|v\|² |
| 和則 Σ(q₀² − \|v\|²) = Σ\|p\|² | どれが電荷でどれが空間か |
| ホロノミーの 4 × 面積 | 光円錐の内外（分解能 δ に依存） |
| 巻き数の整数性 | 時空側と内部側へのホロノミーの配分 |

## 6. 確かめる計算（追加の仮定なし）

1. **分け方の不一致と重力。** 同じ閉塞配置を二つの分け方で読み、(a) 和則がどちらでも成立すること（確認済み）、(b) 各要素の m² と |Q| がどう移り変わるか、(c) 二つの分け方のずれ角と、三角形ホロノミー（時空の枠の回転）の関係。(c) が面積比例で揃えば「重力＝分け方の不一致」が計算結果になる。
2. **三つの内部量の分離。** R・|Q|・巻き数を分けて数値で見る。ℓ を共有する／しないで何が読めるようになるかを、残る対称性の不変量として確認する。ℓ を共有させる共通の参照が殻（静止した背景）だという読みを、計算に落とす。
3. **読めない側の数え上げ。** 同じ閉塞配置で分解能 δ を連続に変え、(a) 読めない殻に落ちた要素の数、(b) こちら側で内部量（|p|、巻き数）として勘定される量、(c) 境界の面積に相当する量、が比例関係に入るか。比例すれば、光円錐・地平線・八元数の分割が同じ一つの数え上げであることになる。
4. **対になる操作の同定。** 同じ配置で (a) 読み出し → 生成子 → 読み出しの往復の不一致、(b) 同じ三つ組の結合子、(c) 分け方の不一致角、を並べ、三者が同じ量の別の顔かどうかを見る。一致すれば「相互作用と対になる操作」が一つに定まる。
5. **八元数版ビューア。** 閉塞の厳密解（Σo = 0, Σo² = 0 の 16 本）を生成し、分け方 H′ をスライダーで変えながら、各要素の (t, xyz) と (R, Q) の読み出しがどう入れ替わるかを見る。前メモの複素版ビューア（`ゼロ閉塞解集合ビューア_20261018/`）の八元数版。

## 7. まだ言えないこと（導出待ち）

- 観測者の ℓ（分け方 H′）を何が選ぶか。殻（静止した背景）が共通の参照になるという読みは未検証。
- κ² を決める配置。換算比の居場所は分かったが値は未導出（2.6）。
- 1/r、1/r² の形。角と冪和から (t, xyz) の読み出しを経て初めて出る。
- 内部 su(2) の巻き数と e/3 の三相（統合仮説論文 §22.2）の対応。閉塞の最小単位が N = 3 であることと、内部が 3 成分であることは別の事実で、まだ結びつけていない。
- 重力の不確定性セルの尺度、エネルギー階層の値。
