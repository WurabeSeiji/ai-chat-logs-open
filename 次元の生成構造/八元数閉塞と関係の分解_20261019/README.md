## 1. なぜ八元数にしたか（経緯）

四元数一つが与えるのは (t, xyz) の読み出しだけで、第二層のスカラー部 q₀² − |v|² は「もう一つの力」ではなく同じ時空側の計量（光円錐）だった。独立な結合が一つしかなく、重力とクーロンの強さの比が入る場所が無い。**自由度が不足しており八元数にする必要がある**（著者の判断、2026-10-19）。

八元数の分割：o = q + pℓ、q = (q₀, v) ↔ (t, xyz)、p = (R, Q₁, Q₂, Q₃) ↔ (R, Q₁Q₂Q₃)。

## 4. 読み（解釈。計算結果ではない）

- **重力＝分け方の不一致。** 二人の観測者が自分の 1 をどの四元数部分代数に置くかの食い違いが、時空の枠の回転として現れる。φ = 0 が凝縮体（全員が揃う＝秩序変数が立つ）、φ ≠ 0 が重力。同じ一本の軸の両端。
- **相互作用と読み出しは同じ非可換性の二つの表し方。** 枠ホロノミー = 4 × 読み出しの一周。読み出しに逆写像が無いこと（N:M）の残りが、そのまま曲率になっている。
- **内部状態は時空側からは読めない。** 時空だけを固定した観測者に残る su(2) が、R と Q を混ぜる。読めるのは質量（内部のノルム |p|、連続）と電荷（内部の時計の巻き数、整数）の二つだけ。Q₁Q₂Q₃ は個別には読めない（色・閉じ込め）。
- **内部空間は「局在」ではなく「まだ開いていない」。** 倍音が増えると外が局在し、同時に内が開く。逆向きではない。本当に共役なのは巻き数と位置。
- **緩さの定量が四つ。** 閉塞 22 と積 14 の差 8、分け方の 8、閾値 k = min(7, N−2)、結合的 3-平面の余次元 4。ガッチリ固まっていたら構造ができない、という著者の立場の数値化。

## 5. まだ言えないこと（導出待ち）

- 観測者の ℓ（分け方 H′）を何が選ぶか。殻（静止した背景）が共通の参照になるという読みは未検証。
- κ² の値。居場所は分かったが値は未導出（検討ルール 2.6 の内と外の換算比）。
- 1/r、1/r² の形。角と冪和から (t, xyz) の読み出しを経て初めて出る。
- 内部 su(2) の巻き数と e/3 の三相（統合仮説論文 §22.2）の対応。閉塞の最小単位が N = 3 であることと内部が 3 成分であることは別の事実で、まだ結びつけていない。
- 重力の不確定性セルの尺度、エネルギー階層の値。
- 要素ごとの 8 次元ヌル条件を閉塞や動力学から出せるか。今は仮定として置いている。

## 6. 次にやる検算（優先順）

1. **A の面積依存を φ 固定で取り直す。** |H_qq − I| の傾きが 1.499 と中途半端なのは、一次の回転項（sin²φ × 面積）と混合の二次項が混ざっているため。φ を固定して分離する。
2. **係数 4 と 4√2 が厳密か。** 枠ホロノミー = 4 × 読み出しの一周 の 4、および検算 A の混合/面積 の 5.649（4√2 = 5.657 と 0.1 % 一致）。解析的に確かめる。
3. **φ の分散と巨視的な重力。** φ の分布を持つ多数の要素からなる配置で、重力に相当する量が φ の分散で書けるか。
4. **k = 4 の等モジュラー解の内部量。** |p| と巻き数を実際に読み出し、質量と電荷に相当する値を測る。
5. **結合的／非結合的の二族を検算 A で比べる。** 非結合的な側が重力を持ち、結合的な側が持たないか。
6. **八元数版ビューア。** 複素版（`次元の生成構造/ゼロ閉塞解集合ビューア_20261018/zero_closure_viewer_20261018.html`）の八元数版。分け方 H′ をスライダーで変えながら (t,xyz) と (R,Q) の読み出しが入れ替わるのを見る。
