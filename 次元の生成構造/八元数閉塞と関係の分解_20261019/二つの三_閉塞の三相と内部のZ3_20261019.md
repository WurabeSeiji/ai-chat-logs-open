# 二つの「三」― 閉塞の三相と内部の Z₃（2026-10-19）

プログラム：`octonion_two_threes_20261019.py`（本体を読み込む、固定シード）。
前段：`kのスペクトルと粒子への割り当て_20261019.md` §7 の最後に挙げた課題。

## 0. 問い

e/3 の三相は、N = 3 の閉塞配置 (1, ω, ω²) のことか、それとも内部半分の Q₁Q₂Q₃ のことか。前メモで「二つの『三』は別物」と書いたが、では thirds を与えているのはどちらか。

## 1. 答え：thirds を与えるのは **stab(ℓ) の中心 Z₃**

観測者が内部の時計軸 ℓ を固定すると、残る対称性は SU(3) = stab(ℓ)（8 次元）。**その中心 Z₃ が thirds を与える。** 閉塞の N = 3 三相とは別の対象である。

### 構成（すべて数値で確認）

1. stab(ℓ) は 8 次元、その Cartan は 2 次元（[H₁, H₂] = 5×10⁻¹⁶）。
2. 7 本の虚方向の重みは、**ゼロ 1 本（= ℓ）と正六角形の 6 本**（間隔ちょうど 60.00°）。一つおきの三つ組が 120° 間隔で和ゼロ（3 と 3̄、和のノルム 4×10⁻¹⁶）。
3. 三つの重みの位相がすべて 2π/3 になるトーラスの点を解く。和がゼロなので目標は (2π/3, 2π/3, −4π/3)。残差 1.8×10⁻¹⁵ で解ける。
4. 得られた **Z は G₂ の元**（積の自己同型、誤差 6×10⁻¹⁴）、**stab(ℓ) の中心**（su(3) 全てと可換、4×10⁻¹⁵）、**Z³ = I**（1.4×10⁻¹⁴）、Z ≠ I（‖Z − I‖ = 4.243）。
5. 固有値の偏角はちょうど **+120° が 3 本、−120° が 3 本、0° が 2 本**。3 に ω、3̄ に ω̄、固定軸（1 と ℓ）に 1。
6. 中心は {I, Z, Z²} ≅ **Z₃**。

## 2. Z は何をするか（これが要点）

観測者が時空を span(1, e₁, e₂, e₃)、内部を span(e₄, e₅, e₆, e₇) に取ると、Z の行列は

- 1（時間軸）と e₄ = ℓ（内部の時計軸）を**固定**
- 三つの平面 **(v₁, Q₁)、(v₂, Q₂)、(v₃, Q₃)** をそれぞれ **120° 回す**（成分は −0.5 と ±0.866）

|Z_qq − I| = 2.598、時空↔内部の混合 = 1.500。

**Z は空間と内部を混ぜる。内部だけの回転ではない。** 空間方向 vᵢ と電荷方向 Qᵢ が組になって回る。thirds を与える対称性は、空間と電荷をまたいでいる。

**（2026-10-19 追記：分け方に依存する。`対称性の鎖と二つの三の訂正_20261019.md` §2.2）** Z が組にする三つの平面 (vᵢ, Qᵢ) は、ℓ を掛けて eᵢ ↦ ℓeᵢ とした対である。**観測者が ℓ を内部の半分に置く分け方を選んだとき**、これは空間と電荷の対として見える。ℓ を含む四元数部分代数 span(1, ℓ, A, ℓA) を時空の半分に取る観測者にとっては、Z は時空の半分を保ち、混合は厳密にゼロ（3.6×10⁻¹⁵）。

| 分け方 | 部分代数か（漏れ） | Z の時空↔内部の混合 |
|---|---|---|
| 時空 = span(1, e₁, e₂, e₃)（ℓ は内部側） | 0.0 | **1.500** |
| **時空 = span(1, ℓ, e₁, ℓe₁)（ℓ を時空側に）** | 0.0 | **3.6×10⁻¹⁵** |
| ランダムな分け方 10 本 | ― | min 0.636 / 中央値 1.388 / max 1.488 |

このとき Z は時空ブロックの中の一平面を 120° 回すだけ（時空ブロックでの回転角は 0°, 0°, ±120°）。**thirds が空間と電荷をまたぐかどうかは、分け方の選択である。**

## 3. 閉塞解への作用と Z₃ の軌道の和（群平均）

- **Z は閉塞解を閉塞解に写す**（k = 1, 2, 3 で確認、Z 後の閉塞残差 10⁻¹⁴）。G₂ の元なので当然だが、数値でも確認した。
- **Z で固定される配置は span(1, ℓ) の中のものだけ**（固定部分空間は 2 次元、基底は 1 と ℓ）。span(1, ℓ) は ℓ² = −1 なので **ℂ の一つのコピー**。
- どの配置でも S + ZS + Z²S = 3 ×（span(1, ℓ) への射影）（誤差 10⁻¹⁴、k = 1, 2, 3）。

**（2026-10-19 訂正。`対称性の鎖と二つの三の訂正_20261019.md` §2.1）** 最後の等式は、**位数 3 の線形写像なら何でも成り立つ恒等式**である（群平均 (I + Z + Z²)/3 は固定部分空間への射影。1 + ω + ω² = 0 から自動）。数値で確かめる対象ではなく、物理の結果でもない。

> Z₃ の軌道の和は固定部分空間に落ちる（群の平均の一般的な性質）。**非自明なのは、その固定部分空間がちょうど span(1, ℓ) の 2 次元であること**と、Z が G₂ の元なので閉塞解を閉塞解に写すこと、この二つだけである。

## 4. 二つの「三」の関係

| | 閉塞の三相 | 内部の Z₃ |
|---|---|---|
| 正体 | 三つの**要素** (1, ω, ω²) の和がゼロ | 位数 3 の**対称性**（stab(ℓ) の中心） |
| 住む場所 | N 要素の閉塞配置（k = 1） | G₂ の中、虚方向への作用 |
| 内部の有無 | 内部ゼロ（四元数に収まる） | ― |
| 電荷を担うか | 担えない | **これが thirds を与える** |

そして両者は無関係ではない。**三相 (1, ω, ω²) をどこに置くかで Z₃ での振る舞いが変わる。**

- **内部軸 span(1, ℓ) に置く**：‖ZT − T‖ = 0.000。Z₃ で不変。トライアリティ 0 で中性。
- **空間軸 span(1, e₁) に置く**：‖ZT − T‖ = 2.121。Z で動き、三つの像を持つ。トライアリティ ≠ 0。

閉塞はどちらでも同じく満たす（残差 10⁻¹⁶）。**同じ三相配置が、観測者の内部軸に乗るか空間軸に乗るかで、中性にも有色にもなる。**

## 5. 読み（計算結果からの解釈、確認前）

- **e/3 の三分の一は、stab(ℓ) の中心 Z₃ から来る。** 配置は Z₃ の軌道で三つ組になり、一つだけでは中性にならず、三つそろって初めて span(1, ℓ)（＝観測者の時間軸と内部時計軸だけ）に落ちる。これは色の閉じ込めの形そのもので、「個別には読めず、そろって初めて一つの整数電荷」という前メモ §2 の結論と同じことを、今度は**具体的な群の元**として与えている。（2026-10-19 訂正：三つそろうと不変部分に落ちること自体は群平均の一般的な性質で、色の中和が「式で出た」わけではない。非自明なのは不変部分がちょうど span(1, ℓ) であること。§3）
- **thirds が空間と電荷をまたいで見えるかどうかは、観測者の分け方による。** ℓ を内部の半分に置く分け方では、Z は空間と電荷を組にして回す。ℓ を含む四元数部分代数を時空の半分に取る観測者には、Z は時空の半分を保ち混合は厳密にゼロ（§2 追記の表）。ℓ を内部に置く分け方で見ると、電荷の三分の一と空間の三方向が同じ一つの対称性で結ばれている、という形になる。これは前の「重み六角形」で見た 3 と 3̄ の幾何を、作用として書き直したもの。
- **中性か有色かは観測者が決める。** 同じ三相が、観測者の ℓ の取り方で中性にも有色にもなる。これは R4（どの観測者の座標か）と R8（内部と広域は別の座標系）が、電荷の値そのものに効いているということ。
- **前メモ §7 の食い違いは解消した。** 「三相は k = 1 で内部ゼロだから電荷を担えない」は、三相を内部軸に置いた場合の話。空間軸に置けば Z₃ で動き、三つ組になる。ただし内部（p）の成分が開くわけではないので、**この三つ組は巻き数としての電荷とは別の量（トライアリティ）**である。両者の関係はまだ出していない。

## 6. まだ言えないこと

- トライアリティ（Z₃ の軌道の分類）と、巻き数としての電荷（内部 su(2) の位相）の関係。前者は k = 1 でも持てるが、後者は内部が開かないと持てない。e/3 がどちらなのか、あるいは両方が要るのかは未決。
- Z₃ の軌道の三つの像が物理的に同じものか違うものか。Z は G₂ の元（対称性）なので、三つは「同じ配置の別の見え方」のはずだが、観測者が ℓ を固定した後では区別がつく。この「固定後に初めて区別がつく」構造が、色の定義と合うかどうか。
- SU(3) の中心が出たことで、k ごとの残る対称性の階段（su(3) → su(2) → 自明）に Z₃ が加わった。U(1) はまだ出ていない。標準模型の群との対応づけは引き続きしない（R5）。

## 7. 次の検算

- k = 3 非結合的の配置で巻き数を読み出し、トライアリティと突き合わせる。
- Z₃ の軌道の三つの像について、読み出し（中心投影）が何を返すか。三つが同じ像を返すなら区別できず、違う像を返すなら区別できる。
- span(1, ℓ) 以外にも Z₃ 不変な配置がないかを網羅的に探す（固定部分空間は 2 次元と出たので無いはずだが、配置としての不変性は要素の置換も許すので別の可能性がある）。
