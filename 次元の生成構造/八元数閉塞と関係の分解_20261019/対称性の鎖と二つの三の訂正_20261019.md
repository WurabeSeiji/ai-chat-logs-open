### 数値で確認したこと

- dim so(8) = 28、dim so(7)（1 を固定）= 21、dim g₂ = 14。
- **g₂ ⊂ so(7)**：rank([so7; g2]) = 21（so(7) 単独と同じ）。
- **so(7) ⊖ g₂ は 7 次元**（21 − 14 = 7）で、g₂ の随伴で閉じる（漏れ 1.1×10⁻¹⁵）。その中の一点の g₂ 軌道は 6 次元（= S⁶）。**G₂ の 7 次元表現**で、既約。
- su(3)、so(4)、so(3) は前段のメモで測ったとおり（`内と外の選択問題_…md` §1.2）。

### 言い方（Claude Code の指摘で訂正）

当初 Claude（chat）は「so(7) は三対性の Z₂ で固定される部分群」「閉塞は三つの役のうち二つを同一視する」と書いたが、**どちらも不正確**。

- 三対性の位数 2 の自己同型で固定される Spin(7) は、8_v に 8 次元のスピノル表現として作用し、1 + 7 ではない。ここでの so(7)（1 を固定し 1 + 7 に作用する）とは、三対性で結ばれた別の埋め込みである。
- 正確には：**閉塞は一つの役の中で 1 を固定するだけ。積は三つの役すべてで 1 をそろえることを要求する。その差が 7 次元。** G₂ は、互いに同値でない二つの Spin(7) の共通部分とも書ける。
- 主張の中身（差の 7 が三対性の一段分）は変わらない。

### 読み（計算結果ではない）

- これまで「閉塞が見るのは 22（= 21 + スケール）、積が見るのは 14、その差 8 の分だけ閉塞を満たす配置の大半は積の対称性から外れている」と書いてきた。三対性の枠で言い直すと、**その差は三対性の一段分**にあたる。
- 形の空間が閉塞の見方と積の見方で **N = 5 から分かれる（8 と 9）**（`正誤と補足_20261019.md` §3）のは、この 7 次元が配置に効き始める点だ、と読める。**これは読みであって計算ではない。**

### 二つの so(4) の区別（混同しないこと）

- Claude Code のメモ §5 の表で ℍ の段に書いた so(4) は、**ℍ 自身に q ↦ aqb̄ で作用する**もので、左右の su(2) ⊕ su(2) に分かれる。

- 次元はどちらも 6、代数の型も同じだが、別物。

## 2. 『二つの三』メモの訂正（二点）

### 2.1 「色の中和が式で出た」は恒等式だった

`二つの三_閉塞の三相と内部のZ3_20261019.md` §3 の

> どの配置でも S + ZS + Z²S = 3 ×（span(1, ℓ) への射影）（誤差 10⁻¹⁴、k = 1, 2, 3 で確認）

は、**位数 3 の線形写像なら何でも成り立つ恒等式**（群平均 (I + Z + Z²)/3 は固定部分空間への射影。1 + ω + ω² = 0 から自動）。数値で確かめる対象ではなく、物理の結果でもない。「恒等式から出る数値を確かめたと書かない」という記録の規則に当たる。

**言い方を次に直す。**

> Z₃ の軌道の和は固定部分空間に落ちる（群の平均の一般的な性質）。**非自明なのは、その固定部分空間がちょうど span(1, ℓ) の 2 次元であること**と、Z が G₂ の元なので閉塞解を閉塞解に写すこと、この二つだけである。

§5 の「色の中和が式で出た」という書き方も同様に直す。

### 2.2 「Z は空間と電荷を混ぜる」は分け方に依存する

同メモ §2 の「Z は空間と内部を混ぜる。内部だけの回転ではない」は、**ℓ を内部の半分に置く分け方を選んだ観測者から見た記述**。Z が組にする平面 (vᵢ, Qᵢ) は、ℓ を掛けると eᵢ が ℓeᵢ に移るという対にすぎない。

**しかも、指摘より強いことが数値で出た。**

| 分け方 | 部分代数か（漏れ） | Z の時空↔内部の混合 |
|---|---|---|
| 時空 = span(1, e₁, e₂, e₃)（ℓ は内部側） | 0.0 | **1.500** |
| **時空 = span(1, ℓ, e₁, ℓe₁)（ℓ を時空側に）** | 0.0 | **3.6×10⁻¹⁵** |
| ランダムな分け方 10 本 | ― | min 0.636 / 中央値 1.388 / max 1.488 |

ℓ を含む四元数部分代数 span(1, ℓ, A, ℓA) を時空の半分に取ると、**Z はその半分を保ち、混合は厳密にゼロ**。そのとき Z は時空ブロックの中の一つの平面を 120° 回すだけ（時空ブロックでの回転角は 0°, 0°, ±120°）。

**したがって「thirds は空間と電荷をまたぐ」は、観測者が ℓ を内部側に置いたときの記述であり、分け方の選択である。** ℓ を時空側に置く観測者にとっては、Z はまったく混ぜない。同メモ §5 の「同じ三相が中性にも有色にもなる」も同じく分け方の話で、それ自体は正しいが「分け方の選択による」と明記する。

**言い方を次に直す。**

> Z が組にする三つの平面 (vᵢ, Qᵢ) は、ℓ を掛けて eᵢ ↦ ℓeᵢ とした対である。**観測者が ℓ を内部の半分に置く分け方を選んだとき**、これは空間と電荷の対として見える。ℓ を含む四元数部分代数 span(1, ℓ, A, ℓA) を時空の半分に取る観測者にとっては、Z は時空の半分を保ち、混合は厳密にゼロ（3.6×10⁻¹⁵）。**thirds が空間と電荷をまたぐかどうかは、分け方の選択である。**

## 3. 残っている問い（Claude Code の提案を採る）

標準模型では、**色の三対性と超電荷の三分の一が連動している**（ゲージ群 SU(3)×SU(2)×U(1) を割る Z₆ による同一視）。それに相当する関係がこの系で出るかどうかが試金石になる。

- いまのところ出ている階段は su(3) → su(2) → 自明で、**U(1) が無い**。Z₆ の同一視に相当するものも無い。
- トライアリティ（Z₃ の軌道の分類、k = 1 でも持てる）と、巻き数としての電荷（内部 su(2) の位相、内部が開かないと持てない）の関係も未決。
- この二つが同じ一つの関係として出れば、e/3 の根拠になる。出なければ、thirds は色の側だけの話で、電荷の三分の一とは別物ということになる。

## 4. Claude Code の観察への応答（記録）

Claude Code が伏せていた四点のうち、こちらが**別の道に進んだ**のは第一点。既存の符号ベクトル分類（tRQ₁Q₂Q₃、16 個で一世代）には収束せず、SU(3) → SU(2) → 1 の階段と Z₃ が出た。SO(10) の 16 とも結びついていない。**この食い違い自体が情報で、どちらが正しいかはまだ決められない。** 既存の分類との突き合わせは、次にやるべきことの一つ。

第二点（閉塞だけでは選別にならない）はそのとおりで、`kのスペクトル…md` §9 に「一般値より下にロックした配置を系統的に探す」と書いた。ただし**ロックをまだ力学ではなく「k が下に落ちること」で定義している**のは Claude Code の指摘どおりで、動力学による選別はまだ手付かず。
