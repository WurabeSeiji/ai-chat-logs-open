# 主張 v2（仮説提案版）——波の周期表：巻き数番地と観測時計による粒子分類の仮説

作成日: 2026-08-06　状態: 主張案（木原レビュー待ち）。
**論文の性格: 仮説提案論文**。証明論文ではない。提案の価値は「独立に確立された
実測群が、一つの分類仮説の下で標準模型の粒子構造と同時に接続されること」で測る。

## 要旨骨子（物語の背骨）

出発点は xyztRQ 符号ベクトル仮説だった——粒子とは6軸のどこに巻きを持つかの
ラベルである、という思考実験（光子=(0,0,0,0,R,0)、W±=(0,0,0,±t,0,0)、
グルーオン=(0,0,0,0,0,Q)）。本稿はこの仮説を、**波の形だけから**（力学は既公開の
二系のまま・粒子概念を一切仮定せず）実測で作り直し、標準模型が予言する粒子構造
——素電荷の一意性、クォークの1/3電荷と閉じ込め、フェルミ/ボーズ統計、
中性フェルミオン、無質量ボゾン——に接続できることを示す。
あわせて前論文（空間軸3軸と固有時間の創生）が未解決課題として明記した
「電荷が±1に安定せず複数の値に分布する」問題が、本仮説の下では**矛盾ではなく
予言**に転じることを示す。これらを束ねる分類仮説を**「波の周期表」モデル**として
提案する。

## 提案する仮説（本論文の主張本体・5本柱）

**柱1（周期律）**: 粒子種の分類子は U^n=I の有理番地である。土台は実測された
普遍時計（ω=π/72/step が N=4〜144 全域で成立・±0.1%）＝単一の U^144 時計格子。
種は「番地（巻き数）×時計との関係」で分類される。

**柱2（電荷則）**: 電荷は Q_em = m/3（m=生η巻き数）であり、支配的観測時計
（分母3——タング幅比461の実測に基づく）が「3巻き=素電荷1」と読む。帰結:
- u型 m=+2 → +2/3、d型 m=−1 → −1/3、電子 m=−3 → −1、ν m=0 → 0
- **閉じ込め＝mod3可読性**: 自由に読出せる種は m≡0 (mod 3) のみ。
  クォークの1/3電荷と単独不可視は同じ一つの事実の二面である。
- 検算: 陽子uud=+3→+1、中性子udd=0、全ハドロンの整数電荷が自動。

**柱3（統計則）**: フェルミ/ボーズの区別は空間回転ではなく**時計の二重被覆**に
住む。状態位相は観測回帰ごとに {0, π} に量子化され（実測・3桁）、フェルミオン的
種（奇数倍音＝偶χ周波数）は両シートを訪れ（被覆度2）、ボゾン的種は訪れない
（被覆度1）。スピン統計の対応がモデル内で成立する。

**柱4（質量則）**: 質量は番地の属性ではなく**海（真空）との関係量**である。
孤立番地は巻きシフト対称性により全てユニタリ等価（実測）——粒子の個性は
海が分化させる（海中の性質は約数類 gcd(m, ne) のみに依存・実測）。
時計にロックした種（ρ=1/1）だけが無質量で安定（光子）、他は共鳴となる。

**柱5（周期表の構成）**: 表は二枚看板である——(a) **孤立安定元素表**
（U^144格子上の純粋番地種・全て自己複製で安定）×(b) **海中寿命表**
（海結合が淘汰: 帯電で長寿命・中性で短寿命・複合で中性化）。
実観測される「粒子」は(b)の準安定階層である。この上に標準模型62種
（クォーク36・レプトン12・グルーオン8・γ・W±・Z・H・G）の割当案を与える。

## 仮説を支える実測（証拠列——証明ではないことを明記）

1. 時計普遍性（N=4..144, ±0.1%）
2. 閉じ込め検定: クォーク型（m≢0 mod3）は孤立で厳密に非可読（f_read=0のまま）、
   海中ではハドロン化（m≡0複合）の分だけ整数電荷単位で可読化。電子型は
   最初から可読。
3. 中性フェルミオンの存在: 純m=0・フェルミオン帯種が被覆度2（Qz2=1.00）——
   ν行が成立。
4. Z₂位相量子化の普遍性と被覆度のパリティ依存（スピン統計対応）。
5. 読出し整流: 観測時計J=3のみが全荷電内容を|q|=1に読む（J=4は電荷消失・
   J=5,6は分散）。素電荷の値 sin²(23π/124)=√(4πα) は既公開実測と接続。
6. 巡回保存と簿記恒等式: 巻き数電荷は mod ne の巡回保存（帯域内で厳密CV≈0）、
   ΔQ3=−3ΔW（精度7×10⁻¹⁰）——読める電荷は消えず中性複合に隠れる。
7. 等価性定理3件（巻きシフト・約数類・χ帯平行移動）——「何が種を分化させ
   何が分化させないか」の地図。

## 既存課題への接続（本仮説の説明力）

- **前論文§9.5「電荷が±1に安定しない」**: 状態側では海駆動の倍加・反転ウォーク
  （実測）が巻き数を分散させ続ける。しかし分母3の観測時計はその全生成物を
  |q|=1に折り返して読む（実測）。**「電荷の多値性」（状態側）と「素電荷の普遍性」
  （読出し側）は矛盾なく同居する**——未解決課題が仮説の予言に転じる。
- **クォークの1/3電荷問題**: Q_em=m/3 の下で分数電荷と閉じ込めは同一の機構
  （mod3可読性）。「なぜ1/3か」と「なぜ単独で見えないか」に別々の答えは要らない。
- **反物質の生成**（既公開実測）: 電荷共役=η反転はスペクトル対称・対生成は
  ウォークの必然。
- **重力の弱さ**: スピン2はℓ=1量子2個の複合としてのみ存在（生成子スペクトルに
  ℓ=2線形枠なし・実測）——結合の二乗抑制 α_G=(m/M)² が構造的に従う
  （double copy構造と同型）。重力が弱い理由と検証が難しい理由は同一構造。

## 仮説の弱点と未検証部分（正直な登録——提案論文でも三層分離を維持）

1. **世代の起源は未解決**: 世代=χ帯位置の素朴仮説は反証済み（3帯で質量5桁一致
   ＝χ帯平行移動対称性）。帯比・結晶学的位数{3,4,6}・複合階層が残る候補。
2. W/Z行: 低エネルギー実験室では直接生成不可（構造的）。有効接触頂点の
   1/δ²スケーリング検定（Fermi理論の道）が指定済み・未実施。
3. グラビトン行: 四重極2ω線は全Nで実在（比2±6%・コヒーレント）だが
   事前基準は1/3のみ通過——枠較正が未了。
4. レジスタ位数 ne=16 は現モデルの仕様: 割当の詳細（±5,±7の帰属等）は
   ne 依存の可能性。ne可変系での再検が必要。
5. Q_em=m/3 と既公開の透過率電荷 √(4πα) の二読出しの統一は未完
   （素電荷の「値」と「単位」の関係）。

## 反証条件（仮説提案としての退路の明示）

1. 分母3以外が支配する閉鎖系で |q|≠1 の安定読出しが構成されれば柱2は棄却。
2. ω≠π/72 の定常時計がどこかのNで再現されれば柱1は棄却。
3. 被覆度がχパリティと独立に変わる種が構成されれば柱3は棄却。
4. 海なしで種の性質（質量・寿命）が分化する実測が出れば柱4は棄却。
5. m≢0 (mod3) の種が単独で可読になる構成が見つかれば閉じ込め則は棄却。
