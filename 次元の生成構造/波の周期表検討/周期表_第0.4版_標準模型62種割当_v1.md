**電荷則**: Q_em = m/3（mは生η巻き数）。観測時計J=3は「3生巻き＝素電荷1」と読む。
- u型クォーク m=+2 → +2/3、d型 m=−1 → −1/3、電子 m=−3 → −1、ν m=0 → 0
- **閉じ込め＝mod3可読性**: 単独で読出せる自由粒子は m≡0 (mod 3) のみ。
  クォーク（m≢0）は単独では非可読番地＝閉じ込め。色＝mod3非可読の生巻き残差
  （＝簿記W・隠れ電荷の帳簿v6と同一物）。
- 検算: 陽子uud: 2+2−1=+3→Q=+1 ✓／中性子udd: 2−1−1=0→Q=0 ✓／
  π⁺(ud̄): 2+1=3→+1 ✓／全ハドロンで整数電荷が自動 ✓
**世代則（候補）**: 世代＝χ倍音帯（分解能階層）。階層比α⁻¹（古典電子半径:
コンプトン:ボーア=1:137:137²）が帯間比の候補。
**統計則（v14主定理・実測済）**: フェルミオン＝χ奇数倍音（偶χ周波数）＝Z₂被覆度2
／ボゾン＝被覆度1。

## 3. この割当が出す検証可能予言（モデル内で検定可能）

1. **閉じ込め検定**: m≢0 (mod3) の純粋種は海中で単独読出しが原理的に失敗し、
   m≡0 の複合（3の和）だけが読める——v5整流計の拡張でそのまま検定可能。
2. **グラビトンℓ=2予言**: v12でℓ=±2モードは凝縮体に不在だった。zR面
   （質量-半径面）の集団励起を立てればℓ=±2が出るはず——空間時間論文の
   質量読出し面での回転荷測定として設計可能。
3. **ν行の白黒**: m=0かつ被覆度2（中性フェルミオン）がモデルで許されるか——
   v14でχ奇束（偶周波数）×m=0セルは構成不能だった。構成法を変えて
   「m=0・χフェルミオン帯」種を作り被覆度を測る＝ニュートリノ存在検定。
4. **世代=χ帯の質量比**: 帯を1,2,3階層に変えた同一m種の質量比が
   α⁻¹級の階層を示すか（分散補償Gram＋帯掃引）。
5. **W/Z の t巻き**: 時間軸巻き（自前時計の離調番地）を持つボゾンが
   有質量になるのは引き込み実験（運動=質量=自前時計）と整合——
   離調を制御注入した種の質量測定で検定。
