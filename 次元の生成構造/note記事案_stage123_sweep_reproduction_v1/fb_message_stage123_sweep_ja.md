# インフレーションを起こす力学は、3つの部品でできていた

詳細はコメント参照

7月に報告した、測定にかからない種（10⁻³⁰）がひとりでに何十桁も指数増幅する現象。その力学を3つの部品に分解した。
部品1は波の集団を回転させる装置と時計。部品2は波の大きさを捨て向きだけで相互作用を組む正規化。部品3は相互作用の半分だけを取り出し回転を実回転にする操作。
増幅が起こるのは、部品2と部品3が両方そろっているときだけである。
どちらか一方を外すと、1歩目で種よりはるかに大きいノイズが注入され、増幅は観測できない。
正規化を最初に1回だけ済ませる手抜きは、最も激しく壊れる。正規化は毎ステップの掟である。
系の大きさ N=3 から 40 まで228通り走らせ、すべてで1歩目が種の大きさに留まり、ほとんどで7月と同じ形の増幅曲線が現れた。特定の系の偶然ではない。
終状態では、波の向きはあらゆる方向に散り、振幅はほぼ完全に揃う。
