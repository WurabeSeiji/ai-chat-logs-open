# 加速度最終実験・無改変対照テスト結果

実施日：2026年7月18日

## 1. 対象の確定

加速度実験のうち、空間位相 `chi` と独立な時間位相候補 `tau` を用いた面積スイープ系列の最終段階を対象とした。

対象スクリプト：

```text
run_ab_two_body_chi_tau_native_inverse_area_extended_sweep_preliminary_v1.py
```

このスクリプトは、次の初期 `chi-tau` 面積スイープスクリプトから、パラメータ定義と計算関数を直接 import する。

```text
run_ab_two_body_c1_internal_calibration_chi_tau_area_sweep_preliminary_v1.py
```

したがって、無改変対照環境には両スクリプトを含めた。

## 2. 原本と複製先

原本：

```text
波の情報読出し/20260711/
```

複製先：

```text
次元の生成構造/対照実験_加速度最終実験_v1/
```

複製先は次の二層に分けた。

- `original_snapshot/`：原本スクリプト2本、原本成果物6点、最終検証メモを保存する。
- `control_run/`：同一のスクリプト2本を置き、原本成果物を上書きせずに再実行する。

## 7. 対照判定

加速度最終実験の複製環境は、原本と同様に動作した。

確認した範囲は次のとおりである。

1. 依存スクリプトを含む実行コードは原本と同一である。
2. 実行は正常終了した。
3. 検証フラグは `true` である。
4. 全主要カウントと数値範囲は原記録と一致した。
5. 全6成果物はバイト単位で原本と完全一致した。

したがって、後続の対照実験は、この `control_run/` を無改変基準として進められる。

ただし、この判定は原実験の再現性を確認したものであり、実験の物理的解釈を追加で正当化したものではない。
