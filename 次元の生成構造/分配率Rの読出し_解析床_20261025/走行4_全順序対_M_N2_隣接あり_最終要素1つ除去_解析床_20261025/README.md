# 走行 4（解析床）：初期化後の配列の最終要素を 1 つ除く（2026-10-25）

走行 1（解析床、`../走行1_全順序対_M_N2_隣接あり_解析床_20261025/`）のプログラムに 1 行を足しただけ：床（N² の解析床）を読んだ直後に
`z0=z0[:-1]; ea=ea[:-1]; eb=eb[:-1]`（配列の最終要素と、辺リストの同じ末尾を落とす。差分 `diff_droplast_vs_run1.txt`、変更 1 行）。
走行 3 の「乱数で並べ直す」1 行をこれに替えた形。床は走行 1 の `floors_all/` をそのまま読み、`one_step` は 2026-09-05 正本と同一、種なし。基準は走行 1。

N² の並び e＝i·N＋j で最終要素は (N−1, N−1)、最後の頂点の自己対。位相のみの生成子では値を 0 にしても `angle(0)=0` の単位波として参加し続けるので、
除くには辺リストから落とす必要がある（その 1 行がこれ）。残る M−1 個の値は床のまま（再構成しない）。

環境：`~/.venvs/stage123_control_py39`（Python 3.9.6、numpy 2.0.2 Accelerate）。N ∈ {3,4,5,6,8,10,12,15,20,25} × den ∈ {N, 124} × 500 step。所要 165 秒。
