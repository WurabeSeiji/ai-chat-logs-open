# 走行 3（解析床）：走行 1 の初期配列を乱数で入れ替える（2026-10-25）

走行 1（解析床、`../走行1_全順序対_M_N2_隣接あり_解析床_20261025/`）の走行系には触れず、入口で初期配列 {zₙ}（N² の解析床）の並びだけを乱数で入れ替える。
唯一の変更は `run_sweep_from_parents_v1_shuffle.py` の 1 行 `z0=z0[np.random.default_rng(20261025+N).permutation(z0.size)]`（差分 `diff_shuffle_vs_run1.txt`、変更 1 行）。
床は走行 1 の `floors_all/` をそのまま読む。`one_step` は 2026-09-05 正本と同一。種なし。基準は走行 1。

解析床では値の情報が明示されている：位相は 90°·((i＋j) mod 4)（符号ゲージを除く）、振幅は parity (i＋j) mod 2 のクラス。
位置を置換 P で入れ替えると値のラベルは k∘P になり、A（添字を共有する対が 1）が要求する (i＋j) mod 4 の格子と一致しなくなる。
一致が保たれるのは P が頂点の置換（行と列を同時に並べ替える）か符号ゲージに相当する場合だけ。乱数置換は一般にそのどちらでもない。

環境：`~/.venvs/stage123_control_py39`（Python 3.9.6、numpy 2.0.2 Accelerate）。N ∈ {3,4,5,6,8,10,12,15,20,25} × den ∈ {N, 124} × 500 step。所要 169 秒。
