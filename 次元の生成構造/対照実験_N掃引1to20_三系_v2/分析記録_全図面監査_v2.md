### ④【最重要】この系には性質の違う二つの法則がある

| 事象 | 決めるもの | 法則 | R² |
|---|---|---|---:|
| 空間の誕生 | **線形部** | τ_space = 9.892 − 48.611·ln A（A = n·δ） | 0.99987 |
| 物質の飽和 | **非線形部** | τ_sat ∝ P_F^(−1.09)（P_F = n_F·δ²） | 0.995 |

線形部の生成子は複素和 Σ C の偏角だけで決まり、非線形部は読出し R（パワー比）に比例する。
**見る事象がどちらの部分に属するかで、効く量が変わる。**
本文 §8 は「効くのは複素振幅の和である」と一般則のように書いている。誤り。

決定的な整合: B3 は P_F = 0 なので τ_sat = ∞ となるはずで、実際どの強度でも永久に飽和しない。
一方 τ_space は A = 3δ の直線に乗る。**B3 は両法則を同時に満たす。**

## 第2級の発見 — 本文に追加すべきもの

### ⑥ 時計には「生まれる」と「定着する」の二段階がある

τ_lock（読み出した ω が基準 π/72 の 1% 以内に入る更新回数）は本文で未使用。

- 混合・T=4000 では **N≥15 で定着しない**（τ_lock = None）。τ_time = 2 で生まれてはいる
- **位相相殺は定着を激変させる**: 混合 δ=10⁻² で **15638 → 18（870 倍速）**、
  δ=0.0316 で 3460 → 1799、δ=0.1 で **96 → 6**。r1 と r2 は完全一致
- 中性型では δ に対して非単調: 16, 16, 15, 8, 2, **131**（δ=0.1 で跳ぶ）

**本文 §8（主張6）は τ_space しか論じていない。位相相殺の効果は時計にも及ぶ。**

### ⑦ 時計の角振動数 ω 自体が条件依存

132 走行のうち **67 件が基準 π/72 = 0.043633 から 5% 以上ずれた**。

- B3 は全条件で ω = 0（時計なし）
- **電子型・δ=10⁻²・N=4 で ω = 0.4327（基準の 9.9 倍）**
- 電子型・δ=0.0316・N=12 で ω = 0.1647（3.8 倍）

### ⑧ 物質の「量」を一度も定量していない

物質分率 f_seed（奇数帯パワー分率・後半中央値）。

- 飽和前は **f_seed = n_F·δ² 厳密**（投入したフェルミオンパワーそのまま）
- 飽和後は **f_seed ≈ 1/2**（奇数と偶数がほぼ等分配）
- B3 は全条件で厳密に 0

「物質の指標」total_closure（実装定義 |Σz²|/Σ|z|²、0 なら真空）も同じ場所で 3 桁跳ぶ。
飽和後の値はモード依存で、**中性型 3.4e-2 > 電子型 1.8e-2 > F5/混合 1.3e-2 > B3 9.3e-3**——
支持セル数（16 < 64 < 128）と**逆順**である。

### ⑨ 少数体（N=3,4,5）は定常状態を持たない

4panel の次元パネルを全数確認した結果。

- **N=3, 4**: n_eff が全区間で 1〜5 を振動し続け、定常状態が無い
- **N=5, 6**: 間欠的なバースト（静穏期と激しい期間が交替）
- N≥8: 滑らかに 1 へ落ち着く（ただし飽和すると再び振動する）

### ⑩ 飽和後は n_eff が振動する

δ ≥ 0.0316（T=42000 内で飽和する条件）では、飽和後に n_eff が 1〜5 を往復する。
**本文 §9 の n_eff 表は δ=10⁻²・T=4000 の未飽和状態の値**であり、
「1 枚の平面が卓越する」という描像は飽和前に限られる。

### ⑪ 排他比は N にも 120 倍依存する

混合・T=4000・δ=10⁻²: N=3 で 57、N=19 で 41、N=20 で 0.47。単調でない。

## 本文の訂正が必要な箇所

### ⑫「8 強度すべてで完全に一致」は 7/8 だった

中性型と電子型の空間誕生時刻は **δ=10⁻¹⁵ でだけ 1644 対 1643 と 1 回ずれる**。
この点は数値精度の床に近く、シードなし（1624）と区別がつかない領域である。

### ⑬「N≥12 で特段大きな変化はない」は自分の縮退リストと矛盾

同じ節で縮退 N として 13 と 20 を挙げている。中性型 n_eff は N=13 で 2.082、N=20 で 2.567。
さらに **N=20 では align = 0.7509 < 0.8 で「3 次元が確定」しない**。

検証した仮説「縮退している N では助走が長い」は**否定された**
（corr(n_eff, τ_space) = +0.089 / −0.164 / −0.276）。両者は独立である。

### ⑭ 支持セル数は強度にも依存する

弱い 2 点では支持が狭い（中性型 10、電子型 34、F5 は 66 → 96 → 128 の 3 段階）。
本文は δ=0.1 の値だけを書いている。

### ⑮ 前論文の「曖昧さ ~1/M」がこの計器では再現しない

多 N 要約図の「曖昧さの M スケーリング」パネルで、1−align を M に対して両対数で描くと、
測定点は 1/M 参照線の上下に 1 桁散らばる（混合・中性型・真空すべて）。
前論文は別の量（回転軸と外積の一致度）で測っており直接の矛盾ではないが、
**frame 整合度では 1/M スケーリングは見えない**ことを明記すべきである。
