## 6. 記録項目（力学・条件に非干渉）

`RecordingEngine.step()` が毎步1回だけ追記。`_readout()` は純関数（`self.C` を読むだけ・
副作用なし）なので再呼出しして node ごとの R = scale·sin²θ を取得する（scale=1 ゆえ R=r）。

| 記録 | 定義 |
|---|---|
| `r_mean` / `r_med` / `r_min` / `r_max` | エンジンの R（node ごと）の統計＝**系全体の混合率** |
| `r_raw` | 生パワー版 P奇/(P奇+P偶)（隣接集約なし・対照） |
| **`r_nopump`** | **ポンプ帯を分母から除いた物質側の r**（H1c が種に対して測った量と同型） |
| `dist_alpha` / `absdist_alpha` / `dist_alpha_nopump` | α 根 R_α との距離 |
| `bands` | **全16帯のパワー Pk[k]**（steps × Nn） |
| `odd_power` / `odd_amp_max` / `even_power` / `even_power_nopump` / `total_power` | 帯パリティ別の総量 |
| `conc_all` / `conc_k3` / `dom_m` / `q_hat` / `readable` / `k3_power` | E1/E2（巻き集中度・優勢巻き・Q̂・単独可読性） |

JSON には窓中央値と `band_rise_even`／`band_rise_odd`（帯ごとの立ち上がり時刻）・
`band_power_med`（帯ごとの窓中央値）を記録。npz に全步時系列。

### 7.1 三系の τ_space 比較

| N | neutral | electron | **vacuum** |
|---|---|---|---|
| 3 | 145 | 145 | **1092** |
| 5 | 180 | 180 | **1166** |
| 12 | 224 | 224 | **1624** |
| 20 | 277 | 277 | **1617** |

物質あり 145〜313 に対し、シードなしは 991〜1899。**空間は生まれるが誕生が 5〜7 倍遅い。**
奇数倍音が無ければ頂点は厳密零なので、crossing は線形部だけで到達している。
すなわちシードは crossing を加速していた（記録・機構は未解明）。

### 7.2 中性 vs 電子型（電荷の効果）

離散量（τ_space・τ_time・τ_lock）は**全 N で完全一致**。連続量の最大相対差は
align 3.7e−10・closure 2.8e−10・ω 8.7e−11・f_seed 1.2e−12・r 8.5e−11・
**r_nopump 0.0e+00**。n_eff のみ 3.6e−3（N=3,5 の低 N 領域）。

差が出るのは毛の記録だけ——中性 m̂=+0.0 / Q̂=+0.000、電子型 m̂=−3.0 / Q̂=−1.000、
集中度はどちらも 1.0000。**電荷は空間・時間・混合率に影響しない**（毛は帳簿上の住所）。

### 7.3 r と α 根の関係（本実験の主目的）

- **系全体の r = 1.00e−4 ≈ δ²** で全 N ほぼ一定。α 根 0.697178 から 0.697 離れている
- **r_nopump = 1.000000**（ポンプを除くと物質は完全に奇数帯側）。α 根との距離は
  **+0.302822 ＝ 1−R_α** にちょうど一致
- vacuum は **r = 0.0 厳密**——新柱6 の真空固定点が成立

**結論（記録）**: 本レシピの生成物の混合率は α 根に来ない。α 根 0.697178 は
H1c/灰色猫が測った**特定の束の組成**（χ奇倍音 29,31,33 × m=−3 の電子束・実測 r=0.6986）
であり、シードから生成された物質の系全体／物質側の混合率とは別の量である。

### 7.4 偶数帯の立ち上がり（V6）

neutral / electron の**両方で、偶数帯 k=4,6,8,10,12,14 が全 16 点で立ち上がる**。
ただし**立ち上がり時刻は τ=1**（遅れではない）で、窓中央値のパワーは
`even_power_nopump_med ≈ 5.5e−17`——ポンプ（1.0）に対して 10⁻¹⁷ のオーダー。
3次選択則の1回作用で全帯に同時に微小値が入る描像であり、「2段目に δ⁴ で遅れて立つ」
という走行前の予想は**時刻については誤り**、振幅の階層としてのみ正しい。
δ の冪の確定には δ 掃引が必要（未実施）。

vacuum では 6帯すべて **0/16 点**——奇数倍音がなければボゾン帯も生成されない。

図をモード別に分けるための修正（`_rename()` 追加のみ・力学と記録には非干渉）後、
三系を全て再走行した。**判定は完全に一致**（V1 の失敗 N・V2/V3/V4・V5 の r 範囲
[9.9966e−05, 1.0851e−04]・V6 の立ち上がり帯数 96／0）。走行時間も 453 s／560 s／221 s
で同等。決定論が保たれている。
