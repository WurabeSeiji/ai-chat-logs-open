### 1.5 力学の定義（実装と正本で照合済み）

**線形部（共有O・正本 `VertexEngineV2._linear`）**

```
θ̄_e = arg( Σ_k c_e[k] )  →  LowRankSystem.set_theta(θ̄)
     →  σ_max（warm-start 冪反復・wp を持ち回す）
     →  各レジスタ列に Cayley 直交步 (I − γK̃)⁻¹(I + γK̃)
```

**読出し（生成子側・`_readout`）**

```
Pk[e,k]  = Σ_η |C2[e,k,η]|²
Av[v,k]  = Σ_{辺 e ∋ v} Pk[e,k]                （隣接辺への集約）
comb[e,k]= Pk + (Av[ia]+Av[ib]−2Pk) = Av[ia]+Av[ib]−Pk
Pf = Σ_{k 奇}      comb        （フェルミオン型パワー）
Pb = Σ_{k 偶, k≠0} comb        （ボゾン型パワー・零モード除外）
θ  = atan2(√Pf, √Pb)
R  = scale · sin²θ
```

**非線形部（媒介頂点・`_nonlinear`）**

```
W    = ifft2(C2, axes=(1,2)) × (Nn·Nη)
rate = 0.5i ( R·(cA·W − cB·W̄) + (cAR·W − cBR·W̄) )
       cA  = A[ia]+A[ib]−2a²      cB  = B[ia]+B[ib]−2z²
       cAR = AR[ia]+AR[ib]−2Ra²   cBR = BR[ia]+BR[ib]−2Rz²
       Ra² = R·a²                 Rz² = R·z²
nsub = max(1, ⌈Lmax / H_MAX⌉)     Lmax = max|rate₀| / max|W|
RK4 部分步を nsub 回
C    = fft2(W, axes=(1,2)) / (Nn·Nη)
```

> **重要（実装上の事実）: 第2群 `(cAR·W − cBR·W̄)` も R に線形比例する。**
> `cAR`・`cBR` は `Ra² = R·a²`・`Rz² = R·z²` の集約から作られるためである
> （正本 stage2:122-131）。したがって **R ≡ 0 のとき頂点式は厳密に零**である。
> 実測: 真空宇宙 δ=0 で |頂点レート| の最大 = 5.85e-29。

毛の和則 **m\* = 2·m_pump − m_seed** は、この頂点式から自動的に成立する
（別途 census 実験で巻き集中度 1.0000 として実証済み）。

**不採用の理由**

②の撤廃を正当化する根拠として「頂点式の第2群には R が掛かっていない」と
記録されていたが、これは**誤読**である（§1.5・正本 stage2:122-131）。第2群も
R に線形比例するため、R≡0 で頂点式は厳密に零であり、G2 は数学的に完全に
正当な短絡である。

②を外しても数学的には同値だが、v2 は毎步 `ifft2 → fft2` の往復を実行する。
この往復は浮動小数で厳密でなく（実測 1.24e-16/步）、**その丸め誤差が
奇数帯（＝物質帯）に漏れる**。結果、物質が厳密に 0 であるべき真空宇宙に
9.66e-15 の物質が湧き、それが R を非零にして頂点を回し始める——自己維持する
数値アーティファクトとなる。

> **「真空宇宙は空間だけ作り、物質は厳密にゼロ」は本シリーズの中心的な実測結果
> （TB2d／ゼロ点対照 `Z5_vacuum.P_matter = 0.0`）である。②はこれを
> ビットレベルで壊し、代わりに得るものが一つもない。**

したがって G2 は「無駄な IF 文」ではなく、**真空を厳密に真空のまま保つ装置**である。

**v2 ファイルの扱い**: 削除せず残置する。理由は (a) 過去版を残す原則、
(b) v2 で取得された 4 実験を後から再解釈するために必要。

### 設計原則（ゲージ構造）

- **個体の位相はゲージ、対の相対位相が物理**。共通位相変換で全対読出しは不変
  （A5 実測 2.9e-15）。片側の π シフトは**ゲージ変換ではなく状態準備（電荷共役）**
  であり全 φ_ch を π 反転させる（A5 実測 2.4e-16）。±電荷の表現は状態側が担う。
- **θ は再実装しない**（正本＝two_body_v1.toy.theta_from_ab。g_pair_flow は引数で受ける）。
- 「同符号＝斥力」への割当は読出しの外＝辞書（翻訳層）——三部作の予言どおり
  距離辞書完成と同時に自動判定（DL7-F2）。

### 資格審査アンカー（三部作第一部）

A1 ヌル定理（搬送波あり交差 2.7e-17）／A2 結合地図（Δk=±2 全対＋特別対(1,1)＝
負周波数枝の c0 アンカー、c=0.5 厳密・他は零 2.8e-15）／A3 流れの恒等式
（4.6e-15・φ 半回転反対称 1.5e-15）／A4 θ 正本受け渡し（5.0e-16）／
A5 ゲージ構造（上記）。
