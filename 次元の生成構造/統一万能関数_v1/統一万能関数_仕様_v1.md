## 1. 統一万能相互作用関数（unified_interaction_v1.py）

### UnifiedEngine（多体・毛込み・テストベッド標準）

- 状態: C2 ∈ ℂ^(M×Nn×Nη)。M=N(N−1)/2 関係波・Nn=帯レジスタ・Nη=毛レジスタ

  σ_max（warm-start冪反復）→ Cayley直交步 (I−γK̃)⁻¹(I+γK̃)。
  **N体Cayley系（LowRankSystem）を毎ステップ内蔵実行**——二系は最初から統一
- **読出し（生成子側）**: 奇/偶帯パワー（隣接辺集約込み）→
  θ=atan2(√P_f,√P_b) → R=scale·sin²θ（一行定式）
- **非線形部（媒介頂点）**: 点ごと積 0.5i(R(cA·W−cB·W̄)+(cAR·W−cBR·W̄))・

## 2.5 統一場の万能読出し関数 v2（曖昧さ保存版・現行）＋選択層

### 設計の要点

> **確定値 = S（選択層・宣言される） ∘ G（曖昧さを保存した読出し）**

v1 の G は「読出し」と「どれを採るかの選択」を一体に焼き込み、確定値を
ひとつだけ返していた（位置の被覆判定 `if |z2|>|z1|`、存在 present の真偽化、
時計 acquirable の真偽化、波数の非零指示）。この設計では「どの選択の下での
値か」を宣言できず、基準値が再現不能になる。**低Nの系では粒子としての存在性・
空間の次元・時間の存在そのものが曖昧であり、確定して見えるのは読出し側の
選択の結果である**——という本シリーズの立場に、読出し関数の型を合わせた。

### 規約 R7（追加）

R1–R6 に加え、**R7 曖昧さ保存**: G は選択をしない。分岐・閾値・二値化・
順序づけ・単一化を行わず、読み値は (値, 重み) の束として返す。不在は真偽値
でなく重み 0 で表す。周期量は円上の値として返し、直線への展開（巻数の累積）
は呼び出し側の責務とする。縮約は関係量への集約までとし、波の添字・セルの
添字は保持してよい（演算対象の構造だから）。

#### 座標時間 t の読出しについて（2026-08-08 追加・重要な訂正）

t は「直接の一次読出しメンバーが無い」だけであって、**読めない量ではない**。
錐の恒等式 x²+y²+z² = t²+R²+Q²（R′²=R²+Q²）から

> **t² = R′² − m² − q²**

として、R′²・m²・q² を独立に読んだ上で**残余として合成して読む**。合成して
読むこと自体が読出しの仕事であり、これを「派生量だから読めない」と扱うのは
誤りである（v1 仕様 §4-4 の記述を本項で訂正する）。

**粒度は関係波 e ごと（M 個）**である。宇宙全体で一つの値にしてはならない
——重力は「ゲージ（空間・時間の目盛）が等間隔でなくなること」として現れる
ため、t を大域一値に定義すると重力の効果が定義上消える。M 本の分布の
広がりが重力赤方偏移に相当する測定量になる。

Gram はエンジン自身の二チャネル分割（帯の偶奇対 k=2j / 2j+1）で作る——
相互作用関数 F が生成子を作るときに使う分割そのものであり、新たな任意構造を
持ち込まない。本メンバーは**スピン読出しではない**（(X,Y,Z) をスピンと解釈
することは主張しない・TB-spin は未確定のまま）。

選択層 selection_v1.py: s_present／s_position_maxmoment（v1 の被覆判定と同一）
／s_position_argmax（一般形）／s_clock_acquirable／s_support_count／
s_occupancy（個数 n=P/ε）／s_unwrap_phase（巻数の累積）。
既定の選択パラメータ（FLOOR_CONTENT=1e-280・FLOOR_OVERLAP=1e-30・
FLOOR_CARRIER=1e-12）は v1 の暗黙値を明示化したもの。

### 数え上げの是正（重要）

v1 の `g_wave_census` は本数を `count = #(振幅²>0)` で返していたが、監査
（N=12・Nn=5）で **到達可能な全セルが例外なく count = M = 66**（パワー 1.0 の
凝縮体も 9.1e-22 の数値塵も同じ 66）となり、`count ≡ M×(power>0)` すなわち
帳簿の台集合以外の情報を持たないことが実測された。個数の量として機能しない
ため v2 では「本数」を返さない。個数は較正で定義する:

- **ε** := 単一局在ドメインあたりの物質パワー（較正値）
- **n̂_P = P/ε**（パワー基準の個数）・**n̂_PR = pr_n / pr_n(単一ドメイン)**
  （局在ドメイン基準の個数）
- 較正実験 `電子の反跳実験/run_tb_epsilon_calibration_v1.py` の実測:
  N=12・Nn=16 で ε=1.000000e-4、pr_n(単一)=2.000000（対蹠二点構造＝柱7）、
  加法性は t=0 で相対誤差 1e-15 級、T=2000 の力学発展後も n̂_PR は
  1.000/2.000/3.000（偏差 0.000）——**個数は測定量として定義され、
  力学の下で整数のまま保存する**。
- 非局在（一様）内容では pr_n = Nn（最大）となり「可算な局在ドメインなし」
  ＝場であって粒子ではない、と読む。
