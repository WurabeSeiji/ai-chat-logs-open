# 素粒子は、なぜ生まれたのか——粒子とは、光の海で閉鎖を完走した稀な波だった

木原範昭
2026年8月4日

標準理論の物理学は、驚くほど多くのことを説明します。素粒子がどう振る舞うか、どう衝突するか、どんな確率で崩壊するか——その精度は驚異的です。

けれど、標準理論が説明していないことがあります。

**光子や電子やクォークといった素粒子が、そもそもなぜ生まれたのか。**

この問いは、時間や空間がなぜ生まれたのかという問いと同じように、理論の外側に置かれています。粒子の種類は、理論の答えではなく、理論への入力なのです。

このシリーズは、その入力を減らす試みを続けてきました。

背景の時空を最初に置かず、複数の波のあいだに Σxₙ² = 0 という二乗閉塞の関係がある——公理はそれだけです。そこから、以前の論文で、空間的に見える三つの方向が自発的に生じる機構を導出しました（種を抜いてもインフレーション的な急拡大は起き、方向は三つで止まりました）。

今回の論文では、その次を導出しました。

**波の形だけから、光子のようにボゾン的に相互作用する波と、電子のように質量と電荷を持ってフェルミオン的に相互作用する波が、生じる機構です。**

## 発想の中心——既定と例外を逆転させる

ふつうは、まず粒子があって、粒子が光を出す、と考えます。

この枠組みでは逆です。

**既定状態は、光の海です。** 公理の二乗閉塞そのものが、質量も電荷も持たない、完全にコヒーレントな共有波——光的な素材——を記述しています。光は作られるものではなく、系の素材が最初から光なのです。

説明を要するのは、物質のほうでした。

## 粒子が生まれる二つの分岐

**第一の分岐は、倍音の偶奇です。** 波はたくさんの倍音でできています（楽器の音色と同じです）。奇数番の倍音でできた波は、半周期ずらすと符号が反転する性質を持ち、これがフェルミオン的な振る舞いの起源になります。偶数番の倍音の波は一価で、ボゾン的です。統計の違いを外から入れる必要がありません。

**第二の分岐は、閉鎖の完走です。** 光の海の中で、波どうしの交換の連鎖が、たまたま整数比の周期をちょうど完走すると、その波は元の状態に厳密に回帰する閉じた波——粒子——になります。完走できなかった関係は、海に留まります。

つまり、

**粒子とは、光の海の中で閉鎖周期を完走した、稀な事象です。**

## 光子と電子が、四つの性質だけで書き分けられる

この枠組みでは、粒子の種類は波の形の四つの性質で決まります。倍音の偶奇、整数比の束縛、コヒーレンス（完全に共有されているか）、そして毛（プラスマイナスの符号を担う搬送波）の有無です。

光子は、毛を持たない、完全に共有された偶数差の波です。完全共有だから質量がゼロ（質量とは共有の破れ——非コヒーレンス——のことだからです）。毛がないから電荷がゼロ。周期の住所を持たないから、束縛されず自由に飛ぶ。

電子型の波は、奇数倍音で（フェルミオン的）、整数比の住所に束縛され（その住所の角度が電荷の値、計算値 0.302822 は物理の無次元素電荷と1億分の16で一致します）、完全共有が破れていて（質量がある）、毛を持つ（プラスマイナスがある）。

そして物質と反物質は、閉鎖完走の幾何が自動的に対で与えます。完走の半分の地点で符号が反転し、全周で元に戻る——粒子と反粒子を別々に用意する必要がありません。

## 物質が「ほとんど無いのにゼロではない」理由

宇宙の光子の数に対して、物質（バリオン）の数はおよそ100億分の6しかありません。なぜこんなに少なく、しかしゼロではないのか。

この枠組みでは、数え上げだけで答えの形が出ます。分解能 N の系には約 N²/2 本の関係波がありますが、閉鎖を完走できるのは整数比の対だけで、その割合はおよそ 2lnN/N。N が大きくなると急激に小さくなりますが、決してゼロにはなりません。物質の稀少さは微調整の産物ではなく、整数比の希少性そのものです。

観測されている100億分の6という比率をこの式に当てはめると、拡大が止まった瞬間の分解能は N ≒ 10の11乗と読めます（これは観測からの読み値であって、導出ではありません——正直に書いておきます）。

## 解明できていないことを、はっきり書きます

この論文は、できたことと同じ明確さで、できていないことを列挙しています。

**クォークのように 1/3 の電荷になる理由は、わかっていません。** この枠組みが導出した電荷は整数比の住所の値であり、クォークの分数電荷や、クォークを閉じ込める強い力の構造（SU(3)型）には、まだ手が届いていません。

**素電荷が特定の値になる理由も、わかっていません。** 住所の候補は数学的には60個あり、そのうちなぜ一つ（値 0.302822 を与える住所）だけが実現するのかは、この系列の最大の未解決問題です。

**より複雑な粒子が生まれる理由も、わかっていません。** 光子以外のボゾン（質量を持つW粒子やZ粒子など）が存在する理由は導出できておらず、判定木の空席として明示してあります。

**質量の階層・エネルギーの階層も、わかっていません。** 質量というものが共有の破れとして生じることは言えますが、電子・ミューオン・タウという世代がなぜ離散的に並び、質量の値がなぜあの値なのか——質量の値は、まだ一つも言えません。

これらは論文の末尾に、三つの階層・十項目の未解決問題として明記しました。課題を曖昧にしないことが、この論文をいちばん強くすると考えたからです。
