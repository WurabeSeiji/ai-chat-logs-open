# Σxₙ² = 0 という式は、生まれつき量子化されていた

これまでこのシリーズでは、Σxₙ² = 0 という式を出発点に使ってきました。

二乗して足したらゼロ。一見すると、全部ゼロという答えしかなさそうな、不思議な式です。この式を閉鎖条件として置くと、位相の関係だけから、位置のような量、加速度のような量、三次元的な方向、波の自発的な分裂といった、理論物理学的な現象がつぎつぎに導出できる——それをひとつずつ論文にしてきました。

ところが最近、順序が逆だったことに気づきました。

この式は、量子的な現象を導出するための道具なのではありません。この式自身が、最初から量子性を内蔵していたのです。

今回は、それを既知の数学の引用だけで確認した解説ノートの内容を、数式少なめで紹介します。

## まず、この式の不思議さから

実数の世界では、二乗は必ずゼロ以上です。だから実数だけで Σxₙ² = 0 を満たそうとすると、全部の成分がゼロという答えしかありません。

ゼロでない答えがほしければ、二乗して負になる数——虚数——がどうしても要ります。たとえば 1² + i² = 1 − 1 = 0 のように。

つまり、複素数はこの理論に後から持ち込んだ道具ではなく、この式が最初から要求しているものです。量子力学はなぜ複素数を使うのか、という古い問いに対して、この式は「ゼロでないのに閉じるためだ」と答えます。

## 要請はもう一つだけ：大きさに意味はない

このシリーズの公理系には、もう一つの柱があります。物理的な内容は比だけであり、状態全体を何倍かしても同じ状態を表す、というスケール無名性です。

x と 2x と 100x は、すべて同じ状態。意味があるのは成分同士の比だけ。

この二つ——Σxₙ² = 0 と、比だけが物理——を合わせると、状態の集まりの形が数学的に確定します。

## 状態空間は、閉じた面だった

Σxₙ² = 0 の解の集まりは、数学で等方錐（ヌル錐）と呼ばれる、原点から放射状に伸びる錐です。

そこに「比だけが物理」を重ねると、錐の中の一本の線（原点を通る方向）がまるごと一つの状態になります。方向だけの集まり——これを数学では射影化と呼びます。

その結果はよく知られた図形になります。複素射影空間の中の二次曲面、射影クアドリック。名前はいかめしいですが、大事な性質は一つだけです。

これは、閉じていて、有限の広さを持つ面（コンパクトな多様体）です。

無限に広がる平面ではなく、球面のように閉じた面。状態空間の正体は、これでした。

## 閉じた面の上では、波は飛び飛びにしかならない

ここで、幾何学と量子論をつなぐ、よく確立された事実が効いてきます。

太鼓の膜を思い出してください。膜は縁で留められている——つまり有限で閉じている——ので、鳴る音は飛び飛びの振動数に限られます。基音、二倍音、三倍音。中間の音はありません。

閉じた面の上の波も同じです。面が有限で閉じているというだけの理由で、その上に乗れる波のパターンは飛び飛びになり、各レベルの状態の数は有限になります。

これを一般的に整理したのが幾何学的量子化と呼ばれる理論です（1970年前後に確立された、標準的な数学です）。教えることは一つ。

コンパクトな状態空間を持つ系は、選択の余地なく、離散スペクトルと有限次元の状態空間を持つ。

普通の量子力学では、プランク定数を外から導入して離散性を得ます。ところがこの系では、状態空間が閉じた面であること自体が離散性を供給します。

つまりこの系は、量子化できるのではありません。生まれつき量子化されているのです。

## 式の中身を開けてみる

x = q + ip と実部と虚部に分けて、Σxₙ² = 0 の中身を見てみます。二乗を展開すると、この一本の式は二本の実条件に分かれます。

実部：Σqₙ² = Σpₙ²

虚部：Σqₙpₙ = 0

実部は、q を位置、p を運動量と読むなら、位置側と運動量側のエネルギーが釣り合っているという条件。調和振動子の等分配そのものの形です。

虚部はもっと面白い。Σqₙpₙ という量は、古典力学でスケール変換（全体の拡大縮小）を生み出す量として知られています。それがゼロ——つまりこの式は、大きさという自由度を最初から自分で殺しているのです。

「比だけが物理」というもう一つの要請は、独立な仮定ではなく、Σxₙ² = 0 の虚部にすでに書き込まれていた可能性がある。式の中を開けたら、そう読める構造が出てきました。

## 倍音は、比喩ではなかった

このシリーズでは「倍音」という言葉を何度も使ってきました。一本の弦の音が基音と倍音に分解できるように、閉鎖状態はいくらでも細かく分解できる、と。

錐の上で使える関数の全体は、数学的に厳密に、調和多項式と呼ばれる関数の集まりと一致します。そして調和多項式とは、球面上では球面調和関数——原子の軌道の形などでおなじみの、整数の番号で分類される、あの関数族です。

英語で球面調和関数は spherical harmonics。harmonics は、そのまま「倍音」の意味です。

つまり、この状態空間の自然な関数系は、文字通りの倍音でした。言葉遊びではなく、状態空間の定理としてそうなっていたのです。

## 整数はどこから来るのか

シリーズの議論には、巻き数——位相が一周する回数——のような整数の量が繰り返し登場します。なぜ厳密に整数なのか。

ドーナツに紐を巻くところを想像してください。紐がドーナツを何周しているかは、紐をどれだけ連続的に動かしても変わりません。3周を2.9周にすることはできない。切って貼り直すしかない。

閉じた面の上では、この種の巻き数が厳密な整数になることが、数学の定理として保証されています（チャーン類と呼ばれる整数の不変量です）。近似的に整数なのではなく、誤差ゼロで整数。しかもどんな連続変形でも、どんな拡大縮小でも変わりません。

飛び飛びの整数が出てくることは、この幾何の上では謎ではなく、閉じた面の性質そのものでした。

## 一番小さな系は、量子ビットだった

成分が三つの場合（N = 3）は、特別に美しい結果になります。

このとき、状態空間の閉じた面はリーマン球面と呼ばれる球面になります。そして球面上の点は、二成分の複素数の組 (a, b)——数学でスピノールと呼ばれるもの——の比で表せます。実際、

x₁ = a² − b²
x₂ = i(a² + b²)
x₃ = −2ab

と置くと、x₁² + x₂² + x₃² = 0 がいつでも成り立ちます（1938年にカルタンが示した古典的な構成です）。

二成分の複素数の比で状態が決まる球面。これは、量子情報でおなじみの量子ビット——スピン1/2の状態空間——と、数学的にまったく同じものです。

このシリーズの最小単位だった二波のABの関係は、状態空間のレベルで、量子ビットと同型でした。スピンや SU(2) と呼ばれる構造が、追加の仮定なしにこの幾何から出てくる位置にあります。

## 正直な区切り

このノートが主張しているのは、状態空間の数学的な正体の同定までです。

新しい定理は一つも含まれていません。使った数学はすべて既知のもので、参考文献は幾何学的量子化の原典（コスタント、スーリオー、ベレザン）、代数幾何の標準教科書、カルタンのスピノール、の計8件だけです。自作論文の引用はゼロ——前提知識なしで独立に読めるノートとして書きました。

また、ここでの同定は状態の集まりの形（運動学）についてであり、シリーズの数値実験の力学や、現実の物理系との対応を主張するものではありません。スピンについても「出てくる位置にある」という数学的同型の指摘までです。

それでも、二つの要請——Σxₙ² = 0 と、比だけが物理——を置いた瞬間に、複素数の必然、離散性、有限次元、倍音、整数、量子ビットが、すべて選択の余地なく付いてくる。この式は最初から、理論物理学者がよく知っている量子の幾何の上に立っていたのです。
