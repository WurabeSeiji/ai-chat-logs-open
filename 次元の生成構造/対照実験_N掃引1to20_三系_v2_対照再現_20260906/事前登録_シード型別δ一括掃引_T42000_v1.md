作成日: 2026-08-09

## 1. 目的と未確定事項

既存の長時間・広範囲 δ 掃引は mixed だけである。したがって、mixed で観測された
`r_nopump` の 0.7 近傍通過、到達・折返し・氾濫時刻、後半の複数読出し値を
「mixed 固有」とはまだ言えない。本実験は、同じ時間軸・同じ δ 格子でシード組成だけを
変え、次を判別できる生データを揃える。

1. 単一フェルミオン住所（neutral / electron）でも長時間に 0.7 近傍へ動くか。
2. mixed のフェルミオン5セルだけで同じ現象が起きるか。
3. mixed のボゾン3セルだけではどうなるか。F v1 の構造予測は
   `P_odd=0 -> R=0 -> 非線形頂点短絡` であり、これは実測する負対照である。
4. mixed で見えた現象に、奇偶共存が必要か。
5. 種類・強度・セル数が `tau_space`、ピーク時刻、滞在、後半統計へどう入るか。

137 / 128 の有限位数根との物理的同定は本実験の前提にしない。各近傍の通過・減速・滞在は
観測候補として保持するが、一般的なピーク前減速との識別は取得後の対照解析で行う。

## 3. シード組成

全セルは既存 mixed のセルまたは既存単一セルであり、新しい住所を発明しない。

| mode | シードセル | 役割 |
|---|---|---|
| `neutral` | (1,0) | 単一・中性フェルミオン |
| `electron` | (1,3) | 単一・電子型フェルミオン |
| `fermion_family` | (1,eta), eta={0,1,3,5,6} | mixed からボゾン3セルだけを除く ablation |
| `boson_family` | (6,eta), eta={0,3,5} | mixed からフェルミオン5セルだけを除く ablation |
| `mixed` | 上記5セルと3セルの和集合 | 既存基準（8点とも取得済み） |
| `vacuum` | なし | 既存シードなし基準。各非真空走行内でも毎回再走する |

和則による主な相棒帯は k=1 に対して k*=3、k=6 に対して k*=14。
`boson_family` で k*=14 が生成されるとは予言しない。F v1 では非線形頂点が短絡するため、
「狙い」は検出窓であり、生成の主張ではない。

`{1e-15, 1e-8, 1e-4, 1e-3, 1e-2, 0.03162277660168379, 0.04357, 0.1}`

| mode | 既存 | 今回の新規取得 |
|---|---:|---:|
| mixed | 8 / 8 | 0（再現対照のみ1本） |
| neutral | 1 / 8（δ=1e-2） | 7（再現対照は別名でもう1本） |
| electron | 0 / 8 | 8 |
| fermion_family | 0 / 8 | 8 |
| boson_family | 0 / 8 | 8 |
| vacuum | δ=0取得済み | 新規格子には数えず、全走行の内部対照 |

科学データ31本と、既存条件の完全再走2本、合計33実行を逐次で行う。同じ固定中間図名を使う
ため並列実行はしない。既存成果物は上書きしない。

`delta=0.02, 0.06` は既存文書の次候補だが、既存 mixed の共通8点には含まれないため、
本一括取得の格子へ事後追加しない。本8点の欠測を埋めた後の独立 holdout とする。

## 5. 強度の記録座標と交絡の扱い

同じ δ でもセル数が違うため、型差を単純な「同じ総パワー」とは読まない。各 run に次を保存する。

- `PF_declared = nF * delta^2`: 奇数シード帳簿パワー、非線形点火量の座標。
- `PB_declared = nB * delta^2`: 偶数シード帳簿パワー。
- `Pseed_declared = (nF+nB) * delta^2`: 総シード帳簿パワー。
- `Acoherent_declared = (nF+nB) * delta`: 全セルが同じ `seed_state` を共有する線形和の座標。
- `r_nopump_initial_cell_ratio = nF/(nF+nB)`: ポンプ除外計器のセル数比（非真空時）。

共有線形部はセル和を使うため、`n*delta^2` と `n*delta` を一つの rescale で同時に一致させる
ことはできない。本実験は同一 δ の完全行列を先に取得し、どの座標が時刻則を説明するかを
取得後に比較する。

## 6. 再現対照と合格条件

本走行に入る前に、改修後 wrapper で以下を別 suffix に再走する。

1. mixed / N=12 / T=42000 / δ=1e-2。
2. neutral / N=12 / T=42000 / δ=1e-2。

合格条件:

- 既存 T=42000 NPZ と、共通する全配列が NaN 配置を含めて最大絶対差 0。
- 再走の先頭4000 stepと既存 T=4000・N=12 NPZが最大絶対差 0。
- 全 run の内部真空軌道が既存 vacuum T=42000 と最大絶対差 0。
- JSON の F/D/G/S、N、Nn、Neta、seed、cell、order、T、window が固定値と一致。
- NPZ の毎step配列長が42000、ledger時刻が既定間隔と一致し、NaN配置を監査する。

いずれかが不一致なら不足 sweep を開始せず停止し、不一致配列と最大差を報告する。
