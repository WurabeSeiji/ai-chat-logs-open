# 四体の閉路から束と分配率を読む（2026-11-09、読みだけ・動力学なし）

木原氏の指摘（11/9）：分配率（視野角）は二体の関係では読めない。四体なら四体全ての関係で初めて決まる。これを式にして計算した。「計算してみては、でもまだ期待しすぎですよ」に対する一回限りの読みで、相互作用の反復はしていない。

## 式

- 要素 q_{i,m}(ψ)：v0.7 の 4 パルス（`exchange_core_v11.make_pulse` を import）を倍音ごとの関数に分けた 4 × 101 個。巻数 m は要素の自己関係 ⟨q̄(ψ) q(ψ+τ)⟩ = |q|² e^{nmτ} から読める量で、名前ではない。
- 二要素の関係 Y_ab = ⟨q̄_a q_b⟩。原点 ψ → ψ + χ に依らないので、巻数が等しい対にしか残らない。
- 束の閉路 Λ = ⟨q̄_a q_b q̄_c q_d⟩、a ∈ 層 m、b = d ∈ 層 m+1、c ∈ 層 m+2。位相 = −α_a + 2α_b − α_c = 位相の二階差分。零で実正なら a, b, c は一つの束（局在波）。どのパルスの要素かを使わず、位相零の閉路で要素を結び、連結成分を束とする。
- 距離の閉路 ⟨q̄_{i,m} q_{j,m} q̄_{j,m+1} q_{i,m+1}⟩。共通軸なら位相は厳密に θ_j − θ_i。
- 束の分配率 Ω_ij = Σ_m Sc Y_{(i,m),(j,m)} / R_i²（符号つき）。層ごとの |Sc| 比と比較。

## 結果（`results/closure_distribution_ratio_v1.json`）

| 項目 | 整数度の配置（v0.7 と同じ） | 一般の角の配置 |
|---|---|---|
| 巻数が違う対の \|Y\| 最大 | 9×10⁻²⁰（同巻数は 3×10⁻⁵） | 同 |
| 同じ束の閉路の位相 最大 | 5×10⁻¹³ 度 | 5×10⁻¹³ 度 |
| 混ざった閉路の位相 最小 | 2×10⁻¹³ 度（偶然に閉じる閉路 6 本／共通軸 29 本） | 0.16 度（偶然ゼロ） |
| 閉路だけから再構成した束 | 1 個に融合（偶然の閉路で全部つながる） | 4 個、各パルスの 101 要素と一致 |
| 距離の閉路（共通軸） | 全 12 対で \|Δ\| と 2.5×10⁻¹² 度で一致 | 同 |
| 距離の閉路（軸 x, y, z, 111） | 平均は \|Δ\| と 0.2 度以内、m ごとの揺れ 0.2〜1.8 度、最大 17.7 度。軸は読む側 n_i | 同 |
| Ω_ij（符号つき Sc/R²）、i ≠ j | −1.3×10⁻³ 〜 7.7×10⁻³ | −2.8×10⁻³ 〜 7.5×10⁻³ |
| 層ごとの \|Sc\| 比の平均 | 0.32〜0.50（共通軸 0.63） | 同 |

整数度の配置で束が融合するのは、Φ_ij と Δ_ij が整数度のため 2[Φ − (m+1)Δ] ≡ 0 (mod 360) が特定の m で厳密に成り立つから。一般の角では起こらない。閉路一本の零で結ぶ方法は、一致が一本でも偶然に起こると束を誤って結ぶ。

## 分かったこと

1. 二要素の関係は巻数ごとの層に分かれ、層の中では遠近がない（|Sc| 比 0.3〜0.6）。遠近を持つ分配率 Ω_ij は 10⁻³ の桁で、層を足した和にしかない。
2. 束は四要素の閉路で初めて現れ、一般の角では閉路の位相だけから 4 つの束が名前なしに再構成できる。
3. 距離は四要素の閉路で読める。共通軸では厳密、軸が違うと m とともに揺れる（歳差）。
4. この読みは初期状態がちょうどパルスの集まりだから一回で閉じている。相互作用の後は閉路の位相が厳密な零にならず、束も Ω も近似になる。木原氏の「自己無撞着は繰り返しで初めて」は、閉路の位相が零に戻るかどうかを反復の中で測ること、と読む。
