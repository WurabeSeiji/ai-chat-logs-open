## 主結果（数値で確認済み）

- 対蹠写像 P: ψ → ψ + π で倍音 m は (−1)^m 倍。η = 〈S, PS〉/‖S‖² = w_e − w_o（奇数だけ −1、偶数だけ +1、両方 −0.077）
- 対蹠対では交換 = P。二チャネル交換写像 A′ = A_e + e^{iΔ_F} A_o の反射率 R = (w_e − w_o)² + 4 w_e w_o sin²(Δ_F/2)。式との最大差 1.3e-15。釣り合い（一山）で R = sin²(Δ_F/2)、純偶奇で R ≡ 1（交換の固有状態、反射も透過もない）。奇数倍音は逆相核 Δ_F = π を内蔵
- 倍音ごとの交差項の縞の位相 mΔ − Φ：傾きが符号つき Δ、切片が Φ。(±30°, 20°) を符号込みで厳密に復元。基本波だけでは Φ = 0 のとき ±Δ が区別できない。軸が違う対は Vec 部の三係数列（n_i, n_j, n_i×n_j）
- 相互相関の半値全幅は共有帯域 min(M_i, M_j) で決まる：(13,13) 15.6°、(13,39) 15.6°、(39,39) 5.4°、幅 × M_共有 ≈ 205°
- 4 波のグラム行列：間隔 s が小さいと最小固有値が消え階数 4 → 3。閾値 0.05 で M = 13 は s ≤ 2.25°、M = 39 は s ≤ 0.75°（∝ 1/M）＝ 凝縮体
