# 骨格写像の定常状態
## ― 相互作用がそのまま読出しである一行の写像は、関係の自己無撞着な固定点へ収束する ―

## 要旨

無名の四元数波の組 {q_i} に対し、状態の更新を一行の写像

q_i′ ＝ normalize_i( Σ_j q_j ⟨q_j, q_i⟩ / E_i )

で置く。⟨a, b⟩ は弦全体での平均 ⟨ā b⟩、E_i は波 i のパワーで、自己項 j ＝ i を含む。交差項 Y_ij ＝ ⟨q_i, q_j⟩ が相互作用であり、同時にそれが読出しである。読出しと作用の二層はない。掛ける側（右）、交差項の取り方（弦全体の積分）、正規化（各波のパワー保存）は、左からの無名性、相互性、弱い観測での放射と吸収の釣り合いという前提から一意に決まる。

この写像を反復すると、4波の基準配置でも200通りのランダム配置でも、複素数・四元数ともに6〜9回で関係 Y_ij が変化しなくなる。これは状態が止まったのではなく、放射と吸収が続いたまま全関係が釣り合った定常状態である。固定点は無名性の変換（全体の左乗、全体の並進）を除いて固定であり、絶対的な状態が大きく動いても関係は 10⁻¹⁵ の精度で不変に保たれる。内部時計の進みと全体の並進は、外の系を持たない4体の内側からは読めない。

固定点では、すべての波が同じ密度分布を共有する（波ごとの密度の差は 10⁻¹⁴）。波どうしの違いは右から掛かる単位四元数 h_ij だけに残る。これは複素数では内部位相の差、四元数では内部位相と軸の差である。相対位置は共通密度の山の配置として現れ、各波がその配置全体を担う。準位に当たる量（実グラム行列の固有値）は初期配置に連続的に依存し、反復だけからは離散化しなかった。

## 1. 骨格

### 1.1 一行の写像

N 個の四元数波 q_i(ψ)（ψ は閉じた弦の位相）に対し、

q_i′ ＝ normalize_i( Σ_{j＝1}^{N} q_j ⟨q_j, q_i⟩ / E_i ),　⟨a, b⟩ ＝ (1/2π)∫ ā(ψ) b(ψ) dψ,　E_i ＝ ⟨q_i, q_i⟩

とする。normalize_i は q_i′ のパワーを E_i に戻す操作である。現在の状態どうしの相互作用が次の状態を与え、その相互作用の量 Y_ij がそのまま読出しになる。縞の傾き・方向・凝縮体といった解釈は、記録した Y_ij を後から読むものであり、更新のループには入らない。

### 1.2 三つの選択は前提から決まる

**右から掛ける。** 無名性は全体を左から単位四元数 g で掛けても何も変わらないことであり、Y_ij ＝ ⟨q̄_i q_j⟩ はこの変換で不変である。更新が共変であるためには q_j → g q_j に対して q_j Y_ji → g q_j Y_ji でなければならず、Y_ij q_j の形は共変でない。添字の順は相互性で決まる。Y_ji ＝ Ȳ_ij を掛けると、観測者自身の読み

⟨q_i, q_i′⟩ ∝ Σ_j |Y_ij|²

は常に実数になる。往きと還りが釣り合っていることの表現である。

**弦全体の積分。** 各点の積 q_j(ψ) q̄_j(ψ) q_i(ψ) ＝ |q_j(ψ)|² q_i(ψ) は振幅の変調にすぎず、位相差も軸も消える。干渉は重ね合わせた全体の交差項なので、積分の ⟨q̄_j q_i⟩ だけが意味を持つ。

**パワーで割り、保存する。** 弱い観測では放射と吸収が釣り合い、エネルギーは跳ばない。自分のパワー E_i で割ると自己項は q_i そのものになり、他者の項は視野角の大きさ |Y_ij|/E_i で入る。そのうえでパワーを E_i に戻す。

## 2. 定常状態の意味

### 2.1 関係の固定点

写像は互いに読み合うことそのものである。反復の結果、Y_ij が変化しなくなった状態では、全員の読みが矛盾なくそろい、放射と吸収が完全に釣り合っている。放射と吸収は続いており、止まっているのは関係である。相対位置もエネルギー準位も、外から与えるものではなく、全関係が安定したときの配置として決まる。

### 2.2 無名性の変換を除いた固定

4体の外に系はないので、読めるのは Y_ij だけである。全員の内部時計が一緒に進むこと、全体の並進、全体の左乗は、関係を一つも変えない。したがって定常状態は「関係が不変になる状態」として定義する。力学の相対平衡に当たる。系はこの読めない方向に動き続けていても、内側からは静止と区別できない。一様な運動と静止の区別がないこと（相対性と慣性）は、無名性からそのまま出る。共通の動きが観測に現れるのは、別の系との関係が生じたときに限られる。

### 2.3 一周ごとの写像

弱い観測では、一回の放射と吸収で内部位相が一周して閉じる。骨格の1ステップは閉じた一周ごとに状態を見る写像である。定常状態では位相は回り続けているが、見るたびに整数周だけ回って元に戻るので、状態は変わらないように見える。四元数では q が元に戻るのは位相 2π（向きとしては二周）である。自己の読みが常に実数になることは、一周ごとに見ているため余りの位相が残らないことと対応する。

## 3. 数値実験

### 3.1 設定

弦の標本数 NG ＝ 721。初期パルスは倍音 m ＝ 1〜12 の和で、振幅に cos²(πm/26) の漸減を掛け、パワー1に規格化した。

q_i(ψ) ∝ Σ_m w_m e^{n_i(φ_{0i} ＋ m(ψ − θ_i))}

基準配置は4波、中心 θ ＝ (0, 25, 60, 200)°、内部位相 φ₀ ＝ (0, 70, 140, 210)°。複素の場合は全軸を i に共通とし、四元数の場合は軸を i, j, k, (1,1,1)/√3 とした。収束判定は関係の相対変化 10⁻¹³ 未満。

有効階数の閾値は「自分の大きさの1/2以下は読めない」から決める。自分の大きさは自己相関の大きさ |⟨q(0), q(s)⟩| の半値全幅 σ である。この初期パルスでは σ ＝ 33.4° で、σ/2 だけ離れた同形二波のグラム最小固有値は 0.501 になる。これを閾値とし、自由パラメータは置かない。

### 3.2 E1：基準配置の反復

|---|---|---|
| 固定点に達した反復回数 | 6 | 6 |
| 実グラム固有値（初期） | 0.29, 0.78, 1.00, 1.93 | 0.64, 0.88, 1.00, 1.48 |
| 実グラム固有値（固定点） | 0.00, 0.00, 0.27, 3.73 | 0.18, 0.29, 0.42, 3.11 |
| 四元数グラム固有値（固定点） | 0, 0, 0, 4.00 | 0, 0, 0, 4.00 |
| 波ごとの密度の差（固定点） | 6.0×10⁻¹⁵ | 8.5×10⁻¹⁵ |
| 自己読みの虚部（全反復の最大） | 9.7×10⁻¹⁶ | 1.4×10⁻¹⁵ |

図1（ファイル：figures/fig1_iteration.png、fig1_iteration.svg）に固有値と関係の変化の経過を示す。

四元数グラム行列は固定点で階数1になる。すべての波が同じ右四元数直線に乗り、q_j ＝ q_1 h_1j と書ける。h_1j は単位四元数で、四元数の場合は例えば h_12 ＝ (0.693, 0.140, 0.140, −0.693) である。複素の場合の h_1j は単位複素数 (0.997, 0.073)、(0.995, −0.105)、(0.823, −0.568) である。波どうしの違いは、複素数では内部位相だけ、四元数では内部位相と軸に残る。実グラム固有値は h_ij の実部から作られ、この内部の違いの構造を表す。複素数では内部の違いが一平面の位相に限られるため実グラムの階数は2を超えず、四元数では3以上を取り得る。

### 3.3 共通密度と相対位置

図2（ファイル：figures/fig2_density.png、fig2_density.svg）に初期の各波の密度と、固定点の共通密度を示す。初期の総密度の山は 13°、54°、200° にあった。固定点の共通密度は 15.5°（四元数では 16.0°）に主峰、55° 付近に肩、199.7° に第二峰を持ち、峰の高さ比は 1 : 0.23（四元数では 1 : 0.27）である。互いに重なっていた3波は一つの塊に、離れていた1波は別の峰になり、二つの峰の間隔は 184.2°（四元数では 183.7°）である。各波はこの配置全体を共有し、内部位相（と軸）だけで区別される。

固定点に全体の左乗（g ＝ (cos 0.7, 0.6 sin 0.7, 0.8 sin 0.7, 0)）と全体の並進（137 標本）を施した。

## 4. 考察

### 4.1 定常状態は「一つの配置を全員が担う」状態

骨格の固定点では、全波が同じ密度分布を持ち、内部の右四元数だけが異なる。位置関係は波と波の間の距離としてではなく、共通の配置の中の峰の並びとして現れる。各波はその配置全体を担い、内部時計と軸で区別される。会話の途中で「四元数では4波とも区別が残る」と述べたのは、実部だけのグラム行列を見たことによる誤りで、位置としては一つの配置に収束し、区別は内部の位相と軸に残る、が正しい。

### 4.2 複素数と四元数の違い

どちらも共通の配置に収束する。違いは、残る内部の区別の次元である。複素数では内部の違いは一平面の位相に限られ、実グラムの階数は2を超えない。四元数では内部位相に加えて軸が残り、階数は3まで現れた（200配置中79）。「複素数の相互作用では何も読めない」と「四元数で壁が破れる」の対比は、位置ではなく内部の区別の次元として現れる。

### 4.3 準位の離散化は骨格だけからは出ない

実グラム固有値は初期配置に連続的に依存した。骨格は一周ごとの写像なので、一周の間に何周回るかという整数（準位）は写像の上では見えず、制約もされない。準位の離散化には、一回の握手の間に内部位相が余りなく閉じるという条件を、写像の外の解釈ではなく状態そのものの性質として扱う必要がある。これが次の課題である。

### 4.4 v0.7 の量の評価場所

v0.7 第I部の量（縞の傾きと切片、偶奇、可視度、有効階数）は、初期パルスに一回だけ作用をかけた状態ではなく、骨格の固定点の上で評価すべきものである。固定点の Y_ij と共通密度の峰の配置が、その評価の対象になる。

### 4.5 範囲

本稿の数値は、置いた一行の写像の振る舞いを示すものである。初期パルスの形（漸減付き12倍音）、弦の標本数、山の検出下限（最大値の5%）は設定値であり、結果ファイルに記録した。準位の離散化、散乱、外の系との関係による運動の観測は扱っていない。

| ファイル | 内容 |
|---|---|
| skeleton_fixedpoint_v1.py | 骨格写像と実験 E1〜E4。results/ に JSON と NPZ を出力 |
| plot_skeleton_fixedpoint_v1.py | results/ を読み figures/ に PNG・SVG を出力 |
| results/skeleton_fixedpoint_v1.json | 全数値（設定、E1 の反復履歴、E2、E3、E4 の集計） |
| results/skeleton_fixedpoint_v1.npz | 初期・固定点の状態 Q と関係 Y、集団の固有値・階数・山の数 |
| figures/fig1_iteration.png / .svg | 図1 反復の経過 |

python3 plot_skeleton_fixedpoint_v1.py
