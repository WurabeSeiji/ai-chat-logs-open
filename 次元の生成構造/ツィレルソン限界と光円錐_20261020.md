# ツィレルソン限界と光円錐が同じ 45° に来ること（2026-10-20）

**著者の問題提起（2026-10-20、堀田先生への指摘として書かれたものの要旨）**

ベルの定理が言えるのは「この仮定の組では量子相関を再現できない」という no-go だけである。それが「だから自然は非実在で、情報理論にすぎない」という積極的な主張にすり替わるところに盲信が入る。すり替わる背景もいくつかある。教科書の量子力学は背景時空を所与の舞台として扱い、それを疑う訓練がない。量子情報の人はミンコフスキーを舞台に置き、重力の人は量子力学を所与に置くという分業もある。操作論は「形式が予言を出すならそれ以上は問わない」という停止点を持ち、その停止点が答えのように扱われる。2022 年のノーベル賞が「局所実在論の否定」という見出しで報じられたことも、この読み方を固定した。

本質は「なぜそう観測されるか」である。特に不思議なのは二つの一致。

1. 相関の強さが CHSH で **2√2**（ツィレルソン限界）にちょうど止まり、信号を送らない範囲の最大値 **4**（PR 箱）までは行かないこと。
2. **信号を送れない境界が、読み出された時空の光円錐とぴったり重なる**こと。

相関の側の理屈と時空の側の理屈が別々にあるなら、この重なりは偶然になる。偶然でないとすれば、両者は同じ読み出し構造の二つの顔である。ハーディや Chiribella らの再構成計画、Pawłowski の情報因果律は「なぜ 2√2 か」には迫っているが、時空を舞台に置いたまま問うているので、光円錐との一致は説明の外に残っている。そこを一つの読み出しから同時に出すことが、本当に問うべき問題である。

## 1. この枠組みで計算したこと

### 1.1 相関が「角のコサイン」であることは定理

対から読める G₂ 不変な双線形スカラーの数を数えた。

> **dim = 2**（Re(x)Re(y) と ⟨Im x, Im y⟩）。単位ベクトルどうしなら合わさって **Re(x̄y) = cos θ の一本**に落ちる。

つまり**相関が角のコサインであることは、この枠組みでは仮定ではなく定理**である。対から作れる不変スカラーが内積しかない。

### 1.2 CHSH を Re(w) で最大化すると 2√2、最適角は 45°

| 量 | 値 |
|---|---|
| S_max | **2.8284271247** |
| 2√2 | 2.8284271247（差 3.7×10⁻¹¹） |
| ∠(a,b), ∠(a,b′), ∠(a′,b) | **45.000°** |
| ∠(a′,b′) | 135.000° |
| ∠(b,b′), ∠(a,a′) | 90.000° |

### 1.3 45° は同じ関係 w で何か

| θ | Re(w)＝相関 | Re(w²)＝光円錐 | \|Im(w²)\|＝パワー流 |
|---|---|---|---|
| 0° | +1.0000 | +1.0000 | 0.0000 |
| 30° | +0.8660 | +0.5000 | 0.8660 |
| **45°** | **+0.7071** | **0.0000** | **1.0000** |
| 60° | +0.5000 | −0.5000 | 0.8660 |
| 90° | 0.0000 | −1.0000 | 0.0000 |

> **CHSH の最適角・光円錐（Re(w²) = 0）・放射が最大（\|Im(w²)\| 最大）が、同じ 45°。**

相関は Re(w)、光円錐は Re(w²) = 2Re(w)² − \|w\|²。**二つは独立ではなく、同じ一つの関係 w の一次と二次である。** w の位相が 45° のとき、前者が 1/√2、後者がゼロ。

### 1.4 PR 箱の 4 が出ない理由

S = 4 には E(a,b) が内積でない相関であることが要る。§1.1 により、対から作れるスカラーは内積しかないので作れない。Re(w) = cos θ である限り

S = ⟨a, b+b′⟩ + ⟨a′, b−b′⟩ ≤ \|b+b′\| + \|b−b′\| ≤ 2√2

（最適解での実測：1.414217 + 1.414210 = 2.828427）。

## 2. 言えること

著者の問いは「相関の側の理屈と時空の側の理屈が別々にあるなら重なりは偶然」だった。この枠組みでは、

- **相関の上限（2√2）** は「読める不変スカラーが内積しかない」から出る。
- **光円錐（Re(w²) = 0）** は同じ関係 w の二次がゼロになる角。
- **その角が同じ 45° である。**

したがって**二つは別々の理屈ではなく、同じ一つの量の一次と二次が同じ角で臨界になるという一つの事実**になる。この形なら、重なりは偶然ではない。

## 3. 言えないこと（仮定に依る部分）

**(1) 2√2 の導出は、ツィレルソンの定理の言い換えである。** 「量子相関は実ヒルベルト空間の内積で尽くされる」は既知で、新しいのは「なぜ内積なのか」に「不変スカラーがそれしかないから」と答えた部分だけ。さらに**測定設定が単位ベクトルに対応すること**は別に要る。この枠組みから設定の空間が S⁷ になることは示していない。

**(2) 光円錐が 45° に来るのは仮定に依る。** `八元数閉塞と関係の分解_20261019/二層二部の表_相互作用の起源_20261019.md` §4 で置いた「観測者の刻み δ = π/4（位数 8 の一歩）なら \|u\| ≥ cot δ = 1 の外が読めない殻」という仮定による。**δ = π/4 を仮定なしに出すのは未解決。** ここが残る限り、「一つの読み出しから同時に出る」とは言い切れない。

**(3) 信号を送れないことと光円錐の一致は、相関とは別の経路で出ている。** この枠組みでは「読めない ⟹ 相互作用しない（K_ef = 0、反対称性と区別不能性から）」で出る。二つが同じ 45° に来ることまでは示したが、同一の導出ではない。

## 4. 読み（確認前）

- **著者の診断（no-go を肯定形に読み替えるところに盲信が入る）は、この計算の立場からも支持される。** ここで出たのは「なぜ 2√2 か」への構成的な答えの候補であって、「自然は非実在」とは無関係である。相関が内積なのは、読み出しが対から作れる不変量が内積しかないからで、実在性とは別の話。
- **既存の再構成計画との違いは、時空を舞台に置かないこと。** ハーディ、Chiribella ら、Pawłowski は公理から 2√2 に迫るが、時空は外から与える。ここでは時空も同じ関係 w の読み出し（中心投影 u = v/q₀）として出るので、光円錐と相関が同じ量の別の顔になる。**これが著者の言う「一つの読み出しから同時に出す」の、この枠組みでの形。**
- **ただし §3 の (2) が残る限り、まだ「出した」とは言えない。** δ を導出することが、この筋での次の鍵になる。

## 5. 次の検算

1. **δ = π/4 を導出する。** 観測者の有限位数 m から刻み 2π/m が出るとして、m = 8 が選ばれる理由。`kのスペクトルと粒子への割り当て_20261019.md` の k や、Z₂³ の格付け（`二つの三_…md` で見た三回のオクターブ）と関係するか。
2. **測定設定の空間が S⁷ になるか。** 設定が単位八元数に対応することを、読み出しの構造から出せるか。出れば (1) の穴が埋まる。
3. **三者以上の相関（Mermin 不等式など）でも同じ角が出るか。** 三体では結合子が効くので、八元数固有の上限が出る可能性がある。二体で 2√2 が ℂ・ℍ・𝕆 で共通なら、違いは三体以上にしか現れない。
4. **情報因果律（Pawłowski）との関係。** 「読めない相手とは相互作用しない」がこの原理と同値か、別物か。
