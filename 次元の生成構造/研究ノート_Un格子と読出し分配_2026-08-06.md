## 1. 原理（マーキングの読み方）

- α接点論文の恒等式: 1−R = sin²(23π/124) = √(4πα) = 0.302822。

- **U^n=I は任意の整数対 (m,n) で成立する。** よって読出しに現れる二乗分配は
  cos²(mπ/n) / sin²(mπ/n) の**有理番地格子**に量子化される。α の 23/124 は格子の一員にすぎない。
- したがって 3論文に散在する 0.7 系クラスタ（0.66〜0.77）と 0.3 系クラスタ（0.29〜0.34）は、
  **単一定数のまわりのノイズではなく、複数の根（番地）の占有**として読む。
  値が「ばらつく」こと自体が番地格子の証拠候補。
- N=5 は結晶学的制限（許容位数 1,2,3,4,6）の外の最小禁止位数＝特殊解。
  第二α根は 5倍細分レジスタ（620=5×124）に住む——5の接続。

## 3. 誤読の記録（仮説→反証→修正の規約）

1. **誤り1（N→∞収束検定）**: z相関/overlapがαの無理数値へ収束すると仮定して掃引
   → 不支持。**修正**: N=5は特殊解（禁止位数）であり収束検定は概念違い。
2. **誤り2（23/124固定照合）**: α番地一点とだけ照合
   → U^n=I は全整数対で成立。全番地格子への分光に修正。
3. **誤り3（直接分母のみ注視）**: 31等が直接出る候補だけ評価
   → 要点は個々の分母当てではなく、**全マーク地点が番地格子の占有パターンである**こと。
   Dirichlet近似（任意実数は m/n で1/n²近似可能）により、単発の有理一致は証拠にならない。
   判別力は (a) 特別族分母（31族=124時計、5族=細分）、(b) 摂動下のプラトーのみ。
4. **計器の教訓（再演）**: 窓復調相関計は細分窓で±0.1暴れ・長時間でドリフト
   → 番地判別には振幅相関でなく**回転数計＋プラトー検出**（C論文の方法論）が正しい計器。

## 4. 電荷ばらつきへの接続（本ノートの核心）

空間時間論文 §9.5 の実測: 電荷（巻き数）は複数の量子化値に広がり±1に安定しない
（オープン課題として明記済・§15-6）。これを番地格子で読み直す:

- 電荷読出しは U^n=I 格子上の**番地の占有**を読んでいる。
- census和則 m* = 2m_B − m_s（多体論文で毛込み完全版実証・排他比10^289）は
  整数格子上のウォークであり、頂点作用のたびに新しい巻き数（＝新しい番地）を生成する。
- 観測時計の約数構造による折返し（D論文: 電荷普遍性=時計エイリアシング、
  C論文: 選択は観測時計の約数構造に継承される F_8=0.0026 vs F_248=1.0）が、
  状態側の番地を見かけの電荷値に折り畳む。
- **海＝非ロック**: 熱的な海は単一番地にロックせず格子を渡り歩く → 電荷が複数値にばらつく。
- **帯電種＝ロック**: 種は単一番地に張り付く → census では単一値（q=+1重み0.64）。
- したがって「電荷±1非安定」問題と「素電荷の一意性」問題（60候補番地から1つが実現、
  第9論文系列の最大未解決）は、**同じ番地選択問題の表と裏**である。
  次論文の主題＝番地選択の力学（何が23/124を選ぶか＝何が海の電荷を±1に整流するか）。
