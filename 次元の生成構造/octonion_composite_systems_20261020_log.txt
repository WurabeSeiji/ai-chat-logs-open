=== 1. 「複合系」の操作的な中身：局所トモグラフィ ===
  標準の要請：AB の状態は、A と B への局所測定の統計だけで決まる。
  これを課すと必然的に dim V_AB = dim V_A x dim V_B になる
  （局所測定の組 {A の効果} x {B の効果} が AB の状態空間を張るから）。

=== 2. 各代数で dim(AB) = dim(A) x dim(B) が成り立つか ===
  代数        1 粒子 n=2    2 粒子 n=4    積 dim(A)^2      一致
  R                3          10             9     いいえ  
  C                4          16            16      はい  
  H                6          28            36     いいえ  
  O               10          52           100     いいえ  （J_4(O) はジョルダン代数にならない）

  R : 3 x 3 = 9 だが実 QM の二粒子は 10。局所トモグラフィが破れる（荒木、Wootters）
  C : 4 x 4 = 16 で一致。【ここだけ成り立つ】
  H : 6 x 6 = 36 だが四元数エルミート 4x4 は 28。テンソル積が圏として定義できない
  O : アルバートの定理により J_3(O) までしかジョルダン代数にならない。複合系を作れない

=== 3. なぜ C だけか（一行の方程式）===
  n x n エルミートの実次元は n + d n(n-1)/2。dim(n=2) = 2+d、dim(n=4) = 4+6d。
  (2+d)^2 = 4+6d  ->  d^2 - 2d = 0  ->  d = 0 または 2
    d = 1: (2+d)^2 =   9、4+6d =  10
    d = 2: (2+d)^2 =  16、4+6d =  16   一致
    d = 4: (2+d)^2 =  36、4+6d =  28
    d = 8: (2+d)^2 = 100、4+6d =  52
  -> d = 2、すなわち複素数だけ。『量子力学はなぜ複素数か』の再構成の一本。

=== 4. この枠組みの『複合』は加法的 ===
  状態は N 個の八元数の配置。二つを合わせるとは要素を足すこと。次元は 8N。
    N = 3 と N = 3: 8*3 + 8*3 =   48（テンソル積なら 24 x 24 = 576）
    N = 4 と N = 5: 8*4 + 8*5 =   72（テンソル積なら 32 x 40 = 1280）
    N = 5 と N = 8: 8*5 + 8*8 =  104（テンソル積なら 40 x 64 = 2560）
  閉塞 Sum o = 0, Sum o^2 = 0 は大域の拘束で、局所の測定からは決まらない。
  -> この枠組みは局所トモグラフィを構成で満たさない。再構成定理の仮定の外。

=== 5. 閉塞は和でそのまま合成する ===
  A（N=5）の閉塞      4e-16, 2e-15
  B（N=6）の閉塞      1e-15, 4e-15
  A ∪ B（N=11）の閉塞 1e-15, 2e-15  -> 和でそのまま閉じる
  テンソル積なしに合成できている。ただし『もつれ』に相当する自由度は入らない。
