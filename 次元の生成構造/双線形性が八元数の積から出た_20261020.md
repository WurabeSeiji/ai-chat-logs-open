# 双線形性が八元数の積から出た ― v2 §4-1 を閉じる（2026-10-20）

**前段：** `ツィレルソン限界と光円錐_v2_20261020.md` §4-1「設定が振幅に線形に入る理由」（最優先の未導出項目）、および §3.4「連鎖ベルでは判定に向かない」。
**プログラム：** `octonion_clifford_bilinearity_20261020.py`。
**結論：** §4-1 は閉じた。ただし著者の見立てとは違う形で閉じ、残る穴も別の場所に移った。§3.4 の「不利」も解消した。

---

## 1. 著者の提案（2026-10-20）

> 標準の量子力学で相関 E(a,b) が設定について双線形になるのは、観測量 a·σ が a について線形だから、つまり「設定ベクトルのクリフォード代数への埋め込み」のおかげである。八元数では、純虚の単位八元数 a による左乗算 L_a が、交代性からクリフォード関係 L_a L_b + L_b L_a = −2⟨a,b⟩ を満たす。すると対称化した読み出し Re(x̄·a(bx)) + Re(x̄·b(ax)) = −2⟨a,b⟩\|x\|² は自動的に設定について双線形になり、符号まで一重項の相関 −cos θ と一致する。残る課題は反対称部分 Re(x̄·[a(bx) − b(ax)]) の扱いで、これが消える状態 x（一重項に相当するもの）を特定できるかどうか。

> また √2 は 2 次元実ベクトルに対するグロタンディーク定数 K_G(2) に等しく、45° が出るのは CHSH の設定が平面に収まるから。連鎖ベルの設定も同じ平面に収まるので判定に向かない。分水嶺になるのは、量子最適に非平面の設定を要する不等式（I3322 やプラトン立体型）である。

## 2. 計算（すべて独立に確認）

### 2.1 クリフォード関係は成り立つ

| 事実 | 誤差 |
|---|---|
| L_a L_b + L_b L_a = −2⟨a,b⟩（a, b 純虚単位） | **4.4×10⁻¹⁶** |
| L_a は反対称（L_aᵀ = −L_a） | **0** |
| \|L_a x\| = \|a\|\|x\|（ノルム乗法性） | 8.9×10⁻¹⁶ |

純虚八元数の左乗算は Cl(7) を作る。そして **a ↦ L_a x は線形等長**（線形性は左乗算が乗数について線形だから、等長性はノルム乗法性＝フルヴィッツから）。**これで「設定が線形に入る」は代数の事実になった。**

### 2.2 反対称部分は、特別な状態を要さず恒等的に消える（見立ての訂正）

| 量 | 最大 |
|---|---|
| Re(x̄·[a(bx) − b(ax)]) | **3.6×10⁻¹⁵** |
| Re(x̄·a(bx)) + ⟨a,b⟩\|x\|² | **3.6×10⁻¹⁵** |

**理由は一行で済む。** [L_a, L_b] は反対称行列であり、任意の反対称 A と任意の x について ⟨x, Ax⟩ = 0。したがって**全ての x で消える**。

> **著者の見立て（消える状態 x を特定する）は不要だった。無条件で消える。**

**ただし、そのぶん代償がある。** Re(x̄·a(bx)) = −⟨a,b⟩\|x\|² は**状態 x に依存しない**。状態依存性のない量はベル相関ではない（一重項も直積状態も同じ値になってしまう）。**この一体の形のままでは使えない。**

### 2.3 二者の形にすると、ツィレルソンの形そのものになる

> **E(a,b) = ⟨a x, b y⟩ / (\|x\|\|y\|)**

| 性質 | 確認 |
|---|---|
| 設定 a についての線形性 | 誤差 4.9×10⁻¹⁵ |
| u_a = a x、v_b = b y が単位ベクトル | §2.1 のノルム乗法性 |
| したがって E(a,b) = ⟨u_a, v_b⟩ | **ツィレルソンの形そのもの** |
| a ↦ u_a は R⁷ → R⁸ の線形等長 | §2.1 |
| 状態 (x, y) に依存 | する |

**CHSH を実際に最大化：2.8284271247**（2√2 との差 1.4×10⁻¹¹、x = y = 1）。

### 2.4 相関行列は 7 次元で、平面に閉じていない（§3.4 への答え）

| 状態 | 相関行列 M（7×7）の特異値 |
|---|---|
| x = y = 1 | **1, 1, 1, 1, 1, 1, 1** |
| ランダムな x, y | 1, 1, 1, 1, 1, 1, 0.0466 |

x = y = 1 で **M = I₇**。最大相関の状態が実現できる。三次元の直交設定だけを取り出しても相関行列は I₃（特異値 1, 1, 1）。CHSH 最適解の設定 4 本が張る次元も **4**（平面なら 2）。

> **読み出しは複素平面に閉じていない。設定空間は 7 次元あり、キュービット相関（3 次元）を完全に含む。**

したがって I3322 やプラトン型の非平面不等式でも量子値に届く見込みであり、**v2 §3.4 の「一致は CHSH 固有で不利」という見込みは、根拠を失った**。著者の読み替え（連鎖ベルは平面に収まるので判定に向かない、非平面の不等式こそが分水嶺）が正しい。

## 3. 何が閉じ、何が残ったか

### 閉じたもの

**v2 §4-1「設定が振幅に線形に入る理由」は閉じた。** 理由は二つの代数の事実だけで、新しい仮定を置いていない。

1. 左乗算 L_a は乗数 a について線形（定義から）
2. \|L_a x\| = \|a\|\|x\|（ノルム乗法性、フルヴィッツ）

この二つで a ↦ L_a x が線形等長になり、E(a,b) = ⟨L_a x, L_b y⟩ が設定について双線形かつ \|E\| ≤ 1 になる。**これはツィレルソンが定理として置いた形そのもので、ここでは代数から出る。** 操作論が公理として置いている部分を、一つ導出したことになる。

**v2 §4-2「測定設定の空間が S⁷ になるか」も、同時に閉じた。** 設定は純虚単位八元数、すなわち S⁶ に住み、像 u_a = L_a x は S⁷ に入る。

**v2 §3.4 の「不利な見込み」も解消した。** §2.4 により読み出しは 7 次元で、非平面の不等式も扱える。

### 残ったもの（場所が移った）

**「二者」という構造がどこから来るか。** §2.2 で見たとおり、一体の形では状態依存性が出ず、ベル相関にならない。§2.3 で二つの八元数 x, y を置いて初めて相関になる。**この二者性（Alice と Bob）がこの枠組みのどこから出るのかは、まだ出ていない。**

候補は二つある。どちらも未検証。

- **𝕆 = ℍ ⊕ ℍℓ の二つの半分**（`八元数閉塞と関係の分解_20261019/内と外の選択問題_…md` の分け方）を二者とする。ただしこれは時空と内部の分け方なので、空間的に離れた二者とは別物に見える。
- **閉塞した配置の二つの要素**を二者とする。この場合 x, y は同じ配置の別の要素で、二者性は配置の構造から出る。

**v2 §4-3「光円錐が π/4 に来ること」は依然として片側だけ。** CHSH 側からは sin 3θ = sin θ で出たが、時空側（読み出し u = v/q₀ と分解能 δ）からは δ = π/4 の仮定に依る。

## 4. 読み（確認前）

- **「なぜ双線形か」に代数から答えられたことが、この筋の一番の成果だと思う。** ツィレルソンの定理は「量子相関は内積で尽くされる」と述べるが、なぜそうなのかは問わない。ここでは**ノルムが乗法的な代数の上で読み出しを作れば自動的にそうなる**、という形になる。そしてノルムが乗法的な実代数は 1, 2, 4, 8 次元の四つしかない（フルヴィッツ）。
- **したがって 2√2 の起源は「ノルムの乗法性」だ、という読みになる。** 干渉の強さが経路に依らないこと（`八元数の干渉と二重スリット_20261020.md` §3）と、ツィレルソン限界が同じ一つの性質から出ている。
- **残った「二者性」の問いは、むしろ本質に近い。** ベル実験の二者は実験者が用意するものだが、この枠組みでは配置の要素でしかない。**二者を分けているのは何か**という問いになり、これは `内と外の選択問題_…md` の「観測者が自分の 1 をどこに置くか」と同じ構造の問いである。

## 5. 次の検算

1. **二者性の出どころ。** 𝕆 = ℍ ⊕ ℍℓ の二つの半分を二者としたとき、E(a,b) が何になるか。閉塞した配置の二要素を二者としたときはどうか。
2. **I3322 を実際に計算する。** §2.4 の見込み（非平面でも量子値に届く）を確かめる。届かなければ枠組みの反証になる。
3. **光円錐側から π/4 を出す。** v2 §4-3。これが埋まれば「一つの読み出しから同時に出す」が完成する。
4. **三者以上（Mermin）。** 三体では結合子が効くので、八元数固有の上限が出る可能性がある。二体の 2√2 が ℂ・ℍ・𝕆 で共通なら、違いは三体以上にしか現れない。
