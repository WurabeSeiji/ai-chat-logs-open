# 検証_対照実験（シリーズ内完結の再現性保証）

## 原則

本シリーズの各論文は、**このシリーズフォルダ内のプログラムだけで独立に検算できる**ことを
絶対要件とする。別シリーズ（過去論文）の結果に依拠する場合は、以下を必ず踏む。

1. **コピー**: 依拠する過去論文のプログラム一式（公開ベースライン結果を含む）を本フォルダに複製。
2. **対照テスト**: コピーしたコードを新規実行し、公開ベースラインを再現することを確認
   （改変前の基準点を固定）。完全一致または機械精度一致を PASS とする。
3. **使用または変更**: 対照テストを通過したコードを、そのまま import して使う、または
   適切に変更して再検証する。**独自の再実装で数値を差し替えない**（改変疑義に耐えられない）。

過去データの参照だけで済ませること、プログラムなしにデータを採用することは禁止。
