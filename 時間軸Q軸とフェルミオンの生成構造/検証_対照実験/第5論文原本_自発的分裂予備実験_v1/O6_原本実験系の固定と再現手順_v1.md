# 実験O6：原本実験系の固定と対照再現手順 v1

## 1. この対照で固定する対象

前シリーズ第5論文
`次元の生成構造/N体関係波閉鎖系における自発的分裂の開始と帰結分類_完成論文_v1.md`
の「実験O6（大N開始走行）」だけを対照対象とする。

論文で使われた体数は、次の3点である。

- `N=40`（`M=780`）
- `N=300`（`M=44,850`）
- `N=1000`（`M=499,500`）

`N=3,100,1000` ではない。`N=3` は同論文の小N実験に現れ、`N=100` は後発の調査に現れるが、実験O6の論文図を構成する系列ではない。

## 2. 原本を構成する三つのプログラム

原本の所在は `次元の生成構造/自発的分裂予備実験_v1/` である。現在のフォルダにコピーされた次の三ファイルを、実験O6の固定された実験系とする。

| 役割 | ファイル | SHA-256 |
|---|---|---|
| 低ランク頂点分解エンジン | `run_n_scaling_lowrank_v1.py` | `ba0fc19b03caf06d16e97e2cd5da499ed2ed8e95288f6dbf2062bedcaf11176d` |
| 各NのCSV/JSON生成 | `run_spontaneous_splitting_largeN_v1.py` | `13baf6f5158c53ee92d1a08a0a5b60832424a83222b0601563a2676a392515ac` |
| 3系列の集約作図 | `make_largeN_figure_v1.py` | `f4cbc4efe2af2ffbffa45eec8c71ecb0340a1a3c940b78a2d83847fb03ea5804` |

三ファイルは、原本だけでなく実験O6追加時のGit履歴ともハッシュが一致する。対照実験中は変更しない。

## 3. 固定する実行条件

論文本文と保存された結果から、各Nに共通する条件を次のように固定する。

```text
delta = 1e-15
seed = 0
cap = 9000
after = 1500
tol = 1e-12
```

乱数生成器の種は走行器内部で `40260722 + 1000*N + seed` として与えられる。親状態は自己無撞着反復を最大1200回行い、種は零閉鎖核内の実正規直交対から構成する。休眠フラクションは親平面の直交補への射影ノルムとして直接測る。

原プログラムを直接使う場合のコマンドは、Nごとに独立している。

```bash
python3 run_spontaneous_splitting_largeN_v1.py 40 1e-15 --cap=9000 --seed=0 --after=1500 --tol=1e-12
python3 run_spontaneous_splitting_largeN_v1.py 300 1e-15 --cap=9000 --seed=0 --after=1500 --tol=1e-12
python3 run_spontaneous_splitting_largeN_v1.py 1000 1e-15 --cap=9000 --seed=0 --after=1500 --tol=1e-12
python3 make_largeN_figure_v1.py
```

ただし、原作図器は出力ディレクトリ内の `fcurve_*.csv` をすべて走査し、先頭3系列だけを描く。既存フォルダには後発の `N=4` CSVが混入しているため、ここで直接作図してはならない。

## 4. 隔離した対照再現

`run_original_O6_control_v1.py` は、固定三ファイルのハッシュを検査してから、出力先だけを
`O6_原本対照結果_v1/` に切り替える。原本コードの数式・初期条件・反復・測定は変更しない。

まず、低ランク実装と密行列実装の300ステップ一致を検証する。

```bash
python3 run_original_O6_control_v1.py validate
```

次に、各Nを必ず個別に実行する。

```bash
python3 run_original_O6_control_v1.py run 40
python3 run_original_O6_control_v1.py run 300
```

各走行後、生成CSVを前シリーズの保存CSVとバイト単位で比較し、JSONは実行時間を除く全項目を厳密比較する。

`N=1000` は計算時間が長いため、2026年7月24日の対照では再実行を省略する。前シリーズの保存CSV/JSONを参照系列として、来歴記録を伴って隔離結果ディレクトリへ導入する。

```bash
python3 run_original_O6_control_v1.py reference 1000
```

`N=40,300` の再生成系列と `N=1000` の原論文参照系列が揃った後に、集約図を生成する。

```bash
python3 run_original_O6_control_v1.py plot
```

一括実行も可能である。

```bash
python3 run_original_O6_control_v1.py all
```

この `all` は密行列検証、`N=40` 再実行、`N=300` 再実行、`N=1000` 原論文参照値の導入、集約作図の順で動く。`N=1000` の再実行は行わない。

## 5. 原論文の対照値

| N | f(0) | 初期成長率 / step | 閾値交差 τ | 最終ステップ |
|---:|---:|---:|---:|---:|
| 40 | `1.0092797236847578e-30` | `0.03597603872311146` | 2011 | 3511 |
| 300 | `1.403006497575905e-30` | `0.02488614006821167` | 4844 | 6344 |
| 1000 | `4.583453843361336e-30` | `0.021137264304715728` | 7926 | 9000 |

この対照は、まず前シリーズの「指数増幅から飽和域へ入る」軌道を同一条件で再現するためのものとする。時間軸・Q軸・統計性・σ比・有効ランク等の新しい観測量は、この対照が完了するまで実験系へ追加しない。
