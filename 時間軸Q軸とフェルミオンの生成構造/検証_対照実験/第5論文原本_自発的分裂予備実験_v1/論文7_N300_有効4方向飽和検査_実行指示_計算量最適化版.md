# 論文7 N=300 有効4方向飽和検査 実行指示・計算量最適化版
## \(G=W^{\mathsf T}W\) の縮約分解を主経路とする、実行可能な数値精度内厳密検査

---

# 0. 目的

N=300については、旧解析で

\[
M=\frac{300\cdot299}{2}=44850
\]

次元の関係辺空間を用い、

- 支配回転平面：2次元
- その他の非零回転部分空間：598次元
- 核：44250次元

まで計算済みである。

しかし、論文7の中心命題に必要な次の検査が漏れている。

1. 初期支配平面 \(B_0\) と瞬時支配平面 \(B_{\mathrm{dom}}(t)\) の結合階数
2. 全時間の支配平面が単一の4次元部分空間へ閉じるか
3. 5方向目以降が存在するか
4. N=5、40、300で有効方向数が4に飽和するか

本指示は、これらをN=300で検査するための実装指示である。

---

# 1. 最重要方針

## 1.1 巨大密行列を構成しない

辺空間上の生成子を

\[
K(t)\in\mathbb R^{M\times M},
\qquad
M=44850
\]

とする。

以下を禁止する。

- \(44850\times44850\) の密行列 \(K\) の構成
- `numpy.linalg.eigh(1j*K)` の実行
- 各保存時刻での \(W\in\mathbb R^{44850\times600}\) に対する全面QR分解
- 全非零固有ベクトル600本の辺空間への持ち上げ
- 全時刻での巨大基底保存

## 1.2 主計算は600次元以下に限定する

既存構造

\[
K=WJW^{\mathsf T}
\]

を使う。

ここで、

\[
W\in\mathbb R^{M\times p},
\qquad
G=W^{\mathsf T}W\in\mathbb R^{p\times p}
\]

とする。

N=300では、非零部分の有効階数は最大600である。

主計算は、

\[
G=W^{\mathsf T}W
\]

の固有分解を使って、最大600次元の正規直交縮約空間を構成する。

# 2. 数値精度内で密行列法と同値な縮約

## 2.1 Gram行列の固有分解

各保存時刻 \(t\) で、

\[
G(t)=W(t)^{\mathsf T}W(t)
\]

を構成する。

対称性を数値的に保証するため、

```python
G = 0.5 * (G + G.T)
```

を行う。

次に、

```python
lam, V = numpy.linalg.eigh(G)
```

を実行する。

固有値を降順に並べ、

\[
\lambda_1\ge\lambda_2\ge\cdots\ge0
\]

とする。

## 2.2 Gram階数の判定

単一閾値だけで決めず、

\[
\tau_G\in
\{10^{-10},10^{-11},10^{-12},10^{-13},10^{-14}\}
\]

を比較する。

採用固有値は、

\[
\lambda_a>\tau_G\lambda_1
\]

を満たすものとする。

採用数を

\[
r_G
\]

とする。

N=300では、期待される値は最大600であるが、600へ固定してはならない。

## 2.3 正規直交縮約基底

採用固有値と固有ベクトルから、

\[
V_r=[v_1,\ldots,v_{r_G}],
\qquad
\Lambda_r=\operatorname{diag}(\lambda_1,\ldots,\lambda_{r_G})
\]

を作る。

辺空間上の正規直交基底を、

\[
Q
=
WV_r\Lambda_r^{-1/2}
\]

と定義する。

ただし、\(Q\) 全体を保存する必要はない。

検証時にのみ、

\[
\|Q^{\mathsf T}Q-I\|_F
\]

を計算する。

## 2.4 縮約反対称生成子

\[
K_r
=
Q^{\mathsf T}KQ
\]

は、\(K=WJW^{\mathsf T}\) を用いて、

\[
K_r
=
\Lambda_r^{1/2}
V_r^{\mathsf T}
J
V_r
\Lambda_r^{1/2}
\]

として計算できる。

実装例：

```python
sqrt_lam = numpy.sqrt(lam_r)
S = V_r * sqrt_lam[numpy.newaxis, :]
K_r = S.T @ J @ S
K_r = 0.5 * (K_r - K_r.T)
```

ここで、

\[
K_r\in\mathbb R^{r_G\times r_G}
\]

であり、最大でも約600次元である。

## 2.5 縮約固有分解

\[
H_r=iK_r
\]

はエルミートなので、

```python
mu, U_r = numpy.linalg.eigh(1j * K_r)
```

で固有分解する。

この方法は、採用したGram像空間内にある \(K\) の全非零固有値・非零固有部分空間について、密行列固有分解と代数的に同値である。

ただし実装は倍精度浮動小数点なので、表現は、

> 数値精度内で密行列法と同値

とする。

「記号的な完全厳密解」とは書かない。

# 3. 計算量

N=300では、

\[
M=44850,
\qquad
r_G\le600
\]

である。

## 3.1 禁止方式

各時刻で \(W\) を全面QR分解すると、

\[
O(Mr_G^2)
\]

となり、

\[
44850\times600^2
\approx1.61\times10^{10}
\]

規模の演算が必要になる。

この方式を全保存時刻へ適用してはならない。

## 3.2 採用方式

主計算は、

- \(G\) の構成または再利用
- \(600\times600\) 以下の対称固有分解
- \(600\times600\) 以下のエルミート固有分解
- 支配平面2方向だけの辺空間への持ち上げ

に限定する。

各時刻の主要計算量は概ね、

\[
O(r_G^3)+O(Mr_Gk)
\]

である。

ここで、持ち上げる列数は

\[
k=2
\]

を基本とする。

全600固有ベクトルを持ち上げてはならない。

## 3.3 所要時間の見込み

最適化BLASを使う一般的なデスクトップCPUまたはApple Siliconを想定する。

既存軌道・既存 \(W\) または \(G\) を再利用できる場合の目安：

| 保存時刻数 | 推定時間 |
|---:|---:|
| 100 | 2〜10分 |
| 500 | 10〜40分 |
| 1000 | 30分〜2時間 |
| 5000 | 2〜8時間 |

これは事前予測であり、最初の10時刻の実測値から再推定すること。

## 3.4 必須ベンチマーク

本計算前に、代表10時刻だけ実行し、次を保存する。

- \(G\) 構成時間
- \(G\) 固有分解時間
- \(K_r\) 構成時間
- \(H_r\) 固有分解時間
- 支配平面持ち上げ時間
- 1時刻合計時間
- 最大メモリ使用量

10時刻の中央値を \(T_{10}/10\) として、

\[
T_{\mathrm{pred}}
=
T_{\mathrm{median}}\times T_{\mathrm{all}}
\]

を計算し、全体予測を報告してから本実行する。

# 5. 支配平面だけを辺空間へ持ち上げる

## 5.1 支配固有対

縮約固有分解から、最大正固有値

\[
\mu_1(t)>0
\]

に対応する複素固有ベクトル

\[
u_r(t)\in\mathbb C^{r_G}
\]

を取得する。

## 5.2 辺空間への持ち上げ

縮約固有ベクトルを辺空間へ戻す。

\[
u(t)
=
Q u_r(t)
=
WV_r\Lambda_r^{-1/2}u_r(t)
\]

実装では、\(Q\) 全体を作らず、

```python
coef = V_r @ (u_r / numpy.sqrt(lam_r))
u = W @ coef
```

とする。

## 5.3 実2次元回転平面

複素固有ベクトルから、

\[
b_1=\sqrt2\,\Re u,
\qquad
b_2=\sqrt2\,\Im u
\]

を初期候補とし、薄いQRまたはSVDで正規直交化する。

\[
B_{\mathrm{dom}}(t)
=
[b_1,b_2]
\in\mathbb R^{M\times2}.
\]

必ず、

\[
B_{\mathrm{dom}}^{\mathsf T}B_{\mathrm{dom}}=I_2
\]

を確認する。

符号、複素位相、平面内基底回転に依存する比較をしてはならない。

# 6. 検査A：初期平面と瞬時支配平面の結合階数

初期支配平面を、

\[
B_0\in\mathbb R^{M\times2}
\]

とする。

各時刻で、

\[
Q_4(t)
=
[B_0\mid B_{\mathrm{dom}}(t)]
\in\mathbb R^{M\times4}
\]

を作る。

直接SVDを行ってもよいが、4列しかないため、

\[
C_4(t)
=
Q_4(t)^{\mathsf T}Q_4(t)
\in\mathbb R^{4\times4}
\]

の固有値から特異値を求める方を推奨する。

\[
q_j(t)=\sqrt{\lambda_j(C_4(t))}.
\]

保存項目：

- \(q_1,q_2,q_3,q_4\)
- 数値階数
- 主角 \(\theta_1,\theta_2\)
- crossingからの相対時刻

判定：

- \(q_3\approx q_4\approx0\)：新方向なし
- \(q_3>0,\ q_4\approx0\)：新方向1本
- \(q_3>0,\ q_4>0\)：新方向2本、結合階数4

注意：

\[
\operatorname{rank}Q_4(t)\le4
\]

は構成上自明である。

この検査だけで5方向目以降の不存在を主張してはならない。

# 7. 検査B：全時間が単一4次元部分空間へ閉じるか

## 7.1 候補4次元空間

代表時刻 \(t_\ast\) について、

\[
C_{\mathrm{raw}}
=
[B_0\mid B_{\mathrm{dom}}(t_\ast)]
\]

を作り、薄いSVDまたはQRにより、

\[
C_4\in\mathbb R^{M\times4},
\qquad
C_4^{\mathsf T}C_4=I_4
\]

を得る。

代表時刻は最低4種類試す。

1. crossing直後
2. 準安定域前半
3. 準安定域中央
4. 最終時刻

## 7.2 閉鎖残差

各時刻について、

\[
R_4(t)
=
B_{\mathrm{dom}}(t)
-
C_4\left(C_4^{\mathsf T}B_{\mathrm{dom}}(t)\right)
\]

を計算する。

\(M\times M\) 射影行列を構成してはならない。

保存量：

\[
\varepsilon_F(t)=\|R_4(t)\|_F,
\]

\[
\varepsilon_2(t)=\|R_4(t)\|_2,
\]

\[
\eta_4(t)
=
\frac{\|R_4(t)\|_F^2}
{\|B_{\mathrm{dom}}(t)\|_F^2}.
\]

中心量：

\[
\varepsilon_{F,\max}
=
\max_t\varepsilon_F(t),
\]

\[
\eta_{4,\max}
=
\max_t\eta_4(t).
\]

## 7.3 5方向目以降のストリーミング探索

最初から基底数を4へ固定しない。

初期基底を

\[
C=B_0
\]

として、各時刻の \(B_{\mathrm{dom}}(t)\) を順次直交化する。

推奨実装：

```python
for col in Bdom.T:
    v = col.copy()
    v -= C @ (C.T @ v)
    # 再直交化
    v -= C @ (C.T @ v)
    nv = numpy.linalg.norm(v)
    if nv > add_threshold:
        C = numpy.column_stack([C, v / nv])
```

閾値を、

\[
\tau_{\mathrm{stream}}
\in
\{10^{-8},10^{-9},10^{-10},10^{-11},10^{-12}\}
\]

で比較する。

保存項目：

- 各時刻の基底次数
- 新方向追加時刻
- 追加前残差
- crossingからの遅れ
- 最終基底次数

# 8. 検査C：全時間結合特異値

## 8.1 全基底を巨大行列として保存しない方式

全時刻の支配平面を

\[

=
[B_0\mid B_{\mathrm{dom}}(t_1)\mid\cdots]

と考える。

ただし、\(\mathcal B\) 全体を必ず保存する必要はない。

ストリーミングSVD、増分QR、または間引き時刻の結合行列を使う。

## 8.2 独立確認用の間引き結合行列

全保存時刻から、

- crossing前
- crossing近傍
- crossing直後
- 準安定域前半
- 準安定域中央
- 準安定域後半
- 最終時刻

\[
\mathcal B_{\mathrm{sub}}
\]

を作り、特異値

\[
s_1\ge s_2\ge\cdots

\[
G_{\mathcal B}
=
\mathcal B_{\mathrm{sub}}^{\mathsf T}
\mathcal B_{\mathrm{sub}}

の固有分解である。

\[

# 14. 判定規則

## 14.1 4方向成立

\[
q_3>\tau q_1,
\qquad
q_4>\tau q_1
\]

が安定して成立する場合、

\[
\operatorname{rank}[B_0|B_{\mathrm{dom}}]=4
\]

と判定する。

## 14.2 4方向飽和

以下をすべて満たす場合のみ、

> N=300でも有効運動方向は4に飽和する

と報告してよい。

1. \(q_3,q_4\) が有限
2. 全時間結合で \(s_4>\tau s_1\)
3. 全時間結合で \(s_5\le\tau s_1\)
4. 全時刻の4次元閉鎖残差が数値誤差範囲
5. ストリーミング探索で5本目が安定して追加されない
6. 閾値感度を変えても結論が変わらない
7. N=40の密行列法とGram縮約法が一致する
8. 持ち上げ固有対残差が十分小さい

## 14.3 5方向目以降の兆候

以下のいずれかが再現可能なら、4方向飽和を棄却または保留する。

- \(s_5/s_1\) が数値誤差より明確に大きい
- ストリーミング基底に5本目が追加される
- 閉鎖残差が特定時刻で系統的に増える
- 時刻サンプリングを細かくしても5本目が残る
- 閾値変更で消えない
- 別の代表時刻から作った \(C_4\) でも閉鎖しない

# 18. 最終報告文

4方向飽和を支持した場合のみ、次の趣旨で報告する。

> N=300の完全関係空間は \(M=44850\) 次元であり、瞬時生成子には多数の非零固有方向が存在する。一方、初期支配平面と分裂後支配平面の結合階数は4であり、全時間の瞬時支配平面を結合した大域部分空間でも第5特異値は数値誤差範囲に留まった。したがって、Nの増大は有効運動方向を段階的に増加させず、分裂停止後の支配運動は4次元部分空間に飽和することが数値的に支持された。

飽和を支持しない場合は、そのまま報告する。

4次元解釈に合わせて、5方向目以降を切り捨ててはならない。
