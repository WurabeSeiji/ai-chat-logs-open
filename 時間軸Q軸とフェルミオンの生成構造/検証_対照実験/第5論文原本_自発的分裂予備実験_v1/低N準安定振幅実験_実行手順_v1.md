# 低N準安定振幅実験：実行手順 v1

## 目的

前シリーズ第5論文の凍結解除力学を変更せず、次の二点を `N=3〜7` で測る。

1. 指数増幅が鈍化する時刻で、閉鎖制約接空間上の局所横方向成長率がどう変化するか
2. 準安定域の振幅がNに対してどの逆スケールを持つか

時間軸、Q軸、ボゾン／フェルミオン対応は、この段階では導入しない。

## 原本から保持するもの

- 位相差正弦生成子
- 毎ステップの生成子再構成
- スペクトルノルムによる正規化
- Cayley更新
- 自己無撞着親状態
- 零二乗和閉鎖

小Nではスペクトルノルムを毎ステップ厳密対角化で求める。大N走行用のwarm-start冪反復は数値近似なので、この小N判別実験では使用しない。

`N>=4` の種は、大N用 `span(W)` 核射影ではなく、前論文の小N実験と同じく親平面の実直交補に
実正規直交対を構成する。大N核射影は小Nで補空間が退化し、閉鎖誤差を増幅するため使用しない。

## N=3の処理

`N=3`、`M=3` では親平面の実直交補が1次元しかなく、
`g=(u+iw)/sqrt(2)` 型の零閉鎖核種を置けない。

そこで円偏波親 `v` と実補方向 `u` から、

```text
Z = v + delta*u - (delta^2/2)*conjugate(v)
```

を構成する。`v^T conjugate(v)=1` なので、
`delta^2 u^T u` と共役親方向の交差項が相殺し、代数的に `Z^T Z=0` を保つ。

## 個別走行

各Nは別プロセスで実行し、個別CSVとJSONを生成する。

```bash
python3 run_lowN_metastable_scan_v1.py 3 1e-15 --seed=0 --cap=100000
python3 run_lowN_metastable_scan_v1.py 4 1e-15 --seed=0 --cap=100000
python3 run_lowN_metastable_scan_v1.py 5 1e-15 --seed=0 --cap=100000
python3 run_lowN_metastable_scan_v1.py 6 1e-15 --seed=0 --cap=100000
python3 run_lowN_metastable_scan_v1.py 7 1e-15 --seed=0 --cap=100000
```

正式な統計では各Nについて16〜32 seedを実行する。`delta` 依存の統制には
`1e-6, 1e-9, 1e-12, 1e-15` を使う。

親構成残差が `1e-10` を超えた走行はプログラムが失敗として停止する。

## 保存量

CSVには次を保存する。

- 初期親平面からの補振幅 `A_perp=sqrt(f)`
- 瞬時生成子の全 `sigma_j`
- 各瞬時回転平面のエネルギー `h_j`
- 第2平面振幅 `A_2=sqrt(h_2/h_total)`
- `epsilon=1/2-sigma_2/sigma_1`
- PR、正規化エントロピー
- 関係波振幅の平均・中央値・5/95%点
- `Z^T Z`、Hermitianノルム
- 閉鎖制約接空間上の1ステップ最大特異値と対数成長率

`A_perp`、`A_2`、`epsilon` は同一視せず、別列として保持する。
`N=3` の反対称生成子は1回転平面しか持たないため、`A_2`、`sigma_2/sigma_1`、`epsilon` は
0ではなく未定義として空欄で保存する。

準安定状態で `PR=M` へ到達し、全関係波の振幅が等しくなった場合は、ノルム保存から

```text
|Z_e| = 1/sqrt(M) = sqrt(2/[N(N-1)])
```

となる。RMS振幅はノルム定義だけで常に `1/sqrt(M)` なので判定には使わず、中央値と
5/95%点の収束、および `PR/M` を使って「等振幅化が実際に起きたか」を検証する。
