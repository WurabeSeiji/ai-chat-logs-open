## 0. シリーズの位置づけ

- 前シリーズ「次元の生成構造」（第一〜第六論文）は**「読出しの飽和」**の物語として閉じている。本シリーズは**「軸の誕生」**の物語であり、混ぜない（両方が薄まる）。
- 前シリーズへの依存: 第一論文（有限位数回帰 Uⁿ = I）、第三論文（ランク線形上界）、第四論文（回転平面分解・AB同型）、第五論文（自発的分裂定理・閉鎖保存量）、第六論文（波の数＝分解能、帯域端凝集）を前提として引用する。

**中心テーゼ**:
> xyzR の4軸が三方向飽和した閉鎖系では、新たに鋳造される平面は空間として読めず、回転角が t、巻き数が Q として読み出される——公理系の読出し予言（エネルギー＝t軸方向運動量、電荷＝Q軸方向運動量、質量＝R軸方向運動量）に、誕生の機構が与えられる。その平面が最初の安定根 m/n = 1/2 に落ちたとき、フェルミオン的な交換クラス（反対称交換・排他性・半巻き）が分化する——ボゾン的な海から最初に分化する交換クラスはフェルミオン的である。

**スコープ宣言（重要）**:
> 本シリーズが主張するのは**読出し軸（t, Q）の誕生と交換クラスの分化**——根源的な対称構造の水準——まで。**粒子の誕生はどこでも主張しない**。現実のフェルミオン（電子・ニュートリノ等）やボゾン（ヒッグス等）への写像は別問題であり、この時点で写像可能性を問うこと自体が時期尚早。粒子表から言えるのは「単純な写像ではあり得ない」ことだけ（第5節・N6参照）。

## 6. 次期シリーズ（写像問題）と矛盾しないための準備

次期シリーズは粒子への写像を主題とする。本シリーズでは写像を主張しないが、後で理論体系全体を掘り返さずに済むよう、以下を布石として仕込む。

**基本認識**: 標準模型の粒子表を写像の「到達目標」として固定しない。灰色猫（中間根＝エニオン的クラス）は、ボゾン/フェルミオン二分法そのものが**基本分類でなく端点**であることを予言している。二分法は存在の水準の事実ではなく、**三方向飽和した読出しの定理**の可能性が高い（交換が3方向空間読出しを通ると置換群に落ちて ±1 のみ残る。ブレイド群の中間位相は2次元平面の住人）。標準模型は3D読出しが見える範囲では厳密に正しいが、その分類体系（行の切り方）は射影後の粗視化——「同じ結果の別写像」姿勢とは矛盾しない。なお読出しが2次元に閉じ込められた現実系（分数量子ホール）で中間統計は既に観測済み（2020 エニオン干渉実験）であり、「二分は次元条件付き」は確立事実。

**見落とされている可能性のあるクラス分け（候補・層3）**: 結晶学的制限による根の二階級分化。格子と両立する有限位数回転だけが厳密層に住める。
- 結晶学的根: 厳密層に住める——安定クラス。非結晶学的根: 揺らぎ層でしか実現しない——原理的に準安定・有限寿命
- **次元による精密化（重要）**: 2D/3D 格子の制限は n ∈ {1, 2, 3, 4, 6} だが、基板が4次元格子なら φ(n) ≤ 4 により **n ∈ {1, 2, 3, 4, 5, 6, 8, 10, 12}** まで開き、どれが実現するかは格子種に依存する——超立方 Z⁴ は 8 まで、D₄（Hurwitz 四元数・24胞体・F₄）は 12、A₄ は 5 と 10。追加分 {5, 8, 10, 12} は準結晶の対称性そのもので、準結晶の構成法（カット・アンド・プロジェクト＝高次元格子の射影）は本モデルの中心投影読出し（公理0.5）と同一機構
- **基板診断**: E4 根ヒストグラムの尾（n = 5, 8, 10, 12 の有無）が厳密層の基板格子を直接同定する。安定な n = 5 根の観測は「基板は4次元格子」の内部証拠（3D結晶では不可能な位数）。さらに H14（8軸・E8）が正しければメニューは φ(n) ≤ 8 まで開く（n = 7, 9, 14, 15, 16, 18, 20, 24, 30 等が追加）——尾がどこまで伸びるかが「4次元基板か、glue された8次元基板か」を判別する第二の診断になる
- 別系列（差異の判別と最小レジスタ）の主定理候補 Z₄/Z₆ 結晶学的制限と同じ着地点＝アトラクター収束の徴候

**格子・球面界面の算術（内部系列との接合）**: 結晶学的制限（格子 vs 回転）と α⁻¹ 整数部の格子勘定（格子 vs 球面殻）は同じ型の通約算術。α⁻¹ = 137 + (π²/2)α の二層＝格子の勘定＋連続幾何の補正、という読みと整合し、α は「離散基板と創発球面の界面を測る数」の位置づけを得る。
- **数え上げ N₀(3) = 137 は公開済み2論文で厳密確立**（監査完了）: BH熱力学 論文3（DOI 10.5281/zenodo.19839395、k ≤ 60 厳密計算、Δ(R) = (16π/3)R³ − 6πR² + … の解析導出、Jacobi r₄ 接続）＋ 双対幾何 論文2（DOI 10.5281/zenodo.20607574、半径スイープ R = 0.5〜10⁴、殻分解 1+8+24+40+64 = 137）。内接条件 Σ(|cᵢ|+1/2)² ≤ R² は規約でなく補題（最遠頂点）から強制され、4倍整数化で境界判定は厳密、接触セルは角セル恒等式 4(k+1/2)² = (2k+1)²（n = 完全平方次元のみ成立、最小非自明 n = 4）による構造的事実
- 未確定なのは数え上げでなく**対応主張**（この137がα⁻¹整数部である）のみ。両論文は意図的に物理対応を主張しないスコープ設計であり、対応主張の昇格は対応写像のプレレジストレーション（N6）を通す

**本シリーズへの布石4点**（→ 引用文献は第7節）:
1. **N3 の語順**: 二分法を前提にせず「梯子が基本、二分は3方向読出しの定理（候補）」と書く。二分の導出（3D交換→置換群→±1）自体を N3 の定理候補に含める
2. **E4 の拡張**: 根の分布に加え**中間根の寿命スペクトロスコピー**を取る。予言:「結晶学的根（n ≤ 6）は長寿命、非結晶学的根は有限寿命で梯子を降りる」——二階級分化の直接測定
3. **禁止則台帳の向きの反転**（N6）: 「粒子表に合わせる」でなく「**粒子表が極限として導出されるべき**」。写像の型は単射でなく射影（粗視化）——標準模型の行は根クラスの商
4. **スピン↔統計連動の再位置づけ**: 「唯一保存される連動」は正確には端点における影。細かい連動（巻き数 m/n ↔ 交換根 m/n）の n = 2 断面がスピン統計定理として見えている
