## finite_order_clustering.py が示したこと（負の知見）

1. **モノドロミー well-definedness（前提作業）は方向として妥当**: 飽和後の主平面回転率は
   時間窓に依らず一定（窓間相対ばらつき中央値 3.5e-4）。σスペクトル比はシード非依存で再現。
   → ただし下記の観測量欠陥のため、この確認も正式測定として設計し直す必要がある。

2. **周波数比観測は欠陥**: 平面間位相速度比が全て ≈1 に出たが、これは物理でなく
   測定漏れ（状態が主平面に約85%集中し、全固定枠射影が主平面周波数を拾う）。棄却。

3. **σスペクトル比は再現するが N 依存で低位数根に乗らない**: N=5 で σ2/σ1≈0.28、
   N=6 で≈0.38（各4シード安定）。cos²(πm/n) の低位数根（0.25, 0.5, 0.75…）に乗らない。

## なぜこれが結果にならないか（核心）

有限位数根 R = cos²(πm/n) は元来**2体交換散乱の交換係数**の量である。N体自発分裂の
生成子σスペクトルと R の間に、**検証された対応写像（橋）が存在しない**。σ2/σ1 を R と
同一視する根拠がないまま「集積した/しない」を論じるのは、このシリーズが批判してきた
「事後の辻褄合わせ」そのものである。
