# 補遺：対数写像はスケールと量子化を分離する
## ——g は特権スケールとして分離され、ω はスケール不変として残る

**関連論文：**「高い対称性の極限におけるスケールの対数写像とスケール・量子化の分離について」§7.3（Concept DOI: 10.5281/zenodo.20740841）

## 趣旨

本補遺は、関連論文の核である §7.3「写像の核心：スケール（g）と量子化（ω）の分離」を、独立に展開する。親論文に新しい主張を加えるものではなく、最も誤読されやすいこの一点——**対数写像による平坦化は「情報を捨てている」のではなく、スケール（g）と量子化（ω）を分離している**こと——を明示することを目的とする。

通常、対称極限での平坦化は「構造が消える・自明になる」と読まれやすい。だが対数写像は ν も δ も同じ写像で写し、**スケール（g）は特権・分離可能な座標として括り出される**一方、**量子化（ω＝Δ）はスケール不変ゆえ分離後も不変に残る**。これが分離である。物理（量子化）が消えないのは、量子化が初めから g（スケール）にではなく ω（揺らぎ・面積、スケール不変な半ビット）に宿っていたからである。これは全対称を要さず、任意の次元で成立する。

本補遺は厳密な証明ではなく、親論文 §7.3 の構造の明示である。揺らぎの大きさ ±1/2 は措定である（親論文 §6.2）。物理量への同定は行わない。本補遺で言う「分離」は operational な意味に限り、シンプレクティック形式を厳密に保つ正準変換であるという主張は含まない（その厳密化は今後の課題）。

---

## 1. 二つの量：g と ω

本系には、二つの独立な実保存量がある（親論文 公理4・公理5、および補遺「複素構造は措定でなく帰結である」）。両者は複素内積 ⟨·,·⟩=g+iω の実部・虚部に対応する。

**g（実部・距離・スケール）：** 二乗和

$$g = \sum \nu_n^2 = R^2.$$

これは観測者にはスケール R（系の大きさ・距離・計量）として現れ、規格化（Born ノルム）の側である。SO(2)——二乗和を保つ回転——の不変量である。

**ω（虚部・面積・量子化）：** 揺らぎの積

$$\omega = \delta_1\delta_2 = \tfrac{1}{2}.$$

これは面積・シンプレクティック形式であり、量子化を担う側である。SO(1,1)——積を保つ双曲的変換——に関係する。

親論文の注の通り、g と ω は相互に導出できない独立な量である。一方はスケール（連続な大きさ）、他方は量子化（離散の最小単位）を担う。

---

## 2. 対数写像は g を分離する

基本量を二乗量の対数 N=log₂ν として導入する（親論文 §4）。この写像はスケール（g）側を**特権座標として分離する**。

積（共役関係）νλ=k は対数で加法的恒等式 ΣNᵢ=K になる。**正準化**：保存量を特権スケール C=k^{1/n} として分離し、規格化シェイプ N̂ᵢ=log₂(νᵢ/C)（ΣN̂ᵢ=0）を取る。これは**任意の次元で成立し、全対称を要さない**（正写像・逆写像の厳密な定式化は補遺「(ν, δ) と (N, Δ) の写像・逆写像」）。スケールの源は二乗（冪）であり、対数は冪を線形化する。

**g は gauge として括り出せる。** スケール C は無変換で渡される唯一の特権座標であり、別座標として分離すれば（あるいは捨てれば）残るのはスケール不変なシェイプである。g 側には量子化を担う構造は無い——もともと g はスケールを担い、量子化を担わなかったからである。

---

## 3. 揺らぎ δ も同じ写像で写るが、Δ はスケール不変

揺らぎ δ も、中心値 ν と**同じ写像** func=log₂ で写る：δ → Δ=log₂(δ の因子)（補遺「(ν, δ) と (N, Δ) の写像・逆写像」§4）。すなわち**対数写像は δ にも作用する**——これは ν→N̂ と同形の正準化であり、無視してはならない。

ただし結果の Δ=±1/2（半ビット）は**スケール不変**である：特権スケール C に依らず、どの scale でも同じ ±1/2。ゆえにスケール C を gauge として分離・括り出した後も、Δ は不変量として残る。**これが ω の不変性の正体である**——「対数写像が ω に作用しない」のではなく、「δ も同じ写像で Δ に写るが、Δ はスケール不変」である。

具体的に、半ビット ±1/2 はスケール C と独立で、C を分離しても変わらない。半ビットを共役対のいずれに配分するかという自由度（Δ_a+Δ_b=0、和ゼロ、補遺「揺らぎの和ゼロから不確定性へ」）も、C の分離と独立に保たれる。

**Δ（ω）はスケール不変な量子化の最小単位として残る。** ω＝面積 δ₁δ₂=1/2 は、このスケール不変な半ビットの単位であり、スケール分離（gauge 化）の後も量子化の最小単位として不変に残る。

---

## 4. 分離の構造

以上より、対数写像は二つの量を分離する。

| 量 | 担うもの | 対数写像の下で |
|---|---|---|
| g（二乗和・距離・実部） | スケール（連続な大きさ） | 平坦化される（gauge として除ける） |
| ω（積・面積・虚部） | 量子化（離散の最小単位） | 不変に残る |

**分離の operational な意味：** 「分離する」とは、写像が ν も δ も同じ写像で写しつつ、g（スケール・実部）を特権スケール C として分離・括り出す一方、ω（Δ・虚部）はスケール不変ゆえ不変量として残ることを指す。g と ω は複素内積 g+iω の実部・虚部であり、写像は両方を写すが、実部のスケールは gauge として分離可能、虚部 ω はスケール不変として残る（図1）。

**図1（fig4_g_omega_separation.svg）：** 対数写像による g/ω 分離。ν 空間のスケール g は、対数で特権スケール C として分離・括り出される（gauge）。一方、量子化 ω（半ビット ±1/2）は写像で不変に残る。これは情報の喪失でなく、g と ω の分離である（全対称不要）。

**「平坦化しても物理が消えない」ことの内実：** スケール（g）を特権座標として分離・括り出しても、量子化（ω）が残るのは、量子化が初めから g（スケール）にではなく、ω（揺らぎ・面積）に宿っていたからである。写像は g を分離するが ω を畳まない。ゆえに、スケールを括り出しても量子化は残る。

この分離は、量子化（ω）が、スケール（g）から独立な、別の保存量であることの帰結である。スケールを平坦面に押し込んで gauge 化し、量子化をその平坦面上の不変量として純化する——これが対数写像の働きである。

---

## 5. 構造の要約

対数写像 N=log₂ν は、複素内積 g+iω に対し：

- **実部 g（スケール）を特権座標として分離・括り出す（gauge、全対称不要）。**
- **虚部 ω（積・量子化、Δ）も同じ写像で写るが、Δ はスケール不変ゆえ平坦面上の不変量として残る。**

平坦化は情報の喪失ではなく、二つの量の分離である。スケール（g）は連続な大きさを担い、平坦化可能。量子化（ω）は離散の最小単位を担い、写像で不変。両者が独立であること（親論文の注：公理4 と公理5 の相互導出不能）が、この分離の根拠である。

これが親論文の核心である——高い対称性の極限で平坦化しても、量子化は消えない。量子化は、平坦化される側（g・スケール）ではなく、不変に残る側（ω・面積）に宿るからである。

## 6. 限界（読み解きの注意）

本補遺は親論文 §7.3 の構造の明示であり、新しい主張を加えない。以下を明記する。

1. **「分離」は operational な意味に限る。** 写像が g を平坦化し ω を不変に保つことを指す。シンプレクティック形式を厳密に保つ正準変換であるという主張は含まない。その厳密化（写像が正準変換であることの証明）は今後の課題である。

2. **±1/2 は措定である。** 親論文 §6.2 の通り、ω の最小単位 ±1/2 は導出ではなく措定であり、本補遺の分離はこの措定を前提とする。

3. **既知枠組みとの異同は未対照である。** 本補遺の g/ω 分離が、既知の Kähler 幾何（計量 g とシンプレクティック形式 ω が複素構造で結ばれる構造）や共形平坦性とどう異同するかは、厳密には対照されていない。親論文 §8.4 の限定の通り、本結果が既知枠組みの特殊例に留まるか否かは確定できない。

4. **分離は任意の次元・任意の k で成立する。** 親論文 §8.1（改訂）の通り、加法構造の平坦化と写像の完全可逆性（正準化：特権スケール分離）は全対称を要さない。本補遺の g/ω 分離も任意次元で成立する。射程外は曲率テンソルへの拡張と、二乗和 Σν² 自体の線形化である。

5. **物理的同定を行わない。** g（スケール）・ω（量子化）の物理的名称は無名のラベルであり、本補遺は特定の物理量への同定を行わない。
