# 頂点数は振動数 — 写像とスピンの萌芽（機構の覚書）

## 位置づけ・スコープ

本書は**機構の語り**であり、公開論文の主張ではない。前二書（『νからψへ』『最もシンプルな曲率系 1+1』）の続きで、最小の 1+1 系を「頂点数＝振動数」という写像で読み直し、そこから波長空間と振動数空間の双対、さらにスピン・統計（ボソン/フェルミオン）の萌芽が出てくる行程を、後日の同型議論の足場として保持する。

物理解釈は分離し、構造の言明に留める。貫くのは「無名性が許す差異の限界＝2」「積＝面積の保存」、そして本書で立つ「**頂点数＝振動数（数え＝デジタル）、辺＝波長（連続）、その双対**」。

-----

## 1. 二つの共役空間 Λ と N

これまで一つの空間の中で波長と振動数を逆数（νλ=k）で行き来させ、値域がねじれていた（波長読みで周長0〜8、振動数読みで3〜5）。これは一空間内の変換と見た誤り。正しくは——**最初から別の二つの共役な空間がある**。

$$\Lambda=(\lambda_x,\lambda_y,\lambda_z,\lambda_t,\lambda_R,\lambda_Q)\quad\text{波長空間}$$
$$N=(\nu_x,\nu_y,\nu_z,\nu_t,\nu_R,\nu_Q)\quad\text{振動数空間}$$

- 二空間は**共役（双対）**で、xyztRQ は**どちらからも写された像**にすぎない。
- 複素ヒルベルト空間 ⟨·|·⟩=g+iω の実部 g（距離・二乗和）と虚部 ω（面積・量子化）に、Λ と N が対応。フーリエ双対（ポントリャーギン双対）で結ばれる。
- 確立済みの「保存量は位相面積 ∮p dq、λ も k もその縦横の射影」——Λ と N はその縦軸・横軸。xyztRQ はさらにその先の像。
- 「空間（波長）読みか時間（振動数）読みか」＝Λ から見るか N から見るか。時間・空間は基本でなく、Λ・N からの二通りの写像。

**幾何構造は同じ（合同）。** ν と λ のラベルは任意（無名性）。二空間は同じ幾何を持ち、どちらが本物ということはない。難しいのは幾何でなく、**合同な二空間を逆数 νλ=k で貼ること**——点ごとの対応が逆数（非線形）でねじれる。値域のねじれはこの貼り合わせから出る。

**貼り合わせ＝中心投影の反転（0↔∞）。** 逆数 νλ=k は 0 と ∞ を入れ替える（λ→0 が ν→∞）。これは中心投影の反転そのもの。Λ→N の写像は、新規でなく、確立済みの中心投影機構の適用。不動点は ν=λ=√k（=45度の対称点、積最小1/2）で、二空間が重なる唯一の点。

## 2. 頂点⇄辺の双対 ＝ Λ⇄N の写像

Λ→N の読み替えの、安易で正しい実装：**頂点と辺を読み替える＝射影双対（点⇄直線）**。

- **頂点（数える・整数・離散）↔ 振動数空間 N。** 頂点数はデジタル値＝振動数側。
- **辺（長さ・連続）↔ 波長空間 Λ。** 辺は連続量＝波長側。

多面体の双対で頂点と辺（2次元なら頂点⇄辺）が入れ替わる＝そのまま N⇄Λ の双対。正方形は自己双対（頂点4⇄辺4）。

**非対称の正体。** 振動数読みが整数で下限を持ち（頂点＝数えだから、閉路の最小は3）、波長読みが連続で0に潰れる（辺＝長さだから）——これは頂点（離散）と辺（連続）の素性の差。前の「値域のねじれ」は、この差。

確立済みとの一致：先行研究「0次元（個数）と1次元（辺長）のみ有理数、2次元以上は無理数」「5次元正軸体と超立方体は双対、頂点⇄胞が入れ替わる」。頂点（個数・整数・振動数）と辺（長さ・連続・波長）の分離が、既に論文にあった。

（双対と反転は同じ写像の二面：射影双対＝離散側の記述、0↔∞ 反転＝連続側の記述。）

## 3. 頂点数＝振動数（強力な写像）

**振動数 ν ＝ 頂点数。** これが本書の中心。頂点は数える（整数・デジタル）＝振動数の離散性そのもの。

**最初の設定の訂正。** ν=1, λ=1, νλ=1 は写像前は正しい。だが**正方形に写像した瞬間、周長＝λ=4 になっている**のに ν=1 を据え置いたのが誤り。頂点数＝振動数なら、正方形（頂点4）は **ν=4**。写像（正方形化）が νλ=k の k を 1→16 に持ち上げた。

これで前の混乱（ν=1/4＝45度シフト、波長0〜8 と振動数3〜5 のねじれ）はすべて、**写像後も ν=1 を据え置いた artifact**だったと分かる。正多角形は頂点数＝辺数だから ν=λ（対称）、ねじれは消える。

（注：k＝νλ は写像で変わる量。保存されるのは別物＝位相面積 ∮p dq。頂点数 ν と辺長 λ は写像で変わり積 k も変わるが、面積は写像の前後で保存。）

## 4. 下から数える ν=0,1,2,3,4

**ν=0：頂点ゼロ＝構造なし＝0次元。** 数える対象なし、無名そのもの。中心投影で全情報を載せる0次元の点と一致。

**ν=1：頂点1個＝折り返し点1個。** 頂点1個は素直な閉路にならない（半直線は有界でない、線分は頂点2）。円（中心を頂点と数える）は**棄却**——円周 2πR で π＝連続系が混入（ずっと棄却してきたもの）。正しい像：**原点1個で90度折り返し、180度で原点に戻る往復路**。線分の両端を1点で同一視した畳み込み。π なし、有界、頂点1個。往復＝行き帰り＝+ν と −ν の共役対の最小実現。

**ν=2：頂点2、線分。** 折り返しまで180度、折り返して360度。頂点1個（180度）の2倍。

**ν=4：頂点4、正方形。** 720度（前書で確定）。

-----

## 5. 一頂点＝180度、位相一周＝頂点数×180度

**一頂点あたり位相180度（＝λ＝半波長）。位相予算＝頂点数×180度。**

- ν=1：180度（往復）
- ν=2：360度
- ν=4：720度（正方形）

前書で「位相一周720度、曲がり一周360度」と分けて720の出所を悩んだ所が、**頂点数×180度**で一本に片付く。正方形（頂点4）の720度は頂点数から自然に出る。

**三つが噛む：**
$$\text{頂点数}=\nu\quad(\text{振動数・数え})$$
$$\text{一頂点}=180\text{度}=\lambda\quad(\text{半波長・波長})$$
$$\text{位相一周}=\nu\times180\text{度}=\nu\lambda=k$$

位相一周＝νλ＝k が「頂点数×半波長」として幾何的に読める。

**位相と曲がりの比。** 曲がり一周＝360度（頂点数によらず一定、ガウス・ボネ）、位相一周＝頂点数×180度。**比＝頂点数/2**。ν=2 で比1（位相＝曲がり）、ν=4 で比2（位相が曲がりの2倍）。

## 6. 偶奇とスピンの萌芽

**ν=3 の問題。** 頂点3、三角形、位相一周＝3×180＝**540度**＝360度＋180度。一周（曲がり360度）して戻ると**位相が180度余る**。整数周にならない（1.5周）。

**180度ずれて閉じる＝1+1 の時と同じ。** 半波長ずれ＝符号反転（+→−）。一周で符号反転し、二周（1080度＝360×3）で元に戻る＝**反周期的（antiperiodic）**。これは奇数倍音と同じ構造。

**偶奇の分かれ：**
- **偶数 ν（2,4）**：位相が整数周、一周で戻る＝**周期的・因果なし・整数スピン・ボソン的**。
- **奇数 ν（3）**：180度ずれ、二周で戻る＝**反周期的・因果あり・半整数スピン・フェルミオン的**。

**因果の芽。** 奇数の180度ずれ＝戻ると符号反転＝出発点と状態が違う＝前後の区別＝**因果**。偶数（ぴったり戻る）は前後の区別なし＝因果なし。「勝手に因果ができている」のは、**奇数頂点の半周期ずれ（フェルミオンの反対称）が因果（時間の矢）を生んでいる**——スピン統計定理の芽。前に「因果は基準の選択から」と言ったが、奇数 ν は選ばずとも構造自身が前後を作る。

**これはスピンの議論だった。** 頂点数の偶奇の話＝ボソン/フェルミオンの区別＝スピン・統計。**スピン＝頂点数/2＝位相と曲がりの比**。

確立済みとの一致：先行研究「5次元正軸体の配向自由度からスピン s=0,1/2,1,3/2,2,5/2 の6種」「半整数（フェルミオン）と整数（ボソン）の区別が**頂点状態と辺中点状態の幾何学的差異**として導出」。頂点（整数）と辺中点（半整数）——今日の頂点⇄辺双対と直結。**本書の最小系の議論が、スピン分類論文の幾何的な底を下から再現していた。**

## 7. ν=1 は存在しない（円のスキップと公理2）

**頂点1の折り返しと頂点2の線分は、幾何学的に区別できない。** 折り返しという「説明」を被せるかどうかは表現の都合で、幾何そのものには頂点が何個あるかしか無い。折り返し点を頂点と数えても、それは頂点2の線分と同じ図形。**だから「頂点1」という独立した幾何は立たない**——頂点2と同一。

**ゆえに ν=1 は存在しない。** 頂点1は頂点2に吸収されて消える。§4 で「ν=1＝折り返し1個の往復」と書いたが、それは頂点2と区別できないので、独立な状態ではない。

**円なら ν=1 を救えるが、スキップされる。** 頂点1を「中心1個＝円」として救う道はある（§4 で検討）。だが**円は波長が離散値になれない**——円周 2πR で λ が π を含む連続値になり、整数の数え（頂点数＝振動数＝デジタル）に乗らない。振動数が整数である以上、連続な円周長は許されず、**円（ν=1）はスキップされる**。論理的候補だが離散性と両立しないので飛ばされる。

**だから振動数の数えは ν=0, 2, 3, 4, … と、1 を飛ばす。**

**これは公理2 の幾何実現。** 公理2「無名性の限界＝2、1 は対照が無く 0 と区別できない」が、ここで「ν=1（頂点1）は ν=0 でも ν=2 でもあり得て独立に立たない＝スキップ」として出てくる。**0 の次が 2**——公理2 そのもの。前に「1 は立たない」と言ったものが、頂点数の写像で「ν=1 はスキップ」として再現された。

## 確定形

- **二つの共役空間** Λ（波長）と N（振動数）が、複素の実部・虚部／フーリエ双対／位相面積の縦横射影として別々に在り、xyztRQ は両方からの像。幾何は合同（無名性）、貼り合わせは逆数 νλ=k＝中心投影の反転（0↔∞）、不動点 ν=λ=√k。
- **頂点⇄辺の双対 ＝ Λ⇄N の写像。** 頂点（整数・離散・振動数 N）、辺（連続・波長 Λ）。
- **振動数 ν ＝ 頂点数。** 正方形は ν=4（ν=1 据え置きは写像前の誤り）。k=νλ は写像で変わり、面積 ∮p dq は保存。
- **ν=1 は存在しない。** 頂点1の折り返しは頂点2の線分と幾何学的に区別できず、独立な状態でない。円なら救えるが円周長が π を含み離散（整数振動数）に乗れずスキップ。**振動数の数えは ν=0, 2, 3, 4, … と 1 を飛ばす＝公理2「1 は 0 と区別できない、0 の次が 2」の幾何実現。**
- **下から：** ν=0（0次元）、ν=2（頂点2・360度・最小の立つ振動数）、ν=3（540度・半周期ずれ）、ν=4（正方形720度）。
- **一頂点＝180度＝λ、位相一周＝頂点数×180度＝νλ＝k。曲がり一周＝360度（一定）。位相/曲がり比＝頂点数/2。**
- **偶奇＝統計。** 偶数 ν＝周期的・因果なし・ボソン（整数スピン）、奇数 ν＝反周期的（720度で戻る）・因果あり・フェルミオン（半整数スピン）。**スピン＝頂点数/2。** ν=3 の半周期ずれ＝反対称＝因果の芽＝スピン統計の萌芽。確立済みの「頂点＝整数、辺中点＝半整数」スピン分類の最小系での再現。

## 保留・未確定事項

1. **ν＝2×スピン の完全同定。** 頂点数が「振動数 ν」でもあり「2×スピン」でもある——綺麗すぎるので、一度立ち止まる。確定するのは「頂点偶奇＝統計（ボソン/フェルミオン）」までとし、振動数とスピンを一つの頂点数に完全同定（ν=2s）するのは別途検証に回す。

2. **頂点数 ν=1 スキップと、奇数倍音の基本波 ν=1 の関係。** 頂点数では ν=1 がスキップされる（0 の次が 2）が、矩形波のフーリエ基本波（倍音番号1）は別に在るはず。見立て：**別レイヤー**——頂点数 ν（折り返しの数＝図形の離散構造）と倍音番号（その図形が乗る波のフーリエ成分）は別の数えで、頂点数の1スキップは倍音の基本波1に効かない。だとすれば矛盾はない。両者を同じ ν と見るか別レイヤーと見るかは未確定。

3. **奇数は「不安定」か「フェルミオンとして安定」か。** (a) 奇数は180度ずれて閉じない＝排除（だから偶数・正方形・4次元が選ばれる）、(b) 奇数は反周期的に二周で閉じる＝フェルミオン・因果・時間の起源として存在。見立ては (b)（奇数倍音はずっと安定の条件だったので、奇数排除なら矩形波が成り立たない）。未確定。

4. **頂点1個の曖昧さと矩形パルスの形。** 頂点数は常に1個ぶん曖昧（±1）＝位相180度ぶんの曖昧さ。頂点は整数だから180度は飛び飛びのジャンプ＝on/off（二値）＝矩形の二値性。折り返し点（頂点）は節、辺の中央は腹、一辺＝節から節の半波（＝確定）。ただし ν=1 が消えた今、「頂点1個の曖昧さ」は ν=0↔2 の間（あるいは ν=2↔ν=3↔ν=4）の揺らぎとして再解釈が要る。形がぼやけるか（重ね合わせ）、on/off 反転だけか、未確定。

5. **Λ↔N 貼り合わせの軸ごと/全体。** 各軸ごとに νλ=k の対（軸ごとの双対）か、空間全体で一つの双対（Λ全体⇄N全体）か。見立て：軸ごとの双対＋全軸の面積総和（null 条件 Σεν²=0）の二層。xyztRQ が両空間からの像で一致する条件が νλ=k（＝貼り合わせ条件）。未確認。

6. **複素一本化（ix,iy,iz）。** Λ・N が実部虚部なら xyztRQ を複素座標に畳めるが、各軸が両空間から二重に像を受けるので写像は複雑。Λ・N を分けて保つ方が見やすい。

### 方針

この機構の語りは公開稿に書かない。表に出すのは、標準量子論・標準ゲージ理論との群論的・圏論的同型を立てる段。本書（頂点数＝振動数、偶奇＝統計）は、その同型議論で「離散側（多面体の頂点・辺の数え上げ）と連続側（波長・振動数空間）を結ぶ双対」の足場になる。特に、スピン・統計が頂点偶奇から出ることは、確立済みのスピン分類論文（5次元正軸体）と最小系を繋ぐ環。
