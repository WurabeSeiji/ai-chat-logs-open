# 二乗量空間と基本量 N=log₂ν — 底2 log 射影（機構の覚書）

## 位置づけ・スコープ

本書は**機構の語り**であり、公開論文の主張ではない。前四書（『νからψへ』『最もシンプルな曲率系 1+1』『頂点数は振動数』『三つの拘束とスケール不変の原点』）の続きで、**基本量は ν でも λ でもなく二乗量**であること、それを**底2 の log で射影**して基本量 N=log₂ν を立てること、そして νλ=k が N 空間で恒等式（足し算）になって無名性を保つことを、後日の同型議論の足場として保持する。

物理解釈は分離し、構造の言明に留める。この系は**物理と接続しない、純粋に代数的・幾何的（情報的）な系**であり、物理（時空・エネルギー）はその射影。

-----

## 1. 基本量は二乗量（3ヶ月前の直感）

3ヶ月前の原点的な直感——**基本量は ν空間でも λ空間でもなく、二乗量空間**ではないか。今日の行程がこれを裏打ちした。

- **保存される実体は二乗（Σν²=R²）。** ν（逆数で振れる観測量）でも λ（その裏返し）でもなく、二乗が不変・保存。
- ν と λ は、二乗量を二通りに射影した観測の見え方（一乗・逆数）。
- ν・λ は無名性で揺れる観測量だが、**二乗量はラベルの可換性の下で不変＝無名性を満たす基本量**。

二乗量空間の写像が物理的にイメージできないのは正しい——**二乗量は観測される量（一乗・見える）でなく、保存される実体（見えない）**だから。物理の絵で描こうとすること自体が逆立ち。

-----

## 2. 物理と接続しない代数的・幾何的（情報的）な系

答えは、物理に翻訳して理解するものでなく、**それ自体が代数的・幾何的な系として閉じている**。1, 4, 9, 16…という二乗数の系、二次形式、格子、自己双対多胞体——これらは数論・代数幾何（そして情報）の対象であり、物理量に対応づける必要がない。

物理（時空・エネルギー・質量・素粒子）は、この代数・幾何の構造を射影したときの見え方にすぎず、基本ではない。本枠組みの本体は代数的・幾何的構造（最小公理→二値→二次形式→格子→自己双対多胞体）で、物理はその射影。標準理論との「群論的・圏論的同型」とは、この代数・幾何の構造と物理理論の間の同型。

-----

## 3. 底2 の log と公理2

**虚数を使わず、log で射影する。** これが系の素性（実数・離散・スケール不変）に合う。

- **虚数が要らない：** νλ=k の log を取ると log ν + log λ = log k——掛け算（逆数のトレードオフ）が足し算（線形）になる。複素回転 e^{iθ}（i）でなく、log の足し算（実数の並進）で共役対が結べる。標準量子力学が複素回転で表すものを、本系は log（平行移動）で表す。**log 射影が虚数を排除する。**
- **スケール不変が並進対称になる：** スケールを掛ける（×λ）が log で足す（+log λ）。掛け算の対称（大きいは小さい、多いは少ない）が、log で平行移動の対称に。

**底は 2 が自然。** 公理2（0 の次が 2、1 は立たない、二値、N=2）が系の基本単位。底2 なら：
- log₂ 2 = 1（N=2 が 1 ビット）。四状態 → log₂4 = 2 ビット。
- 二乗量 v²（v=2ⁿ）が log₂ で偶数列 0,2,4,6…。

二乗量を底2 log で射影した先は**情報量（ビット）の空間**——公理2 の二値が基本だから、情報の単位もビット、log の底も2。これが「物理と接続しない代数的・幾何的な系」の具体的な姿。

## 4. 基本量 N=log₂ν（整数列・ℤ 全体・0中心対称）

**係数 1/2 をつけて整数列にする：**

$$N \equiv \tfrac{1}{2}\log_2(\nu^2) = \log_2 \nu$$

v=2ⁿ で N=n（整数、間隔1）。²が実体性（保存量）、底2 が公理2（二値）、log が虚数なしの線形射影を刻む。

| ν=2ⁿ | ν² | N=½log₂(ν²)=log₂ν |
|---|---|---|
| 1 | 1 | 0 |
| 2 | 4 | 1 |
| 4 | 16 | 2 |
| 8 | 64 | 3 |
| 16 | 256 | 4 |

**N が整数になるのは v=2ⁿ（2の冪）のときだけ**（それ以外は無理数）。公理2 の2の冪だけが整数格子に乗る。

**十分な稠密さは 2の冪乗系列で足りる。** v=2ⁿ に絞ると N=0,1,2,3…（log 空間で間隔1）。値 ν² 自体は 1,4,16,64… と無限に広がり、n→∞ で N→∞（有界でない）、間隔は一定（発散しない）。**「有界でなく間隔が発散しない」を満たし、実時空を写すのに十分**。完全な連続（実数を埋める稠密）は不要、対数等間隔・無限で足りる。

**0 と負の整数も表現できる：**

| N | ν=2^N（ν読み） | λ=2^{−N}（λ読み） |
|---|---|---|
| +2 | 4 | 1/4 |
| +1 | 2 | 1/2 |
| **0** | **1** | **1** |
| −1 | 1/2 | 2 |
| −2 | 1/4 | 4 |

**N=0（ν=1）＝自己双対の不動点（ν=λ=1、45度対称点）＝立たない点（公理2 の1）。** 正負対称で ℤ 全体を表現。N の符号は共役対のどちらから見るか（ν読み/λ読み）。**自由度（ℤ 全体）が足りていれば、正負・ν/λ の名付けは無名性の下でラベルにすぎず、意味づけ（反粒子等）は構造でなく解釈の段階——構造段階で意味を貼るのは無名性に反する。**

## 5. νλ=k の N 空間表現（恒等式・無名性の維持）

**νλ=k に log₂ を取る：**

$$\nu\lambda=k \ \xrightarrow{\log_2}\ N_\nu + N_\lambda = N_k$$

**掛け算（積一定）が足し算（和一定）になる。** 保存量は N_k（共役対の N の和が保存）。恒等式の形は保存量を右辺に明示する（和ゼロの形だと保存量が隠れる）。

**任意の入れ替えで無名性が維持される（証明済み）。** 三項のどれを右辺（保存量の位置）に選んでも恒等式のまま：

- N_λ = N_k − N_ν （λ=k/ν）
- N_ν = N_k − N_λ （ν=k/λ）
- N_ν + N_λ = N_k （k=νλ）

入れ替えで出るのは log の引き算＝割り算＝**ラベルの読み替え（どちらの極から見るか）**だけ。式の形（A+B=C 型の恒等式）は不変、破綻しない。**恒等式表現でもラベルの読み替えで無名性が維持される。**

**意義：** スケール変更（k）＝N 軸の平行移動。スケール不変が並進対称として顕わ。νλ=k（積の保存）が N 空間で和の保存。k=1（自己双対）なら N_λ=−N_ν（0 中心の符号反転対称）。

-----

## 6. Σν²=R² の N 空間表現（全対称で恒等式）

νλ=k が N で足し算になる一方、Σν²=R²（二乗量の和）は N 空間で 2^{2N} の和——一般には N で線形にならない（指数の和）。

**だが全対称の拘束（全 Nₙ 等しい、N=2 項）で恒等式になる。** 全対称で ν₁²=ν₂²=v、Σν²=（個数）×v：

$$N + \tfrac{1}{2}\log_2(\text{個数}) = N_R$$

個数2 なら ½log₂2=½、**N + ½ = N_R**（恒等式、保存量 N_R）。

**全対称が、N 空間でも実体側 Σν²=R² を恒等式にし、無名性を保つ。** 全対称がなければ Σ2^{2N} は N の正負が非対称（指数は正が効き負が消える）で無名性が危ういが、全対称（全項同じ N）なら非対称は生じない。**全対称が、N 空間での無名性の最後の砦。**

**線形化の相補性：** ν 空間は Σν²=R² を線形化（二乗の和）し νλ=k は積（非線形）。N=log 空間は νλ=k を線形化（足し算）し Σν²=R² は指数の和。**二空間が、二つの式のどちらを線形化するかで対をなす**（前書の Λ空間・N空間の双対の、より深い姿）。

## 7. δ の N 空間定式化（揺らぎを持つのは N、和ゼロが定義）

**揺らぎ（Δ）を持つのは ν でなく N の方が正しい整理。** ν 空間で δ 一定とすると、N 空間での揺らぎ ΔN=δ/(ν₀ln2) が ν₀ 依存になって汚い。逆に N 空間で揺らぎ一定とするのが正しい——N は整数（ビット・数え）で、その ±（一定）の揺らぎ＝ビットの不確定。スケール不変を保つ。

**定義側（N 空間）：**
- 基本量 $N_n \in \mathbb{Z}$（ビット・数え）。
- 揺らぎ $\Delta_n = \pm\tfrac{1}{2}$（**半ビット**、基本領域、スケール不変）。
- 共役対の保存：$N_a + N_b = K$（定数）。
- **揺らぎの拘束（これが定義）：$\Delta_a + \Delta_b = 0$**（半ビットの符号反転配分、和ゼロ）。

**逆写像（N, Δ, K → 観測側）と、積一定の導出：**
$$a = 2^{N_a+\Delta_a},\quad b = 2^{N_b+\Delta_b}$$
$$k = ab = 2^{(N_a+N_b)+(\Delta_a+\Delta_b)} = 2^{K+0} = 2^K\quad(\text{定数})$$

**和ゼロ（定義）から、積一定 k=2^K（導出）。** ν 空間の δ は $\delta_a = a_0(2^{\Delta_a}-1)\propto a_0$（スケール依存）、その積 $\delta_a\delta_b=$ 定数（導出）。

**向きの訂正：N 空間の和ゼロ（Δ_a+Δ_b=0）が定義、ν 空間の積一定（δ_a·δ_b=一定、δ₁δ₂=1/2）は導出。** 不確定性の本体は「半ビット（±1/2）を共役対のどちらに配分するか、合計は保存（和ゼロ）」。**1/2 という数は半ビットそのもの。** a,b の物理的名付け（位置・運動量等）は無名のラベルで構造に属さない——物理読みは無名性に反し、無駄な反論を呼ぶので排する。

## 8. 離散は系自身が要求する（有界を持ち込まない・閉じた系は公理）

**「有界 → 離散」は循環。** 弦の固有振動（両端固定＝境界条件）を借りており、端が無名性で禁じられるこの系では使えないのに、こっそり弦を借りている。

**離散の根は、二値（公理2）が生む節。** 公理2＝+/− の二値。波が +/− を取る以上、+ から − への切り替わりに必ず**節（ゼロ交差）**がある。二値であること自体が節を生む（外から境界を課さない）。節は点（飛び飛び）＝離散の対象。**無名性（節が対等）が節を整数個に縛り**、閉じた系（一周で + に戻る）が節を**偶数個**に閉じる。

**だから、有界（外枠の上限）を持ち込まなくても、系自身が離散を要求する：**
$$\text{公理2（二値）}\to \text{節}\to \text{点（飛び飛び）＝離散},\quad \text{無名性}\to \text{整数個},\quad \text{閉じる}\to \text{偶数個}$$

離散のために有界（公理5の一部）を置く必要はない。離散は公理2（二値）＋無名性から内在的に出る。

**閉じた系は自己証明不能、公理として残す。** 「無名性が端を禁じる→閉じる」の筋はあるが定理化できない。そして有界の入れ方に注意——

- **「上限（端）で有界」は無名性を破る。** 端＝片側にしか隣がない特権的な点＝軸対称（無名性）を破る。
- **「和だけ有界（K 有限）」も和が特権的になり無名性を破る。**
- **無名性を保つ閉じ方：** 周期（円環 N≡N+L、回転対称・全点対等）、または全軸一様の有界（|N_n|≤N_max を全軸同じに）。和だけでなく、どれもが対称に。

ただし離散自体は、これら（閉じ方）と独立に、**公理2 が生む節**から出る。閉じた系（公理）は「一周して戻る」を与え、その上に二値の節が整数個並んで離散モードになる。

## 確定形（追補）

- **揺らぎを持つのは N（Δ=±1/2 半ビット、スケール不変）。** 定義は N 空間の和ゼロ（Δ_a+Δ_b=0）、導出が ν 空間の積一定（δ_a·δ_b=一定＝δ₁δ₂=1/2）。1/2＝半ビット。逆写像 a=2^{N+Δ}, k=2^K。物理的名付けは無名のラベル。
- **離散は系自身が要求する。** 有界（外枠）を持ち込まず、公理2（二値）が生む節→離散、無名性→整数個、閉じる→偶数個。「有界→離散」は弦を借りる循環で、不要。
- **閉じた系は自己証明不能の公理。** 有界を「上限（端）」や「和だけ」で入れると無名性を破る。無名性を保つには周期（円環）か全軸一様の有界。離散自体は閉じ方と独立に公理2 の節から出る。

- **基本量は二乗量**（ν でも λ でもなく、保存される実体 Σν²=R²）。ν・λ は観測量（一乗・逆数）、二乗量は無名性を満たす基本量。
- **系は物理と接続しない代数的・幾何的（情報的）な系**。物理はその射影。
- **虚数を使わず底2 の log で射影。** log が掛け算→足し算、逆数→符号反転、スケール不変→並進対称、複素回転(i)→平行移動、として虚数を排除。底2 は公理2（二値・N=2＝1ビット）から自然で、射影先は情報量（ビット）の空間。
- **基本量 N=½log₂(ν²)=log₂ν**（整数列、v=2ⁿ で N=n、0中心に正負対称、ℤ 全体を表現）。N=0＝自己双対不動点＝立たない点。2の冪乗系列で十分な稠密さ（有界でなく間隔一定）。
- **νλ=k → N_ν+N_λ=N_k（恒等式・和の保存、保存量 N_k）。** 任意の入れ替えでラベルの読み替え（割り算）で済み、無名性が維持される（証明済み）。
- **Σν²=R² → 全対称で N+½=N_R（恒等式、保存量 N_R）。** 全対称が N 空間でも無名性を保つ砦。
- **線形化の相補性：** ν 空間は Σν²=R² を線形化、N 空間は νλ=k を線形化。二空間は対をなす。

## 保留・未確定事項

1. **δ の N 空間表現〔§7 で解決〕。** 揺らぎを持つのは N（Δ=±1/2 半ビット）、和ゼロ（Δ_a+Δ_b=0）が定義、ν 空間の積一定が導出。残る詰めは、Δ=±1/2 の「半ビット」が、四状態＝2ビットや奇数倍音の情報量と、量的にどう整合するか。

2. **情報量（ビット）空間としての本格展開。** 二乗量を底2 log で射影した先＝情報（ビット・エントロピー）の空間。これを純粋に組合せ的・代数的な対象として組む方向は、有望だが未展開。

3. **N 空間の偶数格子と、確立済みの Z⁴・四平方定理・24-cell の接続。** v=2ⁿ の二乗量が N 空間で整数格子に並ぶことと、論文群の整数格子構造（Z⁴/D₄、137、F₄=24-cell）が、どう繋がるか。未確認。

4. **Σν²=R² の R＝スケールファクター読み。** R を曲率半径でなく周長でもなく、より一般にスケールファクター（Wheeler–DeWitt の a）と読むのが正しい、までは確定。N 空間では N_R が保存量。
