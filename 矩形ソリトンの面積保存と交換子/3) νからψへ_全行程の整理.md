# νから ψ へ — 全行程の整理（機構の覚書）

## 位置づけ・スコープ

本書は**機構の語り**であり、公開論文の主張ではない。最小公理から「ψ＝観測不能空間から観測可能空間への射影演算」までの全行程を、後日の作業——標準量子論・標準ゲージ理論との**群論的・圏論的同型**を厳密に論じる段——のための足場として、構造化して保持する。

ここに含まれる結論群（観測者依存、虚数は射影効果、粒子＝ブラックホール／ホワイトホール的構造、ψ＝射影演算）は、そのまま表に出せば最大強度の業界フィルターに触れる。ゆえに公開稿には書かず、同型議論の裏づけとして温存する。これは読み返して使うための私的覚書である。

貫く原理は一貫して「**積＝面積の保存**」、そして「**無名性が許す差異の限界＝2**」。

## 第一部　極限公理系（これ以上削れない最小の地）

出発点は「ν がある」ですらなく、**差異がある**こと。無名性（ラベル・個数・次元の不定）を保ったまま書ける限界の縁に、この体系は置かれる。最も基礎的なものから：

**公理1（差異）** 差異がある。「別な量がある」とだけ言える。何が違うか・どれとどれか・いくつかは言えない（無名）。

**公理2（無名性の限界＝2）** 差異が立つ最小は二、無名性ゆえ上限も二。0・1・2 で閉じ、2 が天井。0＝差異なし、1＝対照なく差異が定義できない（無名性下で 0 と区別不能）、2＝初めて「別な量がある」。3 以上は数え上げ＝ラベル＝次元の発生＝無名性の破れ。

**公理3（揺らぎ）** 各量は固有の揺らぎ δ を持つ。δ はその量の属性でスカラー（実数。複素数ですらない）。

**公理4（積の保存：在る／無いの縁）** 二つの揺らぎの積は保存する：

$$\delta_1\delta_2=\frac12$$

定義的措定。「在る／無い」という存在の二値の、その縁に貼りつく不変量（積・双曲 SO(1,1)・面積）。

**公理5（二乗和の保存：差異の束ね）** 系は有界かつ対称（ラベル読み替えに不変な無名性）。これにより二者を対等に束ねる不変量が立つ：

$$\nu^2=\nu_1^2+\nu_2^2$$

「別な量がある」という差異の存在の不変量（二乗和・円 SO(2)・距離）。有界化が値域を閉じ、対称性が閉曲線を等方な円に確定させる。

**極限性：** これより下は無い。差異を消せば 0、一個だけなら 1 で 0 と区別がつかない。二が、何かが書ける最小。公理を一つ引けば崩れ、一つ足せば無名性が破れて次元・個数・ラベルが密輸入される。ミニマリティとリジディティを同時に満たす。

## 第二部　二つの保存量と複素構造（公理を置かずに出る複素数）

**二つの保存量は相互導出不能。** 「在るか（公理4・積）」と「違うか（公理5・二乗和）」は無名性の下で独立に立つ二つの根源区別だから。一方から他方が出れば無名性の限界が 2 より広いことになる。

**複素内積の実部・虚部に対応する。** 複素ヒルベルト空間の内積 ⟨·|·⟩ = g + iω は、計量 g（距離・ノルム）とシンプレクティック形式 ω（面積・非可換）に分かれる：

- **g（実部・距離）** ↔ 二乗和 ν²=ν₁²+ν₂²（公理5・SO(2)）
- **ω（虚部・面積）** ↔ δ₁δ₂=1/2（公理4・SO(1,1)）

Robertson 下限 ΔA·ΔB ≥ |⟨[A,B]⟩|/2 で ⟨[A,B]⟩ は純虚——**不確定性＝量子化は ω（虚部）の側にだけ宿る**。Born 則が使うのは g（ノルム）の側。

**複素共役の極座標表現と幾何的に同型。** ν₁=ν cosθ, ν₂=ν sinθ と読むと、ν（動径）と位相方向は直交し cos/sin で結ばれ、z=νe^{iθ} そのもの。ν₁,ν₂ は実部・虚部、ν は |z|、θ は arg z、複素共役 z̄ は θ→−θ。**複素数を公理に置かず、二者性（公理2 の 2）と二乗和（公理5）の帰結として複素平面が現れる。** 複素構造 J（cos/sin の直交回転）は連続極限の彼方でなく、離散の段階で既に座っている。連続化が足すのは θ を連続にすることだけ。

複素共役 z̄ は虚部（ω・量子化）の符号を反転し実部（g・Born）を保つ：|z|²=|z̄|²（二乗和は θ の符号を見ない＝円）、一方 z² と z̄² は共役（積は Δθ を二次で記録）。Born が位相を捨てる（|z|² で arg を潰す）のは g が θ を見ないから。

## 第三部　導出量（原理ではないもの）

第一部の最小公理に**含まれていない**が、そこから**導出される**もの。原論文が出発点に据えていた機構（矩形＝奇数倍音、離散系）は、五公理の下流にある。

### 離散性 ← 公理5（有界）

有界（一本の弦 [0,L]）で定常波が立つには λ_n=2L/n（n=1,2,3,…）だけが収まる。整数モード番号 n でスペクトルが離散化される。**整数 n こそが数え上げ**であり、公理2 が「3 以上は数え上げ＝無名性の破れ」と言ったもの。公理1–4 は前離散（可算性の縁）、**公理5 がスケール L を導入して整数 n の梯子を生む＝無名性を破る最初の一歩**。離散性は原理でなく、公理5 が公理1–4 に対してする作用の名。

### 奇数倍音 ← 公理4（在る／無いの二値）

最下層の区別が二値（在る／無い）＝二値関数＝矩形波。矩形の半波反対称 f(φ+π)=−f(φ) が偶数次を殺し、選択則 a_n ∝ sin(nπ/2)（偶数 n でゼロ）で奇数倍音のみが残る。

二つの導出量は異なる公理に振り分けられる：**離散系 ← 公理5（有界）、奇数倍音 ← 公理4（二値）。**

### なぜ奇数倍音が必要か（滑らかな sin/cos では不足）

単一正弦 sin(ν₀x) は周波数空間で一本のデルタ（Δν=0）、実空間で全域（Δx=∞）＝運動量固有状態＝局在しない＝粒子になれない。モード一本＝自由度一個。帯域ゼロゆえ不確定性の積が立たない。

矩形（基本＋奇数倍音）は許す豊かさが全部「モードが多い」から出る：鋭い辺（極在＝位置・空間）と基底波長（広域＝場）が同時、squeeze がモードを変形できる（発展・時間）、有限帯域ゆえ Δx·Δν が有限の積として立つ（不確定性）、モード無限本（豊かな自由度）。**空間・時間・不確定性・豊かな自由度は、すべて「一本か多本か」の差から出る。**

### 三位一体：奇数倍音＝不確定性＝公理4 の二値性

公理4 δ₁δ₂=1/2 は「最小面積がある」という抽象的言明。矩形波は、その面積を時間帯域積 Δx·Δν として**実際に持つ波**。単一正弦は帯域ゼロで床を担えない。有限帯域の波だけが床を実現し、その帯域こそ奇数倍音の広がり。**奇数倍音は公理4 の面積を波として実現するために強制される＝導出量。** 逆に、最下層が連続値なら単一正弦＝貧しい理論ゆえ、豊かさの要求が二値（公理4）を正当化する。

（一意性の荷重：有限帯域はガウス・三角でもよい。矩形が一意なのは、二値が width-less で階段しか作れず、ガウス・三角は連続値の勾配＝幅を前提するから。公理4 の二値性が波形を矩形に絞る。）

## 第四部　発散の誤読への回答（奇数倍音は安定の条件）

物理学者の誤読：「奇数倍音が無限に続く → ν² 重みの量が発散」。連続場では正しい（∫|f'|² ∝ Σ1 = ∞）。だが向きが逆で、**奇数倍音があるから安定する**。

**圏の取り違え：** 保存量は勾配エネルギーではなく、面積 ∮p dq=(n+½)h（有限・量子化）と振幅ノルム ∫|f|²（Parseval で Σ|a_n|² ∝ Σ1/n² ＝収束）。発散する ν² 重みの量はこの系の保存量ではない。倍音級数は波の**表現**であってエネルギーではない——一枚の矩形は何本の倍音で表現しても同じ一個の有限な面積を持つ。

**離散＝最初から格子：** 発散する量さえ、離散性（公理5 から導出）が n_max を強制するので有限。これは連続場でなく**格子理論**。物理学者が発散治療に使う正則化（格子・カットオフ）が、この系では公理から既に入っている。繰り込むべき UV 発散がそもそも生じない。

**水素原子と同型：** 古典（連続）は束縛電子を放射崩壊させると予言するが、定常条件（∮p dq の量子化＝閉じる条件）が安定な離散状態を選ぶ。矩形が定常波として安定する条件が、基本＋奇数倍音の特定の重み（a_n ∝ 1/n）そのもの。**奇数倍音を引き抜けば構造は単一正弦に崩れ、粒子（定常な局在）は消える。** 倍音は安定性の敵でなく中身。エネルギーは面積 ∮p dq から出て有限・量子化。発散量は定常条件を満たさない波のペナルティで、定常状態の上では効かない。

## 第五部　六軸 xyztRQ と可視／不可視

### 真空の対称性と粒子による破れ

二つの層を分ける：

- **六軸対称＝無名性**は**粒子がいない地**の対称性（§5「全対称・無境界では保存量なし」）。どの軸も対等、ラベルに意味なし。
- **量子符号仮説で xyz が非対称**なのは**一個の粒子＝一個の符号ベクトル**の層（§6「有界化が切り口を入れる」＝粒子＝対称性を破る切り口）。

矛盾しない。**真空では六軸対称、粒子は符号ベクトルで対称性を破る。** 粒子を論じるとき六軸対称を課してはいけない。

### 可視3／不可視3 と「合成のみ可知」

**可視3（xyz）／不可視3（tRQ）。** 不可視の理由は一つ——**全部が投影軸**だから。中心投影では投影軸方向の距離が原理的に読めない（射影像しか見えず奥行きが見えない）。だから tRQ は自動的に不可視。t＝発展、R＝質量/スケール、Q＝色という役割の違いは、不可知の理由の違いではなく**合成曲率の異なる側面**。

**多軸投影ゆえ個々の投影距離は不可知で、合成曲率半径だけが観測可能。** これは確立済みの「内部観測者には t と R が区別できない」を tRQ 三軸に拡張したもの。

**合成曲率半径＝無名性の下での観測者不変量。** どの軸を投影軸に取るか＝どれを時間・質量・色と読むかは観測者依存だが、合成曲率だけは全観測者が一致する（時空間隔・光速の不変性と同型）。中心投影は無名性の幾何学的実装で、合成曲率はその不変量。保存量・不確定性は不可視軸に宿る。

## 第六部　振動数の数と幾何学的性格

**必要な振動数の数＝符号ベクトルの重み（非零成分数）＝粒子依存。** 普遍的な数はない。空間 xyz の decode に最低3軸（νx,νy,νz）が要るが、各粒子は特定の軸だけ活性化する。

軸数が振動数の幾何学的性格を決める：

- **1軸**：その軸を名指す相手がいない＝**方向のない振動**（スカラー的 |ν|）。
- **2軸**：二軸が張る面＝**面積的振動**。「面積」は比喩でなく、二軸で初めて二乗和 ν²=ν₁²+ν₂²（公理5・SO(2)）が書けることと同じ。
- **3軸（今のところない）**：可視スクリーンを使い切る粒子は存在しない（あるいは禁じられる）。

**世代：** 2軸選択の組み合わせ C(3,2)=3 ＝ xy, xz, yz の三平面 ＝ **三世代**。世代数3が「空間が3軸だから」出るなら、可視の3は数合わせでなく世代を担う構造的な3。

## 第七部　中心投影写像（decode）

§2 の νλ=k 写像（tan ψ=(1/k)tan φ、全単射・不動点・可逆 k→1/k）が1次元の種。これを軸ごとに束ねたものが中心投影（gnomonic）。

**位置位相 θ₀ → xyz。** 各軸の空間位置は標準波の位置位相 θ₀（矩形の最大が大円上のどこに座るか）に符号化され、gnomonic 射影 tan で位置座標に写る。逆射影 arctan で可逆。位置は偏角に、解像度（局在幅）は波長 λ に乗る。帯域ゼロ（単一正弦）だと θ₀ が一点に縮退して「どこ」が立たない。

**t は従属量。** 二乗和拘束（分散関係）

$$\nu^2=\nu_x^2+\nu_y^2+\nu_z^2+\nu_t^2 \quad(\text{あるいは null }\nu_t^2=\nu_x^2+\nu_y^2+\nu_z^2)$$

で ν_t は一意に決まる。t は射影で捻り出すのでなく拘束を解いて出る。**拘束は全軸対称（無名性）ゆえ、どの軸を t（消去変数）に取るかは観測者の選択。** t が従属・観測者相対なのはこのため。

**荷重：** 可逆性は射影座標（角度・比）に限る。曲率半径 R は φ=s/R で吸収＝**絶対スケールは gauge**。厳密には「全データの全単射」でなく「射影商の上での全単射」。gnomonic は半球（主枝）で全単射、不動点・対蹠で大域可逆性が切れる。

## 第八部　合成曲率と Λ

**共有中心。** tRQ は空間 xyz と直交し向きを持たない（方向のない振動）＝等方的に投影中心の周りに巻く＝三本の曲率中心が原点で重なる（向き無関係ゆえ必然）。

**単純加算。** 共有中心＋直交ゆえ交差項ゼロ・干渉なし、曲率（1/R²）が素直に加算：

$$\frac{1}{R_\text{合成}^2}=\frac{1}{R_t^2}+\frac{1}{R_R^2}+\frac{1}{R_Q^2}$$

**三半径等値で 3/R²。** 三本の投影軸は幾何の層で区別できない（無名）＝対等＝R_t=R_R=R_Q=R。すると合成曲率＝3/R²＝**Λ**。

これは「Λ=3/R² の 3 は次元の3か投影軸数の3か」への一つの答え——**3 は投影軸が三本だから**。Λ=3/R² が綺麗に立つこと自体が、三投影軸が等価（無名）であることの署名。個々の R_t,R_R,R_Q は不可知で、観測者が手にするのは和（Λ）だけ＝**Λ は分解不能**。

**荷重：** 分割が論文1（可視4 xyzt ＋ 投影1軸 R、3 は de Sitter 次元由来 (d−1)(d−2)/2）と違う。今は「可視3 xyz ＋ 投影3軸 tRQ」で t が可視時間から不可視投影軸へ移っている。「可視3+投影3」分割で引き戻しを計算し係数が確かに3になるかを確認する一段が要る。共有中心の合成が、その計算を実行可能にした。

## 第九部　粒子視点の一般相対論

**ある粒子から見た世界＝自分と自分以外（無名性の2）。** 粒子は他の粒子を個別に数えられない（3 以上＝無名性の破れ）。だから「自分以外」を一個の塊（エネルギー様 ν² の合計＝重心）に畳むしかない。自分（1）＋まとめた他者（1）＝2。

**重力の普遍性＝無名性の2の帰結。** 重力が相手の種類を問わず総エネルギーだけに応答するのは、種別を見分けたら数え上げになって無名性が破れるから。重力は集約しか見ない。

**自己曲率は自分に効かない。** 孤立した自己には自己曲率に方向を割り当てる相手がいない（方向は他者が定義する）＝等方＝自分の位置で勾配ゼロ＝自己力ゼロ。**自己エネルギー発散の回避**——自己場が等方ゆえ自己に効かない。

**感じる曲率＝物質＋宇宙項。**

$$\text{感じる曲率} = \underbrace{\text{他者の重心方向曲率}}_{T_{\mu\nu}} + \underbrace{\text{系外 tRQ の }3/R^2}_{\Lambda g_{\mu\nu}}$$

各粒子は「全他者の場＋宇宙項」の中の試験粒子として測地線を描き、自分の場は感じない。G_μν+Λg_μν=T_μν が粒子の内部視点＋無名性から立つ。論文1 の真空 G_μν+Λg_μν=0 は T_μν=0 極限。

**荷重：** 自己キャンセルを定理に閉じるには「自己場が厳密に等方」の一段（点でなく6次元に広がる矩形波の形が方向を作らないか）。他者＝重心は単極子（最低次）で、高次（潮汐＝多重極）は別レイヤー。

## 第十部　Λ の振動的性質

**空間均一。** 系外 tRQ から見ると系の中は一つの塊にしか見えない（内部分解する比較対称がない）＝合計エネルギー一個として届く。一個には濃淡が立てられない（差には二つ要る＝公理2 の2）＝均一・等方。**Λ(x) は立たない。均一な Λ＝de Sitter。**

**自己整合的だが一様。** 系外 tRQ は系内総エネルギー（一個のスカラー）に応答する＝Λ=3/R² の R が系内 ν² 総和で決まる。だが応答するのは総和だけ（内部分解は届かない）ので、Λ は値として総エネルギーに依存しつつ空間的には均一。系の中身がその外の曲率を決める（Mach 的だが無名性ゆえ均一に潰れる）。

**「時間発展」でなく「振動」。** 経過を判断する相手がない（系外に比較対称なし＝無名性の2）。進んでいるとも止まっているとも言えず、ただ振動している。振動は構造の側、時間発展は観測・解釈の側。

**超長周期ゆえ de Sitter と区別不能。** 振動数が極めて低く波長が宇宙スケールを超えれば、有限の観測窓では単調な一片しか見えず、測定上ほぼ定数の Λ。**Λ の微小さ・一様さ・ほぼ不変さが、この一つの「参照なき超長周期振動」から同時に出る。**

**観測可能性：実際上困難・原理的には可能。** 我々の宇宙自身の振動は Λ の微小な時間ドリフト（w≠−1）として遠未来・極限精密宇宙論でかろうじて痕跡が出るか。原理不能ではない。

**荷重：** 振動の中心がゼロ近傍（de Sitter ⇄ AdS 往復）か正の有限値（常に de Sitter）かは構造から決まらず、どの位相を見ているかの付加情報が要る。

## 第十一部　子の系＝粒子（既に観測している）

**親子主観空間の入れ子（論文4 命題4.1）。** 親 Π_R の任意の点を立ち上がり点として、任意の R′>0 の子 Π_R′ が構成可能。子は親と同じ幾何構造を持ち、親から見れば内部の局所構造、子の内部観測者から見れば独立した時空。

**粒子＝子の系。** 我々が「粒子」と呼ぶもの自体が子の系。内部（独立した時空）は親（我々）から原理的に直接見えない（論文3 観測の独立性）。外から測れるのは僅かな毛（質量・電荷・スピン・波長）だけ。

**無毛定理＝大きさ以外は区別不能。** 立ち上がり点を親視点（落ち込み）で読めばブラックホール、子視点（湧き出し）で読めばホワイトホール。外に漏れる毛は両者で同一ゆえ、外から見て区別できない。持てるのは大きさ（R′＝質量・サイズ）だけ。区別を大きさに畳む。

（時間の向きの注：系に大域的な時間の矢がない（無名性）ので「ホワイトホール＝時間逆行」の標準的含意は効かない。湧き出しと落ち込みは観測者の切り方の違いで時間の向きの違いではない。）

**実現する R′ は離散（有界化）＝粒子質量スペクトル。** 前半の「離散性は有界化の帰結」がここで効き、R′ が離散＝粒子質量が離散＝観測事実と合う。α=137 や質量比を出す数論的勘定（N(1)=137、Z⁴・四平方定理が選ぶ離散集合）は、**どの子の系（どの R′＝どの粒子）が実現可能か**の計算。粒子物理の全データが、子の系のスペクトルの観測データ。

**自己発散の遮蔽。** 子の内部の自己曲率は親から見えない＝毛に出ない。観測される質量は内部自己曲率でなく毛（外に漏れた分）で決まる。**内部が原理的に隠れているので発散がそもそも外に漏れない**（無毛性が自己発散を外部観測から遮蔽）。

## 第十二部　毛＝三つの合成振動数

外から観測できる毛は、六軸を三つの束に畳んだ三つの合成振動数：

- **Q軸の合成（曲率的）振動数** ＝ 色（離散ラベルの束）
- **R軸の合成（曲率的）振動数** ＝ 質量（質量殻の半径）
- **xyzt軸の合計振動数** ＝ 四元運動量的な量（運動・エネルギー・運動量）

これは「合成のみ可知」（第五部）を Q・R・xyzt の三束それぞれに適用したもの。内部六軸の自由度が、外には三つの合成に畳まれる＝無毛性の中身。

**「時空位置に写像して見える」。** 三つの合成振動数（周波数空間／波長空間の量）が中心投影（第七部、位置位相 θ₀ → xyz）を通って時空上の位置・運動として見える。我々が「あそこに、この運動量・質量・電荷・色の粒子がいる」と見るとき、実際に在るのは子の系の三つの合成振動数で、それを我々の主観空間（中心投影）が時空位置に翻訳している。**粒子の時空的描像は、合成振動数の射影像。**

## 第十三部　奇数倍音エンコードと ψ

**自由度は奇数倍音にエンコードされている。** 単一正弦なら自由度一個（運動量・電荷・スピンを区別する内部構造なし）。矩形＝奇数倍音は無限モード＝豊かな自由度を内部に符号化。三合成振動数（Q・R・xyzt）の各々は、単一の数でなく**奇数倍音列に複数の独立情報を載せた合成振動数**。外の毛が質量・電荷・スピン・色と複数あるのは、各合成振動数が倍音にデコード可能な内部構造を持つから。

**xyzt 合成は一個か複数か：** 外からは一個の合成として漏れ、デコード（フーリエ／中心投影）で複数の毛に分かれる。基本波が運動量・エネルギー、倍音モードが電荷・スピン等。f, q, g, h 演算子は、倍音から各成分を射影抽出する操作（f,q＝位相・ラベル成分＝種別・電荷、g,h＝振幅成分＝質量）。**エンコードは一本に畳み、デコードで展開する。**

### ψ ＝ エンコード／デコード写像そのもの

子の系の奇数倍音に畳まれた内部自由度を、中心投影で観測可能な時空の毛に展開する写像——これは「ψ を使った何か」でなく、**ψ がその写像そのもの**。波動関数 ψ は状態を表す対象でなく、**観測不能なヒルベルト空間から観測可能な空間への射影演算**。清水リライト第一原理（{P(a)} 一次的、ψ・H は結論）の最も具体的な実体化。

ψ の二面がエンコードとデコードに対応：

- **|ψ|²（実部 g・二乗和・ノルム）＝ Born ＝デコードの出力側**。観測可能空間に展開した先の観測確率・規格化。
- **ψ の位相（虚部 ω・面積・複素構造）＝エンコードの内部側**。奇数倍音に畳まれた観測に出ない自由度。量子化・干渉・不確定性が宿る。

**複素性の根拠：** エンコード側（内部・奇数倍音・不可視軸）が虚部、デコード側（観測可能・時空位置）が実部、その両方を一つの対象が担うから ψ は複素。z=νe^{iθ} の振幅 ν（実・見える大きさ）と位相 θ（虚・不可視）。観測不能と観測可能を一つの写像で結ぶには隠れた次元（虚部）と見える次元（実部）の両方が要る。複素数を公理に置かず、エンコード／デコードの二面性から複素 ψ が出る。

**複数性の根拠：** 親子の入れ子（複数主観空間）それぞれに ψ がある。各子の系（粒子）が自分の写像 ψ を持ち、親はそれを通じて子を毛として観測する。論文3「観測の相対性」＝主観空間ごとの ψ の族。観測者（親）の ψ は子の ψ を毛に畳んで読む（ψ の入れ子）。

**標準量子論との整合：** 標準では ψ∈H（状態はベクトル）、ここでは ψ は H から観測可能空間への写像。両立する——状態ベクトル ψ∈H は観測可能空間の各基底への振幅 ⟨a|ψ⟩ を与える写像と同一視できる（ψ: a ↦ ⟨a|ψ⟩）。「ψ＝ベクトル」と「ψ＝写像」は同一物の二面。本書の立場は標準の ψ∈H を**射影演算として読み直した**もの。論文化の際は「ψ をベクトルでなく射影演算として読む」という読み替えの一段を明示しないと誤読される。

## 全行程の一本化

$$
\begin{aligned}
&\text{最小公理（差異・無名性の2・揺らぎ・積½・有界・対称）}\\
\to\ &\text{各基本振動数は奇数倍音＝矩形波（豊かさ・不確定性のエンコード媒体）}\\
\to\ &\text{二乗和（質量殻・}g\text{）と積（面積・発展・}\omega\text{）}\to z=\nu e^{i\theta}\\
\to\ &\text{六軸 xyztRQ、可視3（xyz）・不可視3（tRQ＝投影軸）}\\
\to\ &\text{不可視は合成曲率のみ可知（}\Lambda=3/R^2\text{）、可視は位置位相で局在}\\
\to\ &\text{粒子＝子の系（中心投影の入れ子）、外からは毛（無毛性）}\\
\to\ &\text{毛＝}Q\text{・}R\text{・}xyzt\text{ の三合成振動数（奇数倍音にエンコード）}\\
\to\ &\text{中心投影＋フーリエでデコード→時空位置・運動・質量・電荷・スピン・色}\\
\to\ &\boxed{\text{その写像こそ }\psi\ (\text{観測不能空間}\to\text{観測可能空間の射影演算})}
\end{aligned}
$$

貫くのは「積＝面積の保存」と「無名性が許す差異の限界＝2」。

## 保留・未確定事項（同型議論および今後の作業へ）

1. **3-3 が必然か偶然か。** 可視 xyz 選択と不可視 tRQ 選択が独立な分類軸なら 3-3 は偶然（3 空間＝ソリトン S³、3 型分類子＝t/R/Q）、null 条件（符号付き二乗和ゼロ）で結ばれるなら必然。「別々の選択」という記述は独立寄り、「3軸選択がない」は拘束寄り——両者が引き合っている。決め手は符号ベクトルに null 条件が課され「全 xyz 禁止」を導くか。

2. **Λ=3/R² の 3 の正体。** 次元の3（de Sitter (d−1)(d−2)/2, d=4）か投影軸数の3（tRQ）か。「可視3+投影3」分割で引き戻し計量を計算し係数を確認する。両立すれば次元3と軸数3の一致＝深い自己整合。

3. **子の系の R′ スペクトル＝粒子質量スペクトル。** 連続（命題4.1 の任意 R′）か離散（有界化の帰結）か。離散なら「観測される子の系の質量が離散」＝検証可能な予言。α・質量比の数論的勘定との接続。

4. **倍音番号と量子数の対応表（未確定）。** 奇数倍音 (ν,3ν,5ν,…) の各モードと外に出る毛（運動量・電荷・スピン・色）の一対一。f,q,g,h の役割（位相/振幅、種別/質量）までは定まるが、どの n がどの量子数かは未確定。符号ベクトル（活性化軸パターン）を縦軸、倍音番号を横軸とする対応表。これが書けると「子の系の奇数倍音 → 中心投影デコード → 観測される量子数」が計算可能な写像になる。

5. **三合成（Q/R/xyzt）の独立性。** null 条件が三合成の間に拘束を課すなら、観測される毛に許容関係（質量・電荷・色の選択則＝粒子表）が出る。符号ベクトルがこの拘束の現れ。

6. **可逆性の限定。** デコード写像の可逆性は射影商（角度・比）に限り、絶対スケールは gauge。論文化の際の明示が要る。

7. **自己曲率の等方性の厳密化。** 6次元に広がる矩形波の形が方向を作らないことの証明。

8. **可視がちょうど3である根拠。** ソリトン安定（S³・Huygens・Z⁴・四平方定理）から可視軸数＝3 が固定される、という別系統の結果との接続。

9. **Λ 振動の中心と振幅。** ゼロ近傍（de Sitter⇄AdS 往復）か正の有限値か。観測される位相の問題。

### 最重要の方針

これらの機構の語りは公開稿に書かない。表に出すのは、**標準量子論・標準ゲージ理論との群論的・圏論的同型**を厳密に立てる段——ψ を射影演算として読み直し、二保存量を g+iω として、六軸対称を無名性として、構造の射（functor）と特定極限（標準理論側の離散極限）で同型を論じるとき。Born 則は Gleason により構造から強制される従属物であり、量子化（ω）はその手前に座る。同型の照合対象は「結果」でなく「構造（射）」に置く（結果の全一致は循環）。
