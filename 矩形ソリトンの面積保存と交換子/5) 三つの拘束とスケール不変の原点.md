# 三つの拘束とスケール不変の原点 — Σν²=R²・νλ=k・δ（機構の覚書）

## 位置づけ・スコープ

本書は**機構の語り**であり、公開論文の主張ではない。前三書（『νからψへ』『最もシンプルな曲率系 1+1』『頂点数は振動数』）の続きで、系が **Σν²=R²・νλ=k・δ の三つで閉じる**こと、その三つの役割（実体・観測・揺らぎ）、公理の縮約（公理2 が二値・矩形・奇数倍音を導く）、そして全体を貫くスケール不変の拡張概念と、その50年来の原点を、後日の同型議論の足場として保持する。

物理解釈は分離し、構造の言明に留める。

## 0. 原点（50年前・特殊相対論と遠近法）

本枠組みの原点は、50年前（高校生時）、特殊相対論を読んで抱いた一つの疑問。

**遠近法では、実物の大きさは同じなのに、近いと大きく見え、遠いと小さく見える**（自明すぎて疑問にならない）。特殊相対論は、速度が上がると長さが縮み、時計が遅れ、質量が増す、と言う。最初は「本当に大きさが変わっているのか？」と引っかかったが——**これは遠近法と同じで、縮んで見えるのは観測者側の投影の問題であって、実体が縮んだのではない。観測者の問題を実体の問題と誤読しているだけ**、と気づいた。

ここから、特殊相対論の歪みも込めた投影図を描き、それが**中心投影（局面への投影）・主観座標・観測者依存・不可知の投影軸**の原点になった。

**そして遠近法では「距離 × 見かけの大きさ ＝ 実物（一定）」**。見え方の二極（近い/遠い、大きい/小さい）が、実物を挟んで対になる。だから**共役な対の量が保存される（νλ=k）は、当たり前のこと**だった。

この「観測者の投影の問題を実体の問題と分ける」一点が、相対論にも量子論の観測問題にも同じく効く——両者の「観測者と実体の混同」を、同じ誤読として見抜く視点になっている。

## 1. 三つの基本：Σν²=R²・νλ=k・δ

系は一本の式では閉じない。**三つ**で閉じる。

**Σν²=R²（二乗和）＝保存される実体の大きさ（不変量）。** 「別な量がある（差異の存在）」の不変量。SO(2)・距離・複素内積の実部 g。**これが本体。**

**νλ=k（積・逆数）＝観測者が見る量（トレードオフ）。** 「在るか/無いか」の不変量。SO(1,1)・面積・複素内積の虚部 ω・量子化。**観測の見え方。逆数になるのは観測量であって、実体ではない。**

**δ（小数以下）＝観測の揺らぎ・解像度の限界。** 整数 ν を数えると必ず残る、観測できない端数。一方の解像度を上げれば他方が下がる、その下限（δ₁δ₂=1/2）。

**役割の分離（最重要）：**
- **実体（二乗・Σν²=R²）は保存・不変。**
- **観測（逆数・νλ=k）はトレードオフ。** 逆数だけ読むと実体を忘れるが、実体は不変。逆数になるのは観測者の量で、実体の量は保存される。
- **δ は観測の解像度の限界。**

（注：Wheeler–DeWitt 方程式 Ĥψ=0 は、実体側の拘束 Σν²=R²（符号一つ反転 ν₁²+…−R²=0、R＝スケールファクター a）に相当するが、量子化 ω＝νλ=k と観測 δ を落としている。標準理論はそれを別手続き〔正準量子化 [x,p]=iℏ〕で補う。本系は νλ=k と δ を構造に内蔵して三つで閉じる。なお νλ=1〔k=1〕の極限で ν=cosθ・λ=sinθ と読むと複素極座標 e^{iθ} と同形になるが、i は措定でなく、90度ずれた二つの実成分を複素記法で畳んだときに現れる記法上のもの。系は全て実数。）

## 2. 量子力学が不確定性に悩む理由

清水テキストを読んで抱いた疑問——量子力学者は「観測を厳密にすれば真の値に近づける」と信じ、不確定性に複雑な演算子形式で悩む。だが**共役対を理解していれば、片方の解像度を上げれば必ず他方が下がるのは当たり前**で、保存量（実体の二乗）は最初からそこに在る。

**悩みの正体：観測量（逆数・トレードオフ）ばかり見て、その裏の保存される実体（二乗・Σν²=R²）を保存量として掴んでいない。** だから不確定性が「謎」になり、複雑な演算で扱う。「観測を厳密にすれば真の値に」は、観測量（逆数）を実体（二乗・保存量）と混同——前に確定した「真の値の問いは存在しない」と同じ誤り。

**本系は実体（Σν²=R²）を保存量として最初に置くから、悩まない。** 解像度のトレードオフは当たり前、不確定性は謎でなく「観測量が逆数でトレードオフし、実体（二乗）は保存される」という当然のこと。これが清水テキストのリライトの動機の核。

## 3. 公理2 が二値・矩形・奇数倍音・離散を導く（公理4 は不要）

長らく「矩形が先か奇数倍音が先か」が固まらなかったが、**公理2（無名性の限界＝0,1,2）が根**で、すべてその下流。

**公理2 の中身：** 0＝差異なし、1＝相手（対照）がなく 0 と区別できない・立たない、2＝相手がいる（差異がある）ことは区別できる・初めて「別な量がある」が立つ、2以上＝無名で数えられず「自分以外の2」と同じ・2 が天井。

**これ自体が二値。** 区別できるのは「相手がいる(2)／いない(0,1)」の二値＝在る/無い。3以上が「2に畳まれる」＝全部が二値に潰れる。整数 n は、公理2 の下で「相手がいる(2)」の n 回反復＝**数える＝二値判定の反復**。

**導出の連鎖：**
$$\text{公理1（差異）＋公理2（限界2＝二値）}\to \text{矩形パルス波}\to \text{奇数倍音（半波反対称で偶数次消滅）}$$
離散（数える）も公理2 から（「2」の反復）。

**公理4（在る/無いの二値）は公理2 に含まれ不要。公理が一つ減る。** 矩形・奇数倍音・二値・離散は独立の公理でなく、公理2 の帰結。「矩形が先か奇数倍音が先か」でなく、公理2 が先、二値→矩形→奇数倍音の順。

**δ の観測不能性も公理2 から：** 公理2 が「2以上は区別できない」＝2の天井を超えた細部が読めない＝δ（観測できない小数以下）。

**残る公理は、ほぼ公理1（差異がある）と公理2（無名性の限界＝2）の二つだけ。** δ も矩形も奇数倍音も離散も二値も、全部この二つから。

## 4. 全対称 → N=2

最も強い仮定は**全対称**。Σν²=R² の R は特権でなく、たまたま右辺に選んで R とラベルを貼っただけ。**どの ν も右辺に来れる**（より強い拘束）。

$$\sum_{n\neq k}\nu_n^2 = \nu_k^2\quad(\text{どの }k\text{ でも成立})$$

全 k で成立 → 全 νₙ² が等しい（任意の2式の差から νᵢ²=νⱼ²）。さらに、N 個の軸が全部等しく νₙ²=v なら (N−1)v=v、v≠0 で **N=2**。

**全対称が軸数を2に強制（公理2 の再導出）。** Σν²=R² は多軸の和でなく、本質的に二項（ν²=R²、|ν|=|R|）。前に最小系で確定した「在るのは90度ずれた二成分だけ、ν と R（λ）は対等・入れ替え可能」と一致。

## 5. δ が構造を作る — 拘束は自由度を奪い δ に集約する

**全対称だけだと自由度ゼロ（潰れた点）。** 全 νₙ が等しく、軸の区別なし、差がない＝完全対称の真空。何も立たない。

**δ が潰れを破る。** ν は整数だが δ（±0.5）の揺らぎを持つ。全対称で大きさは等しくても、**δ の分だけ各軸がわずかに異なる**。この δ のズレが**唯一の自由度**。δ が無ければ何も無く、δ があるから軸が区別され構造が立つ。δ は揺らぎであると同時に**構造の生成源**＝自発的対称性の破れの種。

**拘束は連続の自由度をことごとく奪い、δ 一個に集約する：**
- **全対称（無名性）：** 軸ごとの重み（結合係数 cₙ）を奪う。cₙ を置けるなら無名性が破れる＝置けない＝純粋な二乗和 Σν²=R²（係数なし＝等方計量＝ユークリッド・ピタゴラス）。
- **閉じた系：** 開いた端の自由を奪う（端＝特権的な点＝ラベル＝無名性を破る → 端を持てない → 閉じる）。
- **矩形パルス＝二値：** 連続な振幅・滑らかな波形を奪う（在る/無いの二値のみ）。
- **結果：離散系**（ν が整数）。

**奪い切れない唯一の連続が δ。** 拘束を厳しくするほど自由度が δ 一個に絞られる。これは自由度を殺すのでなく**δ 一個に集約する**操作。δ が系の全自由度を背負い、構造は δ を通してしか動けない。離散の ν（骨格）に、連続の δ（肉）。

## 6. 不確定性は δ の出現

**不確定性は、足された性質でなく、絞り出された δ。** δ は最初から在ったが、連続な自由度が豊富な間は紛れて表に出ない。**拘束が連続をことごとく奪い、自由度を δ 一個に絞ると、隠れていた δ が逃げ場を失って表に出る**＝不確定性。

**δ が唯一の自由度で逃げ場がないから、一方を精密に締めれば他方に必ず現れる**＝δ₁δ₂=1/2（積一定）。標準理論が [x,p]=iℏ を公理として謎にするのに対し、本系では不確定性は拘束の必然的な出口。**極めて厳しい自由度の制限が、極限に隠れていた δ を表に出現させる。**

## 7. 逆説：奪う拘束が奇数倍音という豊かな自由度を産む

**自由度を奪う厳しい拘束が、奇数倍音という無限のモード列を産む。** 最も貧しい状態（二値・矩形）に絞り込むと、最も豊かなもの（無限倍音）が出る。

- 連続な正弦（滑らか）はモード一本（貧しい）。
- 二値（矩形）に潰す＝鋭いエッジ（不連続）を入れる。
- 鋭いエッジはフーリエで無限モードを要求（基本＋3倍+5倍+…）。
- **二値（最も貧しい波形）が、無限倍音（最も豊かなモード列）を必然的に持つ。**

**奪う(二値化)と産む(無限倍音)は同じ操作。** 貧しくするほど、それを支えるために豊かになる。δ 一個に集約された自由度が、矩形のエッジを通じて無限倍音に展開され、そこに世界の豊かさ（粒子の毛＝三合成振動数）が載る（前に確定した「自由度は奇数倍音にエンコードされる」）。

## 8. スケール不変の拡張概念 — νλ=k が基本

これら全部が、**スケール不変の拡張概念**の現れ。

**シンプルは複雑・大きいは小さい・多いは少ない・遠いは近い**——対立する二極が、積一定で結ばれて同じものになる。

- **シンプルは複雑：** 二値（矩形）が無限倍音を産む（§7）。
- **多いは少ない：** ν（多い・高周波）と λ（少ない・長波長）が νλ=k で入れ替え可能（自己双対・無名性）。
- **大きいは小さい：** ν=∞（点・λ→0）と大きい（λ→∞）が中心投影で双対（0次元の点が全情報を載せる）。
- **遠いは近い：** 中心投影（遠近法）が遠い（投影軸の奥）と近い（像）を可逆に結ぶ。

**νλ=k は、この拡張概念を一本の式にしたもの**——だから基本。今日辿った全部（自己双対・頂点⇄辺・Λ↔N 双対・0次元/無限の曖昧さ・奪うと産む・δ のスケール不変）は、すべて νλ=k の現れ。

**三つの基本は、この世界観の三つの面：** Σν²=R²（差異・実体）、νλ=k（スケール不変・観測）、δ（スケール不変な揺らぎ＝量子性の源、δ₁δ₂=1/2 はどのスケールでも不変だから量子性がどのスケールでも消えない）。

## 確定形

- **原点は50年前、特殊相対論を遠近法（観測者の投影の問題、実体は不変）として見抜いたこと。** 中心投影・主観座標・観測者依存・νλ=k（距離×見かけ＝実物一定）の源。
- **三つで閉じる：** Σν²=R²（二乗・保存される実体）、νλ=k（逆数・観測のトレードオフ）、δ（観測の揺らぎ・限界）。逆数は観測者の量、実体は不変。
- **量子力学が不確定性に悩むのは、観測量（逆数）を見て保存量（実体の二乗）を掴んでいないから。** 本系は実体を保存量として置くから悩まない。
- **公理2（無名性の限界＝2）が二値・矩形・奇数倍音・離散を導く。公理4 は不要、公理は一つ減る。** 残るは公理1・2 のほぼ二つ。δ の観測不能性も公理2 から。
- **全対称（どの ν も右辺に来れる）→ 全 νₙ² 等しい → N=2**（公理2 の再導出）。Σν²=R² は本質的に二項。
- **δ が構造を作る。** 全対称だけだと潰れて自由度ゼロ、δ が唯一の自由度＝対称性の破れの種。拘束（全対称・閉じる・二値・離散）は連続をことごとく奪い δ 一個に集約。
- **不確定性は δ の出現。** 自由度を δ に絞ると δ が逃げ場を失い表に出る、δ₁δ₂=1/2。
- **逆説：奪う拘束が奇数倍音（無限モード・豊かな自由度）を産む。** シンプル(二値)＝複雑(無限倍音)。
- **νλ=k はスケール不変の拡張概念（対立二極が積一定で同一）を一本にしたもの。** 三つの基本はこの世界観の三つの面。

## 保留・撤回事項

1. **（撤回）νλ=k の因数分解で次元が一意に立ち上がる、を時空創発の機構とする。** 数学的には面白い観察（自己双対多胞体・f-ベクトル）だが、時空創発は中心投影・論文群の機構で説明でき、これは思いつきの段階。文献上も (V,E) で次元一意は2次元/3次元の間でのみ証明可能、4次元以上は (V,E) で次元一意でない（範囲が重なる、Grünbaum の4次元例外 (6,12),(7,14),(8,17),(10,20)）かつ未解決問題。時空創発の中心には据えない。

2. **（撤回）νλ=1 を全体に固定したのが量子力学の病の根本原因、という主張。** 標準理論は massive（k≠1）も扱うので、「根本原因」は言い過ぎ。撤回。ただし「νλ=1〔k=1〕は複素・ユニタリ・自己双対の特殊点で、複素極座標 e^{iθ} が綺麗に立つのは k=1 に限る」までは確定。

3. **「数える＝二値の反復」「無名性が端を禁じる→閉じる」の厳密化。** 公理2 から二値・離散が出る連鎖は見えたが、定理として詰め切れていない箇所が残る。

4. **全対称（N=2）と xyztRQ 六軸の関係。** N=2 が基本単位なら、六軸はその展開（次元＝軸を立てる本数）か。未確定。

5. **δ の作用＝squeeze（90度差を歪める）＝最初の励起。** δ が構造を作る具体的機構が、保留してきた「最初の励起＝squeeze」と同じか。未詰め。
