# 図3 AとBの複素波表現（fig3_AB_complex_wave_v1）

シリーズ: ABC多体遠心力問題 — ステップ3（複素波表現と振幅の決定）
作図は図2と同一フォーマット（同じ構成図、波は描かない、数式ボックスのみ差し替え）。

## 複素波表現（中心結果）

- z_a = A_a · e^{i k_a θ/2}
- z_b = A_b · e^{i k_b θ/2}

θ は円周上の角度。ω, ν, λ, t は現れない — 波は巻き位相の幾何そのもの。
|z| = A は一定なので、円周上に描くべき波形は存在しない（波を描かない理由）。

## 振幅の決定（保留していた重心の仮定を復活）

- 重心条件: M_a A_a = M_b A_b
- 分離条件: A_a + A_b = R
- ⟹ A_a = k_b R/(k_a + k_b)、 A_b = k_a R/(k_a + k_b)
- A_a/A_b = k_b/k_a = M_b/M_a（振幅は質量の逆比）

独立経路（E = hν から定常波エネルギー経由）でも同じ比 A ∝ λ ⟹ A_a/A_b = k_b/k_a に収束。
絶対値は経路依存だが、絶対値は観測不能（比だけが物理）。

## 消去された量（R と k の別名）

- ω = c/R、 ν = kc/(4πR)、 λ = 4πR/k

## 不変量

- A_a k_a = A_b k_b
- A_a M_a = A_b M_b = μR（μ = M_aM_b/(M_a+M_b)）
- Mλ = h/c（省略形 Mλ = 1）

## g_ab・c_ab の展開（追記）

波動質量＝重力質量の同一視（新仮説、等価原理に相当）のもとで:

- g_ab = GM_a/R² = Ghk_a/(4πcR³)
- c_ab = ω²A_b = c²k_a / [R(k_a+k_b)]（B の遠心半径は重心周りの A_b）
- A 側の g_ba, c_ba は k_a → k_b の置換

B の釣り合いと A の釣り合いは同一条件に還元される:

- **k_a + k_b = 4πc³R²/(Gh)**、省略形で **k_a + k_b = 4πR²**（総巻数＝球面積）
- 帰結: R = √((k_a+k_b)/4π)（R は整数で量子化）、M_a + M_b = R（総質量＝分離距離）
- 完全形の読み: ℓ_P² = ℏG/c³ を使うと k_a + k_b = 2(R/ℓ_P)² — 総巻数はプランク単位の面積

注: 図1の簡略版（重心無視）で展開すると k_a = 4πR² になる。重心復活版では両体対称の k_a + k_b = 4πR²。
