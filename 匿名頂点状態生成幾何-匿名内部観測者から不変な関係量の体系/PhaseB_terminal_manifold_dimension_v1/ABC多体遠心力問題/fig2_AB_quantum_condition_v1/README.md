## 量子条件（指示の記録）

A と B の振動数と波長を ν_a, ν_b、λ_a, λ_b とし、巻数 k_a, k_b を定義する:

- 2πR = k_a·(1/2)λ_a、 2πR = k_b·(1/2)λ_b

これは古典的振動条件。節は位相凍結点 θ = 0 に固定され、半波長ごとに節が 1 つ立つ
（k = 1 なら節は 0° の 1 箇所だけ、k = 2 なら 0° と 180°）。

## 導出

- λ_a = 4πR/k_a、 λ_b = 4πR/k_b
- ν_a = k_a ω/(4π)、 ν_b = k_b ω/(4π)
- c = νλ = ωR ⟹ R = c/ω
- 省略形 (c = G = h = 1): ν = kω/4π、λ = 4π/(kω)、R = 1/ω

## 質量比

E = hν、E = Mc² ⟹ M = hν/c²

- M_a/M_b = ν_a/ν_b = k_a/k_b
