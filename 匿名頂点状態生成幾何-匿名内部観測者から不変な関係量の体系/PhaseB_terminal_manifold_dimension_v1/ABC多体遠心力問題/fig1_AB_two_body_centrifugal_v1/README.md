# 図1 AB二体の遠心力運動（fig1_AB_two_body_centrifugal_v1）

シリーズ: ABC多体遠心力問題 — ステップ1（AB二体）

## 条件設定（指示の記録）

- 原点 O に A（質量 M_A）。半径 R の円周上に B（質量 M_B）。
- B は A の周りを角速度 ω で回転する。
- A-B 間の重力加速度 g_ab と、遠心力による加速度 c_ab が釣り合う。
- 時空には AB 二体しかないので厳密には AB の重心位置で回転するべきだが、一旦は無視する（A を原点に固定）。
- 角速度 ω で回転しているが、位相を測る相手がいないので、位相 0 度位置で停止しているとみなす。

## 単位系（意図的な選択）

c = 1、G = 1、かつプランク定数 h もあえて h = 1 とする。
定式化はまず定数 (c, G, h) を明示した完全形で書き、その後 c = G = h = 1 の省略形にする。
このニュートン段階の式に実際に現れる定数は G のみ（c, h はシリーズの後段で現れる）。

- 完全形: g_ab = G M_A / R², c_ab = ω² R, 釣り合い G M_A / R² = ω² R ⇒ ω = √(G M_A / R³)
- 省略形 (c = G = h = 1): g_ab = M_A / R², c_ab = ω² R, ω = √(M_A / R³)
