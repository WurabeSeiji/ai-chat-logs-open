## 2. §20 判定

**rank-4 内部実現多様体仮説（H_B1）：非支持。**

根拠（§20 非支持条件に該当）：
1. d_est は N とともに増加する（N=6 の 4.6 → N=20 の 18）。N 非依存の 4 への飽和はない。
2. K 飽和は K*≈N−1 で、早期飽和しない（高次 P_k が独立情報を加え続ける）。
3. 真の次元が 4 なら n=30〜200 で NN 推定器は容易に ≈4 を返す。N≥8 で全推定器が明確に 4 超。
4. N=6 ですら CI [3.9, 6.3] は中心 4.6 で、「4 に近いから 4」とは読めない。

## 3. ただし N≳20 の平坦域は標本律速

N=20〜40 で d_est が ~18–25 に平坦化するが、この領域は n=5N ≪ 10(d+1) であり、
推定器間不一致（E2≈20 vs E3≈27–31）、A/B 系統差（B が系統的に高い）が出ている。
**「d は N 線形で増え続ける」のか「~20 で物理的に飽和する」のかは現標本では判別不能。**

事前合意の seed 拡張基準（CI 広い／推定器不一致／K 飽和判定不能）に**該当**。
判別には seed 5→50 の拡張が必要（承認待ち。結果を 4 へ近づける目的ではなく、
平坦域の実在判定のため）。

## 4. §22 に基づく解釈

外部解析の rank-4（単一軌道の span）と内部アンサンブル次元は**別物であることが実測された**。
これは実験の失敗ではなく、§22 の「N依存 → rank-4 は外部射影固有」分岐の直接証拠である。
既存シリーズの 4 方向は、Bob 内部幾何の次元ではなく、単一軌道が張る部分空間の性質として
再解釈する必要がある。

## 5. κ_B null 対照（次元推定と独立・非常に強い）

終端 κ_B 中央値は全 N で 5×10⁻⁵〜3×10⁻⁴。generic null での生起確率は
log10 P(κ ≤ median) = −6.0 〜 −7.9 ／ **1 star あたり**（kappaB_null_contrast.csv）。
4025 star 全体では null は事実上棄却され、
「自己無撞着力学は Bob-star 局所閉包を選択する」は Phase B の確定結果と言える。
