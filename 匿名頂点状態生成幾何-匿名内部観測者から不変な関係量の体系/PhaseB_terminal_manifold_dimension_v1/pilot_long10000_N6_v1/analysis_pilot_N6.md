## 検査項目と結果

生成プログラム `run_N3_N40_steps10000_v1.py` の `edges(N)` は `np.triu_indices(N, k=1)`（行優先上三角順）。
機械検査: 各 Bob の star はちょうど N−1=5 本、全 star の合併は各辺を正確に2回被覆。**Bob-star 抽出規約は確定**。

### 2. 大域保存量（sanity）

- κ_global: step0 = 2.74e-15、final = 2.88e-14。力学は Σz²=0（零閉塞）を厳密保存（ランナーの主張と一致）。
- H_total: 1.0 → 0.999999999999699（‖Z‖ 保存 ✓）。

### 4. 事前登録予測との照合

設計書 §8.3 の予測「終端で |P₁|,|P₂| 縮退・|P₄| 相対大・r=4 浮上」は、**この状態では不成立**（|P₁| は O(1)、r=1、|P₄| は小）。
ただし本データは make_parent 床の long-run で N=6 は「ほぼ凍結」＝**床近傍状態**であり、予測の対象である SSB 後の終端リング状態ではない。予測の本検定は第一段（SSB バッチ保存版）で行う。
代わりに床近傍状態の署名が得られた: **r=1 チャート健在＋P₂ のみ縮退（局所閉包）**。

### 5. Bob 間重複率

同一 r（全 Bob r=1）で15対すべて比較可能。距離は 1.63–3.83（中央 2.72）、重複（<1e-12）は **0 対**。
この状態では Bob 多重度は互いに異なる不変量情報を持つ。（SSB 終端での再評価は第一段後。）

### 6. 設計へのフィードバック（v1.3 候補・主推定前に要決定）

|P₂|〜1e-7 の Bob では位相 φ₂ は数値ノイズである。現行 A/B 系は (cosφ_k, sinφ_k) を無条件に含めるため、
**縮退成分のノイズ位相が標本間でランダムに回り、見かけの次元を押し上げる恐れ**がある。
対策候補: 位相を単独成分とせず、G_B 不変な複素数
ζ_k = P_k^r · conj(P_r^k) / |P_r|^k（r=1 では ζ_k = P_k·conj(P₁^k)/|P₁|^k、|ζ_k|=|P_k|）
の (Re, Im) を用いる。|P_k|→0 でノイズ位相が自動的に 0 へ縮退する。
これは凍結仕様の変更にあたるため、採用するなら設計書 v1.3 として明示改訂してから主推定に入る。
