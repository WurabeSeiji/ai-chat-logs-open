# 低位 N の手計算：Bob 錨付き不変量の局所完全系

## 1. 問題設定

全頂点数を \(N\)、Bob を1頂点として固定した後の incident relation 数を

\[
m=N-1
\]

とする。Bob に入る複素関係を外部表記で

\[
z_1,\ldots,z_m\in\mathbb C
\]

と書く。ただし Bob にとって順序は物理的でない。

作業ゲージ群は

\[
G_B=\mathbb C^\times\times S_m
=
(U(1)\times\mathbb R_+)\times S_m,
\]

すなわち

\[
z_j\mapsto c\,z_{\pi(j)},\qquad
c\in\mathbb C^\times,\ \pi\in S_m.
\]

求めるのは、この作用で不変な量である。

## 2. quotient の局所次元

\[
(z_1,\ldots,z_m)\in\mathbb C^m\setminus\{0\}
\]

は実 \(2m\) 次元。共通複素スケール \(c\in\mathbb C^\times\) は2実自由度を消し、有限群 \(S_m\) による商は局所次元を変えない。

したがって generic quotient の実次元は

\[
\boxed{d_B=2m-2=2N-4.}
\]

低位では

\[
N=2\Rightarrow d_B=0,\quad
N=3\Rightarrow d_B=2,\quad
N=4\Rightarrow d_B=4,\quad
N=5\Rightarrow d_B=6.
\]

これは時空次元ではなく、Bob-star の瞬間的匿名複素状態が持つ generic な局所不変自由度数である。

## 3. 対称多項式による局所完全不変量

基本対称多項式を

\[
e_1=\sum_j z_j,\quad
e_2=\sum_{j<k}z_jz_k,\quad \ldots,\quad
e_m=\prod_jz_j
\]

とする。

\(S_m\) の置換で各 \(e_k\) は不変。共通複素スケール \(z_j\mapsto c z_j\) では

\[
e_k\mapsto c^k e_k.
\]

したがって \(e_1\neq0\) の chart では

\[
\boxed{
J_k=\frac{e_k}{e_1^k},\qquad k=2,\ldots,m
}
\]

が \(\mathbb C^\times\times S_m\) 不変である。

\(J_k\) は \(m-1=N-2\) 個の複素数なので、\(2N-4\) 実自由度を持ち、quotient 次元と一致する。

## 4. 局所完全性

共通スケールを使い \(e_1=1\) に規格化する。

\[
y_j=\frac{z_j}{e_1}
\]

とすると、Vieta の公式より \(y_j\) は

\[
\boxed{
y^m-y^{m-1}+J_2y^{m-2}-J_3y^{m-3}
+\cdots+(-1)^mJ_m=0
}
\]

の根である。

したがって \(J_2,\ldots,J_m\) から無順序多重集合

\[
\{y_1,\ldots,y_m\}
\]

を再構成できる。

よって generic chart \(e_1\neq0\) では

\[
\boxed{\{J_2,\ldots,J_m\}}
\]

は Bob-star を \(G_B\) ゲージを除いて局所的に完全に決める。

## 5. N=2

\(m=1\)。Bob-star は \(\{z_1\}\) のみ。

共通 \(\mathbb C^\times\) 作用で任意の非零 \(z_1\) は1へ移せるため、

\[
\boxed{d_B=0.}
\]

また

\[
\kappa=\frac{|z_1^2|}{|z_1|^2}=1.
\]

従って N=2 には連続な相対幾何がない。

## 6. N=3

\(m=2\)。

\[
e_1=z_1+z_2,\qquad e_2=z_1z_2.
\]

唯一の複素局所不変量は

\[
\boxed{
J_2=\frac{z_1z_2}{(z_1+z_2)^2}.
}
\]

規格化関係は

\[
\boxed{y^2-y+J_2=0}
\]

の2根である。

### exact example: 二乗ゼロ閉包

\[
(z_1,z_2)=(1,i).
\]

\[
e_1=1+i,\qquad e_2=i,
\]

\[
J_2=\frac{i}{(1+i)^2}=\frac12.
\]

一方、

\[
z_1^2+z_2^2=0
\]

なので

\[
\boxed{\kappa=0.}
\]

再構成方程式

\[
y^2-y+\frac12=0
\]

の根は

\[
\frac{1\pm i}{2},
\]

であり、実際の \(\{z_1/e_1,z_2/e_1\}\) と一致する。

### exact example: 一直線位相

\[
(z_1,z_2)=(1,2).
\]

\[
J_2=\frac29,
\qquad
\kappa=1.
\]

## 7. N=4

\(m=3\)。

\[
e_1=z_1+z_2+z_3,
\]

\[
e_2=z_1z_2+z_2z_3+z_3z_1,
\]

\[
e_3=z_1z_2z_3.
\]

局所完全不変量は

\[
\boxed{
J_2=\frac{e_2}{e_1^2},\qquad
J_3=\frac{e_3}{e_1^3}.
}
\]

2複素数、すなわち4実自由度。

規格化関係は

\[
\boxed{
y^3-y^2+J_2y-J_3=0
}
\]

の3根として無順序に再構成される。

### exact example

\[
(z_1,z_2,z_3)=(1,i,-1).
\]

\[
e_1=i,\qquad e_2=-1,\qquad e_3=-i,
\]

なので

\[
J_2=1,\qquad J_3=1.
\]

再構成方程式は

\[
y^3-y^2+y-1=0=(y-1)(y^2+1).
\]

根は \(\{1,i,-i\}\) で、規格化 star と一致する。

また

\[
\kappa=\frac13.
\]

## 8. N=5

\(m=4\)。

\[
\boxed{
J_2=\frac{e_2}{e_1^2},\quad
J_3=\frac{e_3}{e_1^3},\quad
J_4=\frac{e_4}{e_1^4}
}
\]

の3複素数、6実自由度。

再構成方程式は

\[
\boxed{
y^4-y^3+J_2y^2-J_3y+J_4=0.
}
\]

したがって低位 N では

\[
\boxed{
N\longrightarrow N-2\text{ 個の複素局所不変量}
\longrightarrow 2N-4\text{ 実自由度}
}
\]

となる。

## 9. chart 境界

この表示は \(e_1\neq0\) でのみ有効。

例えば

\[
(1,i,-1,-i)
\]

では \(e_1=0\) なので \(J_k=e_k/e_1^k\) は使えない。

これは幾何が壊れるのではなく chart の境界である。別の \(e_r\neq0\) を基準にする chart、または normalized Hermitian Gram invariants が必要になる。

## 10. κ と J の役割

\[
\kappa=\frac{|\sum z_j^2|}{\sum|z_j|^2}
\]

は優れた単一秩序量だが、N≥3 では star 全体を一意には決めない。

一方 \(J_2,\ldots,J_m\) は generic chart で star 全体を再構成する局所完全座標である。

\[
\boxed{
J_k:\text{完全な局所匿名座標},\qquad
\kappa:\text{その上の一つのゲージ不変秩序量}
}
\]

と分けるべきである。

## 11. 最初の重要な観察

\[
d_B=2N-4.
\]

特に

\[
\boxed{N=4\Rightarrow d_B=4.}
\]

既存力学で観測された rank-4 と数字は一致する。ただし同一視はまだできない。

N>4 では generic quotient 次元は増えるため、大N力学で rank-4 が飽和するなら、追加の力学的拘束・閉包・縮退が不変量空間を4次元部分多様体へ落としている必要がある。

次の検証問題は

\[
\boxed{
\text{大 }N\text{ の実軌道は、generic }(2N-4)\text{ 次元 quotient の中の}
4\text{ 次元部分多様体へ拘束されるか？}
}
\]

である。
