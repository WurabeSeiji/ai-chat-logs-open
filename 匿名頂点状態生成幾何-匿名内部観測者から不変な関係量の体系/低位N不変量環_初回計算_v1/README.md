## 主要結果

Bob-star の incident relation 数を \(m=N-1\) とすると、generic chart \(e_1\neq0\) で

\[
J_k=\frac{e_k}{e_1^k},\qquad k=2,\ldots,m
\]

が \(G_B=\mathbb C^\times\times S_m\) の局所完全不変量になる。

generic quotient の実次元は

\[
\boxed{2N-4}.
\]

特に

\[
\boxed{N=4\Rightarrow4\text{実次元}}
\]

である。
