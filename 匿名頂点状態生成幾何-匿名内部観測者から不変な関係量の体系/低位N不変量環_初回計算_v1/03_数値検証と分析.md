# 数値検証結果と分析

## 実行内容

N=2,3,4,5 について各1000個のランダム Bob-star を生成した。

各標本に、

- ランダム共通スケール
- ランダム大域位相
- ランダム置換

を同時に作用させ、

\[
z_j'=\lambda e^{i	heta}z_{\pi(j)}
\]

として \(J_k\) と \(\kappa\) の不変性を検証した。

さらに \(J_2,\ldots,J_m\) のみから規格化 Bob-star の根を再構成し、元の無順序関係集合と一致するかを確認した。

\[
\boxed{J_k\text{ の }G_B\text{ 不変性}}

と

\[

\]

を N=2～5 の各1000標本で確認した。

N=5 で `max_J_invariance_error` が約 \(10^{-8}\) まで増えるのは、\(e_1\) が小さい標本で \(e_1^{-k}\) の条件数が悪化するためであり、理論上の不変性の破れではない。これは同時に \(e_1\neq0\) chart の数値境界を示す。

## 結果1：N=2

\[
d_B=0.
\]

独立な \(J_k\) は0個。Bob-star 1本だけでは相対幾何はない。

## 結果2：N=3

\[
d_B=2.
\]

1個の複素不変量 \(J_2\) が完全局所座標になる。

これは「N=3 で初めて関係同士を比較できる」という観測論的予想と一致する。

## 結果3：N=4

\[
\boxed{d_B=4}
\]

となり、

\[
(J_2,J_3)\in\mathbb C^2
\]

が局所完全座標になる。

既存力学系列の rank-4 と同じ数字が自然に現れるが、まだ同一視はしない。

## 結果4：大Nで4次元飽和するには追加拘束が必要

generic quotient は

\[
d_B=2N-4
\]

なので、

\[
N=5\Rightarrow6,\qquad N=6\Rightarrow8,\ldots
\]

と増える。

従って保存済み大N軌道で rank-4 が維持されるなら、それは匿名化だけからは出ない。

必要なのは

\[
\boxed{
\text{力学が generic invariant space 内の低次元部分多様体へ軌道を拘束すること}
}
\]

である。

## 次の検証

1. 保存済み N=6～40 軌道で Bob-star 不変量を構成する。
2. 各 step で不変量ベクトルの局所 SVD / Jacobian rank を測る。
3. generic 値 \(2N-4\) ではなく rank 4 へ拘束されているかを見る。
4. 同時に \(\kappa_B(t)\) を測り、インフレーション開始・モード切替・終端との対応を調べる。

新規走行は不要で、保存済みデータの読出しだけで実施可能である。
