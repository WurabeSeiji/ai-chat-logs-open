## 目的

匿名頂点状態生成幾何 v0.6 で確定した完全フレームを、Phase B 前に低位 N で数値較正する。

条件：
- N=2,3,4,5,6
- 各 N 2000 標本
- Re(z_j), Im(z_j) ~ Normal(0,1)
- seed=20260914

## G_B 不変性

ランダムな共通スケール・大域位相・置換を作用させても、完全フレームの最大差は全 N で約 10^-14 以下。

## K=N-1 での完全復元

H=1、arg P1=0 にゲージ固定し、完全フレームから冪和を復元。Newton 恒等式で基本対称式へ変換し、モニック多項式の根を元の無順序 Bob-star と比較した。

最大復元誤差は N=2〜6 で 0 から約 9.85×10^-14 の範囲。完全性定理と一致した。

## N=3 恒等式

2000 標本で以下を検査した。

w^2=(u^2-4)(1-c^2)

S=uc+iw

1/J2=2+S

|S|=u*kappa_B

最大誤差：
- 実代数関係式: 2.274e-13
- S 恒等式: 7.324e-15
- J2 恒等式: 1.068e-14
- kappa 恒等式: 1.421e-14

すべて丸め誤差範囲。

## P1 chart 境界

今回の通常乱数標本では |P1|<10^-3 は観測されなかった。ただし P1=0 は理論上存在するため、Phase B では |P1| を必ず記録し、境界近傍は別 chart または感度検査で扱う。

## 付随観察

generic 複素ガウスで平均 kappa は N とともに低下した。これは N=40 までの統計実験候補だが、本較正結果とは分離する。

## 結論

v0.6 の完全フレームについて、
1. G_B 不変性
2. K=N-1 完全復元
3. N=3 恒等式群
4. P1 chart 監視

を再較正し、全て理論と一致した。

従って Phase B で K=N-1 まで用いれば、測定される像次元は不完全フレームによる単なる下界ではなく、P1≠0 chart 上の商空間像次元として解釈できる。
