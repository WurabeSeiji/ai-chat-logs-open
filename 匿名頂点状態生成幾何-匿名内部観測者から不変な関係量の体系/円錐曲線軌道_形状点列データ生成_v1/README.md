# 数値実験01　円錐曲線軌道の形状点列データ

時刻情報を含まない軌道点列（形と並び順だけ）から、次のことが推定できるかを調べるためのブラインドテスト用データです。

- 軌道の種類（円・楕円・放物線・双曲線）
- 形の2自由度
- 相手の天体の位置（焦点）と向き
- 時間での位置

焦点の位置・長軸方向・進行方向は乱数で与えてあり、解く側には形の種類・位置・向きの先入観を与えません。生成に使った厳密なパラメータと生成式はすべて保存してあるので、完全に再現・採点できます。

## 実行方法

Python 3.9 以上と NumPy が必要です（図化には Matplotlib も必要）。このフォルダで次の順に実行します。

    python generate_conic_orbit_samples.py   # data/ に点列・正解・自己検証結果を出力
    python reproduce_from_meta.py            # 保存パラメータだけから点列を再生成して照合
    python plot_conic_orbit_samples.py       # figures/ に確認用の図を出力

乱数シードは固定（20260922）なので、何度実行しても同じデータになります。出力先はスクリプトの置き場所を基準に決まるので、どこから実行してもこのフォルダの data/ と figures/ に保存されます。

## 解く側に渡すもの

data/input/ の点列だけです。data/truth/ は採点用なので渡しません。データセット ID（D01〜D16）とケースの対応は乱数で並べ替えてあり、対応表は data/truth/manifest.json にだけあります。ファイル名から軌道の種類が分からないようにするためです。

## 生成式

焦点を原点、近点方向を +x とする標準座標で円錐曲線を作り、乱数の回転と平行移動でデータ座標に置きます。

    r(θ) = p / (1 + e cos θ)
    q(θ) = r(θ) (cos θ, sin θ)
    P = O + R(φ) q(θ),   R(φ) = [[cos φ, −sin φ], [sin φ, cos φ]]

形の2自由度は (p, e) で持ちます（p は半直弦）。a, b のままだと放物線で発散するためで、有限な場合は a, b も派生値として保存しています（楕円は a = p/(1−e²)、b = p/√(1−e²)。双曲線は分母の 1−e² を e²−1 に置き換え）。

| 記号 | 意味 | 範囲 |
|---|---|---|
| p | 半直弦（形の大きさ） | 一様乱数 0.5〜3.0 |
| e | 離心率（形） | ケースごとに固定 |
| O | データ座標での引力中心（焦点）の位置 | 各成分 一様乱数 −20〜20 |
| φ | 近点方向（長軸の向き） | 一様乱数 0〜2π |
| 進行方向 | 反時計回り／時計回り | ちょうど半数ずつ乱数で割り当て |

meta.json には、焦点・もう一方の焦点・中心・近点・遠点の座標、漸近線の方向（双曲線）、データ座標での一般形 A x² + B xy + C y² + D x + E y + F = 0 の係数と判別式 B² − 4AC（= 4(e² − 1)）も入れてあります。

|---|---|---|---|

| C02 | 楕円（円に近い） | 0.02 | 1周 |
| C03 | 楕円 | 0.6 | 1周 |
| C04 | 楕円（細長い） | 0.97 | 1周 |
| C05 | 楕円（細長い・部分弧） | 0.97 | r ≤ 10p の弧 |
| C06 | 放物線 | 1 | r ≤ 10p の弧 |
| C07 | 双曲線（放物線に近い） | 1.03 | r ≤ 10p の弧 |

各ケースを刻み方 A・B の2通りで作り、計16データセットです。C05〜C07 は、同じ観測窓の中だけを見ると区別が難しい組み合わせで、離心率の識別の分解能を測るために入れてあります。

## 刻み方

点は弧長を基準に、時間とは無関係な不規則な間隔で置いています。時間に比例する角（平均近点角）で刻むと、点の密度に 1/v の形で時間情報が残るためです。

- A（一様ゆらぎ）: 弧長の間隔 = h_max × U(0.55, 1.0)
- B（疎密変調）: 弧長の間隔 = h_max × exp(β(sin(2πk s/L + ψ) − 1)) × U(0.7, 1.0)。β = 0.9、k は 1〜3 の乱数、ψ は乱数

間隔の上限 h_max は 0.2p 以下、短い曲線では L/250 以下です。円錐曲線の曲率半径の最小値はどの種類でも p なので、曲線の別の部分へ飛び移ることはありません。揺らぎの幅は、連続する間隔が g[k+1] < g[k] + g[k−1] を満たすように選んであります。このため最近傍を順にたどる並べ替えは、閉曲線ではどの点から始めても、開いた曲線では端から始めれば、順序を一意に復元します。

円は等速運動なので、弧長でほぼ一様に刻む A では時間の刻みもほぼ一様になります。点の密度に頼らない推定になっているかは、同じケースの A と B で結果が変わらないことで確かめてください。

## 並び順

入力の並びは、最近傍の並べ替えで復元できる情報だけを持つようにしてあります。ちょうど半数のデータセットで進行方向に対して並びを反転し、閉曲線では始点もランダムにずらしています。真の時間順は truth.csv の time_rank 列にあります。

## 時刻の定義

GM は形からは決まらないので、時刻は p を長さの単位とする無次元時刻で保存しています。t_p は近点通過時刻です。

    τ = √(GM/p³) (t − t_p) = ∫₀^θ dθ′ / (1 + e cos θ′)²

解析式は次のとおりです。

- 円: τ = θ
- 楕円: τ = (E − e sin E) / (1 − e²)^(3/2)（E は離心近点角）
- 放物線: τ = (D + D³/3) / 2（D = tan(θ/2)）
- 双曲線: τ = (e sinh H − H) / (e² − 1)^(3/2)（H は双曲線近点角）

閉曲線の1周の時間は 2π / (1 − e²)^(3/2) です。

## 自己検証（validation_report.json）

- 点を正解のパラメータで標準座標に戻すと、円錐曲線の式を満たし、θ も一致すること
- 最近傍を順にたどる並べ替えで、入力の順序が復元できること（閉曲線は8か所の始点から、開いた曲線は両端から実行）
- 閉曲線では、どの点から始めても復元できる局所条件 d(i, i+1) < d(i, i−2)、d(i, i−1) < d(i, i+2) がすべての点で成り立つこと
- 曲線に沿って p 以上離れた点までの最短距離が、隣接点の最大間隔より大きいこと
- 時刻の解析式が、数値積分 ∫dθ/(1 + e cos θ)² および普遍変数（Stumpff 関数）の式と一致すること
- 閉曲線では、1周の時刻の合計が周期に一致すること
- 引力中心まわりの回転の向きが、記録した進行方向と一致すること
- 開いた曲線・部分弧では、すべての点が観測窓 r ≤ 10p の中にあること

時刻の刻みの不規則さ（変動係数と最大/最小比）も記録してあります。
