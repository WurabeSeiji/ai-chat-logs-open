# 検証：R12423 系による第十三思考実験 §12.2〜12.6 の追加実験（2026-10-10）

## 目的

第十三思考実験 §12 の検証項目のうち、§12.1（旧実験の再現、[S7]）と厳密根での完全回帰（`検証_R12423厳密根の完全回帰_20261010`）に続き、§12.2〜12.6 を同じ系（R = cos²(23π/124)）で行った。R は入力値なので、ここで得られるのは「動力学なしの線形交換で何が出るか」の基準線である。混合角を相互作用から決める模型は次段（動力学）の課題であり、本検証には含めない。

## 方法

- 原本（0713、SHA256 f815320f…）の関数で初期状態（A：単音 m=1、B：奇数倍音 1〜63 m=2）、散乱係数、倍音分布を作り、更新は U_R = [[r, t], [t, r]]。
- P（局在波）= 原本の B、背景 = 原本の A の写し。多チャネルではチャネルごとのノルムが保存されないため normalize を外した純粋な U_R を使う（閉じた二波では両者が一致することは [S7] で確認済み）。
- 各チャネルは常に x a0 + y b0 に留まるので、E12_3〜E12_5 は係数で計算し、全状態の計算と照合した（M=4、120 衝突で残差 9.3e-16）。
- E12_2（§12.2）閉条件 0〜248 衝突：倍音成分の復元残差、倍音ごとのパワーの保存、二乗閉塞 Σψ²、エネルギー候補 E1・E2（原本の倍音分布の一次・二次モーメント）を別々に記録。
- E12_3（§12.3）閉（M=1）と開：M 本の背景から毎回ラベルに依らず無作為に相手を選ぶ（M=2, 4, 16, 64、64 試行、1000 衝突）、および毎回新しい背景（M=∞）。流出・再流入・局在の残存を記録。
- E12_4（§12.4）R = 0.01〜0.99（99 点）と有限位数根（n ≤ 8 の 10 点と 124/23）で、開条件の寿命 τ_e と閉条件の最小状態距離。整数比を設定として与えず、背景の初期位相も掃引。
- E12_5（§12.5）交換しない基準波 F に対する P の自己振幅 y_P(k) = ⟨b0, P_k⟩（内部時計の読み）と N_eff（局在の読み）を独立に記録。
- 寿命 τ_e：残存率 (w − w_∞)/(1 − w_∞) が 1/e を切る衝突数（線形補間）。w_∞ は後半 500 衝突の平均。

## 結果

- §12.2：Σψ² は A・B・合計とも全衝突で 4.7e-16 以下で、二乗閉塞は保たれる。倍音ごとのパワーは A+B で保存され（ずれ 8.5e-15）、倍音成分は x a0 + y b0 で復元される（残差 1.1e-15）。エネルギー候補 E1 = N_eff（a0：1、b0：32）、E2（a0：2、b0：1366）はいずれも A+B で保存される。
- §12.3：閉（M=1）は k=124 で局在の重みが 1 に戻る。開では局在の重みが 1/(M+1) へ緩和し（w_∞ = 0.334, 0.198, 0.059, 0.016）、τ_e = 1.29, 1.73, 2.37, 2.70 衝突。M=∞ では厳密に R^k（τ = −1/ln R = 2.77）。1000 衝突の再流入の累計は 174.7（閉）、99、56、16、4.3 と M とともに減る。
- §12.4：閉条件はどの R でも散逸がなく、有限位数根でのみ厳密に戻る（最小 ε ≤ 3.0e-14、根でない格子点では最小 3.1e-5）。開条件の τ_e は ω/2π に対して滑らかで、根と ±0.003 の隣接点との相対差（M=2 で 5.4e-3、M=4 で 1.4e-3）は、根でない格子点で測った同じ量（2.7e-2、4.0e-2）の範囲内にある。背景の初期位相は局在の重みに影響せず（差 0）、N_eff には影響する（最大差 29.8）。
- §12.5：閉条件の y_P は中心 1/2・半径 1/2 の円上を進み（ずれ 3.6e-15）、k=124 で 1 に戻る。円上の点 μ^k（μ = r − t）は毎衝突 2 arg r 回る。全開放では y_P = r^k（|y_P|² = R^k、偏角は毎衝突 arg r = −33.39°）。N_eff は閉で 32 に戻り、全開放で 1 になり、M=4 では不規則に変わる。
- §12.6：条件 1 は該当しない（閉で戻る）。条件 2 はこの線形交換系では該当する（整数比への選別は現れない）。条件 3 は未判定（相対運動を変えた比較には衝突の間の伝播の規則が要る）。条件 4 は判定対象外。文言は `results/summary_section12_R12423.json` の E12_6。
