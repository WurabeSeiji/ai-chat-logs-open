# 検証：厳密根 R_{124,23} における二波交換の完全回帰（2026-10-10）

## 目的

第十三思考実験 §6.1 は、0713 の二波交換実験（R = 0.70）について「ω/2π = 0.8155… が無理数なので完全な復帰は起きない。128 回までで最も戻りに近いのは 103 回目で、相手側に残る割合は 1.6×10⁻⁴」と記した。

R = 0.70 は、0713 の実験の反射率掃引（R = 0, 0.51, 0.55, 0.6, 0.7, 0.9, 1）で、二波の局在性の差が最小になった値である
（0713 総括 §7、Zenodo 10.5281/zenodo.21333768）。その後、0.7 前後を細かく掃引した。0715 稿（Zenodo 10.5281/zenodo.21396761）で
0.6866 ≤ R ≤ 0.7025 を刻み 10⁻⁷ で掃引すると R ≈ 0.6971779 に深いピークが現れ、有限位数共鳴論文（2026-07-18、
Zenodo 10.5281/zenodo.21421367）§3・§4.1 で刻みを 10⁻¹² まで縮めると、ピークの中心は有限位数根

    R_{124,23} = cos²(23π/124) = 0.697177927556659…

に収束した（この掃引は、同論文の System B〔準安定界面の系〕で行われた）。意味を持つのは、R が有限位数根 R_{n,m} = cos²(πm/n) であることだけである。同 §6.5 のとおり λ_a³¹ = i、λ_a⁶² = −1、λ_a⁹³ = −i、λ_a¹²⁴ = 1。
本検証は、0713 の元プログラムの更新式を一切変えず、R だけを 0.70 からこの厳密根に置き換えて、
衝突 0〜248（二完全周期）の全ステップを記録し、完全回帰が実際に起きることを確かめた。

## 方法

- 元プログラム `original_copy/run_exchange_scattering_matrix_fermionic_localization_transfer_preliminary_v1.py`
  （0713 の原本と一字一句同一。SHA256 = f815320f5632ae1b23ccade3a53b01e9110ad770da8407e2b10fa6065ef1695c、
  検証_R070交換の正規化と振幅_20261009/SHA256SUMS と一致）をモジュールとして読み込み、その関数だけを使う。
- 更新は原本 `recursive_snapshot_states` と同じ `a' = normalize(r a + t b)`, `b' = normalize(t a + r b)`。
  初期状態も原本の図 1 と同じ（A: 次数 1、識別振動 m=1、q=+1。B: 奇数倍音 1〜63、m=2、q=−1）。
- R = cos²(23π/124) を倍精度で与える（R_VALUE = math.cos(math.pi*23/124)**2）。
- 対照: 同じループを R = 0.70 で回し、[S7] の summary.json（検証_R070交換の正規化と振幅_20261009/results）
  と比較した。ピークの絶対高さの差は 0（完全一致）、散乱係数と ω/2π も同一。
- 全ステップで、N_eff・L（原本の関数）、ピークの絶対高さ、正規化前ノルム、重なり、複素状態の初期状態からの距離 ε
  （第十三思考実験 §12.2 の量。大域位相を除いた版も）、入れ替わり状態からの距離 ε_swap、
  初期二状態への射影座標 (α, β, γ, δ) と復元残差を記録した。

## 結果

| k | kω (deg) | N_eff_A | N_eff_B | ε_state | ε_swap |
|---:|---:|---:|---:|---:|---:|
| 0 | 0.00 | 1.0000 | 32.0000 | 0 | 1.41 |
| 31 | 90.00 | 16.5000 | 16.5000 | 1.00 | 1.00 |
| 62 | 180.00 | 32.0000 | 1.0000 | 1.41 | 2.62e-15 |
| 93 | 270.00 | 16.5000 | 16.5000 | 1.00 | 1.00 |
| 103 | 322.26 | 4.2430 | 28.7570 | 4.57e-01 | 1.34 |
| 124 | 0.00 | 1.0000 | 32.0000 | 5.14e-15 | 1.41 |
| 186 | 180.00 | 32.0000 | 1.0000 | 1.41 | 7.67e-15 |
| 248 | 0.00 | 1.0000 | 32.0000 | 1.02e-14 | 1.41 |

- 完全回帰: k = 124 で ε_state = 5.1×10⁻¹⁵、k = 248 で 1.0×10⁻¹⁴（倍精度の丸め水準）。
  1〜143 の範囲で ε_state が最小になるのは k = 124。第十三思考実験 §7 の区別でいえば「状態の回復」である
  （R = 0.70 の 103 回目は規格化波形がほぼ戻る「見かけの回復」で、残り 1.6×10⁻⁴）。
- 完全入れ替わり: k = 62, 186 で (a, b) = (b₀, a₀)、ε_swap = 2.6×10⁻¹⁵、7.7×10⁻¹⁵。
- 等分: k = 31, 93, 155, 217 で N_eff_A = N_eff_B = 16.5（R = 0.70 では 42 回目に 16.58/16.42）。
- 閉形式 N_A = 1 + 31 sin²(kω/2) との差は最大 2.2×10⁻¹²、N_A + N_B = 33 からの差は最大 6.4×10⁻¹⁴。
- 正規化は何もしていない: 正規化前ノルム²の 1 からのずれは最大 2.4×10⁻¹⁵、純粋 U_R との N_eff の差は最大 3.6×10⁻¹⁴。
- 状態の完全記録: a_k = α a₀ + β b₀, b_k = γ a₀ + δ b₀ の復元残差は最大 3.8×10⁻¹⁵。
  chi 密度は rho_A,k = |α|² rho_a0 + |β|² rho_b0 で復元でき（識別振動 m_A=1, m_B=2 で干渉項は厳密に 0）、
  記録した密度との最大差は 9.2×10⁻¹⁶。したがって `coefficients_R12423.csv` と `basis_density_R12423.csv`
  だけで全ステップの波形が再現できる。
- ω/2π = 101/124 = 0.814516129032258（R = 0.70 では 0.815494940217227）。

周期 124 は入力した R が有限位数根であることの帰結であり、相互作用の結果として U^n = I が現れることを示すものではない（第十三思考実験 12.1 の留保はそのまま）。

## 再現

    sh run_all.sh

で、原本プログラムのコピーと SHA256 照合 → 記録（約 1.5 分）→ 図化 が順に走る。
実行環境: Python 3.9.6、numpy 2.0.2、matplotlib 3.9.4（乱数なし。[S7] と同じ環境）。
同じ環境で 2 回実行し、results/ と figures/ の全ファイル（CSV・npz・JSON・PNG・SVG・実行ログ）がビット単位で一致することを確かめた。
そのため、図化プログラムで `svg.hashsalt` を固定して SVG の日付メタデータを外し、記録プログラムは所要時間を `summary.json` に書かない。
全体図（図 D）の見出しの ε の値は、固定文字列でなく trace_R12423.csv から読む。
別の環境（Python・numpy・libm の版）では、R の最終ビットや CSV の最終桁が異なり得る。
claude.ai の環境（Python 3.12.3、numpy 2.4.4）で最初に実行したときとの差は、trace_R12423.csv で最大 1.5×10⁻¹²。
