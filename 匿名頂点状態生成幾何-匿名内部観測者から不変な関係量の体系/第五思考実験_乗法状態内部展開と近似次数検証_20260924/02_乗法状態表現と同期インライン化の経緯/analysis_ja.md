# 分析と撤回点

この系列は**最終理論ではなく探索経緯**である。

1. exp→multiply→log を内部で繰り返す方法は数値的に同値だが、`log` を状態更新へ戻すため基礎原則に反する。以後は監査用途に限定した。
2. 永続状態だけを乗法更新しても、RK4内部に $P+hK$ 型の加法中間演算が残る。この段階を「完全な乗法系」と呼んではならない。
3. `audit_five_state_full_inline.py` の Jacobian テストは、固定monomial-linear指数写像という狭いクラスを否定するだけで、一般の乗法閉包を否定しない。後にこの解釈を撤回した。
4. `audit_pure_exponential_state_engine.py` の長時間結果は、永続状態更新の同値性・観測枝分離の監査として有効だが、内部演算まで固定乗法作用に還元した証明ではない。

`formula_equivalence_100k.out` では逐次式と完全インライン式の100000点照合が機械精度で一致した。
