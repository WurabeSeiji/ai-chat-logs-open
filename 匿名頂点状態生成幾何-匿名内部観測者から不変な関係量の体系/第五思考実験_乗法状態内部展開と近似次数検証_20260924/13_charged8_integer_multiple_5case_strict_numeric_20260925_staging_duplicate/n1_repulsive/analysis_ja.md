# n1_repulsive — 厳格8状態数値実験 分析

## 実験条件

- $P_0=50$, target $P=20$
- $N=0.25$, $C=0.91$, $D=0.0$
- $\lambda_A=0.3$, $\lambda_B=0.3$
- 永続物理状態: $(U,P,E,H,Q,N,C,D)$
- 生成写像: `transition(z)` のみ

## 解釈上の制限
