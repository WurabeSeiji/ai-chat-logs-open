# n3_repulsive — 厳格8状態数値実験 分析

## 条件

- `P0 = 50`, target `P = 20`
- `lambda_A = 0.9`, `lambda_B = 0.9`
- `N = 0.25`
- `C = 0.19`
- `D = 0.0`
- 永続物理状態: `(U,P,E,H,Q,N,C,D)`
- 生成側は `transition(z)` のみ。解析基準の値は生成終了後の比較にのみ使用。

## 時刻読み出しの有限精度限界

`Q` の有限精度範囲を超え、step **6,316,005**、`P ≈ 41.514301347` で
`t = TAU0 log(Q)` が非有限化した。`P,H,N,C,D` の生成はその後も同一 `transition(z)` で継続し、
`P=20` まで到達した。この現象は修正せず、数値実験の限界として raw データに残している。

## 解釈上の制限

解析基準と生成器は同じ leading-order 物理方程式を異なる表現で評価する。
したがって一致は新しい物理法則の独立導出ではなく、ケース値を永続状態 `N,C,D` に内部化した
同一一回写像表現が保存済み解析基準を再現するかの検証である。
