# 08候補 — ν 第6状態内部化 対照実験 v1

目的: 第五思考実験で外部引数だった $\nu$ を第6永続状態 $\mathcal N$ として内部化し、前実験を厳密再現できるか確認する。

主要結果:

- 12ケース×4000 macro steps: 旧5状態と新5+1の最初の5状態は全保存行で bitwise identical。
- $\mathcal N$ は全保存行で初期 $\nu_0$ と bitwise identical。
- 代表3ケース×12000 macro stepsでも全差0。
- 保存済みPaper-4 C1 CSVに対する誤差プロファイルは旧系と新系で完全一致。
- 新遷移関数は外部 `nu` 引数を持たない。

第6状態は

$$
\mathcal N_{m+1}=\sum_{j=0}^{10}q_{j,m}(1\cdot\mathcal N_m)=\mathcal N_m
$$

として同じone-hot積和作用内で保持する。

**限定:** 荷電相互作用まで入れたときの $\mathcal N$ 恒等性はまだ検証していない。また既存B方式全体の完全乗法性を本実験が証明するものではない。
