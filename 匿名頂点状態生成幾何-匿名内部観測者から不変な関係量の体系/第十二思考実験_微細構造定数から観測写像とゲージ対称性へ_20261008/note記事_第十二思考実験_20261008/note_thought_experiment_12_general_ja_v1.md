# 1/137 はどこから来たのか――光円錐の方程式から、時間・質量・電荷・対称性を読み直した、第十二思考実験

前回の第十一思考実験では、水素原子など四つの二体系について、一般相対論と電磁気学の答え合わせの答えを先に作りました。

その計算には、いくつかの数を入力として入れています。

その一つが、微細構造定数 α です。

α ≈ 1/137

物理を少しかじった人なら、一度は見たことのある数だと思います。

前回は、この数を測定値のまま、何の疑いもなく入れました。

背景時空を置かない、名前のない状態から出発する、と言いながら、いちばん有名な定数を素通りしていたわけです。

そこで今回は、立ち止まって考えました。

αって、そもそも何だっけ。

## α は、まず速度の比でした

教科書では、α は電磁気の力の強さを表す定数として紹介されます。

でも、歴史をさかのぼると、もっと素朴な顔が出てきます。

水素原子のボーア模型では、いちばん内側を回る電子の速さ v と光の速さ c の比が、ちょうど α になります。

　v / c = α ≈ 1/137

つまり、水素原子の電子は、光の 137 分の 1 の速さで回っている、ということです。

1/137 は、まず速度の比として読めます。

速度の比が出てくれば、次に出てくるのは相対性理論です。

速さ v で動くものの時計の遅れ方を表すローレンツ因子は、

　γ = 1 / √(1 − v²/c²)

で、ここに v/c = α を入れると γ = 1 / √(1 − α²) になります。

ゾンマーフェルトが水素原子に相対論の補正を入れたとき α が現れたのは、この形を見れば自然です。

## 私が昔から好きだった式

ここで、少し個人的な話をさせてください。

私は高校のとき、ローレンツ変換と光円錐の方程式を知りました。

ローレンツ変換は、ルートと分数が入り組んだ、見苦しい式でした。

それに比べて、光円錐の方程式は、驚くほど簡単でした。

　x² + y² + z² − t² = 0

（光の速さを 1 とする単位で書いています。）

光が進む先は、この式を満たす点の集まりです。

時間に虚数の i をつけて it と書けば、

　x² + y² + z² + (it)² = 0

と、すべてが二乗の足し算になります。

二乗を足してゼロになる。それだけの式です。

この美しさに惹かれたので、ずっと覚えていました。

ローレンツ変換は、この式の形を変えない変換として、後から決まります。

先にあるのは光円錐の方程式で、ローレンツ変換はそれを守る変換にすぎない。

今回の思考実験は、この順番を最後まで貫いてみた話です。

## 軸を一本足すと、遅い粒子も光円錐に乗ります

光の速さより遅く動く粒子は、光円錐の内側を進みます。

光円錐の表面には乗りません。

ところが、ここに一つ仕掛けがあります。

その粒子の時計が刻む時間（固有時間）を τ とすると、

　t² − r² = τ²

が成り立ちます。r は粒子が進んだ距離です。

τ² を左に移すと、

　r² + τ² + (it)² = 0

になります。

これは、軸が一本増えただけで、光円錐の方程式とまったく同じ形です。

つまり、光より遅い粒子も、固有時間の軸を一本足した空間では、光円錐の表面に乗っているのです。

r と τ を二辺、t を斜辺とする直角三角形ができます。

ローレンツ因子は、この三角形の辺の比 γ = t / τ にすぎません。

## 同じ三角形は、中心投影の三角形でもありました

私はこれまで、中心投影という幾何を使って論文を書いてきました。

球の中心から、球に接する平面の上の点に線を引き、その線が球と交わる点に写す操作です。

このとき、中心から平面上の点までの距離 ℓ は、

　ℓ² = |x|² + R_c²

を満たします。|x| は平面上の距離、R_c は球の半径（曲率半径）です。

さっきの光円錐の三角形と並べると、

- 距離 r が、平面上の距離 |x| に
- 固有時間 τ が、曲率半径 R_c に
- 時間 t が、中心からの距離 ℓ に

それぞれ対応します。

光円錐の方程式から虚数の i を外したものが、中心投影の三平方の式です。

私がずっと使ってきた中心投影は、光円錐の方程式と、同じ形をしていたことになります。

## 軸を 8 本にして、名前を外します

ここから、もう一歩進めます。

固有時間 τ の中身を、さらにいくつかの方向に分けてみます。

　x² + y² + z² + R² + Q₁² + Q₂² + Q₃² + (it)² = 0

軸は全部で 8 本。

x, y, z は、ふつうの空間の三方向です。

R と Q₁, Q₂, Q₃ は、空間のようには直接測れない方向です。

この式も、8 次元の光円錐の方程式です。虚数がつくのは t の一本だけです。

ここで大事なのは、軸に最初から名前をつけないことです。

t は時間、R は質量、Q は電荷、と決めてかかりません。

本当にあるのは、名前のない 8 本の方向だけだと考えます。

時間、質量、電荷という名前は、観測者がそれぞれの方向をどう読んだかに、後からつけた名前かもしれない。

実際、運動量を各方向の勾配として読むと、エネルギー E、運動量 p、質量 m、電荷 q の間に、

　E² = p² + m² + q²

という関係が出てきます。電荷がゼロなら、相対性理論でおなじみの E² = p² + m² です。

隠れた方向の運動量を電荷として読む考え方は、100 年前のカルツァとクラインの 5 次元理論にもあります。

## 読めない方向は、長さとしてしか見えません

観測者は、8 本の方向すべてを区別して読めるとは限りません。

たとえば、t だけしか読めない観測者を考えます。

この観測者には、残りの 7 本の方向が見分けられません。

見えるのは、7 本の二乗をまとめた長さ

　ρ² = x² + y² + z² + R² + Q₁² + Q₂² + Q₃²

だけです。

7 つの自由度は消えたのではありません。

区別できないので、一つの長さとしてしか現れないのです。

## 区別できないこと、それが対称性でした

見分けられない方向をぐるっと回しても、観測者に見える長さは変わりません。

観測者から見れば、回す前と後は同じです。

これを数学では、対称性と呼びます。

観測の結果を P と書くと、状態 U に変換 G を施しても P(U) = P(GU) なら、観測者は二つを区別できません。

つまり、

**対称性とは、区別できないことの数学的な表現**

だと読めます。

対称性は、自然に後から押しつけた約束ではないのかもしれません。

観測者が名前をつけられない方向がある。そのこと自体が、対称性として見えている。

逆に、観測の精度が上がって、それまで見分けられなかった方向が見分けられるようになると、対称性は小さくなります。

物理で言う対称性の破れは、それまで区別できなかったものが区別できるようになること、と読めるかもしれません。

## 3 と 2 に分けると、標準模型の形が出てきます

最後に、私たちのように空間 x, y, z を読む観測者を考えます。

見分けられない方向は、t, R, Q₁, Q₂, Q₃ の 5 本です。

この 5 本が、観測によって

- Q₁, Q₂, Q₃ の 3 本
- t, R の 2 本

の二つの組としてだけ区別できるとします。

3 本の組の中では区別がつかず、2 本の組の中でも区別がつかない。

このとき現れる対称性の候補は、

　SU(3) × SU(2) × U(1)

です。

これは、素粒子の標準模型が持つ対称性の形と同じです。

色荷の SU(3)、弱い力の SU(2)、電磁気につながる U(1) です。

そして、5 本を 3 と 2 に分けるこの構造は、1974 年にジョージャイとグラショウが提案した大統一理論（SU(5)）の分け方と、同じ形をしています。

対称性の形が候補として出てくる、というところまでです。

## もう一度、α に戻ります

出発点の α に戻ります。

水素原子では α = v/c でした。

最初は、ただの速度の比に見えました。

でも、ここまでの見方では、v も c も、名前のない高次元の勾配を、別々の方向から読んだ量なのかもしれません。

そうだとすると、α は、高次元の状態をある観測の方向へ写したときの、角度か比なのかもしれない。

それがどの方向とどの方向の比なのかは、まだ決まっていません。

ここは、正直に、未解決のまま置いています。

## 言っていないこと

今回の思考実験で、言っていないことをはっきりさせておきます。

- 標準模型の対称性を導いたとは言っていません。形が候補として現れる、というところまでです。足し算の二乗（光円錐の式）と、量子力学で使う絶対値の二乗は別のもので、そこをつなぐには、もう一つ仮定が要ります。
- α の値（1/137）を導いたとは言っていません。α がどの方向の比なのかも決めていません。
- 8 本の軸、虚数がつく軸、3 と 2 の分け方は、仮定として手で置いたものです。
- これは計算を伴わない、考えの整理です。

## 分かったこと

分かったことは、三つです。

一つ目。1/137 は、まず水素原子の電子の速さと光の速さの比として読めます。

二つ目。相対性理論のローレンツ因子は、軸を一本足した光円錐の方程式の、辺の比にすぎません。光より遅い粒子も、軸を一本足せば光円錐に乗ります。そしてその三角形は、私がずっと使ってきた中心投影の三角形と同じでした。

三つ目。軸に名前をつけずに、観測者がどの方向を区別できるかだけを考えると、対称性は区別できないことの表現として現れます。3 と 2 に分けると、標準模型と同じ形が候補として出てきます。

これまで私が「ゼロ閉塞」と呼んできた、二乗を足してゼロになる式は、特別な仮説ではありませんでした。

光円錐の方程式そのものだったのです。

次は、この見方で、同じ相互作用の規則のまま、読む方向だけを変えたときに、本当に違う物理が見えるのかを計算で確かめたいと思います。
