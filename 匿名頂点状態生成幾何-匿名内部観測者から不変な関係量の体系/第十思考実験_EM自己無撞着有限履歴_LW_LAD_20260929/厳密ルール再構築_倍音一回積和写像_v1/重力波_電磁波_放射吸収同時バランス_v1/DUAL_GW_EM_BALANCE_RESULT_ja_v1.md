# 厳密ルール再構築版：重力波・電磁波の放射／吸収同時バランス実験

## 1. 目的

厳密ルール再構築版の同一状態写像

\[
Z'_{\alpha}=\sum_{\beta,\gamma}T_{\alpha\beta\gamma}Z_{\beta}Z_{\gamma}
\]

を一切変更せず、電荷を持つ coupled two-channel 系について、重力的 spin-2 読出しチャネルと電磁的 spin-1 読出しチャネルの双方で、内向き吸収フラックスと外向き放射フラックスが同時に釣り合う初期状態が存在するかを数値探索した。

生成側ではチャネルは匿名 channel 0 / channel 1 であり、重力／電磁の意味付けは Q→0 極限に基づく読出しだけで行う。

## 2. 厳格ルール

- persistent state は複素倍音係数のみ。
- transition は `strict_harmonic_rn_tensor_v1.py` の固定 sparse quadratic interaction array による一回積和写像のみ。
- Q/M ごとに transition、interaction array、格子、step 数を変更しない。
- 探索で変更するのは初期状態だけ。
- 読出しフラックスは transition へ帰還しない。
- exact solution を次状態生成に使用しない。

## 3. バランス条件

各読出しチャネル i=0,1 について

\[
\delta_i = \frac{F_{i,\mathrm{out}}-F_{i,\mathrm{in}}}
{F_{i,\mathrm{out}}+F_{i,\mathrm{in}}}
\]

を定義し、

\[
\delta_0\simeq0,\qquad \delta_1\simeq0
\]

を同時に満たす初期状態を探索した。

最終探索では二つの初期波束位置

\[
x_{0,\mathrm{ch0}},\qquad x_{0,\mathrm{ch1}}
\]

だけを探索変数とし、初期振幅比は

\[
\eta=A_1/A_0=-1
\]

に固定した。これは transition の変更ではなく初期状態の選択である。

共通計算条件：

- `nx = 61`
- `K = 4`
- `dt = 0.12`
- `steps = 700`
- `sigma = 1.5`
- channel 0 amplitude = `1e-4`
- channel 1 amplitude = `-1e-4`

全ケースで両チャネルの inner / outer flux は非ゼロであり、同時にほぼ等しい。

したがって、この離散化・境界条件・有限時間窓において、

\[
\boxed{F_{\mathrm{GW,out}}\simeq F_{\mathrm{GW,in}}\neq0}
\]

かつ

\[
\boxed{F_{\mathrm{EM,out}}\simeq F_{\mathrm{EM,in}}\neq0}
\]

に対応する同時バランス初期状態が、少なくとも Q/M=0.3,0.6,0.9,0.99 で存在することを確認した。

## 5. 重要な再探索結果

最初の探索では両チャネルを同じ初期位置 x0 に置き、x0 と振幅比 eta の2変数だけを探索した。この制約では Q/M=0.9 で残差 norm ≈5.62e-3 が残った。

そこで transition は一切変えず、初期状態だけを一般化して channel 0 / channel 1 の初期波束位置を独立にした。その結果、Q/M=0.9 では残差 norm を

\[
5.62\times10^{-3}\rightarrow3.32\times10^{-13}
\]

まで低下させた。

従って、高電荷側でバランス状態が存在しなかったのではなく、最初の初期状態族が狭すぎたことが分かった。

## 6. 状態閉包監査

最終4ケースの最大 Q-power consistency error は

\[
\le 1.11\times10^{-16}
\]

であり、倍音復号の最大虚部残差も

\[
\lesssim1.3\times10^{-17}
\]

であった。

## 7. 独立再実行

探索終了後、保存された最終初期状態を `verify_dual_balance_repro_v1.py` から直接再実行した。

4ケースすべてについて、保存された最終フラックスと再実行値との差は

\[
\boxed{0.0}
\]

であり、δ の差も全ケース 0.0 であった。

`dual_balance_repro_verification_v1.json` の

`all_exact_reproduction = true`

を確認した。

## 8. 解釈上の範囲

この結果が示すのは、現在の strict harmonic RN coupled benchmark の離散モデルに、二読出しチャネルの放射／吸収フラックスが同時にほぼ釣り合う初期状態が存在することである。

これだけから、一般の full nonlinear asymptotically-flat charged binary が永久定常状態を形成することを証明したとは主張しない。また inner boundary flux は本数値系の吸収側読出しであり、full nonlinear horizon flux の直接計算ではない。

一方、今回の重要点は、このバランスを得るために重力用・電磁用の別 transition を追加しておらず、Q/M ごとのケース分岐も行っていないことである。同一の倍音一回積和写像の初期状態だけを変えて、両チャネルの同時バランス条件を得た。
