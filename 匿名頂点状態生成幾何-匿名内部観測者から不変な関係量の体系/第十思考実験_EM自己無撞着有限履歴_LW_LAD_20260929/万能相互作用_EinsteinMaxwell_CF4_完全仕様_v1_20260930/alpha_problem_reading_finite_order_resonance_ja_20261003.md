# 1. 7/18 論文が実際にしていたこと

## 1.1 模型

二チャネル A、B（波束。倍音を持つ）に、衝突ごとに交換散乱作用素

U_R = [[r, t], [t, r]]、 t = e^{iθ} cos θ、 r = −i e^{iθ} sin θ、 θ = arcsin √R

を掛ける。|r|² = R（反射）、|t|² = 1 − R（透過）。ユニタリ。R は**外から与える掃引パラメータ**。

## 1.2 機構（論文 §6）

対称・反対称に分けると X = (A+B)/√2 は不変（固有値 λ_s = r + t = 1）、Y = (A−B)/√2 は衝突ごとに λ_a = r − t = −e^{2iθ} を掛けられる。読み出し S_j = 0.02 cos(jω)、ω = π + 2 arcsin √R は X と Y の干渉項。

有限位数（厳密再帰）：λ_a^n = 1 ⇔ **R_{n,m} = cos²(πm/n)**。全域掃引の最深ピークは R_{124,23} = 0.6971779…。このとき λ_a³¹ = i、λ_a⁶² = −1、λ_a¹²⁴ = 1。対応仮説 N(R) = 4π/(1−R)² で読むと N(R_{124,23}) = 137.036043（CODATA 137.035999、差 4.37×10⁻⁵、相対 3.2×10⁻⁷）。

## 1.3 倍音の役割（論文 §9.1）

U_R^{total} = U_R ⊗ I_H。倍音は根の位置を動かさない（根は作用素だけで決まる）。倍音は反対称セクターを観測量に結合して**共鳴を見えるようにする**自由度。初期状態・倍音・位相を変えても R_{n,m} は動かず、ピークの高さと背景だけが変わる。

## 1.4 論文自身の結論

- α を導出したのではない。一般に既知の有限位数 Floquet 再帰（Anand ほか 2026）を再発見した。
- それでも二つの物理的 α⁻¹（137.036、128.946）の近傍に鋭い偶数位数根が存在する理由は未解決。有限位数根は可算無限で稠密なので、近接の一部は数論的偶然でありうる。
- 実装しているのは衝突開始後の反復散乱核だけで、波束が接近して最初の衝突条件を満たすまでの軌道は実装していない（§7.7）。

# 3. 示唆（なぜ現行模型で α が結果にならないか）

## 3.1 α を担う量が模型にない

旧模型で α を担うのは R（毎衝突の交換の強さ）で、N = 4π/(1−R)²、1−R = √(4πα) = e_HL ≈ 0.303。ロックは R が cos²(23π/124) になる有限位数条件。現行模型にはこれに当たる量がない。κ_C = 2αg は位相の進み率に入るだけで、「毎節点どれだけ相手へ渡るか」を決めていない。

## 3.2 124 は旧模型では結果、v6 では入力だった

旧模型では 31・62・124 は R から出た（λ_a の位数）。v6 では私が Δθ_X = 2π/62 と置いたので、62 節点で一周、124 で再帰は**構成上**出た。これは出てはいけない出方で、α の情報を持たない（試行計画 v1 §1 の「構成上固定」）。v7 で拍動時計にしたら 186 に変わったのは、入力に過ぎなかった証拠。

## 3.3 二つのチャネルと X/Y

7/18 の X = (A+B)/√2（不変）、Y = (A−B)/√2（回る）は、STATUS §9 の全体モード／相対モードそのもの。旧模型では X と Y の位相差が毎衝突 2θ + π ずつ進み、それが 2π·23/124 のとき再帰する。現行模型で X（呼吸）と Y（回転）の位相差の進みは E の差で決まり、節点の刻みは私が置いた。旧模型の構造を E–M で実現するなら、「毎節点の X–Y 位相差の進み」が E–M の係数から決まり、かつその値が有理（23/124）になる所でだけ放射が止まる、という形でなければならない。

## 3.4 旧模型の「単純すぎる」点（木原氏の注意どおり）

- チャネルが二つのスカラー（または U_R ⊗ I）で、空間も時間の歪みもない。
- R が外部パラメータ（7/18）か、倍音パリティ比という一つの読み出し（第 9 論文以降）。E–M の係数との対応がない。
- 有限位数根は稠密なので、「どの根が選ばれるか」を旧模型は決められない（論文 §11.2 が自認）。選ぶ仕組みが外に要る。
- 衝突開始までの軌道（接近）を持たない（§7.7）。現行 E–M 模型が持っているのはまさにこの部分。

したがって旧模型は「α がどこに住むか（交換の強さ）」と「ロックの数学（有限位数）」を示し、現行模型は「軌道・時間・1PN」を持つが交換の強さを持たない。両方を持つ形は、まだどちらにもない。

## 3.5 「厳密な α ≈ 137 にならない理由」の桁の帳簿（事実のみ）

旧模型の根 N(R_{124,23}) = 137.036043 と CODATA の差：ΔN = 4.37×10⁻⁵（相対 3.19×10⁻⁷）。α の冪で測ると

| 桁 | 値 | 現行 E–M 模型でこの桁にある項 |
|---|---|---|
| α（1 次） | 7.3×10⁻³ | v/c そのもの |
| α²（1PN） | 5.3×10⁻⁵（相対） | SR、KN 四重極、スピン–軌道、微細構造。κ_G/κ_C = 1.0×10⁻⁴ も同じ桁 |
| **α³（1.5PN）** | **3.9×10⁻⁷** | **放射反作用（ALD）だけ**。相対で 0.82α³ が ΔN に当たる |
| α⁴（2PN） | 2.8×10⁻⁹ | 2PC 項、重力 2PN |

旧模型の根と α の差は α³ の桁で、E–M の 1PN（α²）項より二桁小さく、2PN より二桁大きい。1PN の項がロック条件に入れば N は 10⁻⁴ ずれて一致が壊れる。α³ の桁にある E–M の項は放射反作用のみで、それは「位相がロックすると放出が止まる」という木原氏の機構を担う項でもある。これは数値合わせではなく桁の分類であり、対応を主張するものではない。ただし「1PN の項はロック条件に入ってはならず、1.5PN の項は入りうる」という制約を与える。

# 5. 追記（10/3）：なぜ評価関数に極めて深い谷ができたか（公開コードを無改変で再実行して確認）

## 5.1 深さの正体

有限位数根 R_{n,m} では λ_a^n = 1 が**代数的恒等式**として成り立つので、S_j = 0.02 cos(jω) は周期 n の厳密な周期列になる。n が偶数なら 2n 標本で平均 0、振幅 0.02、前後半ドリフト 0 が厳密に成立し、gray error ≡ 0。深度 −log₁₀(0) は演算精度だけで決まる（倍精度 14.7、50 桁 52、80 桁 82）。谷は無限に深く無限に狭い（対数の尖点）。これは時間方向の引き込み（アトラクタ）ではなく、ユニタリ写像のパラメータ空間での厳密再帰である。**どの偶数位数根でも同じ深さ**になる。

## 5.2 なぜ 124 と 122 が選ばれたか（評価窓の帰結）

公開コード v5 の候補規則は `stop_reason == early_stop_no_best_update and min_steps − patience ≤ best_step ≤ min_steps`。全域掃引の設定 min_steps = 256、patience = 20 では best_step ∈ [236, 256]。根では最良接頭区間は 2n − 1 なので、n ∈ [118.5, 128.5] の根だけが候補になる。掃引窓 [0.68660, 0.70247] に入る既約 R_{n,m}（n ≤ 140）は 34 個あり、この n 範囲にあるのは 119、122、123、124、125、127 の 6 個、うち偶数は **122 と 124 の二つだけ**（23/122、23/124）。これが論文の候補 1・2 である。

検証（公開コード無改変、steps 1024、min_steps 256、patience 20、φ = 0）：

| R | 根 | 深度 | best_step | 候補規則 |
|---|---|---|---|---|
| 0.69134172 | R_{16,3}（窓内、最低位数） | **15.301** | 31 | 不適格（31 ∉ [236, 256]） |
| 0.69717793 | R_{124,23} | 14.659 | 247 | 適格 |
| 0.68836395 | R_{122,23} | 14.878 | 243 | 適格 |

R_{16,3} は窓内にあり R_{124,23} より深いが、評価窓の規則で落ちている。したがって **31 × 4 = 124 は動力学が選んだのではなく、評価窓の長さ 256 ≈ 2n が選んだ**。論文 §4.3 は高次根（R_{620,117}、2n = 1240）について窓の効果を記しているが、低次根が同じ理由で落ちていることは記していない。

## 5.3 なぜ 0.7 の近くか

物理側の対応点 R_137 = 1 − √(4πα) = 0.697177879（1 − R = e_HL = 0.3028）と R_128 = 1 − √(4π/128.946) = 0.687823 が、System A の固定プローブ（`Params.r137`、`r128`）と System B の掃引窓の位置を決めていた（論文 §8.1 が自認）。したがって「0.7 付近に特異点」は、調べた場所が 0.7 付近だったことと、そこにも（他のどこにも）稠密に根があることの合成である。

**残る本当の偶然または必然**：cos²(23π/124) = 0.6971779276 と 1 − √(4πα) = 0.6971778792 の差 4.8×10⁻⁸（相対 7×10⁻⁸）。窓内の根の密度（n ≤ 140 で 34 個、間隔 ≈ 5×10⁻⁴）から、無作為な点がこれほど近い根を持つ確率は n ≤ 140 で約 2×10⁻⁴、n ≤ 1000 まで許せば約 10⁻²。注目に値するが、圧倒的ではない。N に直すと 137.036043 と 137.035999 の差 4.4×10⁻⁵（相対 3.2×10⁻⁷、α³ の桁）。

## 5.4 現行 E–M 模型への帰結

- 論文の「ロック」は**時間のアトラクタではなく、固定パラメータのユニタリ交換写像の厳密再帰**。v6・v7 で私が「ロック」と呼んだもの（放射で単一倍音に落ちる）は別の概念で、混同していた。
- 深い谷に必要なのは三つ：(i) 毎節点同じユニタリ交換（位相 2θ）、(ii) 厳密周期性を測る読み出し（2n 標本の平均・振幅・ドリフト）、(iii) パラメータが有理点に乗ること。E–M 模型でこれを作るなら、(i) の 2θ は二チャネルの毎節点の相対位相、(iii) は系自身のパラメータ（J → α）が根に乗るという自己無撞着、(ii) の窓 2n は**外から 124 を選ばないように**決めなければならない。
- α 問題の核心は「なぜ R_phys = 1 − e_HL が根の 7×10⁻⁸ 以内にあるか」と「残差 3.2×10⁻⁷（α³ の桁）は何か」の二つ。
