## 1. 実装（固定点 5 との対応）

| 固定点 5 | プログラム |
|---|---|
| 状態：体 A (a₀..a₃)、体 B (b₀..b₃) の指数、補助状態 δτ、座標時間 T。隠しなし | `a[0..3]`, `b[0..3]`（float）、`dtau`、`T`。ω・ξ・L・a・e・時計は毎節点これらから読む |
| 交換の係数は固定 θ₀ = 23π/124（R = sin²θ₀ = 0.3028） | 定数 `C0, S0`。節点ごとに cos/sin を計算しない |
| 書き戻し 1：z₁ ← z₁ + z₂（乗法更新） | `st[0] += st[2]; st[1] += st[3]`（両体） |
| 書き戻し 2：e^{z₂′} = 2cosθ₀ − e^{−z₂} | `g_new = 2*C0 − exp(−z₂)` → `st[2], st[3] = ln|g_new|, arg g_new`。逆数は指数の符号反転 |
| ω を状態から読む | W′/ω = (G − cosθ₀)W/sinθ₀、2a = \|W\|² + \|W′/ω\|²、ω² = κ/(4a)（固定点 5 §2 の訂正どおり） |
| δτ = θ₀·ω⁻¹、ΔT = ∫\|W\|²（閉じた式）、T に積む | `dtau = THETA0*recip(om)`、`dT = [...]*recip(om)`、`T += dT` |
| 時計は読出し | `x3a = F_a·ΔT`、`x3b = (m_b/m_a)F_b·ΔT`、位相 `x1a, x1b` を mod 2π で積算 |
| T4〜T22：ε の偏微分 × ΔT を関係 (ξ, π, φ) への積和で入れ、(W, G) へ写す | `d_eps_full` → Δξ、Δπ、Δφ → `state_from_relations` → a₀..a₃、b₀..b₃ を書き戻す。一次の摂動 |
| 放射：双極子 W²、Kepler の z̈ で ΔE、ΔL を (ε_K, L) へ入れ、(W, G) へ写す。因子は掛けない | `dE, dL` → ε_K、L を更新 → π を再構成 → `state_from_relations`。読み (a) s_dir、読み (b) 124 節点ごとの戻りは出力のみ |
| 割り算・平方根は反復 | `recip`（Newton、種はビット操作）、`sqrt_newton`。exp/log は指数⇄振幅の境界だけ |
| 二体：重心系で W_A = c_A W、W_B = i c_B W。関係 z = W_A² − W_B² | 初期化で置き、以後は両体を同じ規則で更新。z は毎節点 W_A² − W_B² から読む |

## 4. 予告（走行前に書く。成功条件にしない）
- Kepler 対照：倍精度で一致するはず（厳密写像）。関係 z は 124 節点ごとに厳密に戻る（124θ₀ = 23π、半角は符号が反転し z = W² は戻る）。

### 5.4 読み取り（事実から従うことだけ）
1. **八状態・固定係数・乗法更新で Kepler が厳密。** 隠し状態は無く、q も ω も持たない。交換の係数は定数 θ₀ で、R = 0.3028 が毎節点配る。解像度 124 で足りる。
2. **δτ は補助状態として動いた。** 放射で 4% 縮んだ。これは θ₀ 固定の帰結で、δτ の自己無撞着な値（ロックで決まること）はまだ出ていない。
3. **三位相の整数関係は到達していない。** 関係 z は 124 節点で必ず戻るが、二つの時計は 124 節点ごとに円周上をほぼ一様に散り、同時に戻るのは偶然の頻度（1000 回に 1〜2 回、(0.2/2π)²×1000 ≈ 1 と同じ）。放出に因子を掛けていないので、時計が揃う所で止まる機構は入っていない（固定点 5 §3 の 7、読み (a)(b) 未決）。
4. **1PN のキックは粗い。** 3.5〜4.4% の超過と ε_full の漂い。節点内積分の閉じた式に置き替えるのが筋で、節点を細かくするのではない。
5. v1〜v7 の数値との比較はしていない。
