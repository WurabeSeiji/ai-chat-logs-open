## 2. 状態と読出し

| 状態（8） | 中身 |
|---|---|
| a₀、b₀ | ln 振幅（半角の対象）。r_A = e^{2a₀}、r_B = e^{2b₀}、ξ = r_A + r_B |
| a₁、b₁ | 時計の文字盤（mod 2π） |
| a₂、b₂ | 長さの増分 ln\|g\|（両体で同じ値。読みは幾何平均） |
| a₃、b₃ | 時計の一節点の進み F_A·ΔT、(m_b/m_a)F_B·ΔT |

読出し（すべて現在の八状態から）：𝐏² ← b₃/a₃（反復）；a、ω；\|u\|² = 2a/ξ − 1；Re u = (\|g\|² − cos²θ₀ − sin²θ₀\|u\|²)/(2 sinθ₀cosθ₀)；Im u = +√(\|u\|² − Re u²)；L = 2ωξ Im u；e；E_cycle（cos E = (1 − ξ/a)/e、符号は Re u）；t_cycle = (E − e sin E)/n；ΔT = ∫\|W\|²（閉じた式）× 1/√corr；F_A、F_B；g = cosθ₀ + sinθ₀ u（導出量）。

## 3. 一節点（書き込みはすべて指数への加算 ＝ 乗法更新）

1. a₀ += a₂、b₀ += b₂（長さ）。a₁ += a₃、b₁ += b₃（時計の文字盤。mod 2π）。
2. g′ = 2cosθ₀ − 1/g（複素の積和。1/g は \|g\|⁻²·ḡ）。放射なしなら a₂ = b₂ ← ln\|g′\|。
3. 放射あり：1/a′ = 1/a − 2ΔE/κ、L′ = L(1 + ΔL/L)。次の配位 ξ′ で \|u′\|² = 2a′/ξ′ − 1、Im u′ = L′/(2ω′ξ′)、Re u′ = ±√（符号は交換後の向き）→ a₂ = b₂ ← ln\|g′\|（\|g′\|² = (cosθ₀ + sinθ₀Re u′)² + (sinθ₀Im u′)²）。
4. a₃ ← a₃·(F_A′ΔT′)/(F_AΔT)、b₃ ← b₃·(F_B′ΔT′)/(F_BΔT)（次の配位の値への因子）。

v1（ω を不変量から直接読む）では 10⁻¹²〜10⁻¹⁹ だった揺れが 10⁻⁷〜10⁻¹⁰ になった。原因は Q1：エネルギーを時計の率の比 b₃/a₃ から読むので、情報が F_B/F_A − 1 ≈ 2.7×10⁻⁵ の中にあり、倍精度では a が節点ごとに 10⁻¹¹ の桁で揺れる。時間（E_cycle、t_cycle）は状態から読めて閉じた式と一致する。

### 6.2 全項、放射なし（12400 節点 ＝ 2300 周）
円：a、L、ε_K は 10⁻⁹ 相対で一定。1PN 係数 corr = 0.99992011（動径の振動数が Kepler より 8×10⁻⁵ 低い。ΔT に 1/√corr）。離心：同様に一定、corr = 0.99993137。近点移動は軌道角が無いので現れない（ゲージ）。

### 6.5 読み取り
1. 時間は状態から読めた：ΔT、周期内の位置と時刻、時計の文字盤。経過時間 T の変数は無く、要らなかった。
2. エネルギーを時計の率に載せると、倍精度の限界が 10⁻¹¹ に落ちる。これは「x₃ 側がノルムを配る」表現に固有で、結果の読み方（円の e の増加は雑音）に注意が要る。
3. 放射と 1PN は乗法更新で入り、E–M の向き（円化、δτ の縮み）が出る。三位相の同時再帰は偶然の頻度で、放出が消える条件は源の定義の問題のまま（木原氏の決定どおり因子は掛けない）。
