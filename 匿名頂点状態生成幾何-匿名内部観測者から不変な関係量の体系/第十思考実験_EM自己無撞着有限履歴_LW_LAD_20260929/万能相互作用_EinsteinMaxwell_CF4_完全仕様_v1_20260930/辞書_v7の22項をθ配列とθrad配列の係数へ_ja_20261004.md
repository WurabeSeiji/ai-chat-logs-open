## 0. 書き直しの形（結論を先に）

- 状態：a、b それぞれ四つの実数 x = (x₀, x₁, x₂, x₃) = (ln A, φ, Δln A, Δφ)。z₁ = x₀ + i x₁、z₂ = x₂ + i x₃。自由進行は z₁ ← z₁ + z₂。
- E–M の入力（ξ、π、m、s_a、s_b、時計因子 F_a、F_b）は、すべて八つの指数の**差と比**で読む（§1）。
- 固定点 2 の反対称 6 面のうち、E–M（1PN、スピンは軌道軸にそろう）が使うのは六つすべてで、役割は次のとおり（§2）：a↔b 交換面（θ、軌道）、呼吸面（θ_X）、a の時計面（η_a = −ln F_a、双曲角）、b の時計面（η_b）、スピン面 ×2（そろったスピンでは角 0）。
- ε の 22 項は、λ = x₀ᵇ − x₀ᵃ の倍音 e^{−pλ}（p = 0…6）に、増分の冪とスピンを掛けた積和に書き換わる（§3）。9/29 の「倍音一回積和」の倍音が、ここでは関係の指数 λ の倍音になる。
- 各項がどの角に入るかは ε の偏微分で決まる：∂ε/∂m → θ、∂²ε/∂ξ²・∂²ε/∂π² → θ_X、v²・U → η_a、η_b、スピン項 → スピン面（§3 の表の右三列）。
- θ_rad は v7 の ALD と Burke–Thorne の放射パワーを「一節点で対から出る割合」に直したもので、λ の倍音としては p = 6（双極子）と p = 8（四重極）（§4）。
- 二つの角の比 θ/θ_X = γ（近点移動）だけが時計に依らない観測量（v7 §4 と同じ）。

### 4.3 規格化［置4］：N_対 に何を当てるか

| 案 | N_対 | 円軌道・v7 の節点幅での sin²θ_rad | 結果 |
|---|---|---|---|
| A | 対の全ノルム（静止エネルギー 1/ν に相当） | ≈ 2×10⁻¹⁵ | 対のノルムはほとんど動かず、束縛（閉塞のずれ W²）の変化が別の経路で要る。「同じ交換一つ」で書けない |
| **B** | 対の束縛エネルギー \|ε\|（ε の 22 項の値そのもの） | f × 1.400×10⁻⁷（θ_rad = 3.74×10⁻⁴ rad） | 一周（23.25 節点）で束縛の 3.26×10⁻⁶ が出る。古典の放射崩壊率と同じ桁。交換で動く量（配列の対称の組）が束縛そのものになる |

B を置く。理由：固定点 1 §3 の辞書で「交換で動くノルム」に当てたのは E–M の相互作用エネルギー（重力型・クーロン型の二項）であって静止エネルギーではないから。A だと放射が「同じ交換」で書けなくなる。

### 4.4 θ と θ_rad の比

円軌道で sin²θ_rad / sin²θ = 7.7×10⁻⁶（f = 1）。θ_rad は θ の約 2.8×10⁻³。ロックで S₁、S₂ が方向を失えば \|D″\|、\|Q⃛\| → 0 で θ_rad → 0（固定点 1 §7）。背景からの受け取り（気づき文書 §1.4）は本辞書の外（E–M の 22 項に相手がない）。

## 6. 本辞書で決まらないこと（記録のみ。次の文書の課題）

1. **ノルムとエネルギー、振幅と長さ。** 固定点 1 §3「交換はノルム N_A + N_B を保存 ↔ E–M はエネルギーを保存」と、固定点 2 §2「振幅の対数差 ＝ 距離」を同時に取ると、波 e^{z₁} のノルム e^{2x₀} は長さの二乗であってエネルギーではない。本辞書は距離を x₀ の差、エネルギーを ε（配列の読み出しの関数）に置き、交換で保存される「ノルム」が八成分のどこに当たるかを決めていない。
   - A：ノルム ＝ e^{2x₀}（長さの二乗）とすると、呼吸で ξ が動く間 a_a² + ξ² は保存せず、固定点 1 §3 の保存の対応が壊れる。
   - B：エネルギーは位相の進み率（v7 §2.2「E ＝ 位相の進み率 ×2g」はすでに枠組みの中の対応）なので、交換で保存・配分されるノルムは増分の成分 x₃（位相の増分）に当たる。四成分が (x₀, x₂) ＝ 長さとその率、(x₁, x₃) ＝ 位相とその率、に割れ、「振幅の交換」は長さの側、「エネルギーの交換」は位相の率の側になる。質量比 ＝ x₃ の比（§1.2）とも整合する。B にした方がよい。ただしこれは次の文書で固定してから使う。
   - **10/4 解決**：木原氏が B を決定。固定点 3（`固定点_四成分の分割と位相の進み率としてのエネルギー_ja_20261004.md`）で固定。本辞書はその上で読む（長さの側：ξ、π、呼吸面、放射源の形。時計の側：Δθ_k、質量比、F、交換面①が動かすノルム）。
2. **引き込みの条件。** §3.3 の最終段落のとおり、ロックは x₃ᵃ·∂ε/∂m の有理条件になった。どの読み出しの θ がそこへ引き込むかは本辞書の外（固定点 1 §5）。
3. **一般の呼吸での θ_X。** §2 の θ_X は円軌道近傍の式。離心軌道では v7 §2.1 の作用–角変数の積分で Ω_X を取るのと同じ計算が要るが、表を持たないので節点ごとに (λ, Δλ) から読む式が要る。
4. **背景からの受け取り。** E–M の 22 項に相手がないので本辞書に入らない（気づき文書 §4）。
