# 3. 運動方程式（連続形。離散化は §6）

## 3.1 波の倍音 ψ_m（Hamilton 流）

\[
\boxed{
\frac{d\psi_m}{d\theta_a}=-\,i\,\frac{\mu}{2m_a}\,\frac{\partial\varepsilon}{\partial\psi_m^*}
}
\]

（a_a/ħ = 1/(2m_a)。固有状態の位相の進みは ε_m μ/(2m_a) rad／内部 rad。）

\[
\frac{\partial\varepsilon}{\partial\psi_m^*}
=\Big[\frac{2(m_a/\mu)^2m^2}{\xi^2}+\varepsilon_{{\rm SR},m}+\varepsilon_{{\rm D},m}+\varepsilon_{{\rm SO},m}+\varepsilon_{{\rm EIH},m}\Big]\psi_m
+\big(\kappa_C-\kappa_G\big)\sum_n K_n(\xi)\,c_n\,\psi_{m-n}
+F^{\rm RR}_m
\]

ε_{·,m} は §1 の倍音 m あたりの係数（|ψ_m|² の前）。全倍音に共通の項（−κ/ξ、ε_SS、ε_Q2、ε_M2）は位相を一様に進めるだけで、相対位相に効かない。

## 3.2 呼吸 ξ

\[
\boxed{\xi''=-\frac{\partial\varepsilon}{\partial\xi}}
\]

∂/∂ξ は §1 の全項と K_n(ξ) の ξ 依存（∂(ξK_n)/∂ξ = 1/(πξ)）を含む。

## 3.3 スピン

\[
\frac{d\hat s_A}{d\theta_a}=a_a\left(\frac{\partial H}{\partial\mathbf S_A}\right)\times\hat s_A
\]

H_SO = A_A L·S_A の形なので、ŝ_A は軌道軸の周りを歳差する。s_A = ±1（軸にそろう）では歳差なし。A_a = α(1 + 2m_a/m_b)·(2(m_a/μ)/ξ³)·(μ/J_a)（§1 のスピン–軌道の係数を L·S_a で割ったもの）。

## 3.4 内部位相 θ_b

\[
\frac{d\theta_b}{d\theta_a}=\frac{m_b}{m_a}
\]

## 3.5 放射と反作用

双極子（無次元、複素ベクトル）：D ≡ ξ c_1。四重極：Q ≡ ξ² c_2。

電磁の放射反作用の場 E_RR = (2/3)(Q_a/a_a²) D‴（‴ = d³/dθ_a³）が a の要素に働く。倍音方程式への寄与：

\[
\boxed{
F^{\rm RR,EM}_m=-\,f\,\frac{\kappa_C}{3}\,\xi\left[D'''\,\psi_{m+1}+\overline{D'''}\,\psi_{m-1}\right]
}
\]

重力（Burke–Thorne、跡なし四重極、x^ix^jI^{(5)}_{ij} = (μξ²/(2a_a))Re(Q^{(5)}e^{2iφ})）：

\[
\boxed{
F^{\rm RR,GW}_m=+\,f\,\frac{\alpha\,m_a^2}{90}\,\xi^2\left[Q^{(5)}\,\psi_{m-2}+\overline{Q^{(5)}}\,\psi_{m+2}\right]
}
\]

放射パワー（読み出し）：P_EM/μ = (2/3)κ_C|D‴|²/ξ·ξ … 具体的には P_EM = (2/3)(Q_a²/a_a)|D‴|²/a_a、P_GW = (1/5)(μ²a_a⁴/a_a⁵)|Q^{(5)}|²·(1/4)。

**源は c_1、c_2 だけに依存する。** 単一の倍音 ψ_m だけの状態（一様なリング）では c_1 = c_2 = 0 で、放射も反作用もゼロ。放射が出るのは隣り合う倍音が重なるとき（c_1 = Σψ_kψ*_{k−1} ≠ 0）で、その回転は倍音間の位相差の進み（ε_{k} − ε_{k−1}）μ/(2m_a) で決まる。これが「位相がロックすると方向の区別がなくなり放出が止まる」の式である。

B1〜B3：f = 0、設定値、1（STATUS §7.2）。

# 4. 円軌道と α の公理（初期値の確認）

一様なリング（ψ_m = δ_{m,1}）では c_n = δ_{n0}、ε = ½ξ′² + 2(m_a/μ)²/ξ² − κ/ξ + 定数。円の条件 ∂ε/∂ξ = 0：

\[
\xi_0=\frac{4(m_a/\mu)^2}{\kappa}\ \approx\ \frac{2}{\alpha},\qquad
v_0=\xi_0\rho_1=\frac{2(m_a/\mu)}{\xi_0}\approx\alpha,\qquad
\frac{L}{J_a}=\frac{\mu}{m_a}\xi_0^2\rho_1=2
\]

数値：ξ₀ = 274.25（2/α = 274.07）、ρ₁ = 2.6606×10⁻⁵（α²/2 = 2.6626×10⁻⁵）、2(m_a/μ)²/ξ₀² = 2.6620×10⁻⁵ = ½v₀²。**v/c = α と L = 2J は、ħ = 2J_a の同定と ξ₀ から従う。** 一周あたりの内部位相の進みは 2π/ρ₁ = 2/α² ≈ 3.7558×10⁴ サイクル（整数ではない。有理になるかが読み出し）。

# 5. 注意：自己相互作用の大きさ（木原氏の判断が要る点）

a の波を相対角度の上に広げると、E–M はその電荷分布の**自己エネルギー**を要求する。一様なリング（c_0 = 1 のみ）での大きさは

\[
\frac{\varepsilon_{\rm self}}{\varepsilon_{\rm Coulomb}}=\frac{\xi K_0(\xi)}{2}=\frac{\ln(8\xi)}{2\pi}\approx1.22
\]

で、束縛エネルギーと同程度である（古典電子の自己エネルギー問題そのもの）。量子力学では単一電子の確率分布に自己相互作用はなく、水素の実測はそれで合う。E–M に厳密に従えばこの項は入り、入れれば水素型の準位は実測から大きくずれる。

第七思考実験（aa・bb の自己相互作用、C_self = 1 − λ²）でこの項をどう扱ったかとの整合、および本書で ψ_m を「電荷の分布」と読むか「位相の分布（二次の関係からだけ源を作る）」と読むかは、木原氏の判断を要する。読み方によって (κ_C − κ_G)Σ K_n c_n ψ_{m−n} の項を入れるか外すかが決まる。本書は E–M に従って**入れた形**で書いてある。
