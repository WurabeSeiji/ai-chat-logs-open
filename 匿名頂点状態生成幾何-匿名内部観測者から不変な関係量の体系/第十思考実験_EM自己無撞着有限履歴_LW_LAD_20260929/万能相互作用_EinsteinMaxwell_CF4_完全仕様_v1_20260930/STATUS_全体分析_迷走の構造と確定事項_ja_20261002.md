# 7. 追記（2026-10-02）：背景ゲージの気づき

## 7.1 木原氏の解釈（放射の行き先と回転の基準）

背景時空は「ある意味置く」。a, b から十分に遠く、視野角の差も距離も測れない遠方に、隙間なく物体（吸収体）が全方向に対称に並んでいる。放出された重力波・電磁波は無限に遠くまで伝わってその物体を振動させる。これで放射先がない問題は解消し、放射は実在してエネルギーは出て行く。しかし吸収体は全方向に対称で視野角差がないので、**回転を判定するゲージにはならない**。

したがって電磁波も重力波も放出されるが、**a, b の位相がロックすると方向の区別がなくなり、放出が止まる**。これが安定の機構である。読み出せるのは、a の位相、b の位相、a と b の関係が生む全体の位相の進みの**差**だけで、これらが整数関係にあれば何も変化が読み出せない（量子力学の定常状態と同じ構造）。

これは 9/30 23:59 の B3「全空を覆う無限体が無限距離にある。実際の宇宙はこれに近い」そのものである。

## 7.2 B1〜B3 の循環（確認済み）

木原氏の B1 の定義は「なにもしない。二体なら放射する相手がいないので、放射エネルギーはすべて二体に戻って吸収されるしかない。なにもない空間にそのまま反射し続ける写像は無理がある」。B2 は「吸収率 f を状態に置き、放射量と積をとる」（10/1 01:03）。

## 7.3 水素の安定性

# 8. 追記（2026-10-02）：初期の円軌道と二つの不変量

## 8.1 基準のない系での円軌道

z = a + ib と置くと |z|² = a² + b² = r²。r は振幅そのもので、何に対しても相対的でない。位相 θ がフリーズしていても、r は回転半径として読める。円軌道の「半径」は基準のない系でも定義できる。

位相 θ の増分は、固定座標軸に対してではなく、系の中の別の位相に対してだけ意味を持つ。この系で θ と比べられる位相は a の内部の位相 θ_a と b の内部の位相 θ_b だけである。観測できる量は

　r、θ − θ_a、θ − θ_b、θ_a − θ_b（とその整数結合）

であって θ 単独ではない。「31 刻みで元に戻る」も、θ ではなく相対位相についての条件である。相対位相がすべて止まり r が一定なら、関係量の変化はゼロで、円軌道は「回っている」のではなく定常状態である。

## 8.2 α を一次の入力にする

系に最初から入っている速さは光円錐 c だけである（場の方程式の構造。外の枠ではない）。

　v/c = α

は「半径 r を光が渡る時間の間に位相 θ が進む比」であり、固定座標軸なしで定義できる。これまで J = ħ/2 = 9/(2α)、L₀ = 2J から v₀ ≈ α が出ていたが、逆向きにして α を一次の入力にする。入力は電荷素量、質量比、c、α の四つ。J、L₀、Bohr 半径相当の r、Ω/ω_int = α²/2 はそこから従う。「何に対して回転しているか」の答えは、光円錐と a, b の内部時計に対して。

## 8.3 二つの不変量（木原氏の公理）

- **光速不変**：光円錐 c はどの状態から見ても同じ。光に静止系はない。
- **電子角速度不変**：電子の位相の回転は、r を光が渡る時間あたり α。**停止した電子は存在しない**（電子の位相に静止系はない）。

これは物理定数の階層（c と α が幾何学的な不変量、ħ・G・e は派生量）を、この実験の初期条件として書いたものである。回転の基準がないことは障害ではなく、この公理が成り立つ条件そのもの（基準があれば「基準に対して止まった電子」が定義できてしまう）。

## 8.4 電子角速度不変は光速不変より弱い

| | 光速不変 | 電子角速度不変 |
|---|---|---|
| 成立する範囲 | すべての状態で常に | 準安定状態に入ったときだけ |
| 性質 | 運動学的な不変量 | 動力学が選ぶ不変量（定常波として見える状態の性質） |
| 見えるまでの条件 | 一瞬でよい | 31・124 サイクルの倍数の繰り返しが要る |

電子角速度不変は公理というより動力学の固定点の性質である。系が繰り返しの中で位相を揃え、定常波として読めるようになったとき、はじめて v/c = α が成り立つ。過渡状態では成り立たない。

標準理論でも同じ形：量子力学で α が現れるのは束縛した定常状態の性質（Bohr 軌道の v = αc、準位の構造）で、自由電子の速さは α と無関係。有限位数共鳴では鋭いピークは有限位数根の上だけに立ち、読むには 2n 標本が要る。

## 8.5 初期の円軌道の問題の帰結

初期値は v/c = α を正確に置く必要がなく、α の近くに置けばよい。読むのは、E–M から組んだ関係の動力学が 31・124 サイクルの繰り返しの中で v/c = α に揃えるか、揃えないか、どの比に揃うか（＝ロックは結果）。読むために必要な最小の走行長は 124 サイクルの倍数で決まる。

7.5 の書き直しの条件に、次を加える：

- 初期の円軌道は r（振幅）、v/c ≈ α（r の光の渡りあたりの位相の進み）、内部時計との比 Ω/ω_int で置く。固定座標軸に対する Δφ では置かない。

# 9. 追記（2026-10-02）：回転の基準は全体のモード。振動は最低二つ要る

## 9.1 問い

基準のない系で、回転とは何に対する位相差か。a, b 二体で、全体振動と局所振動のように最低二つの振動が必要ではないか（木原氏）。

## 9.2 答え（有限位数共鳴の論文にすでにある構造）

二チャネル a, b を対称と反対称に分ける：

　X = (a + b)/√2（全体の振動）、　Y = (a − b)/√2（相対の振動）

交換作用素 U_R の固有値は λ_s = 1（X は位相が進まない）、λ_a = −e^{2iθ}（Y は毎段 ω 進む）。読み出し S_j = 0.02 cos(jω) は X と Y の干渉項である。

**回転として見えるのは、相対モード Y の位相が、位相の進まない全体モード X に対してずれていくこと。** X が基準、Y が回る。a 単独・b 単独は基準にならない。基準は a と b の和（全体）、回るのは差（相対）。

一つの振動では位相差が作れないので回転は定義できない。二つあれば、その位相差の進みが回転である。これが「全体振動と局所振動の二つが要る」の正体。

## 9.3 二体への当てはめ

- 全体のモード：重心の波（質量で重みを付けた a と b の和）。系全体の振動＝共通時計の担い手。
- 相対のモード：a − b の波。軌道の運動。
- 回転 = 相対モードの位相が全体モードの位相に対してずれる速さ。
- 円軌道 = 相対モードの振幅 |Y| = r が一定で、位相差だけがずれる状態。
- ロック = 位相差の進みが有理（λ_a^n = 1）で、n 段ごとに干渉項が元に戻る。この間、正味の変化はない。

# 10. 追記（2026-10-02）：全体モード X ＝ 呼吸モード

## 10.1 同定

§9 の全体モード X（位相が進まない、λ_s = 1、回らない振動）を幾何学的に見ると、形を変えずに大きさだけが伸び縮みする振動、すなわち**呼吸モード**（距離 r の伸び縮み、ℓ = 0）である。同じものを別の写像で見ている。全体時計は、幾何学的には呼吸モードの位相である。

距離 r を振幅として読むと、絶対の長さは測れなくても r(t₁)/r(t₂) の比と振動の位相は計量できる（スケール不変：比だけが物理）。回転の角度は基準の方向がないので測れないが、呼吸は方向を要しない。

## 10.2 E–M 側の支え

呼吸モード（単極子の振動）は放射しない。重力では Birkhoff の定理（球対称の振動は重力波を出さない）、電磁では単極子放射が存在しない。したがって全体時計は、刻んでも系からエネルギーを持ち出さない振動である。放射するのは相対モード Y（回転、双極子・四重極）だけで、§9 の役割分担（X が基準、Y が回って放射する）と一致する。

標準理論での対応：Sommerfeld の楕円軌道では、動径（呼吸）の周期と角度（回転）の周期の比が γ = 1/√(1 − α²/k²) ≈ 1 + α²/(2k²) で、これが微細構造の起源。呼吸の時計と回転の時計の比に α² が現れる。

## 10.3 注意

完全な円軌道（ロックした定常状態）では呼吸が止まり、全体時計は刻まない。その状態で時間を読むのは内部時計 θ_a、θ_b である。これは「ロックすると変化が読み出せない」と矛盾しない。呼吸の時計が働くのは、ロックに向かう途中（離心率がある間）。

## 10.4 書き直しの条件への追加

# 12. 吸収体の要素数 N と重心の並進（10/6 の決定）

前提の確認（`Grok移行実験/exchange_rel_20261005` の水素一式を対照物として議論した結果）：

- 背景時間は要らない。系の時間は事象（放出・吸収）の列としてしか数えられず、一つの固有状態の全体位相は読めないので、事象と事象の間に系自身の時間は無い（待ち時間の指数分布の無記憶性 = 積の更新に時計が無いこと）。
- 背景空間も要らないが、**重心の並進は吸収体に対してしか定義できない**。等方・無限遠・完全吸収で要素に区別の無い殻（B3 の現状）では方向という関係量が無く、相対位置・速度の向き・反跳は定義不能。今の一式はこれと整合して重心を吸収体の静止系に固定している（並進については M = ∞。放出光のエネルギーが ΔE ちょうどになるのはその帰結で、反跳シフト 13.4 MHz と Doppler 幅は記録に無い）。方向が無くてもスカラー（反跳エネルギー、速さによる線の広がり）は残る。
- 一様な並進そのものは原理的に定義できず、それが正しい（相対性原理）。重心の位置も読めない。一般相対論でも孤立系の運動量・重心は無限遠の漸近構造（ADM・Bondi、BMS 群）にしか定義されず、吸収体はその漸近領域に当たる。

## 12.1 並進を入れる最小の構造

1. 吸収体を、等方に全球を覆う N 個の**区別できる（匿名のままの）等重みの要素**にする。「どの要素が受け取ったか」が記録に加わり、これが方向の定義。視野角（要素の立体角 4π/N）は要るが、座標と要素間の角度は要らない。角度は二光子対の角相関 1 + cos²θ_ij と重心速度の双極子 cos θ_ij から**読まれる**（球の幾何は記録から組み上がり、前提ではない）。
2. 重心に有限の慣性 M = m_a + m_b を与える。読める量は無次元比だけで、一回の放出あたり Δ(v/c) = ħω/(Mc²)、反跳シフト ΔE/(2Mc²)。必要な比 ΔE/((m_a+m_b)c²) は既存の m_a/m_b と α で決まり、新しい入力は無い。吸収体の質量は無限大のまま（吸収体の静止系が慣性系、という漸近条件）。
3. これで読めるもの：吸収体に対する重心速度の向きと大きさ、放出ごとの反跳、対の角相関。読めないまま：重心の位置、一様並進。

## 12.2 N の決め方と決定

N は手で選ぶ数ではなく、吸収体の半径 R と区別できる最小要素 d の比の二乗 N ≈ 4π(R/d)²。物理の水素（吸収体 = 地平線 R_H ≈ 1.3×10²⁶ m）では、d = 波長で Lyman-α 1.5×10⁶⁷・21 cm 5×10⁵⁴、d = Planck 長で 4π(R_H/l_P)² ≈ 7×10¹²²（面積則、上限）。体積の 10¹⁸⁰ は殻には自然でない。

N は方向分解能 1/√N としてしか記録に入らない。水素 n ≤ 5 の記録で方向分解能が律速になる上限は、最も鋭い 21 cm 線（相対線幅 Γ/ω = 3.2×10⁻²⁵）と反跳速度 v/c = 1.1×10⁻⁸ から δθ ≈ 3×10⁻¹⁷、**N_sat ≈ 1.5×10³⁴**。これ以上では記録に差が出ない。小さい N は要素の離散性と割り当ての帳簿が物理に混ざって計算を複雑にするので、十分大きくとって離散化の床を結果から消すのが正しい設計（時間側で 124 節点の離散性が結果に入るのと対照的）。

## 12.3 付随して確認したこと（同日の議論）

- 放出記録 = 事象の列（時刻、量子の種類、振動数、一個か対か、方向と偏光）。準位のラベルと占有確率は帳簿で、外へ出るのは関係量だけ。同じ記録を与える二つの模型は区別できない（「同じ結果の別写像」の操作的な形。交換 U_R が再現すべきは状態でなく記録）。
- 二光子（2s→1s、8.2206 s⁻¹、ΔF = 0）は一つの事象で二個が同時に出る対。和の振動数だけ鋭く（幅 1.3 Hz）、個々は連続（可干渉時間 6×10⁻¹⁷ s）。一つの光子は時空の点を定義せず、同じ事象から出た対が「同時」という関係として原点の共有を外に出す。干渉するのも対（Franson）。偏光相関は Perrie–Duncan–Beyer–Kleinpoppen 1985（重水素 2s→1s）で Bell 不等式の破れが実測済み。
