# 7. 追記（2026-10-02）：背景ゲージの気づき

## 7.1 木原氏の解釈（放射の行き先と回転の基準）

背景時空は「ある意味置く」。a, b から十分に遠く、視野角の差も距離も測れない遠方に、隙間なく物体（吸収体）が全方向に対称に並んでいる。放出された重力波・電磁波は無限に遠くまで伝わってその物体を振動させる。これで放射先がない問題は解消し、放射は実在してエネルギーは出て行く。しかし吸収体は全方向に対称で視野角差がないので、**回転を判定するゲージにはならない**。

したがって電磁波も重力波も放出されるが、**a, b の位相がロックすると方向の区別がなくなり、放出が止まる**。これが安定の機構である。読み出せるのは、a の位相、b の位相、a と b の関係が生む全体の位相の進みの**差**だけで、これらが整数関係にあれば何も変化が読み出せない（量子力学の定常状態と同じ構造）。

これは 9/30 23:59 の B3「全空を覆う無限体が無限距離にある。実際の宇宙はこれに近い」そのものである。

## 7.2 B1〜B3 の循環（確認済み）

木原氏の B1 の定義は「なにもしない。二体なら放射する相手がいないので、放射エネルギーはすべて二体に戻って吸収されるしかない。なにもない空間にそのまま反射し続ける写像は無理がある」。B2 は「吸収率 f を状態に置き、放射量と積をとる」（10/1 01:03）。

## 7.3 水素の安定性

# 8. 追記（2026-10-02）：初期の円軌道と二つの不変量

## 8.1 基準のない系での円軌道

z = a + ib と置くと |z|² = a² + b² = r²。r は振幅そのもので、何に対しても相対的でない。位相 θ がフリーズしていても、r は回転半径として読める。円軌道の「半径」は基準のない系でも定義できる。

位相 θ の増分は、固定座標軸に対してではなく、系の中の別の位相に対してだけ意味を持つ。この系で θ と比べられる位相は a の内部の位相 θ_a と b の内部の位相 θ_b だけである。観測できる量は

　r、θ − θ_a、θ − θ_b、θ_a − θ_b（とその整数結合）

であって θ 単独ではない。「31 刻みで元に戻る」も、θ ではなく相対位相についての条件である。相対位相がすべて止まり r が一定なら、関係量の変化はゼロで、円軌道は「回っている」のではなく定常状態である。

## 8.2 α を一次の入力にする

系に最初から入っている速さは光円錐 c だけである（場の方程式の構造。外の枠ではない）。

　v/c = α

は「半径 r を光が渡る時間の間に位相 θ が進む比」であり、固定座標軸なしで定義できる。これまで J = ħ/2 = 9/(2α)、L₀ = 2J から v₀ ≈ α が出ていたが、逆向きにして α を一次の入力にする。入力は電荷素量、質量比、c、α の四つ。J、L₀、Bohr 半径相当の r、Ω/ω_int = α²/2 はそこから従う。「何に対して回転しているか」の答えは、光円錐と a, b の内部時計に対して。

## 8.3 二つの不変量（木原氏の公理）

- **光速不変**：光円錐 c はどの状態から見ても同じ。光に静止系はない。
- **電子角速度不変**：電子の位相の回転は、r を光が渡る時間あたり α。**停止した電子は存在しない**（電子の位相に静止系はない）。

これは物理定数の階層（c と α が幾何学的な不変量、ħ・G・e は派生量）を、この実験の初期条件として書いたものである。回転の基準がないことは障害ではなく、この公理が成り立つ条件そのもの（基準があれば「基準に対して止まった電子」が定義できてしまう）。

## 8.4 電子角速度不変は光速不変より弱い

| | 光速不変 | 電子角速度不変 |
|---|---|---|
| 成立する範囲 | すべての状態で常に | 準安定状態に入ったときだけ |
| 性質 | 運動学的な不変量 | 動力学が選ぶ不変量（定常波として見える状態の性質） |
| 見えるまでの条件 | 一瞬でよい | 31・124 サイクルの倍数の繰り返しが要る |

電子角速度不変は公理というより動力学の固定点の性質である。系が繰り返しの中で位相を揃え、定常波として読めるようになったとき、はじめて v/c = α が成り立つ。過渡状態では成り立たない。

標準理論でも同じ形：量子力学で α が現れるのは束縛した定常状態の性質（Bohr 軌道の v = αc、準位の構造）で、自由電子の速さは α と無関係。有限位数共鳴では鋭いピークは有限位数根の上だけに立ち、読むには 2n 標本が要る。

## 8.5 初期の円軌道の問題の帰結

初期値は v/c = α を正確に置く必要がなく、α の近くに置けばよい。読むのは、E–M から組んだ関係の動力学が 31・124 サイクルの繰り返しの中で v/c = α に揃えるか、揃えないか、どの比に揃うか（＝ロックは結果）。読むために必要な最小の走行長は 124 サイクルの倍数で決まる。

7.5 の書き直しの条件に、次を加える：

- 初期の円軌道は r（振幅）、v/c ≈ α（r の光の渡りあたりの位相の進み）、内部時計との比 Ω/ω_int で置く。固定座標軸に対する Δφ では置かない。

# 9. 追記（2026-10-02）：回転の基準は全体のモード。振動は最低二つ要る

## 9.1 問い

基準のない系で、回転とは何に対する位相差か。a, b 二体で、全体振動と局所振動のように最低二つの振動が必要ではないか（木原氏）。

## 9.2 答え（有限位数共鳴の論文にすでにある構造）

二チャネル a, b を対称と反対称に分ける：

　X = (a + b)/√2（全体の振動）、　Y = (a − b)/√2（相対の振動）

交換作用素 U_R の固有値は λ_s = 1（X は位相が進まない）、λ_a = −e^{2iθ}（Y は毎段 ω 進む）。読み出し S_j = 0.02 cos(jω) は X と Y の干渉項である。

**回転として見えるのは、相対モード Y の位相が、位相の進まない全体モード X に対してずれていくこと。** X が基準、Y が回る。a 単独・b 単独は基準にならない。基準は a と b の和（全体）、回るのは差（相対）。

一つの振動では位相差が作れないので回転は定義できない。二つあれば、その位相差の進みが回転である。これが「全体振動と局所振動の二つが要る」の正体。

## 9.3 二体への当てはめ

- 全体のモード：重心の波（質量で重みを付けた a と b の和）。系全体の振動＝共通時計の担い手。
- 相対のモード：a − b の波。軌道の運動。
- 回転 = 相対モードの位相が全体モードの位相に対してずれる速さ。
- 円軌道 = 相対モードの振幅 |Y| = r が一定で、位相差だけがずれる状態。
- ロック = 位相差の進みが有理（λ_a^n = 1）で、n 段ごとに干渉項が元に戻る。この間、正味の変化はない。

# 10. 追記（2026-10-02）：全体モード X ＝ 呼吸モード

## 10.1 同定

§9 の全体モード X（位相が進まない、λ_s = 1、回らない振動）を幾何学的に見ると、形を変えずに大きさだけが伸び縮みする振動、すなわち**呼吸モード**（距離 r の伸び縮み、ℓ = 0）である。同じものを別の写像で見ている。全体時計は、幾何学的には呼吸モードの位相である。

距離 r を振幅として読むと、絶対の長さは測れなくても r(t₁)/r(t₂) の比と振動の位相は計量できる（スケール不変：比だけが物理）。回転の角度は基準の方向がないので測れないが、呼吸は方向を要しない。

## 10.2 E–M 側の支え

呼吸モード（単極子の振動）は放射しない。重力では Birkhoff の定理（球対称の振動は重力波を出さない）、電磁では単極子放射が存在しない。したがって全体時計は、刻んでも系からエネルギーを持ち出さない振動である。放射するのは相対モード Y（回転、双極子・四重極）だけで、§9 の役割分担（X が基準、Y が回って放射する）と一致する。

標準理論での対応：Sommerfeld の楕円軌道では、動径（呼吸）の周期と角度（回転）の周期の比が γ = 1/√(1 − α²/k²) ≈ 1 + α²/(2k²) で、これが微細構造の起源。呼吸の時計と回転の時計の比に α² が現れる。

## 10.3 注意

完全な円軌道（ロックした定常状態）では呼吸が止まり、全体時計は刻まない。その状態で時間を読むのは内部時計 θ_a、θ_b である。これは「ロックすると変化が読み出せない」と矛盾しない。呼吸の時計が働くのは、ロックに向かう途中（離心率がある間）。

## 10.4 書き直しの条件への追加

# 12. 吸収体の要素数 N と重心の並進（10/6 の決定）

前提の確認（`Grok移行実験/exchange_rel_20261005` の水素一式を対照物として議論した結果）：

- 背景時間は要らない。系の時間は事象（放出・吸収）の列としてしか数えられず、一つの固有状態の全体位相は読めないので、事象と事象の間に系自身の時間は無い（待ち時間の指数分布の無記憶性 = 積の更新に時計が無いこと）。
- 背景空間も要らないが、**重心の並進は吸収体に対してしか定義できない**。等方・無限遠・完全吸収で要素に区別の無い殻（B3 の現状）では方向という関係量が無く、相対位置・速度の向き・反跳は定義不能。今の一式はこれと整合して重心を吸収体の静止系に固定している（並進については M = ∞。放出光のエネルギーが ΔE ちょうどになるのはその帰結で、反跳シフト 13.4 MHz と Doppler 幅は記録に無い）。方向が無くてもスカラー（反跳エネルギー、速さによる線の広がり）は残る。
- 一様な並進そのものは原理的に定義できず、それが正しい（相対性原理）。重心の位置も読めない。一般相対論でも孤立系の運動量・重心は無限遠の漸近構造（ADM・Bondi、BMS 群）にしか定義されず、吸収体はその漸近領域に当たる。

## 12.1 並進を入れる最小の構造

1. 吸収体を、等方に全球を覆う N 個の**区別できる（匿名のままの）等重みの要素**にする。「どの要素が受け取ったか」が記録に加わり、これが方向の定義。視野角（要素の立体角 4π/N）は要るが、座標と要素間の角度は要らない。角度は二光子対の角相関 1 + cos²θ_ij と重心速度の双極子 cos θ_ij から**読まれる**（球の幾何は記録から組み上がり、前提ではない）。
2. 重心に有限の慣性 M = m_a + m_b を与える。読める量は無次元比だけで、一回の放出あたり Δ(v/c) = ħω/(Mc²)、反跳シフト ΔE/(2Mc²)。必要な比 ΔE/((m_a+m_b)c²) は既存の m_a/m_b と α で決まり、新しい入力は無い。吸収体の質量は無限大のまま（吸収体の静止系が慣性系、という漸近条件）。
3. これで読めるもの：吸収体に対する重心速度の向きと大きさ、放出ごとの反跳、対の角相関。読めないまま：重心の位置、一様並進。

## 12.2 N の決め方と決定

N は手で選ぶ数ではなく、吸収体の半径 R と区別できる最小要素 d の比の二乗 N ≈ 4π(R/d)²。物理の水素（吸収体 = 地平線 R_H ≈ 1.3×10²⁶ m）では、d = 波長で Lyman-α 1.5×10⁶⁷・21 cm 5×10⁵⁴、d = Planck 長で 4π(R_H/l_P)² ≈ 7×10¹²²（面積則、上限）。体積の 10¹⁸⁰ は殻には自然でない。

- **符号を入力にした数値解法と対照実験**：準位を閉じた式でなく径方向 Dirac 方程式の数値解で作る一般の解法を組み、水素（s = −1）で固定一式と対照。クーロン準位 3e-11 eV、重力 相対 4e-9、超微細は Breit の相対論補正 (3/2)α²・(17/8)α² を再現、A 係数は Dirac 行列要素の α²、放出 13.054539268 eV 一致。解法を固定。
- **同符号 ee・pp**（粒子以外は同条件）：正味ポテンシャル正で束縛準位 0。準位と率の模型には対象が無い。木原氏の問い「準位と放射だけで解けるか」への一式自身の答え。
- **散乱の枝は in–out の関係量だけ**：途中の軌道は観測されず、同種粒子では軌道を実在と仮定すると Mott の干渉を落として間違える（Heisenberg 1943 の S 行列の立場）。Mott 断面積（90° で区別できる粒子の 1/2）と四重極制動放射スペクトル（LL §71、Parseval 自己検査）を E = |E(5p₃/₂)| で計算。一回の衝突の光子期待値 5e-16（ee）／5e-23（pp）個。記録に残るのは偏向角の分布だけ。
- **単独の電子・陽子**：比較する相手が無く、存在を含めて読めない（匿名の原点そのもの）。陽子は内部に関係（匿名内部観測者）を持つが、外へは相手が来た時の定数（g_p、電荷半径 0.84 fm、Zemach、分極率）として現れるだけ。スピン ½ なので複合でも静的四重極は無い。
- **三体**：閉じた式は無いが量子の束縛状態は変分で実験精度以上に解けている（He、H⁻、H₂⁺）。この系で作れる三体は H⁻（束縛状態一つ、束縛励起なし）、H₂⁺（等核で E1 禁制、四重極の振動回転線）、eee・ppp（なし）。本題は同種粒子の匿名性が Pauli の反対称化になること。
- **吸収体の異方性（三層）**：層 1 = 方向の印と重心速度（読み出し。M = ∞ なら生成子不変）、層 2 = 温度（生成子が変わる：上向きの率）、層 3 = m 副準位の整列（状態空間と生成子と読み出し。無偏光の強度双極子は整列を作らず、四重極成分 β² ≈ 1.5e-6 と背景の四重極 1e-5 から）。異方性を吸収率に置いてはならない（Partridge 1973：放射パワーの方向依存は 10⁻⁶ で無し → 全方向で完全吸収、f ≡ 1）。順序は 2 → 1 → 3。
- **層 2 実装済み**（`absorber_temperature.py`）：T = 2.7255 K で 21 cm の n̄ = 39.5、1s 超微細の緩和 6.9e4 年、定常 F=1 : F=0 = 0.745 : 0.255 = 3e^{−ħω/kT}（差 4e-16）、spin 温度の読み出し 2.72550 K、詳細釣り合い差 0。5p からの多段は不変。
- **層 1 実装済み**（`absorber_direction_recoil.py`、層 2 を含む）：吸収体の静止系に双極子軸の印、N = 10⁶⁰ は連続方向、原子に v₀ = 370 km/s ẑ、状態に v⃗、準位ごとの質量、静止系で厳密な二体運動学（Lyman-α 反跳シフト 13.40 MHz、反跳 3.26 m/s、21 cm 1.87e-6 m/s）、Lorentz 変換と運動量保存、原子静止系で双極子状の背景（T 前方/後方 2.72887/2.72214 K）、量子跳躍モンテカルロ。記録 (t, 種別, δ = ω_lab/ω′ − 1, n̂) だけからの読み出し：集団 200 原子の多段光子から v⃗ を 0.09 m/s で復元、一個の原子の 21 cm 事象 29 個から蹴りの履歴を積み上げて v⃗₀ を 2.4e-10 m/s で復元（反跳 1.9e-6 の 2e-4）。生成子に「事象が v⃗ を蹴る写像」が加わった。
- **層 3 実装済み**（`absorber_alignment.py`、層 2 を含む）：基底を m_F まで分解（220 状態）、Wigner–Eckart の m 分解率（和則 5e-16）、Δm = q の型の角分布と 90° 直線偏光度、背景 T(n̂) = T₀/(γ(1−β cosθ))(1 + a₂P₂) の型ごとの占有数 ⟨n̄⟩_q、縮退なしの詳細釣り合い。(A) 初期 5p₃/₂ F=1 の m_F = 0 で 5p→1s F0 は純 π（I ∝ sin²θ、偏光度 +1）、m 平均で等方・無偏光に戻り放出 13.054539268 eV。(B) 2.7255 K で定常整列：等方 0、双極子のみ +5e-9、四重極 a₂ = 4e-6 込み +2.5e-8、21 cm 偏光度 −1.9e-8。**整列は 10⁻⁶ でなく 10⁻⁸ 台**：p_m ∝ n̄_q/(1+n̄_q) で占有数差が 1/(n̄(1+n̄)) ≈ 1/1600 に抑えられる（n̄ ≈ 40 の飽和）。三層すべて実装済み。

## 12.5 共通エンジンと水素分子 H₂（10/6 夜、`Grok移行実験/exchange_engine_20261006/`）

経緯：中性子–中性子は強い力を入れない限り意味が無い（木原氏判断）。電荷を持たない質量のある系で、強い力を仮定せずに二体を組めるのは中性原子同士で、最小が H₂。実装は「万能化」でなく、系に依らない部分（生成行列・厳密解・時間発展・三層）を `engine.py` に切り出し、系ごとの部品（準位表と A 係数）を `system_hydrogen.py`・`system_h2.py` に分けて引数で選ぶ形にした。

- **水素原子の回帰**：エンジン＋水素部品で固定一式・層 1〜3 の数値に戻ることを確認（放出 13.054539268 eV 差 −3.6e-15、R・τ・p_∞ 差 0、層 2 の 0.745286/0.254714、層 3 の 0／+5.074e-9／+2.506e-8、層 1 は別乱数列で 0.11 m/s）。エンジンの修正 1 点：モンテカルロで t_cap を超えた事象を記録しない（⟨n̄⟩ ~ 1e-135 の吸収が t ~ 1e135 s に 1 件混入していた。水素の数値は不変）。
- **H₂ の部品の根拠**（すべて文献の値、`h2_data/SOURCES.md`）：BO ポテンシャルは Pachucki 2010（PRA 82, 032509）の表 82 点（精度 1e-15）とその解析フィット（H2SPECTRE 7.4 の V(R)、表との差 2e-12）、断熱補正は Pachucki–Komasa 2014（同 Eaint）、四重極能率 Θ(R) = Q_WSD(R)/2（Wolniewicz–Simbotin–Dalgarno 1998 表 3、257 点）、回転 g 因子 g(R)（Pachucki–Komasa 2011 表 I）。核の動径方程式は sinc-DVR（μ_n = m_p/2、dr 0.025、R ≤ 50、収束 2e-7 cm⁻¹）。率は E2 = α⁵ω⁵/15·(2J_f+1)(J_i 2 J_f;000)²|⟨Θ⟩|²、M1 = α⁵ω³/3·(m_e/m_p)²J(J+1)|⟨g⟩|²、GW = 4(α_Gp/α)|⟨q_m⟩|²/|⟨Θ⟩|²×E2（LL §110/§71、水素の W_GW と同じ比）。非断熱・相対論・QED は入れていない。
- **検証**（`validation_h2.md`）：束縛準位 301（Roueff+2019 の 302 のうち (14,4) は非断熱なしでは束縛しない）。D₀ = 36118.3637 cm⁻¹（E2(FULL) 36118.7977、全補正 36118.0695）、準位差は −0.3〜+4.6 cm⁻¹ で v とともに増える＝非断熱補正。遷移 4669 本の A_qua は CDS と中央値 8e-4（強い線の最大 6% は Δv ≥ 3 の相殺線）、A_ma 中央値 6e-4。代表線 1-0 S(1) 3.471e-7 vs 3.470e-7 s⁻¹、1-0 Q(1) の M1 7.137e-10 一致。H2SPECTRE の H2.dat (2,24) は配布側の誤記（115 cm⁻¹ 外れ）。

**同日の追加（木原氏の問い「水素原子どうしは重力で衝突するまで接近するのか」への答えと、その後の指示 3 件）**

- 答え：重力では近づかない。原子間重力 −Gm_H²/R は電磁（分散力 −C₆/R⁶、化学結合）の 8e-37 倍。重力が Casimir–Polder を上回るのは R ≳ 0.2 mm だが、そこで重力に束縛されるには Bohr 半径 7e22 m（2 Mpc）、束縛 8e-69 eV が要り、束縛状態は事実上ない。実際は電子スピンで分岐：三重項 3/4 は斥力（b³Σu⁺、7.8 a₀ に 6.5 K の浅い井戸、束縛なし）ではね返り、一重項 1/4 は 4.75 eV の井戸に落ちるが、核は Coulomb 斥力で内側転回点（解離限界で 0.776 a₀）まで近づいて戻る。合体には 4.5 eV を放射で捨てる必要があり、等核で E1 が無いので E2 だけ。「静止して向き合う」は量子的には局在の運動エネルギー（R₀ = 10 a₀、幅 3 a₀ で 13 cm⁻¹）が井戸の深さ（1.9 cm⁻¹）を超え、大半は離れていく。
- **原子間重力の別勘定**（実装済み、`system_h2.gravity_level`）：各準位に ⟨−Gm_H²/R⟩（点質量 m_H = m_p + m_e − E_b/c² の Newton 項）。(0,0) −1.244e-31 cm⁻¹、(14,0) −3.97e-32、線のずれ 1e-37〜1e-36 eV。倍精度の床の 20 桁下なので E には加わらず別列。未実装：電子の交差項（核–核の ~1e-3、~1e-7。Σ⟨1/r_ia⟩(R)・⟨1/r_12⟩(R) が要る）、1PN（1e-10）。
- **解離限界直下からのカスケード**（`audit_h2_v14J0.txt`、`audit_h2_v14J1.txt`）：(14,0)（深さ 143 cm⁻¹）・(14,1)（126 cm⁻¹）から放出 4.4603／4.4478 eV（= E_init − E_final）、光子 e2 7.5／7.0、m1 0.02。最初の段は (10,J±2)・(9,J±2)・(8,J±2) へ（ħω 0.6〜1.1 eV、分岐 0.37/0.36/0.14）、v' = 0 へ直接は行かない。
- **放射会合 H + H → H₂ + 光子**（`radiative_association_h2.py`）：箱で規格化した離散化連続状態（J ≤ 24、E ≤ 4389 cm⁻¹）から束縛準位への率を束縛–束縛と同じ式で計算。通過 1 回あたりの捕獲確率 P_J = 2πħρ_J ΣA（R_max 50→100 で相対差 1e-5、往復時間は古典値と 1% 一致）。P₀ = 6e-20〜1.3e-19、主な終準位 v' = 8〜11（v' = 0 へは行かない）。σ ≈ 1e-34 cm²（3〜100 cm⁻¹）、k(E) 4e-30〜3e-29 cm³ s⁻¹、k(T) 2〜4e-29 cm³ s⁻¹（10〜3000 K）。E ≈ 1 cm⁻¹ は (14,4) 準束縛共鳴（本計算では解離限界のすぐ上、全補正では束縛）が 99%。Claude の事前見積もり 1e-14 は 5 桁過大（ħω = D_e で ω⁵ を見積もったため。実際の捕獲は ħω ≈ 0.4〜1.1 eV）。三重項チャネルには捕獲が無い。

**論文化の決定（10/6 夜）**：Grok 移行実験の一式（水素原子・ee・pp・H–H の 4 系統）を新実験の論文にする。動機と主旨の置換文に合意（第 7〜10 と E–M 離散変分の失敗の後、万能相互作用の導出は一旦置き、既知の標準理論――Dirac–Coulomb 束縛状態と反跳・QED 補正、1PN 二体重力と四重極 GW、Einstein A のマスター方程式――を背景時空の格子・計量なしに数値計算するプログラムの記録。新発見は主張せず、将来の分配配列演算が再現すべき放出記録の基準を与える）。訂正点：「厳密な Einstein–Maxwell 方程式」とは書かない（場は時間発展させていない）、G=c=q₀=1 では ħ = 9/α で h は独立入力でない（独立入力は α・μ_p・μ = m_e√G/q₀・g_p、H₂ は文献曲線）、吸収体の静止系が漸近領域に当たる、ee/pp は in–out の閉じた式だけ、H–H は一重項の振動回転のみ。**図パッケージ** `Grok移行実験/figures_paper_20261006/`（make_figures.py、15 図、data/*.json、README、run_all.sh、SHA256SUMS 29 ファイル）。engine 側に図化用 JSON 出力を追加（計算は不変）。教訓：重い Python を並走させると Accelerate の全コア使用で負荷平均 100・10 倍以上の遅延になる。
