## 1. 状態（隠しなし）

| 状態 | 中身 |

これまでの隠し状態の行き先：q → 増分 (a₂, a₃)。ω → 状態から読む。Δs → δτ。t → T。s → 節点数（状態でない）。x₁ᵃ、x₁ᵇ → 読出し（F_A·ΔT、F_B·ΔT の積算）。ξ、L、ε_K、a、e → 読出し。

## 2. 係数（固定）と状態からの読み（反復）

- **交換の係数は固定**：θ₀ = 23π/124。R = sin²θ₀ = 0.3028、相手側 cos²θ₀ = 0.6972。方程式は時間方向で変わらない。関係の位相の再帰は 124 節点 ＝ 23 周。回転は厳密な一節点写像なので、この粗さで Kepler が厳密。解像度 124 で足りる理由。
- **ω は状態から読む**：三項漸化式 W_{n+1} = 2cosθ₀·W_n − W_{n−1} の離散不変量
  Q = |W|² + |W·g⁻¹|² − 2cosθ₀·Re(W̄·W·g⁻¹)　（g = e^{z₂}）
  が Q = κ·sin²θ₀/(2ω²) に等しい（|W|² + |W′/ω|² = 2a、a = κ/(4ω²)）。よって ω⁻² = 2Q/(κ sin²θ₀)。g⁻¹ は指数の符号反転。平方根と逆数は反復（当たり前）。これが「エネルギーは位相の進み率」の読出し。
  **訂正（実装時の検算、10/4）**：状態に持つ増分 g は「次へ進む増分」（W_{n+1} = W_n·g）なので、g⁻¹ で作れるのは一つ前の値 W_{n−1} ではなく、W′/ω = (g − cosθ₀)·W/sinθ₀ と前向きに読む。よって 2a = |W|²·(1 + |g − cosθ₀|²/sin²θ₀)、ω² = κ/(4a)、L = 2ω·Im(W̄·W′/ω)。g⁻¹ を使う上の形は、一つ前の増分 g_{n−1} に対してだけ正しい（離心軌道の検算で不変量が崩れて判明）。
- **E–M の係数**：T1〜T3 は ω に厳密に入る（Kepler ＝ 等方振動子、固定点 4 §1）。T4〜T22 は関係の単項式（e^{−pλ}、増分の冪、L）の積和として増分へ（§3 の 3）。放射は双極子 W² の片側交換（§3 の 4）。

## 3. 書き戻し（一節点、積和）

1. **現在値**：z₁ ← z₁ + z₂（両体。W ← W·G）。
2. **増分（交換そのもの）**：e^{z₂′} = 2cosθ₀ − e^{−z₂}。係数 (2cosθ₀, −1) の積和。回転 U_R(θ₀) と同じ写像で、ノルムの配分は第 9 論文の恒等式のとおり（検算：差 10⁻¹⁰）。
3. **1PN〜（T4〜T22）**：ε の偏微分（辞書 §3.2）× ΔT を、関係 (ξ, ξ̇, φ) への節点ごとの積和として入れ、(W, G) へ写す。軌道平均・求積は使わない。一次の摂動。
4. **放射（背景 B3 への片側交換）**：損失率は指数の単項式（κ²e^{−8a₀}·ΔT など）。増分へ加算で入る（振幅の対数と位相の増分）。放出の因子は三位相の配位の関数（STATUS §7.1。整数関係で 0）。読み (a)(b) のどちらで止めるかは未決のまま、因子は掛けずに読出しとして出す。
5. **ω、δτ、T**：§2 の読みで ω → δτ = θ₀·ω⁻¹ → ΔT = ∫|W|²（一節点、閉じた式）→ T。
6. **時計（読出し）**：x₃ᵃ = F_A·ΔT、x₃ᵇ = (m_b/m_a)F_B·ΔT を積算。F は関係の読出し。
7. **ロック（読出し）**：関係の位相は 124 節点で必ず戻る。問いは二つの時計も 124 節点（の倍数）で戻るか。これが「δτ と陽子・電子の振動数がロックする」「31・124 サイクルの倍数の繰り返し」の実体で、放射で軌道が動いて時計が揃う所で放出が止まる。

## 4. 比較の基準

v1〜v7 の数値とは合わせない。合わせるのは、(i) Kepler の閉じた式（厳密写像なので合うはず）、(ii) E–M の係数（ε の各項がそのまま入っているか。1PN の近点移動は E–M の解析値と）、(iii) 放出が止まる所が 23/124 と時計の整数関係を同時に満たしているか、の三つだけ。
