## 1. 実装（固定点 4 §1〜4 との対応）

| 固定点 4 | プログラム |
|---|---|
| 半角の対象 w、w² = z。二チャネル p = w/√2（現在値）、q = w′/(√2 iω)（率） | 状態 `p, q`（複素 2 個 ＝ 4 実数）。ξ、π、m、L、a、e はすべて p、q から読む |
| 一節点の交換 U_R(θ)、θ = ωΔs、ω = √(\|ε_K\|/2) | `p′ = cosθ p + i sinθ q、q′ = i sinθ p + cosθ q`。**これが S1。** R = sin²θ は毎節点 N_p、N_q を配る |
| 不変量 N_A + N_B = a、L = 2ω(N_A − N_B) | α = (p+q)/√2、β = (p−q)/√2 から読み、csv に出す |
| 節点時間 ds = dt/ξ、一節点の Δt = ∫\|w\|²ds | 厳密式 `a·Δs + 2Re[αβ̄(e^{2iωΔs} − 1)/(2iω)]` |
| 時計 x₃ᵃ = F_aΔt、x₃ᵇ = (m_b/m_a)F_bΔt | v7 手順 5 のまま |
| 1PN〜（T4〜T22）：近点移動 ＝ 共通位相 Δα = ½(∂⟨δε⟩/∂L)Δt | `precession_rate`：δε = ε_full − ε_K を Kepler 軌道で平均（離心近点角 64 点）、L での微分（e の偶関数性を使い e → 0 でも有限）。**一次の摂動** |
| 放射 ＝ 背景への片側の交換。双極子 z = w²、Kepler の z̈ = −κz/ξ³ | ΔE = −(2/3)κ_C κ²/ξ⁴·Δt、ΔL = −(2/3)κ_C κL/ξ³·Δt。a と L/(2ω) を減らし、α、β の大きさだけを縮める（位相は保つ） |
| 三位相（x₃ᵃ、x₃ᵇ、双極子の進み 2Δarg w） | 読み (a)：Δa、Δb、Δab と s_dir。読み (b)：双極子の位相と二つの時計が同時に初期へ戻る節点。**どちらも読み出しのみ。放出に掛けない（既定）** |
| 節点幅 | v7 の Δt = 10153（ξ₁ での値）を Δs = Δt/ξ₁ = 37.03 として継承。窓・分母の入力なし |

## 4. 予告（走行前に書く。成功条件にしない）
- Kepler 対照：ξ と t は閉じた式と倍精度で一致するはず（交換 U_R は振動子の厳密な一節点写像）。a、L、ε_K は不変。円で N_p = N_q、離心で N_p と N_q が 2θ の率で往復（呼吸）。θ = 0.1351（辞書・v1 と同じ値）。
- 近点移動：円で一周あたり 1.25×10⁻⁴ の桁。
- 放射：円の毎節点の損失は v1 と同じ式なので 1.40×10⁻⁷·|ε|。離心は円化。読み (a) の s_dir は三位相の端数で決まり、因子を掛けないので放出は止まらない。

### 5.4 読み取り（事実から従うことだけ）
1. **S1 が入った。** 状態は (p, q) の 4 実数と時計だけで、節点演算は U_R(θ) の混合。R = sin²θ = 0.0181 が毎節点 N_p、N_q を配り（離心では 137〜180 の間を往復＝呼吸）、Kepler を倍精度で再現した。v1〜v3 の正準積分器と ψ += 2θ は無い。
2. **E–M は係数として入った。** T1〜T3 は ω に厳密、T4〜T22 は近点移動の一次摂動で、v7 の独立計算（作用–角変数）と 4 桁で一致。放射は双極子 w² の片側の交換で、v1 と同じ損失率。
3. **不変量と配分の対応が出た。** N_p + N_q = a（長半径）、Re⟨p|q⟩ = L/(4ω) は不変。N_p − N_q と Im⟨p|q⟩ が 2θ で回る（呼吸）。円では N_p = N_q = Re⟨p|q⟩ で配列が静止する。
4. **ロックの因子は掛けていない。** 読み (a) の s_dir は三位相の端数で 0〜0.75 を往復し、瞬間的に 10⁻⁶ まで落ちる節点はあるが留まらない。読み (b) の全配列の同時再帰は 10⁵ 節点で 0 回。どちらで放出を止めるかは固定点 4 §5 のとおり未決。
5. **節点の座標時間 Δt は距離で伸縮する**（離心で 10057〜13297）。これが「δτ 自身が変化する」の実体で、節点時間 Δs は一定。
