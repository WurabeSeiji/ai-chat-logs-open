## 1. 配分は何と何の間で、何が配られるか

相対関係を z = ξ e^{iφ}（距離と向き）とし、その**半角の対象** w を w² = z で置く（固定点 2「関係は状態の二乗、倍角、二重被覆」の対象）。

E–M の Newton＋クーロンの部分は、節点時間 ds = dt/ξ（距離で伸び縮みする刻み。「δτ 自身が変化する」〔木原 10/1 00:23〕の実体）で書くと、厳密に

  **w″ = (ε_K/2)·w**　　（ε_K = ½|ż|² − κ/ξ、κ = κ_C + κ_G、束縛で ε_K < 0）

になる。近似ではなく Kepler の厳密な書き換え。角振動数 ω = √(|ε_K|/2) の等方振動子で、**エネルギーが位相の進み率**（固定点 3）が文字どおり成り立つ。

w を二つの位相子に分ける：w(s) = A e^{iωs} + B e^{−iωs}。

| 関係量 | E–M での意味 | 検算 |
|---|---|---|
| N_A + N_B | 軌道長半径 a（ε_K = −κ/(2a)） | r_max = (\|A\|+\|B\|)²、r_min = (\|A\|−\|B\|)² |
| N_A − N_B | 角運動量 L = 2ω(N_A − N_B) | 保存量。反対称の組の不変量（固定点 2 §6.3） |
| \|⟨A\|B⟩\| = \|A\|\|B\| | 離心率 e = 2\|A\|\|B\|/(N_A+N_B) | 円軌道 ⇔ B = 0 |
| arg⟨A\|B⟩ | 軌道上の位置（離心近点角）。**一節点に 2θ 回る** | 倍角 |
| 共役なしの w² = z | 双極子（方向を持つ関係。固定点 2 §3 の S₂ 型） | 一節点に 2θ 回る |

**二チャネル** a、b は A、B の対称・反対称の組

  p = (α + β)/√2、q = (α − β)/√2、　α = Ae^{iωs}、β = Be^{−iωs}

で、w = √2·p、w′ = √2·iω·q。すなわち **p は半角の対象の現在値、q はその率**（木原氏の四成分 z₁ = 現在、z₂ = 増分 の対）。一節点の Kepler の進み diag(e^{iθ}, e^{−iθ})（θ = ωΔs）を p、q の基底で書くと

  **p′ = cosθ·p + i sinθ·q、　q′ = i sinθ·p + cosθ·q**

で、有限位数共鳴論文の U_R = [[r, t],[t, r]]（t = cosθ、r = i sinθ、全体位相を除く）そのもの。したがって**一節点ごとの配分は第 9 論文の恒等式 dN_q = sin²θ(N_p − N_q) + sin2θ·⟨p|q⟩ の項、そのまま**で、R = sin²θ は出力ではなく毎節点ノルムを動かす係数。配られるのは「現在値と率」（軌道上の位置＝呼吸、運動と束縛の往復）で、不変量は N_p + N_q = N_A + N_B（エネルギー）と L。

**数値の検算**：Bohr 型円軌道 ε_K = −2.6631×10⁻⁵ → ω = 3.649×10⁻³。節点を v7 から継承した座標時間幅 Δt = 10153（a の 1616 周）とすると Δs = Δt/ξ₁ = 37.03、θ = ωΔs = 0.1351。辞書の θ = (Δθ_k/4g)∂ε/∂m = 0.13512 と一致する。別の導出で同じ角が出るので、辞書の θ はこの振動子の位相の進みだった。7/18 の R ≈ 0.7 は θ = 23π/124 = 0.583 で、節点が v7 の 4.3 倍の場合に当たる。

## 2. なぜ変分式での配分であって v1 の偽物でないか

- v1〜v3 は E–M をシンプレクティック Euler で積分し、ψ += 2θ を「回転」と呼び、R は表示だけだった。
- U_R(θ) は、振動子 w″ = −ω²w の**離散作用の厳密な一節点伝播子**である。離散 Lagrangian を一節点で厳密に取ると一節点写像は回転行列になる。積分器ではなく、9/29 規則の「固定の積和 z_next = M @ (z[i]·z[j])」の M が、位相子の対に対しては U_R そのもの。
- 状態は (p, q) ∈ ℂ²（4 実数：二つの位相子の対数振幅と位相）と二つの時計だけ。ξ、π、m、呼吸は持たず、関係から読む（固定点 1 §4）：ξ = |w|² = 2N_p、ż = 2ww′/ξ、L = 2 Im(w̄w′)、π = Re(z̄ż)/ξ、m = L/(2g)。

## 4. 時計と三位相

一節点の座標時間は Δt = ∫|w|²ds（節点内で厳密：(N_A+N_B)Δs + 2Re[αβ̄(e^{2iωΔs} − 1)/(2iω)]）。a の時計は x₃ᵃ = F_a·Δt、b は x₃ᵇ = (m_b/m_a)F_b·Δt（v7 手順 5）。三位相は x₃ᵃ、x₃ᵇ、双極子 z = w² の一節点の位相の進み（= 2·Δarg w）。節点の大きさ Δs が三位相の整数関係を満たす値に落ちるかが「δτ がロックするのは結果」（木原 10/1 11:11）の問い。

## 5. 決まっていない一点（正直に）

「整数関係」（STATUS §7.1）の読み。
- (a) 節点ごとに三位相の進みの差が 0（mod 2π）。v3 の読み。23/124 型の再帰は原理的に出ない。
- (b) q 節点後に全配列（双極子の位相、二つの時計の位相）が戻る再帰（木原 10/1 17:45「31・124 サイクルの倍数の繰り返し」）。放出の相殺は q 節点にわたる干渉になり、q は配列の戻りとして現れる必要がある。7/18 で q が評価窓から出た問題がここに残る。

§1〜4 の力学はどちらの読みでも同じ。違うのは放出が消える条件の形だけ。実装は §1〜4 を書き、(a)(b) を読み出しとして両方出し、どちらで放出を止めるかは走らせる前に木原氏に確認する。

## 5.1 追記（実装時の検算、10/4）：p、q の関係の中身
p̄q = w̄w′/(2iω) なので、**Re⟨p|q⟩ = Im(w̄w′)/(2ω) = L/(4ω)**（反対称の不変量。円軌道では N_p = N_q = Re⟨p|q⟩）、**Im⟨p|q⟩ = −Re(w̄w′)/(2ω) = −(dξ/ds)/(4ω)**（動径の率。呼吸で回る）。配分で回る対は (N_p − N_q, 2Im⟨p|q⟩)、不変なのは N_p + N_q と Re⟨p|q⟩。

## 6. 先行の固定点との関係

- 固定点 1 §2「E–M の二体厳密解を a–b 交換係数として得る」→ 本文書 §1 で構成された（Kepler 部で厳密）。
- 固定点 2 §6「関係の配列の倍角の回転」→ ⟨p|q⟩ と w² が 2θ 回ることとして実現。
- 固定点 3「エネルギーは位相の進み率」→ ω = √(|ε_K|/2) として文字どおり。
- 辞書の置3「軌道角の一節点の進み = 2θ（交換角）」は、本文書では「双極子 w² の進み = 2Δarg w」で、円軌道では 2θ に一致し、離心軌道では一致しない（真近点角と離心近点角の差）。置3 は円軌道でだけ正しかった。
