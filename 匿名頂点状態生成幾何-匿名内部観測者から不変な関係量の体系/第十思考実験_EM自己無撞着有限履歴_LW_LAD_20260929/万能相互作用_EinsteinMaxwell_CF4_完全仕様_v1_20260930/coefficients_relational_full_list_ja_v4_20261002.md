# 2. 節点写像（微分形ではなく 1 節点の増分）

## 2.1 1 節点（k → k+1）の手順。Δθ_X は固定

**手順 0（節点の定数）** 現在の |ψ_m|² のモーメントから ξ̄_c,k、ω_X,k、ρ̄_k、E_m の ξ 展開係数を作る。式は §1.2 の単項式の積和で、Newton 次では ξ̄_c = ⟨m²⟩ξ₁、ω_X = ρ̄ が閉じた形。1PN 以下の補正は ⟨m²⟩、⟨m⁴⟩、⟨m⁶⟩ の多項式として初期化で展開しておく。

**手順 1（座標時間幅、中間量）**
\[
\Delta\theta_k=\Delta\theta_X\cdot\omega_{X,k}^{-1}
\]

**手順 2（節点での分離と動径運動量）**
\[
\xi_k=\bar\xi_{c,k}-A_k\cos\theta_{X,k},\qquad \pi_k=A_k\,\omega_{X,k}\sin\theta_{X,k}
\]
（(A/ξ̄_c)² 以上の項：Kepler の e 級数 ξ = ξ̄_c[1 − e cos θ_X − (e²/2)(cos 2θ_X − 1) + …]、e = A/ξ̄_c。必要次数は e^n < 1/124 で決め、初期化で展開。）

**手順 3（四つの位相の進み）**
\[
\boxed{
\begin{aligned}
\Delta\theta_{X,k}&=\Delta\theta_X &&\text{（定義）}\\
\Delta\theta_{Y,k}&=\bar\rho_k\,\Delta\theta_k &&\text{（回転）}\\
\Delta\theta_{a,k}&=F_{a,k}\,\Delta\theta_k,\quad F_a=1-\tfrac12 v_a^2-U_a-\tfrac18 v_a^4,\quad v_a^2=\bar v^2/g^2,\quad U_a=\frac{\kappa_G}{g\,\xi_k}\\
\Delta\theta_{b,k}&=\frac{m_b}{m_a}F_{b,k}\,\Delta\theta_k,\quad F_b=1-\tfrac12 v_b^2-U_b,\quad v_b^2=\Big(\frac{g-1}{g}\Big)^2\bar v^2,\quad U_b=\frac{\kappa_G(g-1)}{g\,\xi_k}
\end{aligned}}
\]
F_a、F_b は固有時因子 dτ_A/dt の 1PN 展開（⅛v_a⁴ = 3.5×10⁻¹⁰ は 2PC 項と同じ桁なので入れる。U の 2 次、Uv² は 10⁻¹³ 以下で落とす）。v̄² = π_k² + Σ|ψ_m|²v_m²(ξ_k)。

**手順 4（倍音の更新。保存部分は位相の乗算、放射反作用は積和）**
\[
\psi_m\leftarrow\Big[\psi_m-i\frac{\mu}{2m_a}\Delta\theta_k\,(V_{\rm RR}\psi)_m\Big]\cdot\exp\!\big(-iE_m(\xi_k,\pi_k)\Delta\theta_k\big),\qquad
E_m=\frac{\mu}{2m_a}\,\varepsilon(\xi_k,\pi_k,m,s_a,s_b)
\]
exp は固定項数の級数。m に依らない共通位相はゲージ。

**手順 5（呼吸の中心と周波数の更新）** 更新後の |ψ_m|² から ξ̄_c,k+1、ω_X,k+1 を作る（手順 0 と同じ式）。Δξ̄_c,k = ξ̄_c,k+1 − ξ̄_c,k。

**手順 6（呼吸の複素振幅の更新。同じ乗法の位相写像）**
\[
\boxed{
B_{k+1}=\Big[\big(\mathrm{Re}B_k-\Delta\bar\xi_{c,k}\big)+i\,\mathrm{Im}B_k\cdot\omega_{X,k}\,\omega_{X,k+1}^{-1}\Big]e^{\,i\Delta\theta_X}+\Delta A^{\rm RR}_k\,e^{\,i\theta_{X,k}}}
\]
\[
\Delta A^{\rm RR}_k=f\,\frac{\sin\theta_{X,k}}{\omega_{X,k}}\Big[\frac{2\kappa_C}{3}\mathrm{Re}\big(\overline{D'''}S_1\big)-\frac{2\alpha\mu m_a}{45}\,\xi_k\,\mathrm{Re}\big(Q^{(5)}\overline{S_2}\big)\Big]\Delta\theta_k
\]
第 1 項は中心のずれ（|ψ_m|² が変わると平均の円軌道半径が変わる。ξ と π は連続なので B が平行移動する）、第 2 項は放射反作用の動径成分による振幅の変化（dI_r/dθ = −∂⟨V_RR⟩/∂θ_X、I_r = ½ω_X A²）。保存部分だけなら B は位相を Δθ_X 進めるだけで A は一定。A_{k+1} = |B_{k+1}|、θ_X,k+1 = θ_X,k + Δθ_X（定義。arg B_{k+1} との差は読み出し）。

**手順 7（内部位相・スピン）**
\[
\theta_a\leftarrow\theta_a+\Delta\theta_{a,k},\qquad \theta_b\leftarrow\theta_b+\Delta\theta_{b,k},\qquad
\hat s_A\leftarrow\hat s_A+(\boldsymbol\Omega_A\times\hat s_A)\,\Delta\theta_k
\]
Ω_A は §2.3。

# 8. 初期化で行うこと

2. 導出定数：§0.4。ξ₁ は §1 の全項で ∂ε/∂ξ = 0 を一度解く（274.1811）。§6 の展開係数。
3. 初期の円軌道（§8.5）：r = ξ₁（振幅）、v/c = α(1+δ)（r を光が渡る間の回転位相の進み）、Ω/ω_int = ρ̄F_a⁻¹（内部時計との比）。固定軸の Δφ は使わない。

\[
|\psi_0|^2=|\psi_2|^2=\frac{\langle m^2\rangle-1}{2}=\frac{2\delta+\delta^2}{2},\qquad |\psi_1|^2=1-(2\delta+\delta^2)
\]
