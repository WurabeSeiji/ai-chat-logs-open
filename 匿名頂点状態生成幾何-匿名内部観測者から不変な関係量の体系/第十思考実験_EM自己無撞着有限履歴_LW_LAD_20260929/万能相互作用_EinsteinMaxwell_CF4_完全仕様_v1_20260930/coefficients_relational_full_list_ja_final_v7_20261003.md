5. **v6 の B3 走行の結論**：m = 0 への漏れで ξ̄_c → 0 に向かい、ロックに達しない（Rutherford 崩壊）。原因は m = 0 を状態に含めたこと（公理②の未実装）と、呼吸に規格化・零点がなかったこと（表現の非統一）。v7 で両方を直す。

# 2. 初期化で E–M から作る表（相互作用中は固定）

## 2.1 作用–角変数の軌道

倍音番号を実数 m̄ として ε(ξ, π, m̄) を取り、動径運動 dξ/dθ = ∂ε/∂π、dπ/dθ = −∂ε/∂ξ、dφ/dθ = (1/2g)∂ε/∂m̄ を近点から遠点まで求積する（DOP853、相対許容 10⁻¹²。鏡映で一周）。得るもの：

| 量 | 定義 |
|---|---|
| I_r/μ = (1/π)∫_{近点}^{遠点} π dξ | 動径作用 |
| ω_X = π/T_半周 | 呼吸の角振動数（座標時間 θ あたり） |
| γ_cl = φ(2π)/(2π) | 一周の回転（古典の γ。1PN で 1 からずれる） |
| Z_k = (1/2π)∫ ξ e^{i(φ − γ_cl θ_X)} e^{−ikθ_X} dθ_X | 双極子の Fourier 係数（実数） |
| W_k = (1/2π)∫ ξ² e^{2i(φ − γ_cl θ_X)} e^{−ikθ_X} dθ_X | 四重極 |
| X_k = (1/2π)∫ ξ e^{−ikθ_X} dθ_X | 半径 |
| ⟨𝐏²⟩、⟨1/ξ⟩、⟨ξ⟩ | 一周の平均 |

# 6. 表現の規約

- **統一表現**：状態は Ψ_{n,m} 一つ。呼吸と回転は同じ倍音の列で、違うのは公理が定める範囲（m ≥ 1、n ≥ 0）だけ。別のチャネル・別の積分器・古典変数を置かない。
- **節点 = Δθ_X の固定増分**（2π/62）。刻み = 節点。
- **上限** M = 31、N = 8、K = 8。初期の台は §8。
- **E–M は初期化だけ**：ε の 22 項から §2 の表を一度作る。相互作用中に E–M も軌道も解き直さない。
- **割り算を使わない**：ω_X⁻¹ は逆数反復。表の値はすべて初期化で確定。
- **exp は固定項数の級数**。倍音の位相 E(n,m)Δθ/(2g) は有界（|E| ≤ |ε₁|）で、v6 の m² の発散はない。
- **後退差分**：D‴、Q⁽⁵⁾ は直前 4・6 節点（1 次精度）。拍動 ρ + kΩ_X の 1 節点の位相は (γ + k)·2π/62 で、|k| ≲ 5 まで有効。
- **状態は関係の位相と比だけ**（STATUS 7.5）。固定座標軸に対する角度はどこにもない。
- **予想は成功条件にしない。**

## 11.2 疑問(1)：124 節点の再帰

Ψ₀₁ の位相は古典の一周あたり −π（E = −LΩ/2、L = ħ）で、v6 と同じ。v7 は節点を 1 量子の拍動 Ω_beat = [E(1,1) − E(0,1)]/(2g) で刻むので、1 呼吸 = 8/3 古典周、位相 −8π/3、再帰は 3 呼吸 = 186 節点になった。節点を小振幅の呼吸 ∂E/∂I_r（表の om_cl）で刻めば 62 節点 = 1 古典周、再帰 124 節点に戻る。この時計の変更は Claude が v7 で表現から従うものとして置いたが、表現は二つの定義（差分＝1 量子の拍動、微分＝小振幅の呼吸）のどちらも許す。**どちらを共通時計とするかは木原氏の判断。**
