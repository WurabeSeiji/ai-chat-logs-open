## 1. 状態（持つのは関係とその率。a、b の成分は持たない）

| 記号 | 意味 | 側 |
|---|---|---|
| λ、Δλ | 対数距離とその一節点の増分。ξ = e^λ、π = ξΔλ/Δθ_k | 長さの対 |
| ψ | 関係の位相（配列の回転角の積算。mod 2π） | 向き（背景に対してだけ意味がある） |
| m | 反対称の組の不変量（角運動量 L/ħ）。θ はここから ε を介して読む | 不変量 |
| x₃ᵃ | a の位相の一節点の増分 ＝ 節点の時計。Δθ_k = x₃ᵃ/F_a | 時計の対 |
| x₁ᵃ、x₁ᵇ | 二つの時計の位相（mod 2π。帳簿） | 時計の対 |

## 2. 節点（辞書 §2 の六面の順）

0. 読み出し：ξ、Δθ_k = x₃ᵃ/F_a（F と Δθ_k は一節点内で 3 回反復）、π、𝐏²、F_a、F_b、x₃ᵇ = (m_b/m_a)F_bΔθ_k、ε。
1. 角：θ = (Δθ_k/4g)∂ε/∂m（面①）、θ_X = (Δθ_k/2)√(ε_ξξε_ππ)（面②）、η_a = −ln F_a、η_b（面③④）。スピンは定数（面⑤⑥、角 0）。
2. 面②（呼吸）：E–M の正準更新 π ← π − ∂ε/∂ξ·Δθ_k、ξ ← ξ + ∂ε/∂π·Δθ_k（シンプレクティック Euler）。λ、Δλ を更新。
3. 面①（配列の回転）：ψ ← ψ + 2θ（倍角）。
4. 時計：x₁ᵃ += x₃ᵃ、x₁ᵇ += x₃ᵇ。
5. 放射（背景との片側の交換、f）：|D″|² を形の群から読む（φ̇ = 2θ/Δθ_k、ξ̇ = ∂ε/∂π、ξ̈ = −∂ε/∂ξ、φ̈ は連鎖律。履歴は使わない）。ΔE = f·(2/3)κ_C|D″|²Δθ_k、sin²θ_rad = ΔE/|ε|（辞書 置4）。Δm = −ΔE/(2gφ̇)（∂ε/∂m = 2gφ̇ なので ε はちょうど ΔE 減る）。

## 4. 本プログラムで置いたこと（辞書・固定点に無い決め）

| # | 置いたこと | 理由 | 別の取り方 |
|---|---|---|---|
| P1 | 持つ状態を a、b の八成分ではなく、関係 (λ, Δλ, ψ, m) と時計 (x₃ᵃ, x₁ᵃ, x₁ᵇ) にした | 固定点 2 §4「持つべき状態は a、b の四成分ではなく二体の間の関係そのもの」。a、b の成分を持って I₄⊗R(θ) で回すと、λ = x₀ᵇ − x₀ᵃ も x₃ᵃ も一節点で壊れる（辞書の読み出しがチャネル回転で不変でない） | 成分を持ち、読み出しをチャネル不変量（固有チャネル）に直す（v2 候補） |
| P2 | m を状態（反対称の組の不変量）として持ち、θ は ε(ξ, π, m) から読む | 固定点 2 §6.3「反対称の組は回転で不変、θ はそこから読む」。θ ↔ m の循環（辞書 §1.2）はこれで閉じる | m を時計の比 x₃ᵇ/x₃ᵃ から逆に読む（精度 10⁻¹¹ が要る） |

| P5 | 節点の時計 x₃ᵃ を v1 では定数にした | 辞書 §1.2「外から Δθ_X を置かない」の最小形。何がこれを変えるかは再定義文書の課題 | x₃ᵃ を F_a で更新する／引き込みの候補 |

## 5. 予告（走行前に書く。成功条件にしない）

- 円（δ = 0、f = 0）：ξ、m、ε、θ は不変。ψ は毎節点 2θ = 0.2702 rad 進む。配列の再帰は 2θ·n ≡ 0 mod 2π の有理条件。θ は v7 の対角位相と同じ値（固定点 3 §2.3）。
- 離心（δ = 0.065、f = 0）：ξ が呼吸、θ が ξ とともに振れる。γ = θ/θ_X は 1 + O(α²)。
- 円＋放射（f = 1）：sin²θ_rad ≈ 1.4×10⁻⁷ 毎節点で m が減り、ξ ∝ m² で縮む。引き込みの機構は入っていないので、ロックは起きない見込み。

### 6.1 読み取り（事実から従うことだけ）
- 配列の回転は動く。円軌道でも ψ は毎節点 2θ 進み、2θ/2π が有理数に近い所で配列が再帰する。これが「ロック ＝ 配列の再帰」の実体で、v7 の対角位相（Ψ₀₁ の位相が 124 節点で戻る）と同じ量を、関係の位相として持ったもの。
- 放射は θ を単調に増やす（ξ が縮む ⇒ ∂ε/∂m ∝ 1/ξ² が増える）。有理点は固定点ではなく通過点。**有理点に留まる機構（引き込み）は E–M の係数のどこにもない**（固定点 1 §5 のとおり）。
- x₃ᵃ（節点の時計）を定数にしたので、2θ/2π = x₃ᵃ·∂ε/∂m/(4πgF_a) は ξ の単調関数。引き込みを入れる場所は、x₃ᵃ か θ の読み出しのどちらか（P5）。
- 離心軌道で γ = θ/θ_X が大きく振れるのは読み出しの式の限界（P3）。呼吸の率は正準更新が持っている。
