# 2. 節点写像（微分形ではなく 1 節点の増分）

## 2.1 1 節点（k → k+1）の手順。Δθ_X は固定

**手順 0（節点の定数）** 現在の |ψ_m|² のモーメントから ξ̄_c,k、ζ_c,k、ω_X0,k を作る。Newton 次 ζ₀ = κ/(4g²⟨m²⟩) に非 Newton 単項式の 1 次補正を Newton 法 1 歩で加える（相対誤差 10⁻⁹ 以下）。

**手順 2（呼吸の級数：ξ_k、π_k、ω_X,k）** 初期化で ε̄ の動径運動を一周だけ機械精度で解いて展開した級数を、B と ζ_c、ξ̄_c、ω_X0 から積和で評価する：
\[
s=|B|^2\zeta_c^2,\qquad P_n=(\zeta_c B)^n,\qquad
\xi_k=\bar\xi_c\Big[\hat C_0(s)+\sum_{n=1}^{N}\hat C_n(s)\,\mathrm{Re}P_n\Big],\qquad
\omega_{X,k}=\omega_{X0}\,\hat\Omega(s),\qquad
\pi_k=\omega_{X,k}\,\bar\xi_c\sum_{n=1}^{N}\hat S_n(s)\,\mathrm{Im}P_n
\]
Ĉ_n、Ŝ_n、Ω̂ は s の多項式（次数 5）。打ち切り N は読み出し基準で決める：q^{N+1} < 2.7×10⁻⁸（q₀ = 0.137 で N = 12、q₀¹³ = 6×10⁻¹²）。Kepler 極限では Ĉ_n、Ŝ_n は Bessel 係数、Ω̂ = 1。1PN 以下の項による形の補正は初期化時のモーメントで固定する（モーメントの変化による補正のずれは基準以下）。θ_B = 0（B 実）が近点。

**手順 1（座標時間幅、中間量）**
\[
\Delta\theta_k=\Delta\theta_X\cdot\omega_{X,k}^{-1}
\]

**手順 3（四つの位相の進み）**
\[
\boxed{
\begin{aligned}
\Delta\theta_{X,k}&=\Delta\theta_X &&\text{（定義）}\\
\Delta\theta_{Y,k}&=\bar\rho_k\,\Delta\theta_k &&\text{（回転）}\\
\Delta\theta_{a,k}&=F_{a,k}\,\Delta\theta_k,\quad F_a=1-\tfrac12 v_a^2-U_a-\tfrac18 v_a^4,\quad v_a^2=\bar v^2/g^2,\quad U_a=\frac{\kappa_G}{g\,\xi_k}\\
\Delta\theta_{b,k}&=\frac{m_b}{m_a}F_{b,k}\,\Delta\theta_k,\quad F_b=1-\tfrac12 v_b^2-U_b,\quad v_b^2=\Big(\frac{g-1}{g}\Big)^2\bar v^2,\quad U_b=\frac{\kappa_G(g-1)}{g\,\xi_k}
\end{aligned}}
\]
F_a、F_b は固有時因子 dτ_A/dt の展開。⅛v_a⁴（3.5×10⁻¹⁰）は入れ、U の 2 次と Uv²（≤ 10⁻¹³）は落とす。v̄² = π_k² + Σ|ψ_m|²v_m²(ξ_k)。

**手順 4（倍音の更新。保存部分は位相の乗算、放射反作用は積和）**
\[
\psi_m\leftarrow\Big[\psi_m-i\frac{\mu}{2m_a}\Delta\theta_k\,(V_{\rm RR}\psi)_m\Big]\cdot\exp\!\big(-iE_m(\xi_k,\pi_k)\Delta\theta_k\big),\qquad
E_m=\frac{\mu}{2m_a}\,\varepsilon(\xi_k,\pi_k,m,s_a,s_b)
\]
exp は固定項数の級数（z/2⁸ で級数、8 回二乗、絶対値を 1 に補正）。m に依らない共通位相はゲージ。

**手順 5（呼吸の中心と周波数の更新）** 更新後の |ψ_m|² から ξ̄_c,k+1、ζ_c,k+1、ω_X0,k+1 を作る（手順 0 と同じ式）。

**手順 6（呼吸の複素振幅の更新：接触軌道要素）** ξ と π は節点で連続である。新しい定数（ξ̄_c,k+1、ζ_c,k+1、ω_X0,k+1）の級数で (ξ, π) = (ξ_k, π_k + F_rΔθ_k) を満たす B′ を、現在の B を種に Newton 法 1〜2 歩で求める（Jacobian ∂(ξ,π)/∂(Re B, Im B) は手順 2 の級数の解析微分。1/det は逆数反復）。そのあと時計の増分だけ回す：
\[
\boxed{B_{k+1}=B'\,e^{\,i\Delta\theta_X}},\qquad

# 6. 表現の規約

- **節点 = Δθ_X の固定増分**。初期値 Δθ_X = 2π/62。**刻み = 節点**。「1 刻み = 4 節点」は本書にない（物理の項でも定義でもない）。4 重構造は ψ₁ の位相（§4）が担う。
- **倍音の上限 M = 31**（62 節点の角度標本化の上限）。初期の台とは別（§8）。
- **倍音の位相の折り返し**：倍音 m の 1 節点の位相 E_mΔθ_k は m² に比例し、δ = 0.065 の初期状態で m = 1 が 0.061 rad、|m| = 8 で π を超え、m = 31 で 58 rad。発展（位相の乗算）は厳密だが、節点時計では |m| ≳ 8 の倍音の位相は読めない（折り返し）。後退差分の放射反作用は双極子成分の 1 節点の位相が 1 rad 程度まで（|m| ≲ 10）で有効。初期の台 {0,1,2} と放射反作用で励起される近傍の倍音はこの範囲にある。
- **倍音とスピン 1/2**：倍音が要る理由は角度の源（固定軸なしに双極子・四重極・ロックを持つ唯一の表現）であってスピン 1/2 ではない。半整数の倍音は置かない。二重被覆の 4 重構造は整数倍音 m = 1 の Bohr 位相として導出される。
- **呼吸の級数**：初期化で ε̄ の動径運動を一周だけ機械精度で解き（常微分方程式の求積、DOP853、相対許容 10⁻¹³）、θ_X の Fourier 級数の係数を s の多項式として当てはめる（e の格子 18 点、次数 5、|C_n| が読み出し基準より小さい格子点は除く）。打ち切り N は q^{N+1} < 2.7×10⁻⁸。再構成の残差 5.7×10⁻¹¹、軌道に沿った ε̄ の揺らぎ 4×10⁻¹¹（δ = 0.065）。
- 保存部分の更新はすべて乗法の位相写像（ψ_m に exp(−iE_mΔθ_k)、B に e^{iΔθ_X}）。別の積分器を置かない。
- 割り算を使わない：ω_X⁻¹、ξ⁻¹、1/det J は逆数反復 y ← y(2 − xy)（前節点の値を種に。ξ は 4 回）。初期化だけは割り算・平方根・求積を使う。
- exp は固定項数の級数（14 項、z/2⁸、8 回二乗、|·| → 1 の補正）。
- 初期化で展開するもの：ξ̄_c、ω_X0 の 1 次補正、呼吸の級数、E_m。相互作用中に E–M も動径運動も解き直さない。
- 状態は関係の位相と比だけ（STATUS 7.5）。固定座標軸に対する角度 φ はどこにもない。

# 8. 初期化（すべて数値まで確定）

1. 入力：Q_a = −3、Q_b = +3、m_a = 7.0×10⁻⁴、m_b/m_a = 1836.15267343、α、f。**δ = 0.065**（v₀ = α(1+δ)）。Δθ_X = 2π/62。N = 12、次数 5。
