## 実行

```
./run_all.sh                                   # 動作確認一式
python3 em_two_body_node_map.py --selftest     # 単項式表 = T1..T22、exp 級数、呼吸級数の残差
python3 em_two_body_node_map.py --delta 0.065 --f 1 --sa up --sb down --orbits 1000 --log-every 62 --out results/run.csv
```

引数：`--delta`（v₀ = α(1+δ)、既定 0.065）、`--f`（吸収率 0/設定値/1）、`--sa --sb`（up/down/zero、軌道軸にそろえたスピン）、`--orbits`（節点数 = 62×orbits。「周」は呼吸の周期）、`--log-every`、`--M`（倍音上限、既定 31）、`--n-harm`（呼吸級数の倍音数、既定 12）、`--poly-deg`（係数多項式の次数、既定 5）。
速度は約 4,700 節点/秒。B3 の本走行（≈ 2×10⁵ 周 ≈ 1.2×10⁷ 節点）は約 45 分の見込み。**本走行は指示があってから。**

## 実装上の注記

- **(a) 接触軌道要素の更新**：|ψ_m|² の変化による呼吸の中心・周波数の変化と、放射反作用の動径成分（Δπ = F_rΔθ_k）は、(ξ, π) の連続性を目標にした Newton 更新で B に入れる（仕様 手順 6）。
- **(b) 平方根**：ω_X0 = √(ε̄_ξξ ε̄_ππ) に `math.sqrt`（割り算ではない）。
- **(c) 後退差分**：D‴、Q⁽⁵⁾ は仕様どおり直前 4・6 節点（1 次精度）。ψ への反作用の仕事は Larmor（解析 D″）の 0.951 倍、Larmor（差分 D″）の 0.979 倍。
- **(d) exp 級数**：倍音 m の 1 節点の位相は m² に比例し m = 31 で約 50〜60 rad。z/2⁸ で級数（14 項）→ 8 回二乗 → 絶対値を 1 に補正。|z| ≤ 120 で誤差 4×10⁻¹⁵。
- **(e) 逆数**：1/ξ_k は Newton 反復 4 回、ω_X⁻¹・ζ_c・1/det は 2〜3 回。種は前節点の値。初期化だけは割り算・平方根・求積を使う。
- **(f) 初期化の ξ₁**：走行のスピン値で解く（δ = 0 で厳密に円軌道）。§3 の表はスピン 0。
- **(g) 呼吸級数の当てはめ**：|C_n| が読み出し基準（ξ̄_c の 10⁻⁸）より小さい格子点は丸めの雑音なので当てはめから除き、全格子点で無視できる係数は 0 にする。
- **(h) 混合状態の級数**：級数は初期化時のモーメントで展開し、Kepler 部分は ξ̄_c と s でスケールするので厳密。1PN の形の補正はモーメントの変化（走行で 13%）で 10⁻⁸ 以下しかずれない。

## v5 の実装からの変更（木原氏「適切と考える条件に仕様書とプログラムを修正」）

- 手順 2 の呼吸級数を、Kepler の e² 級数（中心 ξ̄_c）から、初期化で厳密に解いた軌道の Fourier 級数（係数は s の多項式、N = 12）に置き替えた。v5 の級数は中心が e² の桁で誤り（Kepler の中心は a = ξ̄_c/(1−e²)）、打ち切りが一周平均の回転率に +2.2×10⁻⁴ の偏りを残していた。v6 では ε̄ が呼吸一周内で 10⁻¹² まで一定。
- 初期の呼吸振幅 A₀ = 36.80（v5、誤り）→ 42.50。e = 0.118 → 0.134。
- 手順 6 の B 更新を調和近似から接触軌道要素の Newton 更新に置き替えた。放射で q が減る（円軌道化）ようになった（v5 では増えていた）。

## 仕様に関わる事実（v6 §4・§6 に記載）

1. 倍音 m の 1 節点の位相は m² に比例し、|m| ≥ 8〜9 で π を超える（m = 31 で 48〜58 rad）。発展は厳密だが、節点時計では |m| ≳ 8 の倍音の位相は読めず、後退差分の放射反作用は |m| ≲ 10 の双極子成分で有効。
2. δ = 0.065 の混合状態（台 {0,1,2}）では γ_mean − 1 ≈ 1/√⟨m²⟩ − 1 = −6.1×10⁻²。α² の読み出しは各倍音の位相と S₁ の拍動で行う。
3. ロックまでの時間：f = 1 の ε̄ の減少率から ≈ 2×10⁵ 周（≈ 1.2×10⁷ 節点、約 45 分）。
