# 2. 運動方程式（連続形。離散化は §6）

## 2.1 波の倍音 ψ_m

\[
\boxed{
\frac{d\psi_m}{d\theta_a}=-\,i\,\frac{\mu}{2m_a}\,\varepsilon_m(\xi,\xi')\,\psi_m+F^{\rm RR}_m
}
\]

a_a/ħ = 1/(2m_a)。固有の位相の進みは ε_m μ/(2m_a) rad／内部 rad。**放射反作用 F^RR 以外に倍音を混ぜる項はない。** 全倍音に共通の項は位相を一様に進めるだけで、相対位相に効かない。

## 2.2 呼吸 ξ

\[
\boxed{\xi''=-\frac{\partial\varepsilon}{\partial\xi}},\qquad
\frac{\partial\varepsilon}{\partial\xi}=\sum_m|\psi_m|^2\frac{\partial\varepsilon_m}{\partial\xi}
\]

主要項：∂/∂ξ[2(m_a/μ)²m²/ξ²] = −4(m_a/μ)²m²/ξ³、∂/∂ξ[−κ/ξ] = κ/ξ²。

## 2.3 スピン

\[
\frac{d\hat s_A}{d\theta_a}=\boldsymbol\Omega_A\times\hat s_A,\qquad
\boldsymbol\Omega_a=\frac{2\alpha(1+2m_a/m_b)\langle m\rangle}{\xi^3}\,\hat z,\qquad
\boldsymbol\Omega_b=\frac{2\alpha(m_a/m_b)^2(1+2m_b/m_a)\langle m\rangle}{\xi^3}\,\hat z
\]

（⟨m⟩ = Σm|ψ_m|²、ẑ は軌道軸。軸にそろったスピン s_A = ±1 は歳差しない。スピン–スピンの歳差は上に κ_C(m_a/m_b)/ξ³ の次数で加わる。）

## 2.4 内部位相 θ_b

\[
\frac{d\theta_b}{d\theta_a}=\frac{m_b}{m_a}
\]

## 2.5 放射と反作用

電磁（双極子、ALD）。D = ξS_1、′ = d/dθ_a：

\[
\boxed{
F^{\rm RR,EM}_m=-\,f\,\frac{\kappa_C}{3}\,\xi\left[\overline{D'''}\,\psi_{m-1}+D'''\,\psi_{m+1}\right]
}
\]

\[
\left.\frac{d\varepsilon}{d\theta_a}\right|_{\rm EM}=-\,f\,\frac23\kappa_C\,|D''|^2
\]

重力（四重極、Burke–Thorne）。Q = ξ²S_2：

\[
\boxed{
F^{\rm RR,GW}_m=+\,f\,\frac{\alpha\,m_a^2}{90}\,\xi^2\left[Q^{(5)}\,\psi_{m+2}+\overline{Q^{(5)}}\,\psi_{m-2}\right]
}
\]

\[
\left.\frac{d\varepsilon}{d\theta_a}\right|_{\rm GW}=-\,f\,\frac{\alpha\,\mu\,m_a}{45}\,|Q'''|^2
\]

（m_a、μ は G = q₀ = c = 1 での質量の数値。）

**源は S_1、S_2 だけに依存する。** 単一の倍音だけの状態（一様なリング）では S_1 = S_2 = 0 で、放射も反作用もゼロ。放射が出るのは隣り合う倍音が重なるとき（S_1 = Σψ_kψ*_{k+1} ≠ 0）で、双極子の回転は倍音間の位相差の進み (ε_k − ε_{k+1})μ/(2m_a) で決まる。これが「位相がロックすると方向の区別がなくなり放出が止まる」の式である。

B1〜B3：f = 0、設定値、1（STATUS §7.2）。

# 3. 円軌道と α の公理（初期値の確認）

単一の倍音 m（S_n = δ_{n0}）での ε = ½ξ′² + 2(m_a/μ)²m²/ξ² − κ/ξ + 共通項。円の条件 ∂ε/∂ξ = 0：

\[
\xi_m=\frac{4(m_a/\mu)^2m^2}{\kappa}=m^2\xi_1,\qquad
\xi_1\approx\frac2\alpha
\]

\[
v_1=\xi_1\rho_1=\frac{2(m_a/\mu)}{\xi_1}\approx\alpha,\qquad
\frac{L}{J_a}=\frac{\mu}{m_a}\xi_1^2\rho_1=2
\]

数値：ξ₁ = 274.25（2/α = 274.07）、ρ₁ = 2.6606×10⁻⁵（α²/2 = 2.6626×10⁻⁵）、2(m_a/μ)²/ξ₁² = 2.6620×10⁻⁵ = ½v₁²。**v/c = α と L = 2J は、ħ = 2J_a の同定と ξ₁ から従う。**

一周あたりの内部位相の進み：2π/ρ₁ = 2/α² ≈ 3.7558×10⁴ サイクル（整数ではない。有理になるかが読み出し）。

# 4. 汎関数の性質（成功条件ではない。読み出しの解釈に使う事実）

単一倍音 m の平衡での位相の進み：

\[
\varepsilon_m(\xi_m)=-\frac{\kappa^2}{8(m_a/\mu)^2m^2}=-\frac{\alpha^2}{2m^2}\left(1+\frac1{C_0-1}\right)^2
\]

隣り合う倍音の相対位相の進み（双極子の回転＝放射の振動数）：(ε_m − ε_{m′})μ/(2m_a)。これらは ħ = 2J_a を置いた時点で汎関数に入っている数で、動力学がどの倍音に落ち着くか・落ち着かないか・呼吸とどう絡むかは結果である。

# 5. 自己相互作用の読み（第七との整合）

第七の定義：**ab に使った同じ写像の両脚に同じ状態 a を入れる**。C_aa = 1 − λ_a²、D_aa = 0。self-field の正則化ではない（第七 §1.3、§9）。

電子型では λ_a = Q_a/m_a ≈ 4.3×10³ で C_aa ≈ −1.8×10⁷ < 0。第七は C < 0 を「実数の準円写像の定義域外」として記録した（n = 4 で C = −0.44）。これは Kerr–Newman の超極限（|Q| > M）と一致する：自己関係は時間的な円軌道を作れず、地平面のない**光的なリング**（半径 a_a、ω_a a_a = c）として実現される。

したがって本書では：

- aa の自己関係 = KN の光的リング。その性質（m_a、J_a、a_a、μ_a = Q_aJ_a/m_a、Q₂ = −Q_aa_a²、M₂ = −m_aa_a²）は定数として入っている。a の自己場のエネルギーは m_a（ADM 質量）の中にある。
- ψ_m は **ab の関係の位相の分布**であって、電荷を軌道上に広げたものではない。位相の分布に対するクーロン自己エネルギーは課さない（量子力学で単一電子の確率分布に自己相互作用がないことと同じ位置）。
- 二次の関係 S_n は放射の源（遠方の場への結合）としてだけ使う。

E–M を文字どおりに読んで ψ_m を電荷の分布とした場合の自己項 (κ_C − κ_G)Σ_n K_n(ξ) S_n ψ_{m−n} と、その核 K_n の表は、付録に比較用の読み出しとして残す（一様なリングで κ_C ξK₀/2 ≈ 1.22 × クーロン束縛。入れれば水素型の準位は実測から大きくずれる）。

# 6. 離散化（積和、割り算なし）

- 節点の時間変数は θ_a。1 節点の進み Δθ_a,k は節点時刻の変分 E_d(k−1) = E_d(k) で決まる（設定しない）。初期値は一周 = 62 節点：Δθ_Y = 2π/62 → Δθ_a,0 = Δθ_Y/ρ₁ ≈ 3.808×10³ rad（約 606 内部サイクル）。

# 8. 初期化で行うこと

1. 入力：Q_a = −3、Q_b = +3、m_a、m_b/m_a、α、f。初期の速さの α からのずれ δ（v₀ = α(1 + δ)、「α の近く」の量）。
2. 導出定数：§0.3。ξ₁ = 4(m_a/μ)²/κ。
3. **初期状態の倍音分布は導出量。** ⟨m⟩ = 1（L = 2J）、ξ = ξ₁、ξ′ = 0 のとき、エネルギーの α からのずれが倍音の広がりを決める：

\[
\langle m^2\rangle-1=\frac{\varepsilon_0-\varepsilon_1}{|\varepsilon_1|}\approx 2\delta
\]

δ = 0 なら単一の倍音 m = 1（すでにロックした状態）。δ > 0 なら ψ_1 を中心に ψ_0、ψ_2 … が √(δ) の振幅で混ざる。節点一つに局在した波（|m − 1| ≤ M で等振幅）は ⟨m²⟩ − 1 ≈ M(M+1)/3 ≈ 331 で非束縛（ε > 0）となり、水素型の初期状態ではない。倍音が決められない場合の判断は別の課題（木原氏）。
4. θ_b = 0、ŝ_a、ŝ_b は run 条件（反平行／平行／0）。
5. 節点時刻の初期値 Δθ_a,0。
6. 相互作用は §2 の積和だけ。

# 付録：E–M を文字どおりに読んだ場合の自己相互作用の核（比較用）

半径 ξ のリング上の 2 点の距離 2ξ|sin(Δ/2)| を a_a（= 1）で正則化：

\[
K_n(\xi)=\frac1{2\pi}\int_0^{2\pi}\frac{\cos n\Delta\ d\Delta}{\sqrt{4\xi^2\sin^2(\Delta/2)+1}},\qquad
\xi K_n(\xi)=\frac1\pi\left[\ln(8\xi)-2\sum_{k=1}^{n}\frac1{2k-1}\right]\ (n\ll\xi)
\]

数値（ξ₁ = 274.25）：ξK₀ = 2.44891、ξK₁ = 1.81230、ξK₂ = 1.60011、ξK₃ = 1.47281、ξK₄ = 1.38190、ξK₅ = 1.31121、ξK₆ = 1.25339、ξK₇ = 1.20448、ξK₈ = 1.16211、ξK₉ = 1.12473、ξK₁₀ = 1.09130、ξK₁₁ = 1.06108、ξK₁₂ = 1.03349（閉じた式と 4 桁一致）。

自己項：ε_self = ((κ_C − κ_G)/2) Σ_n |S_n|² K_n(ξ)。一様なリング（S_0 = 1 のみ）で ε_self/ε_Coulomb = ξK₀/2 = ln(8ξ)/(2π) ≈ 1.22。本書の本文では入れない（§5）。
