# 0. 前提（確定事項）

1. **S を関数にしてよい意味**：係数の中に複雑な閉じた式が残ってよい。係数の式そのものは時間発展の方向で変化しない。時間で変わる部分は、時間 \(T\) を刻み \(\delta\tau\) からの乗算値として状態に持つ。
2. **Einstein–Maxwell 方程式は初期値と係数の導出にだけ使う。** 相互作用中は解き直さない。
3. **単位**：\(G=q_0=c=1\)（\(q_0\) は電荷素量の 1/3）、Gauss 幾何単位（\(4\pi\epsilon_0=1\)）。\(Q_a=-3\)（電子型）、\(Q_b=+3\)（陽子型）。
4. **離散系**：\(\delta\tau\) より下の時間・状態はない。拘束 \(x^2+y^2+z^2-t^2=W^2\)（\(R^2=t^2+W^2\)）は有限の代数関係として厳密に成り立ち、微分の形にしない。
5. **共通時計**：系全体の振動（\(R\) の振動）の刻みが \(\delta\tau\)。1 周期 = 31 刻み × 4 段 = 124 段。
6. **割り算禁止**（状態に依存する量で割らない）、**exp と log を往復しない**（log は初期化だけ）、**予想を成功条件にしない**。
7. **放射の出口**：吸収率 \(f\)（B1：0、B2：初期設定値、B3：1）を恒等状態として持つ。

**注意（将来の誤読防止）**：1 刻み内の 4 段、\(N_{\rm tick}=31\)、初期スピン \(J=\hbar/2=9/(2\alpha)\) は、\(\alpha\) の値と有限位数根 \(m/n=23/124\)（\(124=31\times4\)、\(\lambda_a^{31}=i\)）から予測値として与えたものである。本研究は最小の公理系が自己無撞着になることを条件と考えている。そのため循環のように見えるが、これは隠れたパラメータの導入ではない。任意に与えたパラメータが自己無撞着になるには特定の値でなければならないことを示そうとするものである。

# 1. 導出の基礎：この系の解像度

木原氏が示した原則「系の解像度は 1 周期 124 段であり、それより細かい精度の計算は必要ない（存在しない）」から、次が導かれる。

**(a) 系の大きさと 1 セル。** 1 刻みに光が進む距離は \(c\,\delta\tau=2\pi r/(31\,v)\)。軌道速度 \(v=\alpha\)（初期スピン \(J=\hbar/2\) と \(L=2J\) から）なので \(c\,\delta\tau\approx28\,r\)。系全体が 1 セルの内側にある。

**(b) 補正の大きさ。** 最低次（重力＋クーロンの静的相互作用、四重極・双極子の放射）を超える補正は、すべて「系の大きさ / 波長」\(\sim v/c=\alpha\) の冪の展開であり、1 セルより細かい構造に当たる。具体的には：

| 補正 | 相対的な大きさ | 1 周期あたりの位相に直すと |
|---|---|---|
| 相対論的な補正（\(v^2/c^2\)） | \(\alpha^2\approx5.3\times10^{-5}\) | \(2\pi\alpha^2\approx3.3\times10^{-4}\) rad。1 段 \(2\pi/124\approx5.1\times10^{-2}\) rad の約 1/150 |
| スピン–軌道結合 | \(\sim\alpha^2\) | 同上 |
| スピン–スピン結合（超微細） | \(\sim\alpha^2(M_a/M_b)\) | さらに小さい |
| 各体の時計の歪み \((W_A/R)^2\) | \(\sim10^{-16}\)（\(W\sim3\)、\(R\sim2.4\times10^8\)） | 倍精度の丸め誤差と同程度 |

いずれも 1 周期の中で 1 段に届かず、この系の解像度では存在しない構造である。したがって、この系の係数は最低次の閉じた式で**厳密に**与えられる。これは近似ではなく、系の解像度がそれより細かい区別を持たないことの帰結である。重力の寄与（\(M_aM_b\) の項）はクーロンの \(10^{-2}\)〜\(10^{-6}\) であっても、係数 \(K\) の中に落とさず厳密に入っている。

# 2. v1 の要確認 6 項目の確定

1. **\(R\) の意味と初期値**：\(R\) は曲率半径であり、その空間写像が軌道半径である。円軌道の軌跡の曲率半径は、軌道半径そのものである。したがって \(R\) は a,b の分離 \(r\) と同一であり、状態は一つ（\(\rho=\ln R=\ln r\)）にまとめる。初期値は \(R_0=d_0=L_0^2/(\mu K)\)（\(L_0=2J\)）。v1 の「\(R\) を系の全エネルギーとし、吸収エネルギー分を直接引く」は撤回する。
2. **\(R\) の振動 = 共通時計**：\(R\) を空間のベクトルとして見ると、\(x=R\cos\theta\)、\(y=R\sin\theta\) と振動する（a,b は重心の周りを同じ位相 \(\theta\) で回る）。この振動が系全体の共通時計であり、位相 \(\Theta=e^{i\theta}\) として持つ。
3. **\(R\) の変化**：放射がなければ \(R\) は一定（円軌道）。吸収された放射の分だけ束縛エネルギー \(E=-K/(2R)\) が変わり、それに応じて \(R\) が減る（第六思考実験と同じエネルギー収支）。
4. **\(W_A\) と時計の歪み**：各体の時計の比（赤方偏移）\(z_A=\cos\chi_A\) を、初期データ（厳密な Einstein–Maxwell 場）から求め、\(W_A=R_0\sin\chi_A(0)\) とする。\(W_A\) は恒等。以後 \(\sin\chi_A=W_Ae^{-\rho}\) で導出する。§1(b) のとおり、その運動への影響はこの系の解像度より下なので、\(\chi_A\) は読み出し量であり、係数には入らない。これは定式化の欠落ではなく、解像度の帰結である。
5. **軌道の角振動数**：重力＋クーロンの静的相互作用 \(K/R^2\) との釣り合い \(\Omega=c_\Omega e^{-3\rho/2}\)（\(c_\Omega=\sqrt{M_{\rm tot}C_0}\)）。相対論的な補正は §1(b) により解像度より下。
6. **スピン**：スピン–軌道・スピン–スピン結合は §1(b) により解像度より下なので、\(\mathbf J_A\) は恒等。**4 段**：位相の進みが 1 段あたり \(2\pi/124\) で一定なので、4 段とも同じ S を作用させ、\(\Delta s=\delta\tau/4\) ずつ進める。

# 7. 規則の照合

| 規則 | 本一覧での扱い |
|---|---|
| 係数の式が時間で変化しない | §5 はすべて状態と定数の固定の式 |
| 方程式を解き直さない | 空間微分・右辺評価・RK4 なし |
| 状態に依存する量で割らない | 割り算は §3.2 の定数どうしだけ。\(1/R\) は \(e^{-\rho}\) |
| exp と log を往復しない | log は初期値 \(\ln d_0\) だけ。v1 の \(\ln(1-x)\) の級数は不要になった |
| 拘束を微分にしない | \(R^2=t_A^2+W_A^2\) は各刻み厳密 |
| 乗法更新 | \(\sigma,\Theta,T_\tau\) は積、\(\rho\) は指数の和（値では積） |
| 予想を成功条件にしない | ロック、\(\alpha_{\rm eff}\) 等は §6 の読み出しのみ |
| 重力を落とさない | \(K=M_aM_b-Q_aQ_b\) に厳密に入っている |
