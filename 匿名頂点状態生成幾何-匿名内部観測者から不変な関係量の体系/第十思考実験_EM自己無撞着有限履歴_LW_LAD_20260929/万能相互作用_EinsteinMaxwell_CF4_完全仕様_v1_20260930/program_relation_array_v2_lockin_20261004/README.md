## 2. 二パターンの定義と拠り所

共通：放射は背景との片側の交換（固定点 1 §7）。ロックで方向を持つ関係量が方向を失えば放出が止まる（STATUS §7.1）。その最小形として、放出される割合に有限履歴の方向和 \|H\|² を掛ける。有限履歴はこの系列の題（EM 自己無撞着**有限履歴** LW/LAD）の有限履歴で、窓 N は入力。

| パターン | 損失の行き先 | 拠り所 | 予想される向き（成功条件にしない） |
|---|---|---|---|
| **A 時計側** | 節点の時計 x₃ᵃ（a の位相の一節点の増分） | 固定点 3：エネルギーは位相の進み率。θ = ε の一節点の位相（固定点 3 §2.3）なので、時計側の関係ノルムは θ そのもの。損失を時計側から取れば x₃ᵃ が縮む。v1 P5「x₃ᵃ か θ の読み出し」の x₃ᵃ 側 | 2θ/2π ∝ x₃ᵃ が減る → 初期値より小さい k/N へ向かう |
| **B 軌道側** | 反対称の不変量 m（角運動量） | v1 の P4 そのまま（ε の減りが ΔE に一致）。\|H\|² を掛けるだけ | m が減り ξ ∝ m² が縮み θ ∝ 1/ξ² が増える → 初期値より大きい k/N へ向かう |

### 5.3 読み取り（事実から従うことだけ）

1. **二パターンは同じブレーキ、逆向きの進み。** 損失率は両方とも v1 の sin²θ_rad に \|H\|² を掛けた値になり、\|H\|² は Dirichlet 核 \|sin(Nπ·frac)/(N sin(π·frac))\|² と一致する（N = 62：0.0108、124：0.00269、248：0.00067、93：7×10⁻¹⁰。手計算と一致）。進む向きは A が 2θ/2π を減らし（x₃ᵃ ∝ 2θ/2π が縮む）、B が増やす（m が減り ξ ∝ m² が縮み θ ∝ 1/ξ²）。A は軌道（ξ、m）に触れず、B は軌道を縮める。
2. **50000 節点では k/N に届かない。** 最寄りの k/N までの距離が 10⁻³ の桁、進みが 10⁻¹¹/節点の桁なので、届くには 10⁸ 節点の桁（約 4×10⁶ 周）が要る。本走行で見えたのは「\|H\|² の分だけ放射が遅くなった v1」であって、引き込みの到達ではない。近づくほど \|H\|² ∝ (frac − k/N)² で速度が落ちるので、到達は漸近（1/n）。
3. **窓を近再帰に合わせると凍結する。** N = 93 では初期から \|H\|² ≈ 10⁻⁹ で、損失率は 10⁻¹⁶/節点（倍精度の床）。A は完全に止まり、B は窓が埋まるまでの放射で軌道に 10⁻⁶ の離心が入り、その呼吸で 2θ/2π が ±4×10⁻⁸ 揺れる（図の B_N93）。どの k/N で止まるかは窓 N が決める。7/18 論文の読み直し §5「124／122 は評価窓が選んだ」と同じ構造が、ここでも窓の選択として現れた。
4. **x₃ᵃ の役割の違い。** A では節点の時計が引き込みの変数になり（P5 の x₃ᵃ 側）、軌道は E–M のまま保たれる。B では節点の時計は定数のままで、軌道側が動く。E–M の二体問題として「水素が安定に存在する」に対応するのは、軌道が保たれる A の側。ただし A が到達する点（frac が減る側の k/N）は、B の点（増える側）と異なる。
5. **窓 N は入力で、状態から読めていない**（P7）。引き込みを本当に閉じるには、N を外から置かずに配列から決める必要がある。候補は、\|H\| が最小になる窓長を配列自身が選ぶこと（分母の探索）だが、本走行では置いていない。

決定済みの設計で実装に要るもの（本 README で新しく決めたことは一つもない）：
- 動的な変数は節点の時計 δτ（x₃ᵃ）。相対論の効果（F）で変わる（木原 10/1 00:23）。
- ロックの条件は、a の位相の進み、b の位相の進み、関係の位相の進みの三つの差が整数関係になること（STATUS §7.1）。窓は要らない。
- 放出の源は、方向を持つ関係量を関係の位相の配位（aa・ab・bb）の関数として書いたもので、整数関係で方向を失って 0 になる（STATUS §7.5）。背景は B3（等方な吸収体、戻らない）。
- 受け取り（10/3 の気づき）は大きさの項で、等方・無位相。安定の機構とは別の項。

v2 の走行は、D1・D2・D4 の代用品で何が起きるかの記録としてだけ残す。
