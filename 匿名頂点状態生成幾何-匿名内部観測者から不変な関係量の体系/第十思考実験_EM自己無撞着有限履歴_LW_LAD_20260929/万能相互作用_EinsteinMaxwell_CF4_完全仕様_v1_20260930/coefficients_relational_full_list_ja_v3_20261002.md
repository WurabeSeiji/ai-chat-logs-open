# 2. 運動方程式

## 2.1 倍音 ψ_m

\[
\boxed{
\frac{d\psi_m}{d\theta_a}=-\,i\,\frac{\mu}{2m_a}\Big[\varepsilon(\xi,\pi,m,s_a,s_b)\,\psi_m+(V_{\rm RR}\psi)_m\Big]
}
\]

ε(ξ,π,m,…) は §1 の値を m ごとに評価したもの（倍音 m の固有の位相の進みは ε_m μ/(2m_a) rad／内部 rad）。**倍音を混ぜる項は放射反作用 V_RR だけ**（§2.5）。

## 2.2 呼吸 ξ、運動量 π（正準）

\[
\boxed{\frac{d\xi}{d\theta_a}=\frac{\partial\bar\varepsilon}{\partial\pi},\qquad
\frac{d\pi}{d\theta_a}=-\frac{\partial\bar\varepsilon}{\partial\xi}},\qquad
\bar\varepsilon\equiv\sum_m|\psi_m|^2\,\varepsilon(\xi,\pi,m,s_a,s_b)
\]

## 2.3 スピン（歳差。軸にそろったスピン s_A = ±1 は歳差しない）

\[
\frac{d\hat s_a}{d\theta_a}=\boldsymbol\Omega_a\times\hat s_a,\quad
\boldsymbol\Omega_a=\frac{\langle m\rangle}{\xi^3}\Big[2\alpha(2g-1)+\frac{2\alpha}{C_0-1}(4g-1)\Big]\hat z
-\frac{1}{\xi^3}\Big[2\alpha(g-1)+\frac{2\alpha m_a^2}{9}\Big]\big[\hat s_b-3(\hat s_b\!\cdot\!\mathbf n)\mathbf n\big]
\]

\[
\boldsymbol\Omega_b=\frac{\langle m\rangle}{\xi^3}\Big[2\alpha\big((g-1)^2+2(g-1)\big)+\frac{2\alpha}{C_0-1}\big(4(g-1)+3(g-1)^2\big)\Big]\hat z
-\frac{1}{\xi^3}\Big[2\alpha(g-1)+\frac{2\alpha m_a^2}{9}\Big]\big[\hat s_a-3(\hat s_a\!\cdot\!\mathbf n)\mathbf n\big]

（⟨m⟩ = Σm|ψ_m|²。第 1 括弧がスピン–軌道（電磁＋重力）、第 2 括弧がスピン–スピン（電磁＋重力）。Ω_A = a_a·∂(με)/∂S_A、S_A = J_aŝ_A なので Ω_A a_a の係数は §1 の係数 ×(μ/m_a)/J_a·a_a = ×1/g：κ_C/g = 9/(m_aa_a) = 2α、κ_G/g = m_b/a_a = 2αm_am_b/9 = 2α/(C₀−1)、κ_G(g−1)/g = m_a/a_a = 2αm_a²/9。数値：2α = 1.4595×10⁻²、2α/(C₀−1) = 1.4590×10⁻⁶、2αm_a²/9 = 7.95×10⁻¹⁰。直接の式 Ω_a^{SO,G} = (G/r³)[2 + 3m_b/(2m_a)]L、Ω_a^{SS} = (Q_aQ_b/(m_am_br³))[S_b − 3(S_b·n)n] + (G/r³)[3(S_b·n)n − S_b] と一致する。）

## 2.5 放射反作用（B1〜B3 = f 倍）

電磁（双極子、Abraham–Lorentz–Dirac。相対座標の反作用 μr̈ = 6 r⃛、双極子 d = −3r、E_RR = (2/3)d⃛、V = −d·E_RR）。′ = d/dθ_a：

\[
\boxed{
(V_{\rm RR}^{\rm EM}\psi)_m=-\,f\,\frac{\kappa_C}{3}\,\xi\Big[\overline{D'''}\,\psi_{m-1}+D'''\,\psi_{m+1}\Big]},\qquad
\frac{d\bar\varepsilon}{d\theta_a}\Big|_{\rm EM}=-\,f\,\frac23\kappa_C\,|D''|^2
\]

重力（四重極、Burke–Thorne。Φ_BT = (1/5)Q_ij^{(5)}x_ix_j、Q_ij = μ(r_ir_j − δ_ijr²/3)）：

\[
\boxed{
(V_{\rm RR}^{\rm GW}\psi)_m=+\,f\,\frac{\alpha\,\mu\,m_a}{90}\,\xi^2\Big[Q^{(5)}\,\psi_{m+2}+\overline{Q^{(5)}}\,\psi_{m-2}\Big]},\qquad
\frac{d\bar\varepsilon}{d\theta_a}\Big|_{\rm GW}=-\,f\,\frac{\alpha\,\mu\,m_a}{45}\,|Q'''|^2
\]

（μ、m_a は G = q₀ = c = 1 での質量の数値。αμm_a/90 = μ/(20a_a)。）

源は S_1、S_2 だけに依存する。単一の倍音（一様なリング）では S_1 = S_2 = 0 で放射も反作用もゼロ。放射が出るのは隣り合う倍音が重なるときで、双極子の回転は倍音間の位相差の進み [ε(m) − ε(m+1)]μ/(2m_a) で決まる。これが「位相がロックすると方向の区別がなくなり放出が止まる」の式である。

# 5. 自己相互作用の読み（第七との整合）

第七の定義：**ab に使った同じ写像の両脚に同じ状態 a を入れる**。C_aa = 1 − λ_a²、D_aa = 0。self-field の正則化ではない。

電子型では λ_a = Q_a/m_a ≈ 4.3×10³ で C_aa ≈ −1.8×10⁷ < 0。第七は C < 0 を「実数の準円写像の定義域外」として記録した。これは Kerr–Newman の超極限（|Q| > M）と一致する：自己関係は時間的な円軌道を作れず、地平面のない**光的なリング**（半径 a_a、ω_aa_a = c）として実現される。

したがって：

- aa の自己関係 = KN の光的リング。その性質（m_a、J_a、a_a、μ_a = Q_aa_a、Q₂ = −Q_aa_a²、M₂ = −m_aa_a²）は定数として T13・T17・T19・T21 に入っている。a の自己場のエネルギーは m_a の中にある。
- ψ_m は **ab の関係の位相の分布**であって、電荷を軌道上に広げたものではない。位相の分布に対するクーロン自己エネルギーは課さない。
- 二次の関係 S_n は放射の源としてだけ使う。

# 8. 初期化で行うこと

1. 入力：Q_a = −3、Q_b = +3、m_a、m_b/m_a、α、f。初期の速さの α からのずれ δ（v₀ = α(1+δ)、「α の近く」の量）。
2. 導出定数：§0.4。ξ₁ を §3 の全項で解く（8 次ではなく §1.2 の多項式の根を一度だけ求める）。
3. **初期状態の倍音分布は導出量。** ⟨m⟩ = 1（L = 2J）、ξ = ξ₁、π = 0 のとき、エネルギーの α からのずれが倍音の広がりを決める：⟨m²⟩ − 1 ≈ 2δ。δ = 0 なら単一の倍音 m = 1（すでにロックした状態）。δ > 0 なら ψ_1 を中心に ψ_0、ψ_2 … が √δ の振幅で混ざる。節点一つに局在した等振幅の波は ⟨m²⟩ − 1 ≈ 331 で非束縛となり、水素型の初期状態ではない。倍音が決められない場合の判断は別の課題（木原氏）。
4. θ_b = 0、ŝ_a、ŝ_b は run 条件（反平行／平行／0）。
5. 節点時刻の初期値 Δθ_a,0 = 3807.1 rad。
6. 相互作用は §2 の積和だけ。E–M を解き直すことはない。
