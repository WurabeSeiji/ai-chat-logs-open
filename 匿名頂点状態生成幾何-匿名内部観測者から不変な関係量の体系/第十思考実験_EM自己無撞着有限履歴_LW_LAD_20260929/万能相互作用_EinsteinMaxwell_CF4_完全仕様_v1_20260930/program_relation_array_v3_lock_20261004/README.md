## 2. 本プログラムで Claude が読んだ点（決定の読み方。新しい装置ではない）

## 4. 予告（走行前に書く。成功条件にしない）
Δa ≡ 0 は構成で成り立つ。Δb は x₃ᵇ = (m_b/m_a)(F_b/F_a)x₃ᵃ の端数で決まり、放射で ξ・m が動くと掃引される（θ と F_b/F_a の両方から）。Δb ≡ 0 を通る所で s → 0 となり放出が止まる。近づき方は s ∝ Δb² なので漸近。Δb の掃引は 10⁻⁴ rad/節点の桁、一周 2π に 10⁴〜10⁵ 節点の桁なので、100000 節点で最初の零点に届く見込み。

### 5.2 閉じの確認（lock on、f = 0、δ = 0、2000 節点）
x₃ᵃ = 10153.897725 = 2π·1616 + 2θ（2θ = 0.270268）。Δa = 2×10⁻¹³（恒等的に 0）。Δb = +2.4208 rad、s = 0.5838 で一定。ξ・m・ε 不変。放射なしなので何も動かない。

- **Δb は単調に 0 へ向かい、1/Δb が n に比例する**（n ≥ 30000 で 1/Δb = 0.268 + 2.853×10⁻⁵ n、最大残差 0.03）。s ∝ Δb² なので接近は漸近（1/n）。放出は節点ごとに減り続ける。
- ξ(n) ≈ 273.6574 + 7775/(n + 9400)（n ≥ 50000、残差 4×10⁻⁴）。**収束先 ξ_lock = 273.657、ξ₁ に対して −1.95×10⁻³。** m → 0.999025。収束先での一周の節点数 1/0.04313 = 23.2。
- 放出したエネルギーの和 ＝ ε の変化（後半 50000 節点で 5.8217×10⁻⁹ ＝ 5.8217×10⁻⁹）。帳簿は閉じている。
- Δa は全節点で 2×10⁻¹³。x₃ᵃ は 10153.897725 → 10153.898411（2θ の分だけ動いた。δτ は動的）。x₃ᵇ/x₃ᵃ は 1836.201531 → 1836.201614（F の分）。

### 5.4 離心軌道（lock on、f = 1、δ = 0.065、100000 節点 ＝ 3514 周）
- ξ は呼吸し、その範囲が 274〜366 から 297〜325 に狭まる（円軌道 ξ_c(m = 1.0633) = 310 へ向かう円化）。m は 1.065 → 1.0633、ε は −2.3056×10⁻⁵ → −2.3506×10⁻⁵（離心の分のエネルギーが出ている）。
- θ は呼吸の中で 0.08〜0.14 に振れるので、x₃ᵇ は一呼吸の中で約 200 rad 動き、**Δb は一呼吸で約 35 回 2π を掃く**。s は 0〜0.67 を往復し、瞬間的に 10⁻⁸ を切る節点はあるが留まらない。三位相の整数関係は離心軌道では節点ごとに成り立ちようがなく、放出が続く。
- 100000 節点ではロックに達していない。円化が先に進み、円に近づけば §5.3 の機構に移る見込み（未走行）。

### 5.5 読み取り（事実から従うことだけ）
1. **決定済みの機構は、円軌道で片側の漸近的なロックを与える。** Δa は閉じで恒等的に 0。残る Δb は放射による ξ・m の変化で掃引され、0 に向かうにつれ源の因子 s ∝ Δb² で放出が消え、軌道は ξ_lock に収束する。ロックは外から置いた周期ではなく、三位相の整数関係の到達点として出た。
2. **ロックの軌道は K（継承した節点の周数 1616）と質量比で決まる。** Δb ≡ 0 は「b の時計の一節点の進みの端数 ＝ 関係の進み 2θ/2π」で、x₃ᵇ = (m_b/m_a)(F_b/F_a)(2πK + 2θ) の端数が条件。K を変えると ξ_lock が変わる。K の自己無撞着な値（9/30 23:01 の課題）は本走行の外。
3. **接近は 1/n。** 10⁵ 節点（4000 周）で Δb = 0.32 rad、s = 0.017。これは 10/1 17:45 の「準安定、定常波に見えるまで多数回の繰り返しが要る」に当たる形。
4. **離心軌道は先に円化する。** 三位相の関係は一呼吸の中で保てないので放出が続き、離心のエネルギーが先に出る。
5. v2 の窓 N、|H|²、パターン B はどこにも使っていない。
