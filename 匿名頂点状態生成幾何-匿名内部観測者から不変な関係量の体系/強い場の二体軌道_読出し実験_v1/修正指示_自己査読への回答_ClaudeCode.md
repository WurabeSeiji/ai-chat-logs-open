## 2. [9] 読み出しのモデル計算の刻み — 先に判別計算 G1 を行う

読み出しのモデルは1周あたり 500 刻み、生成は約 4000 刻みで、刻みの影響を確かめた記録が無い。D2（最も強い場）だけで刻みを 2000 にして読み出し直し、結果の変化を見る。約 12 分。

```
cd 強い場の二体軌道_読出し実験_v1
python -c "import sys, readout_binary_pn as R; R.MODEL_STEPS_PER_ORBIT = 2000; sys.argv = ['readout_binary_pn.py', '--datasets', 'D2', '--out', 'results_steps2000']; R.main()"
```

- 出力先は `results_steps2000/` にする。`results/` は上書きしない。
- `results/summary.csv` と `results_steps2000/summary.csv` の D2 の全行について、readout の差を「差 ÷ 正解」と「差 ÷ sigma」で表にする（sigma が空の行は前者だけ）。
- `results_steps2000/` は作業用なので、確認後に削除してよい（残す場合は README に一行書く）。

結果に応じて §7.4 に項目を1つ追加する（2番目の項目 `読み出しでは、データの生成と同じ運動方程式を使った。…` の直後）。

（a）差 ÷ 正解の最大が $10^{-5}$ 以下、かつ差 ÷ sigma の最大が 0.1 以下のとき：
`- 読み出しのモデル計算の刻みは1周あたり 500 で、生成の約 4000 より粗い。D2 で刻みを 2000 にして読み出し直すと、読み出した値の変化は最大で正解の X 倍（1σ の Y 倍）で、読み出しの誤差より十分小さかった。`
（X、Y は実測値を有効2桁で入れる。）

（b）それより大きいとき、または G1 を実行できないとき：
`- 読み出しのモデル計算の刻みは1周あたり 500 で、生成の約 4000 より粗い。この刻みの積分誤差が読み出しの誤差に与える寄与は、本稿では別に確かめていない。`
（b）で差が読み出しの誤差と同程度に大きい場合は、§7.4 に書くだけでなく、その数値を報告して止まる（本文の §6 の数値には手を付けない）。
