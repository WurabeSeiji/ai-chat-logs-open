# 数値実験02 読出し：強い場の2体の観測1・観測2から、2体の状態を読み出す（v1.0.0）

`強い場の二体軌道_観測1観測2データ生成_v1` で作った観測データ（D1〜D3）から、G = c = M = 1 の2体の状態が実際に読み出せるかを確かめる数値実験。読出しは `data/input` だけを使い、正解 `data/truth` は最後の照合でだけ読む。

## 実行方法

```
python readout_binary_pn.py        # 読出しと照合（D1〜D3、全体で約11分）
python plot_readout_results.py     # 図（figures/ に SVG と PNG、日本語版と英語版）
```

- 必要なもの: Python 3、numpy、matplotlib。このフォルダと生成フォルダを同じ親フォルダに置く（`--gen` と `--data` で変更可）。
- 生成と同じ運動方程式（2PN + 2.5PN）を生成プログラムから読み込んで使う。
- 当てはめごとに `results/cache/` に途中結果を保存し、止まっても続きから再開する。

## 何から何を読むか

| 読み出す量 | 使う観測 | 手がかり |
|---|---|---|
| 質量比 q、どちらが重いか | 観測1 | 重心: X1 = C + (m2 + 1PN補正)(X1 − X2) |
| 軌道の形 a, b（e） | 観測1 / 観測2 | 近点移動の大きさと、近点距離と遠点距離の比（観測2では振幅の極大と極小の比） |
| ν | 観測1 / 観測2 | 動径周期の減少（重力波の放射） |
| T_M（M の秒数） | 観測1 / 観測2 | 動径周期の秒数 ÷ モデルの周期（M 単位） |
| 距離 D | 観測1 / 観測2 | 角度の大きさ ÷ M 単位の大きさ、重力波の振幅 |
| r(t)、経過時間 t | 観測1 / 観測2 | 読み出した尺度と T_M、または再構成した軌道 |
| τ_A(t), τ_B(t)、レーダー距離 d_A, d_B | 読み出したパラメータ | 再構成した軌道で dτ/dt = 1 − m_相手/r − v²/2 を積分。d = r dτ/dt |

方法: 近点通過ごとに特徴量（時刻、方向または位相、近点距離と遠点距離または振幅の極大と極小）を取り出し、同じ運動方程式のモデル軌道から同じ手順で取り出した特徴量の列を当てはめる。モデル軌道は観測と同じ時刻で標本化して取り出すので、取り出し方に由来する偏りは打ち消し合う。非線形パラメータは a, e（, ν）、線形パラメータは時刻の原点、T_M、方向の原点、尺度。誤差（1σ）は当てはめの共分散から見積もる。

## 結果（相対誤差 |読出し − 正解| / 正解）

正解: D1 = a 120, b 112, q 4 / D2 = a 30, b 27, q 1（最も強い場）/ D3 = a 60, b 50, q 2。観測の分解能は1回あたり 1/1000。

| q | 重力波（ν から） | 7.9e-4 | 6.0e-2 | 3.3e-3 |
| ν | 重心（観測1） | 1.2e-4 | 1e-8 | 1.1e-5 |
| ν | 周期の減少（観測1） | 4.3e-3 | 1.4e-4 | 9.1e-4 |
| ν | 重力波 | 4.8e-4 | 8.6e-4 | 1.1e-3 |
| a | 観測1 / 重力波 | 4.4e-4 / 1.0e-3 | 1.8e-4 / 5.1e-5 | 2.4e-4 / 6.3e-4 |
| e | 観測1 / 重力波 | 3.2e-4 / 7.0e-4 | 1.4e-4 / 5.4e-4 | 1.3e-4 / 6.8e-4 |
| T_M | 観測1 / 重力波 | 6.6e-4 / 1.5e-3 | 3.1e-4 / 4.5e-6 | 3.5e-4 / 9.0e-4 |

| r(t) の二乗平均 | 再構成（観測1 / 重力波） | 4.6e-4 / 1.1e-3 | 3.9e-4 / 3.3e-4 | 3.0e-4 / 7.8e-4 |

- どちらの天体が重いかは D1、D3 とも正しく判定（D2 は等質量なので対象外）。
- ※ D2 の τ_A − τ_B と d_A − d_B は正解が 0。観測1からの読出しは τ_A の 5.7e-6、d_A の 5.1e-6。重力波からは τ_A の 1.8e-3（読み出した ν = 0.24979 が 0.25 よりわずかに小さく、質量差 0.03 として再構成されるため）。
- 読み出した値の例: D1 の τ_A − τ_B は 1853.2 M（正解 1852.6 M）、D3 は 778.85 M（正解 778.90 M）。
- 当てはめの χ²/自由度は 1.05〜1.09。誤差の見積もりに対する実際の誤差（pull）はおおむね ±2 以内。

## 注意

- 読出しは、生成と同じポストニュートン近似（2PN + 2.5PN）の運動方程式を既知として使う。この範囲での、観測量からパラメータが一意に決まるかの確認である。
- 重力波だけからの質量比は ν から求めるので、等質量の近くでは誤差が大きくなる（D2 で 6%）。どちらの天体が重いかは重力波だけでは決まらない。
- 重力波から読んだ e は3例とも正の側に 5〜7e-4 ずれている（pull 2.5〜3.2）。振幅の極大・極小の値を雑音のあるデータから求めるときの偏りで、雑音のないモデル側では打ち消されない。a と T_M（重力波）のずれもこれに連動している。
- レーダー距離はシャピロ遅延を除く1PN近似（d = r dτ/dt）で定義した。
- 図は `plot_readout_results.py` で作る（入力は results/ の summary.csv, features.csv, reconstruction.csv の3つだけ）。
