# 二体を読もうとしたら、観測者が三つ目の状態として現れました――軌道と重力波から質量比・距離・時間を読み出す、第三思考実験

## 前回の続きです

前回の記事では、意味をまだ決めていない二つの値のまま、線形のルールからクーロン型の逆二乗の力を読み出しました。

引力と斥力と中性は、別々のルールを入れなくても、同じ一つの仕組みから出てきました。

その一方で、二つの値だけでは書けないものも、はっきりしました。

質量比が読めない。  
電荷比が読めない。  
二体を同じ地図の上に置いて比較することもできない。

前回の記事の最後を、私はこう結びました。

「次は三体です。」

今回は、その続きです。

ただし、最初から三体問題を解こうとしたわけではありません。

二体の状態を、外から答えを教えずに読み出そうとした。

すると、そこに観測者が必要になりました。

そして、その観測者自身も状態だと数えるなら、系にはすでに三つの状態がありました。

---

## 今回の問いは、「二体の軌道から、二体の状態を読み戻せるか」です

二つの天体 A、B が運動しているとします。

生成側では、質量比や軌道の形、時間尺度、距離などを決めて、観測データを作ります。

しかし読み出す側には、その正解を渡しません。

読み出す側が知っているのは、

G = c = M = 1

という単位系と、既知の二体重力のモデルです。

そして渡される観測は二種類だけです。

一つ目は、遠方の観測者 C から見た、二つの天体 A、B の天球上の位置です。

二つ目は、その連星が出す重力波の二つの偏光です。

この観測だけから、

どちらが重いのか。  
質量比はいくつか。  
軌道はどんな形か。  
二体の距離は時間とともにどう変わるか。  
二つの時計はどれだけ違って進むのか。

そこまで読み戻せるかを調べました。

---

## 何も知らない、という意味ではありません

ここは今回、かなり慎重に区別しました。

読み出す側が知らないのは、生成側で使った a、b の値や、質量比などの正解です。

物理法則まで知らないわけではありません。

読み出しには、2PN の二体運動、2.5PN の重力波放射による軌道減衰、重心の関係、重力波の波形、固有時間の進み方という、既知の重力理論を使います。

つまり今回調べたのは、

「法則は知っている。しかし、実際にその系がどんな状態なのかは知らない」

という条件で、観測から状態を逆算できるか、という問題です。

生成した正解ファイルは、読み出しが終わるまで見ません。

最後にだけ答え合わせをします。

---

## 二つの天体を別々に見ると、質量比が読めました

最初の観測は単純です。

観測者 C から、A と B の位置を同じ天球座標の上で追います。

二つの天体は重心のまわりを動いています。

重い天体は重心の近くを、小さく動く。  
軽い天体は遠くを、大きく動く。

二つを同じ座標、同じ時計で比較できれば、その動きの非対称性から質量比を読むことができます。

これは前回の思考実験で読めなかったものです。

前回は「二体の相対運動」しかありませんでした。

相対運動だけを見ると、二つの質量は一つの組み合わせにまとまってしまい、どちらがどれだけ重いのかを分離できません。

今回は違います。

観測者 C が、A と B を同じ座標の上で比較する基準を与えました。

その追加の関係情報によって、質量比が読めるようになりました。

---

## 強い場の軌道そのものにも、質量比が書き込まれていました

さらに一般相対論の補正を入れると、相対軌道そのものにも質量比の情報が現れます。

近点の向きが少しずつ進む。

重力波を出すことで、軌道の周期が少しずつ短くなる。

この進み方や縮み方は、軌道の大きさだけではなく、二つの質量の組み合わせにも依存します。

そこで、

近点がどれだけ進むか。  
周期がどれだけ短くなるか。  
近点と遠点の距離がどう変化するか。

という時系列を読み、既知の二体モデルに当てはめました。

重力波についても同じです。

波の強さ、位相、周期の変化から、軌道の形と質量の組み合わせを逆算します。

---

## 三つの異なる連星で試しました

数値実験では、質量比の異なる三つのケースを用意しました。

質量比 1。  
質量比 2。  
質量比 4。

読み出し側には、この値を知らせません。

その状態で、

天球上の二体位置から読む方法と、  
重力波だけから読む方法を、

別々に試しました。

結果として、質量比、軌道の形、時間尺度、距離、相対距離、二つの固有時間の差などを再構成できました。

多くの量では、正解に対する相対誤差はおおむね 10^-4 から 10^-3 程度でした。

## 一つ、目立って悪い結果も残しました

すべてが同じ精度で読めたわけではありません。

質量が等しいケースでは、重力波から読み出した量を質量比 q に戻すところが不安定になり、約6%のずれが残りました。

これは計算が完全に失敗したというより、等質量の極限では、途中の量の小さな誤差が q に変換すると大きく増幅されるためです。

この結果も、そのまま残しました。

前二稿と同じく、うまくいった結果だけを選んではいません。

何が読めて、どこで読み出しが弱くなるのかも、今回の実験結果です。

---

## そして、観測者 C が問題になりました

ここからが、今回もっとも面白かったところです。

最初、C はただの観測者として置いていました。

A と B から十分遠く、二体の軌道面をほぼ正面から見る位置に置きます。

C から見ると、A と B は非常に小さな角度の中に収まっています。

今回の設定では、その視野角は最大でもおよそ 2×10^-4 rad 程度です。

一方で、A と B の側から見れば、C は二体を結ぶ方向とはほぼ直角の方向にあります。

つまり、

C からは A と B の小さな差を読むことができる。

しかし C は、A と B の内部の相対運動からは非常に遠くにいる。

この幾何によって、二体への影響を小さくしたまま、二体の関係を読み出すことができます。

本稿では C を「試験観測者」として扱い、C 自身が A、B の運動に与える反作用は無視しました。

---

## でも、C も状態ではないのか

ここで、最初の設計図に戻ります。

状態とは、最初から「電子」「惑星」「観測装置」と名前を付けたものではありませんでした。

区別可能で、自由度を持つものです。

そう考えると、観測者 C も、

位置を持つ。  
向きを持つ。  
時計を持つ。

一つの状態です。

すると、今回の系は実は、

A  
B  
C

という三つの状態を持っています。

そして関係も、

A と B  
A と C  
B と C

の三つになります。

二体の状態を読み出そうとしただけなのに、三つ目の状態が自然に入り込んできました。

---

## ここでは、三体問題には進みません

ただし、今回の論文ではここで止めました。

C を含めた三つの状態を、すべて同じ力学の内部に入れてはいません。

C は十分遠く、十分影響の小さい試験観測者として置いています。

A と B と C が互いに影響を与え、

A-B  
A-C  
B-C

という三つの関係が同時に時間発展したとき、何が起きるのか。

それは今回の問題ではありません。

次の思考実験です。

前回の記事の最後に「次は三体です」と書きました。

今回、いきなり三体の運動方程式を解くところへは行きませんでした。

二体をきちんと観測しようとしただけで、まず観測者という第三の状態が必要になった。

三体問題への入口は、そこにありました。

---

## 分かったこと

今回の結果を一行でつなぐと、こうなります。

二体の相対運動だけでは読めない量があった。

そこに共通の座標と時計を持つ観測者 C を加えると、質量比を含む二体の状態を読み出せた。

そして C 自身も状態だと数えるなら、系はすでに三状態になっていた。

つまり、

「二体をどう動かすか」

を考えていた問題が、

「三つの状態のあいだの関係を、どう閉じるか」

という問題に変わりました。

次は、そこへ進みます。
