# exchange_general_20261006 — 電荷の符号を入力にした二体の数値解法と、閉じた式の一式との対照実験

目的：固定した水素の一式 `../exchange_rel_20261005/`（準位を閉じた式で与える）を、電荷の符号 s = sign(q_a q_b) を入力にして
準位を径方向 Dirac 方程式の数値解で作る一般の解法に置き換え、同じ条件（水素、s = −1）で結果が一致するかを対照する。
一致すれば、この解法を固定し、同じコードで s = +1（e⁻e⁻、p⁺p⁺ など同符号）を走らせられる。

木原氏の問い（2026-10-06）：「準位と放射だけで解けるか」。同符号では束縛準位が無く、準位模型には表現する対象が無い。
その事実をプログラムの出力として残す（`audit_general_repel.txt`）。

## 実行

```
./run_all.sh
```

`control_report.md`（対照実験）、`audit_general_attract.txt`（s = −1）、`audit_general_repel.txt`（s = +1）、`SHA256SUMS` を作る。
共通の関数（角運動量代数、M1、反跳の高次、マスター方程式の構造、定数）は `../exchange_rel_20261005/exchange_cascade.py` から import する
（シリーズ内再現性規約：コピー → 対照 → import。対照は本文書 §対照実験）。所要約 20 秒。

## 解法（two_body_general.py）

| 部分 | 固定一式（閉じた式） | 本解法（数値） |
|---|---|---|
| 一体の相対論的準位 | Dirac–Coulomb の f(n,j) | 径方向 Dirac 方程式 G′ = −κG/r + (2−η−V)F、F′ = (η+V)G + κF/r（V = sα/r、質量 μ、束縛エネルギー η = 1−ε を変数）を両側から打ち込み、接続点での Wronskian の零点を Brent 法で求める。節点数 n−ℓ−1 で状態を同定。閉じた式と相対 1e-12〜4e-11 |
| 反跳（Barker–Glover、Breit、Salpeter、(Zα)⁶・⁷） | 閉じた式 | 同じ式に数値の η を入れる（Salpeter 以降は n, ℓ の表） |
| 重力 1PN | 水素の期待値公式 | Schrödinger 方程式の数値解（同じ打ち込み法）から ⟨1/r⟩、⟨1/r²⟩、⟨1/r³⟩、\|ψ(0)\|²、∫R′²r dr を数値積分（公式と相対 1e-9〜1e-11）。項の式は同じ |
| 超微細 | 非相対論 Fermi–Breit の式 | 相対論的（点双極子、Breit 1930）：(g_pα/(m_p/m_e))·κ/(j(j+1))·∫GF/r² dr·μ³·⟨I·J⟩。1s で閉じた式の 1 + (3/2)α² 倍、2s で 1 + (17/8)α² 倍（Breit の相対論補正） |
| E1・E2 の動径積分 | Schrödinger の Laguerre 関数 | Dirac の ∫(G_aG_b + F_aF_b) r^k dr。2p→1s で閉じた式の 0.99998 倍（相対論補正） |
| 角度因子、M1、二光子、生成行列、τ = −R⁻¹p₀、Radau | 同じ関数を import | 同じ |

束縛状態の探索は n ≤ 5 の全 κ について行い、斥力（s = +1）では束縛解が無いので準位表が空になる。

## 粒子対の指定と同符号の走行（2026-10-06、木原氏の指示：粒子以外の条件は同じ）

`python3 two_body_general.py ep|ee|pp`。電荷は q₀ = e/3 単位、質量は m_e 単位。

| 対 | q_a, q_b | m_a, m_b | クーロン結合 (q_aq_b/9)α | 重力結合 α_G m_a m_b | 正味 | 重力/クーロン | 結果 |
|---|---|---|---|---|---|---|---|
| ep（水素） | −3, +3 | 1, 1836.15 | −α | +α_G·1836 | 引力 | 4.4e-40 | 束縛準位 50、上の対照実験（`audit_general_ep.txt`） |
| ee | −3, −3 | 1, 1 | +α | +α_G | 斥力 | 2.4e-43 | 束縛準位 0（`audit_general_ee.txt`） |
| pp | +3, +3 | 1836.15, 1836.15 | +α | +α_G·1836² | 斥力 | 8.1e-37 | 束縛準位 0（`audit_general_pp.txt`） |

同符号では正味のポテンシャル [(q_aq_b/9)α − α_G m_a m_b] ħc/r の係数が正で、全ての r で斥力。斥力だけのポテンシャルに束縛状態が無いのは厳密で、
重力はクーロンの 10⁻⁴³〜10⁻³⁷ 倍なので覆せない。準位と率の模型には表現する対象が無く、初期状態 5p₃/₂ F=1 に当たる準位も無い。放出 0、終状態なし。
これが「準位と放射だけで解けるか」への、この一式自身の答えである。

E–M が予言するのは散乱：Rutherford／Mott（同種粒子は a↔b 交換の干渉）の反跳。同種粒子では重心系の電気双極子が恒等的に消えるので
制動放射は四重極だけ、重力波と電気四重極の放出比は 4Gm²/q² = 4 × (重力/クーロン)（ee で 9.6e-43、pp で 3.2e-36）。

## 散乱の枝：断面積とスペクトル（scattering_same_sign.py → scattering_same_sign.md）

途中の軌道は in と out を結ぶ帳簿で観測されない（一回の衝突から放射はほぼ出ない）。同種粒子では軌道を実在と仮定すると Mott の干渉項を落として
間違えるので、計算するのは in–out の関係量だけにした。条件は水素と揃え、相対運動エネルギー E = |E(5p₃/₂ F=1)| = 0.543934 eV、
スペクトルの衝突径数は ℓ = 1 の L = ħ√2 から。

| 量 | ee | pp |
|---|---|---|
| Sommerfeld 径数 η = (q_aq_b/ħc)/(v/c) | 3.54（量子領域） | 151.5（準古典） |
| de Broglie 波長／正面衝突の最接近距離 | 2.35 nm／2.65 nm | 0.055 nm／2.65 nm |
| Mott dσ/dΩ（90°、nm²/sr） | 1.75（区別できる粒子の 1/2） | 1.75（同） |
| 磁気（Darwin）項 v²/c² | 4.3e-6 | 2.3e-9 |
| 四重極制動放射の合計（b = L/μv） | 1.5e-16 eV（E の 2.8e-16 倍、光子数の期待値 5e-16） | 3.6e-25 eV（6.6e-25 倍、5e-23 個） |
| 重力波 | その 9.6e-43 倍 | その 3.2e-36 倍 |

- 断面積：クーロンの厳密な振幅 f(θ) = −(η/2k sin²(θ/2)) exp[−iη ln sin²(θ/2) + 2iσ₀] を同種スピン ½ 非偏極で対称化（Mott 1930）。
  dσ/dΩ = (η/2k)²[1/sin⁴(θ/2) + 1/cos⁴(θ/2) − cos(η ln tan²(θ/2))/(sin²cos²)]。90° で区別できる粒子の 1/2（反対称化）。前方発散、全断面積は無い。
- スペクトル：Landau–Lifshitz §71 の四重極放射を斥力双曲線で評価。D⃛ は運動方程式から閉じた形、Fourier 変換は ξ で数値積分、
  Parseval（時間積分と周波数積分）で自己検査（pp 1.00002、ee 0.996）。質量四重極で同じ計算をすると比は 4Gm²/q² になる。
  ω → 0 で一定、ω ≳ v/a で指数的に落ちる。pp は古典の前提 ħω ≪ E を満たす。ee は η ≈ 1 の量子領域で、表は桁の目安（Gaunt 因子なし）。
- 結論：一回の反跳からは光子も重力子も出ず（期待値 10⁻¹⁶〜10⁻²³ 個）、記録に残るのは in と out の関係（偏向角の分布）だけ。
  同符号の対で E–M が外に出す情報は Mott の断面積に尽きる。

## 層 2：吸収体の温度（absorber_temperature.py → absorber_temperature.md、STATUS §12 の三層のうち生成子が変わる層）

固定一式の準位と A 係数に、電磁の各辺で Planck の占有数 n̄(ω) による誘導放出 A(1+n̄) と吸収 A n̄ g_i/g_f（g = 2F+1、詳細釣り合い）を加える。
重力波と二光子には掛けない。T = 0 で固定一式に戻ることを確認（吸収状態 1s F=0）。

T = 2.7255 K（宇宙背景放射）：

| 量 | 値 |
|---|---|
| 21 cm の ħω/kT、n̄ | 0.0250、39.5 |
| 1s F=1→0：自発 A／誘導 A n̄／吸収 A n̄ g₁/g₀ | 2.87e-15／1.13e-13／3.40e-13 s⁻¹ |
| 1s 超微細の緩和時定数 | 2.19e12 s = 6.9e4 年（自然放出だけなら 1.1e7 年） |
| 定常分布 1s F=1 : F=0 | 0.745286 : 0.254714。比 2.925977 = 3e^{−ħω/kT}（差 4e-16） |
| 読み出せる spin 温度 (ħω/k)/ln(3p₀/p₁) | 2.72550 K（与えた 2.7255 K） |
| 定常での放出パワーと吸収パワー | 5.083371e-19 eV/s で一致（詳細釣り合い、差 0） |
| 正味の放出 p₀·E − π·E | 13.054534895 eV（T = 0 より 4.37e-6 eV 少ない：F=1 に残る分） |
| Lyman-α 以上 | ħω/kT ≥ 4×10⁴、n̄ = 0。5p からの多段は不変 |

結論：温度は生成子を変える（上向きの率が入る）が、変わるのは 1s 超微細だけ。吸収状態が Boltzmann の定常分布に置き換わり、原子は背景の温度計になる。
定常分布は率が 24 桁またぐ R の固有分解では数値的に取れないので、t_max = 1e17 s ≫ 緩和時定数 の長時間積分で取り、残差 max|Rπ| = 0 で確認。
層 1（方向・重心速度・反跳）と層 3（m 副準位の整列、放射場の四重極成分 ≈ 10⁻⁵）は未着手。§12 の要素の構造が要る。

## 入れていないもの

- 層 1・層 3（上記）。
- 連続状態（散乱状態）の離散化と、自由–自由・自由–束縛の遷移率。斥力の枝を準位模型で近似する場合に要るが、散乱一回の放射を表すには迂遠で、別の過程計算が自然。
- 固定一式と同じ：QED、核サイズ、重心運動、重力 2PN。
- 数値精度：Dirac 固有値 相対 1e-11、期待値 1e-9。閉じた式の一式が機械精度の正解表として残る。
