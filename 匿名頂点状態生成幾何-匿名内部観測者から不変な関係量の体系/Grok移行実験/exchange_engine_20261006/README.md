# exchange_engine_20261006：共通エンジン＋系の部品（水素原子・水素分子）

水素原子の固定一式（../exchange_rel_20261005/）と吸収体の三層（../exchange_general_20261006/）から、系に依らない部分を `engine.py` に切り出し、系ごとの部品（準位表と A 係数）を `system_*.py` に分けた。水素原子では元の数値に戻ることを回帰テストで確認し、同じエンジンで水素分子 H₂ を走らせた。

| 層 3（m = 0 から） | 1-0 S(1) の N₀:N₊:N₋ = 0.6:0.2:0.2（P = +0.5）、終状態 (0,1) の整列 −0.187 | 整列 −0.135 |

水素原子との違い：H₂ の最低遷移（純回転 587 cm⁻¹）は 2.7255 K の kT の 310 倍なので、背景は励起も m 緩和も起こさず（水素の 21 cm は n̄ = 39.5、双極子整列 5e-9）、層 2・3 の「背景の読み出し」は無い。層 1（Doppler 記録から v⃗ の復元）は線の自然幅が 1e-22 と極めて細いため、水素原子より精度が高い。

**解離限界直下からのカスケード**（audit_h2_v14J0.txt、audit_h2_v14J1.txt）：(14,0) は深さ 143 cm⁻¹、(14,1) は 126 cm⁻¹。放出合計 4.4603 / 4.4478 eV（= E_init − E_final、差 1e-14）、光子数 e2 7.48 / 6.97、m1 0.022 / 0.024。最初の段は (14,J)→(10,J±2)、(9,J±2)、(8,J±2)（ħω 0.58〜1.1 eV、分岐 0.37/0.36/0.14）で v' = 0 へ直接は行かない。その後 v を 1〜3 ずつ下げ、最後は純回転の (0,2)→(0,0)（τ 3.4e10 s）または (0,3)→(0,1)（1.3e9 s）で止まる。

**原子間重力の別勘定**：各準位に ⟨−Gm_H²/R⟩（点質量 m_H = m_p + m_e − E_b/c² の Newton 項）を付けた。(0,0) で −1.244e-31 cm⁻¹、(14,0) で −3.97e-32 cm⁻¹、線のずれ Δ(ħω) は 1e-37〜1e-36 eV。準位エネルギーの倍精度の床（1e-12 cm⁻¹）の 20 桁下なので E には加わらず、別の列として出す。入れていないもの：電子–核・電子–電子の重力の交差項（核–核項の ~1e-3、~1e-7。Σ⟨1/r_ia⟩(R)、⟨1/r_12⟩(R) が要る）、1PN（(v/c)² ~ 1e-10）。GW の放出は 1.5〜5.4e-35 eV。

## 3a. H + H → H₂ + 光子（radiative_association_h2.md）

箱 R ≤ 50 bohr で規格化した離散化連続状態（部分波 J ≤ 24、E ≤ 4389 cm⁻¹）から束縛準位への率を、束縛–束縛と同じ式で計算。通過 1 回あたりの捕獲確率 P_J(E) = 2πħρ_J ΣA は R_max に依らない（50 → 100 で相対差 1e-5）。箱の往復時間 2πħρ は古典の 2∫dR/v と 1% で一致。

| 量 | 値 |
|---|---|
| P₀(E)（1 回の通過での捕獲確率） | 6e-20（1 cm⁻¹）〜1.3e-19（3000 cm⁻¹）。主な終準位は v' = 8〜11（ħω 0.4〜1.1 eV）、v' = 0 へは行かない |
| σ(E)（電子一重項 1/4 × 核スピン統計込み） | 1e-34 cm²（3〜100 cm⁻¹）、2e-35（3000 cm⁻¹）。E = 1 cm⁻¹ の 9e-33 は (14,4) 準束縛共鳴（E = 0.74 cm⁻¹、P₄ = 9e-18）が 99% |
| k(E) = σv | 4e-30（3 cm⁻¹）〜3e-29 cm³ s⁻¹（1000 cm⁻¹） |
| k(T)（Maxwell–Boltzmann） | 2.4e-29（10 K、共鳴込み）、3.2e-29（100 K）、3.8e-29（300 K）、3.5e-29（1000 K）cm³ s⁻¹ |

事前の粗い見積もり（ħω = D_e の率 × 通過時間 ≈ 1e-14）は 5 桁過大だった。(14,4) 共鳴は本計算（非断熱なし）では解離限界のすぐ上に出るが、全補正では 0.027 cm⁻¹ 下で束縛なので、非断熱補正を入れれば連続状態からは消える。三重項チャネル（電子スピンの 3/4、斥力）には捕獲が無い。

```
bash run_all.sh        # 約 5 分（水素回帰 45 s、H₂ 検証 25 s、走行 4 本 160 s、放射会合 35 s）
```
