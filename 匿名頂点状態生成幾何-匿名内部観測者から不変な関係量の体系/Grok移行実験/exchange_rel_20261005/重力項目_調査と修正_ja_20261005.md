## 2. 実装した重力ハミルトニアン（二体 1PN、一次摂動）

Barker–O'Connell 1975 の二体 1PN ハミルトニアン。量子化の順序は、静的計量 ds² = V²dt² − W²dx² の Dirac ハミルトニアン H = βmV + ½{F, α·p}（Obukhov 2001）を Foldy–Wouthuysen 変換した
H_FW ∋ mΦ + (3/4m){p², Φ} + (3ħ²/8m)∇²Φ + (3/2m)(∇Φ × p)·S
で固定（Φ = −GM/r。古典極限 −(3GM/2mr)p²、測地歳差 3/2 を再現）。

| 項 | 式 | 期待値に使う量 | 1s での値 [eV] |
|---|---|---|---|
| Newton | −G m_e m_p/r | ⟨1/r⟩ = 1/(n²a) | −1.199e-38 |
| 1PN 自己項 | −(3G/4)(m_p/m_e + m_e/m_p){p², 1/r} | ⟨(1/r)p²⟩ = 2μ(E_n⟨1/r⟩ + e²⟨1/r²⟩)（固有状態で厳密） | −2.870e-42 |
| 重力 Darwin | +(3πGħ²/2)(m_p/m_e + m_e/m_p) δ³(r) | |ψ(0)|² = δ_ℓ0/(πn³a³) | +9.565e-43 |
| 1PN 交差項 | −(G/2) p_i[(7δ_ij + n_in_j)/r]p_j | ⟨p·(1/r)p⟩ = ⟨(1/r)p²⟩ − 2πħ²|ψ(0)|²、⟨p_i(n_in_j/r)p_j⟩ = ħ²∫R'²r dr = ⟨(1/r)p²⟩ − ħ²ℓ(ℓ+1)⟨1/r³⟩ − 2πħ²|ψ(0)|² | −1.389e-45 |
| G² 項 | +G² m_e m_p(m_e+m_p)/(2r²) | ⟨1/r²⟩ = 1/(n³(ℓ+½)a²) | +2.8e-82 |
| 重力–電磁 1PN 交差 | +G[−q_eq_p(m_e+m_p) + (m_pq_e² + m_eq_p²)/2]/r² = (27/2)G(m_e+m_p)/r²（Khalil ほか 2018、arXiv:2205.11591 式(4.8)、H = −L。v7 の T8 = (3/2)κ_Cκ_G/ξ² と同一） | ⟨1/r²⟩ | +1.915e-42 |
| スピン軌道（電子） | (G/r³)(2 + (3/2)m_p/m_e) L·S_e（測地 3/2） | ⟨1/r³⟩ = 1/(n³ℓ(ℓ+½)(ℓ+1)a³)、⟨L·S_e⟩ = (ħ²/2)[j(j+1) − ℓ(ℓ+1) − ¾] | 0（ℓ = 0）。2p₃/₂ +1.99e-44、2p₁/₂ −3.99e-44 |

自己項＋交差項は EIH の −(GMμ/2r)[(3+ν)p²/μ² + ν(n·p)²/μ²] と一致する（ℓ ≥ 1 で相対差 2.7e-16。ℓ = 0 は FW が決める接触項の分だけ違う）。重力のスピン結合には g 因子が無い（等価原理）。

第十思考実験 v7 の 22 項のうち重力項（T3 Newton、T6 EIH、T7 G²、T8 重力–電磁交差、T15/T16 スピン軌道、T18 スピン・スピン）はこれで全部入っている。T8 は調和座標の Hamiltonian で、等方座標の FW の項とは 1PN で座標が一致するので足せる（1s で検算：(27/2)G(m_e+m_p)⟨1/r²⟩ = (3/2)κ_Cκ_G⟨1/ξ²⟩·μ = 1.91512e-42 eV、同一）。T21/T22（KN 質量四重極）はトレースレスの 2 階テンソルで、m_j を分解しない準位では一次の寄与が恒等的に 0（Σ_m⟨P₂⟩ = 0）なので、この基底では項が立たない。

## 3. 重力波

同じ四重極演算子 r_ir_j なので E2 と GW の行列要素は共通で、放出比は古典の四重極公式の比に等しい（Landau–Lifshitz §110 と §71：(G/45)/(1/180) = 4G）。重心系の質量四重極 μ r r、電荷四重極 e(m_p−m_e)/M · r r から

W_GW = 4Gμ²M²/(e²(m_p−m_e)²) = 4g·m_e m_p/(m_p−m_e)² = 9.612906e-43（SI から独立に 9.612906e-43）。

検算：3d→1s の E2 率を A = (ω⁵/90ħc⁵)(6/5)e²|⟨r²⟩₁₃|²、⟨r²⟩₁₃ = (8·6!/(81√30))(3/4)⁷ a = 1.73303 a で計算すると 593.8 s⁻¹（文献値 594 s⁻¹）。Γ_GW(3d→1s) = 5.71e-40 s⁻¹、寿命 5.6e31 年。

## 7. 入れていないもの

- QED（Lamb シフト、電子の異常磁気能率）と陽子の有限サイズ。E–M の外。実測との差はすべてこの大きさ（1S 電離の残差 8170.3 MHz = QED＋核サイズ、微細構造 25.4 MHz、超微細 0.11%）。
- 超微細と遷移行列要素の相対論補正（相対 α² ≈ 5e-5）。二光子と 2s→1s M1 の率は文献定数。
- 重力の 2PN 以上。混合項（G e² の 2PN）と ℓ = 0 の量子的順序が文献で閉じていない。

## 8. 電磁の遅延の高次（同日、第四段）

Breit（1/c²）の先にある電子–陽子間の遅延した光子交換の束縛状態効果を、CODATA 2010（Mohr–Taylor–Newell）式 (28)–(33) の形で ORB_C に加えた（`recoil_level`）。

| 項 | 式 | 出典 |
|---|---|---|
| Salpeter (Zα)⁵ m²/M（m/M 全次数） | (m_r³/(m_e²m_N))(α⁵/πn³) m_ec² {(1/3)δ_ℓ0 ln α⁻² − (8/3) ln k₀(n,ℓ) − (1/9)δ_ℓ0 − (7/3)a_n − (2/(m_N²−m_e²))δ_ℓ0[m_N² ln(m_e/m_r) − m_e² ln(m_N/m_r)]}、a_n = −2[ln(2/n) + H_n + 1 − 1/2n]δ_ℓ0 + (1−δ_ℓ0)/(ℓ(ℓ+1)(2ℓ+1)) | Salpeter 1952、Erickson 1977、CODATA (28)(29) |
| (Zα)⁶ m²/M | (m_e/m_N)(α⁶/n³) m_ec² D60、D60 = 4ln2 − 7/2（S）、[3 − ℓ(ℓ+1)/n²]·2/((4ℓ²−1)(2ℓ+3))（ℓ ≥ 1） | Pachucki–Grotch 1995、Eides–Grotch 1997、Golosov ほか 1995、Jentschura–Pachucki 1996、CODATA (31)(33) |
| (Zα)⁷ の対数二乗項 | 同 × D72 α ln²α⁻²、D72 = −11/(60π)（S）。この次数はこの項だけが既知 | Pachucki–Karshenboim 1999、Melnikov–Yelkhovsky 1999、CODATA (32) |
| Bethe 対数 ln k₀(n,ℓ)、n ≤ 5 の 15 準位 | 1S 2.984128556 … 5G −0.000772098902 | CODATA 2010 Table V（Drake–Swainson 1990）、Jentschura–Mohr 2005 |

検算（`coulomb_levels_check.txt`）：1S と 2S の E_S、(Zα)⁶、(Zα)⁷log² が Eides–Grotch–Shelyuto 2001 表 VIII の 2409.51／341.29、−7.38／−0.92、−0.42／−0.05 kHz と全桁一致。1S 電離エネルギーの残差は 8170.31 MHz となり、Lamb シフト 8172.84 から反跳 2.40 を除いた QED＋核サイズ 8170.44 MHz と 0.12 MHz で一致。2S₁/₂ − 2P₁/₂ に反跳の差 0.35 MHz が立つ（残り 1057.5 MHz が QED の Lamb シフト）。多段の結果は放出 13.054539268 eV（1e-8 eV の変化）。

これで電磁側は、点 Dirac 粒子の二体問題として文献で閉じている次数（(Zα)⁶ m²/M）まで入った。残るのは (Zα)⁷ の非対数項（未計算）と、E–M の外の QED・核サイズ。
- 重力 1PN の接触項の陽子側は対称性で補った。スピン・スピンの接触項はベクトル解析から。文献との突き合わせ未了。
- KN 四重極（T19–T22）は m_j を分解しない準位では一次で 0。
- この一式は標準の量子力学の水素原子であり、万能相互作用（交換 U_R、ロック、δτ）の実装ではない。
