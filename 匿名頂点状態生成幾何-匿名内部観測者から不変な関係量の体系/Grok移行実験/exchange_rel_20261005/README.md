## 中身

- **基底** (n, ℓ, s_e, s_p)、n = 1..5、50 準位。s_e は j − ℓ の符号、s_p は F − j の符号。初期状態は 5p₃/₂ F=1。
- **準位** ETOT = ORB_C（Dirac–Coulomb 厳密解＋Barker–Glover 反跳＋Breit 項＋遅延の高次 (Zα)⁵・(Zα)⁶・(Zα)⁷log²）＋ ORB_G（二体 1PN 重力、1e-38 eV、別配列で保持）＋ HFS（超微細、g_p = 5.5857）。
- **遷移率** 全ての下向き対。E1 (4ω³/3ħc³)e²|⟨r⟩|²、E2 (ω⁵/90ħc⁵)·6e²|⟨r²⟩|²(2ℓ'+1)(ℓ 2 ℓ';000)²、GW = W_GW × E2（W_GW = 4Gμ²M²/(e²(m_p−m_e)²) = 9.613e-43）、M1（同じ nℓ：μ = −μ_B(L+2S) + g_pμ_N I）、2s→1s 二光子 8.2206 s⁻¹ と M1 2.496e-6 s⁻¹。j と F の分解は 6j 記号（Racah の式、有理数）。動径積分は Laguerre 関数の数値積分。
- **時間発展** 滞在時間 τ = −R_TT⁻¹ p₀ を厳密に解き、各辺の流量 A·τ に ΔE を掛けて放出を数える（時間刻みの誤差なし）。図と時刻ごとの pool は陰的 Radau（Jacobian = R）。
- **会計** 電荷・静止質量・外からの吸収 0 の検査、pool（超微細・クーロン・重力・管への放出）、重力波の物理の重みと重み 1 の実験（Grok の設計を維持）。

## 環境の注意

- numpy 2.0.2 + Accelerate（macOS）では 50×50 以上の `@` が有限な乱数行列でも `divide by zero encountered in matmul` の偽の警告を出す（`np.dot` は出さず、値は一致）。本体は `np.dot` を使う。Grok の元プログラムの `m @ p` の警告も同じもの。

## 入れていないもの

- QED（Lamb シフト、電子の異常磁気能率）、陽子の有限サイズ。実測との差はすべてこの大きさ。
- 遅延（反跳）の (Zα)⁷ の非対数項（未計算、Eides は対数二乗項の半分を目安とする）、(Zα)⁶ m³/M² 以上の質量比高次。
- 超微細と遷移行列要素の相対論補正（相対 α² ≈ 5e-5）。
- 重力の 2PN 以上。混合項（G e² の 2PN）と ℓ = 0 の量子的順序が文献で閉じていない。
- 重心運動（位置・並進）。放出光の反跳シフト (ħω)²/(2Mc²)（Lyman-α 13.4 MHz）と Doppler 幅は模型に無い（表 F に参考値）。
- KN 四重極（第十思考実験 v7 の T19–T22）。m_j を分解しない準位では一次の寄与が 0。
- 二光子と 2s→1s M1 の率は文献定数。
- 重力 1PN の接触項（ℓ = 0）は電子側を FW で導き、陽子側は対称性で補った。スピン・スピンの接触項はベクトル解析の恒等式から。文献との突き合わせはしていない。
- この一式は標準の量子力学の水素原子であり、万能相互作用（a–b 交換 U_R、ロック、δτ）の実装ではない。交換実装が再現すべき正解表として使う。
