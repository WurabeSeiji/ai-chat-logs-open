## 0. 全体の流れ

```
定数（§1.1）→ 基底 ST（§1.2）→ 準位 ETOT = ORB_C + ORB_G + HFS（§1.3）→ 初期占有 p₀（§1.4）
   → 辺 edges()：全下向き対の A 係数（§2.2）→ 生成行列 R（§2.3）
   → 厳密解：滞在時間 τ = −R_TT⁻¹ p₀、終状態 p_∞、流量 A·τ（§2.3）
   → 時間履歴：Radau で dp/dt = R p（§2.3、図と時刻ごとの pool 用）
   → 読み出し：種別ごとの放出、pool、収支、audit.txt（§3）
```

状態ベクトルは占有確率 **p ∈ ℝ⁵⁰**（成分 p_i、Σ p_i = 1）の一本。準位エネルギーの三配列 ORB_C、ORB_G、HFS と生成行列 R は初期化で一度だけ作る定数表で、相互作用中に変わらない。ステップごとに状態を書き換えるループは無く、更新式は線形のマスター方程式 dp/dt = R p だけである（§2.3）。

### 1.3 準位エネルギー ETOT = ORB_C + ORB_G + HFS（m_e c² 単位）

```python
def parts():
    mu_red = MU_P / (1.0 + MU_P)
    orb_c, orb_g, hfs = [], [], []
    m_tot = 1.0 + MU_P
    for n, ell, s_e, s_p in ST:
        j, F = jf_of(ell, s_e, s_p)
        kappa = j + 0.5
        delta = kappa - np.sqrt(kappa**2 - ALPHA**2)
        f_dirac = (1.0 + (ALPHA / (n - delta))**2) ** -0.5
        breit = (ALPHA**4 * mu_red**3 / (2.0 * n**3 * MU_P**2)
                 * (1.0 / (j + 0.5) - 1.0 / (ell + 0.5)) if ell > 0 else 0.0)
        coul = mu_red * (f_dirac - 1.0) - mu_red**2 * (f_dirac - 1.0)**2 / (2.0 * m_tot) + breit + sum(recoil_level(n, ell))
        orb_c.append(coul)
        orb_g.append(sum(gravity_level(n, ell, j, F).values()))
        hfs.append(hyperfine_level(n, ell, j, F))
    return np.array(orb_c), np.array(orb_g), np.array(hfs)
```

#### 1.3.1 ORB_C：電磁の二体準位

$$f(n,j)=\Bigl[1+\frac{\alpha^2}{(n-\delta)^2}\Bigr]^{-1/2},\qquad \delta=j+\tfrac12-\sqrt{(j+\tfrac12)^2-\alpha^2}$$

$$E_C = \underbrace{\mu(f-1)}_{①} \;\underbrace{-\;\frac{\mu^2(f-1)^2}{2(m_e+m_p)}}_{②} \;+\;\underbrace{\frac{\alpha^4\mu^3}{2n^3m_p^2}\Bigl[\frac1{j+\frac12}-\frac1{\ell+\frac12}\Bigr](1-\delta_{\ell0})}_{③} \;+\;\underbrace{E_S+E_R}_{④}$$

| 項 | 内容 | 根拠 | 検算 |
|---|---|---|---|
| ① | Dirac–Coulomb 厳密解（電子一体、α の全次数。Sommerfeld の微細構造を含む） | Dirac 1928、Sommerfeld 1916。結合 q_eq_p/ħ = 9/ħ = α | 1S の Dirac シフト α²/4、2P₃/₂−2P₁/₂ = 10943.68 MHz（実測との差 25.4 MHz = (α/π)×分裂、QED） |
| ② | 陽子の反跳の主項。二体の相対論的運動学 W² = m² + M² + 2mM·f の展開 | Barker–Glover 1955。CODATA 2010 式 (26) の第 3 項（分母は全質量 M = m_e + m_p） | 1S で −9.85e-8 eV = 23.8 MHz。これが無いと 1S の残差が Lamb シフトから 24 MHz ずれる |
| ③ | Breit 相互作用の軌道–軌道・スピン–他軌道（磁気と遅延の 1/c²） | CODATA (26) の (1−δ_ℓ0)/(κ(2ℓ+1)) 項。κ = (−1)^{j−ℓ+½}(j+½) で上の括弧と同じ | 2p で ±9e-12 eV |
| ④ | 遅延の高次：Salpeter (Zα)⁵、(Zα)⁶、(Zα)⁷ の対数二乗項（下記 recoil_level） | CODATA 2010 (28)–(33) | Eides 表 VIII と全桁一致 |

①〜③ を α⁴ まで展開すると −μα²/(2n²) − μα⁴/(2n³)[1/(j+½) − 3/(4n) + μ/(4n(m+M))] + ③ で、閉じた式との差は相対 O(α⁴)（1s で α⁴/8）。

```python
def recoil_level(n, ell):
    mu = MU_P / (1.0 + MU_P)
    d0 = 1.0 if ell == 0 else 0.0
    Hn = sum(1.0 / i for i in range(1, n + 1))
    a_n = -2.0 * (np.log(2.0 / n) + Hn + 1.0 - 1.0 / (2.0 * n)) * d0 + (0.0 if ell == 0 else 1.0 / (ell * (ell + 1) * (2 * ell + 1)))
    masslog = (2.0 / (MU_P**2 - 1.0)) * d0 * (MU_P**2 * np.log(1.0 / mu) - np.log(MU_P / mu))
    E_S = (mu**3 / MU_P) * (ALPHA**5 / (np.pi * n**3)) * (
        (1.0 / 3.0) * d0 * np.log(ALPHA**-2) - (8.0 / 3.0) * LN_K0[(n, ell)] - d0 / 9.0 - (7.0 / 3.0) * a_n - masslog)
    if ell == 0:
        D60, D72 = 4.0 * np.log(2.0) - 3.5, -11.0 / (60.0 * np.pi)
    else:
        D60, D72 = (3.0 - ell * (ell + 1) / n**2) * 2.0 / ((4 * ell**2 - 1) * (2 * ell + 3)), 0.0
    E_R = (1.0 / MU_P) * (ALPHA**6 / n**3) * (D60 + D72 * ALPHA * np.log(ALPHA**-2) ** 2)
    return E_S, E_R
```

$$E_S=\frac{\mu^3}{m_e^2 m_p}\frac{\alpha^5}{\pi n^3}\Bigl\{\tfrac13\delta_{\ell0}\ln\alpha^{-2}-\tfrac83\ln k_0(n,\ell)-\tfrac19\delta_{\ell0}-\tfrac73 a_n-\frac{2\,\delta_{\ell0}}{m_p^2-m_e^2}\Bigl[m_p^2\ln\frac{m_e}{\mu}-m_e^2\ln\frac{m_p}{\mu}\Bigr]\Bigr\}$$

$$a_n=-2\Bigl[\ln\frac2n+\sum_{i=1}^n\frac1i+1-\frac1{2n}\Bigr]\delta_{\ell0}+\frac{1-\delta_{\ell0}}{\ell(\ell+1)(2\ell+1)},\qquad
E_R=\frac{m_e}{m_p}\frac{\alpha^6}{n^3}\bigl[D_{60}+D_{72}\,\alpha\ln^2\alpha^{-2}\bigr]$$

| 記号 | 値 | 根拠 |
|---|---|---|
| E_S | Salpeter の反跳（(Zα)⁵ m²/M、質量比の全次数） | Salpeter 1952、Erickson 1977、Sapirstein–Yennie 1990。CODATA 2010 式 (28)(29) を原文から転記 |
| ln k₀(n,ℓ) | Bethe 対数（非相対論の水素固有状態だけで決まる） | CODATA 2010 Table V（Drake–Swainson 1990、10 桁）、残りは Jentschura–Mohr 2005（9 桁）。15 準位を `LN_K0` に保持 |
| D₆₀(S) = 4 ln 2 − 7/2 | (Zα)⁶ m²/M、S 状態 | Pachucki–Grotch 1995、Eides–Grotch 1997。CODATA (31) |
| D₆₀(ℓ≥1) = [3 − ℓ(ℓ+1)/n²]·2/((4ℓ²−1)(2ℓ+3)) | 同、ℓ ≥ 1 | Golosov ほか 1995、Jentschura–Pachucki 1996。CODATA (33)、Eides 式 (146) |
| D₇₂ = −11/(60π) | (Zα)⁷ の対数二乗項（S のみ。この次数で既知なのはこの項だけ） | Pachucki–Karshenboim 1999、Melnikov–Yelkhovsky 1999。CODATA (32) |

#### 1.3.2 ORB_G：二体 1PN の重力準位

```python
def gravity_level(n, ell, j, F):
    mu = MU_P / (1.0 + MU_P)
    g = MU_P * MU**2 / 9.0
    G = 9.0 * g / MU_P
    hb = HBAR
    a = 9.0 / (ALPHA**2 * mu)
    En = -mu * ALPHA**2 / (2.0 * n**2)
    r1 = 1.0 / (n**2 * a)
    r2 = 1.0 / (n**3 * (ell + 0.5) * a**2)
    r3 = 1.0 / (n**3 * ell * (ell + 0.5) * (ell + 1) * a**3) if ell > 0 else 0.0
    psi0sq = 1.0 / (np.pi * n**3 * a**3) if ell == 0 else 0.0
    kin = 2.0 * mu * (En * r1 + 9.0 * r2)
    p_r_p = kin - 2.0 * np.pi * hb**2 * psi0sq
    p_nn_p = kin - hb**2 * ell * (ell + 1) * r3 - 2.0 * np.pi * hb**2 * psi0sq
    newton = -9.0 * g * r1
    self_pn = -(3.0 * G / 4.0) * (MU_P + 1.0 / MU_P) * 2.0 * kin
    darwin = (3.0 * np.pi * G * hb**2 / 2.0) * (MU_P + 1.0 / MU_P) * psi0sq
    cross = -(G / 2.0) * (7.0 * p_r_p + p_nn_p)
    g2 = 9.0 * g * G * (1.0 + MU_P) / 2.0 * r2
    mixed = 13.5 * G * (1.0 + MU_P) * r2
    LS_e = 0.5 * hb**2 * (j * (j + 1) - ell * (ell + 1) - 0.75)
    LJ = 0.5 * hb**2 * (j * (j + 1) + ell * (ell + 1) - 0.75)
    JI = 0.5 * hb**2 * (F * (F + 1) - j * (j + 1) - 0.75)
    LI = LJ * JI / (hb**2 * j * (j + 1))
    so_e = G * (2.0 + 1.5 * MU_P) * r3 * LS_e
    so_p = G * (2.0 + 1.5 / MU_P) * r3 * LI
    if ell > 0:
        ss = G * r3 * (ell * (ell + 1) - j * (j + 1) + 0.75) / (2.0 * j * (j + 1)) * JI
    else:
        ss = G * (8.0 * np.pi / 3.0) * psi0sq * JI
    return {"newton": newton, "self_pn": self_pn, "darwin": darwin, "cross": cross, "g2": g2, "mixed": mixed,
            "so_e": so_e, "so_p": so_p, "ss": ss}
```

Coulomb 固有状態での一次摂動。単位は m_e = 1、ħ = 9/α、e² = 9、G m_e m_p = 9g、a = 9/(α²μ)、E_n = −μα²/(2n²)。

|---|---|---|
| r1, r2, r3 | ⟨1/r⟩ = 1/(n²a)、⟨1/r²⟩ = 1/(n³(ℓ+½)a²)、⟨1/r³⟩ = 1/(n³ℓ(ℓ+½)(ℓ+1)a³) | 水素の標準公式。`gravity_levels_check.py` で Laguerre 関数の数値積分と 1e-16 一致 |
| psi0sq | \|ψ(0)\|² = δ_ℓ0/(πn³a³) | 同 |
| kin | ⟨(1/r)p²⟩ = 2μ(E_n⟨1/r⟩ + e²⟨1/r²⟩) | p²ψ = 2μ(E − V)ψ。固有状態で厳密 |
| p_r_p | ⟨p·(1/r)p⟩ = kin − 2πħ²\|ψ(0)\|² | p_i f p_i = ½{p², f} + (ħ²/2)∇²f、∇²(1/r) = −4πδ³ |
| p_nn_p | ⟨p_i (n_in_j/r) p_j⟩ = ħ²∫R′² r dr = kin − ħ²ℓ(ℓ+1)⟨1/r³⟩ − 2πħ²\|ψ(0)\|² | 部分積分と動径方程式。数値積分と 1e-16 一致 |

|---|---|---|
| newton | −G m_e m_p/r | Newton。元の Grok 版は coul×g で、この半分だった（運動エネルギーの応答が無い） |

self_pn + cross = EIH の −(GMμ/2r)[(3+ν)p²/μ² + ν(n·p)²/μ²]（ℓ ≥ 1 で相対差 2.7e-16）。KN 質量四重極（v7 の T21、T22）はトレースレスの 2 階テンソルで、m_j を分解しない準位では一次の寄与が恒等的に 0 なので項が無い。

#### 1.3.3 HFS：超微細

```python
def hyperfine_level(n, ell, j, F):
    mu = MU_P / (1.0 + MU_P)
    K = G_P * ALPHA**4 * mu**3 / MU_P
    return K * (F * (F + 1) - j * (j + 1) - 0.75) / (4.0 * n**3 * (ell + 0.5) * j * (j + 1))
```

$$E_{hfs}=K\,\frac{F(F+1)-j(j+1)-\tfrac34}{4n^3(\ell+\tfrac12)\,j(j+1)},\qquad K=g_p\,\alpha^4\,\frac{\mu^3}{m_p/m_e}$$

根拠：Maxwell の磁気双極子相互作用（Fermi 接触項、スピン双極子、軌道）を μ の Bohr 半径の非相対論波動関数で評価した標準式（Bethe–Salpeter §22）。電子は Dirac の g = 2。検算（`rates_check.txt`）：1s 1418.84 MHz、2s 177.36、2p₁/₂ 59.12、2p₃/₂ 23.65（実測 1420.41、177.56、59.22、23.65。比 0.9989 = 1/(g_e/2)、QED）。元の Grok 版の se 項は電子スピン軌道で Dirac 厳密解との二重計上なので削除、sp 項をこの式に置換した。

```python
def wigner6j(a, b, c, d, e, f):
    a, b, c, d, e, f = (Fraction(x) for x in (a, b, c, d, e, f))
    for tri in ((a, b, c), (a, e, f), (d, b, f), (d, e, c)):
        if not _tri(*tri):
            return 0.0
    pref = _Delta(a, b, c) * _Delta(a, e, f) * _Delta(d, b, f) * _Delta(d, e, c)
    kmin = int(max(a + b + c, a + e + f, d + b + f, d + e + c))
    kmax = int(min(a + b + d + e, a + c + d + f, b + c + e + f))
    s = Fraction(0)
    for k in range(kmin, kmax + 1):
        s += (-1) ** k * Fraction(factorial(k + 1),
                                  factorial(k - int(a + b + c)) * factorial(k - int(a + e + f))
                                  * factorial(k - int(d + b + f)) * factorial(k - int(d + e + c))
                                  * factorial(int(a + b + d + e) - k) * factorial(int(a + c + d + f) - k)
                                  * factorial(int(b + c + e + f) - k))
    return float(np.sign(float(s)) * sqrt(float(pref * s * s)))

def w3j000_sq(l1, l2, l3):
    J = l1 + l2 + l3
    if J % 2 or not (abs(l1 - l2) <= l3 <= l1 + l2):
        return 0.0
    g = J // 2
    D = Fraction(factorial(J - 2 * l1) * factorial(J - 2 * l2) * factorial(J - 2 * l3), factorial(J + 1))
    return float(D * Fraction(factorial(g), factorial(g - l1) * factorial(g - l2) * factorial(g - l3)) ** 2)

def recouple(l, j, l2, j2, F, F2, k):
    return ((2 * j2 + 1) * (2 * l + 1) * wigner6j(l, j, 0.5, j2, l2, k) ** 2
            * (2 * F2 + 1) * (2 * j + 1) * wigner6j(j, F, 0.5, F2, j2, k) ** 2)

def radial_fn(n, l):
    N = sqrt((2.0 / n) ** 3 * factorial(n - l - 1) / (2.0 * n * factorial(n + l)))
    Lag = genlaguerre(n - l - 1, 2 * l + 1)
    return lambda r: N * np.exp(-r / n) * (2.0 * r / n) ** l * Lag(2.0 * r / n)

def radial(n, l, n2, l2, power):
    key = (n, l, n2, l2, power)
    if key not in _RAD:
        R, R2 = radial_fn(n, l), radial_fn(n2, l2)
        _RAD[key] = quad(lambda r: R(r) * R2(r) * r ** (power + 2), 0, 60.0 * max(n, n2), limit=800, epsabs=0.0, epsrel=1e-12)[0]
    return _RAD[key]
```

**更新式。** 状態ベクトル p の各成分は

$$\frac{dp_i}{dt}=-\Gamma_i\,p_i+\sum_{f\ne i}A_{f\to i}\,p_f,\qquad \Gamma_i=\sum_{f\ne i}A_{i\to f},$$

行列で dp/dt = R p、R_{fi} = A_{i→f}（f ≠ i）、R_{ii} = −Γ_i。各列の和は 0 なので Σ_i p_i は保存する。

| R | 生成行列。辺ごとに R[dst,src] += A、R[src,src] −= A。e2 と gw は同じ (src,dst) を共有するので加算 | 自発放出だけの率方程式（吸収・誘導放出 0）。各 A は §2.2 |

| 準位の空間的な広がり | ⟨r⟩ = (a/2)[3n² − ℓ(ℓ+1)]、⟨r²⟩ = (a²n²/2)[5n² + 1 − 3ℓ(ℓ+1)]、Δp = ħ/(na) | 水素の標準公式。Δr·Δp/ħ ≥ ½ | 1s：⟨r⟩ 79 pm、Δr·Δp/ħ = √3/2 = 0.866 |

時間方向の幅と空間方向の幅は「逆数」ではなく、生成子の中で Γ = (4/3)αω(ωa/c)²\|R̃\|²·𝓡 として結ばれている。双極子長が大きく振動数が高いほど寿命が短く、波束が短い。

**模型の外にあるもの。** 位置と並進は定義されていない。重心運動を凍結しているので、放出光の反跳シフト (ħω)²/(2Mc²)（Lyman-α で 13.4 MHz、表 F の参考列）と Doppler 幅は無い。反跳シフトは 2p の自然幅 99.7 MHz の 13% で、超微細分裂と同じ桁の、実測される量である。
