# 高次 N=2〜40 generic 複素ガウス null 実験 v1

## 目的
論文2の generic null と完全不変量フレームを N=2〜40 まで連続検証する。これは Phase B 本体ではなく、その前の高次 N null 対照実験である。

## 条件
- N=2,...,40
- κ統計: 各N 20,000標本
- 完全フレーム不変性: 各N 300標本
- Newton/root復元: 各N 50標本
- Re(z_j), Im(z_j) ~ N(0,1)
- seed=20260914

## 結果1: κ null 則
N=40 (m=39) で、標本平均 0.199080、厳密平均 0.199409。標本中央値 0.188620、厳密中央値 0.189272。

N=3〜40 の Beta KS 検定で最小 p 値は 0.044103 (N=30)。38検定中の単発5%近傍であり、Nに沿った系統的逸脱は見られない。N=40 の p 値は 0.835200。

## 結果2: 完全フレーム不変性
全 N を通じた最大不変誤差は 3.033e-13。高次 N でも倍精度丸め誤差範囲。

## 結果3: 明示的 Newton/root 復元の条件悪化
解析的完全性は成立する一方、高次数多項式の係数から根を復元する数値操作は悪条件化する。N=40 の最大復元誤差は 0.154876。

これはフレームの情報喪失ではなく、根復元アルゴリズムの数値条件の悪化である。Phase B では完全フレームそのものを座標として使い、根復元は行わない方針が適切。

## 結論
N=2〜40 で generic null の Beta 則・厳密平均/中央値・G_B 不変性を確認した。N=40 の generic null 基準は E[κ]=0.199409。自己無撞着力学が κ≈0 を選ぶ場合、generic null から強く逸脱する。
