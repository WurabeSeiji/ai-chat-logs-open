# 第十四思考実験 数値実験 E4（2026-10-14）

## 目的
α は 23/124（K4 の R₁₂₄,₂₃）から求まり、四次元格子の条件がその 23/124 にロックさせやすい、という見方を検証する。あわせて、観測値が 23/124 の値から僅かにずれる理由（観測は遷移中の状態を含む多数サンプルの平均）について、遷移中の読み出しの向きと持続を測る。

## 方法
- 系：E2/E3 と同じ（四次元フルヴィッツ格子＋位相回転、外部時計なし、位相幾何的回転数 ρ_top）。軸 Z4。乱数種 20261014。
- (A) 選択：回転を 23/124 と近くの根（23/122, 23/126, 22/119, 24/131, 17/92, 18/97）に替え、半径 32・64・96 で自分の比にロックする率。
- (A') 追加（(A) の結果を見た後に設定）：分母が4の倍数の根（21/116, 19/104, 25/136, 27/148, 23/120）とそうでない根（21/110, 25/134, 19/102）、半径64。
- (B) 引き込み：回転を 23/124+ε、23/122+ε（ε=±√2×10⁻³〜10⁻⁶）として、もとの比に引き込まれる率。
- (C) 回復：23/124 にロックした軌道に格子1単位の擾乱を加え、再ロックまでの長さと過渡中の読み出し。

## 結果
1. (A) 自己ロック率（半径32/64/96）：23/124 は 40%/70%/86%。同程度の分母の隣の根 23/122・23/126・22/119・24/131 は 0〜27%。17/92 は 53%/93%/100%。
2. (A') 分母が4の倍数の根は半径64で 40〜76%（23/124 は 70%）、そうでない根は 10〜40%。Z4 軸の四次元格子は、分母が4の倍数の根（λₐ^{n/4}=i が格子の対称性になる根）をロックさせやすい。124=4×31 はこの群に入る。ただし 23/124 だけが特別に選ばれているわけではない。
3. (B) 23/124 は |ε|≤1.4×10⁻⁵ で 83〜93%、1.4×10⁻⁴ で 24〜31% が 23/124 に引き込まれ、1.4×10⁻³ では0。23/122 は最大43%、1.4×10⁻⁴ で0。23/124 の引き込み幅は 23/122 より広く強い。
4. (C) 20回中18回が 23/124 に再ロック（他は 13/70、28/151）。再ロックまでの長さは平均274、中央値159更新。過渡中の読み出し α⁻¹ は平均136.83、時間重み付き平均136.74で、x₂₃/₁₂₄=137.036043 より下側。
5. 観測値 137.035999177 になるのに必要な遷移中の時間割合は、時間重み付き平均を使うと f≈1.46×10⁻⁴。回復1回あたり平均274更新なので、必要なスリップ頻度は約 5.3×10⁻⁷/更新（約190万更新に1回）。この頻度を与える機構は今回の決定論的な系には含まれておらず、未検証。
