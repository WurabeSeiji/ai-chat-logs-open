# 第十四思考実験 数値実験 E5（2026-10-14）

## 目的
電子自身の質量・エネルギーが四次元ゲージ（フルヴィッツ格子）を僅かに歪め、そのためにゲージ（23/124 のロック）から外れることがあるかを確かめる。E4 では格子が固定されていたため、一度ロックすると外れず、外れる頻度は外から仮定するしかなかった。

## 方法
- 系：E4 と同じ（四次元フルヴィッツ格子、Z4 軸、R₁₂₄,₂₃ の位相回転、外部時計なし、位相幾何的回転数）。
- 歪み（事前固定）：更新ごとに、状態自身のクーロン的自己エネルギー α/r（r は格子単位の半径）に比例して丸めの基準格子を伸縮させる。x ← u q、x ← x(1 + s·α/r)、q ← round_H(x)。s=+1（伸張）と s=−1（収縮）の両方。自由パラメータなし。
- 自己無撞着：α₀=1/x₂₃/₁₂₄ から始め、周期軌道の回転数 ρ=W/P から α_read⁻¹=4π/sin⁴(πρ) を読み、その平均で α を更新して3回反復。
- 読み出し：23/124 にロックする軌道の数、ロックした軌道の周期内で局所回転数（124更新窓）が 23/124 から外れる時間割合 f、α_read⁻¹ の平均。
- 初期点：半径64で24点（乱数種 20261014）。対照（te14_E5_control.py）：同じ初期点で歪みなし（s=0）。

## 結果
1. 歪みは軌道を変える：24本中15本が、歪みなしと異なる周期軌道に落ちた（s=+1、s=−1 とも）。
2. 23/124 にロックする軌道は、歪みなしで14本、s=+1 で19本、s=−1 で17本。自己歪みはロックを壊すのではなく、むしろ増やした。
3. 周期内でのロックの外れ：ロックした軌道の周期の中で、局所回転数が 23/124 から外れる区間は0。外れてはまた戻る間欠的な振る舞いは現れなかった。各軌道は「ずっとロック」か「ずっと別の準位」のどちらか。
4. 軌道の集まりで平均した α_read⁻¹ は s=+1 で 137.0059、s=−1 で 137.0940。ロックしない少数の軌道（s=+1 では 18/97、135/728、167/900、s=−1 では 5/27 など）の寄与による。これは初期条件の集まりの平均で、時間平均ではない。
5. 自己無撞着の反復：α の変化（相対 2×10⁻⁴）は丸めの結果を変えず、1回目で固定点になった。

## 読み
状態だけで決まる決定論的な歪み（電子の位置で瞬時に決まる歪み）では、有限の格子上の写像は必ず周期軌道に入るため、外れて戻る間欠的なスリップは生じない。外れて戻るには、歪みが電子の位置に瞬時に従うのではなく、ゲージ側が自分の状態（遅れ・記憶）を持ち、電子の状態とずれて変化する必要がある。次段はゲージの歪みを状態変数として持たせ、遅れて追従させる形（E6）で確かめる。
