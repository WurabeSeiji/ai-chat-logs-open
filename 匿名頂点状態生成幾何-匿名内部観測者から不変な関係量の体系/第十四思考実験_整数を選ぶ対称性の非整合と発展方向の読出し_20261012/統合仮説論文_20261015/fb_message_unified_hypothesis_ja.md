時間も空間も置かない円周の住民から、質量・電荷・速度・スピンを読み出します

詳細はコメント参照

背景の時間も空間も置かず、閉じた円周の上の位相 θ と虚数振幅 A、成分の本当の二乗の和 Σxₙ² = R² だけを置きます
節の数 n が量子化で、奇数は二周・偶数は一周で元に戻ります。フェルミオンとボゾンの区別が偶奇だけから出ます
同じ振幅の倍音を重ねると一点に局在し、位置と原点が干渉だけから生まれます
Σxₙ² + (iR)² = 0 は光円錐そのもので、R は外に置いた半径ではなく振幅です
振動しない張り付いた位相（ヒッグス場に相当）とのビート一つから、質量・時間・空間が同時に読めます
円周で v² + (1/γ)² = 1 が残差 10⁻¹⁵ で成り立ち、速度合成則と 6 桁一致し、質量は逆回りの回転項の交差項の割合です
一様な並進の群・ホイヘンスの原理・読める曲率の三条件を満たすのは四次元球殻 S³ だけで、三次元が選ばれます
S³ の住民ではスピン（奇偶）、電荷（ホップ・ファイバーの巻き数）、観測（二つの波の交差項）が読めます
電子を読むと α を介して質量が決まり、G = c = q₀ = 1 ではプランク定数 ħ = 9α⁻¹ が出力です。23/124、137、四次元格子、E₈ はその先の一段です
