# 時間も空間も置かない円周の住民から、質量・電荷・速度・スピンを読み出す――統合仮説論文

標準理論と一般相対性理論は、時間と空間を先に置きます。

その上に粒子と場を置き、質量と電荷の値を入力として与えます。

今回の論文は、順序を逆にしました。

背景の時間も空間も置かず、閉じた円周の上の複素波の関係と干渉だけから、何がどこまで読み出せるかを一段ずつ調べました。

主張は一つです。

**背景時空を置かず、奇数・偶数の倍音の進行波ですらない複素波の関係と干渉だけから、時間・空間・質量・電荷・並進速度・スピンまでが読み出せる。**

論文は、私と AI（Claude）の二つの対話を一次資料にして、私が問い、AI が誤り、私が訂正して道が定まった順序のまま書いてあります。

この記事も、その順序で要点を追います。図は論文のもの、対話型の図は Zenodo に置いた HTML です。

## 設定：円周の住民

半径 R の円周に住む住民を考えます。背景の時間も空間も想定しません。

住民には、円の中心も、円の内側も外側も見えません。半径 R は外から見た言葉で、住民が内側から測れる量ではありません。

住民に残る手がかりは、一周すると元に戻ることだけです。

この円周に波を置きます。

横波の振幅を置く方向は円周と直交する方向ですが、それは背景空間の方向なので住民にはありません。そこで振幅は虚数の方向に置きます。

系の要素は、位相 θ と虚数の振幅 A の二つだけです。

閉じていることから、許される波はとびとびになります。振幅がゼロになる位相を節と呼び、一周にある節の数を n とします。n は半波長の数を数えるので、奇数でも構いません。

- n ＝ 0 は、円周全体が一様に ＋iA または −iA を持つ二つの状態です
- n が奇数の波は、一周すると符号が反転し、二周して元に戻ります
- n が偶数の波は、一周で元に戻ります

二周で戻る波と一周で戻る波の区別は、スピノルとベクトル、つまりフェルミオンとボゾンの区別と同じ構造です。

n ＝ 1 から 18 までの波を同じ振幅で重ねると、一点に鋭い山が立ちます。山が立つことと、原点 θ₀ が決まることは同じ出来事です。

奇数次だけの和は二周に一度、偶数次だけの和は一周に一度、山が現れます。両方の和は一周目の終わりで打ち消し合い、二周目の終わりに戻ります。

## 条件は一つ：本当の二乗の和

置く条件は一つです。成分の本当の二乗（共役をとらない二乗）の和が R² に等しい。

　Σxₙ² ＝ R²

私は最初、絶対値の二乗と実数の半径でこの条件を解く数値実験を走らせました。結果は整っていましたが、誤りでした。

本当の二乗で読むと、R は虚数、つまり成分と同じ種類の量（振幅）です。外に置いた半径ではありません。円周の外はありません。

条件を移項すると

　Σxₙ² ＋ (iR)² ＝ 0

で、これは光円錐の条件です。

住民に曲率は読めません。ただし、位相で等間隔に刻んだ一目盛りの長さ（測地線長）は、場所によって違います。

全次数 N ＝ 18 の合成波では、山の区間の一目盛りが平均の 1.245 倍になります。奇数次だけでは、山の反対側（対蹠点）の区間が 0.835 倍に縮みます。

## 第 1 段：質量を読む

ここまでの波は定在波で、進行波が作れません。この問いから、質量の読み出しが始まりました。

鍵は、振動しない位相です。場所ごとに位相が割り当てられ、そこに張り付いて動きません。

標準理論のヒッグス場の真空期待値は、振動せず、空間全体に静的に居座っています。張り付いた位相は、これと同じ形です。

合成波（粒子）がこの背景の中で位置を変えると、張り付いた位相との差（ビート）を拾います。

- 背景と結合しない成分は、位相差を拾わず、比 1 で進みます。光に当たります
- 背景と結合する成分は、位置を変えるたびに位相を合わせ直す分だけ遅くなります。質量に当たります

ビート一つから、三つが同時に読めます。止まっていても残るビートの強さが質量、ビートの傾きの向きと大きさが進む方向と速さ（空間）、位置を変える間に積み上がったビートの数が粒子の経験する時間（固有時）です。

ここで AI は、ビートの位相速度が光速を超えると計算しました。これは外から一様な物差しを持ち込んだ計算です。住民の物差しは、山のある場所で伸びています。

ただし、空間の目盛の広がりだけを ω/k と比べた検証は成り立ちませんでした。比べ方に無理がありました。

答えは、置いた条件そのものでした。

　Σxₙ² ＝ 0 の光円錐です。

全体の回転の予算 R のうち、空間方向に回る分が k、張り付いた背景とのビートに回る分が m です。

　R² ＝ k² ＋ m²

速さは k/R、ローレンツ因子の逆数 1/γ は m/R です。時間の遅れも長さの縮みも、この一つの割合から出ます。

円周の上で、N ＝ 18 の成分を右回り a、左回り b の重みで置いて数値で確かめました。

- v² ＋ (1/γ)² ＝ 1 が、残差 10⁻¹⁵ で成り立つ。係数の形から、恒等式です
- 速さは重み比の対数で決まる。v ＝ tanh ln(a/b)
- 二つの速さを合成すると、相対性理論の速度合成則と小数 6 桁まで一致する。単純な和では 1 を超えるものも出る
- 質量 1/γ は、逆回りの二つの回転項の交差項 2ab の割合として読める

ヒッグス場に相当する背景は、外から置く必要がありませんでした。本当の二乗をとると、逆回りの回転項の交差項として出てきます。

## 第 2 段：なぜ三次元か

円周の住民は一次元です。次に、四次元の球殻（S³）の住民を考えます。表面に住む住民にとって、世界は三次元です。

条件を三つ並べます。

- 一様な並進が、固定点なしに群をなすこと。これを満たす球面は S¹ と S³ だけです
- 波が尾を引かずに伝わること（ホイヘンスの原理）。これは奇数次元だけです
- 住民が読める曲率があり、質量の隙間が生まれること。これは S¹ 以外です

三つを同時に満たすのは S³ だけです。

S³ では、位相の進みに曲率の項が付きます。質量の役をする項は、住民に読める曲率そのものから出て、R は Σxₙ² ＝ R² で波自身から決まります。

S³ を輪切りにすると、偶数成分は山の反対側（対蹠点）に同符号の山を立て、奇数成分は逆符号の山を立てます。両方がそろって初めて、位置が一点に決まります。

## スピン、電荷、観測

S³ の住民では、さらに次が読めます。

スピン。奇数と偶数の区別が、そのままスピン 1/2 と整数スピンです。S³ の並進は左からの四元数の積で、これがスピン 1/2 の生成子です。交差項はスピン 0 です。

一点に局在することと、スピンの固有状態であることは両立しません。スピンの固有状態は二点に局在し、反対側の逆スピンは誰にも観測できません。

電荷。S³ にはホップ・ファイバーと呼ばれる円周の束があります。その巻き数が電荷で、整数であることが量子化を与えます。

観測。粒子と観測者はどちらも住民で、観測は二つの波の交差項です。読めること、放射すること、エネルギーが分配されることは同じ出来事です。不確定性と量子化は、その帰結です。

## その先：電子、α、四次元格子、E₈

この系で電子を読むと、どうなるか。

電子を検証の場に選び、微細構造定数 α を入れます。前回の記事に出てきた数が、ここで使われます。

- 二つの波の交換が 124 回で元に戻る根 23/124。α⁻¹ の近傍の値 137.036042915… を与えます
- 四次元の格子で、半径 3 の球に入る単位セルの数 137 ＝ 1 ＋ 8 ＋ 128

四次元が背景である理由は、対角線の長さが整数（√4 ＝ 2）になる最小の次元で、そこでだけ 4 回対称と 6 回対称が一つの格子に同居するからです。見える空間が三次元である理由と、同じ答えの二つの面です。

四次元の格子の上で 23/124 の回転と格子への丸めを同時に課すと、半径を上げるにつれて近似分数の階段 1/6 → 3/16 → 5/27 → 13/70 → 23/124 を経て捕まります。

## 確かめた部分、仮説、検証の手段

論文は、この三つを分けて書いています。

確かめた部分（論文と数値実験で数値が出ているもの）。

- 奇数は二周、偶数は一周で閉じる。倍音の合成で一点に局在する
- 本当の二乗で R は虚数。一目盛りの測地線長は山の区間で 1.245 倍
- 円周で光円錐が恒等式として成り立ち、速度合成則と 6 桁一致する
- 一様な並進の群を持つ球面は S¹ と S³ だけ。ホイヘンスの原理は奇数次元
- 四次元格子で 23/124 への引き込み率が 86 パーセントに達する
- 二つのフルヴィッツ整数の接着で E₈ の 240 本が出る

仮説としてつないだ部分（対話の中で配置したもの）。

- 張り付いた位相がヒッグス場に相当する
- 電荷がホップ・ファイバーの巻き数である（巻き数と k の数値的な分離は未実施）
- 観測が粒子と観測者の交差項である
- なぜそのウィンドウにロックするかは、整数を選ぶ構造が近くにあるからである
- 宇宙の始まりから背景放射までが、同じ系の段として並ぶ

検証の手段。

- 第十一思考実験で作った水素原子の正解表。記録されない交換が 8170 MHz と 1057.85 MHz（ラムシフト）を出すか
- α の実測値 137.035999177 と、電子一個の g 因子から出る値 137.035999166 の差
- 背景放射の低い多重極に、4 回対称の系統の痕跡があるか

## 次に確かめること

- 二つの局在した波の交差項として、放射・吸収・反跳・引力を一つの計算で出す
- 電荷の巻き数と運動量 k を数値で分離する
- 分母が 4 の倍数の根を列挙し、N(R) が 137 付近に入るものを探す
- E₈ の接着条件の下で 23/124 と 101/124 を同時に回したとき、ロックできる組が絞られるか
