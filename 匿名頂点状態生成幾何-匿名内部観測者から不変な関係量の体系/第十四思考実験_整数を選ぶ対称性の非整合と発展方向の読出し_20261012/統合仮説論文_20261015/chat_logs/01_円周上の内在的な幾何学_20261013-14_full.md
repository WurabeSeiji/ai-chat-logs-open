$$\cos\psi=\cos\chi\cos\chi_0+\sin\chi\sin\chi_0\left[\cos\theta\cos\theta_0+\sin\theta\sin\theta_0\cos(\phi-\phi_0)\right]$$

S³ を単位四元数とみなせば、これは x = x0·e^{ψu}（u は純虚単位四元数）とも書けます。ψ は、仮想原点から見た点の「指数部の角度」そのものです。

**波形**
円周の式で φ/2 を ψ に置き換えると、次のようになります（振幅は iA = e^{α+iπ/2}）。

$$f_{\mathrm{odd}}=e^{\alpha+i\frac{\pi}{2}}\,\frac{e^{i(N+1)\psi}-e^{-i(N+1)\psi}}{2\left(e^{i\psi}-e^{-i\psi}\right)}$$

指数部 E は、これまでと同じく ln をとれば得られます。

**計算を軽くできる理由**
波がピーク一つの周りに対称（ピークからの角度だけの関数）なら、殻もピーク軸の周りの回転体になります。三つの θ0 は軸の向きを決めるだけです。すると問題は、ピーク（χ = 0）から対蹠点（χ = π）までの一本の子午線 r(χ) を求める一次元の問題に帰着します。二次元版との違いは次の二点だけです。

- **住民の位相**: ピークからの測地距離を、子午線に沿った弧長 s で測ります。位相は ψ = π·s(χ)/s(π) で、対蹠点が ψ = π です。
- **重心の重み**: 子午線上の各点は、半径 r sin χ の 2 次元球面を代表します。そのため重心の重みは弧長 ds ではなく (r sin χ)² ds になります。ピークと対蹠点の付近は重みがほとんどなく、赤道付近が重心を支配します。

**計算前に一つ決める必要があること**
S³ 上の成分 xₙ の形です。

- **(a) cos(nψ)**: 円周の cos(nφ/2) で φ/2 を ψ に置き換えた直接の対応です。R² = A²Σcos²(nψ) となり、二次元版と同じ式のまま比較できます。

u は、ln R² の虚部の傾斜（± 回転項の偏り）から決めることも、手で与えることもできます。全成分で共通です。

**段 3：配列演算で一度に回す**

qₙ = cos αₙ + sin αₙ·(u₁i + u₂j + u₃k) を、全格子点の四元数 p に左から掛けます。これで三成分が一回の積で同時に回ります。

```python
def angles(dphi, kappa):          # 段1: (Nc,)
    return dphi / kappa
def distribute(alpha, u):         # 段2: (Nc,3)
    u = np.asarray(u) / np.linalg.norm(u)
    return alpha[:, None] * u[None, :]
def apply(p, a):                  # 段3: p (M,4) -> (Nc,M,4)
    ang = np.linalg.norm(a, axis=1, keepdims=True)
    v = np.sin(ang) * a / np.where(ang == 0, 1, ang)
    q = np.concatenate([np.cos(ang), v], axis=1)[:, None, :]
    w, x = q[..., :1], q[..., 1:]
    pw, px = p[None, :, :1], p[None, :, 1:]
    return np.concatenate([w*pw - (x*px).sum(-1, keepdims=True),
                           w*px + pw*x + np.cross(x, px)], axis=-1)
```
