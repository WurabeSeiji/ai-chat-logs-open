## 2. 追記と先行論文の食い違い（著者確認が必要なもの）

1. **第17.1節の N=40・十字の帯・Mexican-hat・90°異方性の出典。** インフレーション機構 第2版の本文には N=40、十字の帯、Mexican-hat、「90°系列の異方性が終状態に残る」の記述がない（第2版は N=3〜16、宇宙論的類似は扱わないと明記 §1.2・§9）。これらは時間頂点化 K₄ 論文 §2 の図1〜4 にあり、図の元データは `干渉保存力学_資格審査とシード無し系列_20260831/make_parent型初期値_自己無撞着構造_20260907/full_N3_N40_sweep/states/hm_N40_den_40_states_500.npz`（未公開の干渉保存力学系列）である。時間頂点化 K₄ 論文は出典を [K1]＝インフレーション機構 第2版としているが、第2版本体には該当がない。仮説論文では図の出典を時間頂点化 K₄ 論文とその元データとして書くのが正確。
2. **第28節「飽和状態（段1+2+3掃引の終状態＝均質な真空）」と第2版 §7.3 の衝突。** 第2版では飽和後は少数の関係への局在（PR/M 0.05〜0.31）で、等分配（均質）は撤回済み（§9 の表、主張 8）。時間頂点化 K₄ 論文の N=40 リングは「ほぼ等振幅」で、これは干渉保存力学の走行。仮説論文で「均質な真空」と書くなら、どの力学の結果かを明記する必要がある。訂正済みの誤りを持ち込まない規則に関わるので、著者判断を仰ぐ。
3. **第17.1節「高い対称性を持つ自己無撞着な相対平衡のうち線形に不安定なもの」。** 第2版では対称性のない乱数均衡親（rb）も N=5〜13 で不安定、高対称の hm は奇数 N で中立。「高い対称性」は不安定性の条件ではない（§7.4）。
4. **第17.2節の2「Q_loop(m;K) に K=124 を入れると奇数の m ではすべて 0」。** 一般式 Q_loop(m;124)=124·1[124|2]+124·1[124|2m]=124·1[62|m] なので、奇数だけでなく 62 の倍数でない偶数 m でも 0 になる。偶奇の選択則は K=4 に固有（時間頂点化 K₄ 論文 §14 末尾も「一般 K では偶奇そのものではない」と明記）。(23+4k) が奇数であることは正しいが、Q_loop がそれを選んでいるわけではない。
5. **第17.2節の1「始まりの Z4 が 124 の因数として残る」と第2版 §3.4。** 第2版の刻み Δ=2π/124 は統一プロトコルで入力した値で、連続極限では時間の再径数化にしか効かない（§3.4）。124 が両方に現れることを、Z4 が残った証拠として使うことはできない（入力の一致）。
6. **第33.2節「接着条件を満たす u は ±1,±i,±j,±k の8個だけ」。** x∉(1+i)H のときに成り立つ。x∈(1+i)H なら x−ux∈(1+i)H は u によらず成り立つ（(1+i)H は両側イデアル）。プログラムは x を3点で確かめただけ。本文では条件を付けて書く。
7. **第26節の4「空隙の第二項 −6πR²」。** BH 論文3 では包除原理による Vol(Ω_R) の解析値だが、格子点誤差 E(R) の R² 寄与は未解決で、数値フィットの c₂ は −22〜−41（−6π=−18.85）と安定しない（§7.2）。第二項を使う議論は「解析値、数値未確認」と書く。
8. **第15・27節の吸収殻の要素数 N=10⁶⁰。** 第十一思考実験では N は置いた値で導出していない（非主張 11）。値は記録に現れないことも確かめている（§2.2）。電子の倍音本数の「10⁶⁰の桁」に結びつけるのはつないだ部分。
9. **ADM の文献。** 第十一思考実験 [60] は ADM 1962 "The dynamics of general relativity"。追記 第6・11節の「ADM 1960、発散は止まり質量はストーニー質量の大きさ」は別論文（自己エネルギーの論文）で、書誌確認が要る。
10. **第14節「自己無撞着になるのは 23/124 のロックだけ」と第十四思考実験 §7.6「ロックが見つかれば仮説が崩れる」。** E3 で回転数は 23/124 に厳密にロックするが、保存量（ノルム）一定の完全ロックは 480 本中 0 本、三つの 137 も一致しない。「回転数のロック」と「完全ロック」を分けて書けば両立する。用語の区別を本文で固定する必要がある。
11. **第14節「輪が閉じるのは 23/124 だけ」の根拠。** 現状の根拠は 17/92 が外れること（α⁻¹=138.885）だけで、分母が4の倍数の根を列挙して N(R) が 137 付近に入るものを数えた計算はない。閉じる条件（どの幅の窓か）も未定義。仮説論文では「つないだ部分」として書き、列挙を検証課題に置く。
12. **第14節「7月の粗い掃引で 0.7 が最もきれい、細かく掃引すると中心が R₁₂₄,₂₃ に収束」。** 粗い掃引（0, 0.51, …）は System A（局在性移乗、第十三思考実験の二波交換）、10⁻⁷〜10⁻¹² の細かい掃引は System B（白猫・黒猫・灰色猫）で行われた（K4 論文 §1.2〜1.3・§3〜4、第十三思考実験 §6.2）。同じ U_R を共有するが別の系。
13. **E2 README のウィンドウ内の値（137.0327〜137.0359）。** 第23節で撤回された幾何平均角の読み方による値。本文に持ち込まない（E3 の ρ_top を使う）。
