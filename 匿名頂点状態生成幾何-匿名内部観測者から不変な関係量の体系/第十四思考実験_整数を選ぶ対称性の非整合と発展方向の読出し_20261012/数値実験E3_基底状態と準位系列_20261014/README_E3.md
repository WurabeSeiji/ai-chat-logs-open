# 第十四思考実験 数値実験 E3（2026-10-14）

## 目的
E2 の系（四次元フルヴィッツ格子＋R₁₂₄,₂₃ の位相回転、外部時計なし）で、基底状態（完全ロック）と準安定な準位の系列を分け、基底状態から α を読む。

## E2 からの修正
回転数を、等傾回転の二つの複素成分の巻き数（整数）から求める位相幾何的な回転数 ρ_top=W/P に改めた。E2 の幾何平均角は四次元では加法的でなく、周期124の軌道でも 23/124 から 10⁻⁶〜10⁻⁵ ずれて見えていた。E2 のウィンドウ内の値はこの読み方によるもので、ρ_top では周期124の軌道はすべて厳密に 23/124 になる。

## 方法（te14_E3_ground_and_levels.py、E2 の te14_E2_hurwitz_124_23.py を同じフォルダに置く）
- 初期半径 16, 24, 32, 48, 64, 96 で各40点（乱数種 20261014）、軸 Z4・Z6。
- 基底状態の定義（事前固定）：ρ_top=23/124 かつ ノルム一定。
- 注意：E2 の結果を見た後に設計した。

## 結果
1. 完全ロック（ρ_top=23/124 かつ ノルム一定）の軌道は 480 本中 0 本。
2. ρ_top=23/124 の軌道は Z4 軸で 115/240（半径96で 85%）、Z6 軸で 6/240。いずれも周期内でノルムが変動する（回転数は厳密にロック、保存量は揺れる）。
3. 占有される準位：Z4 軸は 23/124 が最多、次いで 3/16、29/156、5/27、13/70。Z6 軸（三相の軸）は 5/27 が最多（141/240）。
4. 23/124 にロックした状態の読み出しは α⁻¹=137.036042915（観測値との相対差 3.19×10⁻⁷）。
5. 過渡区間は短く（数百更新）、準位を段階的に下る推移は見られなかった。

## 単位系（G=c=q₀=1、q₀=e/3、ガウス系）での読み
- α=9q₀²/(ħc) より ħ=9α⁻¹。ħ は入力ではなく α から決まる。
- 質量の単位 m₀=q₀/√G=6.1974×10⁻¹⁰ kg、mₑ=1.46988×10⁻²¹ m₀。相対不確かさは G の測定精度で約 1.1×10⁻⁵。
- 23/124 の読み出しと観測値の差（α で 3.2×10⁻⁷）は、この単位系での電子の質量の不確かさより小さく、棄却されない。
- 注：初版で記した「電子の質量が測定精度の約2000倍ずれる」という判定は、h を定義値とする SI（ħ を入力に置く単位系）で計算したもので、撤回する。
