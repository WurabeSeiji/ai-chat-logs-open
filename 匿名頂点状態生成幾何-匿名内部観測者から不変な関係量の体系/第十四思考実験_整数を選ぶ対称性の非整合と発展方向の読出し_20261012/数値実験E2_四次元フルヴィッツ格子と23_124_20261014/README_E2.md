# 第十四思考実験 数値実験 E2（2026-10-14）

## 目的
背景を四次元とし、対角線 (1,1,1,1) の長さが 2（整数）になる四次元固有の格子＝フルヴィッツ格子（整数点＋半整数点、Z4 と Z6 が共存）の上で、発展側の 23/124（K4論文 R₁₂₄,₂₃ の反対称固有位相 λₐ）と空間側の格子を同一状態に同時に課す（課題1・2・3）。

## 方法（te14_E2_hurwitz_124_23.py）
- 状態：フルヴィッツ整数 q。
- 更新：q←round_H(u q)、u=cos φ + I sin φ（左乗法）。外部時計なし。
- 軸 I：Z4 側＝i（λₐ³¹=i の四相）、Z6 側＝(i+j+k)/√3（三相、e^{Iπ/3}=(1+i+j+k)/2 は格子の単位）。
- φ：試験 2π·23/124、対照 2π/4・2π/6。
- 初期点：0<N≤9 の全フルヴィッツ点（半径3の球）936点。
- 読み出し（事前固定）：実効回転数 ρ、K4 の対応式による α_read⁻¹=4π/sin⁴(πρ)、ノルム変化、丸め同点。観測値は入力しない。
- 補助（te14_E2_radius_scan.py）：初期半径 3〜64 で各12点（乱数種 20261014）。

## 結果
1. 対照：Z4 軸の90°、Z6 軸の60°はいずれも全軌道が完全ロック（周期4・6、ノルム一定、同点0）。
2. 半径3（137セルの球）では、23/124 の回転は格子に完全に捕まる。Z6 軸では全軌道が 1/6（周期6、ノルム一定）にロック。Z4 軸では周期4・6・16 の軌道に落ちる。α_read⁻¹ はウィンドウに入らない。
3. 半径を大きくすると、実効回転数は 23/124 の連分数 [0;5,2,1,1,4] の近似分数の順に捕まりながら 23/124 に近づく：1/6 → 3/16 → 5/27 → 中間分数 13/70・18/97 → 23/124（周期124・248・372 の軌道が半径16以上で出現）。
4. 半径24以上の Z4 軸で、α_read⁻¹ がウィンドウ [137, 137.036043] に入る軌道が現れる（137.0327〜137.0359）。ウィンドウ外（上側）の軌道もある。値は軌道ごとにばらつき、単一値には収束していない。
5. 丸めの同点は全条件で0。

## 電子の質量
電子の質量は α から決まる：mₑ = 2hR∞/(α²c)（h, c は定義値、R∞ は水素分光で独立に測定、CODATA 2022 R∞=10973731.568157 m⁻¹）。
| α⁻¹ の値 | mₑ c²（MeV） |

| x₂₃/₁₂₄ = 137.036042915 | 0.5109992769 |

感度：δmₑ/mₑ = 2 δ(α⁻¹)/α⁻¹。
