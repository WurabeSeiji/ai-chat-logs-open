同じ作用を繰り返すだけでは足りず、作用そのものを状態で変えたら重力軌道が9本とも載りました

詳細はコメント参照

緩めたのは一箇所だけです。作用を固定するという仮定を外し、作用そのものを関係の状態の関数にしました
処理の番号は時刻ではありません。物理時間は面積の時計から別に読み出します
作用は回転と伸び縮みだけで作り、各処理で面積が保たれます。数値では |det−1| が 6.7e-16 以下です
判定基準は一本の軌道の精度ではなく、同じ作り方の規則を固定したまま別の軌道族へ移せるかにしました
一本の軌道から作用を逐次逆算するのは軌道の符号化にすぎず、相互作用則を得たことにはなりません
生成則を一切変えずに9条件へ移植でき、半径のずれは中央値 0.508%、最大 2.864%、弱場ほど系統的に改善しました
質量比を 1・2・4・10 と変えても、ずれは 0.508% から 0.438% と増えませんでした
内部は面積保存のまま、読み出された軌道は重力波で縮みます。内部の保存と観測される散逸は同じではありません
一般相対論を導出したのではなく、保存部は既知の解・散逸部は既知の式を使った表現可能性の試験で、軌道の縮みは全条件で基準の約92%どまり（約8%不足）です
