Repeating the same action was not enough; letting the action itself change with the state made nine gravitational orbits fit

Details in the comments

Exactly one thing was relaxed: the assumption that the action is fixed, making the action itself a function of the relational state
The processing number is not a time; the physical time is read out separately from the area clock
The action is built from a rotation and a stretch alone, so the area is preserved at every step; numerically |det-1| stays below 6.7e-16
The criterion is not the accuracy on one orbit but whether the same rule for making the action, held fixed, transfers to another family of orbits
Computing the action backwards from a single orbit is only an encoding of that orbit; it is not obtaining a law of interaction
Without changing the generating rule at all, it transferred to nine conditions: radial discrepancy 0.508% at the median, 2.864% at worst, improving systematically in weaker fields
Changing the mass ratio to 1, 2, 4 and 10 did not increase the discrepancy either: it went from 0.508% to 0.438%
Inside, the area stays preserved; the orbit that is read out shrinks by gravitational waves. Internal conservation and observed dissipation are not the same
General relativity was not derived: the conservative part uses a known solution and the dissipative part a known expression, and the orbital shrinkage stays at about 92% of the reference (about 8% missing)
