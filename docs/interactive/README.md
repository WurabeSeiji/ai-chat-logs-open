# interactive

対話型の図（HTML）の表示用の写し。GitHub Pages（https://wurabeseiji.github.io/ai-chat-logs-open/interactive/）でブラウザにそのまま表示するために置いている。

正本は `次元の生成構造/四元数を基本量とする思考実験_20261018/` の同名ファイル。正本を直したら、ここにもコピーし直す。

- quaternion_circle_gnomonic.html：四元円の切断、実部と虚部の分解、中心投影、光円錐
- quaternion_16cell.html：正十六胞体の配置と閉塞の判定
- quaternion_circle_icosa.html：最も対称な形（正二十面体、四元円の図と同じ形式）
- quaternion_light_cone_icosa.html：最も対称な形（正二十面体、正十六胞体の図と同じ形式）
