Supplement to the Sixth Thought Experiment: Does the State Generation Change When the Normalization Reference Is Changed from Mass to a Charge Unit? - A Restricted Renormalization from G = M = c = 1 to G = q_0 = c = 1, and an Exact-Match Verification of the Initial States of the Five Stored Conditions

第六思考実験 補遺：規格化基準を質量から電荷単位へ変更しても状態生成は変わるか

Noriaki Kihara (WF System Co., Ltd.) · ORCID 0009-0004-6753-4020 · 2026-09-27 · v1.0 · Series: Generative Structure of Dimensions

Abstract

The sixth thought experiment (10.5281/zenodo.22974631) internalized, under the normalization G = M = c = 1, the conservative effects of gravity and Coulomb and the dissipative effects of GW quadrupole and EM dipole radiation of a charged quasi-circular binary into eight persistent logical states Z_8 = (U, P, E, H, Q, N, C, D) and a single synchronous state map transition(z). It was confirmed there, by a code audit and numerical experiments over five conditions, that transition(z) receives no external physical argument other than the state z and that the difference of physical conditions is given only by N, C, D stored in the initial state. This supplement changes, for the same physical system, only the normalization reference, from G = M = c = 1 to G = q_0 = c = 1, where q_0 is the reference charge unit counting discrete charges, taken here as q_0 = e/3. No new dynamics, interaction term, state, update rule, readout or approximation is added; the only thing changed is the initialization that builds the initial state from the masses and the charges. With equal masses m_A = m_B = M/2 and charges q_A = s_A n q_0, q_B = s_B n q_0 (s = +1 or -1), the charge-to-mass ratios of the sixth thought experiment become lambda_A = s_A 2 n q_0 / M and lambda_B = s_B 2 n q_0 / M. Preserving the n = 1 condition |lambda| = 0.30 requires M / q_0 = 20/3, and with this single mass-to-charge ratio, n = 1, 3, 4 regenerate |lambda| = 0.30, 0.90, 1.20. This initialization was implemented as an independent initialization program and compared with the micro = 0 rows of the stored raw data raw_first_macro_microsteps.csv of the five conditions of the sixth thought experiment. In all five conditions the stored diagnostic columns micro, q_index, P, N, C, D, k1p, k2p, k3p, k4p, dP, Q, including the initial work registers, matched exactly as IEEE-754 values after reading the CSV. Since the sixth thought experiment has already audited that the next state is determined from the present state alone, z_{k+1} = T(z_k), the whole subsequent state sequence is identical to the existing experiment once the same initial state z_0 is generated; re-running the interaction runs would give no new independent verification and is not done here. The conclusion is restricted: for the five conditions of the sixth thought experiment, changing the normalization from G = M = c = 1 to G = q_0 = c = 1 with M / q_0 = 20/3 generates the same initial states and therefore does not change the existing state evolution. This is not a derivation of a new physical law; it restates the degree of freedom that had been absorbed into the mass reference as a mass-to-charge ratio referred to the charge unit. It does not claim that q_0 = e/3 is derived, that M/q_0 = 20/3 is a universal constant, or that the origin of mass or charge quantization is explained. The Japanese version is the original; the English version is a translation.
