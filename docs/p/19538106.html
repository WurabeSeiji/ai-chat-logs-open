Dimensional Interpretation of Geodesic Structure at the R→0 Limit

$R \to 0$ 極限における測地線構造の次元的解釈

Noriaki Kihara (WF System Co., Ltd.) · ORCID 0009-0004-6753-4020 · 2026-04-12 · Series: Central Projection Framework (Gnomonic Spacetime Geometry)

Abstract

We provide a unified description of the geodesic structure at the R -> 0 limit by integrating the nested structure (Paper [4]), dimensional hierarchy (Paper [6]), geodesic bridging (Paper [7]), and the Schwarzschild-de Sitter exact solution (Paper [9]). The R -> 0 limit is described as a two-stage process: dimensional collapse followed by dimensional reconstruction.
