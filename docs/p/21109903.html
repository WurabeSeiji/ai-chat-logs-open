Simulated Observation of the de Broglie Wavelength in a Localized Odd-Harmonic Double-Slit Model

局在奇数倍音ダブルスリット模型における de Broglie 波長の模擬観測

Noriaki Kihara (WF System Co., Ltd.) · ORCID 0009-0004-6753-4020 · 2026-07-01 · v0.3 · Series: Square-Quantity Readout Series

Abstract

A numerical experiment that simulates and observes the de Broglie relation lambda=h/p inside a single-source double-slit classical wave model. An electron is modeled as a spatially localized wave built from an equal-amplitude sum of odd harmonics (N>1). The central result is NOT the value of h (which is a near-tautological self-consistency, since lambda0=h/p is the input and the resonance lattice is dense ~1e-19 m): it is (i) that a highly localized odd-harmonic classical wave can survive two-slit interference as a sharp single peak only under an inter-harmonic alignment condition, and (ii) that the observed central fringe spacing DeltaX = lambda' D/W is set by the fundamental wavelength and is independent of the harmonic count N (N controls only the localization sharpness ~1/(N+1)). Scope is stated explicitly: this is neither a first-principles derivation of p*lambda=h nor a derivation of a Delta_x*Delta_p ~ h uncertainty relation. Each electron is given independent Monte Carlo draws of source position (cos^2, +/-lambda0/2) and initial wavelength (cos^2, +/-1%), with interference, alignment and exclusion recomputed exactly per trial.
