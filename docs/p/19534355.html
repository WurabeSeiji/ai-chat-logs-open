Realization of a Wave Packet Collapse Model in the Delay Circuit Model / ディレイ回路モデルでの波束の収縮モデルの実現

ディレイ回路モデルでの波束の収縮モデルの実現

Noriaki Kihara (WF System Co., Ltd.) · ORCID 0009-0004-6753-4020 · 2026-04-12 · Series: Wave Equation / Phase Equation & Delay-Circuit Model

Abstract

Defines class G in which wave packet radius r and maximum wave height w_max are promoted to information. Under conservation of mass analogue M = w_max · r, wave packet collapse is realized upon collision. / クラスGを定義し、波束半径rと最大波高w_maxを情報に昇格。質量の類似物M = w_max·rの保存下で波束の収縮を実現する。
