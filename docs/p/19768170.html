Considerations on Mass Structure: A Framework for Mass Analysis via Axis Scale Values and Signed Areas

質量構造の考察——軸スケール値と符号付き面積による質量分析の枠組み

Noriaki Kihara (WF System Co., Ltd.) · ORCID 0009-0004-6753-4020 · 2026-04-26 · Series: Other / Not stored in this repository

Abstract

A preliminary investigation into constraining the abstract mass mapping functions f_m^rest and f_m^curv defined in the companion paper on 6-dimensional hypercube particle classification (Definitions 9.4-9.5). Axis scale values and signed areas provide a framework for analyzing mass hierarchies among Standard Model particles.
